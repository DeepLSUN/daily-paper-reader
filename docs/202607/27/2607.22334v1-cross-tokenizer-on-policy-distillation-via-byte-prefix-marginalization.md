## 摘要
来自不同系列的开源语言模型展现出互补能力，促使通过同策略蒸馏（OPD）将其整合到一个紧凑的学生模型中。然而，全词汇OPD通常假设共享分词器，而现有的跨分词器方法可能会丢弃教师概率质量，或将其分配给内容不相关的学生分词。我们提出字节前缀边缘化（BPM），该方法在共享字节空间中重新表达教师对学生的下一词分布。具体而言，BPM将每个教师分词的概率分配给其字节表示为教师分词字节前缀的最长学生分词，将映射到相同学生分词的质量聚合，并将其他未匹配的质量置于一个显式的残差类别中。这为密集OPD生成了一个词汇完备、字节对齐且质量保持的目标。当相关前缀不跨越多个教师分词时（在超过99%的训练位置满足该条件），该目标精确恢复教师诱导的字节前缀边缘分布，否则使用质量保持的链式分解下界。以Qwen3-32B、GLM-Z1-9B-0414和MiniMax-M2.7为教师模型，BPM在六个数学和编程基准测试上持续优于当前的跨分词器方法，在六基准测试avg@8上比最强基线提高3.7-6.6个百分点。

## Abstract
Open-weight language models from different families exhibit complementary capabilities, motivating their consolidation into a compact student through on-policy distillation (OPD). However, full-vocabulary OPD typically assumes a shared tokenizer, while existing cross-tokenizer methods may discard teacher probability mass or assign it to student tokens with unrelated content. We introduce Byte-Prefix Marginalization (BPM), which re-expresses the teacher's next-token distribution over the student vocabulary in a shared byte space. Specifically, BPM assigns each teacher token's probability to the longest student token whose byte representation is a prefix of the teacher token's bytes, aggregates mass mapped to the same student token, and places otherwise unmatched mass in an explicit residual category. This produces a vocabulary-complete, byte-aligned, and mass-preserving target for dense OPD. The target exactly recovers the teacher-induced byte-prefix marginal when the relevant prefix does not span multiple teacher tokens (a condition satisfied at more than 99% of training positions) and uses a mass-preserving, chain-factorized lower bound otherwise. Across Qwen3-32B, GLM-Z1-9B-0414, and MiniMax-M2.7 as teachers, BPM consistently outperforms current cross-tokenizer methods on six mathematics and programming benchmarks, improving six-benchmark avg@8 by 3.7-6.6 points over the strongest baselines.

# 结构化论文总结

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：不同系列的开源大语言模型（如 Qwen、GLM、MiniMax）在数学推理、代码生成等方面展现出互补的能力。在实践中，需要将这些能力整合到单个紧凑的学生模型中，以提高推理效率和降低部署成本。**同策略蒸馏（On-Policy Distillation, OPD）** 是一种有效方法：让学生模型在自己生成的轨迹上模仿教师模型的预测行为。
- **关键挑战**：全词汇 OPD 通常假设教师和学生使用相同的分词器（tokenizer）。这限制了教师的选择范围，可能错过更强大的异源教师。若要扩展至不同分词器，必须满足三个属性：
  - **(D1) 词汇完备性**：目标分布对学生词汇表中每个 token 都有定义。
  - **(D2) 字节级对齐**：根据 token 的字节表示建立教师概率与学生 token 之间的对应关系。
  - **(D3) 质量保持**：转换过程保留教师总概率质量（包括显式的残差质量）。
- **现有方法的缺陷**：
  - 候选集方法（如 SimCT）丢弃未匹配的教师质量，违反 D1。
  - 排序匹配方法（如 ULD、GOLD）可能将教师质量分配给字节内容无关的学生 token，违反 D2。
  - 序列级方法（SeqKD）不提供全词汇分布目标。
- **本文贡献**：提出 **字节前缀边缘化（Byte-Prefix Marginalization, BPM）**，在共享字节空间中对齐教师和学生分布，同时满足 D1-D3，并系统性评估跨三个不同分词器距离的教师-学生对的蒸馏效果。

## 2. 论文提出的方法论

### 核心思想
- 利用**字节表示**的共享性：尽管教师和学生 tokenizer 对同一响应产生不同词序列，但它们解码后得到相同的字节流。
- 将教师的下一词分布**边缘化**为学生 tokenizer 在字节空间中的前缀匹配分布，从而得到定义在学生词汇表上的完整分布。

### 关键技术细节
- **定义**：给定对齐的学生位置 i 和对应教师位置 j(i)，教师分布 q₍ⱼ₎(w) 中每个 token w 被映射到**最长字节前缀匹配的学生 token**：
  - φ(w) = argmax_{u ∈ Vₛ, bytes(u) ⪯ bytes(w)} |bytes(u)|，若无匹配则 φ(w)=⊥。
- **目标构造**：
  - 对齐边界位置：tᵢ(u) = Σ_{w: φ(w)=u} q₍ⱼ₎(w)，tᵢ(∅) = Σ_{w: φ(w)=⊥} q₍ⱼ₎(w)。这保证质量守恒。
  - 教师 token 内部位置（学生精分）：类似条件概率计算。
  - **跨 token 情况（spanning）**：当学生 token 跨越多个教师 token（如 `</think>` 在教师中拆为三个），采用**链式分解下界**：tᵢ(u) = (∏_{k=j}^{j+m-1} qₖ(wₖᵗ)) · πⱼ₊ₘ(r)，确保质量保持。
- **训练目标**：
  - 使用广义 **Jensen–Shannon 散度** D_β，默认 β=1/2。端点处理：前向 KL (β=0) 和偏斜反向 KL (β=1, λ=0.1)。
  - **空白行掩码**：针对代码数据中全空白 token 位置，预计算掩码排除这些行，防止学生学到分词器特有的缩进噪声。
  - **停止标记处理**：定义教师和学生的停止集合，通过 φ 映射教师停止 token 到学生实际停止 token，并设置桥接目标（bridge target）训练于 D₀。
- **算法流程**（Algorithm 1）：
  - 预计算：为学生词汇表构建字节 Trie，为每个教师 token 计算 φ。
  - 训练时：对每批次中每个响应，确定每条学生 token 的位置类型（对齐边界 / 内部 / 跨越），计算对应目标，应用空白掩码，计算损失并更新参数。

## 3. 实验设计

- **BPM 在跨分词器蒸馏中显著优于所有基线**：在所有三个教师-学生对上，BPM 的 best 变体在六基准 avg@8 上分别超过最强基线 3.7、6.6、5.9 个百分点。
