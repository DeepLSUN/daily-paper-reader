## 摘要
具有可验证奖励的强化学习（RLVR）已成为提升大语言模型推理能力的高效框架，其中GRPO等方法是最成功的实例之一。然而，GRPO依赖于重复生成长链思维展开，训练时间随展开数量增长，而其中大部分展开信息量不足。因此，GRPO计算成本高且不稳定。为缓解这一问题，现有方法要么生成更大的展开池并过滤信息最丰富的提示，要么在训练后期利用历史信号进行过滤。这些策略带来了适度的性能提升，但减慢了整体进程。为此，我们提出方差引导的在线展开分配（VIGOR），该方法不是为每个示例分配固定的展开预算，而是从批次中所有示例的少量展开开始，迭代地向具有最高组奖励方差的示例分配额外展开，直至达到固定的总展开预算。理论上，我们证明在RLVR下，奖励方差控制梯度大小，并推导出VIGOR相对于GRPO的闭式加速比，该加速比在帕累托分布奖励方差下随精炼轮次增加而增长。在数学推理和编程任务上的实验表明，VIGOR在数学任务上达到目标精度所需展开数减少多达2.3倍，在编程任务上达到GRPO的最终通过率所需展开数减少1.49倍，并将编程平均测试通过率提高3.4个百分点。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) has emerged as a highly effective framework for improving LLM reasoning, with methods such as GRPO among its most successful instantiations. However, GRPO relies on repeated generation of long chain-of-thought rollouts. Training time scales with the number of rollouts, a large fraction of which are uninformative. Thus, GRPO is computationally expensive and unstable. To mitigate this, existing approaches either generate a larger pool of rollouts and filter the most informative prompts, or leverage historical signals for filtering at later stages of training. These strategies offer modest performance gains, but slow down the overall process. To address this, we propose VarIance Guided Online Rollout allocation (VIGOR) which instead of allocating a fixed rollout budget per example, begins with a small number of rollouts for all examples in a batch and iteratively allocates additional rollouts to those with the highest group reward variance until a fixed total rollout budget is reached. Theoretically, we show that under RLVR, reward variance controls the gradient magnitude, and derive VIGOR's closed-form speedup ratio over GRPO, which grows with refinement rounds under Pareto-distributed reward variance. Experiments on mathematical reasoning and coding tasks show that VIGOR reaches target accuracy with up to 2.3$\times$ fewer rollouts on math, reaches GRPO's final coding full pass rate with 1.49$\times$ fewer rollouts, and improves the coding average test pass rate by 3.4 points.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：基于可验证奖励的强化学习（RLVR）中，GRPO 算法需要为每个 prompt 生成大量 chain-of-thought rollout，但其中大部分是“无信息”的（例如组内奖励方差为零或很小），导致计算成本高昂且训练不稳定。
- **动机**：现有方法（如 DAPO 预生成大量 rollout 再过滤、GRESO 利用历史统计采样困难样本、RL-ZVP 修改目标函数）要么增加额外计算开销，要么收益有限且拖慢整体进程。因此需要一种高效的自适应 rollout 分配策略，在不修改 GRPO 目标的前提下，聚焦于信息量最大的 prompt。
- **整体含义**：提出 VIGOR（VarIance Guided Online Rollout allocation），通过在线组奖励方差指导 rollout 的迭代分配，显著提升训练效率，理论推导加速比，并实验证明在数学推理和编程任务上的有效性。

## 2. 方法论

### 核心思想
- 不采用固定 rollout 预算均匀分配给所有 prompt，而是**从少量 rollout 开始**，根据每个 prompt 的组奖励方差（u = Var(rewards)）逐步增加预算，仅保留方差最高的 prompt 进行后续生成，直到达到总 rollout 预算上限。

### 关键技术细节
- **理论动机**：在二元奖励（+1/-1）下，GRPO 的梯度范数上界与组奖励标准差 σ 成正比（Theorem 1），因此方差越大的 prompt 提供越强的梯度信号，即信息量更大。
- **算法流程**（Algorithm 1）：
  1. 每个训练 step 采样一个 batch B。
  2. 初始化所有 prompt 的 rollout 集合为空，初始预算 m0。
  3. 迭代 T 轮（refinement rounds）：
     - 当前轮 active 集合 At 中的每个 prompt，生成 m(t) 个 rollout 并加入其集合。
     - 计算每个 prompt 的奖励方差 u(t)。
     - 保留 top-α 比例（α<1）的 prompt 进入下一轮 At+1。
     - 被保留的 prompt 预算乘以扩张因子 γ（γ>1）。
  4. 使用所有保留的 rollout 进行标准 GRPO 更新。
- **预算守恒条件**：αγ = 1 时总 rollout 数不变；可设置 αγ > 1 以加大高方差样本权重（compute-skew 情况）。
- **理论加速比**（Theorem 2）：假设 prompt 方差符合 Pareto 分布，VIGOR 相对 GRPO 的特征时间尺度比 τ_GRPO/τ_VIGOR = Θ((α^{-1/k})^{T/3})，随迭代轮数 T 和尾重程度（k→1）指数增长。

## 6. 主要结论与发现

- VIGOR 显著提升了 GRPO 的训练效率，在数学任务上达到相同精度需要最多 2.3× 更少 rollout，在编程任务上达到 GRPO 最终全通过率需要 1.49× 更少 rollout，并将平均测试通过率提高 3.4 个百分点。

- VIGOR 在训练过程中自然引出“课程学习”（emergent curriculum），即自动将更多 rollout 分配给较难 prompt。
- 初始两轮 rollout 的方差估计误判率低（仅有 7.9% 的高方差 prompt 被误判为低方差）。

## 7. 优点

- **简单高效**：不修改 GRPO 目标，即插即用；增量生成 rollout，无需预先生成大量样本再过滤，不增加额外计算开销。
- **理论扎实**：给出梯度范数与方差的关系，并推导出加速比公式，解释性能提升机理。
- **实验全面**：涵盖多种模型规模、任务类型、对比方法和消融实验，结果一致。
- **实际增益**：不仅节省消耗（rollout 数/时间），还经常提升最终精度，尤其在编程任务上提升显著。
- **自适应**：能自动聚焦高方差 prompt，体现 emergent curriculum，无需人工设置难度分级。

## 8. 不足与局限

- **理论假设限制**：梯度上界推导假设二元奖励和重要性采样梯度有界；加速比推导假设 Pareto 分布，这些在连续奖励或非均匀分布下可能不成立。
- **实验覆盖不足**：
  - 编程仅测试了 Qwen3-8B，未在更多模型（如 7B、14B）上验证。
  - 未在非推理任务（如一般对话、安全性）上测试 RLVR 适用性。
  - 未与最新的自适应 rollout 方法（如 AR3PO、XRPO）进行直接对比。
- **初始方差估计风险**：m0=2 可能偶尔错过真正高方差的 prompt（但实验表明误判率低，且后续 epochs 可重新选中）。

- **消融深度**：对无效 rollout 比例和课程学习的分析较定性，缺乏量化指标衡量其对加速的贡献。
