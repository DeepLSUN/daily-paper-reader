## 摘要
大型语言模型（LLMs）在一系列自然语言处理（NLP）任务中展现了卓越的能力，但其高计算和内存需求对部署在资源受限的边缘设备上构成了重大挑战。现有的模型压缩和优化方法通常依赖于粗粒度的剪枝或量化，这可能会损害准确性或需要重新训练和微调。在这项工作中，我们提出了SelectInfer，一种神经元级别的优化框架，通过选择性神经元加载和计算实现端侧设备的LLM高效推理。通过使用离线LLM分析器对任务特定和通用神经元进行分析和识别，SelectInfer实现了两项关键优化：选择性加载，通过仅加载在离线阶段被识别为最重要的神经元子集来减少内存占用；以及选择性计算，在运行时仅动态计算最相关的神经元。在多个数据集上的评估表明，SelectInfer在保持任务性能的同时，显著减少了内存占用和计算量，为在端侧设备上部署LLM迈出了实际的一步。

## Abstract
Large Language Models (LLMs) have demonstrated remarkable capabilities across a range of Natural Language Processing (NLP) tasks, but their high computational and memory demands pose significant challenges for deployment on resource-constrained edge devices. Existing approaches to model compression and optimization often rely on coarse-grained pruning or quantization, which can compromise accuracy or require re-training and fine-tuning. In this work, we introduce SelectInfer, a neuron-level optimization framework that enables efficient LLM inference on edge devices through selective neuron loading and computation. By profiling and identifying both task-specific and general-purpose neurons using an offline LLM profiler, SelectInfer implements two key optimizations: selective loading, which reduces memory footprint by selectively loading a subset of neurons that were identified to be most important during the offline stage, and selective computation, which dynamically computes only the most relevant neurons at runtime. Evaluation across multiple datasets shows that SelectInfer achieves significant reductions in memory footprint and computation while preserving task performance, making it a practical step towards enabling LLM deployment on edge devices

# SelectInfer 论文详细总结

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：大型语言模型（LLMs）在边缘设备（如NVIDIA Jetson Orin Nano）上部署面临严重的内存和计算瓶颈。传统方法如粗粒度剪枝、量化会损害精度或需要昂贵的重新训练；运行时稀疏方法（如CoreInfer）虽加速推理但仍需加载完整模型，无法解决内存不足问题。
- **背景**：边缘设备对隐私、离线能力和低延迟的需求日益增长，但现有方法无法同时优化内存占用、推理速度和输出精度这三个关键维度。
- **整体目标**：提出一种神经元级优化框架，通过选择性地加载和计算最关键的神经元，在保持任务性能的前提下显著降低内存和计算开销，实现LLM在资源受限设备上的实际部署。

## 2. 方法论：核心思想、关键技术细节
### 核心思想
- 发现LLM神经元存在双重结构：**模型特定神经元**（跨任务稳定激活的通用神经元）和**任务特定神经元**（任务内一致激活但跨任务差异大的神经元）。离线分析可预先识别这两类神经元，从而在运行时进行精准的选择性加载和计算。

### 关键技术细节
1. **离线LLM分析器（LLM Profiler）**：
   - 对多个数据集（如PiQA、CNN/DailyMail、WMT16）进行推理，记录每个FFN层神经元的绝对值激活值。
   - 对每个神经元计算得分：$s_n = \sum_{t \in T} |a_n(t)|$，其中 $T$ 为所有token，$a_n(t)$ 为激活值。
   - 合并同一任务的得分文件得到任务特定神经元，跨任务合并得到模型特定神经元，输出按重要性排序的神经元索引文件。

2. **选择性加载（Selective Loading）**：
   - 将FFN神经元分为 **基础神经元**（任务特定，占$\delta$）和 **二级神经元**（模型特定，补足至总加载比例$\gamma$）。
   - 仅加载重要性排名前$\gamma$的神经元（包括对应的权重矩阵切片），丢弃其余神经元，从而减少内存占用。
   - 参数$\gamma$由设备内存上限决定（实验中$\gamma = 70\%$），仅应用于中间层（跳过首尾敏感层）。

3. **选择性计算（Selective Computation）**：
   - 在运行时进一步减少计算量：将加载的神经元分为 **静态神经元**（等于基础神经元，固定计算）和 **动态神经元**（根据当前输入提示在prefill阶段动态选择，占$\epsilon$）。
   - 动态选择过程：对输入token，计算所有加载神经元的激活值，取top-$\alpha$；统计所有token中神经元出现频率，取top-$\beta$作为动态神经元集；静态+动态神经元合计计算比例$\phi = \delta + \epsilon$。
   - 实验中$\phi = 40\%$（$\delta=30\%$, $\epsilon=10\%$），实现了内存和计算的双重削减。

## 6. 主要结论与发现
1. **神经元双重结构**：LLM中存在跨任务通用的模型特定神经元和任务内专用的任务特定神经元，两者互补。
2. **SelectInfer有效性**：在保持竞争性精度的前提下，显著降低内存（3B模型从6.88GB降至5.97GB，降幅13.2%）和提升解码速度（Llama3.2-3B达9.85 tokens/s，比4-bit量化快1.53×，比磁盘卸载快13×）。
3. **选择性加载优于随机加载**：随机加载导致精度崩溃，而基于离线分析的选择性加载能稳定保留大部分性能。
4. **选择性计算进一步改善精度**：相比仅使用选择性加载（CoreInfer+Selective Loading），结合动态神经元选择（SelectInfer）可大幅提升翻译等任务的BLEU分数（例如从1.70提升至25.68）。
5. **可配置权衡**：用户可通过调整加载比例$\gamma$和计算比例$\phi$灵活调节内存-速度-精度的平衡点。
