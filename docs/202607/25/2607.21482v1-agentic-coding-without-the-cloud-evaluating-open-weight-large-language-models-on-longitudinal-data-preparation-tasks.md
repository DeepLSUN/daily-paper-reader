## 摘要
大型语言模型（LLM）及其代理现已广泛应用于代码开发，数据通常被发送至第三方云端模型。然而，在涉及个人数据的研究中，其应用受到治理要求的约束，通常禁止将数据传输至外部服务。本地可部署的开源权重模型提供了一种替代方案，因为敏感数据始终不会离开本地环境。我们引入了一个开源框架，用于评估基于开源权重LLM的AI代理在纵向人群研究中最持久的瓶颈之一——数据准备——上的效能。该框架包括：一个精心策划的真值数据集（来自英国队列研究的六轮数据清洗脚本）、涵盖类别统一和多波次合并等任务的定义，以及自动评估LLM生成的R代码和输出数据的程序。我们在（消费级）部署光谱上对LLM进行基准测试，以评估其在20个数据准备任务（创建102个变量）中的效能。当前最先进的31-35B参数模型几乎饱和了我们的基准（“平均任务完成度”高达87.9%）。在消费级硬件上运行的开源权重LLM的性能显示出在治理受限的研究环境中实现AI辅助数据准备的可行路径。我们的框架公开可见于：https://github.com/UCL-ARC/RRBench。

## Abstract
Large language models (LLMs) and agents are now widely used tools in code development, with data typically sent to third-party cloud-based models. Their adoption in research using personal data is constrained by governance requirements that typically prohibit data transmission to external services. Locally deployable open-weight models offer an alternative since sensitive data never leave the local environment. We introduce an open-source framework for evaluating the efficacy of AI agents powered by open-weight LLMs on one of the most persistent bottlenecks in research on longitudinal population studies: data preparation. The framework comprises: a curated ground-truth dataset (cleaning scripts preparing six sweeps of data from a British cohort study), task definitions encompassing tasks such as category harmonization and multi-wave merging, and automated routines for evaluating the LLM-produced R code and outputted data. We benchmark LLMs across the (consumer grade) deployment spectrum to assess their efficacy in 20 data preparation tasks (creation of 102 variables). Current state-of-the-art, 31-35B parameter models almost saturated our benchmark ("average task completion" up to 87.9%). The performance of open-weight LLMs running on consumer-grade hardware shows promise of a viable path toward AI-assisted data preparation in governance-restricted research settings. Our framework is publicly available at: https://github.com/UCL-ARC/RRBench.

### **1. 核心问题与整体含义 (研究动机和背景)**

- **核心问题**：在量化健康和社会科学领域，数据准备工作（如变量重编码、多波次数据合并、指标构建等）极为耗时且容易出错，构成了研究效率的主要瓶颈。同时，这些研究常涉及敏感的个人数据，受到严格的数据治理规定限制，禁止将数据传输至外部云服务（如前沿LLM服务）。
- **研究动机**：探索一种既能利用AI（特别是LLM）提高数据准备效率，又能确保敏感数据不外泄的可行方案。
- **整体含义**：该研究旨在验证在消费级硬件上本地部署的开源权重LLM，是否能够胜任纵向健康和社会科学调查数据的准备任务，从而为治理受限的研究环境提供一条AI辅助数据准备的有效路径。研究结果表明，即便是在本地部署，当前最先进的开源模型也已展现出接近饱和的性能，具有巨大的应用潜力。

### **2. 方法论**

- **核心思想**：构建一个标准化的开源评估框架（RRBench），用于客观、可复现地评估LLM在特定领域（纵向调查数据准备）的自动化能力。该框架通过让LLM代理自动执行数据准备任务，并将其输出与人类专家构建的真值数据进行对比，来量化模型性能。
- **关键技术细节**：
    1.  **真值数据集构建**：基于真实的纵向队列研究“Next Steps”数据，由领域专家使用R语言编写并经过同行评审的清洗脚本，处理6轮调查数据，形成一个包含102个变量的“真正”标准数据集。
    2.  **任务定义**：将真值数据集拆解为20个不同复杂度的“任务”。每个任务包含：
        - **提示词**：向LLM代理描述所需生成的变量、逻辑要求和命名规范的详细或简化指令。
        - **输入数据**：原始的、未经处理的调查数据文件和元数据（JSON格式，包含变量名、标签、值标签等）。
    3.  **自动化评估例程**：
        - **LLM代理**：使用Hugging Face的轻量级框架`SmolAgents`构建AI代理，它接收任务描述和工具函数（如执行代码），由LLM驱动，能自主迭代地编写并执行R代码，直到生成最终数据集。
        - **性能评估**：将LLM生成的输出数据集与真值数据集进行逐变量、逐单元格的对比。核心指标包括：
            - **完整度**：生成的目标变量占所有预期变量的比例。
            - **正确度**：在生成的变量中，满足精度阈值（分类变量95%单元格一致；连续变量归一化RMSE < 10⁻⁴）的变量比例。
            - **均衡性能**：完整度与正确度的乘积，衡量整体准确性。
            - **平均任务完成度**：每个任务中成功生成的平均变量比例。
- **算法流程**：代理循环 (1) 读取输入数据和提示 -> (2) 生成并执行R代码 -> (3) 检查执行结果和错误 -> (4) 若出错则迭代修改代码 -> (5) 执行成功或达到重试次数上限后输出最终数据集。然后，评估模块将该数据集与真值数据集进行比对。

### **3. 实验设计**

- **数据集/场景**：使用了英国“Next Steps”纵向研究调查的原始数据。该研究追踪了出生于1989-1990年的青少年，数据涵盖多轮（wave）调查，包含人口统计学、教育、健康、社会经济等多种变量类型，非常具有代表性。
- **Benchmark**：论文自身提出的基准测试（RRBench），包含20个覆盖不同复杂度的数据准备任务。这些任务被分类为：波次特定逻辑、分类法压缩、缺失值处理、跨波次合并等操作。
- **对比方法**：评估了8个不同的开源权重LLM，覆盖不同的参数规模和架构：
    - **高端消费级**：Gemma 4 31B (Dense), Qwen3.6-35B-A3B (MoE), Qwen3.5-35B-A3B (MoE), Devstral-Small-2-24B-Instruct (Dense).
    - **消费级**：GPT-OSS-20B (MoE), Ministral-3-14B-Instruct (Dense), Qwen3.5-9B (Dense).
    - **轻量级**：Gemma 4 E4B (Dense).
- **对比方式**：所有模型均在相同的20个任务上，使用相同的代理框架和提示（分为详细版和精简版）运行，最终将其输出与同一个“人类专家”构建的真值数据集进行比较。

### **4. 资源与算力**

- 论文没有提供训练LLM所使用的算力资源信息（如GPU型号、数量、训练时长），因为本研究是对现有、预训练好的开源模型进行推理/微调级别的评估，而非从头训练。
- **论文提及了模型部署的门槛**，例如“高消费级”模型需要单张24GB GPU (如 RTX 4090/3090) 或32GB+ Mac。这概括了运行这些模型所需的本地硬件资源。所有模型都使用了量化版本在评估环境中运行。

### **5. 实验数量与充分性**

- **实验数量**：
    - **主要实验**：评估了8个模型在20个任务上的表现，每个任务重复3次（3 runs），共进行了 8 * 20 * 3 = 480 次 LLM代理运行。
    - **下游分析**：选取了3个变量组（性能高、中、低），进行了6个简单线性回归的下游分析。
    - **敏感性分析**：
        - 测试了不同分类变量精度阈值 (80%-100%) 对性能的影响。
        - 评估了“精简版”提示（20个任务）与“详细版”提示的对比。
        - 在比较中排除了缺失值，以探究其影响。
- **充分性与公平性**：
    - **充分性**：实验覆盖了多种模型规模、多种任务类型和多次运行，共产生了数百个结果，足以支撑其结论。下游分析和敏感性分析增强了结论的可靠性。
    - **客观与公平**：
        - **公平性**：所有模型在完全相同的条件（任务、提示、代理框架、评估指标）下进行测试。使用固定的、预先设定的精度阈值，避免了主观判断。
        - **潜在偏差**：
            1.  **任务来源单一**：真值数据仅来自一个“Next Steps”队列研究，这限制了任务类型的多样性，模型的通用性有待更多不同场景的验证。
            2.  **评估语言单一**：仅使用了R语言。虽然R在社会科学领域常用，但未测试Python等更通用的语言，评估存在语言偏差。
            3.  **提示设计主观性**：论文承认提出一个“最优”提示非常困难，不同设计会影响结果。尽管有详细和精简两种提示，但仍有主观因素。
            4.  **任务定义依赖人类判断**：任务的分割和复杂操作分类依赖于作者的手动审查，可能引入主观性。

### **6. 主要结论与发现**

1.  **本地部署可行**：在消费级硬件上运行的开源权重LLM，在纵向数据准备任务上展现了有意义的性能，为治理受限环境中的AI辅助数据准备提供了可行路径。
2.  **模型越大越好，正确性是关键**：模型性能基本随参数规模增大而提升（Gemma 4 31B与Qwen3.6-35B-A3B最佳）。**正确度**是区分模型好坏的关键因素，而非完整度（所有模型都能识别正确的变量集）。
3.  **任务复杂性是瓶颈**：任务复杂性（如需要理解特定调查元数据、复杂的多波次逻辑、多输入变量推导）与成功率呈强烈负相关。通用概念（如性别、BMI）的任务完成度高，而特定调查相关任务（如住房所有权、家庭收入）则普遍困难。
4.  **提示词重要性**：提供详细的、包含具体逻辑的提示词对性能至关重要。“精简版”提示导致性能显著下降。
5.  **下游影响巨大**：最差模型（Ministral 3 14B）产生的数据看似正常，但包含“静默错误”（例如错误处理缺失值），这些错误在回归分析中导致了方向性甚至数值大小的显著变化，改变了研究结论。最佳模型（Gemma 4 31B）则完美复现了真值系数。
6.  **当前模型近乎饱和**：当前最先进的31-35B参数模型（如Gemma 4 31B）在详细提示下“平均任务完成度”达到87.9%，几乎饱和了该基准测试，暗示未来提升的瓶颈可能在于任务理解，而非法代码生成能力。

### **7. 优点**

1.  **填补空白**：针对健康和社会科学领域的特定需求（R语言、元数据理解、纵向数据分析）构建了新的基准测试，补充了现有通用软件工程基准的不足。
2.  **真实世界数据**：使用来自真实队列研究的数据和人类专家的真值，确保了评估的现实性和应用价值。
3.  **框架开源、可扩展**：RRBench框架设计为开源、可移植的，其他研究者可以轻松地将其应用于自己的数据集、编程语言或研究问题，具有很强的社区价值和可复现性。
4.  **全面评估维度**：不仅评估了变量创建级（完整度、正确度），还评估了下游分析影响（回归系数比较），使结论更具说服力和实用性。
5.  **方法论严谨**：提供了清晰的定义、详细的实验设置（重复次数）、系统的评估指标以及全面的敏感性分析。

### **8. 不足与局限**

1.  **任务与数据的领域限制**：基准测试完全基于单一英国队列（Next Steps），其任务和元数据模式具有特定性。结论的普适性需在更多不同的队列、问卷和调查环境中验证。
2.  **评估语言单一**：仅评估了R语言，未涵盖Python、Stata、SAS等其他在更大范围研究者中使用的语言，限制了框架的即时扩展性。
3.  **全自动vs.人机协作**：实验设置要求LLM完全自主完成任务，但实际应用中研究者可能更倾向于将其作为“编码副驾驶”使用。论文承认这一差距，并建议人机协作是当前更现实的模式。
4.  **资源门槛仍未完全消除**：表现最佳的模型仍需要高端消费级显卡硬件才能本地部署。对于只有普通电脑的研究者来说，仍存在使用壁垒。
5.  **提示设计的主观性**：虽然尝试了详细和精简两种提示，但提示的质量和设计方式对结果影响巨大。研究中没有系统性地探索或优化提示策略，可能存在未探索的偏差。
6.  **缺乏人类对照**：实验设计只将模型与“人类专家”的最终真值结果对比，但没有设置一个“其他人类研究者”的对照组，以比较LLM与普通研究人员相比的效率或错误率。
7.  **Meta假阳性问题**：在评估正确度时，论文设定了95%一致性的阈值，可能会对某些高度统一但仍存在细微差异的范畴产生误判。
