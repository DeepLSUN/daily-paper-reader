## 摘要
监督微调（SFT）能够为高性能计算（HPC）任务（如数据竞争检测和基准问答）赋予大语言模型（LLMs）领域知识。然而，仅凭知识并不能保证任务适当的行为：同一个SFT模型在正确分类88.65%的C/C++数据竞争样本的同时，却会对事实性查询产生冗长、不精确的答案，其中65.9%的MLPerf响应超过40个字符。强化学习（RL）后训练通过优化任务特定奖励而非令牌级模仿来解决这一差距。然而，HPC任务表现出极度的异构性，二分类、事实性QA和语义生成在答案长度上相差58倍，跨越三个不同的奖励分布，并显示出入较大的SFT准确性。这使得GRPO等统一权重RL方法次优。我们提出HARGO，异构感知奖励引导优化，它通过置信度调制优势引入每个响应的重要性权重：从组级奖励对比中计算判别信号，从参考模型对数概率中计算置信度信号，然后在计算每个响应的权重之前调制优势，无需任务类型标签。在四个HPC任务和九种方法中，HARGO在所有三个主要指标上均取得最佳性能：WinRate 54.62%，数据竞争F1 91.30%，PLP相似度0.8558。消融研究证实了两种信号的互补贡献。HARGO在异构HPC任务的比较方法中确立了最佳的整体对齐质量。

## Abstract
Supervised fine-tuning (SFT) can equip large language models (LLMs) with domain knowledge for high-performance computing (HPC) tasks such as data race detection and benchmark question answering. However, knowledge alone does not guarantee task-appropriate behavior: the same SFT model that correctly classifies 88.65\% of C/C++ data race samples produces verbose, imprecise answers to factual queries, with 65.9\% of MLPerf responses exceeding 40 characters. Reinforcement learning (RL) post-training addresses this gap by optimizing for task-specific rewards rather than token-level imitation. Yet HPC tasks exhibit extreme heterogeneity, with binary classification, factual QA, and semantic generation differing by 58x in answer length, spanning three distinct reward distributions, and showing widely varying SFT accuracy. This makes uniform-weight RL methods such as GRPO suboptimal. We propose HARGO, Heterogeneity-Aware Reward-Guided Optimization, which introduces per-response importance weighting via confidence-modulated advantage: computing a discrimination signal from group-level reward contrast and a confidence signal from reference model log-probabilities, then modulating the advantage before computing per-response weights, without requiring task-type labels. Across four HPC tasks and nine methods, HARGO achieves the best performance on all three primary metrics: WinRate 54.62\%, Data Race F1 91.30\%, and PLP Similarity 0.8558. Ablation confirms complementary contributions from both signals. HARGO establishes the best overall alignment quality among compared methods for heterogeneous HPC tasks.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：在高性能计算（HPC）领域，大语言模型（LLM）的落地应用通常依赖监督微调（SFT）来注入领域知识。以 HPC-GPT 为代表的工作表明，SFT 可以使 LLM 在数据竞争检测、HPC 基准问答等任务上获得不错的领域能力。
- **核心矛盾**：知识注入 ≠ 行为适配。论文观察到，同一个 SFT 模型在 C/C++ 数据竞争分类任务上准确率高达 88.65%，但在 MLPerf 事实性问答上却有 65.9% 的响应超过 40 个字符——回答冗长、不精确，呈现出明显的“知道但不会用”的偏差。
- **RL 后训练的潜力与挑战**：强化学习（RL）后训练通过任务特定的奖励函数优化模型行为，而非逐 token 模仿，能弥补 SFT 的这一缺陷。然而，HPC 任务之间存在极端的异构性：
  - 答案长度最大相差 **58 倍**（数据竞争二分类约 2.5 字符 vs. PLP 描述性问答约 146.5 字符）；
  - 奖励分布横跨三种不同类型（二值奖励、分层离散奖励、连续相似度奖励）；
  - SFT 基线准确率从 51.10%（MLPerf）到 100%（PLP）不等。
- **现有方法的不足**：GRPO 等统一权重 RL 方法对组内所有响应给予相等的梯度贡献（1/G），无法适应上述异构性，导致计算效率低下——提升性能需要更多 rollout 样本，而非更充分地利用已有样本。
- **论文主张**：与其盲目扩大计算量，不如在固定组大小下，**识别并放大信息量更高的响应**，提高每个单位计算的有效性。这构成了 HARGO 方法的核心出发点。

## 2. 方法论：HARGO 的核心思想与关键技术细节

### 2.1 核心思想

HARGO 用**逐响应重要性加权**替代 GRPO 的均匀加权，通过两个互补信号来评估每个响应的“学习价值”：

- **判别信号 d**：衡量响应在组内奖励对比中的区分度（有多大把握地“对”或“错”）；
- **置信度信号 c**：衡量参考模型对响应的置信水平——区分“模型本来就不知道的随机错误”与“违背模型已有知识的真错误”。

两个信号均从训练过程内部自动计算，**无需任务类型标签、无需额外模型**。

### 2.2 关键技术细节与公式

**前置：GRPO 的均匀加权设置**

- GRPO 对每个 prompt q 采样 G 个响应，计算组内相对优势：

  $$A_i = \frac{r_i - \bar{R}}{\sigma_R + \varepsilon}$$

- 损失为平均加权：$L_{GRPO} = \frac{1}{G}\sum_i L_i$，每个响应梯度贡献恒为 1/G。

**HARGO 的两信号机制**

1. **置信度信号 c**：
   - 计算参考模型（SFT 初始化模型）对每个响应的逐 token 平均对数概率：$\text{ref\_logp}_i = \frac{1}{|y_i|}\sum_t \log \pi_{ref}(y_{i,t} | y_{i,<t}, q)$
   - 通过指数移动平均（EMA，ρ=0.9）维护跨 batch 的全局基线 ref_logp_global；
   - 归一化为 sigmoid：$c_i = \sigma(\text{ref\_logp}_i - \text{ref\_logp}_{global}) \in (0,1)$。
   - 含义：参考模型比平均更自信的响应 c>0.5，获得梯度放大；反之被抑制。

2. **优势调制（Advantage Modulation）**：
   - $A_{mod,i} = A_i \times (1 + \alpha \cdot c_i)$，其中 α=0.3；
   - 该设计**保持 A_i 的符号不变**（梯度的方向不变），仅将幅度缩放至基准的 1.0~1.3 倍；
   - 关键优势：避免了加性加权（w=d+α·c 的梯度正反馈循环）和乘性加权（w=d×c 在 d 与 c 反相关时的信号扭曲）的缺陷。

3. **判别信号 d 与权重计算**：
   - $d_i = |A_{mod,i}| / (\max_j |A_{mod,j}| + \varepsilon)$
   - 权重归一化：$w_i = d_i / \sum_j d_j$
   - **等权回退机制**：当组内奖励方差接近零（全对组）时，$\sum d_j < \varepsilon_w$，自动退化为均匀权重 1/G，保持 KL 正则化。

**训练流程（伪代码概要）**

1. 策略 πθ 初始化为 SFT 模型 πref；
2. 对每个 batch 的每个 prompt 采样 G=4 个响应，计算奖励和参考对数概率；
3. 更新 EMA 全局基线 → 计算标准 GRPO 优势 → 计算置信度 c → 调制优势 A_mod → 计算 d 并归一化权重；
4. 加权梯度更新：$L_{HARGO} = \sum_i w_i \cdot L_i$。

## 3. 实验设计

### 3.1 数据集与任务

- **数据来源**：HPC-GPT 开源指令数据集（Ding et al., 2023），共 5,273 条训练 / 584 条评估样本（9:1 划分）；数据竞争检测部分源自 DataRaceBench。
- **四个任务**（覆盖三种问题类型）：

| 任务 | 描述 | 答案类型 |
|------|------|----------|
| race_c | C/C++ OpenMP 数据竞争检测 | 二分类（yes/no） |
| race_fortran | Fortran OpenMP 数据竞争检测 | 二分类（yes/no） |
| mlperf | HPC 基准事实性问答 | 事实型（数字/名称/短文本） |
| plp | 编程语言处理描述性问答 | 描述型（长文本） |

- **奖励函数**（所有 RL 方法共享，外部固定组件）：
  - race：精确匹配 yes/no，1.0/0.0；

### 3.2 对比方法（共九种）

- **非 RL 基线**：SFT（起始点）、HPC-GPT（LoRA SFT 基线）；
- **离线偏好方法**：DPO、KTO、SimPO（偏好数据由 SFT 模型自动生成，无人工标注）；
- **在线 RL 方法**：PPO、GRPO、DrGRPO（去归一化变体）、**HARGO**（提出方法）。

### 3.3 评估指标

- **主要指标（3 个）**：WinRate（对 SFT 基线的胜率）、Data Race F1（race_c + race_fortran 宏平均 F1）、PLP Similarity（语义余弦相似度）；
- **辅助指标（2 个）**：MLPerf EM（精确匹配）、MLPerf AvgScore（奖励均值）——不作为排名依据。

## 6. 主要结论与发现

- **HARGO 全面领先主要指标**：
  - WinRate **54.62%**（比 HPC-GPT +4.79，比 GRPO +1.45）
  - Data Race F1 **91.30%**（比 DrGRPO +0.51，比 SFT +1.71）
  - PLP Similarity **0.8558**（比 KTO +0.011，比 SFT +0.032）
- **逐任务表现**：race_fortran 94.90%（全场第一）、plp 100%（并列第一）、mlperf 56.04%（第三，仅次于 GRPO 59.34% 和 KTO 56.59%）；race_c 89.19%（第四）。
- **数据竞争检测策略**：HARGO 采取高召回策略——Recall 94.23%（全场最高）、FN=9（最少漏报）、Accuracy 91.81%（全场最高）；代价是 Precision 88.55%（第 8 位），但 F1 确认了这一权衡的综合最优性。
- **KTO 在辅助指标上领先**（EM 27.47%、AvgScore 0.4537），说明其对精确复述类任务有优势，但主要指标落后于 HARGO；DPO 和 SimPO 表现较差，DPO 的 race_fortran 精度暴跌至 73.25%。
- **消融结论**：B1（仅 d）→ B2（仅 c）→ B3（完整 HARGO）的 WinRate 单调递增（53.34 → 53.60 → 54.62），证明两个信号互补，优势调制组合优于任一单独信号；B3 的 F1 与 B1 几乎持平（91.30 vs 91.37），PLP 提升明显（0.8558 vs 0.8480），说明 c 调制不损害检测能力。
- **行为分析**：HARGO 以更低的 KL 系数（β=0.02 vs. GRPO 的 0.04）实现更稳定的训练，优势调制的有界缩放（≤1.3 倍）提供了内建正则化；WinRate 在三轮 epoch 中单调提升，无训练崩溃。

## 7. 优点

1. **问题识别精准**：从数据中量化了 HPC 任务的三维异构性（58 倍长度差、三种奖励分布、51%~100% 准确率跨度），为方法设计提供了扎实的动机基础。
2. **方法设计优雅且计算开销极小**：
   - 两个信号（d 和 c）全部从 GRPO 流程中已有的量（奖励、参考模型对数概率）推导，不需要额外模型、不需要任务标签；
   - 等权回退机制避免了全对组的梯度退化问题；
   - 优势调制（A×(1+α·c)）在数学上有界（≤1.3 倍），天然防止训练不稳定。
3. **消融实验设计清晰**：B1/B2/B3 三个变体精确隔离了各信号的贡献，并给出了合理的机制解释（为什么 B3 的 EM 低于 B1——全局最优 vs. 单任务最优的权衡）。
4. **评估客观公正**：九种方法统一从同一检查点出发、共享奖励函数，主要指标与训练奖励有一定独立性（F1 用词边界提取，PLP 用语义相似度）；报告了完整的混淆矩阵而非仅 F1 值。
5. **结论有边界意识**：明确指出 0.5B 规模的局限性和未来扩展方向，不做过度宣称。

## 8. 不足与局限

1. **规模验证不足**：全部实验仅基于 Qwen2.5-0.5B（5 亿参数），未验证在 7B/13B/70B 等更大规模下 HARGO 是否仍然有效；论文自述未来工作包括规模扩展。
2. **数据集覆盖有限**：仅使用 HPC-GPT 单一数据集（5,273 条训练样本），未在更多 HPC 语料或其他领域验证泛化性；MLPerf 部分仅有约 1,000+ 条样本，统计效力有限。
3. **缺乏统计显著性检验**：未报告多次运行的标准差、置信区间或显著性测试，方法间的微小差距（如 F1 91.30 vs 90.79）是否可靠存疑。
4. **偏好方法的公平性问题**：DPO/KTO/SimPO 的偏好数据由 SFT 模型自动生成（模拟对），这种方式对这些方法可能不利；论文也承认自动偏好数据对 Fortran 任务的区分度不足（DPO 的 race_fortran 精度跌至 73.25%）。
5. **辅助指标方面的短板**：HARGO 在 EM（17.58%）和 AvgScore（0.4000）上明显落后于 KTO（27.47%, 0.4537），论文将其归因于全局最优 vs. 单任务最优的权衡，但未充分讨论在需要精确复述的 HPC 场景中这一短板的实际影响。
6. **消融细节不足**：消融实验未按任务拆分报告（只有合并指标），无法判断 c 信号在哪些具体任务上增益最大、在哪些任务上有害。
7. **训练时长与成本信息缺失**：未报告各方法的实际训练时间、HARGO 相对 GRPO 的具体计算开销比例。
8. **实际应用限制**：单卡 RTX 3080、0.5B 模型、3 epoch 的实验设定与真实 HPC 场景（大规模代码库、多语言并行程序）之间存在较大距离，结论的外推需谨慎。
