## 摘要
现有的大型语言模型自适应推理方法依赖于观测启发式（如隐藏状态相似性或激活幅度）来丢弃冗余模块。然而，这些基于相关性的指标通常无法捕捉对语义准确性至关重要的微妙非线性结构计算。我们提出了CausalGate，一种用于高效计算Transformer推理的干预引导框架。在校准阶段，CausalGate隔离各个注意力层和MLP子层，将其输出置零，并通过最终logit分布的Kullback-Leibler散度测量精确的语义损伤。为了消除运行时路由开销，这种结构重要性层次通过指数移动平均平滑目标与可微分的成对排序损失蒸馏到一组全局静态轻量级标量门控中。在TinyLlama-1.1B、Qwen2.5-3B和Llama-3.1-8B上的语言建模和常识推理基准测试中，CausalGate持续优于突出的动态路由和层跳过基线，将理论上的计算节省转化为具体硬件延迟降低，且零运行开销。

## Abstract
Existing adaptive inference methods for Large Language Models rely on observational heuristics, such as hidden-state similarity or activation magnitudes, to drop redundant modules. However, these correlation-based metrics often fail to capture subtle, non-linear structural computations vital for semantic accuracy. We introduce CausalGate, an intervention-guided framework for compute-efficient transformer inference. During a calibration phase, CausalGate isolates individual Attention and MLP sub-layers, zeros out their respective outputs, and measures the exact semantic damage via the Kullback-Leibler divergence of the final logit distribution. To eliminate runtime routing overhead, this structural importance hierarchy is distilled into a global set of static, lightweight scalar gates using an Exponential Moving Average smoothing objective paired with a differentiable pairwise ranking loss. Evaluated on TinyLlama-1.1B, Qwen2.5-3B, and Llama-3.1-8B across language modeling and commonsense reasoning benchmarks, CausalGate consistently outperforms prominent dynamic routing and layer-skipping baselines, translating theoretical compute savings into concrete hardware latency reductions with zero operational overhead.

### 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：大型语言模型（LLM）推理的计算成本是部署瓶颈。现有自适应推理方法（如 CALM、MoD、GateSkip、AdaSkip）依赖**观测启发式**（如隐藏状态相似度、激活幅度）来跳过冗余模块。但这些相关性指标无法捕捉模块的**非线性因果贡献**，导致重要但表现“安静”的模块被误删，在高压缩比下出现严重性能下降。
- **核心问题**：如何在不引入运行时开销的前提下，**直接衡量每个子层（Attention/MLP）对最终输出分布的因果影响**，并据此产生稳定的、输入无关的模块重要性排序，从而实现高效的离线结构剪枝。
- **整体含义**：CausalGate 将“干预”（intervention）思想引入 Transformer 模块重要性评估，将动态路由转换为静态编译时掩码，在保持模型质量的同时实现零额外开销的推理加速。

### 2. 方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：通过**主动置零**每个 Attention 或 MLP 子层的输出，观察最终 logit 分布相对于原始分布的变化（KL 散度），从而量化该模块的因果重要性。再将这种昂贵干预获得的重要性排序蒸馏为**轻量静态标量门控**，推理时直接根据门控值选择保留 Top-K 模块。
- **关键技术细节**：
  - **干预阶段（Algorithm 1）**：对每个模块 \(m_i\)，将其残差分支输出置零，计算干预分布与原始分布的 KL 散度 \(\Delta_i = D_{KL}(p(y|x, do(m_i=0)) \parallel p(y|x))\)。
  - **归一化与时间平滑**：将当前迭代的 \(\Delta_i^{(t)}\) 除以最大值后，加上目标下限 \(\alpha\) 得到 \(z_i^{(t)}\)，再通过 EMA 更新 \(\bar{z}_i^{(t)} = \beta \bar{z}_i^{(t-1)} + (1-\beta) z_i^{(t)}\)，消除单次干预的噪声。
  - **门控学习**：每个模块关联可训练标量 \(\theta_i\)，门控值 \(g_i = \sigma(\theta_i)\)。优化目标包含三个部分：
    - **回归损失** \(L_{\text{MSE}} = \frac{1}{M}\sum (g_i - \bar{z}_i)^2\)
    - **成对排序损失** \(L_{\text{rank}} = \frac{1}{|P|}\sum_{(i,j)\in P} \max(0, \gamma - s_{ij}(g_i - g_j))\)，其中 \(s_{ij} = \text{sign}(\bar{z}_i - \bar{z}_j)\)，鼓励门控值保留因果排序。
    - **稀疏正则化** \(L_{\text{sparse}} = \frac{1}{M}\sum g_i^2\)
  - **总损失**：\(L = \lambda_{\text{LM}} L_{\text{LM}} + \lambda_{\text{sparse}} L_{\text{sparse}} + \lambda_{\text{causal}} L_{\text{MSE}} + \lambda_{\text{rank}} L_{\text{rank}}\)
  - **推理阶段**：根据学习到的门控值对模块降序排序，保留 Top-K 模块（K = ⌈(1-ρ)M⌉），其余跳过，形成二进制掩码，实现直通式执行。

### 7. 优点

- **方法论创新**：首次将**因果干预**（do-operator）引入 Transformer 模块级结构剪枝，从根本上取代相关性启发式。
