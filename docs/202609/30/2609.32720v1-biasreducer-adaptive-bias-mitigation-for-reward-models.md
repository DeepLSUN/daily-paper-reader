## 摘要
奖励模型对大型语言模型（LLM）生成的回复进行评分，并引导LLM训练趋向人类偏好。然而，奖励模型可能偏好长度或置信度等表面属性，导致LLM生成评分更高但并不更正确的回复。现有缓解方法要么重新训练奖励模型，要么对某一已知偏差（例如偏好更长回复）施加固定校正。重新训练需要额外数据和计算资源，而现有编辑方法需要预先指定目标偏差，并对该偏差使用固定编辑。为此，我们提出BiasReducer，一个轻量级框架，仅编辑线性奖励头，并为每个新数据集选择相关编辑。首先，BiasReducer使用稀疏自编码器（SAE）风格的编码器来学习奖励模型对哪些属性（例如长度和置信度）敏感。其次，它通过确定调整奖励头的方向以及调整幅度，学习如何降低奖励模型对每个属性的依赖。第三，对于新数据集，它按属性对奖励分数的影响进行排序，选择相关属性，并据此编辑奖励模型。BiasReducer持续提升奖励模型对表面回复属性偏差的鲁棒性。在五个奖励模型上，BiasReducer-M将三个基准平均提升8.3、18.0和6.9个百分点，优于两个基于训练的基线。这些增益可迁移至下游，减少不必要的冗长和谄媚，同时保持相当的评判质量。

## Abstract
Reward models score responses from large language models (LLMs) and guide LLM training toward human preferences. However, reward models can favor superficial attributes such as length or confidence, leading LLMs to produce higher-scoring but not more correct responses. Existing mitigation methods either retrain the reward model or apply a fixed correction to one known bias, such as a preference for longer responses. Retraining requires additional data and computational resources, while existing editing methods require the target bias to be specified in advance and use a fixed edit for that bias. To this end, we propose BiasReducer, a lightweight framework that edits only the linear reward head and selects the relevant edits for each new dataset. First, BiasReducer uses a sparse autoencoder (SAE)-style encoder to learn which attributes (e.g., length and confidence) the reward model is sensitive to. Second, it learns how to reduce the reward model's dependence on each attribute by determining which direction to adjust the reward head and how much to adjust it. Third, for a new dataset, it ranks the attributes by their influence on reward scores, selects the relevant ones, and edits the reward model accordingly. BiasReducer consistently improves reward-model robustness to biases toward superficial response attributes. Across five reward models, BiasReducer-M improves the three benchmarks by 8.3, 18.0, and 6.9 percentage points on average, outperforming the two training-based baselines. The gains transfer downstream, reducing unnecessary verbosity and sycophancy while maintaining comparable judged quality.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：奖励模型（Reward Model, RM）在 RLHF 中为 LLM 输出打分，引导模型向人类偏好靠拢。但 RM 只是人类偏好的不完美代理，容易偏好**表面属性**（长度、格式、置信度、谄媚等），而非回答的正确性或有用性。
- **危害**：当这些表面信号被用于响应选择或下游训练时，会诱发 **reward hacking**——模型优化的是被奖励的属性（如"更长、更自信"），而非真正的质量。
- **现有方法的局限**：
  - **基于训练的方法**（如 RRM、ODIN、CROME、反事实微调）：改变数据/损失/架构或继续微调，效果尚可但**计算昂贵、需要大量新数据**。
  - **模型编辑方法**：无需重训，但通常**必须预先指定目标偏差**，并对该偏差施加**固定校正**。
- **关键问题**：RM 可能同时依赖多种属性，且不同目标数据分布下相关属性不同。能否在**不重训、不预设偏差**的前提下，为每个新数据集选择合适的校正？
- **整体含义**：论文提出 **BiasReducer**，一种轻量级框架——只编辑线性奖励头（reward head），学习可复用的"属性专用校正"，并针对新数据集自适应选择要施加的校正。

## 2. 方法论

### 2.1 核心思想

- 将问题拆为三步：
  1. **学习与预定义属性对应的内部表示**（给选定维度赋予可解释含义）；
  2. **学习如何降低 RM 对每个属性的依赖**（确定编辑方向与幅度）；
  3. **为新数据集选择要施加哪些编辑**。
- 只修改线性奖励头权重 $w_r \to w_r'$，其余 RM 参数冻结。
- 奖励模型形式：$r(q,x)=w_r^{\top}h(q,x)+b$，其中 $h$ 为奖励头输入隐表示。
- 记号：源偏好数据 $D_{src}$ 划分为 $D^{train}_{src}$、$D^{val}_{src}$；偏好对 $(x^+,x^-)$ 的偏好对比 $\Delta h = h(x^+)-h(x^-)$；新数据集 $D$ 只提供响应、隐表示与原始奖励分数，**不知道哪条被偏好**。

### 2.2 第一步：学习响应属性的表示

- 使用 **SAE 风格编码器-解码器**，在偏好对比 $u=\Delta h$ 上训练：
  - $z_{pre}=W_{enc}u+b_{enc}$，$z_{post}=\mathrm{TopK}(z_{pre})$（保留绝对值最大的 $k_{act}$ 个坐标并保留符号），$\hat{u}=Vz_{post}$。
- 为每个预定义属性 $a\in\mathcal{A}$ 指定一个坐标 $z_a$，并用**语义监督**赋予可解释含义：
  - **行为监督 $L_{beh}$**：用文本测量（如词数差）的标准化差值让坐标追踪自然差异，并压制与其他命名坐标的关联（$L_{axis}$、$L_{dec}$）。
  - **干预监督 $L_{int}$**：用受控改写（增/减某属性）确定坐标方向，并确保响应强于其他坐标。
  - **伪影监督 $L_{art}$**：用一个额外"伪影坐标"吸收改写过程引入的共享变化，避免污染命名属性。
- 联合目标：$\mathcal{L}=\mathcal{L}_{rep}+\gamma_b\tilde{\mathcal{L}}_{beh}+\gamma_i\tilde{\mathcal{L}}_{int}+\gamma_a\tilde{\mathcal{L}}_{art}$，其中 $\mathcal{L}_{rep}$ 含重构、稀疏（$L_1$）与解码方向不相关（incoherence）正则。

### 2.3 第二步：学习如何降低对每个属性的依赖

- 对每个属性 $a$，估计与其激活共变的隐状态方向：
  - $C_a=\mathrm{Cov}_{h\sim D^{train}_{src}}(h,\,z_{post,a}(h))$。
- 定义奖励头编辑（借鉴线性概念擦除 LEACE 的思想）：
  - $w_a(\lambda)=w_r-\lambda\dfrac{w_r^{\top}C_a}{C_a^{\top}C_a+\epsilon_{edit}}C_a$。
  - 当 $\lambda=1$ 时，编辑后奖励与属性激活沿 $C_a$ 线性去相关；$0<\lambda<1$ 为部分校正，$\lambda>1$ 为过度校正。
- 编辑幅度 $\lambda_a^{\star}$ 的选择：在候选集 $\Lambda$ 中，最大化源训练集上的平均奖励变化 $Agg_a(\lambda)$，同时约束源验证集偏好准确率下降不超过 $\tau_{src}=0.02$：
  - $\lambda_a^{\star}=\arg\max_{\lambda\in\Lambda}Agg_a(\lambda)\ \text{s.t.}\ \Delta Acc_{src}(w_a(\lambda))\le\tau_{src}$。
  - 无可行非零值则该属性标记为**不合格（ineligible）**。
- 收集合格编辑构成**编辑库** $\mathcal{B}=\{(a,C_a,\lambda_a^{\star})\}$。

### 2.4 第三步：为新数据集选择要编辑的内容

- 对每个合格属性计算两个信号（仅用响应、隐表示与原始奖励分数）：
  - **奖励依赖度**：$G_a(D)=\mathrm{Cov}_{h\sim D}(w_r^{\top}h,\,z_{pre,a}(h))$；
  - **编辑影响度**：$I_a(D)=\mathbb{E}_{h\sim D}[h^{\top}w_a(\lambda_a^{\star})-h^{\top}w_r]$。
- 用 **Borda 式秩和**聚合两个排名：$B_a(D)=\mathrm{rank}_{\downarrow G}(a)+\mathrm{rank}_{\downarrow I}(a)$，越小优先级越高。
- **BiasReducer-S**：选排名最高的单个属性，施加其源端确定的编辑。
- **BiasReducer-M**：按排名顺序依次组合最多 $k_{max}$（默认 4）个编辑；每次组合都需在源验证集上满足准确率约束，若超限则尝试更小的 $\lambda$，必要时回退降低已选最大 $\lambda$，仍不可行则跳过。

## 6. 主要结论与发现

- **主结果**：BiasReducer 在所有模型-基准组合上均优于原始 RM；BiasReducer-M 平均提升 **8.3 / 18.0 / 6.9 pp**（RM-Bench-Hard / Arena-StyleConflict / JudgeBiasBench），BiasReducer-S 提升 6.2 / 15.7 / 6.0 pp；相比更强的训练基线 RRM，M 版额外提升 4.1 / 13.2 / 2.3 pp。
- **下游迁移**：用编辑后的 Mistral-7B 奖励头做 best-of-N 与 GRPO 训练，可**减少不必要冗长与谄媚**，同时质量保持或略升（如 Qwen3-4B GRPO 质量 4.29→4.53，冗余 0.74→0.58，谄媚 0.08→0.04，词数 331→285）。
- **语义监督有效**：相比 vanilla SAE，属性轴相关从 0.26 提升到 0.55，编辑增益显著更大；去掉 $L_{beh}$ 使轴相关降到 0.17，去掉 $L_{int}$ 使符号准确率从 0.99 降到 0.75。
- **编辑构造关键**：协方差方向远优于 SA
