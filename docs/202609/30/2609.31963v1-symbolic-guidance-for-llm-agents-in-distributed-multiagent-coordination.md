## 摘要
大语言模型（LLMs）正越来越多地被部署为多智能体系统中的自主智能体，但其可靠执行分布式协调协议的能力仍未被充分理解。尽管AgentsNet——一个用于LLM智能体间分布式协调的基准框架——能够支持此类协调，但在复杂领域中赋予完全推理自主权往往会导致性能不稳定或下降。我们假设，通过源自成熟算法的符号引导来调控智能体自主性，可以改善协调效果。为研究这一点，我们引入符号引导分类体系（Symbolic Guidance Taxonomy, SGT），它刻画了从开放式自然语言推理到完全规定式算法执行的自主性谱系，其中间层级提供部分伪代码引导。我们的结果表明，中等自主性水平始终优于无引导智能体和完全规定式规范。这些发现将自主性调控确定为基于LLM的分布式协调的一项关键设计原则。

## Abstract
Large language models (LLMs) are increasingly deployed as autonomous agents in multi-agent systems, yet their ability to reliably execute distributed coordination protocols remains poorly understood. While AgentsNet, a benchmark framework for distributed coordination among LLM agents, enables such coordination, granting full reasoning autonomy often leads to inconsistent or degraded performance in complex domains.   We hypothesize that coordination can be improved by regulating agent autonomy through symbolic guidance derived from established algorithms. To investigate this, we introduce the \emph{Symbolic Guidance Taxonomy (SGT)}, which characterizes a spectrum of autonomy ranging from open-ended natural language reasoning to fully prescribed algorithmic execution, with intermediate levels providing partial pseudocode guidance. Our results show that intermediate autonomy levels consistently outperform both unguided agents and fully prescriptive specifications. These findings identify autonomy regulation as a key design principle for LLM-based distributed coordination.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：LLM 正越来越多地被部署为多智能体系统中的自主智能体，但其可靠执行分布式协调协议的能力仍缺乏系统理解。经典符号算法（如 AAMAS 社区提出的分布式算法）具备形式化正确性与收敛保证，但依赖完整、规范的问题表述，面对不确定或欠规范环境时脆弱；LLM 智能体则具备自然语言适应性，但缺乏保证一致性、收敛性与最优性的内在机制。
- **核心问题**：AgentsNet 等基准框架赋予 LLM 智能体完全自由的推理自主权，但在更复杂领域（如 3-着色、最大匹配、最小顶点覆盖）中，这种完全自主往往导致性能不稳定甚至下降。
- **核心假设**：通过源自成熟符号算法的**符号引导（Symbolic Guidance）**来调控智能体的自主程度，可以改善分布式多智能体协调的效果。
- **整体含义**：论文将"自主性调节"确立为基于 LLM 的分布式协调的关键设计原则，试图在符号控制的理论严谨性与 LLM 的生成灵活性之间架起桥梁，使二者在统一的多智能体框架中共存。

## 2. 方法论：符号引导分类体系（SGT）

- **核心思想**：受"可调自主性（Adjustable Autonomy）"启发，SGT 将 LLM 智能体的自主性建模为一个连续谱——从完全开放式推理（最大自主）到严格算法执行（最小自主），并系统性地改变"向智能体揭示参考算法 A 的哪些部分"以及"以何种表示形式呈现"。
- **形式化定义**：引导策略定义为映射 `G(S, E; A) → I`，其中：
  - **S（选择）**：指定提供算法的哪些部分（步骤序列、函数集合、平局打破规则等）；
  - **E（编码）**：指定表示形式，取值于 `{main-pseudocode, function-pseudocode, function-description, full-pseudocode}`；
  - **I**：智能体最终接收到的引导块。
- **五类智能体 + 两个基线（按自主性从高到低）**：
  1. **AgentsNet 智能体（基线）**：`G(∅, ∅; A) = ∅`，仅给任务描述与输出要求，完全自主；
  2. **Function-description 智能体**：提供所有辅助函数的自然语言描述（不含实现），保留实现灵活性；
  3. **Function-pseudocode 智能体**：提供辅助函数的伪代码，但不告知如何组合使用；
  4. **Main-pseudocode 智能体**：仅提供主函数伪代码，辅助函数需自行实现；
  5. **Full-pseudocode 智能体**：提供完整算法伪代码（含所有函数体与平局规则），自主性最小；
  6. **Code 智能体（Oracle 基线）**：算法 A 用 Python 实现并直接执行，完全无 LLM 参与。
- **算法流程说明（以 MIS 图着色为例）**：算法按轮次运行，智能体先试探性提出颜色，通过平局规则与邻居解决冲突后提交选择。SGT 的关键在于同一"提议（propose_group）"步骤可依 (S, E) 配置以自然语言描述、函数伪代码、主流程步骤或完整伪代码等形式呈现，从而产生从"行为直觉"到"确定性执行"的不同引导强度。

## 3. 实验设计

- **Benchmark 基础**：基于 AgentsNet 公开实现构建，使用其消息传递与网络生成代码，并扩展加入更难的全局变体与 SGT 引导变化。
- **问题域（3 个经典分布式图问题，每个含局部/全局两变体）**：
  - **图着色**：局部 `(∆+1)-着色`（∆ 为最大度）；全局 `3-着色`；
  - **匹配**：局部 `极大匹配`；全局 `最大匹配`；
  - **顶点覆盖**：局部 `极小顶点覆盖`；全局 `最小顶点覆盖`。
- **参考算法（作为引导来源 A）**：
  - 局部变体：**MIS（极大独立集）启发式**；
  - 全局变体：**MIS 启发式** 与 **分布式 DFS（回溯搜索）** 两种。
- **图拓扑**：Smallworld、Scalefree、Delaunay 三类，每类生成 5 个 n=16 的图，共 15 个网络；所有实验运行 `2D+1` 轮同步消息传递（D 为图直径）。
- **LLM 模型**：Llama-3.1-8B Instruct（Ollama 本地）、Qwen-2.5-7B Instruct（Ollama 本地）、Gemini-2.5 Flash（OpenRouter）。
- **评价指标**：统一采用**误差平方和（SSE）**，并取 `ln(1+SSE)` 进行报告：
  - 局部变体：基于无效边/无效顶点的平方计数（如 `|I(x)|²`）；
  - 全局变体：基于与最优解（OPT）的差距（如 `(|OPT(G)| − |V(x)|)²`）。
- **对比方法**：上述 5 类 SGT 智能体 + AgentsNet 基线 + Code Oracle 基线，跨 3 个模型、3 个问题域、2 种难度、2 种算法。

## 6. 主要结论与发现

- **中等自主性最优**：部分伪代码引导（尤其 Function-description 与 Function-pseudocode）在多数任务上持续优于无引导的 AgentsNet 基线和完全规定式的 Full-pseudocode；性能不随引导增加或自主性增加而单调变化。
- **模型差异显著**：
  - **Gemini-2.5** 整体表现最佳，最能内化并运用符号脚手架；
  - **Llama** 通常能从各种引导中获益（相对 AgentsNet 有统计显著性提升）；
  - **Qwen** 对引导基本不敏感（与 AgentsNet 无显著差异）。
- **算法来源的影响**：
  - 源自**局部启发式算法（MIS）**的引导普遍稳健有效；
  - 源自**复杂全局搜索算法（Distributed DFS）**的引导效果混杂，常常收益有限甚至有害，因其控制流过于刚性、超出 LLM 的表示能力。
- **过度规定反而有害**：完整伪代码或主函数伪代码在部分任务（如极大匹配、最小顶点覆盖）中甚至比无引导更差，说明过度约束会破坏 LLM 的推理灵活性。
- **总体设计原则**：符号引导是调控 LLM 自主性的有效杠杆；最优配置出现在"符号结构提供有用支架、同时保留推理灵活性"的中间地带，且这一平衡是**情境依赖**的，而非二元或单调的。

## 7. 优点

- **概念创新性强**：提出 SGT，将"可调自主性"这一人机协作概念系统化地引入 LLM 多智能体协调领域，并给出形式化定义 `G(S, E; A) → I`，为后续研究提供了统一的设计空间与术语。
- **实验设计系统**：同时因子化"算法结构（局部启发式 vs 全局搜索）"与"引导层级"，并在多模型、多拓扑、多难度上交叉验证，能有效解耦引导形式与算法来源的交互作用。
- **基线设置合理**：既保留 AgentsNet 作为完全自主基线，又引入 Code Oracle 作为无 LLM 的性能上界，形成完整的自主性光谱。
- **结论具有可操作性**：明确指出"函数级、概念级引导优于过程级、全规定式引导"，为实际部署多智能体 LLM 系统提供了具体的设计建议。
- **方法可扩展**：SGT 的框架设计天然支持未来扩展到混合自主团队与动态自适应引导机制。
