## 摘要
大语言模型（LLM）智能体日益依赖外部记忆来支持长时程推理与决策。现有记忆系统通常将历史轨迹或摘要作为独立的上下文片段进行检索，忽略了多步执行所依赖的过程性依赖关系。随着记忆规模增长，这种扁平化检索会引入上下文碎片化和跨任务干扰，导致推理轨迹在结构上不一致。我们提出 ActiveMem，一种分层记忆框架，它将智能体经验递归地组织为依赖感知的潜在执行树。ActiveMem 将轨迹抽象为可复用的子任务节点，同时显式保留执行转移关系，从而能够以当前执行状态为条件检索连贯的推理路径。为支持持续适应，ActiveMem 进一步通过强化学习学习动态记忆扩展、检索与剪枝策略。在多种智能体基准上的实验表明，相较于现有基于记忆的智能体，ActiveMem 能够持续提升任务完成度、推理稳定性与记忆效率。此外，ActiveMem 使紧凑的开源权重模型能够取得与规模大得多的专有系统相竞争的性能。

## Abstract
Large Language Model (LLM) agents increasingly rely on external memory to support long-horizon reasoning and decision making. Existing memory systems typically retrieve historical trajectories or summaries as independent context fragments, overlooking the procedural dependencies underlying multi-step execution. As memory scales, such flat retrieval introduces context fragmentation and cross-task interference, leading to structurally inconsistent reasoning trajectories. We propose ActiveMem, a hierarchical memory framework that recursively organizes agent experiences into dependency-aware latent execution trees. ActiveMem abstracts trajectories into reusable subtask nodes while explicitly preserving execution transitions, enabling coherent reasoning-path retrieval conditioned on the current execution state. To support continual adaptation, ActiveMem further learns dynamic memory expansion, retrieval, and pruning policies through reinforcement learning. Experiments across various agent benchmarks demonstrate that ActiveMem consistently improves task completion, reasoning stability, and memory efficiency over existing memory-based agents. Moreover, ActiveMem enables compact open-weight models to achieve competitive performance with substantially larger proprietary systems.

- **后果**：
  - **上下文碎片化**：检索到功能相关但时序不兼容的动作；
  - **跨任务干扰/泄漏**：例如在机票预订流程中错误套用酒店预订的步骤序列；

- **关键洞察**：长时程任务天然具有**层次化分解**结构——高层目标逐步细化为可复用子任务，且子任务之间存在因果约束的执行转移。因此记忆不仅要"存得下"，更要"按执行结构组织和检索"。

## 2. 方法论

### 2.1 核心思想

- 用**层次化潜在记忆树（HLMT, Hierarchical Latent Memory Tree）** 替代扁平记忆池：节点编码可复用的子任务级潜在抽象，边显式表达执行依赖。
- 检索时返回**依赖一致的执行路径**而非孤立片段，从而保持高层过程结构、抑制无关分支干扰。
- 与既有记忆增强智能体的三点根本差异：
  1. 使用**连续潜在记忆**而非原始文本块；
  2. **主动优化记忆拓扑**而非被动追加历史；
  3. 通过强化学习**联合优化推理适配与记忆结构**。

### 2.2 问题形式化

- 任务指令 $x$，冻结的 LLM $\pi_\theta$ 与环境 $\mathcal{E}$ 交互 $T$ 步，产生轨迹 $\tau=(s_0,a_0,\dots,s_T)$。
- 历史前缀被压缩为动态记忆树 $\mathcal{T}_t$，通过离散拓扑动作更新：$\mathcal{T}_t=\text{TreeUpdate}(\mathcal{T}_{t-1}, a^{tree}_{t-1})$。
- 给定当前状态 $s_t$ 检索记忆路径 $P_t=f_{retrieve}(s_t,\mathcal{T}_t)$；轻量控制器 $W_\phi$ 结合当前观测隐状态 $h_t$（冻结 LLM 的 last-token hidden state）产出共享表示 $u_t$，分流到两个头：生成**潜在记忆前缀** $m_t$ 与预测**树动作** $a^{tree}_t$。
- 潜在前缀改变冻结 LLM 的隐激活，从而隐式定义新的动作策略：$\pi_{\theta,\phi}(a_t|s_t)=\pi_\theta(a_t|s_t,m_t(\phi))$，目标是 $\max_\phi \mathbb{E}_{x\sim\mathcal{D},\tau\sim\pi_{\theta,\phi}}[R(\tau)]$。

### 2.3 关键技术细节

**（1）HLMT 结构与检索**
- 节点定义为元组 $n_i=(e_i, pa(i), ch(i))$，$e_i\in\mathbb{R}^d$ 为控制器生成的压缩潜在摘要；树形结构天然建模语义层次（上层粗粒度任务语义，下层细粒度执行细节）。
- 初始化一个不携带任务语义的虚拟根节点 $n_r$，在 episode 边界重置。
- 以 $h_t$ 为查询做**递归贪心遍历**：在深度 $k$ 选择与 $h_t$ 余弦相似度最大的子节点 $n_{k+1}=\arg\max_{n\in ch(k)} \frac{h_t\cdot e_n}{\|h_t\|\|e_n\|}$；当最大相似度低于阈值 $\tau_{stop}$ 时终止，得到激活路径 $P_t=(n_1,\dots,n_d)$。
- 检索复杂度为 $O(DB)\approx O(\log_B|\mathcal{T}|)$，显著优于扁平检索的 $O(|\mathcal{T}|)$。

**（2）双头记忆控制器**
- 路径平均池化 $\bar{p}_t=\frac{1}{|P_t|}\sum_{n_i\in P_t} e_i$（路径顺序由遍历深度隐式编码，故均值池化有效），再经 2 层 MLP 得 $u_t=\text{MLP}_{shared}([h_t;\bar{p}_t])$。
- **潜在注入头**：$m_t=W_{latent}u_t\in\mathbb{R}^{l_p\times d_{model}}$，作为动态软提示直接前置于当前观测的输入嵌入（附录中亦描述为前置到选定注意力层的 KV cache：$\tilde{K}=[m_t;K],\tilde{V}=[m_t;V]$）。虽然 $\theta$ 冻结，RL 梯度仍可经 LLM 计算图回传到输入层以更新 $\phi$。
- **树动作头**：$\pi_{tree}(\cdot|u_t)=\text{Softmax}(W_{tree}u_t)$，对离散拓扑操作采样。

**（3）即时执行与延迟执行**
- **Immediate（在线高频）**：
  - `insert`：新节点 $e_{new}=W_{ins}u_t$ 作为检索到的叶节点 $n_d$ 的子节点挂载，显式保留时序层次；
  - `update`：门控精化 $e_d\leftarrow(1-\alpha)e_d+\alpha W_{upd}u_t$，$\alpha=\sigma(W_{gate}u_t)$；
  - 新插入/更新嵌入均做 L2 归一化以防止表征坍塌。
- **Deferred（episode 末低频维护）**：
  - 节点效用 $S(n_i)=\sum_k \gamma^{k-t_i} r_k$（同一 episode 多次激活取平均，避免过度奖励高频循环），并用 EMA 平滑 $S_{EMA}\leftarrow(1-\beta)S_{EMA}+\beta S$；
  - 剪枝 $S_{EMA}<\tau_{del}$ 的节点，其子节点直接重挂到父节点以保持拓扑连通；
  - 兄弟节点相似度 $sim(e_i,e_j)>\tau_{merge}$ 时平均池化融合。

**（4）训练配方（GRPO）**
- 无需 critic，对同一 prompt 采样一组轨迹 $G$ 做组内归一化；结合**可验证的过程监督**（细粒度步骤奖励 + 最终回报）缓解长时程奖励稀疏。
- 层次化优势：$A_i=\lambda_g\frac{S(n_i)-\mu_G(S)}{\sigma_G(S)+\epsilon_0}+\lambda_l\big(S(n_i)-S(pa(i))\big)$，全局项衡量任务级有用性，局部项保留节点相对父节点的专门化；并施加深度折扣 $\tilde{A}_i=\gamma^{d_i}A_i$。
- 联合目标 $L(\phi)=L^{latent}_{GRPO}(\phi)+\lambda L^{tree}_{GRPO}(\phi)$，两项均采用带裁剪的 GRPO 代理目标并加 KL 惩罚防止策略坍塌；两头共享表示、梯度联合累积（作者称未观察到训练不稳定）。

**（5）算法流程（Algorithm 1 概览）**
