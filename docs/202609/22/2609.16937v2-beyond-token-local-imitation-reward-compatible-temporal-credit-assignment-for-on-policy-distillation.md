## 摘要
在线策略蒸馏（OPD）已成为大语言模型后训练的一种有效方法，但现有目标在目标保真度与优化稳定性之间面临权衡。Token 级 OPD 提供稳定但局部的监督，而序列级 OPD 以依赖时域的方差为代价捕获未来信用。我们为这些形式建立统一的时序信用视角，表明实际的 Token 级 OPD 可解释为对序列级反向 KL 梯度的一种时序近似。基于这一联系，我们提出 $γ$OPD（GammaOPD），它使用折扣时序信用分配来平衡长时域监督与优化稳定性，同时具有不依赖于时域的方差界。我们进一步为 $γ$OPD 开发了一种奖励兼容的有界混合（RBM）机制，该机制平衡可验证的结果反馈与折扣 OPD 优势，以超越纯粹依赖教师的优化。在数学与代码推理上的实验表明，在普通、规模不匹配和多教师蒸馏设置中，该方法相较于现有 OPD 方法均取得了一致提升。

## Abstract
On-policy distillation (OPD) has emerged as an effective approach for large language model post-training, yet existing objectives face a trade-off between objective fidelity and optimization stability. Token-level OPD provides stable but local supervision, whereas sequence-level OPD captures future credit at the cost of horizon-dependent variance. We establish a unified temporal-credit view of these formulations, showing that practical token-level OPD can be interpreted as a temporal approximation to the sequence-level reverse-KL gradient. Building on this connection, we propose $γ$OPD (GammaOPD), which uses discounted temporal credit assignment to balance long-horizon supervision and optimization stability, while admitting a horizon-independent variance bound. We further develop a reward-compatible bounded mixing (RBM) mechanism for $γ$OPD that balances verifiable outcome feedback with the discounted OPD advantage to move beyond purely teacher-dependent optimization. Experiments on mathematical and code reasoning demonstrate consistent improvements over existing OPD methods across vanilla, size-mismatched, and multi-teacher distillation settings.

## 一、核心问题与整体含义

- **背景**：在线策略蒸馏（On-Policy Distillation, OPD）已成为 LLM 后训练（如 Kimi K3、GLM-5、DeepSeek-V4 等）的关键手段，通过在学生自身采样的轨迹上施加教师监督，缓解 exposure bias，尤其适合长链推理任务。
- **核心矛盾**：现有 OPD 目标在**目标保真度**与**优化稳定性**之间存在权衡。
  - **Token 级 OPD**（主流实现）：用单样本 token 级 Monte Carlo 估计反向 KL 的策略梯度，计算高效、优化稳定，但监督是"局部"的，仅关注当前 token，忽略了当前 token 对后续推理步骤的间接影响。
  - **序列级 OPD**：忠实保留原始反向 KL 目标，能累积未来信用，但信用随响应长度增长而方差急剧上升（最坏情况二次增长），长推理轨迹下训练不稳定。
- **整体含义**：作者从统一的**时序信用分配（temporal credit assignment）**视角重新审视二者，指出实践中的 token 级 OPD 实质是序列级反向 KL 梯度的**时序截断近似**；并据此提出可插值的折扣方案 γOPD，进一步结合可验证奖励以突破"纯教师模仿"的天花板。

### 2.1 统一时序信用视角（理论起点）

- 定义 token 级与序列级 log-ratio：Δ_t = log π_θ(y_t|h_t) − log π*(y_t|h_t)，Δ(y) = Σ_t Δ_t。

- **值等价但梯度不等价**：当 ¯θ = θ 时二者函数值相同，但 J_token 截断了前缀分布对 θ 的依赖。

- **结论**：实践 OPD 丢失了 token 对后续前缀的间接效应，是对序列级目标的时序近似。

### 2.2 γOPD：折扣时序信用分配

- 引入折扣因子 γ ∈ [0,1]，定义折扣优势：
  **A_t^(γ) = −Σ_{t'=t}^{T} γ^{t'−t} Δ_{t'}**
  对应代理梯度 g_γ(θ) = −E[Σ_t A_t^(γ) ∇log π_θ(y_t|h_t)]。
- **两端点插值**：γ = 1 退化为序列级 return-to-go（式 6）；γ = 0 退化为 token 级优势（式 5）；0 < γ < 1 为有偏但可控的插值。
- **定理 3.3（方差稳定性）**：在 E[(A_t^(0))²] ≤ σ_Δ² 假设下
  - 序列级：Var(A_t^(1)) ≤ (T − t + 1)² σ_Δ²，随时域**二次增长**（且最坏情况可达）；
  - γOPD：Var(A_t^(γ)) ≤ σ_Δ² / (1 − γ)²，**与时域无关**。
- 因此 γ 提供了长程信用传播与训练稳定性之间的原则性权衡旋钮。

## 六、主要结论与发现

- **理论结论**：token 级 OPD 是序列级反向 KL 梯度的时序截断近似；γOPD 以有偏代理在两端点间插值，并获得**与时域无关的方差上界**（对比序列级的二次增长）。
- **Vanilla 蒸馏**：γOPD 平均精度 69.49%、平均 Pass 82.41%，相对最强基线分别提升 **2.30% / 1.80%**，且两项均**超过教师**。
- **Size-mismatch 蒸馏**：所有学生方法均低于教师，但 γOPD 最优，相对最强基线提升 **4.92%（AvgAcc）/ 2.06%（AvgPass）**，说明容量受限时时序信用分配收益更大。
- **多教师蒸馏**：TotalAvg 达 66.00，较最强基线 AOPD 提升 **1.87%**，并在 HumanEval+（89.02）与 LCB（28.14）上最佳，数学与代码平均均超过教师。
- **消融结论**：单独时序折扣 +2.04；单独"奖励混合+归一化"（无 γ）+2.00；γ+Mix（无 Norm）仅 +2.09；三者齐全达 **+3.91**，说明时序折扣与有界归一化互补，且朴素奖励混合收益有限、有界归一化是必要环节。
- **γ 敏感性**：γ = 1（序列级）梯度范数显著增大、策略熵迅速塌缩、性能最差；γ = 0.99 最佳，优于 γ = 0.9 与 γ = 0，表明"大但小于 1"的折扣因子是最佳平衡点。
- **训练动态**：γOPD 全程可验证奖励最高、绝对优势稳定、梯度范数波动最小，响应长度收敛到更短
