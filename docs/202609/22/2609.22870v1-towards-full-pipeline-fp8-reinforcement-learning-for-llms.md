## 摘要
强化学习（RL）已成为提升大语言模型（LLMs）推理与智能体能力的一项关键技术。尽管 FP8 量化能够加速 RL 训练，但在整个 FP8 RL 流程中保持稳定性仍然具有挑战性。此前工作主要关注使用 TIS 等校正技术解决训练-推理不匹配问题，而我们发现，全流程 FP8 RL 仍会遭受严重的训练不稳定性，表现为训练中期出现异常的熵激增以及输出乱码。我们将这种不稳定性追溯到一个此前被忽视的原因：复合的 FP8 量化噪声会扭曲重要性比率，不成比例地将负优势 token 推出信任域，并错误地将其梯度置零。结果，病态输出无法得到适当惩罚，并会在训练过程中不断累积。为解决这一问题，我们提出 Calibrated Clipping（校准裁剪），这是一种动态方法，通过匹配下界裁剪分位数并相应地重新平衡上界，使 FP8 裁剪边界与高精度 BF16 分布对齐。在 GRPO 和 DAPO 算法、8B 到 32B 的模型规模以及多种 FP8 缩放粒度上的大量实验表明，我们的方法成功消除了熵激增，并恢复了与 BF16 基线相当的性能。

## Abstract
Reinforcement learning (RL) has become a key technique for improving the reasoning and agentic abilities of large language models (LLMs). Although FP8 quantization can accelerate RL training, maintaining stability throughout an FP8 RL pipeline remains challenging. While previous works have focused on resolving train-inference mismatches using correction techniques like TIS, we reveal that full-pipeline FP8 RL still suffers from severe training instability, manifesting as anomalous mid-training entropy surges and garbled outputs. We trace this instability to a previously overlooked cause: compounded FP8 quantization noise distorts the importance ratio, disproportionately pushing negative-advantage tokens outside the trust region and erroneously zeroing out their gradients. As a result, pathological outputs are not properly penalized and accumulate over the course of training. To address this, we propose Calibrated Clipping, a dynamic method that aligns the FP8 clipping bounds with high-precision BF16 distributions by matching the lower-bound clipping quantile and rebalancing the upper bound accordingly. Extensive experiments across GRPO and DAPO algorithms, model scales from 8B to 32B, and multiple FP8 scaling granularities demonstrate that our approach successfully eliminates entropy surges and restores performance comparable to the BF16 baseline.

## 1. 核心问题与整体含义

- **已有工作的盲区**：此前研究（TIS、MIS 等）主要聚焦于修正 FP8 rollout 与训练之间的"训练-推理不匹配"，以及通过统一 FP8 流程缩小精度差距；但**没有人识别出本文所揭示的失败模式**。
- **核心洞察（本文关键发现）**：复合的 FP8 量化噪声在重要性比率 $r_t(\theta)$ 上被放大（相对单点概率误差放大 1.65×–2.90×），系统性地将**负优势 token** 推出信任域下界 $1-\epsilon$，错误地将其梯度置零。结果是乱码输出无法被惩罚，逐步累积并最终导致训练崩溃。

## 2. 方法论：Calibrated Clipping（校准裁剪）

### 核心思想
- FP8 量化后，重要性比率的真实分布被非线性算子 $\tilde{Q}(\cdot)$ 扭曲。理想裁剪边界应满足 $L = \tilde{Q}(1-\epsilon)$、$H = \tilde{Q}(1+\epsilon)$，但 $\tilde{Q}$ 不可解析。
- 因此**不直接改变裁剪语义，而是动态重建信任域**：用高精度 BF16 参考分布来"校准"FP8 域中的裁剪上下界。

### 两阶段校准流程

1. **下界对齐（Lower-Bound Alignment）**
   - 仅针对负优势 token（$A_t<0$），定义 BF16 与 FP8 下重要性比率的累积分布函数 $F_{BF16,-}$ 与 $F_{FP8,-}$。
   - 先从 BF16 参考分布求出目标裁剪分位数：$\alpha_{low} = F_{BF16,-}(1-\epsilon)$。
   - 再对 FP8 分布取逆 CDF 得到校准下界：$L = F^{-1}_{FP8,-}(\alpha_{low})$。
   - 效果：使 FP8 域中被下界裁剪的 token 比例与 BF16 一致，消除"过度裁剪"。

2. **上界重平衡（Upper-Bound Rebalancing）**
   - 仅放宽下界会导致过度负更新与熵过早饱和。为此引入正/负更新贡献比 $\rho$（公式 5），包含 TIS 权重 $w^{TIS}_t$。
   - 计算 BF16 参考比值 $\rho_{BF16}$，在给定校准下界 $L$ 的条件下，搜索新的上界 $H$，使 $\rho_{FP8}(L,H) = \rho_{BF16}$，从而平衡正负更新。

3. **周期性重校准与平滑更新（Algorithm 1）**
   - 每隔若干训练步（默认每 20 步）执行两次 **BF16 前向影子计算**（仅前向，无反向），获取 $\pi_\theta^{BF16}$ 与 $\pi_{old}^{BF16}$ 的参考比率。
   - 搜索区间：$I_L=[0.5,0.9]$、$I_H=[1.2,2.0]$，步长 $\Delta=0.02$。
   - 平滑更新：$\text{SmoothUpdate}(b,b^\star,\delta)=b+\text{clip}((b^\star-b)/2,-\delta,\delta)$，最大步长 $\delta_L=0.05$、$\delta_H=0.1$，防止信任域突变。
   - 初始化边界 $[0.6, 1.8]$，以加快收敛。

## 6. 主要结论与发现

- **机制性发现**：全流程 FP8 RL 的不稳定性源自**复合量化噪声 → 重要性比率失真 → 下界过度裁剪 → 负优势梯度被错误置零 → 乱码输出累积**的失败循环。
  - 后训练阶段约 **70% 的过度裁剪发生在下界**；
  - 约 **90% 的下界过度裁剪 token 来自高熵（乱码）响应**；
  - 即使最细粒度的 blockwise FP8，裁剪比例仍比 BF16 高近 **4×**。
- **方法有效性**：Calibrated Clipping 在所有算法、模型规模和 FP8 粒度上**消除熵激增**，恢复到 BF16 级别性能。
  - Qwen3-8B GRPO：blockwise FP8 + Calibrated Clipping 平均分 **58.6**，超过 BF16 基线（57.6）；tensorwise 从 46.1 提升至 55.9，rowwise 从 47.0 提升至 56.5。
  - Qwen2.5-32B：blockwise 达到 53.4 vs BF16 的 51.9。
  - DAPO/Qwen3-14B：tensorwise 从 35.7 提升至 47.9（接近 BF16 的 50.9）。
- **效率收益**：Tensorwise FP8 训练吞吐量可达 BF16 的 **1.5×**，blockwise 仍有 10%–20% 提升；结合 FP8 rollout 约 30% 的生成加速，整体管线效率显著提升。
- **方法对比结论**：CISPO 在 FP8 下仍崩溃（保留被裁剪梯度不足以稳定训练）；BAPO 的固定贡献目标在 FP8 设置下失效。

## 7. 优点

- **问题识别新颖且深入**：首次将 FP8 RL 崩溃归因于"重要性比率上的复合噪声导致的系统性下界过度裁剪"，并用 BF16 影子前向做了定量验证（NMAE 放大倍数、下界裁剪占比、高熵响应来源占比）。

- **鲁棒性验证较全面**：跨 GRPO/DAPO、8B–32B、三种缩放粒度、数学与编码任务均一致有效；消融显示对更新间隔与初始化不敏感。
- **与已有校正手段正交**：默认叠加 TIS，说明方法可与既有 FP8 RL 稳定化技术组合使用。
- **提供了反例证据**：附录中 CISPO 与 BAPO 的失败实验增强了"必须校准裁剪边界"这一论点的说服力。
