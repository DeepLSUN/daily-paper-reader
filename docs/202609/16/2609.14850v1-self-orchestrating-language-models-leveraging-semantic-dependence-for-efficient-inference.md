## 摘要
大型语言模型（LLMs）展现出令人印象深刻的能力，但其部署面临显著的效率挑战。自回归解码带来可观的推理延迟，并在低批量大小场景下未能充分利用硬件加速器。离散扩散模型可以并行生成，但若没有大量扩散去噪步骤，难以匹敌自回归的质量。长上下文推理造成内存瓶颈，甚至使最先进的加速器也承受压力。我的论点是，语言模型可以通过在其生成过程中标注语义依赖——即哪些词元依赖于哪些其他词元——来指导自身的推理执行策略。我将这类模型称为自编排语言模型。针对每个系统，我设计了一个运行时，它根据这些标注来并行化自回归解码、逐出中间上下文或推导去噪顺序，从而实现帕累托最优的质量-效率权衡。我通过三个自编排系统展示了这一方法。首先，PASTA 利用语义依赖来并行化自回归解码，训练模型标注哪些输出块可以独立生成。其次，TIP 利用语义依赖从 KV 缓存中逐出中间推理步骤，在保持准确率的同时降低内存消耗。第三，Planned Diffusion 利用语义依赖为离散扩散推导去噪顺序，自回归地生成一个计划，指定哪些块并行去噪。

## Abstract
Large language models (LLMs) demonstrate impressive capabilities, but their deployment presents significant efficiency challenges. Autoregressive decoding imposes substantial inference latency and under-utilizes hardware accelerators in low batch size regimes. Discrete diffusion models can generate in parallel but struggle to match autoregressive quality without many diffusion denoising steps. Long-context reasoning creates memory bottlenecks that strain even state-of-the-art accelerators.   My thesis is that language models can direct their own inference execution strategy by annotating semantic dependence -- which tokens depend on which others -- in their generation. I call such models self-orchestrating language models. For each system, I design a runtime that acts on these annotations to parallelize autoregressive decoding, evict intermediate context, or derive denoising orders, achieving Pareto-optimal quality-efficiency trade-offs.   I demonstrate this approach through three self-orchestrating systems. First, PASTA uses semantic dependence to parallelize autoregressive decoding, training the model to annotate which output chunks can generate independently. Second, TIP uses semantic dependence to evict intermediate reasoning steps from the KV cache, reducing memory consumption while preserving accuracy. Third, Planned Diffusion uses semantic dependence to derive a denoising order for discrete diffusion, autoregressively generating a plan that specifies which chunks to denoise in parallel.

## 一、核心问题与整体含义（研究动机与背景）

- **效率瓶颈**：大语言模型（LLM）推理已占全部AI算力约三分之二，需求年增4–5倍，远超硬件效率提升速度。自回归解码存在两大结构性瓶颈：
  - **顺序延迟**：每个token依赖所有前驱token，形成全序依赖链，低批量下MFU不足20%。
  - **内存膨胀**：KV缓存随生成长度线性增长，长链推理（如数万token的思维链）严重制约批大小与吞吐。
- **现有方法的不足**：
  - 推测解码（Speculative Decoding）无法突破顺序链，只是并行验证。
  - 异步解码（SoT、APAR）依赖手工正则启发式，不可学习、不鲁棒、无法随训练算力扩展。
  - 离散扩散可并行生成，但去噪顺序依赖随机或熵启发式，质量-延迟权衡欠佳。
  - KV缓存驱逐方法（StreamingLLM、H2O等）使用位置或注意力分数启发式，牺牲精度。
- **核心论点**：语言模型可通过在生成过程中标注**语义依赖**（哪些token依赖哪些其他token）来指导自身的推理执行策略。作者将这类模型称为**自编排语言模型**（Self-Orchestrating Language Models），并主张好的推理优化应满足三个设计目标：
  1. **输入自适应**（Input-adaptive）
  2. **可学习**（Learnable）
  3. **可检查**（Inspectable）

## 二、方法论：核心思想与关键技术细节

### 2.1 统一设计方法论
每个系统均包含三要素：**标注语言** + **协同设计的运行时** + **训练程序**。

| 系统 | 标注语言 | 运行时动作 | 训练方式 |
|------|---------|-----------|---------|
| PASTA | `<promise/>`、`<async>`、`<sync/>` | 并行解码线程 | SFT + 偏好优化 |
| TIP | `<reg_0>`…`<reg_{N-1}>` | KV缓存页驱逐 | SFT + GRPO强化学习 |
| Planned Diffusion | `<topic>`、`<async>`、`<sync/>` | 扩散去噪顺序 | SFT（联合AR+扩散损失） |

### 2.2 PASTA（并行生成）
- **核心思想**：将响应划分为语义独立的**块（chunk）**，通过`<promise/>`声明块及其主题/长度，`<sync/>`标记同步点。无依赖的块并行解码。
- **运行时**：单一预分配KV缓存池，线程交错写入；注意力掩码防止跨线程干扰；同步后KV缓存恢复连续布局。
- **训练**：
  - 阶段一：用Gemini 1.5 Flash标注SlimOrca数据集（成功87K/100K），SFT微调Gemma 7B。三项关键修改：异步块注意力隔离、预测块长度以分配位置ID、跳过`<promise/>`的下一token目标。
  - 阶段二：BoNBoN偏好优化，评分 = 理论加速比 + λ × 质量（置信度加权胜率），联合优化质量与延迟。

### 2.3 TIP（上下文驱逐）
- **核心思想**：引入N个**思维寄存器**（thought registers），每个推理步骤前缀一个寄存器token。复用寄存器即标记旧步骤为“死亡”，运行时驱逐其KV缓存页。活跃步骤数上界为N。
- **运行时**：基于Paged Attention（vLLM），维护寄存器表，页内全部token死亡时才驱逐整页；使用FlexAttention块稀疏掩码，增量缓存掩码。
- **训练**：
  - 阶段一：Gemini Flash标注DeepMath-103K的5K子集，生成步骤依赖DAG，贪心分配寄存器（Bélády式最优替换），SFT 2轮。
  - 阶段二：GRPO强化学习50步，奖励 = 正确性基础奖励 × (1 − k̄/L)，其中k̄为平均活跃KV token数，线性惩罚缓存占用。

### 2.4 Planned Diffusion（分解生成）
- **核心思想**：单一模型先自回归生成**计划**（`<topic>`定义各块主题与长度），再对独立块并行扩散去噪。多轮迭代：计划→去噪→再计划。
- **形式化**：联合分布 p_PD(z, x | c; σ_Plan(z)) = p_AR(z|c) · p_D(x|z,c; σ_Plan(z))，其中σ_Plan将各块内去噪顺序合并为全局顺序。
- **注意力掩码**：计划阶段因果注意力，`<async>`块内双向注意力（支持并行去噪），`<sync/>`后可见全部历史。
- **训练损失**：L(θ) = 自回归CE（计划token）+ 扩散CE（内容token，含掩码率1/t加权）。
- **推理**：定义**步比r**（去噪步数 = r × 最长块长度）和**置信度阈值τ**控制质量-延迟权衡。

### 2.5 统一抽象（第6章）
- 三个系统可归约为单一**任务（task）**抽象：
  - **声明式自编排**：模型标注任务DAG（名称+依赖集），运行时推导并行/驱逐策略。PASTA与Planned Diffusion为扁平任务，TIP为嵌套任务（子目标完成后释放内部步骤）。
  - **命令式自编排**：模型直接发出`fork`/`wait`/`free`命令，运行时执行。可表达依赖图无法编码的决策（如优先级、预取）。

- **评价指标**：准确率、平均活跃KV缓存、聚合吞吐（tok/s）、总解码时间。

- **数据集/Benchmark**：AlpacaEval 805条；SlimOrca用于训练。

- **硬件**：4×H200（141GB），PyTorch + HuggingFace，per-GPU batch size 1，global batch size 4。

  - PASTA和Planned Diffusion仅在AlpacaEval上评估，未覆盖代码、数学等长推理场景。
  - TIP仅在数学竞赛（AIME）上评估，领域较窄。
  - 未报告统计显著性检验或置信区间（除Planned Diffusion的数据集细分表外）。

---

## 六、主要结论与发现

1. **PASTA**：几何平均加速1.21×–1.93×，质量变化+2.2%至−7.1%（LC Win Rate），帕累托支配APAR和SoT。偏好优化迭代持续改善质量-延迟前沿，无饱和迹象。
2. **TIP**：AIME 2024/2025上KV缓存减少59%/54%，准确率提升6.4/2.1个百分点；吞吐提升30%/21%，解码时间缩短35%/28%。帕累托支配Dense、SLLM和PH2O。
3. **Planned Diffusion**：相对自回归加速1.27×–1.81×，质量下降0.87%–5.4%；PD-SA达1.81×加速、44.6% LCWR。关键路径缩短2.3–2.8倍。质量随训练epoch持续提升（PD +4.3点），而自回归基线持平。
4. **统一发现**：三个系统验证了同一设计方法论——标注语言 + 运行时 + 训练——可在三个不同瓶颈（并行生成、内存管理、去噪调度）上实现帕累托改进。模型可管理服务系统，而非仅被服务系统管理。

---

## 七、优点

- **范式创新**：首次系统性地提出“自编排语言模型”概念，让模型通过标注语义依赖来指导自身推理执行，区别于传统外部调度器。
- **统一方法论**：三个系统共享“标注语言-运行时-训练”三件套，第6章进一步抽象为任务DAG和命令式两种统一视图，理论优雅。
- **可学习性**：相比SoT/APAR的固定正则，PASTA和TIP通过偏好优化/RL直接从任务性能优化，可随训练算力扩展。
- **工程细节扎实**：PASTA的交错KV缓存池与注意力掩码、TIP的Paged Attention页级驱逐与增量掩码缓存、Planned Diffusion的混合注意力掩码，均展示了深入的系统级思考。
- **实验严谨性**：使用几何平均（并解释为何不用算术平均）、不同judge防reward hacking、mean-of-16降方差、Lyapunov式消融分析。
- **可检查性**：离散标注token可被人类审查、调试，符合设计目标中的“inspectable”。

## 八、不足与局限

- **理论边界缺失**：论文自述结果为纯实证，未分析可达到的加速/内存缩减理论上限。
- **系统未收敛**：三个系统未统一到单一标注语言或单一运行时，无法同时提供所有优化。
- **位置ID预测误差**：PASTA依赖模型预测异步块长度来分配位置ID，预测偏差会导致位置不单调或出现间隙；虽采用Pred-10X粗粒度缓解，但仍是近似方案。
- **TIP页面碎片化**：由于不对齐页边界，活跃KV缩减不直接转化为页数减少，吞吐增益小于缓存缩减比例（21–30% vs 54–59%）。禁用页对齐和死token抑制是精度与吞吐的折衷。
- **Planned Diffusion失败模式**：当规划器生成泛化主题（如“list part 1”）时，PD-SA的块间独立注意力导致严重重复（如“New York City”出现4次）；密集注意力PD可缓解但增加计算。
- **最小问题规模依赖**：标注开销要求响应足够长（TIP需长推理链，PASTA/PD需多并行块），短响应下标注成本可能超过收益。
- **评估覆盖有限**：仅AlpacaEval（指令遵循）和AIME（数学竞赛），缺乏代码生成、多轮对话、工具调用等场景；未在更大规模模型（如70B+）上验证。
- **算力报告不完整**：未披露总GPU小时数、训练能耗或碳足迹，不利于可复现性与可持续性评估。
- **RL在扩散模型上的空缺**：作者指出Planned Diffusion的计划token原则上可用RL优化，但留作未来工作。
