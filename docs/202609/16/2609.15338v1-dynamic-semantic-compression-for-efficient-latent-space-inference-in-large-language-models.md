## 摘要
大语言模型（LLM）主要在词元（token）级别进行推理，导致大量内存开销并损害计算效率。本文提出了一种动态语义提取与推理（DSEI）框架，通过两阶段训练策略在潜在空间中实现片段级推理。首先，我们通过自监督学习构建动态语义自编码器（DSAE）。DSAE 通过自适应语义加权和门控融合，动态提取片段级语义并将其压缩为紧凑的潜在表示。随后，我们将 DSAE 集成到 LLM 架构中，并训练模型在稠密潜在空间上进行推理。DSEI 大幅缩短了输入和生成序列，并显著提升了推理效率。在万卷数据集上进行的大量实验表明，与静态句子级潜在推理基线相比，DSEI 将困惑度降低了 48%。此外，与使用词元级推理的标准 LLM 相比，DSEI 将推理速度提升了 2.5 倍，并将内存开销降低了 90%。

## Abstract
Large Language Models (LLMs) primarily perform inference at the token level, resulting in substantial memory overhead and compromised computational efficiency. In this paper, we propose a Dynamic Semantic Extraction and Inference (DSEI) framework, which achieves segment-level inference within the latent space through a two-stage training strategy. First, we construct a Dynamic Semantic Autoencoder (DSAE) via self-supervised learning. DSAE dynamically extracts segment-level semantics and compresses them into compact latent representations via adaptive semantic weighting and gated fusion. Subsequently, we integrate the DSAE into the LLM architecture and train the model to infer over dense latent space. DSEI substantially reduces both input and generation sequences and significantly enhances inference efficiency. Extensive experiments conducted on the Wanjuan dataset demonstrate that DSEI reduces perplexity by 48% compared to static sentence-level latent inference baseline. Furthermore, compared to standard LLMs using token-level inference, DSEI accelerates inference speed by 2.5$\times$ and reduces memory overhead by 90%.

## 1. 核心问题与整体含义

- **研究动机**：主流 LLM 以 token 为粒度进行自回归推理，导致序列长、显存访问密集、部署成本高，尤其在资源受限或延迟敏感场景中问题突出。
- **背景趋势**：已有潜在空间推理工作多用于压缩中间推理链（如 CoT 到隐表示），或采用固定句子级压缩（如 SentenceVAE/SVAE），但固定粒度忽略句子长度差异与 token 语义密度差异，容易造成长句信息瓶颈或冗余压缩。
- **整体含义**：论文提出 **DSEI（Dynamic Semantic Extraction and Inference）**，把 LLM 推理从 token 级推进到 **自适应片段级潜在空间推理**，同时压缩输入与输出序列，在生成质量与部署效率之间取得更好折中。

## 2. 方法论

- **核心思想**：
  - 两阶段训练：先自监督训练 **DSAE（Dynamic Semantic Autoencoder）**，再将其接入 LLM 做端到端潜在空间推理。
  - 用长度自适应分段 + token 级语义加权 + 门控融合，生成紧凑但信息量高的片段级隐表示。
  - LLM 不再直接处理 token，而是处理这些片段级隐向量，输出端再由解码器还原为自然语言。

- **DSAE 编码器细节**：
  - 输入句子经 token 化与嵌入后，由堆叠 Transformer 编码层得到隐藏状态 \(h_{1:l}\)。
  - 按 token 长度分段：少于 15 个 token 为 1 段；15–30 个 token 为 2 段；更长句子为 3 段。
  - 每个片段 \(h_k\) 形成两种表示：
    - **静态语义 \(s_{k,a}\)**：对片段隐藏状态求和后 LayerNorm，保留全局信息。
    - **动态语义 \(s_{k,b}\)**：用 Semantic Probe 将 \(h_k\) 映射为 token 权重，经 softmax 归一化后对 \(h_k\) 加权平均，突出语义重要 token、抑制功能词。
  - **门控融合**：\(s_k = \sigma(w_{gate}) \cdot s_{k,a} + (1-\sigma(w_{gate})) \cdot s_{k,b}\)，平衡全局信息与动态稀疏信息，减少冗余。
  - 解码器以片段隐表示序列为 cross-attention 的 key/value，自回归重建原句；训练目标为 focal loss，用于缓解重建难度。

- **参数迁移策略**：
  - DSAE 编码器/解码器初始参数来自同功能 LLM 骨干。
  - 编码器参数取自 LLM 前 \(i\) 层，解码器参数取自 LLM 后 \(i\) 层；仅使用 self-attention 模块权重，不使用 FFN 权重。
  - 目的：让模型从预训练语言理解能力出发，而不是从随机初始化开始学习语法与语义。

- **DSEI 推理流程**：
  - 将 LLM 的 token embedding 层替换为 DSAE 编码器与语义提取层；LLM 输出隐藏状态由 DSAE 解码器还原为文本。
  - 输入文本按标点分句，每句按长度分成 \(K_i\) 个片段，编码为片段级隐表示并拼接，总输入长度从 \(m\) 降为 \(\sum_i K_i\)。
  - LLM 自回归生成输出片段级隐表示 \(\hat{s}_{1:T}\)。
  - **Segmentation Head**：预测隐表示是否为一个句子级隐组的边界，用于恢复句子结构。
  - **Termination Head**：判断生成是否应终止。
  - 总损失包含三部分：token 级生成项、句子边界分段项、停止项，联合优化，权重系数为 \(\lambda\)。
