## 摘要
大型语言模型（LLM）推理受限于自注意力的二次方扩展和 KV 缓存的线性扩展；随着上下文长度增长，这会增加延迟、能耗和 GPU 内存需求。现有的软压缩方法要么在推理时缺乏查询引导的记忆选择，要么在训练时没有面向答案的监督，要么将压缩与特定解码器架构紧密耦合。我们提出 Context-to-Answer-Aligned Memory Compression（CMC）框架，将长输入上下文压缩为紧凑的 Context Memory Embeddings（CMEs），并将其对齐到任意冻结解码器的嵌入空间，从而在不修改解码器权重的情况下降低推理成本。CMC 引入一种双层 KV 缓存，将问题引导的 CME 选择与局部上下文窗口相结合，并利用来自冻结 LLM 的答案目标蒸馏训练压缩器。在九种编码器-解码器组合和四个问答基准上的实验表明，CMC 始终优于基线，在 SQuAD 上最多获得 7.3 EM 和 4.0 F1 点的提升，同时在生成 3,000 个 token 时将推理时间和能耗最多降低 20%，并将峰值预留 GPU 内存最多降低 50%。消融研究证实，每个架构组件和训练目标都对性能有贡献。

## Abstract
Large language model (LLM) inference is constrained by the quadratic scaling of self-attention and the linear scaling of the KV cache, increasing latency, energy consumption, and GPU memory demand as context length scales. Existing soft-compression methods either lack query-guided memory selection at inference time, train without answer-targeted supervision, or couple compression tightly to a specific decoder architecture. We propose a Context-to-Answer-Aligned Memory Compression (CMC) framework, which compresses long input contexts into compact Context Memory Embeddings (CMEs) aligned to any frozen decoder's embedding space, reducing inference costs without modifying decoder weights. CMC introduces a two-tier KV cache that combines question-guided CME selection with a local context window, and trains the compressor with answer-targeted distillation from a frozen LLM. Experiments across nine encoder-decoder combinations and four QA benchmarks show that CMC consistently outperforms the baseline, achieving up to 7.3 EM and 4.0 F1 point gains on SQuAD, while reducing inference time and energy consumption by up to 20% and peak reserved GPU memory by up to 50% at 3,000 generation tokens. Ablation studies confirm that each architectural component and training objective contributes to the performance.

## 1. 核心问题与整体含义

- **研究动机**：LLM 推理受两大瓶颈制约——自注意力计算量随序列长度二次方增长，KV 缓存随序列长度线性增长。上下文变长时，延迟、能耗与 GPU 显存需求同步上升，在真实部署（长文档、多轮对话、多文档推理）中尤为突出。
- **现有方法的不足**：
  - **架构类方法**（稀疏/局部注意力、位置编码扩展）需要大幅修改架构或继续预训练，难以用于已部署模型。
  - **硬提示压缩**（按自信息或困惑度丢弃 token）模型无关，但造成不可逆信息损失，在多跳推理与长文档 QA 上性能退化。
  - **软压缩**将上下文编码为稠密嵌入供冻结解码器使用，压缩率更高，但现有工作（如 PCC）仍存在三大缺口：推理时缺少查询引导的记忆选择、训练缺乏答案目标监督、压缩与特定解码器架构强耦合。
- **整体含义**：论文提出 **Context-to-Answer-Aligned Memory Compression（CMC）** 框架，首次尝试同时解决"跨架构部署 + 答案目标监督 + 查询引导记忆选择"三个问题，在不修改解码器权重的前提下实现面向答案的长上下文软压缩与高效推理。

## 2. 方法论

### 核心思想
将长上下文 $C$ 压缩为紧凑的 **Context Memory Embeddings（CMEs）**，经投影后对齐到任意冻结解码器的嵌入空间，使冻结解码器能够以 CME 替代原始 token 进行注意力计算。整体形式化为：

$$\hat{a} = f_{\theta_d}(\cdot \mid M^*, C_{local}, q), \quad M^* = \text{TopK}(g_\phi(f_{\theta_c}(C)), q, K)$$

其中 ContextEncoder $f_{\theta_c}$ 与 MemoryBridge $g_\phi$ 是唯一可训练组件，DecoderLLM $f_{\theta_d}$ 全程冻结。

### 三大组件

- **ContextEncoder（可训练）**：
  - **图基上下文去噪**：对每个 token 与其 $g$ 个下游邻居计算余弦相似度，若与至少一个后续邻居的相似度 ≥ 阈值 $\tau$ 则保留，否则丢弃（式 3），以去除语义孤立的低显著 token。
  - **分段与记忆 token**：去噪后的上下文按固定长度 $t$ 切分为 $n_s$ 个非重叠片段，每段附加 $m^{(c)}$ 个固定占位 token（由 `<MEM>`/`</MEM>` 包围），压缩率 $r = t/m^{(c)}$，实验取 $r \in \{2,4,8\}$。
  - **CME 提取**：通过因果自注意力，占位 token 聚合片段内容，取最终 Transformer 层中占位位置的隐藏状态作为段级 CME（式 5），拼接得到完整 CME 矩阵（式 6）。

- **MemoryBridge（可训练）**：两层 MLP + LayerNorm，将 CME 从编码器隐空间 $\mathbb{R}^{H_c}$ 投影到解码器嵌入空间 $\mathbb{R}^{H_d}$。采用**范数校准 tanh**（式 7）：$\tilde{m} = \nu \tanh(\hat{m}) \cdot \min(1, 2\nu / \|\nu\tanh(\hat{m})\|_2)$，保证投影后 CME 的 $\ell_2$ 范数不超过解码器自身 token 嵌入平均范数的两倍，实现跨架构适配。

- **冻结 DecoderLLM**：以两层 KV 缓存为条件生成答案。

### 两阶段训练

- **Phase-1（解码器对齐）**：用自编码（AE）重建完整上下文 + 自回归（AR）重建前半上下文，损失 $L_1 = L_{AE} + \lambda_{AR} L_{AR}$，确保 CME 携带足够信息。
- **Phase-2（答案对齐）**：利用冻结 DecoderLLM 同时作为"教育者"（输入局部窗口+问题）和"学习者"（输入 CME+局部窗口），联合三项损失：
  $$L_2 = L_{CE} + \lambda_{KL} L_{KL} + \lambda_{CL} L_{CL}$$
  其中 $L_{CE}$ 监督金答案 token，$L_{KL}$ 对齐学习者与教育者的输出分布，$L_{CL}$ 对比损失将 CME 均值拉向教育者在答案跨度的隐藏状态。

### 推理：两层 KV 缓存策略

- **Tier-1（问题引导 Top-K）**：将问题 token 经冻结嵌入层平均池化得查询向量 $q_{vec}$，对每个 CME 按余弦相似度打分（式 11），选 Top-K 并按原文档位置重排为 $M^*$。
- **Tier-2（局部上下文窗口）**：以金答案起始位置 $\alpha$ 为中心截取 $W$ token 窗口 $C_{local}$（式 12），保留全 token 分辨率的局部精度。
- **KV 缓存组装**：预填输入为 $[M^* \parallel C_{local} \parallel q]$，总缓存长度在任意生成步都被限定在 $K + W + |q|$ 以内，与文档长度无关。
