## 摘要
同策略蒸馏（OPD）为每个新批次付出双倍代价：学生生成轨迹，更强的教师对其打分。现有方法改进了哪些轨迹被打分以及教师信号如何构造，但通常仅用一次 actor 更新来消费该信号。我们提出 CLOOPD，一个闭环框架，将教师信号获取与学生侧实现分离。CLOOPD 在 KL 包络内选择一个自适应 α 路点，冻结已打分的批次及其优势，在每次 actor 更新后重新前向传播学生模型，度量实现程度，并在单独的 token 预算下分配 actor 工作量。该框架包括确定性的两遍与三遍策略、按 token 计价的 CLOOPD-TPMR，以及预算匹配的对照。在 8-H20 节点上的六次 300 步运行中，每个 CLOOPD 策略在教师 token 规模相当的情况下都优于单遍 TOP-D 基线：宏观准确率从 15.41 提升至 CLOOPD-Fixed2 的 17.78，以及 CLOOPD-Fixed3 的 19.36。在第 100 步时，CLOOPD-Fixed3 达到 15.35，几乎匹配第 300 步的 TOP-D，同时使用的教师打分 token 少 67.2%，GPU 小时少 28.0%。此前的 8-A100 消融实验表明，自适应 α 消除了观察到的信任包络违规；第三遍增加了余量。这些结果将 CLOOPD 定位为一个框架，用于为学生在多大程度上从教师打分 token 中学习进行预算。

## Abstract
On-policy distillation (OPD) pays twice for each fresh batch: the student generates trajectories and a stronger teacher scores them. Existing methods improve which trajectories are scored and how the teacher signal is constructed, but usually consume it with one actor update. We introduce CLOOPD, a closed-loop framework separating teacher-signal acquisition from student-side realization. CLOOPD selects an adaptive $α$ waypoint inside a KL envelope, freezes the scored batch and its advantages, re-forwards the student after each actor pass, measures realization, and allocates actor work under a separate token budget. The framework includes deterministic two- and three-pass policies, token-priced CLOOPD-TPMR, and a budget-matched control. Across six 300-step runs on an 8-H20 node, every CLOOPD policy improves the one-pass TOP-D anchor at comparable teacher-token scale: macro accuracy rises from 15.41 to 17.78 with CLOOPD-Fixed2 and 19.36 with CLOOPD-Fixed3. At step 100, CLOOPD-Fixed3 reaches 15.35, nearly matching TOP-D at step 300 while using 67.2% fewer teacher-scored tokens and 28.0% fewer GPU-hours. Earlier 8-A100 ablations show adaptive $α$ eliminates observed trust-envelope violations; a third pass adds headroom. These results position CLOOPD as a framework for budgeting how fully students learn from teacher-scored tokens.

- **研究动机**：同策略蒸馏（On-Policy Distillation, OPD）中，每个新批次都要付出“双倍成本”：学生生成轨迹，强教师对轨迹逐 token 打分。现有工作多聚焦于“哪些轨迹值得打分”“如何构造更安全的教师信号”，但通常只做一次 actor 更新，随后丢弃该教师打分批次。
- **核心缺口**：论文提出一个互补问题——在已经为安全教师信号付费后，学生到底把该信号“实现”了多少？标准单遍 OPD 把两个资源混在一起：购买更多批次增加教师信号**广度**，复用同一批次做更多 actor pass 增加学生实现**深度**。二者都表现为“更多训练”，但成本结构不同。
- **整体含义**：CLOOPD 将教师信号获取与学生侧实现解耦，把“学生从教师打分 token 中学到多充分”显式纳入预算管理，目标是在教师推理昂贵时，通过复用已打分批次来摊销教师 token 成本。

### 2. 方法论：核心思想与关键技术
- **总体框架**：CLOOPD 把每个教师打分批次视为闭环交易，包含 **Probe–Observe–Allocate** 三阶段：
  - **Probe**：构造 KL 可行路点并执行 actor pass；
  - **Observe**：在同一批轨迹上重新前向学生，测量实现程度；
  - **Allocate**：按实现策略决定是否追加 actor token。
- **自适应 α 路点构造**：
  - 对学生采样轨迹，令 \(\ell^S_t=\log\pi_0(y_t|x,y_{<t})\)，\(\ell^T_t=\log q^T(y_t|x,y_{<t})\)。
  - TOP-D 构造近端教师 \(q_\alpha=(1-\alpha)\pi_0+\alpha q^T\)，采样 token 奖励为  
    \(g_{\alpha,t}=\log(1-\alpha+\alpha e^{\ell^T_t-\ell^S_t})\)。
  - CLOOPD 在 32 点对数间隔的 \(\alpha\in[0.01,1]\) 网格上，选择满足  
    \(\widehat K_{\text{ext}}(\alpha)=\langle e^{g_\alpha}-1-g_\alpha\rangle_m\le0.02\)，且 \(Q_{0.05}(g_\alpha)\ge-0.5\) 的**最大** \(\alpha\)。这使每个批次在信任包络内获得尽可能强的教师信号。
  - 将 \(g_\alpha\) 转为 TOP-D token return，并在 prompt 内归一化得到优势 \(A_0\)。路点、响应、行为/教师 log 概率、mask、\(A_0\) 全部冻结。
- **Probe：冻结信号下的 actor passes**：
  - 第一遍 E1 产生 \(\pi_1\)；CLOOPD 策略可选第二遍 E2、第三遍 E3，产生 \(\pi_2,\pi_3\)，但始终复用同一 \(A_0\)。
  - E2/E3 只消耗 actor response token，不触发生成新 rollout，也不调用教师。
- **Observe：路点实现与优势实现**：
  - 采样 token 学生位移：\(\Delta_t^{(k)}=\log\pi_k(y_t|x,y_{<t})-\log\pi_0(y_t|x,y_{<t})\)。
  - 初始路点 gap \(e_{0,t}=g_{\alpha,t}\)，残差 gap \(e_{k,t}=e_{0,t}-\Delta_t^{(k)}\)。
  - Teacher-Signal Realization：\(\text{TSR}^{(k)}=1-\frac{\langle e_k^2\rangle_w}{\langle e_0^2\rangle_w}\)，衡量在采样路径上闭合教师路点 gap 的程度。
  - 权重 \(w_{i,t}=\frac{1}{|P|\,|R(p_i)|\,L_i}\)，实现 prompt 均衡，避免长答案或多 rollout prompt 主导统计。
  - 优势空间边际实现：\(M_k=\langle A_0,\log\pi_k(y)-\log\pi_{k-1}(y)\rangle_w\)，按 prompt 计算均值、标准误和 95% 下置信界（LCB）。\(M_k>0\) 表示第 k 遍在冻结交易上做出优势对齐的进展。
- **Allocate：四种实现策略**：
  - **CLOOPD-Fixed2**：每批固定 E1+E2，稳定可预测的两遍骨干。
  - **CLOOPD-Fixed3**：每批固定 E1+E2+E3，展示实现深度上限与 E3 余量。
  - **CLOOPD-TPMR**：E1+E2 后，E3 为在线动作。定义 \(g_t=\max(\text{LCB}(M_{2,t}),0)\)，\(c_t\) 为一次 actor pass 的有效 response token 数，效用 \(u_t=\frac{10^6 g_t}{\max(c_t,1)}\)。当 \(u_t\ge\lambda_{\text{token}}\) 且满足安全、预算、节奏约束时执行 E3；预算仅在成功 E3 后按实际 active-token 计费。\(\lambda_{\text{token}}\) 由 Fixed3 试点校准，不使用 E3 结果或 held-out 准确率。
  - **CLOOPD-Random**：共享 TPMR 的 E1+E2 骨干、硬 E3 token 上限、节奏和安全检查，但随机选择 E3，不读取 \(M_2\)，作为预算匹配的分配对照。
- **四个不变量**：rollout 策略 \(\pi_0\) 锚定所有采样 token ratio；路点每批只求解一次后冻结；\(A_0\) 不在 E1/E2 后重算；教师 token 与 actor token 按资源所有者分开计费。
