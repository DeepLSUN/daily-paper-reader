## 摘要
同策略蒸馏（OPD）通过学习更强教师与同策略学生之间的 token 级差异来改进推理模型。然而，这种差异并不纯粹反映教师与学生之间的能力差距：它还包含源于教师自身的偏差，这些偏差因此被混入观测到的师生差异中，并在训练期间被标准 OPD 不加区分地学习。特权 OPD 进一步加剧了该问题：特权信息会引发更大的教师侧似然偏移，从而促使学生学习更多教师自身的偏差。我们提出校准同策略蒸馏（Cal-OPD），它通过正向和负向特权干预来估计教师的自偏差区域，并通过仅保留超出该区域的分量来校准原始师生差异。在数学推理基准上的实验表明，Cal-OPD 仅保留原始师生差异的约 52--65% 作为优化信号，却在不同模型规模上始终优于标准 OPD 及其变体。

## Abstract
On-policy distillation (OPD) improves reasoning models by learning the token-level discrepancy between a stronger teacher and an on-policy student. However, this discrepancy does not purely reflect the capability gap between the teacher and the student: it also contains deviations arising from the teacher itself, which are consequently mixed into the observed teacher--student discrepancy and indiscriminately learned by standard OPD during training. This issue is further exacerbated by privileged OPD, where privileged information induces larger teacher-side likelihood shifts, thereby encouraging the student to learn more of the teacher's own deviation. We introduce \textbf{Calibrated On-Policy Distillation (Cal-OPD)}, which estimates the teacher's self-deviation region through positive and negative privileged interventions and calibrates the original teacher--student discrepancy by retaining only the component that lies beyond this region. Experiments on mathematical reasoning benchmarks show that, while retaining only about 52--65\% of the original teacher--student discrepancy as the optimization signal, Cal-OPD consistently outperforms standard OPD and its variants across model scales.

# 论文总结：Calibrating Teacher–Student Discrepancy for On-Policy Distillation

## 1. 核心问题与整体含义

- **研究背景**：知识蒸馏（KD）将强教师能力迁移至弱学生，但传统离策略蒸馏存在训练数据与学生演化分布不匹配的问题。同策略蒸馏（OPD）通过在学生自生成轨迹上使用教师–学生 token 级似然差异作为稠密监督，缓解了该分布不匹配，已在 Qwen3 等大规模推理模型后训练中采用。
- **核心问题**：OPD 隐式假设教师对每个 token 赋予的似然都是同等可靠的参考，但实际稳定性因 token 而异。作者将这种由上下文干预引起的教师似然变化称为 **教师自偏差（Teacher Self-Deviation, TSD）**。因此，观测到的师生差异不仅反映真实能力差距，还混入了教师自身的偏差，标准 OPD 会不加区分地学习这些偏差。
- **特权 OPD 的加剧效应**：特权 OPD 通过给教师额外条件（如参考解、最终答案、提示）来增强监督，但这会引发更大的教师侧似然偏移，使学生学到更多教师自身的偏差，甚至导致信息不对称、捷径行为和性能下降。
- **整体含义**：有效 OPD 的关键不在于不加区分地学习更多师生差异，而在于识别哪些差异真正值得学习。Cal-OPD 通过剥离 TSD 解释的分量，为更可靠的策略蒸馏提供了校准思路。

## 2. 方法论

### 核心思想
- 将观测到的师生差异分解为 **TSD 解释的分量** 与 **校准后的残差**：
  $$A^{OPD}_t = A^{Cal}_t + A^{TSD}_t$$
- 通过正负特权干预估计教师的 token 级自偏差区域，仅保留超出该区域的师生差异作为优化信号。

### 关键技术细节

- **TSD 定义**：对固定问题 $x$、学生轨迹 $y$ 和 token 位置 $t$，引入教师侧上下文干预 $c$（仅提供给教师），定义似然变化：
  $$\Delta^T_t(c) = \ell^T_t(c) - \ell^T_t(c_0)$$
  其中 $c_0 = \emptyset$ 为无额外上下文的原始设置。

- **TSD 区域估计**：给定干预集 $\mathcal{C}$，估计向下和向上偏差幅度：
  $$\hat{d}^{\downarrow}_t = \max(0, -\min_{c \in \mathcal{C}} \Delta^T_t(c)), \quad \hat{d}^{\uparrow}_t = \max(0, \max_{c \in \mathcal{C}} \Delta^T_t(c))$$
  得到 TSD 区域：
  $$\hat{\mathcal{R}}^T_t(\mathcal{C}) = [\ell^T_t - \hat{d}^{\downarrow}_t, \ell^T_t + \hat{d}^{\uparrow}_t]$$

- **Cal-OPD 校准**：使用两个对比干预 $c^{pos}$ 和 $c^{neg}$，引入松弛因子 $\lambda \geq 1$：
  $$\hat{\mathcal{R}}^T_t = [\ell^T_t - \lambda \hat{d}^{\downarrow}_t, \ell^T_t + \lambda \hat{d}^{\uparrow}_t] = [L^T_t, U^T_t]$$
  校准后的优势：
  $$A^{Cal}_t = [L^T_t - \ell^S_t]_+ - [\ell^S_t - U^T_t]_+, \quad [z]_+ = \max(z, 0)$$
  当学生似然 $\ell^S_t \in \hat{\mathcal{R}}^T_t$ 时，$A^{Cal}_t = 0$；否则仅保留超出最近边界的差异。

- **干预类型**（见表 1）：任务无关指令（$c_{inst}$）、评估反馈（$c_{eval}$）、答案级特权（$c_{ans}$）、解级特权（$c_{sol}$），各有正负变体。
- **训练目标**：沿用标准 OPD 目标，仅将 $A^{OPD}_t$ 替换为 $A^{Cal}_t$，特权信息仅用于校准教师参考，不直接蒸馏给学生。

## 6. 主要结论与发现

- **TSD 的存在性与特性**：
  - TSD 在无任务知识时即可大量出现（任务无关指令下约 20.2%–25.8% token 出现显著 TSD，并集覆盖 29.8%）。
  - 更丰富的特权上下文主要扩展受影响 token 集合，而非创造全新偏差模式；低信息干预下受影响的 token 在解级特权下保留率高达 98% 以上。
  - TSD 对干预语义和正确性不敏感：答案正确性反转仍有 88.7% 方向一致性和 74.7% 共享偏差比。
  - TSD 高度集中在表面形式 token（如 maybe、however、therefore、consider，显著 TSD 率超 89%）而非数学内容 token（如数字、符号、记号，显著 TSD 率低于 9.3%），差距近一个数量级。
- **Cal-OPD 性能**：
  - 仅保留约 52–65% 的原始师生差异，却在两种配置上均取得最优平均性能：4B→1.7B 为 53.1（较学生 +3.9，较 OPD +2.3），30B-A3B→4B 为 69.0（较学生 +2.4，较 OPD +3.1）。
  - 在 12 个基准–配置对中 7 个取得最佳结果。
  - 标准 OPD 对 4B→1.7B 提升有限（49.2→50.8），对 30B-A3B→4B 甚至下降（66.6→65.9）；Privileged-OPD 退化最严重（49.3 和 64.0）。
- **训练动态**：
  - Cal-OPD 保留差异比从 65% 降至 52%，零优势 token 比从 27% 升至 34%。
  - 标准 OPD 响应长度从约 9.8K 膨胀至 11.8K，Cal-OPD 最终仅 9.3K，缓解长度膨胀。
  - Cal-OPD 保持更高学生熵和 Top-16 token 重叠，同时降低 Top-16 概率质量重叠，表明学生覆盖更多教师支持的模式而非过拟合单一分布。
- **消融结论**：
  - 评估反馈干预（$c_{eval}$）校准效果最佳（平均 53.1）；解级特权（$c_{sol}$）过度过滤，降至 49.0。
  - $\lambda=5$ 最优；$\lambda$ 过大（如 80）导致过度过滤，性能下降 1.7 分。
  - 保留匹配控制均无法复现 Cal-OPD 增益，证明其优势来自软校准机制而非信号衰减或 token 稀疏化。

## 7. 优点

- **问题识别新颖且重要**：首次明确将教师似然在上下文干预下的变化建模为“教师自偏差区域”，并系统实证其存在性、语义不敏感性和表面形式集中性，为 OPD 监督可靠性提供了新视角。
- **方法设计优雅**：通过正负特权干预构造对比探针，用有限干预近似 TSD 区域，仅需两次额外教师前向传播；校准公式简洁，易于集成到现有 OPD 框架。
- **实验严谨**：保留匹配控制实验（Advantage-Sync、Token-Sync、TSD-Filter）有效排除了信号衰减和 token 稀疏化等替代解释，增强了因果推断的可信度。
- **跨规模有效性**：在两个不同规模区间的教师–学生配置上均取得一致增益，且缓解响应长度膨胀。
- **效率分析完整**：详细报告了墙钟时间和额外前向传播开销，指出在中等规模差距下 Cal-OPD 反而更快，具有实际部署参考价值。
- **诊断分析深入**：token 级形式分析、轨迹级案例研究、跨阈值/跨模型验证等多角度刻画 TSD 特性，支撑方法动机。

## 8. 不足与局限

- **任务覆盖有限**：实验仅限数学推理基准（AMC、AIME、HMMT、MATH500），未验证代码生成、科学推理、多语言等场景；TSD 在其他领域的表现未知。
