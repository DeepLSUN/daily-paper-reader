## 摘要
长上下文大语言模型推理日益受到预填充阶段的制约，在该阶段，稠密自注意力会在生成开始前处理整个提示。稀疏块选择可以降低这一开销，但块质心可能掩盖众多无关 token 中一个高度相关的 token。我们将这种失效模式称为均值稀释（mean dilution），并提出 RBS-Attention，一种无需训练的稀疏预填充方法，具有两个互补的选择分支。一个质心基础分支捕获平均相关性，而一个救援分支利用最大键块半径及其依赖于提示、层和头的分布，来识别有被低估风险的块。对两个分支分别进行阈值化并合并其掩码，可在保留常规块稀疏 FlashAttention 执行的同时，控制救援块的贡献。在 H100 GPU 上，RBS-Attention 在 Qwen3-30B-A3B-Instruct-2507-FP8 上、128K 长度下，实现了 20.65$\times$ 独立预填充注意力加速比、11.92$\times$ vLLM 预填充注意力加速比，以及 5.97$\times$ 端到端首 token 时间加速比。在稠密 Qwen3-32B 模型上，其总体 RULER 准确率为 88.65，而稠密注意力为 89.52；LongBench-v2、InfiniteBench 和 Video-MME 提供了额外的质量评估。支撑实验测量了实际保留率，在匹配密度下比较了选择器，并刻画了块大小、阈值和内存行为。综合来看，这些结果支持将半径自适应双分支选择作为长上下文预填充的一种有效方法。

## Abstract
Long-context large language model inference is increasingly limited by prefill, where dense self-attention processes the entire prompt before generation begins. Sparse block selection can reduce this cost, but a block centroid may hide a highly relevant token among many irrelevant ones. We call this failure mode mean dilution and propose RBS-Attention, a training-free sparse-prefill method with two complementary selection branches. A centroid base branch captures average relevance, while a rescue branch uses the maximum key-block radius and its prompt-, layer-, and head-dependent distribution to identify blocks at risk of underestimation. Independently thresholding the two branches and combining their masks controls the contribution of rescue blocks while preserving regular block-sparse FlashAttention execution. On H100 GPUs, RBS-Attention achieves 20.65$\times$ standalone prefill-attention speedup, 11.92$\times$ vLLM prefill-attention speedup, and 5.97$\times$ end-to-end time-to-first-token speedup at 128K on Qwen3-30B-A3B-Instruct-2507-FP8. On the dense Qwen3-32B model, it obtains 88.65 overall RULER accuracy versus 89.52 for dense attention; LongBench-v2, InfiniteBench, and Video-MME provide additional quality evaluation. Supporting experiments measure actual retention, compare selectors at matched density, and characterize block-size, threshold, and memory behavior. Together, these results support radius-adaptive dual-branch selection as an effective approach to long-context prefill.

# RBS-Attention 论文总结

## 1. 核心问题与整体含义

- **背景**：长上下文 LLM 推理的瓶颈从 decode 转移到 **prefill**——生成开始前，稠密自注意力要对整个提示做 O(N²) 的 query–key 交互。FlashAttention 等优化改善了访存与硬件利用率，但没有减少交互次数。
- **现有方案**：稀疏预填充通过模式推断或块级打分，只计算被选中的 query–key 块对。块级稀疏保留了合并访存、天然适配 GPU kernel。
- **核心失效模式（本文命名）**：**均值稀释（mean dilution）**。块选择常用键块**质心** c_b 近似整块相关性（分数如 qᵀc_b）。当块内只有极少数高相关 token、其余方向无关时，质心会被拉偏，整个块被打低分并剪掉——一旦剪掉，其中的关键证据 token 无法再进入注意力输出。
- **实证支撑**（图 1）：
  - 质心的秩低估程度**随块半径（块内 token 到质心的最大 L2 距离）单调上升**；
  - 最高半径五分位 Q5 集中了 **39.5% 的 top-5% 注意力块**，而均匀分布下应只有 20%；
  - RBS 在 Q4/Q5 明显降低低估，Q5 上差距达 **25 个百分点**。
- **整体含义**：长上下文任务（检索、多跳、证据聚合）往往依赖埋在长提示中的小片段，因此需要一个**仍然廉价、但对块内高异质性更保守**的选择器。论文据此提出**半径自适应双分支**选择策略。

## 2. 方法论

### 2.1 块统计与几何动机
- 将序列切分为大小 B 的块，对每个键块 K_b 计算：
  - 质心 **c_b = (1/|K_b|) Σ k**
  - 最大半径 **r_b = max_{k∈K_b} ‖k − c_b‖₂**
- 由 Cauchy–Schwarz 得块内最大 logit 的上界：
  **s_b(q) = max_k qᵀk ≤ qᵀc_b + ‖q‖₂ r_b = U^L2_b(q)**（式 3）
- 直觉：半径刻画"单个 token 最多能比质心分数高出多少"，因此可作为**均值稀释风险信号**。

### 2.2 半径自适应救援系数
- 对**每一层、每个 KV head**，由当前 prompt 的块半径分布取分位数：
  **r_low = quantile(r, 0.5)，r_high = quantile(r, 0.9)**
- 定义归一化救援系数：
  **β_b = clamp((r_b − r_low)/(r_high − r_low), 0, 1)**
- 效果：紧凑块（半径低于中位数）几乎得不到救援权重；高度分散块（接近 90 分位）获得完整救援项。该归一化随 prompt/层/头自适应，**无需逐 prompt 调参**。

### 2.3 双分支打分
- **基分支**：ℓ_base(q,b) = qᵀc_b —— 捕捉平均相关性。
- **救援分支**：ℓ_rescue(q,b) = qᵀc_b + ‖q‖₂ r_b β_b —— β=1 时退化为完整 L2 上界；β<1 时**只是风险分数，不保证是块内所有 token logit 的上界**（附录 E 给出反例：K={−u,u}, q=u 时真实最大 logit 为 1，而衰减分数为 β）。
- **查询块聚合**：以 query block Q_i 为单位（而非逐 token 选择），对候选因果键块做数值稳定的 max-shift log-sum-exp 聚合，得到 S^base_{i,b} 与 S^rescue_{i,b}；该 shift 在同一分支同一 query block 内共享，比较相对分数时抵消。

### 2.4 独立阈值与掩码并集
- 两个分支各用**相对阈值**：
  - M^base_i = { b : S^base_{i,b} ≥ α_base · max_{b′} S^base_{i,b′} }
  - M^rescue_i = { b : S^rescue_{i,b} ≥ α_rescue · max_{b′} S^rescue_{i,b′} }
- 最终掩码为**并集**，并强制保留 attention sink、局部滑窗与最近块：
  **M^final_i = M^base_i ∪ M^rescue_i ∪ M^{sink/window/last}_i**
- **为何必须保留基分支**（附录 E.3）：救援项的抬升会同时抬高相对阈值所用的最大值，可能把其他候选挤出；单独计算的基掩码可防止这些候选被"连带"剔除。
- 阈值是**相对分数控制**而非固定 Top-K 预算，因此保留密度随内容（prompt/层/头）变化。

### 2.5 稀疏执行与复杂度
- 选中块对交给 **block-sparse FlashAttention kernel** 执行，保留 tile 内做 token 级点积、因果掩码与 softmax 归一化；近似来源即"未选块的省略"，**不宣称等价于稠密注意力**。
- 复杂度：块统计 O(Nd)；打分 O(N²d/B)；阈值与并集 O(M²)；稀疏注意力 O(M·K_avg·B²·d)，K_avg ≪ M 时大幅降本，但最坏情况仍对 N 二次。
- 持久存储：每 KV head 每块一个质心向量 + r_b、β_b 两个标量；另有 O(M²) / O(NM) 的临时工作区。
