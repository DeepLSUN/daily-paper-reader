## 摘要
长期运行的LLM智能体需要能够在跨会话中持续存在并演化的记忆。基于文本的记忆在每次查询时检索并重构过去的交互，使得随着历史增长，长时程性能越来越依赖于检索质量和上下文推理。参数化记忆将经验直接编码到模型计算中，但现有方法对跨会话记忆演化的支持有限。它们与特定骨干模型的耦合进一步限制了模型替换后的记忆复用。我们提出RPMem，一种两阶段架构，它通过前向计算将每个会话编译为与模型无关的潜在记忆，并通过任务训练的循环门控将其与保留的记忆选择性整合。随后，整合后的记忆被映射为特定于骨干模型的低秩适配（LoRA）参数，使得在替换骨干模型时编码能力能够迁移。在三个长期记忆基准和五个不同骨干模型上的评估表明，该方法具有广泛泛化能力，且更新成本和内存占用近乎恒定。在PERMA上使用Qwen3-8B时，RPMem达到85.52%，分别超过最强的参数化基线和基于文本的基线5.32和12.98个百分点。消融实验验证了会话编译和跨会话整合的互补作用，而动态分析揭示该门控习得了任务特定的记忆整合策略。这些结果确立了RPMem作为一种生命周期无关的参数化记忆框架，能够维护不断演化的跨会话记忆，并在骨干模型替换后仍可复用。我们的实现可在 https://github.com/Quark-Medical/rpmem/tree/main 获取。

## Abstract
Long-running LLM agents require memory that persists and evolves across sessions. Text-based memory retrieves and reconstructs past interactions at every query, making long-horizon performance increasingly dependent on retrieval quality and contextual reasoning as histories grow. Parametric memory encodes experience directly into model computation, but existing approaches provide limited support for cross-session memory evolution. Their coupling to a specific backbone further restricts memory reuse after model replacement. We introduce RPMem, a two-stage architecture that compiles each session into a model-independent latent memory through forward computation and selectively integrates it with retained memory via a task-trained recurrent gate. The consolidated memory is then mapped to backbone-specific low-rank adaptation (LoRA) parameters, allowing the encoding capability to transfer when the backbone is replaced. Evaluation across three long-term memory benchmarks and five diverse backbones demonstrates broad generalization with near-constant update cost and memory footprint. With Qwen3-8B on PERMA, RPMem reaches 85.52%, outperforming the strongest parametric and text-based baselines by 5.32 and 12.98 percentage points, respectively. Ablations validate the complementary roles of session compilation and cross-session consolidation, while dynamics analyses reveal that the gate acquires task-specific memory integration strategies. These results establish RPMem as a lifecycle-independent parametric memory framework that maintains evolving cross-session memory that remains reusable across backbone replacements. Our implementation is available at https://github.com/Quark-Medical/rpmem/tree/main.

- **论文提出的核心概念**：**生命周期独立性（lifecycle independence）**——在服务端 backbone 被替换后，仍能保留并继续使用累积记忆。作者认为这是持久化参数记忆走向部署的核心未解障碍。

## 2. 方法论

### 2.1 核心思想

两阶段架构：**会话编译（compilation）** 把每个会话前向映射为与模型无关的定形潜在记忆；**跨会话整合（consolidation）** 用任务监督训练的轻量循环门控把新会话选择性并入累积记忆；最后通过**模型特定解码器**把整合记忆转成当前 backbone 的 LoRA 参数。

### 2.2 单会话记忆编译

- **记忆编译器 = 超网络**：冻结的上下文编码器 $E_\xi$（ModernBERT-base）+ 可训练的 Perceiver 重采样器 $G_\phi$。
- 对会话 $c_t$ 先取特征 $X_t = E_\xi(c_t)$（从 L 个等间隔深度提取），再由 $G_\phi$ 压缩为固定形状记忆 $q_t \in \mathbb{R}^{L\times M\times r\times d}$；其形状与会话长度 $n_t$ 无关。
- 解码器 $D_\beta(q_t)=\Lambda_t=\{A_{t,\ell,m},B_{t,\ell,m}\}$ 生成 LoRA 因子，并施加 $\widetilde{W}_{t,\ell,m}=W_{\ell,m}+\gamma B_{t,\ell,m}A_{t,\ell,m}$。
- **训练目标**：让「带生成适配器的冻结 backbone」与「直接读会话文本的同一 backbone」的下一 token 分布对齐（前向 KL），在 top-K 支撑集 + 尾部聚合概率上计算；加入 LoRA 因子幅值正则 $R_1$，权重 $\lambda=0.01$。目标为 $L_{comp}=\mathbb{E}_c[L_{FKL}(c)+\lambda R_1(c)]$，仅更新 $\phi,\beta$。
- **关键设计**：固定参考响应轨迹（fixed FKL）+ 保留支撑集外的概率质量（尾部类别）。
- **跨 backbone 迁移**：保留 $G_\phi$ 不变，只训练目标专用解码器 $D_{\beta'}$，用同一固定参考前向 KL 目标适配新 backbone 的层数与模块维度。

### 2.3 跨会话记忆整合

- 累积记忆 $h_t$，初始 $h_0=0$，$h_1=q_1$。
- 循环门控：
  - 保留系数 $z_t=\sigma([h_{t-1};q_t]W_g+b_g)$（$t\ge2$）
  - 状态更新 $h_t = z_t\odot h_{t-1} + (1-z_t)\odot q_t$
- 门控在所有层、模块、rank 索引上共享，参数量 $2d^2+d=524{,}800$，与 $L,M,r$ 无关。
- **训练**：目标应用分布 $D_{task}$ 上最小化任务损失 $L_{con}(\psi)=\mathbb{E}[\ell_{task}(p_{\theta\oplus\Lambda_T}(\cdot|x),y)]$，梯度穿过冻结 backbone 与解码器只更新 $\psi$；编译器输出 $q_t$ 可预计算缓存。
- **部署**：全部模块冻结；首会话初始化、后续会话前向更新；替换 backbone 时只需换用新的适配解码器 $D_{\beta'}$，累积记忆、会话编码器与门控均保留。

- **通用能力保留**：MMLU / GSM8K / IFEval 分别距 Base LLM 差 1.83 / 1.43 / 3.81 pp，且均优于 Latest Session。
- **消融**：Fixed FKL 比 Top-K CE 高 7.86 pp、比 Compiler SFT 高 24.31 pp；反向 KL 掉 16 pp 以上；学习门控比最强固定规则（因子平均）高 **31.31 pp**，在多域历史中优势达 41.16 pp。
- **机制发现**：门控习得语义结构化策略——领域**涌现**事件的写入显著大于**补充**事件（差异约为 Clean/Noisy 差异的 5 倍）；同域写入模式更相似（0.872 vs 0.784），新事件对同域历史贡献的衰减更强（单步存留 0.458 vs 0.818）；涌现源存留优势从 1 次更新后的 1.31× 增长到 60 次后的 6.64×。

## 7. 优点

- **问题定义清晰**：明确提出「生命周期独立」这一部署导向的问题设定，把 backbone 解耦与跨会话演化联合建模。
- **架构分工合理**：模型无关潜在记忆空间 + 模型特定解码器，使记忆可跨模型复用；两阶段解耦使编译可离线大规模预训练、整合可低成本按场景适配。
- **训练目标设计扎实**：固定参考轨迹 + top-K

支撑集概率保留与尾部概率质量聚合，避免了前向 KL 在长尾词表上过早饱和；幅值正则 $R_1$ 抑制了 LoRA 因子膨胀，使编译过程更稳定。
- **整合阶段极度轻量且可部署**：门控仅 $2d^2+d=524{,}800$ 参数、与层数/模块数/rank 无关，单折训练仅需 1 张 A800-80GB、13 分钟、检查点 2.004 MiB，且编译器输出 $q_t$ 可离线预计算缓存，实际部署时几乎不增加推理负担。
- **推理侧真正省上下文**：查询阶段不拼接历史 token，64 会话下写入仅 0.043 s，PersonaMem-v2 上平均前向 0.055 s vs Full Context 4.287 s，量级差异来自架构而非工程调优。
- **实验闭环完整**：主结果、7 变体、28 个迁移组合、6 种编译目标消融、5 种整合规则消融、数据效率曲线、部署剖析、通用能力保持、机制分析相互印证，且报告了 bootstrap 置信区间与协变量匹配等统计细节。
- **机制层面可解释**：门控并非黑箱，作者量化出「领域涌现事件写入量显著大于补充事件」「同域历史写入模式更相似」「涌现源存留优势随更新次数从 1.31× 增至 6.64×」等可复现规律，为参数化记忆的可控性研究提供了实证抓手。

## 8. 不足与局限

- **「生命周期独立」是部分的，而非完全零成本**：记忆、编码器与门控可复用，但每换一个 backbone 仍需用固定 FKL 目标重新训练专用解码器 $D_{\beta'}$；这一步在 Qwen3.5-35B-A3B 上需要 32 卡跨 4 节点、38.42–41.66 小时。严格说，论文解决的是「记忆表示与 backbone 解耦」，而非「记忆适配零成本」。
- **编译阶段算力门槛高**：约 338 GPU-hours（8 卡），而采样轨迹类对照目标需 24 卡、2,939–5,284 GPU-hours，远超多数学术团队的常规预算；且正文未说明编译阶段 8 卡的具体 GPU 型号，复现成本存在不确定性。
- **记忆容量受固定形状约束**：$q_t \in \mathbb{R}^{L\times M\times r\times d}$ 与会话长度 $n_t$ 无关，这是泛化性的来源，同时也意味着超长、超高信息密度会话必然面临压缩瓶颈；门控本质上是对固定形状张量的逐元素 EMA，长期累积是否会被「覆盖」而非「累积」，论文仅在 64 会话范围内剖析，更长生命周期未验证。
- **整合依赖任务监督信号**：门控训练需要目标应用分布 $D_{task}$ 上的任务标签，属于有监督的场景适配；在无标注、任务快速漂移或隐私受限无法取标签的场景下，冷启动能力未被讨论。
- **门控表达能力有限**：保留系数 $z_t$ 在所有层、模块、rank 索引上共享同一标量，参数效率极高，但无法做细粒度（如按层或按知识类型）的差异化写入，这可能是其在多域历史中仍存在提升空间的来源。
- **基线公平性存在残余风险**：PERMA 上多数文本记忆基线由作者自行复现，实现细节差异难以完全排除；作者在附录 H 也承认 prompt 敏感性——同一 Qwen3-32B 在不同 prompt 下官方 Type-3 结果波动 0.7–5.7 pp，提示部分结论对提示工程敏感。
- **绝对性能仍有明显天花板**：PersonaMem-v2 Overall 仅 40.22%，即便相对领先 SFT 8.58 pp，说明长程人格记忆任务本身仍远未解决；Pref Eval 在 10 轮、70 轮设置下也非最优（分别为第三、第二）。
- **泛化边界未充分探索**：5 个 backbone 均为 decoder-only Transformer（含稠密与 MoE），跨架构（如非 Transformer、不同 tokenizer、多模态）迁移性未验证；Metis 对照也主要围绕 Qwen3.5-9B 展开。
- **缺少记忆安全与治理讨论**：参数化记忆一旦写入难以审计、定点删除或满足「被遗忘权」类合规要求，论文未涉及遗忘机制、污染注入与对抗性会话的鲁棒性。

## 9. 结论与启示

- **核心结论**：RPMem 通过「模型无关潜在记忆编译 + 轻量循环门控整合 + 模型特定解码」的三段式设计，证明了持久化参数记忆可以在跨会话持续演化的同时保持与 serving backbone 的解耦，在 PERMA、PersonaMem-v2、Pref Eval 上全面优于文本记忆与既有参数化记忆方法，且不显著损害通用能力。
- **方法学启示**：把「记忆表示」与「记忆使用」在架构上分层，是兼顾可复用性与性能的可行路径；固定参考轨迹的前向 KL 显著优于 Top-K 交叉熵与 SFT 式编译，说明**对齐目标的设计**比**容量堆叠**更关键。
- **工程启示**：0.043 s 写入、2 MiB 检查点、13 分钟场景适配，说明参数化记忆在延迟与存储上已具备实际部署可行性，其主要成本集中在一次性编译与每次换 backbone 的解码器适配。
- **后续方向**：更细粒度的门控（按层/按知识类型）、无监督或自监督的整合目标、显式遗忘与可编辑机制、更长生命周期与跨架构迁移验证，是该路线走向生产级「终身记忆智能体」的关键待解问题。
