## 摘要
扩展语言模型不仅是最终质量的问题：架构选择决定了为达到特定模型质量而在训练、提示处理和自回归解码期间花费多少计算量。理想的模型架构应降低上述所有计算成本，以促进扩展至更大的模型，同时确保更大的模型确实优于较小的基线。我们提出 KV 不变 Transformer 扩展（KITE），这是一种实现该目标的扩展范式。它将模型从较小规模训练至较大规模（即通过 upcycling 节省训练成本），同时将新增参数置于不影响注意力 KV 的区域。因此，在推理期间，KV 预填充仅依赖模型中较小的部分，从而节省推理成本。作为具体实例，我们提出 Step Scale Transformer（SST），这是一种双塔解码器，其中一个塔生成 KV，另一个塔读取它们。在累计训练计算量相当的情况下，SST 是一个 67B MoE 模型，每解码 token 具有 2.15B 活跃主体参数，其训练损失低于分别具有 1.48B 和 2.02B 活跃主体参数的 47B 和 63B MoE Transformer，同时将估计推理成本降低 6.7% 和 31.6%。

## Abstract
Scaling a language model is not only a question of final quality: the architectural choice determines how much computation is spent during training, prompt processing, and autoregressive decoding to achieve certain model quality. An ideal model architecture should lower all above computation costs to facilitate scaling to a larger model, while ensure the larger model indeed outperforms smaller baselines. We introduce KV-Invariant Transformer Expansion (KITE), a scaling paradigm that achieves this goal. It trains the model from a smaller size to a larger size (i.e., saving training costs via upcycling), while places newly added parameters in regions that do not affect attention KV. Consequently, during inference, prefilling KV only relies on the smaller part of the model, so the inference costs are saved. As a concrete instantiation, we present Step Scale Transformer (SST), a two-tower decoder in which one tower produces KV and the other reads them. At comparable cumulative training compute, SST, a 67B MoE model with 2.15B active body parameters per decode token, achieves lower training loss than 47B and 63B MoE Transformers with 1.48B and 2.02B active body parameters, respectively, while reducing estimated inference cost by 6.7% and 31.6%.

# KITE：面向高效智能体 LLM 扩展的 KV 不变 Transformer 扩展 —— 论文总结

## 1. 核心问题与研究动机

- **根本矛盾**：扩展语言模型不仅是"最终质量"问题。架构选择决定了为达到某一质量水平，需要在**训练、提示处理（prefill）、自回归解码（decode）**三处花费多少算力。理想架构应当同时压低三者，并保证更大模型确实优于小基线。
- **已有方案的单边性**：
  - **MoE**：成功之处在于同时降低训练与推理算力（固定参数下省算力，或固定算力下扩容量）。
  - **渐进式 upcycling（Net2Net 类）**：先训小模型再长大，节省训练算力；但通常被认为不如同规模从头训练，节省的训练成本在推理端"还回去"。
  - **KV 复用（YOCO 家族）**：让深层复用浅层 KV，使 prefill 随模型增长仍可控；但移除 KV 生成层可能损害质量，恢复质量需更大模型或更长训练，等于训练成本损失。
  - 结论：只在单一轴上获益，会被另一轴的回退抵消，因此需要**联合优化**。
- **应用背景（agentic 负载）**：智能体场景中反复调用模型、处理累积上下文与工具输出，**输入密集**。作者统计 OpenRouter 六个模型的公开流量（2026-08-22 至 09-20）：未缓存输入 token 量远超输出，且占"未缓存输入+输出"计费的 **67.4%–76.7%**，说明 prefill 成本权重很高。
- **整体含义**：提出 KITE（KV-Invariant Transformer Expansion）范式——扩展时把新增容量放在**不影响注意力 KV 的区域**，使 bulk prefill 的计算量保持"源模型规模"，从而让模型质量、训练成本、推理成本**三者同时向有利方向移动**。

## 2. 方法论

### 2.1 核心思想
- 把模型划分为两个区域：**决定 KV 的区域（Prefiller P）** 与 **不影响 KV 的区域（Decoder D）**。
- 从小模型（源模型）出发，中途扩张时**只在 D 侧增加容量**：
  - 新增容量不是从 token 0 开始训练（源于 upcycling），因此质量/训练成本比更划算；
  - KV 计算路径不扩张，因此推理时 bulk prefill 成本保持源模型量级。

### 2.2 形式化表述
- 基本分解：
  - $(M_t, z_t) = P(x_{1:t}; \theta_P)$，$\ell_t = D(x_t, z_t, M_t; \theta_D)$
  - $M_t$ 为可复用注意力记忆，$z_t$ 为可选 Prefiller 特征，$\ell_t$ 为下一 token logits。
- **结构不变式（非冻结权重/KV）**：
  - Decoder **不得产生**未来位置所需记忆；
  - 为在生成时省略历史 Decoder 计算，其被保留位置必须**在给定 Prefiller 输出后与已省略的 Decoder 位置独立**。
- 允许增长的只有预测容量；**prompt 级 KV 构建（bulk prefill）不增长**；首个输出 token 的末位读出头与解码期 Decoder 计算仍必需。

### 2.3 具体实例：Step Scale Transformer（SST）
- **双塔同深结构**：Prefiller 与 Decoder 各 18 层；Prefiller 先执行并产出**逐层 KV**；每个 Decoder 块自算 query，读取对齐的 Prefiller 层 KV：
  - $q^D_{l,t} = Q^D_l(h^D_{l-1,t})$，$a^D_{l,t} = \mathrm{Attn}(q^D_{l,t}, K^P_l[I_l(t)], V^P_l[I_l(t)])$
  - $I_l(t)$ 由原因果 full/sliding 掩码决定；两塔保留源模型的位置 ID。
- **入口桥（token-local entry bridge）**：
  - $h^D_{0,t} = \mathrm{RMS}_\epsilon(e_t) + \mathrm{RMS}_\epsilon(h^P_{L,t})$，$\mathrm{RMS}_\epsilon(v) = v/\sqrt{\mathrm{mean}(v^2)+\epsilon}$，$\epsilon=10^{-5}$，**无训练参数**。
- **输出**：$\ell_t = W_{out}\,\mathrm{Norm}_{out}(h^D_{L,t})$；两塔共享一份 embedding、输出归一化与输出头（embedding 与 head 权重不绑定）。
- **梯度**：经入口桥与复用的 KV 同时回传至 Prefiller。

### 2.4 训练与推理流程
- **Stage 1**：训练源模型（Prefiller），167.98B tokens，13,350 步。
- **扩张**：把源 checkpoint 的每层权重**复制**到 Prefiller 与 Decoder 的对应层；共享 embedding/输出头只保留一份；Decoder 优化器状态新初始化。
- **Stage 2**：两塔**联合训练**（BF16，Muon + Adam），继续沿用源模型余弦学习率调度并延长衰减，Decoder 无单独 warmup；222.55B tokens，17,687 步；合计 31,037 步 / 390.54B tokens。
- **Prefill**：Prefiller 处理完整 prompt 生成逐层 KV；Decoder **只需算最后一个 prompt 位置**来预测首个输出 token（其他 Decoder 操作为 token-local，可省略）。
- **Decode**：每个新 token 经过两塔（Prefiller 扩 KV，Decoder 读 KV 出预测）。
- **累计训练算力**：$C_{train} = 3(D_s f_s + D_c f_c)$（因子 3 近似前向+反向），两阶段均计入；47B classic 定义 $B_{ref}\approx 5.16836\times10^{21}$ FLOPs。

## 6. 主要结论与发现

- **训练损失**：SST 在 conversion 处损失上升，随后在续训中下降；最终 EMA-200 = **1.5900**（390.54B tokens），低于 47B classic 的 1.6006（443.16B tokens）与 63B classic 的 1.5921（334.62B tokens），即在**相近累计训练算力**下达到更低训练损失。
- **下游任务**：SST 在全部 7 项任务上均优于两个基线（如 OpenBookQA 75.00 vs 71.00/68.50；MMLU 60.54 vs 59.39/58.44；GSM8K 58.38 vs 55.04/56.56；HumanEval 37.80 vs 32.93/35.98），ARXIV NLL 最低（1.4421）。说明训练损失的改善确实传导到了下游性能。
- **推理成本**：在 75:25 的 P:D 混合下，SST 估计推理成本比 47B classic 低 **6.7%**、比 63B classic 低 **31.6%**；break-even 点分别为对 63B 的 13.4:86.6、对 47B 的 65.5:34.5；在 OpenRouter 参考区间（prefill 权重 67.4–76.7%）内，SST 分别比 47B 低 1.3–7.9%、比 63B 低
