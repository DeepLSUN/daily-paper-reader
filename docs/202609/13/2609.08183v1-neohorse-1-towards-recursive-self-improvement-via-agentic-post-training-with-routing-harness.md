## 摘要
递归自我改进（RSI）需要一种具体机制，使 AI 系统能够观察自身能力，并将这些证据转化为下一轮学习。我们提出 NeoHorse-1，一个面向智能体原生模型系列，旨在通过智能体式后训练探索这一路径。我们的系统将异构模型池与智能路由相结合，记录每个用户轮次的预测能力需求、所选服务层级以及后续交互。这些记录被转化为训练样本，保留交错推理、工具调用和 harness 上下文，并通过结构验证、六维语义评估和子场景级标注进行准入。路由信号将监督微调组织为三阶段课程，并扩展为路由引导的在线策略蒸馏；在此过程中，教师模型在相同进阶安排下监督学生模型生成的回复。随后，能力引导的分配将评估反馈转化为下一轮训练数据混合，从而闭合“评估—选择—更新”循环；在该循环中，系统学会做什么会塑造它下一步从什么中学习。在涵盖基于 harness 的智能体、工具使用、编程和指令遵循的十一个基准上，后训练使 4B 模型的宏平均从 58.94 提升至 64.87，使 9B 模型从 65.60 提升至 69.04，显著缩小了后训练 4B 模型与 9B 基础模型之间的总体差距。NeoHorse-1 为这一反馈驱动过程提供了初步原型，并给出了一条通过 harness 介导、跨连续迭代实现 RSI 的路径。

## Abstract
Recursive self-improvement (RSI) requires a concrete mechanism through which an AI system observes its capabilities and converts that evidence into the next round of learning. We present NeoHorse-1, a family of agent-native models developed to explore this path through agentic post-training. Our system combines a heterogeneous model pool with intelligent routing, recording the predicted capability demand, selected service tier, and subsequent interaction for each user turn. These records are converted into training examples that preserve interleaved reasoning, tool calls, and harness context, and are admitted through structural validation, six-dimensional semantic evaluation, and subscene-level labeling. Routing signals organize supervised fine-tuning into a three-stage curriculum and extend to routing-guided on-policy distillation, where a teacher supervises student-generated responses under the same progression. Capability-guided allocation then converts evaluation feedback into the next training mixture, closing an evaluation-selection-update loop in which what the system learns to do shapes what it learns from next. Across eleven benchmarks covering harness-based agents, tool use, coding, and instruction following, post-training raises the macro-average from 58.94 to 64.87 at 4B and from 65.60 to 69.04 at 9B, substantially narrowing the aggregate gap between the post-trained 4B model and the 9B base model. NeoHorse-1 provides an initial prototype of this feedback-driven process and a path toward harness-mediated RSI across successive iterations.

## 1. 核心问题与研究动机

- **核心问题**：递归自我改进（Recursive Self-Improvement, RSI）被广泛视为 AI 发展的重要方向，但缺乏一个**可操作的具体机制**——系统如何"观察自身能力"，并把这种观察转化为下一轮学习的信号。现有工作多把智能体轨迹当作静态监督数据，未充分利用其中蕴含的能力证据。
- **核心洞察**：一个**已部署的路由 harness**（负责管理上下文、工具与环境交互的执行层）本身就内置了这种机制。除任务输出外，智能体交互还留下三类可复用信号：
  - 执行轨迹（execution trajectories）：真实交互经验；
  - 路由信号（routing signals）：刻画每个请求的能力需求等级；
  - 记录结果（outcomes）：暴露模型在哪些区域仍然不足。
- **整体含义**：作者提出 NeoHorse-1 作为"harness 介导的 RSI"的初步原型，试图闭合 **评估—选择—更新（evaluation–selection–update）** 回路，使"系统学会做什么"反过来决定"它下一步从什么中学习"。其目标是让模型改进过程部分自动化，形成可跨代累积的复合式提升，而非依赖人工筛选数据与监督。

## 2. 方法论

### 2.1 核心思想
- 将**异构模型池 + 多 harness（含 OpenSquilla）+ 智能路由**作为数据生成与能力反馈的源头；把路由记录（预测能力需求、策略调整后的决策、实际服务层级）与交互轨迹对齐，形成 **预测—动作—结果（prediction–action–outcome）** 三元组，用于组织训练数据与后续配比。

### 2.2 数据构建（三层粒度）
- **轨迹（trajectory）**：完整交互，含用户请求、模型回复、工具调用、环境观测、恢复尝试与终止结果。
- **用户轮次（user turn）**：从一次用户请求到下一次用户请求或任务终止，是**基本序列化训练单元**；保留当前轮的推理、工具调用与观测（reasoning–action–feedback 链），历史轮次保留可见回复与工具交互但**省略历史推理**。
- **子场景（subscene）**：共享局部目标的相邻若干用户轮次，是**语义刻画单元**。
- 主语料规模约 **10⁵–10⁶ 条 harness 生成轨迹**，另混合公开的指令、推理、工具/代码、智能体交互与偏好数据。

### 2.3 数据质量与标注
- **去重与去污染**：精确/近似去重，并用同一匹配设施对训练候选与评测集做重叠筛查，保证训练集与评测集不相交。
- **结构验证**（规则驱动，非模型打分）：校验 payload 可读性、消息结构、请求/响应存在性、事件因果顺序、工具调用与结果的标识符闭合等；产出三类结果——**内部完整 / 部分可恢复 / 隔离**。
- **六维语义评估**：目标达成、指令遵循、工具使用、证据一致性、错误恢复、终止。每维给 PASS / WARN / FAIL / NOT_EVALUATED，长轨迹分段评估后按轮聚合；证据缺失或判定中断**绝不转成正向结论**。
- **子场景场景刻画**（三轴）：Scene（任务类型、领域、使用情境、信息寻求/执行）、Goal（验收标准、跨轮关系：新增/延续/修改/恢复/模糊）、Outcome（可验证结果、目标满足度）。每个属性保留推导方式与置信度，结构事实不可被语义判定覆盖。

### 2.4 路由信号与课程
- harness 路由器在**用户轮次级**估计能力需求，分四级服务层级：**C0**（有界低风险）、**C1**（通用默认）、**C2**（多步推理与执行）、**C3**（最高能力/可靠性）；策略可因风险、上下文压力、历史失败或服务约束调整。
- 训练语料保留**原始预测、策略调整后决策、实际服务层级**三个字段，以便独立分析；课程排序**只使用预测需求**，不用实际服务层级作难度标签（因为实际路由还受用户覆盖、可用性、部署策略影响）。
- **排序分数**（论文式 2）：
  - 硬排序：直接用分配的层级索引 $k_i$；
  - 软排序：用层级得分的加权均值 $s_i=\sum_{k=0}^{3} k\,\pi_{i,k}$，可区分同一层级内不同支持度的样本。
  - 该分数仅用于**排序/调度**，不用于对 SFT 损失重新加权。

### 2.5 智能体监督式微调（Agentic Supervision）
- 每个样本为"一个用户轮次 + 历史上下文"，按 **Qwen3.5 chat template 与工具调用格式**序列化。
- **损失掩码**：仅对当前轮保留的助手目标 span（推理、序列化工具调用及参数、可见回复、回复结束 token）置 1，其余（系统指令、工具规范、harness 上下文、用户消息、工具结果、padding）置 0。
- **SFT 目标**（式 1）：对所有受监督 token 等权，并按**批内受监督 token 总数**归一化，而非按序列长度或轮次数归一化。

### 2.6 路由引导的课程学习
- 三阶段课程，每阶段约含 1/3 样本，逐步引入更高路由分样本，同时**把部分低分样本保留到后期阶段**，避免训练末期被高需求交互独占；每个样本每遍只使用一次。
- 全程沿用同一掩码 SFT 目标，**阶段间不重置优化器、不重启学习率调度**。

### 2.7 路由引导的在线策略蒸馏（R-OPD）
- 动机：SFT 学的是记录下来的助手回复，而部署时模型面对的是**自己生成的前缀**。
- **上下文调度**：以助手回复前的记录上下文为生成起点，用同一套三阶段分配（式 2 打分）安排上下文分布 $\rho_j$（$j\in\{1,2,3\}$）。
- **学生生成 + 教师监督**：学生检查点对每个上下文生成一条回复；固定教师在同一上下文与已生成前缀上给出下一 token 分布；两侧用各自原生模板渲染同一批消息与工具，并对齐 token ID。训练中**刷新 rollout 检查点**，使后阶段上下文由更新的学生行为产生；收集回复期间 rollout 参数固定。
- **蒸馏目标**（式 3）：保留 rollout 学生的 top-$K$ 候选 token，其余概率质量并入一个 bin，形成 $K+1$ 个 bin 的粗化分布，最小化**响应归一化的反向 KL** $D_{KL}(\tilde P_{\theta,r,t}\,\|\,\tilde Q_{r,t})$；提示 token 与 padding 不计损失。
- **阶段目标**（式 4）：$\mathcal{L}^{(j)}_{\text{R-OPD}}(\theta)=\mathbb{E}_{C\sim\rho_j,\ R\sim p_{\bar\theta}(\cdot|C)}[\mathcal{L}_{\text{OPD}}(\theta;R)]$。

### 2.8 能力引导的数据分配
- 每次迭代用当前检查点在**与训练去污染隔离的分层评测集**上评估，按属性、质量维度、结果状态、路由层级聚合，形成**模型缺陷画像**。
- 依据画像把下一轮训练混合**向表现不足的区域倾斜**，同时保持覆盖广度；验证成功的轨迹提供正向监督，有信息量的失败指出需补充/再平衡的区域。分配改变的是**数据组成**，而非引入独立的失败专用目标。

## 6. 主要结论与发现

- **两个规模上均有一致增益**：4B 宏平均 58.94 → 64.87（+5.93），9B 65.60 → 69.04（+3.44）；增益集中在基于 harness 的智能体任务与编程任务，工具使用与指令遵循也有一致改善。
- **规模依然有益**：NeoHorse-1-9B 在所有可比基准上优于 4B 版本，额外收益集中在需要持续状态跟踪、外部工具交互、依据执行反馈修正中间决策的任务；指令遵循类差距较小。
- **训练可部分弥补规模差距**：NeoHorse-1-4B 在若干基准上追平或超过 Qwen3.5-9B。
- **轨迹行为机制**：训练使模型能闭合端到端执行回路（补全证据获取、约束修正、重算验证、写入正确路径）；更大模型在**迭代验证与失败恢复**（WorkBuddy 的 edit–test–inspect–repair 循环）与**环境约束下的策略切换**（PinchBench 中放弃不可用依赖、改用标准库，请求数/耗时/token 分别减少约 70.8%/76.7%/83.6%）上更稳健。
- **数据侧结论**：路由 harness 轨迹在相同训练配方下比公开合成数据（Toucan）五基准均分高 **+6.26**（HumanEval +8.54、τ²-Bench +11.31）；监督规模从基线 69.31 稳步升至 71.45（唯一受监督 token 对数轴），说明高质量智能体监督可产生一致聚合增益。
- **RSI 层面的初步验证**：后训练检查点可回到异构模型池继续服务，产生新的轨迹、路由记录与能力反馈，从而为下一轮训练混合提供种子——构成跨代迭代的操作基础。

## 7. 优点与亮点

- **把"路由信号"重新定义为难度代理**：无需显式难度标签或数据集启发式，直接用路由器在

用户轮次级估计出的能力需求作为课程排序依据，省去了额外难度标注成本，也避免了"按数据集名粗略分档"的启发式做法；同时保留**原始预测 / 策略调整后决策 / 实际服务层级**三个独立字段，为后续单独评估路由校准质量预留了接口。

- **数据粒度设计精细且有明确分工**：trajectory（经验载体）、user turn（训练单元）、subscene（语义刻画单元）三者分离，使得"用什么训练"与"用什么描述/调度"互不干扰；尤其是历史轮次只保留可见回复与工具交互、省略历史推理，既压缩上下文又避免把无关推理链当作监督目标。
- **质量管线坚持"结构事实优先于语义判定"**：规则验证（因果顺序、工具调用与结果 ID 闭合等）与语义评估分层，且明确规定证据缺失或判定中断**绝不转成正向结论**。这一保守策略直接抑制了长轨迹自动标注中的假阳性，对依赖自动数据闭环的方法尤为关键。
- **课程设计包含反偏斜机制**：三阶段递进但不"清空"低分样本，把部分低分样本保留到后期阶段，避免训练末期被高需求交互独占；阶段间不重置优化器与学习率调度，保证课程是连续的而非三次独立训练。
- **R-OPD 的技术取舍合理**：以 top-$K$ 粗化 + 概率质量并入 bin 的方式压缩教师分布，并用**响应归一化的反向 KL** 做目标，既保留学生自身前缀上的 on-policy 特性，又回避了全词表 KL 的高方差；训练中刷新 rollout 检查点、收集期间冻结参数，兼顾了分布跟随与稳定性。
- **闭环的"目标一致性"处理得当**：能力引导分配只改变**数据组成**，不引入独立的失败专用损失或额外头，因此评估—选择—更新回路不会因目标切换而破坏已学到的能力分布。
- **工程完整性**：从 harness 侧数据采集、清洗与去污染、课程排序、SFT、在线蒸馏到后训练检查点回流模型池继续服务，构成了一个可实际运行的多代迭代骨架，而不只是算法片段。
- **提供机制性证据而非仅分数**：轨迹行为分析（迭代验证与失败恢复循环、环境约束下的依赖替换）解释了增益从何而来，增强了结论的可信度与可迁移解读空间。

## 8. 局限与不足（客观审视）

- **算力与训练配置不透明**：GPU 型号/数量、总时长、批大小、学习率、步数均未披露，可复现性与成本可行性无法评估，也使"相同预算"等表述难以被外部核验。
- **缺少组件级消融**：无法回答结构验证、六维语义评估、三阶段课程、R-OPD、能力引导分配各自贡献多少；例如 +5.93 的宏平均增益中，课程与蒸馏的相对权重未知。
- **路由信号作为难度代理的校准未被直接检验**：论文本身也承认这是待办项。若预测层级与真实任务难度弱相关，课程的"由易到难"语义就只是名义上的。
- **RSI 主张强于证据**：核心卖点是"harness 介导的递归自我改进"，但实验只覆盖**单轮闭环**，未展示多代迭代下增益是否持续、是否饱和或退化，"复合式提升"仍是操作可行性论证而非实证结论。
- **评测层面存在若干偏差来源**：部分基线为引用值（带 ∗）与自测结果非同源；PinchBench、VitaBench 为单次运行，缺少方差报告；VitaBench 因原推荐模型不可用改用 DeepSeek-V4-Flash 作模拟器与裁判，可能系统性影响分数。
- **语义评估与场景刻画依赖模型判定**：尽管规定了保守策略，但六维评估与三轴刻画本身由模型给出，其一致性、可复现性与裁判偏差未被量化（如人工抽检一致率、跨裁判一致性）。
- **规模与泛化覆盖有限**：仅 4B/9B 两档，未验证更大规模是否仍受益（还是被更强基座的能力覆盖）；数据与工具接口强绑定 OpenClaw 类 harness，迁移到其他环境（不同工具协议、不同上下文预算）的有效性未测。
- **跨规模比较的解释力**：9B 档混入 Gemma-4-12B、Muse-Glimmer-30B 等不同参数量参考模型，读者需谨慎对待"同档最优"之类的解读。

## 9. 启示与可跟进方向

- **把 harness 当作"能力观测仪器"而非仅执行容器**，是本文最具迁移价值的视角：任何已部署的请求路由、工具网关或上下文管理组件，都可能附带可用于自改进的难度与结果信号。
- **后续最值得补的三块实验**：(1) 路由校准评估（预测层级 vs. 实际成功率/所需交互轮次）；(2) 逐步消融（SFT → +课程 → +R-OPD → +能力引导分配）；(3) 多代 RSI 迭代曲线（增益是否累积、何时收敛）。
- **方法层面可探索**：软排序分数 $\pi_{i,k}$ 的自适应更新（用实际结果反向校准路由器）、蒸馏中 $K$ 与 bin 策略的敏感性、以及能力引导分配从"手写规则倾斜"走向可学习配比。
- **报告规范层面**：若此类工作要支撑"RSI 可行性"这类较强论断，需公开训练算力、超参与裁判协议，否则难以区分是方法有效还是工程调优。

## 10. 一句话总评

NeoHorse-1 给出了一条**工程上可落地、机制上自洽**的"harness 介导自改进"路径——用路由信号做难度代理、用三层数据粒度组织监督、用课程与在线蒸馏闭合分布差距、用缺陷画像回流数据配比；其单轮实验证据（4B +5.93、9B +3.44 宏平均，以及相对公开合成数据的 +6.26）令人信服地支持"该闭环有效"，但**多代累积、组件贡献与路由校准这三项决定其 RSI 主张成立与否的关键验证仍然缺位**，目前更应被读作一份扎实的原型与路线图，而非对递归自我改进的完整证明。
