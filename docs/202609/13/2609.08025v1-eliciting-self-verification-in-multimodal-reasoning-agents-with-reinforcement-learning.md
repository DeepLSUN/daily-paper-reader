## 摘要
推理智能体越来越依赖网络搜索等外部工具来回答复杂查询。诸如 GRPO 之类的强化学习（RL）微调算法已经提升了纯文本语言模型的长篇推理能力，尤其是在编程和数学领域。然而，多模态智能体中的可靠工具使用仍然具有挑战性，因为模型必须解读文本和图像，同时整合含噪的检索证据，而且往往是在缺乏显式验证信号的稀疏结果级监督下进行。我们提出通过强化学习的自我验证（SVRL），这是一个仅使用 RL 的微调框架，训练多模态智能体在自身的推理轨迹中验证并过滤检索到的证据，从而在推理时减少对外部验证器的依赖。SVRL 还引入搜索感知惩罚以抑制不必要的工具调用，并引入查询多样性奖励以鼓励多样且形式良好的搜索查询，从而就何时搜索以及搜索什么提供细粒度反馈。仅用 5,000 个视觉问答示例对 Qwen-2.5-VL-7B 进行 SVRL 微调，即可在多个基准上持续提升多跳 VQA 泛化能力和工具效率。总体而言，SVRL 缩小了紧凑型智能体与远更大的专有模型之间的差距，同时显著降低了训练和推理成本。

## Abstract
Reasoning agents increasingly rely on external tools such as web search to answer complex queries. Reinforcement learning (RL) finetuning algorithms such as GRPO have improved long-form reasoning in text-only language models, particularly for coding and mathematics. Reliable tool use in multimodal agents, however, remains challenging because models must interpret text and images while integrating noisy retrieved evidence, often under sparse outcome-level supervision without explicit verification signals. We present Self-Verification via Reinforcement Learning (SVRL), an RL-only finetuning framework that trains multimodal agents to verify and filter retrieved evidence within their own reasoning traces, reducing reliance on external verifiers at inference time. SVRL also introduces a search-aware penalty that discourages unnecessary tool calls and a query-diversity reward that encourages diverse, well-formed search queries, providing fine-grained feedback on when and what to search. Finetuning Qwen-2.5-VL-7B with SVRL on only 5{,}000 visual question answering examples yields consistent gains in multi-hop VQA generalization and tool efficiency across benchmarks. Overall, SVRL narrows the gap between compact agents and much larger proprietary models while requiring substantially lower training and inference cost.

## 1. 核心问题与整体含义

- **研究背景**：多模态大语言模型（MLLM）正从静态感知系统演进为可调用外部工具（如网络搜索、图像搜索）的交互式智能体。GRPO 等 RL 微调算法已在纯文本长程推理（代码、数学）上取得显著进展，但多模态智能体的可靠工具使用仍困难重重。
- **核心痛点**（论文以多跳 VQA 为具体场景，如 InfoSeek、OK-VQA、FVQA）：
  - **工具调用校准差**：在 FVQA 2000 例子集上分析 MMSearch-R1，超过 10% 的样本"该搜却没搜"，超过 30% 的样本"不该搜却搜了"。

  - **监督稀疏**：通常只有最终答案的结果级奖励，中间决策（搜什么、信哪条、何时停）无标注，导致信用分配脆弱；且组内奖励方差塌缩会使 GRPO 优势失效。
- **整体含义**：论文提出 **SVRL（Self-Verification via Reinforcement Learning）**，一种仅用 RL 的微调框架，让多模态智能体在自身推理轨迹中显式地对检索证据打分、过滤，并在**推理时无需任何外部验证器**，从而在紧凑模型规模下逼近大型专有模型。

## 2. 方法论

### 2.1 核心思想
将证据选择与搜索决策转化为**可学习的轨迹级信号**：通过细粒度奖励区分"何时搜"、"搜什么"、"信什么"，并在训练时用带真值的外部验证器提供对齐监督，推理时则完全由模型自主完成验证。

### 2.2 问题形式化
- 模型视为随机策略 πθ，给定 (I, q) 生成轨迹 τ = (s₁:ₜ, y)，每步 sₜ = (lₜ, aₜ, pₜ)，含 `<reason>` 自然语言推理、动作（工具调用或回答）及参数。
- 基础 GRPO 目标：组内标准化优势 Âᵢ + PPO 裁剪代理目标 + KL 正则。

### 2.3 关键技术细节

- **工具校准（何时搜）——r_aware**
  - 先用模型对 (I, q) 做一次**无工具前向**得到 ŷ，若 ŷ = y* 则标记为 `search_free`。
  - 若在 search_free 样本上调用搜索工具，则奖励乘以 λ_sa = 0.1，否则为 1，替换原始统一搜索惩罚。

- **查询多样性（搜什么）——r_count**
  - 让模型一次提出 k 个候选查询（实验中 k=5），随机执行其中一个有效且唯一的查询。
  - 设唯一有效查询数为 k̂，则 r_count = 1（无文本搜索）或 max(ε, k̂/k)（有搜索）。

- **自验证（信什么）——r_qalign、r_salign**
  - 模型在每次工具调用后输出结构化二值验证向量，如 `<verify>0,1,0,1</verify>` 并附简短理由。
  - 训练时用**带真值答案的外部验证器（GPT-5）**标注哪些查询有用、哪些片段含支撑证据，得到 r_qalign（查询对齐）与 r_salign（片段对齐）。
  - **推理时丢弃该验证器**。

- **组合奖励（公式 3、4）**
  - r_svrl = r_aware · r_count · r_qalign · r_salign
  - r(τ) = (1−α)·r_acc·r_svrl + α·r_fmt，其中 α = 0.1，r_acc 为精确匹配，r_fmt 为格式奖励。
  - 关键设计：**细粒度信号以乘法方式受正确性门控**，避免加性塑形导致"答案错误也得部分分"的奖励黑客。

- **稳定优化与算法流程**（Algorithm 1）
  1. 自标注阶段：对每个训练样本做无工具前向，得到 search_free 标签。
  2. RL 微调循环：采样组内 rollout → 解析答案/工具参数/自验证 → 用验证器 G 生成真值标签 → 计算 r_svrl → 计算总奖励 → 用 **Dr. GRPO** 更新。
  - 采用 **Dr. GRPO** 移除标准差与长度归一化，缓解轨迹依赖奖励下的梯度尖峰与响应长度漂移；组大小 G=4（比 MMSearch-R1 的 G=8 更小，吞吐更高）。
  - 不使用 LLM-judge 作为训练奖励（易被奖励黑客：答案冗长、模棱两可），仅在评测时使用。

## 6. 主要结论与发现

- **性能提升**：SVRL-full-7B 相比最强自适应搜索基线 MMSearch-R1++，FVQA-test 提升约 8 分（65.3 vs 56.4），InfoSeek 提升约 9 分（64.7 vs 55.1），同时**搜索率更低**（61.4% vs 80.3%；52.3% vs 59.7%），实现更好的精度–成本权衡。
- **逼近大模型**：在 FVQA-test 上 65.3 逼近 GPT-4o 的 66.0；在自适应搜索设定下，SVRL-7B/8B 的 GPT-5.0 judge 准确率**高于 GPT-5.2-thinking**（60.8 / 52.2）。
- **骨干泛化**：SVRL 在 Qwen3-VL-8B 上同样有效（FVQA 64.9、InfoSeek 64.0），说明增益不依赖单一骨干。
- **组件贡献**：搜索校准（search-aware）与自验证（self-verification）贡献主要增益；测试时外部验证（SVRL-ttv）增益大，说明**证据选择是主导失败模式**；自验证能以无外部验证器方式恢复大部分去噪收益。
- **工具行为改善**：过度自信漏搜率从 12.6% 降至 2.7%；搜索精度从 89.9% 升至 97.7%；搜索召回从 54.6% 升至 70.8%；平均每步生成 4.86 个唯一查询，未塌缩为单一模板。
- **测试时扩展**：SVRL 随搜索预算增加持续获益，而基线约 5 次搜索后饱和。
- **验证器对齐**：SVRL 验证掩码与 GPT-5 标签一致率 71.3%，但分歧高度不对称——欠过滤（1495 例）远多于过过滤（82 例），说明模型倾向于保守保留可疑证据。

## 7. 优点

- **推理时零外部验证器**：将验证能力内化到推理轨迹中，显著降低部署成本与延迟，区别于依赖额外重排/验证阶段的工作。
- **细粒度、可区分的轨迹奖励**：乘法门控 + 四个因子使组内奖励方差增大，避免 GRPO 优势塌缩，支持更小的组大小（G=4）与更高吞吐。
- **奖励设计的反黑客考量**：明确指出加性塑形与 LLM-judge 的奖励黑客风险，采用精确匹配 + 乘法门控，并有实验证据支撑。
- **搜索校准建模巧妙**：用模型自身无工具前向作为"能力先验"标注 search_free，比统一步数惩罚更符合预训练模型的实际情况。
- **多维度验证**：不仅有精度对比，还有工具使用分析、条件查询分析、验证掩码对齐分析、测试时扩展曲线与定性案例，论证链条较完整。
- **工程实用性**：缓存层（DynamoDB + Jaccard 复用）降低 40% 检索成本，随机返回 2–6 条摘要以避免过拟合固定证据模式。

## 8. 不足与局限

- **依赖训练时教师验证器**：查询/片段对齐奖励依赖带真值答案的 GPT-5 标注，引入教师模型偏差；论文承认这是主要局限之一。
- **评测不可完全复现**：主指标使用 GPT-5.0 作 judge，对 prompt 措辞敏感、非完全可复现；EM 指标虽严格但受表面形式影响大。
- **过滤仍偏保守**：模型欠过滤显著多于过过滤（1495 vs 82），倾向于保留噪声证据，可能影响最终答案质量。
- **检索环境非平稳**：网页可能不相关、不可访问、过时或解析失败；对检索分布漂移的鲁棒性未充分验证。
- **任务范围窄**：仅覆盖短交互跨度（最多 3 步）、受限动作空间（图像搜索、文本搜索、验证、回答）的多跳 VQA，未涉及长程交互、持久记忆、更丰富工具套件；作者自述结果应理解为"搜索式多模态推理的改进证据"而非通用多模态智能体的完整方案。
- **测试时聚合规则简单**：仅用精确匹配多数投票 + 嵌入最近邻共识，未探索更强的结构化搜索与聚合策略。
- **部分场景增益有限**：SimpleVQA 上提升较小，作者推测与查询语言等工具参数有关；时效性强或欠定义的问题也引入不可约的评测噪声。
- **对提示与工具格式敏感**：性能受 prompt 与工具输出格式影响，泛化稳定性有待进一步检验。
