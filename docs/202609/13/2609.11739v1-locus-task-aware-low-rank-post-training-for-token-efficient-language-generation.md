## 摘要
大语言模型的服务成本随输出序列长度直接增长，然而标准的偏好对齐往往会增加回复的冗长程度，却并未提升效用。我们研究后训练更新的参数化是否会影响生成长度：低秩子空间能够在不修改对齐损失的情况下改变序列长度。我们提出 LOCUS，一种在效用约束下选择任务感知的低秩适配子空间以最小化输出令牌成本的方法。在该子空间内，后训练在冻结主干的情况下保留原生偏好目标。在 Anthropic HH-RLHF 对话偏好数据上，我们评估了两个 $\sim$3B 解码器主干，Pythia-2.8B 和 Qwen2.5-3B，并与协议匹配的全参数 DPO 和 DrDPO 分支以及已发布的 SamPO 检查点进行比较。LOCUS 在 Pythia-2.8B 上将续写长度最多减少 39.84\%，在 Qwen2.5-3B 上减少 14.87--17.58\%，同时仅更新 0.24--0.28\% 的模型参数，且内部偏好诊断没有实质性变化。

## Abstract
Large language model serving costs scale directly with output sequence length, yet standard preference alignment often inflates response verbosity without improving utility. We study whether the parameterization of post-training updates affects generation length: low-rank subspaces alter sequence length without modifying the alignment loss. We present LOCUS, a method that selects a task-aware low-rank adaptation subspace to minimize output-token cost subject to a utility constraint. Within this subspace, post-training retains the native preference objective with a frozen backbone. Across Anthropic HH-RLHF dialogue preferences, we evaluate two $\sim$3B decoder backbones, Pythia-2.8B and Qwen2.5-3B, against protocol-matched full-parameter DPO and DrDPO branches and the released SamPO checkpoint. LOCUS reduces continuation length by up to 39.84\% on Pythia-2.8B and by 14.87--17.58\% on Qwen2.5-3B while updating only 0.24--0.28\% of model parameters, with no material change in the internal preference diagnostic.

## 一、核心问题与整体含义

- **研究动机**：大语言模型（LLM）的服务成本（延迟、显存带宽、KV 缓存）与自回归生成的输出 token 数量直接挂钩；每多解码一个 token 就需一次完整深度的前向传播。
- **背景矛盾**：标准偏好对齐方法（DPO、DrDPO、SamPO 等）虽能对齐人类偏好，却普遍诱发**冗长偏置（verbosity bias）**——模型学到"回答越长、偏好分数越高"的错误关联，导致回复变长但不提升实际效用。
- **已有方案的缺陷**：
  - 启发式长度惩罚 / 负长度奖励会扭曲原生偏好目标，可能造成过早终止或质量退化；
  - 提示模型"简洁回答"依赖脆弱的指令遵循，在分布偏移下失效；
  - 这些方法都改动了学习目标或推理接口，未回答一个更本质的问题：**更新参数化方式本身是否影响生成长度？**
- **核心洞察**：低秩适配（LoRA）把可训练更新限制在因子化矩阵中，使"更新子空间"成为一个可操纵的具体变量。冻结主干、将更新约束在结构化低秩轨迹上，模型可在**完全保留原偏好损失**的前提下落到一个更优的"质量—token"工作点。
- **整体含义**：论文把 token 高效偏好后训练形式化为一个**受效用约束的任务感知低秩子空间选择问题**，为低成本部署提供一条轻量路径。

## 二、方法论

### 核心思想
- 不修改对齐损失（无长度归一化、无显式 token 惩罚、无简洁提示），只把**低秩子空间配置**当作结构化设计变量，在效用约束下最小化输出 token 成本。

### 三阶段流程
1. **目标保持适配（Objective-Preserving Adaptation）**
   - 冻结预训练主干 $W_0$，仅在选定模块上附加 LoRA：$W = W_0 + \Delta W = W_0 + \frac{\alpha}{r}BA$，其中 $A \sim \mathcal{N}(0,\sigma^2)$、$B$ 零初始化、$r \ll \min(d_1,d_2)$。
   - 用**原生目标** $L_{\text{base}}$（DPO / DrDPO / SamPO 的精确形式）训练，不添加任何额外正则项。
2. **任务感知约束选择（Task-Aware Constrained Selection）**
   - 配置元组 $c = (r, \alpha, P, L, s) \in \mathcal{C}$：$r$ 为秩、$\alpha$ 为缩放因子、$P \subseteq \{Q,K,V,O,\text{MLP}\}$ 为目标模块、$L$ 为层索引集合、$s$ 为训练检查点步数。
   - 效用定义（式 4）：在 held-out chosen-vs-rejected 序列 log 概率上的偏好准确率
     $Q_t(c) = \frac{1}{|D_t|}\sum \mathbb{I}(\pi_c(y_w|x) > \pi_c(y_l|x))$。
   - 约束最小化（式 5）：$c_t^* = \arg\min_{c \in \mathcal{C}} T_t(c)$，s.t. $Q_t(c) \ge Q_t^{\text{base}} - \epsilon_t$，其中 $T_t(c)$ 为贪心解码下平均续写 token 长度，$\epsilon_t = 1.0$ 个百分点。
   - **两阶段防过拟合**：先在 selection split $D_t^{\text{sel}}$ 上筛选可行候选并选最短者；若有 confirmation split $D_t^{\text{conf}}$，需再通过效用与长度双重检查，否则**回退到基线**；无 confirmation 时返回"未确认"适配器（Algorithm 1）。
3. **服务与部署**
   - 单租户：可预合并 $W^* = W_0 + \frac{\alpha}{r}B^*A^*$，零适配器引入的延迟与参数开销；
   - 多租户：单一冻结主干动态服务多个任务适配器。

### 理论分析
- **命题 1（可训练参数计数）**：全参数微调暴露 $d_1 d_2$ 个标量，LoRA 只暴露 $r(d_1+d_2)$ 个因子条目；当 $r(d_1+d_2) < d_1 d_2$ 时严格减少。注意区分"暴露的因子条目数"与"所表示更新集合的内在维度"（因 $G$ 变换冗余，rank-$r$ 流形局部维度为 $r(d_1+d_2-r)$）。
- **命题 2（合并等价性）**：推理模式下（adapter dropout 关闭），未合并计算 $W_0 h + \frac{\alpha}{r}B(Ah) + b$ 与合并计算 $W^*h+b$ 对任意输入 $h$ 输出完全相同；但有限精度/量化实现可能有微小数值差异。
- **参数核算**：Pythia-2.8B 适配器 7,864,320 参数（0.2826%）；Qwen2.5-3B 为 7,372,800（0.2383%）；Adam 两状态优化器下对应约 7.86M / 7.37M 条目。
