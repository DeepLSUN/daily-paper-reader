## 摘要
当前基于LLM的多智能体系统（MAS）会定期压缩中间状态，以减少推理时的token消耗，从而试图纳入更多智能体。然而，朴素的扩展策略面临挑战。例如，在经济模拟中，大规模MAS通常会丢弃语义丰富的经济状态，即智能体行为轨迹，而这是宏观经济波动的关键驱动因素。本文揭示了模拟过程中智能体异质性逐渐下降的现象，并提出了面向多智能体系统的前景状态传播（PspMAS）。受前景理论启发，PspMAS将每个智能体的微观状态解耦为紧凑的前景状态和富有表达力的语义状态。前者通过轻量、可并行化的传播器记录心理痕迹，并向系统持续注入异质性。后者利用LLM强大的感知、推理、规划和决策能力。这两个组件互补协作，提供了一种可扩展的基于LLM的多智能体模拟解决方案。

## Abstract
Current LLM-based multi-agent systems (MAS) periodically compress intermediate states to reduce inference-time token consumption, thereby attempting to incorporate more agents. However, naive scaling strategies face challenges. For example, in economic simulations, large-scale MAS typically discard semantically rich economic states, i.e., agent behavioral trajectories, which are key drivers of macroeconomic fluctuations. In this paper, we reveal a phenomenon in which agent heterogeneity gradually decreases during simulation, and propose Prospect-State Propagation for Multi-Agent Systems (PspMAS). Inspired by prospect theory, PspMAS decouples each agent's micro state into a compact Prospect State and an expressive Semantic State. The former records psychological traces through a lightweight, parallelizable propagator and continuously injects heterogeneity into the system. The latter leverages the strong perception, reasoning, planning, and decision-making abilities of LLMs. These two components work complementarily, providing a scalable LLM-based multi-agent simulation solution.

# 论文总结：Scaling Multi-Agent Systems with Prospect-State Propagation

## 1. 核心问题与整体含义

- **研究背景**：基于大语言模型（LLM）的多智能体系统（MAS）被广泛用于宏观经济模拟，其微观状态由固定数值向量演变为语义丰富的自然语言描述，从而支撑行为异质性，而异质性正是宏观经济波动的关键驱动因素。
- **核心问题**：长时程模拟中，丰富语义状态消耗大量推理 token，现有系统通过**周期性反思/摘要**压缩中间状态以纳入更多智能体；但这一压缩策略会丢弃经济决策所必需的时间顺序与中间状态，导致智能体行为逐渐趋同。
- **关键现象揭示**：论文指出，传统 MAS 在模拟推进过程中会出现**智能体异质性逐渐下降**（行动收敛，action convergence）的现象。名义智能体数量虽大，但"有效智能体"数量随周期压缩不断减少，宏观波动因此被削弱。
- **深层机制**：真正具有预测价值的风险信号往往首先出现在少数智能体的局部状态中（如次贷危机前"平均工资但高负债"的智能体 Sara）。若状态描述被滞后宏观变量主导，这些局部异常在语义压缩中被稀释或抹除，微观到宏观的传导被抑制。
- **整体含义**：论文提出 **PspMAS（Prospect-State Propagation for Multi-Agent Systems）**，通过解耦微观状态，在控制 token 成本的同时持续注入异质性，为可扩展的 LLM 多智能体经济模拟提供新范式。

## 2. 方法论

### 2.1 核心思想
- 受**前景理论**（Kahneman & Tversky）启发，将每个智能体的微观状态解耦为两个互补分支：
  - **紧凑的前景状态（Prospect State）**：由轻量、可并行的传播器持续更新，记录心理痕迹，注入长期异质性；
  - **表达性语义状态（Semantic State）**：由 LLM 周期性刷新，支撑感知、推理、规划与拟人决策。
- 两分支并行运作：前景状态低成本连续演化，保留长期路径依赖；语义状态在较长时间尺度上刷新，注入丰富行为模式而不产生过高 token 开销。

### 2.2 关键技术细节

- **微观状态表示**：$M_t^i = (s_t^i, \sigma_t^i, e_t^i)$，其中 $s_t^i$ 为前景状态，$\sigma_t^i$ 为语义状态，$e_t^i$ 为经济记账变量（财富、债务、工资、就业状态等）。
- **宏观状态**：$S_t$ 包括价格水平、利率、失业率、GDP 等。
- **动作空间**：$a_t^i = (l_t^i, p_t^i) \in \{0,1\} \times [0,1]$，即是否工作与消费比例。

- **前景状态向量**：$s_t^i = (\lambda_t^i, \gamma_t^i, R_t^i) \in \mathbb{R}^3$，分别对应损失厌恶系数、概率权重参数、动态参考点。
- **马尔可夫传播更新**：
  - $\tilde{s}_{t+1}^i = \Phi(s_t^i, o_t^i, S_{t+1})$，$s_{t+1}^i = \Pi_P(\tilde{s}_{t+1}^i)$，其中 $o_t^i$ 为市场清算后的个体结果，$\Pi_P$ 投影到有效域以保证有界。
  - 参考点更新：$\tilde{R}_{t+1}^i = \alpha_r W_t^i + (1-\alpha_r) R_t^i + \beta_r (\bar{R}_c^t - R_t^i) I_{scl}^t$（含社会比较）；
  - 损失厌恶更新：$\tilde{\lambda}_{t+1}^i = \lambda_t^i + \eta_\lambda (\bar{\lambda}_t - \lambda_t^i) I_{crs}^t + \xi_t^i$（含危机趋同与随机扰动）；
  - 概率权重更新：$\tilde{\gamma}_{t+1}^i = \gamma_t^i + \eta_\gamma (1-\gamma_t^i) \min(1, E_t^i/E_{thr}) - \zeta I_{shk}^t$。
- **语义状态更新**：每 $K$ 步由 LLM 接收当前前景状态、记账变量、最近 $K$ 步原始事件历史与上一语义状态，生成新的 $\sigma_t^i$。
- **经济状态读取**：$(M_{t+1}, S_{t+1}, o_t) = \Psi(a_t, M_t, S_t)$，市场清算按比例配给，价格工资随供需调整，政府累进税并均等再分配，央行按泰勒规则设定利率。

- **异质性量化**：
  - **轨迹矩阵** $H_{traj}^t$：基于最近 $L=12$ 步动作序列的 RBF 相似核；
  - **前景矩阵** $H_{pros}^t$：基于前景状态向量的 RBF 相似核；
  - **融合异质性矩阵**：$H_{fuse}^t = \alpha H_{traj}^t + (1-\alpha) H_{pros}^t$（$\alpha=0.5$），正半定，可用谱分析；
  - **谱熵** $E_t$ 与**有效多样性** $D_{eff}^t = \exp(E_t)$，归一化多样性 $D_{norm}^t = D_{eff}^t / N$。

- **算法流程**（Algorithm 1）：初始化微观状态 → 每个时间步并行执行（每 $K$ 步更新语义状态、生成经济动作）→ 市场清算 → 并行更新前景状态 → 构建异质性矩阵并计算多样性指标。

### 2.3 实现细节
- 使用 Qwen3 系列模型，决策温度 0.7、摘要温度 0.2；更新间隔 $K=5$；传播器系数 $\alpha_r=0.1, \beta_r=0.05, \eta_\lambda=0.001, \eta_\gamma=0.005, \zeta=0.1, \sigma_\lambda=0.02$；阈值 $E_{thr}=10$。

## 6. 主要结论与发现

- **RQ1 结论（缩放失效）**：SaMAS 名义人口从 $N=100$ 增至 $N=500$，VR 仅提升 0.2 个百分点（81.8% → 82.0%），而 $D_{norm}$ 下降 9.9 个百分点（43.2% → 33.3%），说明**名义智能体数量不等于有效系统规模**，重复语义压缩导致行为收敛。
- **PspMAS 表现**：VR 从 82.9% 提升至 85.3%，同时保持较高多样性（$N=100$ 时 61.9%，$N=500$ 时 56.9%）；在 $N=500$ 时 VR 超过 SaMAS 3.3 个百分点，$D_{norm}$ 超出 23.6 个百分点。
- **RQ2 结论（异质性保持）**：SUMMARY SYSTEM 在 $N \approx 200$ 时饱和（$D_{norm} \approx 0.21$）；REFLECTION SYSTEM 呈次线性缩放；PspMAS 在 $N=500$ 时 $D_{norm} > 0.56$，且该优势在不同 LLM 规模（8B/32B）与模拟时程（50/200）下持续存在。
- **核心发现**：**保持状态异质性是释放 MAS 缩放收益的前提**；前景状态传播器能同时保留行为轨迹与路径依赖的心理差异。

## 7. 优点

- **理论驱动的创新**：首次将行为经济学的**前景理论**（参考依赖、损失厌恶、概率权重）系统性地引入 LLM 多智能体经济模拟的状态更新机制，具有较强的跨学科洞察力。
- **问题揭示有价值**：明确指出现有 MAS 中"异质性损失/行动收敛"现象，并用具体案例（次贷危机中的高负债个体）说明其宏观后果，动机论证充分。
- **架构设计巧妙**：将微观状态解耦为"轻量确定性传播器 + 周期性 LLM 语义刷新"双分支，在 token 成本与行为丰富度之间取得平衡，计算上可并行、可扩展。
- **异质性度量体系完整**：构建轨迹矩阵、前景矩阵与融合矩阵，并用谱熵定义有效多样性与归一化多样性，为"有效智能体数量"提供了可量化的度量工具。
- **实验维度设计合理**：同时考察智能体规模、LLM 规模与模拟时程，结论在不同设定下保持一致，增强了说服力。
