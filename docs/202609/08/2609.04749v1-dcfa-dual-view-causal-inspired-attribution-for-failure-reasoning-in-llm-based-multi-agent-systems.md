## 摘要
近年来，基于大型语言模型（LLM）的多智能体系统经历了快速发展。尽管前景广阔，但此类系统仍然脆弱，经常出现推理和协调错误，可能导致系统级故障。此类系统中的故障归因依赖于追踪智能体之间的自然语言交互，以识别决定性错误，即最早可以通过纠正其来逆转系统失败的动作。存在两个关键挑战：1）浅层归因：现有方法通常仅捕获微小的偏差，如不完整的检索或格式错误，这些错误可通过验证机制纠正，而遗漏了系统失败的决定性原因。2）上下文退化：随着系统轨迹长度的增加，模型的推理能力迅速恶化。为应对这些挑战，我们提出了DCFA，一种无需训练的故障归因框架。DCFA集成了一个全局模块，该模块从系统轨迹中构建结构化的因果启发依赖图以识别初始决定性错误，以及一个局部模块，该模块应用局部反事实启发推理来细化因果启发归因。在Who&When基准上跨六个LLM的实验表明，DCFA相比最先进的基线，在步骤级准确率上提升了最高达8.27%。

## Abstract
Large language model (LLM)-based multi-agent systems have experienced rapid growth in recent years. Despite their promise, such systems remain fragile, frequently exhibiting reasoning and coordination errors that can lead to system-level failures. Failure attribution in such systems relies on tracing natural language interactions among agents to identify the decisive error, which refers to the earliest action whose correction can reverse system failure. There are two key challenges: 1) Shallow attribution: Existing methods often capture only minor deviations, such as incomplete retrievals or formatting errors, which verification mechanisms can correct, while missing the decisive cause of system failure. 2) Contextual degradation: As the length of the system traces increases, the model's reasoning ability rapidly deteriorates. To address these challenges, we propose DCFA, a training-free framework for failure attribution. DCFA integrates a global module that constructs structured causal-inspired dependency graphs from system traces to identify the initial decisive error, and a local module that applies local counterfactual-inspired reasoning to refine causal-inspired attribution. Experiments on the Who&When benchmark across six LLMs show that DCFA improves step-level accuracy by up to 8.27% over state-of-the-art baselines.

## 2. 论文提出的方法论：核心思想与关键技术细节

### 2.1 总体框架
论文提出 **DCFA（Dual-view Causal-inspired Failure Attribution，双视角因果启发失败归因）** ，集成两大模块：
- **全局因果启发归因模块（GCA）** ：负责全局结构化推理
- **局部反事实启发增强模块（LCE）** ：负责局部精化验证

### 2.2 全局因果启发归因模块（GCA）

该模块分三步进行，目的是克服“浅层归因”：

1. **微小偏差识别（Minor Deviation Identification）**
   - 通过MDI(·)过程从系统轨迹中提取候选微小偏差（如格式错误、不完整检索等），并生成每个偏差对应的自然语言解释。
   - 关键设计：GCA并不在这阶段急于确定哪个偏差是决定性错误，而是保留所有潜在相关的交互，供后续结构推理和精化使用。
   - 公式：`(Tⁱ, Rⁱ) = MDI(T)`

2. **依赖图构建（Dependency Graph Construction）**
   - 以微小偏差节点为中心，在系统轨迹上构建**因果启发依赖图** G=(V,E)，节点为交互步骤索引，有向边表示依赖关系。
   - 边的判定需同时满足**三重判定准则**：
     - **时间性（Temporality）** ：τp必须在τq之前发生（p<q）
     - **必要性（Necessity）** ：若移除τp则τq不会发生，通过反事实判断函数J评估
     - **充分性（Sufficiency）** ：执行τp是否足以导致τq发生
   - 仅在三条准则均满足时才添加边，从而过滤虚假相关，保留因果支撑的依赖。
   - 公式：`G = CGC(T, Tⁱ, Rⁱ, I)`（通过结构化提示注入指令）

3. **假设生成（Hypothesis Generation）**
   - GCA基于紧凑证据集合（包括真实结果、系统轨迹、候选微小偏差、对应原因和构建的图）进行全局推理，生成关于决定性错误的初始假设(τ⋆, r⋆)。
   - 公式：`(τ⋆, r⋆) = HG(Ŷ, T, Tⁱ, Rⁱ, G)`

### 2.3 局部反事实启发增强模块（LCE）

该模块旨在解决“上下文退化”，在GCA产生的全局假设基础上进行局部精化：

1. **双向依赖邻域搜索（Bidirectional Dependency Neighborhood Search）**
   - 以GCA假设τ⋆为轴心（pivot），沿依赖图G进行**前向搜索**（追踪错误的下游传播）与**反向搜索**（寻找上游误推理或缺失前提）
   - 每次迭代贪心选择边际贡献最大的后继/前驱节点
   - 搜索方向终止条件均为：没有正向边际贡献的候选节点

2. **反事实启发评估（Counterfactual-inspired Evaluation）**
   - 首先构造完全修正的轨迹：`T̂ = Correct(Ŷ, T, Tⁱ, Rⁱ, G)`
   - 对第i步交互构建反事实轨迹：`T̂(i) = {τ̂₁,…,τ̂ᵢ, τᵢ₊₁,…,τ_N}`（前i步已修正+后方原始未修正）
   - 通过仿真过程获得该轨迹的输出，用预训练编码器计算与真实结果的余弦相似度：`S(τᵢ) = Cos(Enc(Y(i)), Enc(Ŷ))`
   - 定义修正第i个交互的**边际归因影响**：`ΔS(τᵢ) = S(τᵢ) − S(τᵢ₋₁)`，衡量逐级纠正带来的增量改进。

3. **决定性错误判定（Decisive Error Decision）**
   - 合并前向集和反向集及全局假设形成局部候选集
   - 通过函数`τ∗ = DED(Ŷ, Tᶜ, G)`判定最终决定性错误——避免了对完整长轨迹的分析，极大减弱上下文退化影响

### 2.4 核心设计逻辑
GCA首先建立全局因果依赖结构，LCE再沿关键链路进行局部反事实验证，形成一个“由全局到局部”“由因果到反事实”的递进精化过程，实现了对非结构化和长系统轨迹的可解释失败归因。

- **双视角协同创新**：将“全局因果结构化推理”与“局部反事实验证”结合，先在全局依赖图上锁定错误区域，再在局部邻域精确定位，与人类逐步排除的诊断思维高度契合，也为归因结果提供了因果链层面的可解释性。
- **无需训练**：规避了微调范式的高昂标注和重训成本，直接利用LLM推理能力即可适配。
- **有效对抗长上下文退化**：LCE仅在局部候选集上运行，避免全轨迹分析导致的注意力涣散与上下文超限问题，在Hand-crafted数据（最长130步）上有显著提升，比仅用长上下文推理的基线更加稳健。
- **理论上具有通用性**：非特定于某一MAS架构，理论上可适用于任意以自然语言交互为中介的多智能体系统归因。
- **面向现实设定的问题建模**：将“多个错误共存时无单步修正能完全恢复正确输出”纳入正式定义，使系统能区分“贡献性错误”与“决定性错误”，更贴合真实多智能体故障场景。

## 8. 不足与局限

- **对底层LLM能力的高度依赖**：弱模型在超长轨迹中难以维持一致的依赖结构表达，在局部反事实精化时判断精度也受限。即使LCE可在一定程度上补偿“全局因果图质量”，当模型结构化推理能力过弱时（如DeepSeek-R1-32B在某些长度级别上性能低于ECHO），整体准确率仍受影响。
- **可扩展性限制**：虽然对中等长度轨迹具备鲁棒性，但对极长（超百步）或高度分支的多智能体交互仍可能力不从心，深层嵌套或持续交互模式下的实用性有待验证。
- **内在LLM推理错误的归因困难**：DCFA所定位的决定性错误反映的是MAS工作流内的失败环节；对源于底层LLM本身幻觉（hallucination）的失误，归因准确性可能受限——这类错误的产生与工作流的结构性无关。
- **计算开销问题**：GCA需要两次全上下文调用，LCE平均需要4.5次局部调用，整体推理时间（300秒/实例）显著高于基线，实际部署中可能存在成本瓶颈。
- **实验局限**：
  - 数据集层面：仅使用Who&When单一基准（含184条轨迹），样本规模偏小，且两类分布不太均衡
  - 未进行跨基准泛化验证（如AgentErrorBench设置的任务虽有差异但也可作为补充对照）
  - 未报告在极端长轨迹（>100步)上框架表现的详细分解
- **伦理与责任归属问题**：框架仅为诊断辅助工具，其归因结果依赖底层模型推理行为，在高压决策场景下需谨慎使用，不宜由自动化归因结果直接决定责任归属。
