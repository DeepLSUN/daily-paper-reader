## 摘要
混合大语言模型将全注意力层与线性注意力层交错排列，以降低长上下文推理的成本。这种结构使前缀缓存变得复杂：全注意力键值缓存是令牌可寻址的，而线性注意力层维护的循环状态无法回滚到任意前缀边界。现有的混合前缀缓存方法通过存储循环状态检查点来解决这种不匹配问题。因此，令牌级匹配仅在存储检查点的位置直接可用，将前缀重用限制在一组离散的边界上。我们提出了Tail-Replay，一种在混合大语言模型中实现无约束令牌级前缀重用的前缀缓存机制。关键洞察在于，诸如Gated DeltaNet之类的线性注意力机制可以被视为输入前缀的一种结构化、有损压缩：门控循环更新会逐渐衰减早期输入的贡献。因此，匹配前缀的循环状态可以通过仅重放该前缀的一个短近期后缀来很好地近似。Tail-Replay利用了这一特性，缓存精确的全注意力键值缓存，同时省略循环状态检查点。在缓存命中时，它通过重放匹配前缀的一个短近期后缀来重建线性注意力状态。因此，重用边界由共享令牌决定，而非循环状态检查点。我们使用LongBench和RULER基准评估了基于Gated DeltaNet的三种混合模型上的Tail-Replay。仅使用5-10%的重放预算，它在LongBench和RULER上保留了92.8-99.9%的全预填充质量。在服务效率方面，我们评估了多个匹配前缀长度——8K、16K和32K下的首令牌时间加速比。加速比随前缀长度增长，在32K时达到全预填充的9.1-14.3倍。

## Abstract
Hybrid large language models interleave full-attention layers with linear-attention layers to reduce the cost of long-context inference. This structure complicates prefix caching: full-attention key-value caches are token-addressable, whereas linear-attention layers maintain recurrent states that cannot be rolled back to arbitrary prefix boundaries. Existing hybrid prefix caching methods address this mismatch by storing recurrent-state checkpoints. As a result, token-level matches are directly usable only at positions aligned with stored checkpoints, constraining prefix reuse to a discrete set of boundaries. We present Tail-Replay, a prefix caching mechanism that enables unconstrained token-level prefix reuse in hybrid large language models. The key insight is that linear-attention mechanisms such as Gated DeltaNet can be viewed as a structured, lossy compression of the input prefix: gated recurrent updates progressively attenuate the contributions of earlier inputs. Consequently, the recurrent state of a matched prefix can be well approximated by replaying only a short, recent suffix of that prefix. Tail-Replay exploits this property by caching the exact full-attention key-value cache while omitting recurrent-state checkpoints. On a cache hit, it reconstructs the linear-attention states by replaying a short, recent suffix of the matched prefix. As a result, the reuse boundary is determined by the shared tokens rather than by recurrent-state checkpoints. We evaluate Tail-Replay on three Gated DeltaNet-based hybrid models using the LongBench and RULER benchmarks. With only a 5--10\% replay budget, it retains 92.8--99.9\% of full-prefill quality on LongBench and RULER. For serving efficiency, we evaluate time-to-first-token speedups across multiple matched-prefix lengths---8K, 16K, and 32K. The speedup grows with prefix length, reaching $9.1$--$14.3\times$ over full prefill at 32K.

## 论文详细总结

### 1. 论文的核心问题与整体含义（研究动机和背景）

- 混合大语言模型（Hybrid LLMs）通过将全注意力（Full Attention, FA）层与线性注意力（Linear Attention）层交错排列，在保持较强建模能力的同时降低长上下文推理成本。然而，这种结构给前缀缓存（Prefix Caching）带来了根本性挑战：
  - 全注意力层的键值缓存（KV Cache）是**令牌级可寻址**的，可以按任意前缀边界复用；
  - 线性注意力层把前缀压缩为**循环状态（recurrent state）**，该状态一经推进就无法回滚到任意较早的前缀边界。
- 现有的混合前缀缓存方案（如 Marconi、Sparse Prefix Caching）通过显式存储**循环状态检查点（checkpoint）**来规避此问题，但这样做的后果是：前缀复用只能发生在少数与检查点对齐的离散边界上，无法实现灵活的令牌级前缀复用。
- 论文将这一矛盾概括为 **“线性注意力对前缀缓存的诅咒”（the curse of linear attention for prefix caching）**：一个令牌级的前缀匹配，不再直接意味着模型状态可被复用。
- **核心研究问题**：能否在不存储任何循环状态检查点的前提下，实现混合 LLM 中无约束的令牌级前缀复用？

### 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

#### 2.1 核心思想

- 论文的关键洞察是：**线性注意力机制（如 Gated DeltaNet）本质上是对输入前缀的一种结构化、有损压缩**。门控循环更新会逐渐衰减早期输入对当前状态的贡献，因此近期输入的信息在循环状态中占据主导地位。
- 由此推出：**匹配前缀的循环状态，可以由仅重放该前缀的一个短近期后缀来近似**。即“Tail-Replay”（尾部重放）。

#### 2.2 技术细节

- **缓存策略**：只缓存 FA 层的令牌级 KV 对，以及每个 FA 层的输出隐藏状态（FA output hidden），**不保存任何线性注意力的循环状态检查点**。
- **分组结构（Independent Tail-Replay）**：
  - 将混合架构划分为若干组，每组包含一个 FA 层及其之后连续的线性注意力层；
  - 缓存每个 FA 层的输出隐藏状态，确保重放时第一个线性注意力层的输入隐藏状态与原始预填充时完全一致，从而将重放误差限制在组内。
- **重放过程**：
  - 给定缓存命中覆盖前 m 个令牌时，检索对应 FA KV，仅取最近的 k = ⌈rm⌉ 个缓存的 FA 输出隐藏状态作为重放输入（r 为重放比率）；
  - 从零初始化状态 Ŝₘ₋ₖ = 0 开始，对最近 k 个令牌应用 Gated DeltaNet 的循环更新；
  - 每组独立重放，最终得到匹配前缀边界处的循环状态近似值 Ŝₘ。
- **Gated DeltaNet 更新公式**：
  - Sᵢ = TᵢSᵢ₋₁ + βᵢvᵢkᵢ⊤，其中 Tᵢ = αᵢ(I − βᵢkᵢkᵢ⊤)，αᵢ ∈ (0,1] 是学习得到的门控因子，βᵢ 为更新门，kᵢ、vᵢ 分别为第 i 个令牌的键向量和值向量。
- **两个效率优化**：
  1. **尾部 FFN 跳过（tail-FFN skip）**：重放组时，无需计算组末的 FFN 输出，因为下一组从下一个 FA 层的缓存隐藏状态出发，因此重放时只计算线性注意力块的循环状态更新，节省计算量；
  2. **传输/重放重叠（transfer/replay overlap）**：FA KV 从主机内存到设备的传输与重放计算相互独立，可在单独复制流上并发执行，仅在查询前向计算前同步，从而隐藏大部分数据移动开销。

#### 2.3 算法流程

- 步骤 1：收到请求，检测与已缓存前缀的共享令牌前缀；
- 步骤 2：检索匹配前缀的 FA KV 缓存和 FA 输出隐藏状态；
- 步骤 3：从匹配边界向前取最近 k 个令牌的 FA 输出隐藏状态，每组独立从零状态开始重放，重建线性注意力状态；
- 步骤 4：使用检索到的 FA KV 与重建的线性状态继续处理未匹配的后缀令牌。

### 3. 实验设计：数据集、benchmark、对比方法

### 6. 论文的主要结论与发现

- **质量保留**：
  - 在 LongBench 上，5% 重放预算保留 92.8–98.9% 的预填充质量，10% 重放预算保留 93.9–98.1%；
  - 在 RULER 上，5% 重放预算保留 93.1–99.9%，10% 重放预算保留 96.7–99.9%；
  - Zero-only 基线显示不重建状态会带来显著质量下降，直接验证了状态重建的必要性和 Tail-Replay 的有效性。
- **服务效率**：
  - TTFT 加速比随匹配前缀长度增大而显著增长；在 32K 匹配前缀下，5% 重放 + 重叠优化的加速比达到 9.1–14.3×，远高于 8K 下的 2.5–5.7×；
  - 重叠优化相比串行 H2D 传输，在 32K 下进一步降低 TTFT 18–42%；
  - 增加重放预算（10%）在短上下文下影响不大，但在 32K 时长上下文中重放成为主要成本项，会明显提高 TTFT。
- **核心结论**：Tail-Replay 利用线性注意力的有损压缩/渐进遗忘特性，以极小重放代价在混合 LLM 中实现了无检查点、无边界约束的令牌级前缀复用。

### 7. 优点

- **问题洞察深刻、角度新颖**：将线性注意力机制正式理解为“输入前缀的结构化有损压缩”，从而把状态重建问题转化为短后缀重放问题，设计思路优雅、直觉性强；
- **方法简单有效**：仅缓存 FA KV 和 FA 输出隐藏状态，完全省去循环状态检查点的存储与管理，架构层面的复杂度显著降低；
- **设计具有良好的可扩展原理**：分组独立重放将误差控制在组内，缓存 FA 层输出隐藏状态以保证输入一致性的思路，理论上可推广到其他混合架构；
- **两项优化务实有效**：FFN 跳过和传输/重放重叠都是工程上立即可用的手段，显著增强了方法的端到端实用性；
- **实验设计有对照意识**：Zero-only 基线有效隔离了重放的作用，使实验结果更具说服力；质量与效率的双维评测也比较完整。

### 8. 不足与局限

- **适用范围受限于线性注意力种类**：方法的成立依赖“门控循环更新逐步衰减早期输入”的性质。论文只在 Gated DeltaNet 上验证过，对 Mamba-style（无显式门控衰减）、Lightning Attention 等其他线性注意力机制是否同样适用尚未验证；
- **重放输入的质量依赖 FA 输出隐藏状态的缓存**：这增加了缓存内存开销；虽然省去了循环状态检查点，但需要额外缓存所有 FA 层的输出隐藏状态，论文未对比这一新增存储开销与传统 checkpoint 方案的存储开销差异；
- **重放比率是敏感超参数**：质量效率之间存在明显权衡曲线，论文只在 5% 和 10% 两个离散档位上测试，未提供自适应重放比率或质量-延迟的帕累托前沿分析；
- **效率评测场景单一**：只测试了 narrativeqa 一种共享前缀场景，未覆盖 RAG、多轮对话、多 Agent 协作等更常见的缓存命中场景；未报告批处理（batch serving）场景下的吞吐表现，而实际生产环境通常批量推理；
- **未报告资源的完整信息**：未披露实验用 GPU 数量、时间成本、缓存命中率、内存占用、端到端吞吐等生产级指标，对系统部署的实际参考价值有限。
