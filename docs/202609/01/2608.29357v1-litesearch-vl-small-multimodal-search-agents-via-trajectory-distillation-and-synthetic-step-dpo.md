## 摘要
多模态搜索智能体通过交错进行图像理解、网络检索、工具使用和证据综合来回答视觉问题。现有较强系统往往依赖两种昂贵模式：一种是GPT-5和Gemini等专有前沿模型，另一种是使用大量智能体数据和强化学习训练的大型开源视觉-语言骨干网络。我们提出了一个不同的问题：当已发布的智能体轨迹在单节点预算下被蒸馏到更小的骨干网络时，究竟传递了什么？我们通过LiteSearch-VL对此进行研究，这是一种针对Qwen3-VL-2B和Qwen3-VL-4B的低计算量方案，仅使用已发布的OpenSearch-VL轨迹、参数高效的LoRA适配器以及合成步骤级偏好：在GPT-5生成的硬负样本上进行DPO，针对五个局部失败模式（过早回答、错误工具、弱查询、重复查询、忽略图像）。在SimpleVQA、FVQA、LiveVQA和VDR-Bench-testmini上进行的12,400次GPT-5评判的滚动评估中，主要影响是行为层面的而非统一的准确率提升：全轨迹监督微调传递了智能体契约，使2B模型从几乎从不输出可用答案（1,240次滚动中1,237次为无回答）提升到28.4%的宏Pass@1，与现成的4B基线（25.6%）相当或略优。合成偏好学习和紧凑工具蒸馏起到的是优化作用而非阶段转变（最佳4B配置：30.8%的宏Pass@1）。最后，一项受控的VDR步骤预算消融实验表明，额外的搜索轮次将弃答转化为错误实体错误而非正确答案，从而确定答案验证（而非搜索深度）是小型多模态智能体的下一个瓶颈。

## Abstract
Multimodal search agents answer visual questions by interleaving image understanding, web retrieval, tool use, and evidence synthesis. Strong systems exist, but in two expensive regimes: proprietary frontier models such as GPT-5 and Gemini, or large open vision-language backbones trained with substantial agentic data and reinforcement learning. We ask a different question: when released agent trajectories are distilled into much smaller backbones under a single-node budget, what is actually transferred? We study this with LiteSearch-VL, a low-compute recipe for Qwen3-VL-2B and Qwen3-VL-4B that uses only released OpenSearch-VL trajectories, parameter-efficient LoRA adapters, and synthetic step-level preferences: DPO on GPT-5-generated hard negatives targeting five local failure modes (premature answer, wrong tool, weak query, repeated query, ignored image). Across 12,400 GPT-5-judged rollouts on SimpleVQA, FVQA, LiveVQA, and VDR-Bench-testmini, the dominant effect is behavioral rather than a uniform accuracy lift: full-trajectory supervised fine-tuning transfers the agent contract, taking the 2B model from almost never emitting a usable answer (1,237/1,240 no_answer rollouts) to 28.4% macro Pass@1, matching or slightly exceeding the off-the-shelf 4B base (25.6%). Synthetic preference learning and compact tool distillation act as refinements rather than phase transitions (best 4B configuration: 30.8% macro Pass@1). Finally, a controlled VDR step-budget ablation shows that extra search turns convert abstentions into wrong_entity errors rather than correct answers, identifying answer verification, not search depth, as the next bottleneck for small multimodal agents.

## 2. 提出的方法论

### 核心思想
采用**三阶段低计算量训练流水线**：轨迹蒸馏（SFT）→ 工具面精简（Tool Distillation）→ 合成步骤级偏好优化（Synthetic Step-DPO）。核心假设是：已发布的教师轨迹足以教会小模型"智能体行为契约"，而偏好优化只需要作为增量优化手段。

### 技术细节与关键公式

**① Agent 形式化框架**
- 给定图像 $I_0$ 和问题 $q$，策略 $\pi_\theta$ 在每一步基于历史 $h_\ell$ 输出 $a_\ell = [z_\ell, c_\ell]$（思维链 + 工具调用或最终回答）。
- 环境返回观察 $o_\ell$ 追加至历史，循环直至 `<response>` 或步数耗尽。

**② Stage A：全轨迹监督蒸馏**
- 数据：OpenSearch-VL 发布的 SearchVL-SFT-36k 语料（36,592 条轨迹，7 个领域）。
- 预处理：压缩观察（截断至 4,000 字符）、分层划分（36,092/500 train/val）、步骤展开（133,439 条步骤级样本，3.65× 扩展）。
- 训练：Qwen3-VL-2B/4B + LoRA（rank=16, α=32），视觉塔冻结、投影层可训练，单节点 8 GPU + DeepSpeed ZeRO-3，单 epoch，有效批次 64，564 优化步。
- 损失函数：
  $$L_{SFT}(\theta) = -\sum_{\ell=0}^{L} [\log P_\theta(z_\ell | h_\ell) + \log P_\theta(c_\ell | h_\ell, z_\ell)]$$
  （观察 token 不参与损失计算）

**③ Stage B：三工具蒸馏 SFT**
- 将七工具动作空间缩减为 `image_search`、`text_search`、`crop` 三个工具；
- 重写系统提示词与工具 schema，剔除使用了禁用工具的轨迹（移除 2,849 条，剩余 33,743 条）；
- 训练超参与 Stage A 基本一致，仅上下文长度从 8,192 缩短到 6,144。

**④ Stage C：合成步骤级 DPO**
- 利用步骤展开产生的 ~133K 教师决策点，让 GPT-5 针对**五种可解释失败模式**合成硬负样本：过早回答（premature answer）、错误工具（wrong tool）、弱查询（weak query）、重复查询（repeated query）、忽略图像（ignored image）。
- 程序化验证器（五重检查：格式、模式结构规则、答案泄漏、元语言泄漏、图像引用合法性）过滤，经提示词迭代后审计问题率从 54% 降至 0%。
- 最终获得 324,121 个偏好对，过滤长度后保留 ~234K 训练对。
- DPO 损失：
  $$L_{DPO}(\theta) = -\mathbb{E}_{(h, a^+, a^-)} \log \sigma\left(\beta \log \frac{\pi_\theta(a^+ | h)}{\pi_{ref}(a^+ | h)} - \beta \log \frac{\pi_\theta(a^- | h)}{\pi_{ref}(a^- | h)}\right)$$
- 超参数：β=0.3，学习率 1e-6（标准配方 β=0.1、LR=5e-6 会导致 2B 模型早期崩溃）。

## 6. 主要结论与发现

1. **SFT 传递的是"智能体契约"而非单纯的事实搜索能力**：2B 基线在 1,240 题中 1,237 次无可用回答（0.1% Pass@1），全轨迹 SFT 后降至 514 次并达 28.4% Pass@1，在 FVQA、SimpleVQA、LiveVQA 上反超 4B 基线。4B 的提升仅 +3.5 点，说明 4B 基线已部分具备契约能力。

2. **合成步骤级 DPO 是"优化"而非"阶段转变"**：2B +1.0 点、4B +1.7 点（最大单点增益在 4B FVQA：+8.5 点），但置信区间重叠，LiveVQA 上 4B 反而 -2.8 点。证据支持 SFT 为主、DPO 为辅助的定位。

3. **步骤级 SFT 改变终止行为权衡**：2B 上 Step-SFT 比全轨迹 SFT 低 1.5 点且 no_answer 更多（514→780）；4B 上反而 +1.0 点。小模型需要完整轨迹监督才能内化完整契约。

4. **紧凑工具面不必然更易学**：3-tool SFT 在 2B 上显著更差（-9.0 点），在 4B 上几乎无损（-1.8 点），且在 FVQA 上取得最佳成绩（71.2%）。工具面设计应与模型容量匹配。

5. **VDR 瓶颈是答案验证而非搜索深度**：步数从 5 增至 8 后 no_answer 减少 33-50%，但 Pass@1 几乎不变——多出来的滚动主要变成 wrong_entity 错误。小模型缺少"用检索证据交叉验证答案"的能力。

## 7. 优点

- **极低计算门槛**：单节点八卡完成 2B/4B 智能体的完整训练与评估，与 OpenSearch-VL 的 256+64 张 H20 GPU 形成鲜明对比，大幅降低复现成本。
- **清晰的问题切分**：将"能否传递智能体契约"与"能否提升搜索能力"分离，通过三阶段消融逐层归因，结论干净有力。
- **合成偏好数据的工程创新**：用 GPT-5 按五种可解释失败模式生成硬负样本 + 程序化验证器过滤，在无在线 RL 的成本下获得步骤级偏好信号，问题率可从 54% 降至 0%。
- **可复现性承诺完整**：释放训练配置、agent 代码、数据管道、评判提示词、搜索缓存 schema。
- **深入定性分析**：附录 K 的五个案例研究（含轨迹逐行对比）直观展示了 SFT/DPO 对行为的具体改变，增强了定量结论的可信度。
- **对失败模式的关注**：不只报告 Pass@1，还系统分析 no_answer、wrong_entity、hallucinated 等错误类型分布，揭示性能瓶颈的真实来源。

## 8. 不足与局限

- **评判者偏差风险**：主评估完全依赖 GPT-5 评判短答案；作者坦诚所有 12,400 条评判 confidence 全为 2（"明显"档），自评置信度无判别信号；建议人工抽检但未提供人工验证的子集结果。
- **基准样本量偏小**：FVQA 仅 59 题、LiveVQA 181 题，部分结论（如 4B FVQA 的 +8.5 点）对应绝对量不到 10 题，统计强度有限。
- **VDR 覆盖不足**：所有模型在 VDR 上 Pass@1 ≤2.6%（5 步设置下），该基准对 2B/4B 模型明显过难，将其作为"验证瓶颈"的证据基础较弱——也可能只是模型整体能力不足。
- **未与更大模型对比**：研究有意不比较 OpenSearch-VL 8B/30B/32B，因此无法刻画小型模型与大模型的差距函数，也无法判断 28.4%/30.8% 的性能水平在绝对意义上的优劣。
- **合成 DPO 的分布偏移**：GPT-5 生成的负样本可能无法完全模拟真实小模型的犯错分布；作者也承认在线策略（on-policy）偏好是自然下一步，但未在本文解决。
- **工具集评估受限**：3-tool 蒸馏变体仅被评估于短答案基准，未在多跳需要 OCR/透视校正的复杂场景检验其覆盖率损失。
- **LoRA 架构限制**：仅训练 LoRA 适配器（视觉塔完全冻结），可能限制了小模型在多模态感知层面的适应能力。
- **伦理考虑**：部署低成本智能体的可及性增加可能带来"自信的错误答案"风险（VDR 消融已显示额外搜索会把弃答转为自信的错误实体），论文建议部署时不应视为已验证答案。
