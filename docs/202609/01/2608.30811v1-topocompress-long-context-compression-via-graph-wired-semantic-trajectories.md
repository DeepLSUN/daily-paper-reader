## 摘要
长上下文压缩对于降低大型语言模型推理的成本和延迟至关重要。然而，现有方法可能会割裂重要证据，需要额外训练或对齐，且通常依赖目标模型才能实现有效压缩。我们提出了TopoCompress，一个无需训练且与模型无关的框架，通过选择连贯的语义片段来压缩长上下文。TopoCompress首先利用稠密和词法查询相关性以及语义加速对每个片段进行评分。然后，它构建一个混合图，根据语义相似性和序列邻接性连接片段，并在图上传播查询引导的相关性分数。在五个长上下文任务——HotpotQA、2WikiMQA、MuSiQue、Qasper和MultiFieldQA-en——上，TopoCompress持续优于强压缩基线。值得注意的是，TopoCompress在使用4倍更小的压缩预算时达到与最强基线相当的性能，并且压缩时间比最快基线缩短了1.41倍。

## Abstract
Long-context compression is essential for reducing the cost and latency of large language model inference. However, existing methods can fragment important evidence, require additional training or alignment, and often depend on the target model for effective compression. We introduce TopoCompress, a training-free and model-agnostic framework that compresses long contexts by selecting coherent semantic spans. TopoCompress first scores each span using dense and lexical query relevance together with semantic acceleration. It then constructs a hybrid graph that connects spans based on semantic similarity and sequential adjacency, and propagates the query-guided relevance scores over the graph. Across five long-context tasks-HotpotQA, 2WikiMQA, MuSiQue, Qasper, and MultiFieldQA-en-TopoCompress consistently outperforms strong compression baselines. Notably, TopoCompress achieves performance comparable to the strongest baseline while using a 4x smaller compression budget, and provides a 1.41x smaller compression time over the fastest baseline.

- **步骤二：稠密-词法查询相关性**：使用冻结的 bge-m3 编码器：
  - 稠密相关性：`r_i = max(0, sim(e_i, e_q))`，即跨度与查询的余弦相似度。
  - 词法相关性：`ℓ_i = Σ_{t∈q∩u_i} w_q^t · w_u_i^t`，利用 bge-m3 的稀疏词权重。
  - 查询对齐分数：`g_i = μ·r̂_i + (1−μ)·ℓ̂_i`，μ 控制语义与词法平衡。

- **步骤三：语义加速（Semantic Acceleration）**：对每个内部跨度计算二阶差分 `a_i = 2e_i − e_{i−1} − e_{i+1}`，取其范数 `κ_i = ‖a_i‖₂` 衡量语义轨迹的突变程度。最终初始分数为 `s_i = (1 + λ·κ̂_i)·g_i`，即加速项仅提升已与查询对齐的跨度。

- **步骤四：混合图构建与相关性传播**：
  - 语义边：k 近邻（基于稠密嵌入相似度），权重为 `max(0, sim(e_i, e_j))`。
  - 序列边：同一文档相邻跨度，权重为 1。
  - 合并：`W = α·W_sem + β·W_seq`，行归一化得到转移矩阵 P。
  - 个性化传播：`s^(m+1) = (1−η)·s + η·P^T·s^(m)`，η 为阻尼因子，重启项保持与原始查询信号锚定。迭代至收敛得到最终分数 ṡ。

- **步骤五：冗余感知选择**：贪心选择时对语义相似候选施加惩罚：`u* = arg max_{u_i∈R} [ṡ_i − δ·max_{u_j∈A} sim(e_i, e_j)]`，直到满足 token 预算 K，最后按原始顺序恢复跨度。

- **性能优势**：TopoCompress 在所有压缩预算和全部三个目标模型上持续优于所有基线。K=500 时，比最强基线 LongLLMLingua 平均 F1 分别高出 8.15（GPT-5-mini）、8.44（Llama-3.1-8B）、7.21（Qwen3-8B）个点。
- **预算效率**：TopoCompress 在 K=500 时的性能（如 GPT-5-mini 上 51.37）与 LongLLMLingua 在 K=2000 时（51.44）相当，即以 **4× 更小预算**达到相同性能。
- **压缩速度**：TopoCompress 是最快的压缩方法（总时长 6:54），比最快的基线 LLMLingua-2（9:43）快 1.41 倍，比 LLMLingua（43:59）和 LongLLMLingua（51:50）快一个数量级。
