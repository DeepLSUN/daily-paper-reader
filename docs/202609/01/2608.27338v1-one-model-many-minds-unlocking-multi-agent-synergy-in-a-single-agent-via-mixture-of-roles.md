## 摘要
将大型语言模型（LLM）向不同能力进行专门化支撑了从个性化助手到多智能体系统（MAS）等一系列成功应用。单智能体范式依赖预定义的角色或引导向量来实现专门化，但它们强加了一种固定的专门化，无法适应多样化的查询。相反，MAS通过编排具有不同基于文本角色的智能体来实现动态多视角问题求解，但融合这些专门化需要多轮交互，这会增加上下文长度和推理成本。为了解决这些局限性，我们提出了角色混合（Mixture of Roles, MoRe），它能够自适应地将多种专门化组合成一个引导向量，用于单轮推理。具体而言，MoRe学习一个多样化的引导向量码本，每个向量编码一个潜在角色。一个查询感知的路由器动态地将码本融合成一个包含多个角色的引导向量。通过用组合后的向量引导主干LLM，MoRe在单智能体、单轮推理过程中实现了多视角专门化。所提出的MoRe可以通过三阶段SFT课程和GRPO后训练高效训练，而主干LLM保持冻结。在推理和个性基准上的实验表明，MoRe平均比单智能体基线高出2.2%，并且在与MAS性能相当的同时，将令牌成本降低了20倍。

## Abstract
Specializing Large Language Models (LLMs) toward distinct abilities underpins successes ranging from personalized assistants to multi-agent systems (MAS). Single-agent paradigms rely on pre-defined personas or steering vectors to induce specialization, yet they impose a single fixed specialization that fails to adapt to diverse queries. Conversely, MAS achieves dynamic multi-perspective problem solving by orchestrating agents with distinct text-based roles, but fusing these specializations requires multi-turn interactions that inflate context length and inference cost. To address these limitations, we propose Mixture of Roles (MoRe), which adaptively composes multiple specializations into a single steering vector for single-turn inference. Specifically, MoRe learns a diversified codeboox of steering vectors, each of which encodes a latent role. A query-aware router dynamically fuses the codebook into a steering vector that encompasses multiple roles. By steering the backbone LLM with the composed vector, MoRe enables multi-perspective specialization in a single-agent, single-turn inference process. The proposed MoRe can be efficiently trained via a three-stage SFT curriculum and GRPO post-training, while the backbone LLM remains frozen. Experiments across reasoning and personality benchmarks show that MoRe outperforms single-agent baselines by 2.2% on average, and achieves performance on par with MAS while reducing token cost by 20x.

## 2. 论文提出的方法论

### 2.1 核心思想

- 用一个**可学习码本（codebook）** 存储一组候选转向向量，每个向量代表一种潜在角色。
- 设计一个**查询感知路由器（query-aware router）**，针对每个输入查询选择并组合多个候选向量，生成一个查询专属的组合转向向量。
- 将该组合向量注入骨干 LLM 的中间层，对最后一个 prompt token 的隐藏状态进行调整，从而在单轮推理中诱导多视角行为。

### 2.2 关键技术细节

- **转向操作**：
  ```
  h̃_t^(ℓ*) = h_t^(ℓ*) + α · (‖h_t^(ℓ*)‖₂ / ‖v_Q‖₂) · v_Q
  ```
  其中 ℓ* = ⌊L/2⌋（中间层），t = 最后一个 prompt token，α 为转向强度。

- **组合向量生成**：
  ```
  v_Q = Σ_{n∈TopK} w_n · e_n，w_n = softmax(g)_n
  ```
  路由 logits g 通过以下方式得到：将专家探针矩阵 U 作为 query，输入 token 嵌入 X 作为 key/value，做多头交叉注意力，再经 MLP 映射为 N 维 logits，取 Top-K 做 softmax 加权求和。

- **码本初始化**：前 M 个条目用 CAA（对比激活提取）得到的向量初始化，其余条目用这些向量的凸组合初始化，以保证初始方向位于有行为意义的区域。

- **训练流程**：
  1. **三阶段 SFT 课程**：
     - 阶段 1：只优化码本，每个 query 随机采样单个候选向量，用下一个 token 预测损失训练。
     - 阶段 2：冻结码本，训练路由器，使用 Top-K 路由和负载均衡损失（`L_lb = N·Σ_n f_n·p_n`）防止路由崩溃。
     - 阶段 3：联合优化码本与路由器，让两者协同适应。
  2. **GRPO 后训练**：
     - 将骨干 LLM 视为黑盒环境，**动作空间定义为角色子集空间**（所有无序 Top-K 子集）。
     - 路由策略 `π(S|Q)` 通过带温度的 softmax 无放回采样 K 个专家，并考虑所有排列的边际概率。
     - 用可验证奖励（多选、自由问答、长链推理分别设计软奖励）对样本分组，计算组内优势，用 clipped surrogate loss 更新路由器。
     - 由于策略完全由轻量路由器决定，奖励可以精确归因到路由动作，并且 rollout 不需要梯度跟踪，内存和计算开销小。

## 6. 论文的主要结论与发现

- **单智能体专门化能提升性能**，但不同角色擅长不同任务，没有单一角色普遍最优（例如 mathematician 强于数学，但弱于 TriviaQA）。
- **MoRe 在推理基准上显著优于单智能体基线**：在两个骨干上分别比最强单智能体基线 ActAdd 平均高 0.96 和 0.97 个百分点；长推理链任务（MATH、GSM8K）增益更明显。
- **MoRe 与 MAS 性能相当，但 token 开销仅为后者的约 1/20**：单轮推理、单次模型调用即可达到多轮互动效果，位于性能-效率帕累托前沿。
- **人格基准上 MoRe 全面第一**，且跨模型鲁棒性最好（在 Llama 和 Qwen 上均排名第 1），标准差低，说明它不仅能控制任务角色，也能稳定诱导人格特质。
- **路由器学到了有意义且可迁移的角色组合**：数学数据集高权重使用“mathematician”初始化专家，MedQA 组合 teacher/skeptic/doctor，MMLU 则更分散。
- **码本方向具有多样性和功能性分化**：不同候选向量形成紧凑聚类，余弦相似度低，说明端到端训练自然鼓励多样性。
- **消融表明**：学习码本比学习路由更重要，两者联合效果最佳；转向位置以“最后一个 prompt token”最优，单点干预优于全局扰动。

## 7. 优点

## 8. 不足与局限

- **无法用于黑盒 API 模型**：MoRe 需要访问内部 hidden states 做激活转向，因此不能直接应用于仅有输入输出接口的闭源大模型。
- **潜在角色可解释性有限**：码本向量是隐式学习的方向，初始来自文本角色，但训练后语义不完全透明；对“每个专家到底对应什么能力”解释不足。

- **查询级静态人格**：当前是查询级固定组合，无法在长对话中根据语境动态调整角色或人格，限制了交互式场景的适应性。
