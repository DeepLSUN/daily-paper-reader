## 摘要
自主大语言模型（LLM）智能体在复杂、长周期任务中日益面临可靠性、上下文消耗和执行稳定性瓶颈。虽然整体式提示工程和无状态工具调用范式难以扩展，该领域正迅速向“智能体技能”（agentic skills）收敛：模块化过程抽象将执行知识外部化为可重用、可执行且可移植的工件。本文为智能体技能生态系统建立了统一的系统基础和参考架构。我们将技能形式化为外部化过程知识，连接高层认知规划与确定性执行环境，并系统性地描述了跨九个阶段生命周期的架构：自主发现、编写与表示格式、记忆存储、动态检索与路由、组合与编排、执行与修复、终身适应、实证评估以及安全治理。我们进一步审视了市场动态、公共注册表以及新兴对抗性威胁向量，连同运行时验证和防御机制。最后，我们对跨软件工程、操作系统导航、具身机器人和科学发现的系统实现进行分类，同时强调持续学习和基准现实性方面的关键开放挑战。这项工作将智能体技能确立为构建可扩展、稳健且可验证的自主语言智能体的基础范式。

## Abstract
Autonomous large language model (LLM) agents increasingly face reliability, context consumption, and execution stability bottlenecks when deployed on complex, long-horizon tasks. While monolithic prompt engineering and stateless tool-calling paradigms struggle to scale, the field is rapidly converging toward \emph{agentic skills}: modular procedural abstractions that externalize execution knowledge into reusable, executable, and portable artifacts. This paper establishes a unified systems foundation and reference architecture for the agentic skills ecosystem. We formalize skills as externalized procedural knowledge bridging high-level cognitive planning with deterministic execution environments, and systematically delineate the architecture across a nine-stage lifecycle: autonomous discovery, authoring and representation formats, memory storage, dynamic retrieval and routing, composition and orchestration, execution and repair, lifelong adaptation, empirical evaluation, and security governance. We further examine marketplace dynamics, public registries, and emerging adversarial threat vectors, alongside runtime verification and defense mechanisms. Finally, we categorize system implementations across software engineering, operating system navigation, embodied robotics, and scientific discovery, while highlighting critical open challenges in continual learning and benchmark realism. This work establishes agentic skills as a foundational paradigm for building scalable, robust, and verifiable autonomous language agents.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：自主LLM智能体在复杂、长周期任务中面临三大关键瓶颈：
  - **可靠性瓶颈**：随着任务跨度（horizon）拉长，智能体性能急剧下降。失败往往发生在早期步骤且难以恢复，导致"无恢复机制"（no-recovery regime），智能体陷入循环或耗尽递归限制。
  - **上下文消耗瓶颈**：将过程性知识直接注入上下文窗口会产生随指令集增长而膨胀的Token成本，且缺乏按需加载的机制。
  - **执行稳定性瓶颈**：微调将过程性知识写入权重，但智能体所需的例程与快速变化的工具、API和组织约定紧密耦合，重训练周期无法跟上变化速度。
- **关键洞察**：智能体即使成功完成任务，过程性知识仍被锁存在会话结束时被丢弃的转录中，无法跨会话积累。
- **提出方案**：**智能体技能（Agentic Skills）**——将执行知识外部化为可重用、可执行、可移植的模块化程序工件，将高层认知规划与确定性执行解耦。

### 2.1 技能的形式化定义

- 技能被形式化为六元组：**s = (A, I, C, T, π, E)**

  - **I**：过程性指令或引导（procedural instructions/guidance）
  - **C**：适用性约束与环境前置条件（applicability constraints）
  - **T**：可访问的工具和接口（tools and interfaces）
  - **π**：执行策略或过程控制流（execution policy/procedural control flow）
  - **E**：预期的状态转换或后置条件效果（intended state transitions）

### 2.2 三项核心判定标准（Triad Membership Criteria）

1. **封装模块化（Encapsulated Modularity）**：技能是离散的、外部化的资产，可独立编写、版本化、验证和更新，无需修改模型权重或全局harness代码。
2. **晚期绑定动态调用（Late-Binding Dynamic Invocation）**：技能外部化并按需加载，通过激活函数 A(xt, g) → {0, 1} 基于当前状态和活动目标动态评估。
3. **过程性状态转换（Procedural State Transformation）**：技能编码可重用的操作知识，通过策略π指示如何执行任务并处理错误，而非记录声明性事实或日志历史。

## 6. 主要结论与发现

1. **技能是唯一结合持久性、外部执行、运行时组合性和无需重训练可修改性的抽象**（对比系统提示、情景记忆、工作流、工具）。
2. **可验证性与可移植性呈单调权衡关系**：提高预执行可验证性必然降低跨平台可移植性，且所有格式均未解决自然语言指令的预验证问题，这是持久的安全盲点。
3. **环境反馈带宽决定技能边际效用**：在高反馈环境中（如CLI shell返回即时stderr），技能增益趋零；这为"何时使用技能"提供了理论边界。
4. **技能外部化解决上下文消耗**：将公式化过程记忆从附加式会话历史中解耦，实现O(1)活动提示足迹和O(T)线性累计复杂度。
5. **安全威胁遍布全生命周期**：从注册表准入到运行时执行到进化阶段，漏洞跨越全部五个生命周期阶段，需要静态审计、运行时防护和市场治理的联动。
6. **技能价值在野外条件下大幅退化**：开放检索噪声、元数据歧义和描述-实现差距显著削弱了技能的真实效用。
7. **共同进化面临漂移风险**：策略与技能库的无监督共同适应可能导致脆弱的依赖关系和灾难性回归。

- **概念密度高、工程落地鸿沟大**：六元组形式化虽精确，但从形式定义到实际实现之间仍存在较大距离；九阶段生命周期内部各阶段之间的接口协议、数据交换格式与抽象边界未给出具体建议，不利于工程团队直接照搬实施。
- **评估维度缺乏优先级与权衡讨论**：七个评估维度被并列提出，但实际场景中各维度常相互冲突（如Token经济性与安全审计开销、可验证性与可移植性），论文只揭示了后者的单调权衡，未系统讨论其余维度间的取舍策略。
- **社会技术层面讨论偏薄**：虽然提出了市场治理、声誉系统等概念，但对激励机制设计、去中心化信任基础设施、标准制定流程与法律合规（如技能版权、数据许可）等层面的探讨不够深入。
- **安全评估偏重标准化对抗集**：安全分析以构造好的对抗攻击数据集为主，对真实攻击者的自适应行为、跨阶段组合攻击链（如"投毒→触发→横向移动"）的端到端模拟不足，防御效果的真实上限仍不明确。
- **语言与生态偏向**：所讨论技能几乎均为英文编写，代码实现绑定Python/JavaScript生态；对低资源语言、异构运行时环境（如嵌入式、浏览器沙箱）的适用性与泛化能力存疑。

## 9. 适用场景与建议阅读对象

- **系统架构师与平台工程师**：可将九阶段生命周期作为设计企业级智能体平台的蓝图，按阶段确定基础组件、接口与验收标准。
- **安全研究团队**：可参考其五维威胁分析框架（威胁类别、目标组件、注入表面、生命周期阶段、妥协影响）与三层防御体系，构建技能的准入审计、运行时守护与供应链治理机制。
- **LLM应用开发者**：可借鉴两阶段检索-路由管道、记忆更新算子和组合编排策略，改进现有智能体在长周期、多工具任务中的可靠性和Token经济性。
- **学术研究人员**：可从论文识别的六个开放挑战（跨模型移植性、超大规模路由、图编译恢复、零信任安全、共同进化漂移、基准现实性）中直接提炼研究选题。
- **不宜读者**：追求具体算法实现细节的工程师、希望直接获得可部署代码的实践者、以及偏好短篇实证论文的读者，可能难以从中获得直接可操作的价值。

## 10. 总体评价

本文是智能体技能领域一份里程碑式的系统化综述。其核心价值不在于具体的算法创新，而在于将快速膨胀、高度碎片化的研究文献整合为统一的概念框架与生命周期架构，为领域提供了共同语言——六元组定义、三项成员判定标准、九阶段生命周期、五维安全分析——这些术语与框架极有可能成为后续研究的标准参照。论文最深刻之处在于揭示了技能作为"系统组件"与"安全边界"的双重身份：它既是提升智能体自主能力的手段，又是控制能力滥用的边界单元，这双重属性在当前研究中尚未被充分调和。总体而言，论文适合作为该领域的权威入门指南与研究路线图；但其各阶段的设计主张仍需读者结合具体场景进行实证检验，方能完成从架构蓝图到工程现实的跨越。
