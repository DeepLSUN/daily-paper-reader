## 摘要
键值（KV）缓存是长上下文大型语言模型（LLM）推理中主要的显存瓶颈，其大小随上下文长度线性增长。我们表明，在分数位网格上的均匀KV量化并不能优雅地退化：在预设的多种子统计协议下，使用仿射量化器的Llama-3.1-8B-Instruct在低至2.322代码位/值时与FP16 KV在统计上无差异，并在2.0位时发生崩溃——这一质量悬崖位于(2.0, 2.322]区间，在生成时量化和多轮对话中重现，并迁移至Mistral-7B。该悬崖重新定义了重要性感知的混合精度：在悬崖之上，八种模型内部重要性指标在统计上可互换，因此混合的好处在于网格插值，达到均匀量化无法实现的平均精度。SemKV保留每个令牌，根据模型内部得分对令牌进行排序，并分配两个相邻的悬崖以上精度，实现了实测6.0倍的存储缩减，且与完整KV（n=900，三粒种子）相比无统计可检测的质量差异，并优于在1.5倍更大显存预算下进行的FP16令牌剪枝。将仿射基替换为失真优化的量化器（TurboQuant-MSE）在所有测试协议中降低了悬崖，将无可检测损失的工作点提升至7.9倍。方法如下：为目标部署环境测量悬崖，然后在悬崖之上进行插值。

## Abstract
The key-value (KV) cache is the dominant memory bottleneck of long-context large language model (LLM) inference, growing linearly with context length. We show that uniform KV quantization on a fractional-bit grid does not degrade gracefully: under a prespecified multi-seed statistical protocol, Llama-3.1-8B-Instruct with an affine quantizer is statistically indistinguishable from FP16 KV down to 2.322 code bits/value and collapses at 2.0 bits - a quality cliff in (2.0, 2.322] that reappears in generation-time quantization and multi-turn dialogue and transfers to Mistral-7B. The cliff reframes importance-aware mixed precision: above it, eight model-internal importance indicators are statistically interchangeable, so the benefit of mixing is grid interpolation, reaching average precisions uniform quantization cannot realize. SemKV preserves every token, ranks tokens by a model-internal score, and assigns two adjacent above-cliff precisions, achieving a measured 6.0x storage reduction with no statistically detectable quality difference from full KV (n=900, three seeds), and outperforming FP16 token pruning granted a 1.5x larger memory budget. Replacing the affine base with a distortion-optimized quantizer (TurboQuant-MSE) lowers the cliff in every protocol tested, raising the no-detectable-loss operating point to 7.9x. The recipe: measure the cliff for the target deployment setting, then interpolate above it.

# SemKV：面向长上下文LLM推理的语义混合精度KV缓存量化

## 1. 核心问题与研究动机

- **背景**：在长上下文 LLM 推理中，KV 缓存大小随上下文长度线性增长，成为限制 batch size 和上下文预算的主要显存瓶颈。现有解决方案主要有三类：
  - **均匀量化**（KIVI、KVQuant、TurboQuant）：对所有 token 一视同仁地压缩，忽视 token 间差异；
  - **删除/驱逐**（H2O、SnapKV、PyramidKV）：仅保留部分 token，存在移除关键证据的风险；
  - **重要性感知混合精度**（MiKV、QAQ、ZipCache）：保留或高精度化部分 token，但缺乏系统性的精度选择依据。
- **核心观察（论文的出发点）**：均匀 KV 量化在分数位网格（如 \(\log_2 5\approx2.322\)、\(\log_2 6\approx2.585\) bits）上扫描时，质量并非逐步退化，而是在特定区间内发生"悬崖式"崩塌。
  - 具体而言，Llama-3.1-8B-Instruct 搭配仿射量化器时，从 3.0 位直到 2.322 位都与 FP16 KV 统计上无差异，而在 2.0 位时质量急剧崩塌——**质量悬崖位于 (2.0, 2.322] 位区间**。
- **由此提出的核心问题**：既然悬崖之上存在一个"平坦区"（flat regime），且此区间内不同重要性指标统计等价，那么混合精度的真正价值是什么？论文给出的答案：**混合精度的作用是网格插值（grid interpolation）**——均匀量化只能落在离散网格点上（2.322、2.585…），而按重要性比例混合两种相邻的悬崖以上精度，可实现均匀量化无法达到的平均位宽（如 2.39 位），且不产生可检测的质量损失。

## 2. 方法论：SemKV 框架

### 2.1 总体架构

- 输入 prompt 通过 Transformer prefill 阶段生成全精度 KV 缓存 → 计算 token 级语义重要性 → 按重要性排名分配高/低两种精度 → 构建混合精度 KV 缓存用于解码。
- **全 token 保留**：与剪枝方法不同，SemKV 不删除任何 token，只调整每个 token 的量化精度。

### 2.2 语义重要性估计

- 默认指标为**隐藏态 Δ-norm**（最后 m=4 层）：

\[
s_i = \frac{1}{m}\sum_{l=L-m+1}^{L}\left\|h_i^{(l)} - h_i^{(l-1)}\right\|_2
\]

- 将指标视为**可插拔模块**，系统性评估了 8 种模型内部指标，分属四个家族：
  - **隐藏态家族**：delta-norm（默认）、final-layer norm、variance、cosine-delta；
  - **KV 范数家族**：key-norm、value-norm；
  - **logit 家族**：self-information（\(-\log p_\theta(x_i|x_{<i})\)）；
  - **注意力家族**：累积注意力接收量（最接近 H2O 等驱逐启发式）。
- 分数只用于 prompt 内的相对排名，无需归一化或阈值估计，因此所有指标共享同一分配流程。

### 2.3 悬崖映射与精度分配

- **离线悬崖映射**（核心操作规则）：对目标部署配置（模型、基量化器、评估协议、上下文预算构成）进行一次均匀量化扫描，找出质量崩塌边界；然后将 \((b_{\text{high}}, b_{\text{low}})\) 设为悬崖之上的两个相邻网格点。该映射与单个 prompt 无关，但在模型/量化器/协议发生重大变化时需重新验证。
- **两档分配**：对分数排名前 \(r\) 比例的 token 分配 \(b_{\text{high}}\)，其余分配 \(b_{\text{low}}\)。默认配置为 \(b_{\text{high}}=2.585\)，\(b_{\text{low}}=2.322\)，单轮 \(r=25\%\)（平均 2.39 位），多轮含生成 token 时 \(r=35\%\)（平均 2.41 位）。
- **生成 token 的块精确延迟量化**（block-exact deferred quantization）：新生成 token 先以全精度追加并收集分数，每积累 B=64 个 token 后，在块内精确选择 top-\(r\) 比例进行量化；每轮生成结束时的残余块亦然。这避免了对未来分数分布的脆弱近似，且量化误差每块最多半个 token。

### 2.4 存储开销核算

- 非 2 的幂级数通过混合进制打包存储：3 个 5 级码打包为 7 位（每值 2.333 位），5 个 6 级码打包为 13 位（2.600 位）。
- 每行仿射量化器参数（offset+scale）增加 0.25 位/值；每 token 精度标志约 \(<10^{-4}\) 位/值。
- 2.39 位操作点的实际存储为 **2.65 有效位/值，约 6.04 倍压缩**（微基准测量为 6.02–6.04×，与核算一致）。

## 6. 主要结论与发现

1. **质量悬崖的存在与位置**（仿射基）：统一量化在 [2.322, 3.0] 位区间与 FP16 KV 统计不可区分；2.0 位崩塌（\(\Delta=-0.0448, p<10^{-7}\)）。悬崖位置在 prefill、生成 token 量化、多轮对话中一致，并迁移到 Mistral。
2. **悬崖内部不可安全导航**：混合 2.322/2.0 位时，即使保护 75% token 仍显著退化（\(\Delta=-0.0266\)）；且悬崖内部重要性集中保护劣于随机摊开——退化是全方位的，而非局部证据缺失。
3. **悬崖之上的网格插值**：SemKV 在 2.39 平均位下与全 KV 统计不可区分（8 种指标全部 n.s.），实现 **6.0 倍存储压缩**（含元数据）。平坦区内指标选择对质量无影响，应按计算成本选指标（value-norm 最便宜，约 0.2ms/22MiB）。
4. **删除劣于低精度保留**：FP16 keep-25% 剪枝在 1.5 倍更大的内存预算下崩溃（分数 0.063–0.149 vs SemKV 0.438）；随机剪枝与指标剪枝无差异，说明删除本身而非选择质量是失败主因。
5. **生成 token 量化**：2.322 位安全且降低 max-length 终止率；任何含 2.0 位低档的配置都显著退化——低档低于悬崖时无法靠高档混合补偿。
6. **基量化器决定悬崖位置**：TurboQuant-MSE 将悬崖下移一步——prefill/多轮到 (1.585, 2.0]，生成侧到 (1.0, 1.585]；SemKV 在新的网格间隙（2.0/1.585 位、代码 1.9 位）插值，有效 2.025 位/值，与全 KV 不可区分，实现 **7.9 倍压缩**；多轮 floor 缩小 2.5 倍但未消失。
7. **跨模型迁移**：Mistral 上悬崖、插值性质均迁移；但随机选择的混合精度显著退化（\(\Delta=-0.0213\)）——**信息性选择在 Mistral 上是安全混合的必要条件**。
8. **上下文预算影响**：4k 预算下仿射 2.322 位也会退化（\(\Delta=-0.0243\)），SemKV 将损失缓冲一半——悬崖位置依赖上下文构成。
9. **多轮 floor**：全缓存多轮量化在两种基量化器下都存在小的崖上残差（仿射 \(-0.021\)、TurboQuant \(-0.008\)），对高于悬崖的位数不敏感（2.322 与 2.585 位无差异），集中于最依赖先前生成内容的任务（expansion），符合"错误通过对话文本累积"的解释。

## 7. 优点

- **概念清晰且具有通用性**："测量悬崖 → 悬崖之上插值"这一配方将混合精度的作用从模糊的"重要性感知"重新定义为精确的"网格插值"，解释并统一了文献中关于重要性分配有时有效有时无效的矛盾结果。
- **统计协议严谨**：预指定多种子、配对检验、Bonferroni 校正、item 级稳健性检查、同运行锚点复现，使"无统计可检测差异"这一核心声明具有较强可信度。
- **全 token 保留的独特定位**：在删除/驱逐方法主导的 KV 压缩领域，提供了"保留一切、只调精度"的第三种路径，并通过受控对比证明在匹配预算下删除结构本身是失败主因。
- **可插拔指标设计**：8 种指标、四大家族、含随机基线，使"平坦区内指标无关、悬崖之下指标关键"的结论建立在消融而非单点选择上。
- **块精确的生成侧扩展**：deferred block-exact 方案设计精巧，避免了逐 token 决策的脆弱性，并将整个框架扩展到生成 token 和多轮对话。
- **基量化器正交组合**：明确展示 SemKV 与量化器改进（TurboQuant）在轴向上的正交性——Token 轴 vs Channel 轴，两者组合将无损压缩从 6.0× 提升到 7.9×。
- **诚实的局限披露**：对协议分辨率限制、n.s. 不等于零损失、重实现偏差、小样本压力测试等均明确声明。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号、数量、总推理时长，影响复现性评估和实际部署成本判断。

## 8. 不足与局限（续）

- **TurboQuant 为重实现（续）**：原始论文某些细节未公开，重实现不可避免地引入近似。具体而言，离群通道的选择标准、旋转矩阵的共享范围（全局 vs 按头）、以及 MSE 目标下 scale 的初始化策略，均可能与原实现存在细微差异。因此，TurboQuant 对比部分展示的"悬崖下移一步"虽方向可信，但其绝对位宽边界（1.585 位）应谨慎解读为对 TurboQuant 原系统的近似估计，而非精确复现。
- **悬崖映射的离线成本与漂移风险**：SemKV 的精度选择依赖离线均匀量化扫描确定悬崖位置。该扫描需在目标模型、基量化器、评估协议、上下文预算组合上分别进行，虽然与 prompt 无关，但在模型迭代或部署环境变化时需重新执行。论文未报告该扫描的具体算力开销（需扫描 5–6 个位宽 × 多协议），也未讨论模型微调或量化器版本更新后悬崖位置漂移的频率与幅度。
- **上下文预算的敏感性暴露了脆弱性**：论文发现 4k 预算下 2.322 位也会退化（悬崖右移），这意味着悬崖映射的离线结论对部署时的上下文长度构成敏感。实际系统中上下文预算可能动态变化（如不同请求长度混排），单一离线映射可能无法覆盖所有情况。论文对"如何在线自适应调整精度阈值"未给出方案。
- **多轮 floor 的解释缺乏直接消融**："错误通过对话文本累积"是推断性解释，论文未通过中间轮次的分层检查（如第 1 轮 vs 第 5 轮的误差传播路径）、或对生成 token 打分精度的受控扰动来直接验证该机制。
- **部署工程复杂度未充分讨论**：混合精度存储涉及非 2 的幂打包（5 级码、6 级码）、每 token 精度标志、块边界的残余处理。论文给出了存储核算和微基准位宽，但未报告打包/解包的延迟开销、对随机访问（按 token 取 KV）的影响、以及在真实推理引擎（如 vLLM、TensorRT-LLM）中 paged KV 结构下混合精度的实际吞吐表现。理论压缩率与实际端到端加速之间存在未测量的间隙。
- **重要性分数计算的运行时开销只做了微基准**：value-norm 虽最便宜（约 0.2ms/22MiB），但该测量在什么硬件、什么 batch 配置下获得未明示；且分数计算在 prefill 阶段进行，与解码阶段的延迟重叠关系未在端到端延迟数据中体现。
- **缩放范围有限**：最大上下文 7500 token，未验证 32k/128k 等现代长上下文区间；8B 级模型之外未覆盖更大规模（如 70B）或多 MoE 架构。Mistral 迁移实验虽好，但架构多样性仍有限。
- **未与端到端系统级基线对比**：未与已部署的量化 KV 缓存系统（如实际吞吐下 KIVI、KVQuant 的工程实现，或 vLLM FP8 KV 缓存）比较端到端延迟、吞吐、TTFT/TPOT 等系统指标，仅对比了质量指标——这削弱了对"6× 压缩能转化为实际收益"的直接论证。
- **随机基线在 Llama 上的表现**：论文指出 Misral 上随机混合精度显著退化，而 Llama 上随机选择未作同等强调——8 指标消融中未系统包含随机基线在 Llama 上的完整数据，跨模型的随机基线结论仅覆盖 Mistral，可能让"信息性选择必要"的普适性判断略显薄弱（虽然 Llama 的 8 指标+随机数据的部分信息存在于剪枝对照中）。

## 9. 总体评价

SemKV 是一篇**方法概念清晰、统计论证严谨**的 KV 缓存量化论文。其核心贡献不在于提出一个新的重要性指标，而在于重新定义了混合精度量化的作用机理——**从"保护重要 token"转向"在悬崖之上进行网格插值"**。这一重新定义具有解释力和预测力：它解释了为何文献中重要性感知混合精度的效果时好时坏（取决于操作点是否落在悬崖之下），并预测了悬崖位置由基量化器决定、与模型可迁移等可检验事实。

论文最大的亮点是统计协议的严谨性——预指定分析、多种子配对检验、Bonferroni 校正、与 FP16 全缓存锚点的同运行复现——这使得其最核心的声明"与全 KV 统计不可区分"具有可信度，而非常见的"无显著差异"式弱断言。同时，全 token 保留的立场、可插拔的指标评估、块精确的生成侧扩展，都展示了良好的方法工程素养。

主要遗憾在于：端到端系统指标的缺失、上下文预算敏感性的未解决、多轮 floor 的机制解释依据不足，以及算力披露的空白。这些决定了该工作作为"概念验证与机制阐明"的价值高于作为"可直接部署的工程方案"的价值。
