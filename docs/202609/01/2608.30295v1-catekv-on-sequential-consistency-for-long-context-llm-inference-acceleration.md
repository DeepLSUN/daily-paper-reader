## 摘要
大型语言模型（LLM）在处理长上下文任务方面展现了强大的能力，但由于大量的内存需求和推理延迟，处理此类长上下文仍然具有挑战性。在这项工作中，我们发现某些注意力头在其注意力模式中表现出顺序一致性，可以通过基于变异系数的算法持续识别。受这一观察启发，我们提出了CateKV，一种混合KV缓存方法，该方法仅保留一致头的关键令牌信息，从而减少KV缓存大小和计算开销，同时保留自适应头中的大部分KV对以确保高准确性。我们展示了我们算法的独特特性及其与现有加速方法的扩展。在长上下文基准上的综合评估表明，在保持与全注意力相当的准确性的同时，CateKV在单样本输入中将内存使用减少高达$2.72\times$，解码加速$2.18\times$，并在批量场景中将吞吐量提升$3.96\times$。

## Abstract
Large language models (LLMs) have demonstrated strong capabilities in handling long-context tasks, but processing such long contexts remains challenging due to the substantial memory requirements and inference latency. In this work, we discover that certain attention heads exhibit sequential consistency in their attention patterns, which can be persistently identified using a coefficient-of-variation-based algorithm. Inspired by this observation, we propose CateKV, a hybrid KV cache method that retains only critical token information for consistent heads, thereby reducing KV cache size and computational overhead, while preserving the majority of KV pairs in adaptive heads to ensure high accuracy. We show the unique characteristics of our algorithm and its extension with existing acceleration methods. Comprehensive evaluations on long-context benchmarks show that, while maintaining accuracy comparable to full attention, CateKV reduces memory usage by up to $2.72\times$ and accelerates decoding by $2.18\times$ in single-sample inputs, and boosts throughput by $3.96\times$ in batch scenarios.

## 1. 论文的核心问题与整体含义

- **研究动机**：随着大语言模型（LLM）支持越来越长的上下文（如128K甚至1M tokens），推理阶段需要存储和读取全部Key-Value（KV）缓存，导致内存占用和计算延迟急剧增长。例如，Llama-3-8B模型上下文从1K扩展到1M时，推理延迟可增加超过3000倍。
- **核心问题**：如何在保证生成质量的前提下，减少KV缓存占用并加速解码过程，同时兼顾批量推理时的吞吐量。
- **整体含义**：论文发现部分注意力头在预填充（pre-filling）与解码（decoding）阶段表现出“顺序一致性”（sequential consistency）的注意力模式，即始终关注一小部分关键token；而另一些头则表现出动态变化。基于这一现象，提出CateKV混合KV缓存策略，对两类头采用不同保留策略，从而在不明显损失精度的情况下显著降低内存和计算开销。

## 2. 论文提出的方法论

- **核心思想**：
  - 将注意力头分为两类：
    - **一致头（Consistent heads）**：注意力模式在不同解码步骤中稳定，只关注少量关键token。
    - **自适应头（Adaptive heads）**：注意力分布动态变化，需要保留大部分KV对以保证准确性。
  - 利用预填充阶段的信息识别头类型和关键token，指导解码阶段的稀疏化。

- **关键技术细节**：
  - 设置观测窗口（observation window），使用输入末尾部分query token构建观测矩阵 \( A = \text{softmax}(Q[-L_{obs}:,:] K^T / \sqrt{d}) \)。
  - 对观测矩阵进行阈值二值化，统计每个token在窗口内被判定为关键的次数，得到频率向量 \( C \)。
  - 计算变异系数（Coefficient of Variation, CV）作为头类型的判别分数：\( score = \frac{\sqrt{\frac{1}{N}\sum_i (C_i - \mu)^2}}{\mu} \)。
  - 通过参考数据集统计每个头被判定为一致头的频率，得到模型级的固定头类型划分（而非每次推理动态判断）。
  - 对于一致头，仅保留top-k关键token的KV对；对于自适应头，保留大部分KV对（按保留比例 η）。
  - 与检索型方法（如Quest）兼容，可采用分块（chunk）选取以提高效率，并可与DuoAttention、MInference等其他加速方法集成。

- **算法流程（文字说明）**：
  - 预填充阶段：计算注意力得分 → 生成频率向量 → 分块最大值 → 根据头类型选取KV索引并缓存（一致头选少量关键块，自适应头选大部分块）。
  - 解码阶段：一致头直接从缓存中读取固定KV；自适应头可进行检索或全量读取，然后计算注意力输出。
