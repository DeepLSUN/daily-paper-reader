## 摘要
检索增强生成（RAG）提高了大型语言模型（LLM）的事实性，但现有的RAG系统在处理需要自适应检索和中间上下文持续修正的复杂多步推理时往往存在困难。最近的基于强化学习（RL）的智能体RAG方法部分缓解了这一问题，但通常依赖于粗粒度的动作空间和轨迹级奖励，导致奖励分配薄弱，并偏向于短视、刻板的推理模板。为解决这一问题，我们提出了AgenticRag-R1，一种通过记忆堆栈和细粒度动作空间深度融合推理、检索与记忆的强化学习框架，并辅以分层动作感知奖励和信息感知轨迹拒绝策略，以实现有效的长视界学习。在跨越多种骨干模型规模的多跳、开放域和智能体推理基准测试中进行的实验表明，AgenticRag-R1持续优于强基线。此外，AgenticRag-R1学习了更鲁棒、可解释且具有记忆感知的推理行为，突显了细粒度动作建模和信息感知优化对长视界推理的作用。我们的代码以匿名形式发布于 https://github.com/jiangxinke/Harness-RL/tree/AgenticRAG-R1-Whitebox。

## Abstract
Retrieval-Augmented Generation (RAG) improves the factuality of large language models (LLMs), yet existing RAG systems often struggle with complex, multi-step reasoning that requires adaptive retrieval and continuous revision of intermediate contexts. Recent reinforcement learning (RL)-based agentic RAG methods partially alleviate this issue, but typically rely on coarse-grained action spaces and trajectory-level rewards, resulting in weak reward assignment and a bias toward short-horizon, stereotyped reasoning template. To address, we propose AgenticRag-R1, a RL framework that deeply integrates reasoning, retrieval, and memory via a memory stack and fine-grained action space, supported by hierarchical action-aware rewards and an information-aware trajectory rejection strategy to enable effective long-horizon learning. Experiments across a diverse set of multi-hop, open-domain, and agentic reasoning benchmarks, spanning multiple backbone model sizes, demonstrate that AgenticRag-R1 consistently outperforms strong baselines. Moreover, AgenticRag-R1 learns more robust, interpretable, and memory-aware reasoning behaviors, highlighting the effect of fine-grained action modeling and information-aware optimization for long-horizon reasoning. Our code is anonymous available at https://github.com/jiangxinke/Harness-RL/tree/AgenticRAG-R1-Whitebox.

## 1. 论文的核心问题与整体含义

### 研究背景与动机
- **核心痛点**：大语言模型（LLM）在复杂、多步推理任务上表现不佳。现有 RAG（检索增强生成）系统虽然在事实性方面有所提升，但在面对需要**自适应检索**和**中间上下文持续修正**的复杂任务时仍有显著不足。
- **现有方法局限**：作者指出，尽管近年来基于强化学习（RL）的 agentic RAG 方法（如 Search-R1、AEPO、ARPO、Mem1）开辟了新的方向，但普遍存在以下结构性缺陷：
  - **粗粒度动作建模**：动作空间高度简化（如仅 <think> 和 <search>），几乎将推理与检索全过程强制压缩为不可逆的"append-only"记忆模板，无法支持对中间结论的检视、修订或丢弃。
  - **奖励信号稀疏**：仅有轨迹级（trajectory-level）的结果奖励，缺乏对中间动作（检索、推理、记忆操作）贡献的细粒度分解，导致"弱奖励分配"问题。
  - **短视策略偏差**：RL 倾向收敛于低信息量、短视、易复现的推理模板，难以有效探索长视界（long-horizon）的复合认知行为（如计划、回溯、摘要）。
- **阻碍问题**：作者总结为两大挑战：
  - **C1**：如何在多步推理与检索中实现细粒度、记忆感知的动作决策及奖励分配？
  - **C2**：如何让 RL 接触到足够多样、富含信息量的推理与检索 rollout（而不是被低信息轨迹支配）？

### 整体含义
- 论文旨在回答一个深层方法论问题：**"智能体应如何在开放环境中自主管理外部检索与内部记忆状态，通过试错学习长视界推理策略？"** 作者从"环境状态"的视角，将记忆建模为可压栈、可回溯的显式变量，从而打破了传统 Transformer 固定因果上下文的限制，将 RL 的优化从"预测下一个 token"提升到"管理内部知识状态"的层次。

## 2. 论文提出的方法论：核心思想与关键技术

### 总体框架
AgenticRag-R1 由两大核心部件组成：图2给出了整体架构的概览。

### ① 动作建模与栈式记忆（解决 C1）
作者设计了一套基于 LIFO（后进先出）记忆栈的多动作机制。每个栈元素对应一个离散且有语义的推理单元。动作类型包括：

- **<Plan>（push）**：生成并存储子目标、任务分解或高层策略。
- **<Think>（push）**：记录内部推理过程。
- **<Search>（push）**：生成结构化的检索查询，调用外部检索工具。
- **<Backtrack>（pop → push）**：在检测到错误或不一致时，弹出若干顶层内容，恢复先前状态后写入修正后的推理。
- **<Summary>（pop → push）**：将最近若干记忆项压缩为摘要后重新压栈。
- **<Conclusion>（push）**：结束推演，输出候选最终答案。

### 分层奖励机制
奖励分两个层面：

- **结果奖励（Outcome Reward, `r_out`）**：通过将 `<Conclusion>` 中提取的回答与标签对比（离散答案用精确匹配；开放式答案用 F1）得到。
- **过程奖励（Process Reward, `r_proc`）**：仅在动作 token 上计算，又细分为：
  1. **格式奖励**（`r_fmt`）：校验动作标签格式是否规范（如 <Conclusion> 占权重 1.0，其他合法动作占 0.5）。
  2. **检索奖励**（`r_rag`）：以通用奖励模型（GRM）对"查询-检索片段-原问题"三者语义相关性打分。
  3. **记忆奖励**（`r_mem`）：用 GRM 评估 <Backtrack> / <Summary> 操作是否在当前推理语境和记忆状态下合理且有益。
- 每条轨迹设置有进程奖励预算上限（`B_proc`）；超出时比例缩放，避免因动作调用过多导致的奖励欺骗（reward hacking）。
- 检索到的 observation token 被掩蔽（mask），不参与策略梯度更新，防止模型学到直接从检索文本复制。

### ② 信息感知的轨迹拒绝（Information-Aware Trajectories Rejection，解决 C2）
- **批量级 Rollout 集成**：训练中按批次采样 B 个问题，每个问题采样 K 条随机 rollout。
- **输入不确定性估计**：对同一问题 b 的 K 条 rollout 计算奖励均值 μ(b) 与方差 (σ(b))²，方差用于度量该输入在推理/检索过程中的学习信号分散程度。
- **UCB 式评分**：
  ```
  r̃(b,i) = (σ(b))² · r(b,i) + μ(b)
  ```
  该项对"高奖励、且输入本身存在路径多样性"的轨迹做乘法放大；对无信息或退化的轨迹做压制。
- **全局截断**：在 batch × rollout 联合空间上按得分排序，只保留前 p 比例的样本参与优化，其余丢弃；该机制有效解决了**低难度、单次检索类问题在训练中占主导导致长视界策略被忽视**的问题。

### ③ Pop-Based 注意力掩码（技术细节）
- 标准因果注意力保证每个位置只能 attend 到其前面的 token，但无法应对"显式弹出后，信息被从活跃记忆中移除"的场景。作者额外引入 `M_pop` 掩码：已被 <Summary> 压缩或 <Backtrack> 弹出的 token 在后续生成时被禁止直接 attend（只能通过摘要 token 间接访问）。

1. **性能全面领先**：在 In-domain（2Wiki、HotpotQA）与 OOD（Bamboogle、FRAMES、MusiQue、NQ、TriviaQA）上普遍优于当前最强基线（Search-R1、ARPO、ReAct、TC-RAG 等）。例：Qwen2.5-3B 上 2Wiki +3.02%、HotpotQA +6.76%；Qwen2.5-7B 上 Bamboogle +7.17%。

3. **基于语义的过程奖励有效**：用 GRM 评估检索相关与记忆操作合理性可获得额外收益；若换成 ROUGE-L 等启发式奖励，平均性能由 33.55% 回落到 29.40%。
4. **信息感知拒绝带来增益**：相对于低信息轨迹被混入训练，执行全局 UCB 式筛选可稳定提升 3.4%–8.1%；阈值选在 0.6–0.8 时性能最强且保留训练样本足够。
5. **长视界可扩展性**：AgenticRag-R1 在步数上限增大时几乎单调提升（如 2Wiki 由 23.91 在 10 步升至 47.45 在 30 步），而基线 Search-R1 与 TC-RAG 在长步数下波动/下降，说明仅有更多预算还不够，必须有可逆记忆机制才能把预算用于信息增益。
6. **学到的行为倾向更合理**：训练曲线显示模型逐步减少无效检索、更多使用 <Summary> / <Backtrack>，并在收敛时响应更长但更明确，显示出自适应的"推理-记忆-规划"策略。
7. **在泛化设置中依然有效**：医疗 QA（MedQA 87% 答题准确率、92% 格式准确率）、长报告生成（DeepResearch Bench 43.60 RACE / 较高的 Fact 分数）、交互决策（ALFWorld 51.1%、WebShop SR 2.3%）均有提升。

## 7. 优点：方法或实验设计上的亮点

1. **记忆与检索的一体化设计**：将堆栈操作引入了 RL 的动作空间；这使得中间知识状态可被检视、压缩与修正，从根源上减小错误累积。
2. **细粒度、分层奖励**：将传统"结果驱动"升级为"结果 + 过程动作语义"的联合监督，且检索内容 token 被屏蔽，规避了复制粘贴式奖励窃取。过程奖励还带预算上限，能在促进有效探索与钳制冗长思维间取得平衡。
3. **信息感知的优势选择**：与传统每样本独立筛选不同，在 batch-rollout 复合空间采用 UCB 型评分能保留"同输入多路径的差异"，打压低难度样本主导分布的问题。该想法明显是受深度 RL 探索/利用权衡启发的工程迁移。
4. **多维度验证与消融设计**：不仅覆盖多跳与开放域 QA，还扩展到长报告与真实交互场景；奖励消融、单动作消融、阈值搜索、模型尺寸响应曲线等给出较丰实的证据。
5. **理论动机明确**：附录通过简单的梯度推倒说明：outcome-only 奖励会把"正确奖励"平均给中间错误动作并放大其概率，而 Pop 掩码能从因果结构中隔离这类影响，将记忆栈的影响理论化为"奖励分配的结构修正器

## 8. 缺点与潜在风险

### 方法层面的局限

1. **记忆动作粒度的语义依赖较强**：`<Backtrack>` 和 `<Summary>` 动作虽然设计为“弹出/压缩”记忆项，但其实际执行效果严重依赖 LLM 对当前记忆状态的自我感知能力。如果骨干模型无法准确判断“哪一部分推理已经过时”，栈式操作反而可能丢弃有用的中间结论。目前论文中关于记忆操作的粒度（一次弹出多少项、以什么准则决定弹出阈值）仍依赖模型隐式学习，缺乏显式的记忆状态价值函数来指导回溯的时机与深度。

2. **动作空间设计仍偏于“认知层”而非“环境层”**：虽然动作类型比 Search-R1 丰富，但所有动作本质上仍是文本生成的形式（即通过模型生成的 token 来“宣称”做了一个操作）。这种设计依赖模型自身在生成层面的一致性——例如 `<Search>` 后必须保证检索查询格式正确、`<Backtrack>` 后必须保留栈底关键前提等。若骨干模型小（如 1.5B），在格式与语义间容易出现“顾此失彼”的现象，导致过程奖励被大量用在纠正格式错误上，而非真正推动推理深度。

3. **GRM 奖励模型的可靠性未被充分检验**：`r_mem` 与 `r_rag` 完全依赖一个通用奖励模型（GRM）的语义评估。论文并未详细说明该 GRM 的规模、训练数据、在记忆操作合理性上的对齐程度以及误判率。GRM 的“幻觉式奖励”可能对模型策略产生隐性误导——尤其是在 `r_mem` 上，一个“看似合情合理的 Summary”和“真正能帮助后续推理的 Summary”之间的边界是模糊的，而 GRM 未必能捕捉这种差异。

### 优化与训练层面的风险

4. **训练存在潜在的“奖励预算”与“信息拒绝”之间的张力**：一方面，过程奖励设置预算上限以抑制过长的推理链；另一方面，信息感知拒绝偏好高方差、长视界的轨迹——这意味着 RL 实际上被鼓励以“较长但也必须足够有信息量”的方式行动。这种微妙平衡虽然在小规模实验上有效，但在更大模型上是否需要随模型能力提升动态调整预算（而非固定常数）没有说明。

5. **批量内奖励均值的引入可能造成同批输入相互干扰**：`r̃(b,i) = (σ(b))² · r(b,i) + μ(b)` 中，μ(b) 对所有同输入轨迹是一致的，不影响相对排序，但 `(σ(b))²` 对不同输入会产生不同的放大/压缩尺度。这等价于在 batch 内部引入了一种隐式的按输入分配权重，可能导致模型训练的目标在不同 batch 间并不一致（例如一个 batch 中方差普遍很小，则所有轨迹得分被压平，近似平均奖励，探索信号减弱）。

### 评估与外部有效性层面的局限

6. **静态知识库与真实场景之间的鸿沟**：检索语料锁定在 2023 年 11 月维基百科，这意味着训练/评估环境几乎没有时间敏感性问题。真实 agentic 场景中的网页更新、信息冲突、链接失效与权限问题完全未被建模。如果一个系统只在固定真实环境上训练，很难说明其“Backtrack 能力”是对信息冲突的响应，还是仅对语料内噪声的响应。

7. **RL 数据生成成本未完全透明**：训练集虽然最终只含经过筛选的中等规模 QA，但前期为了构建该集合，需要多次使用 TC-RAG 进行 10 次 rollout，这部分的推理开销没有被纳入论文的成本计算（论文只报告了 AgenticRag-R1 自身的 GRPO 训练开销）。对于希望复现的团队，实际总支出比论文报告的 6 小时要多出若干倍。

8. **安全性、偏见与奖励滥用风险几乎没有讨论**：agentic 系统拥有检索、记忆编辑与回溯能力后，若遭遇对抗性提示（prompt injection）或恶意网页信息，模型由于具备 `<Search>` 后自动吞入 web 内容的接口，可能将有毒内容写入记忆栈并在后续推理中反复引用。论文没有给出对这一漏洞的缓解措施分析（例如记忆内容消毒、检索结果的 provenance 校验等）。

## 9. 创新点总结

综合全文，AgenticRag-R1 的贡献可提炼为四点：

1. **首次将可逆的栈式记忆操作纳入 agentic RAG 的动作空间**。不同于此前方法将记忆等同于“对话历史的拼接”，该项工作使模型能显式地在上下文中执行“入栈、出栈、压缩回写”等认知操作，配合 Pop 注意力掩码，在 Transformer 的因果结构之上实现了可控的记忆遗忘与间接索引。

2. **构建了“结果 + 过程 + 记忆”三层奖励的联合优化目标**。这套目标首次将检索相关性和记忆操作的价值从结果奖励中解耦出来，并通过过程预算约束抑制 reward hacking，同时用掩码隔离 observation tokens，为后续 agentic RAG 的奖励工程设计提供了新的范本。

3. **提出 batch × rollout 联合空间的 UCB 型轨迹拒绝机制**。它有效缓解了 RL 训练中低难度、短视样本对策略梯度的支配效应——本质上是用“输入的路径不确定性”来重加权样本贡献，让策略优化专注于信息增益潜力更大的问题上。

4. **通过系统性的长步数行为变化分析，展示了“推理预算”与“推理能力”的关系可被训练改变**。实验表明此类方法不仅提升了 F1，还改变了模型的认知策略形态——由“即时检索-立即作答”过渡为“先规划 → 检索 → 验证 → 回退 → 总结”的多阶段复合行为。这一发现对未来大推理预算模型（如 o1 类架构）的训练策略有直接启发。

## 10. 对未来研究方向的展望

作者的框架打开了若干后续可能，但论文本身尚未涉足或仅浅浅提及：

- **动态记忆结构的进一步扩展**：目前仅支持单个记忆栈，未来可在栈的基础上引入“检索记录与推理草稿分离”“不同主题的并行记忆分区”，甚至结合遗忘曲线的显式记忆时效衰减机制，使模型能自我决定“何时该忘、忘到什么程度”。
- **基于世界模型的过程奖励设计**：用 GRM 做记忆合理性评估本质上是“外部裁判”。若能将过程奖励替换为一个可学习、可随着主模型提升而持续迫近的“记忆状态价值函数”（类似 MCTS 中的 value network），有望解决 GRM 不可微、不可在线更新的缺陷。
- **从结果反馈走向交互反馈**：ALFWorld 与 WebShop 的结果虽然展示了可迁移性，但这两个环境都是一步一观测的封闭交互。真正的开放 agentic 场景需要在记忆栈之外引入“试探性动作”（如反问用户、提交中间产物、获取澄清）等动作类型，使记忆管理不仅仅是推理的事后修正，而是行动规划的一部分。
- **安全强化学习与记忆访问控制**：若记忆栈中的一个早期结论由于检索污染或提示注入而被恶意篡改，后续所有回溯与总结动作都会成为错误传播的载体。是否可以让模型对自己记忆项附带“置信度标签 + 来源引用”，并在回溯时优先检验低置信度项，是一个值得深挖的安全方向。

## 11. 总体评价

AgenticRag-R1 应是当前 agentic RAG 在 RL 训练框架下一个较系统、较规范的进阶工作。相比此前仅将“搜索”动作插入思维链的路线（ReSearch / Search-R1），它把握住了 agentic 系统的本质——不是按模板调用工具，而是有序地管理自己的认知状态——并设计了与之匹配的奖励体系和优化抽样机制。论文没有回避可逆动作带来的结构复杂性，而是以 Pop 注意力掩码给出了一个可落地的工程解法。

不过，其结论的适用范围要谨慎理解：**它证明了在中等规模（1.5B–7B）LLM 上、以静态维基百科为检索源、以事实多跳问答为主要任务的环境下，记忆感知的 RL 能优于短视检索 RL**；但“记忆栈上的回溯”是否等同于“人类的反省”，以及在小模型上习得的记忆动作能否在大模型以及动态知识环境中无损迁移，仍需后续更细致的实验检验。整体而言，该工作从问题意识到方法细节均有较强新意，实验设计与分析也较为扎实，属于该方向上值得细读的代表性论文之一。
