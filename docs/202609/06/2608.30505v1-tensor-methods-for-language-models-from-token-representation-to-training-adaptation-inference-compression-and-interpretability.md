## 摘要
大型语言模型（LLMs）由结构化高维对象构建，如 token 表示、权重、适配更新、缓存和激活值，其多线性结构在传统的以矩阵为中心的视角下未得到充分利用。张量分解和张量网络为这种结构提供了原则性的代数语言，然而文献中往往将其视为孤立的压缩机制。本综述通过两个互补的视角来组织 LLM 的张量方法：一个涵盖分词、嵌入、预训练、适配、压缩、推理和可解释性七个阶段的生命周期分类法，以及一个涵盖嵌入、注意力机制和前馈网络的组件视角。我们提供统一的符号表示和理论基础，分析各个 Transformer 组件的张量化策略，并在每个生命周期阶段比较各种方法，同时明确评估协议和模型规模的差异。我们进一步将张量方法与邻近的效率技术及概率张量网络联系起来。最后，我们综合了开放挑战，并引入了 $ρ_{\rm gap}$ 这一用于衡量理论内存缩减与实际系统级加速之间压缩-实现差距的指标。通过将张量化视为一种共同的结构原则，本综述为张量化语言模型提供了一个结构化的切入点，并阐明了参数节省何时能合理地转化为内存效率、计算效率或可解释性。本文的 GitHub 页面可在此 https URL 访问：\href{https://github.com/ma-tt-a/awesome-tensor-methods-for-llms}{https://github.com/ma-tt-a/awesome-tensor-methods-for-llms}。

## Abstract
Large language models (LLMs) are built from structured high-dimensional objects such as token representations, weights, adaptation updates, caches, and activations, whose multilinear structure is underexploited by the conventional matrix-centric view. Tensor decompositions and tensor networks provide a principled algebraic language for this structure, yet the literature often treats them as isolated compression mechanisms. This survey organizes tensor methods for LLMs through two complementary views: a seven-stage lifecycle taxonomy covering tokenization, embeddings, pre-training, adaptation, compression, inference, and interpretability, and a component view covering embeddings, attention, and feed-forward networks. We provide unified notation and theoretical foundations, analyze tensorization strategies for individual Transformer components, and compare methods at each lifecycle stage while making differences in evaluation protocols and model scales explicit. We further connect tensor methods to neighboring efficiency techniques and probabilistic tensor networks. Finally, we synthesize open challenges and introduce $ρ_{\rm gap}$, a metric for the compression-realization gap between theoretical memory reduction and measured system-level speedup. By treating tensorization as a common structural principle, the survey provides a structured entry point to tensorized language models and clarifies when parameter savings can plausibly translate into memory efficiency, computational efficiency, or interpretability. The GitHub page dedicated to this paper is accessible at \href{https://github.com/ma-tt-a/awesome-tensor-methods-for-llms}{this https URL}.

    - 嵌入层（经典嵌入表、N-gram 嵌入表、词素嵌入表）

    该视角关注张量对象的来源，并根据模式的语义性对张量化策略进行二分：
    - **模式特定（mode-specific）**：各模式（如位置、头索引、层）携带语义，可利用共享因子等进行结构分解。
    - **施加式（imposed）**：通过物理变换（reshape）人为引入张量化，无先验语义约束。
  - 两条轴互补：生命周期回答"何时/为何"引入张量化，组件视角回答"什么对象被张量化"。

- **核心技术基础**：
  - 统一符号系统（如图 1：标量、向量、矩阵、张量、外积、Kronecker 积、模态积、收缩操作，及对应的张量网络表示）。
  - 系统阐述常用低秩格式：
    - **CP 分解**（式 (10)-(11)）：最紧凑，具有唯一性，但最佳低秩逼近可能不存在（病态），拟合不稳定。
    - **Tucker 分解**（式 (12)-(13)）：逐模分配秩因子，但核心张量随阶数呈指数增长且存在规范自由度。
    - **TT 分解**（式 (14)-(16)）与 **TTM 分解**（式 (17)-(19)）：核心张量数为 O(N·I·R²)，呈链状，参数随阶线性增长，并保持操作者结构。
    - **Block-Term（BT）分解**（式 (20)-(21)）：对每项引入独立 Tucker 块，连续插值 CP 与 Tucker 之间的设计空间。
    - **Kronecker 分解**（式 (3)）：将矩阵块化后，通过SVD求解最佳加性 Kronecker 逼近。

- **针对 LLM 的张量化案例分析**：
  - 嵌入层：TensorGPT 将每行 token 嵌入 reshape 为高阶张量，随后施加 TT-SVD 做行级压缩（无训练）。
  - FFN 投影：GPT-TTM 以 TTM 表示投影矩阵，压缩比例如 LLaMA-3-8B 中 W_down 可达 60×。
  - 适配更新：KronA 以 Kronecker 积形式（$\alpha(A \otimes B)$）定义权重更新，单个 Kronecker 项即可达到与更低参数成本下更高的矩阵秩。
  - KV-cache：Tensor Product Attention (TPA) 将每个 token 的键矩阵分解为低秩模式。
  - 双线性 FFN 可表示为一个精确的三阶张量 $B \in \mathbb{R}^{d\times d\times d}$，从而可直接对权重进行分析，而不必引入任何结构化近似的先验约束。
  - 张量化压缩方法，如 LeSTD，将多头投影聚合为高阶张量，对维进行相应 Tucker 分解并与稀疏化步骤结合。

- **压缩-实现差距度量**：
  - 提出 $C_B = B_{\text{dense}}/B_{\text{TN}}$（字节压缩率），$C_F = F_{\text{dense}}/F_{\text{TN}}$（FLOPs 压缩率），$S_T = T_{\text{dense}}/T_{\text{TN}}$（加速比）。
  - 定义为 $ρ_{\rm gap} = C_B / S_T = (C_B/C_F) \times (C_F/S_T)$，拆分为"算法部分"与"实现部分"，其中实现部分等价于 MFU_{\text{dense}}/MFU_{\text{TN}}（设备利用率之比），能够清晰地指出该瓶颈究竟来源于分解本身，还是源于 GPU 上低效的收缩实现。

### 6. 论文的主要结论与发现

- **张量化是一个可贯穿多个组件层面的共通原理，而非某种特殊的压缩技巧**：TT/TTM 出现于嵌入、预训练、PEFT 与压缩多个阶段，但因优化目标和约束不同，其同一分解的实际效果评估标准截然不同。
- **组件-张量化之间的兼容性与模式的语义意义高度相关**：极大多数有效设计方案其实建立在结构明确的层面：
  - 在多模态上，嵌入层 / FFN 中的加权投影出现"强加式 reshape";
  - 而注意力和投影堆叠多可进行"模式联动共享"（如跨头共享因子），并据不同的模语义进行"针对性分解"。
- **解码阶段真正可压缩的主体是 KV-cache**：其作用远超参数压缩；量级、Kernel 效率与质量均需共同优化。
- **许多声称的压缩比未能转化为系统的端到端速度提升** —— 压缩-实现差距是普遍痛点，文中把它形式化定义为 ρ_gap，将其分解为"算法部分"与"系统实现部分"来引导清晰解析。
- **不同生命周期的发展成熟度高度不均衡：** 分词领域其目前完全空白，可解释性则是当前最新且有希望的方向，预训练阶段缺乏系统性的跨规模研究，未能形成对 scaling law 的有效证据支撑。
- **张量分解与概率图模型间的关联是有前提条件的**：只有以非负且归一化核心才能将其解释为朴素 Bayes/HMM 等结构；否则仅形式类同，"易用但并非可解释，须避免误导地看其潜语义"。
- **展望方向**：生命周期的联合设计（tokenization+embedding+pre-training），条件性张量化，张量训练状态与分布式训练，以及多模态/MoE 等跨模式共享。

### 7. 优点

- **结构清晰**：综述提出了能贯穿全部 Transformer/LLM 实践环节的系统性分类方法 —— "生命周期 × 组件" —— 双轴结构，纵横交错却职责清晰，相互独立：
  - Unlike 前述只拿张量做压缩的旧工作（只聚焦 layer 层面），本工作指出了何时、基于何目标、应用何种张量化才可能带来真正的收益。
- **强调公平性与差异性**：在归纳表格中展示统一的比较元信息但同时进行了大量"警示性注记"，例如：
  - 提醒是否相对不同基准，压缩率范围是否仅覆 MHA 而非端到端、对PEFT是否源自LoRA结果而非得自完整 Fine-tune，为评估综合建立批判性视角。
- **工程上切中要害**：明确点出了"系统硬件"瓶颈，指出"收缩变慢"是压缩到实际加速链路上的限制, 并使用ρ_gap将抽象压缩差异切分为可用 MFU 度量解释的物质性因素；
- **跨领域的连接性**：纳入张量与概率图模型的对应、注意力和/或量子张量网络（如 QuanTA、量子 PEFT）、既有 LLM 优化技术（如量化、低秩适配等），且并不仅仅囿于单一方法群。
- **完备的落地资料**：附有应用软件（即张量库概览如 TensorLy/Torch tntorch/quimb等）与两处开源案例深度解析（分别针对研究级（PicoGPT以MPO做微型试验）与可部署级别的方法（32B Qwen模型的 Minima 生产管线））。这样统一了设计与实现阶段。

### 8. 不足与局限

- **资源消耗和数据重现性受制于综述形态**：无任何自行设计的实现与复现实验，只能依靠从其归纳表中的原始论文差异作判断，进而限制了彻底结论推导出的可能性。
- **不可比的评测协议持续存在**：即便是作者做了归一化比较，基础数据也来自不同实验设置、不同基线与某种程度上的局部调优（甚至每个工作自行选择评测子集）。因此即使表中加以说明，读者也不能归纳出统一结论。
- **结果参数与真实效果间的互相联系较弱**：有多处比较表的指标口径不统一，例：有的压缩率只是非全尺寸模块且没计元数据/临时缓冲；有的度量计算未考虑量化储存幅值带来的差别。这些都影响公平对比的检验力。
- **分词阶段无可用案例**：由于无法将代理解析建模成本
