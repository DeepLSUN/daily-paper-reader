## 摘要
自回归视觉语言模型统一了异质的感知任务，但极易受到复合错误的影响。在策略蒸馏（OPD）通过让学生在自身轨迹上训练来弥合训练与推理之间的不匹配。然而，不可靠的学生预测，尤其是在训练早期，可能会使轨迹偏离轨道并降低教师监督的质量。尽管最近的交错式蒸馏方法允许教师验证并替换学生令牌，但它们主要依赖严格的排序指标而非精确的教师置信度，并且忽略了干预决策如何影响令牌级监督。为解决这一问题，我们引入了置信度感知在策略蒸馏（CA-OPD），一个将可靠的轨迹构建与自适应监督相结合的框架。CA-OPD利用教师置信度选择性地纠正不可靠的学生状态转移，通过从严格到宽松的调度逐步将轨迹控制权转移给学生。关键在于，CA-OPD将这些干预决策与知识迁移对齐：被纠正的位置直接接受来自教师预测的交叉熵监督，而被保留的位置则受益于教师的完整预测分布。在多教师设置下针对GUI接地和光学字符识别进行评估，CA-OPD在全部六个目标基准上显著提升了Qwen3.5-0.8B基线，包括在ScreenSpot-Pro上提升9.50分，在OCRBench-v2英文上提升6.72分。对照研究进一步表明，这些提升依赖于干预放置、渐进式轨迹控制和干预对齐的监督，而非仅依赖干预频率。

## Abstract
Autoregressive vision language models unify heterogeneous perception tasks but are highly susceptible to compounding errors. On-policy distillation (OPD) bridges the training-inference mismatch by training students on their own rollouts. However, unreliable student predictions, especially early in training, can derail the trajectory and degrade the quality of teacher supervision. While recent interleaved distillation methods allow the teacher to verify and replace student tokens, they primarily rely on rigid ranking metrics rather than exact teacher confidence, and they overlook how intervention decisions can inform token-level supervision. To address this, we introduce Confidence-Aware On-Policy Distillation (CA-OPD), a framework that couples reliable rollout construction with adaptive supervision. CA-OPD utilizes teacher confidence to selectively correct unreliable student transitions, gradually transferring rollout control to the student via a strict-to-relaxed schedule. Crucially, CA-OPD aligns knowledge transfer with these intervention decisions: corrected positions receive direct cross-entropy supervision from the teacher's prediction, while retained positions benefit from the teacher's full predictive distribution. Evaluated in a multi-teacher setting for GUI grounding and optical character recognition, CA-OPD substantially improves the Qwen3.5-0.8B baseline across all six target benchmarks, including gains of $9.50$ points on ScreenSpot-Pro and $6.72$ points on OCRBench-v2 English. Controlled studies further show that the gains depend on intervention placement, progressive rollout control, and intervention-aligned supervision, rather than intervention frequency alone.

## 一、核心问题与整体含义

- **背景与动机**：自回归视觉语言模型（VLM）通过统一的 token 序列接口（如坐标、文本、动作 token）处理 OCR、GUI grounding、视觉 grounding 等多种结构化感知任务。由于每个生成的 token 都成为后续生成的输入前缀，任何局部错误都会沿序列传播并累积（compounding errors），导致整体输出质量迅速恶化。
- **现有方法的不足**：
  1. 自回归预测的级联错误意味着一个 token 错误可能破坏整条轨迹上教师监督的质量。
  2. 传统离线蒸馏 / 序列级蒸馏使用教师生成的静态轨迹，与推理时学生自生成前缀的分布不一致。
  3. on-policy 蒸馏（OPD）虽然缓解了训练-推理状态失配问题，但训练早期学生策略不可靠，错误 token 一旦进入前缀就会“带偏”后续所有状态，劣化教师监督的有效性。
  4. 近期的交错蒸馏方法（如 SKD）让教师验证并替换学生 token，但用“相对排序”而非“精确置信度”来判定是否值得信任，且忽略了一个关键问题：**何时替换（干预决策）本身就蕴含着可用于 token 级监督的信号**。
- **核心解决思路**：本文提出 CA-OPD（Confidence-Aware On-Policy Distillation），将两条主线统一在一个框架内：一是利用**教师的精确置信度**（negative log-likelihood）决定是否纠正不可靠的学生 token 来构建可靠的 rollout；二是根据干预结果**自适应地选择监督方式**（被纠正位置用交叉熵，保留位置用分布匹配）。进一步通过严格至宽松的进度调度，让训练随着学生能力提升逐步将生成控制权交还学生，维持 on-policy 特性。

## 二、方法论：核心思想、技术与算法机制

### 2.1 置信度感知的 Rollout 控制
- 在每个解码步骤，学生先采样一个候选 token：$\hat{y}_t \sim \pi_S(\cdot|s_t;\theta)$。
- 教师计算对该候选 token 的 NLL：$\text{NLL}_{T,t} = -\log \pi_T(\hat{y}_t|s_t)$。
- 阈值比较决定是否替换：
  - 阈值较低（早期）表示要求更高的教师置信度，更多学生 token 被拒绝；
  - 阈值随训练进度按余弦函数从 $\tau_{\text{start}}$ 松弛到 $\tau_{\text{end}}$，即对应的教师概率下限从 $\alpha=0.50$ 放松到 $\alpha=0.25$；
  - 被拒绝的位置由教师 argmax 输出 $\tilde{y}_t = \arg\max_v \pi_T(v|s_t)$ 替换并写入前缀；被接受的学生 token 保留。
- 替换指示 $r_t$ 统一驱动 rollout 构造和监督目标，形成“干预决策—状态访问—知识迁移”三者一致的闭环。

### 2.2 干预对齐的监督（Intervention-Aligned Supervision）
- **被替换位置** $(r_t=1)$：直接对学生做交叉熵监督 $\mathcal{L}_t^R=-\log\pi_S(y_t|s_t;\theta)$，相当于告诉学生“这里你错了，正确答案是教师的输出”。
- **被保留位置** $(r_t=0)$：用教师完整预测分布（实际使用 top-k 截断近似）做前向 KL 蒸馏：
$$\mathcal{L}_t^K = D_{\text{KL}}(\pi_T(\cdot|s_t) \,\|\, \pi_S(\cdot|s_t;\theta))$$
  top-k 截断后做零下界钳制，保留的教师概率质量中位数 > 0.999，截断影响可忽略。
- **总目标**：$\mathcal{L}_{\text{CA-OPD}}=\frac{1}{\sum_t m_t}\sum_t m_t[\lambda_{\text{CE}} r_t \mathcal{L}_t^R + \lambda_{\text{KL}}(1-r_t)\mathcal{L}_t^{K\text{-topk}}]$

### 2.3 渐进式控制权移交
- 设 $p_s$ 为归一化训练进度（含 warm-up 调整），阈值调度为余弦形式：$\tau_{\text{nll},s} = \tau_{\text{start}} + \frac{\tau_{\text{end}}-\tau_{\text{start}}}{2}[1-\cos(\pi p_s)]$。
- 训练早期：阈值低 → 更多教师干预，防止不成熟的学生错误进入前缀；
- 训练后期：阈值升高 → 更多学生 token 被保留，保证 on-policy 特性不被破坏；
- 该调度控制“置信度标准”而非固定替换比例，替换率随训练自然衰减，体现学生与教师的逐步对齐。

### 2.4 实现层面的关键细节
- 学生每次提议 32 个 token 的 chunk，教师基于共享前缀批量评分；若触发替换，则从首个被替换位置重新开始生成后续 chunk，语义等价于逐 token 的混合前缀更新，并降低查询开销。
- warm-up 占 10% 的优化步数，期间保持最严格接受标准。

## 六、主要结论与发现

1. **CA-OPD 在全部 6 个目标基准上一致超过标准 OPD**，典型提升：
   - ScreenSpot-v2 +9.08（对比基线 Qwen3.5-0.8B）或 OPD 87.34 → 88.41；
   - ScreenSpot-Pro 40.82 → 45.92（相对 OPD +5.10）；
   - OCRBench-v2 英文 50.79 → 52.47（相对 OPD +1.68）；
   - OCRBench-v2 中文 52.45 → 53.22；
   - CC-OCR 63.93 → 67.32；
   - OmniDocBench 68.57 → 70.43。
2. **优于 SKD**：直接对比 rank-based 门控方法，CA-OPD 在 ScreenSpot-Pro、OCRBench-v2 等上均更高，表明“绝对置信度”比“相对排名”能更精确地识别需要教师介入的位置。
3. **干预策略的价值排序**：退火调度 > 固定阈值 > 反向调度 → 证明渐进式把 rollout 控制权从教师交给学生是关键。
4. **随机干预与纯监督变化无法替代选择性写回**：随机插入教师 token 效果接近 OPD；不做前缀写回只改监督也无效；只有“置信度引导的选择性写回 + 干预对齐监督”同时启用才有明显增益。
5. **干预决策可作为学习信号**：被替换位置适合直接交叉熵纠正，被保留位置保留分布级蒸馏——两两搭配效果最好（在 ScreenSpot-Pro 上，KL 替换 CE 损失较少；sampled writeback 低于 argmax writeback）。
6. **保留能力无损伤**：在 RefCOCO 与 MMBench 上，CA-OPD 与 SFT 初始化及其他对照方法持平，没有牺牲 OOD/保留能力。
7. **方差角度**：CA-OPD 在跨运行稳定性上也优于标准 OPD（SS-Pro 标准差从 1.46 降至 0.72，CC-OCR 从 0.96 降至 0.51），说明门控同时带来了一定训练稳定性收益。

## 七、优点

1. **问题切中要害**：把自回归结构化预测的“错误累积”问题与蒸馏的“状态失配”问题联合起来，识别到此前方法忽略的两处短板（置信度而非排名；干预决策包含监督信号），问题定位清晰。
2. **方法优雅、自洽**：把“门控”（是否替换）从逻辑上同时用于 rollout 构造和 token 级目标选择，用同一个 $r_t$ 统一状态访问与知识迁移，形成一个闭环的“单决策双用途”结构，概念干净、推导清晰。
3. **调度设计合理**：从严格到宽松的置信度阈值变化符合课程式训练直觉，warm-up + 余弦退火与训练过程契合。
4. **实验设计严谨（较突出的优点）**：
   - 用多组对照（随机干预、无写回、固定阈值、反向调度、采样矫正、KL vs CE）逐一排除替代性解释；
   - 使用配对反事实分析和 rank 对比说明 CA-OPD 的置信度门控确实找到了“排名方法漏掉但影响重大”的位置；
   - 报告 3 次独立运行均值与标准差，避免单次运行噪声；
   - 预算/公平性做得好（方法间数据、算力、训练步数一致），并用约 1.5× 的额外算力换取了显著且一致的提升。
5. **分析详尽**：分层分析（长度、初始能力、拒绝密度）与训练动态图相结合，从多个角度验证增益的来源与均匀性，说明结果不是偶然的少数样本驱动。

## 八、不足与局限

1. **置信度校准依赖性**：CA-OPD 假设教师概率能有效识别不可靠的学生状态。若教师存在明显域偏移或置信度校准偏差，则需要重新调节 α/τ 阈值；该敏感性问题论文只在局限中一笔带过，没有做噪声模拟或滥用实验。
2. **评估任务范围受限**：
   - 只在“封闭词表、共享 tokenizer”的场景下验证了 GUI 坐标与 OCR 字符序列两类结构化输出；
   - 没有验证开放式生成、自由文本推理或与其他 tokenizer 不匹配的师生组合；
   - 对开放词汇视觉定位或更复杂的组合动作规划缺少证据。
3. **部分机制分析以相关性为主**：混合初始能力组增益 +10.60 更突出这一点，论文也承认此为描述性结果而非确定性机制；教师拒绝密度与初始能力存在相关性（r=-0.51），使“干预必要性”与“样本难度”的独立影响难以完全拆清。
4. **过度依赖架构假设**：方法假设教师与学生都是自回归 next-token 模型且可进行逐 token 评分；对非自回归或串行解码的学生模型不适用。
5. **性能天花板与现实约束**：
   - 在 SS-Pro “全部正确”子集上，CA-OPD 保留了 93.83，但仍低于 SFT 初始化的 96.03，说明知识蒸馏依然会侵蚀部分已学好的行为，只是“减少”而非“消除”这种侵蚀；
   - 训练成本约 1.5× 标准 OPD（每次教师查询都发生在每个被访问状态），在极大规模部署时开销可能不可忽视；
   - 单教师无 SFT 场景、策略梯度和部分阈值变体仅单次运行，结论的稳健性弱于主表中的 3 次运行。
6. **代码与复现细节未完全开放**：论文详细配置可见，但未提供公开代码链接、数据过滤细节与模型权重，外部可复现性有待后续工作补足。
