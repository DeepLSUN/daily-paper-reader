## 摘要
部署在专业领域的大型语言模型必须在不牺牲通用能力的前提下提高领域内性能。现有的参数高效微调方法通常是始终开启的：其学习到的扰动被应用于每个输入，这可能会降低领域外（OOD）性能。我们提出了Engram Adapter，一种将预训练时的条件记忆重新用作冻结LLM的事后适配器的框架。它利用局部n-gram模式上的多通道匹配与显式占用跟踪作为轻量级选择性先验，使得残差注入更可能发生在领域内输入上，而学习到的标量门控则抑制不连贯的OOD检索。我们在Qwen3-4B和Qwen3-8B上使用AG-News和MedMCQA作为适配任务，并使用涵盖推理、翻译、代码生成和法律推理的OOD基准进行评估。Engram Adapter提高了领域内准确率，同时保持了平均OOD性能的99.4%–100.1%；在LegalBench上，其平均略超过冻结的基础模型，而可比的始终开启基线则显著下降。机制分析表明，尽管OOD激活非零，但门控和投影衰减将残差降低到隐藏状态范数的约0.08%，从而产生较小的KL漂移和可忽略的准确率变化。这些结果表明，条件激活是在冻结骨干网络上实现模块化、保留性领域特化的一个有前途的途径。

## Abstract
Large language models deployed in specialized domains must improve in-domain performance without sacrificing general capabilities. Existing parameter-efficient fine-tuning methods are typically always on: their learned perturbations are applied to every input, which can degrade out-of-domain (OOD) performance. We propose Engram Adapter, a framework that repurposes pretraining-time conditional memory as a post-hoc adapter for frozen LLMs. It uses multi-channel matching over local n-gram patterns with explicit occupancy tracking as a lightweight selectivity prior, making residual injection more likely on in-domain inputs while a learned scalar gate suppresses incoherent OOD retrievals. We evaluate on Qwen3-4B and Qwen3-8B with AG-News and MedMCQA as adaptation tasks and OOD benchmarks spanning reasoning, translation, code generation, and legal reasoning. Engram Adapter improves in-domain accuracy while preserving 99.4%--100.1% of average OOD performance; on LegalBench it slightly exceeds the frozen base model on average, whereas comparable always-on baselines degrade sharply. Mechanistic analyses show that although OOD activations are non-zero, gate and projection attenuation reduce residuals to approximately 0.08% of hidden-state norm, yielding small KL drift and negligible accuracy change. These results suggest conditional activation is a promising route toward modular, retention-preserving domain specialization over frozen backbones.

# 论文中文总结

## 1. 核心问题与整体含义（研究动机与背景）

- 大型语言模型（LLM）在医学、法律、金融等专业领域部署时，需要在不牺牲通用能力的前提下提升领域内性能，这就形成了“适配（adaptation）—保留（retention）”的权衡。
- 以 LoRA、Adapter、DoRA、PiSSA、prefix tuning 等为代表的参数高效微调（PEFT）方法虽然降低了训练与存储开销，但它们的本质是“始终开启”（always-on）：训练得到的残差或权值扰动会无差别地施加到每一个输入上。当领域数据规模小、分布狭窄时，这种无条件干预会扭曲通用表征，诱发灾难性遗忘。
- 作者由此提出本文的核心问题：领域特化的关键不只是“如何注入领域知识”，更是“**何时**才应该触发这些知识”。现有方法大多只回答前者，而本文直接面向后者。
- 整体贡献在于：提出了一种“条件激活”式（conditional activation）的适配范式，把领域特化从“均匀参数扰动”转变为“由局部模式匹配驱动的选择性知识注入”，实现冻结骨干网络之上的模块化、保留性领域特化。

## 2. 方法论（Engram Adapter）

### 2.1 核心思想
- 将 DeepSeek Engram（一种为预训练设计的、基于哈希查找的“条件记忆”模块）重新改造为冻结 LLM 的即插即用式（post-hoc）适配器。
- 用局部 n-gram 模式匹配作为“选择性先验”：领域内输入更可能命中已训练的记忆槽位从而激活适配器；领域外输入在无匹配或弱匹配时，残差被遮蔽或由门控衰减。
- 适配器不是“开了就永远在动”，而是在每个 token 位置上根据 n-gram 的域归属动态决定是否注入残差。

### 2.2 总体框架
- 冻结基础模型参数（\(\nabla_\theta L=0\)）。
- 仅在指数间隔的 4 个自注意力层 \(L=\{1,3,7,15\}\)（共 36 层中）通过 PyTorch forward hook 注入 Engram Adapter 模块，其余层完全不变。
- 修改后的隐藏状态为：
  \[
  u^{(\ell)}_{\text{new}} = u^{(\ell)} + \alpha \cdot g^{(\ell)} \cdot \mathrm{mem}^{(\ell)}(x_{1:t})
  \]
  其中 \(\alpha=0.2\) 为固定缩放因子，\(g\in[0,1]\) 为学习到的标量门，\(\mathrm{mem}\) 为记忆检索结果。

### 2.3 域匹配记忆结构
- 采用三类 n-gram 通道：后缀二元组 \(n=2\)、后缀三元组 \(n=3\)、以及前文背景三元组 \(n_{\text{prev}}=3\)（覆盖连续 4-token 窗口但每次哈希只涉及 3 个 token ID，避免长 n-gram 的直接哈希冲突）。
- 对每个类别、每个哈希（共 \(k=4\) 个哈希函数），维护一张嵌入表 \(E_{n,h}\in\mathbb{R}^{M\times d_h}\) 和一张布尔占用图 \(F_{n,h}\in\{0,1\}^M\)，其中 \(M=90007\)，\(d_h=128\)（Qwen3-4B）或 256（Qwen3-8B）。
- 12 张记忆表在全部注入层之间共享，降低记忆开销并保证各层拥有相同的模式清单。

### 2.4 哈希与联合遮蔽
- 对位置 \(t\)、阶数 \(n\)、哈希 \(h\) 的桶索引为：
  \[
  \mathrm{idx}_{n,h}(t)= \left( \sum_{j=0}^{n-1} x_{t-j}\,(1{,}000{,}003+97^j) + s_{n,h} \right) \bmod M
  \]
- 与前文 n-gram 使用带 1,000,000 偏移的同一公式。
- 每个哈希的激活状态由**占用标志**决定（而非嵌入向量范数）：\(\mu_{n,h}(t)=F_{n,h}[\mathrm{idx}_{n,h}(t)]\)。
- 组级联合掩码要求同一阶数组内所有 \(k\) 个哈希都命中已填桶，乘积为：
  \[
  m_n(t)=\prod_{h=0}^{k-1}\mu_{n,h}(t)
  \]
  任一哈希未命中则整组向量被清零，形成强“选择性先验”。

### 2.5 投影与门控
- 过滤后的向量经拼接投影得到记忆向量：
  \[
  \mathrm{mem}(t)=W_{\text{proj}}\,c(t)
  \]
  其中 \(c(t)\) 拼接所有通道输出，\(W_{\text{proj}}\) 零初始化。
- 标量门为：
  \[
  g(t)=\sigma\left(W_m c(t) + \frac{(W_u\odot u(t))^\top \mathrm{mem}(t)}{\sqrt{D}}\right)
  \]
  第一项为纯学习线性项；第二项为权重隐藏态-记忆点积相干项（消融显示相干项贡献可忽略，主要抑制来自 \(W_m c(t)\)）。
- 训练参数约 154M（4B 配置），约为 LoRA r=64（132M）的 1.2 倍，但实际大量记忆行因稀疏占用而无效，且只注入 4/36 层，故层间开销较全层设计降低约 89%。

### 2.6 相对 DeepSeek Engram 的关键改进
1. 增加前文背景通道，缓解长 n-gram 哈希碰撞问题；
2. 组级联合遮蔽（occupancy-tracked joint masking）形成跨哈希协同选择性；
3. 学习标量门控衰减不连贯检索；
4. 随机初始化嵌入表并维护独立布尔占用图，避免嵌入值过小导致的假阴性；
5. 模型级前向 pre-hook 支持自回归生成时正确构造 n-gram。
