## 摘要
基于LLM的多智能体系统在复杂任务上已展现出强大性能，但通过交互经验实现持续改进仍然具有挑战性。现有的自我反思方法会构建经验记忆，但记忆大多难以调用、精炼或扩展；而智能体技能提供了一种更具可操作性的单元：结构化的程序性知识，用于规定何时行动、如何行动，以及使用哪些资源或工具。我们提出MASkills，一个通过智能体技能优化多智能体LLM系统的持续学习框架。MASkills提出了一种新的智能体优化流水线，集成了技能条件化的信用分配、分层信用聚合和动量平滑优化，使智能体技能库能够通过精炼、归纳、整合和剪枝不断演化。在HotpotQA、LoCoMo和GAIA上的实验证明了MASkills在多种智能体任务上的有效性。我们的代码见 https://github.com/DaRL-GenAI/MASkills

## Abstract
LLM-based multi-agent systems have shown strong performance on complex tasks, yet continual improvement from interaction experience remains challenging. Existing self-reflection methods build experience memories, but memories are mostly hard to invoke, refine, or scale, while agent skills offer a more actionable unit: structured procedural knowledge that specifies when to act, how to act, and which resources or tools to use. We introduce MASkills, a continual learning framework that optimizes multi-agent LLM systems through agent skills. MASkills presents a new agent-optimization pipeline that integrates skill-conditioned credit assignment, hierarchical credit aggregation, and momentum-smoothed optimization, enabling agent skill libraries to evolve through refinement, induction, consolidation, and pruning. Experiments on HotpotQA, LoCoMo, and GAIA demonstrate the effectiveness of MASkills across multiple agentic tasks. Our code is available at https://github.com/DaRL-GenAI/MASkills

## 1. 核心问题与研究动机

- **背景**：基于LLM的多智能体系统通过角色分工、协调与长时程交互，在复杂任务上表现突出，但**如何随时间从交互经验中持续改进**仍很困难。
- **现有方法局限**：主流做法是用自我反思（self-reflection）构建经验记忆。记忆能保存经验，但作为持续改进的基础较弱：
  - 只记录过去轨迹中"发生了什么"，不指明"应复用哪种行动策略"；
  - 缺乏可靠的调用条件；
  - 随规模增长，有用经验与噪声、冗余、陈旧记录混杂。
- **技能作为更优单元**：借鉴 Anthropic 的定义，技能是**结构化程序性知识包**，规定何时调用、如何行动、使用哪些资源或工具，具备渐进式披露（progressive disclosure）特性，比非结构化记忆更可扩展、更可操作。
- **关键缺口**：现有技能发现方法（MemSkill、EvoSkill、PolySkill）多为**单智能体**设定，未在多智能体协调动态下优化技能；多智能体场景下技能更新需同时反映个体结果与对团队协调的贡献。
- **三大挑战**：
  1. **技能级信用分配**：团队奖励应归因到"正确的技能"，而不仅是正确的智能体；技能可能只在少数时间步被调用，其效果与其他智能体行为纠缠。
  2. **噪声与异构交互**：语言反馈噪声大、不一致；不同协调结构（集中式规划 vs 去中心化对等通信）导致不同的依赖与信用传播模式。
  3. **离散且高风险的技能更新**：技能是 SKILL.md、脚本、参考文件等离散语言工件，需开放式结构修改而非平滑数值更新；错误编辑会直接改变有效动作空间。

## 2. 方法论

### 2.1 核心思想
- 在**技能空间**而非参数空间做策略改进，采用**语言空间策略梯度式**框架（结构上类比 TextGrad 与 LangMARL，是概念类比而非可微梯度）。
- 将去中心化 rollout 视为轨迹采样，语言 critic 提供技能级"优势"式反馈，分层聚合与动量平滑近似蒙特卡洛期望与方差缩减，信用驱动的技能编辑算子充当伪梯度更新。

### 2.2 问题形式化
- 建模为 **Dec-POMDP**：`M = ⟨S, {Ai}, {Oi}, P, R, γ⟩`，共享团队奖励 `rt = R(st, a1t, ..., aNt)`，各智能体执行去中心化策略 `πi(ait | oit)`，目标为期望折扣回报 `J(π) = Eπ[Σ γ^t rt]`。
- **技能工件**：`k(j)i = (y(j)i, m(j)i, R(j)i)`，其中 `y` 为元数据（如 skill.yaml），`m` 为程序指令（如 SKILL.md），`R` 为辅助资源（脚本、参考、资产、配置）。
- 每个智能体维护技能库 `Ki = {k(1)i, ..., k(Mi)i}`，作为策略的可学习组件。
- **优化目标**：`max_{ {Ki} } E_{τ∼π(·|{Ki})}[R(τ)]`，优化变量为技能工件。

### 2.3 四步流水线（对应 Fig. 1）

**(1) 多智能体技能执行**
- 仅将每个 skill.yaml 的轻量元数据（名称、简短描述）注入 agent prompt；技能以**可调用工具**形式暴露，而非完整展开的提示。
- 被选中时动态加载其 SKILL.md 与资源 `R`，保持活动上下文紧凑。
- 策略形式：`ait ∼ πθ(· | oit, Ki, hit)`；用 `cit ∈ Ki ∪ {∅}` 表示调用的技能（∅ 表示直接行动），技能轨迹 `ξi = {(t, cit)}` 可直接从执行日志观测。
- 轨迹扩展为 `τ = ⟨s0, {ai0, ξi0}, ..., sT⟩`，显式记录技能调用，支撑后续技能级信用分配。

**(2) 细粒度技能信用分配**
- 由**集中式语言 critic** 对每个实际调用的技能，给出相对"未使用该技能的反事实"的贡献评估：`Ctext_i(τ, k) = LLM Critic(τ, i, k, ξi)`，说明该技能是促进协调、冗余、导致失败，还是应泛化/特化。
- 同时输出**智能体级残差信用** `Ctext_i(τ) = LLM Critic(τ, i)`，捕捉无法归因于单一技能的效果，对**技能归纳**尤为关键（若失败无法由现有技能解释，则提示需要新技能）。

**(3) 稳定化语言梯度下降**
- **轨迹级编辑方向**：`gi(τ, k) = LLM Grad(Ctext_i(τ, k))`，将文本信用转为结构化自然语言编辑方向（精炼、行为调整、泛化、移除）。
- **分层聚合**：对 rollout 批次 `B = {τ1,...,τB}`，在技能级合并为 `G(m)i(k) = LLM Agg({gi(τb, k)})`，合并重复模式、消解冲突、去冗余、总结协调效用；再递归跨智能体、跨交互拓扑聚合。
- **动量稳定化技能编辑**：`K(m+1)i = LLM Edit(K(m)i, G(m)i, G(m−1)i)`，当前编辑方向充当"当前梯度"，历史编辑方向充当"动量项"，抑制瞬时/矛盾批评，鼓励长时程一致的技能演化。

**(4) 技能演化算子**（LLM Edit 的具体实例化）
- **精炼（Refinement）**：`k ← k ⊕ Δk, Δk = LLM Refine(k, G(m)i(k))`，以局部 diff 式补丁修改被反馈涉及的区域，保留无关结构与已验证行为。
- **归纳（Induction）**：对持续失败/未解决的协调模式，从困难轨迹集 `Hi` 提出新技能 `knew ∼ LLM Propose(Hi, G(m)i)`，引入全新程序抽象。
- **整合（Consolidation）**：对功能重叠的技能 `{ka, kb, ...}` 合成 `kmacro = LLM Merge(...)`，减少冗余、形成更高层可复用抽象。
- **剪枝（Pruning）**：移除效用持续为负、冗余、不稳定或极少被调用的技能：`Ki ← Ki \ {k : LLM LowUtility(G(m)i(k))}`。
- **验证与回滚**：候选编辑先在留出验证集 `Dval` 上评估（固定其他智能体技能）：`Ĵval(K′i | K−i) = E_{τ∼Dval}[R(τ)]`；仅当 `Ĵval(K′i | K−i) ≥ Ĵval(Ki | K−i) − δ`（δ≥0 吸收方差与评估噪声）时才接受，否则丢弃并恢复旧技能空间——相当于技能空间的 trust-region 约束，防止噪声批评或过拟合近期轨迹导致的不稳定更新。

## 6. 主要结论与发现

- **性能提升**：在三个 benchmark 上，MASkills 均取得优于所列基线（IO/CoT/CoT-SC/MedPrompt/MultiPersona/Self-Refine/ADAS；MemoryBank/ReadAgent/LoCoMo/MemGPT；Base/Search-o1/Vanilla ReAct/R1-Searcher）的结果，说明在技能空间做策略改进相比提示工程与记忆增强更有效。
- **技能优于记忆与提示**：技能质量对比显示，结构化技能（含调用条件与资源）显著优于无技能与提示生成的技能，支持"技能是比非结构化记忆更可扩展的改进单元"这一核心论点。
- **技能可迁移**：跨任务迁移实验中，直接将某环境学到的技能库用于未见目标任务（不再优化）仍能带来增益，说明学到的程序性知识具有一定通用性，而非仅记忆特定任务的答案模式。
- **拓扑鲁棒**：在 centralized、hierarchical、decentralized peer 三种协调结构下均有效，表明该方法不绑定于特定通信架构；不同拓扑下的差异也印证了"信用传播模式随协调结构变化"的动机。
- **Backbone 泛化**：在 GPT-4o-mini、Claude-3.5-Sonnet、Llama-3.1-70B 上均保持增益，说明优化发生在技能（语言工件）层面，与 actor 的具体实现解耦。
- **各机制均有贡献**：消融结果显示移除技能级信用分配、动量平滑、验证回滚、整合与剪枝中的任一项都会导致性能下降，其中技能级信用分配与验证回滚的影响较为关键，验证了"技能级信用分配"与"技能空间 trust-region"两个设计点的必要性。
- **训练动态**：性能随优化轮次单调上升并趋于收敛（约 5–6 轮），说明语言空间"梯度下降"具备可预期的稳定性，动量与回滚机制有效抑制了震荡。
