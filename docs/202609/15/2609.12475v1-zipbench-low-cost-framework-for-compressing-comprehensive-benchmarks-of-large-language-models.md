## 摘要
综合基准套件对于提升大型语言模型（LLMs）至关重要，但许多广泛使用的基准存在冗余，导致评估成本不必要地高昂。尽管近期的基准压缩方法（BCMs）可以缓解这一成本，但许多强 BCM 依赖从大量 LLM 收集的逐样本评估结果来识别代表性样本。除非这些结果已经公开，否则构建此类集合同样昂贵，这使得这些方法难以扩展到新发布的基准。为应对这一挑战，我们提出 ZipBench，一种简单且低成本的 BCM，并具有理论上的误差与排序一致性保证。ZipBench 仅评估一小组锚点 LLM，合成伪评估结果以扩大覆盖范围，学习紧凑的样本表示，并选择一个虽小但具有代表性的子集。基于此，我们构建了 ZipBench Zoo，它包含 100 多个基准代理的紧凑版本，涵盖文本、多模态和智能体任务。这些基准与完整基准相比的平均绝对误差为 0.002--0.02，平均 Spearman 相关系数约为 0.98。总体而言，ZipBench 降低了 LLM 评估和紧凑基准构建的成本，为计算资源受限的研究人员降低了开展广泛 LLM 研究的门槛。代码已发布在 https://github.com/MilkThink-Lab/ZipBench。

## Abstract
Comprehensive benchmark suites are essential for improving large language models (LLMs), but many widely used benchmarks are redundant, making evaluation unnecessarily expensive. Although recent benchmark compression methods (BCMs) can mitigate this cost, many strong BCMs rely on large collections of per-sample evaluation results from numerous LLMs to identify representative samples. Building such collections is also expensive unless they are already public, making these methods difficult to extend to newly released benchmarks. To address this challenge, we present ZipBench, a simple and low-cost BCM with theoretical error and rank-consistency guarantees. ZipBench evaluates only a small set of anchor LLMs, synthesizes pseudo evaluation results to broaden coverage, learns compact sample representations, and selects a small yet representative subset. Building on it, we create ZipBench Zoo, a collection of compact versions of 100+ benchmark proxies spanning text, multimodal, and agent tasks. These benchmark achieve mean absolute errors of 0.002--0.02 and average Spearman correlations of ~0.98 with the full benchmarks. Overall, ZipBench reduces the cost of both LLM evaluation and compact benchmark construction, lowering the barrier to broad LLM research for compute-constrained researchers. The code has been released in https://github.com/MilkThink-Lab/ZipBench.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想

- 用**少量锚点 LLM 的真实评估日志**（默认 N₁ = 6）作为唯一真实信号来源；
- 通过**合成伪评估日志**（不实际运行任何额外 LLM）拓宽能力覆盖范围；
- 基于**项目反应理论（IRT）** 学习 LLM 与样本的紧凑指纹表示；
- 通过 **K-means 聚类**选取代表性样本，构造紧凑基准。

### 2.2 符号与预备定义

- 锚点 LLM 集合 S = {ℓ₁, …, ℓ_N}，待压缩基准样本集 I = {x_j}，共 m 个样本；
- 二元响应 y_ij ∈ {0, 1} 表示 LLM i 在样本 j 上的对错，连续指标（如 F1）先归一化再按阈值 γ*_bin 二值化；
- LLM i 的准确率 κ_i = (1/m) Σ_j y_ij；
- 为每个 LLM 和样本分配 d 维指纹向量 a_i 与 b_j。

### 2.3 三阶段流程（Algorithm 1）

**Stage 1：初始评估**

- 选取 N₁ 个准确率分布广泛分散的锚点 LLM（本文取 N₁ = 6），在完整基准 I 上评估，得到二元响应矩阵 Y；
- 该阶段是构建成本的主要来源。

**Stage 2：合成伪日志**

- 计算锚点准确率范围 [κ_min, κ_max]，等宽划分为 M 个桶 B_h；
- 枚举 S 的所有 k-子集（k = 1, …, N₁），将每个子集视为一个"虚拟 LLM"，其对样本 j 的答案为子集内多数投票；
- 计算虚拟 LLM 准确率 κ_L，采用拒绝采样：若 κ_L 落入空桶则接受为合成锚点日志，否则拒绝；
- 直到生成 N₂ 条伪日志或候选耗尽，最终锚点集规模 N = N₁ + N₂；
- 目的：在几乎零额外评估成本下，使锚点准确率分布趋于均匀。

**Stage 3：表示学习与压缩**

- 采用 IRT 建模：P(y_ij = 1) = σ(a_iᵀ b_j)，其中 σ 为 sigmoid；
- 通过最小化负对数似然（式 7）拟合指纹，初始化自标准正态分布；
- 对学到的样本指纹 {b_j} 做 K-means，每个簇选一个代表样本，得到规模为 K 的紧凑基准 I_zip。

### 2.4 理论保证

- **定理 1（误差分析）**：在 IRT 模型下，任意 LLM 在完整基准与紧凑基准上的准确率差满足 |μ_i − μ'_i| ≤ δ_w := Aε/4，其中 A 为指纹范数上界，ε 为最大簇半径；Stage 3 通过优化指纹与 K-means 同时压小这两个量。
- **定理 2（排序一致性）**：在密度上界 f(x) ≤ c 的假设下，Spearman 相关系数期望满足 E[ρ] ≥ 1 − 96c²δ²_w − O(cδ_w/N)，即排序保真度由 δ_w、锚点数 N 和密度上界 c 共同决定。
- **均匀分布的重要性**：c 的最小可行值为 1（仅均匀密度可取到），Stage 2 通过均匀化锚点准确率将 c 推向最小值；若锚点准确率坍缩（Proposition 1），Fisher 信息矩阵 I(b_j) 退化为秩一矩阵、条件数发散，导致指纹不可辨识。

## 6. 主要结论与发现

- ZipBench Zoo 在留出 LLM 上达到 **MAE 0.002–0.02**、**平均 Spearman 相关约 0.98**，平均将评估成本降至原始的 **20%–40%**；
- small 版本平均缩减 **57.4%**，tiny 版本平均缩减 **77.5%**，tiny 版本三次重复评估仍比完整基准单次运行更快；
- 压缩质量随锚点数量 N 增加先快速上升后饱和，验证了定理 2 中 N 仅出现在 1/N 衰减项的理论预测；
- 均匀锚点分布显著优于 clustered 与 normal 分布，验证了 Proposition 1 关于指纹可辨识性的分析；
- 在 OOD 外推中，ZipBench 在 Mid-75%/High-75%/Low-75% 三种设置下均取得最低 MAE（平均 0.0309），优于 tinyBenchmarks（0.0381）和 SUBLIME（0.0336）；
- 在智能体基准上，ZipBench 在不同压缩率下均优于无日志基线 EffiEval；
- 锚点准确率范围越宽，压缩质量越好；指纹维度 d = 5 已足够，增大 d 反而引入噪声。

## 7. 优点

- **低成本**：仅需 6 个锚点 LLM，无需大规模历史评估日志，显著降低紧凑基准构建门槛，尤其适用于新发布的基准；
- **理论支撑**：提供误差界（定理 1）与排序一致性下界（定理 2），并从 Fisher 信息角度论证锚点均匀分布的必要性（Proposition 1），理论与实验形成闭环；
- **规模与通用性**：一套统一配置（d = 5、2000 epochs）覆盖 100+ 个文本/多模态/智能体基准，证明方法的广泛适用性；
- **实证扎实**：100 次重复稳定性实验、OOD 外推、多种锚点分布对比、与 7 种以上 BCM 的对比，验证维度全面；
- **实用性强**：提供 small/tiny 两档预设，支持按目标缩减率或保真度约束灵活生成新版本；有公开日志时可零额外成本复用。

## 8. 不足与局限

- **固有近似误差**：紧凑子集无法保留完整基准的所有信号，压缩必然引入近似误差；
- **锚点评估残差成本**：虽然仅需 6 个锚点，但它们仍需在完整基准上评估，对智能体等昂贵基准该成本不可忽略；
- **完全去日志不可行**：分析表明完全移除性能记录难以产生可靠压缩；
- **IRT 假设限制**：方法依赖单维性与单调性假设，对混合多子技能的基准不适用（论文通过分指标压缩规避，但增加了流程复杂度）；
- **对比公平性存疑**：与 tinyBenchmarks 等方法的对比在"仅 6 条真实记录"的受限设置下进行，这些方法原本设计场景并非如此，可能低估其真实能力；
- **算力信息缺失**：未报告 GPU 型号、数量与训练时长，难以评估方法自身的计算开销；
- **公开日志依赖**：部分基准（尤其智能体类）的构建成本为 $0 是因为复用了公开日志，若日志不可用，构建成本会显著上升；
- **测试集差异**：各基准测试 LLM 数量不等（6–181），智能体基准测试模型较少，可能影响 SP 估计的稳健性。
