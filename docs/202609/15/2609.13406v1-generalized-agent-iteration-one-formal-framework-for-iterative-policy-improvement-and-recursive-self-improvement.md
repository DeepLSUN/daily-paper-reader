## 摘要
当我们谈论递归自我改进（RSI）时，我们谈论的是一种现象、一种机制，还是一种前景？面向自主且不断演化的智能，RSI 正以多种尺度被主张，但尚无单一框架能够形式化描述这些新兴实例。其在经典领域的对应物——迭代策略改进——由广义策略迭代（GPI）刻画；GPI 是一个适用性广泛、理论性质已被充分理解的框架，但仅适用于更新原则与评估基础位于智能体之外的情形。在本文中，我们提出广义智能体迭代（GAI），一个将迭代策略改进与 RSI 描述为同一学习范式的两种情形的形式化框架。GAI 将智能体定义为一个系统内可修改组件的配置，并将学习过程建模为智能体评估与智能体改进的循环。随后，两个关键旋钮区分这些实例：改进机制是否是智能体的一部分，以及其所对照的标准是否以智能体之外为基础。前一个旋钮划定了 GPI 与 RSI 之间的边界，后一个则决定系统的极性：锚定、目标漂移或完全自指。此外，我们使用这些坐标将现有系统置于相同的两个轴上，并使递归自我改进的缺陷能够一次一个条件地加以陈述。我们将本文视为探索 RSI 形式化刻画的第一步，这种刻画建立在经典解释之上，使现有系统可比较，并为分析和设计新系统提供有原则的基础。

## Abstract
When we speak of recursive self-improvement (RSI), are we speaking of a phenomenon, a mechanism, or a prospect? Towards autonomous and evolving intelligence, RSI is being claimed at many scales, while no single framework that formally describes these emerging instances exists. Its counterpart in the classical realm, iterative policy improvement, is characterized by generalized policy iteration (GPI), a framework of broad applicability with well-understood theoretical properties, but only where the update principle and the evaluation base lie outside the agent. In this paper, we propose Generalized Agent Iteration (GAI), a formal framework that describes iterative policy improvement and RSI as two cases of a single learning paradigm. GAI defines the agent as a configuration of modifiable components within a system and models the learning process as a cycle of agent evaluation and agent improvement. Two pivotal dials then distinguish the instances: whether the improving mechanism is part of the agent and whether the standard it is measured against is grounded outside it. The former dial delineates the boundary between GPI and RSI, and the latter determines a system's polarity as anchored, goal drift, or fully self-referential. Moreover, we use these coordinates to place existing systems on the same two axes and make the defects of recursive self-improvement statable one condition at a time. We see this paper as a first step toward exploring a formal characterization of RSI that rests on the classical account, makes existing systems comparable, and provides a principled basis for analyzing and designing new ones.

- **核心问题**：递归自我改进（Recursive Self-Improvement, RSI）在当今被以多种尺度广泛宣称——从智能体自我精炼输出、到改写自身改进例程、再到研究循环与共演化评估器——但**缺少一个统一的形式化框架**来界定"哪些系统真正在自我改进"以及"一旦自我指涉，系统性质发生了什么变化"。领域内标签使用松散，野心差异巨大（Chen et al., 2026 综述指出这一点）。
- **经典对应物**：迭代策略改进由**广义策略迭代（GPI）**刻画，在有限 MDP 中评估与改进交替收敛到最优策略，理论性质清晰。但 GPI 有一个隐含前提：**更新原则与评估基础都位于智能体之外**（改进机制固定、奖励由世界提供）。
- **研究缺口**：RSI 中改进机制与评价标准不再外置，却不存在与 GPI 同等适用范围的形式化描述。论文要提供的是**一个判据（criterion）而非又一个例子**。
- **整体含义**：论文提出**广义智能体迭代（Generalized Agent Iteration, GAI）**，把 GPI 与 RSI 描述为同一学习范式的两个实例，并借此让现有系统可比较、使 RSI 的缺陷"一次一个条件地"被陈述。

## 二、方法论：核心思想与关键技术细节

### 2.1 核心思想

- GAI 保留 GPI 的"评估—改进"交替循环，但将其**一般化到智能体组件本身可被编辑**的场景。
- 把智能体定义为**系统内可修改组件的配置**，学习过程建模为**智能体评估**与**智能体改进**的循环。

### 2.2 系统与智能体的形式定义（Definition 1）

- 世界为 MDP：\(W=(S,A,p,r)\)，外部目标为 \(G\)，二者均属环境、不属于系统。
- **系统**是一个五元组配置：\(\chi=(\pi,V,m,U,\rho)\)，分别对应：
  - \(\pi:S\to\Delta(A)\)：策略（选择世界动作）；
  - \(V:S\to\mathbb{R}\)：动作评论家（评价策略好坏）；
  - \(m:X\to\Delta(X_{\mathrm{Ag}})\)：修改器（提出系统应如何改变）；
  - \(U:X\to\mathbb{R}\)：修改评论家（评价提议的修改是否服务于 \(G\)）；
  - \(\rho\)：评估基础（评论家所对照的标准）。
- 系统空间 \(X=\prod_{o\in O}C_o\)，其中 \(O=\{\pi,V,m,U,\rho\}\)。
- **智能体**是系统中可修改的组件集合 \(Ag\subseteq O\)，智能体实例 \(\xi\in X_{Ag}\)；\(\chi[\xi]\) 表示用 \(\xi\) 替换系统 \(\chi\) 的智能体部分。
- 目标配置为 \(\chi^\star\in\arg\max_\chi \mathbb{E}[\sum_{t\ge0}\gamma^t r(S_t,A_t)\mid\chi]\)，该目标由世界与目标决定，**不由系统自身设定**。
- 备注：智能体自提任务仍从属于不可编辑的外部目标，视为自我改进的一种形式。

### 2.3 GAI 过程（Definition 2）

- 在系统的智能体部分交替执行两个操作：
  - **智能体评估**：评论家对照评估基础 \(\rho\) 给智能体部分打分（策略层用 \(V\)，智能体层用 \(U\)）；
  - **智能体改进**：修改器产生新智能体实例 \(\xi\sim m(\cdot\mid\chi)\)，系统采纳 \(\chi\leftarrow\chi[\xi]\)。

### 2.4 两个旋钮（Two Dials）

- **旋钮 1：改进机制是否属于智能体？**
  - \(m\notin Ag\)：修改器固定，作为外部改进机制，即 GPI 所迭代的抽象评估—改进算子；
  - \(m\in Ag\)：系统可改写自己的修改器，递归在 \(m\) 处闭合，无外部元层。
- **旋钮 2：改进所对照的标准是否有外部基础？**
  - 评估基础 \(\rho\) 的内容来自系统外部（世界与目标）且 \(\rho\notin Ag\)，则为**有基础（grounded）**；
  - 若内容来自外部但 \(\rho\in Ag\)，标准可被系统自身改写；
  - 若无外部内容，则循环仅受自洽性约束。

### 2.5 GPI 与 RSI 作为两个实例

- **GPI（锚定实例）**：\(Ag=\{\pi,V\}\)，\(m\notin Ag\)，其内容固定为评估算子 \(E_m\) 与改进算子 \(I_m\)：
  - \(V\leftarrow E_m(V,\pi;\rho_V)\)（评估），\(\pi\leftarrow I_m(V)\)（改进）；
  - \(U\) 存在但不被使用；\(\rho_V\) 有基础，内容为世界奖励 \(r\)；当 \(E_m\) 为策略评估、\(I_m\) 为贪婪时即策略/值迭代。
- **RSI（自修改实例）**：\(m\in Ag\)，典型 \(Ag=\{\pi,V,m,U\}\)，步骤为：
  - 策略更新：\(V\leftarrow E_m(V,\pi;\rho_V)\)，\(\pi\leftarrow I_m(V)\)；
  - 智能体更新：\(\xi\sim m(\cdot\mid\chi)\)，\(\chi\leftarrow\chi[\xi]\)，\(m'\leftarrow(\xi)_m\)，\(U'\leftarrow(\xi)_U\)；
  - 即下一轮的修改器与修改评论家由当前修改器产生，递归在 \(m\) 处闭合，无外部元层。

### 2.6 自洽性参考理想（公式 4）

- 记 \(\rho_U(\chi,\xi)\) 为基础赋予"从 \(\chi\) 采纳 \(\xi\)"的价值，则：
  - **智能体评估**：\(U(\chi)=\mathbb{E}_{\xi\sim m(\cdot\mid\chi)}[\rho_U(\chi,\xi)+\gamma U(\chi[\xi])]\)；
  - **智能体改进**：\(\mathrm{supp}\,m(\cdot\mid\chi)\subseteq\arg\max_{\xi\in X_{Ag}}[\rho_U(\chi,\xi)+\gamma U(\chi[\xi])]\)。
- 这两条是**刻画条件而非强制更新**：描述自我改进者必须具备的内部结构，但没有任何外部机制保证其成立；且不涉及目标 \(G\)。

### 2.7 自我改进的极性（旋钮 2 的三态）

- **锚定（Anchored）**：\(\rho\) 有外部内容且 \(\rho\notin Ag\)，智能体无法改写标准，朝固定外部标准改进。
- **目标漂移（Goal Drift）**：\(\rho\) 有外部内容但 \(\rho\in Ag\)，标准本身可被改写，自我改进可能偏离外部目标（漂移的是衡量标准，而非目标本身）。
- **完全自指（Fully Self-Referential）**：\(\rho\) 无外部内容（空或依赖 \(U\)），无外部信号进入循环，评论家方程退化为内部自洽。

## 六、主要结论与发现

- **统一性结论**：GPI 与 RSI 是**同一交替循环的两个设置**，仅由两个旋钮区分；其余描述共享。
- **边界刻画**：旋钮 1 划定 GPI 与 RSI 的边界；旋钮 2 决定系统极性为锚定、目标漂移或完全自指。
- **现有系统的统一读数**：
  - 固定外层循环、策略/值迭代、PPO 等属 **(Anchored) GPI**（修改器冻结在智能体外）；
  - Gödel machine 及 Gödel Agent、DGM、STOP、SICA、Polaris、Hyperagents 属 **Anchored RSI**（修改器在智能体内，但评估仍为外部基准/验证集，其中 Hyperagents 只可改脚手架，改进能力有界）；
  - Red Queen Gödel Machine 属 **Drifting RSI**（智能体与评估器共演化，无固定外部标准）；
  - Socratic learning 等闭系统提案属 **Fully Self-Referential RSI**（目前为立场论文而非已验证系统）。
- **RSI 的四个缺陷**（每个对应一项被违反的 GPI 条件，Table 4）：
  1. **候选自我搜索**（旋钮 1：\(m\in Ag\)）：改进步在有界性未知的内容空间上取 argmax，非廉价且非单调；Gödel machine 的证明门与统计变体的风险预算只是规避手段。**结构性 + 已观察到**。
  2. **自我评估**（旋钮 1：\(U\in Ag\)）：被评估对象与评估工具重合，报告值本身可修改；限制只能来自系统内容而非外部约束。**结构性**。
  3. **无基础的基础**（旋钮 2：\(\rho_U\) 无基础）：自洽条件只约束 \((m,U)\) 对，不涉及 \(G\)，不唯一、不保证忠实；形式类比为"幻觉箱"（delusion box, Ring & Orseau, 2011）。**结构性**。
  4. **目标漂移**（旋钮 2：\(\rho_U\in Ag\)）：目标名称不变但衡量机制改变，系统报告进步却未必真正跟踪目标；形式对应为"可改写效用函数的智能体仅在价值函数预期该改写时才无害"（Everitt et al., 2016），模型型效用可提供保障（Hibbard, 2012）。**结构性 + 已观察到**。
- **总体结论**：GAI 是探索 RSI 形式化刻画的第一步，使现有系统可比，并为分析、设计新系统提供原则性基础。
