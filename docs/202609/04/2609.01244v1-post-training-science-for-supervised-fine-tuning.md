## 摘要
每一次监督微调运行都迫使相同的一系列决策，例如学习率、批大小、LoRA或全量微调、训练轮数、优化器选择以及喂给模型的数据。这些决策通常对每个新模型和新数据集都从零开始重新摸索。在此，我们在一个统一工具下测量它们：一次扫描每次只改变一个杠杆，覆盖两个模型家族（Qwen3和Llama）中的稠密模型和混合专家模型，在四个真实世界的客户SFT数据集上，同时针对LoRA和全量微调。这些数据集提供了一个受控测试平台：每个任务都带有与客户共同构建的评估，其训练数据是通过迭代式监督微调生成的，该方法不断优化模型输出直到通过该评估，因此监督目标是内部一致的，我们报告所依据的任务评判标准正是这些数据为满足其而构建的标准。我们探究最优学习率和批大小如何随模型规模、家族和数据变化，以及是否存在一种选择规则可跨场景迁移；LoRA与全量微调相比的取舍，以及其秩和alpha如何设定适配器可学习的内容；验证损失（或其他指标，如损失曲面平坦度）是否能忠实排名下游质量；在通过混合专家扩展到235B参数的模型阶梯上，后期训练收益是否随模型大小和数据量扩展；在通用指令遵循能力退化之前，应训练多少个轮次；以及几何感知优化器是否能改进AdamW。每条建议都附带其不确定性度量。

## Abstract
Every supervised fine-tuning run forces the same chain of decisions, such as learning rate, batch size, LoRA or full fine-tuning, how many epochs, which optimiser, and what data to feed the model. Each of these is typically rediscovered from scratch for every new model and dataset. Here we measure them under one instrument: a sweep that varies one lever at a time, and spans dense and mixture-of-experts models in two families (Qwen3 and Llama), on four real-world customer SFT datasets, for both LoRA and full fine-tuning. These datasets give a controlled testbed: each task carries an evaluation built with the customer, and its training data is produced by iterative supervised fine-tuning that refines model outputs until they pass that evaluation, so the supervised target is internally consistent and the task judge we report against is the criterion the data was built to satisfy. We ask how the optimal learning rate and batch size move with model scale, family, and data, and whether one selection rule transfers across them; what LoRA trades against full fine-tuning, and how its rank and alpha set what the adapter can learn; whether validation loss (or other metrics, such as loss landscape flatness) faithfully ranks downstream quality; whether post-training gains scale with model size and data volume, on a model ladder extended through mixtures-of-experts to 235B parameters; how many epochs to train before general instruction-following erodes; and whether a geometry-aware optimiser improves on AdamW. Each recommendation is paired with a measure of its uncertainty.

## 1. 核心问题与研究动机

- **研究背景**：将开源基础模型适配到下游任务（监督微调，SFT）已成为语言模型走向生产的主要方式，但每次 SFT 运行都需要人工反复摸索一系列超参和训练决策：
  - 学习率（learning rate）
  - 全局批大小（batch size）
  - LoRA 还是全量微调（full fine-tuning）
  - LoRA 的秩（rank）与 alpha
  - 训练轮数（epochs）
  - 优化器选择（如 AdamW vs. Muon）
  - 训练数据规模与数据构成
- **核心问题**：上述决策通常是针对每个新模型/新数据集从零开始“重新发现”的，缺少跨模型规模、跨模型家族、跨数据集的系统性、可迁移的指导规则。
- **总体目标**：用受控测量替代临时试错，把后期训练（post-training）的经验判断变成有数据支撑、带不确定性的科学结论。

## 2. 方法论

- **统一扫描框架**：单变量扫描（one-lever-at-a-time sweep），每一步只改变一个因素，其他条件（数据、划分、随机种子）固定，从而把损失或下游分数的变化归因于被研究的杠杆本身。
- **模型与数据设计**：
  - 两个稠密模型家族：Qwen3（0.6B/1.7B/4B/8B/14B/32B）与 Llama（3.2-1B/3.2-3B/3.1-8B），并额外加入 Qwen3 混合专家模型（MoE）作为架构外推测试。
  - 四个匿名客户 SFT 数据集：`security`（安全审查，属于信息抽取类）、`leasing`（租赁合同，通过率任务）、`support`（客服支持，指令遵循率任务）、`docs`（文档生成，评分任务）。
  - 每个任务的训练数据由**迭代式 SFT（iSFT）** 生成：模型先起草输出，再由评估者打分并给出失败原因，不断修订直到通过评估。这样保证了监督目标内部一致、无矛盾标签，且下游判断标准正是数据构建时依据的判据（由客户验证）。
- 关键分析工具：
  - 以**验证集负对数似然（validation NLL）**作为选择指标，并用**相对预训练基线的改进量**做跨数据集比较以消除不同数据 token 数量的混淆。
  - 用 **Fisher 迹**度量收敛极小点的平坦程度，检验损失景观平坦度能否预测下游质量。
  - 采用损失加权拟合、bootstrap 置信区间等方法量化不确定性。

## 3. 实验设计与基准

- **学习率 × 批大小基础扫描**：
  - 9 个稠密模型、两类适配器（LoRA 与全量微调）、四个数据集；
  - 固定 5,000 个样本、1 个 epoch，LoRA 臂批大小 {8,16,32,64}、学习率 {3e-5,…,3e-3}；全量微调为参考臂，批大小 {16,64}、学习率 {3e-6,…,1e-4}；
  - 共计划 1,008 个稠密单元（cell），其中 970 个合格；被排除的 38 个全部是最高学习率下的 LoRA 失稳运行。
- **跨架构迁移测试**：对未参与拟合的 Qwen3-30B-A3B MoE 做全套扫描；对 Qwen3-Next-80B-A3B 和 Qwen3-235B-A22B 做盲测（blind test）。
- **LoRA 秩与 alpha 扫描**：在 Qwen3-4B/8B 上、两个数据集（leasing、docs），固定学习率 1e-3，扫描 rank ∈ {8,16,32,64,128} 与 α ∈ {16,32,64}。
- **损失与下游质量关系**：对基座模型和微调模型（Qwen3-8B、Llama-3.1-8B，两种 tuner，多种学习率/批大小），用 200 行规范测试样本做生产级评测，同时计算测试 NLL 与 Fisher 迹。
- **规模扩展趋势**：Qwen3 的 6 个稠密尺寸，加三个 MoE；LoRA 和 FullFT 分开拟合饱和幂律 L(N)=L∞+A·N^{-α}。
- **数据规模效应**：5k/10k/15k 样本、1/2/4 轮交叉实验，Qwen3-4B/8B/14B，leasing 与 security。
- **优化器对比**：Qwen3-8B 全量微调，四个数据集，AdamW vs Muon，各自单独扫描学习率；用验证 NLL 选点后对比任务得分、IFEval 与 Fisher 迹。
- **轮数研究**：1/2/4/8 epochs，两个 8B 模型（Qwen3 与 Llama）配合 LoRA 和 FullFT、1.7B 小模型以及更大数据量（10k/15k）的跟随后续实验。

**评价基准**：四个数据集均有客户共建的专业评测（如 find-ings 比较 micro-F1、pass rate、graded writing score、指令遵循通过率等），另用 IFEval 作为跨判据的通用指令遵循检测。对比方法主要是 LoRA 与全量微调、不同超参设置以及 AdamW vs Muon。

- **实验数量**：非常庞大。PDF 提到 1,008 个稠密计划单元中 970 个合格（包含 682 个 LoRA 单元、288 个 FullFT 单元）；MoE 扫描另加 112 个单元（80 个 LoRA + 32 个 FullFT）。总共有 224 个基础扫描单元被用于下游评分，形成 896 对（单元 × 任务）的结果。

## 6. 主要结论与发现

1. **最优学习率与批大小**
   - LoRA 的最优学习率**在 0.6B–32B 范围内几乎恒定在 1e-3**，约是全量微调最优值（约 3e-5）的 33 倍；该规则可在家族间转移，也可直接应用到 30B MoE，且在 80B/235B 上保持趋势。
   - 全局批大小没有单一最优值：更小批可在固定 epoch 预算下降低损失，但增加优化器步骤；批大小主要受显存限制。
   - 数据集组成（token 负载）决定可达损失；绝对 NLL 不可跨数据集比较，须用“相对基线的改进”。

2. **LoRA vs. FullFT、rank 与 alpha**
   - 匹配参数时 FullFT 在 72/72 次比较中均优于 LoRA，但 LoRA 恢复 FullFT 改进的中位数达 98%，而只训练 3–13% 的参数；该差距随模型规模增大而缩小。
   - LoRA rank 增加至 64 后趋于饱和；rank 32 是省钱替代（损失最多增加 0.003 nats）。α=32 在所有比较中最佳；r=64、α=32 仍是推荐默认。

3. **验证损失与下游质量的关系**
   - 在同一“（模型、数据集、微调方式）”单元内，验证 NLL 能负向排序下游质量（Spearman 范围 −0.38 到 −0.88）；**但跨模型家族不可靠**。
   - Fisher 迹在相同损失下**不能可靠地增加排序信息**（有时符号不稳定），因此平坦度对域内选择而言没有额外价值；但平坦度与保留通用能力有关，特别是跨优化器时最明显。

4. **规模扩展**
   - 在固定默认超参下，损失随规模呈**饱和幂律下降**：LoRA 指数约 0.31–0.40，FullFT 指数约 0.40–0.51（更陡）。
   - 三个 MoE 均大致相当于“active 与 total 参数的几何平均”的水平进入稠密趋势——30B-A3B 约相当于 8.5B 稠密模型。
   - 三倍的新鲜样本能降低 LoRA 验证损失（在不同规模上稳定），但收益主要由**数据集**决定，而非模型大小；数据应以“样本数”而不是轮次更重要。

5. **优化器：AdamW vs. Muon**
   - Muon 的最优学习率约为 AdamW 的 1/3；在其最优点上 Muon 的验证 NLL 略低，且最小点更平坦（per-parameter trace 低 1.2–2.8 倍）。
   - 在任务 judge 上两者持平；但在 IFEval 上 Muon 在四个数据集上均更高，表明平坦度对应更强的通用指令遵循保留。

6. **训练轮数**
   - 验证 NLL 大约在 2 轮后过拟合并持续上升；但下游任务得分并不随之下降（甚至会略微上升）。
   - 通用指令遵循（IFEval）随轮数增加而普遍侵蚀，尤其在指令密集型任务上；全新数据优于重复训练，数据增加并不会把最优 epoch 推迟到 2 轮之后。
   - LoRA 在任务得分上不输 FullFT，但两种方法在 IFEval 上的侵蚀相似。

7. **其他**
   - 余弦学习率调度优于常数学习率（在正确校准的学习率下）；常数学习率仅在学习率过低时有轻微优势，在高学习率端会严重不稳定。
   - 微调会提升目标任务并在其他任务上造成负迁移（相对基线的 off-diagonal 变化 −0.05 至 −0.44）。

## 7. 优点

- **统一化与受控性**：将散乱的经验调参转化为单变量对照实验；数据、种子、划分完全固定，合格单元有明确准入标准，原因归因可靠。
- **真实生产数据与有据可依的评测**：四个任务是真实客户 SFT 数据集，由 iSFT 保证标签一致性；评测是客户验证过的判断标准，具有较高生态效度。
- **架构与规模覆盖全面**：包括两个模型家族、dense 与 MoE、0.6B 至 235B；且用未参与拟合的 MoE 做外推盲测，十分有力。
- **细致的不确定性量化**：给出 95% bootstrap 区间、basin 定义、跨模型/留一法验证等，避免过度宣称结论。
- **结论可操作性强**：直接给出保持默认（r=64、α=32、LR=1e-3、~2 epochs）或替代方案（rank 32）的实用建议，并附带成本。
- **公平对比**：对每个优化器/模型用其独立校准的学习率网格；排除了不稳定单元；比较只在与预训练基线有改进的单元上进行。

## 8. 不足与局限

- **跨家族/跨任务推广受限**：验证损失在下游质量上的排名只在 recipe 内成立，跨家族失效；因此用损失跨模型选型仍需下游评测。
- **评测与训练目标不独立**：iSFT 数据是优化出来通过客户 judge 的，因此该 judge 并非“外部真值”；作为替代只用 IFEval 做了交叉检查。
- **token 与样本数混淆**：在同一数据集内 token 数几乎随样本数线性变化，因此无法完全区分“更多例子”与“更多 token”的贡献。
- **规模点较少，幂律拟合区间宽**：每族只有 3–6 个规模，外推到 80B/235B 属于超出拟合范围，模型点少导致指数置信区间较宽。
- **优化器比较仅针对全量微调**：未测试 Muon 在 LoRA 低秩子空间中的效果。
- **epoch 研究未能覆盖最大的 32B 模型**：端到端评估超过单设备显存限制；此外 downstream 探测部分只有 50 个样本，只能作为方向性证据。
- **最高学习率栅格固定导致稳定性边界问题**：3e-3 以上学习率在大模型上失败，说明“可用学习率上限”具有模型依赖性，可能需要更多稳定性检查。
- **尚未涉足方向**：reasoning 模型的数据行为、与预训练继续训练的交互、更广的适配方法（如量化感知训练、learned weight deltas）、更长的数据运行、拒绝采样微调等，均留作未来工作。
