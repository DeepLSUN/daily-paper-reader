## 摘要
编码智能体可以递归地修改自身实现，从而形成自我改进的循环。尽管先前工作表明这能提升编码基准上的性能，但现有方法成本高昂且计算密集。我们提出一个简单、样本高效的自我改进框架，在严格预算约束下显著提升编码性能。我们将候选自我修改的评估识别为主要运行时瓶颈，因为先前方法通过用修改后的智能体重新运行一部分基准任务来估计其有效性，这非常耗时。我们提出基于快速树搜索的递归自我改进（SIFT），它用 LLM 作为评判者的信号来增强这些下游任务评估，该信号在候选补丁之间进行成对比较，其中胜负记录通过正则化 Bradley-Terry 模型进行聚合，所得的强度分数驱动轻量级解耦树搜索中的基于排名的父代采样。昂贵的下游任务评估仅保留给最有希望的节点。使用完全解耦的树搜索流水线，评判者分数提供中间信号以引导对有望成功的候选补丁的探索，而不会因缓慢的评估运行而受阻。SIFT 在完整的 Polyglot 基准上优于现有的基于树搜索的自我进化框架，并在 CPU 小时、墙钟时间和 API 成本方面显著降低资源需求。

## Abstract
Coding agents can recursively modify their own implementations, forming a loop of self-improvement. While prior work shows this can boost performance on coding benchmarks, existing approaches are costly and compute-intensive. We introduce a simple, sample-efficient self-improvement framework that significantly improves coding performance under strict budget constraints. We identify evaluation of candidate self-modifications as the main runtime bottleneck since prior approaches estimate their effectiveness by re-running a subset of benchmark tasks with the modified agent, which is time-consuming. We introduce Recursive Self Improvement via Fast Tree-search (SIFT), which augments these downstream task evaluations with an LLM-as-a-judge signal that performs pairwise comparisons between candidate patches, where the win-loss record is aggregated with a regularized Bradley-Terry model, and the resulting strength scores drive rank-based parent sampling inside a lightweight disaggregated tree search. Expensive downstream task evaluations are reserved only for the most promising nodes. Using a fully disaggregated tree search pipeline, the judge scores provide intermediate signal to guide exploration on promising candidate patches without being bottlenecked by slow evaluation runs. SIFT outperforms existing tree-search based self-evolution frameworks on the full Polyglot benchmark with significantly lower resource requirements in terms of CPU hours, wall clock time, and API cost.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：LLM 驱动的编码智能体近年来在软件工程任务上进展迅速，而"递归自我改进"（recursive self-improvement）是其中一个前沿方向——智能体通过修改自身源码来提升未来表现。理论框架如 Gödel Machine、Gödel Agent、SICA、Darwin-Gödel Machine (DGM) 等已验证其可行性。
- **核心痛点**：现有自我改进方法的搜索过程**极其低效且昂贵**。每个候选修改都必须用完整的基准任务套件重新评估，才能估计其效用。文献报道 SWE-Bench 上的评估成本可高达约 22,000 美元、消耗数千 CPU 小时，严重阻碍了该领域的研究可及性。
- **瓶颈识别**：作者将自我改进的主要瓶颈归结为**评估方法的信号-成本权衡差**——完整基准执行信号可靠但代价极高；小规模任务子集便宜但信号噪声大。
- **核心主张**：通过引入一个独立的 LLM 评判器（LLM-as-a-judge）对自我改进提案进行评分，提供**廉价、中间的偏好信号**，从而在昂贵下游评估之前就能指导搜索方向。据此提出 **SIFT**（Recursive Self-Improvement via Fast Tree Search）框架。
- **整体意义**：论文指出，自我改进的关键瓶颈不仅是"生成候选修改"，更是"决定哪些修改值得进一步投入"。SIFT 通过将**廉价排序**与**昂贵验证**分离，显著降低了递归自我改进的算力与资金门槛。

## 2. 方法论

### 2.1 核心思想
- 维护一个候选智能体 harness 的**存档（archive）**，构成搜索树；用**成对 LLM 评判**产生廉价的中间信号，再用**正则化 Bradley-Terry 模型**将稀疏的胜负记录聚合为全局强度分数；分数仅通过**排名**驱动父节点采样与评估优先级；整个流水线**解耦（disaggregated）**，使扩展（expansion）与评估（evaluation）可并行推进。

### 2.2 关键技术细节

- **递归自我改进循环**：编码模型（coding model）负责实际解题；自我改进模型（self-improving model）位于上一层，根据当前代码和诊断上下文（评估日志、失败轨迹）识别弱点并写出补丁，产生子智能体；子智能体通过下游任务评估反馈信号，驱动下一轮修改。

- **LLM-as-a-judge**：
  - 评判器**从不接触基准任务或任务结果**，仅比较两个候选智能体的实现代码。
  - 每个新子节点与存档中**最多 K=10 个**表现最强的既有节点（按评判排名 + 准确率排名选取）进行成对比较。
  - 输入格式有两种变体："Diffs"（根实现 + diff 链）与 "Full files"（完整源文件）。消融显示 **Full files** 的 Spearman 相关性达 0.68，远高于 Diffs 的 0.40（见表 6），故默认采用完整文件、不做 swap-order。

- **Bradley–Terry 聚合**：
  - 假设每个节点 i 有潜在正强度参数 θ_i，P(i ≻ j) = θ_i / (θ_i + θ_j)。
  - 用全局胜负矩阵 W（W_ij 为 i 被偏好于 j 的次数）联合解释所有成对偏好。
  - 引入**正则化伪计数 λ**（防止新节点因比较数据少而得分不稳定），并对分数归一化使 Σθ_i = n。
  - 用标准 minorization–maximization (MM) 不动点迭代求解，收敛条件为最大绝对变化 < 10⁻⁶ 或 100 次迭代。

- **基于排名的父节点采样**（公式 1）：
  ```
  P(i) ∝ exp( −α·r_b(i) − β·r_a(i) − η·log(1 + v_i) )
  ```
  其中 r_b(i) 为 BT 强度排名，r_a(i) 为基准准确率排名，v_i 为节点 i 已被选为父节点的次数（访问计数惩罚项）。默认 α=β=η=1。尚未完成评估的节点暂时继承父节点的准确率。

- **解耦流水线（Algorithm 1）**：
  1. 按公式 1 采样待扩展节点，先跑**4 任务的"easy subset"门控**，立即过滤损坏补丁；
  2. 将改进后的智能体与强 incumbent 比较并重新拟合 BT，得到强度 b_i 与排名 r_b(i)；
  3. 将新智能体插入**评估优先队列**，按 r_b(i) + r_a(i) 排序；
  4. 扩展与评估**并行运行**，扩展不必等待完整评估完成。
  - 采用**固定子集**比较准确率（而非随机采样），以保证节点间可比、公平。

- **理论支撑**（附录 B.4）：
  - **定理 1**：对任意非负 W 与 λ>0，正则化 BT 对数似然在归一化子空间上有唯一最大值（严格凹 + 上水平集有界）。
  - **定理 2**：在随机设计 BT 模型下，正则化 BT MLE 可恢复 top-K 潜在前沿（含误差界与分离间隙条件）。
  - **命题 1**：指数排名采样将概率质量集中到 top-M 节点，相比均匀采样的放大因子为 (n/M)·(1−e^{−αM})/(1−e^{−αn})。
  - **命题 2**：固定存档下，任意 η≥0 时每个节点几乎必然被采样无限次（无永久饥饿）。
