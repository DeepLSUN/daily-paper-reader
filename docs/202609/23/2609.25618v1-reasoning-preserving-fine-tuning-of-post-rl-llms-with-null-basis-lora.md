## 摘要
基于强化学习（RL）的后训练已成为激发大语言模型（LLM）推理能力的有效方法。然而，通过后续监督微调（SFT）使 RL 后模型适应新知识领域或行为，可能会严重覆盖这些能力。现有方法通过经验回放、专门初始化或使用梯度投影的约束优化来缓解此类遗忘，但要么保持能力有限，要么带来大量训练开销。我们的分析表明，推理激活集中在低维子空间中，为适应留下了充足的零空间容量，并且相应的近似零空间可以从少量样本中可靠估计。受这些观察启发，我们提出零空间基低秩适应（Null-Basis Low-Rank Adaptation, NB-LoRA），一种参数高效的方法，用于在适应 RL 后 LLM 的同时保持其已获得的推理能力。我们将推理保持形式化为逐层隐藏状态保持约束，并从推理激活中构建固定的近似零空间基。随后，LoRA 更新通过该基进行重参数化，从而在微调过程中始终施加保持约束。在多个经 RL 训练的 LLM 和多样化下游任务上的大量实验表明，NB-LoRA 在适应性能上匹配标准 LoRA，将推理准确率保持在接近微调前水平，并将这种保持能力泛化到留出的推理基准。

## Abstract
Reinforcement learning (RL)-based post-training has become an effective approach for eliciting reasoning capabilities in large language models (LLMs). However, adapting post-RL models to new knowledge domains or behaviors through subsequent supervised fine-tuning (SFT) can severely overwrite these capabilities. Existing approaches mitigate such forgetting through experience replay, specialized initialization, or constrained optimization using gradient projection, but either provide limited preservation or incur substantial training overhead. Our analysis shows that reasoning activations concentrate in low-dimensional subspaces, leaving substantial null-space capacity for adaptation, and that the corresponding approximate null spaces can be reliably estimated from a modest number of examples. Motivated by these observations, we propose Null-Basis Low-Rank Adaptation (NB-LoRA), a parameter-efficient method for adapting post-RL LLMs while preserving their acquired reasoning ability. We formulate reasoning retention as a layer-wise hidden-state preservation constraint and construct a fixed approximate null basis from reasoning activations. LoRA updates are then reparameterized through this basis, enforcing the preservation constraint throughout fine-tuning. Extensive experiments across multiple RL-trained LLMs and diverse downstream tasks show that NB-LoRA matches standard LoRA in adaptation performance, maintains reasoning accuracy near pre-fine-tuning levels, and generalizes this preservation to held-out reasoning benchmarks.

## 1. 核心问题与研究动机

- **背景**：基于强化学习（RL）的后训练（如 GRPO）已成为激发大语言模型推理能力的有效手段。但这类 RL 方法主要是在**重塑基础模型已有的输出分布**，而非注入新知识；且 RL 仅对基础模型做轻微扰动，使模型在分布上仍接近基础模型。
- **核心矛盾**：RL 后的模型往往需要后续的监督微调（SFT）来注入新知识或调整响应风格，但 SFT 缺乏像 RL 那样的分布约束，容易大幅偏离原分布，**严重覆盖（overwrite）RL 阶段获得的推理行为**，造成灾难性遗忘。
- **现有方法的局限**：
  - 经验回放（Experience Replay）：需要精细平衡旧推理数据与新任务数据，回放不足难保持、回放过量难适配。
  - 零空间梯度投影（如 NSCL）：在全模型尺度上约束更新，带来**巨大的计算与显存开销**（每步需 O(d³) 投影）。
  - 特殊初始化方法（LoRA-Null、MiLoRA）：仅在初始化阶段利用零/次奇异子空间，**不约束后续训练更新**，仍可能覆盖推理行为。
- **核心研究问题**：如何高效地将 RL 训练的 LLM 适配到新任务，同时保留其已获得的推理能力？
- **关键观察（动机依据）**：
  - 推理激活尽管来自很长的推理轨迹，却**集中在低维子空间**中，留下大量零空间容量可用于适配。
  - 对应的近似零空间可**从少量样本中可靠估计**。

## 2. 方法论：Null-Basis LoRA（NB-LoRA）

### 2.1 核心思想
将"推理保持"形式化为**逐层隐藏状态保持约束**：若更新不改变某层在推理样本隐藏状态上的输出，则该层承载的推理计算得以保留。通过把 LoRA 更新**重参数化到一个固定的近似零空间基**上，使约束在参数化层面**天然成立**，从而可用任意标准优化器无约束地训练。

### 2.2 关键技术细节
- **保持约束**：设 H ∈ R^{N×n} 为某线性层在推理数据 D_r 上收集的输入隐藏状态矩阵（每行一个 token）。要求：
  - H(W + ΔW)ᵀ = HWᵀ，等价于 **HΔWᵀ = 0**。
  - 即 ΔWᵀ 的每一列都落在 H 的零空间中。
- **近似零空间构造**：
  - 对较小的 n×n 矩阵 **G = HᵀH** 做特征分解；
  - 保留占 99% 谱能量的主特征向量（丢弃），其余特征向量堆叠为近似零空间基 **N_s ∈ R^{n×k}**，满足 HN_s = 0；
  - 利用 Transformer 中 Q/K/V 共享同一输入隐藏状态的性质，**同一输入的投影共享一个 N_s**，显著降低构造开销。
- **重参数化**：
  - ΔW = **B C N_sᵀ**，其中 B ∈ R^{m×r}、C ∈ R^{r×k} 可训练，N_s 冻结；
  - 于是 HΔWᵀ = H N_s Cᵀ Bᵀ = 0 对任意 B、C 恒成立，**约束由构造保证**。
  - 可理解为标准 LoRA 中 A = C N_sᵀ，即把 A 的行空间限制在推理状态矩阵的零空间内；引入秩 r 瓶颈可进一步减少参数量（可训练参数 mr + rk < 标准 LoRA 的 mr + rn）。
- **三阶段算法流程**（Algorithm 1）：
  1. **Stage 1 Rollout**：用 RL 后模型在 D_r 子集上生成轨迹，收集各目标层全部 token 的输入隐藏状态 H。
  2. **Stage 2 零基计算（离线一次）**：对每层计算 G = HᵀH 的特征分解，丢弃覆盖 99% 谱能量的主特征向量，其余堆叠为 N_s。
  3. **Stage 3 约束适配**：冻结 W 与 N_s，用标准 SFT 目标优化 {B, C}。
- **理论性质**：由于 N_s 列正交，右乘 N_sᵀ 是 Frobenius 等距映射，保持损失的梯度 Lipschitz 常数不变，因此 NB-LoRA 在相同光滑性假设下**继承标准 LoRA 的 O(1/log T) 收敛速率**。

### 2.3 可行性分析（论文的实证支撑）
- **谱分析**（Qwen2.5-3B，MATH-lighteval）：HᵀH 特征值在前几百个索引内快速衰减数个量级，说明隐藏状态确实张成真子空间；99% 能量阈值下各层零空间维度占比约 29%–45%（QKV 平均 34.3%、Down 45.1%、Up 29.2%）。
- **零空间稳定性**：以 4096 样本估计的零空间为参照，用主角度衡量相似度，发现**约 512 个样本后趋于稳定**。

## 6. 主要结论与发现

- **标准 LoRA 会严重破坏推理能力**：Qwen2.5-3B 从 63.8% 掉到 8.3%，1.5B 从 80.1% 掉到 9.4%。

- **效率显著优于 NSCL**：在 Qwen2.5-3B 上快 6.3×、峰值显存少 2.1×，且随模型增大差距进一步扩大（NSCL 需全模型优化器状态 + O(d²) 投影器 + 每步 O(d³) 投影）。
- **消融结论**：
  - MLP 投影对下游适配最关键（仅调 Q/K/V 严重欠拟合）；MLP-only 或 Q/K/V+MLP-Up 可作为低成本替代；

- **顺序多任务可行**：经 8 任务常识 + 工具使用两阶段适配后，推理能力仍接近 RL 后水平，且零空间仍有约 25%–33% 余量，未耗尽。

## 7. 优点

- **方法设计优雅**：将约束编码进参数化结构而非训练循环，**无需回放数据、无需每步梯度投影**，可用任意标准优化器，保留标准 LoRA 的工程简洁性。
- **理论支撑完整**：给出零空间基右乘为等距映射的引理，证明光滑性常数不变，从而严格继承 O(1/log T) 收敛率。
- **参数更省**：引入秩 r 瓶颈后，可训练参数 mr + rk 小于标准 LoRA 的 mr + rn。
- **利用结构复用**：Q/K/V 共享输入隐藏状态，零空间只需计算一次，进一步降低开销。
- **实证扎实**：既有谱分析与主角度相似度等可行性验证，又有留出基准的泛化检验和逐任务消融；效率对比给出结构性解释而非仅经验数据。
- **实用性强**：仅需约 64–512 条推理样本即可稳定估计零空间，阈值选择有较宽鲁棒区间，便于实际部署。

## 8. 不足与局限

- **模型规模有限**：仅在 1.5B 与 3B 模型上验证，未涉及 7B 以上或 MoE 架构，"随规模扩大效率优势更明显"的论断主要基于结构性推断而非大规模实测。
- **算力信息不透明**：未披露 GPU 数量、总训练时长与总算力消耗，复现与成本评估受限。
- **近似零空间依赖锚点数据**：约束质量取决于 D_r 的代表性；若推理能力来源多样而锚点语料单一，或推理分布本身高维，零空间容量可能不足。论文虽做了顺序多任务实验，但长期/多轮持续适配下零空间耗尽的临界点仍未刻画。
- **阈值敏感性存在断崖**：能量阈值 0.75 时推理保持崩溃，说明超参数选择并非完全无风险，需要一定调参经验。
- **目标任务仍局限于 PEFT 场景**：未与全参数微调对比，也未讨论 LoRA 秩 r 与零空间维度 k 的交互影响。
- **评估偏差风险**：推理保持主要用准确率衡量，未评估推理轨迹质量、响应长度、格式遵循等更细粒度行为；MMLU-STEM 等留出基准与锚点基准（数学）在能力上仍有一定相关性，泛化结论的外推范围需谨慎。
- **未讨论安全/对齐影响**：约束只保护推理子空间，对 RL 阶段可能引入的其他行为（如冗长输出、过度思考）是否一并保留或加剧，未作分析。
- **应用限制**：需要预先离线收集推理轨迹并构造零基，对快速迭代或多任务频繁切换的场景，额外的离线准备成本需纳入考量。
