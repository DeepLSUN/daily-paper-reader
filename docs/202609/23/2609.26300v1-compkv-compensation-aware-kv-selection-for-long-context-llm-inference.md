## 摘要
尽管大语言模型（LLM）性能强劲，但在长上下文推理中仍受限于 KV 缓存的内存流量瓶颈。稀疏注意力通过在一部分被选中的 token 上计算精确注意力，被广泛用于加速 LLM 推理。为了恢复被排除在精确注意力之外的 token 的贡献，近期方法对遗漏的注意力尾部进行粗粒度补偿。然而，现有方法通常基于注意力质量选择 token，然后才补偿未被选中的 token。这种解耦设计忽略了二者之间的相互作用：选择应优先考虑若被省略会导致最大补偿误差的 token。为解决这一局限，我们提出 CompKV，这是首个补偿感知的稀疏注意力框架，它将 token 划分为块，并针对下游补偿机制显式优化选择。我们的理论分析表明，块级均值补偿留下的残差由块注意力质量和块内 logit 变化共同决定。我们使用紧凑的块级统计量来近似该残差，从而得到一个可部署的选择准则。我们进一步开发了一种高效的异步实现。在 RULER 和 LongBench-Pro 上的实验表明，CompKV 在所评估的稀疏基线中表现最佳，同时相比全注意力实现了最高达 6.85 倍的自注意力加速。

## Abstract
Despite their strong performance, large language models (LLMs) are bottlenecked by KV cache memory traffic during long-context inference. Sparse attention is widely used to accelerate LLM inference by computing exact attention over a selected subset of tokens. To recover the contribution of tokens excluded from exact attention, recent methods apply coarse-grained compensation to the omitted attention tail. However, existing methods typically select tokens based on attention mass and only then compensate for the unselected tokens. This decoupled design overlooks their interaction: selection should prioritize tokens that would leave the largest compensation error if omitted. To address this limitation, we introduce CompKV, the first compensation-aware sparse attention framework that divides tokens into blocks and explicitly optimizes selection for the downstream compensation mechanism. Our theoretical analysis shows that the residual left by block-level mean compensation is governed by both block attention mass and within-block logit variation. We approximate this residual using compact block-level statistics, yielding a deployable selection criterion. We further develop an efficient asynchronous implementation. Experiments on RULER and LongBench-Pro show that CompKV performs best among the evaluated sparse baselines while delivering up to a $6.85\times$ self-attention speedup over full attention.

## 1. 论文核心问题与整体含义

- **研究背景**：长上下文 LLM 推理中，KV 缓存随上下文增长，自回归解码每步都要读取完整 KV 缓存，导致内存流量成为主要瓶颈。稀疏注意力通过只对一部分 token 计算精确注意力来加速推理。
- **现有方法的问题**：近期方法通常把 KV 分块，并补偿未选中块对注意力的贡献。但选择与补偿是**解耦**的：先按注意力质量或预测相关性选块，再对未选块做粗粒度补偿。
- **关键矛盾**：高注意力质量的块未必“难重建”；低注意力质量但块内 logit 变化大的块，被均值补偿后可能留下更大残差。因此，选择应优先保留**补偿后残差最大**的块，而不是简单保留注意力质量最大的块。
- **整体含义**：论文提出 CompKV，声称是首个**补偿感知**的稀疏注意力框架，将块选择显式面向下游补偿机制优化，以在固定精确读取预算下提升长上下文推理质量与效率。

## 2. 方法论：核心思想、技术细节与算法流程

- **核心思想**：
  - 将 KV 缓存划分为连续块。
  - 选中 Top-K 块进行精确注意力计算；未选中块用块级均值统计进行 **Mean compensation**。
  - 选择准则不再只看注意力质量，而是估计“若省略该块，Mean compensation 会留下多大残差”。
- **理论分析**：
  - 定义每个查询头的全注意力分布 \(P_g\) 与补偿后分布 \(\hat P_g(S)\)，选择损失为 KL 散度之和：
    \[
    L(S)=\sum_{g=1}^G D_{KL}(\hat P_g(S)\|P_g)
    \]
  - 推导出 KL 可写成 log-partition 形式，并进一步展开为未选块残差。
  - 对块内 logit 做二阶 Taylor 展开后，单个未选块的残差近似为：
    \[
    p_{g,b}\left(1-\frac{|b|e^{\bar z_{g,b}}}{Z_{g,b}}\right)
    \approx p_{g,b}\left(\frac12 \sigma_{g,b}^2+O(\sigma_{g,b}^3)\right)
    \]
  - 因此，在二阶意义下，选择应最大化：
    \[
    \sum_{b\in S}\sum_{g=1}^G p_{g,b}\sigma_{g,b}^2
    \]
    即块注意力质量与块内 logit 方差的乘积。
- **可部署估计**：
  - 每个块存储紧凑统计：块大小 \(|b|\)、均值 key \(\bar k_b\)、分组 key 方差 \(\bar D_b\in\mathbb R^r\)、均值 value \(\bar v_b\)。每块约 \(2d+r+1\) 个标量。
  - 用查询坐标平方和加权分组方差，估计块内 logit 方差：
    \[
    \hat\sigma_{g,b}^2=\frac1d\sum_{t=0}^{r-1}\left(\sum_{i\in G_t}q_{g,i}^2\right)(\bar D_b)_t
    \]
  - 用二阶 log-partition 近似估计注意力质量：
    \[
    \hat p_{g,b}=
    \frac{|b|\exp(\bar z_{g,b}+\frac12\hat\sigma_{g,b}^2)}
    {\sum_{c\in B}|c|\exp(\bar z_{g,c}+\frac12\hat\sigma_{g,c}^2)}
    \]
  - 最终块分数：
    \[
    S_b=\sum_{g=1}^G \hat p_{g,b}\hat\sigma_{g,b}^2
    \]
- **选择与解码流程**：
  - 强制保留第一个 sink 块和最近两个块，并计入预算。
  - 其余块按 \(S_b\) 取 Top-K。
  - 选中块使用原始 K/V 精确计算；未选中块使用均值摘要补偿。
  - 两类贡献在分母中联合归一化，输出最终注意力结果。
- **高效实现**：
  - 完整 BF16 KV 缓存和 FP32 块摘要放在 pinned CPU 内存。
  - GPU 上融合 kernel 更新当前块统计并打包 K/V。
  - 主 CUDA 流负责选择区域传输、块统计与 Top-K 评分；辅助流传输均值并计算 Mean compensation。
  - 辅助流与 CPU gather、H2D 传输、FlashInfer 精确注意力重叠，最后合并结果。
