## 摘要
大语言模型（LLM）智能体为实现无需人工干预、自主管理长期物理任务提供了一条有前景的路径。然而，物理任务要求智能体持续观察环境、采取具有重要后果的行动，并在环境变化时仍保持有效。现有方法要么需要大量数据和重新训练，要么主要关注在虚拟世界中运行的智能体。在本工作中，我们探索构建一种自适应物理 AI 智能体的可行性：该智能体能够以零样本方式管理长期物理任务，并在无需人工干预的情况下适应环境变化。我们设计了一个集规划、工具调用、观察与验证于一体的多智能体框架，并在不同天气模式下针对农业任务将其与强化学习（RL）智能体进行评估。结果表明，在相同天气模式下，零样本 LLM 智能体能够取得与 RL 智能体相当的管理效果；而在环境发生偏移时进行评估时，其适应能力优于 RL，这凸显了通向自适应物理 AI 智能体的一条有前景的路径。

## Abstract
Large Language Model (LLM) agents offer a promising path toward autonomously managing long-term physical tasks without human intervention. However, physical tasks require agents to continuously observe the environment, make consequential actions, and remain effective as the environment changes. Existing approaches either require substantial data and retraining, or primarily focus on agents operating in the virtual world. In this work, we explore the feasibility of building a self-adaptive physical AI agent that manages long-term physical tasks in a zero-shot manner and adapts to environmental changes without human intervention. We design a multi-agent framework that integrates planning, tool calling, observation, and verification, and evaluate it on agricultural tasks against reinforcement learning (RL) agents under different weather patterns. Our results show that zero-shot LLM agents can achieve comparable management outcomes to RL agents under the same weather pattern and adapt more effectively than RL when evaluated under a shifted environment, highlighting a promising path toward self-adaptive physical AI agents.

- **核心问题**：LLM 智能体能否在**零样本（zero-shot）、无人类干预、无重训练**的条件下，自主管理**长时程物理任务**，并在**环境发生偏移**时持续自适应？

  - 物理任务要求智能体持续观测环境、执行**不可逆**的动作，并在数月量级的时间跨度上保持有效（如"帮我照顾植物"这一设想）。
  - 传统信息物理系统（CPS）方法（规则控制、PID、MPC、RL）依赖人工规则或显式模型，且 **RL 训练代价高**（如 HVAC 控制需数十年等效运行数据）、**对环境偏移敏感**，部署环境一变往往失效。
  - 现有 LLM 智能体大多运行在**虚拟/软件环境**中，或依赖人类引导与验证；具身 LLM 工作又多依赖机器人示范与预训练控制策略，缺乏"在真实物理过程中自主适应"的证据。
- **整体含义**：论文将这类系统命名为 **Physical AI Agents**，并以**农业作物管理**作为代表性长时程物理任务（长周期、不可逆动作、奖励延迟），尝试验证"结构化多智能体推理 + 结果反馈"能否替代"数据驱动的策略训练"，为自适应物理 AI 提供一条可行路径。

## 2. 方法论

### 2.1 核心思想
- 用一个**零样本提示的多智能体框架**，把长时程物理决策分解为**感知 → 管理 → 决策 → 修订 → 安全校验 → 执行 → 反思**的闭环，通过**角色分离 + 信息与权限受限 + 独立验证**抑制幻觉，通过**反思引导的回合内反馈**实现持续自适应。

### 2.2 问题形式化
- 每个决策步 $t$，智能体接收观测 $o_t$，依据历史 $h_t=(o_0,a_0,\dots,o_{t-1},a_{t-1},o_t)$ 选择动作 $a_t=\pi(h_t)$。
- 多目标优化：主目标最大化成熟期产量 $Y$，次目标最小化累计资源消耗 $C=\sum_{t=0}^{T-1}c(a_t)$：
  - $\pi^\star \in \arg\max_\pi \left(\mathbb{E}_\pi[Y] - \mathbb{E}_\pi[C]\right)$
  - 注：正文称 $\lambda \ge 0$ 控制权衡，但公式中**未出现 $\lambda$**，属表述不一致。

### 2.3 框架流程（8 个组件）
1. **Environment**：提供作物状态（确定性 step）。
2. **Perception Agents（6 个，确定性）**：各自只负责指定环境变量，输出结构化报告，不得凭空创造测量值。
3. **Manager Agent（LLM）**：仅汇总 6 份报告、识别关系与冲突，产出统一状态摘要；**不得引入新测量或直接选动作**。
4. **Decision Agent（LLM）**：选择干预类型并给出用量。
5. **Revision Agent（LLM）**：独立复核用量，可批准/上调/下调，但**不能改变干预类型、不能改成 no-op**。
6. **Execution Safety Guard（确定性）**：校验动作是否合法、合规、量化正确、编码无误。
7. **Action Agent**：编码并执行动作。
8. **Reflection Agent（LLM）**：评估已执行动作的实际结果，并将**角色定制的反馈**分别回传给 Manager（解读是否有据）、Decision（干预是否有效、是否考虑替代方案）、Revision（用量是否恰当）；其余组件不接收反馈，保持确定性。

### 2.4 两个关键设计原则
- **幻觉抑制**：责任分离 + 限制各智能体的信息与权限 + 执行前独立验证，避免无依据推理直达环境。
- **反思引导自适应**：回合内（within-episode）反馈把上一动作的结果接入下一轮决策，实现"不更新参数"的行为级适应（非参数级学习、非永久策略变更）。

## 3. 实验设计

- **仿真环境 / Benchmark**：WOFOSTGym 的 `lnpkw-v0` 环境，模拟氮磷钾与水分受限下的年度作物生长，支持对应管理动作。
- **任务设定**：模拟小麦生长季，**每回合 241 天**；所有策略接收**相同 15 个环境观测变量**（IRRAD、TEMP、RAIN、DAYS、SM、TOTIRRIG、NAVAIL/PAVAIL/KAVAIL、TOTN/TOTP/TOTK、DVS、FIN、WSO），在**相同 17 个动作空间**中选择（no-op；N/P/K 各 2/4/6/8 kg/ha；灌溉 0.5/1.0/1.5/2.0 cm）。
- **两套环境**：
  - **Environment A（无偏移）**：2000 年气象，纬度 44、经度 −99（美国南达科他附近），oregon-3 土壤。
  - **Environment B（分布偏移）**：1984 年气象，纬度 50、经度 5，oregon-1 土壤；作物仍为小麦，代表季节性、气候与土壤条件的真实分布偏移。
- **对比基线（3 个）**：
  - **No-intervention**：全程 no-op，作为自然生长对照。
  - **Fixed-intervention**：按固定生育阶段施用 P/K/N，并在分蘖、拔节、抽穗、灌浆期固定灌溉。
  - **Reinforcement Learning（PPO）**：在 Environment A 训练与评估；偏移实验中直接迁移到 Environment B 测试。
- **指标**：① 累计奖励（WOFOSTGym 奖励函数）；② 最大产量（成熟期贮藏器官干重 WSO）；③ 总资源用量（N/P/K 与灌溉累计量）。

## 4. 资源与算力

- **RL 基线训练**：10 核 Apple M2 Pro CPU、16 GB 统一内存、**单环境 worker、无分布式**；约 **100 万 timesteps**，耗时 **2 小时 44 分钟**。**未使用 GPU**。
- **LLM 侧**：Manager/Decision/Revision/Reflection 均为零样本 LLM 智能体（GPT-5.6 Luna），用 OpenClaw 协调多智能体工作流；**每次运行 964 次 GPT 调用，约 2382 万 tokens**。

## 5. 实验数量与充分性

- **实验组数（大致）**：
  - 4 种策略（No-intervention / Fixed / RL / Agentic）× 2 个环境（A 无偏移、B 偏移）× 3 个指标（累计奖励、最大产量、资源用量）。
  - 即核心对比约 **8 组策略-环境配置**，加上资源用量表（表 3）的同类统计。
- **充分性评估**：
  - **未见消融实验**：没有单独验证 Perception、Manager、Revision、Safety Guard、Reflection 各组件的贡献（论文将反思机制的有效性仅用单个案例说明）。
  - **未见多次重复/方差/显著性检验**：LLM 输出具随机性，单次运行结果的稳健性无法判断。

  - **基线强度存疑**：RL 仅在 CPU 上训 100 万步、单 worker、未提及超参搜索；其迁移后产量从 5976 kg/ha 崩到 110 kg/ha，这种极端退化也可能反映**基线训练/实现不足**，而非纯粹的方法劣势，因此"偏移下大幅胜出"的**公平性需要保留**。

## 6. 主要结论与发现

- **相同环境（A）下**：零样本智能体框架达到 **4152 kg/ha** 最大产量（约为 RL 的 **69%**，RL 为 5976 kg/ha），累计奖励 **216,390** vs RL 的 **340,724**——即**未训练也能取得有竞争力的管理水平**。
- **环境偏移（B）下**：框架累计奖励 **453,956**、最大产量 **6519 kg/ha**，而迁移的 RL 仅 **4798** 与 **110 kg/ha**，框架**显著优于 RL**。
- **资源效率**：Env A 智能体用 N/P/K = 68/12/72 kg/ha、灌溉 21 cm（RL 为 554/142/258 与 141 cm）；Env B 为 98/16/100 与 28.5 cm（RL 为 632/170/360 与 113 cm）。**所有类别均低于 RL 的 28%**，说明其性能并非靠更激进的资源投入换取。
- **定性证据**：反思机制的一个实例——观察到钾施用使有效钾从 0.138 升至 1.284 后，Decision Agent 不再施钾，转而针对下降的氮有效性施用少量氮，体现了基于结果反馈的策略调整。
- **总体结论**：结构化多智能体推理 + 结果反馈，是构建**自适应物理 AI 系统**的有前景方向。

## 7. 优点（亮点）

- **零样本、免训练、免微调、免人工干预**：直接针对"物理 AI 数据昂贵、环境易漂移"的痛点，绕开数据采集与再训练成本。
- **面向物理世界的架构约束设计**：确定性感知 + 角色分离 + 信息/权限受限 + 独立用量复核 + 确定性安全闸门，形成**多层防幻觉机制**，符合不可逆动作场景的安全要求。
- **反思反馈的角色定制化**：反馈直连 Manager/Decision/Revision 且按职责裁剪，避免中间角色造成信息失真，实现"不更新参数的在线适应"。
- **资源效率突出**：在性能接近甚至（偏移下）远超 RL 的同时，资源消耗不足 RL 的 28%，兼具经济与环保意义。
- **可复现的评测基础**：采用公开作物仿真器 WOFOSTGym，观测/动作空间对全部策略统一，支持受控且可重复的对比；明确给出 token 与调用次数。
- **诚实的问题定位**：明确把"零样本自适应"作为研究问题提出，并用"同分布可比、异分布更优"两个角度分别验证。

## 8. 不足与局限

- **仅在仿真中验证**：全部实验限于 WOFOSTGym 单一作物环境，未涉及真实传感器/执行器，作者本人也将真实植物部署列为未来工作；仿真无法覆盖真实世界的噪声、部分可观测与安全风险。
- **实验规模偏小、缺少消融**：未逐组件消融（如去掉 Revision、Safety Guard、Reflection 的影响），也未做多次重复与统计显著性分析，结论稳健性证据不足。
- **基线公平性风险**：RL 仅 CPU 训练、单 worker、100 万步、未见超参搜索；其在偏移下的崩溃式表现可能低估了 RL 的真实能力（例如域随机化、微调、集成等常见做法未纳入比较），因此"大幅胜出"的结论应谨慎解读。
- **单一模型与单次运行**：仅使用一个 LLM（GPT-5.6 Luna）与一种提示设计，未做模型间对比或提示敏感性分析；LLM 的非确定性未被量化。
- **成本与可扩展性未评估**：964 次调用/回合、约 2382 万 tokens 的开销未与 RL 训练成本做经济性对比；241 天逐日调用在高频控制场景下的时延与成本可行性存疑。
- **公式与表述不一致**：优化目标中引入 $\lambda$ 的说明与公式不符，细节严谨性有待完善。
- **偏移维度有限**：只考察"气象年份 + 地理位置 + 土壤类型"的一次性组合偏移，未覆盖传感器退化、极端气候、任务目标变更等更广泛漂移。
- **元信息可核验性提示**：论文为预印本，且引用与发布时间（2026 年、GPT-5.6 Luna、OpenClaw 等）带有明显的未来/设想色彩，外部复现与引用链条的可核验性需读者自行确认。
- **应用限制**：方法依赖确定性感知层与预定义动作边界/安全上限，迁移到感知噪声大、动作空间连续、后果更难逆的领域（如医疗、工业过程控制）时，安全性论证仍不充分。
