## 摘要
大语言模型（LLM）智能体日益将自然语言推理与外部工具（如网络搜索和代码执行）交织在一起。这些工具使用策略通常通过强化学习（RL）进行优化，而 RL 可能放大训练数据中的虚假相关。在这项工作中，我们研究 RL 训练的智能体何时以及为何会学到捷径式工具选择策略：基于表面的提示线索而非真实任务需求来调用工具。我们构建了受控的合成环境，结合事实性问答和数学推理任务，并注入在训练期间与特定工具强相关、但在因果上与工具必要性无关的线索。在反事实评估中，当线索存在但相关工具并不需要时，智能体表现出显著的捷径行为，虚假工具调用率最高增加 39%。然而，捷径的形成并非普遍现象：在我们测试的各种条件下，它仅在智能体已经学会可靠使用目标工具时出现，这表明任务能力而非仅数据集不平衡，是捷径学习的关键因素。一项交换线索分析进一步表明，线索与工具之间的语义对齐会显著放大这一效应。为缓解这些失败，我们引入一种密集的、决策级奖励，其中由 LLM 评判器评估每次工具调用的必要性。这种工具必要性奖励有效抑制了线索驱动的工具使用，同时保持任务性能，为提升 LLM 智能体工具使用策略的鲁棒性提供了一种实用方法。

## Abstract
Large language model (LLM) agents increasingly interleave natural language reasoning with external tools such as web search and code execution. These tool-use policies are often optimized via reinforcement learning (RL), which can amplify spurious correlations in the training data. In this work, we study when and why RL-trained agents learn shortcut tool-selection policies: invoking tools based on superficial prompt cues rather than genuine task requirements. We construct controlled synthetic environments combining factual question answering and mathematical reasoning tasks, and inject cues that are strongly correlated with specific tools during training but causally irrelevant to tool necessity. Across counterfactual evaluations where cues are present but the associated tools are not required, agents exhibit substantial shortcut behavior, with spurious tool invocation rates increasing by up to 39 percent. However, shortcut formation is not universal: across the conditions we test, it arises only when the agent has already learned to use the target tool reliably, suggesting that task competence, rather than dataset imbalance alone, is a key factor in shortcut learning. A swapped-cue analysis further shows that semantic alignment between cues and tools substantially amplifies this effect. To mitigate these failures, we introduce a dense, decision-level reward in which an LLM judge evaluates the necessity of each tool call. This tool-necessity reward effectively suppresses cue-driven tool use while preserving task performance, providing a practical approach to improving the robustness of LLM agent tool-use policies.

# 论文总结：Spurious Tool Use: When RL Agents Learn the Wrong Reason to Act

## 1. 核心问题与研究动机

- **背景**：LLM 智能体日益将自然语言推理与外部工具（如网络搜索、代码解释器）结合，并通过强化学习（RL）优化工具调用策略。RL 的目标是让智能体学会“何时调用哪个工具”。
- **核心问题**：RL 优化会放大训练数据中的虚假相关（spurious correlation），使智能体学到**捷径式工具选择策略**——依据表面的提示线索（如格式标签、来源标记）而非真实任务需求来调用工具。
- **与已有问题的区别**：
  - 不同于“工具使用低效或过度调用”的研究，本文聚焦**线索驱动的虚假工具选择**（cue-driven spurious tool selection）。
  - 该捷径发生在**中间策略决策层**（调用哪个工具），而非最终预测层。
- **隐蔽性**：不必要的工具调用不一定导致答案错误（例如调用搜索后忽略结果仍答对），因此标准评估只看最终答案正确性时，这类虚假行为难以被发现。
- **关键张力**：研究发现捷径脆弱性与**任务能力**强相关——智能体越能可靠使用某工具，越容易形成线索与工具之间的虚假关联，即“能力提升可能同时增加捷径易感性”。

## 2. 方法论

### 2.1 问题形式化

- 借鉴 Sagawa 等人的组鲁棒性框架：输入 $x=(x_c, a)$，其中 $x_c$ 为因果特征，$a$ 为与标签相关但非因果的虚假属性；组定义为 $G = Y \times A$。
- **工具虚假相关定义（Definition 1）**：若虚假属性 $a$ 的存在使策略选择工具 $T_s$ 的概率超出仅凭任务相关特征应有的水平（$\pi_\theta(T_s|x_c,a) \gg \pi_\theta(T_s|x_c)$），且该工具对任务性能无贡献（$P(R=1|x_c,T_s) \le P(R=1|x_c,T \ne T_s)$），则存在工具虚假相关。
- **操作化指标**：构造反事实评估组——同一问题分别加线索（Y）与不加线索（N），计算 $\Delta \text{Tool}_{Y-N} = \hat\pi_\theta(T_s|x_c,a) - \hat\pi_\theta(T_s|x_c)$。在不需要该工具的任务上 $\Delta > 0$ 即表明存在捷径。

### 2.2 合成数据集构造

- 数据来源：**NQ**（需网络搜索的事实问答）与 **DeepMath-103k**（需 Python 解释器的数学推理），各采样 500 条，构成 1000 条平衡训练集。
- **线索注入**：将线索注入其中一个子集（NQ 或 DeepMath），另一子集保持不变，每个线索单独训练一次以隔离效应。所有线索对工具必要性均因果无关。
  - **搜索语义线索**（注入 NQ）：`[WEB INDEX 742]`、`[REFERENCE]`（前缀）、`<answer>`（后缀格式指令）。
  - **代码语义线索**（注入 DeepMath）：`# Cell [1] | kernel: python3 | status: idle`、`#!/usr/bin/python3`、`[CODE]`（均为前缀）。
- **反事实评估组**：对每个测试问题构造“有线索 / 无线索”两个变体，并在 2Wiki（事实）与 GSM8K（数学）上做分布外评估。

### 2.3 工具必要性奖励（缓解方法）

- **核心思想**：标准 RL 仅在最终答案上给奖励，工具选择决策缺乏监督；本文引入**密集的决策级奖励**，对每次工具调用评估必要性。
- **必要性定义**：若一个有能力模型无法在不使用该工具的情况下正确回答问题，则该调用必要；纯便利性调用（如简单算术、格式化、二次确认）视为不必要。
- **LLM 评判器**：使用 GPT-5 Nano，输入问题 $q$、工具类型 $\tau_t$、工具输入 $x_t$，输出二元必要性标签 $\hat n_t$。评判的是“该工具对解题是否必要”，而非工具输入本身是否合理。
- **总奖励**：$r_{total} = r_{task} + \sum_t r_{nec}^t$，其中 $r_{nec}^t = -\alpha$（当 $\hat n_t = 0$），否则为 0；$\alpha = 0.5$。仅惩罚不必要调用，避免激励无意义地多用工具。

### 2.4 训练设置

- 框架：**VerlTool**（模块化智能体 RL 框架）；算法：**GRPO**；基座模型：**Qwen2.5-7B-Instruct**。
- 工具通过结构化标签触发：`<python>...</python>` 调用 Python 解释器，`<search>...</search>` 调用网络搜索。

## 6. 主要结论与发现

- **捷径确实存在且显著**：搜索语义线索使数学任务上的虚假搜索调用率最高增加 **+39.2%**（GSM8K 上 `[WEB INDEX 742]`），DeepMath 上 +19.9%～+21.7%。
- **捷径形成具有选择性**：代码语义线索注入 DeepMath 后，在事实任务上几乎不产生虚假 Python 调用（$\Delta Py$ 多为 −0.3～+0.7，2Wiki 上 `[CODE]` 仅 +3.8）。尽管组不平衡程度相同，效果却不对称。
- **任务能力是关键因素**：NQ 验证准确率从约 45% 稳步升至约 75%，而 DeepMath 始终停留在 45–50%。捷径只在智能体已可靠掌握的工具上形成——**能力而非单纯数据不平衡**驱动捷径学习。
- **语义对齐起调节作用**：交换线索实验显示，代码线索与已掌握的事实任务配对时，$\Delta Search \le 3.5\%$；而语义对齐时可达 39.2%。即任务能力“使能”捷径，语义对齐“放大”其强度。
- **相关性强度存在阈值效应**：相关性 ≥80% 时捷径明显，≤70% 时基本消失。
- **工具必要性奖励有效**：加入该奖励后，所有条件下虚假工具调用降至接近 0，且任务准确率保持或提升（如 DeepMath 上 55.2/57.2，GSM8K 上 91.8/89.2）。

## 7. 优点

- **问题新颖且有现实意义**：首次系统研究 RL 工具使用智能体的“线索驱动虚假工具选择”，揭示了最终答案正确性评估掩盖的隐蔽失败模式。
- **形式化严谨**：将组鲁棒性框架扩展到中间工具选择决策，给出可操作的反事实度量 $\Delta \text{Tool}_{Y-N}$。
- **实验设计精巧**：
  - 合成环境严格控制变量，可归因于线索而非分布混淆；
  - 反事实评估组 + 交换线索设计有效解耦“任务能力”与“语义对齐”两个因素；
  - 相关强度扫描揭示阈值效应。
- **缓解方法实用**：工具必要性奖励思路简洁（LLM 评判 + 密集惩罚），效果显著且不损害性能，具有实际部署价值。
- **重要洞见**：提出“能力—脆弱性耦合”的观点，对智能体安全与鲁棒性研究有启发。

## 8. 不足与局限

- **规模与泛化性**：
  - 合成数据集仅 1000 条、训练仅 30 步，结论在更大规模、自然训练环境中的有效性未知；
  - 仅一个基座模型、一个随机种子，统计显著性存疑。
- **混淆因素**：任务能力与语义对齐虽经交换线索解耦，但 DeepMath 本身未被学会这一事实可能同时影响工具使用频率与线索学习，二者仍非完全独立。
- **应用限制**：
  - 工具必要性奖励依赖 GPT-5 Nano 评判器，可能引入该模型固有偏见；论文也承认这只是“实用设计选择”而非工具必要性的确定标准；
  - 仅覆盖搜索与代码两种工具，多工具、工具组合场景未涉及。
- **偏差风险**：线索设计偏向人工构造（如 `[WEB INDEX 742]`），真实提示中线索形态更复杂、更隐晦，结论的外部效度需进一步验证。
- **阈值普适性**：约 80% 的相关性阈值是否跨线索、跨训练规模成立，论文明确列为开放问题。
