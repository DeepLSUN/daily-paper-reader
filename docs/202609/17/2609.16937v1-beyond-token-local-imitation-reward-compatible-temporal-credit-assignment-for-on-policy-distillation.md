## 摘要
同策略蒸馏（OPD）已成为大语言模型后训练的一种有效方法，但现有目标在目标保真度与优化稳定性之间面临权衡。词元级 OPD 提供稳定但局部的监督，而序列级 OPD 能够捕捉未来信用，但代价是依赖于时域的方差。我们建立了这些形式化的统一时序信用视角，表明实际的词元级 OPD 可以解释为对序列级反向 KL 梯度的一种时序近似。基于这一联系，我们提出 γOPD，它使用折扣时序信用分配来平衡长时域监督与优化稳定性，同时具有与视界无关的方差界。我们进一步为 γOPD 开发了一种奖励兼容的有界混合（RBM）机制，该机制平衡可验证结果反馈与折扣 OPD 优势，从而超越纯粹依赖教师的优化。在数学与代码推理任务上的实验表明，在常规、规模不匹配和多教师蒸馏设置下，该方法相较现有 OPD 方法均取得一致改进。

## Abstract
On-policy distillation (OPD) has emerged as an effective approach for large language model post-training, yet existing objectives face a trade-off between objective fidelity and optimization stability. Token-level OPD provides stable but local supervision, whereas sequence-level OPD captures future credit at the cost of horizon-dependent variance. We establish a unified temporal-credit view of these formulations, showing that practical token-level OPD can be interpreted as a temporal approximation to the sequence-level reverse-KL gradient. Building on this connection, we propose $γ$OPD, which uses discounted temporal credit assignment to balance long-horizon supervision and optimization stability, while admitting a horizon-independent variance bound. We further develop a reward-compatible bounded mixing (RBM) mechanism for $γ\mathrm{OPD}$ that balances verifiable outcome feedback with the discounted OPD advantage to move beyond purely teacher-dependent optimization. Experiments on mathematical and code reasoning demonstrate consistent improvements over existing OPD methods across vanilla, size-mismatched, and multi-teacher distillation settings.

## 1. 核心问题与研究动机

- **背景**：同策略蒸馏（On-Policy Distillation, OPD）已成为大语言模型（LLM）后训练的关键手段。它在学生策略自己采样出的轨迹上提供教师模型的稠密监督，既提升推理质量，又缓解暴露偏差（exposure bias）。
- **核心矛盾**：现有 OPD 目标存在**目标保真度 vs. 优化稳定性**的两难：
  - **词元级 OPD**（token-level）：为规避全词表反向 KL 的高昂开销，被改写为策略梯度形式，用单样本词元级蒙特卡洛估计，计算高效，但只提供**局部**监督，相对序列级目标存在不可忽视的偏差，实质上改变了优化问题。
  - **序列级 OPD**（sequence-level）：用序列级蒙特卡洛估计更忠实地保留原始目标，但需在剩余响应上累积未来信用，**方差随序列长度增长**，长推理轨迹下训练不稳定。
- **整体含义**：论文试图从统一的"时序信用分配"视角厘清两类目标的联系，并给出一个能在长时域监督与稳定性之间可控折中、同时能吸收可验证奖励信号的新框架 γOPD。

## 2. 方法论

### 2.1 统一时序信用视角（理论基础）

- **记号**：定义词元级对数比 $\Delta_t=\log\pi_\theta(y_t|h_t)-\log\pi^*(y_t|h_t)$，序列级对数比 $\Delta(y)=\sum_{t=1}^T \Delta_t$。
- **两个目标的区分**：
  - 序列级目标 $J^{\text{seq}}_{\text{OPD}}=\mathbb{E}[D_{KL}(\pi_\theta(y|x)\|\pi^*(y|x))]$；
  - 词元级目标 $J^{\text{token}}_{\text{OPD}}$ 在各前缀上比较下一词元分布，前缀分布 $\bar d_\theta(h_t|x)$ 采用 **stop-gradient**。
- **关键洞察（命题 3.1 / 3.2）**：
  - 词元级梯度为 $\sum_t \Delta_t \nabla_\theta\log\pi_\theta(y_t|h_t)$，恰好还原实践中常用的 OPD 更新；
  - 序列级梯度为 $\sum_t \left(\sum_{t'=t}^{T}\Delta_{t'}\right)\nabla_\theta\log\pi_\theta(y_t|h_t)$，即每个词元的权重是**从当前步到末尾的未来对数比之和**。
  - 结论：实践中的词元级 OPD 可视为序列级反向 KL 梯度的一种**时序截断近似**，其差距源于前缀分布的 stop-gradient 处理。

### 2.2 γOPD：折扣时序信用分配

- **核心思想**：引入折扣因子 $\gamma\in[0,1]$，控制当前词元能分得多少未来 OPD 信用，从而在词元级与序列级之间插值。
- **折扣优势定义**：$A^{(\gamma)}_t \triangleq -\sum_{t'=t}^{T}\gamma^{t'-t}\Delta_{t'}$
  - $\gamma=1$：退化为序列级 return-to-go（恢复式 6）；
  - $\gamma=0$：退化为词元级优势 $A^{(0)}_t=-\Delta_t$（恢复式 5）。
- **方差稳定性定理（定理 3.3）**：在词元级优势二阶矩有界（$\le\sigma_\Delta^2$）的假设下，
  - 序列级信用的方差上界为 $(T-t+1)^2\sigma_\Delta^2$，**随时域二次增长**（最坏情形可达）；
  - γOPD 信用方差上界为 $\sigma_\Delta^2/(1-\gamma)^2$，对任意固定 $\gamma<1$ **与时域无关**。
  - 因此调节 γ 提供了稳定性与长时域信用传播之间的原则性权衡。

### 2.3 奖励兼容有界混合（RBM）

- **动机**：γOPD 的信号仍源于教师分布，学生受教师能力上限约束，缺少面向可验证任务的显式任务级信号。
- **朴素结合的隐患**：教师优势 $A^{(\gamma)}_t$ 的量级跨响应差异大，可能压倒取值范围为 $\{-1,1\}$ 的任务奖励。
- **RBM 三步操作**：先按响应内平均绝对量级归一化 → 经 softsign 类变换有界化到 $(-1,1)$ → 再与可验证奖励相加，即
  $\hat A^{(\gamma)}_t = \dfrac{A^{(\gamma)}_t}{\frac{1}{T}\sum_k |A^{(\gamma)}_k| + |A^{(\gamma)}_t|} + R(x,y)$（分母为零时归一化项取 0）。
- **奖励兼容性**：由于 $R\in\{-1,1\}$，可得 $\mathrm{sign}(\hat A^{(\gamma)}_t)=R(x,y)$——可验证奖励决定响应被强化还是抑制，有界 γOPD 信用只调节词元级更新强度。
- **最终代理梯度**：$\hat g_\gamma(\theta)=-\mathbb{E}\left[\sum_t \hat A^{(\gamma)}_t \nabla_\theta\log\pi_\theta(y_t|h_t)\right]$。
- **算法流程**：采样 prompt 与学生响应 → 验证器给出奖励 $R$ → 逐词元计算 $\Delta_t$ → 按折扣公式与 RBM 计算 $\hat A^{(\gamma)}_t$ → 用上式更新 θ。

## 6. 主要结论与发现

- **理论结论**：实践中的词元级 OPD 是序列级反向 KL 梯度的时序截断近似；γOPD 通过折扣在二者之间插值，并具备与时域无关的方差上界。
- **常规蒸馏**：γOPD 在 AvgAcc 上相对最强基线提升 2.30%、AvgPass 提升 1.80%，并在两项平均指标上**超过教师**，说明 RBM 能更好利用稠密教师监督并突破直接模仿。
- **规模失配蒸馏**：所有学生方法均低于教师，但 γOPD 将差距显著缩小，相对最强基线 AvgAcc 提升 4.92%、AvgPass 提升 2.06%，显示时序信用分配在弱容量学生上收益更大。
- **多教师蒸馏**：数学基准整体领先，HumanEval+ 与 LCB 为最优，TotalAvg 相对最强基线 AOPD 提升 1.87%，并在数学与代码的平均表现上均超过教师。
- **训练动态**：γOPD 全程可验证奖励最高、绝对 OPD 优势更稳定、梯度范数波动最小，响应长度收敛到较短且更稳定的区间。
- **消融**：仅加时序折扣即提升 2.04 分；去掉折扣后增益从 3.91 降到 2.00，说明折扣与有界归一化互补；朴素奖励混合仅带来 0.05 分的边际收益，说明**有界归一化是关键**。
- **γ 敏感性**：γ=1（无折扣序列级）因长响应导致梯度范数剧增与熵快速坍缩，性能最差；γ=0.99 最优，优于 0.9，表明"大但小于 1"的折扣因子是最佳折中。
- **词元优势可视化**：$A^{(0)}_t$ 稀疏、局部，可能惩罚与真实错误无关的词元；$A^{(0.99)}_t$ 信号更平滑，能把信用重新分配给与最终结果更相关的关键推导步骤，对错误公式推导给出更强负信用而不苛责末尾 token。

## 7. 优点

- **理论贡献清晰**：把词元级/序列级 OPD 统一到同一时序信用框架，严格给出两者梯度形式（命题 3.1/3.2），指出 stop-gradient 是偏差来源，并给出可证的方差界（定理 3.3），为"折扣"这一工程直觉提供了理论依据。
- **方法简洁且代价极低**：γOPD 只是对优势项加折扣，RBM 仅需归一化 + 有界变换 + 奖励相加，不引入额外模型或组内优势估计，实测额外开销约 0.1%，工程可用性强。
- **RBM 的设计精巧**：通过"有界性"保证 $\mathrm{sign}(\hat A_t)=R(x,y)$，从构造上确保可验证奖励主导强化/抑制方向，避免教师信号淹没任务信号，同时保留词元级相对信用。
- **实验设计有层次**：三种蒸馏配置 + 多领域基准 + 消融 + 敏感性 + 动态曲线 + 词元级可视化，既回答"是否有效"，也回答"为何有效"。
- **结果一致性**：在几乎所有配置下都优于多个近期 OPD/RL 基线，且能超过教师，说明方法不是单纯提高模仿保真度。

## 8. 不足与局限

- **模型规模受限**：作者明确承认实验仅在 <10B 参数模型上完成（4B 教师 / 4B 或 1.7B 学生），大模型与更长思维链下的可扩展性未验证。
- **γ 的设定依赖经验**：γ=0.99 为默认且最优，但论文未给出自适应选择 γ 的机制，其最优值可能随任务、响应长度分布变化；作者也将"自适应或熵感知折扣"列为未来工作。
- **方差界的前提较强**：定理 3.3 依赖"词元级优势二阶矩一致有界"的假设，且 γOPD 相对序列级目标仍是**有偏**代理，论文未量化该偏差对最终收敛点的影响。
- **统计稳健性证据不足**：主结果未报告多次随机种子的均值±方差或显著性检验，难以排除单次运行波动；部分提升幅度（如多教师 TotalAvg +1.87%）是否显著缺乏统计支撑。
- **评测基准的饱和与污染风险**：MATH500、HumanEval+、MBPP+ 等相对饱和，AMC23 多数方法已达 90+ 分，区分度有限；尽管使用了 LiveCodeBench 与 AIME25 等较新集合，整体仍以既有基准为主。
- **教师依赖与奖励设计**：RBM 依赖二元可验证奖励 $\{-1,1\}$，对没有可靠验证器的开放域任务（写作、开放问答等）适用性未知；RBM 中的归一化与 softsign 只保证有界性，未讨论奖励稀疏/噪声情况下的行为。
- **覆盖缺口**：论文提到但未展开的对比（如 SCOPE、RWOPD、截断类方法等）在正文中缺少直接实验对照；消融仅在 AIME 两个集合上做，未在代码或多教师场景复现，结论的普适性略受限。
- **长度偏置问题**：响应长度作为结果之一被报告，但未深入讨论折扣时序信用是否会系统性影响输出长度或引入长度偏置，这一点在长思维链场景中值得关注。
