## 摘要
深度剪枝通过移除完整的 Transformer 块来降低大语言模型（LLM）的推理成本。基于激活的方法需要在校准数据上进行前向传播以收集隐状态，而现有的无前向传播方法则分别对每个 Transformer 块进行评分，并未度量块之间的相似性。我们提出权重冗余剪枝（Weight-Redundancy Pruning, WRP），这是一种无前向传播的深度剪枝方法，它从检查点权重中估计层间冗余，从而在无需校准数据或模型前向传播的情况下选择块。WRP 比较各层的注意力输出权重与 MLP 下投影权重，并将其成对相似性与相对投影尺度信息相结合。由此得到的全对相似度矩阵用于指导层分组与块选择。在多种剪枝设置、模型家族和下游任务中，WRP 始终优于现有的无前向传播幅度剪枝方法，并接近基于激活方法的性能。

## Abstract
Depth pruning reduces large language model (LLM) inference cost by removing complete Transformer blocks. Activation-based methods collect hidden states through forward passes on calibration data, while existing forward-free methods score each Transformer block separately without measuring similarity between blocks. We propose Weight-Redundancy Pruning (WRP), a forward-free depth-pruning method that estimates inter-layer redundancy from checkpoint weights to select blocks without calibration data or model forward passes. WRP compares attention output and MLP down-projection weights across layers and combines their pairwise similarities with relative projection-scale information. The resulting all-pairs similarity matrix guides layer grouping and block selection. Across multiple pruning settings, model families, and downstream tasks, WRP consistently outperforms existing forward-free magnitude pruning and approaches the performance of activation-based methods.

# 论文总结：Forward-Free LLM Depth Pruning via Weight Redundancy（WRP）

## 1. 核心问题与研究动机

- **背景**：LLM 规模持续增长，推理所需显存与算力随之上升；而预训练模型家族通常只发布少量固定尺寸的检查点，难以匹配用户的硬件预算。**深度剪枝**（移除完整的 Transformer 块）可以在保留标准稠密算子的前提下灵活调整模型规模。
- **现有方法的两难**：
  - **基于激活的方法**（ShortGPT、LLM-Streamline、LoRP）需要在校准数据上跑前向传播、收集隐状态，能显式度量层间相似性；但对大模型而言，校准前向与激活存储的显存开销可能超过待剪枝模型本身的推理需求——**有足够显存跑剪枝后模型，却未必有足够显存完成剪枝过程**。
  - **免前向方法**（Shortened LLaMA 的 Mag / Mag+）直接从检查点权重按幅度打分，避免了前向开销；但**逐块独立评分，不度量层间冗余**，而幅度只反映单个块的尺度，并非层间相似性。
- **核心论点**：检查点权重本身蕴含可用的层间冗余信号。论文提出 **Weight-Redundancy Pruning (WRP)**，无需校准数据、前向传播、梯度或内部通道匹配，即可完成全局层选择。

## 2. 方法论

### 2.1 核心思想

- 用**注意力输出投影 W^o** 与 **MLP 下投影 W^down** 刻画层间冗余：二者共享同一 hidden-state 输出空间（h_{ℓ+1} = h_ℓ + W^o_ℓ(·) + W^down_ℓ(·)），剪枝正是移除这两项贡献；其余投影映射到层内私有空间、依赖输入分布，因此只取其尺度信息。
- 融合「跨层投影相似度」与「相对投影尺度」两类描述子，构成全对相似矩阵 S，再做谱聚类与两阶段分配。

### 2.2 权重空间描述子

- **中心化**：对 W^a_ℓ ∈ R^{d×m_a} 施加输出通道中心化 H_d = I_d − (1/d)·11^⊤（线性 CKA 的标准步骤），得 W̃^a_ℓ。
- **Gram 构造与跨层投影相似度**：G^a_ℓ = W̃^a_ℓ (W̃^a_ℓ)^⊤，用线性 CKA 计算
  s^a_ij = ⟨G^a_i, G^a_j⟩_F / (‖G^a_i‖_F ‖G^a_j‖_F + ε)，
  S^proj_ij = (s^o_ij + s^down_ij)/2。
  该构造对中间维度置换不变（(WΠ)(WΠ)^⊤ = WW^⊤），且 CKA 额外归一化尺度差异；ε = 10⁻¹²。
- **投影尺度相似度**：用 7 个投影（q, k, v, o, gate, up, down）的 Frobenius 范数构成块特征 f_ℓ，减去全体均值得中心化特征 f̃_ℓ；再取余弦相似度 S^scale_ij。
- **合成**：S_ij = ½(S^proj_ij + S^scale_ij)，对角线 S_ii = 1。

### 2.3 聚类与分配

- **聚类数自动选择**：令 A = (S+1)/2（单位对角），归一化拉普拉斯 L = I − Δ^{−1/2} A Δ^{−1/2}，Δ = diag(A1)。取升序特征值间隙 d_j = λ_{j+1} − λ_j（j ∈ {2,3}）：d₂ 反映粗粒度二簇结构强度，d₃ 反映额外结构证据。为削弱「深度邻近效应」，构造 S⁰（把 S_ij 替换为同深度距离 |i−j| 下的平均相似度、保留单位对角），同法得到参考间隙 n₂、n₃，定义 e_j = max(d_j − n_j, 0)。当 e₂+e₃ > 0 时 ρ = e₂/(e₂+e₃)：ρ ≥ ½ 取 K = 2，否则取 K = 4；e₂+e₃ = 0 时取 K = 2。论文报告三个模型的 (ρ, K) 分别为 (0.778, 2)、(0.084, 4)、(1.000, 2)。
- **谱聚类**：对 A 做归一化拉普拉斯嵌入 + 固定种子 k-means，得到 K 个簇，按簇内最浅块深度排序。
- **两阶段分配**（沿用 LoRP 规则）：计算块 ℓ 到同簇其他块的平均相似度 r(ℓ; C_k)，以及簇内剩余块集合 R_k 的平均两两相似度 r̄(R_k)。**保护首块与末块**；簇内按 r 从高到低排序。
  - Stage 1：按簇顺序，从每簇选出排名最高的合格块；
  - Stage 2：反复从 r̄ 最大的簇中选其排名最高合格块，每次更新 R_k 与 r̄；|R_k| < 2 时设 r̄ = −∞，平局偏向低索引；直到 |D| = P。
- 选中块被直接删除，**其余参数不做任何改动**（无重训练、无恢复）。

## 7. 优点

- **方法层面**：
  - 真正免前向、免校准、免梯度、免内部通道匹配，规避了大模型剪枝中的显存瓶颈（选择阶段显存需求近乎为零）。
  - 选用 W^o 与 W^down 具有明确的物理依据——它们是唯一直接写入共享 hidden-state 空间的投影，其余投影只以尺度信息参与，设计克制且有解释性。
  - 基于线性 CKA 的相似度对中间维度置换不变、对尺度差异归一化，比单纯权重幅度更稳健。
  - 用谱间隙（扣除深度邻近效应后的参考间隙）自动决定聚类粒度 K，避免了手工调参。
  - 与 LoRP 的两阶段分配规则兼容，形成「权重版 LoRP」的清晰定位；保护首尾块比 Mag+ 保护 6 块更节省预算。
- **实验层面**：
  - 覆盖 3 个模型家族、6 个剪枝预算、9 个下游任务，协议统一为 one-shot 无恢复，横向对比干净。
  - 在真实 GPU 上实测延迟与显存，而非仅报告参数量或理论 FLOPs。
  - 诚实报告与 LoRP 的差距（57.41 vs 57.93），未夸大结论。

## 8. 不足与局限

- **实验覆盖**：
  - 模型规模仅 8B–14B，未验证更大模型（如 70B 级）或 MoE 架构；仅 3 个家族，泛化性证据有限。
  - 9 个任务均为零样本、短文本的分类/推理型 benchmark，缺少生成任务（摘要、翻译、代码）、长上下文与指令跟随评测。
  - 仅测试 6/8 块（约 19%–25%）的中等剪枝率，未探索高稀疏度（如 50% 以上）下的行为。
- **消融与机制验证缺失**：未拆解 S^proj / S^scale 的独立贡献，未做 K 选择、保护策略、聚类算法的敏感性分析，未与随机/均匀删除基线对比，因此「权重冗余信号有效」的因果归因尚不完整。
- **偏差与公平性风险**：所有对比方法均未做剪枝后恢复，这一协议虽保证公平，但**不代表实际部署中的最佳性能**；WRP 与恢复式方法的兼容性完全未验证。Mag+ 的保护块数（6 块）多于 WRP（2 块），在保护策略上对 Mag+ 稍不利，可能放大 WRP 的相对优势。
- **应用限制**：剪枝后仍需评估是否会破坏特定领域能力；方法假设层间冗余可由静态权重刻画，对激活分布高度漂移的任务或微调后的模型是否仍成立，论文未讨论。
