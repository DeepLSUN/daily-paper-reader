## 摘要
监督微调(SFT)训练基础语言模型以模仿目标回答，而这些目标可能需要基础模型尚未稳健内化的知识。我们将其视为幻觉的一个来源，并将一系列缓解方法框架化为“知识对齐微调”：将SFT训练目标约束于基础模型的参数化知识。在统一设置下，我们比较了现有的基于生成和基于估计的知识对齐方法，并引入了两种新变体：证据重写，利用外部证据验证基础模型的生成；以及召回重写，仅保留那些能被基础模型一致召回的主张。使用Qwen 3 4B和OLMo 3 7B的实验表明，知识对齐微调能够在很大程度上保持通用能力的同时，减少WildHalu和Biography上的事实性幻觉。召回重写在事实性提升上效果最强，并改善了UnknownBench上的拒答行为。这证实了超出基础模型知识的SFT目标会驱动幻觉行为。

## Abstract
Supervised fine-tuning (SFT) trains a base language model to imitate target responses, and these targets may require knowledge the base model has not robustly internalized. We study this as a source of hallucinations and frame a group of mitigation methods as \emph{knowledge-aligned SFT}: constraining SFT training targets to the base model's parametric knowledge. Under a unified setup, we compare existing generation-based and estimation-based knowledge-alignment methods and introduce two new variants: Evidence Rewrite, which verifies base-model generations using external evidence, and Recall Rewrite, which retains claims only when they can be consistently recalled by the base model. Experiments with Qwen 3 4B and OLMo 3 7B show that knowledge-aligned SFT can reduce factual hallucinations on WildHalu and Biography while largely preserving general capabilities. Recall Rewrite yields the strongest factuality gains and improves refusal behavior on UnknownBench. It thereby confirms that SFT targets beyond the base model's knowledge drive hallucination behavior.

## 1. 核心问题与整体含义（研究动机与背景）

- 论文关注的是 LLM 在监督微调（SFT）后出现的**事实性幻觉**——生成与真实世界相悖的主张。
- 核心观点认为：SFT 训练目标通常要求模型生成大量**事实性主张**，而这些主张可能超出了基础模型在预训练阶段已稳定内化的**参数化知识**范围。当训练目标要求模型输出其「不知道」的内容时，模型会被迫在不确定状态下学习「看起来合理的猜测」，从而诱发幻觉。
- 论文将这一 mismatch 明确定义为：
  - **知识对齐（Knowledge-Aligned）SFT**：构造训练集 \(D^*\)，使其所有主张 \(C(R^*|P) \subseteq K(M_{\text{base}})\)，即全部落在基础模型的参数化知识边界以内。
  - **幻觉区（Hallucination Zone）**：微调模型生成空间落在真实世界知识之外的部分。
- 整体含义在于：**SFT 不是注入新知识的有效载体**，而是塑造行为与输出风格的阶段；事实知识不足的部分应通过检索增强或继续预训练解决，而不是通过 SFT 强制模型输出不确定信息。

## 2. 方法论

### 统一框架
- 论文提出了一个统一的数据构造算法（Algorithm 1），所有方法均沿「门控（GATE）→ 响应来源（SOURCE）→ 声明分解（Mdec）→ 过滤/重写（UNKNOWN + Mrewriter）」的流程执行，四个方法仅在以下钩子上不同：
  - `GATE(P)`：该提示词是否需要处理；
  - `SOURCE(P,R)`：用原始回答还是基座模型采样的回答；
  - `UNKNOWN(c_n)`：主张是否被判定为「未知」；
  - `Mrewriter`：是否使用重写器。
- 两种对齐策略：
  1. **基于生成的对齐**：直接从基座模型采样自我生成的内容，假定其隐式落在模型知识边界内。
  2. **基于估计的对齐**：对每条主张逐一判断是否属于基座模型的知识。

### 四种方法对照
| 方法 | 来源 | 判定「未知」的机制 |
|---|---|---|
| FLAME（基线） | 基座模型采样 | 无过滤（默认全部已知）|
| UNIT cut（基线）| 原始回答 | 主张条件概率 CCP 低于阈值则删除 |
| **Evidence Rewrite（新）** | 基座模型先采样答案 → 再用外部证据验证 | 事实核查流水线：声明分解 → Wikipedia 证据检索 → 验证，不支持的主张删去；不足以回答时生成拒答 |
| **Recall Rewrite（新）** | 原始回答 | 见下方详细步骤 |

### 新方法 1：Evidence Rewrite
- 对知识寻求类提示词（knowledge-seeking），先从基座模型采样长回答。
- 增加**头脑风暴**步骤令生成内容更详尽。
- 对回答做声明分解（VeriScore 样式）→ Wikipedia 分层证据检索 → FActScore 式验证（SUPPORTED / NOT_SUPPORTED）→ 仅保留可验证主张 → 用重写器流畅改写，信息不足则触发拒答。

### 新方法 2：Recall Rewrite（主要贡献）
核心逻辑是：**一个主张只有能被基座模型从多种角度独立记忆中稳定复现时，才应被纳入 SFT 目标。** 实施步骤为：

1. **知识分解**：将回答分解为知识依赖型主张（事实、程序、结构、元知识）与非知识依赖型主张（情境性、主观性、纯推理内容）；后者总是保留。
2. **问题生成**：对每条知识依赖主张，由教师模型（gpt-5-mini）生成 5 个上下文无关的探测问题（J=5）。
3. **多路采样**：基座模型对每个问题生成 2 个回答（K=2，温度 0.5）。
4. **蕴含判定**：对回答判断为 ENTAILS / CONTRADICTS / UNRELATED。
5. **一致性判据**（公式 1，核心）：
   \[
   \text{known}(c_n) \iff
   \big|\{j: e_{n,j} \ge k_e\}\big| \ge j_e
   \ \land\
   \big|\{j: d_{n,j} \ge k_c\}\big| \le j_c
   \]
   即至少 \(j_e=2\) 个问题各有至少 \(k_e=1\) 个蕴含回答、且至多 \(j_c=2\) 个问题各出现 ≤\(k_c=1\) 个矛盾回答，才会将该主张视为「已知」。
6. **重写**：以保持原始结构和措辞的最小编辑方式删去「未知」主张；信息不足时返回固定拒答模板。

## 6. 主要结论与发现

1. **知识对齐可以显著降低事实幻觉**：所有知识对齐变体（除 FLAME 外）在 WildHalu 与 Bios 上的 %Supp. 与 FActScore 均优于标准 SFT。
2. **越严格的对齐 → 越正确但越不丰富**：Recall Rewrite 取得最高 %Supp. 与 FActScore，但 #Supp. 显著下降、拒答率升高，体现事实精度和信息覆盖度之间的固有取舍。FActScore 将拒答视为完全支持，因此高 FActScore 不等同于在等覆盖度下的更好生成。
3. **因果机制被验证**：训练目标中已知主张的占比从 100% 降到 50% 和 0%，WildHalu 上 FActScore 约下降 5.7/6.6 个百分点，Bios 上下降 31/31.5 个百分点（0% 与 50% 相当）——证明「超知识目标」是幻觉驱动因素。
4. **生成式对齐不等于知识对齐**：FLAME 在全实验中相当于标准 SFT，并未提升事实性；从生成中再增加外部验证（Evidence Rewrite）后性能即可提升。
5. **Recall Rewrite 的拒绝行为显著改善**：在 UnknownBench 全部三个子任务上获得最高 F1（68.7/68.8/69.9），在不可回答题目上的拒答召回率大幅领先（如 RefuNQ 79.1% vs 标准 SFT 50.7%），但牺牲了精度（过度拒答更多）。
6. **通用能力几乎持平**：Recall Rewrite 相较标准 SFT 在 OLMES 四个任务平均仅降低 0.9 个百分点；IFEval 差 3.2 个点完全可归因于对 30 个创意写作提示词的拒绝而非指令服从能力退化；GSM8K 的 2.3 点差距属普通推理失误与拒答无关，可视为训练方差。
7. **知识对齐 SFT 不弱于额外的对齐阶段**：在 OLMo 3 7B 上，仅用知识对齐 OASST1 的 SFT 在 WildHalu 的 %Supp./FActScore 即高于官方的 SFT、DPO 乃至 RLVR 检查点；但在 Bios 上 DPO/RLVR 的 FActScore（72.4）仍明显高于 Recall Rewrite（56.6），提示二者并非简单的可替换关系。

## 7. 优点

- **框架统摄性好**：将 FLAME、UNIT cut 和两种新方法统一到一条数据构造算法（Algorithm 1）中，方法差异被精确界定为三个 hook 的差异，极大改善了跨方法可比性与可复现性。
- **新颖且自然的「主动探测记忆」思路**：Recall Rewrite 不依赖句子级自信度（如 UNIT 的 CCP），而是通过多角度提问、多次采样与蕴含判断，得到了参考基座模型真实知识边界更稳健的估计——问题设计和旁路 LLM 回答结合起来，能避免问题措辞泄露答案的偏置。
- **因果验证意识强**：设计了 %Known 从 100%→0% 的定向干预来直接展示「目标越不匹配知识，幻觉越严重」，将相关性证据升格为因果关系。
- **多维证据链完整**：把「更好的事实性」与「增高拒答率」「保持通用能力」「降低不可答场景不当作答」等多角度量化表现放在一起呈现，并用逐例质性分析解释各指标在数字互动中的变化成因，避免单指标驱动的误解。
- **数据与中间产物的释放**：发布训练数据、声明分解、探测问题、基座答案与蕴含标签，为后续研究提供了宝贵的可复现材料。
- 观察到并细致分析了真实的生产陷阱，如问题生成对声明的注意偏差、代码改写引入的副作用、IFEval 中由 SFT 拒答样本泛化导致的过度拒答，这些都有清晰的改进方向。
