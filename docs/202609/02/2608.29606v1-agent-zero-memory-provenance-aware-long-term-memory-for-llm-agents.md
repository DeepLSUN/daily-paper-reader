## 摘要
大型语言模型（LLM）智能体需要对用户或组织所说和存储的一切拥有持久、忠实的记忆，然而大多数记忆系统局限于单一组织结构（事实存储、向量索引或知识图谱），并继承了其盲点。我们提出Agent Zero Memory，一个溯源感知的长期记忆系统，将用户的对话、文件和关联来源提炼为三个并行的记忆系统，每个系统捕捉同一历史的不同侧面：事件性记忆事件时间线，将“何时”和“发生了什么变化”作为一等公民；关联性实体-事件知识图谱，跨会话关联人物和项目；以及经过语义化、人工整理、带引文锁的层级文档记忆（HDM），存储持久事实。检索回合运行一个意图门（因此自包含回合不会增加延迟）、一个来源路由器，以及三个并发的智能体搜索（每个系统一个），每个搜索都是智能体控制过滤器下的混合（嵌入+词汇）搜索的工具使用循环；它们基于依据并附引文的答案被整合为一个具有单一置信度的答案。我们形式化阅读纪律：每个学到的项都是带来源的项，携带其出处、时间戳和证据指针；每个答案都在引文锁下读取，因此只能引用读者实际打开过的证据；结构上排除了捏造，系统宁可弃权也不猜测。在两个公开基准上，该系统达到了新的最先进水平：LongMemEval 95.60%，LoCoMo 93.60%，比最强的先前系统分别提高了+0.73和+1.10个百分点。一项跨八个骨干LLM的受控研究刻画了准确率-成本-延迟边界：准确率仅变化3.4个百分点，而每次查询成本约变化30倍；在每次查询成本降低达20倍的情况下仍接近最先进质量，这是记忆驱动而非模型驱动质量的特征。

## Abstract
Large language model (LLM) agents need durable, faithful memory of everything a user or organization has said and stored, yet most memory systems commit to a single organizing structure (a fact store, a vector index, or a knowledge graph) and inherit its blind spots. We present Agent Zero Memory, a provenance-aware long-term memory system that distils a user's conversations, files, and connected sources into three parallel memory systems, each capturing a different facet of the same history: an episodic Memory Events timeline that makes when and what changed first-class, an associative entity-event knowledge graph that links people and projects across sessions, and a semantic, curated, citation-locked Hierarchical Documentary Memory (HDM) of durable facts. A retrieval turn runs an intent gate (so self-contained turns add no latency), a source router, and three concurrent agentic searches, one per system, each a tool-using loop over hybrid (embedding + lexical) search under agent-controlled filters; their grounded, cited answers are integrated into one answer with a single confidence. We formalize the reading discipline: every learned item is a provenanced item carrying its origin, timestamp, and evidence pointer, and every answer is read under a citation lock, so it may cite only evidence its reader actually opened; fabrication is structurally excluded and the system abstains rather than guesses. On two public benchmarks the system sets a new state of the art: 95.60% on LongMemEval and 93.60% on LoCoMo, improving over the strongest prior systems by +0.73 and +1.10 points. A controlled study across eight backbone LLMs characterizes the accuracy-cost-latency frontier: accuracy varies by only 3.4 points while per-query cost varies by ~30x, with near-state-of-the-art quality at up to 20x lower cost per query, the signature of memory-driven, rather than model-driven, quality.

## 一、核心问题与研究动机

**要解决的问题**：LLM智能体需要跨会话、跨来源的持久且忠实的长期记忆，但现有记忆系统普遍存在三大结构性缺陷：

1. **组织方式单一**：多数系统只依赖一种结构（事实库、向量索引或知识图谱），每种结构只能擅长特定类型的问题，无法全面覆盖时间推理、多跳检索、持久档案等不同查询需求。
2. **缺乏溯源与诚实性**：存储系统记录了"说了什么"，但很少建模"为什么相信"以及"证据积累后置信度如何变化"。用户更正事实时，系统要么静默覆盖，要么累积矛盾，无法区分修正与旧值。
3. **三类普遍失效轴**（论文归纳的现有系统通病）：
   - **写入端**：按消息逐个用LLM提取/整理，摄入成本随历史线性增长，且处于对话热路径上；
   - **读取端**：某些系统读取成本与历史长度无关地膨胀（如整个日志常驻上下文、全图PageRank等）；
   - **认知端**：更新即破坏性覆盖，无法追溯修正出处；且系统多为单用户/单项目设计，不能成为共享组织记忆。

**核心论断**：长期记忆的本质是维护一个**持久、可查询、诚实**的"已知什么"模型——不仅记录断言本身，还要记录其来源、支持证据和校准的置信度；且**没有任何单一表征能服务所有问题类型**。

## 二、方法论：Agent Zero Memory

### 2.1 总体架构：三套并行记忆

将用户的聊天、文件和连接来源蒸馏为三个相互关联的记忆系统，每个捕捉同一历史的不同侧面：

| 记忆系统 | 类型 | 功能定位 |
|---|---|---|
| **Memory Events（事件时间线）** | 情节性 | 将"何时发生"和"什么变了"作为一等公民，支持时间推理与知识更新类问题 |
| **Entity–Event Knowledge Graph（实体-事件知识图谱）** | 关联性 | 跨会话关联人物、项目与事件，支持多跳检索 |
| **Hierarchical Documentary Memory（HDM，分层文档记忆）** | 语义性 | 人工整理的持久事实库（用户画像、偏好等），带引文锁，回答稳定事实 |

### 2.2 Memory Build：四阶段后台流水线

1. **预处理与分类**：将原始来源规范化，标记为聊天/文件/智能体会话；
2. **索引**：为所有内容建立嵌入索引 + 词法搜索索引（双通道）；
3. **抽取**：由LLM将已分类材料蒸馏为 Memory Events 和 HDM；
4. **连接**：agentic过程构建实体-事件本体图。

三种记忆类型按可靠性与生命周期区分：**事实型**（直接从来源读取，源不变则真）、**经验型**（推断并随时间精炼，可被验证）、**工作型**（当前会话，结束后有用部分提升为持久记忆，形成持续学习闭环）。组织中一个智能体学到的经验可被所有智能体共享。

### 2.3 Memory Injection：三路并发智能体搜索

每个查询回合经历的流程（Algorithm 1）：

1. **意图门控（Intent Gate）**：小型快分类器判断本轮是否需要记忆以及哪种类型，自包含回合直接通过（零延迟）；
2. **来源路由器（Source Router）**：将检索范围限制在可能相关的来源桶子集；
3. **三路并发智能体搜索**：每个记忆系统一个，各是工具使用循环——混合嵌入+词法搜索、智能体自主控制过滤器（时间窗口、标签、来源、说话者）、按需打开原始块；
4. **整合**：合并三个部分答案，取引用集的并集与聚合置信度，输出带引文的单一答案。

### 2.4 核心形式化原理

三个设计公理：
- **(P1) 分层**：原始内容与蒸馏记忆分离，人工整理的源锁定事实与推断的、可修正的经验分离，从类型上防止推断污染真实；
- **(P2) 溯源与引文锁**（两个正式定义）：
  - **溯源项（Definition 1）**：每个学习项携带来源（scan/infer/doc/dialogue/manual）、不可变时间戳、可追溯回原始内容的证据指针；
  - **引文锁答案（Definition 2）**：答案只能引用读者实际打开的项（C ⊆ O），每条原子断言须有引用支持；无法满足时系统弃权（a = ⊥）。由于读者接口在构造上不存在引用未打开材料的通道，**捏造在结构上被排除**；
- **(P3) 有依据、结构感知的检索**：通过语义和精确词两种方式搜索，感知并可遍历结构（时间线、实体图、文档层级），而非自由生成。

### 2.5 与现有方法的关键差异

| 维度 | 现有系统的做法 | Agent Zero Memory 的做法 |
|---|---|---|
| 记忆组织 | 单一结构（事实库/向量/图） | 三套并行结构，各取所长 |
| 更新语义 | 覆盖/删除 | 追加式、非破坏性：事件累积而非互斥 |
| 读取成本 | 随历史或会话长度增长 | 意图门控 + 路由，仅访问相关记忆 |
| 溯源 | 多数丢弃 | 全项溯源 + 引文锁 |
| 范围 | 多为单用户 | 组织级共享 |

## 七、优点与亮点

1. **三套并行记忆的架构创新**：针对不同查询类型设计专用记忆结构，是对"单一结构有盲区"问题的直接回应；同时事件时间线版本化记录、知识图谱跨会话关联、HDM锁定持久事实——分工清晰合理；
2. **引文锁与形式化的诚实性保证**：以构造方式（Definition 2）排除捏造而非仅靠提示约束，并可弃权而非猜测，这对企业级可信应用是重要性质；
3. **非破坏性追加更新语义**：知识更新=追加新时间戳信念而非覆盖旧值，旧值与修正可区分，保留完整审计轨迹；
4. **读取成本与查询相关**：意图门控使自包含回合零延迟，各搜索只取top-k而非扫描整体，避免了历史越长读取越贵的扩展性问题；
5. **写入路径非热路径**：蒸馏为后台离线流水线，原始内容保持可索引，抽取失误可恢复；
6. **骨干无关性实证**：精度跨8个模型仅波动3.4点，证明质量来自记忆架构——这是可迁移的普适设计信号，且提供了明确部署经济学选择（高精度、低成本、低延迟三个帕累托前沿点）；
7. **成本透明**：详细报告token构成、缓存比例与成本来源，便于重新定价分析。

1. **对比公平性**：跨系统比较采纳各家的最佳公开数字，不同框架下评判模型、提示各异，不是严格受控的对抗试验；
2. **消融不完整**：仅做了检索通道消融；未量化三个记忆各自、意图门控、实体图连接、HDM三档细节各自的边际贡献；
3. **统计效力**：单次运行无方差估计。鉴于两个基准已近饱和（95%+/93%+），0.73和1.10的提升幅度是否有统计显著性未报告；
4. **记忆写入成本未充分量化**：论文批评了其他系统每条消息的LLM提取成本，但未报告自己Memory Build流水线的token总消耗，无法全面对比写放大；
5. **置信度校准未验证**：论文声称携带标量置信度，但未对这种置信度进行任何校准实验（在Limitations中也承认为后续工作）；
6. **时态与可复现性**：论文日期为2026年，所用模型版本（gpt-5.5、opus4.8等）在真实世界中不存在或不可及，成本数字随价格变动漂移，客观上无法复现验证；
7. **冲突仲裁与遗忘缺失**：当不同来源持有多个并存的事实版本时如何优先选择（包括何时询问用户而非选择）、如何优雅老化过时经验记忆，均未解决（列为未来方向）；
8. **评估局限**：完全依赖LLM评判器协议，未辅以人类评估；未覆盖真实组织级共享记忆等论文声称支持但基准未测试的应用场景（如跨用户共享、知识提炼后的遗忘与压缩）。
