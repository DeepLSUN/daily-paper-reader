## 摘要
随着大型语言模型越来越多地通过外部工具行动，决定何时调用工具已成为与决定如何使用工具并列的核心问题。不必要的工具调用会引入延迟、成本、检索噪声和错误传播，而遗漏调用则会损害需要最新证据的知识密集型查询或问题。现有方法通常根据绝对查询或生成信号（如难度、置信度或最终任务奖励）触发工具，因此缺乏对工具使用实例级边际收益的显式估计。我们提出CoBRA，一种用于工具增强语言模型的反事实边界学习框架。CoBRA首先从同一基础模型构建内部和外部专家，收集配对轨迹，并估计使用工具与不使用工具回答之间的奖励边际。该边际将数据划分为内部偏好、外部偏好和模糊情况。然后，CoBRA使用清晰边际样本进行边界感知冷启动SFT，随后采用具有参考分离轨迹和反事实边际优势的MARS-RL来优化边界决策。以检索作为主要工具在Qwen3-4B上的实验表明，CoBRA提高了工具使用效率和边界敏感答案准确性，同时在依赖工具的分布外问题上保持了强劲性能。

## Abstract
As large language models increasingly act through external tools, deciding when to call a tool has become a central problem alongside deciding how to use it. Unnecessary tool calls introduce latency, cost, retrieval noise, and error propagation, while missed calls hurt knowledge-intensive queries or questions requiring up-to-date evidence. Existing methods typically trigger tools from absolute query or generation signals, such as difficulty, confidence, or final task reward, and therefore lack an explicit estimate of the instance-level marginal benefit of tool use. We propose CoBRA, a counterfactual boundary-learning framework for tool-augmented language models. CoBRA first constructs internal and external experts from the same base model, collects paired trajectories, and estimates the reward margin between answering with and without tools. This margin partitions data into internal-favored, external-favored, and ambiguous cases. CoBRA then uses clear-margin samples for Boundary-Aware Cold-Start SFT, followed by MARS-RL with reference-split rollouts and counterfactual marginal advantages to optimize boundary decisions. Experiments with retrieval as the main tool on Qwen3-4B show that CoBRA improves tool-use efficiency and boundary-sensitive answer accuracy while maintaining strong performance on tool-dependent out-of-distribution questions.

- **问题定位**：大型语言模型（LLM）在调用外部工具（检索器、搜索引擎、API）时，除了“如何调用”（how）之外，“何时调用”（when）同样关键且未被充分研究。不必要的工具调用会带来延迟、API成本、检索噪声和误差传播；而该调用时不调用则会损害知识密集型问题或时新性问题的事实正确性。
- **现有方法的不足**：既有工具调用触发方法往往基于难度估计、置信度信号、自反思想，或最终任务奖励作为绝对信号来决定是否检索。这类信号只刻画了“问题本身的绝对难度”，而无法估计“工具带来的实例级边际收益”——一个困难问题未必需要工具，一个模型自信的问题也可能因为陈旧或长尾知识而答错。
- **核心主张**：CoBRA将工具路由视为一个“反事实决策”问题——针对某个具体查询，需要比较“使用工具”与“仅依赖内部知识”两种路径的期望效用差，而这正是这一框架的核心创新所在。

## 2. 方法论

**核心思想**：在实例级别上显式估计工具使用的反事实边际效用，并以此作为工具调用决策的边界学习信号。整体流程包括四个环节：

- **双专家构建（Dual-Expert Construction）**：从同一基础模型出发，通过拒绝采样SFT构建两个分支专家——`M_int`（内部专家：只用参数化知识，禁止调用工具）和 `M_ext`（外部专家：必须调用检索工具并整合证据再回答）。两者使用同一系统提示与工具schema，保证对比的公平性。
- **反事实边界发现（Counterfactual Boundary Discovery）**：在同一查询上，两个专家各自用温度0的确定性策略生成轨迹，用统一效用函数打分，视二者差异为工具边际奖励估计：

  - 效用：`R(τ) = S(τ) − λC(τ)`
  - 边际：`ˆΔ(q) = R(τ_ext | q) − R(τ_int | q)`

  根据边际符号与阈值 `ϵ` 将数据划分为三个子集：`D_int`（内部偏好），`D_ext`（外部偏好）和 `D_amb`（模糊区间，其中包含两者都失败的样本）。
- **边界感知冷启动SFT（Boundary-Aware Cold-Start SFT）**：仅选用清晰边际样本（`D_int ∪ D_ext`），用专家输出作为监督轨迹，让模型学会基础的“调用/不调用”路由先验，刻意排除模糊样本以避免早期噪声硬标签干扰训练。
- **MARS-RL（Marginal Advantage from Reference-Split Rollouts, 即通过参考分离轨迹和反事实边际优势算法）**：针对模糊区域样本做两阶段训练。
  - **参考分裂rollouts**：同一查询上并行采样多组轨迹，一组内部路由，一组外部路由；仅做分支干预，其余（提示、schema、参考策略）保持一致，保证奖励差反映的是“工具价值”而非“指令格式差异”。
  - **逐分支归一化优势（PBN）**：先在各自分支内做z-score归一化，避免高奖励分支整体压制另一分支的优秀样本。
  - **分支边际项（BM）**：将两组平均效用差归一化为 `e∆_B(q)`，然后以 `β·sign(T_i)·e∆_B(q)` 的形式对称地注入优势函数。该部分直接引导模型选择反事实效用更高的分支。
  - 整体采用PPO-style clipped优化目标，KL散度约束在Mwarm参考策略附近。

## 6. 主要结论与发现

- **核心发现**：工具路由决策应该由“边际效用”驱动而非“绝对难度”驱动，此框架直接学习该信号可显著改善工具使用决策的质量。CoBRA在主评测中取得了最高judgedEM（jEM）与整体质量指标，同时将工具调用从基线水平缩减2~3成。
- **质量与效率双赢**：在In-domain提升jEM 9.15 pp（相对Mwarm），OOD提升9.04 pp；在保持不损失OOD准确率的同时，比Search-R1-3B平均减少约20%~22%的工具调用次数。
- **边界行为改善**：在最有代表意义的模糊边界子集（Damb）上，jEM达到0.9658（较Mwarm提升3.66 pp、较Search-R1-3B提升6.14 pp）。内部偏好样本的过度调用率（16.4%）与外部偏好样本漏调用率（1.2%）也优于同类方法。
- **消融结论**：参考分裂轨迹、分支归一化并分支边际项三者缺一不可；基线Vanilla GRPO若缺少这些组件容易在最终答案监督下坍缩为“永不调用工具”，验证了两阶段训练的合理性。warm-start的SFT是后续RL成功的关键。
- **垂直域验证**：在音乐域的工业数据中质量收益与工具调用率同时下降（39.3%→25.1%），证明了该方法具有较好的跨任务泛化能力。

## 7. 优点

- **问题切分精准**：它抓住“何时使用工具”这一关键却常被忽视的环节，并把难度问题转化为边际效用问题，视角新颖而有解释性。
- **方法论连贯度高**：反事实边际估计—数据集划分—冷启动SFT—强化学习逐层递进，每一环节均有清晰动机和可测量的中间产物（分区、warm模型、策略轨迹）。
- **训练信号严谨**：RL阶段通过参考分离（Reference-Split）和分支内归一化，很好地区分“分支选择”与“分支内部推理质量”两类信号，避免最终答案奖励淹没路由信号。
- **实验设计较全面且充分透明**：不仅关注端到端指标，还单独设计边界行为评测（Dint/Dext/Damb拆分），并能独立度量过调用率与漏调用率、考察OOD和垂直域泛化度。

## 8. 不足与局限

- **验证范围有限**：仅以Qwen3-4B作为底层模型（虽在小规模上验证了通用性，但未披露在更大强模型或不同架构上的结果）；工具仅验证了检索器类型，对多工具调用编排、API选择等更复杂场景尚未覆盖。
- **反事实估计的可靠性**：两个分支的轨迹质量受限于Scorer可靠性和检索返回质量；反事实“配对”依靠的是“同一问题、不同分支策略”的rollout，虽设计合理，但仍是启发式近似而非真反事实，存在残余偏差。
- **成本模型简化**：论文仅用工具调用次数来刻画成本，实际生产环境中的延迟、token价格、隐私合规等没有纳入效用函数。
- **评估公平性隐患**：部分公认数据集使用dev split而非正式test split；2WikiMultiHop上的prompt基线的judgedEM反常地高，提示评测模型/检索机制可能存在偏置。
- **统计验证不足**：论文未报告多次运行的方差或显著性检验（仅在附录提同checkpoint的三次重复取平均），难以完全排除随机训练波动。
