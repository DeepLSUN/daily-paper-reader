## 摘要
我们研究自我建模：LLM回答关于自身行为问题的能力。我们关注可验证的行为问题，例如提示编辑是否会改变模型的最终答案。为了衡量这种能力，我们引入了一个基准测试，测试不同类型的自我建模问题。当前模型展现出不可忽视但有限的自我建模技能，并在关于自身行为的简单反事实问题上犯系统性错误。为了提高自我建模技能，我们开发了一个可扩展的合成数据管道，用于生成自我建模训练数据，并表明强化学习可以提高三个开源模型家族的整体自我建模技能，并对保留任务有一定迁移性。然而，这些收益似乎并不一致地构成内省：改进的自我建模可能并非源于对模型内部决策过程的特权访问。

## Abstract
We study self-modeling: an LLM's ability to answer questions about its own behavior. We focus on verifiable behavioral questions, such as whether a prompt edit would change the model's final answer. To measure this capability, we introduce a benchmark that tests diverse types of self-modeling questions. Current models show non-trivial but limited self-modeling skill, and make systematic mistakes on simple counterfactual questions about their own behavior. To improve self-modeling skill, we develop a scalable synthetic-data pipeline that produces self-modeling training data, and show that reinforcement-learning can improve aggregate self-modeling skill across three open-source model families with some transfer to held-out tasks. These gains, however, do not seem to constitute introspection consistently: improved self-modeling may not arise from privileged access to the model's internal decision process.

## 1. 核心问题与整体含义

- **背景动机**：随着 LLM 在日常与安全场景中被要求“反思自身”，例如估计答案置信度、判断提示扰动是否改变行为、预测自身输出分布等，学界需要一种可度量的方式来评估这种“自我建模”能力。作者强调这是行为层面的能力，而非内省或对内部状态的特权访问。
- **核心问题**：现代 LLM 能否准确回答“关于自身行为”的问题？这种能力能否通过训练提升？
- **整体意义**：这项工作首次系统构建了多任务、多格式的自我建模评估基准，并通过合成数据 + 强化学习展示了该能力是可训练的；同时揭示当前模型在简单反事实问题上会系统犯错，且提升并不必然来自真正的内省。

## 2. 方法论

### 2.1 自我建模任务的定义

- 一个自我建模任务包括三要素：
  1. 一个**自我建模提问**（meta-prompt），要求模型报告自身行为属性；
  2. 一个**行为真值**（ground truth），由“被评估模型”自身在多次采样中的可观测行为测出；
  3. 一个**评分函数**，将模型的自述与行为真值比较。
- “强化学习改进模型”的核心思想是：**先让模型预测试验性扰动效果，再用可验证的真实行为作为奖励标签进行训练**，类似可验证奖励强化学习（RLVR），使用 LoRA 适配器。

### 2.2 关键指标：技能分数（self-modeling skill score）

- 原始任务分数受模型自身行为分布（如翻转率高了难预测）影响，不能跨模型直接比较。
- 引入**虚拟预测器基线**：离散任务预测众数、连续任务预测均值、生成任务输出零基线。
- **技能分数 = 原始分数 − 虚拟基线**，正数表示模型的自述包含特定于示例的信息；消除样本分布偏差后的公平比较。

### 2.3 评估基准

- 十个自我建模任务，覆盖二进制、多项选择、数值、自由文本/生成式格式：
  - Flip-Decision（翻转决策）、Output-Prediction（输出预测）、Flip-Rate（翻转概率）、Self-Accuracy（准确率自估）、Confidence-Recall（置信度回忆）、Perturbation-Choice（扰动选择）、Component-Attribution（组件归因）、Edit-Proposal（编辑提议）、Feature-Rate（特征出现率）、Logit-Estimation（logit 估计）。
- 从四个领域语料库构建：GSM8K（数学）、HumanEval（编码）、WildGuardTest（安全）、BBQ（偏见/公平），每类手工设计多种注入式扰动（如“提示答案是42”“增加变量名提示”等）。
- 行为真值通过采样数量 K=1（主排行榜）或更多采样计算；多标签多选题允许并列集。

### 2.4 训练数据生成管道

- **单轮 HF 轨道**：
  - 使用约 100 个 HuggingFace 数据集（由 LLM 驱动的自动发现 + 手工列表扩充），排除评估用的四个语料。
  - 辅 LLM 将提示分解为组件并建议“翻转 / 边界 / 不翻转”扰动；
  - 目标模型实际采样验证扰动效果；失败时反馈给生成器修订，形成“生成→验证→反馈→再生成”的循环。
  - 按标签分布、任务规模做过滤与平衡。
- **多轮 BLOOM 轨道**：
  - 基于 Bloom 框架覆盖 20 个目标对齐行为（如自我保存、自利偏好等），在完整多轮会话中选取分叉点，修改一个对话组件后重放轨迹；
  - 用 LLM 裁判按 1–10 标度评分，以≤5/>5为翻转阈值；仅保留验证过的翻转/非翻转样本。

### 2.5 训练目标与奖励

- 基于 REINFORCE 目标，组内均值中心化优势，无 clip、无 KL 惩罚：
  - 每个输出有格式奖励（0.5）+ 任务奖励（0 到 1）。
  - 连续型任务使用 1−(r−g)²；离散任务使用精确匹配；Edit-Proposal 使用翻转且小编辑奖励。
- 训练标签大多在初始模型上一次性生成，并用“在线刷新标签”消融验证了该简化假设的合理性。

## 3. 实验设计

- **自我建模基准评估**：
  - 18 个模型（开源 + 专有，如 DeepSeek、GPT-5.x、Claude Opus、Gemini、Kimi、Llama、Qwen、Grok、GPT-OSS 等）。
  - 每个模型 5 个 seed，每 seed 100 个样例（25 × 4 领域）。
  - 原始分数与虚拟基线一起汇报。主榜最佳聚合技能分数约 +0.147，远低于上限 +1；部分模型接近 0 或负（如 Llama-3.1-8B 为 −0.007）。
- **训练比较**：
  - 目标模型：Llama-3.1-8B、Qwen3-8B、GPT-OSS-20B（另测 Qwen3-4B/32B 用于规模效果）。
  - 训练方法对照：无微调、单任务 RL、多任务 RL、BLOOM-only RL；并加入 SFT、SFT+RL 等对照。
  - 结果：多任务 RL 在三个模型上均能提升聚合技能分数；BLOOM-only 有时迁移但效果不稳。
- **跨任务泛化**：
  - “训练任务 × 验证任务”矩阵，判断同任务与跨任务迁移的收益；多任务 RL 整体好于单任务。
- **跨模型迁移诊断**：
  - 让 Llama 解释 Qwen 行为、反之亦然；不能一致观察到“自己解释自己”的优势，说明改进更像一般模式学习而非特权内省。
- **下游任务验证**：
  - 红队审计（Petri）：自我报告是否帮助审计师找到攻击点。
  - 提示工程：带自述的反馈与纯结果反馈的对比（基于 HelpSteer2 五轴评分）。
- **消融与敏感性**：
  - 系统提示有无、思考模式、采样温度、重采样数、示例规模、任务提示变体（JSON/释义/结构）、基座 vs 指令微调模型等。

## 4. 资源与算力

- 论文中**没有给出整体 GPU型号/集群规模/总训练时长的明确统计**。
- 已知细节：
  - 本地推理与训练使用 NVIDIA H200 GPU，通过 vLLM 0.19.0 服务；
  - LoRA rank = 32，batch size = 64 prompts/step，每 prompt 采样 K=16，序列长 4096，学习率 2×10⁻⁵，约 200 步，约 10 epoch（单任务）或约 1 epoch（多任务）。

## 5. 实验数量与充分性

### 实验数量统计性很强

- **评估基准**：18 个模型的完整排行榜，外加基座 vs 指令模型对照、Logit-Estimation 单独表、温度/重采样/样本数等敏感性扫描。
- **训练**：3 个主要开源模型家族，多个训练方案（9–12 种单任务 + 多任务 + BLOOM）；每题/每配置用 5 或 20 个 seed。
- **消融和对照**：SFT 格式×权重网格（12 组合）、SFT 在线刷新、SFT vs RL 对比、跨模型解释、提示模板变体、系统提示等。
- **下游应用实验**：Petri 红队（100 场景 × 14 微调变体）、提示工程（多目标模型 × 15 变体 × 5 轴 × 3 seed）。

### 充分性评价

- **优点**：实验设计覆盖面广，且有跨模型迁移、多任务迁移、SFT 对照与消融等，能较好支撑“RL 提升自我建模技能”的结论。
- **限制**：主结论中自我报告在红队/提示工程等下游任务上的增益较小，统计显著边界并不清晰；跨模型迁移实验只对少数模型对做了详细分析；训练标签预计算依赖初始模型，虽然做了刷新消融但未完全遍历。

## 6. 主要结论与发现

- **自我建模能力可测但远未饱和**：最佳指标也只到 +0.147，许多简单反事实问题被所有前沿模型答错，例如“插入显式错误数据后答案会不会变？”
- **RL 能显著提升自我建模能力**：多任务 RL 在 Llama-3.1-8B、Qwen3-8B 与 GPT-OSS-20B 上均有提升，并迁移到未训练的自建模任务；SFT 单独训练则会导致分布塌缩，SFT+RL 不如纯 RL。
- **改进不构成一致的内省证据**：跨模型训练的解释者时常在目标模型自身行为预测上“反客为主”，没有稳定存在“自己比自己预测更准”的优势，表明模型可能学习的是外部行为规律而非内部决策过程。
- **训练数据的难度与质量需要针对性生成**：最初扰动生成高度不平衡；迭代“验证-修订”能提升翻转/不翻转类别的平衡；困难多轮数据有时能迁移到单轮评估。
- **下游价值仍需小心**：自我报告能辅助红队与提示工程，但仅在部分场景有效，不可靠的自述可能比没有更糟。

## 7. 优点

- **系统化基准**：把以往独立的自我解释 / 置信度 / 扰动预测任务统一到同一“提问-行为真值-评分”框架，首次提供了跨模型可比的 18 模型排行榜。
- **消除基线的技能分数设计**：先按各模型行为分布算虚拟基线，再比较提升幅度，避免了“低翻转率模型只需一直预测 No 就高分”的假性优势。
- **可扩展的合成数据管道**：自动发现数据集、自动分解提示、自动生成并验证扰动的闭环能被多个模型复用；并排除评估语料，防止泄漏。
- **丰富的实验范式**：同时考虑同任务增益、跨任务转移、多轮 BLOOM 会话转移、跨模型自我 vs 他人预测、SFT/RL/LoRA 消融，提供了较强证据链条。
- **开放评估与训练代码**：附带了可复现的评估与训练仓库，推进社区标准化。

## 8. 不足与局限

- **任务范围受限于文本、单轮或受控多轮环境**：未覆盖真实部署中的长上下文、工具调用、记忆、异构用户状态，以及提示搜索引擎等复杂系统。
- **行为标签不等于因果机制**：论文刻意不区分自我报告来自内省、提示线索还是“模型常规行为知识”，因此不能回答“模型是否真的知悉自身机制”这一更深层次问题。
- **每个被评估模型需单独测量行为真值**：成本较高；同时扰动是人工/模型手工池，难以覆盖目标模型的全部潜在盲区，跨模型公平性可能受限。
- **跨模型/下游实验结论并不完全一致**：自己模型优势视模型对与任务而异，说明训练提升的归因仍较脆弱；红队/提示工程上的增益很有限，在若干情形下自我报告设置实际不及结果反馈。
- **微调后的自我报告会被恶意利用**：服务使用者（例如越狱者）也能从自述中找到可利用弱点；模型并未因此获得内在“诚实”保障。
- **训练与评估均使用遥测采样和概率/数值自动解析**，很容易受格式方差影响，基座模型因格式失败而几乎无法评测；对非严谨 API 或不稳定的解码设置鲁棒性不足。
