## 摘要
LLM智能体日益依赖生成的交互数据来学习如何与外部环境交互。智能体数据生成必须在环境、任务、交互和成功信号之间保持一致，同时产生有用而非仅丰富的经验。现有工作涵盖众多智能体领域，但以领域为中心的组织方式和异质评估常常掩盖了共同的生成机制，并将候选构建与验证和选择混为一谈。本工作为该领域构建了一个两层框架。首先，我们将智能体数据表示为一个公共的因子化对象$(E,q,τ,v)$，包含环境规范、任务信号、交互实现和可选的验证器。我们按其主要锚点和依赖结构来组织生成范式。其次，我们通过准确性-复杂性-多样性（ACE）视角将生成形式化为有约束的分布设计。准确性确立了基于实际且内部一致的数据的可行支持。在此支持内，复杂性将学习质量相对于声明的学习者和执行配置的能力进行分配，而多样性则控制数据的覆盖度和冗余度。利用该框架，我们探讨了先前工作如何验证生成的经验、构建并校准难度，以及扩展行为覆盖。文献揭示了一种向执行锚定的准确性、学习者相对的复杂性以及超越表面变化或数据集规模的多样性转变。我们进一步通过ACE视角讨论了智能体数据生成的更广泛方向和新兴趋势，包括其对扩展、数据来源、训练范式和适应性学习的影响。总体而言，核心挑战并非简单地生成更多数据，而是在智能体和环境演化过程中持续分配有效、信息丰富且不冗余的经验。

## Abstract
LLM agents increasingly rely on generated interaction data to learn how to interact with external environments. Agentic data generation must maintain consistency among environments, tasks, interactions, and success signals while producing experience that is useful rather than merely abundant. Existing work spans many agent domains, but domain-centered organization and heterogeneous evaluation often obscure common generation mechanisms and conflate candidate construction with verification and selection. This work develops a two-level framework for the field. First, we represent agentic data as a common factorized object $(E,q,τ,v)$, comprising an environment specification, task signal, interaction realization, and optional verifier. We organize generation paradigms by their primary anchor and dependency structure. Second, we formulate generation as constrained distribution design through the Accuracy-Complexity-divErsity (ACE) lens. Accuracy establishes the feasible support of grounded and internally consistent data. Within this support, Complexity places learning mass relative to the capability of a declared learner and execution configuration, while divErsity controls coverage and redundancy of data. Using this framework, we explore how prior work verifies generated experience, constructs and calibrates difficulty, and expands behavioral coverage. The literature reveals a shift toward execution-grounded accuracy, learner-relative complexity, and diversity beyond surface variation or dataset size. We further discuss broader directions and emerging trends in agentic data generation through the ACE lens, including their implications for scaling, data sources, training regimes and adaptive learning. Overall, the central challenge is not simply to generate more data, but to continually allocate valid, informative, and non-redundant experience as agents and environments evolve.

## 2. 论文提出的方法论

### 2.1 因子化数据对象

论文将智能体数据统一表示为一个公共对象：

```
d = (E, q, τ, v)
```

| 因子 | 含义 | 说明 |
|---|---|---|
| **E** | 环境规范 | 可行动的世界：工具模式、数据库/模拟器状态、转移规则、策略、权限、观察接口、终止条件 |

### 2.2 生成范式分类

论文按**主要锚点**（起点因子）和**依赖结构**划分生成范式：

- **前向生成（Forward Generation）**：按自然依赖顺序 **E → q → τ** 构建。环境来源三类：真实/精选（真实API、MCP服务、仓库）、LLM合成（合成工具、工具图）、程序化构造（可执行环境、模拟器）。代表性工作见 Table 1（如 ToolLLM、APIGen、ToolACE、EnvScaler、EnvFactory 等）。
- **反向生成（Reverse Generation）**：不从环境出发，包括——
  - **任务优先（Task-First）**：先定目标能力/任务，再构造相应环境与交互（如 AgentInstruct、BUTTON、ToRA、MathCoder）；
  - **轨迹优先（Trajectory-First）**：先从已探索/观察到的有效行为中派生任务（如 Trajectory2Task、OS-Genesis、Explorer）；
  - **结构优先（Structure-First）**：先生成中间脚手架（工具图、蓝图、计划、对话骨架），再实现完整数据（如 ToolACE-MT、Magnet、APIGen-MT）。
- **自适应与自进化（Adaptive & Self-Evolving）**：生成与学习、覆盖率反馈闭环（如 AgentEvolver、WebEvolver、SESA、Socratic-SWE）。

### 2.3 ACE 目标：约束分布设计

论文将数据生成形式化为**受约束的分布设计问题**，给出核心公式：

```
max_φ  E_{B~pφ} [ λC · (1/|BA|) Σ_{d∈BA} gz(Cz(d)) + λD · D(BA) ]
s.t.  Pr_{d~pφ} [A(d)=1] ≥ α
```
- A(d) 为准确性（admission）判定，α 为最低接受率；BA 为通过准确性门控的子集；
- **准确性（Accuracy）** 定义可行支持（feasible support），是前提性门控条件：
  ```
  A(d) = VE(E) ∧ Vq(q|E) ∧ Vτ(τ|E,q) ∧ Vv(v|E,q,τ)
  ```
- **复杂性（Complexity）** 在可行支持内，相对"声明的学习者+执行配置z"分配学习质量：
  ```
  Cz(d) = 1 − Pr[v(d,τ)=1 | d, z]
  ```
  最优复杂度不在"越难越好"，而在**学习者的能力前沿附近的可学习带宽（learnable band）**内；
- **多样性（Diversity）** 是批次级属性，衡量环境、任务、交互三个层面的有效覆盖与非冗余程度：
  ```
  D(B) = Σ_k w_k H(Z_k | d∈BA, Cz(d)∈Iz) − λ_Red(BA)
  ```
- **非对称性**：无效样本不能通过"更难/更不同"来弥补；准确是必要条件，复杂度与多样性是在有效集合内的优化目标。

### 2.4 各维度的因子级分解

- **准确性的四因子**（Fig. 4）：环境一致性、任务可执行性、交互因果有效、验证器/结果正确。保障机制四方向（Fig. 5）：分层规则/模型/人工检查、约束锚定构建、执行与状态验证、基于反馈的修复与选择性接收。
- **复杂性的四因子**（Fig. 7）：环境复杂度、任务信号复杂度、交互实现复杂度、验证器约束的完成复杂度。校准机制：结构规范与组合、任务与信息控制、环境与交互设计、完成与反馈设计、渐进演化、失败驱动与模型感知校准、双向校准与脚手架。
- **多样性的四因子**（Fig. 8）：环境规范多样性、任务信号多样性、交互实现多样性、生成器与来源多样性。扩展机制：来源扩展、组合重组、探索优先发现、扰动与反事实变化、覆盖引导的配平与自适应。

## 6. 论文的主要结论与发现

- **文献趋势一**：从表面文本合理性（plausibility）转向**执行锚定的准确性（execution-grounded accuracy）**——越来越多系统以真实执行、状态检查、可运行测试与形式化验证作为准确性标准。
- **文献趋势二**：从静态难度启发式转向**学习者相对复杂度（learner-relative complexity）**——难度不是固定属性，而是相对于特定模型、脚手架、推理预算的"已验证失败概率"；最优学习数据落在学习者当前能力前沿附近的可学习带宽内。
- **文献趋势三**：从表面变化/数据规模转向**行为覆盖（behavioral coverage）**——多样性不再是工具名、提示改写或样本量的增加，而是环境、任务、轨迹三个层面产生可观察行为差异的有效覆盖。
- **ACE的核心不对称性**：数据越多并不等于越好；有效数据需先通过准确性门控，再谈复杂度和多样性。
- **方向性判断**：智能体数据生成正在从固定的后训练轨迹走向生成的执行环境、更早阶段（预训练/中训练）的监督，以及随学习者演化的闭环经验。核心挑战是维持一个**有依据的学习闭环**——持续扩展智能体能力而不放大错误、不缩小覆盖面、不失联真实环境。

## 8. 不足与局限
