## 摘要
尽管测试时扩展增强了大型语言模型（LLM）智能体在长时程软件工程（SWE）中的能力，但稀疏的二值奖励（通过/失败）造成了严重的信用分配危机，并浪费了失败的探索轨迹。当前的轨迹优化与扩展方法成本高昂且存在结构性局限，它们依赖启发式状态复用而缺乏因果诊断，或依赖延迟的标量评分而缺乏可操作的在线指导。我们提出 FLARE（Full-Lifecycle Alignment and Reward Engine，全生命周期对齐与奖励引擎），一种由轻量级生成式奖励模型（GRM）驱动的新型密集监督范式。首先，RADAR 是一种离线因果感知诊断框架，它通过因果链回溯提取高保真、无后见之明的监督信号，以蒸馏出一个提供实时、步骤级风险反馈的 GRM。其次，FLARE 利用该 GRM 在智能体的整个生命周期中持续优化智能体。在推理阶段，FLARE 充当主动脚手架，自主拦截高风险的生成步骤以进行局部断点重执行，从而大幅降低计算开销。在后训练阶段，GRM 的结构化信号作为监督微调（SFT）的过程监督重排序分数，以及强化学习（RL）的步骤级密集奖励，缓解稀疏环境中的策略崩溃。大量评估表明，FLARE 在智能体生命周期中建立了新的帕累托前沿：FLARE（N=1）优于 Global Rollout（N=5），同时 token 消耗降低至 1/5。将 FLARE 扩展到训练中，克服了长时程交互任务中的稀疏奖励问题，通过过程感知的数据整理在 SFT 中带来 19.13% 的相对性能提升，并在 RL 中持续获得 9.19% 的提升。

## Abstract
While test-time scaling enhances Large Language Model (LLM) agents in long-horizon software engineering (SWE), sparse binary rewards (Pass/Fail) create a severe credit assignment crisis and waste failed exploratory trajectories. Current trajectory optimization and scaling methods are costly and structurally limited, relying on heuristic state reuse without causal diagnosis or delayed scalar scoring without actionable online guidance. We propose FLARE (Full-Lifecycle Alignment and Reward Engine), a novel dense supervision paradigm driven by a lightweight Generative Reward Model (GRM). First, RADAR, an offline causal-aware diagnostic framework, extracts high-fidelity, hindsight-free supervision through causal-chain backtracking to distill a GRM providing real-time, step-level risk feedback. Second, FLARE uses this GRM to continuously optimize the agent across its entire lifecycle. During inference, FLARE acts as an Active Scaffold, autonomously intercepting high-risk generation steps for localized breakpoint re-execution, drastically reducing compute overhead. During post-training, the GRM's structured signals serve as process-supervised reranking scores for Supervised Fine-Tuning (SFT) and step-level dense rewards for Reinforcement Learning (RL), mitigating policy collapse in sparse environments. Extensive evaluations show that FLARE establishes a new Pareto frontier across the agent lifecycle: FLARE (N=1) outperforms Global Rollout (N=5) with a 5x reduction in token consumption. Extending FLARE to training overcomes the sparse reward problem in long-horizon interactive tasks, delivering relative performance gains of 19.13% in SFT through process-aware data curation and a consistent 9.19% improvement in RL.

# FLARE 论文中文总结

## 1. 核心问题与整体含义
- **研究动机**：长时程软件工程（SWE）智能体通常只依赖最终 Pass/Fail 的二值稀疏奖励，导致严重信用分配危机：失败后无法知道是哪一步出错，大量失败探索轨迹被浪费。
- **现有方法瓶颈**：
  - 测试时扩展（TTS）如 Global Rollout 需反复从零采样，计算昂贵。
  - 启发式状态复用（如 SWE-Replay）依赖结构代理进行分支，缺乏真正因果诊断。
  - 离线进化搜索或多智能体辩论依赖延迟标量评分或重型协商，无法在轨迹首次偏离时在线干预。
- **整体含义**：FLARE 试图将“盲目全局重试 / 延迟评分”转为“实时、轻量、步骤级诊断与干预”，并用同一诊断信号贯穿推理、SFT 和 RL 全生命周期，建立新的性能—成本帕累托前沿。

## 2. 方法论：核心思想与关键技术
- **核心思想**：训练一个轻量级生成式奖励模型（GRM），提供结构化、步骤级风险反馈；该反馈既用于在线断点修复，也用于 SFT 数据筛选和 RL 密集奖励。
- **RADAR 离线诊断框架**：
  - **轨迹语义压缩**：将每步 \(s_t\) 压缩为意图、动作、观察三元组 \((I_t,A_t,O_t)\)。
  - **双轨诊断蒸馏**：
    - **反向因果错误链分析**：对失败轨迹，从最终失败信号反向回溯，识别根因优先的因果相关步骤，并标注风险等级、错误类型、诊断分析。
    - **主动错误注入**：对成功轨迹的高影响步骤注入错误，断点重放估计恢复率，按阈值 \(\theta\) 将错误标为 critical 或 trivial，以扩充长尾错误样本。
  - **因果前缀蒸馏**：将离线分析改写为仅使用任务、当前步及历史的前缀可见分析，防止 patch、未来结果、测试 oracle 泄漏；并用合规门检查分类一致性、无支撑锚点与泄漏。
- **GRM 优化**：
  - 条件生成模型 \(p_\psi(\tilde y_t \mid q,s_t,H_t)\)，输出风险等级、错误类型和因果诊断。
  - 实际基于 Qwen3.5-4B 进行 SFT，输出结构化 XML：`<safe/>` 或 `<risk>` 包含分析、rubric issue、severity。
- **测试时干预（Active Scaffold）**：
  - 智能体提出下一步动作时，GRM 异步诊断上一步。
  - 若上一步为 critical，则基于诊断反馈重新生成下一步；否则继续。干预发生在下一步提交前，不撤销已执行工具操作。
- **训练时对齐**：
  - 构造步骤级风险校准奖励：风险严重度因子、错误重要性因子、位置权重、动作稀有度权重、错误重复惩罚。
  - 轨迹奖励 \(R(\tau)=\frac{1}{T}\sum_t r_t^{step}\)。
  - **SFT 数据选择**：按 \(R(\tau)\) 选 top 轨迹。
  - **RL 密集奖励**：将 \(R(\tau)\) 与最终 Pass/Fail 奖励结合，组内 z-score 归一化优势，使用 GRPO 优化。
