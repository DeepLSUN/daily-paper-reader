## 摘要
LLM 智能体常常使用生成模型进行有界决策，这引出了一个问题：何时可以在不降低任务成功率的情况下更高效地处理这些决策。我们研究了 REFLEX，一种智能体架构，它使用 Jev 作为快速、类型化的决策层，并在置信度低或需要生成时调用强 LLM。在一个冻结的 100 任务基准上，REFLEX 实现了 95% 的成功率，同时比仅使用强模型的智能体减少了 72.7% 的强模型调用，且这种减少在三个回退系列中持续存在。受控干预表明，其可靠性取决于动作集大小以及授权边界附近的近有效替代项。外部 BFCL 和 $τ$-style 评估显示，当普通路由已经高度准确时，相较于廉价的生成式级联，其优势有限。这些发现明确了使用 Jev 的选择性控制何时能够减少计算，以及其收益在何处受限。

## Abstract
LLM agents often use generative models for bounded decisions, raising the question of when these decisions can be handled more efficiently without reducing task success. We study REFLEX, an agent architecture that uses Jev as a fast, typed decision layer and calls a strong LLM when confidence is low, or generation is required. On a frozen 100-task benchmark, REFLEX achieves 95% success with 72.7% fewer strong-model calls than a strong-only agent, with reductions persisting across three fallback families. Controlled interventions show that reliability depends on action-set size and near-valid alternatives near authorization boundaries. External BFCL and $τ$-style evaluations reveal limited advantages over a cheap generative cascade when ordinary routing is already highly accurate. These findings identify when selective control with Jev can reduce computation and where its benefits are limited.

## 1. 核心问题与整体含义

- **研究动机**：工具型 LLM 智能体在每一步（状态检查、工具选择、参数填充、是否继续、生成回复）几乎都调用生成式强模型，灵活但代价高昂；而其中许多步骤本质上只是从固定集合中做有界选择，并不需要昂贵的生成式推理。
- **核心问题**：能否用专门的决策模型处理有界决策，在不降低任务成功率的前提下减少强模型调用？以及在什么条件下，这种"选择性控制"相比廉价的生成式级联（cheap generative cascade）才具有优势？
- **已有工作的空白**：多 LLM 路由器（FrugalGPT、RouteLLM、RouterBench 等）是在**整个查询层面**选择模型；工具使用基准主要评估函数选择是否正确。本文关注的是**智能体轨迹内部单个决策**的粒度，允许两种推理在同一 episode 中交替。

## 2. 方法论

### 2.1 核心思想
- 将智能体控制形式化为**选择性决策问题**：在步骤 t，状态为 \(s_t\)，类型化有界决策集合为 \(A_t\)（工具或控制动作）。
- 决策层 Jev 返回二元组 \((\hat{a}_t, c_t) = J(s_t, A_t)\)，其中 \(c_t \in [0,1]\) 为置信度。
- 策略函数：若 \(c_t \geq \tau\) 且该动作可执行，则直接执行 \(\hat{a}_t\)；否则调用强模型 \(L_{strong}(s_t)\)。高置信度决策可省去一次强模型调用，低置信度决策则把控制权交回回退模型而不强制行动。

### 2.2 关键设计细节
- **三类角色分离**：控制（从有界备选中选择）、参数合成（提供结构化取值）、生成/推理（自由文本或开放策略问题）。REFLEX 只针对**控制**。
- **REFLEX-Sim 中**：大量参数是状态的确定性函数；**外部多轮设置中**，在 Jev 与强模型之间插入一个廉价生成式执行器（executor）来生成文本和任意参数，强模型作为最终回退。
- **误差分类**：区分工具选择错误、参数错误、过早终止、策略错误，并区分"可恢复的无效决策"与"不可逆/终局失败"的动作（如额外检索 vs 不可逆写入）。

### 2.3 度量与统计
- **GMR（强模型调用减少率）**：\(GMR = 1 - N^{REFLEX}_{strong} / N^{strong-only}_{strong}\)。
- 同时报告每 episode 成本、每成功 episode 成本、每成功任务强调用数（防止因"早早失败而显得便宜"）。
- **选择性可靠性**：Risk(τ) = P(invalid | c ≥ τ)，Coverage(τ) = P(c ≥ τ)，用 AURC 汇总风险–覆盖权衡，并与匹配覆盖下的随机升级对比。
- **置信度门控与自升级**：把"廉价生成模型自行决定何时调用强模型"作为核心基线 B3，不预设专用决策层一定更优。
- 统计方法：配对簇 bootstrap（主分析 10000 次重采样，探索性 ≥2000 次）、McNemar 检验、RF-5C 采用预注册的边缘对比。

## 6. 主要结论与发现

### 6.1 正面结果
- **REFLEX-Sim 主结果**：τ=0.5 时成功率 **95%**，每任务强调用 **1.12 次**（B0：88%，4.10 次），**GMR = 72.7%**；每个测试阈值都相对 B0 构成 Pareto 改进。
- **选择性可靠性**：τ=0.5 时 251 个自主决策中 250 个有效，唯一无效决策可恢复；AURC = 0.019，远低于匹配覆盖下随机升级的 0.145（约 7.6×）；Brier = 0.103、ECE = 0.129，说明"有用但非完美"的置信度已足够。
- **被替代的决策类型**：工具选择 99%、完成判定 77%、检索决策 56%、澄清仅 28%——**澄清与授权相关判断更难委托**。
- **跨族稳健性**：强调用减少 66.1%–71.9%，token 减少 50.6%–64.1%，三个族均无统计显著的成功率下降；但按"置信下界需 > −0.02"的正式非劣检验，**Qwen 与 DeepSeek 通过，Kimi 不通过**（Kimi strong-only 处于天花板）。
- **固定自主子集**：三个族下门控选出的**同一 66/100 任务子集全部成功**，且门控不依赖下游强模型身份；所有 E6 失败都发生在需升级的 34 任务子集中。

### 6.2 边界与负面结果
- **可靠性受决策结构限制**：K 从 10→50 平均降低准确率 6.7 个百分点（p=0.0008）；A0→A3 降低 5.6 个百分点（p=0.038）；两者交互不显著。误差高度集中在**授权/风险类控制决策**（208 个错误中 192 个），检索、普通工具选择、工作流 720 个决策零错误。
-
