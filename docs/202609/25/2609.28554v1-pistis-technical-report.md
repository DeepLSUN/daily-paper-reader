## 摘要
我们提出 Pistis 模型系列，包含分别基于 Qwen3.6 和 Qwen3.5 构建的 27B 与 9B 参数多模态大语言模型，并通过一个通用且可扩展的后训练框架开发而成。该框架首先通过大规模多模态监督微调（SFT）建立坚实基础。在此 SFT 基础上，我们提出交错蒸馏与强化学习（IDRL），一种新颖的后训练范式，将同策略蒸馏与强化学习紧密集成在单个训练循环中。通过在两个目标之间交替，而不是孤立优化任一目标或将它们组合为静态联合损失，IDRL 能够实现更有效的知识迁移、更高的优化稳定性，以及对长时程智能体轨迹更精确的信用分配，从而在缓解常见能力权衡的同时取得更强性能。在两种模型规模上，该框架均产生两个专用变体：Pistis-Thinking，旨在增强深度多模态推理；以及 Pistis-Agentic，额外融入智能体轨迹数据，以支持长时程规划、迭代推理和工具使用。Pistis-Agentic 在多模态搜索方面尤其强大。两种规模均优于其对应的基础模型。除模型参数优化之外，我们进一步提出 Pistis-Auto-Harnessing（PAH），一种系统级方法，通过迭代优化自动改进智能体的推理执行框架。实验表明，PAH 在不更新模型参数或不增加交互预算的情况下提升了模型性能。

## Abstract
We introduce the Pistis model family, comprising 27B- and 9B-parameter multimodal large language models built on Qwen3.6 and Qwen3.5, respectively, and developed through a general and scalable post-training framework. The framework first establishes a strong foundation through large-scale multimodal supervised fine-tuning (SFT). Building on this SFT foundation, we propose Interleaved Distillation and Reinforcement Learning (IDRL), a novel post-training paradigm that tightly integrates on-policy distillation and reinforcement learning within a single training loop. By alternating between the two objectives, rather than optimizing either in isolation or combining them in a static joint loss, IDRL enables more effective knowledge transfer, greater optimization stability, and more precise credit assignment for long-horizon agentic trajectories, leading to stronger performance while mitigating common capability trade-offs. At both model scales, the framework produces two specialized variants: Pistis-Thinking, designed to strengthen deep multimodal reasoning, and Pistis-Agentic, which additionally incorporates agentic trajectory data to support long-horizon planning, iterative reasoning, and tool use. Pistis-Agentic is particularly strong in multimodal search. Both scales outperform their corresponding base models. Beyond model-parameter optimization, we further introduce Pistis-Auto-Harnessing (PAH), a system-level method that automatically improves the agent's inference harness through iterative optimization. Experiments demonstrate that PAH enhances the model performance without updating the model parameters or increasing the interaction budget.

## 1. 核心问题与整体含义

- **研究背景**：多模态大语言模型（MLLMs）在图像、视频、文档理解方面进展迅速，但后训练（post-training）仍是释放高阶推理、鲁棒泛化与真实可用性的关键瓶颈。
- **核心痛点**：
  - 现有流水线通常将监督微调（SFT）与强化学习（RL）分阶段执行，二者互补优势未被充分利用。
  - 蒸馏提供稠密监督，但使学生受限于教师分布；RL 优化任务奖励，但易导致策略熵坍塌并造成训练不稳定。
  - 长时程智能体任务需要过程级监督，仅靠最终答案奖励无法提供，中间动作的信用分配困难。
- **整体含义**：论文提出 **Pistis 模型家族**（27B/9B 多模态大模型）及通用可扩展后训练框架，旨在统一推理与智能体能力，缓解常见能力权衡，并额外从系统层面（PAH）优化推理执行框架。

## 2. 方法论

### 2.1 总体流程
- 基座模型：**Qwen3.6-27B** 与 **Qwen3.5-9B**。
- 三阶段框架：**大规模多模态 SFT → IDRL（交错蒸馏与强化学习）→ 推理时 PAH 自动 harness 优化**。
- 产出两类变体：**Pistis-Thinking**（深度多模态推理）与 **Pistis-Agentic**（长时程规划、迭代推理、工具使用）。

### 2.2 监督微调（SFT）
- 构建约 **320 万 QA 对**的多模态 SFT 语料，含推理数据与智能体轨迹数据。
- **推理数据**覆盖数学、图表/文档理解、科学图表、医学 VQA、代码生成、逻辑推理、通用 VQA；采用 `<think>…</think>` 结构化输出格式，便于解析与细粒度监督。
- **智能体轨迹数据**：工具集成推理（TIR）约 40%、搜索约 20%、通用智能体轨迹约 40%；自生成数据通过多轨迹采样 + 任务奖励筛选，保留中等难度成功轨迹。
- **质量控制**：标签校验、逻辑完整性、最小推理长度、答案一致性检查；采用 AdamW、学习率 1e-5、余弦衰减、序列打包至 32,768 token、3 个 epoch、全局 batch size 1,536。

### 2.3 IDRL（核心算法贡献）
- **核心思想**：在同一条训练循环中**交替**执行 on-policy 蒸馏（OPD）与 RL，而非顺序执行或静态联合损失。
- **调度函数**：`Πs = OPD` 当 `(s mod S) < S_OPD 且 s < S*`，否则为 `RL`；`S = S_OPD + S_RL`；熵平台期后切换为纯 RL（`S*`）。
- **On-Policy Distillation**：
  - 使用 **广义 JSD(β)** 作为目标，插值于 mode-seeking（反向 KL）与 mass-covering（正向 KL）之间。
  - **Top-k 词表限制**（k=50）：仅计算教师 top-k token，并对学生 top-k 外质量做解析残差处理，避免重归一化失真。
  - 关键发现：多模态场景下学生-教师初始分布重叠不足，需**冷启动 SFT** 桥接差距，否则 OPD 直接应用收益有限。
- **RL with Verifiable Reward**：
  - 采用 **SAPO** 平滑自适应策略梯度，以平滑温度门控替代 PPO 硬裁剪，形成平滑信任域。
  - **组相对优势**：`A_i = (R_i - mean)/std`。
  - **步级正优势抑制（PAS）**：对无效/被拒/重复/无法利用观察的中间动作，将其正优势置零，保留零或负优势，改善长时程信用分配。
  - **奖励设计**：优先规则/可执行验证（格式、STEM、OCR、IoU 定位），开放式任务用强 judge 模型。
- **为何交错优于求和**：
  - OPD 提供稠密 token 级信号并保持熵；RL 锐化策略、降低熵。
  - 联合目标 `L_joint = -J_RL + αL_OPD` 会产生交叉项 `g_R^T g_D`，当策略在实现 token 上过度自信时二者梯度冲突，联合更新可能拖累甚至反转其中一个目标。
  - 交错后每步只含单一梯度，一阶改进 `ΔJ_RL ≈ η‖g_R‖² ≥ 0`、`ΔJ_D ≈ ηα‖g_D‖² ≥ 0`，无交叉项污染。

### 2.4 PAH（Pistis-Auto-Harnessing）
- **系统级方法**：模型参数、工具协议、评测入口固定，仅优化推理 harness（代码约束、提示、状态表示、能力模块、路由规则、工作流）。
- **五阶段外循环**：归因 → 提案（单一可证伪改动）→ 实现 → 金丝雀门控 → 全量开发集评估；仅当开发指标提升才接受，否则回滚。
- **优化后 harness 组件**：
  - **Candidate Ledger**：有界结构化候选记录，含证据 ID、来源关系、未满足约束，保证可追溯。
  - **Search Skills**：条件加载的可复用操作流程（触发条件、步骤、成功标准、停止条件）。
  - **自适应工作流与预算控制**：证据驱动检查点、硬恢复步骤、预算感知终止。
- **最小干预原则**：默认保留原始推理路径，仅在可重放结构状态触发时增加提示/路由/恢复动作。

### 2.5 基础设施
- **训练**：SFT 用 VeOmni（padding-free 动态 token 预算批处理、FSDP2、FlashAttention-2、Liger-Kernel），比标准 HF 流水线端到端加速 >80%；RL 用 VeRL 异步 rollout + vLLM，比同步 RL 流水线约 2× 加速。
- **评测**：PistisEvalKit 基于 VLMEvalKit，模块化 Model/Benchmark 解耦，支持自动训练-评测循环与原生智能体基准。
- **推理**：vLLM 系统/调度/内核级优化，异步流水线 + 多进程前后端分离，ViT 参数 128 对齐以启用 H20 TMA 算子，部分 prefill 场景推理速度提升 >100%。
