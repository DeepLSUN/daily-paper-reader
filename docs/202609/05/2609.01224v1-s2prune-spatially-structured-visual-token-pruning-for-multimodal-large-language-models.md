## 摘要
视觉标记剪枝通过仅保留部分视觉标记来降低多模态大语言模型（MLLMs）的推理开销。现有方法通常基于重要性或冗余度来选择标记。然而，我们观察到这些标准在不同输入间会产生稳定的空间偏差，且并不总是优于简单的均匀网格采样，这凸显了广泛空间覆盖的价值。受此启发，我们提出了S$^2$Prune，一种无需训练的剪枝方法，它在保持空间覆盖的同时，使标记密度适应局部图像结构。我们首先将图像划分为多个区域，并为每个区域分配至少一个标记以保持覆盖。然后根据拉普拉斯变化分配剩余的标记预算，将更多标记赋予结构更丰富的区域。接着，我们利用从第一个解码器块计算的早期表示变化（ERC），在每个区域内选择代表性标记。我们在多种设置和两种MLLM架构上评估了S$^2$Prune。在Qwen2.5-VL-7B-Instruct上，它在所评估的免训练剪枝方法中实现了最高的平均准确率。在仅使用原始576个视觉标记中的32个时，它仍保留了全模型性能的79.3%。代码可在https://github.com/yuanyuanjia71-spec/S2Prune获取。

## Abstract
Visual token pruning reduces the inference overhead of multimodal large language models (MLLMs) by retaining only a subset of visual tokens. Existing methods usually select tokens based on importance or redundancy. However, we observe that these criteria produce stable spatial biases across inputs and do not always outperform simple Uniform Grid sampling, highlighting the value of broad spatial coverage. Motivated by this, we propose S$^2$Prune, a training-free pruning method that preserves spatial coverage while adapting token density to local image structure. We first divide the image into regions and assign at least one token to each region to preserve coverage. The remaining token budget is then distributed according to Laplacian variation, giving more tokens to regions with richer structure. We then use Early Representation Change (ERC), computed from the first decoder block, to select representative tokens within each region. We evaluate S$^2$Prune across diverse settings and two MLLM architectures. On Qwen2.5-VL-7B-Instruct, it achieves the highest average accuracy among the evaluated training-free pruning methods. With only 32 of the original 576 visual tokens, it still retains 79.3% of the full-model performance. Code is available at https://github.com/yuanyuanjia71-spec/S2Prune.

- 视觉 token 剪枝旨在保留少量关键视觉 token，以降低推理开销。已有方法主要基于 token 重要性（如注意力分数）或 token 冗余度/多样性进行筛选。
- 论文观察到两个关键现象：
  1. 不同评分准则（重要性、多样性等）会产生稳定且各异的**空间偏差**——某些位置（如边缘、特定行列）被系统性地高频选中，这种偏差与具体图像内容、问题内容关系不大；
  2. 这些精心设计的评分准则并不总是优于朴素的 **Uniform Grid（均匀网格采样）**，甚至有些方法不如 Random 采样。
- 这表明："选哪些 token"很重要，但"token 预算花在图像空间的哪些位置"同样关键。作者由此将视觉 token 剪枝类比为**图像压缩中的码率分配问题**：平滑区域需要少量 token 表示，而边界、文字、纹理等结构丰富区域需要更密集的采样。
- 论文的核心主张是：好的剪枝策略应当**在保持广泛空间覆盖的同时，根据局部图像结构自适应调整 token 密度**。

## 二、论文提出的方法论

### 1. 核心思想

S²Prune 是一种**无需训练**的剪枝框架，将任务拆分为两个阶段：

- **空间支架（Spatial Scaffold）**：决定"图像每个区域分到多少 token 预算"，由图像自身结构决定；
- **局部选择（Local Selection）**：在已分配预算的空间单元内选择"哪个 token 代表该单元"，由第一个解码器层的响应决定。

### 2. 关键技术细节

**（1）区域划分与结构复杂度计算**

- 将 24×24 的视觉 token 网格划分为 $G$ 个粗粒度区域 $\{R_g\}_{g=1}^G$（$G$ 根据预算选择，如 B=128 时用 8×8，B=64 时用 5×5，B=32 时用 4×4）。
- 整图转为灰度图后，用四邻域拉普拉斯算子（replicate padding 仅在图像外边界）计算响应图 $L$；
- 每个区域 $R_g$ 映射到图像域 $\Omega_g$，区域结构分量为：
  $$c_g^{raw} = \text{Var}(L|_{\Omega_g})$$
- 原始分数在单张图像内做 min-max 归一化，得到最终的分配分数 $c_g$。

**（2）预算分配公式**

- 每个粗区域首先获得 1 个 token，以保留基础空间覆盖；
- 剩余 $B-G$ 个 token 按结构分数比例分配，并满足约束 $1 \le B_g \le |R_g|$、$\sum_{g=1}^G B_g = B$：
  $$w_g = \frac{c_g}{\sum_{j=1}^G c_j}$$
- 使用迭代 largest-remainder 方法处理整数分配和区域容量上限。若所有结构分数为零，则退化为均匀分配。

**（3）局部单元划分**

- 每个区域 $R_g$ 按其得到的预算 $B_g$ 递归划分为 $B_g$ 个**近似等面积、互不重叠的矩形单元**（cell）；
- 拆分规则优先沿较长边、优先按行拆分，保证视觉 token 恰好一一覆盖。

**（4）ERC——局部代表 token 选取**

- 在残差 Transformer 中，token $i$ 经过第 0 个解码器块后的更新幅度为：
  $$r_i = \|h_i^1 - h_i^0\|_2 = \|\Delta_i^0\|_2$$
  即 Early Representation Change（ERC）分数，衡量第一个解码器块对该 token 表示的"改变程度"；
- 每个单元 $C_{g,k}$ 内保留 ERC 分数最大的 token：
  $$i^*_{g,k} = \arg\max_{i \in C_{g,k}} r_i$$
- 注意：ERC 分数只在单元内部比较，不做跨区域比较；区域的预算由拉普拉斯结构决定，ERC 只负责"选谁"。
- 剪枝只发生在解码器第 0 层之后、第 1 层之前；保留 token 按原始序排列并保留原始 M-RoPE 位置 ID。

### 3. 算法流程（文字概述）

1. 将视觉 token 网格划分为 $G$ 个粗区域；
2. 整图做灰度化和四邻域拉普拉斯变换，计算每个区域的方差并归一化；
3. 每区域先分配 1 个 token，再将剩余预算按结构分数比例分给未饱和区域（largest-remainder 取整）；
4. 将每个粗区域递归划分为 $B_g$ 个近等面积单元；
5. 全部视觉 token 通过解码器 Layer 0，计算每个 token 的 ERC 分数；
6. 在每个单元内选择 ERC 分数最高的 token；
7. 将选出的 token 按原索引排序后，在第 1 层前物理删除未选中 token，保留原位置编码继续推理。

## 六、论文的主要结论与发现

1. **全局 token 评分隐式决定了剪枝预算的空间分配**：不同评分准则在图像空间中产生稳定且各异的偏差（FastV、FEATHER 偏好边缘，占比近 58%），这种偏差不受图像内容影响，说明"空间位置"是独立于"token 重要性"的剪枝维度。
2. **朴素的空间覆盖具有强健壮性**：Uniform Grid 在 B=64 时在 4/5 基准上超过 Random，且能与复杂方法相竞争，说明空间覆盖不是 token 选择的副产品。
3. **均匀空间密度并不最优**：当局部结构高度不均匀时，自适应密度相对均匀密度优势显著（B=32 时增益为 2.79 pp，B=64 时为 1.39 pp）；结构分布均匀时两者差距小。
4. **S²Prune 在 Qwen2.5-VL-7B 上所有预算下取得最高平均精度**：B=128/64/32 时 Acc. 分别为 64.0/60.6/55.9，相对保持率 92.1%/87.0%/79.3%，领先最强基线分别 0.1/0.3/0.9 个百分点。
5. **在 LLaVA-OneVision-7B 上同样一致领先**（B=160/80/40 时 Rel. 为 94.6%/86.8%/77.2%），验证了方法跨架构的迁移性。
6. **攻击性剪枝下优势更明显**：B=32 时 S²Prune 在 GQA 上超出最强基线 2.6 pp、POPE 上 3.7 pp、MMB_EN 上 2.2 pp，表明结构自适应的空间分配在极端预算下尤为关键。

## 七、优点

1. **视角新颖**：跳出"哪个 token 重要"的既有范式，将剪枝重新定义为**空间码率分配问题**——"预算花在哪里"与"选哪个 token"解耦，为视觉 token 剪枝提供了新的理论视角。
2. **动机扎实**：通过多组控制实验（Random、Uniform Grid、结构异质性分组）逐步验证核心假设，从现象到方法再到验证链条完整。
3. **方法简洁有效**：完全免训练、无额外参数、无需 query 注意力或文本相关性，只依赖图像自身的拉普拉斯结构和第一个解码器块的表示变化，计算开销低。
4. **分析深入**：用 1,000 个样本的 token 选择频率图、边缘/中心比例、跨预算相关性等证据，系统揭示了空间偏差的存在及其稳定性，分析质量高于一般剪枝论文。
5. **实验全面**：两个架构、十个以上基准、多种压缩比、两组消融、效率分析、定性可视化，且区分了"结构分配"与"局部选择"各自贡献。
6. **工程细节完善**：补充材料提供了完整的伪代码（预算分配、递归分割）、网格敏感性和网格尺寸选择的依据，保证了可复现性。

   - 模型架构仅验证了 7B 级别的两个模型（Qwen2.5-VL 与 LLaVA-OneVision），未在更大模型（如 72B）或更多架构（如 InternVL）上验证；
   - 未涉及视频输入、多图输入等场景，仅针对单图视觉 token；
   - 生成任务（长文本生成）下的表现未做系统性评估，效率报告以分类任务（POPE）为主。

2. **算力信息不透明**：未披露完整实验所用 GPU 数量与总耗时，只说明效率测量在单张 RTX 5090 上完成，读者难以判断大规模基准实验的成本规模。

3. **局部选择器依赖单一信号**：ERC 仅在第一个解码器层响应后计算，理论上若采用 query 注意力或更深层信息可能进一步改善性能，但论文未做跨层选择信号的充分探索（仅在消融中对比了注意力和 Hidden Norm）。

4. **空间网格参数的启发式选择**：粗网格大小（G）随预算人为设定（4×4、5×5、8×8、9×9），论文虽提供了网格敏感性分析且显示结果稳定，但未给出理论上的最优网格选择准则。

5. **结构先验可能遗漏与语义强相关但低纹理的区域**：如平滑天空中的小物体与均匀背景的区分依赖拉普拉斯方差，对于结构性弱但语义重要的区域（如纯色背景上的小目标）可能分配不足。

6. **优势幅度有限**：在较大预算下（B=128、B=64）相对于已有最强基线（HoloV、GridPrune）的优势仅 0.1~0.3 pp，收益随预算放宽而缩小，方法主要价值体现在极端压缩率（B=32）条件下。

7. **基准偏向 VQA 类任务**：主实验以 VQA-型基准为主，未包括如 DocVQA、ChartQA、MathVista、AI2D 等更具专门推理难度的基准，结论外推需谨慎。
