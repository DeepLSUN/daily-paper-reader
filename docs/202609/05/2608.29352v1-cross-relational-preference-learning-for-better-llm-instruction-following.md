## 摘要
大型语言模型（LLMs）在遵循复杂指令方面仍表现出有限的能力。虽然现有方法通常依赖偏好学习来增强这种能力，但它们往往忽略不同指令允许的响应空间之间的关系，这限制了模型与细微且多样的约束变化对齐。为解决这一问题，我们提出了跨关系偏好学习（CRPL），一种构建偏好数据的新颖框架，通过两种关键技术显式建模指令间关系：跨关系扰动和跨区域对采样。这使得能够生成更多样化的偏好数据，捕获广泛的约束变化。此外，我们引入了一种基于原子约束的验证机制来严格评估响应满足度，确保高质量偏好对的构建。在多种偏好学习方法（如DPO、KTO）、LLM骨干网络和四个指令遵循基准上进行的大量实验表明，我们的方法相对于先前基线取得了显著改进，并展现出强大的泛化能力。

## Abstract
Large Language Models (LLMs) still exhibit limited capability in following complex instructions. While existing approaches often rely on preference learning to enhance this ability, they typically overlook the relationships between the permissible response spaces of different instructions, which restricts a model to align with subtle and diverse constraint variations. To address this, we propose Cross-Relational Preference Learning (CRPL), a novel framework for constructing preference data that explicitly models inter-instruction relationships through two key techniques: Cross-Relationship Perturbation and Cross-Region Pair Sampling. This enables the generation of more diverse preference data that captures a wide spectrum of constraint variations. Additionally, we introduce an atomic constraint-based verification mechanism to rigorously assess response satisfaction, ensuring high-quality preference pair construction. Extensive experiments across multiple preference learning methods (e.g., DPO, KTO), LLM backbones and four instruction-following benchmarks demonstrate that our approach achieves substantial improvements over prior baselines and exhibits strong generalization.

## 一、核心问题与整体含义（研究动机与背景）

- 面向L大语言模型（LLMs）虽在简单指令上表现优异，但在涉及**多重约束的复杂指令**上仍然存在明显不足。
- 现有基于偏好学习（如DPO、KTO）的对齐方法，其性能很大程度上取决于**偏好数据的质量**，而现有偏好数据构建方法存在一个共同盲点：**忽略了不同指令之间“允许响应空间”的关系**。
- 论文将两个指令的响应空间关系划分为三种基本类型（如图1所示）：
  - **包含（containment）**：一个指令的合法响应集是另一个的（真）子集；
  - **部分重叠（partial overlap）**：两个合法响应集存在交集，但互不包含；
  - **不相交（disjoint）**：两个合法响应集完全没有交集。
- 关键缺陷：已有方法要么完全忽视这些关系（如AutoIF），要么只利用不相交情形（如IOPO、MUSC），导致生成偏好数据覆盖不足，模型无法对细粒度、多样化的约束变化形成充分认知。
- 核心主张：训练应显式建模响应空间的**跨指令关系**，才能类比人类“利用相似性、对立性进行比较学习”的方式，增强模型对复杂指令的响应区分能力。

## 二、方法论：Cross-Relational Preference Learning（CRPL）

整体框架由两个阶段构成（对应图2）：

**阶段1：跨关系扰动（Cross-Relationship Perturbation）**

- 先用强LLM（DeepSeek v3.1）将原始指令分解为一组**可代码验证的原子硬约束**：C = {c₁, …, c_m}。
- 对每条指令的每一个约束，分别按三种目标关系（包含/部分重叠/不相交）生成扰动指令，得到P_con、P_par、P_dis三组扰动集。
- 扰动方式通过精心设计的Prompt完成。以“包含”关系为例，系统会指示LLM使扰动后的合法集为原合法集的**真子集**或**真超集**（论文实际实现中包含两种子类型：Containment-1和Containment-2，分别对应原约束更严格/更宽松）；部分重叠要求两个集合互不包含但存在交集；不相交则要求无交集。
- 对不适合直接修改的约束（如“输出JSON”这类类别型约束），允许保留原约束并附加额外约束来构造关系。

**阶段2：跨区域对采样（Cross-Region Pair Sampling）**

- 以“部分重叠”为例，将原指令x与扰动指令x̂_cᵢ的联合响应空间划分为三个互斥子区域：
  - S1：只满足原指令；
  - S2：只满足扰动指令；
  - S3：同时满足两者。
- 偏好对按公式(2)(3)构造（以负样本来自对侧专属区域、正样本来自专属或交叉区域的原则）：
  - O_original 包含：(x, S1正样本, S2负样本) 和 (x, S3正样本, S2负样本)；
  - O_perturbed 包含：(x̂_cᵢ, S2正样本, S1负样本) 和 (x̂_cᵢ, S3正样本, S1负样本)。
- 这种**交叉区域配对**能提供强对比信号，让模型更好区分对与错的约束满足。

**原子约束验证机制（Atomic Constraint-Based Verification, ACV）**

- 针对每条原子约束，让LLM生成独立的Python验证函数vᵢ；要求函数能通过6个LLM生成的测试用例且准确率超过80%，否则重新生成（这一阈值是为了避免多次重训）。
- 响应y_k的整体满足度计算为公式(4)：a_k = ∏ vᵢ(y_k)，即所有原子约束验证函数取与运算，只有全部通过才视为正样本。
- 相比“LLM直接打分”（LAJ）或“单一全指令验证函数”（ILV），ACV的粒度更细，能够避免因某一约束出错而整体误判的情况。

## 六、主要结论与发现

1. CRPL在所有训练策略（DPO、KTO、在线DPO）、两个主骨干模型、四个测试集上均优于既有基线。例如，Qwen2.5-7B + DPO配置下，Ours IFEval平均准确率比AutoIF高6.9%。
2. 方法具备良好的数据规模化性质：随数据量增大，CRPL性能持续上升，而基线方法增长趋于平缓，说明**数据质量而非单纯数量**才是关键。
3. 三种关系类型均不可或缺。消融结果显示，移除“不相交”关系影响最大（Acc_ins降低约7.8%），说明强对比信号对区分正确与错误约束满足至关重要。
4. 四项跨区域配对都对最终性能有贡献，移除任何一个都会造成性能下降。
5. 原子约束验证机制（ACV）在测试集统计中取得误判率最低（66/027个真阳性、零假阳性），显著优于LLM作为裁判（LAJ）和全指令级验证（ILV），且在端到端偏好训练中带来更高准确率。
6. 模型在“Perturbed-IF”和“FollowBench”上的优势证明，训练数据注入多样约束关系后可产生良好的**跨约束类型泛化能力**，不仅是在训练分布内有效。

## 七、主要优点与亮点

1. **思路新颖**：将指令间关系系统化建模为包含/部分重叠/不相交三类空间关系，这是偏好数据构造方面的重要视角转换——从“生成好坏样本”到“控制样本间的集合关系”。
2. **方法模块化**：CRPL只负责数据层（构造偏好对），可以无缝对接不同偏好学习算法（DPO/KTO/Online DPO），通用性强。
3. **验证机制严谨**：ACV通过分解约束生成独立代码验证器，并附测试用例生成与80%准确率门槛要求；相比以LLM为主观的评判，提供更强可复现性且实现零假阳性。
4. **实验设计有一定系统性**：覆盖原指令与扰动指令稳定性测试、随数据缩放、组件消融等方面；额外构建Perturbed-IF对评估泛化性很有说服力。
5. **充分考虑了泛化**：从代码可验证硬约束的IFEval/IFBench扩展到依赖LLM裁判的FollowBench，验证了跨约束类型的泛化能力。

## 八、不足与局限

1. **适用范围受限**：指令分解步骤极为强调“可程序化验证的硬约束”，论文也承认只关注硬约束；对需要主观、质量、风格类约束的复杂指令遵循问题，整个CRPL框架无法直接适用。
2. **消融范围较窄**：消融只在Qwen2.5-7B + IFEval + 离线DPO配置下进行，未能建立模型规模、数据源对组件重要性影响的更完整画面。
3. **基线复现公平性存疑**：某些基线（如SPAR在Qwen2.5上性能差于预训练模型，AutoIF等某些数据集的低下表现）暗示基线在复现时可能存在超参数未调优、训练启发因素影响等情况。
4. **VerIF对比方式不严格**：直接使用词表加载官方模型，不同骨干模型和数据配比下直接对比未必反映CRPL的实际优势。
5. **算力限制**：单卡A100并未支撑更大规模的响应采样与更多在线DPO迭代，可能低估了在线方法在更大步数下的表现。
6. **验证函数的可靠性依赖初始LLM生成**：虽然增加测试用例检验和80%阈值要求，但最终的验证函数可靠程度仍受限于生成LLM的能力，存在偏差风险。
7. **在线DPO下的增益相对有限**：在Qwen2.5-7B上，Ours IFEval在线版虽然在部分指标超过基线，但提升幅度明显小于离线版本；这暗示框架优势在自采样在线循环中会被稀释，需要更深入分析。

## 九、综合评价

CRPL是一篇以“偏好数据构造的多样性”为核心贡献的工作。论文核心贡献在于提出的跨关系扰动与跨区域区间采样为偏好对齐训练注入了结构化的关系信号，提出ACV验证机制保证采样点落位正确性。实验覆盖面较宽，亮点是现象清晰、组件贡献拆解得比较完整；局限是数据集与模型范围的过滤偏窄，跨任务的泛化验证主要依赖FollowBench一种场景，且软约束、更大模型、更多偏好学习算法的扩展仍留待后续研究。总体而言，这一工作在复杂指令遵循的偏好数据构造方向上提供了一个有价值的新视角和灵活框架。
