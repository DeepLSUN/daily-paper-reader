## 摘要
现代视觉语言模型（VLM）在图像地理定位任务上的表现明显高于人类基线，该任务在灾难响应、开源情报验证和位置隐私方面至关重要。然而，目前大多数有关人工智能在此任务上行为的研究仍局限于基于静态图像的检索、分类和预测。我们认为，真实的任务复现应该涉及具身导航，即多智能体自主探索周围环境以收集观测结果，再做出预测。为此，我们引入了GeoAgent——一个基于智能体环境的基准测试，要求智能体在街景环境中导航，通过顺序推理来优化其地理定位。我们的分析显示，现代VLM在尝试分辨区域级地理模式时表现困难，而在国家和大陆级别的预测上表现良好。与基于静态图像的方法相比，智能体导航在所有既定指标上显著提高了准确性。我们还注意到，在前沿模型架构中，对于发达/发展中地区的背景存在严重偏差，并且在给定错误先验时自我改进能力较弱。总体而言，我们的工作确立了具身导航和地理空间推理所面临的挑战。我们公开了代码和GeoAgent环境：https://geoagent-benchmark.github.io

## Abstract
Modern Vision-Language Models (VLMs) perform well above the human baseline in image geolocalization, a task critically important in disaster response, OSINT verification, and location privacy. However, most efforts to study AI behavior on the task remain limited to static image-based retrieval, classification, and predictions. We argue that faithful recreation of the task should involve embodied navigation, where a multimodal agent autonomously explores its surroundings to gather observations before submitting a prediction. To this end, we introduce \textbf{GeoAgent}, an agentic environment-based benchmark that requires agents to navigate Street View environments to refine their geolocalization through sequential reasoning. Our analysis shows that modern VLMs struggle to discern regional patterns while succeeding at country- and continent-level predictions. When compared to static image-based baselines, agentic navigation significantly improves accuracy across established metrics. We also note severe bias in a developed/developing region context across frontier model architectures and poor self-improvement capabilities given incorrect priors. Overall, our work establishes the challenges of embodied navigation and geospatial reasoning. We publicly release our code and the GeoAgent environment: https://geoagent-benchmark.github.io

### 一、论文的核心问题与整体含义（研究动机与背景）

- **问题背景**：图像地理定位（geolocalization）在灾难响应、开源情报（OSINT）验证、位置隐私等真实场景中十分关键。现代视觉语言模型（VLM）在该任务上已超过非专家人类表现，但现有评估方式大多仅限于**静态单图或视频切片**的检索/分类/预测，属于"被动推理"（passive inference）。
- **核心批判**：被动式评估无法反映人类真实的定位过程——人类是通过主动探索环境（移动、环顾、寻找路牌与地标）来逐步消除不确定性的。静态视角下，最具判别力的画面可能根本不在给定图像集合中，模型没有机会"主动求证"，因此评测到的是**识别能力而非不确定性下的推理能力**。
- **论文主张**：真实的地理定位任务应包含**具身导航（embodied navigation）**——智能体在多视图街景环境中自主移动、收集观测、做序列推理，再给出最终预测。据此，作者提出 **GeoAgent**：一个开源、模块化、可复用的智能体环境与基准，用于在可完全探索的 Google Street View 环境中评测 VLM。
- **整体含义**：GeoAgent 将地理定位从"单张图片分类"推进到"具身空间智能"评测新范式，并揭示了前沿 VLM 在主动探索下的三类行为缺陷：初始假设错误时缺乏自我纠正、发达/发展中地区的系统性偏差、探索策略的低效与工具调用脆弱性。

### 二、论文提出的方法论（核心思想、技术细节与关键流程）

**1. 核心思想**
- 将地理定位重新定义为**智能体顺序决策任务**：智能体通过"观察 → 推理 → 动作"的循环（ReAct 风格）在受限街景环境中探索，在每一步输出当前的位置猜测，直到提交最终答案。
- 显式区分两个子能力：**探索动作的工具调用能力**与**地理空间推理能力**。

**2. 环境与动作空间**（共 9 个工具调用）：

| 动作 | 说明 |
|---|---|
| `ROTATE:<degrees>` | 旋转至指定朝向（0–360°） |
| `ROTATE_LEFT` / `ROTATE_RIGHT` | 向左/右旋转 90° |
| `ROTATE_BEHIND` | 向后转 180° |
| `LOOK_UP` / `LOOK_DOWN` | 俯仰 ±20° |
| `MOVE_FORWARD` | 沿道路前进 |
| `RETURN_START` | 返回起点 |
| `GUESS` | 提交最终猜测 |

**3. 关键流程设定**
- 每个 round 从一个固定出生点开始，模型每轮输出结构化 JSON（observation、reasoning、confidence、action、guess）。
- **动作预算设为 8 步**（有限智能体导航）：作者在附录 B 中发现，平均 Haversine 距离在动作 5 之后趋于平台甚至退化；无限预算不会带来提升，反而会放大确认偏差并显著推高 API 成本。
- 为避免 LLM 在坐标换算上产生幻觉，模型提交的猜测（城市/国家名）由 Google Geocoding API 转为经纬度。

**4. 评测指标**
- **Haversine 大圆距离**：d = R·c，其中 a = sin²(Δϕ/2) + cos ϕ₁·cos ϕ₂·sin²(Δλ/2)，c = 2·atan2(√a, √(1−a))，R = 6371 km；同时报告均值与中位数（分布高度偏斜）。
- **改进率（Improvement Rate）**：improvementₖ = (1 − dₖ/d₁) × 100%，其中 d₁ 为第 1 步（初始猜测）距离，dₖ 为第 k 步距离；按最终城市猜测正确与否分层计算。
- **TF-IDF 词表分析**：将每个 round 的观察与推理文本按国家聚合为文档，抽取 top-N 特征词，用于分析模型对各地理类别的典型用语。

**5. 对比条件设计**
- **静态 4-View / 8-View 基线**：拼接多个视角截图，单次推理、无交互（4-view 为 0°/90°/180°/270° 全景；8-view 增加一次前移后的另一组四视角）。
- **随机基线（Random Baseline）**：均匀随机采样经纬度作为下限参考。
- **随机游走（Random Walk）**：8 步动作全部随机抽取，但模型仍看到所有渲染画面并给出最终猜测——用于分离"目标导向的动作选择"与"视觉覆盖+推理"的贡献。
- **无限步智能体（Unlimited Agentic）**：去掉 8 步上限并加入显式自我反思提示词。
- **人类参照点**：6 名志愿者（GeoGuessr 新手至中级经验），共完成 380 轮，使用相同街景界面。

### 三、实验设计（数据集/Benchmark 与对比方法）

### 六、论文的主要结论与发现

1. **主动探索确实提升定位，但高度依赖初始假设质量（RQ1）**：总体而言，智能体导航相较静态 4-view/8-view 显著缩小了距离误差并提升城市级准确率（如 Gemini 3.0 Flash 城市准确率从 39.5% 提升至 50.1%，相对提升 26.8%；GPT-5 Mini 从 30.3% 升至 34.5%）。但当初始猜测已经错误时，模型表现出**确认偏差**：额外探索很少纠正错误先验，多数模型对错误结果近乎"免疫"。最终成功轮次的中位初始距离为 847 km，而失败轮次为 2,341 km；逻辑回归系数 β = −0.43（p < 0.001），说明探索的作用是"精化合理假设"而非"重新发现"。

2. **系统性的发达地区偏差（RQ2）**：所有模型在发达地区距离误差比发展中地区低 50–103%；Gemini 3.0 Flash 在国家层面的偏差超过 20 个百分点。该偏差无法用数据质量解释——发展中地区的街景影像实际上更新（中位 2.51 vs 3.09 年）、质量评分略高、锐度无差异。Gemma 3 27B 是唯一在城市准确率上反转这一趋势的例外。

3. **探索长度与推理篇幅不等于更好成绩（RQ3）**：GPT-5 Mini 距离成绩最好且推理最短（182.8 词）；Claude Haiku 4.5 最弱却最冗长（424.2 词）。探索动作与成绩的相关虽然显著，但效应量很小（|ρ|<0.25），**动作质量比数量更重要**。
