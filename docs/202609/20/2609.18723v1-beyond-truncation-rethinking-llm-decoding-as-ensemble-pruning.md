## 摘要
我们提出马氏距离集成解码（Mahalanobis-Ensemble Decoding，ME-Decoding），一种新的大语言模型（LLM）解码框架，将候选词元选择建模为集成剪枝。现有选择策略主要依赖标量概率，忽略了几何语义关系，并导致候选冗余。与此同时，当前几何感知方法通常需要复杂优化，或直接重新加权原始词元概率，从而导致显著的计算开销或推理不稳定。为解决这一问题，我们将解码形式化为一个子集优化问题，使用马氏距离驱动的目标，以在保持高概率的同时增强语义多样性。具体而言，我们利用词元相似度矩阵动态折减冗余生成路径，该矩阵通过词元嵌入上的自适应带宽核构建。我们进一步设计了一种高效的贪心选择算法，在早停条件下对候选规模具有近线性复杂度，并建立了其理论近似保证。这使ME-Decoding成为一个稳健的即插即用模块，且推理开销可忽略不计。在多种推理和生成任务上的大量实验表明，我们的方法持续取得强劲性能。

## Abstract
We introduce Mahalanobis-Ensemble Decoding (ME-Decoding), a novel Large Language Model (LLM) decoding framework that frames candidate token selection as ensemble pruning. Existing selection strategies rely predominantly on scalar probabilities, ignoring geometric semantic relationships and causing candidate redundancy. Meanwhile, current geometry-aware methods often require complex optimization or directly reweighting the original token probabilities, leading to significant computational overhead or inference instability. To address this, we formulate decoding as a subset optimization problem using a Mahalanobis distance-driven objective to enhance semantic diversity while preserving high probabilities. Specifically, we dynamically discount redundant generation paths using a token similarity matrix, constructed via an adaptive-bandwidth kernel over token embeddings. We further devise an efficient greedy selection algorithm with near-linear complexity in the candidate size under early stopping, while establishing its theoretical approximation guarantees. This renders ME-Decoding a robust, plug-and-play module with negligible inference overhead. Extensive experiments across diverse reasoning and generation tasks demonstrate that our method consistently achieves strong performance.

- **几何感知方法的局限**：
  - Top-W：将解码表述为 Wasserstein 正则化的分布匹配问题，需要近似目标与细致调参，且未显式优化候选冗余。

- **关键研究问题**：如何设计一个**简单高效**的框架，选出**紧凑但信息量大**的词元集合，同时保留高置信候选？
- **整体含义/新视角**：论文借鉴集成学习中的**集成剪枝**范式——候选词元类比为集成成员，其概率衡量个体置信度，嵌入相似度衡量语义冗余；理想解码子集应同时保留高似然词元并抑制冗余候选，对应准确率–多样性的权衡。

## 2. 方法论

### 2.1 核心思想
- 将解码形式化为**子集优化问题**，用**马氏距离驱动**的目标增强语义多样性，同时保留高概率词元。
- 候选池为概率截断得到的 $V_t \subseteq \Omega$（全文简记为 $V$），最终从选出的子集 $S$ 中重归一化采样。

### 2.2 关键定义
- **马氏集成能量（MEE）**：$\mathrm{MEE}(S) = p_S^\top K_S^{-1} p_S$，其中 $p_S$ 为 $S$ 上的词元概率向量，$K_S$ 为 $S$ 上的相似度矩阵；$K_S^{-1}$ 对冗余词元降权、奖励集体质量高的子集。
- **马氏集成得分（MES）**：
  $$\mathrm{MES}_\lambda(S) = \frac{\mathrm{MEE}(S)}{\left(1+\lambda H_{T_2}(p)\right)^{|S|}}$$
  其中 $H_{T_2}(p) = 1 - \sum_{i\in V} p_i^2$ 为二阶 Tsallis 熵（度量分布不确定性），$\lambda>0$ 控制熵相关的大小惩罚。分子奖励非冗余贡献，分母抑制子集过度扩张；分布平坦时惩罚抬高纳入门槛，仅保留非冗余贡献足够大的词元。
- **最终目标**：$S^\star = \arg\max_{S\subseteq V} \mathrm{MES}_\lambda(S)$。

### 2.3 相似度矩阵构造
- 归一化嵌入 $e_i$，语义距离 $C_{ij} = 1 - e_i^\top e_j$，高斯核 $K_{ij} = \exp\{-C_{ij}/\epsilon\}$。
- **自适应带宽**：$\epsilon = \frac{1}{2}\sum_{i,j\in V} p_i p_j C_{ij}$（概率加权语义分散度）。候选语义集中→$\epsilon$ 小→更概率驱动；语义分散→$\epsilon$ 大→更几何感知。
- 计算上无需构造完整 $N\times N$ 矩阵：$\epsilon = \frac{1}{2}(1 - \|\sum_i p_i e_i\|_2^2)$，仅需 $O(Nd)$。

### 2.4 优化算法
- 直接最大化是 NP-hard，采用**贪心前向选择**（概念上类似正交匹配追踪 OMP），增量维护 $K_S^{-1}$ 的**逆 Cholesky 因子**，避免重复矩阵求逆。
- **Algorithm 1 流程**：初始化选最高概率词元 → 计算 $R=(K_{S,S}^{1/2})^{-1}$、$z=Rp_S$、当前 MES → 循环：对每个候选 $j$ 计算 $\beta_j$、$b_j$、$\alpha_j=R\beta_j$、$r_j=(b_j-\|\alpha_j\|_2^2)^{-1/2}$ 及加入后能量 $c_j$ → 选最大 $c_j$ 的 $j^\star$ → 若惩罚后 MES 不再改善则**早停**，否则用块更新更新 $R$、$z$ 并入集。

### 2.5 理论性质
- **Theorem 3.1（贪心单峰性）**：若受限条件数 $\kappa_N(K) \le 1+\lambda H_{T_2}(p)$，则 MES 贪心序列一旦下降就不再上升，早停规则合理，停止点即贪心路径最大值。
- **Theorem 3.2（近似保证）**：$\mathrm{MES}^g_\tau \ge (1-\exp\{-\lambda_{\min}(K,N)\})\,\mathrm{MES}^\star_\lambda$，近似因子取决于 $K$ 的受限最小特征值（反映非冗余性与条件数）。
- **复杂度**：$O(N\tau(d+\tau^2))$，早停使 $\tau \ll N$ 时近似 $O(Nd)$；内存 $O(N\tau)+O(\tau^2)$。
