## 摘要
推理智能体越来越依赖网络搜索等外部工具来回答复杂查询。诸如 GRPO 之类的强化学习（RL）微调算法提升了纯文本语言模型中的长格式推理能力，尤其是在编程和数学领域。然而，多模态智能体中可靠的工具使用仍然具有挑战性，因为模型必须理解文本和图像，同时整合带有噪声的检索证据，且常常处于稀疏的结果级监督之下，缺乏显式的验证信号。我们提出基于强化学习的自我验证（Self-Verification via Reinforcement Learning，SVRL），这是一个仅使用 RL 的微调框架，训练多模态智能体在自身的推理轨迹中验证并过滤检索到的证据，从而在推理时减少对外部验证器的依赖。SVRL 还引入了搜索感知惩罚，以抑制不必要的工具调用，并引入查询多样性奖励，以鼓励多样且格式良好的搜索查询，从而对何时搜索以及搜索什么提供细粒度反馈。仅用 5,000 个视觉问答示例对 Qwen-2.5-VL-7B 进行 SVRL 微调，即可在多跳 VQA 泛化能力和跨基准的工具效率上取得一致提升。总体而言，SVRL 缩小了紧凑型智能体与规模大得多的专有模型之间的差距，同时显著降低了训练和推理成本。

## Abstract
Reasoning agents increasingly rely on external tools such as web search to answer complex queries. Reinforcement learning (RL) finetuning algorithms such as GRPO have improved long-form reasoning in text-only language models, particularly for coding and mathematics. Reliable tool use in multimodal agents, however, remains challenging because models must interpret text and images while integrating noisy retrieved evidence, often under sparse outcome-level supervision without explicit verification signals. We present Self-Verification via Reinforcement Learning (SVRL), an RL-only finetuning framework that trains multimodal agents to verify and filter retrieved evidence within their own reasoning traces, reducing reliance on external verifiers at inference time. SVRL also introduces a search-aware penalty that discourages unnecessary tool calls and a query-diversity reward that encourages diverse, well-formed search queries, providing fine-grained feedback on when and what to search. Finetuning Qwen-2.5-VL-7B with SVRL on only 5{,}000 visual question answering examples yields consistent gains in multi-hop VQA generalization and tool efficiency across benchmarks. Overall, SVRL narrows the gap between compact agents and much larger proprietary models while requiring substantially lower training and inference cost.

## 1. 核心问题与整体含义
- **研究背景**：多模态大模型正从静态感知系统转向可调用外部工具（如网络搜索）的交互式智能体。GRPO 等强化学习微调已在纯文本长程推理（代码、数学）中展现效果，但多模态工具使用仍不可靠。
- **核心问题**：多模态智能体需要同时理解图像与文本，并整合噪声检索证据；但监督通常只有结果级奖励，缺少显式验证信号，导致三类失败：
  - **搜索校准差**：需要搜索时未搜索，或不需要时过度搜索。论文分析 MMSearch-R1 在 FVQA 子集上：超过 10% 应搜未搜，超过 30% 不必要搜索。
  - **检索证据噪声大**：约 45% 检索结果不相关；即使查询合适且有相关证据，仍有超过 28% 回答错误。
  - **稀疏监督与 GRPO 方差崩塌**：中间决策无标注，不同失败获得相同终端惩罚；若组内奖励相同，GRPO 优势信号消失。
- **整体含义**：论文提出 **SVRL（Self-Verification via Reinforcement Learning）**，一种纯 RL 微调框架，让紧凑多模态智能体在自身推理轨迹中学会验证、过滤检索证据，并在推理时无需外部验证器，从而缩小与大型专有模型的差距。

## 2. 方法论
- **核心思想**：将多模态工具增强 VQA 建模为策略优化。模型给定图像 \(I\) 和问题 \(q\)，生成包含推理、工具调用、验证和最终答案的轨迹 \(\tau\)。通过 RL 奖励塑造，使模型学会：
  - 何时搜索；
  - 生成多样且有效的搜索查询；
  - 对检索片段进行自我验证与过滤。
- **基础设置**：
  - 沿用 MMSearch-R1 的工具与格式，动作包括 `<search><img></search>`、`<text_search>...</text_search>`、`<answer>...</answer>`。
  - 每次工具调用后，模型需输出二进制验证向量，如 `<verify>0,1,0,1</verify>`，对每个检索片段判断是否有用。
- **奖励设计**：
  - 基础奖励：\(r_{base}=(1-\alpha)r_{acc}\cdot r_{search}+\alpha r_{fmt}\)，其中 \(r_{acc}\) 为答案精确匹配，\(r_{fmt}\) 为格式奖励。
  - SVRL 最终奖励：
    \[
    r(\tau)=(1-\alpha)r_{acc}(\tau)r_{svrl}(\tau)+\alpha r_{fmt}(\tau)
    \]
    \[
    r_{svrl}=r_{aware}\cdot r_{count}\cdot r_{qalign}\cdot r_{salign}
    \]
  - **搜索感知因子 \(r_{aware}\)**：先用无工具单次前向判断问题是否“search_free”。若问题无需搜索却调用搜索工具，则降权 \(\lambda_{sa}=0.1\)，否则为 1。用于抑制不必要工具调用。
  - **查询多样性因子 \(r_{count}\)**：模型每次文本搜索提出 \(k=5\) 个候选查询，训练时随机执行一个有效唯一查询。若未调用文本搜索则为 1；否则为 \(\max(\epsilon,\hat{k}/k)\)，鼓励生成多个格式良好且多样的查询。
  - **查询对齐 \(r_{qalign}\)**：衡量模型提出的查询与训练时验证器标注的有用查询之间的一致性。
  - **片段对齐 \(r_{salign}\)**：衡量模型自我验证分数与验证器标注的片段有用性之间的一致性。
  - **正确性门控**：细粒度奖励乘在 \(r_{acc}\) 上，只有最终答案正确时才获得验证/搜索塑形奖励，避免部分正确奖励被刷。
- **训练时验证器**：使用外部验证器（GPT-5）并额外提供真实答案 \(y^*\)，为查询和检索片段生成标签；推理时丢弃该验证器，由模型自主验证。
- **稳定优化**：采用 **Dr. GRPO**，移除标准差归一化和长度归一化等可能放大梯度的因子，稳定轨迹级奖励下的训练。SVRL 可用更小的 group size \(G=4\)，而 MMSearch-R1 使用 \(G=8\)。
- **算法流程简述**：
  1. 对训练集每个样本做无工具前向，标记是否 search_free。
  2. 采样一组 rollout，解析答案、工具参数、自我验证向量。
  3. 用训练时验证器生成查询/片段标签。
  4. 计算 \(r_{aware},r_{count},r_{qalign},r_{salign}\)，组合为 \(r_{svrl}\)。
  5. 计算最终奖励，用 Dr. GRPO 更新策略。
