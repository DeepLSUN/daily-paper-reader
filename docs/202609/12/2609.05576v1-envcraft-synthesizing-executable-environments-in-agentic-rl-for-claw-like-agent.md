## 摘要
LLM 的范式已迅速从被动的语言接口转向能够在有状态工作空间中执行长时程任务的自主类 Claw 智能体。尽管智能体强化学习（Agentic RL）为优化这类智能体提供了有前景的路径，但其规模化受到交互式训练环境严重稀缺的制约。现有的合成环境严格局限于工具调用端点，难以满足类 Claw 智能体端到端的现实需求。为弥合这一差距，我们提出 EnvCraft，一个用于合成可执行环境与可扩展训练数据的自动化框架。具体而言，EnvCraft 采用环境合成引擎构建沙箱隔离的工作空间，并配合拓扑感知的数据生成引擎生成连贯的任务轨迹。总体而言，我们合成了 139 个交互式环境，包含约 2 万个复杂任务，用于智能体强化学习训练。在 Qwen3/3.5 模型（8B-32B）上的实验表明，我们的方法在 Claw 风格基准上最高提升 +11.9%，在通用工具使用基准上提升 +8.0%，同时降低了推理 token 成本。结果证实，合成的可执行环境为训练提供了稳健且可泛化的学习信号。

## Abstract
The paradigm of LLMs has rapidly shifted from passive language interfaces to autonomous Claw-like agents that execute long-horizon tasks across stateful workspaces. While Agentic Reinforcement Learning (Agentic RL) provides a promising path to optimize these agents, its scaling is heavily bottlenecked by the severe scarcity of interactive training environments. Existing synthetic environments are strictly limited to tool-calling endpoints, rendering them insufficient for accommodating the end-to-end real-world demands of claw-like agents. To bridge this gap, we introduce EnvCraft, an automated framework for synthesizing executable environments and scalable training data. Specifically, EnvCraft employs an environment synthesis engine to build sandbox-isolated workspaces, alongside a topology-aware data generation engine to produce coherent task trajectories. Overall, we synthesize 139 interactive environments comprising approximately 20K complex tasks for Agentic RL training. Experiments on Qwen3/3.5 models (8B-32B) show that our method yields gains of up to +11.9% on Claw-style benchmarks and +8.0% on general tool-use benchmarks, with concurrent reductions in inference token cost. The results confirm that synthesized executable environments provide robust and generalizable learning signals for training.

## 二、方法论

### 2.1 问题形式化

- **环境四元组**：`E = ⟨D_doc, I_tool, S, T⟩`
  - `D_doc`：环境文档（系统规则、操作约束、安全边界）
  - `I_tool`：工具接口（名称、参数、描述）
  - `S = {s_data, s_runtime}`：持久可观测状态空间（数据状态 + 运行时会话）
  - `T: S_t × I_tool → S_{t+1} × O_{t+1}`：沙箱内确定性状态转移函数
- **数据点三元组**：`P = ⟨Q, S_0, V_script⟩`，即用户查询、初始环境状态、确定性验证脚本（基于状态突变 `S_0 → S_n` 给出程序化奖励）。

### 2.2 环境合成引擎

- **场景收集**：从 OpenClaw 社区与既有工作收集原始样本，去重与语义过滤后保留 **12 个通用工具使用粗粒度领域 + 13 个 Claw 专用类别**，细化为 **41 个通用场景 + 42 个 Claw 场景（共 83 个细粒度场景）**；再用 LLM 将简短描述扩写为环境规格 `E_spec` 与工具接口规格 `T_spec`。
- **九种交互原型（Interaction Archetypes）**：作为结构化提示模板 + 参考实现，覆盖：①事务型工作空间、②跨工具数据流水线、③动态人机交互、④异步事件触发、⑤约束引导状态机、⑥多资源时序调度、⑦多准则双边匹配、⑧分布式工作流编排、⑨容错流处理。通过关键词重叠打分检索，最多取 top-2 作为上下文架构锚点。
- **规格引导生成**：LLM 融合 `P_proto + E_spec + T_spec`，程序化生成完整可执行环境类（会话生命周期、领域工具模块、状态初始化、文档 README/SKILL、持久化 store.py、异常处理、并发测试、验证器兼容接口）。
- **Claw 专用扩展**：
  - **内置工具**：注入源自 OpenClaw harness 的系统级 Bash 执行工具，赋予 CLI 级交互能力。
  - **并行技能协同合成**：同步生成领域定制的 Agent Skills（Markdown 形式可复用工作流指南）。
- **质量审计（双阶段）**：
  - 静态：AST 解析 + 合规规则检查语法与接口规范。
  - 动态：实例化初始状态、执行预置测试用例，验证工具可用性与状态转移逻辑、边界异常处理。
  - 失败环境进入 **自愈循环**：将执行日志回灌 LLM 自动修补代码后复检。
  - 结果：**324 个原始环境 → 139 个通过（42.9%）**，其中通用工具环境 70 个、Claw 环境 69 个。

### 2.3 数据合成引擎

- **工具链采样（拓扑感知）**：构建**双层有向图**
  - 底层：每个沙箱内的**环境内工具依赖图**（静态代码分析 + LLM 对前后置条件推理，形成带权边）
  - 顶层：**跨环境依赖图**（环境为节点，LLM 依语义域与跨环境数据流建带权边）
  - 采用**分层加权随机游走**：单环境任务在工具图上游走；跨环境任务先采样 2–5 个逻辑相连环境，再在各工具图内游走并拼接带前缀子链。
  - **可验证性约束**：工具划分为只读（read）与写入（write），强制每条链**以状态突变工具结尾**，保证任务必然改变环境状态、可程序化验证。
- **三段式任务合成**：
  1. **链到任务逆向工程**：LLM 区分参数为「用户指定字面量」或「工具派生中间结果」，逆向生成自然语言指令——**显式给出用户值、抽象引用工具派生值**，隐藏真值，强制智能体通过真实工具执行发现中间结果（保证任务不可凭空推测）。
  2. **意图分解**：将复合指令拆解为**逐步披露信息的多轮用户指令序列**；引入 PersonaHub 人格画像（按与环境的语义相似度每环境保留至多 5 个，共 500 个），随机选一用于条件化模拟用户行为。
  3. **意图到环境构建**：生成初始环境状态（含正确执行路径所需实体 + 合理干扰记录）与确定性验证脚本，输出自包含 JSON 任务记录（任务 ID、用户任务、初始状态、可执行验证脚本）。
- **数据质量审计**：
  - LLM 评审（使用 DeepSeek-V4-Pro，确定性解码）：三维度 0–3 分——任务可解性与逻辑 `s_sol`、验证协议完整性 `s_val`、数据一致性 `s_con`；保留条件为 `s_sol=3 且 s_val=3 且 s_con≥2 且总分≥8`。
  - **难度校准**：用 Qwen3.5-27B 对每题独立 rollout 8 次（温度 0.7，top-p 0.95），计算通过率 `p`，**仅保留 0 < p < 1 的样本**（剔除全对与全错），以形成平衡难度分布。
  - 结果：**35,464 条原始候选 → 19,777 条高质量样本（55.77%）**，含 14,215 条通用工具使用（EnvCraft-Tool）与 5,562 条 Claw 专用（EnvCraft-Claw）。

### 2.4 训练算法

- 采用 **GRPO**（在 VERL 框架内实现），轨迹级结果奖励，`Â_{i,t} = Â_i` 对所有 token 共享；目标函数含裁剪重要性比与 KL 惩罚项 `β D_KL`。

### 3.1 训练数据与策略

- 数据：EnvCraft-Tool（14,215 条通用工具使用）+ EnvCraft-Claw（5,562 条 Claw 专用）。
