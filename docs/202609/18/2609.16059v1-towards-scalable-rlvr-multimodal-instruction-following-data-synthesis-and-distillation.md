## 摘要
多模态指令遵循（MMIF）对于构建通用智能体至关重要。然而，当前训练范式严重依赖监督微调（SFT），这往往导致表层模式匹配并损害通用能力。尽管可验证奖励强化学习（RLVR）提供了一种有前景的替代方案，但其在 MMIF 中的可扩展性受到高质量、可直接用于 RL 的多模态数据稀缺的严重制约。为弥补这一差距，我们提出 MIFS（Multimodal Instruction Following Synthesis，多模态指令遵循合成），一个旨在生成可直接用于 RL 的多模态数据的系统化流程。具体而言，MIFS 引入生成式约束协议以合成多样化的原始样本，随后采用可学习性感知的蒸馏机制，基于 RL 训练动态对数据进行过滤，以确保稳定的策略优化。此外，基于代码的验证器为策略学习提供高精度奖励信号。所得数据集包含 8 个约束类别、14 个任务领域的 90k 个样本。实证评估表明，与使用原始数据相比，经 MIFS 训练的多模态大语言模型（MLLM）在四个 MMIF 基准上平均提升 8.13%，训练收敛速度快 3 倍。至关重要的是，我们的方法缓解了 SFT 典型的泛化权衡，在显著提升指令遵循精度的同时保留了核心视觉能力。

## Abstract
Multimodal instruction following (MMIF) is crucial for building generalist agents. However, current training paradigms rely heavily on Supervised Fine-Tuning (SFT), which often leads to surface-level pattern matching and degrades general capabilities. While Reinforcement Learning with Verifiable Rewards (RLVR) offers a promising alternative, its scalability in MMIF is severely bottlenecked by the scarcity of high-quality, RL-ready multimodal data. To bridge this gap, we present MIFS (\textbf{M}ultimodal \textbf{I}nstruction \textbf{F}ollowing \textbf{S}ynthesis), a systematic pipeline designed to generate RL-ready multimodal data. Specifically, MIFS introduces a generative constraint protocol to synthesize diverse raw samples, followed by a learnability-aware distillation mechanism that filters data based on RL training dynamics to ensure stable policy optimization. Furthermore, a code-based verifier provides high-precision reward signals for policy learning. The resulting dataset comprises 90k samples across 8 constraint categories and 14 task domains. Empirical evaluations demonstrate that MIFS-trained MLLMs achieve an average improvement of 8.13\% on four MMIF benchmarks and a 3$\times$ faster training convergence compared to using raw data. Crucially, our approach mitigates the generalization trade-offs typical of SFT, preserving core visual capabilities while significantly boosting instruction-following precision.

## 1. 核心问题与研究动机

- **背景**：多模态指令遵循（MMIF）是构建通用智能体的关键能力，要求 MLLM 在复杂视觉输入下准确解析并执行用户给定的多重约束。其应用场景包括自主机器人、精确代码生成、创意内容合成等。
- **现有范式瓶颈**：主流做法仍是监督微调（SFT）或 DPO。但研究表明 SFT 倾向于"表层模式匹配"而非真正内化指令逻辑，常出现"指令遵循提升、通用推理能力下降"的泛化权衡。
- **RLVR 的潜力与阻碍**：可验证奖励强化学习（RLVR）在文本推理模型（如 DeepSeek-R1 系列）上已证明有效，但向多模态扩展时，**高质量、可直接用于 RL 的多模态数据严重稀缺**。已有 MMIF 数据集要么规模小（MIA-Bench 400 条、CrafText 3,924 条、MMMT-IF 990 条），要么仅面向 SFT 而非 RLVR（MM-IFInstruct 23k，无 RLVR 支持）。
- **三大挑战**：
  1. **执行级规模与复杂度**：如何在全自动高吞吐流程中合成嵌入多重交织约束的多样化指令；
  2. **策略优化的数据可学习性**：并非所有数据都契合 RL 训练动态，需筛出位于模型"学习前沿"的样本；
  3. **奖励保真度与验证**：LLM-as-a-judge 易受奖励黑客与偏见影响，需要程序化、零容忍的可验证奖励信号。

## 2. 方法论：MIFS 流水线

### 2.1 核心思想
构建一套**三阶段系统化流水线**（MIFS），把普通视觉问答对转化为"约束密集 + 程序可验证"的 RL 就绪数据，再基于 RL 训练动态蒸馏出高信号子集。

### 2.2 阶段一：种子空间构建与指令合成

- **视觉基础**：从 CC3M 与 ALLaVA 中筛选 20,000 张高分辨率图像。对无标注数据集（CC3M）用 IC9600 与 RAM Stage 1 指标筛选语义密度高的自然场景；对 ALLaVA 仅保留原始图像、丢弃原有 QA 对；统一排除低分辨率样本。
- **认知任务分类法**：建立四级层次、14 个子领域的任务池——感知（Perception）、表达（Expression）、认知（Cognition）、元分析（Meta-Analysis）。
- **生成式约束协议（Generative Constraint Protocol）**，三条准则：
  1. **语义—代码等价性**：每条自然语言约束严格映射为可执行的 Python `checker_code`，消除主观歧义；
  2. **结构复杂度**：每条查询强制要求 ≥5 条非平凡、相互作用的约束；
  3. **可量化透明性**：所有阈值（比例、计数）必须在 prompt 中显式声明，保证任务逻辑可解。
- **生成流程**：随机采样图像与查询构成基础 VQA 对 → 用先进 LLM（本文使用 Gemini 3.0-Pro）按协议合成约束集 → 编排为"图像—指令任务 + 代码验证器"。共获得 **500k 原始样本**。
- **剪枝—重生成策略**：先让 LLM 生成初始回答，用代码验证器动态执行；若失败则定位失败约束、剪除问题约束（downsample constraints），再让 LLM 重新生成一致回答，迭代直至逻辑自洽且可程序化校验。

### 2.3 阶段二：多步质量蒸馏（三层漏斗）

- **Step A｜约束密度过滤**：过滤 n=1 的过简样本，对 n>10 的样本下采样 30%，聚焦 2–10 条约束的高密度区间，兼顾复杂度与可解性。
- **Step B｜难度感知剪枝**：以 Qwen3-VL-8B 作为经验审计器：
  - 8 次独立推理，avg@8 > 0.8 的"简单样本"丢弃（信息增益有限）；
  - avg@128 = 0 的"不可能样本"丢弃（避免陷入死胡同奖励空间）；
  - 同时利用 128 次独立试验中验证正确的回答构建 SFT 用的 VQA 对。
- **Step C｜RL 可学习性过滤**：计算每条样本在多训练轮次中的**轨迹偏差**：
  
  $$D_i = \frac{1}{E}\sum_{e=1}^{E}(r_{i,e} - \bar{r}_e)^2,\quad \bar{r}_e = \frac{1}{N}\sum_{i=1}^{N} r_{i,e}$$
  
  其中 $r_{i,e}$ 为样本 $i$ 在第 $e$ 轮的奖励，$\bar{r}_e$ 为该轮全体样本平均奖励。$D_i$ 越大表示越偏离整体学习趋势（离群样本）。仅保留偏差最低的 **40%**，以提供稳定梯度。

### 2.4 奖励验证器
采用**基于代码的验证器**提供二值奖励：全部约束通过则 R=1，否则 R=0。刻意排除主观标准，只保留确定性、规则化约束，以避免奖励黑客。

### 2.5 数据划分与特征
- 最终数据集 **90,838（≈90k）条**，平均每条 **7.1 条约束**，覆盖 **8 类约束、14 个任务领域**。
- 划分：**MIFS-RL 60,048** 条用于 RL；**MIFS-SFT 83,280** 条（由 ≤3 个候选回答构成的 `<instruction, response>` 对）；**MIFS-Eval 1,200** 条留出评测集。
- 约束类型分布：关键词包含 17.7%、负向约束 16.8%、长度 17.1%、结构 16.2%、标点 13.5%、位置 9.6%、格式与风格 6.5%、语法约束。
- 高熵量化：约束类别 Shannon 熵 ≈2.84 bits（理论最大值的 94.76%）；任务域熵 ≈3.77 bits（99.13%）。近重复率：Jaccard≥0.8 为 0.00%，Cosine≥0.8 在 SFT/RL/Eval 分别为 2.61%/4.73%/1.31%。

## 6. 主要结论与发现

- **指令遵循显著提升**：RL 训练在 4B/8B/32B 上平均提升 **+8.16 / +8.13 / +8.52**；8B 上 SFT+RL 达 +9.23。32B 在 MM-IFEval（75.91）与 MIFS-Eval（89.79）取得最高绝对分。
- **RL 优于 SFT**：SFT 仅 +3.09%，直接 RL 达 +8.13%，说明基于探索的 RL 比模仿式 SFT 更能内化逻辑约束；SFT+RL 相比纯 RL 仅再提升约 1.1%，暗示可直接通过 RL 完成高精度指令遵循，简化传统多阶段对齐流程。
- **缓解泛化权衡**：RL 训练在 OCRBench/MMVet/MMBench 上波动 <0.5%，保持通用视觉能力；而纯 SFT 平均下降 12.3%，验证了 SFT 的"能力退化"现象。纯文本 IFEval 亦有提升，说明未造成语言能力灾难性遗忘。
- **蒸馏带来效率与性能双赢**：数据量压缩 82%（500k→90k），最终性能绝对提升 2.4%；收敛步数从 ~420 步降至 ~140 步，实现 **约 3× 训练加速**。
- **稳定性提升**：MIFS-RL 的奖励曲线更单调稳定，而原始数据虽名义奖励更高但测试精度更低（含大量简单样本）。

## 7. 优点（方法/实验亮点）

- **数据侧创新**：生成式约束协议把自然语言约束严格映射为可执行 Python 检查器，从源头保证"零歧义 + 程序可验证"，有效规避 LLM-as-judge 的奖励黑客与偏见问题。
- **首创性定位清晰**：是当前少有的**专为多模态 RLVR 设计**的大规模数据合成流水线，填补了"MMIF 缺 RL 数据"的空白，并与现有数据集做了系统性表格对比。
- **可学习性感知蒸馏**：用轨迹偏差 $D_i$ 量化样本与整体学习趋势的一致性，是一种可复用、可迁移到其他 RL 数据筛选场景的通用机制；同时结合难度双阈值（avg@8 与 avg@128）实现"学习前沿"定位。
- **数据质量量化严谨**：用 Shannon 熵、Jaccard/Cosine 近重复率等指标量化高熵性与低冗余，并设计了防泄漏的评测集划分（图像与约束组合双重隔离）。
- **闭环验证**：从数据合成 → 质量过滤 → 训练动态可视化 → 人工审计，形成较完整的证据链；代码与数据集均已开源。
- **实际工程价值**：90k 样本即可获得 3× 收敛加速，对 RLVR 训练成本控制具有直接意义。

- **架构覆盖有限**：实证仅锚定 Qwen-VL 系列，跨主流 MLLM 家族（LLaVA、InternVL

- **自建评测的潜在偏置**：MIFS-Eval 由作者自行构建，虽做了防泄漏设计，但约束类型分布与训练数据同源，可能高估方法在真实开放指令场景下的表现。
- **约束类型的语义局限**：为追求"程序可验证"，刻意排除主观、开放性约束（如"回答要有创意""风格需幽默"），导致数据分布偏向形式化/可机械校验的约束（关键词、长度、标点、位置等），对真实世界中模糊、语用层面指令的覆盖不足，存在"可验证性—真实性"之间的取舍。
- **奖励信号过于稀疏**：采用二值奖励（全对为 1、否则为 0），在约束数较多（平均 7.1 条）时，部分正确无法获得中间信号，可能导致 RL 早期探索效率偏低；论文未与"部分信用分配"类奖励设计做对比。
- **数据合成算力成本未披露**：虽然 RL 训练算力（128×Ascend 910B、约 12 小时）报告清晰，但 500k 原始样本的合成、剪枝—重生成迭代、avg@128 难度审计等高开销环节的算力与时间成本缺失，难以评估端到端成本效益。
- **蒸馏指标单一**：可学习性过滤仅依赖轨迹偏差 $D_i$ 这一离群度指标，未与基于梯度、影响函数（influence function）或数据价值估计（如 Data Shapley）等更细粒度的样本选择方法对比，最优性未被证明。
- **基线与评测可比性受限**：多模态侧缺乏同类 RLVR 工作，文本侧 RECAST/VerIF 无法直接迁移到多模态，导致"多模态 RLVR 优于其他范式"的论断主要依赖内部消融而非强外部对照。
- **人工审计规模偏小**：仅 50 条样本、3 名标注者，虽报告一致率 92.0%、精确率 97.22%，但样本量与标注者多样性有限，验证器可靠性的统计置信区间较宽。
- **消融维度不够全面**：三层蒸馏以串联方式评估，未做交叉/独立消融（如单独启用 Step C 或调换顺序），难以精确量化每层过滤的边际贡献；同时未系统探索约束数区间、任务领域配比等数据组成因素的影响。
- **超参与规模敏感性未分析**：未报告对 G、clip ratio、KL 系数、学习率等 RL 超参的敏感性实验，也未验证方法在 4B 以下或 32B 以上规模的趋势。

## 9. 总体评价与启示

- **定位与贡献**：本文是一篇**数据-centric 的工程—方法混合型工作**，核心贡献不在于提出新算法，而在于系统性地解决了"多模态 RLVR 缺数据"这一瓶颈问题。MIFS 流水线的价值在于把"数据合成—质量蒸馏—可验证奖励"三者串联为一个可复用、可扩展的闭环范式。
- **方法层面的可迁移性**：
  - "自然语言约束 → 可执行检查器"的生成式约束协议，可迁移到 Agent 工具调用、代码生成、结构化输出等一切需要程序化验证的场景；
  - 基于轨迹偏差的可学习性过滤，是一种与具体任务无关的 RL 数据筛选启发式，理论上可移植到文本 RLVR、机器人策略学习等。
- **实证层面的关键启示**：
  - **RL 在指令遵循上优于 SFT**，且 SFT+RL 的边际增益有限，暗示对于"规则明确、可程序验证"的任务，可以跳过 SFT 直接做 RL，简化对齐流程；
  - **数据质量 > 数据数量**：82% 的数据压缩反而带来性能提升与 3× 收敛加速，为 RLVR 的算力经济学提供了实证支持；
  - **RL 缓解了 SFT 的能力退化**：SFT 导致通用视觉能力平均下降 12.3%，而 RL 波动 <0.5%，说明基于探索的优化更有利于保留预训练能力。
- **对领域的推动**：本文与同期 RLVR 数据合成工作（文本侧的 RECAST、VerIF 等）形成互补，把 RLVR 从纯文本推理推向多模态指令遵循，为构建"可验证奖励驱动的通用多模态智能体"提供了数据基础设施。
- **开放问题**：如何把程序化可验证约束扩展到主观/开放指令？如何设计部分信用奖励以缓解稀疏性？如何在跨架构、跨任务上验证可学习性过滤的普适性？这些都是后续工作值得深挖的方向。

## 10. 一句话总结

本文提出 MIFS——一条把普通 VQA 对转化为"约束密集、程序可验证"的多模态 RL 就绪数据的合成与蒸馏流水线，仅用 90k 样本即在 Qwen3-VL 4B/8B/32B 上取得平均 +8% 以上的指令遵循提升、约 3× 训练加速，同时避免 SFT 带来的通用能力退化，是多模态 RLVR 数据基础设施领域的一项务实且具迁移价值的工作。
