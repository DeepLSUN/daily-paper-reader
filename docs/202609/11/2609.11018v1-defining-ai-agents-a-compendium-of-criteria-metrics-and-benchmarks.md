## 摘要
人工智能中的“智能体”（agent）一词缺乏标准定义，这给AI智能体研究的评估、比较和可复现性带来了困难。我们通过一项围绕智能体性的五个维度组织的综述来应对这一模糊性：环境交互、学习与适应、自主性、目标导向行为以及时间连贯性。针对每个维度，我们考察已有工作中如何对底层能力进行概念化，并综合用于评估该能力的指标、基准和评估框架。本综述对智能体评估的当前图景进行了结构化梳理，既强调了已确立的方法，也指出了评估仍然有限或不一致的领域。我们还介绍了Agent Compendium，这是一个面向公众的数字资源，用于组织和扩展本综述所识别的评估方法。综述与汇编共同为评估和比较不同AI系统中的智能体能力提供了通用结构，有助于提升研究的可复现性、促进更清晰的交流，并推动对人工智能体更系统的研究。

## Abstract
The term agent in artificial intelligence lacks a standard definition, complicating the evaluation, comparison, and reproducibility of AI agent research. We address this ambiguity through a survey organized around five dimensions of agenticness: environmental interaction, learning and adaptation, autonomy, goal-directed behavior, and temporal coherence. For each dimension, we examine how the underlying capability has been conceptualized across prior work and synthesize the metrics, benchmarks, and evaluation frameworks used to assess it. This review provides a structured account of the current landscape of agent evaluation, highlighting both established approaches and areas where evaluation remains limited or inconsistent. We additionally introduce the Agent Compendium, a public-facing digital resource that organizes and extends the evaluation methods identified through this review. Together, the survey and compendium provide a common structure for evaluating and comparing agent capabilities across AI systems, supporting more reproducible research, clearer communication, and more systematic study of artificial agents.

## 1. 核心问题与整体含义（研究动机与背景）

- **术语模糊性**：AI 领域中的“agent（智能体）”缺乏被广泛接受的定义，研究者对“一个系统需要具备哪些能力才能被称为智能体”长期存在分歧。
  - 例如：2026 年某教材将 AI agent 描述为具备环境感知、自主决策、网络优化的“智能软件实体”；同年另一篇研究则将其定义为“完成任务并与其他 agent 通信的自主系统”。
  - 业界定义也不一致：OpenAI 强调“独立替你完成任务”，Anthropic 强调“LLM 动态主导自身流程与工具使用”。
- **三大现实问题**：
  1. **评估与可复现性受损**：缺乏共同标准时，能力差异巨大的系统可能被用同一术语描述，导致评估结果不可比。LLM 融入 agent 架构进一步加剧了“该评估什么能力、用什么基准”的不确定性。
  2. **沟通困难**：研究者、开发者与公众之间对 agent 能力、自主程度、所需人类介入的理解出现偏差。Shome et al. (2026) 发现用户存在“prompt gambling”——因不确定 agent 会如何行动而不敢下指令。
  3. **概念混淆**：AI agent 与 agentic AI 被混用，缺乏对“是否算 agent”与“agentic 程度高低”的明确区分。
- **整体含义**：论文主张将“agent”从笼统标签转变为可测量的能力集合（agenticness），并通过建立显式准则 + 评估方法映射，提升研究的可复现性、可比性，并为未来 agentic AI 研究奠定基础。

## 2. 方法论：核心思想、关键技术细节与框架

- **核心思想**：以 Bent (2025) 提出的 **agenticness 框架**为组织骨架，围绕五个维度系统梳理已有评估方法，并将准则映射到具体指标、基准与评估框架，最终形成公开数字资源 **Agent Compendium**（agent.duketrustlab.com）。
- **五大维度**（全文组织主线）：
  1. **环境交互（Environmental Interaction）**：感知、理解与操纵环境。
  2. **学习与适应（Learning and Adaptation）**：利用资源执行任务并调整行为以适应新条件。
  3. **自主性（Autonomy）**：无需人类干预或指导独立运行的程度。
  4. **目标导向行为（Goal-Directed Behavior）**：形成、理解并追求目标的能力。
  5. **时间连贯性（Temporal Coherence）**：通过记忆、上下文与意图维持逻辑一致性。

- **各维度的关键技术内容与代表性公式/流程**：

  - **环境交互**
    - **Agent 架构**：分为 deliberative（符号表征 + 推理）、reactive（条件-动作规则，无内部世界模型）、hybrid（两者结合）。指出 deliberative 基于 Newell & Simon 的物理符号系统假设，存在“现实世界难以符号化”“符号推理难以实时”两大缺陷；纯 reactive 不可适应。
    - **导航**：核心指标为 **SPL（Success weighted by inverse Path Length）**：
      `SPL = (1/N) Σ Si · ℓi / max(pi, ℓi)`，其中 ℓi 为最短路径，pi 为实际路径，Si 为二值成功指示。涵盖 Point-Goal、Object-Goal、Vision-Language、Audio-Visual、EQA、VQA 六类任务（对应 DD-PPO、ZSON、CLIP-Nav、CoW、Room-to-Room、REVERIE、VLN-CE、SoundSpaces、EXPRESS-Bench、NoisyEQA、ScanQA、Oscar 等模型）。
    - **工具使用**：MultiCAT-Bench 将工具调用拆解为 call、tool name、arguments 三类，计算 Accuracy、Overall Recall/Precision/F1、ToolName R/P/F1、Arguments R/P/F1；工具参数分 minimal / partial / complete 三档。另有 **Tool Dexterity Index (TDI)**：`TDI = Σ 工具使用得分 / 工具使用机会总数`，+1 最优、−1 误用、−0.5 忽略更优工具。
    - **空间分析**：Felicia et al. (2026) 提出 micro-（厘米）、meso-（米）、macro-（千米）三级空间尺度，指出“尺度不匹配是空间 AI 迁移失败的主因”。记忆系统分短期/长期/情景/空间；四类失败模式：空间幻觉、参考系混淆、尺度不敏感、时间漂移。**目前尚无跨 agent 的空间失败追踪评估框架，作者建议作为活跃研究方向。**
    - **一致性**：三分面——结果一致性、轨迹一致性（类型 + 序列）、资源一致性。给出公式：结果一致性 `Cout = (1/T) Σ(1 − σ̂t²/(p̂t(1−p̂t)+ε))`；轨迹类型一致性用 JSD 衡量；轨迹序列一致性用归一化 Levenshtein 距离；资源一致性用变异系数 `Cres = exp(−(1/|R|)Σ CVr)`。Agent drift 用 **Agent Stability Index (ASI)** 的四个维度衡量（输出语义相似度、决策路径稳定性、置信度校准、工具序列一致性）。
    - **鲁棒性**：`RobustSucc = (1/NM) Σ Σ si,m`，`WorstSucc = (1/N) Σ min_m si,m`。分四类：对抗鲁棒性（AgentDojo、HarmBench、AdvBench、JailbreakBench、CyberSecEval）、故障鲁棒性 R_fault、环境鲁棒性 R_envt、提示鲁棒性 R_prompt（均为 `min(Acc_pert / Acc_0, 1)` 形式）。

  - **学习与适应**
    - **效率与成本**：**CES（认知效率分数）** = (生成 token 总数 + 工具/API 调用 × token 等价) / 成功完成任务数；延迟用分位数 `Quantile_q(t) = t(⌈qN⌉)`；token 用量与成本 `Tokens = (1/N)Σ(xi+yi)`，`Cost = (1/N)Σ(pin·xi + pout·yi)`。
    - **轨迹与规划**：分计划形成（任务分解）与计划反思。指标：动作有效率 ValidActRate、循环率 LoopRate、计划遵循度 PlanAdh。
    - **可靠性**：与鲁棒性区分——可靠性指跨时间与重复的一致性，用跨种子方差 Var 衡量。
    - **Agentic 能力层级（Ritchie et al., 2026）**：1 工具使用 → 2 规划与目标形成 → 3 适应性 → 4 扎根性 → 5 常识推理。
    - **任务分解度量（Meshkov, 2026）**：Granularity Score ≥ 0.75、Efficiency Ratio ≥ 0.80、Goal Alignment（cos_sim）≥ 0.85、Logical Correctness = 1.0。
    - **上下文保持度量**：CRA（上下文保持准确率）、SRA（来源追踪准确率）、Context Decay `C(d) = αe^(−βd) + (1−α)/(1+γd²)`，并按短/中/长程给出成功阈值。
    - **可预测性**：校准 P_cal（ECE 形式）、区分度 P_AUROC（等价 AUC-ROC）、Brier 分数 `Pbrier = 1 − (1/T)Σ(ci−yi)²`。
    - **通用性**：Morris et al. (2023) 按最低性能阈值分 5 级（Emerging → Superhuman）；Kasirzadeh & Gabriel (2025) 按任务掌握广度分 5 级（单一专长 → 完全通用）。

  - **自主性**
    - **三套 5 级分类体系**：
      - Kasirzadeh & Gabriel：受限 → 部分 → 中间 → 高 → 完全自主（改编自 SAE 驾驶自动化分级）。
      - Morris et al.：AI 作为工具 → 顾问 → 协作者 → 专家 → agent（并给出各级风险：过度依赖、定向操纵、准社会关系、大规模劳动力替代）。
      - Feng et al.：以用户角色分——操作员 → 协作者 → 顾问 → 审批者 → 观察者。
    - OECD 按动作自主性分 4 级：human support / in-the-loop / on-the-loop / out-of-the-loop。
    - **安全指标**：Compliance = 无违规任务比例；Harm severity = 1 − E[w|违规]（低 0.25 / 中 0.5 / 高 1.0）；Risk = (1−Compliance)×(1−Harm)；Policy Violation Rate；Human Intervention Rate。

  - **目标导向行为**
    - **意向性（Intentionality）**：Chiappetta & Mahari (2026) 的 **FIT-Eval**，五个子维度各分 0–4 级：purpose（目标稳定性）、foresight（预见）、volition（意志/主动性）、temporal commitment（时间承诺）、coherence（推理连贯性）。
    - **目标复杂度**：5 级（Minimal → Unbounded），映射到计算复杂度（P 类 → NP 类 → 不可判定）与系统论特征。
    - **目标执行**：任务型指标 GCR（目标完成率）、DTT（决策周转时间）；资源型指标 CES、CQI（协作质量指数）、TDI。
    - **韧性与适应**：MTR（多步任务韧性）、CRS（链鲁棒性分数）、AD（适应性差值 = few-shot 表现 − zero-shot 表现）。

  - **时间连贯性**
    - **连贯性**：核心是**主动处理窗口（APW）**与**上下文锚定（context anchoring）**；锚点对语义漂移施加“恢复力”。
    - **漂移度量**：状态向量 si、与参考状态 s0 的偏差 Di（欧氏距离或余弦散度）、漂移速度 Vi、漂移加速度 Ai（持续正加速度是锚点失效的强信号）。
    - **滞后性（Hysteresis）**：`H = E[‖s(x)_i − s(x)_{i−k}‖₂]`；H 低意味着过度敏感、锚点退化，是漂移的先兆。

    - 未对纳入的指标进行实证验证或一致性检验，因此“充分性”主要体现在梳理广度而非实证效度。

## 6. 主要结论与发现

- **术语歧义是结构性问题**，不仅是命名问题，还影响评估可复现性、人机沟通、用户信任与治理。
- **五维 agenticness 框架可作为共同结构**，将“是否算 agent”转化为“在哪些维度上具备何种程度的可测能力”。
- **评估领域存在明显空白与不一致**：
  - 混合 agent 架构缺少评估方法（建议结合 Carrascosa et al. 的 reactivity degree）。
  - 导航指标高度模型特定，缺少 model-agnostic 指标（如 SPL 是少数通用者）。
  - 任务掌握（task mastery）缺乏量化标准。
  - 空间失败追踪、时间连贯性/状态意识与记忆结构缺少专门基准。
- **提出 Agent Compendium** 作为公开、持续更新的数字资源，用于组织与扩展评估方法。
- **长期目标**：支持更可复现的研究、更清晰的沟通、更系统的 agent 研究，并为 agentic AI 的治理与监管提供基础。

## 7. 优点

- **结构清晰、组织有力**：以五维度为骨架，每个维度再拆分子组件，逻辑层级分明，便于读者按能力定位评估方法。
- **概念辨析到位**：明确区分 robustness（扰动下的成功）与 reliability（跨时间/重复的一致性）、AI agent 与 agentic AI、capability 与 autonomy 等易混概念。
- **公式化与可操作性**：大量指标
