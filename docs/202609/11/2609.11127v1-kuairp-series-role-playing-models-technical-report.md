## 摘要
本文介绍了 KuaiRP 系列角色扮演模型的完整技术方案。我们旨在为专用角色扮演模型实现四个核心目标：简化提示工程、高度稳定的输出质量、内置领域世界知识，以及小参数量下的高效部署。然而，有效注入深度领域知识往往会导致模型通用智能体能力出现严重的灾难性遗忘。为克服这一权衡，我们提出了一种多阶段训练流程。首先，我们设计标准化角色模板，并基于用户行为模拟与反向画像过滤构建 SFT 数据流程。其次，我们在强化学习（RL）阶段利用基于规则的复合奖励函数，以消除长度膨胀和重复生成等常见退化现象。最后，为恢复在 SFT 和 RL 过程中受损的通用能力，我们提出了一种新颖的自蒸馏范式，采用配备累积散度衰减（CDD）的两阶段同策略蒸馏（OPD）。通过将领域适配模型作为教师、原始基础模型作为学生，我们有效平衡了深度领域知识注入与通用智能体能力保持。实验结果表明，KuaiRP 模型不仅在我们目标领域的角色扮演保真度上匹配当前最先进的专有模型，还成功恢复了通用智能体能力，同时保持极低的部署成本。

## Abstract
This paper introduces the complete technical solution for the KuaiRP series of role-playing models. We aim to achieve four core objectives for a dedicated role-playing model: simplified prompt engineering, highly stable output quality, built-in domain world knowledge, and high-efficiency deployment with a small parameter size. However, effectively injecting deep domain knowledge often leads to a severe catastrophic forgetting of the model's general agent capabilities. To overcome this trade-off, we propose a multi-stage training pipeline. First, we design a standardized character template and construct an SFT data pipeline based on user behavior simulation and reverse profile filtering. Next, we utilize a rule-based composite reward function during the Reinforcement Learning (RL) phase to eliminate common degradation phenomena like length expansion and repetitive generation. Finally, to recover the general capabilities compromised during SFT and RL, we propose a novel self-distillation paradigm using Two-stage On-Policy Distillation (OPD) equipped with Cumulative-Divergence Decay (CDD). By using the domain-adapted model as the teacher and the original base model as the student, we effectively balance deep domain knowledge injection with the preservation of general agent capabilities. Experimental results demonstrate that the KuaiRP models not only match the current state-of-the-art proprietary models in role-playing fidelity within our target domains, but also successfully recover general agent capabilities, maintaining extremely low deployment costs.

## 2. 方法论

### 2.1 总体思想
采用 **SFT → RL → 两阶段 OPD（自蒸馏）** 的流水线：先在小规模领域数据上做领域适配，再用"以原始基座为学生、领域模型为教师"的在线策略蒸馏把领域能力"注回"基座，从而在不牺牲通用能力的前提下获得领域角色扮演能力。

### 2.2 角色扮演模板设计
- 设计**固定填空式模板**，统一创作者侧（标准化填写）与模型侧（统一理解）的接口，降低提示工程成本。
- 两个特殊设计点：
  - **玩家画像写入 prompt**：昵称、与角色关系、性别等，使角色能区分社交语境（亲密者用昵称、语气随意；陌生人则正式礼貌），实现个性化对话；
  - **"特定行为模式"（Specific Behavioral Patterns）触发机制**：玩家提及关键词或满足游戏内条件时触发角色特殊反应，贴合游戏玩法。

### 2.3 SFT 数据构建与训练
- **角色库**：从目标领域原著抽取 12 个性格鲜明角色 + 依世界观设计 13 个衍生角色，覆盖性格/性别/年龄/风格；每个角色含男/女用户两版设定，共 **50 条角色 prompt**。
- **用户库**：10 种风格的模拟用户画像，贴合真实网络聊天特征（表情包、碎句、标点错误、网络用语等）。
- **对话生成**：Claude 3.7 Sonnet 扮角色，Qwen2.5-14B 扮用户。三项关键创新：
  1. **指令注入的用户行为模拟**：在用户回合生成前**临时注入 system message**（比改写原 system prompt 更贴近 token 生成），从预定义行为策略库采样——覆盖不配合、突然换话题、错字漏字，以及**追问历史信息、追问角色画像细节、追问世界观知识、工具调用、对抗攻击**等，从而在自然对话中同时蒸馏人设遵循与世界知识（比直接 QA 对训练更高效）。
  2. **反向画像过滤（RPF）**：对每条数据做"画像条目 ↔ 角色回复"的语义相关性检测，删除全程未被任何回复体现的"无效条目"，使"画像 → 回复"映射更纯净，同时因不同对话触发不同条目子集而提升画像组合多样性。
  3. **对话轮数分层采样**：由原"20 段 × 15 轮"改为在总 token 量大致不变下按 **5/10/15/20/25 轮 × 各 4 组**分布，缓解长轮次（>10 轮）性能退化。
- **微调方式选择**：在 Qwen3-8B 上对比 LoRA 与全参数 SFT——LoRA 易学格式（动作标记、性别称呼、画像遵循）且不易过拟合，但对**世界知识注入极不敏感**（低秩瓶颈），加大学习率虽能注入更多知识却明显过拟合。最终选择**全参数 SFT**（LR 1e-5，Batch 64，2 Epoch）。

### 2.4 RL 阶段
- **动机**：SFT 模型存在三类问题——**长度膨胀**（轮次越后越长）、**格式错误**（动作描述标记解析失败）、**重复复读**（照抄历史内容）。其共性是"偶发但可验证"，适合用规则奖励纠正输出分布。
- **复合奖励函数**：取三个二值子奖励的**最小值**，构成硬约束的"无捷径"合取：
  - 格式奖励 r_format ∈ {0,1}：动作标记与冒号使用等全部规则满足才为 1；
  - 长度奖励 r_length：去掉动作标记后的**非动作字符数 ℓ 满足 1 ≤ ℓ ≤ 100** 时为 1，同时惩罚空泛回复与冗长独白；
  - 多样性奖励 r_diversity：按 。！？；!?;\n 切句并过滤 <5 字的短句，计算当前回复与历史回复句子的**字符级 2-gram Jaccard 相似度**取最大 J_max，若 J_max > 0.4 则 0，否则 1；无可比内容直接给满分。
  - 最终 r = min(r_format, r_length, r_diversity)，仍为二值信号，未达标样本进入负样本池参与策略梯度。
- **训练配置**：基于 GRPO，奖励内 KL=True（系数 0.005）、Actor 侧 KL 损失系数 0.005、PPO clip [0.20, 0.28]、LR 3e-6、每 prompt 8 rollouts、训练 Batch 32、PPO Mini-batch 16、总步数 20。

### 2.5 OPD（同策略蒸馏）与 CDD
- **动机**：SFT+RL 后模型通用能力（尤其工具调用）下降，本质是训练分布高度集中于领域世界设定而偏离基座通用知识空间。
- **基本设定**：**教师 = 领域适配模型（SFT+RL），学生 = 原始 Qwen3-8B 基座**；OPD 在学生在线采样轨迹上以教师 token 级分布为偏好信号更新，避免离线蒸馏的分布偏移。
- **两类 OPD 变体**：
  - **OPD-GKD**：最小化前向 KL（实践用 teacher top-k 近似），信号强、覆盖快，但对学生原分布冲击大、易过拟合；
  - **OPD-K1（OPD-PG）**：以 K1 估计量（教师 log-prob 减学生 log-prob，带 stop-gradient）作为逐 token 奖励，是反向 KL 的单样本蒙特卡洛估计；只压制"学生高概率而教师低概率"的 token，干预更温和精确。
- **遇到的问题**：纯 OPD-PG 下，领域世界知识所需 token 几乎不出现在基座采样分布中，教师梯度无法有效传递，知识学不到；切到 GKD 能稳定学到知识，却更易过拟合、损害角色扮演能力。
- **两阶段策略**：
  - **Stage 1（PG + KL）**：在完整 OPD 数据集上训练，温和迁移教师的格式规范与对话风格，对通用能力冲击小；
  - **Stage 2（GKD top-k）**：仅在**世界设定相关子集**上做高强度聚焦蒸馏，高效注入世界知识；因通用数据不参与梯度更新，通用能力得以保留。
- **累积散度衰减（CDD）**：针对 GKD-OPD 的**前缀漂移**问题——学生未学会教师风格时，其采样前缀是教师"不愿生成"的序列，教师在该 OOD 前缀上的 top-k 分布噪声高、且各 token 梯度权重相同会稀释有效样本。CDD 做法：
  - 令 div_t 为当前前向中 top-k 前向 KL 的逐 token 值（取正部、detach）；
  - 定义**严格因果的累积散度** cum_t = Σ_{s<t, s∈valid} div_s；
  - 权重 raw_t = exp(−λ · cum_t)，w_t = max(w_min, raw_t)，并按批次有效 token 均值归一化 w̃_t = w_t / w̄；
  - 最终损失为加权 GKD 损失 L_CDD-GKD = (1/Σw̃) Σ w̃_t · L_GKD(s_t)。
  - λ 控制衰减陡峭度（取 0.1），w_min 防止长文本尾部权重塌缩为 0（取 0.05）。其设计优势被表述为：基于**局部全分布散度**评估真实差异，且**全局绝对指数衰减**——未漂移则全程权重近 1，一旦致命漂移则瞬时指数下降；相比 FiRe-OPD（轨迹级硬过滤、熵加权混淆多模态与无知）、TOPD（用最优传输对齐未来窗口，破坏自回归因果、开销大）、IW-OPD（逐点评估不准、句内线性归一化导致健康轨迹尾部也被降权、缺乏硬截断）。
- **OPD 配置**：两阶段 LR 均为 1e-6，Batch 64，PPO Mini-batch 16，Stage 1 为 PG(K1)/GRPO、不含 KL、1 Epoch；Stage 2 为 GKD、TopK=64、2 Epoch。
