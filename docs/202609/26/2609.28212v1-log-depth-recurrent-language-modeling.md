## 摘要
使用 Transformer 的语言建模已变得司空见惯，尽管其计算深度固定，且运行时间相对于输入 token 呈二次方增长。另一方面，循环模型提供线性深度，但无法并行执行。在这项工作中，我们将平衡树递归算子从序列编码扩展到自回归预测，使得所有前缀表示都能以对数深度和线性运行时间计算。我们的实验对该模型类别进行了初步刻画，展示了稳健的长度外推能力，以及接近基于 ALiBi 的 Transformer 的性能，突显了其作为语言建模替代架构的潜力。

## Abstract
Language modeling using Transformers has become commonplace despite their fixed computational depth and quadratic runtime with respect to input tokens. Recurrent models on the other hand offer linear depth but no parallel execution. In this work, we extend balanced-tree recursive operators from sequence encoding to autoregressive prediction, enabling all prefix representations to be computed with logarithmic depth and linear runtime. Our experiments provide an initial characterization of this model class, demonstrating robust length extrapolation and performance approaching that of ALiBi-based Transformers, highlighting its potential as an alternative architecture for language modeling.

## 1. 核心问题与整体含义

- **研究背景**：Transformer 已成为大语言模型的主流架构，训练时可并行计算所有位置的条件概率，但其计算深度固定，且注意力机制相对于输入 token 数具有二次运行时复杂度。循环模型则相反，深度随序列长度线性增长，但传统循环存在顺序执行瓶颈，无法并行。
- **核心矛盾**：如何在保留并行训练能力的同时，让计算量或深度更好地随序列长度伸缩：既避免 Transformer 的二次复杂度，又避免 RNN 的线性顺序深度。
- **已有工作局限**：树结构递归神经网络多用于编码任务，如情感分析；若直接用于自回归预测，需要为每个前缀重复计算，效率低下。Log-Depth Recurrent Units 使用平衡树上的 up-sweep，但只产生单一序列表示，无法高效得到每个前缀表示。
- **本文整体含义**：作者将平衡树递归算子从序列编码扩展到自回归语言建模，通过补全 Blelloch 并行扫描的 down-sweep，使所有前缀表示可以并行计算，并保持对数深度与线性总工作量。论文将结果定位为对该模型类的初步实证刻画，而非已优化的 Transformer 替代品。

## 2. 方法论

- **核心思想**：使用并行扫描算法中的 up-sweep 与 down-sweep，在平衡二叉树上学习二元组合算子，从而高效计算每个位置的自回归前缀表示。
- **整体流程**：
  - 输入 token embedding $x \in \mathbb{R}^{N \times E}$。
  - 经过层归一化、线性投影和位置式残差 MLP，得到隐藏表示 $h \in \mathbb{R}^{N \times D}$。
  - 使用可学习二元算子 $\odot_\theta: \mathbb{R}^D \times \mathbb{R}^D \to \mathbb{R}^D$ 沿平衡树组合表示。
  - **Up-sweep**：递归合并相邻表示，并存储中间结果，形成层级表示。
  - **Down-sweep**：复用 up-sweep 的中间结果，为每个位置 $i$ 产生 exclusive prefix 表示 $h_i$，即用于预测下一个 token 的前缀表示。
  - 每个组合操作后应用层归一化和残差 post-merge 网络。
  - 扫描输出投影回 embedding 维度，并通过 tied token embedding 矩阵解码。
  - 使用标准 shifted next-token cross-entropy 损失训练。
- **复杂度**：该过程具有 $O(\log N)$ 深度和 $O(N)$ 次算子应用，避免了传统循环的线性顺序深度和 Transformer 的二次运行时。
- **算子参数化：Gated Recursive Cell, GRC**：
  - 给定两个状态 $a,b \in \mathbb{R}^D$，先拼接为 $[a;b]$。
  - 通过两层 MLP，隐藏宽度为 $4D$，输出 $[g_a;g_b;g_c;c] \in \mathbb{R}^{4D}$。
  - 三个门向量 $g_a,g_b,g_c$ 经 sigmoid 激活，$c$ 为候选向量。
  - 最终输出为：
    \[
    \odot_\theta(a,b)=\mathrm{LN}(\sigma(g_a)\circ a+\sigma(g_b)\circ b+\sigma(g_c)\circ c)
    \]
  - 该算子不强制结合性，因此前缀表示依赖平衡树结构；非结合的 $\sigma(g_c)\circ c$ 项被证明有助于提升表达力。
  - 使用 GRC 自回归训练的模型称为 **AR-GRC**。
- **消融对比**：作者还与 Pert 等人提出的 MLP-LDRU 结合性偏置算子对比，发现 AR-GRC 在 WikiText-2 和 PTB 上更优。
