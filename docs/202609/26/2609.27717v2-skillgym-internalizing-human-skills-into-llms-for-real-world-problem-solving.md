## 摘要
人类编写的智能体技能编码了用于真实世界问题求解的丰富工作流，但通常被用作推理时的外部指令，而非内化为可复用的模型能力。我们提出 SkillGym，一个将这些技能转化为可执行、可验证的训练环境以用于大语言模型智能体的框架。其技能到任务流水线实例化具体任务，用基于代码的检查器验证结果，并通过对比执行评估实证技能依赖。我们构建并发布涵盖 12 个类别的 2,756 个环境，并从多个模型和运行框架收集了 8,364 条成功轨迹，平均有 49 次工具调用和超过 6 万个记录的文本 token。这些资源支持在已验证工作流上进行监督微调，以及基于结果奖励的强化学习。在 Claude Code 下，监督微调使 Qwen3.5-35B-A3B 在 GDPval-AA v2 上提升 199 Elo，在 Terminal-Bench 2.1 上提升 19.10 个百分点，并在带技能和不带技能的 SkillsBench v1.1 上分别提升 28.13 和 12.38 分。我们的 35B SkillGym-Agent 在技能辅助的 SkillsBench 上达到 51.47%，超过 Claude Sonnet 4.6、GPT-5.4 Mini 和 DeepSeek V4 Pro 的报告分数。在不使用技能时，它也在 Codex 和 Claude Code 下超过技能辅助的基线，表明其具备可复用的程序性能力。

## Abstract
Human-written agent skills encode rich workflows for real-world problem solving, but are typically used as external inference-time instructions rather than internalized as reusable model capabilities. We introduce \texttt{SkillGym}, a framework that transforms these skills into executable, verifiable training environments for large language model agents. Its skill-to-task pipeline instantiates concrete tasks, verifies outcomes with code-based checkers, and assesses empirical skill dependence through contrastive executions. We construct and release 2,756 environments across 12 categories and collect 8,364 successful trajectories from multiple models and harnesses, averaging 49 tool calls and over 60k logged text tokens. These resources support supervised fine-tuning on verified workflows and reinforcement learning with outcome-based rewards. Under Claude Code, supervised fine-tuning improves Qwen3.5-35B-A3B by 199 Elo on GDPval-AA v2, 19.10 percentage points on Terminal-Bench 2.1, and 28.13 and 12.38 points on SkillsBench v1.1 with and without skills, respectively. Our 35B \texttt{SkillGym-Agent} reaches 51.47\% on skill-assisted SkillsBench, exceeding reported scores for Claude Sonnet 4.6, GPT-5.4 Mini, and DeepSeek V4 Pro. Without skills, it also surpasses skill-assisted bases under Codex and Claude Code, suggesting reusable procedural competence.

# SkillGym 论文总结

## 1. 核心问题与整体含义

- **研究动机**：人类编写的智能体技能（agent skills）封装了真实世界工作流，包括指令、脚本、示例与执行约束，但通常只在推理时作为**外部指令**被检索和调用，而非内化为模型自身能力。
- **核心问题**：能否将人类编写的智能体技能转化为**可执行、可验证的训练环境**，让 LLM 通过实践与反馈获得程序性能力（procedural competence）？
- **关键难点**：
  - 技能文档描述的是可复用流程，而非具体问题，需要落地为带输入、目标与交互协议的任务实例；
  - 程序性成功依赖任务特定要求，不能仅靠与技能描述的相似度判断，需要**可执行任务构建 + 结果验证**。
- **整体含义**：SkillGym 不是再建一个技能库，而是把技能文档转化为交互式学习问题，使模型通过训练获得可复用的工作流执行能力，并探索“外部技能指导”与“内化能力”的互补关系。

## 2. 方法论

### 2.1 核心思想

- 将人类技能转化为**可执行环境**，用代码检查器验证结果，并通过**对比执行**评估技能依赖。
- 训练信号来自“执行底层工作流”的过程，而非复述技能描述。

### 2.2 三阶段流程

- **A. 技能感知模板构建**
  - 从在线技能注册表出发，组织为 **12 大类、63 子类**。
  - 每个子类选取高星技能，整理为结构化**技能卡**：描述、使用示例、伪代码/脚本、执行约束。
  - 为每个子类人工构建**可复用任务模板** \(T_c\)：任务蓝图、输入资产、文件结构、运行时要求、检查器规范、执行约束。
  - 技能卡提供“目标程序”，模板提供“可执行任务结构”，二者互补。

- **B. 环境构建与验证**
  - 实例化任务环境：\(E_i = \text{Instantiate}(K_i, T_{c(i)}) = (x_i, A_i, \rho_i, V_i)\)
    - \(x_i\)：任务指令；\(A_i\)：输入资产；\(\rho_i\)：文件结构、运行时、依赖、访问接口、执行约束；\(V_i\)：基于代码的结果验证器。
  - 任务打包为 **Docker**，验证器包含反捷径检查（防篡改输入、复制答案、绕过要求、伪造输出）。
  - **两级验收**：
    - 可行性 \(F_i=1\)：通过设计、结构、端到端执行检查，验证器可用且存在通过解。
    - 对比执行：参考智能体在“有技能”和“无技能”下分别得到 \(r_i^+, r_i^- \in \{0,1\}\)。
    - 标签规则：
      - **Skill-Dep.**：\(F_i=1\) 且 \((r_i^+, r_i^-)=(1,0)\)，即参考配置下“有技能成功、无技能失败”；
      - **Verifier-Passed**：\(F_i=1\) 但未满足对比条件，保留为回退环境；
      - **Discarded**：\(F_i=0\)。
  - **失败驱动精炼**：将失败归为环境错误、检查器错误、难度不匹配、弱技能依赖，并据此修改运行时、任务要求与验证器逻辑。

- **C. 多框架轨迹采样**
  - 使用多种 **harness–model 组合**（如 Codex、Claude Code 搭配不同模型）与环境交互。
  - 轨迹采样：\(\tau_i^{h,m} \sim \text{Rollout}(E_i, \pi^{h,m})\)，奖励 \(r_i^{h,m} = V_i(z(\tau_i^{h,m})) \in \{0,1\}\)。
  - 成功轨迹用于 **监督微调（SFT）**，失败轨迹用于失败模式分析，环境与验证器支持**基于结果奖励的强化学习（RL）**。
