## 摘要
多示例上下文学习（ICL）使大语言模型（LLM）能够以数千个演示示例为条件来适应复杂任务，但这一范式将推理效率瓶颈转移到了键值（KV）缓存内存上。由于 KV 缓存呈线性扩展行为，存储这些中间张量已成为在线服务和端侧部署的首要挑战。为解决该问题，我们提出了一种新颖的压缩框架，称为 MILO，其利用多示例上下文中固有的低秩冗余。具体而言，MILO 采用分块低秩压缩策略，以块为粒度压缩 KV 缓存，其中每个块包含多个 many-shot 示例。此外，为处理不同块之间异构的上下文密度，MILO 基于信息熵动态分配秩预算，在保留关键块保真度的同时，对冗余块进行激进压缩。在 Qwen2.5 模型上的实验结果表明，我们的方法实现了高达 50% 的 KV 缓存内存减少和 1.8 倍的吞吐量提升，同时在分类和推理基准上性能下降可忽略不计，显著优于先前基线。

## Abstract
Many-shot in-context learning (ICL) enables large language models (LLMs) to adapt to complex tasks by conditioning on thousands of demonstration examples, but this paradigm shifts the inference efficiency bottleneck to the key-value (KV) cache memory. Due to the linear scaling behavior of the KV cache, storing these intermediate tensors has become a paramount challenge for both online serving and on-device deployment. To address this issue, we propose a novel compression framework, termed MILO, that exploits the low-rank redundancy inherent in many-shot contexts. Specifically, MILO features a block-wise low-rank compression strategy that compresses the KV cache at the block granularity, where each block contains multiple many-shot examples. Furthermore, to handle the heterogeneous context density across different blocks, MILO dynamically allocates rank budgets based on the information entropy, preserving the fidelity of critical blocks while aggressively compressing redundant ones. Experimental results on Qwen2.5 models demonstrate that our method achieves up to 50% reduction in KV cache memory and 1.8x throughput improvement, with negligible performance degradation on classification and reasoning benchmarks, significantly outperforming prior baselines.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：随着大模型上下文窗口扩展到百万甚至千万 token 级别（如 Gemini 支持 10M token），"多示例上下文学习"（Many-shot ICL）成为可能——通过在提示中放入数百至数千个演示示例，模型无需参数更新即可适配复杂任务，性能可逼近全量微调模型。
- **核心问题**：多示例 ICL 将推理效率瓶颈从离线训练转移到在线推理。由于自注意力复杂度随序列长度二次增长，且 KV 缓存随序列长度线性增长，存储这些中间张量成为在线服务与端侧部署的首要挑战。
- **具体量化**：为 8B 稠密模型存储 90k 示例的 KV 缓存需额外约 11.1 GB 内存；随着上下文继续扩展，KV 缓存的内存占用使多示例 ICL 越来越受内存约束，难以满足严格的服务等级目标（SLO）。
- **研究空白**：已有工作（如 DBSA 的动态稀疏注意力、Adapshot 的语义感知 KV 缓存复用）主要解决计算延迟与 KV 复用问题，**均未讨论 KV 缓存的存储与内存效率**。本文填补这一空白。

## 2. 方法论

### 2.1 核心思想
利用多示例上下文中 KV 缓存固有的**低秩冗余**（多个示例共享相似语义特征，导致潜空间中表示高度相关），将 KV 缓存存入低维空间，实现最高 50% 存储压缩和 1.8× 加速。

### 2.2 关键观察（Section 3）
- **K 缓存比 V 缓存具有更强的低秩性**，这与先前发现一致（pre-RoPE key 更适合低秩压缩）。
- **反直觉现象**：示例数越多，KV 存储越大，但低秩空间中的冗余也越多。
- **异构性**：不同块、不同层的低秩行为差异显著，为动态秩分配提供依据。

### 2.3 分块低秩压缩（BLC）
- 将 KV 缓存划分为 N 个块，每块包含多个示例（块大小 B 为块内总 token 数）。
- 对每个块的 K 和 V **分别**做低秩近似：K_i ≈ A_i^k Σ_i^k (B_i^k)^T，V_i ≈ A_i^v Σ_i^v (B_i^v)^T。
- 存储成本从每块 2Bd 个参数降为 (r_i^k + r_i^v)(B + d)，压缩比 ρ 由所有块的秩之和与原始规模之比给出。
- **设计权衡**：全局压缩会丢失跨示例细粒度信息并引入冗余解压计算；逐示例压缩则累积信息损失导致性能显著下降；块级粒度取得最佳平衡。

### 2.4 动态秩分配（熵驱动）
- 将秩选择形式化为**固定总秩预算下的全局资源分配问题**。
- 对每个块做 SVD 得到奇异值，定义保留的谱信息：H_i(d) = Σ_{j=1}^{d} log(1 + σ_j²/ε²)。
- 优化目标：max Σ H_i(r_i)，约束 Σ r_i ≤ R_tot 且 r_min ≤ r_i ≤ r_max。
- 由于 H_i(r) 对奇异分量可加，采用**贪心算法**：从 r_i = r_min 开始，每次将单位秩分配给边际增益 ΔH_{i,r} = log(1 + σ_{i,r+1}²/ε²) 最大的块，直至耗尽总预算。
- 效果：谱衰减慢（信息密集）的块获得更多秩，冗余块被激进压缩。

### 2.5 工作流程（Algorithm 1）
- **编码阶段**：多示例上下文分块 → SVD 求最优秩 → 按秩预算低秩压缩 → 存入低秩 KV 缓存。
- **推理阶段**：查询经 BM25 检索器进行 KV 选择 → 选中的低秩缓存段**并行全秩重建** → 重建 KV 与原查询一起送入稀疏注意力完成生成。

### 2.6 系统优化
- **融合 Triton 核**：将缓存检索、奇异值缩放、重建合并为单次 pass，减少 HBM 中间流量与核启动开销。
- **CUDA Streams 并行重建**：独立块分发到多流实现块级并行，仅在稀疏注意力前同步。
- **CUDA Graphs**：捕获并重放重复的推理路径，降低 CPU 启动开销。

## 6. 主要结论与发现

- **精度**：在相同秩预算下，MILO 优于 SOTA 低秩方法，最高提升 **4.5%** 准确率。Qwen2.5-7B 上 MILO 平均 0.725，显著高于 ASVD（0.680）和 Palu（0.700），逼近 Full Cache（0.753）。
- **内存与吞吐**：KV 缓存内存减少高达 **50%**；相比全量 KV offloading 平均加速 **1.6×**，7B 模型 512-shot 场景下吞吐最高提升 **3.2×**；相比 Palu 和 ASVD 分别提升最高 **37%** 和 **60%**。模型越大，收益越明显（因 KV 传输量更大，推理更受内存约束）。
- **块大小**：块大小增至 32 时精度与效率同时提升（暴露更多跨示例冗余），但超过后精度与加速均下降（压缩/检索粒度变粗、重建开销增大）。
- **核优化**：融合 Triton 核降低延迟约 2.5×，加 CUDA Streams 达 3.3×，再加 CUDA Graphs 达 3.7×。
- **秩分配**：熵驱动分配在所有设置下精度最高，示例数增加时与基线差距缩小但仍保持领先。
- **量化兼容**：MILO + INT8 实现 4× 内存压缩（3B 精度 0.621），MILO + KIVI 实现 4.7×–5.3× 压缩，验证了方法可与量化正交叠加。
