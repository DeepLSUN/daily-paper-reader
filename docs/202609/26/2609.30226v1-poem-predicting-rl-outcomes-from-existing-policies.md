## 摘要
基础模型通过强化学习（RL）进行后训练，以最大化特定奖励，例如人类对齐、正确性或指令遵循。这一后训练过程计算密集，有时不稳定，并且每当奖励模型发生变化，或我们希望组合多个奖励时，都必须从头开始运行。因此我们提出：给定一个新的奖励函数，是否有可能在不实际对其运行 RL 的情况下预测 RL 结果？我们给出了肯定回答，并提出 PoEM，一个利用已基于其他奖励后训练好的一组模型，来预测在新奖励函数上进行 RL 的输出结果的框架。首先，我们表明，如果新的奖励函数可以写成现有奖励函数的线性组合，那么新的策略在对数空间中也可以写成现有对数策略的线性组合。令人惊讶的是，即使奖励之间不具有线性关联，我们观察到来自 RL 训练的对数策略在不同奖励之间往往张成一个近似低秩的子空间。对我们有利的是，这种组合的权重系数可以仅利用样本上的奖励或基策略输出进行估计。我们将这些观察转化为一种算法，该算法接收后训练模型和一个新的奖励函数，并在无需实际运行任何额外 RL 训练的情况下逼近目标 RL 策略。我们在合成奖励和真实奖励上通过实验验证了我们的方法，涵盖文本和图像两种模态。

## Abstract
Foundation models are post-trained with reinforcement learning (RL) to maximize specific rewards, such as human alignment, correctness, or instruction following. This post-training process is computationally intensive, sometimes unstable, and has to be run from scratch every time the reward model changes or when we want to combine multiple rewards. We hence ask: given a new reward function, is it possible to predict the RL outcomes without actually running RL on it? We answer this in the affirmative by introducing PoEM, a framework to predict the outputs of RL on a new reward function using a set of models already post-trained on other rewards. First, we show that if the new reward function can be written as a linear combination of existing ones, then the new policy in log-space can be written as a linear combination of the existing log-policies. Surprisingly, even in cases where the rewards are not linearly connected, we observe that often log-policies from RL training span an approximately low-rank subspace across rewards. To our benefit, the weighting coefficients for this combination can be estimated using only the reward or basis policy outputs on the samples. We turn these observations into an algorithm that takes post-trained models and a new reward function, and approximates the target RL policy without actually running any additional RL training. We experimentally validate our approach across synthetic and real rewards, spanning both text and image modalities.

# PoEM: Predicting RL Outcomes from Existing Policies 论文总结

## 1. 核心问题与研究动机

- **背景**：基础模型通常通过强化学习（RL）进行后训练，以最大化人类对齐、正确性、指令遵循等特定奖励。但 RL 后训练**计算密集、有时不稳定**，且每当奖励模型变化或需要组合多个奖励时，都必须**从头重新训练**。
- **现有方法的局限**：
  - 参数空间平均（如 averaging adapter weights）在模型数量增加时会退化；
  - Best-of-N 采样仅在狭窄场景下有效；
  - 多目标对齐方法需在训练前固定奖励权重。
- **核心问题**：给定一个新的奖励函数，能否**不实际运行 RL** 就预测其 RL 结果（即目标策略）？
- **整体含义**：作者提出 PoEM（Product of Experts Mixing），利用已基于其他奖励后训练好的模型集合，通过推断时的策略组合来近似新奖励下的 RL 最优策略，从而为奖励模型迭代、多奖励融合和昂贵奖励评估提供低成本替代方案。

## 2. 方法论

### 2.1 核心思想
- **理论观察**：若新奖励是已有奖励的线性组合 $r_{\text{tar}} = \sum_k \alpha_k r_k$，则在 KL 正则化 RL 目标下，目标策略可写为**指数倾斜参考策略**，即基策略与参考模型的**对数空间线性组合**（专家乘积）：
  $$\pi^*_{\text{tar}} \propto \pi_{\text{ref}} \prod_{k} \left(\frac{\pi_k}{\pi_{\text{ref}}}\right)^{\alpha_k}$$
- **关键定义**：策略对数比率 $\phi_k(x,y)=\log\pi_k(y|x)-\log\pi_{\text{ref}}(y|x)$，目标策略即 $\pi^*_{\text{tar}}\propto \pi_{\text{ref}}\exp(\sum_k \alpha_k \phi_k)$。

### 2.2 关键技术细节
- **自回归语言模型**：将序列级组合分解到 token 级前缀，逐 token 组合 logits：
  $$\log \pi_{\text{PoEM}}(y_t|h_t) = \log\pi_{\text{ref}}(y_t|h_t) + \sum_k \alpha_k \phi_k(h_t,y_t)$$
  无需参数更新，仅需参考模型与基策略的下一 token logits。
- **扩散模型**：利用 Tweedie 公式证明，新奖励下的去噪器是已有去噪器的线性组合加上修正项 $\sigma^2(t)\nabla\log Z(x_t)$，修正项在 $\sigma(t)\to 0$ 或基策略为共享协方差高斯时为零。
- **权重恢复**：
  - **奖励空间回归**：用岭回归将中心化的目标奖励拟合到基奖励矩阵（式 9）；
  - **策略空间回归**：若无法访问基奖励，用基策略的对数比率作为特征拟合（式 11），利用 DPO 隐式奖励恒等式。
  - 中心化操作去除仅依赖 prompt 的项。
- **覆盖度评分**：用留出集上目标奖励对基策略对数比率的 $R^2$ 衡量基策略张成空间是否覆盖目标方向（式 12），可提前判断 PoEM 是否适用。
- **组合强度 $\gamma$**：由于 GRPO/DPO 会丢弃奖励尺度，引入 $\gamma_{\text{geom}}$（基于 Gram 矩阵）补偿平均导致的收缩，等效于测试时调整 KL 强度。

### 2.3 算法流程
1. 在小规模校准集上评分；
2. 通过奖励空间或策略空间回归得到系数 $\hat\alpha$；
3. 计算留出覆盖度；
4. 在推断时按式（6）或式（8）组合基策略，**不更新任何参数、不运行额外 RL**。

## 3. 实验设计

- **基策略训练**：
  - **语言程序化奖励**：P-GRPO 与 P-DPO 共享 20 个程序化奖励（词汇多样性、形式性、可读性等），每个专家为 Qwen3-0.6B 上的 rank-64 LoRA，分别用 GRPO（在线）和 DPO（离线）训练。
  - **语言奖励模型**：RM-RB（4 个 RewardBench 高分 RM，PPO 训练）、RM-HH（ArmoRM 的有用性与无害性头）、RM-Div（10 个多样公开 RM，经奖励黑客检查）。
  - **图像奖励**：SD-DDPO，在 Stable Diffusion v1.4 上训练 13 个 LoRA 专家（10 个图像统计奖励 + 3 个图像 RM：美学、PickScore、CLIP）。
- **数据集**：UltraChat prompts、PKU-SafeRLHF 有害请求、ImageNet 类别名；评估 prompt 均从训练集中留出。
- **Benchmark 与对比方法**：
  - **目标策略**：每个目标奖励单独训练一个 RL 策略 $\pi_{\text{tar}}$ 作为 oracle；
  - **对比基线**：Best-of-N（16/64）、top expert、均匀权重、DeRa、MOD、第二次 RL 运行（不同 seed）、GDPO（多奖励 RL）。
- **评估指标**：奖励恢复率 $\text{rec}(\pi)$、与 $\pi_{\text{tar}}$ 的相对 KL、覆盖度与奖励误差的秩相关 $\rho$。
- **实验类型**：① 精确线性组合奖励；② 策略空间几何（有效秩）；③ 留出奖励（非线性组合）。

## 6. 主要结论与发现

- **线性组合奖励**：PoEM 恢复 RL 奖励增益的 0.78–1.08（RM 基）和 0.83–1.00（程序化基，$\gamma_{\text{geom}}$ 后），与第二次 RL 运行的误差（0.12–0.17）相当；在 P-GRPO 和 RM 基上分布上更接近 $\pi_{\text{tar}}$。
- **策略空间低秩结构**：20 个近正交适配器（权重更新有效秩 19.43）的对数比率矩阵有效秩仅 6.25，即策略空间比参数空间和奖励空间**显著低秩**。
- **超越线性组合**：即使奖励非线性相关，只要目标策略的对数比率落在基策略张成空间内，PoEM 仍可近似；覆盖度评分能提前排序哪些留出奖励可被预测（$\rho=-0.71$ 至 $-0.81$）。
- **扩散模型**：组合其他 12 个专家可恢复留出专家 0.67 的奖励增益（9/13 超过一半）。
- **核心洞见**：RL 后训练主要是在**重加权参考模型已有行为**，而非创造全新方向；因此已训练策略集合携带足够结构来在推断时组合出新奖励对齐行为。

## 7. 优点

- **理论优雅**：从 KL 正则化 RL 闭式解出发，给出线性奖励下精确组合的严格推导，并扩展到扩散模型（Tweedie 公式）。
- **无需训练**：推断时组合，零参数更新、零额外 RL 运行，显著降低新奖励评估成本。
- **实用性设计**：
  - 两种权重恢复路径（奖励可用 / 仅策略可用），适应不同访问权限；
  - 覆盖度评分可提前预警不可达奖励，支持"预览奖励再训练"；
  - $\gamma_{\text{geom}}$ 解决 GRPO/DPO 丢弃奖励尺度的实际问题。
- **跨模态验证**：语言与图像、在线与离线 RL、程序化与神经奖励模型均有效。
- **诚实报告**：如实指出 P-DPO 距离指标噪声、覆盖度跨基不通用、图像权重拟合使用了留出专家等限制。

## 8. 不足与局限

- **覆盖度受限**：方法上限由所选基策略的策略空间张成决定；目标方向若在张成之外，无论校准集大小或回归强度都无法恢复。
- **理想化假设**：精确组合假设每个专家是共享参考模型和 $\beta$ 的 KL 正则化最优；实际中大量后训练不包含 KL 项。
- **算力与规模**：仅在 Qwen3-0.6B 和 Stable Diffusion v1.4 等小模型上验证，**未测试长上下文生成**，也未验证权重能否跨参考模型迁移。
- **推断成本**：需同时加载 $k$ 个专家，运行成本随基规模增长；作者建议蒸馏或以此为 RL 起点，但未实验。
- **实验偏差风险**：
  - 图像扩散实验的权重是在每个去噪步用留出专家的噪声预测拟合的，**并非完全无专家的预测**，与语言实验设置不同；
  - RM-RB 覆盖度近零但恢复率不低，说明覆盖度阈值不具跨基通用性；
  - 当奖励评估成本较低时，Best-of-N 可能更有竞争力。
- **未明确报告**：GPU 型号、数量、总训练时长等算力信息缺失，影响可复现性与成本评估。
