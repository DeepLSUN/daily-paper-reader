## 摘要
随着智能体系统演变为复杂的多智能体编排工作流，对于能够衡量智能体行为一致性和确定性的系统性框架的需求日益增长且至关重要。在本文中，我们介绍了一种正式的评估方法，该方法基于AgentGraph——一个由领域特定语言驱动的规划器，通过动态可调的有向图来表示智能体的推理过程。我们利用这种结构化形式，并采用图遍历算法来穷举枚举对话路径，形成覆盖智能体完整行为空间的综合评估集。然后，我们系统地重放这些可复现的轨迹，将观察到的输出和状态转换与预期的DSL规范进行比较。为了量化可靠性，我们定义了新的指标，用于衡量响应和轨迹的确定性、结构遵循度以及语义一致性，这些指标涵盖精确重放及其语言变体。我们系统的结果表明，使用AgentGraph和LangGraph等框架配置的智能体，在具有明确结构化节点转换的情况下，其确定性优于未配置受控转换的智能体。

## Abstract
As agentic systems evolve into complex multi agent orchestration workflows, there is a growing and critical need for systematic frameworks that measures an agent's behavioral consistency and determinism. In this paper, we introduce a formal evaluation methodology that is grounded in AgentGraph, a planner powered by a domain specific language that represents agent reasoning through a dynamically adjustable directed graph. We leverage this structural formalism and utilize graph traversal algorithms that exhaustively enumerate conversational paths, forming a comprehensive evaluation set that captures the agent's complete behavioral space. We then systematically replay these reproducible trajectories to compare observed outputs and state transitions against the intended DSL specification. To quantify reliability, we define novel metrics that measure response and trajectory determinism, structural adherence and semantic consistency across both exact replays and their linguistic variants. Our system's results demonstrate that agents configured using frameworks like AgentGraph and LangGraph with explicitly structured node transitions show superior determinism over agents that are not configured with controlled transitions.

### 2. 方法论：EDGE 框架

- **核心思想**：智能体行为由 DSL（JSON 格式的领域特定语言）定义；该 DSL 本质是一个有向无环图（DAG），图中每个节点是一个具有独立记忆、工具与状态转移能力的子智能体（sub-agent）。EDGE 将"对话路径是否与设计图一致"作为确定性观察量，系统性地对这些路径进行模拟、捕获与度量。
- **3 个高层步骤**：
  - **对话模拟（Conversation Simulation）**：设计者依据 DSL 指定 N 条路径（DFS 穷举生成），每条路径对应 M 个多轮对话；由 LLM 扮演"用户"（可变化 persona、temperature、意图表述措辞），驱动被测智能体沿不同节点流转。
  - **捕获行为（Capture Simulation Details）**：记录每轮用户输入、智能体应答、内部遍历状态、调用的动作及参数。
  - **计算确定性度量（Compute Determinism Metrics）**：在精确重放与语义变体两种模式下计算多组指标。
- **确定性度量体系**（表 1、表 2 所定义）：
  - **Response Consistency**（1–4 分制）：用 LLM-as-a-Judge 判断重放轮次中语义响应的相似性。
  - **Node Trajectory Consistency**：多次运行中按顺序排列的节点路径完全一致的占比。
  - **Node Trajectory Coverage**：节点集合（忽略顺序）的重叠比例。
  - **Action Trajectory Consistency**：动作名称序列（有序）的一致占比。
  - **Action Trajectory Coverage**：动作集合（忽略顺序）的重叠比例。
  - **Action+Input Trajectory Consistency / Coverage**：动作连同输入参数一并比较的有序一致率与覆盖重叠率。
- **在线稳定性指标**：
  - **Conversation Convergence Rate（CCR）**：无需回溯即可沿期望节点顺序完成模拟的路径百分比。
  - **Path Completion Rate（PCR）**：经历（可能含）回溯后成功走完整条状态转换的路径百分比。
- **图遍历统计指标**：节点利用率（Node Utility）、边利用率（Edge Utility）、平均节点跳数、节点/边失败计数。这些统计可用于可视化"真实流转热度图"（图 3），定位未覆盖或过覆盖的子图。
- 该方法不依赖特定写作框架，LangGraph 与 AgentGraph 均可适用。

### 3. 实验设计与 Benchmark

- **被测对象（三类智能体）**：
  1. **Honda Dealer Agent**（LangGraph 实现，4 节点）：处理预约试驾、保修查询、汽车手册问答三类意图。
  2. **Complex Recruitment Agent**（AgentGraph 实现，6 节点）：包含 Topic Selector（专用路由节点）与有条件边——筛选题未通过不进入 Killer Questions。
  3. **Baseline Recruitment Agent**（AgentGraph 实现，6 节点）：与复杂版节点相同，但所有节点之间互连，启用全部可能转换（密集图），即"无受控转换"的对照。
- **对话数据生成方式**：
  - Honda：从图路径采样出 30 个对话场景序列，含对抗性场景（用户表述缺失必要条件）；每个场景重放 4 次。
  - 招聘智能体（复杂版与基线版）：所有 DFS 可达路径共生成 136 个对话场景；每个场景重放 3 次。
- **对比逻辑**：以递归招聘智能体两类变体（有向稀疏图 vs 全连接密集图）做对比；以 Honda Agent 作跨框架通用性示例；并未与其他外部确定性评测框架（如 AgentEvals、AGORA 等）进行同条件数值对比。
- **主要观察结果（表 3）**：
  - **Node Trajectory Consistency**：Complex Recruitment 98.89% > Baseline Recruitment 90.19% > Honda 78.89%。
  - **Action Trajectory Consistency**：Complex Recruitment 91.30%，Baseline 79.81%，Honda 78.89%。
  - **Response Consistency（满分 4）**：Honda 3.13 > Complex 2.92 > Baseline 2.25。

### 6. 主要结论与发现

- 图结构越是有向、稀疏、受约束，确定性越高：Complex Recruitment（有筛选条件与专用 topic selector）在节点轨迹确定性（98.89%）与动作轨迹一致性（91.30%）上全面胜过全连接 Baseline（90.19% / 79.81%）以及 LangGraph Honda（78.89% / 78.89%）。
- **路径一致 ≠ 响应一致**：两个招聘 Agent 轨迹一致性很高，但 Response Consistency 反而比 Honda 更低（2.92 和 2.25），说明"走对路、选对动作"不一定带来语义输出稳定——诊断确定性必须将结构指标与语义指标分开报告。
- 专用 Router 节点（Topic Selector）和受约束的状态转移有助于抑制发散行为，平衡反应性与主动性，是"可引导确定性（guided determinism）"的关键工程杠杆。
- EDGE 可适配 LangGraph 与 AgentGraph 两种 authoring 框架，具备工具级通用性。

### 7. 方法上的优点与亮点

- **拓扑穷举式覆盖**：以 DFS 遍历设计图获得全路径评估集，弥补了真实流量后验评估的"冷启动路径缺失"缺陷，逻辑覆盖有形式化保证。
- **以 DSL 图为真值**：将评估从"语义相似性比较"上升到"行为轨迹与设计规范的对齐验证"，结构遵循度指标可解释、可回溯。
- **层次化指标设计**：区分 node 轨迹与 action 轨迹、区分 ordered consistency 与 order-free coverage、区分精确重放与语言变体，能够多维定位不确定性来源；加入 Action+Input 粒度的对比，使指标可用于检查工具调用参数漂移。
- **双通道模拟**：既考虑同一表述的多次精确重放，也生成 person/温度/措辞各异的语义变体，考察输入变化下的稳定性，能较好反映真实使用分布。
- **附带实用性工具**：CCR/PCR 与节点/边利用率可视化能为设计者指出未覆盖或过度集中的子图；提出可泛化使用到生产对话重放的扩展场景。
