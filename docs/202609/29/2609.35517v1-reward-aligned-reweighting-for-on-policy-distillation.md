## 摘要
同策略蒸馏（OPD）利用来自更强教师的稠密反馈，在学生生成的轨迹上训练学生语言模型。然而，标准 OPD 对 token 级蒸馏项进行均匀加权，隐含地将局部教师偏好视为纠正效用的代理。然而，一个决策的任务价值取决于学生如何完成后续推理。这种不匹配可能导致模仿压制可行的学生策略，或强化学生无法可靠执行的路径。已验证的轨迹结果为续写质量提供了补充证据，但并不能直接识别单个决策的效用。我们提出面向同策略蒸馏的奖励对齐重加权（R$^{2}$-OPD），它利用结果一致性以及教师—学生分歧的幅度，持续重新分配教师监督。它在保留稠密反馈的同时，赋予奖励对齐的纠正更大的相对影响力，从而超越均匀模仿和硬过滤。我们的分析形式化了局部教师偏好与学生续写价值之间的不匹配，并建立了重新分配相对于均匀 OPD 能够改善一阶任务进展的充分条件。在七个数学推理基准上，R$^{2}$-OPD 在跨规模与同规模蒸馏中均取得所比较训练方法中最高的平均准确率。它在全部七个基准上均优于标准 OPD，对于 1.7B 和 4B 学生模型，平均分别提升 3.5 和 2.4 个百分点。将其扩展到代码生成时，相比标准 OPD 平均提升 1.6 个百分点。这些结果凸显了结果引导的监督分配是一种有效方式，能够将稠密的教师反馈转化为跨模型规模和任务领域更强的学生性能。

## Abstract
On-policy distillation (OPD) trains a student language model with dense feedback from a stronger teacher on student-generated trajectories. Yet standard OPD weights token-level distillation terms uniformly, implicitly treating local teacher preference as a proxy for correction utility. A decision's task value, however, depends on how the student completes the subsequent reasoning. This mismatch can cause imitation to suppress viable student strategies or reinforce paths the student cannot reliably execute. Verified trajectory outcomes provide complementary evidence about continuation quality, but do not directly identify the utility of individual decisions. We introduce Reward-Aligned Reweighting for On-Policy Distillation (R$^{2}$-OPD), which uses outcome agreement and the magnitude of teacher--student disagreement to continuously reallocate teacher supervision. It gives reward-aligned corrections greater relative influence while retaining dense feedback, moving beyond uniform imitation and hard filtering. Our analysis formalizes the mismatch between local teacher preference and student continuation value and establishes sufficient conditions for reallocation to improve first-order task progress over uniform OPD. Across seven mathematical reasoning benchmarks, R$^{2}$-OPD achieves the highest average accuracy among the compared training methods in both cross-size and same-size distillation. It outperforms standard OPD on all seven benchmarks, with average gains of 3.5 and 2.4 percentage points for 1.7B and 4B students, respectively. An extension to code generation yields an average gain of 1.6 percentage points over standard OPD. These results highlight outcome-guided supervision allocation as an effective way to translate dense teacher feedback into stronger student performance across model scales and task domains.

## 一、核心问题与研究动机

- **背景**：同策略蒸馏（On-Policy Distillation, OPD）已成为大模型后训练的标准环节——教师模型在学生自采轨迹的访问前缀上提供稠密的 token 级反馈，从而缓解训练上下文与推理时行为之间的分布错配。
- **核心矛盾**：标准采样 token 版 OPD 直接用师生对数概率差 $A_t=\log\frac{\pi_T(o_t|s_t)}{\bar\pi_\theta(o_t|s_t)}$ 作为纠正系数并**均匀加权**，隐含地把「局部教师偏好」当作「纠正效用」的代理。
- **关键区分**：一个决策的真实任务价值取决于**学生自己**如何完成后续推理（student continuation value），而非教师如何完成。
- **两类失效模式**：
  - **成功轨迹上的过度纠正**：压制教师不偏好但学生可行的策略，侵蚀有效行为；
  - **失败轨迹上的过度信任**：强化教师偏好但学生无法可靠执行的推理路径。
- **理论佐证（Proposition 1）**：在固定前缀对下一动作分布做向教师插值 $\pi_\epsilon \propto \bar\pi_\theta^{1-\epsilon}\pi_T^{\epsilon}$ 时，有 $D_s'(0)=-\mathrm{Var}_s[A_t]$、$F_s'(0)=\mathrm{Cov}_s(A_t,Q^{\bar\theta}_R)$。即**只要 $A_t$ 非常数，反向 KL 必然下降，而期望奖励可能同时下降**——分布层面的「更像教师」并不等价于任务层面的「更好」。
- **动机**：已验证的轨迹结果 $z\in\{-1,+1\}$ 提供了关于续写质量的补充证据，但不能直接标注单个 token 的效用。因此作者主张：**用结果证据来引导教师纠正的「相对强度」，而不是用它做硬过滤或 token 价值标签**。

## 二、方法论：R²-OPD

### 核心思想
- 连续地重新分配教师监督的权重：让「奖励对齐」的纠正获得更大相对影响，同时保留全部非零反馈；通过**逐响应系数质量归一化**实现「再分配」而非「简单削减」。

### 关键技术细节
- **对齐判据**：$z(q,o)A_t>0$ 为奖励对齐，$<0$ 为奖励不一致。
- **响应局部尺度**：$\nu_o=\max\{\operatorname{median}_{j}|A_j|,\ \epsilon\}$（$\epsilon>0$ 为尺度下限，实验取 $2^{-23}$），用于把分歧幅度归一化到响应内部典型量级。
- **sigmoid 门控**：$g_t=\sigma\!\left(\beta z(q,o)A_t/\nu_o\right)$，$\beta\ge 0$ 控制锐度；$\beta>0$ 时对齐纠正 $g_t>1/2$、不一致纠正 $g_t<1/2$，且门控恒严格为正。
- **质量保持归一化**：$M_o=\sum_t|A_t|$，$Z_o=M_o/\sum_j g_j|A_j|$，最终系数
  $$A_t^{R^2}=Z_o\,g_t\,A_t$$
  保证 $\sum_t|A_t^{R^2}|=M_o$，符号与非零性均保留。
- **训练目标**：把 $A_t^{R^2}$ 代入停梯度对数概率代理损失 $L_{R^2}(\theta;\bar\theta)=-\mathbb{E}\left[\sum_t \mathrm{sg}[A_t^{R^2}]\log\pi_\theta(o_t|s_t)\right]$；梯度只流经 $\log\pi_\theta$，**不引入额外策略梯度项或价值估计器**。

### 算法流程（Algorithm 1）
1. 冻结学生快照 $\bar\theta\leftarrow\theta$，采样一批 prompt；
2. 用 $\bar\pi_\theta$ 生成响应 $o$，查询教师得到 $A_t$，用验证器得到 $z$；
3. 对完整且 $M_o>0$ 的响应计算 $\nu_o$ 与 $g_t$，再算 $Z_o$ 并重加权；
4. 用 $\mathrm{sg}[A_t^{R^2}]$ 更新 $\theta$。截断响应回退到标准 OPD 系数；零质量响应保持零系数（$Z_o=1$）。

### 理论刻画
- **Proposition 2（精确分解）**：$A_t^{R^2}=\underbrace{\frac{Z_o}{2}A_t}_{\text{Term A 教师偏好}}+\underbrace{\frac{Z_o}{2}z|A_t|\tanh\!\left(\frac{\beta|A_t|}{2\nu_o}\right)}_{\text{Term B 奖励对齐调制}}$。Term B 在成功响应上非负、失败响应上非正，即**衰减成功轨迹上的压制与失败轨迹上的强化**，并增强对齐纠正；其幅度严格小于 Term A，故符号不变。
- **Proposition 3（质量保持的对齐分配）**：$\sum_t|A_t^{R^2}|=M_o$，且不一致系数质量占比 $\kappa_o(\beta)$ 满足 $\kappa_o'(\beta)<0$（两侧均有权重时）；$\beta\to\infty$ 收敛为质量归一化的硬对齐门控。
- **Proposition 4（条件式任务进展恒等式）**：$\langle g_R,\ d_{R^2}(o)-d_V(o)\rangle = M_o\,\frac{\mathrm{Cov}_{p_o}(g,u)}{\mathbb{E}_{p_o}[g]}$，其中 $u_t=\mathrm{sgn}(A_t)\langle g_R,\psi_t\rangle$。因此**重加权改善一阶任务投影当且仅当门控权重与纠正效用正相关**；仅减少不一致质量并不保证任务进展。
