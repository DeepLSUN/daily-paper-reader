## 摘要
言语反馈能够识别错误并给出纠正建议，即使在没有可靠程序化验证器时，也能为语言模型后训练提供丰富监督。此类反馈通常由能力较强的模型生成，可用于在同策略蒸馏中条件化教师模型，从而训练学生匹配教师在学生生成轨迹上的预测。然而，该方法可能迁移并非由反馈所激发的教师偏好，同时使反馈中的大量指导未被利用。我们发现，这两个问题均源于标准的同策略蒸馏目标，具体而言，是其最小化的散度以及其所用作目标的分布。我们提出的方法同时解决了这两个局限。首先，为了将反馈所传达的信息与教师固有偏好分离开来，我们将言语反馈视为支持或反对“在给定前缀下下一个词元为某个特定词元”这一假设的证据。然后，我们采用一个概率确认框架，该框架基于教师在接收反馈前后的预测，唯一地确定词表上的一个排序。使用与该排序一致的确认分数，我们在学生的信赖域内构造一个目标分布。其次，为了从学生轨迹可能未加利用的指导中学习，我们推导出一个简单的共享轨迹估计器，用于估计学生分布与目标分布在轨迹上的对称散度，并通过重要性加权在两个方向上复用学生轨迹和以反馈为条件的教师轨迹。实证评估表明，在基于知识的基准和智能体基准上，我们的方法优于常见的同策略蒸馏方案以及近期的一种对比式变体。

## Abstract
Verbal feedback can identify errors and prescribe corrections, providing rich supervision for language-model post-training even when reliable programmatic verifiers are unavailable. Such feedback, often generated by a capable model, can be used to condition the teacher in on-policy distillation, which trains the student to match the teacher's predictions on student-generated rollouts. However, this approach can transfer teacher preferences that the feedback did not motivate, while leaving much of the feedback's guidance unused. We find that both problems come from the standard on-policy distillation objective, specifically the divergence it minimizes and the distribution it uses as its target. Our proposed method addresses both limitations. First, to isolate the information conveyed by the feedback from the teacher's inherent preferences, we treat verbal feedback as evidence for or against the hypothesis that a particular token comes next at a given prefix. We then adopt a probabilistic confirmation framework which uniquely determines an ordering over the vocabulary based on the teacher's predictions before and after it receives feedback. Using a confirmation score consistent with this ordering, we construct a target distribution within a trust region of the student. Second, to learn from guidance that student rollouts can leave unused, we derive a simple shared-rollout estimator of a symmetric divergence between the student and target distributions over rollouts, reusing student and feedback-conditioned teacher rollouts in both directions through importance weighting. Empirical evaluations show that our method outperforms the common on-policy distillation recipe and a recent contrastive variant on knowledge-based and agentic benchmarks.

# 论文总结：《Inductive Feedback for Mixed-Policy Distillation》

## 1. 核心问题与整体含义

- **背景**：语言模型后训练广泛依赖强化学习，但核心难点是**信用分配**——GRPO 等方法把单个标量奖励级联到轨迹所有 token 上，无法区分真正贡献结果的 token 决策。
- **在线策略蒸馏（OPD）** 提供了替代方案：让学生在自己的 rollout 上匹配教师的 next-token 预测，从而构造 token 级优势。当教师是学生自身、但条件化于特权信息（参考答案、执行反馈、**言语反馈**）时尤为有用。
- **言语反馈的价值**：由 LLM judge 撰写，能指出错误位置并给出纠正建议，在缺乏可靠程序化验证器的场景下是实用监督源，且可保留被奖励聚合丢失的细粒度信息。
- **标准 OPD 的两个缺陷**（本文核心动机）：
  - **迁移过多**：直接匹配教师分布会把与反馈无关的教师固有偏好（措辞、格式、训练习惯）当作训练信号迁移给学生。
  - **利用过少**：OPD 只在学生实际访问的前缀上监督，一旦学生轨迹走偏，反馈的纠正内容可能只影响极少数 token 位置，大量指导被浪费。
- **作者判断**：两个问题都源于标准 OPD 目标本身——即它最小化的**散度**（reverse KL）与它使用的**目标分布**（教师 next-token 分布）。

## 2. 方法论

### 2.1 反馈作为证据：修正的蒸馏目标

- **核心思想**：把言语反馈视为关于"下一 token 是 v"这一假设的**证据**，用教师在有/无反馈下的预测作为后验/先验概率：
  - $P_{\text{post}}(v)=\pi_T(v\mid x,y_s,F,y_{<t})$，$P_{\text{prior}}(v)=\pi_T(v\mid x,y_s,y_{<t})$
- **确认分数公理**（Crupi & Tentori, 2013）：要求分数 $S(v)=\sigma(P_{\text{post}},P_{\text{prior}})$ 满足
  - **A0** 概率依赖；**A1** 对后验单调；**A2** 反确认下仅依赖剩余概率比例；**A3** **互补性**（token 与补集的排序必须反转）。
- **定理 1**：满足 A0–A3 的分数当且仅当是**相对距离** $d(v)$ 的严格递增变换：
  - $d(v)=\dfrac{P_{\text{post}}-P_{\text{prior}}}{1-P_{\text{prior}}}$（概率上升时），$\dfrac{P_{\text{post}}-P_{\text{prior}}}{P_{\text{prior}}}$（下降时）
  - 取恒等变换得 $S=d\in[-1,1]$，反馈无变化时为 0。
- **关键反例**：常用对数概率差 $\log P_{\text{post}}-\log P_{\text{prior}}$ 违反 A3。例如 0.01→0.02（比例翻倍）会排在 0.40→0.60 之前，但补集排序相同，违反互补性；本文给出三 token 合成实验（图 1）证明该违反会在精确优化下**反转学生对正确 token 的偏好**，且严格递增变换无法修复。
- **目标构造**：在学生的信任域内求解 KL 正则化问题
  - $\pi_{\text{corr}}=\arg\max_{\pi}\ \mathbb{E}_{v\sim\pi}[S(v)]-\frac{1}{\beta}\mathrm{KL}(\pi\|\pi_\theta)$
  - **闭式解**（重加权学生自身概率）：$\pi_{\text{corr}}(v)=\mathrm{sg}\!\left[\dfrac{\pi_\theta(v)\exp\{\beta S(v)\}}{Z_t}\right]$，$Z_t=\sum_v \pi_\theta(v)\exp\{\beta S(v)\}$
- **目标性质**：
  - 反馈不改变教师分布时 $S\equiv 0$，目标恰等于学生，该前缀不产生梯度；
  - $e^{-2\beta}\le \pi_{\text{corr}}/\pi_\theta\le e^{2\beta}$，重加权有界，训练更稳定；
  - 在 reverse KL 下给出有界 token 优势 $\beta(S(v)-\mathbb{E}_{\pi_\theta}[S])$。

### 2.2 共享 rollout 的对称目标

- **动机**：学生轨迹会浪费反馈的"规定性"内容，需在教师建议的纠正路径上也获得监督。
- **目标散度**：采用 **Jeffreys 散度** = reverse KL + forward KL
  - reverse 项：在学生的前缀上监督（即 OPD 目标，以 $\pi_{\text{corr}}$ 为目标）；
  - forward 项：在 $\pi_{\text{corr}}$ 生成的前缀上监督，塑造学生尚不能稳定生成的轨迹。
- **共享 rollout 估计器（平衡启发式）**：每条 rollout 以概率 $\lambda$ 来自 $\pi_\theta$，以 $1-\lambda$ 来自 $\pi_{\text{corr}}$，混合分布 $m=\lambda\pi_\theta+(1-\lambda)\pi_{\text{corr}}$。
  - 重要性权重：$w_{\text{rev}}=\pi_\theta/m\le 1/\lambda$，$w_{\text{fwd}}=\pi_{\text{corr}}/m\le 1/(1-\lambda)$
  - 因混合分布同时包含两个策略，**权重天然有界**，避免直接重要性比率可能出现的任意大值。
- **理论保证**（附录 B.3）：
  - 共享 rollout 在重叠支撑下给出**严格更大的渐近有效样本量**（ESS 分数 $\rho_q=\lambda/(1-(1-\lambda)\kappa)$ 等）；
  - 给出半梯度的**梯度方差上界**。

### 2.3 实现细节

- 用 **α-skew 散度**（$\alpha=0.01$）替换每个 token KL，限制单 token 损失幅度为 $\log(1/\alpha)$，避免 rollout 级 skew 的退化问题。
- 以**反馈条件教师 $\pi_F$ 作为 proposal** 生成教师轨迹，前向权重裁剪 $c_{\text{IS}}=2$（实测约 1% 权重被裁剪）。
- 词表近似：取教师两分支 top-k 并集，缺失项设统一正下限，分数在并集外置零，目标仍归一化。
- 训练采用**半梯度**：目标、归一化常数、采样前缀与重要性权重固定，梯度只流经学生出现的 q。

## 7. 方法局限与潜在问题

- **对教师/judge 质量的依赖**：确认分数完全由“有/无反馈的教师后验差”定义。若 judge 反馈本身错误或噪声大，$P_{\text{post}}$ 可能朝错误方向移动，方法会系统性地放大该错误，而论文未提供反馈可靠性过滤或不确定性建模机制。
- **KL 正则项与 β 的作用域**：闭式解在“学生信任域”内推导，但实验中的 β 取值（1–10）如何随模型规模、任务、反馈长度缩放，缺少理论或经验指引；β 的调参成本可能抵消部分实用性。
- **forward KL 项的成本**：需要额外从 $\pi_{\text{corr}}$ 生成轨迹并计算教师打分，共享 rollout 只降低了采样成本，未降低教师前向推理成本；在长序列/大词表下开销仍可观。
- **理论保证的条件性**：ESS 与梯度方差上界依赖“重叠支撑”与混合分布假设；当纠正分布与学生在某些前缀上几乎不重叠时（例如学生完全不会的任务），$\lambda$ 边界仍成立但有效样本量可能退化。
- **评估局限**：主表仅 3 个 checkpoint 平均，未报告多种子训练方差；多个基准的置信区间重叠（生物、材料、工具），方法优势在这些任务上未被严格分离，需更多重复实验确认。
- **范围局限**：所有实验均在较小模型（2B/4B）与特定 judge（Gemini 系列）上进行，尚未验证在更大模型、其他反馈来源（人类反馈、工具执行反馈）或更长 horizon 任务上的可扩展性。

- **实证信号混合但方向清晰**：Trivia Fantasy（2.8%→98.3%）与 EmbodiedEval（73.7%→82.1%）的跃升极具说服力，SciKnowEval 化学/物理的显著增益也表明改进来自反馈的细粒度信息而非一般能力提升；但生物、材料、工具上的小幅增益与重叠置信区间提示方法收益具有任务依赖性，可能受 judge 反馈质量或任务本身的可迁移性限制。
- **报告透明度**：算力与硬件描述偏简略（仅列 GPU 型号，未给数量/时长/总计算量），消融仅在单一基准、100 步预算下进行，这是可复现性与结论稳健性上的主要缺口。
- **启示**：本文提示“反馈条件化自蒸馏”的关键不在于更强的教师，而在于**如何定义反馈带来的概率变化**以及**在哪些前缀上施加监督**。确认分数公理与 Jeffreys 散度的组合，为后续在缺少程序化验证器的领域（具身、工具调用、开放域问答）中利用言语反馈提供了可复用的目标构造范式；未来工作可探索反馈可靠性建模、β 的自适应调度，以及更大规模与多轮反馈场景下的扩展。
