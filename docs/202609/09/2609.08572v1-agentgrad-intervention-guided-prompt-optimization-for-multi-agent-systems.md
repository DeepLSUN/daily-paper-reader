## 摘要
基于大型语言模型（LLM）的多智能体系统（MAS）通过采用专门化的多个智能体实现了强劲性能，但其性能依赖于每个智能体的提示设计。对于MAS提示优化，利用自然语言反馈指导提示更新的文本梯度方法已成为主流范式。在本文中，我们指出了现有文本梯度方法在梯度提取和梯度聚合两个阶段的局限性。在梯度提取中，先前的工作选择目标提示时未验证修改该提示是否能解决失败，并且在缺乏对相应智能体中间输出的智能体级监督的情况下推导梯度。在梯度聚合中，单个梯度被随机分组并拼接，常常混合不相关的失败模式，产生无法泛化的提示。为解决这些局限性，我们提出了	extbf{AgentGrad}，一种基于顺序干预和语义文本梯度抽象的多智能体系统提示优化框架。对于每次失败，顺序干预每次仅修改一个智能体的行为，以识别其修改能解决失败的目标智能体。随后，目标智能体的修改后输出作为智能体级监督，用于提取细粒度梯度。语义文本梯度抽象将语义相似的梯度聚类，以防止混合不相关的失败模式，并将每个聚类抽象为捕获共享修正模式的泛化梯度。实验结果表明，AgentGrad在五个MAS基准测试中达到了最先进的性能，并且与次快基线相比，平均将墙钟优化时间减少了$2.5\times$。

## Abstract
Large language model (LLM)-based multi-agent systems (MAS) achieve strong performance by employing specialized multiple agents, yet their performance depends on the prompt design of each agent. For MAS prompt optimization, textual gradient methods that guide prompt updates using natural-language feedback have emerged as a leading paradigm. In this paper, we identify limitations in two stages of existing textual gradient approaches: gradient extraction and gradient aggregation. In gradient extraction, previous works select a target prompt without verifying whether modifying it resolves the failure, and derive gradients without agent-level supervision over the corresponding agent's intermediate output. In gradient aggregation, individual gradients are randomly grouped and concatenated, often mixing unrelated failure modes and producing prompts that fail to generalize. To address these limitations, we propose \textbf{AgentGrad}, a prompt optimization framework for multi-agent systems based on sequential intervention and semantic textual gradient abstraction. For each failure, sequential intervention modifies the behavior of one agent at a time to identify the target agent whose modification resolves the failure. The modified output of the target agent then serves as agent-level supervision for extracting a fine-grained gradient. Semantic textual gradient abstraction clusters semantically similar gradients to prevent mixing unrelated failure modes, and abstracts each cluster into a generalized gradient that captures the shared corrective pattern. Experimental results show that AgentGrad achieves state-of-the-art performance across five MAS benchmarks and reduces wall-clock optimization time by $2.5\times$ on average compared to the next-fastest baseline.

### 1. 核心问题与研究动机（Problem & Motivation）

基于 LLM 的多智能体系统（MAS）通过多个专业化智能体协同工作来解决复杂任务，表现出很强的性能。MAS 中每个智能体的行为由其输入 prompt 控制，因此 prompt 设计对系统性能至关重要，自动提示优化（APO）成为重要方向。文本梯度方法——用自然语言反馈来指导 prompt 迭代更新的方法——在 MAS 提示优化中已成为主流范式。

然而，论文指出现有文本梯度方法在**梯度提取（Gradient Extraction）**与**梯度聚合（Gradient Aggregation）**两个阶段存在系统性不足：

- **梯度提取方面的两个问题**：
  1. 目标 prompt 选择缺乏验证：现有方法要么同时更新所有智能体的 prompt（成本高），要么用轮询方式选择而**不测试哪个 agent 的 prompt 被修改后确实能修复失败**；
  2. 梯度推导缺乏 agent 级监督：当最终系统输出错误时，仅凭系统级反馈与 ground truth 的差异，无法得知哪个中间智能体的哪个中间输出出了问题——存在信用分配难题。

- **梯度聚合方面的问题**：单个样本级梯度常被随机分组后直接拼接，容易把来自**互不相关的失败模式**的更新方向混在一起，导致 prompt 更新方向混乱、泛化性差。

上述问题共同导致优化效率低、最终提示泛化能力差、收敛慢。

### 2. 方法论（Method）

AgentGrad 的整体框架是一个“提取 → 聚合 → 更新 → 验证”的迭代优化循环。核心思想是针对每个失败样本，先**用顺序干预定位真正该负责的智能体**，再**把干预后的输出作为 agent 级伪标签来提取细粒度梯度**，最后**把语义相似的梯度聚类、抽象成泛化的更新方向**。其中每一步的设计都直接对应一个已识别的缺陷。

#### 2.1 目标智能体定位：顺序干预（Sequential Intervention）

**核心逻辑**：要更新谁，先验证“改了谁有用”。

- 将训练集上当前 prompt 集合 P 下未达满分（r < r_max）的样本构成失败集合 F。
- **按逆执行序（从最后一个 agent 到第一个）** 逐个智能体进行干预——给该智能体的 prompt 追加 hint H（由 ground truth 或任务约束构造，仅训练时使用），引导该智能体生成“修正后的中间输出”，再让后续智能体照常执行。
- 如果干预第 n 个智能体后，最终输出达到了 r_max，说明“修正第 n 个智能体就足以解决该失败”，因此将该样本归入 T_n，并**将第 n 个智能体确定为目标智能体**；未解决样本则进入下一轮干预。
- 逐层剥离后得到每个失败样本的**唯一归属目标** T_n。逆序干预利用了失败往往集中在后段 agent 的经验，减少了平均干预次数。仍无法解决的样本作为“硬案例”留待下一轮（因为下一轮会在新 prompt 下重新构建失败集合）。
- 定义公式：T_n = {(x_i, y_i) ∈ F_{n+1} | r(Π(n,H)(x_i; P), y_i) = r_max}，即第 n 个智能体被判定为目标智能体的失败样本子集。

**关键贡献**：这是首个将“失败归因”从分析工具延伸到提示优化中、用干预结果反向决定更新哪个 prompt 的方法（论文明确做到了对目标选择进行验证）。

#### 2.2 通过智能体级监督提取文本梯度（Agent-level Supervision）

**核心逻辑**：既然干预后这个 agent 在同样的输入下输出了正确的中间结果，那“错在哪”和“应改成什么”其实已经由输出对比告诉了。

- 对被归因到第 n 个智能体的每个失败样本（x_i, y_i），记录两个输出：
  - 失败执行中的原始输出 ŷ_ni = π_n(x_ni; p_n)；
  - 干预注入 hint H 后的修正输出 ỹ_ni = π_n(x_n; p_n, H)。
- 两者输入上下文相同，因此差异完全来自干预诱导的行为变化。将 ỹ_ni 看作 agent 级伪标签（agent-level pseudo-label）。
- 用 LLM 梯度提取器提取样本级文本梯度：δ_ni = LLM∇(pn, x_ni, ŷ_ni, ỹ_ni)——即“prompt 应如何修改才能让 agent 输出 ỹ_ni 而不是 ŷ_ni”。
- **无需显式损失函数**：对比 ˆyni 和 ỹni 本身就蕴含了 agent 级监督信号，不需要系统级输出对 ground truth 的显式损失。

**关键贡献**：在大多数 MAS 场景缺少 agent 级人工标注的情况下，用干预构造出伪标签，把监督信号从系统级下沉到 agent 级，得到更细粒度的更新信号。

#### 2.3 语义文本梯度抽象（Semantic Textual Gradient Abstraction）

**核心逻辑**：随机小批量把不同错误模式的梯度混在一起，优化的更新方向就会混乱。如果把“说同一件事”的样本级梯度放进同一个 minibatch，再把它抽象成一句概括性的泛化梯度，更新方向就集中且更有泛化性。

- 对第 n 个 agent 的全部样本级梯度集合 Ω_n，调用 LLM 聚合器一次性完成两件事：
  1. **语义聚类**：将语义相近的样本级梯度分成若干组，每组对应一个语义小批量 D_nj；
  2. **泛化抽象**：把每组概括为一个泛化文本梯度 δ̄_nj，提炼组内共享的修正模式。
- 聚合器由 LLM 自动决定聚类数 M_n；并通过**循环调度的小批量下界**（如 5→3→1→5…）控制系统在不同轮次交替采用粗粒度与细粒度的更新信号。下界是建议性的而非硬约束。

#### 2.4 提示更新与验证（Prompt Update & Validation）

- 按语义小批量大小的降序（先应用覆盖样本更多的高影响力更新）逐个处理泛化梯度。
- 用 prompt 优化器 LLM 生成候选 prompt：p_new = LLM_PromptOptimizer(p_n, δ̄_nj)。
- 候选 prompt 先在**语义小批量**上验证：若性能提升，再到**独立验证集**上验证；两级都通过才接受更新，否则丢弃。

#### 2.5 算法总览（伪代码结构化描述）

算法在 rollout 预算未耗尽时循环：

1. 用当前 prompt 集在训练集上跑出失败样本集 F；
2. 从第 N 个 agent 到第 1 个 agent 逆序干预，逐步析出每个 agent 对应的已纠正样本集 T_n；
3. 对每个 T_n 中的样本，利用原始输出与干预后输出的差异构造 agent 级伪标签，提取样本级梯度；
4. 用 LLM 聚合器对每个 agent 的样本级梯度做语义聚类与抽象（形成语义 minibatch 与泛化梯度）；
5. 按 minibatch 规模降序更新 prompt，经两级验证后接受或丢弃，更新全局 prompt 集。

- 相比 MIPROv2、TextGrad 和 GEPA 等 State-of-the-Art 方法，**AgentGrad 在 5 个 MAS 基准、两个骨干上都取得了最优平均性能**（GPT-5-mini：相对无优化基线平均提升 +11.76 分；Qwen3-8B：+9.67 分，均优于所有基线）。

### 8. 不足与局限（Limitations）

1. **干预模式的前提假设**：顺序干预假定问题可以通过单次“给单个 agent 注入 hint”来修复；对那些需要多个 agent 协同修正才能解决的“连环错误/交互性失败”，该方法可能无能为力（只能作为无法解决的硬案例跳过）。对于依赖跨 agent 上下文信息往返的动态系统，应用起来会面临挑战。
2. **干预成本**：每轮每一失败样本都要对所有 agent 逆序做一次系统级 rollout，尽管采用逆序调度来缓解，但训练开销依然较高。虽然优化 wall-clock 时间总体上低于基线，但随着 agent 数量增加或失败率升高，时间增加是否可以保持经济性尚需验证。
3. **未报告推理时的额外开销**：优化后的提示部署时不含 hint——即推理时零增量延迟，但论文并未将这一点作为明确的推理效率指标给出。
4. **Agent 级提示数据集的覆盖限制**：所有基准都是任务型或偏静态的跨 agent 数据流水；不涉及动态环境、工具调用、实时记忆或多轮对话等典型 agentic 交互模式，也缺少多分支并行 agent 架构的相关内容。
5. **失败样本集的周期性重建**：每次外层迭代对训练集重新执行全系统 rollout 来重建失败集合——意味着过度依赖随机种子、出现较长迭代的无失败回合等情况时可能引入方差。
6. **隐藏细节或成堆的实现选择**：hint H 的构造（如何从 ground truth/约束中生成）、提示的轮数/budget B 的大小、minibatch 的迭代时长等细节未完整展开，在复现和应用到其他 MAS 时可能面临隐藏偏好限制。
7. **实验规模较小**：每个实验仅使用 3 个随机种子，在低方差代理任务上主实验的标准误在 0.09 到 1.91 之间；对照方差较高（例如 TextGrad 的 Qwen3-8B 在 HotpotQA 上 ±5.36），缺少显著性差异检验（如配对 t-test 或置信区间）来说明与次强基线的差异是否统计上显著。
8. **硬件资源未透出**：文中未说明 GPU 型号、算力或不同方法是否在相同硬件条件下对比（baselines 的时间可能受到各自对特定求解器调用方式的 rollouts 次数影响），对“2.5× 加速”能在同等算力配置下普遍成立的有力性打了折扣。
9. **结论的适用空间有限**：只测试了单一知识点范式上的文本梯度优化（MIPROv2、TextGrad、GEPA 均基于 rollout 预算的搜索）；没有与其他更广泛的 APO 框架（如 RL 方式、贝叶斯优化或其他非文本梯度方式）对比，因此并不能完整描述

#### 8.10 评价与展望（简短收束）

总体而言，论文的实验证据足以支撑“AgentGrad 在它所定义的问题域（单轮、静态数据流的文本梯度式 MAS 提示优化）内显著优于同类基线”这一核心主张；但若要将其结论推广到更复杂、动态、多分支的真实智能体系统，仍需要更多架构层面的适配验证与更大规模的统计检验。

### 9. 可复现性与开放性（Reproducibility）

- 论文给出了算法级伪代码、干预 hint 的构造思路和两级验证流程，主框架可复现性较好。
- 但存在若干未展开的实现细节可能影响精确复现：hint H 的具体构造模板未提供完整示例；迭代轮数/rollout 预算 B 在各基准上的具体取值未逐表列出；语义聚类时 LLM 聚合器的指令模板与“minibatch 下界”的具体调度（5→3→1）在代码库中如何实现未见附录细节。
- 骨干模型选择为 GPT-5-mini 与 Qwen3-8B，两者均为可公开调用的模型（Qwen3-8B 为开源权重），从模型获取角度看具备复现条件；但论文未明确是否将释放完整 prompt 模板、干预 hint 集与聚合器指令，这部分开放性信息需在论文与代码仓库中进一步确认。
- 依赖 LLM-as-judge 的评分方式（r 函数）在各基准上的具体 prompt 与判定准则未完全公开，这也是影响验证环节可复现性的关键点之一。

### 10. 对领域的影响与启示（Broader Impact & Takeaways）

1. **从“更新所有”到“验证后定向更新”**：AgentGrad 最重要的方法论启示是——提示优化不应盲目地对所有智能体同时施加梯度，而应先通过低成本干预实验确定“修改谁确实有效”，再对目标智能体做定制化更新。这一“先验证、后更新”的因果归因思路可推广到其他多组件系统（如 RAG 流程、工具链编排）的自动调试中。

2. **伪标签下沉是解决 MAS 信用分配的有效手段**：当系统缺少 agent 级标注时，利用可控干预构造 agent 级伪标签，将系统级损失拆解为组件级修正信号，为 MAS 场景下的细粒度监督提供了一种轻量且通用的范式。

3. **语义级小批量比随机小批量更适合文本梯度**：文本梯度本质上是自然语言描述，其“梯度方向”的可叠加性远弱于数值梯度。AgentGrad 证明了将语义相近的文本梯度聚类后再抽象，能显著减少更新方向间的相互抵消——这对所有基于自然语言反馈的优化方法都有借鉴意义。

4. **优化质量与优化效率不必二选一**：通过提高每次 rollout 的信息利用率（小批量改进比从 0.51 提升到 0.87），AgentGrad 实现了比基线更高的最终性能与更短的优化时间，说明“高质量梯度”才是同时改善两者的核心杠杆。

### 11. 总体评价与推荐结论（Overall Assessment）

AgentGrad 是一篇**问题定义清晰、方法设计有因果逻辑、实验覆盖面较完整**的文本梯度提示优化工作。它的主要学术贡献不在于提出全新的优化范式，而在于**将“失败归因”与“监督信号下沉”这两个在 MAS 调试中被长期忽视的环节系统性地引入提示优化流程**，并给出了对应的、可验证的工程实现。

在“论文的强度-弱点权衡”上：

- 如果读者关注的是**如何在缺少 agent 级标注的 MAS 中做高效提示优化**，AgentGrad 提供了一个完整、有说服力的解决方案，值得精读并作为后续工作的 baseline；
- 如果读者关注的是**更广泛的 agentic 场景（动态环境、工具调用、多轮对话、并行协作）下的自动优化**，AgentGrad 的实验范围与干预假设尚不足以覆盖这些复杂情形，需要谨慎外推其结论。

**一句话总结**：AgentGrad 通过“顺序干预定位责任智能体 + 干预输出构造 agent 级伪标签 + 语义聚类抽象文本梯度”三步走，在静态任务型 MAS 上同时实现了优于 SOTA 的最终性能和约 2.5 倍的优化加速，是该子方向上方法设计最完整、证据链最清晰的工作之一，但其适用边界也明确受限于“单 agent 修正即可修复的系统失败”与“数据流水式 MAS 架构”。
