## 摘要
我们提出了FrogNano，一个4B规模的编码智能体，旨在资源受限环境下高效且有效地处理软件工程（SWE）任务。它仅通过约1,500个SWE环境下的强化学习（RL）和合成任务进行后训练。提升性能的一个关键要素是在线任务合成流水线，该流水线创建的任务与当前检查点可学习前沿相校准。本报告提供的证据表明，仅使用合成任务即可训练出具有竞争力的轻量级编码智能体，无需传统地从更大模型进行蒸馏，并且生成位于当前智能体可学习前沿的任务至关重要。我们报告了训练方法的细节、跨多种环境的评估以及深入分析，为我们持续探索可在最低硬件上运行的轻量级但功能强大的编码智能体奠定基础。

## Abstract
We present FrogNano, a 4B coding agent designed to tackle software engineering (SWE) tasks efficiently and effectively, even under resource-constrained environments. It is post-trained exclusively via RL on around 1,500 SWE environments with synthetic tasks. A key ingredient for improving performance is an online task synthesis pipeline that creates tasks calibrated to the frontier of learnability for the current checkpoint. This report provides evidence that competitive small coding agents can be trained with synthetic tasks alone, without traditional distillation from larger models, and that generating tasks at the learnability frontier of the current agent is important. We report details on the training methodology, evaluations across diverse environments, and in-depth analyses, serving as a foundation for our ongoing exploration of lightweight yet capable coding agents that can run on minimal hardware.

## 1. 论文的核心问题与整体含义

**研究动机**：当前软件工程（SWE）编码智能体的性能突破几乎完全由两类模型驱动——以 API 形式提供的专有前沿模型，或参数规模高达“百B”量级的开源模型。这两类系统在部署成本、本地化运行和反复实验的可行性上均存在严重瓶颈。论文由此提出一个根本性问题：

> *一个仅约 4B 参数的紧凑模型，能否通过合理训练流程成为具备仓库级（repository-level）编码能力的智能体？*

**核心意义**：该论文**不依赖任何传统意义的大模型蒸馏**（即不借用更大模型的轨迹、行为目标或推理过程作为监督），而完全相同地采用“强化学习（RL）+ 在线合成任务”的范式，将 Qwen3.5-4B 这一小型基础模型训练成一个性能可匹敌 32B–100B 级编码模型的高效仓库级 agent。结论暗示：**只要任务合成能与当前策略的学习前沿耦合，紧凑模型的编码能力上限远高于业界通常预期**，这为资源受限场景下的编码智能体部署提供了新的可能性。

## 2. 方法论

论文方法由三个关键部件组成，构成闭环训练系统（图 3）。

### 2.1 Leaf：面向小模型的轻量级 Agent Harness

- **问题诊断**：在既有 R2E-Gym/SWE-Agent 式 harness 下，Qwen3.5-4B 的轨迹中约 **96% 达到轮次上限**而无法正常终止，解决率仅 8.3%；说明小模型对复杂交互协议的遵循能力是主要瓶颈。
- **Leaf 设计**：受 Claude-Code 工具约定启发的轻量 harness：
  - **五个类型化工具**：`read`、`write`、`edit`、`glob`、`bash`；
  - **自然终止规则**：无工具调用的响应即视为提交，终止回合；
  - **无冗余交互特征**：省略计划模式、权限弹窗、辅助工具等复杂产品功能。
- **量化收益**：仅将 harness 从 R2E-Gym 切换为 Leaf（其他设置不变），相同模型的 SWE-bench Verified 解决率从 **8.3% → 37.2%**；而大模型 MiniMax-M2.5 对同种 harness 变化不敏感（两者均为 66.5%），说明界面简化主要对紧凑模型重要。

### 2.2 TaskPilot：策略自适应的在线任务合成流水线

- **输入来源**：SWE-rebench 中的真实仓库快照（约 1500 个训练任务总量）。
- **任务生成**：由生成模型产出**问题陈述（problem statement）、参考补丁（gold patch）、隐藏的失败-通过（F2P）测试**；并用可执行性双重验证——F2P 测试须在原始仓库上失败、应用 gold patch 后通过，且原有 P2P（通过-通过）测试保持不变。
- **基于当前策略的校准与精炼**：
  - 对每个候选任务，用当前策略 checkpoint 执行 N 次 rollout，估计解决率：

    $$\hat{p}_{policy} = \frac{1}{N}\sum_{j=1}^{N} R_j,\quad R_j\in\{0,1\}$$

  - RL 训练须落在策略的“可学习区”，即以 **0 < p̂policy < 1** 的“混合成功率”区域表示；具体校准目标：迭代 1–4 期以 **p̂ = 0.5** 为靶；迭代 5 改用更强的任务生成模型并把目标降到 **0 < p̂ ≤ 0.5**。
  - 对于过难（p̂ = 0）或过易（p̂ = 1）的任务，**不是简单丢弃，而是语义性精炼并重新评估**（generate–evaluate–refine–re-evaluate 闭环），直至落入目标难度区间。
- **核心认知贡献**：任务合成可以对照当前策略不断调整问题的“可学习前沿”，从而使任务分布随模型能力演化，而不是对固定候选集做一次性静态过滤。

### 2.3 RL 训练配方

- **算法**：DPPO（连续组间相对优化），每个任务组采样 8 条轨迹，组内标准化优势

  $$A_{ij} = \frac{R_{ij}-\bar{R}_i}{\mathrm{std}(R_i)+10^{-6}}$$

  丢弃零方差组；采用异步轨迹重要性采样修正 rollout 滞后，并通过 DPPO 非对称裁剪掩码排除陈旧轨迹。
- **奖励塑造**：成功率门控的对数长度惩罚（success-gated log-length penalty）：

  $$R(n) = \begin{cases} 1, & n\le N \\ 1-\alpha\ln(n/N), & n>N \end{cases}$$

  其中 $N$ 为允许的免费 token 数，$\alpha$ 控制惩罚强度；仅对**成功且完成**轨迹生效，以鼓励简洁推理并稳定训练吞吐。
- **截断轨迹**：任务解决但因达到上下文/轮次/时间上限而截断的轨迹获得部分奖励 0.5。
- **训练节奏**：每轮 RL 包含 200 次更新，权重跨轮保留，但优化器与 RNG 状态逐轮重置。
- **损失口径**：仅模型生成的 token（推理、文本、工具调用）计入损失；工具观测保留在上下文中但被掩码。

## 6. 主要结论与发现

1. **在线校准可学习前沿有用**：模型仅从合成任务中学习就可以获得与其从大规模真实任务过滤集训练相当甚至更优的效果；连续 5 轮迭代中每轮新课程均提供额外增益（+11.7、+3.4、+5.6、+3.0、+5.4 个百分点），且无需熵坍塌。
2. **无蒸馏的可行路径**：FrogNano 证明一个仅 4B 参数的模型可以在无任何更强模型轨迹监督下达到与一年前 32B–100B 级模型相当的性能（SWE-bench Verified 61.5%），并且是**能力边界的真实提升而非 pass@k→pass@1 的蒸馏**——Pass@k 曲线相对基础模型整体上移。
3. **Harness 适配小模型是核心杠杆**：一个简单的、模型可遵循的界面（Leaf）比训练算法的影响更直接；同样的模型在两个 harness 上的成绩差 3 倍以上。
4. **接口行为的差异影响性能**：通过 Leaf 时验证类行为从 53.4%（基础模型）提升到 94.3%（最终检查点），成功轨迹显著更倾向做“最后一次编辑后测试”等闭环行为。
5. **迭代训练中会发生行为漂移与遗忘**：后期模型更加串行（并行工具调用几乎消失）、更长的步骤/轨迹也非必然带来性能增益；consolidation SFT 实验能够部分恢复有效行为。
6. **奖励黑客在现实训练中大量被阻止**：确认的尝试类型集中在弱化评分测试，但 scaffold/基础设施的有效防护可把“作弊成功率”控制在 0%。
7. **上下文压缩可行**：在 64K 的上下文窗口下，通过自摘要压缩可恢复 131K 全上下文 100% 的性能水平，而无需引入外部大模型。

| **小模型亲和的 Harness 设计** | 揭示出“接口复杂度”是小模型训练/推理的核心瓶颈，并给出一个简单、可复现的解决样例（Leaf），而非一味堆参数提升模型能力。 |
| **无蒸馏承诺与课前沿的证据** | 通过对照实验表明，合成任务的可学习前沿校准带来与昂贵真实任务过滤相当甚至更优的学习信号；这是对“合成数据不过是廉价的真实数据替代品”观点的重要反例。 |
| **实验分析翔实** | 失败归因（90.8% 推理缺口）、工具动态、奖励黑客、行为漂移、压缩、consolidation 等分析将“模型为什么会变好/变坏”解释清楚，而非仅交付一个性能数字。 |
| **成本可负担** | 单任务推理成本约 $0.21，支持在有限单节点硬件上做端到端 agent 研究，实验具有低门槛可复现性。 |
| **严谨性** | 对统计不确定性（多 seeds、bootstrap CI）、配对轨迹比较、评审间一致性（Fleiss κ）等进行了明确报告说明。 |
