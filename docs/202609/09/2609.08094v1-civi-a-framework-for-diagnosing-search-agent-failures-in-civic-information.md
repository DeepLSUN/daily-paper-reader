## 摘要
大型语言模型日益部署在公共部门环境中，在这些环境中，不正确的指导可能导致不可逆转的伤害。我们引入了CIVI，这是第一个用于诊断公民信息中搜索代理故障的框架。其基准实例化同时涵盖了跨国、跨辖区政府背景（联邦、州和地方）以及国际采用的联合国标准中的功能类别。我们评估了十个前沿搜索代理，发现没有一个能达到细心的非专业人类基线。除了准确性之外，CIVI还衡量搜索调用率、选择性不搜索准确性以及代理引用权威政府来源的频率。为了执行这一诊断，我们引入了ARISE，它将代理搜索故障分解为四种互斥模式，通过源注入消融进行隔离。ARISE将72.1%的观察到的故障归因于检索受限的原因，而不是模型参数知识中的差距。

## Abstract
Large Language Models are increasingly deployed in public-sector settings, where incorrect guidance can cause irreversible harm. We introduce CIVI, the first framework for diagnosing search agent failures in civic information. Its benchmark instantiation jointly spans cross-national, interjurisdictional government contexts (federal, state, and local) and functional categories from an internationally adopted United Nations standard. We evaluate ten frontier search agents and find that none matches an attentive human baseline. Alongside accuracy, CIVI measures search invocation rate, selective no-search accuracy, and how often agents cite authoritative government sources. To perform this diagnosis, we introduce ARISE, which decomposes agentic search failures into four mutually exclusive modes, isolated via source-injection ablation. ARISE attributes 72.1% of all observed failures to retrieval-bound causes rather than to gaps in the models' parametric knowledge.

### 一、核心问题与研究动机

- **问题场景**：大语言模型（LLM）正被大量部署于公共部门与公民信息获取场景，如福利资格、税务义务、法律合规咨询等。此类信息"容错率接近零"，一条错误指引即可造成不可逆的实际伤害。
- **现实风险例证**：纽约市 MyCity 聊天机器人曾给出违法建议（如允许解雇举报性骚扰的员工、认为被鼠咬的奶酪可安全食用等）；美国约 32% 成年人已向 AI 聊天机器人咨询健康信息；IRS、SSA、CDC 等政府聊天机器人已处理超 7000 万人次交互。
- **现有研究的三点空白**：① 已有政府信息基准仅限单一国家、单一辖区层级，缺乏跨国家且跨辖区的国际标准评测；② 公民问答评测只报告总体准确率，缺少对失败原因的分解诊断；③ 真实部署中"代理式搜索"（agentic search）行为（是否调用搜索、是否引用权威来源）未被系统研究。

### 二、方法论

论文提出一个"基准 + 诊断方法"组合：

- **CIVI 基准（Civic Intergovernmental Verification of Information）**
  - 规模：4,097 个专家验证的单选题（可多选）问答对，锚定 576 个手工筛选的权威政府部门网页。
  - 三维分层：按联合国 COFOG 国际标准抽取 4 个政府职能类目（公共秩序与安全、经济事务、卫生、社会保障）× 3 个联邦制国家（加拿大、美国、澳大利亚）× 3 个辖区层级（联邦、州/省、地方/市政），共 36 个分层单元（每单元 16 个来源页、约 114 个问答）。
  - 生成流程：使用 Claude Opus 4.6 自动生成（温度 0），每题 8 个选项、至少一个正确答案，附逐字支持引文；随后两名公共部门 AI 领域专家独立复核（原始一致率 96.8%，通过率 94.1%）。生成遵循四条标准：来源可推导、有具体后果、辖区精确、来源可追溯。

- **ARISE 失败诊断（Agentic failuRe dIagnoStic probE）**
  - 将搜索代理的每次错误响应确定性归入 4 种互斥且完备的失败模式：
    1. **Search bypass（搜索跳过）**：未调用搜索，仅凭参数化知识作答；
    2. **Retrieval failure（检索失败）**：调用了搜索但未取回金标准来源页；
    3. **Grounding failure（接地/锚定失败）**：已取回正确来源却答错；
    4. **Comprehension failure（理解失败）**：把金标准来源页直接注入上下文且关闭搜索后仍答错。
  - 技术流程：**两步诊断**——第一步"源注入消融"（source-injection ablation），若注入权威来源后仍错则归为理解失败；第二步"检索轨迹分析"（trace analysis），检查原始回答中是否搜索、是否取回金标准 URL，进而区分前三种模式。该方法无需额外模型调用，只需回放已记录的搜索轨迹。

- **评测指标（除准确率外）**
  - **搜索调用率**：在全部问题中至少调用一次搜索的比例（按辖区层级分别报告）；
  - **选择性不搜索准确率**（Selective No-Search Accuracy）及 Δskip 指标：衡量模型"跳过搜索"策略的校准度（不搜时答对率减去强制关闭搜索时全基准准确率）；
  - **权威命中率（meanAHR）**：回答中来自权威政府域名的引用 URL 占比，按辖区层级定义权威域集合，并附 95% 自助法置信区间。

### 三、实验设计

- **评测数据集/基准**：CIVI 基准本身（4,097 题，36 分层单元），覆盖加、美、澳三国及 COFOG 四大职能；另设 5 名人类受试者、每人 150 道分层抽样题（允许自由使用搜索引擎且不限时），作为人类基线（均值 92.67%，标准差 3.1 个百分点）。
- **被评测模型**：共 10 个前沿 LLM。
  - 闭源系：Google（Gemini 3.1 Pro、Gemini 3 Flash）；OpenAI（GPT-5.4、GPT-5.2 Chat、GPT-5.4-mini）；Anthropic（Claude Sonnet 4.6、Claude Haiku 4.5）。
  - 开源/开放权重系：DeepSeek-V3.2、Mistral Large 3、Qwen3.6-Plus。
- **统一搜索环境**：所有模型都经由 Exa 搜索引擎执行代理式搜索（每模型至多 3 轮搜索、累计最多取回 10 个 URL）；全部经由 OpenRouter API、温度 0 调用。
- **对比条件/基线**：
  - 主条件：代理式搜索（agentic search）；
  - 对照条件 1：搜索禁用（closed-book）；对照条件 2：单次检索 RAG（top-3 结果注入上下文）；
  - 与人类基线的匹配子集对比（150 题）；
  - 运行稳定性：410 题分层子集上重复 3 次；
  - 国家维度独立汇总；全量错误经 ARISE 归因分解。
- **答案提取**：用 Gemini 2.5 Flash 从最终回答抽取选项字母并与标准答案精确集合匹配（抽样 100 题人工校验全部正确）。

### 四、资源与算力

- 论文未报告任何 GPU 型号、数量或训练时长等细节，也未进行任何模型训练或微调。
- 所有实验均为 API 推理调用（OpenRouter，温度 0），QA 对生成使用 Claude Opus 4.6，答案抽取使用 Gemini 2.5 Flash；搜索统一通过 Exa API。若需复现成本估算，需自行按 API 调用量推算。

### 五、实验数量与充分性

- **实验量较为充足**：核心评测为 10 模型 × 4,097 题；另有 150 题人机对比、410 题 × 3 次稳定性验证、搜索禁用与单次 RAG 两种对照条件、按辖区/国家/模型家族的多种切片分析，以及 ARISE 对全体错误的归因。
- **稳定性与公平性**：三次运行中各模型极差均值约 2.2 个百分点，最大 3.4 个百分点，除 Gemini 3 Flash 与 Qwen3.6-Plus 互换名次（置信区间重叠）外排名基本稳定；所有模型共享同一搜索基座与预算，具有可比性。
- **略显不足**：人类基线仅 5 名志愿者；评测限于英文、多项选择格式（未覆盖开放生成式回答的评测）；消融层面只做了"是否搜索/是否单次检索"两种对比，未对不同搜索轮数、检索条数做系统消融。

### 六、主要结论与发现

1. **全部模型低于人类基线**：最强模型 Gemini 3.1 Pro 准确率 78.28%，比人类基线（92.67%）低 14.4 个百分点（匹配子集上低 15.3 个百分点）；最弱的 Claude Haiku 4.5 仅 45.45%。
2. **表现随辖区层级下移而递减**：平均准确率从联邦 65.6% → 州/省 62.6% → 地方/市政 56.7%（差距 8.9 个百分点）；模型间差距在地方层面拉大至 38.1 个百分点，说明越基层的权威信息在训练语料中越稀缺。
3. **代理式搜索具有显著增益**：较搜索禁用平均提高 10.0 个百分点、较单次 RAG 提高 9.1 个百分点，但不同模型的默认搜索调用率差异悬殊（13.5% 到 ≥99%）；多数模型能"选择性跳过搜索"（Δskip 为正），Gemini 3 Flash 为唯一负值。
4. **权威来源引用呈现明显两档分化**：GPT 家族占据 top 位置（meanAHR 0.69–0.71），且与模型能力排序无显著相关（Elo 排名 ρ=0.27），说明"引用权威性"是独立于通用能力的一维。
5. **失败主因在检索环节而非知识**：ARISE 归因显示平均 72.1% 的错误来自检索相关问题（34.5% 搜索跳过 + 37.6% 检索失败）；即使在注入金标准来源页后仍有 2.3%–4.8% 的错误保持（理解失败），体现出公共部门制度性语言的推理难度。

### 七、优点与亮点

- **首创性**：首个同时覆盖"跨国家 × 跨辖区 × 国际职能分类标准"的公民信息问答基准；构建框架国别无关，易于扩展。
- **诊断设计精巧**：ARISE 将错误归因与干预目标一一映射（如检索失败对应查询改写/权威源索引优化），采用源注入消融 + 轨迹回放，无需额外模型调用，且四类模式完备互斥。
- **部署生态真实**：评测采用真实代理式搜索（而非闭卷或预给上下文），与人们实际使用 AI 助手的方式一致；统一搜索基座保证了跨模型可比性。
- **指标维度丰富**：除准确率外引入搜索调用率、不搜索策略校准（Δskip）、权威命中率（meanAHR），能独立刻画信息获取行为，并设置真实人类基线作参照。

### 八、不足与局限

- **地域与语言局限**：仅覆盖三个英语主导的联邦制民主国家（英文材料；加拿大虽双语但未含法语），不涉及其他治理传统、法律体系或非英语环境，外部推广需谨慎。
- **单一搜索基座**：全部模型经 Exa 路由，可能削弱在各自原生搜索基础设施下的生态效度（作者已承认，并建议未来用原生工具互补评测）。
- **人类基线样本小**：仅 5 名志愿者、150 题，代表性有限；受试者来自作者社交网络且无报酬，存在抽样偏差可能。
- **格式限制**：采用固定 8 选项"选择所有正确项"格式，难以反映真实开放问答中模型自行组织表述的能力；部分正确回答会被判错（符合公共部门安全要求，但严格性偏高）。
- **类别均衡问题**：各单元问题数不均衡（75–146 题区间浮动），可能对按单元聚合的结果产生轻微影响。
- **未报告算力/成本细节**及自动化提取答案的规模化误差分析（仅抽检 100 题人工验证），复现成本难以预判。
