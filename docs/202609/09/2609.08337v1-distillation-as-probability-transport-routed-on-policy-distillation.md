## 摘要
同策略蒸馏（OPD）在学生生成的轨迹上传递教师知识，但高效的采样目标将教师分布简化为对单个标记的标量信用。这类信用指示某个标记应增加还是减少概率，但未指明相应的重分布。我们将OPD重新表述为教师引导的概率传输，并提出RouteOPD（路由式同策略蒸馏），它将师生局部分歧分解为学生冗余源和教师不足目的地，并将它们耦合成明确的传输对。RouteOPD将成对对数几率优化至从有界教师势获得的共同可实现目标，同时使传输预算适应教师需求的集中程度。该表述在单一传输算子中将更新引导至教师偏好的目的地并控制其幅度。在四个师生设置和四个数学推理基准上的实验表明，RouteOPD持续优于采样的反向KL OPD，且改进伴随更高的路由保真度和更低的背景泄漏。这些结果证明了在同策略蒸馏中显式建模概率传输的有效性。

## Abstract
On-policy distillation (OPD) transfers teacher knowledge on student-generated trajectories, but efficient sampled objectives reduce the teacher distribution to scalar credit on individual tokens. Such credit indicates whether a token should gain or lose probability, yet leaves the corresponding redistribution unspecified. We recast OPD as teacher-guided probability transport and propose RouteOPD (Routed On-Policy Distillation), which decomposes local teacher--student disagreement into student-excess sources and teacher-deficit destinations and couples them into explicit transport pairs. RouteOPD optimizes pairwise log-odds toward jointly realizable targets obtained from a bounded teacher potential, while adapting the transport budget to the concentration of teacher demand. This formulation directs updates toward teacher-preferred destinations and controls their magnitude within a single transport operator. Experiments across four teacher--student settings and four mathematical-reasoning benchmarks demonstrate that RouteOPD consistently outperforms sampled reverse-KL OPD, with improvements accompanied by higher routing fidelity and lower background leakage. These results demonstrate the effectiveness of explicitly modeling probability transport in on-policy distillation.

## 一、核心问题与整体含义（研究动机与背景）

- **研究动机**：同策略蒸馏（On-policy Distillation, OPD）是一种有效的语言模型后训练范式，学生模型在自己的生成轨迹上向教师模型学习。主流的采样式 OPD 虽然效率高，但其高效目标存在一个结构性缺陷：它在每个访问状态下仅将教师分布浓缩为单个 token 上的**标量信用**。

- **核心问题**：论文指出，标量信用只能告诉模型某个被采样的 token 应被鼓励还是抑制（以及强度如何），但**无法指明概率质量应当重新分配到哪个 token**。然而，归一化的分类策略无法孤立地改变一个概率——抑制一个 token 会释放概率质量，这些质量必须被分配到别处；增加一个 token 也必须从其他候选中抽取质量。因此，标量信用不是一个"传输计划"，它最多只确定了一次重分布的一侧，忽略了教师分布中同时存在的另一侧证据。

- **关键危害**：未被指定的重分布不会保持中性，而是由**学生 softmax 的几何特性隐式填充**。具体地，对于 logits \(z\) 和被采样的 token \(a\)，有 \(\nabla_z \log \pi_\theta(a|s) = e_a - \pi_\theta(\cdot|s)\)。负信用抑制 \(a\) 的同时，会对所有非源 token 产生正梯度的背景更新，权重正比于学生当前的概率。这意味着：
  - 重分布方向偏向学生已有的常见 token，而非教师真正偏好的 token；
  - 每个随机更新的实现都委托给学生自身的几何结构，造成更新目标的结构性欠定（under-specification）。

- **论文定位**：本文不在"何处/何时蒸馏"（数据级选择）或"如何稳定反馈"（目标函数改造）层面切入，而是回答一个正交问题——**在固定被访问状态下，被纠正的概率质量应该流向哪个词汇候选项**。该工作将这一行动空间内的概率重分配问题形式化为概率传输（probability transport），因此属于对 OPD 认知的一个前移：从隐式重分配推进到显式、教师引导的传输。

## 二、方法论

### 核心思想
RouteOPD 将教师-学生分歧视为一个局部守恒问题：从学生冗余（excess）token 上移除的概率应当被重新分配给教师不足（deficit）token。在每个学生访问的状态 \(s_t\) 上，RouteOPD 构造师生 top-\(k\) 令牌的离线并集，将归一化分歧分解为源边缘分布与目的地边缘分布，再以独立积耦合（最大熵耦合）采样显式的源→目的地"路线"，从而同时确定重分配的**目的地**与**幅度**。

### 关键技术细节

1. **构建稀疏共享支撑集**：对每个状态，取学生（行为策略）和教师分布的 top-\(k\) 并集作为离散支撑集 \(U_t\)，并按各自在该支撑集上的质量重新归一化得到 \(p_S\) 与 \(p_T\)（全部采用 stop-gradient 分离，不参与更新求导）。

2. **分解过剩与不足**：定义 excess \(e_t(a) = [p_S(a) - p_T(a)]_+\) 和 deficit \(d_t(b) = [p_T(b) - p_S(b)]_+\)。两者的总质量相等，即 \(M_t = \sum e_t = \sum d_t = \mathrm{TV}(p_S, p_T)\)（总变差距离），称为可输运质量。低于阈值 \(\delta_M\) 的状态不产生路由损失。

3. **独立积耦合与路线采样**：归一化 \(e_t\) 与 \(d_t\) 为边缘分布 \(q^-_t\) 与 \(q^+_t\)，采用积耦合 \(\Gamma_t(a,b) = M_t q^-_t(a) q^+_t(b)\) 采样 \(m\) 条源-目的地路线。该积耦合是固定边缘下最大熵耦合，无需求解密集的 \(k^2\) 传输表，只需 \(O(k+m)\) 的开销。

4. **显式路径的成对目标（直接 logit 局部性）**：对路线 \((a, b)\)，定义当前学生相对旧策略的**成对 log-odds 变化量**：
   \[
   \Delta_t(a,b) = [\log \pi_\theta(b) - \log \pi_\theta(a)] - [\log \pi_{\text{old}}(b) - \log \pi_{\text{old}}(a)]
   \]
   关键梯度恒等式为 \(\nabla_z[\log \pi_\theta(b) - \log \pi_\theta(a)] = e_b - e_a\)。对数分区函数被抵消，**未参与路线的 token 得到零直接梯度**，更新被精准限定在源（被压低）与目的地（被抬高）两端。

5. **共享有界教师势（联合可实现目标）**：为规避独立裁剪每条路线造成的循环不一致问题——例如四元环恒等式被违背时不存在任何统一的 token 势——RouteOPD 将所有成对目标定义为**同一个有界势函数在两端点的差**：
   \[
   \phi_B(x) = \frac{B}{2}\tanh\left(\frac{2x}{B}\right),\quad \hat{D}_t(a,b) = \phi_{B_t}(g_t(b)) - \phi_{B_t}(g_t(a))
   \]
   其中教师 token 势 \(g_t(v) = \log\max\{p_T(v), \delta_p\} - \log\max\{p_S(v), \delta_p\}\)。同一势的差值结构天然满足循环一致性，其更新可通过一个 token 级平移 \(z_v \leftarrow z_v + \phi_{B_t}(g_t(v))\) 一次性对全部路线联合实现。单调性保证目标有界（\(0 \le \hat{D} < B_t\)）。

6. **需求自适应预算**：以归一化赫芬达尔指数衡量教师 deficit 需求的集中程度 \(c_t \in [0,1]\)，将预算按 \(B_t = B_{\min} + (B_{\max}-B_{\min})c_t\) 线性插值。集中度越高（教师需求越集中于少数清晰目的地），给该状态的修正预算越大；需求弥散时则保持保守。

7. **损失形式与 Huber 过渡**：RouteOPD 的 token 级损失为
   \[
   \mathcal{L}_t^{\text{RouteOPD}} = M_t \, \mathbb{E}_{(a,b)\sim q^-_t \times q^+_t}\left[h_\kappa(\Delta_t(a,b) - \hat{D}_t(a,b))\right]
   \]
   总传输质量 \(M_t\) 提供自然的路由损失加权，Huber 函数控制过渡平滑性，并防止过大的单步成对差值产生不稳定梯度。

8. **算法流程**（每个学生访问状态）：
   - 形成 \(U_t\)（师生 top-\(k\) 并集），构建去附带的 \(p_S, p_T\)；
   - 计算 \(e_t, d_t, M_t\)；若位置无效或 \(M_t \le \delta_M\) 则返回零损失；
   - 归一化得到 \(q^-_t, q^+_t\)，采样 \(m\) 对独立路线；
   - 计算教师势 \(g_t\)、集中度 \(c_t\)、预算 \(B_t\)；
   - 经有界 tanh 势得到成对目标 \(\hat{D}_t\)；
   - 用当前/旧策略的 log 概率差 \(\Delta_t\) 与目标差构造 Huber 损失返回。

## 六、主要结论与发现

- **发现 1：RouteOPD 在每组师生设置上都有提升**——相对于采样-RKL 平均提高 2.70 分（各设置 2.19–3.61 分），相对全词表 RKL 提高 1.24 分，相对固定中预算路由提高 1.20 分；配对 bootstrap 区间全部显著。强学生（OpenMath-Nemotron）从 79.73 提升至 83.34，说明不是弱学生走捷径的假象。
- **发现 2：目的地身份和双侧更新都重要**——教师-deficit 目的地 + 成对更新（64.43）优于秩/频目标（63.72）、随机背景（62.72）、源单侧（63.55）与目的地单侧（63.84）更新。教师确定的不只是纠正符号，还有重分配的目的地。
- **发现 3：共享势能保证目标联合可实现**——独立边裁剪产生 27.6% 的四元环违背，共享势将其降为 0；目标 MAE 从 0.091 降至 0.067（固定预算）或 0.052（自适应），有界完成率从 76.4% → 83.2%（固定）→ 88.1%（自适应）。
- **发现 4：自适应预算能奏效的场合是被教师"需求集中度"所预言的**——在与固定预算差值的四档分层中，差值为 −0.10、+0.40、+1.30、+2.70，随集中度单调递增。不仅整体提升，而且提升模式和机制预测一致。
- **发现 5：性能提升伴随强烈的路由信号**——路由保真度从采样-RKL 的 35.4% 拉升至 RouteOPD 的 90.4%；全词表背景泄漏从 68.3% 降至 13.8%。该效果在 1,024 状态库中具有广谱性（中位

该效果在 1,024 状态库中具有广谱性（中位路由保真度接近 90%），且在四分之一分位数处仍显著高于采样式基线，说明不是少数特殊状态拉高的平均值；同时训练初期即可快速进入高保真区间，并随训练推进稳定保持，与外部精度曲线呈时间同步演变。

- **发现 6：机制层面的额外收益**——即使不做任何 OPD（理想 logit 干预探测），RouteOPD 的目标也能给出更接近"正确"的梯度方向；在与优化器交互后（AdamW 动量干扰、保存优化器重放、SGD 复测），其目标比采样式 RKL 和高秩替代目标都更稳健地转换为最终概率变化，目标失配带来的欠冲与过冲均更小。

- **发现 7：开销可控且实用**——RouteOPD 的每步端到端耗时仅比采样式 OPD 高约 2.5%（189.2 vs 184.6 秒/步），峰值显存与吞吐基本持平；显式路由构建只贡献不足 2% 的额外每步开销，而全词表 RKL 变体则要面对显著更重的计算与通信负担。

## 七、局限性与未来工作

- **覆盖范围**：论文仅在数学推理数据集（DAPO-Math-17K）与数学基准（MATH500、AMC23、AIME24/25）上验证，未涉足代码生成、通用指令跟随或对话场景；数学领域对中间推理步骤的客观可验证性较高，但其他领域中"目的地正确性"的衡量可能更困难或更需要代价函数参与。

- **支持集构建以 top-k 并集为基础**：默认 \(k=32\) 在词表规模 20 万～30 万的情况下仍是极稀疏的支撑，模型对低概率长尾 token 的意图无法被表达。虽然作者通过 \(k\in\{16,32,64\}\) 与全词表对照证明了合理范围内的鲁棒性，但 k 上限仍受传输路线数量与内存限制，更深层的问题——即"正确的目的地若不在 k 内则该状态的路由丧失意义"——未被彻底解决。

- **自适应预算规则仍偏启发式**：论文选择以教师 deficit 需求的赫芬达尔集中度 \(c_t\) 线性插值得到预算 \(B_t\) 并证明了其分层有效性，但这是一个相对简单的函数形式；需求集中度低的状态也可能出现高价值目的地只是被分散于多个中等概率候选之中的情况，此时一刀切地调低预算可能过于保守。作者没有尝试对预算进行元学习或在线优化。

- **最大熵耦合并非真正的最优传输**：RouteOPD 取积耦合作为独立采样路线的方式，优先保证了熵最大与高效采样，但它并不对应最小传输代价。真实教师概率质量在词汇-位置联合空间中的最佳"搬运路线"可能因任务而异，而论文默认使用均匀代价；在代价随 token 语义相似度变化时，积耦合未必是最优选择。

- **衡量口径仍以校准精度为主**：虽然论文附加了语法、错误类别分析（由 LLM 法官对 1,920 条响应进行双盲两轮标注，一致性 92.4%），但对生成质量的其他维度（灵活性、多样性、对提示条件的从属性）评估有限；路径保真度高是否等同于学到更稳健的推理能力，还需要更长程的泛化测试（如分布外基准）来确证。

- **未来方向**：将路由机制延伸到句子块或程序级结构（把"token 势"推广为"结构单元势"）；用真实语义代价训练耦合（例如以 embedding 余弦距离近似 token 语义代价）；把预算控制器从启发式升级为可学习的元策略；在更多样化的教师与学生规模组合上检验标量→向量→结构化传输的一般性。

## 八、总结

RouteOPD 将同策略蒸馏中被忽视的概率重分配问题显式化：与其让未指定的概率质量被学生自身的几何结构悄悄填充，不如在每个被访问状态下把师生分歧拆解为源边缘与目的地边缘，用最大熵积耦合采样显式传输路线，将每条路线上的修正归结为共享有界教师势之差。这个看似简单的改变——让"被压下的概率该流向哪里"由教师证据而非学生先验决定——带来了 16 组主实验中的一致提升（相对采样 RKL 平均 +2.70 分），并通过联锁消融、机制诊断与成本分析证明了提升的来源确实是"传输方向被正确指定"而不是额外的正则化或优化副作用。该工作的价值不仅在于一个新蒸馏损失，更在于为 OPD 研究提供了一个新的分解轴：在数据选择、损失稳定、预算自适应之外，"目的地选择"同样是一个不可省略的自由度。
