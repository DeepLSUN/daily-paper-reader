## 摘要
现有的监督微调范式，尤其是全参数微调，常常受到参数冗余、数据质量不一致和灾难性遗忘的困扰，而当前方法通常孤立地解决这些问题，缺乏统一的优化信号来衔接数据选择、参数更新和知识保留。为解决这一问题，我们提出了神经引导微调（NGFT），一个利用神经元激活模式作为通用代理来统一微调生命周期的整体框架。NGFT通过三种协同机制运作：(1) 自适应任务特定神经元选择，在单次前向传播中识别关键神经元，以集中更新并减少冗余；(2) 基于激活的数据选择，优先选择信息密集的样本，最大化对关键神经元的贡献；(3) 神经元激活对齐，一种新颖的损失函数，将激活锚定到预训练状态，深化表示学习并保留通用知识。在三个模型上的实验结果表明，在领域特定和通用基准上，NGFT在效率和性能上均显著优于现有主流微调方法，同时有效缓解了灾难性遗忘。

## Abstract
Existing Supervised Fine-Tuning paradigms, particularly Full Parameter Fine-Tuning are often plagued by parameter redundancy, inconsistent data quality, and catastrophic forgetting, which current methods typically address in isolation and lack a unified optimization signal to bridge data selection, parameter updates, and knowledge preservation. To address this, we propose Neuron-Guided Fine-Tuning (NGFT), a holistic framework that leverages neuron activation patterns as a universal proxy to unify the fine-tuning lifecycle. NGFT operates via three synergistic mechanisms: (1) Adaptive Task-Specific Neuron Selection, which identifies essential neurons in a single forward pass to concentrate updates and reduce redundancy; (2) Activation-Based Data Selection, which prioritizes information-dense samples that maximize contribution to key neurons; and (3) Neuron Activation Alignment, a novel loss function that anchors activations to pre-trained states, deepening representation learning and preserving general knowledge. Experimental results across three models across both domain-specific and general benchmarks demonstrate that NGFT significantly outperforms existing mainstream fine-tuning methods in both efficiency and performance, while effectively mitigating catastrophic forgetting.

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

论文提出 **NGFT（Neuron-Guided Fine-Tuning）** 框架，由三个协同模块组成，并以图 1 流程示意。整体思想：先识别任务关键神经元，再据其激活强度筛选高质量数据，最后用“神经元对齐损失”进行深度表示对齐。

- **(1) 自适应任务特定神经元选择（Adaptive Task-Specific Neuron Selection）**
  - 对每层 FFN（含 Gate/Up/Down 投影），把每个隐神经元视为“神经元”。
  - 使用每层**输入的最后 token** 的激活作为聚合特征。
  - 采用两个约束识别 Task-Knowledge Neurons：
    - **激活状态**：样本输入下激活值 > 0；
    - **分布稳定性**：通过变异系数（Coefficient of Variation, CV）过滤噪声神经元。
  - 公式概括：
    - 均值：μ(l,j) = (1/m)Σ h(i)(l,j)
    - 标准差：σ(l,j)
    - 变异系数：R(l,j) = σ(l,j)/(μ(l,j)+ε)
    - 满足 R(l,j) < τ 且 h(i)(l,j) > 0 的神经元组成关键集合 N_k。
  - 关键点：**自适应确定稀疏率**，不用固定比例，能根据任务难度/领域差异动态调整需要更新的神经元规模。
  - 微调时构造二进制梯度掩码 M，只对关键神经元反向传播梯度 ∇θL_mask = ∇θL ⊙ M，冻结非关键神经元，实现结构化稀疏更新。

- **(2) 基于激活的数据选择（Activation-Based Data Selection）**
  - 对每个指令样本，计算它在关键神经元上的平均激活值：S_i = (1/|N_k|) Σ A(i)(l,j)。
  - 不简单取激活值最高的样本，而是基于**中位数中心的区间选择**，以平衡“充分性”与“最小性”（信息瓶颈观点）：既保留足够任务信息，又滤除冗余/噪声。
  - 将所有样本按 S_i 排序后，仅选择位于中位数附近、占样本量比例 ρ 的样本子集 D_s：
    - D_s = { x_i | |rank_i - m/2| ≤ ρ·m/2 }
  - 该策略既能涵盖多子类的核心样本，又避免极端激活值造成的偏斜。

- **(3) 神经元激活对齐损失（Neuron Alignment Loss）**
  - 在做完数据筛选后，先计算“神经元激活锚点” C_pred：在选出的数据子集上，对预训练模型提取所有 FFN 层激活向量并取均值。
  - 微调过程中增加对齐目标，最小化实时激活与该锚点的均方误差：L_neu = ||ω(i)_train − C_pred||²。
  - 采用**分阶段损失加权**：在交叉熵损失 L_ce 下降至阈值 γ 之前只使用 L_ce；当 L_ce < γ 时加入对齐损失：
    - L_total = L_ce + I(L_ce < γ)·L_neu
  - 设计动机：先完成粗粒度的语义/输出层学习，而后在神经层面（后期梯度弱）引入锚定对齐，既深化任务表示学习，又限制非关键神经元漂移，缓解灾难性遗忘。

整体流程可概括为：
1. 对原始指令数据集做单次前向激活统计，识别任务相关知识神经元（基于变异系数阈值 τ）；
2. 用这些神经元的激活强度挑选中位数邻域内高信息密度子集；
3. 使用该子集预计算激活锚点，再结合梯度掩码仅更新关键神经元，并在 CE 损失稳定后加入神经元对齐损失联合优化。

## 6. 论文的主要结论与发现

- **领域任务性能显著提升**：在 Qwen2.5-7B、Llama3.1-8B、Mistral-7B 上，NGFT 相比 FPFT 在全量数据上平均提升 2.14/2.11/2.80 分；相比 Strong Baseline 平均提升 1.37/1.89/2.21 分。
- **低资源数据场景优势尤为突出**：例如在 Mistral-7B 上的 GSM8K 任务，1%/5%/10% 数据下相比 FPFT 分别高出 3.72/7.66/12.97 分，显示其能从小样本中提取有效特征。
- **显著缓解灾难性遗忘**：
  - 在许多配置下，NGFT 的 CF 得分大幅优于 FPFT，甚至接近或超过未微调的 zero-shot 水平。
  - 例如 Qwen2.5-7B 使用 BioInstruct 的 5%/10% 数据时，CF 得分为 70.31/70.46，高于 zero-shot 的 68.62，出现正迁移。
- **各模块均有效**：
  - 神经元选择的“自适应比例”优于固定比例的方法；NCFT 利用 NGFT 推导出的比例也能获得增益。
  - 基于关键神经元激活的数据选择优于全 FFN 神经元，证明关键神经元子空间对数据评估更有判别力。
  - 神经元对齐损失能在不牺牲领域性能的前提下大幅提升抗遗忘能力，它有效限制了非关键神经元的漂移。
- **效率优势**：在只花约 20% 的 FPFT 训练时间时即可达到与 FPFT 相当甚至略优的性能；若花约 11.3% 额外时间，则能稳定超过 FPFT 数个百分点。时间-性能曲线提供灵活配置。

## 7. 优点

- **统一性**：以“神经元激活模式”为桥梁，将数据选择、参数更新、知识保留三件事放在同一个可解释的代理空间解决，避免了各方法互相脱节的问题。
- **低开销数据选择**：只需单次前向传播，无需外部 LLM 打分、梯度计算或辅助模型，比 Nuggets/Data Whisperer 等方法省时一个量级以上。
- **自适应稀疏**：不事先固定更新神经元比例，而是根据任务数据激活统计动态求出阈值，更好地适配不同领域和模型；且验证了该比例可迁移到其他基线。
- **创新的损失与分段策略**：将“激活锚点”用于表征对齐，且在 CE 收敛后才介入，形成从粗到细的优化过程，既能继续提升任务精度又能抑制灾难遗忘。
- **实验扎实**：覆盖多个模型家族、参数规模、领域任务、数据比例、消融与时间复杂度分析，并做了模块化验证，论证充分。
- **实际价值高**：为计算受限环境或追求高性能上限的用户提供了模块化取舍方案，可直接作为开源训练方案使用。

## 8. 不足与局限

- **适用性受限**：方法需要访问模型权重和内部激活状态，对 GPT-5 等闭源黑盒 LLM 不可用，只能用于开源权重模型。
- **计算成本未完全透明**：绝对 GPU 时长没有公开，读者难以精确估算总耗能；且全量数据+神经元对齐损失的训练时间是 FPFT 的近 2 倍，并非“零成本提升”。
- **模态与任务覆盖有限**：实验主要集中在数学推理、生物医学指令、对话摘要三个 NLP 领域，未覆盖多模态、代码、Agent 等新型对齐场景。
- **不同数据集训练步数固定为 4**：虽然确保公平，但可能并非每个数据规模下最优停止点，无法完全排除“过/欠拟合干扰结果”的可能。
- **对齐损失额外开销来源**：由于需自回归生成以采集训练样本激活，全数据训练时开销显著；论文主要依赖数据筛选来补偿这部分开销，若用户不用数据筛选则成本较高。
- **内部机制解释仍有一定黑盒成分**：虽然用变异系数锚定“任务知识神经元”有理论支撑，但对“为什么这些神经元更符合任务语义”的因果解释较弱，主要依赖统计稳定性。
- **对超参数敏感**：阈值 τ（选择 0.10）和 CE 介入时机 γ（选择 0.04）存在模型/任务差异，虽然文中给推荐范围，实际部署仍需针对性调参。
