## 摘要
智能体式网络搜索可以检索相关信息，但并不确认检索到的内容确实支持答案中使用的论断。现有智能体通常将搜索和证据记录保存在线性交互轨迹中，主要针对最终答案的正确性进行优化，而对中间依据的监督有限。我们提出EviGraph，一种深度搜索框架，它将搜索执行与证据记录分离，同时为可训练角色使用共享策略。执行器规划简洁的查询，冻结的证据验证器检查来源页面并返回带有明确极性的逐字证据项，策略将这些证据项映射为添加/支持图请求，再由确定性结构验证器进行检查。生成的图既充当持久工作记忆，又作为密集过程奖励的来源，使强化学习能够直接监督证据构建，而不仅仅是最终答案。在BrowseComp-Plus上，使用Qwen3-8B的EviGraph智能体在匹配的交互预算下取得了35.9%的准确率，相比之下，没有强化学习的相同双角色架构为26.9%，单体智能体为2.7%，同时每个回合生成的令牌更少。在BrowseComp、GAIA和XBench上的一致提升表明，显式地结构化和奖励证据记录改善了智能体搜索。

## Abstract
Agentic Web search can retrieve relevant information without establishing that the retrieved content actually supports the claims used in an answer. Existing agents typically keep search and evidence recording in a linear interaction trace and optimize primarily for final-answer correctness, providing limited supervision for intermediate grounding. We present EviGraph, a deep-search framework that separates search execution from evidence recording while using a shared policy for the trainable roles. An executor plans concise queries, a frozen evidence verifier inspects source pages and returns verbatim evidence items with an explicit polarity, and the policy maps those items to add/support graph requests that are checked by a deterministic structural validator. The resulting graph serves both as persistent working memory and as a source of dense process rewards, enabling reinforcement learning to directly supervise evidence construction rather than only the final answer. On BrowseComp-Plus, a Qwen3-8B EviGraph agent achieves 35.9% accuracy under a matched interaction budget, compared with 26.9% for the same dual-role architecture without reinforcement learning and 2.7% for a monolithic agent, while generating fewer tokens per rollout. Consistent gains on BrowseComp, GAIA, and XBench indicate that explicitly structuring and rewarding evidence recording improves agentic search

## 1. 论文的核心问题与整体含义

**研究动机与背景：**

- 现有智能体式网络搜索系统虽然能检索相关信息，但**未能确认检索到的内容确实支持答案中的论断**。
- 当前主流方法（如 Search-R1、R1-Searcher 等）通常将搜索与证据记录线性混合在交互轨迹中，仅针对**最终答案正确性**进行优化，对**中间证据构建过程缺乏监督**。
- 论文指出三个关键缺陷：
  - **检索相关性 ≠ 证据支持**：页面可能提及正确实体，但指向不同时间、地点或数值；
  - **答案级奖励会鼓励捷径行为**：允许在证据缺失、矛盾或未支撑的情况下得出正确答案；
  - **引用无法揭示哪段来源文本支持哪个具体主张**。
- 多约束网络研究任务（如时间、地点、职业等多重可独立搜索的约束同时满足）加剧了这一问题——检索到相关页面并不能证明候选答案满足所有约束。

**整体含义：** 论文主张将智能体搜索重新定义为**证据构建**（evidence construction）过程——显式构建一个类型化、基于逐字文本锚定的"主张—证据"有向无环图（DAG），并以此作为工作记忆和过程奖励来源。

## 2. 论文提出的方法论

**核心思想：**

- 将智能体搜索分解为两个可训练角色（共享同一策略模型），即**执行器（Executor）**与**证据提议（Evidence-Proposal）**角色，外加一个**冻结的证据验证器（Verifier）**和一个**确定性结构验证器（Structural Validator）**。
- 核心创新：**检索与证据记录在流程上分离**，但可训练策略共享；证据图同时作为**持久工作记忆**和**密集过程奖励**的来源。

**证据图结构（Schema）：**

- 四种节点：文档（Document）、逐字片段（Span）、原子主张（Atomic Claim，即候选者-约束对）、答案候选（Answer Candidate）。
- 两种边：CONTAINS（文档包含片段）、Evidence 边（片段链接到主张，极性为 support/conflict）。
- 模态无关：多模态（图像、OCR）内容转换为文本描述后按相同方式进入图。

**关键流程（Algorithm 1）：**

1. 系统初始化空图和待满足的约束集合；
2. 执行器基于图快照规划查询（SEARCH）或决定回答（ANSWER）；
3. 搜索结果交给**冻结验证器**检测，返回带极性的逐字证据项（含来源、片段、约束标签、相关性和极性）；
4. 策略的证据提议角色将证据项映射为 ADD（新增候选）或 SUPPORT（追加支撑）图请求；
5. 结构化验证器检查请求合法性（文本存在、标识符有效、标签有效、极性匹配、无循环、无自支撑、规范签名去重等），合法则提交图更新。

**核心公式（过程奖励）：**

- 候选覆盖率：`c(G) = max_f |T_cov(G,f)| / max(1,|T|)`（仅统计有正极性支持边的约束标签）
- 执行器过程奖励：`r_Em = α·n_m + [γβ·c(G_{m+1}) − β·c(G_m)] − κs`（检索新颖性 + 势能差覆盖塑造 − 搜索成本）
- 证据提议奖励：`r_Pm,j = λv·v_m,j + [γΦ(G_{m,j+1}) − Φ(G_{m,j})]`（接受奖励 + 势能差的策略不变形式）
- 图质量势能：`Φ(G) = λcov·c(G) − λu·U(G) − λo·O(G)`（覆盖率 − 未解决冲突率 − 离题约束惩罚）
- 角色条件化 GRPO 损失函数：执行器和证据提议角色分别计算优势并 clip，共享策略联合优化。

**防止奖励滥用的机制：**

- 规范证据签名去重（重复记录为零奖励）；
- 每个候选-标签-极性三元组的接受奖励设上限；
- 势能差采用策略不变形式（γΦ′−Φ）避免坍缩；
- KL 惩罚防止策略漂移；丢弃非噪声验证器项会触发拒绝惩罚。

## 6. 论文的主要结论与发现

- **同骨干受控对比中**（Qwen3-8B，BrowseComp-Plus）：
  - 单智能体 ReAct 仅 2.7% 准确率（常提前停止搜索，平均 3.7 次搜索）；
  - 双角色无 RL 架构提升至 26.9%（平均 12.9 次搜索）；
  - 双角色 + RL 达到 35.9%（13.2 次搜索），**且生成 token 更少**（1,689 vs 1,878/轮）。
- 表明**9.0 个百分点的 RL 增益不是来自更多检索，而是来自更高质量的搜索与证据记录策略**。
- 跨基准一致提升（BrowseComp 17.8%、GAIA 53.4%、XBench 56.0%），说明方法的泛化性。
- **多模态零样本迁移成功**：Qwen3-VL-8B + EviGraph 无额外微调即达 LiveVQA 78.0%，超过 Gemini-2.5-Pro（76.0%），与 Vision-DeepResearch-30B-A3B（77.6%）基本持平。
- 核心结论：**显式结构化并奖励证据记录，比单纯优化最终答案更能提升智能体搜索的可验证性和效果**。

## 7. 优点

**方法设计的亮点：**

1. **清晰的角色分工**：将搜索、验证、记图分离，隔离了三类失败源（检索失败、记录失败、决策失败），各获得独立的过程信用分配；
2. **过程奖励的直接监督**：将证据图质量（覆盖率、冲突率、离题率）转化为密集过程奖励，使强化学习不只监督最终答案；
3. **防奖励滥用的多重机制**：策略不变势能塑造、规范签名去重、每三元组奖励上限、KL 惩罚等，设计考虑了 RL 训练中常见的 reward hacking 问题；
4. **模态无关的优雅扩展**：将视觉证据转为文本描述，保持图结构、验证器和奖励不变，零样本迁移到多模态搜索；
5. **可审计性**：每条被记录的主张均可溯源至实际观察的逐字文本，结构验证器保证图不变式；
6. **训练效率**：RL 后 token 消耗减少，说明学习到了更简洁的查询和图编辑行为。

**实验设计的优点：**

- 同骨干消融控制了变量（架构 vs. RL 的贡献分离）；
- 同时覆盖固定语料和实时网络场景；
- 使用了多个基准（5 个）交叉验证泛化性。

## 8. 不足与局限

**实验相关局限：**

- **基准性能仍低于最强系统**：论文坦诚指出，Qwen3-8B EviGraph（35.9%）低于 Tongyi DeepResearch（44.5%），定位为"参数高效开源结果"而非 SOTA 主张；
- **统计报告不完整**：除 BrowseComp-Plus 外，其他 benchmark 仅单次评估，无方差信息；
- **对比公平性存疑**：部分基线数据来自不同论文的原始报告，执行协议和工具可能不一致；
- **训练数据单一**：仅基于 Search-R1 的 NQ + HotpotQA，缺乏更多样的科研型或长尾问题训练数据。

**方法层面局限：**

- **验证器本身的可靠性未充分评估**：冻结验证器输出的极性、相关性和逐字片段质量直接影响图质量，但论文未单独评估验证器的错误率及其对最终准确率的影响；
- **扩展性瓶颈**：作者承认大规模约束集合需要候选剪枝、来源去重和层级图摘要，当前方法在约束数量增长时的扩展性有限；
- **"解决"状态缺失**：图本身不标记已解决/已矛盾状态，依赖执行器自行判断——这保留了灵活性但可能带来停止时机的不稳定；
- **终局奖励的局限**：训练期间终局奖励依赖外部裁判模型（DeepSeek-V4-Flash），对无标准答案的实例直接设为零权重，适用场景有限；
- **未见对图结构质量的直接定量评估**（如证据精确率/召回率的度量），主要指标仍是最终答案准确率。

**应用层面局限：**

- 方法依赖"约束标签集合 T"的先验识别，对开放式探索型任务（无预定义约束）的适应能力未验证；
- 多模态迁移虽成功，但仅验证了 8B 规模的 Qwen3-VL 零样本，未测试更大多模态模型或进一步微调的效果。
