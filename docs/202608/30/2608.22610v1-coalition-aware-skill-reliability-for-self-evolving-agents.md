## 摘要
技能是从交互轨迹中提炼的结构化产物，可从技能库中动态复用，已成为使基于大语言模型的自发进化体能够从过往经验中学习的关键机制。然而，现有工作主要关注技能的操作层面，如获取、进化和检索，而一个更根本的可靠性问题仍有待解决：智能体技能库中积累的技能是否真正产生了正向机制性贡献？我们通过跨不同技能库组成和部署领域的系统性技能库审计来探究该问题，并衡量由此引发的智能体行为变化。这些审计揭示了两种反复出现的可靠性缺陷：联盟污染，即技能库层面的收益掩盖了负向联盟级技能贡献；以及跨域效用反转，即源域有益技能在迁移后效果发生反转。这些发现催生了两种可靠性干预措施：技能积累期间的联盟感知技能选择，以及迁移后的无标签技能掩蔽。联盟感知技能选择利用采样的沙普利边际为当前技能库选取更可靠的候选技能；无监督技能掩蔽联盟优化器则掩蔽那些排除后能提升无标签目标域数据检索质量的迁移技能。在 LoCoMo、LongMemEval、HotpotQA 和 ALFWorld 上的智能体实验表明，CASS 与 u-SMCO 相较于强基线方法——基于技能的自发进化智能体，能持续提升任务性能与跨域泛化能力。除准确性外，联盟条件下的可靠性建模降低了对强化学习中噪声奖励波动的敏感性，并揭示了基于孤立性的技能评估的局限性。

## Abstract
Agent skills, structured artifacts distilled from interaction trajectories and dynamically reused from skill banks, have become a central mechanism for enabling large language model (LLM)-based self-evolving agents to learn from past experience. Yet existing work has largely focused on the operational aspects of skills, such as acquisition, evolution, and retrieval, while leaving a more fundamental reliability question unresolved: Do accumulated skills in an agent's skill bank actually make positive mechanistic contributions? We investigate this question through systematic skill-bank audits across alternative bank compositions and deployment domains, measuring the resulting changes in agent behavior. These audits reveal two recurring reliability failures: coalition pollution, where bank-level gains conceal negative coalition-level skill contributions, and cross-domain utility reversal, where source-beneficial skills reverse their effects after transfer. These findings motivate two reliability interventions: coalition-aware skill selection during skill accumulation and label-free skill masking after transfer. Coalition-Aware Skill Selection (CASS) selects more reliable candidate skills for the current bank using sampled Shapley marginals. Unsupervised Skill-Masked Coalition Optimizer (u-SMCO) masks transferred skills whose exclusion improves retrieval quality on unlabeled target-domain data. Agentic experiments on LoCoMo, LongMemEval, HotpotQA, and ALFWorld show that CASS and u-SMCO consistently improve task performance and cross-domain generalization over strong skill-based self-evolving agent baselines. Beyond accuracy, coalition-conditioned reliability modeling reduces sensitivity to noisy outcome-reward fluctuations during reinforcement learning and exposes the limits of isolation-based skill evaluation.

# 论文总结：Coalition-Aware Skill Reliability for Self-Evolving Agents

## 1. 核心问题与研究动机

- **背景**：基于大语言模型（LLM）的自发进化智能体（self-evolving agents）通过从交互轨迹中蒸馏技能（skill），并存入持久化的技能库（skill bank），在推理时检索复用，从而无需更新模型参数即可从经验中学习。现有研究主要关注技能的**获取、演化、检索**等操作层面，以及个体技能的泛化能力，但**未回答一个根本问题**：技能库中积累的技能被调用时，是否真的产生了正向的机制性贡献？
- **核心发现**：论文通过系统性的“技能机制可靠性审计”（Skill Mechanistic Reliability Audit, SMRA），发现技能可靠性**不是技能的内在属性**，而是依赖于技能、周围技能库（联盟）和部署域三者共同决定的**联合属性**。由此识别出两类此前被忽视的可靠性失效：
  - **联盟污染（Coalition Pollution）**：在技能演化阶段，基于银行整体收益的接受门（gate）可能接收贡献约等于零甚至为负的技能，而真正的“功臣”是既有技能。整体增益掩盖了联盟层面的负面贡献。
  - **跨域效用反转（Cross-Domain Utility Reversal）**：在跨域迁移时，源域中有利的技能在目标域中效果反转，甚至损害性能。

## 2. 方法论

### 2.1 审计框架：SMRA（Skill Mechanistic Reliability Audit）
- 采用 Shapley 边际贡献视角：技能视为博弈中的玩家，`V^D(C)` 表示技能联盟 `C` 在领域 `D` 上的下游价值。
- 通过剔除干预（knockout）计算单技能的整库边际贡献：`Δ^D_s(B) = V^D(B) − V^D(B \ {s})`，配对评估保证统计可比性。
- Shapley 值通过对所有子集的加权平均，给出跨联盟组成的组合条件化可靠性画像。

### 2.2 理论动机
- 定理 1（**Outcome-only 不可辨识性**）：只观察 `V(Be)` 和 `V(B̃e+1)` 的端点的门控，无法确定新银行的技能中是否包含负贡献技能。即只要候选库整体收益上升，不能推断每个技能的贡献符号。该限制是**结构性的**而非统计性的。

### 2.3 干预一：CASS（Coalition-Aware Skill Selection）
- **目标**：解决演化阶段的联盟污染。
- **核心思想**：放弃精确的逐技能 Shapley 估值（计算成本过高），改为在候选库上**蒙特卡洛采样有限数量的技能联盟**，计算联盟剔除边际：
  - 每次采样先均匀随机抽取联盟大小 `|S| ~ Unif{1,...,k}`，再均匀抽取该大小的子集；
  - 计算联盟剔除边际：`Δ_S(B) = (V(B) − V(B\S)) / |S|`，将联合损失均摊到成员；
  - 对 `N` 个采样边际取均值得到 `Δ̄_N(B)`；
  - 与在线结果奖励加权融合为排序标量：`σ(B) = Δ̄_N(B) + λ·r_out(B)`（λ=0.2），只保留超过历史最优得分的候选库。

### 2.4 干预二：u-SMCO（Unsupervised Skill-Masked Coalition Optimizer）
- **目标**：解决迁移后的跨域效用反转。
- **核心思想**：在部署阶段，仅使用目标域的**无标签查询**，以检索质量（retrieval quality）作为无监督替代信号，贪心掩蔽负贡献技能。
- **检索质量指标**：`RQ(A) = mean_{q∈Qtgt} mean_{m∈Top(q)} cos(e_q, e_m)`，衡量内存写入技能是否提升了目标查询的语义局部性。
- **算法流程（Algorithm 1）**：
  1. 每次迭代对每个技能计算掩蔽分数 `ψ(s) = RQ(kept) − RQ(kept\{s})`；
  2. 选择分数最低的技能，若低于阈值 `τ` 则掩蔽，否则终止；
  3. 循环直到无技能可掩蔽或只剩一个技能。
- **对比信号失败**：基于智能体自身选择策略熵的信号与基于标签的真实贡献排名反相关（ρ = −0.18），因为它继承了训练时 outcome gate 的偏差。

## 3. 实验设计

### 3.1 基准与数据集

  - LongMemEval（长期交互记忆）
  - HotpotQA（多跳问答，用作跨域迁移目标域 HP-50）
  - ALFWorld（具身交互任务，含 ALF-Seen 和 ALF-Unseen 两个子场景）

- **评估指标**：F1（对话基准）、LLM-as-Judge 分数（L-J）、成功率 SR 和平均交互步数 #Stps（ALFWorld）。

### 3.2 实验分组

- **CASS 专项实验**：12 个候选技能提案中（3 种子 × 4 次门控决策），对比 CASS 与 MemSkill 的接受率；固定 K 值下审计 gate 新增技能的实际贡献（K-controlled ablation）。
- **u-SMCO 专项实验**：对 6 个训练好的技能库（3 个 CASS 库 + 3 个 MemSkill 库）逐一执行掩蔽，报告 HP-50 上的性能变化。

## 6. 主要结论与发现

1. **技能可靠性不是内在属性**：同一技能在不同联盟组成和不同部署域下的贡献符号和幅度会改变。
2. **Outcome-only 门控在结构上失效**：定理 1 证明仅凭银行整体收益无法识别负贡献技能，实际中接受/拒绝的边际与噪声误差相当，而单技能审计分辨率（±0.04）比门控操作的分辨率（0.006–0.02）粗一个数量级。
3. **CASS 有效抑制联盟污染**：12 次提案中 CASS 仅接受 1 个，而 MemSkill 接受 6 个；被 outcome gate 接受的技能整体净贡献为 −1.38 pp（表 3），而 CASS 接受率低是因为被拒绝的技能确实不值得接受。
4. **u-SMCO 能无标签检测跨域反转**：在所有 6 个训练好的银行上都提升了 HP-50 性能，对 MemSkill 银行的提升幅度（平均 7.17 pp）是 CASS 银行（3.59 pp）的两倍，说明 CASS 在源头阻止的污染正是 u-SMCO 事后需要清理的。
5. **检索质量是比策略熵更可靠的无标签信号**：检索质量与标签排名的相关性 ρ = +0.76，策略熵信号为 ρ = −0.18。
6. 联盟条件可靠性建模降低了训练中对噪声结果奖励的敏感性。

## 7. 优点

- **问题新颖且根本**：首次将技能评估从“个体技能”视角转向“联盟级可靠性”，揭示了现有技能生命周期研究忽视的深层次失效模式。
- **理论与实践结合紧密**：定理 1 给出了 outcome-only 门控失效的结构性理论证明，而非仅凭经验观察；SMRA 审计方法有清晰的 Shapley 理论支撑。
- **方法轻量且正交**：CASS 只改动门控标量，u-SMCO 只在部署前运行一次，不增加任何推理时间成本，易于嵌入现有技能进化框架。
- **两个干预互为补充**：CASS 在训练时源头防治，u-SMCO 在部署时兜底清理；u-SMCO 仅用无标签数据，避免了目标域标注的成本。
- **实验严谨**：严格复现基线、匹配协议、3 seeds 均值 ± 标准差、配对审计保证公平性；案例研究直观展示了三类技能（被污染技能、联盟感知技能、效用反转技能）的实际文本。
- **诚实呈现不确定性**：对跨域反转目标端的结论明确标注“方向性反转”而非“显著损害”（95% CI 含零）。

## 8. 不足与局限

- **理论局限**：定理 1 证明了 outcome-only 门控的不可辨识性，但 CASS 的 Shapley 采样估计本身也无精确保证，论文未给出采样数量 N 与估计误差的理论界。
- **跨域实验覆盖有限**：仅将 LoCoMo 作为源域、HotpotQA-50 作为目标域验证了效用反转，未在更多源域-目标域组合（如 LongMemEval→ALFWorld）上验证 u-SMCO 的泛化性。
- **CASS 接受率极低**：12 次提案仅接受 1 个，虽论证了质量，但可能低估了高价值技能的漏筛风险（假阴性）；多次拒绝可能导致技能库停滞更新。
- **u-SMCO 依赖检索质量假设**：核心假设“检索质量提升 → 下游任务效用提升”只在部分任务成立；对于非检索主导型技能（如规划、动作选择类技能），该信号可能失效。
- **成本报告粒度较粗**：提到 8×H20 GPU 和整体 20 小时运行，但未细分不同基准各自的时间、内存占用等。
- **迁移阶段的诊断与实际干预存在张力**：审计表明跨域反转的 95% CI 包含零（方向性证据），但 u-SMCO 仍基于点估计做掩蔽，可能在某些 seed 上误掩蔽中性技能。
