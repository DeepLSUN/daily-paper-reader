## 摘要
多智能体强化学习（MARL）是解决复杂协作任务的强大框架，但它严重依赖于定义良好的全局奖励函数。设计此类奖励具有挑战性，尤其是在具有异构智能体的系统中，单一的标量目标可能无法捕捉多样化的行为。在本文中，我们介绍了多智能体偏好集成学习（MAGPIE），通过智能体特定的偏好建模来应对这些挑战。每个智能体由专门的专家通过偏好信号进行评估，无需全局评估。我们从理论上证明，优化这些去中心化的偏好会收敛到纳什均衡策略。为了将局部偏好整合为连贯的全局目标，我们从偏好数据构建智能体特定的奖励模型，并通过单调聚合机制将其组合。我们进一步证明，优化该聚合奖励模型等同于训练纳什均衡策略。在基准多智能体任务和顺序生产线任务上的大量实验表明，MAGPIE取得了与经过奖励工程设计的基线相当的性能，展示了其在精确奖励工程不可行的情况下促进策略学习的潜力。

## Abstract
Multi-agent reinforcement learning (MARL) is a powerful framework for solving complex collaborative tasks, but it relies heavily on well-defined global reward functions. Designing such rewards is challenging, especially in systems with heterogeneous agents, where a single scalar objective may fail to capture diverse behaviors. In this paper, we introduce Multi-AGent Preference-Integrated lEarning (MAGPIE), which addresses these challenges through agent-specific preference modeling. Each agent is evaluated by a dedicated expert through preference signals, eliminating the need for global evaluation. We theoretically prove that optimizing these decentralized preferences converges to a Nash equilibrium policy. To integrate local preferences into a coherent global objective, we construct agent-specific reward models from preference data and combine them via a monotonic aggregation mechanism. We further prove that optimizing this aggregate reward model is equivalent to training the Nash equilibrium policy. Extensive experiments on benchmark multi-agent tasks and a sequential production line task show that MAGPIE achieves performance comparable to reward-engineered baselines, demonstrating its potential to facilitate policy learning in scenarios where precise reward engineering is impractical.

- **核心问题**：多智能体强化学习（MARL）通常依赖一个精心设计的全局奖励函数来指导协作策略学习。然而，在真实复杂系统中，尤其当智能体具有异构性（不同角色、能力与目标）时，设计这样一个全局奖励函数十分困难甚至不可行：
  - 稀疏奖励难以提供有效学习信号；
  - 稠密奖励设计需要大量领域知识，且容易产生脆弱或次优行为；
  - 许多期望行为（如“流畅协作”“优雅动作”）难以用数学函数显式刻画。
- **研究动机**：偏好反馈（比较两个轨迹片段哪个更好）比显式数值奖励更符合人类直觉，已在单智能体偏好强化学习（PbRL）中取得显著成功。但直接将其扩展到多智能体场景存在三大问题：
  1. **全局评估困难**：人类难以对包含多个异构智能体的联合轨迹做出一致、可靠的全局偏好判断；
  2. **同质性假设**：现有部分方法通过跨智能体比较来评估个体贡献，隐含假设智能体可比较，不适用于异构系统；
  3. **依赖真实奖励**：有些方法仍需要真实奖励作为辅助监督，并未真正摆脱奖励工程。
- **整体含义**：论文提出MAGPIE（Multi-AGent Preference-Integrated lEarning），将复杂的全局评估分解为每个智能体专属的局部偏好评估，并通过理论保证的单调聚合机制整合为全局目标，从而在不需要任何真实奖励的情况下，引导异构多智能体系统收敛到纳什均衡策略。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式与算法流程

### 2.1 核心思想
- 为每个智能体 \(i\) 分配一位专属“教师”（teacher），仅对该智能体的行为提供偏好信号（如“片段A优于片段B”）。
- 利用偏好数据学习每个智能体的局部奖励模型 \(\hat{r}_i(s, A)\)。
- 通过**加性单调聚合**得到全局奖励模型：
  \[
  \hat{r}(s, A) = \sum_{i=1}^{n} \hat{r}_i(s, A)
  \]
- 使用标准MARL算法（论文以QMIX为例）在该全局奖励上训练策略，从而避免任何手工奖励设计。

### 2.2 理论基础与关键命题
- **假设1-2**：每个智能体存在定义良好、满足对称性/一致性/传递性的偏好，且有稳定教师提供反馈。
- **假设3-4**：存在有界真实全局奖励；教师对某智能体策略更新的局部偏好等价于该更新带来全局回报提升。
- **假设5-7**：存在真实的局部潜在奖励函数；全局奖励可表示为局部奖励的单调函数；任一局部改进对其他智能体的负向影响有界（保证局部改进不损害整体）。
- **定理1**：在有限状态/动作空间及理想化条件下，基于局部偏好的迭代更新算法（Algorithm 1）最终收敛到纳什均衡（当片段长度 \(H \to \infty\)）。
- **推论1**：若片段对可区分度足够（回报差有下界δ），则有限片段长度 \(H \ge \log_\gamma(\delta(1-\gamma)/(2r_{\max}))\) 时可保证收敛。
- **引理1与定理2**：若全局奖励为局部奖励的严格单调函数，则局部偏好改进带来全局回报提升；若学习到的局部奖励完美对齐教师偏好，则最大化聚合奖励 \(\sum \hat{r}_i\) 的策略就是真实奖励下的纳什均衡。
- **定理3**：在足够偏好数据下，通过最小化交叉熵损失训练的Bradley-Terry偏好模型可收敛到真实局部奖励（允许仿射变换），并给出有限样本误差界（依赖Rademacher复杂度）。
- **定理4**：有限偏好样本下，最优策略构成真实目标下的ε-纳什均衡，\(\epsilon = \frac{2n\epsilon_r(N)}{1-\gamma}\)，随样本量增大趋于0。
- **附录定理5**：在随机采样（随机逼近）条件下，QMIX式值迭代过程几乎必然收敛到最优Q函数（结合定理4，即收敛到ε-纳什均衡）。

### 2.3 奖励学习与算法细节
- **偏好概率**（Bradley-Terry模型）：
  \[
  P_\psi[\sigma^{(1)} \succ_i \sigma^{(0)}] = \frac{\exp\left(\sum_t \gamma^t \hat{r}_i^\psi(s_t^{(1)}, A_t^{(1)})\right)}{\sum_{j\in\{0,1\}} \exp\left(\sum_t \gamma^t \hat{r}_i^\psi(s_t^{(j)}, A_t^{(j)})\right)}
  \]
- **偏好损失**：交叉熵损失 \(L_i^\text{pref}\)。
- **正则化损失** \(L_i^\text{reg}\)：惩罚“局部偏好的片段但全局聚合回报反而下降”的情况，维护假设7的实际可行性。
- **总损失**：\(L_i = L_i^\text{pref} + \lambda L_i^\text{reg}\)。
- **两种实用技术**：
  - 连续偏好收集（周期性地从当前策略生成的新轨迹中采样偏好）；
  - 经验重标注（更新奖励模型后用新的全局奖励重新标注回放缓冲区中的转移）。
- **算法流程（Algorithm 2，以QMIX为例）**：
  1. 初始化Q网络、混合网络、奖励模型、回放缓冲区与偏好缓冲区；
  2. 每个环境步骤中，智能体由局部Q函数选动作，执行联合动作，用当前 \(\hat{r} = \sum_i \hat{r}_i^\psi\) 计算奖励并存储转移；
  3. 每K个迭代，为每个智能体采样M对片段，查询教师偏好，更新对应奖励模型（最小化 \(L_i\)）；
  4. 更新全局奖励并重标注回放缓冲区；
  5. 用QMIX损失更新Q函数与单调混合网络。

## 6. 论文的主要结论与发现

- MAGPIE仅使用去中心化的、智能体特定的偏好信号，即可取得与真实奖励工程方法（oracle QMIX）相当的性能。
- 理论证明：局部偏好优化可收敛到纳什均衡；加性单调聚合学习到的奖励模型可保障全局最优策略对应真实任务的纳什均衡。
- 在异构智能体（Speaker-Listener、Reference）、扩展规模（3~6个智能体）以及真实工业风格产线任务中均表现稳定。
- 消融实验表明：偏好奖励学习、单调聚合、连续偏好收集和经验重标注均对性能至关重要。
- 可视化显示学习到的奖励能合理反映智能体对未占据地标的偏好，策略表现出良好的分工与避碰。
- 额外训练时间开销可忽略，适合实际系统部署。
