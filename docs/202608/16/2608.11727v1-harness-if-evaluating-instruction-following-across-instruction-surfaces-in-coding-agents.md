## 摘要
当编码代理遵守规则时，它可能本来就会这样做。现有的指令遵循基准无法区分这一点：它们将规则集中在用户回合中，而编码代理基准则强调最终任务的成功。我们引入了Harness-IF，它根据执行证据对操作规则逐条评分：从642条规则库中抽取的60个真实多轮编码任务，256条规则获得判定结果，分布在一个部署代理可读取的五个可配置表面上。为了区分遵从与巧合，我们引入了反先验准确率（AP-Acc），它仅对标记为反对非提示默认值的规则进行评分，通过在九个探针构建中剔除规则后重新运行任务进行观察，并进行其他方面的人工整理。在12个前沿模型中，准确率范围为72.1-85.9%，AP-Acc为66.1-78.6%；每个模型在反先验规则上都表现更差，差值为3.6至7.4个百分点（平均5.81），这一方向在具有项目聚簇区间的共同支持分析中仍然成立。因此，聚合分数会以模型特定的幅度夸大遵从性：先验控制使顶级构建保持不变，并交换了三对相邻排名。在九个独立构建上进行的平衡冲突试点增加了第二个结果：汇总的优先级顺序不遵循提示深度，系统提示、项目文件和用户指令排在工具和技能描述之前。

## Abstract
When a coding agent obeys a rule, it may simply have been going to do that anyway. Existing instruction-following benchmarks cannot tell the difference: they concentrate rules in the user turn, while coding-agent benchmarks emphasize final task success. We introduce Harness-IF, which scores operational rules one at a time from execution evidence: 60 realistic multi-turn coding items drawn from a 642-rule library, 256 rules receiving verdicts, placed on the five configurable surfaces a deployed agent reads. To separate compliance from coincidence we introduce Against-Prior Accuracy (AP-Acc), which scores only rules labeled as opposing unprompted defaults, observed by re-running tasks with the rule withheld across nine probe builds and curated otherwise. Across 12 frontier models, accuracy spans 72.1-85.9% and AP-Acc 66.1-78.6%; every model is worse on against-prior rules, by 3.6 to 7.4 points (mean 5.81), and the direction survives a common-support analysis with item-clustered intervals. Aggregate scores therefore overstate compliance by a model-specific margin: prior control leaves the top build unchanged and exchanges three adjacent rank pairs. A counterbalanced conflict pilot on nine separate builds adds a second result: pooled precedence does not follow prompt depth, with system prompts, project files, and user instructions ahead of tool and skill descriptions.

## 1. 核心问题与整体含义

**研究动机**：当编码代理遵循某条规则时，它可能本来就会这样做——这正是现有评估体系无法识别的盲区。现有指令遵循（Instruction Following, IF）基准存在两个结构性缺陷：
- **规则集中在用户回合**：传统 IF 基准（如 IFEval）将全部规则塞入用户提示中，忽略了真实部署环境中代理读取的是"一整套指令栈"——系统提示、工具描述、技能描述、项目文件、用户指令等多层表面。
- **编码代理基准强调最终任务成功**：SWE-bench 等基准只关心最终代码是否通过测试，无法回答"代理是否真正遵守了某条操作规则"。

**整体含义**：作者引入 **Harness-IF**，将"操作指令遵循"转化为规则级（rule-level）测量问题：对每条规则逐条判定 pass/fail/不适用，并引入 **反先验准确率（AP-Acc）** 来区分"真正遵从"与"巧合符合默认行为"。最终发现：12 个前沿模型的聚合准确率系统性高估了真实遵从水平 3.6～7.4 个百分点，且高估幅度因模型而异——这意味着**聚合分数比较会误导模型间的真实排名**。

## 2. 方法论

### 2.1 核心设计：指令表面（Instruction Surfaces）
将部署中的代理实际读取的指令来源划分为六个表面：
- **HD**（Harness Default）：平台固定默认指令，用户不可编辑；
- **SP**（System Prompt）：系统开发者设定的角色与行为；
- **TD**（Tool Description）：工具功能与使用规范描述；
- **SD**（Skill Description）：可复用技能的触发条件与规则；
- **PF**（Project File）：如 CLAUDE.md、AGENTS.md 等项目级指令文件；
- **UI**（User Instruction）：用户当前请求。

### 2.2 数据结构
- 约束库共 **642 条原子规则**，按 8 个独立标注轴组织：家庭（7 类）、模态（7 类逻辑运算符）、先验（align/against/neutral）、可观测性、可验证性、普适性、表面适配度、表面变体；
- 每条规则被判定为 pass/fail/n/a，并要求**原子性、可验证性、非平凡性、适配编码代理任务**；
- 规则放置采用"可操作表面"分配策略：保证语义不变，按表面适配度抽样。

### 2.3 核心度量公式

**基础准确率**（Acc）：

\[
Acc(a)=\frac{\sum_{(i,r)\in E_a} z_{a,i,r}}{|E_a|}
\]

**AP-Acc**（仅评估反对默认行为的规则子集 P）：

\[
AP\text{-}Acc(a)=\frac{\sum_{(i,r)\in E_a,\,r\in P} z_{a,i,r}}{|\{(i,r)\in E_a: r\in P\}|}
\]

**关键思想**：Acc 与 AP-Acc 的差 ∆ 即是"默认行为对遵从度分数的虚高贡献"。由于两者来自同一批判定记录、同一套二元定义，∆ 是逐项可比（like-for-like）的对比，而非聚合方式不同造成的误差。

### 2.4 先验标签的获得
- **零注入探针（zero-injection）**：在 9 个探针构建上，隐藏目标规则后重跑同一任务，观察模型在无指令时的默认行为；规则在 ≥5/9 的模型上呈现一致默认行为时打上共识标签；
- **人工整理**：无法通过探针恢复的标签由人工标注或既有整理记录补充；
- 先验分布：18% 对齐（align）、44% 反对（against）、38% 中性（neutral）——保证面板不能单靠默认行为得分。

## 3. 实验设计

### 3.1 数据集与基准构成

- **每条规则放置在一个可操作表面上**，随机采样广告许可表面；
- **评分方法**：6 种——正则、AST、跨文件一致性、命令输出、混合（确定性预检+LLM 精判）、LLM 判定（GPT-5.2 三票多数，temperature=0.3）；
- **E0 冲突试点**：9 个较老模型构建、4 个合成冲突对、916 次运行、纯确定性评分，测试表面优先级；
- **非编码扩展**：40 个案例、5 个领域（客服、法律合规、营销、金融分析、研究/学术写作），1,440 条尝试轨迹、1,428 条有效。

## 6. 主要结论与发现

1. **每个模型在反先验规则上都更差**：12 个模型无一例外，Acc−AP-Acc 差距为 3.6～7.4 点（均值 5.81），常见支持分析+项目聚类区间逐模型为正。**聚合分数系统性高估遵从性**。
2. **高估幅度因模型而异**：差距分布存在两倍差异（3.6 vs 7.4），因此聚合分数比较会扭曲模型排名：先验控制交换了 2–3、4–5、11–12 三对相邻排名。
3. **表面优先级不遵循提示深度**：E0 中 SP、PF、UI 三者的模型级排名总和完全打平（20/9=2.22），TD 为 3.78，SD 为 4.56。用户指令并非无条件占优，这一发现与"越靠后的指令越有效"的简单深度假说相矛盾。
4. **失败集中在"要求行动"型规则**：Shortfall（要求做/设下限）类规则占全部 8,440 次失败的 77.1%，与 Overstep 类失败率相近（23.8% vs 20.8%），说明差距主要来自暴露量而非倾向。
5. **输出控制和命令性模态最难**：输出控制家族准确率 70.9%，为 12 个模型中 11 个的最低；命令性模态（require/forbid）76.0%，偏好类最优（90.6%）。
6. **跨模型规则难度结构高度共享**：各模型逐规则通过率与队列均值的相关性为 0.57～0.89（均值 0.80）。

## 7. 优点

- **规则级评估，而非任务级**：每个可适用规则单独判定，能精确定位失败在哪些规则、哪个表面、哪种模态上发生，比 task-success 粒度细得多。
- **AP-Acc 概念清晰、实现严谨**：通过隐藏规则的零注入探针观察真实默认行为，将"遵从"与"先验一致"解耦；∆ 的对比是同一判定集合下的类同对比，而非不同聚合约定的差异。
- **多表面覆盖 + 受控冲突**：五个可配置表面 + 固定 HD，在受控冲突（E0）中测量表面优先级，在自然面板（主面板）中测量真实遵从率，二者互为补充。
- **数据与代码可复现**：所有报告数字可由发布记录离线重算；约束库、组装项目、评分脚本、判定面板全部发布。
- **审慎、诚实的不确定性报告**：明确区分"确定的跨模型模式"与"不确定的排名"，声明排名为点估计而非置信结论；对先验标签谱系（哪些来自零注入共识、哪些来自整理）做了透明披露。
- **方法论的推广价值**：提出评估编码代理指令遵从的四项原则——保留规则来源、对机会而非任务计分、分离反先验行为与聚合成功、做优先级声明时进行表面计数平衡——为后续工作提供了模板。

## 8. 不足与局限

### 8.1 测量层面的局限
- **LLM 裁判主导**：86.8% 的判定行涉及 GPT-5.2 裁判，裁判互换时 κ 仅 0.163，绝对分数受裁判选择影响较大；作者承认绝对水平是"仪器特异"的，跨模型对比（共享同一仪器）才是可靠信息。
- **相邻排名不可区分**：共同支持分析中所有相邻模型区间都包含零，所有 12 个模型形成一个保守的"相邻并列组"；排行榜排序只能作为点估计。
- **测试-重测单元稳定性有限**：单元级 ICC 0.599，说明单轮/单元得分难以支撑精细结论。

### 8.2 数据与覆盖的局限
- **选择优化偏差**：60 个项目从 80 个候选中按可区分性和难度挑选，可能有利于在试点模型中产生分离的项目，导致对未知模型的代表性失真。
- **先验标签谱系不完整**：36 条规则标签谱系未知，12 条与可恢复共识冲突且无保留的覆盖原因；零注入共识仅覆盖 287 条规则（44.1% 的反先验判定来自探针共识，46.5% 来自人工整理，9.4% 未知）。
- **探针队列与评估队列重叠**：5/12 评测模型与探针构建共享标识符，没有任何零注入标签完全独立于被测队列；作者将这一差异量化为 0.43 点，作为边界报告而非独立性证据。
- **E0 仅覆盖老模型与合成冲突**：9 个构建中有 4 个不在主面板中，仅 4 个合成冲突对，结果是一个"池化趋势"而非普适层级；作者没有将其与主面板合并，保持了审慎的分离。

### 8.3 场景与通用性局限
- **语言和文化偏向**：约束库以英语、软件工程中心的人类调查为基础，不构成可追溯的仓库采样框架。
- **非编码扩展属于探索性**：NC-Macro 使用不同的任务种群、本体、评分协议和模型构建快照，不可与编码面板合并；部分案例只有 1～2 条有效轨迹。
- **专业写作规则未在主编码面板中测试**：仅在非编码扩展中覆盖，编码面板无法对标出专业写作类约束的遵从表现。
- **缺乏人工基准的完全审计性**：历史人工参考审计使用五票配置（n=919，κ=0.515），但原始连接标签、采样框架和裁决记录未完整保留，属于"合格证据"而非完全可审计研究。
- **范围有限**：基准针对多轮编码代理，不覆盖单轮提示、无工具环境或非文本模态。

**总体评价**：Harness-IF 在方法论创新与测量严谨性之间实现了较好的平衡。它首次将编码代理的"指令遵循"从任务级成功中剥离，转化为可逐条判定的规则级测量问题，并通过反先验准确率揭示了一个此前被系统性忽视的现象——聚合分数对不同模型的虚高程度不同，足以颠倒相邻排名。这一核心发现对现有基准（如 SWE-bench、IFEval）的解读方式提出了实质性质疑：任务成功无法证明遵从，而聚合遵从分数本身也未必可比。

尽管存在裁判一致性偏低（κ=0.163）、相邻排名不可区分、测试-重测稳定性有限、先验标签谱系不完整、以及语言与场景覆盖偏窄等局限，作者在不确定性披露上的坦诚程度远超同类工作：明确将排名称为"点估计"、量化探针重叠差异、分离可复现记录与人工审计证据。从研究价值看，本文的贡献不仅在于 12 个模型的具体分数，更在于提出了一套可迁移的评估范式——保留规则来源、按机会而非任务计分、分离反先验行为与默认行为、在优先级声明中做表面计数平衡——为后续更可靠、更细粒度的代理遵从性评估提供了方法论模板。对于任何使用聚合分数对编码代理进行排名的实践者而言，这是一个必须引用的警示：未控制先验行为的排行榜，不能作为真实遵从能力的可靠依据。
