## 摘要
同策略蒸馏（OPD）在其当前策略采样的轨迹上对学生语言模型进行监督，但对监督价值不等的响应标记赋予相同的权重。选择性OPD通过根据估计的训练价值在响应标记间非均匀地分配监督，解决了这一限制。然而，大多数现有标准主要关注优化需求，如不确定性或师生分歧，而任务相关性（即监督是否与当前输入的语义内容相关）作为一个补充维度仍未被直接刻画。为弥补这一空白，我们提出了用于同策略蒸馏的反事实相关性（CROP），它通过释义校准的反事实敏感性边界来实现任务相关性。对于每个源提示，CROP构建经过验证的原始-释义-反事实三元组，固定学生轨迹，并通过每个响应位置对任务相关条件变化的敏感性（经其对保持语义改写的敏感性校准）来度量该位置。匹配选择控制显示，CROP比随机或最低相关性选择识别出更有用的监督位置，而组件比较证实了反事实敏感性和释义校准的价值。在两种师生设置中，CROP比最强的非CROP选择器分别提高了1.92和2.96个百分点的整体性能。这些结果支持将任务相关性作为选择性OPD的补充标准，并确立了CROP作为一种模型内部的、对比特定的分配标记级监督的方法。

## Abstract
On-policy distillation (OPD) supervises a student language model on trajectories sampled from its current policy, but assigns equal credit to response tokens with unequal supervision value. Selective OPD addresses this limitation by allocating supervision non-uniformly across response tokens according to their estimated training value. Most existing criteria, however, focus primarily on optimization need, such as uncertainty or teacher-student disagreement, while task relevance, namely whether the supervision is tied to the semantic content of the current input, remains less directly characterized as a complementary dimension. To address this gap, we introduce Counterfactual Relevance for On-Policy Distillation (CROP), which operationalizes task relevance through a paraphrase-calibrated counterfactual sensitivity margin. For each source prompt, CROP constructs a validated original-paraphrase-counterfactual triplet, holds the student rollout fixed, and measures each response position by its sensitivity to a task-relevant condition change calibrated by its sensitivity to a meaning-preserving rewrite. Matched selection controls show that CROP identifies more useful supervision positions than random or lowest-relevance selection, while component comparisons confirm the value of both counterfactual sensitivity and paraphrase calibration. Across two teacher-student settings, CROP improves aggregate performance by 1.92 and 2.96 points over the strongest non-CROP selector. These results support task relevance as a complementary criterion for selective OPD and establish CROP as a model-internal, contrast-specific method for allocating token-level supervision.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：语言模型后训练通常结合监督微调（SFT）和强化学习（RL）。同策略蒸馏（On-policy Distillation, OPD）通过让教师模型对学生当前策略访问过的前缀进行评分，兼顾了同策略覆盖与密集的 token 级分布监督。
- **问题**：标准 OPD 对所有响应 token 一视同仁，但不同 token 的监督价值并不相同。现有选择性 OPD 方法（如基于不确定性、师生分歧、可教性等）主要刻画的是 **“优化需求”**（这个 token 需不需要被纠正），而较少直接刻画 **“任务相关性”**（这个 token 的学习信号是否与当前输入的任务语义紧密相关）。
- **核心问题**：一个 token 即使是不确定的、与教师有分歧的、或容易被纠正的，也可能是输入无关的通用模式。如何直接度量“监督是否与任务语义相关”，并将其作为 token 选择的补充维度？
- **整体含义**：论文提出将“任务相关性”作为选择性 OPD 中一个独立的、互补于“优化需求”的选择标准，并据此设计了一个模型内部、对比特定的 token 级监督分配方法。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

**核心思想**：通过构造“原文–释义–反事实”三元组，利用学生对**语义相关条件变化**的敏感性（减去对**同义改写**的敏感性）来度量每个 token 的任务相关性，并根据该评分在固定预算下选择监督 token。

**关键技术细节与流程**：

- **三元组构造（离线）**：为每个源提示 x，用 LLM（GPT-5.1）生成并验证一个三元组：
  - 原文 x：原始问题；
  - 释义 x_para：保持语义完全不变的改写；
  - 反事实 x_cf：只改变一个关键数学条件、但保持任务类型和答案类型一致的改写。
  - 由独立 critic 提示对生成的候选进行严格验证（要求语义保持、单条件干预、确定性、答案类型一致等），默认只保留严格通过验证的三元组。

- **固定 rollout 重新评分**：固定学生在原提示下生成的响应 y，将同样的 y 和前缀 y<t 分别放到三个提示下重新评分，得到三个概率分布：P_o、P_para、P_cf。这样做可以避免不同采样轨迹被误当作提示敏感性。

- **Top-K JSD 计算**：由于全词表概率不可得，采用 Top-K 词表并加入残差桶，计算近似 Jensen-Shannon 散度：
  - `JSD_K(P, Q)` 基于 `(P(v), Q(v), 残差)` 在有限支持集上计算。
  - 语义敏感性：`d_sem = JSD_K(P_o, P_cf)`
  - 表面敏感性：`d_surf = JSD_K(P_o, P_para)`

- **得分公式**（式 5）：
  - `s_CROP = d_sem - d_surf`
  - 分值越高表示该位置对任务相关条件变化越敏感，同时受同义改写影响越小。

- **熵增强变体 CROP-ent**（式 6-7）：
  - 将 CROP 得分和学生熵分别做批级 5-95% 分位数归一化（clip 到 [0,1]），再用 Soft-OR 组合：
    `s = e_H + e_CROP - e_H * e_CROP`
  - 仅用于检验任务相关性与不确定性是否互补，不作为主方法。

- **批级全局预算选择**（式 8-13）：
  - 设定名义保留比例 ρ（如 10%），对当前 batch 内所有有效响应位置按评分全局排序，保留 Top-b 个位置；
  - 同时引入每条响应的最少保留 token 数（L=1）作为保护，避免某些响应完全没有监督；
  - 最终生成二进制硬掩码，作用于原始 OPD loss。

- **掩码应用**：CROP 不改变教师目标、不改变学生采样分布，只通过掩码选择哪些响应 token 进入原始采样token OPD loss（式 18）。底层 OPD 更新保持原样，CROP 本质上是一个硬选择器。

### 6. 论文的主要结论与发现

1. **任务相关性是独立且有价值的选择维度**：CROP 在两种师生设置中分别超过最强非 CROP 选择器 1.92 点和 2.96 点（Qwen3-4B→Qwen3-1.7B：CROP 47.98 vs. TIP 46.06；Qwen3-8B→Qwen3-4B：CROP-ent 57.48 vs. 最强非 CROP 基线约 54-55）。

3. **熵排名分析显示 CROP 覆盖了不确定性方法忽略的低熵 token**：CROP 保留的 token 中 10.0% 落在最低熵十分位，而 Entropy/TIP/TA-OPD 几乎为 0，CREDIT 为 3.6%。
4. **反事实敏感性是主要选择信号，释义校准提供额外收益**：CROP 超过 CS-OPD 1.98 点、超过 PC-OPD 4.89 点。
5. **CROP-ent 的收益依赖于设置**：在 Qwen3-8B→Qwen3-4B 上熵可互补，但在小设置上反而低于 CROP，说明熵并非普遍有益。

### 7. 优点

- **问题视角新颖**：明确提出“任务相关性”作为与“优化需求”互补的选择维度，填补了选择性 OPD 的一个概念空白。

- **保持 OPD 目标不变**：CROP 只改变 token 掩码，不引入额外损失或改变教师目标，作为“硬选择器”易于集成到现有框架。

### 8. 不足与局限

- **领域覆盖有限**：仅覆盖数学训练提示，未验证代码、开放域问答、指令遵循等领域的适用性；

- **预算敏感性不强**：性能随预算非单调变化，最佳预算在不同设置下不一致，实际使用中选择预算需要另作调优；
