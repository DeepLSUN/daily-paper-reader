## 摘要
全模态语言模型（OLM）实现了统一的音视频理解，但处理长联合token序列使得推理在计算上代价高昂。尽管最近的token压缩方法试图缓解这一负担，但孤立地压缩模态往往会破坏连贯推理所必需的时序跨模态锚点。我们提出了Omni2LoRA，一个通过保相干性上下文蒸馏实现高效参数记忆压缩的两阶段框架，从根本上绕过了token瓶颈。首先，一个Perceiver超网络处理来自冻结OLM的中间表示，在单次前向传播中将多模态上下文编码为全秩低秩自适应（LoRA）适配器。为防止由此产生的参数占用随记录长度线性增长，我们通过组相对策略优化（GRPO）优化离散秩分配策略，该策略使用模态消融的反事实奖励显式惩罚音视频相干性的损失，迫使模型将其固定的次线性秩预算分配给协同的跨模态锚点而非孤立的视觉特征。在三个全模态骨干网络上，以30%秩预算运行的Omni2LoRA在四个音视频问答基准上优于直接全上下文推理和强token压缩基线（OmniZip、OMAC、O-MARC），相较于最强基线平均准确率提升8-12%，并在压缩比高达75%时保持稳定，而token剪枝方法在此情况下性能急剧下降。通过将多模态记忆转换为固定预算、可复用的参数状态，我们的方法将答案时的多模态token负载降至零，相较于全上下文推理，每次查询的首token时间（TTFT）最多缩短12倍，并在少量查询后摊销至0.5秒以下。

## Abstract
Omnimodal language models (OLMs) enable unified audio-visual understanding, but processing long joint token sequences makes inference computationally prohibitive. While recent token compression methods attempt to alleviate this burden, compressing modalities in isolation often destroys the temporal cross-modal anchors necessary for coherent reasoning. We introduce Omni2LoRA, a two-stage framework for efficient parametric memory compression via coherence-preserving context distillation that bypasses the token bottleneck entirely. First, a Perceiver hypernetwork processes intermediate representations from a frozen OLM to encode the multimodal context into a full-rank Low-Rank Adaptation (LoRA) adapter in a single forward pass. To prevent the resulting parameter footprint from scaling linearly with recording length, we optimize a discrete rank allocation policy via Group Relative Policy Optimization (GRPO) that uses a modality-ablated counterfactual reward to explicitly penalize the loss of audio-visual coherence, forcing the model to allocate its fixed sub-linear rank budget to synergistic cross-modal anchors rather than isolated visual features. Across three omnimodal backbones, Omni2LoRA operating at a 30% rank budget outperforms direct full-context inference and strong token-compression baselines (OmniZip, OMAC, O-MARC) on four audio-visual question answering benchmarks, improving average accuracy by 8-12% over the strongest baseline and remaining stable under compression ratios as tight as 75%, where token-pruning methods degrade sharply. By converting multimodal memory into a fixed-budget, reusable parameter state, our method drives answer-time multimodal-token load to zero, cutting per-query Time to First Token (TTFT) by up to 12x relative to full-context inference and amortizing to under 0.5s after a handful of queries.

## 一、论文的核心问题与整体含义

- 全模态语言模型（OLM）能统一处理音频、视觉和语言，但在推理时需将视频帧与音频波形编码为大量连续 token 输入上下文窗口，导致长录音/视频场景下计算开销和内存占用巨大。
- 现有 token 压缩方法（如 token 合并、剪枝、音频引导压缩）虽能减少 token 数，但往往对音频、视频“分别压缩”，容易破坏跨模态的时序锚点，丢失音视频联合推理所需的互补证据。
- 论文的根本思路是绕过 token 上下文瓶颈：不压缩 token，而是把多模态内容直接“参数化”为模型权重（即 LoRA 适配器），让推理时上下文中不再保留任何音视频 token。
- 核心含义：为长上下文全模态记忆压缩提供了一种新范式——把“记忆”从 token 空间转移到参数空间，并通过对跨模态相干性的显式保护，兼顾效率与推理质量。

## 二、论文提出的方法论

### 2.1 总体框架：两阶段 Omni2LoRA

- 阶段一：全秩超网络训练（Full-Rank Hypernetwork Training）
  - 使用冻结的 OLM 编码器 \(E\) 处理同步音视频录音，得到分层隐藏状态 \(C_t \in \mathbb{R}^{L \times S \times D}\)。
  - 用 Perceiver 超网络 \(H_\phi\) 将每个时间块的表示映射为候选 LoRA 因子 \(\{A_{\ell,m,t,r}, B_{\ell,m,t,r}\}\)，即“rank-one”更新方向。
  - 通过教师强制交叉熵损失训练 \(H_\phi\)，使生成的全秩适配器能重建音频-视觉字幕；训练后 \(H_\phi\)、编码器 \(E\)、答案模型 \(F\) 全部冻结。
- 阶段二：保相干性的压缩蒸馏（Memory-Augmented Compression Distillation）
  - 为将随录音长度线性增长的参数预算压缩到固定、次线性的秩预算 \(R_{\text{total}}\)，训练一个轻量评分网络 \(g_\psi\)，对每个候选“槽位”打分为 logit。
  - 采用无放回的顺序采样构造分配 \(K_{\text{sel}}\)，并用 PPO/GRPO 风格的目标优化策略。
  - 关键创新是“相干性感知优势塑形”：对每个查询预先用三种冻结参考 rollout 计算奖励：完整音视频 \(R_{AV}\)、仅视频 \(R_V\)、仅音频 \(R_A\)，由此定义音频-视觉依赖分数：
    \[
    \Omega(q)=\mathrm{ReLU}(R_{AV}-\max(R_V,R_A))
    \]
    再用 \(\Omega(q)\) 放大压缩导致的性能退化项：
    \[
    \tilde{\Delta}_i=\Delta_i \cdot (1+\eta\Omega(q))
    \]
    并重塑 GRPO 优势：
    \[
    w_i=\mathrm{ReLU}(\hat{A}_i)\cdot\tilde{\Delta}_i,\quad \tilde{A}_i=\hat{A}_i-\lambda w_i
    \]
    从而在策略梯度更新中显式惩罚“丢掉了高音视频依赖查询所需锚点”的分配。

### 2.2 推理流程

- 推理时只需一次性地把录音编码为候选槽位，用 \(g_\psi\) 贪心选择 top-\(R_{\text{total}}\) 槽位组成紧凑适配器并缓存；之后每个查询仅由冻结模型加上该适配器作答，上下文中零多模态 token，因此 TTFT 大幅降低。

## 三、实验设计

### 3.1 骨干模型与训练数据

- 三种全模态骨干：Qwen2.5-Omni-3B、InteractiveOmni-4B、Qwen2.5-Omni-7B。
- 阶段一用 VALOR-1M 进行教师强制训练；阶段二用 FineVideo 语料做压缩蒸馏，并从下游训练集补充查询与视频。

### 3.3 对比方法与消融

- 基线：Full Tokens（直接全上下文推理）、OmniZip、OMAC、O-MARC。

- 变量实验：不同压缩比（25%/50%/75%）、不同帧数（8 到 1024）、TTFT 与摊销延迟。

## 六、论文的主要结论与发现

- 在 30% 秩预算下，Omni2LoRA 在四个音视频问答基准上平均准确率比最强 token 压缩基线 O-MARC 高 8–12%，并且超过未经压缩的全上下文推理。
- 在 UGC-AVQA 上提升最明显（如 Qwen2.5-Omni-7B 达到 68.0%），说明参数记忆压缩能避免 token 剪枝固有的跨模态信息损失。
- 在 75% 极端压缩比下仍保持较高准确率（60.7%），而 OmniZip、OMAC、O-MARC 明显下降。
- 帧数从 32 增加到 1024 时，直接上下文推理会因上下文耗尽而崩溃，而 Omni2LoRA 性能单调增长（最高 46.2），能天然扩展至长视频。
- 推理效率方面：单问题 TTFT 最低达 0.49 秒（7B），比全上下文推理最多降低 12 倍；多查询摊销后降到 0.43 秒左右，显著优于始终保留 token 的压缩基线。

- 问题切入点新颖：跳过 token 压缩，直接进行“参数记忆压缩”，思路有较大创新性。
