## 摘要
智能体检索工作流在回答问题过程中会产生查询、检索和停止轨迹作为副产品。我们研究这些轨迹如何能够在没有新相关性标签、合成查询或LLM判断的情况下，使已部署的密集检索器适应不断变化的工作流分布。我们引入了导航信息嵌入（NIE），一系列从轨迹中衍生的目标函数。NIE-Stop将停止文档转化为软正例；NIE-Path额外使用前面的路径文档作为硬比较，并施加具有几何衰减的序数约束。一个从保留的源轨迹中适应的BGE编码器在独立的目标基准上将整体支持Recall@20从72.2提升到78.0。NIE-Stop达到76.9整体，长路径上52.3；NIE-Path将长路径性能提升到55.4，而未适应的编码器为46.7。在完整路径目标下的乱序对照损失了3.2个点。在没有公共基准训练的情况下，同一适配器在标准BEIR HotpotQA上将nDCG@10提高了1.9个点。因此，NIE为已经保留轨迹的场景提供了一种轻量级自适应渠道，且零增量标注成本。

## Abstract
Agentic retrieval workflows produce query, retrieval, and stopping traces as a byproduct of answering questions. We study how these traces can adapt a deployed dense retriever to changing workflow distributions without new relevance labels, synthetic queries, or LLM judgments. We introduce Navigation-Informed Embeddings (NIE), a family of trace-derived objectives. NIE-Stop turns the stopping document into a soft positive; NIE-Path additionally uses preceding path documents as hard comparisons and imposes ordinal constraints with geometric decay. A BGE encoder adapted from retained source trajectories improves support Recall@20 on an independent target benchmark from 72.2 to 78.0 overall. NIE-Stop reaches 76.9 overall and 52.3 on long paths; NIE-Path raises long-path performance to 55.4, compared with 46.7 for the unadapted encoder. A shuffled-order control under the full path objective loses 3.2 points. Without public-benchmark training, the same adapter also improves nDCG@10 by 1.9 points on standard BEIR HotpotQA. NIE therefore provides a lightweight adaptation channel for settings where trajectories are already retained, with zero incremental labeling cost.

## 1. 论文的核心问题与整体含义

- **背景**：部署在智能体检索工作流中的密集检索器（如 BGE）常面临查询与语料分布的持续漂移。传统适应方式依赖人工相关性标注、LLM 生成的合成查询或 LLM 判断，成本高且难以频繁更新。
- **核心问题**：能否直接利用智能体在检索过程中自然产生的“导航轨迹”（查询、有序检索文档、停止文档）作为监督信号，实现零增量标注的检索器自适应？
- **整体含义**：论文提出 **Navigation-Informed Embeddings (NIE)**，将停止事件和路径顺序转化为软监督，无需任何新标签即可更新密集编码器，为持续适应提供了轻量、低成本的通道。

## 2. 论文提出的方法论

- **核心思想**：把智能体轨迹转化为三类弱监督信号：
  - **软正例**：最终停止文档（agent 停止检索并生成答案前最后检索的文档）视为对查询有用的软正例；
  - **路径低排名项**：更早检索的文档作为硬比较项（hard comparisons），提供相对排序信息；
  - **随机负例**：从语料中随机采样无关文档。
- **NIE-Stop**：仅使用停止文档作为正例，采用标准对比学习目标：
  \[
  \mathcal{L}_{\text{contrast}} = -\log \frac{\exp(\text{sim}(q,d^+)/\tau)}{\sum_{d \in \mathcal{B}} \exp(\text{sim}(q,d)/\tau)}
  \]
  其中 \(\mathcal{B}\) 包含一个停止正例、随机负例和批次内其他正例。
- **NIE-Path**：在 NIE-Stop 基础上增加路径顺序信息：
  - **几何衰减权重**：\(w_t = \gamma^{T-t}\)，越靠后的文档权重越高；
  - **相邻排序损失**：鼓励相邻文档满足 \(d_{t+1} \succ d_t\)，使用带几何缩放 margin 的 hinge 损失：
    \[
    \mathcal{L}_{\text{order}} = \frac{1}{T-1} \sum_{t=1}^{T-1} \max\left(0, \text{sim}(q,d_t) - \text{sim}(q,d_{t+1}) + m \cdot w_{t+1}\right)
    \]
  - **组合目标**：\(\mathcal{L}_{\text{path}} = \mathcal{L}_{\text{contrast}} + \lambda \mathcal{L}_{\text{order}}\)，实验取 \(\lambda=1\)，\(\gamma=0.7\)，\(m=0.1\)。
- **训练流程**：从源轨迹中提取训练样本（约 2197 个），微调 BGE-base-en-v1.5 全部参数，使用 AdamW，训练 3 个 epoch，不使用任何人工或 LLM 标签。

## 6. 论文的主要结论与发现

- NIE 可有效利用轨迹进行零标签密集检索器适应：
  - 目标基准整体 Support Recall@20 从 72.2 提升至 78.0（+5.8 点）；
  - 长路径查询从 46.7 提升至 55.4（+8.7 点），其中 NIE-Stop 贡献 +5.6，NIE-Path 额外 +3.1；
  - 洗乱路径顺序导致长路径下降 3.2 点，证明顺序信息有效；
  - 在 BEIR HotpotQA 上，NIE-Path 较初始器提升 nDCG@10 1.9 点、Recall@100 1.5 点（无公共基准训练）。
- 停止文档即使含有噪声（26% 审计为错误），在聚合层面仍具有有效信号。
- NIE 为持续适应提供了可行机制，可将同一目标应用于后续轨迹窗口，无需新的标注接口。

## 7. 优点

- **零标注成本**：利用工作流天然产生的轨迹，省去了人工标注、LLM 生成查询或 LLM 判断；
- **目标设计精细**：软正例、硬比较、几何衰减和相邻排序损失组合合理，能够处理“早期有用但未停止”的真实场景；
- **实验控制严密**：设计了大量匹配基线和顺序扰动控制，能将停止信号、路径组成、顺序信息、对比集构成等因子逐一分离；
- **统计可靠性好**：提供 bootstrap 置信区间和多 seed 标准差；
- **具有实践价值**：适应后的编码器可直接替换现有密集检索组件，兼容混合检索栈；适用于已保留轨迹的系统。

## 8. 不足与局限

- **算力细节缺失**：未报告 GPU 型号、数量、训练时间，难以评估可复现性和部署成本。
- **基准覆盖有限**：仅一个主工作流基准 + HotpotQA 转移，且 HotpotQA 构造为“池化”版本（含重复文档竞争），与标准全维基检索不完全可比。
- **策略依赖性**：轨迹信号受生成轨迹的智能体行为影响，若智能体本身有系统性偏差（如过早停止、检索模式偏窄），NIE 会继承这些偏差；论文仅通过 26% 噪声审计和随机终端控制间接验证，未做更多偏差场景测试。
- **单调相关性先验的风险**：路径顺序假设“越晚越有用”，对证据累积型任务不完全成立（早期文档可能为必要支持），论文虽用相邻损失缓解，但未量化极端违反情况下的表现。
- **冷启动问题**：依赖足够多的已有轨迹，低流量或冷启动场景可能需要额外合成数据或人工标注来引导。
- **未研究连续多轮适应**：实验只验证了一次离线源→目标更新，实际持续部署中多轮适应是否会漂移或积累错误未被评估。
