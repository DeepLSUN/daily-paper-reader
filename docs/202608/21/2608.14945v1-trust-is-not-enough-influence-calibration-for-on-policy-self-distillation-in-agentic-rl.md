## 摘要
在线策略自蒸馏（OPSD）通过特权自教师（self-teacher）在策略自身轨迹上提供密集的令牌级监督。现有方法主要根据教师信任度来分配这种监督，但信任度并不能揭示强调某个令牌是否支持当前策略目标。我们将此称为信任-效用不匹配，并引入自蒸馏影响力校准（ICSD）。对于每个受监督的令牌，ICSD衡量其重要性加权RL代理贡献对教师导向输出扰动的一阶响应。批量自适应校准将此非平稳信号转换为有界的分配权重，同时保留每个动作轮次内原始辅助损失的规模。这些分离的权重仅影响蒸馏损失，且不需要额外的模型传递。在ALFWorld、WebShop和Search-QA上，ICSD在组相对策略优化（GRPO）和组中组策略优化（GiGPO）下，跨两个涵盖1.5B至7B的模型家族，在所有匹配的汇总指标上均优于仅信任分配。在7B规模下，ICSD达到96.1%的ALFWorld成功率和93.1的WebShop分数。冻结批次分析表明，ICSD将分配给目标对立令牌的教师支持质量从60.1%降至37.8%，并将与RL梯度的余弦兼容性提高了0.192。相关代码库可在https://github.com/lanqz7766/Influence-Calibration-for-On-Policy-Self-Distillation-in-Agentic-RL获取。

## Abstract
On-policy self-distillation (OPSD) gives language agents dense token-level supervision from a privileged self-teacher on the policy's own trajectories. Existing methods allocate this supervision mainly by teacher trust, but trust does not reveal whether emphasizing a token supports the current policy objective. We call this the trust-utility mismatch and introduce Influence Calibration for Self-Distillation (ICSD). For each supervised token, ICSD measures the first-order response of its importance-weighted RL surrogate contribution to a teacher-directed output perturbation. Batch-adaptive calibration converts this non-stationary signal into a bounded allocation weight while preserving the original auxiliary-loss mass within each action turn. These detached weights affect only the distillation loss and require no additional model pass. Across ALFWorld, WebShop, and Search-QA, ICSD improves all matched aggregate metrics over trust-only allocation under Group Relative Policy Optimization (GRPO) and Group-in-Group Policy Optimization (GiGPO), across two model families spanning 1.5B to 7B. At 7B, it reaches 96.1% ALFWorld success and a WebShop score of 93.1. Frozen-batch analyses show that ICSD reduces teacher-supported mass assigned to objective-opposed tokens from 60.1% to 37.8% and raises cosine compatibility with the RL gradient by 0.192. A companion repository is avail- able at https://github.com/lanqz7766/Influence-Calibration-for-On-Policy-Self-Distillation-in-Agentic-RL.

### 1. 核心问题与研究动机

语言智能体在长时间交互任务中越来越多地依靠**在线策略强化学习（on-policy RL）** 进行训练。然而，奖励信号每整条轨迹只返回一次，远粗于产生该轨迹的每个决策步骤——少数关键动作往往决定了整个回合的成败，但 RL 奖励无法提供细粒度指导。

**在线策略自蒸馏（On-Policy Self-Distillation, OPSD）** 通过一个享有特权信息的"自我教师"（privileged self-teacher）在策略自身的 rollout 上提供密集的 token 级监督，弥补了这一粒度鸿沟。但在一条 rollout 中涌现大量教师监督信号时，**如何分配这些辅助更新的权重**成为一个关键问题。

现有方法主要依据**教师信任度（teacher trust）** 分配监督——包括教师-学生一致性、不确定性差异、token 位置、结果证据等。然而，作者指出一个根本性缺陷：

> **信任-效用错配（trust–utility mismatch）**：信任解决的是"这个纠正信号是否可信"，而效用回答的是"朝向该纠正移动是否服务于当前策略改进方向"，二者并不等价。两个 token 可能获得同样强的教师支持，但一个位于优势估计器（advantage estimator）认可的回合中，另一个位于其惩罚的回合中。

作者通过实验佐证了这一问题的严重性：在冻结的 ALFWorld 批上，纯信任分配将 60.1% 的教师支持质量分配给了当前策略目标所**反对**的 token。

### 2. 方法论：ICSD

#### 2.1 核心思想

ICSD 不是替代教师信任信号，而是**以目标效用（objective utility）为前提条件来调节信任监督的分配**。其核心逻辑是：保留原有的教师信任权重，但通过目标影响力（objective influence）重新分配相同质量的辅助损失，使监督从目标对立的 token 流向目标支持的 token。

#### 2.2 关键技术细节

**（1）教师导向的目标影响力分数**

对每个 token t，定义策略比率为 $\\rho_t = \\pi_\theta(a_t|x_t)/\\pi_{old}(a_t|x_t)$，token 优势为 $\\hat{A}_t$，教师-学生差距为 $\\Delta_t$（正表示教师比学生更偏好该 token）。token 对未截断 RL 替代目标（surrogate objective）的贡献为 $J_t = \\hat{A}_t\\rho_t$。

关键洞察：不使用需要 Hessian 逆计算的经典参数空间影响力函数（计算代价对十亿参数模型不可行），而是对**标量输出坐标**施加教师导向扰动：

$$\\log \\rho_t(\\epsilon) = \\log \\rho_t + \\epsilon\\Delta_t$$

由此得到一阶泰勒系数——**教师导向目标影响力**：

$$u_t := \\left.\\frac{d\\,\\hat{A}_t\\rho_t(\\epsilon)}{d\\epsilon}\\right|_{\\epsilon=0} = \\hat{A}_t\\rho_t\\Delta_t$$

该分数仅使用 RL 更新中已有的量（优势、比率、教师差距），无需额外模型前向或反向传播。其符号就表明：增大该 token 概率是否提升当前 RL 替代目标的局部贡献。

**（2）批量自适应校准（batch-adaptive calibration）**

$u_t$ 的绝对尺度继承自优势估计和策略比率，跨 minibatch 不稳定且具有重尾（heavy tails）。ICSD 采用：
- 以**中位数**为稳健位置估计，降低离群值影响；
- 在两侧分别拟合单侧尺度（与中位数的平均绝对偏差）；
- 通过**非对称 Laplace 族的 CDF** 将分数映射到 $(0,1)$ 区间的有界相对分数 $\\tilde{m}_t$；
- 校准组按**动作轮次索引**（across trajectories）汇集，稀疏组回退到 minibatch 全局统计。

**（3）保守组合（conservative composition）**

当 $\\hat{A}_t < 0$ 且 $\\Delta_t < 0$（双负区域）时，两者乘积使 $u_t > 0$，但实际教师干预方向与辅助损失更新方向不一致，此时分数会错误地表现为"支持"。ICSD 对这类 token **保留原有 SDAR 信任权重** $g_t$，不做重新分配。

**（4）准确的回合级质量匹配（exact action-turn mass matching）**

对每个动作回合 q，计算缩放因子：

$$\\alpha_q = \\frac{\\sum_{j \\in C_q} g_j}{\\sum_{j \\in C_q} g_j \\tilde{m}_j}$$

从而保持每个回合内**辅助损失总质量不变**（$\\sum_{t\\in q} c_t = \\sum_{t\\in q} g_t$），ICSD 只是重新分配质量而非改变总量。

#### 2.3 理论性质

作者证明了该方法满足：
- **仿射不变性**：对影响力分数做正仿射变换（$u' = au + b, a>0$）后，校准分数和最终权重不变；
- **回合级质量守恒**：每个回合内总权重等于该回合的原始信任权重之和；
- **单调排序保持**：相等信任的 token 中，影响力分数越高则权重越高。

### 6. 主要结论与发现

1. **信任不等于效用**：纯信任分配将 60.1% 的教师支持质量投给目标对立的 token，ICSD 将此降至 37.8%（22.3 个百分点的下降，95% CI [22.1, 22.6]）。
2. **ICSD 在所有匹配指标上优于信任基线**：在 GRPO 和 GiGPO 下，两个模型家族、五种规模的配置中均一致成立。
3. **最佳结果**：Qwen2.5-7B + GiGPO + ICSD 达到 ALFWorld 成功率 96.1%、WebShop 得分 93.1 / 准确率 84.4，大幅超越 SDAR 基线的 94.5 / 88.4 / 78.9。
4. **梯度兼容性提升**：在 16 个冻结批上，ICSD 将蒸馏梯度与 RL 梯度的余弦兼容性平均提高 0.192（95% CI [0.147, 0.240]），所有批次均为正向提升；置换同一批权重后仅剩 0.020 增益，证明收益来自 token 分配而非总质量变化。
5. **无需额外模型计算**：ICSD 不增加前向/反向传播，只做分离的逐元素操作（端到端开销约 0.4%），这在十亿参数模型在线训练中极为重要。

### 7. 优点

- **问题定位精准**：敏锐指出信任-效用错配这一 OPSD 中的根本缺陷，并用数据支撑（60.1% 目标对立质量）。
- **计算高效**：不需要参数空间影响力函数（如 Hessian 逆求解或重复 HVP），仅使用 RL 更新中已有的量即可计算，是**零额外模型调用**的轻量方案。
- **理论属性明确**：具有仿射不变性、回合级质量守恒和单调排序保持等良好性质，保证了分配规则的稳定性和可解释性。
- **设计谨慎**：保守回退机制正确处理了双负符号歧义区域；分离权重确保不影响 RL 替代目标；回合级质量匹配防止辅助损失总量被篡改。
- **机制验证充分**：不仅报告终端指标，还通过 frozen-batch 分析、TCM 指标、梯度余弦兼容性、置换检验等手段确认了方法的因果机制。
- **开源可复现**：提供了公开代码仓库。

---

### 8. 不足与局限

- **模型覆盖有限**：仅测试了 Qwen 家族（Qwen2.5 / Qwen3），未验证在其他架构（如 Llama、Mistral、Gemma）上的泛化性。
- **终端指标统计显著性不足**：主结果表中的大部分指标未报告多次独立运行的均值与方差，仅有 best 值；统计推断主要用于机制分析而非终端性能，存在结果可靠性的不确定空间。
- **Search-QA 提升幅度较小**：在该任务上的提升不如 ALFWorld 和 WebShop 显著，ICSD 对推理型长链任务的作用强度有待进一步验证。
- **裁剪暴露未完全消除**：影响力分数定义在未裁剪的替代项上，而部署损失会裁剪策略比率。虽然审计表明受影响 token 占比极小（0.128%），但存在理论上的不一致性。
- **基础设施细节披露不足**：未完整提供所有实验的 GPU 类型、并行策略、训练时长、能耗等详细信息，增加了复现难度。
- **应用限制**：ICSD 依赖已有的 RL 优势估计和教师差距信号，对于不使用优势估计器的训练范式的适用性需要额外论证。
