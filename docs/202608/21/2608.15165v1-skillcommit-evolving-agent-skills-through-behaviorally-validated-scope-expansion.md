## 摘要
大型语言模型（LLM）智能体可以通过将历史经验转化为可重用的程序性知识，在不断更新参数的情况下持续改进。然而，现有方法通常基于语义相似性或LLM判断来整合经验，这可能将表面上相关但行为上不兼容的策略合并在一起，从而降低性能。为解决这一问题，我们提出了SkillCommit，一种在线技能演化框架，可不断将经验转化为分层结构的可重用技能库。每条新经验最初被保留为实例特定的补丁，保留其局部上下文中经过验证的行为。随着相关技能的积累，SkillCommit将那些共享共同行为机制的技能抽象为更高级别的技能。具体来说，对于每个传入的技能，基于嵌入的检索首先识别出候选的相关技能。跨实例重放和基于LLM的机制检查用于确定这些技能是否能在不同案例间迁移，以及是否共享共同的潜在机制。通过这两项检查的候选技能被抽象为更高级别的技能，并且仅当它保留了所有组成技能的已验证行为时才被提交。在RuleArena、OpenExempt和KOR-Bench上的实验表明，SkillCommit在不同领域持续提升了智能体的性能。此外，学习到的技能可在不同模型规模和系列间迁移，实现跨模型的经验转移。

## Abstract
Large language model (LLM) agents can continually improve without parameter updates by converting historical experience into reusable procedural knowledge. However, existing methods often consolidate experience based on semantic similarity or LLM judgments, which may merge superficially related but behaviorally incompatible strategies and thereby degrade performance. To address the issue, we propose SkillCommit, an online skill evolution framework that continuously transforms experience into a hierarchical library of reusable skills. Each new experience is initially preserved as an instance-specific patch, retaining the behavior validated in its local context. As related skills accumulate, SkillCommit abstracts those sharing a common behavioral mechanism into higher-level skills. Specifically, for each incoming skill, embedding-based retrieval first identifies candidate related skills. Cross-instance replay and an LLM-based mechanism check determine whether these skills transfer across cases and share a common underlying mechanism. Candidates that pass both checks are abstracted into a higher-level skill and committed only if it preserves the validated behavior of all constituent skills. Experiments on RuleArena, OpenExempt and KOR-Bench demonstrate that SkillCommit consistently improves agent performance across diverse domains. Moreover, the learned skills transfer across model scales and families, enabling cross-model experience transfer.

## SkillCommit：通过行为验证的范围扩展来演化智能体技能——论文分析与总结

### 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：大语言模型（LLM）智能体在不更新模型参数的前提下，可以通过将历史经验转化为可复用的程序性知识（即“技能”）来持续改进。然而，实际场景中的领域知识往往散落在执行轨迹和任务反馈中，难以预先以完整文档形式获取。
- **核心问题**：现有技能学习方法（如ExpeL、ReasoningBank、ACE、Trace2Skill等）习惯于基于**语义相似度**或**LLM主观判断**来合并经验，但语义上相似的补丁可能编码了相互冲突的策略，而语义上不同的补丁可能共享相同的行为机制。这种“以表面相似度代替行为兼容性”的做法，会导致行为不兼容的经验被错误合并，进而降低智能体的性能。
- **论文主张**：可靠的技能演化需要超越表面相似度的标准——具体而言，技能的每一次“范围扩展”（从实例补丁到更高级别的抽象技能）都必须经过**行为验证（behavioral validation）**，即以重放（replay）证据来支撑更广泛适用性的声明。

### 2. 方法论

SkillCommit是一个在线技能演化框架，将技能库的构建视为一系列“行为验证的范围扩展”过程，包含三个阶段：

**阶段一：反馈引导的补丁归纳（Feedback-Guided Patch Induction）**

- **补丁生成**：当执行器在某实例上失败时，教师模型（teacher model）在获得原始任务、标准答案和失败轨迹后，生成一条到达正确结果的参考轨迹，并诊断失败与成功行为之间的差异，最终产出一条包含行为约束、决策规则等程序性指导的候选补丁。
- **防泄漏处理**：包含最终答案或实例特定解决方案的候选补丁会被丢弃。
- **来源重放验证**：候选补丁通过“冻结执行器”在来源实例上重放验证；若补丁能引导执行器成功解决该实例，则被接纳为“实例特定补丁”；否则生成下一轮补充重放轨迹和验证反馈，最多尝试K=3轮。论文统计显示，88.0%的失败实例能在3次尝试内获得验证通过的补丁，其中91.8%在前2次内成功。

**阶段二：行为兼容性分组（Behavioral Compatibility Grouping）**

该阶段判断一个经验补丁能否在原始实例之外被更广泛地复用，包含两条路径：

- **扩展已有技能**：通过嵌入编码计算新补丁与现有高级技能描述的余弦相似度，检索出前R个候选（R=4）。随后进行**跨实例重放**：将已有技能补丁重放到新来源实例上，同时将新补丁重放到已有技能覆盖的实例集上。行为兼容性分数计算如下：

  `C(p, q_t) = (ρ(p, x_t) + Σ_{x_j∈W(p)} ρ(q_t, x_j)) / (1 + |W(p)|)`

  其中ρ(m, x)∈{0,1}表示冻结执行器在仅由记忆m引导时能否解决实例x。当C(p, q_t) ≥ γ（阈值）时通过行为兼容性筛查。随后由“模式作者”（pattern author）通过LLM机制检查判断两个记忆是否共享潜在程序机制。两项都通过后，提出一个覆盖新来源的扩展技能候选。

- **形成新技能**：若无现有技能通过检验，则在仍未被任何高级技能纳入的“残留补丁”中检索语义相关的候选集，通过跨实例重放评估行为兼容性，寻找一个“锚点补丁”能迁移到组内所有其他补丁的来源实例。合格组须至少包含m个成员（m为超参数，依数据集设为2或3）。选取行为覆盖最广的合格组用于诱导新技能。

**阶段三：保留来源的整合（Source-Preserving Consolidation）**

- **候选技能归纳**：由模式作者（不接触原始问题、答案、教师轨迹或来源信息）基于匿名补丁文本生成技能，包含三个字段：`when`（适用条件）、`repair`（可执行程序性指导）、`avoid_when`（排除条件）。
- **全范围来源重放**：在候选技能声明的所有来源实例上使用冻结执行器重放；若全部成功，则视为完全支持；否则由模式作者基于重放轨迹和验证反馈进行迭代精炼，最多L轮。
- **三种提交决策**：
  - **提交（Commit）**：候选在全部来源上重放成功，即提交为（或更新为）高级技能，同时保留旧版本以追踪溯源。
  - **拆分（Split）**：仅在部分来源上成功时，若支持集合大小≥m，则缩窄范围后重新验证，通过则作为独立高级技能提交。
  - **拒绝（Reject）**：支持集合不足或缩窄后验证失败，则丢弃候选，相关补丁继续以实例特定技能形式保留。

### 6. 主要结论与发现

- **SkillCommit在全部18个任务配置中均超过No Skill基线，并在每个任务上取得最佳成绩**，将各任务指标的无加权均值从50.80%提升至78.15%。
- 匹配模型配置下，DeepSeek-V4-Flash和Qwen3.6-35B-A3B的六任务平均分分别提升19.33和30.02个百分点；SkillCommit最强竞争方法（Trace2Skill）在三个配置中的平均分分别高出14.48、28.08和28.01个百分点。
- **对比基线方法的分析揭示**：ExpeL、ReasoningBank、ACE、Trace2Skill中，72个任务级结果中有31个低于无技能基线、6个持平，说明**未经行为验证的经验记忆要么帮助有限，要么引入的新错误抵消了收益**。实例级分解显示，这些方法普遍存在“修复一些案例但破坏更多原本正确案例”的模式。
- **组件消融证实了三阶段的必要性**：补丁归纳贡献了最大的性能增益（去除后下降17.78个百分点）；兼容性分组和来源保留整合各贡献约4.44个百分点；仅保留补丁归纳可达到64.44%的次优水平，说明核心收益来自将建议转化为冻结执行器已验证可执行的指导。
- **跨模型迁移结论**：Qwen-35B作者技能使Qwen-9B用户的平均分从48.97提升至75.25（同族跨规模）；GPT-5.4作者的技能使其提升至69.75（跨族跨规模）。迁移有效但并非无损，说明技能保留了可复用的程序性核心，但仍带有执行器特定解读和提示约定的残余差异。
