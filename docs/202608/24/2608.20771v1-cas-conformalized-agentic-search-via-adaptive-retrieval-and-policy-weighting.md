## 摘要
搜索智能体在强化学习（RL）微调过程中面临严重的可靠性危机。启发式Top-K检索常导致关键证据丢失或噪声引入，而渐进式RL引发的过度自信则导致幻觉答案和冗余搜索。为构建高度可靠的智能体，我们引入共形预测（CP）并提出共形化智能体搜索（CAS）框架。该框架在检索端和训练端均建立了可靠性保证：在检索端，自适应预测集（APS）作为CP的一种具体实现，将统计覆盖率转化为动态文档截断，从而构建大小自适应的预测集；在训练端，自适应共形推断（ACI）作为一种动态CP算法，动态构建具有可控覆盖率的预测集以量化答案置信度，并将其用于在组相对策略优化（GRPO）目标中对低置信度轨迹进行惩罚，确保模型仅从可靠轨迹中学习。跨单跳和多跳问答数据集的实验表明，我们的框架显著提升了推理准确性，同时大幅减少了冗余工具调用，建立了一种高度可靠且高效的智能体范式。我们的代码可在https://github.com/S1llyBird/CAS获取。

## Abstract
Search Agents face a severe reliability crisis during reinforcement learning (RL) fine-tuning. Heuristic Top-K retrieval often causes critical evidence loss or noise inclusion, while over-confidence induced by progressive RL leads to hallucinated answers and redundant searches.   To build highly reliable agents, we introduce Conformal Prediction (CP) and propose Conformalized Agentic Search (CAS). This framework establishes reliability guarantees on both the retrieval and training sides: on the retrieval side, an Adaptive Prediction Set (APS), a specific CP realization, translates statistical coverage into dynamic document truncation to construct prediction sets that are adaptive in size; on the training side, Adaptive Conformal Inference (ACI), a dynamic CP algorithm, dynamically constructs prediction sets with controllable coverage to quantify answer confidence, which is then used to penalize low-confidence trajectories within the Group Relative Policy Optimization (GRPO) objective, ensuring the model learns only from reliable ones.   Experiments across single-hop and multi-hop QA datasets demonstrate that our framework significantly improves reasoning accuracy while drastically reducing redundant tool invocations, establishing a highly reliable and efficient agent paradigm. Our code is available at https://github.com/S1llyBird/CAS.

  - **训练端**：LLM在RL训练过程中易出现过度自信（overconfidence），导致产生幻觉答案和冗余的重复搜索。

### 2. 论文提出的方法论：核心思想、关键技术细节

**总体框架**：CAS（Conformalized Agentic Search）——首次将CP引入搜索智能体的RL微调中，在检索端和训练端同时施加统计可靠性约束。

**（1）检索端：自适应预测集（APS）**

- 核心思想：将CP的边际覆盖保证转化为动态文档截断，使检索文档数量随查询难度自适应调整。
- 技术细节：
  - 搜索返回初始候选文档集 D = {d₁, d₂, …, dₙ} 及原始检索分数。
  - 对检索分数用softmax归一化，得到每个文档的相关性概率 p(dᵢ|q)。
  - 按概率从高到低累积，直到累积概率首次超过校准阈值 q̂_APS，确定截断索引 k。
  - 最终返回动态子集 D_APS = {d₁, …, d_k}。
- 效果：简单查询获得紧凑的文档集（减少噪声），复杂查询获得扩充的文档集（确保证据完整）。

**（2）训练端：自适应共形推断（ACI）+ 加权GRPO**

- 核心思想：使用ACI动态构造预测集以量化答案置信度，并在GRPO目标中惩罚低置信度轨迹。
- 非一致性分数定义：以最终答案 `<answer>...</answer>` 标签内生成token的平均负对数似然（NLL）作为非一致性分数：

  s(xₜ, yᵢ) = Σⱼ∈Mᵢ (−log πθ(yⱼ|y<ⱼ, xₜ)) / |Mᵢ|

- ACI动态更新规则（带指数加权移动平均平滑）：

  αₜ₊₁ = αₜ + γ(ρ − Σₛ₌₁ᵗ vₛ·errₛ)

  其中 ρ 为目标错误率，γ 为步长，vₛ 为时间权重（平滑因子0.95），errₛ 为历史误覆盖指示器。

- 分位数阈值：在滚动校准窗口（最近2000个分数）上计算经验分位数 q̂ₜ = Q̂ₜ(1 − αₜ)。
- **ACI引导的GRPO损失函数**：

  L_GRPO(θ) = E[(1/G)Σᵢ₌₁ᴳ ωᵢ L_clipᵢ(θ) − βD_KL(πθ‖π_ref)]

  - 权重 ωᵢ 的设定：若 s(xₜ, yᵢ) ≤ q̂ₜ（高置信度），ωᵢ = 1；否则（低置信度），ωᵢ = η（折扣因子，默认0.5）。
  - 该权重与RL优势Aᵢ协同形成双重约束：
    - 对低置信度但高奖励的"幸运猜测"：折扣正向强化，防止模型学习猜测。
    - 对高置信度但低奖励的"自信错误"：施加完整惩罚。

**（3）奖励设计**

- 奖励函数：r(x, y) = r_acc + r_fmt
  - r_acc：精确匹配（EM）指示器。
  - r_fmt：格式奖励，包含结构完整性 I_valid 和答案边界 I_ans 两个布尔指示器，防止奖励黑客。

- **主结果**：CAS在全部7个数据集上均取得最佳或次佳表现。在Qwen3-8B上平均EM达0.464，超越Search-R2（0.446）与Search-R1（0.400）；在Qwen2.5-3B上平均分0.401，比Search-R1提升+0.065。

- **效率显著提升**：ACI约束使模型在训练过程中保持稳定且较低的搜索调用频率，避免了盲目过度自信和不必要的验证性搜索。
- **模块互补性**：APS提供自适应、低噪声的上下文；ACI抑制不必要的探索性搜索——二者协同是实现最优性能的关键。

### 7. 优点：方法与实验设计亮点

- **理论严谨性与实践性能的平衡**：首次将CP框架系统性地引入搜索智能体的RL微调中，为检索和训练两端同时提供严格的有限样本统计保证（边缘覆盖率、长期错误率收敛），而非仅仅依赖启发式方法。
- **模块化设计具有清晰的分工与协同**：APS解决"检索多少"（信息完整性），ACI解决"相信什么"（输出置信度），两者互补性强。消融实验明确验证了这种协同关系。
- **时间适应性设计得当**：ACI采用指数加权移动平均平滑，降低αₜ局部波动；滚动校准窗口适应策略演化；对非平稳分布具有理论保证。
- **奖励设计细致**：格式奖励对正确答案与错误答案分别采用不同处理策略，有效防止奖励黑客。
- **实验分析深入**：不仅报告静态精度指标，还通过训练动态可视化（搜索调用演化、αₜ收敛轨迹）揭示方法内在机理；案例研究直观展示方法在噪声检索和多跳推理下的行为模式。

### 8. 不足与局限

- **任务覆盖局限**：实验仅限于开放域QA。专业领域（法律、医疗、科学等）的适用性未经验证；也未覆盖代码生成、工具调用等更广泛的agentic场景。
- **对强外部模型的依赖**：构建APS校准集需要依赖DeepSeek-V3.2进行查询分解和相关判断，这引入了较高的外部依赖成本，且校准质量直接受teacher模型能力影响。
- **仅保证结果可靠性，未覆盖过程可靠性**：CAS只对最终答案提供统计保证，中间推理步骤（如多跳链中的每个中间结论）缺乏不确定性量化。
- **敏感性局限**：ACI的超参数（γ、η、EMA平滑因子）和APS的α_APS均需要仔细调优。过严（ρ=0.4）或过松（ρ=0.1）的置信度阈值都会明显损害性能。
- **消融验证覆盖不足**：消融和敏感性分析仅在3B模型上进行，8B模型上缺少对应验证；与Search-R2的对比因闭源而无法在3B上完成。
- **假设条件与实现细节**：虽然ACI对分布偏移稳健，但APS的校准依赖标准CP的交换性假设；在多轮检索场景中，检索分布会随策略变化而产生偏移，APS在这种动态环境下的覆盖保证还需进一步验证。
- **训练时长未报告**：论文未报告总训练时长或GPU hour，无法从算力成本角度评估方法的效率优势。
