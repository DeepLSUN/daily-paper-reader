## 摘要
智能体语言模型会反复编码在不同请求中以不同组合和顺序出现的工具与技能模式，这阻碍了标准前缀缓存重用其键值（KV）状态。我们提出了ReCache框架，用于独立缓存资源表示，同时降低其推理时的计算和内存开销。资源级注意力消除了跨资源交互，并分配资源局部位置，从而产生组合不变的KV块。随后，ReCache将资源可见性限制在贡献选择的层-KV头组路由上，并通过结构和语义剪枝仅保留调用关键字段。我们在由七个公共工具和技能使用数据集组成的基准上评估了ReCache，包括资源不相关测试。资源级注意力匹配密集调用性能（82.3%对比82.4% Inv-F1），同时提供3.655倍的首次令牌时间加速。完整框架将分配的KV张量内存减少92.43%，并将注意力加速1.423倍。这些结果表明，将可重用模式编码与选择性资源访问分离，能在有限的效果损失下大幅降低智能体推理成本。代码可在https://github.com/EIT-NLP/ReCache获取。

## Abstract
Agentic language models repeatedly encode tool and skill schemas that recur across requests in different combinations and orders, preventing standard prefix caching from reusing their key--value (KV) states. We introduce \textbf{ReCache}, a framework for independently caching resource representations while reducing their inference-time computational and memory overhead. Resource-wise attention removes cross-resource interactions and assigns resource-local positions, producing composition-invariant KV blocks. ReCache then restricts resource visibility to contribution-selected layer--KV-head-group routes and retains only invocation-critical fields through structural and semantic pruning. We evaluate ReCache on a benchmark assembled from seven public tool- and skill-use datasets, including resource-disjoint tests. Resource-wise attention matches dense invocation performance (82.3\% versus 82.4\% Inv-F1) while providing a 3.655$\times$ time-to-first-token speedup. The complete framework reduces allocated KV-tensor memory by 92.43\% and accelerates attention by 1.423$\times$. These results show that separating reusable schema encoding from selective resource access substantially reduces agentic inference costs with limited effectiveness loss. The code is available at https://github.com/EIT-NLP/ReCache.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **问题背景**：工具增强型智能体语言模型（Agentic LLMs）在响应不同请求时，需要反复编码动态检索到的工具和技能模式（论文中统称为“资源”，Resource）。这些资源以不同组合和顺序反复出现，导致了大量重复的预填充（Prefill）计算。
- **核心矛盾**：标准的KV缓存复用（如前缀缓存，Prefix Caching）要求被复用的内容必须构成完全一致的前缀，而动态组合的资源上下文几乎不可能满足这一条件，使得KV缓存复用机制无法奏效。
- **研究动机**：论文通过实验发现，模型在资源内部的注意力强度显著高于跨资源之间的注意力（图1a），同时对话令牌对资源的注意力主要集中在末尾令牌上（图1b）。这表明资源内部的语义信息比全局资源顺序更为关键，为独立缓存资源表示提供了实证基础。
- **整体目标**：提出一种能够独立缓存、复用并压缩资源级KV表示的框架，从而在有限的效果损失下大幅降低智能体推理的计算和内存开销。

## 2. 方法论：核心思想、关键技术细节与算法流程

ReCache 采用渐进式三阶段策略，将资源编码与交互访问分离，通过三个核心机制实现高效的 KV 复用与压缩：

### 2.1 资源级注意力（Resource-Wise Attention）

- **核心思想**：移除不同资源块之间的交叉注意力，仅保留资源内部（即资源内令牌到共享前缀和资源内令牌）的注意力路径；同时将位置索引重置为资源局部位置（每个资源从位置0开始）。
- **实现效果**：注意力复杂度从 O(D²_R) 降为 O(∑D²_i)（D_R 为总资源长度，D_i 为单个资源长度），使每个资源块成为位置无关、组合不变的独立KV块，可被独立构造和跨请求复用。
- **模型适应性**：通过轻量级微调，使模型适应这种注意力模式与位置重置设置。

### 2.2 结构剪枝（Structural Pruning）

- **核心思想**：Transformer的不同层和KV头组对资源调用预测的贡献存在显著差异，因此只需向少数关键层–KV头组路由暴露资源KV状态。
- **关键技术：贡献度引导的路由选择**
  - 对每个路由（层l与KV头组g的组合），采用 **leave-one-in** 分析，即从 Ω=∅（对话令牌无法访问资源）出发，单独激活某个层或头组，度量其在精简数据集 D_h 上的调用损失（Invocation Loss）降低幅度。
  - 调用损失定义：ℓΩ(X, Y) = −(1/|T(Y)|) Σ_{t∈T(Y)} log p^Ω_θ(y_t | y_{<t}, X)，只对目标调用的生成位置计算损失。
  - 损失降低量归一化为贡献权重 w_i = max(s_i, 0) / Σ_j max(s_j, 0)，据此选出 Top-K 的层和头组，构造最终路由配置 Ω⋆ = L⋆ × G⋆。
- **调度机制**：Ω⋆ 内的路由使用 M_resource（资源可见的注意力掩码），其余路由使用 M_context（结构上裁剪掉所有资源令牌，仅保留上下文令牌间的标准因果注意力）。

### 2.3 语义剪枝（Semantic Pruning）

- **核心思想**：资源模式是高度结构化的文本，不同字段对调用行为的影响不同，保留调用关键字段比压缩通用文本更为重要。
- **保留字段**：资源名称（支持资源识别）、参数名称（支持参数接口对齐）、参数描述（提供参数值约束），以及每个资源的最终末尾令牌（作为聚合前面字段信息的语义锚点，利用其因果状态）。
- **对比动机**：通用摘要方法（如Gist、Beacon）在资源场景下会使模型丢失精确的接口信息，导致幻觉频发，因此需要字段感知的压缩策略。

## 6. 主要结论与发现

- **资源级注意力的有效性**：Block与Ωfull相比Dense，各项指标差异不超过0.2%，说明跨资源注意力和全局资源顺序对资源调用贡献有限；Ωfull实现3.655×的TTFT加速。
- **贡献度引导的结构剪枝优于注意力基准**：在相同结构预算下，Ω20,G相较Ωfull+SPEED，在TIND上Inv-F1高3.2%，在TOOD上高10.0%；Ω20,3相较SA20,3在两个测试集上分别高3.0%和5.0%。OOD幻觉率显著更低（0.5% vs 13.4%/5.1%）。
- **字段感知语义剪枝优于通用压缩方法**：Gist严重损害效能（TIND Inv-F1仅39.2%）；Beacon不足；SMP保留了较完整的调用性能（TIND 81.6%，OOD 62.8%）。
- **完整框架效果**：ReCache实现1.423×注意力加速，KV张量内存减少92.43%（上限0.03 GiB），在TIND上保持Dense Inv-F1的97.5%，在TOOD上保持91.8%。
- **结构预算依赖模型规模**：Qwen3-4B仅需3个KV头组即可保持性能（CC仅47.3%），而Qwen3-1.7B需要7个（CC 99.3%），说明较大模型具有更强的结构冗余和可替换性。

## 7. 优点

- **问题洞察深刻**：通过注意力可视化的实证分析（图1）直接验证了“资源内部注意力主导”和“后缀令牌作为信息聚合点”的核心假设，方法论有扎实的实证基础而非纯粹启发式。
- **多粒度、多维度压缩**：从注意力模式（块级）、结构路由（层与头组级）、令牌保留（字段级）三个层面系统性地压缩资源KV状态，实现了可组合、多层次的效率提升。
- **贡献度引导的选路标准**：基于 leave-one-in 的预测损失贡献度量，比注意力质量（SA）和层对称剪枝（SPEED）更具解释力和更强的OOD泛化能力。
- **字段感知的语义剪枝**：针对资源模式的结构化特性设计了专用压缩策略，与通用文本压缩方法相比显著保留了调用所需的关键接口信息，体现了领域适配性。
- **Benchmark构建严谨**：多样性优先的采样策略有效避免了重复资源和候选配置造成的频率偏差；同时构建资源不重合的OOD测试集，使泛化能力的评估更加可信。
- **效率分析完整**：TTFT、TPOT、注意力延迟、KV内存四维度的效率分析覆盖了预填充、解码和缓存的全链路，且按资源长度分档考察了方法的可扩展性。

## 8. 不足与局限

- **实验覆盖范围有限**：
  - 端到端实验仅使用Qwen3-4B，结构预算分析虽覆盖Qwen3-1.7B，但未在更大模型（如7B/14B/32B）上验证方法有效性，结论的模型普适性存疑。
  - 论文未报告多轮对话、并行调用等更复杂的真实智能体场景下的实验数据。
- **训练成本与适用前提**：
  - ReCache修改了注意力掩码和位置编码，因此需要微调模型，无法直接适用于冻结模型（frozen model），限制了在现有服务上的零成本部署。
  - 方法假设系统指令和资源模式相对稳定（可复用前提），对于检索顺序或跨资源依赖承载关键信息的动态环境可能不适用。
- **基准隐患**：论文虽然做了多样性采样和幻觉调用过滤，但未报告各数据集在过滤前/后的具体质量指标（如解析通过率等），难以评估数据质量波动对结果的影响。
