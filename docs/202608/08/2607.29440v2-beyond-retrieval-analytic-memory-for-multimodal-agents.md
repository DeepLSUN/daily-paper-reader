## 摘要
长期多模态记忆不仅需要支持检索相关信息，还需要对跨交互累积的观测进行计算。现有系统主要强调\emph{检索记忆}，通过摘要和索引组织交互历史，以多种粒度返回查询相关信息，从高层抽象到底层记录。在本文中，我们将\emph{分析记忆}定义为一种互补抽象，它将重复出现的多模态观测组织成可查询的结构，支持过滤、聚合、排序和时间比较。我们提出AdaMM，一个联合支持检索和分析记忆的框架。AdaMM不依赖应用定义的模式，而是从对话、图像和上下文元数据中提取具有来源链接的属性-值观测，发现重复出现的字段结构，并将其物化以供分析访问。在推理时，一个记忆感知规划器将查询分解为检索和分析操作，并将每个操作路由到适当的工具。在两个长期多模态记忆基准MemEye和MemGallery上的实验表明，AdaMM分别将性能提升了11.3\%和6.9\%。

## Abstract
Long-term multimodal memory must support not only retrieving relevant information but also computing over observations accumulated across interactions. Existing systems largely emphasize \emph{retrieval memory}, organizing interaction histories through summaries and indexes to return query-relevant information at multiple granularities, from high-level abstractions to underlying records. In this paper, we formulate \emph{analytic memory} as a complementary abstraction that organizes recurring multimodal observations into queryable structures supporting filtering, aggregation, ranking, and temporal comparison. We present AdaMM, a framework that jointly supports retrieval and analytic memory. Rather than relying on application-defined schemas, AdaMM extracts provenance-linked attribute-value observations from dialogue, images, and contextual metadata, discovers recurring field structures, and materializes them for analytical access. At inference time, a memory-aware planner decomposes queries into retrieval and analytic operations and routes each operation to the appropriate tools. Experiments on two long-term multimodal memory benchmarks, MemEye and MemGallery, show that AdaMM improves performance by up to 11.3\% and 6.9\%, respectively.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：随着大语言模型（LLM）智能体与用户在长时间跨度内交互，它们会积累庞大的多模态历史记录（对话、截图、图像、文档等）。这些记录远超模型有限的上下文窗口，因此多模态记忆系统成为必要。现有系统主要采用“检索-回答”范式，即将查询相关的少量记忆片段作为上下文提供给LLM，这种方式被称为**检索记忆**。
- **核心问题**：论文指出，这种以相关性为基础的检索记忆存在一个内在缺陷，即**“检索-分析不匹配”**。对于需要完整范围数据进行计算的分析性查询（如过滤、聚合、排名、时间比较），检索只能返回“相关”而非“完整”的数据子集。较小的检索集可能遗漏关键观测，导致结果有偏；较大的检索集则占用有限的上下文预算，并引入冗余信息。
- **整体含义**：现有记忆系统擅长“回忆”历史信息，但不擅长“计算”历史信息。本文旨在弥合这一差距，引入**分析记忆**作为检索记忆的互补，使智能体不仅能找到信息，还能对累积的观察进行结构化运算。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 提出一个联合框架**AdaMM**（Adaptive Multi-view Memory），将记忆系统解耦为两个互补子系统：
  - **检索记忆**：负责灵活的语义回忆，通过层次化组织（主题→片段→事件）支持开放式事件和视觉细节的查询。
  - **分析记忆**：主动从交互历史中归纳出可重用的结构化模式（即Schema），将其物化为可查询的表结构，以支持精确的过滤、聚合、排序和时间比较。
- 关键是不依赖应用定义的模式，而是通过数据驱动的方式**自动发现**并演化出模式。

### 关键技术与流程

**阶段一：分析记忆构建（Analytic Memory Construction）**

1.  **属性提取（Attribute Extraction）**：
    - 对每个交互轮次，使用LLM提取器联合检查对话和视觉内容，识别所有有依据的属性-值对，并链接到其来源（对话片段或图像）。
    - 公式：`O_t = Extractor(R_t) = {(a_t^l, x_t^l, p_t^l)}`，其中a是属性，x是值，p是来源指针。

2.  **模式归纳（Schema Induction）**：通过以下两个过程发现和演化模式：
    - **候选模式挖掘**：基于Apriori频繁项集挖掘框架，使用**支持度**（support）衡量属性集C在历史轮次中共同出现的次数，`supp_t(C) ≥ θ_s` 则保留为候选。
    - **模式发现（Schema Discovery）**：使用**全置信度**（all-confidence）来衡量模式内部属性的共现一致性，`all-conf_t(C) = supp_t(C) / max_a∈C supp_t({a}) ≥ θ_a`。只有满足该阈值的包含最大新颖候选模式才会被接纳为新Schema，防止某个普遍属性被错误合并到大多数模式中。
    - **模式演化（Schema Evolution）**：当现有模式A是候选C的子集时，使用**扩展置信度**（extension confidence）评估新属性∆的稳定性，`ext-conf_t(C|A) = supp_t(C) / supp_t(A) ≥ θ_e`。如果满足，则将模式A扩展为C。

3.  **记忆物化（Memory Materialization）**：
    - 每个诱导出的Schema被物化为一张关系表`T_A`，属性作为列，匹配的交互作为行。
    - 使用语言模型为表生成元数据（名称、描述）并推断列类型。
    - 每个交互轮次提取的值构成一行记录，并附带`order`和`time`辅助列。

**阶段二：检索记忆构建（Retrieval Memory Construction）**
- 采用“主题（topic）→ 片段（episode）→ 事件（event）”的三级层次结构组织交互历史。
- 事件保留轮次级证据；片段由时间相邻且语义连贯的事件构成；主题聚合相关片段。
- 每个节点维护独立的文本和视觉嵌入，用于多模态相似度计算。

**阶段三：自适应查询处理（Adaptive Query Processing）**
- **记忆访问工具**：将不同记忆的底层能力抽象为工具，如分析工具（LOOKUP, FILTER, COMPUTE, RANK）和检索工具（SEMANTIC MATCH, EVENT LOCATE）。
- **规划上下文构建**：将待选表/片段的元数据与查询进行匹配（融合语义编码和BM25），选出相关条目，并附带其可用工具描述，形成规划上下文`D_q`。
- **渐进式工具执行规划**：该框架采用“高层规划-渐进实例化”的两阶段策略。
    - 首先，规划器根据查询和上下文生成一个抽象计划`π̄`，指定信息目标和所需工具。
    - 然后，在执行每一步时，规划器结合上一步的输出结果动态地实例化当前工具的具体参数，这解决了后续步骤参数依赖于先前输出结果的问题。

## 6. 主要结论与发现

- **核心结论**：将**分析记忆**与**检索记忆**相结合，能显著提升多模态智能体在长期记忆任务上的表现，解决了单纯依赖检索无法进行结构化计算的问题。
- **性能提升**：在MemEye和MemGallery上，AdaMM相较于最强基线分别取得最高11.3%和6.9%的绝对性能提升（LLM-Judge指标）。
- **互补性**：消融实验证实分析记忆和分析检索记忆的互补价值——移除分析记忆严重损害健康类数字分析任务（下降14.9%），而移除检索记忆则显著损害品牌类视觉回忆任务（下降9.9%）。
- **规划器的价值**：记忆感知的规划上下文和渐进式工具执行对于复杂查询尤为重要（分别带来3.3%和4.2%等性能提升）。
- **能力边界**：在更依赖直接视觉语义回忆的任务（如卡通娱乐）上，AdaMM的优势相对较小，这符合预期。

## 8. 不足与局限

- **对提取质量的依赖**：分析记忆的质量高度依赖属性提取步骤。如果提取出的属性或值有误或缺失，错误会传播至模式归纳和后续所有计算。论文虽在展望中提出未来可用置信度感知提取及跨轮次一致性校验来解决，但当前仍是一个潜在脆弱点。
