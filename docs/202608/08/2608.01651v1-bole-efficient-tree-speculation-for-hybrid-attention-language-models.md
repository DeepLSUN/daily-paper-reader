## 摘要
混合注意力大语言模型将全注意力与循环线性注意力相结合，以降低长上下文推理成本，但其自回归解码仍受内存限制。树推测解码提供了一种有吸引力的加速路径，但现有的树推测系统是针对全注意力模型的键值缓存设计的。在混合模型上，它们逐分支遍历循环层，并为每个提议节点物化完整状态，导致验证延迟和瞬态内存随树大小和批处理大小扩展性差。我们提出了Bole，一种内核与运行时协同设计，可为混合注意力LLM实现高效树推测。Bole将线性注意力循环转化为树结构闭式形式，并通过资源高效的GPU内核实现，并行验证所有提议节点，将线性注意力树验证加速3.4-7.7倍。它无损地将推测状态更新编码为词元级因子，并仅重构采样后选择的状态，将瞬态状态内存减少82-99倍，释放GPU容量用于KV缓存。其与广泛部署的生产级LLM服务引擎SGLang的集成，将高效状态管理与针对完整混合前向传播校准的批量验证预算相结合。在四个模型、两个GPU平台和多样化数据集上，Bole相比自回归解码提供高达4.72倍离线解码吞吐量，相比最强的树推测基线提供高达2.03倍。在在线代理工作负载下，相比最强树推测基线，其TTFT和TPOT分别降低高达67.6%和49.9%。

## Abstract
Hybrid-attention large language models combine full attention with recurrent linear attention to reduce long-context inference costs, yet their autoregressive decoding remains memory-bound. Tree speculative decoding offers an attractive acceleration path, but existing tree-speculation systems are designed around the key--value caches of full-attention models. On hybrid models, they traverse recurrent layers branch by branch and materialize a full state for every proposal node, causing verification latency and transient memory to scale poorly with tree and batch sizes. We present Bole, a kernel--runtime co-design that enables efficient tree speculation for hybrid-attention LLMs. Bole transforms the linear-attention recurrence into a tree-structured closed form and realizes it with a resource-efficient GPU kernel, verifying all proposal nodes in parallel and accelerating linear-attention tree verification by 3.4--7.7$\times$. It losslessly encodes speculative state updates as token-level factors and reconstructs only the state selected after sampling, reducing transient state memory by 82--99$\times$ and freeing GPU capacity for KV caches. Its integration into SGLang, a widely deployed production LLM serving engine, couples efficient state management with a batch-wide verification budget calibrated to the complete hybrid forward. Across four models, two GPU platforms, and diverse datasets, Bole delivers up to $4.72\times$ the offline decode throughput of autoregressive decoding and up to $2.03\times$ that of the strongest tree-speculative baseline. Under online agent workloads, it reduces TTFT and TPOT by up to $67.6%$ and $49.9%$, respectively, over the strongest tree-speculative baseline.

## 论文详细总结

### 1. 核心问题与整体含义（研究动机和背景）

- **背景**：混合注意力大语言模型（Hybrid-attention LLM）将**全注意力层**与**循环线性注意力层**（如 Gated DeltaNet）交错组合，以固定大小的循环状态压缩前缀，从而降低长上下文推理的 KV 缓存开销。
- **核心问题**：尽管混合注意力降低了单 token 推理成本，其**自回归解码仍以内存为瓶颈**，每个输出 token 都需要一次完整的目标模型调用。树推测解码（Tree Speculative Decoding）通过一次前向验证多 token 树来利用空闲算力，但现有树推测系统均为全注意力模型设计：
  - **逐分支串行遍历循环层**，树规模增大时线性注意力验证时间急剧上升；
  - **为每个提议节点物化完整状态快照**，瞬态内存随树大小和批处理线性增长，挤占 KV 缓存容量；
  - **验证容量存在硬件相关的临界点**，额外 token 并非始终“近乎免费”，而现有系统缺乏硬件感知的自适应预算。
- **整体含义**：现有内核与运行时均无法高效支持混合注意力模型的树推测解码，导致其解码吞吐和在线延迟显著受限于串行递归和状态内存爆炸。

### 2. 论文提出的方法论

#### 核心思想
Bole 提出 **内核–运行时协同设计**（kernel–runtime co-design），通过三项机制解决上述问题：
1. **并行树求解器**：将 Gated DeltaNet 的线性注意力递归转化为树结构闭式形式；
2. **因子化状态生命周期**：用 token 级因子无损表示候选状态更新，仅在采样后重构被选中的状态；
3. **硬件感知验证预算**：按 GPU 与执行配置离线校准批量验证容量。

#### 关键技术细节

**（1）闭式并行树验证（Theorem 1）**
- 对 t 个提议节点，将顺序树执行等价改写为：

  \[
  O = D_P Q S_{pre} + C(I+G)^{-1} D_\beta (V - D_P K S_{pre})
  \]

  其中 \(S_{pre}\) 是共享的树前状态，\(D_P\) 为衰减门积，\(G\) 为祖先遮掩的传递矩阵，\(C\) 为读出行列。
- 三个结构性引理支撑该定理：
  - **Lemma 1（路径因子化状态）**：每个节点的前后状态均可分解为共享状态与沿祖先路径的 rank-1 更新之和；
  - **Lemma 2（祖先遮掩线性系统）**：将校正项堆叠为 \((I+G)U = R\) 的线性系统，\(G\) 严格下三角，仅包含父节点到子节点的依赖；
  - **Lemma 3（深度有界幂零性）**：因 \(G^{d+1}=0\)（d 为最大祖先深度），逆矩阵可展开为有限 Neumman 级数 \((I+G)^{-1} = \sum_{m=0}^d (-G)^m\)。
- 该形式**代数上精确等价于顺序执行**，无需逐节点中间状态。

**（2）值分块（Value-Tiled）并行 GPU 内核**
- 将值维度 \(d_v\) 切成 \(N_v\) 个块，每个块分配给一个 CTA（线程块），覆盖全部树节点；
- 树相关因子 \(G, C\) 由单一生产者构造，被所有值块复用；
- CTA 内部通过张量核（MMA）分块执行状态乘积和深度有界有限 Neumman 迭代，中间结果保留在片上；
- 采用二维资源分块：值块宽 \(b_v\) 与键维度块宽 \(b_k\) 平衡片上存储与并发度。

**（3）融合树验证管线**
- 每轮顶层预处理：构建父映射、祖先掩码、最大深度；
- 每层三级流水：树并行卷积/门预备 → 因子构造 → 值分块求解与读出；
- 实现精确并行且避免每分支完整状态物化。

**（4）因子化推测状态生命周期**
- 每个请求仅保留**一个不可变规范状态 \(S_{pre}\)**；
- 候选分支以 \(P, K, U\) 因子表示，空间复杂度从 \(\Theta(H d_k d_v T)\) 降为 \(\Theta(H d_k d_v + T H(d_k+d_v+1))\)；
- 采样后按被接受路径执行一次矩阵乘法：

  \[
  S_{new} = P_a S_{pre} + (D_a K_a)^\top U_a
  \]

  跨层合并为一次 GPU 启动，拒绝分支不消耗状态缓存。

**（5）硬件感知批量验证调度**
- 离线按配置（模型、GPU、批大小、KV 长度、树模板）扫描总验证节点数 N，选择满足 \(T_{ver}(N|c) \le (1+\epsilon) T_{dec}(c)\) 的最大容量；
- 运行时按批量共享容量分配给各请求的树节点，以累计 draft 概率作为效用评分，全局 top-k 选择且保持前缀连通性。

**（6）生产引擎集成（SGLang）**
- 在 SGLang 中实现约 6.2 kLoC（Python + Triton）；
- 支持 CUDA Graphs 原生的平铺不规则森林、跨层统一状态提交、无气泡 GPU 执行。

- **创新性**：首次将 Gated DeltaNet 树推测验证转化为精确闭式形式，绕开递归关键路径，是算法层面的实质贡献；
- **系统性**：从数学证明（定理+三个引理）到 GPU 内核再到生产运行时全栈设计，逻辑自洽；

### 8. 不足与局限

- **适用模型范围有限**：仅验证 Qwen3.5 系列，闭式形式依赖 Gated DeltaNet 的具体递归结构，其他混合架构（如 Kimi Linear 的不同线性核）可能需要重新推导；

- **硬件平台有限**：A100 与 GB10 虽代表不同计算/内存比，但未覆盖 Hopper、AMD MI 系列等常见推理硬件。
