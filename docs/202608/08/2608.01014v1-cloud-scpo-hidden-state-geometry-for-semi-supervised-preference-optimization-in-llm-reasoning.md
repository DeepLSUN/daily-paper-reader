## 摘要
偏好优化可以提升大型语言模型（LLM）的数学推理能力，但可靠的chosen-rejected对通常需要验证答案、人工标注或外部奖励模型。我们研究在半监督环境中，是否可以从模型内部表示几何中推导出偏好监督。我们的分析表明，跨不同数学问题生成的推理轨迹形成结构化的全局点云，其中正确和错误的轨迹表现出不同的几何组织。基于这一观察，我们提出了Cloud-ScPO，一种拓扑引导的偏好挖掘框架，利用少量标注集构建多个正确和错误的参考点云。每条轨迹通过均值池化隐状态表示，并使用跨参考库平均的组件级软k近邻度量，对连接性诱导组件进行评分。我们将这种跨问题Cloud信号与提示级自洽性相结合：自洽性决定答案级偏好方向，而Cloud评分选择具体轨迹并按分数差异过滤对。在GSM8K和MATH-Numeric上跨四种模型设置的实验表明，Cloud-ScPO始终优于ScPO，在GSM8K上提升高达4.49\%，在MATH-Numeric上提升高达4.19\%。对级分析进一步表明，Cloud-ScPO保持了可比的正确性可靠性，同时更有效地将信息丰富的chosen轨迹与不完整、重复或其他低质量的rejected响应分离。

## Abstract
Preference optimization improves mathematical reasoning in large language models (LLMs), but reliable chosen-rejected pairs usually require verified answers, human annotations, or external reward models. We investigate whether preference supervision can instead be derived from the model's internal representation geometry in a semi-supervised setting. Our analysis shows that reasoning trajectories generated across different mathematical problems form structured global point clouds in which correct and incorrect trajectories exhibit different geometric organization. Based on this observation, we propose Cloud--ScPO, a topology-guided preference-mining framework that uses a small labeled set to construct multiple correct and incorrect reference Clouds. Each trajectory is represented by a mean-pooled hidden state and scored against connectivity-induced components using a component-level soft $k$-nearest-neighbor measure averaged across reference banks. We combine this cross-problem Cloud signal with prompt-level self-consistency: self-consistency determines the answer-level preference direction, while Cloud scoring selects concrete trajectories and filters pairs by their score margin. Experiments on GSM8K and MATH-Numeric across four model settings show that Cloud--ScPO consistently improves over ScPO, with gains of up to 4.49\% on GSM8K and 4.19\% on MATH-Numeric. Pair-level analyses further show that Cloud--ScPO maintains comparable correctness reliability while more effectively separating informative chosen trajectories from incomplete, repetitive, or otherwise low-quality rejected responses.

### 1. 论文的核心问题与整体含义

- **研究背景**：偏好优化（如 DPO、RLHF、GRPO）能显著提升大模型的数学推理能力，但其效果高度依赖**chosen–rejected 偏好对的构建质量**。传统构建方式依赖人工标注、验证答案或外部奖励模型，成本高且在小规模标注下容易失效；在仅有一小部分问题有验证答案的半监督场景下，如何从无标注的推理轨迹中自动挖掘高质量偏好信号是一个关键挑战。
- **核心问题**：能否不依赖外部奖励模型或逐题人工标注，仅利用模型**内部表示几何**来判别轨迹质量，从而在半监督设置下构建可靠偏好对？
- **核心观察**：跨不同数学问题生成的推理轨迹在表示空间中形成**结构化的全局点云**——正确轨迹在更小的过滤尺度下就连接成致密、连贯的区域，而错误轨迹分布更分散、拓扑变化更大。该几何结构可作为偏好监督的信号源。
- **整体含义**：该工作证明“隐状态几何”可以为半监督偏好优化提供可靠的替代监督信号，减少对外部监督的依赖，为后续模型自主挖掘推理质量信号提供了新思路。

### 2. 论文提出的方法论

- **总体框架**：先使用少量标注集（600题）生成轨迹并划分正确/错误池，再用来构建多库参考云；未标注问题的轨迹经 SFT 后生成，用 Cloud 评分+自一致性构建偏好对，最后用 DPO / Cloud–ScPO 目标优化。

- **关键技术细节**：

  - **轨迹表示**：将一条轨迹的末层隐状态在有效回答 token 上做均值池化，再进行 ℓ2 归一化：`z = mean(ht) / ||mean(ht)||₂`。相比只用最后一个 token，均值池化更全面。
  - **参考云构建**：用 600 个有标注问题的轨迹分别形成正确池 P+ 和错误池 P−，反复采样得到 R 个平衡参考库 (C+r, C−r)。
  - **拓扑引导的组件发现**：利用零维 Vietoris–Rips 持久同调 H0，在升序欧氏距离下做连通分量合并，经比例 ρ 截断和尺寸过滤后，得到正确/错误云内部的**早期连接组件** Gcr,j。
  - **组件级软 k 近邻评分**：候选轨迹 z 与每个组件的最近距离通过核 κ(d)=exp(−d^p/τ) 加权（按组件大小加权，p=2），并只取 q 个最近组件，得到组件兼容度 Scr(z)。最终云分数 s_cloud = (1/R) Σ [S+r(z) − λneg S−r(z)]，跨 R 个参考库取平均。
  - **Pure Cloud**：完全不用答案分组，直接选最高/最低 Cloud 分的轨迹作 chosen/rejected，按分数差排序后保留 top-α 比例，用标准 DPO 优化。
  - **Cloud–ScPO 混合策略**：
    - **自一致性定方向**：按提取的最终答案分组，保留唯一多数答案簇为偏好答案，少数簇中选拒绝答案；
    - **Cloud 评分选轨迹**：在多数簇内选 Cloud 分最高的轨迹作 chosen，少数簇内选最低的作 rejected；
    - **置信度过滤**：按 Cloud 分数差 c_hybrid 排序，保留 top-α 比例；
    - **优化目标**：L = E[w(x)( ℓDPO + λNLL ℓNLL )]，使用归一化投票差 w(x) 加权，包含 DPO 项和 chosen 回答的长度归一化 NLL 项。

### 6. 论文的主要结论与发现

- 隐状态几何中的全局连接模式（正确轨迹更致密、更早连通）可作为跨问题的半监督偏好信号。
- Cloud–ScPO 在 GSM8K 和 MATH-Numeric 四个设置上**一致优于 ScPO**，最高提升 4.49%（GSM8K / Mistral-7B）和 4.19%（MATH-Numeric / Qwen3-8B）。
- 偏好对的质量比数量更重要：IRPO-RM 用的数据量是 Cloud–ScPO 的 4~5 倍，但准确率更低。
- Cloud–ScPO 在保持类似理想对率（正确性可靠性）的同时，将更多不完整、截断、重复的轨迹分到拒绝端，并显著扩大 chosen/rejected 长度差。
- Cloud-score gap 可作为筛选高区分度偏好对的置信度信号。
- mean-token 均值池化表示优于 last-token 表示；全局综合判别最优配置为 M=100、R=10，但对极端拒绝端的排序提升依赖更多/更小的参考库。

### 7. 优点

- **信号来源创新**：将持久同调（H0 拓扑）分析转化为实操的轨迹评分机制，而不停留在诊断层面。
