## 摘要
直接偏好优化（DPO）现已成为利用人类偏好数据对齐大语言模型（LLM）的标准方法。每个DPO样本包含一个提示和一对候选模型回复。虽然提示和回复通常是公开的或由模型生成的，但回复之间的相对偏好反映了主观判断，并可能泄露标注者或最终用户的敏感属性。现成的隐私保护方法与这种结构匹配不佳，导致训练中不必要的噪声注入和有偏更新。在本文中，我们形式化了偏好隐私——一种标签DP风格的隐私概念，用于DPO，它仅保护候选回复之间的相对偏好，假设对手已知提示和回复。然后我们设计了PrivDPO，一种在保持与大规模LLM训练兼容的同时实施偏好隐私的DPO变体。我们的主要观察是，对于仅在偏好信号上不同的相邻样本，梯度差异位于一条仅由文本确定的一维偏好轴上；所有偏好信息都通过该轴流动。PrivDPO通过对DPO目标进行无偏随机缩放，仅沿该轴添加校准的随机性，从而避免了逐样本梯度操作。我们在三个对齐基准和三个LLM家族上的实验表明，与隐私保护基线相比，PrivDPO持续实现了强大的隐私-效用权衡。

## Abstract
Direct preference optimization (DPO) is now a standard method for aligning large language models (LLMs) using human preference data. Each DPO example contains a prompt and a pair of candidate model responses. While prompts and responses are often public or model-generated, the relative preference between responses reflects subjective judgments and can reveal sensitive attributes of annotators or end users. Off-the-shelf privacy-preserving approaches are not well matched to this structure, leading to unnecessary noise injection and biased updates in training.   In this paper, we formalize preference privacy, a label-DP-style privacy notion for DPO that protects only the relative preference between candidate responses, assuming an adversary who already knows the prompt and responses. We then design PrivDPO, a DPO variant that enforces preference privacy while remaining compatible with large-scale LLM training. Our main observation is that, for neighboring examples differing only in their preference signal, the gradient difference lies on a one-dimensional preference axis determined solely by the text; all preference information flows through this axis. PrivDPO adds calibrated randomness only along this axis via an unbiased randomized rescaling of the DPO objective, avoiding per-example gradient operations. Our experiments on three alignment benchmarks and three LLM families show that PrivDPO consistently achieves strong privacy-utility trade-offs compared with privacy-preserving baselines.

### 1. 核心问题与整体含义

- **背景与动机**：直接偏好优化（DPO）已成为大语言模型（LLM）对齐的主流方法。每个 DPO 训练样本由三元组 \((x, y_w, y_l)\) 构成，其中 prompt \(x\) 与候选回复 \(y_w, y_l\) 通常来自公开数据或模型生成，而“哪个回复更优”的偏好信号反映了人类标注者或用户的个人判断，可能泄露政治立场、伦理态度等敏感属性。因此，在医疗、金融、法律等垂直场景中，偏好标签本身的隐私保护尤为关键。
- **现有方法的不足**：标准差分隐私（DP）保护整个三元组（prompt + 两个回复 + 偏好信号），但实际场景中文本内容往往是非敏感的，这导致 DP 方法注入过多不必要噪声；随机响应（RR）等标签扰动方法则会给 DPO 优化带来偏差；DP-SGD 需要对每个样本的完整梯度进行裁剪和加噪，计算与内存开销巨大，难以扩展到十亿级以上参数模型。
- **整体贡献**：
  - 形式化了**偏好隐私（Preference Privacy）**——一种标签 DP 风格的隐私定义，只保护偏好信号本身；
  - 提出 **PrivDPO**，通过无偏随机缩放 DPO 目标来实现偏好隐私，避免逐样本梯度操作，与现代大规模训练框架兼容；
  - 在三个对齐基准、三个模型家族（参数规模 3B–32B）上验证了强隐私-效用权衡。

### 2. 方法论

- **核心观察**：对于仅偏好信号不同的相邻样本 \(t=(x,y_w,y_l)\) 和 \(t'=(x,y_l,y_w)\)，其 DPO 梯度差 \(\Lambda\) 只沿一条由文本内容决定的一维方向 \(\mathbf{v}=\nabla_\theta \log \pi_\theta(y_w|x)-\nabla_\theta \log \pi_\theta(y_l|x)\) 变化。作者将这条方向称为**偏好轴（preference axis）**，所有偏好信息都通过该轴流动，其余正交子空间不含偏好信息。
- **偏好强度与区间结构**：定义偏好强度 \(\psi = \sigma(\beta \log \frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)} - \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)})\)。由于 sigmoid 满足 \(\sigma(z)=1-\sigma(-z)\)，翻转偏好等价于将 \(\psi\) 变为 \(\psi-1\)。这使偏好信号在梯度上只表现为两个相差 1 的标量系数，为设计低噪声的私有机制提供了结构条件。
- **无偏扰动机制**：PrivDPO 对偏好强度 \(\psi\) 施加如下无偏随机化：
  \[
  \mathcal{M}_{\text{unbias}}(\psi) =
  \begin{cases}
  \psi + \frac{1}{e^\epsilon-1}, & \text{概率 } \frac{e^\epsilon}{e^\epsilon+1},\\
  \psi - 1 - \frac{1}{e^\epsilon-1}, & \text{概率 } \frac{1}{e^\epsilon+1}.
  \end{cases}
  \]
  该机制满足 \(\mathbb{E}[\mathcal{M}_{\text{unbias}}(\psi)]=\psi\)，保证无偏性；同时两个相邻偏好信号的输出分布满足 \(e^{-\epsilon}\le \Pr[M(t)=r]/\Pr[M(t')=r]\le e^\epsilon\)，满足 \(\epsilon\)-偏好隐私。
- **等价实现——目标缩放**：扰动偏好强度等价于对 DPO 目标进行随机缩放：
  \[
  -\beta\tilde{\psi}\mathbf{v} = \nabla_\theta \left( \mathrm{sg}\left[\frac{\tilde{\psi}}{\psi}\right] \mathcal{L}_{\text{DPO}}\right),
  \]
  其中 \(\mathrm{sg}[\cdot]\) 为 stop-gradient 算子。因此，PrivDPO 无需显式计算或修改单样本梯度，只需在前向过程中计算 \(\psi\)（已包含在 DPO 目标计算中），然后采样一个缩放权重作用于损失即可。
- **算法流程（Algorithm 1）**：
  1. 将数据集随机排列，划分为不相交的 mini-batch；
  2. 对每个样本计算（detach 后的）偏好强度 \(\psi\)；
  3. 按上述扰动机制采样随机权重 \(\tilde{w}\)；
  4. 用 \(\tilde{w}\cdot \mathcal{L}_{\text{DPO}}\) 作为损失反向传播；
  5. 对 batch 内梯度求平均并更新模型参数。
- **私有 SFT 设计（PrivSFT）**：标准 DPO 之前的 SFT 只用优选回复训练，会泄露偏好。PrivDPO 提出的 PrivSFT 对 \(y_w\) 和 \(y_l\) 对称地做极大似然训练，不包含任何偏好信号，因此不产生隐私开销。
- **理论性质**：隐私由“逐梯度释放满足 \(\epsilon\)-偏好隐私”+“变换不变性”保证；单轮训练即可获得数据集级 \(\epsilon\)-偏好隐私；多轮场景可线性组合。梯度无偏性（Lemma 4.1）与沿任意方向的 Bernstein 型误差上界（Theorem 4.2）也一并给出。

### 6. 主要结论与发现

1. **PrivDPO 显著优于隐私保护基线**：在几乎全部配置下，reward margin 比 RR、Duchi、Piecewise 高 2–3 倍，reward accuracy 和 DPO 目标值也一致更优。
2. **与标准 DPO 差距很小**：在 \(\epsilon=1\) 时，PrivDPO 的表现接近非私有 DPO；\(\epsilon=0.5\) 时仍有竞争力，但存在可观察的性能差距，反映了隐私成本。
3. **生成质量同样占优**：LLM-as-a-judge 的 win-rate 显示 PrivDPO 明显胜过所有私有基线，通常达到 58% 以上；与非私有 DPO 相比多数情况下超过 47%，全部配置下不低于 40%。
4. **偏好记忆化风险显著降低**：在“记忆化优势”（MemAdv）指标上，PrivDPO 在隐私预算 \(\epsilon=0.5\) 时接近零，而标准 DPO 在三个数据集上均为 7%–10%。
5. **可扩展性良好**：PrivDPO 可直接适配 FSDP 等大规模训练框架，最高在 32B 模型上仍能保持强对齐效果，训练时间几乎所有增加。

### 7. 优点

- **隐私定义更贴合实际**：偏好隐私将 prompt 与回复视为公开、仅保护偏好信号，比标准 DP 更精准地刻画了 DPO 场景中的真实敏感面，避免不必要的噪声。
- **算法与理论高度匹配**：利用 DPO 梯度沿偏好轴的一维流动结构，将隐私扰动从全参数空间降为一维，同时保持无偏，理论误差与方差都有明确上界。
- **工程实现极为轻量**：仅需对 DPO 目标做随机缩放，无需 per-example gradient、裁剪或额外存储，因此与现有大规模训练流水线天然兼容，可被视为标准 DPO 的 drop-in 替换。
- **实验验证充分**：跨 3 个数据集、4 个模型规模、3 个模型家族的实验，配合 reward、win rate、攻击测试、成本分析等维度，结论具有较好的一般性和可信度。
- **隐私语义明确**：给出与 Pufferfish 一致的语义解释，强调贝叶斯后验变化率受 \(e^\epsilon\) 限制，并支持凸性、变换不变性、顺序组合等基本性质。

### 8. 不足与局限

- **隐私假设有适用范围**：偏好隐私要求 prompt 和候选回复必须是非敏感的。如果文本内容本身包含隐私或专有信息，PrivDPO 不提供保护，必须与标准 DP 等机制结合使用。
- **只针对标准 DPO 目标**：隐私分析依赖 DPO 损失的具体数学形式，无法直接推广到 SimPO、KTO、IPO 等变体；论文也承认这一限制。
- **单轮训练假设**：主要分析基于单 epoch 训练（这也是常见 DPO 实践），多 epoch 时隐私预算线性增长，缺少可能更紧的组合界。
- **实验方面**：
  - 大部分实验为单 seed，标准差不全；
  - 对 32B 模型只做了 Qwen2.5 一个家族，跨家族扩展未验证；
  - 经验攻击为简单“可推断性”检查，并非最强的 worst-case 攻击，MemAdv 只作为 sanity check；
  - DP-SGD 基线仅作为说明性比较，未作为主基准参与全面实验。
- **效用与隐私的理论权衡不够全面**：作者给出的是以概率为 1 的逐方向误差界，但未讨论优化收敛性、泛化保证或对下游任务的影响；与 DP-SGD 的比较依赖“低有效秩”的经验假设，缺乏严格的理论保证。
