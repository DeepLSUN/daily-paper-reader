## 摘要
长程智能体任务要求大型语言模型（LLMs）在多轮交互中迭代地检索、整合和维护分散的信息，但保留所有交互历史会导致工作上下文持续膨胀。近期的主动上下文管理方法允许模型使用专门工具编辑自身的工作上下文，但仍面临三个关键限制：（1）工具集有限，仅限于搜索、删除和摘要，不支持全局规划、长期记忆和自适应压缩；（2）探索效率低下，将上下文管理操作视为同质处理，尽管它们对最终结果的影响各不相同；（3）粗粒度的信用分配，在强化学习中将最终轨迹级奖励平均分配给所有中间的上下文编辑操作。为弥补这些差距，我们提出了ContextPilot，一个面向长程智能体推理的主动上下文管理框架。我们的方法系统地扩展了工具集，加入规划、长期记忆和软性上下文卸载工具。我们进一步提出了一种针对上下文管理定制的强化学习方法，该方法利用上下文和熵变化来识别关键编辑决策以进行分支采样，并从所有经过相应上下文编辑操作的分支轨迹中估计动作级优势。在长上下文问答和深度搜索任务上的实验表明，ContextPilot能以更紧凑的工作上下文实现更强的性能，在各种基础模型和基准上持续优于现有基线。代码可在https://github.com/Tencent/ContextPilot获取。

## Abstract
Long-horizon agentic tasks require large language models (LLMs) to iteratively retrieve, integrate, and maintain dispersed information across multi-turn interactions, but preserving all interaction histories leads to a continuously growing working context. Recent proactive context management methods allow models to edit their own working context with specialized tools, yet they still face three key limitations: (1) a limited toolset restricted to search, deletion, and summarization, with no support for global planning, long-term memory, and adaptive compression; (2) inefficient exploration that treats context management actions uniformly despite their heterogeneous impacts on final outcomes; and (3) coarse-grained credit assignment that assigns the final trajectory-level reward to all intermediate context editing actions during RL. To bridge these gaps, we introduce ContextPilot, a proactive context management framework for long-horizon agentic reasoning. Our approach systematically augments the toolset with planning, long-term memory, and soft context offloading tools. We further propose an RL method tailored for context management, which uses context and entropy variation to identify critical editing decisions for branch sampling and estimates action-level advantages from all branched trajectories that pass through the corresponding context editing action. Experiments on long-context QA and deep search tasks show that ContextPilot achieves stronger performance with a more compact working context, consistently outperforming existing baselines across various base models and benchmarks. Code is available at https://github.com/Tencent/ContextPilot.

## 2. 论文提出的方法论

### 2.1 核心思想
ContextPilot包含两大支柱：（1）**工具层面**——系统性扩展上下文管理工具集；（2）**训练层面**——提出针对上下文管理的定制RL算法，含上下文感知的部分展开（Context-Aware Partial Rollout）与细粒度信用分配（Fine-Grained Credit Assignment）。

### 2.2 工具集设计（表1）
在StateLM基础工具集之上新增四类关键工具：
- **规划工具**：`plan`（提出简明策略）；
- **长期记忆工具**：`memorize`（提取实体/时间戳/事件片段的实体-事件记忆，并构建跨片段关联）、`updateMemory`、`readMemory`（读取目标记忆及相邻记忆）；
- **软卸载工具**：`summarizeContext`（摘要替换）、`compressContext`（基于LLMLingua-2的轻量压缩）、`foldHistory`（折叠历史为关键词+摘要，可后续通过`searchContext`恢复）；
- 此外保留原有感知/规划、信息检索、短期笔记类工具（`analyzeText`、`checkBudget`、`buildIndex`、`searchContext`、`readChunk`等）。

### 2.3 SFT数据构建
- 使用**上下文管理脚手架（harness）**引导教师模型（Qwen3.5-397B-A17B）生成轨迹，动态展示满足前置条件的工具，并包含提示、纠错与重试机制（这些辅助仅作为生成时脚手架，不进入最终SFT轨迹）。
- 三层过滤管线：结果过滤（含两次重试）→ 基于GPT-OSS-120B的过程过滤 → 峰值上下文≤32K过滤，最终保留3,068条轨迹并切分为51,469个轨迹快照。

### 2.4 RL训练方法（核心贡献）

**（1）上下文感知的部分展开（Context-Aware Partial Rollout）**
- 受ARPO启发，为每个上下文管理动作计算**敏感度分数**：
  - 上下文变化量：  
    \[
    \Delta C^{cm}_t = \frac{len(c^{cm}_{t+1}) - len(c^{cm}_t)}{len(c^{cm}_t)}
    \]
  - 熵变化量：  
    \[
    \Delta H^{cm}_t = H^{cm}_t - H_{initial}
    \]
    （\(H_t\) 为该动作后k个生成token的平均熵，\(H_{initial}\) 为轨迹初始熵，作为全局参考而非相邻步局部波动）
  - 综合敏感度：  
    \[
    S(a^{cm}_t) = \alpha \cdot \Delta C^{cm}_t + \beta \cdot \Delta H^{cm}_t
    \]
- 展开策略：每查询全局预算N=128快照，先做8条轨迹级展开（可产生至多64个快照），剩余预算分配给最高敏感度动作的分支采样，从而将更多探索资源聚焦于影响更大的关键上下文编辑决策。

**（2）细粒度信用分配（Fine-Grained Credit Assignment）**
- 将终端轨迹快照\(S_M\)的奖励定义为结果奖励\(R_{out}\) + 格式奖励\(R_{fmt}\) − 惩罚项\(R_{pen}\)（惩罚无效工具调用和超长上下文）；
- 对于中间快照\(S_i\)，其奖励由所有以\(S_i\)为前缀的终端轨迹奖励的均值定义：  
  \[
  R(S_i) = \frac{1}{|\mathcal{T}(S_i)|}\sum_{T\in\mathcal{T}(S_i)} R(T)
  \]
- 在同查询分组内用GRPO目标计算优势（组均值与标准差归一化），以轨迹快照为独立样本优化策略。

**（3）理论保证（附录A）**
- 证明细粒度信用分配是条件延续值\(Q(S)=\mathbb{E}[R(T)|S\preceq T]\)的无偏估计，且方差从\(\sigma^2(S)\)降至\(\sigma^2(S)/n_S\)（\(n_S>1\)时严格更小），提供更稳定的优势信号。

## 6. 论文的主要结论与发现

1. **主动上下文管理显著优于被动与无管理基线**：ContextPilot以32K窗口超越128K上下文的无工具骨干模型和现有RL上下文管理体（如StateLM），证明“管理上下文”比“硬撑更大上下文”更有效。
2. **RL在更具挑战性的长程任务上收益更大**：在BrowseComp+（552K文档）上RL提升5.34分，远超NovelQA的1.32分，说明任务越复杂、上下文越长，细粒度RL的价值越大。
3. **RL重塑工具使用策略**：训练中信息检索占比从约50%下降，规划/感知、长期记忆和上下文卸载工具占比上升（图5），说明模型从“短视检索”转向“全局协调管理”。
4. **RL提升工具使用的正确性**：记忆与卸载工具早期失败率高（达8%~10%），随着RL训练显著下降并伴随任务得分上升（图6）。
5. **工具扩展逐项有效**：规划、软卸载、长期记忆对性能的增量贡献依次递增，尤其对超长文档（BrowseComp+）增益显著（63.49%→80.96%）。
6. **细粒度信用分配优于轨迹级奖励**：在四个基准上带来稳定增益（如LongMemEval-S +2.87、BrowseComp+ +3.10），理论证明其方差更小。
