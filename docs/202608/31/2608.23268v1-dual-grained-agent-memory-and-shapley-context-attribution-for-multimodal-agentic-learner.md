## 摘要
前沿多模态大语言模型（MLLMs）展现出令人印象深刻的感知能力，但在科学和数学推理上仍显不足。对于闭权重或设备端骨干模型，参数级自适应不可用，而无状态提示则无法从已解决的问题中获得任何复合收益。我们提出DG-Mem，一种双粒度智能体记忆框架，通过从训练时展开中构建一次、并在测试时只读访问的非参数化外部存储记忆来增强冻结的MLLM。受人类记忆的互补学习系统（CLS）解释启发，DG-Mem将其存储分解为实例级范例记忆和IF-THEN规则的类别级模式记忆，并由一个瞬态反射存储介导其构建，使得模式仅从抽象反思中综合，而非从范例文本中生成。两个设计选择使DG-Mem与众不同：一个在线概念分类器，在训练期间增量增长类别空间，而不是预先定义分类体系；以及一个Shapley上下文归因过程，将正确性分解到整个检索到的规则集上，并生成每个规则的工具性效用，用于在测试时重新加权检索。该流程无需梯度更新，可部署在闭权重或设备端骨干模型上。在MathVista、MMMU和MMMU-Pro上，基于四个开放权重和专有骨干模型（Qwen3.5-27B、Qwen3.5-122B-A10B、GPT-5-Nano、Gemini-3-Flash），DG-Mem一致优于无记忆基线和有竞争力的记忆基线。

## Abstract
Frontier multimodal large language models (MLLMs) deliver impressive perception yet still falter on scientific and mathematical reasoning. Parameter-level adaptation is unavailable for closed-weight or on-device backbones, and stateless prompting forfeits any compounding benefit from problems already solved. We propose \textbf{DG-Mem}, a dual-grained agentic memory framework that augments a frozen MLLM with a non-parametric, externally stored memory built once from training-time rollouts and consulted read-only at test time. Motivated by the Complementary Learning Systems (CLS) account of human memory, DG-Mem factors its store into an instance-grounded exemplar memory and a category-level schema memory of IF-THEN rules, with a transient reflection store mediating their construction so that schemas are synthesized only from abstract reflections, never from exemplar text. Two design choices distinguish DG-Mem: an online concept categorizer that grows the category space incrementally during training rather than committing to a predefined taxonomy, and a Shapley context attribution procedure that decomposes correctness across the entire retrieved rule set and yields a per-rule utility that re-weights retrieval at test time. The pipeline introduces no gradient updates and is deployable on closed-weight or on-device backbones. Across MathVista, MMMU, and MMMU-Pro on four open-weight and proprietary backbones (Qwen3.5-27B, Qwen3.5-122B-A10B, GPT-5-Nano, Gemini-3-Flash), DG-Mem improves consistently over no-memory and competitive memory baselines.

## 方法论

### 核心思想
- 以 CLS 理论中的"快速实例系统 + 慢速结构化系统"双系统交互为原型：
  - **实例级范例记忆（ME）**：对应快速、具体、逐实例的存储系统。
  - **类别级模式记忆（MS）**：对应缓慢综合、跨实例抽象的 schema 系统。
  - **瞬态反思存储（MR）**：作为未整合的情景痕迹中间层，仅用于模式合成，推理阶段不直接访问。
- 设计核心约束：**模式只能从抽象反思（IF-THEN 规则）中综合，绝不接触范例原文**，以符合 schema-mediated consolidation 的认知机制并防止记忆污染。

### 关键技术细节

1. **Stage 1 – 记忆构建（Memory Construction）**：
   - 对每个训练问题 q，以温度采样生成 N 条解轨迹，用验证级联（原生匹配器 → 符号解析器 → LLM裁判）标注正确/错误。
   - 并行生成三类产物：
     - 反思 ρ(q) = Refl_R(q, a⋆, {rollouts})：提取 2-5 条抽象 IF-THEN 规则，存入 MR；
     - 范例 e(q) = Refl_E(q, a⋆, {rollouts})：提炼策略与验证检查，存入 ME；
     - 类别标签 κ(q) = Cat(q)：由在线分类器产生。
   - 抽象约束：所有存储内容禁止出现数值、选项字母、变量绑定和命名实体，确保跨问题迁移时不会泄漏具体题面信息。
   - **在线概念分类器（Online Concept Categorizer）**：动态地将新问题匹配到现有类别或创建新类别，类别空间在训练中单调增长，避免固定分类体系过粗/过细的问题。

2. **Stage 2 – Shapley 上下文归因（Shapley Context Attribution）**：
   - 将同一类别内的规则视为合作博弈中的玩家，通过子集展开计算边际贡献：
     - Δq(rᵢ) = (1/K!) Σ_π [v(P_πᵢ ∪ {rᵢ}) − v(P_πᵢ)]
     - v(S) 为在特定规则子集条件下生成的答案的二元奖励（正确/错误）。
   - 每条规则累积效用 U(rᵢ) = 所有包含该规则问题上的 Shapley 值均值，存入持久化文件，支持并行化和断点续跑。
   - 范例记忆明确排除在此归因之外，避免 Stage-1 / Stage-2 数据重叠造成的泄漏。

3. **记忆访问（Memory Access）**：
   - 检索分数 = α × 归一化嵌入相似度 + (1 − α) × 归一化累积效用（α = 0.8）。
   - 规则用文本嵌入（Qwen-3-Embedding）检索；范例用多模态嵌入（Qwen-3-VL-Embedding）检索，带相似度阈值过滤。
   - 记忆以两种模式注入：**priming**（问题前，预先引导思路）和 **verification**（问题后，事后审计答案）。

### 关键设计特征
- 全程冻结骨干模型，无梯度更新，可部署于闭权重和设备端模型。
- 采用同构配置：所有智能体节点（求解器、反射器、模式合成器、在线分类器）均使用同一个骨干模型，排除隐式知识蒸馏的干扰。

## 主要结论与发现

- DG-Mem 在绝大多数实验配置下一致优于 No-memory 基线和 ViLoMem，最高平均提升达 +12.5%（GPT-5-Nano）。
- **双粒度分离有效**：消融表明，去除任一记忆粒度都会造成性能下降，且两粒度覆盖的是非重叠的失败模式，而非冗余信号。
- **Shapley 效用重加权有真实贡献**：在相似度已达候选集收窄的情况下，效用仍有稳定增益（−0.6/−0.7/−2.1），且越难的数据集差距越大。
- **在线分类器设计得到验证**：无需预设分类体系即可有效组织概念空间，避免固定分类的过粗/过细问题。
- 定性案例表明，检索到的模式规则能补足基线缺失的关键步骤（如穷举清点、逐项阈值计算、实体对齐），范例则提供近同构的可迁移解法模板。

## 优点

- **方法设计亮点**：
  - 将 CLS 认知理论转化为明确的架构约束（模式只由反思合成、绝不读范例原文），理论动机有据可依。
  - 在线增量分类器解决了预设分类体系无法适应未知概念空间的实际问题。
  - 将 Shapley 值引入智能体记忆的信用分配，属创新性尝试，且无需梯度、可并行、可断点续跑。
  - 全流程冻结骨干、无梯度更新，对闭源/设备端模型友好，工程上具可部署性。
- **实验设计亮点**：
  - 同构配置（所有节点同一骨干）排除了隐式知识蒸馏，实验归因更干净。
  - 消融实验在多个骨干上执行，结果模式一致，增强了结论的稳健性。
  - 对 ViLoMem 同时汇报在线/离线模式，比较更全面。

## 不足与局限

- **归因的随机性**：Shapley 归因假设骨干是确定性的价值函数，但 GPU 内核非确定性、动态批处理、浮点非结合律会导致相同上下文产生不同奖励；有限子集预算 B 下，真正边际效应很小的规则可能因答案翻转而获得非零 Shapley 值，效用 U 的符号可能依赖数据顺序。
  - 缓解措施：跨多个问题平均 + 只排序不设阈值，但残余方差是价值函数的固有属性。
- **测试期记忆冻结**：为避免在线学习干扰评估而冻结记忆，放弃了对测试期错误的持续学习，未探索有界在线更新与离线整合的结合。

  - Qwen3.5-27B 在 MMMU-Pro 上低于基线的反例未获解释。
