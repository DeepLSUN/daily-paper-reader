## 摘要
多模态搜索代理利用开放网络中新兴的长尾证据扩展参数化知识。然而，许多现有的代理搜索环境通常仅将检索到的证据以文本形式呈现，并在后续上下文中省略工具返回的图像，将视觉相关的轨迹简化为仅文本推理。长时程交互还会加剧工具调用、响应长度、超时和预算失败，这些失败可能丢弃可挽救的轨迹、浪费展开计算并干扰策略更新。为了解决这些问题，我们引入了WeAgent-Harness，一个支持原生文本-视觉交互和运行时恢复的多模态代理框架。检索到的图像获得持久的磁盘引用，使模型能够在整个轨迹中检查、处理和引用它们。基于该框架，我们开发了WeAgent-MMSearch，一个涵盖数据构建、代理后训练和多模态展开的综合系统。在数据构建方面，一个强大的多模态大语言模型（MLLM）使用WeAgent-Harness来发现、合成和验证MMSearch风格的任务，并收集专家轨迹。在训练后阶段，我们的故障感知GSPO（FA-GSPO）恢复可挽救的异常展开并过滤无效展开，以改进受限的多模态规划与搜索。我们还引入了VisTarget-Bench，这是一个包含150个任务的人工验证基准，将每个问题与一个保留的目标图像配对，以区分图像检索失败与视觉感知失败。在VisTarget-Bench和七个公共基准上的评估显示，代理后训练将平均分数提高了19.22分，使我们的模型能够超越同等规模的开源模型，并与参数规模约为其十倍的大型模型相抗衡。

## Abstract
Multimodal search agents extend parametric knowledge with newly emerging and long-tail evidence from the open web. Yet many existing agentic search environments often expose retrieved evidence only as text and omit tool-returned images from subsequent context, reducing visually grounded trajectories to text-only reasoning. Long-horizon interaction also compounds tool-call, response-length, timeout, and budget failures, which can discard salvageable trajectories, waste rollout computation, and disturb policy updates. To address these issues, we introduce WeAgent-Harness, a multimodal agentic harness that supports native text-vision interaction and runtime recovery. Retrieved images receive persistent disk references, allowing the model to inspect, process, and cite them throughout the trajectory. Based on this harness, we develop WeAgent-MMSearch, an integrated system spanning data construction, agentic post-training, and multimodal rollout. For data construction, a strong MLLM uses WeAgent-Harness to discover, synthesize, and verify MMSearch-style tasks and collect expert trajectories. During post-training, our Failure-Aware GSPO (FA-GSPO) recovers salvageable abnormal rollouts and filters invalid ones to improve bounded multimodal planning and search.We also introduce VisTarget-Bench, a 150-task human-verified benchmark that pairs each question with a held-out target image, distinguishing image-retrieval failures from visual-perception failures. Evaluation on VisTarget-Bench and seven public benchmarks shows that agentic post-training improves the average score by 19.22 points, enabling our model to outperform similarly sized open-source models and rival models with roughly ten times its parameter count.

## 2. 提出的方法论

### 2.1 WeAgent-Harness：统一的工具交互与状态管理框架
- **持久化多模态状态**：`web_search`、`web_extract`、`web_search_for_image`、`web_search_based_on_image`、`execute_code` 五个工具返回的多模态证据被写入磁盘并注册为带稳定引用的对象（如 `<user_image_1>`、`<search_image_3>`），每个图像保留来源元数据；后续轮次可以继续查看、引用或反向检索同一图像。
- **可靠且有界的执行**：
  - **缓存搜索**：对规范化请求做精确匹配缓存，命中时直接返回，未命中才访问实时网页，平衡新鲜度与延迟。
  - **错误恢复**：对明确无歧义的调用错误（工具名、参数名、序列化格式）自动修复；语义不清时返回结构化错误观察，允许模型自纠正；抑制重复无效调用。
  - **超长响应处理**：单轮响应超过长度上限则丢弃并允许再生成一次，避免整条轨迹被废弃。
  - **预算控制**：设置上下文长度、工具调用次数、轮次和墙钟时间限制；在轮次预算耗尽后禁用工具但允许一次无工具总结回答。

### 2.2 数据构建：Harness 原生 MMSearch 数据流水线
- 以 Kimi K2.6 作为专家 MLLM，在同一工具/状态契约下运行四阶段流水线：
  1. **视觉根基种子生成**：从 Wikipedia 实体和 2026 年 1 月至 7 月的时间敏感网络事件中获取视觉事实，要求目标图像可通过 Harness 检索到、答案必须依赖像素且来源可审计。
  2. **反向多跳展开**：从终端视觉问题（包含目标图像 C 和必须从像素读取的答案 D）出发，每步反问“要找到当前节点需要什么前置证据”，构造 2~4 跳的潜在推理链 `n0 → … → nd`。
  3. **任务验证**：检查锚点完整性、桥接唯一性、避免答案泄漏（如 URL/元数据暴露答案），并确保答案真正依赖目标图像像素。
  4. **轨迹采样**：专家代理在 WeAgent-Harness 下执行任务，成功的正确路径进入 SFT 集，失败但可训练的任务保留为 RL prompt。
- **开源数据规范化**：将 Metis、OpenSearch-VL、REDSearcher 三类外部 SFT/RL 数据统一到同一轨迹格式（工具命名空间加前缀、助手掌规范化为 `<think>…<tool_call>…</tool_call>` 或 `<think>…<response>…</response>`），并进行长度/噪声过滤和 RL prompt 结果方差筛选。
- **最终数据规模**：SFT 混合 59.5K（内部 3.3K + 开放 56.2K），RL 混合 13.3K（内部 4.9K + 开放 8.3K）。

### 2.3 智能体后训练
- **SFT**：基于成功演示做标准 next-token prediction；工具观察和 Harness 插入的干预信息被掩码，只在模型生成的 token 上计算损失。
- **FA-GSPO（Failure-Aware GSPO）**：在 GSPO 基础上加入“先恢复、后过滤”的机制。
  - 超长单轮会重新生成一次；无效工具调用以结构化错误返回并允许自纠正；轮次耗尽时触发一次无工具总结回答；超出上下文或墙钟限制的轨迹直接排除。
  - 对每个 prompt 的候选组 `{ogi}`，只保留可训练轨迹集合 `Eg`，用其计算均值和标准差：
    - `R̄g = (1/max(ng,1)) Σ_{i∈Eg} Rgi`
    - `σg = sqrt((1/max(ng-1,1)) Σ_{i∈Eg} (Rgi - R̄g)²)`
  - 奖励简单二元化：`Rgi = 0.9·Cgi + 0.1·Fgi`（对错 + 格式合规）。
  - 优势只对 `ng ≥ 2` 的组计算，组内有效样本 < 2 时整组丢弃。
  - 目标函数为带 clip 的序列级比值更新：
    - `J_FA-GSPO(θ) = E[ (1/|G_train|) Σ_g (1/n_g) Σ_{i∈Eg} min(ρgi·Âgi, clip(ρgi, 1-ε_lo, 1+ε_hi)·Âgi) ]`
  - 关键设计是：**可恢复性（能否被挽救）与优化资格（是否进入训练）分离**，异常轨迹不参与梯度更新，避免无关失败信号干扰策略学习。

### 3.1 基准与数据集
- **公共基准（7 个）**：MMBrowseComp、MMSearch、MMSearch-Plus、SimpleVQA、VDR-Bench、LiveVQA、FVQA，覆盖多跳浏览、证据溯源、事实性 VQA、实时视觉问答和开放域 VQA。
- **自建基准**：VisTarget-Bench，150 个人工验证任务，其中 80 个带输入图像、70 个纯文本输入。每个问题配有一个保留的目标图像，要求模型返回答案并引用支持图像的索引，从而区分“未找到目标图”和“找到但用错”两类失败。

### 3.2 对比方法
- **直接回答**：Qwen3-VL-30B-A3B、Kimi K2.6（无检索）。
- **前沿模型 + WeAgent-Harness**：Gemini3.6-Flash、GPT-5.6-Sol-High、Opus-5-High、Kimi K2.6、Qwen3.5-Plus、Qwen3.6-35B-A3B、Qwen3.8-27B。
- **轻量搜索代理基线**：OpenSearch-VL-30B-A3B-Instruct、REDSearcher-MM-30B-A3B-Thinking、HyperEyes-30B-A3B-Instruct。
- **Our variants**：WeAgent-MMSearch-Base（Qwen3-VL + WeAgent-Harness，无后训练）、WeAgent-MMSearch-SFT、WeAgent-MMSearch-RL。

### 3.3 消融实验
- **Harness 消融**：Kimi K2.6 / Gemini3.6-Flash / Qwen3.5-Plus 配 Hermes vs 配 WeAgent-Harness。
- **图像回传消融**：WeAgent-MMSearch-RL 去掉图像回传 vs 保留图像回传。
- **SFT 数据消融**：原始开源 SFT vs 规范化开源 SFT vs 完整 SFT（加内部数据）。
- **RL 优化消融**：Vanilla GSPO vs FA-GSPO。

### 3.4 运行细节
- SFT：全参数更新（语言模型 + 视觉塔 + 投影器），batch size 32，语言模型 LR 1e-5，视觉塔 LR 1e-6。
- RL：冻结视觉塔/投影器，只训练语言模型；prompt batch 64，每组 8 样本（全局轨迹 batch 512），LR 5e-7，rollout 温度 1.0。
- 每次评估 3 次取均值 ± 标准差；高度耗时的闭源模型（Gemini3.6-Flash、Opus-5-High、GPT-5.6-Sol-High）单次评估。

## 5. 实验数量与充分性

- **实验数量较充实**：
  - 1 个主实验（8 个基准 × 多个模型）；
  - 3 组消融（Harness 对比、图像回传开/关、SFT 数据规范化 + 内部数据增量）；
  - 1 组优化方法消融（Vanilla GSPO vs FA-GSPO）；
  - 1 组恢复机制统计（图 7：5 类恢复机制触发率与保留率）；
  - VisTarget-Bench 上的分阶段指标（Accuracy、Cite、Match、Match+Acc）；
  - 附录含 3 个定性 RL 轨迹案例和 3 个答案对比示例。
- **充分性评价**：
  - 优点：既有总分对比又有分项指标；覆盖率较广（公共 + 自建 + 消融 + 案例分析）；在 VisTarget-Bench 上引入引用图匹配的流水线诊断，能较好分离“检索失败”和“感知失败”。
  - 客观性风险：闭源模型单次评估、对手方法用官方公布分数（可能采用不同协议）、OpenSearch-VL 被作者复现但仅 3 次均值；Kimi K2.6 既是数据构造专家（生成训练数据），又是评测打分者（外部答案判断），存在一定的自我偏向风险；基线模型使用 Hermes 时的超参/提示词不一定经过同等调优，公平性尚可但仍有改进空间。

## 6. 主要结论与发现

- **WeAgent-Harness 对任何策略都有提升**：Qwen3-VL 从直接回答的 19.13% 提升到 36.75%；Kimi K2.6 从 21.92% 提升到 58.42%，且无需参数更新。
- **后训练带来显著增益**：WeAgent-MMSearch-Base（36.75%）→ SFT（51.04%）→ RL（55.97%），后训练平均提升 19.22 分。
- **FA-GSPO 有效**：相比 Vanilla GSPO，平均分数从 51.10% 提升到 55.97%，VisTarget-Bench 从 9.78% 提升到 30.22%。
- **图像回传是关键**：关闭图像回传后，WeAgent-MMSearch-RL 平均分从 55.97% 跌到 46.89%，下降约 9 个点。
- **可视化诊断显示 RL 改善了两端**：VisTarget-Bench 上，图像引用率从 SFT 的 14.00% 提升到 RL 的 20.67%；已引用图像中目标匹配率从 47.62% 提升到 87.10%；匹配后的回答正确率从 70.00% 提升到 77.78%。
- **与同规模/更大规模模型对比**：RL 模型优于相似规模的开源搜索代理（如 OpenSearch-VL、REDSearcher、HyperEyes），且能与部分约 10 倍参数量的模型（如 Kimi K2.6 1T、Qwen3.5-Plus）在某些基准上竞争，但总体仍落后于最强的闭源前沿模型。

## 7. 优点

1. **问题定位准确且有实际价值**：抓住“工具返回图像被丢弃”这一普遍但常被忽视的工程缺陷，把视觉证据的持久化提升为系统的一等公民。
2. **一体化设计**：数据构建、SFT、RL 和推理全部使用同一工具/状态契约，避免了训练-推理环境不一致带来的分布偏移。
3. **失败感知 RL 的创新**：FA-GSPO 把“运行时恢复”与“训练资格”解耦，既能挽救可修复轨迹（减少算力浪费），又保证无效轨迹不进入梯度计算，逻辑清晰且工程上可落地。
4. **诊断型基准**：VisTarget-Bench 通过目标图像 + 引用索引，将最终答案准确性拆解为 Cite、Match、Match+Acc 三阶段指标，能直接定位瓶颈在“没找到图”还是“没用对图”。
5. **消融设计完整**：分别验证了 harness、图像回传、数据规范化和内部数据增益、FA-GSPO 相对 Vanilla GSPO 的差异，归因相对干净。
6. **运行时可恢复数据丰富**：图 7 对恢复机制的触发频率和保留率做了量化，增加了工程说服力。

## 8. 不足与局限

1. **算力与成本披露不足**：未报告 GPU 型号/数量/训练时长，使成本可复现性和可比较性受限。
2. **评测公平性风险**：闭源模型只评测一次且不报告方差；部分基线采用公布分数而非统一协议复现；Kimi K2.6 同时承担数据生成者和判别者的角色，可能给模型带来参考标签的隐性偏好。
3. **图像引用匹配依赖 VLM 判断**：目标图像匹配使用 VLM judge（如 `J(Ĉi, Ci)`），不同 judge 的阈值和偏好未做敏感性分析。
4. **应用场景有限制**：主要通过搜索类工具构建的多跳任务，对网页表单、JS 交互、购物/订票等真实网页操作类 agent 不适用；`execute_code` 只用于图像裁剪/测量等简单操作，未扩展到复杂数据科学任务。
5. **时间敏感数据框架化**：数据窗口固定在 2026 年 1 月至 7 月，事件范围有限，时间泛化能力尚不明确。
6. **多语言覆盖不足**：系统提示/评测主要针对英文或与搜索 locale 相关，非英文场景没有专门分析。
7. **异常恢复仍有上限**：上下文长度和墙钟超限的轨迹被直接丢弃，说明长时程任务的经验上限依然存在，恢复机制只缓解局部异常，无法解决真正的超长/失控轨迹。
