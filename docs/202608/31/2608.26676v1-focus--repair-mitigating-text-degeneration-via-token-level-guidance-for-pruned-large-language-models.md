## 摘要
剪枝是压缩大语言模型（LLM）的一种实用方法，但它可能加剧文本退化，尤其是重复循环，即使困惑度和任务准确率基本保持不变。在这项工作中，我们通过将解码视为一个进入并持续存在于一小群循环上下文中的动态过程，对该失败模式进行了令牌级分析。我们的分析将退化分解为循环进入风险和循环持续性，并表明持续性由分配给令牌采样集中合理备选方案的逃逸质量所控制。基于这些发现，我们提出了两个用于剪枝后微调的令牌级引导目标。FOCUS 将蒸馏重新加权到高置信度的教师区域以抑制泄漏，而 RePAIR 使用以起始为中心的正面/负面延续对和间隔损失来促进合理备选方案，并防止过早陷入重复循环。在开放式续写和基于指令的生成上的实验表明，这两种方法都能持续减少重复并提高生成质量。

## Abstract
Pruning is a practical approach to compress large language models (LLMs), but it can amplify text degeneration, especially repetition loops, even when perplexity and task accuracy remain largely unchanged. In this work, we present a token-level analysis of this failure mode by viewing decoding as a dynamical process that enters and persists in a small set of recurrent contexts. Our analysis decomposes degeneration into loop entry risk and loop persistence, and shows that persistence is controlled by the escape mass assigned to plausible alternatives within the token sampling set. Motivated by these findings, we propose two token-level guidance objectives for post-pruning fine-tuning. FOCUS reweights distillation toward high-confidence teacher regions to suppress leakage, while RePAIR uses onset-centered positive/negative continuation pairs with a margin loss to promote plausible alternatives and prevent early commitment to repetition loops. Experiments on open-ended continuation and instruction-based generation show that both methods consistently reduce repetition and improve generation quality.

### 2. 方法论

- **核心思想**：将解码视为一个进入并持续停留在“循环上下文集合”中的动态过程，从 token 级别把退化分解为两个因素：
  - **循环进入风险（loop entry risk）**：进入重复循环区域的概率。
  - **循环持续性（loop persistence）**：一旦进入循环区域后继续留在其中的概率（长期重复主要由持续性主导）。
- **关键公式与分析**：
  - 退化概率的上界：`P(Coverage ≥ τ) ≤ R_T · ρ̄^{ℓ_τ}`，其中 `ρ̄` 是持续性上界，`ℓ_τ` 是需要连续在循环内转移的步数。持续性是指数项，因此对重复抑制更关键。
  - 在 nucleus（top-p）解码下，持续性 `ρ(c) = a(c) / (a(c) + e(c))`，其中 `a(c)` 是核集合内“维持循环”的 token 概率之和，`e(c)` 是“逃逸”到非循环 token 的概率之和（逃逸质量）。降低持续性需要在核集合内提高合理备选 token 的质量，而不是简单增加全词表的熵。
  - 剪枝与朴素 KD 会同时加剧两类风险：向前 KL 蒸馏在容量受限时产生“模式平均”，导致概率泄漏到教师分布被抑制的尾部分布（增大进入风险）；同时使教师原本近似的多候选变成单一“主导 token”，压缩核内逃逸质量（增大持续性）。
- **提出的方法**：
  - **FOCUS**：对蒸馏损失进行 token 级重加权，权重 `w_i,t(v) = [q_i,t(v)]^β + [1 - q_i,t(v)]^γ`，强调教师高置信区域，抑制向低支持（tail leakage）区域的概率漂移。推导表明其梯度等价于以重加权教师分布 `q̃` 为目标的 KD。
  - **RePAIR**：构造“前缀 + 负向重复续写 / 正向正常续写”的配对数据，以重复循环起点为对齐点，利用 margin ranking loss 鼓励模型偏好正向续写，从而在循环敏感位置保留合理的逃逸备选，防止过早进入重复回路。
  - 总损失：`L_total = L_CE + α1·L_FOCUS + α2·L_RePAIR`，默认 `α1 = 0.05`、`α2 = 1`。
