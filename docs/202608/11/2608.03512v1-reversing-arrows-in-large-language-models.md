## 摘要
大语言模型（LLMs）在文本到知识图谱生成及相关任务中表现出强劲性能。然而，目前尚不清楚它们是否准确建模了逆关系的方向依赖语义，即交换参数顺序会改变关系含义（例如，"母亲"与"孩子"）。据我们所知，本研究首次系统地考察了LLMs中逆关系方向性，使用了一个包含5,457个实例、涵盖27个不同逆关系标签的基准。我们在多项选择提示框架下评估了五个开源LLMs，并通过将原始实体替换为合成实体和掩蔽实体，进一步考察了关系描述和实体表示的影响。我们的研究结果揭示了LLMs在逆关系分类中存在的系统性不对称性，表明关系描述并不总能稳定提升性能，并显示模型性能可能对实体表示的变化敏感。

## Abstract
Large language models (LLMs) have achieved strong performance on text-to-knowledge graph generation and related tasks. Nevertheless, it is still unclear whether they accurately model the direction-dependent semantics of inverse relations, in which reversing the order of the arguments alters the meaning of a relation (e.g., \textit{mother} versus \textit{child}). To the best of our knowledge, this work presents the first systematic study of inverse relation directionality in LLMs, using a benchmark consisting of 5,457 instances spanning 27 distinct inverse relation labels. We evaluate five open-source LLMs under a multiple-choice prompting framework and further examine the influence of relation descriptions and entity representations by substituting the original entities with synthetic and masked entities. Our findings reveal systematic asymmetries in inverse relation classification across LLMs, indicate that relation descriptions do not consistently improve performance, and show that model performance can be sensitive to variations in entity representations.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：指令微调后的大语言模型（LLMs）是否能够正确识别逆关系（inverse relations）的方向性？也就是当两个实体的顺序互换时（如 head→tail 与 tail→head），模型能否正确区分如“母亲”与“孩子”、“父亲”与“孩子”这类语义相反的关系。
- **研究背景**：
  - LLMs 在文本到知识图谱生成、本体学习、关系抽取等结构化知识获取任务中表现出色。
  - 知识图谱是有向标签图，关系方向性是知识图谱补全和语义准确性的关键。
  - 逆关系（converse relations）是二元关系的反向关系，不能与对称关系混淆，例如 (x, part of, y) ↔ (y, has part, x)。
  - 已有研究表明，当逆关系对出现在标签空间中时，关系分类模型性能会显著下降，尤其是在少样本场景下。
- **研究空白**：此前没有研究在**句子级关系分类**层面系统性地评估 LLM 对逆关系方向性的理解。已有工作要么在三元组层面评估（如 ConvRE），要么研究同一关系标签的方向敏感变体（如 Member-Collection(e1,e2) 与 Member-Collection(e2,e1)），而非显式的逆关系对（如 parent/child）。
- **整体含义**：本研究首次系统揭示了 LLM 在逆关系方向性建模上的系统性薄弱环节，对知识图谱构建、关系抽取等下游任务的可靠性有重要警示意义。

## 2. 论文提出的方法论

### 核心思想
通过构建一个基于 Wikidata 验证的逆关系基准数据集，在零样本多项选择提示框架下系统评估 LLM 的逆关系方向性理解能力，并通过实体扰动（合成/掩码）控制实体熟悉度因素，从而分离“关系推理”与“实体记忆”的影响。

### 关键技术细节

- **逆关系的形式化定义**：R⁻¹xy ⇔ Ryx for all x, y ∈ D，即 R⁻¹ = {(x, y) ∈ D×D | (y, x) ∈ R}。文中假设逆关系中可能存在性别特定子关系（如 Wife/Husband ⊆ Spouse），并且同一有序对(x, y)上R与R⁻¹不能同时成立。
- **基准构建流程**（5步）：
  1. 从 FewRel 1.0 和 TekGen（TEXT2KGBENCH 分区）中筛选候选逆关系对。
  2. 提取头尾实体对。
  3. 通过 SPARQL 查询 Wikidata，检索连接每个实体对的**所有**属性。
  4. 过滤出预定义的逆关系对。
  5. 分配方向特定标签（head-to-tail 和 tail-to-head）。
  - 方向信息经 Wikidata 验证，方向不一致的实体对被丢弃。
- **多项选择提示设计**：
  - 每个提示包含三个候选关系：(A) 头到尾关系，(B) 其逆关系（尾到头），(C) 一个负样本关系（与当前逆关系对无关，从其余逆关系标签中随机选取，固定种子42）。
  - 两种提示变体：**带关系描述**与**不带关系描述**。
  - 答案选项顺序在生成时随机化。
- **实体扰动策略**：
  - **合成实体**：使用 Presidio Anonymizer 将原始实体替换为合成实体（如 Niels Bohr → Devin Rodriguez）以降低实体熟悉度。
  - **掩码实体**：将实体完全替换为 XXX/YYY，移除全部实体词汇线索，纯化关系推理评估。
- **评估方法**：零样本多项选择问答，采用贪心解码，宏F1（macro-F1）作为评估指标（因数据集类别不平衡）。
- **统计检验**：配对 Wilcoxon 符号秩检验 + 95% bootstrap 置信区间（10,000 次重采样），比较方向性、关系描述、实体类型的影响。

## 3. 实验设计

### 数据集 / 基准

- **基准规模**：5,457 个句子级实例，涵盖 27 个不同逆关系标签。
- **数据来源**：
  - **FewRel 1.0**：包含 7 个逆关系对（child/father/mother/followed by/follows/has part/part of），其中 child 关系样本最多（988 条），总计约 3,401 条实例。仅包含 7 个逆关系对是因为只有这些对在 FewRel 中有句子实例。
  - **TekGen（TEXT2KGBENCH 分区）**：包含 16 个逆关系对，但只有 12 对有关联句子实例（如 characters present in work、position held/officeholder、astronaut mission/crew member 等），全部方向都经 Wikidata 验证。
- **三类实体设置**：原始实体、合成实体、掩码实体。

### 评估模型

对比了五个开源指令微调模型：
1. Flan-T5 XL
2. Qwen2.5-7B-Instruct
3. Qwen3-4B-Instruct-2507
4. Llama-3.1-8B-Instruct
5. Mistral-7B-Instruct-v0.3

### 实验矩阵

- **2 个数据来源**（FewRel、TekGen）× **2 个方向**（head-to-tail、tail-to-head）× **2 种提示**（带/不带关系描述）× **3 种实体类型**（原始、合成、掩码）= **24 组主要实验设置**，每组包含 5 个模型。

## 6. 论文的主要结论与发现

1. **系统性方向不对称性**：
   - 在 FewRel 上，所有实体类型下 head-to-tail 与 tail-to-head 之间的性能差异均达到统计显著（p<0.05），表明 LLM 对逆关系方向存在系统性不对称。
   - 在 TekGen 上，原始实体和合成实体未表现出显著方向差异，但掩码实体下差异显著（p<0.05），说明方向性影响依赖数据集。

2. **关系描述并非普遍有效**：
   - 加入关系描述仅在 FewRel 的掩码实体设置下带来边缘性提升（p<0.1）。
   - 对其他实体类型和 TekGen 数据集，关系描述的加入没有带来统计显著的性能提升。
   - 结论：不能断言关系描述能一致改善逆关系识别。

3. **实体表示敏感性显著**：
   - 在 FewRel 上，无论是否包含关系描述，原始实体与合成/掩码实体之间的性能差异均显著（p<0.05），说明模型对实体表示变化敏感。
   - 在 TekGen 上，仅当提示包含关系描述时，原始与扰动实体间呈现边缘显著差异；不带描述时，原始与合成实体间无显著差异。
   - 提示：基于网络资源构建的基准可能导致 LLM 评估结果偏高，因为模型可能受益于 web 数据中接触过的实体/关系模式。

4. **模型间性能差异大**：没有单一模型在所有设置下表现最优。Llama-3.1-8B 在 FewRel 方向上表现突出，Qwen2.5-7B 在带描述的 tail-to-head  FewRel 设置中达到最高 69.56% 的宏F1，而 Flan-T5 XL 在 TekGen 的多个设置下表现最佳。总体性能中等偏下（多数宏F1 低于 50%），说明逆关系方向性识别对 LLM 仍是挑战。

## 7. 优点

- **首次系统性研究**：这是第一篇在句子级关系分类层面系统评估 LLM 逆关系方向性的工作，填补了研究空白。
- **严谨的数据验证**：所有关系方向均通过 Wikidata SPARQL 查询验证，不符合方向的实体对被剔除，保证了标签质量。
- **精细的消融控制**：通过原始/合成/掩码三组实体设置 + 有无关系描述的组合，有效分离了实体熟悉度、关系语义描述、关系方向性等因素的贡献。
- **统计严谨性**：使用配对 Wilcoxon 符号秩检验和 bootstrap 置信区间，而非仅汇报各模型的宏F1数值，增强了结论的可靠性。
- **实用的基准资源**：构建了包含 5,457 个实例、27 个逆关系标签的基准，可服务于后续研究者的评测需求。
- **清晰的提示模板设计**：提供三点式选择题，包含目标关系、逆关系、负关系三类选项，能捕捉模型误判逆关系的具体模式。

## 8. 不足与局限

- **匿名化不彻底**：
  - Presidio 无法识别所有实体，部分原始实体名可能保留，导致合成实体设置中的混淆因素。
  - 未评估匿名化过程是否改变句子语义或自然度，尤其对 father/mother 等依赖实体属性的关系，替换实体可能导致关系本身不成立（语义改变而非纯粹实体替换）。
- **无法直接证明记忆化**：虽然实体扰动实验提示模型可能受实体熟悉度影响，但实验无法直接证明记忆化或对实体熟悉度的依赖，因为语义改变与实体熟悉度效应纠缠在一起。
- **数据集覆盖面有限**：
  - 基准仅来自 FewRel 和 TekGen，且 FewRel 仅包含 7 个逆关系对（其原始标签空间中有更多关系），TekGen 的 16 对中只有 12 对有句子实例。
  - 结论可能无法推广到其他关系分类基准或知识图谱领域。
- **语言局限**：数据均为英文，无法推广到其他语言。
- **计算资源披露不足**：仅提到 A100 GPU 和 Google Colab Pro，未提供 GPU 数量、推理时间、总预算等量化信息，可复现性和算力成本透明度有待提升。
- **负关系选择单一性**：使用固定随机种子从其余逆关系标签中选取单一负样本，可能导致某些提示的区分难度不一致，影响评估公平性。
- **未探讨模型规模效应**：未分析模型参数量与逆关系识别能力之间的扩展规律，也未与其他非 LLM 方法（如微调 BERT 或专门关系分类模型）做对比，缺少基准下界参照。
