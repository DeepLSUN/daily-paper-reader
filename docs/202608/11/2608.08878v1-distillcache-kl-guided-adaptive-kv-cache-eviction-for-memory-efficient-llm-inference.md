## 摘要
基于Transformer的大型语言模型（LLM）在许多任务上表现出色，但其键值（KV）缓存随序列长度线性增长，导致长上下文推理面临严重的内存瓶颈。现有的启发式驱逐方法（如H$_2$O和SnapKV）依赖于静态注意力或位置信号，往往无法捕捉token未来的预测影响力。我们提出DistillCache，一种强化学习框架，将KV缓存驱逐问题建模为序列决策问题。DistillCache利用丰富的内部模型信号（注意力统计量、值范数、熵和位置）学习轻量级策略网络，并通过REINFORCE算法以每步KL散度奖励进行训练，以保留全缓存输出分布。在7B参数指令微调Transformer（Mistral-7B-Instruct-v0.3）上，DistillCache在25%缓存预算下保留了LongBench全缓存准确率的94.2%，比强启发式基线（H$_2$O、SnapKV）高出最多2.7个绝对百分点，并且在我们重新实现的并发基于RL的方法（ForesightKV、RLKV）上，在长上下文任务中高出最多1.4个百分点。在推理基准上，DistillCache与最优并发方法相当，并在激进压缩下超越它。它还实现了最高2.1倍的全缓存吞吐量，同时保持有竞争力的实际效率。这些结果突显了学习型、分布感知策略在内存高效长上下文LLM推理中的有效性。

## Abstract
Transformer-based large language models (LLMs) achieve strong performance across many tasks, but their Key-Value (KV) cache grows linearly with sequence length, creating a severe memory bottleneck for long-context inference. Existing heuristic eviction methods (e.g., H$_2$O and SnapKV) rely on static attention or positional signals that often fail to capture a token's future predictive influence. We propose DistillCache, a reinforcement learning framework that formulates KV-cache eviction as a sequential decision problem. DistillCache learns a lightweight policy network using rich internal model signals (attention statistics, value norms, entropy, and position) and trains it with REINFORCE via a per-step KL-divergence reward to preserve the full-cache output distribution. On a 7B-parameter instruction-tuned Transformer (Mistral-7B-Instruct-v0.3), DistillCache retains 94.2% of full-cache accuracy on LongBench at a 25% cache budget, outperforming both strong heuristic baselines (H$_2$O, SnapKV) by up to 2.7 absolute points and, under our re-implementations, concurrent RL-based methods (ForesightKV, RLKV) by up to 1.4 points on long-context tasks. On reasoning benchmarks, DistillCache is competitive with the best concurrent method and surpasses it under aggressive compression. It also delivers up to 2.1x full-cache throughput while maintaining competitive practical efficiency. These results highlight the effectiveness of learned, distribution-aware policies for memory-efficient long-context LLM inference.

## 论文核心问题与整体含义（研究动机和背景）

- **核心问题**：Transformer 大模型在自回归解码时需要维护 KV 缓存以避免重复计算，但 KV 缓存随序列长度线性增长，成为长上下文推理的主要内存与吞吐瓶颈。
- **现有方法的局限**：H₂O、SnapKV、StreamingLLM 等启发式驱逐策略依赖静态的注意力统计或位置信号，假设过去的注意力模式能可靠预测 token 未来效用，这在长程依赖、结构化推理等复杂场景中经常失效。
- **核心主张**：将 KV 缓存驱逐建模为序贯决策问题，用强化学习直接优化"驱逐哪些 token 能最大程度保持全缓存输出分布"，而非优化注意力启发式代理指标，从而在固定内存预算下获得更好的生成质量。

## 方法论

### 核心思想
- 训练一个轻量级策略网络（约 20 万参数的两层 MLP），在每一步解码时对缓存中每个 token 打分，保留得分最高的 Top-B 个 token，以最小化修剪后模型与全缓存模型逐位置输出分布的 KL 散度。

### 关键技术细节

**状态空间（每个 token 的五维特征向量）**
- αᵢ：该 token 作为 key 在最近一次前向传播中接收到的平均注意力质量；
- ‖vᵢ‖₂：该 token 值向量的 ℓ2 范数；
- σᵢ：各头间注意力质量的方差；
- Hᵢ：近期查询（窗口 w=64）注意力加权平均熵，衡量 token 被集中还是分散的注意力选中；
- posᵢ：token 在缓存内的归一化位置。

**动作空间与 Gumbel-Top-B 采样**
- 策略网络输出每个 token 的分数 sᵢ = f_φ(xᵢ)；
- 训练时加入 i.i.d. Gumbel 噪声后取 Top-B，构成 Plackett-Luce 分布下的随机子集采样；
- 推理时去掉噪声，确定性选取 Top-B。

**训练架构（教师-学生双缓存）**
- 教师缓存从不修剪，用于计算全缓存分布 P_t；
- 学生缓存每步按策略修剪，用于计算修剪缓存分布 P̂_t；
- 每步奖励定义为 R_t = −KL(P_t ∥ P̂_t)，直接衡量修剪对预测分布的影响。

**理论动机**
- 论文证明：若被驱逐 token 的注意力质量为 ε_t，则注意力输出扰动有上界 2Cε_t，logits 扰动有类似上界，最终 KL 散度 ≤ (2C'²ε_t²)/σ²_min——即 per-step KL 与驱逐注意力质量的平方成正比，为 KL 奖励提供了理论依据。

**策略优化**
- 使用 REINFORCE 算法，配合折扣回报（γ=0.99）、熵正则化（β=0.01）、RLOO 基线（批内留一平均）和指数移动平均基线来降低方差；
- log π_φ(a|s) 通过动态规划在 O(L·B) 时间内精确计算子集划分函数的 log 值，避免蒙特卡洛近似引入的方差；
- 推理时每次解码仅需一次前向传播，教师分支和奖励计算全部移除。

## 主要结论与发现

- **核心结果**：在 Mistral-7B-Instruct-v0.3 上，25% 缓存预算下 DistillCache 保留 LongBench 全缓存准确率的 **94.2%**（39.1 vs 41.5），比 H₂O 高 2.7 个点、比 SnapKV 高 2.1 个点、比 ForesightKV 高 0.9 个点、比 RLKV 高 1.4 个点。
- **推理任务**：50%/25% 预算下略逊于 RLKV（0.3-0.7 个点），但在 12.5% 激进压缩下反超（39.9 vs 38.9），说明极端压缩下 token 级分布保真度优势更显著。
- **跨模型泛化**：零样本从 Mistral-7B 迁移到 Llama-3-8B 仍超过两个原生启发式基线，而并发 RL 方法需要逐模型重训，展示出更强的泛化性。
- **长上下文优势扩大**：2K 上下文中各方法差距在 1 点以内（预算充足时选择压力小），8K 上下文中 DistillCache 优势扩大到 1.1-4.0 个点。
- **行为特征**：策略在无手工保护的情况下自动学习保留注意力汇聚 token 和近期 token（恢复 StreamingLLM/H₂O 的模式），同时额外保留否定词、从句支配动词等分布关键 token；异于启发式方法偏爱早期/近期 token，DistillCache 分配更多预算给中段上下文。
- **错误模式**：重复错误率最低（0.8% vs H₂O 4.8%），正确实例总失败率最低。
- **混合策略有效**：DistillCache + RLKV 头部级门控可进一步 +0.7 个点（5/5 个种子一致），证明两种策略的正交性。

## 优点

- **方法创新**：首次系统性地将"逐位置 KL 散度"作为 KV 缓存驱逐的奖励信号，直接优化分布保真度而非代理指标；理论推导将驱逐注意力质量与 KL 上界关联，为奖励设计提供了理论依据。
- **理论与实践结合**：Gumbel-Top-B + Plackett-Luce 分布提供了可微的子集采样方案，精确动态规划计算划分函数避免了蒙特卡洛方差，REINFORCE 配合 RLOO 与熵正则解决了训练稳定性问题。
- **特征设计合理**：五维特征兼具全局显著性（注意力、位置）与上下文敏感性（值范数、注意力方差、熵），且全部可从解码过程中现成获取，无额外模型调用。
- **实验严谨性**：多组消融实验严谨区分了特征丰富度与 RL 优化各自贡献；报告 5 种子均值和标准差；对并发方法的重实现局限有透明披露；训练协议完整（数据、超参数、评估设置）。
- **实用价值**：推理时仅需单次前向 + 轻量策略前向，25% 预算下约 2.1 倍全缓存吞吐；零样本跨模型迁移有效；逻辑上与系统级优化技术（offloading、PagedAttention、FlashDecoding++）正交可组合。

## 不足与局限

- **训练成本高**：约 130 GPU 小时训练时间 + 双倍内存占用，显著高于零训练的启发式方法，仅当反复推理效率收益可摊薄训练成本时才具部署优势。
- **RL 稳定性**：REINFORCE 本质存在高方差，依赖熵正则、RLOO 基线和多种子平均来缓解，更先进的 PPO/GRPO 可能改善但会增加复杂度和成本。
- **推理开销**：+1.4 ms/token 的额外延迟使其吞吐略低于 H₂O（38.0 vs 42.8 tokens/s），特征提取是主要成本（0.9 ms），虽可通过内核融合降低但尚未实现。
- **并发方法公平性**：ForesightKV 与 RLKV 为最佳努力重实现，论文声明了这一点但不排除与官方实现存在差异，绝对数值差距带有不确定性。
- **建模局限**：策略独立打分每个 token，未显式建模 token 间交互；特征设计耦合 Transformer 注意力结构，迁移到非注意力架构（Mamba 等）需重新设计。
- **推理任务短板**：在中等缓存预算（50%/25%）下，推理基准上 RLKV 仍领先 0.3-0.7 个点，说明特定于推理的头部级门控在部分场景下优于纯 token 级分布保真策略。
- **代码未开放与上下文覆盖有限**：论文承诺录用后开源；实验最长上下文仅 8K，未触及 32K-128K 的当代长上下文实战场景；训练序列截断为 4,096 tokens，与评估长度的不匹配可能影响策略在更长序列上的最优性。
