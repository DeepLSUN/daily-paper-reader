## 摘要
推测解码通过草拟多个令牌进行并行验证来加速大型语言模型推理，其效率关键取决于每轮解码所选择的推测长度。现有的动态推测方法通过估计将被接受的令牌数量来选择推测长度，这对于按顺序生成令牌的自回归式草拟器是合理的。然而，最近一波基于扩散的草拟器以显著更低的草拟成本并行生成候选块，将关键问题从生成多少令牌转变为有多少生成的令牌值得验证。因此，我们将动态推测长度选择重新表述为预期加速优化，并推导出一个边际准则：仅当接受增益超过额外验证成本时，才扩展推测序列。基于这一准则，我们开发了LibraSpec，这是一种无需训练且即插即用的算法，利用草拟器的置信度分数迭代地确定推测长度。理论上，我们证明了LibraSpec单调收敛于最优推测长度。在六个目标模型、三种基于扩散的推测解码方法以及数学、编码和聊天基准上的实验表明，在贪婪和采样设置下均能持续改进，相对于基线额外提升0.5至1.5倍，并相对于自回归解码实现高达8.49倍的加速。

## Abstract
Speculative decoding accelerates large language model inference by drafting multiple tokens for parallel verification, with efficiency critically determined by the speculative length selected at each decoding round. Existing dynamic speculation methods select the speculation length by estimating how many tokens will be accepted, which is reasonable for autoregressive drafters that generates tokens sequentially. The recent wave of diffusion-based drafters, however, generates candidate blocks in parallel at substantially lower drafting cost, shifting the key question from how many tokens to generate to how many generated tokens are worth verifying. We therefore reformulate dynamic speculative-length selection as expected-speedup optimization and derive a marginal criterion that extends the speculative sequence only when its acceptance gain outweighs the additional verification cost. Building on this criterion, we develop \textit{LibraSpec}, a training-free and plug-and-play algorithm that iteratively determines the speculative length using drafter confidence scores. Theoretically, we prove that LibraSpec monotonically converges toward the optimal speculative length. Experiments across six target models, three diffusion-based speculative decoding methods, and math, coding, and chat benchmarks show consistent improvements under both greedy and sampling settings, achieving a further $0.5\sim1.5\times$ improvement over baselines and up to $8.49\times$ speedup over autoregressive decoding.

- **背景**：自回归大语言模型（LLM）逐 token 生成，解码是长上下文推理（代码生成、交互应用）的主要瓶颈。推测解码（Speculative Decoding）通过轻量草稿模型生成候选 token，再由目标模型并行验证，实现无损加速。
- **关键问题**：每轮解码时所选择的“推测长度”（speculative length，即提交验证的候选 token 数）对加速效果至关重要。长度过短会浪费并行验证能力，过长则可能因早期拒绝而导致后续验证浪费。
- **现有方法的局限**：已有动态长度选择方法通常预测“将被接受的 token 数”，适用于顺序生成的自回归草稿者；但新兴的**扩散式草稿者**能以极低并行成本一次性生成候选块，核心问题从“生成多少 token”转变为“有多少已生成的 token 值得验证”。因此，仅估计接受长度不足以决定最优长度。
- **LibraSpec 的含义**：本文将动态推测长度选择重构为“期望加速比优化”问题，提出边际增益准则：只有当代入的扩展段带来的接受增益超过其验证成本时才扩展序列。该方法无需训练、即插即用，可显著提升扩散式推测解码效率。

## 2. 方法论：核心思想、技术细节与算法

- **核心思想**：将推测长度选择视为对端到端加速比 `η_d` 的优化，而非对接受长度的预测。通过迭代执行“单次有益调整”（single beneficial adjustment）逐步逼近最优长度。
- **速度模型**：
  - `η_d = τ_d · L_target / (T_draft_d + T_verify_d)`
  - 扩散式草稿者草拟成本极低，可近似忽略 `T_draft_d`，于是问题简化为在给定候选块（视为无限长草稿流）时，选择多长的验证序列。
- **单次有益调整（Definition 3.1）**：长度从 `d` 调整到 `d'` 当且仅当 `E[η_d'] > E[η_d]`。
- **边际准则（Theorem 3.2）**：延长或截断草稿序列时，新增/移除片段的“边际收益/边际验证成本”需优于当前全序列的平均收益/成本。例如延长时要求：
  - `E[τ_{d:d'}] / T_verify_{d:d'} > E[τ_d] / T_verify_d`
- **位置相关界（Theorem 3.3 / 3.4）**：在前缀接受假设下，定义 `ε_i` 为每个草稿位置 `i` 允许的最大长度上限：
  - `ε_i = max( d' ∈ Z | d' < (T_verify_i / (τ_i·c)) · Σ_{j=i}^{d'} Π_{k=i}^{j} p_k + i )`
  - 满足所有位置约束的 `d' = min_i ε_i` 是保证加速提升的充分条件；超出该界则必然违反必要条件。
- **收敛性证明（Theorem 3.5 / 3.6）**：
  - 期望加速比是推测长度的**单峰函数**（因前缀接受下，边际条件接受概率非增，边际验证成本近似恒定）。
  - 反复执行有益调整会在有限步内单调收敛至全局最优长度区间。
- **实践实现（Algorithm 1）**：
  - 用草稿者置信度 `q_i` 近似未知的目标接受概率 `p_i`（假设校准良好）。
  - 引入单个权衡超参数 `α`（吸收 `T_verify_i / (τ_i·c)`）和一个模型相关的最大推测长度 `d_max`。
  - 初始块大小设为草稿模型默认块大小；维护“草稿预算 `B`”以减少草稿模型调用；若计算的 `ε*` 低于当前长度，则回滚并终止调整（最多一次回滚，避免振荡）。
