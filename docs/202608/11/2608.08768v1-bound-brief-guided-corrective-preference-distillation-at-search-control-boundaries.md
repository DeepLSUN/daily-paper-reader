## 摘要
基于大语言模型（LLM）的深度搜索智能体通过迭代检索和推理来完成任务，但局部相关的证据可能导致持续的错误锚点漂移、约束漂移或局部主题漂移。现有方法监督轨迹、结果或步骤，但很少区分与任务对齐的延续与强化漂移的局部合理延续。我们提出BOUND，一种用于持续搜索漂移的简报引导纠正性偏好蒸馏框架。对于每个由学生诱导的决策时状态，BOUND构建一个教师端搜索状态简报，该简报保留原始搜索目标和关键约束，同时总结已确认证据、缺失信息和漂移状态。在简报的引导下，教师判断学生的延续是否包含可能影响后续决策的可纠正的局部搜索控制错误。结合rollout结果，该评估决定是构建学生特定修正与原始延续之间的纠正性对比，还是构建有依据答案与不必要检索延续之间的终止性对比。每个经过验证的状态匹配偏好对都操作化了一个搜索控制边界。直接偏好优化（DPO）将这些偏好蒸馏到学生中，而简报和教师端计算仅保留在训练阶段。我们在四个多跳QA基准和三个深度搜索基准上评估BOUND。在我们重新运行基线的六个基准中，BOUND在五个数据集和14个指标中的12个上领先。在相同的搜索控制接口和匹配设置下，BOUND在Bamboogle上超过Trajectory SFT 5.6个EM点，在BrowseComp-Plus上超过4.8个准确率点。代码可在https://github.com/RUCAIBox/BOUND获取。

## Abstract
Large language model (LLM)-based deep search agents solve tasks through iterative retrieval and reasoning, but locally relevant evidence can cause persistent wrong-anchor drift, constraint drift, or local-topic drift. Existing methods supervise trajectories, outcomes, or steps, but rarely distinguish task-aligned continuations from locally plausible ones that reinforce drift. We propose BOUND, a brief-guided corrective preference distillation framework for persistent search drift. For each student-induced decision-time state, BOUND constructs a teacher-side search-state brief that preserves the original search target and key constraints while summarizing confirmed evidence, missing information, and drift status. Guided by the brief, the teacher determines whether the student's continuation contains a correctable local search-control error likely to affect subsequent decisions. Together with the rollout outcome, this assessment determines whether to construct a corrective contrast between a student-specific correction and the original continuation, or a termination contrast between a supported answer and an unnecessary retrieval continuation. Each validated state-matched preference pair operationalizes a search-control boundary. Direct preference optimization (DPO) distills these preferences into the student, while the brief and teacher-side computation remain confined to training. We evaluate BOUND on four multi-hop QA benchmarks and three deep-search benchmarks. Across the six benchmarks for which we reran baselines, BOUND leads on five datasets and 12 of 14 metrics. Under the same search-control interface and matched settings, BOUND outperforms Trajectory SFT by 5.6 EM points on Bamboogle and 4.8 accuracy points on BrowseComp-Plus. Code is available at https://github.com/RUCAIBox/BOUND.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题背景**：基于大语言模型（LLM）的深度搜索智能体通过"迭代查询—检索—推理"的循环来完成多跳信息获取任务。然而，在逐步获取证据的过程中，语义上相关但局部性的证据可能将搜索导向偏离原始目标的方向。
- **核心问题——持续搜索漂移（Persistent Search Drift）**：论文系统性地刻画了三种漂移形态：
  - **错误锚点漂移（Wrong-Anchor Drift）**：检索证据引入的相关实体取代原始搜索目标成为新的检索锚点。例如，检索到"Lenard"的实验发现后，智能体转而搜索 Lenard 而非爱因斯坦。
  - **约束漂移（Constraint Drift）**：在查询改写过程中丢失关键限定条件（如年份、获奖理由等）。例如，丢失"1921年诺贝尔物理学奖"这一时间约束。
  - **局部主题漂移（Local-Topic Drift）**：探索与问题相关的旁支主题（如光电效应的历史），而非继续解决原始追问（如物理学家完成大学学业所在的城市）。
- **现有方法的不足**：
  - 基于成功轨迹的模仿学习难以覆盖上下文诱导的偏差；
  - 基于结果的强化学习在长交互中信号过于稀疏；
  - 现有细粒度监督（查询质量、信息获取、过程奖励等）往往只评估单步动作本身，却无法区分"局部合理但整体延续漂移"的行为——一个动作在当前上下文下看起来合理，却可能在强化已有偏差的方向上推进搜索。
- **论文的核心主张**：需要识别并纠正"搜索控制边界"（search-control boundary）上的局部决策错误，即在同一学生可见状态下，不同延续具备不同的搜索控制含义，且决策时证据足以支撑可靠偏好。BOUND 正是为此而设计的框架。

## 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

### 2.1 总体框架

BOUND 采用"教师引导 + 偏好蒸馏"的训练范式。学生策略（Qwen3-4B-Instruct）生成搜索轨迹，教师（DeepSeek-V4-Flash）在训练时基于学生状态构建偏好对，再通过 DPO 将偏好蒸馏回学生。整个流程如图 2 所示。

### 2.2 搜索状态简报（Search-State Brief）

核心创新之一是**教师端特权表示**——搜索状态简报 \(b_t = g_B(s_t)\)，其中 \(s_t = (q, H_t, C_t)\) 是学生可见状态（问题、动作历史、当前证据上下文）。简报包含五个字段：

1. **Original Search Target（原始搜索目标）**：问题真正询问的对象；
2. **Key Constraints（关键约束）**：答案必须满足的约束条件；
3. **Confirmed Evidence（已确认证据）**：当前证据中与问题相关的事实；
4. **Missing Information（缺失信息）**：仍需获取的信息；
5. **Drift Status（漂移状态）**：当前搜索方向相对原始目标的偏离程度。

简报的关键作用是：将"任务不变需求"（目标和约束）与"状态相关的搜索进展"分离，为教师在决策时点提供稳定的任务锚点，从而避免教师被已漂移的上下文带偏。

### 2.3 决策时评估与结果条件化对比构建

- **教师评估**：对每个决策时状态，教师结合简报和学生原始延续 \(y_t^0\)，输出评估记录 \(d_t = (z_t, \rho_t, e_t)\)：
  - \(z_t\)：辅助路由标签（evidence_completion / target_maintenance / answerability / not_selected）；
  - \(\rho_t\)：基于状态的论证；
  - \(e_t \in \{0,1\}\)：该延续是否包含具体的局部搜索控制错误。
- **评估排除未来信息**：教师评估时不看该延续产生的检索观测结果、后续轨迹信息、rollout 结局或金标答案。
- **结局决定对比形式**：
  - **失败 rollout（\(r=0\)）**：若存在可靠局部错误，则构建**纠正性对比**：选择学生特定修正（student-specific correction），拒绝学生原始延续。
  - **成功 rollout（\(r=1\)）**：在最早可被证据支持的 Answer 处构建**终止性对比**：选择该答案，拒绝一个"貌似合理但无必要"的继续检索动作。
  - **无可靠偏好的状态不产生任何对比**。

### 2.4 状态匹配偏好对与搜索控制边界

每个保留的偏好对形式为 \((s_t, y_t^+, y_t^-)\)，两个延续共享相同的问题、动作历史和证据上下文，因此对比隔离的是**局部搜索控制决策本身**。验证环节剔除：格式错误、动作/参数无差异、暴露教师独有信息、与构建路线不一致等无效对。

### 2.5 训练目标

使用 DPO 优化，初始策略 \(\pi_0\) 作为参考策略：
- 提升选择延续 \(y_t^+\) 的概率；
- 降低被拒延续 \(y_t^-\) 的概率。
- 简报和教师计算仅存在于训练阶段，推理时学生只依赖学生可见状态 \(s_t\)。

### 2.6 Reroute 执行语义

选择 Reroute 动作时，修正后的查询被追加到历史中，并过滤前一步检索结果中与修正查询相似度过低（E5-cosine < 0.2）的段落（若全部过低则保留最高分段落），再发起新一轮检索。该转换不需要教师调用，在 rollout 收集和推理中一致使用。

## 6. 论文的主要结论与发现

- **BOUND 显著优于轨迹级蒸馏**：在相同搜索控制接口和匹配设置下，BOUND 比 Trajectory SFT 在 Bamboogle 上高 5.6 EM，在 BrowseComp-Plus 上高 4.8 准确率（统计显著，\(p<0.001\)）。
- **BOUND 在多数基准上领先**：在重跑基线的 6 个数据集中，BOUND 在 5 个上取得最佳成绩；在 14 个指标上领先 12 个。
- **针对 7B 基线具有竞争力**：BOUND 虽仅 4B 参数，但在 5 个数据集上超过所有 Qwen2.5-7B 训练基线（如 R1-Searcher、SimpleDeepSearcher 等）。
- **深度搜索任务优势明显**：FRAMES F1 达 24.7（超最强 7B 基线 4.8 点），GAIA F1 达 40.8（超 6.5 点）。
- **Reroute 监督最关键**：消融显示移除 Reroute 后 BrowseComp-Plus 准确率从 29.6 降至 21.2，说明重新锚定目标对纠正漂移至关重要。
- **教师修正优于学生自生成替代**：教师修正保留了原始目标和约束，更可靠。
- **学生特定修正是必要的**：不依赖学生原始延续生成的通用修正效果下降。
- **简报的增益跨教师一致**：DeepSeek 和 Qwen3-32B 两位教师使用简报后学生表现均提升。
- **偏好构建应结合简报评估与 rollout 结局**：单独使用任何一种信号均不如两者结合。
- **BOUND 具有跨骨干可迁移性**：在更强的 Qwen3.5-4B 骨干上仍获得显著提升（准确率 +6.6，召回 +4.1）。

   - 状态匹配偏好对精确隔离局部搜索控制决策，避免了粗粒度轨迹监督的问题；
   - 教师"弃权"机制（not_selected）避免了在不可靠状态上强行构建偏好；
   - 训练/推理不对称设计：简报和教师计算完全限于训练，不增加推理开销。
3. **消融实验设计严谨**：各变体共享相同训练问题和候选状态池，归因清晰；控制实验（Trajectory SFT）设置匹配度高。
4. **跨数据集和跨骨干验证充分**：多跳 QA + 深度搜索共 7 个基准，辅以两种骨干、两种教师的扩展验证，增强了结论的普适性。
5. **可复现性意识较好**：代码开源，附录详细披露了构建接口、schema、验证规则和合成问题构造流程，并进行了污染审计。

## 8. 不足与局限

1. **算力信息缺失**：未报告 GPU 类型、数量、训练时长等关键资源信息，影响成本评估和可复现性。
2. **训练数据规模有限**：仅 983 道训练问题 / 2,424 个偏好对，且合成问题来自单一维基百科快照（2022 年 3 月），可能限制覆盖面与时效性。
3. **教师依赖**：教师使用闭源模型 DeepSeek-V4-Flash，且未开源教师评估模板的真实验证数据；教师本身也可能存在错误，论文仅通过 50 个样本的人工检查评估简报质量。
4. **部分基准劣势**：2WikiMultiHopQA 上弱于使用了该数据集训练的 7B 基线，说明跨基准泛化仍有提升空间。
5. **统计报告不完整**：除一处 \(p<0.001\) 外，未报告多次运行的标准差、置信区间或更多显著性检验。
6. **人工评估样本小**：50 个状态的抽样可能在漂移分布上不具备完全代表性。
7. **应用限制**：Reroute 的过滤机制依赖 E5-base-v2 相似度阈值（0.2），该阈值是否对不同检索环境和查询类型均稳健未做敏感性分析。
8. **无法完全排除泄漏风险**：虽然进行了污染审计，但合成问题的生成和基于偏好对的训练仍然共享同一维基百科语料库，存在潜在的主题分布耦合。
