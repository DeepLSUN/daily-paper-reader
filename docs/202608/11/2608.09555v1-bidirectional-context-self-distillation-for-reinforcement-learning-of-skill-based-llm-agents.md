## 摘要
外部自然语言技能为大型语言模型（LLM）智能体提供了可重用且可编辑的指导，以解决复杂任务。然而，其有效性不仅取决于技能质量，还取决于策略能否将提供的指导转化为适当的行动。然而，专门用于提升这种技能利用能力的方法仍未得到充分探索。在实践中，基于技能的智能体通常使用以任务级奖励为中心的强化学习目标进行训练，这种目标提供的监督有限，难以捕捉策略在利用所提供技能时的细微差异。我们提出了BCSD（双向上下文自蒸馏），一种将自蒸馏与强化学习相结合的训练框架，使LLM智能体更有效地利用外部技能。与以往依赖单一特权上下文的自蒸馏方法不同，BCSD从两个互补的技能上下文视角评估每条轨迹。增强视图引入更高级别的元技能指导，而缩减视图则修剪通用指导以突出任务特定技能。它们互补的令牌级信号被组合起来重新缩放RL优势。在ALFWorld和WebShop上的实验表明，BCSD在不同模型规模下取得了最强的整体性能，使智能体能够更有效地利用外部技能。消融研究进一步验证了增强视图和缩减视图的互补贡献。代码将发布以确保完全可复现性。

## Abstract
External natural-language skills provide large language model (LLM) agents with reusable and editable guidance for solving complex tasks. Yet their effectiveness depends not only on skill quality, but also on whether the policy can translate the provided guidance into appropriate actions. However, methods specifically designed to improve this skill-utilization ability remain largely underexplored. In practice, skill-based agents are commonly trained with reinforcement learning objectives centered on task-level rewards, which offer limited supervision and struggle to capture subtle differences in how effectively the policy uses the provided skills. We propose BCSD (Bidirectional Context Self-Distillation), a framework that combines self-distillation with reinforcement learning to train LLM agents to use external skills more effectively. Unlike prior self-distillation methods that rely on a single privileged context, BCSD evaluates each trajectory from two complementary skill-context views. The augmented view introduces higher-level Meta-Skill guidance, while the reduced view prunes general guidance to highlight task-specific skills. Their complementary token-level signals are combined to rescale the RL advantage. Experiments on ALFWorld and WebShop demonstrate that BCSD achieves the strongest overall performance across model scales, enabling agents to utilize external skills more effectively. Ablation studies further verify the complementary contributions of the augmented and reduced context views. Code will be released to ensure full reproducibility.

### 一、核心问题与研究动机

外部自然语言技能（如任务指南、操作规范）为LLM智能体提供了可复用、可编辑的先验知识，是提升复杂任务求解能力的重要手段。然而，现有研究存在两条主流路径却都忽略了“技能利用”这一核心问题：

- **技能生成/精炼路线**（如 SkillRL、SkillEvolver）：聚焦于如何提升技能本身的质量，却忽视了智能体是否能在长程任务中可靠地遵循这些技能。
- **技能内化路线**（如 Skill-SD、SDAR、SIRI）：将技能知识蒸馏到模型参数中，虽然减少了推理时的上下文依赖，但牺牲了技能的显式性、可编辑性和可迁移性。

已有证据表明，**提供高质量技能并不等于智能体能有效利用它们**。而现有基于技能的强化学习训练，采用任务级稀疏奖励作为唯一监督信号，无法识别决策中哪些是真正由技能引导的，难以捕捉策略利用技能的细微差异——这正是本文要解决的核心问题。

### 二、方法论：BCSD框架

#### 核心思想

> **“不把技能内化进参数，而是训练策略更有效地使用显式外部技能。”**

BCSD保留了外部技能在训练和推理时的显式上下文形式，并受 **OPSD（On-Policy Self-Distillation）** 范式的启发，将单一特权教师扩展为**双向互补上下文视图**，用两个视图产生的token级信号共同重缩放RL优势（Advantage），从而提供更细粒度、更可靠的训练监督。

#### 关键技术细节

**1. 上下文构建（三视图）**

| 视图 | 上下文构成 | 作用 |
|------|-----------|------|
| 基础上下文 C₀ | (Q, G, Sc) | 训练/推理共用，含通用技能G和任务特定技能Sc |
| 增强视图 C₁ | (Q, G, Sc, Mc) | 加入Meta-Skill高层使用指导，作为特权教师上下文 |
| 精简视图 C₂ | (Q, Gp, Sc) | 外部LLM剪枝G得到Gp，聚焦任务特定技能，减少干扰 |

**2. Meta-Skill提取与动态刷新**

- 定义：**Meta-Skill** 是从策略当前rollout轨迹中提取的、关于“如何应用给定技能”的高层文本指导，反映策略当前成功/失败的模式，属于训练期间的特权信息。
- 提取方式：从成功/失败轨迹集合中，用冻结的外部LLM对比提炼得到。
- 动态刷新：每经过一个验证窗口，基于新收集的轨迹数据重新刷新Meta-Skill，使其不断对齐策略持续进化的行为模式。

**3. Token级双向Gap计算**

对同一轨迹在C₀下采样后，固定响应序列不变，分别用当前策略在C₁和C₂下重新打分，得到两个token级对数概率差：

- Δaug = log πθ(yₜ|C₁, y<ₜ) − log πθ(yₜ|C₀, y<ₜ)
- Δpru = log πθ(yₜ|C₂, y<ₜ) − log πθ(yₜ|C₀, y<ₜ)
- 融合：Δ = α·Δaug + (1−α)·Δpru（默认α=0.9）

**4. 优势重缩放（核心公式）**

BCSD不改变GRPO优势的方向，仅调整其幅度：

- wᵢ,ₜ = clip(exp(sign(A_GRPO)·Δ), 1−c, 1+c)
- **A_BCSD = A_GRPO·[(1−λₙ) + λₙ·wᵢ,ₜ]**

其中λₙ从初始值λ₀=0.1线性衰减至0。训练早期提供密集的上下文引导，后期逐步回归纯环境奖励驱动。

**5. 训练算法**

遵循标准GRPO的裁剪目标，将A_BCSD替换原轨迹级优势，加上KL正则损失，以标准的on-policy RL流程迭代优化。

### 六、主要结论与发现

1. **BCSD整体性能最优**：在三个模型规模上都取得最强综合性能。Qwen2.5-3B上提升最显著——ALFWorld成功率82.0（比最强基线高5.4），WebShop成功率66.4（比最强基线高9.4）。
2. **两种上下文视图互补必要**：两个视图各自的token级信号仅有约50%的一致性（始终在47%-53%区间波动），说明它们提供非冗余的补充信息；任一视图缺失都会显著掉点。
3. **Meta-Skill特有权重最高**：去除Meta-Skill教师是最大的性能退化源（ALFWorld 82.0→71.1，WebShop 66.4→50.0），证明策略相关的高层使用指导是最关键信号。
4. **λₙ衰减策略有效**：从λ₀=0.1线性衰减到0最优；不衰减会导致策略过度依赖特权信号，干扰后期奖励驱动的优化。
5. **BCSD提升真正的“技能利用”能力**：移除任务特定技能Sc后，BCSD性能下降幅度大于Skill_GRPO*（ALFWorld -2.3 vs -0.8，WebShop -7.8 vs -6.2），说明BCSD更多地将增益归因于对外部技能的利用，而非将任务知识记忆化到参数中。
6. **训练动态优势明显**：在WebShop上，BCSD在60步时达到约45%成功率，而其他方法仍低于20%；且训练后期无显著回退，稳定性更好。

### 七、方法亮点

- **视角创新**：将自蒸馏的“单一特权上下文”拓展为“增强+精简”双向互补视图，更全面、更可靠地捕捉token级信用分配。
- **定位精准**：聚焦于“技能利用能力”这一既有文献盲点，在不牺牲外部技能显式性、可编辑性的前提下提升策略的遵循能力，属于概念上更合理的研究路径。
- **设计精细**：Meta-Skill动态刷新机制使特权指导与策略进化保持同步，避免信息过时；λₙ衰减使早期自蒸馏引导平滑过渡到后期环境奖励驱动。
- **分析的严谨性**：附加了跨视图一致性分析和技能去除敏感性分析，从机制层面解释为何双向视图有效。
- **保留外部技能的推理时可见性**：与技能内化方法不同，BCSD训练出的策略在使用时仍然依赖显式技能，便于人机协作中的审计和调试。
