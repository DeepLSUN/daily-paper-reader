## 摘要
虽然大型语言模型（LLM）代理越来越依赖长期记忆进行持续交互，但控制这种记忆的检索机制很少被视为可进化的组件。这种静态方法在异构记忆查询上限制了性能，这些查询通常需要多样化的证据构建策略。为了解决这个问题，我们引入了\textbf{ERSkill}，一个以检索为中心的自进化、技能引导记忆访问框架。ERSkill将交互历史编译为结构化记忆存储，并将检索行为表示为由基本原语组成的可执行技能。在推理时，训练好的路由器动态地将每个查询匹配到最优技能，以构建定制证据用于答案生成。为了实现持续改进，ERSkill在训练过程中共同进化技能集和路由器。它采用经验字典树来高效记录探索过的检索路径，以及一种双前沿机制，安全地将新技能能力的扩展与稳定、面向路由器的部署解耦。跨多个代理记忆基准的实验表明，ERSkill大幅优于强大的非进化和自进化基线。值得注意的是，使用Qwen3-Next-80B-A3B-Instruct时，它在F1、BLEU-1和LLM-judge分数的整体平均值上提高了31.3%，使用GPT-5.4-nano时提高了28.1%。

## Abstract
While Large Language Model (LLM) agents increasingly rely on long-term memory for persistent interactions, the retrieval mechanisms governing this memory are rarely treated as evolvable components. This static approach limits performance on heterogeneous memory queries, which often demand diverse evidence construction strategies. To address this, we introduce \textbf{ERSkill}, a retrieval-centric framework for self-evolving, skill-guided memory access. ERSkill compiles interaction histories into a structured memory store and represents retrieval behaviors as executable skills composed of fundamental primitives. At inference time, a trained router dynamically matches each query to the optimal skill to construct tailored evidence for answer generation. To enable continuous improvement, ERSkill co-evolves the skill set and the router during training. It employs an experience trie to efficiently record explored retrieval paths, alongside a double-frontier mechanism that safely decouples the expansion of new skill capabilities from stable, router-facing deployment. Experiments across multiple agent memory benchmarks demonstrate that ERSkill substantially outperforms strong non-evolving and self-evolving baselines. Notably, it improves the overall average across F1, BLEU-1, and LLM-judge scores by 31.3\% with Qwen3-Next-80B-A3B-Instruct and by 28.1\% with GPT-5.4-nano.

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：以检索为中心的自进化框架 **ERSkill** (Evolving Retrieval Skill)，将记忆访问建模为“技能引导的证据构建”。
- **整体架构**（图 2）：
  1. 将交互历史编译为结构化记忆存储；
  2. 将检索行为表示为可执行技能（由基础原语组成）；
  3. 训练一个路由器，为每个查询动态匹配合适的技能；
  4. 执行技能生成证据视图，供 LLM 生成答案；
  5. 训练阶段，技能集与路由器协同进化。

### 2.1 记忆存储与检索原语
- **结构化记忆**：将交互历史 D 拆分为原子级记录 A = {a1,...,an}，每个原子包含文本、元数据和时间戳；记忆存储表示为 M(D) = (A, I, G)，其中 I 是索引集合，G 是图集合。
  - 索引：稠密索引（embedding）、实体-原子索引、词法统计索引等。
  - 图：相似度图（atom 之间余弦相似度 top-k）、关系图（时间邻接规则边 + LLM 抽取的语义关系边，关系类型包括 Changed, Cause, Reason, HinderedBy, React, Want, none）。
- **固定原语库 P**（表 3）：
  - 搜索原语：`entity_search`（实体锚定检索）、`lexical_search`（BM25 词法匹配）、`dense_search`（稠密向量检索）。
  - 扩展原语：`temporal_focus_expand`（时间区间扩展）、`similarity_expand`（相似度边传播）、`relation_expand`（类型化关系边扩展）。
  - 处理原语：`llm_process`（查询改写、证据过滤、提取控制变量如 time_range、preferred_relations）。
- 原语库固定，技能通过组合原语不同序列形成，因此所有技能结果可累加在统一经验结构中。

### 2.2 检索技能与路由器
- **技能定义**：技能 κ = (cκ, ρκ)，cκ 是技能描述与信息偏好，ρκ 是原语序列。执行时按顺序应用原语更新证据状态 s，返回最终证据视图 s_Lκ。
- **技能路由器**：使用共享编码器 Enc(·) 编码查询 q 和技能 κ，通过可学习评分函数 uθ(q, κ) 计算兼容性，再经 softmax 得到技能分布：
  \[
  R_\theta(\kappa \mid q, K) = \frac{\exp(u_\theta(q,\kappa))}{\sum_{\kappa'\in K}\exp(u_\theta(q,\kappa'))}
  \]
  - 文本编码器冻结（Qwen3-Embedding-0.6B），仅优化路由参数（线性投影 + 两层 MLP）。
  - 推理时选择 argmax 技能执行，将证据视图送入 LLM 生成答案 ŷ = fLLM(q, s_L)。

### 2.3 技能-路由器协同进化
- **双前沿机制**（Pareto 风格）：
  - **能力前沿 Ct**：保留具有“oracle 侧价值”的技能（即针对每个查询选择最佳技能时能达到的最优效用），跟踪已发现的检索能力。
  - **部署前沿 Bt**：向路由器暴露的技能集，只保留经过验证、路由器能够稳定选择的技能。
  - 该分离允许探索新能力的同时保持部署稳定。
- **经验字典树（Experience Trie）**：记录探索过的原语路径，共享前缀仅存储一次；每个路径存储训练批量 rollout、验证 rollout、前沿状态等信息。技能生成器基于路径历史避免重复提出等价的检索程序。
- **技能候选生成**：通过编辑当前能力前沿技能（增/删/替换原语）产生新候选，并排除已记录路径；使用分析器（失败/成功轨迹分析）、设计器（整合诊断并产生高层提案）、生成器（具体化为技能字段）三阶段工作流。
- **能力前沿更新**：定义效用 Util(κ; Q) 和 oracle 分数剖面 gK(q)=max_{κ∈K} r(q,κ)。使用前沿重算算子 Φ(K; Q)：按效用排序，仅当移除某个技能不减少任何查询的 oracle 分数时才删除。先在训练批次上做临时前沿过滤，再用验证集做最终前沿更新。
- **路由器更新**：使用历史 rollout 窗口 Wt 中的 (q, Kq, {r(q,κ)}) 实例，以 soft-label 交叉熵训练：
  \[
  \tilde{p}(\kappa \mid q, K_q) \propto \exp(r(q,\kappa)), \quad
  L_{\text{router}} = -\sum_{(q,K_q,\cdot)\in M}\sum_{\kappa\in K_q} \tilde{p}(\kappa\mid q,K_q)\log R_\theta(\kappa\mid q,K_q)
  \]
- **部署前沿更新**：仅在能力前沿变化时尝试更新；候选部署前沿 B'_t = Φ(Bt ∪ Ht; Qval)，计算路由性能差 Δroute，若满足增益阈值 γroute 或满足允许小幅度性能下降但更紧凑的条件（|B'|≤|B| 且 Δ ≥ -ξdrop）则接受，否则保持 Bt 不变；接受/拒绝结果写回经验字典树。
- **理论保证（Proposition 2.1）**：能力前沿和部署前沿的 oracle 覆盖率 OCov(K; Q) 在验证集上单调不减，证明见附录 C。

## 6. 论文的主要结论与发现

- **主结果**：ERSkill 在三个基准上均取得最佳平均性能，相比最强基线将 F1、BLEU-1、L-J 整体平均提升 **31.3%**（Qwen3-Next-80B-A3B-Instruct）和 **28.1%**（GPT-5.4-nano）。
- **细粒度分析**（图 4）：在需要精确定位证据的任务（Single Hop、Multi Hop）上增益更大，说明自适应检索行为对证据搜索能力有实质帮助。
- **迁移效果**：直接在 LongMemEval 上迁移训练的 router 和技能仍达到最佳，说明学到的检索技能具有跨数据集的复用性。
- **成本-性能优势**：ERLSkill 在采用 LLM 构建记忆的方法中最轻量（只在关系抽取时使用 LLM），推理 token 处于较低区间但 L-J 分数最高，说明增益来自“精准证据构建”而非“喂更多检索内容”。
- **消融结论**：去除技能进化或路由器会带来最大性能下降，证明“发现有效技能”和“查询依赖的技能选择”都至关重要；双前沿稳定了技能接受，经验字典树降低重复探索并指导候选生成。
- **进化稳定性**：变异系数最大低于 5.4%，进化过程稳定可重复。

## 7. 优点

- **问题定义新颖**：首次系统地将“记忆检索行为”本身作为可进化对象，填补了自进化智能体在检索侧设计的空白。
- **方法设计有层次感**：
