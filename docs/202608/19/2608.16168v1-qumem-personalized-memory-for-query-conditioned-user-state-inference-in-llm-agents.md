## 摘要
大语言模型（LLM）智能体越来越多地使用外部记忆系统，通过利用长期且不断演变的交互历史来支持个性化，其中用户偏好可能分布在不同时间、随情境变化，并与早期证据相冲突。然而，现有系统面临三个局限：固定轮次、固定词元或基于会话的边界可能会混淆无关对话，或将事件与其原因、决策和结果割裂开；将同一交互中的多条用户信息存储为单一记忆，会把功能不同且应可独立检索的项目绑定在一起；将当前任务视为单个top-k检索查询，可能会返回单独相关但无法共同捕捉偏好演变、时间有效性和上下文适用性的碎片。我们提出QUMem，一种用于查询条件下用户状态推断的结构化记忆框架。QUMem首先根据语义连续性将交互历史分割为变长片段，然后将每个片段分解为可独立检索的事实、偏好和可迁移洞察记忆，同时保留时间位置和来源证据。在推理时，三个顺序智能体识别任务特定的信息需求，在类型化记忆存储上规划多查询检索，并联合推断出在时间和上下文上均有效的用户状态，用于下游响应生成。QUMem在PersonaMem和KnowU-Bench上均取得了最先进的表现，证明了查询条件下用户状态推断对长期个性化的有效性。

## Abstract
Large language model (LLM) agents increasingly use external memory systems to support personalization by drawing on long and evolving interaction histories, in which user preferences may be distributed across time, change with context, and conflict with earlier evidence. However, existing systems face three limitations: fixed-turn, fixed-token, or session-based boundaries can mix unrelated dialogue or split an event from its causes, decisions, and outcomes; storing multiple pieces of user information from the same interaction as a single memory binds together items that serve different functions and should be independently retrievable; and treating the current task as a single top-$k$ retrieval query can return fragments that are individually relevant but fail to jointly capture preference evolution, temporal validity, and contextual applicability. We introduce \textsc{QUMem}, a structured memory framework for query-conditioned user-state inference. \textsc{QUMem} first segments interaction histories into variable-length episodes according to semantic continuity, then decomposes each episode into independently retrievable factual, preference, and transferable insight memories while preserving temporal positions and source evidence. At inference time, three sequential agents identify task-specific information needs, plan multi-query retrieval over the typed memory stores, and jointly infer a temporally and contextually valid user state for downstream response generation. \textsc{QUMem} achieves state-of-the-art performance on both PersonaMem and KnowU-Bench, demonstrating the effectiveness of query-conditioned user-state inference for long-term personalization.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**
- LLM智能体日益需要作为跨会话的持久个人助理，必须记忆和利用长期、不断演变的用户交互历史，以实现个性化服务。
- 然而，用户偏好在长程交互中可能：分布在不同的时间点、随情境变化、与早期证据冲突，这给记忆系统带来根本性挑战。
- 现有记忆系统普遍存在三大局限：
  1. **边界划分不当**：固定轮次/词元/会话边界可能混合无关对话，或将事件与其原因、决策、结果割裂，破坏事件级上下文。
  2. **混合存储耦合**：同一交互包含的多种功能各异的信息被绑定为单一记忆，无法独立检索。
  3. **单一查询失效**：将当前任务直接作为单一top-k检索查询，返回的碎片化记忆虽然各自相关，但无法联合捕捉偏好演化轨迹、时间有效性和上下文适用性。

**核心问题的本质：**
- 长期个性化的关键不仅在于找到相关记忆，更在于从历史中推断出**与当前查询相关、且时间与上下文有效**的用户状态（user state）。
- 论文将"用户状态"定义为：由历史证据支持、与当前查询相关、并在当前上下文中适用的结构化用户信息表征。

## 2. 提出的方法论：QUMem

### 2.1 核心思想
QUMem 提出"查询条件下的用户状态推断"范式，将记忆构建与查询时推断解耦为两个阶段：**构建时**保留事件上下文并区分记忆功能角色，**查询时**通过多智能体协作完成信息的获取与联合解释。整体流程遵循 `Zq = Φmem(H, q); ŷq = Ψ(q, Zq)` 的形式化框架。

### 2.2 模块一：动态情节构建（Dynamic Episode Construction）
- 使用轻量级**语义连续性分类器 fθ**（基于 Qwen3.5-4B 微调），仅接收相邻用户话语 (xt−1, xt)，判断二者是否属于同一事件（ct=1 继续、ct=0 切分）。
- 场景避免了固定边界问题，使事件的原因、决策、反馈和结果得以在同一情节中联合解释。
- 选择轻量分类器而非反复调用大模型，以降低计算开销和推理延迟。

### 2.3 模块二：类型化记忆分解（Typed Memory Decomposition）
- 对每个情节 Ek 调用同一 LLM 分解器 gϕ 三次（按记忆类型 d 分别条件化），抽取三类原子记忆：
  - **事实记忆（F）**：记录具体经验、行为、活动、状态或事件。
  - **偏好记忆（P）**：记录用户对特定对象/情境的选择、倾向、需求与约束及其直接理由，不假设永久有效。
  - **可迁移洞察记忆（I）**：从具体决策和反馈中抽象出的、可迁移到新情境的用户决策原则，同时保持证据可追溯。
- 每条记忆表示为其内容 v、类型 d、时间位置 p（该记忆最新来源轮次的最大位置）、支撑交互集合时 E，并通过索引 k 链接回源情节。
- 三类记忆分别存入对应的类型化记忆库 MF、MP、MI，实现独立检索与动态路由。

### 2.4 模块三：查询条件下用户状态推断（Query-Conditioned User-State Inference）
推理阶段由三个顺序协作的智能体完成，将"证据需求→证据获取→证据解释"三阶段显式分离：

1. **信息需求智能体（A1）**：分析当前查询 q，确定需要从历史中核实的用户信息（如偏好早期与后期表达、各自适用情境、变化原因等），但不指定检索语句或存储位置。
2. **检索规划智能体（A2）**：将每条信息需求改写为一个或多个自包含查询，并为每个查询选择一个或多个类型化记忆库，生成检索计划 `Pq = {(eq_j, D_j)}`，随后执行检索并对候选结果去重合并。
3. **用户状态推断智能体（A3）**：基于检索到的候选记忆，重构查询条件下的用户状态 `Zq = (Fq, Tq, Iq)`——按时间组织的相关事实、偏好演化轨迹、以及适用于当前任务的迁移洞察，供下游模型生成个性化响应。

## 6. 主要结论与发现

1. **主结果**：QUMem 在两个基准上均达到最优——PersonaMem Overall 从 52.99%（Mem0）提升至 **61.02%**（GPT-4o-mini），从 63.29% 提升至 **70.58%**（Gemini-3.5-flash）；KnowU-Bench 总体成功率较最强基线提升 **4.6 个百分点**。
2. **优势来源**：最大的性能增益出现在需要联合解释多时点/多情境证据的任务上（完整偏好演化追踪、偏好一致推荐、跨情境泛化），而"识别最新偏好"类任务提升较小——说明 QUMem 的价值**不仅是检索最新偏好，而是组织时间与情境分布的证据**。
3. **长上下文优势**：随着历史长度增长（32K→1M），QUMem 相对基线的优势持续扩大，表明其在证据分散于长上下文时的结构化组织能力更有价值。
4. **效率优势**：QUMem 以最低的 LLM 调用数和 token 成本达成最优效果，证明低构建频率 + 每情节固定 3 次 LLM 调用的设计同时带来计算效率与质量收益。

## 8. 不足与局限

- **绝对性能仍有提升空间**：PersonaMem 的"生成新建议"类别仍是最弱项，论文也承认推理偏好与生成"既新颖又符合偏好"的响应之间存在鸿沟；KnowU-Bench 硬任务的绝对成功率仍较低，端到端个性化执行仍不可靠。
- **长上下文的退化趋势**：虽然 QUMem 在 1M 配置下相对基线优势扩大，但其绝对准确率仍低于短配置，说明超长历史中的证据利用仍是未完全解决的问题。
- **实验范围限制**：KnowU-Bench 仅使用了单一基座模型（GPT-4o-mini）；未报告统计显著性检验或多轮运行方差；未在开源模型系列上验证。
- **依赖大模型质量**：记忆分解和三个推断智能体均依赖 LLM 能力，在较弱基座上的表现未知；且论文对失败案例缺乏深入分析。
- **评估粒度有限**：PersonaMem 的四选一格式可能高估/低估真实场景中的开放生成质量；可迁移洞察记忆的抽象质量未做独立评估。
- **工程与部署细节**：构建时的分类器训练数据（来自 LoCoMo）与测试域（PersonaMem/KnowU-Bench）的分布差异未讨论。
