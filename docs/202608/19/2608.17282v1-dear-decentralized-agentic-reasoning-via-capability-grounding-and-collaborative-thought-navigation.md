## 摘要
现有的智能体推理系统通常依赖集中式协议。这种设计引入了路由瓶颈和静态角色分配，在处理复杂的多模态查询时往往失效。我们提出DeAR（去中心化智能体推理），一种从集中控制转向自主点对点协作的框架。DeAR基于三种机制：（1）用于查询相关智能体特化的去中心化能力锚定，（2）用于定向智能体交互的思维图导航，以及（3）用于自适应纠错的拓扑更新。在9个多样化的多模态推理和基于文本的问答基准上的评估表明，DeAR持续优于最近的基线方法，验证了智能体间的去中心化与自适应协作能提升知识密集型推理任务的准确性。源代码将在https://open_upon_acceptance提供。

## Abstract
Existing agentic reasoning systems typically rely on centralized protocols. This design introduces routing bottlenecks and static role allocations that often fail when handling complex multimodal queries. We propose DeAR (Decentralized Agentic Reasoning), a framework that shifts from central control to autonomous peer-to-peer collaboration. DeAR is built on three mechanisms: (1) decentralized capability grounding for query-dependent agent specialization, (2) thought map navigation for targeted peer interactions, and (3) topology update for adaptive error correction. Evaluations across 9 diverse multimodal reasoning and text-based QA benchmarks indicate that DeAR consistently outperforms recent baseline methods, validating that decentralized and adaptive collaboration among agents enhances accuracy in knowledge-intensive reasoning tasks. The source code will be available at https://open_upon_acceptance.

### 一、核心问题与整体含义（研究动机与背景）

- **研究动机**：现有基于大语言模型（LLM/MLLM）的智能体推理系统大多依赖**集中式协作协议**——由一个中央协调器（planner/judge）统一负责任务路由、角色分配和结果聚合。这种设计存在三个结构性缺陷：
  1. **路由瓶颈**：中央协调器成为单点故障，信息流经单一节点时产生严重的信息损失与延迟。
  2. **静态角色分配**：预定义的固定角色标签（如"Math Agent"）无法反映真实能力，导致在开放场景中能力错配与幻觉。
  3. **错误传播**：当某一智能体产生错误中间结果时，中央 Judge 往往盲目聚合这些缺陷结果，缺乏同伴验证机制，最终导致错误答案。
- **核心论点**：复杂推理的失败根源在于**集中式协作协议的结构性缺陷**，而非底层模型能力不足。现实世界的复杂问题解决本质上是去中心化的——跨学科专家通过点对点交流、协商边界、自组织协作来弥合知识鸿沟。
- **整体含义**：论文提出 **DeAR（Decentralized Agentic Reasoning）** 框架，将智能体推理从集中控制范式转向自主点对点协作范式，为多智能体系统设计提供了一种新的"去中心化"路径。

### 二、方法论：DeAR 框架

DeAR 的核心是**在智能体思维图（Agentic Thought Map）上进行协作导航**，系统形式化定义为：
```
S = (Q, A, C, K)
```
其中 Q 为查询，A 为智能体集合，C 为协作倾向矩阵，K 为知识状态序列。整体包含三大核心机制：

#### 1. 去中心化能力锚定（Decentralized Capability Grounding）
- **摒弃静态角色标签**，智能体基于其底层模型的技术报告/模型卡（官方基准数据）构建可验证的能力画像：
  - τ_cr：常识推理（源于 MMLU）
  - τ_ea：解释能力
  - τ_nc：数值计算（源于 GSM8K）
  - τ_fr：事实可靠性（源于 TruthfulQA）
  - τ_cm：自然语言理解
- **校准机制**：将原始基准得分通过 Softmax 函数投影到共同尺度，确保跨智能体的可比性和数值稳定性。
- **查询相关的动态能力状态**：智能体收到查询后，结合自身基准画像动态评估能力状态，实现**查询驱动的动态专业化**。

#### 2. 协作倾向矩阵与思维图导航（Thought Map Navigation）
- 定义**协作倾向向量** c_i，其中协作倾向系数通过温度缩放 Softmax 计算：
```
c_ij = exp(τ_dj / T) / Σ_k≠i exp(τ_dk / T)
```
- 自协作被禁止（c_ii = 0），所有智能体的偏好向量聚合为**协作倾向矩阵 C ∈ R^N×N**。
- **局部图遍历**：从随机种子智能体开始，当前活跃智能体作为局部导航器，依据增量效用函数选择下一个下游同伴：
```
u_i(a_j) = c_ij（若 a_j 未访问），否则 0
a_{i+1} = arg max u_i(a_j)
```
- **动态终止**：当所有未访问同伴的倾向值低于阈值或智能体耗尽时终止，由终端智能体基于完整累计上下文生成最终答案。

#### 3. 拓扑更新与渐进式精炼（Topology Update / Progressive Refinement）
- 若最终答案验证失败（"思维地图中的死胡同"），系统执行**局部化、渐进式回溯**——先修剪当前终端边，若局部路径尝试耗尽，则逐步向先前边扩展。
- 对失败边施加**衰减因子 α（默认 0.5）** 更新协作矩阵：
```
c_ij ← α · c_ij（若边失败），否则保持不变
```
- 智能体随后在更新后的拓扑上重新导航，逐步收敛到有效推理路径，**避免从头重启的高昂代价**。

### 六、主要结论与发现

1. **去中心化优于集中化**：DeAR 在全部 4 个多模态基准上均超越 AutoGen、AgentVerse、DyLAN 等集中式多智能体框架，证明去中心化拓扑能有效规避中心瓶颈。
2. **小模型协作可超越大模型**：DeAR（四模型总参数小于 72B）在 MathVista 上比 Qwen2-VL-72B 高 18.07 分（59.41 vs. 41.34），表明**结构化协作架构的收益可超越参数规模增益**。
3. **三大机制缺一不可**：消融实验显示，固定角色导致 MMMU 下降 5.76 分；去除思维图导航导致大幅退化（MathVista 下降 7.73）；去除拓扑更新导致一致性的多基准退化。
4. **拓扑更新有效纠错**：通过渐进式回溯与衰减因子，各基准收益稳定（MMMU: +2.37，MathVista: +3.76，ChartQA: +1.42，ScienceQA: +2.53）。
5. **动态资源分配**：MathVista 上 62.5% 的查询由不超过 3 个智能体解决，只有 37.5% 的复杂问题需要全部 4 个智能体，体现资源高效性。
6. **衰减因子最优区间**：α ∈ [0.5, 0.8] 时性能最优；过小导致过度修正和不稳定路径，过大致使无效路径重复计算。
