## 摘要
我们提出了MoNe，一种轻量级模块化神经记忆，可附加到任何冻结的预训练Transformer上，无需重新训练即可实现长上下文推理。MoNe通过测试时学习的快速权重神经记忆网络和层局部梯度更新，以固定大小的分段读取上下文；在推理时，记忆仅从查询令牌生成键和值，不重新读取上下文令牌。这种两阶段设计将推理成本与上下文长度解耦，实现了O(N)预处理和O(1)查询成本，峰值GPU内存不随N增长。在128K令牌时，与ICL相比，MoNe将计算和峰值GPU内存均减少了约80%，仅增加6.4%的参数开销。MoNe可泛化到远超骨干网络原生窗口的上下文长度，在RULER的针在海捞和单词提取基准上表现出强劲性能，而ICL在这些基准上性能急剧下降。

## Abstract
We present MoNe, a lightweight modular neural memory that attaches to any frozen pretrained Transformer to enable long-context inference without retraining. MoNe reads context in fixed-size segments via test-time learning of fast-weight neural memory networks with layer-localized gradient updates; at inference, the memory generates keys and values from the query tokens alone, with no context tokens re-read. This two-phase design decouples inference cost from context length, achieving $O(N)$ preprocessing and $O(1)$ query cost with peak GPU memory that does not grow with $N$. At 128K tokens, MoNe reduces both compute and peak GPU memory by approximately 80% compared to ICL with only 6.4% parameter overhead. MoNe generalizes to context lengths far beyond the backbone's native window, achieving strong performance on needle-in-a-haystack and word extraction benchmarks from RULER, where ICL degrades sharply.

## 1. 核心问题与整体含义

**研究动机**

大语言模型（LLM）在实际应用中面临长上下文处理的严峻挑战：

- **上下文学习（ICL）的二次复杂度成本**：将完整上下文直接输入 prompt 会让自注意力机制的 FLOPs 随上下文长度呈二次方增长（O(N²)），在移动设备等资源受限环境中变得不可行。
- **小模型在长上下文下的脆弱性**：即便上下文适配于窗口内，小模型也往往难以从长 prompt 中可靠提取信息，尤其在需要跨多个分散片段进行复杂推理的任务上。
- **RAG 的局限**：检索增强生成（RAG）虽通过分块选择缓解成本，但嵌入检索本质上依赖局部可恢复的事实，当答案需要整合多个单独不显著的散布片段时容易失败。
- **循环模型（Mamba、TTT、Titans）的集成障碍**：这类模型可实现线性复杂度，但要求从头设计并训练全新架构，无法无缝集成到现有预训练 Transformer 中。

**核心含义**
MoNe 旨在以**即插即用**的方式，为任意冻结的预训练 Transformer 赋予高效长上下文推理能力，无需重训练骨干网络，同时将推理成本与上下文长度解耦——这是对"长上下文必须付出高成本"这一假设的直接挑战。

## 2. 方法论

### 2.1 核心思想

MoNe 采用**两阶段设计**：

1. **测试时学习（Test-Time Learning）**：将上下文 C 划分为 S 个固定大小（T=512）的非重叠分段，依次处理并更新每层的"快速权重"神经记忆网络。
2. **推理阶段**：查询令牌仅通过与记忆模块交互生成记忆令牌（memory tokens），这些记忆令牌作为键值供冻结骨干网络的自注意力使用，**无需重新读取任何上下文令牌**。

### 2.2 关键技术细节

- **记忆模块结构**：每层使用 SwiGLU MLP 作为快速权重记忆模块，参数为 W(l) = {Win, Wgate, Wout}，均为 dh×dh 维度，使用非线性网络增强记忆的表达容量。
- **记忆注入**：查询令牌经 Wq 投影后读取缓存的快速权重状态 W(l)_S，生成记忆令牌 hj = M(Wq·xj; W(l)_S)，经 RMSNorm 归一化和学习网关缩放后，投影到键值空间并与标准注意力条目拼接：`Attention(Q, [K ∥ Wkh], [V ∥ Wv h])`。
- **关联记忆损失**：ℓ(l)_s,j(W(l)) = −(v(l)_s,j)ᵀ M(k(l)_s,j; W(l))，通过最大化记忆输出与目标值的內积来"印记"关联 k → v，无需预测误差。
- **层局部梯度更新**：每个更新仅由该层自身的正向传播激活计算，不通过其他层传播梯度（∂ℓ(l)/∂W(l′) = 0, ∀l′≠l），实现真正的模块化。
- **分段局部 RoPE**：位置编码使用局部索引 p_local = j mod T，使位置始终落在 [0, T) 范围内，不受总上下文长度 N 影响——这是 32 倍外推（4K→128K）的关键机制。
- **元学习训练**：LoRA 适配器和元参数（学习率、动量投影、输出缩放等）通过离线生成损失训练，部署时完全冻结，快速权重更新作为一个固定的预学习算法运行。

### 2.3 复杂度优势

- 测试时学习：O(N) 总 FLOPs
- 推理时：O(1) 查询成本（与 N 无关）
- 峰值 GPU 内存：不随 N 增长（恒定）

1. **性能优势显著**：MoNe 在所有任务和长度上保持近完美表现（S-NIAH 128K 时 0.96、MK-NIAH 0.94、FWE 0.96），远优于 ICL（在 128K 时分别降至 0.28、0.00、0.23）。

4. **32 倍外推能力**：仅用 4K 训练上下文即可泛化到 128K，无需额外训练或位置插值，关键机制是分段局部 RoPE。
5. **设计决策明确**：全部 24 层覆盖和 T=512 分段大小是性能-效率最优配置。

## 7. 优点

- **即插即用的模块化设计**：不修改骨干任何权重，仅增加 6.4% 参数，可无缝集成到现有预训练 Transformer，避免了重新训练新架构的高昂代价。
- **层局部梯度更新**：关联记忆损失的局部性使更新高效且真正模块化，避免了从输出 logits 反向传播到深层的巨大开销。
- **优雅的位置外推机制**：分段局部 RoPE 是一个精巧设计，将位置索引限制在固定范围内，使长度外推变得"免费"。
- **常数额定内存**：记忆 KV 对大小固定（每层 T 条目），不随 N 增长——这对资源受限设备（移动端、端侧 AI）极具吸引力。
- **多查询复用与增量更新**：最终快速权重状态可跨多个查询复用，新上下文可增量扩展而无需重新处理旧内容。
- **元学习范式**：快速权重更新作为预学习的固定算法运行，保证了部署时的稳定性和效率。
