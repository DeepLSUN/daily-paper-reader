## 摘要
测试时计算可以大幅提升大语言模型的推理性能，然而额外计算如何以及何时发挥作用仍未被充分理解。我们研究了发散-收敛推理（DCR），一个简单的两阶段原语，包括生成多个候选解决方案的探索阶段和随后的收敛协调阶段。我们提出了三项核心结果。首先，我们表明即使单次协调步骤也能可靠地放大正确的少数派报告：跨数据集而言，当正确的探索输出处于少数时——即多数投票失效的情形——DCR 常常能恢复正确答案。其次，我们引入了递归 DCR，一种自回归协调系统，它迭代地分析分歧并分配额外的测试时计算。递归 DCR 在 AIME 2024 上达到 93.3%，在 AIME 2025 上达到 92.0% 的准确率，同时平均使用约少 27% 的计算量，表明精细化的资源分配优于统一缩放。第三，我们通过一个简单且无需训练的离散度指标分析探索输出之间的分歧。离散度揭示了分歧与测试时收益之间的结构化关系：在 DCR 有效的场景中，探索输出间更高的分歧与协调带来的更大准确率提升相关联。综合来看，这些结果表明，常被视为噪声的分歧可以被系统性地利用以改进测试时推理，并揭示了智能体式大语言模型系统的新兴缩放规律。

## Abstract
Test-time compute can substantially improve Large Language Model (LLM) reasoning performance, yet how and when additional compute helps remains poorly understood. We study Divergent-Convergent Reasoning (DCR), a simple two-phase primitive consisting of an exploration phase that generates multiple candidate solutions followed by a convergent reconciliation phase. We present three core results. First, we show that even a single reconciliation step can reliably amplify correct minority reports: across datasets, DCR often recovers the correct answer when correct exploration outputs are in the minority, a regime where majority voting fails. Second, we introduce recursive DCR, an autoregressive reconciliation system that iteratively analyzes disagreements and allocates additional test-time compute. Recursive DCR achieves higher accuracy than fixed-compute baselines-reaching 93.3% on AIME 2024 and 92.0% on AIME 2025-while using roughly 27% less compute on average, demonstrating that attentive resource allocation is superior to uniform scaling. Third, we analyze disagreement among exploration outputs via a simple, training-free dispersion metric. Dispersion reveals a structured relationship between disagreement and test-time gains: in regimes where DCR is effective, higher disagreement among exploration outputs is associated with larger accuracy improvements from reconciliation. Together, these results show that disagreement, often viewed as noise, can be systematically exploited to improve test-time reasoning and reveal emerging scaling laws for agentic LLM systems.

- **整体含义**：论文提出 **发散-收敛推理（Divergent-Convergent Reasoning, DCR）** 框架，证明分歧并非噪声，而是一种可被系统利用、用于分配测试时计算的高价值信号；并揭示了“面向智能体 LLM 系统”的测试时扩展规律。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 总体框架

DCR 是一个两阶段原语：

1. **发散探索（Divergent Exploration）**
   - 对给定问题 \(Q\)，通过多个独立 LLM 副本、不同随机种子/温度采样 \(N\) 个候选解决方案（proposals），构成解池 \(S = \{x_1,...,x_N\}\)。
   - 目的是鼓励多样性，模拟多个独立研究团队从不同角度探索问题。

2. **收敛调和（Convergent Reconciliation）**
   - 使用 \(K\) 个独立 reviewer 调用（reviewer width \(K\)）对解池进行批判性分析。
   - 提示要求 reviewer 完成三步：
     1. **识别共识步骤**：多数方案共同出现的推理路径，通常只需简单验证。
     2. **定位分歧步骤**：方案间不一致的点，被视为问题中最难的部分，需要深入分析。
     3. **综合调和答案**：结合已验证的共识步骤和对分歧步骤的新推理，构造一个全新的一致解；同时**显式考虑少数派提案是否包含关键修正**（“是否多数派忽略了少数派中的正确校正”）。

### 2.2 递归 DCR（Recursive DCR）

- 单轮 DCR 可扩展为多轮递归版本：将每一轮调和后的输出作为下一轮的提案池，形成自回归控制循环。
- **停止规则：一致同意停止（unanimous-consent stopping）**
  - 每一轮检查 \(K\) 个 reviewer 是否产生完全相同的最终答案；若是则提前停止并返回该答案。
  - 否则继续下一轮，直到达成一致或达到最大轮次/预算。
  - 该规则无需验证器、自动调整：简单任务快速收敛，困难任务自动消耗更多计算。
- 默认参数：每轮 reviewer 宽度 \(K=8\)；计算量从 8 次调用（快速收敛）到最多 80 次调用（10 轮）动态变化。
- 若预算耗尽仍未达成共识，则返回多数答案并附带少数派报告供下游复查。

### 2.3 离散度指标（Dispersion Metric）

- 一种**无需训练、事后计算**的分散度度量，用于反映模型在探索阶段输出的稳定性/分歧程度。
- 定义：给定 \(N\) 个候选答案 \(\{y_n\}\)，用 Sentence-BERT（RoBERTa 主干）嵌入为 1024 维向量，计算质心 \(\bar{z} = \frac{1}{N}\sum \phi(y_n)\)，则
  \[
  D_{\text{sampling}} = \frac{1}{N}\sum_{n=1}^N \|\phi(y_n) - \bar{z}\|_2^2
  \]
- 该质心式度量对“多数派错误聚类 + 少数派分散正确”的情形具有鲁棒性。
- 论文将离散度作为**任务相对难度的代理**，并用于分析“何时调和最有效”（Result 3）。

### 2.4 计算预算定义

- 论文用 **API 调用次数**（而非 token 数）作为计算预算的度量，因为调用次数是系统层面可控的参数，便于进行计算量匹配的比较。
- 单轮 DCR 基线：探索 25 次 + 调和 25 次 = 50 次调用；递归 DCR 总调用数可变（约 33~80 次）。

## 6. 主要结论与发现

### Result 1：单轮 DCR 能放大正确少数派报告

- 在几乎所有数据集和模型上，单轮 DCR（\(K=25\)）同时提升 Trial accuracy 和 Consistency。
- 典型例子：
  - AIME 2024 + GPT-OSS：Trial accuracy 从 74.3% 提升至 88.1%，Consistency 从 76.7% 提升至 90.0%。
  - 弱模型提升更显著：Llama-4 在 MATH500 上从 36.4% 提升至 73.7%。
- 关键发现：当正确探索答案处于少数时（多数投票会失败），调和仍能可靠恢复正确答案，说明 DCR 是一个**选择算子**，能提高解池的信噪比。
- 同时发现一个失败模式：混合池中弱模型的错误提案可能“污染”强模型的判断，说明混合策略更适合“提升弱模型”而非“稀释强专家”。

### Result 2：递归 DCR 实现“更准且更省”的注意力式计算分配

- 在 AIME 2024 上达到 93.3%，AIME 2025 上达到 92.0% 的 Trial accuracy，均优于单轮 DCR（88.1%、87.2%）。
- 平均调用数从 50 次降至约 36 次，**节省约 27% 计算量**。
- 机制：一致同意停止规则在简单问题上快速收敛（约 33 次调用），在困难问题上自动升级（最多 80 次调用）——即**计算分配因题而异，而非均匀扩展**。
- 实验表明**深度（多轮顺序调和）比宽度（更多 reviewer）更有效**：深度允许模型利用前期分歧进行“反思式调试”（reflective debugging），打破单轮无法解决的僵局。
- 与 ReConcile 对比：仅 40.0%（AIME 2024）和 53.3%（AIME 2025），远低于 DCR，说明显式的“评审者-作者”角色区分优于“同行辩论”式聚合。

### Result 3：离散度可作为相对难度的代理，识别测试时计算的“甜区”

- 顶层图显示：基线准确率随离散度增加单调下降，说明离散度是无需校准的难度信号。
-

- **调和收益的非单调性**：DCR 相对基线的性能增益并非随难度单调增长，而是在中等离散度区间达到峰值——过于简单的问题本就能答对、收益有限；极度困难的问题即使追加计算也难以突破；**“甜区”位于难度适中、存在分歧但仍具有可恢复信号的问题集合上**。
- **实践意义**：离散度可作为一个免训练、按需计算的信号，帮助部署者在推理前预判“这道题要不要分配更多测试时计算”，从而自适应地控制计算调度（例如仅在离散度超过阈值时启用递归 DCR）。

## 7. 局限性与潜在缺陷

- **基准范围有限**：所有实验均集中于数学/知识型推理（MATH500、AIME、MMLU-PRO），未涉及代码生成、开放域问答、多步工具调用等更广泛的智能体任务，其推广性有待验证。
- **token 级成本不透明**：论文以 API 调用次数作为计算预算代理，但未报告 token 级消耗。不同方法的提案长度、reviewer 生成长度差异可能导致实际成本偏离名义调用数对照。
- **对提示模板的敏感性未消融**：reviewer 指令中“识别共识/分歧、考虑少数派修正”的关键提示词是否最优、对各模型是否敏感，论文未做系统性扰动实验。
- **Reviewer 自评偏差**：在单模型设置中，生成与评审为同一模型，可能存在自我强化偏差；虽然混合模型实验在一定程度上缓解了该问题，但未完全消除。
- **对 ReConcile 的对照公平性**：ReConcile 为复现实现，可能与其原始调优设置存在偏差；且未与更多近期强基线（如 Best-of-N 带 LLM 排序、Self-Refine、多轮自一致性等）进行统一对比。
- **失败模式未充分刻画**：论文指出混合提案池中弱模型噪声可能污染强模型判断，但未对该现象做深度失效分析或提出明确缓解策略。

## 8. 未来研究方向

- 将 DCR 迁移到非数学领域（编程、法律、医学诊断、多智能体协作）验证“分歧信号”的普适性。
- 引入动态 reviewer 宽度和预算分配策略，将离散度度量纳入在线计算调度器。
- 探索“作者-评审者”角色解耦的模型组合：用弱模型探索、强模型调和，或将调和职责交给专门训练的验证模型。
- 对分歧类型做更细粒度的结构化分类（如数值错误、误读题意、遗漏约束），以指导 reviewer 的定向纠错。
- 将 DCR 与强化学习/过程奖励模型结合，利用调和结果生成更高质量的训练数据。

本文的核心贡献在于**在概念层面推翻“分歧=噪声”的默认假设**，并给出了一个简洁、无需训练、即插即用的两阶段推理框架（DCR）。它用充分的实验证据表明：分歧不仅是可解释的难度信号，还是可被计算的资源；递归版本的动态收敛机制实现了“按需分配算力”，兼顾性能与成本。虽然在基准覆盖、成本度量和基线对照上存在局限，但其核心洞见（选择比生成容易、少数派报告具有信息价值、深度递归优于宽度堆叠）对后续测试时计算研究具有启发性，是探索 LLM 推理新范式中值得参考的工作。
