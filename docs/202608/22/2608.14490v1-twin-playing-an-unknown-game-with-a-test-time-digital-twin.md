## 摘要
我们提出了一种测试时世界模型推理（Twin）系统，在该系统中，一个前沿编码智能体编写一个可执行的世界模型，用于完成持续学习任务，如ARC-AGI-3游戏。传统方法为每个任务手工设计定制模型。每个游戏隐藏其规则和目标，而我们的系统仅通过模拟和交互来构建这些规则和目标。其对网格游戏的归纳先验足够强大，能够在几乎所有关卡中恢复游戏的真实转换和目标。回放验证在孪生世界模型中进行。测试框架强制执行：在程序重现每个先前观察到的游戏转换之前，不得执行任何动作。世界模型预测与实际动作结果之间的每一次不匹配都会成为一个反例，用于修复世界模型。Twin在183个关卡中通过了179个（97.8%），并且在179个关卡中的158个（88.3%）中比人类更高效。该系统在它通过的156个关卡（87.2%）中，在获得任何奖励之前就推断出了目标，并在其余关卡中通过搜索自动发现目标。基准测试根据人类首次游玩每个游戏的表现，对完成度和动作效率进行评分，范围在0到100之间。直接游玩时，基础模型得分仅为7.8%；现成的测试框架将其提高到61.1%，而我们的孪生世界模型将相同的基础模型提高到93.3%，通过了25个游戏中的23个。构建可用的世界模型比预期的要简单，而更难的问题是推断正确的目标。

## Abstract
We present a Test-time World-model Inference (Twin) system, in which a frontier coding agent writes an executable world model for completing continual learning tasks, such as ARC-AGI-3 games. Traditional approaches hand-engineer such models, one custom design per task. Each game hides its rules and goal, and our system constructs them from simulation and interaction alone. Its inductive prior over grid games is strong enough to recover the true transitions of the game and the goal on nearly all levels. Replay validation happens in a twin world model. The harness enforces that an action is not made until the program reproduces every previous observed game transition. Each mismatch between a world model prediction and the actual action result becomes a counterexample that is used to repair the world model. Twin clears 179 out of 183 levels (97.8%), and does so more efficiently than humans in 158 out of 179 levels (88.3%). The system infers the goal before any reward on 156 of the levels it clears (87.2%), and in the remaining levels automatically discovers the goal by search. The benchmark scores completion and action efficiency, between 0 and 100, against humans playing each game for the first time. Played directly, the base model scores only 7.8%; an off-the-shelf harness increases it to 61.1%, whereas our twin world model increases the same base model to 93.3%, clearing 23 out of 25 games. Building a usable world model is simpler than anticipated, whereas the harder problem is inferring the right goal.

### 2. 方法论：Twin 系统核心思想与流程

#### 核心思想
Twin 的核心是将未知环境视为 **可编写、可验证、可修复的程序**，而非不可解释的黑盒。智能体将自身的环境理论写为 Python 代码（`step(grid, action)` 和 `goal_reached(grid)`），并强制要求该代码能重放所有历史交互记录。

#### 关键技术细节与流程（对应 Algorithm 1 与图 1）
1. **问题定义**：环境为确定性 MDP，状态为 64×64 颜色网格；动作集为 4~6 个按钮和点击坐标。智能体只能观察到当前帧和动作结果，不知晓底层规则。
2. **三个 Harness 例程**：
   - **Validate（验证）**：重放整个交互日志 D，检查孪生模型预测的下一帧是否与真实观测单元格级一致（公式 1：∀(s,a,s′)∈D, T̂(s,a)=s′）。若存在不匹配，则生成反例。
   - **Explore（探索）**：根据"当前障碍"分流——若验证失败（动态墙），将反例分组并按错误率、效果多样性、支持度排序，交由编码智能体修复；若验证通过但无规划路径（目标墙），则在孪生模型内部以更深预算（深度 14，30,000 节点）搜索可达状态，并基于 5 个视觉变化信号（颜色消失、颜色出现、局部剧变、全局剧变、新前沿）对候选目标状态排序。
   - **Plan（规划）**：在已验证的孪生模型内运行广度优先搜索（BFS），以 `goal_reached` 为停止条件，在固定预算（深度 8，20,000 节点）内寻找最短动作序列。
3. **ExecuteChecked（检查执行）**：将规划的动作序列逐个提交到真实引擎；每一步先预测下一帧，提交后与真实帧对比。若匹配，则继续；若不匹配，则将该转换作为反例加入日志，并立即停止，阻止后续计分动作直到模型修复。
4. **目标发现（Goal Discovery）**：在无任何奖励的情况下，将可达状态转为"假设目标"；通过两个过滤器确认：①必须对所有历史帧返回 false；②曾被精确到达但未通关的候选永久排除。测试结果的三个分支分别更新目标、拒绝候选或修复动态。

#### 公式化说明
- **拟合约束（硬性）**：$\phi_{fit}(D, \hat{T}) \iff \forall(s,a,s') \in D,\ \hat{T}(s,a) = s'$。此约束由系统强制执行，不满足则禁止任何计分动作。
- **可达性条件（软性）**：$\phi^H_{reach}(s, \hat{T}, \hat{R})$，存在长度≤H的动作序列使 `goal_reached` 为真。只需一条想象路径即可解锁规划。

### 3. 实验设计与 Benchmark

#### 数据集与场景

- **运行方式**：每游戏从头开始（初始化为恒等孪生模型、空日志、新智能体上下文）；智能体通过文件接口观测整数网格、执行动作，无任何游戏特定工具或特权信息。

#### 对比方法
- **Twin（本文）**：GPT-5.6 Sol 作为基础模型，Codex CLI 驱动。
- **OPINE-World**：双智能体协调，Bayesian 本体错误驱动探索（Claude Opus 4.8）。
- **Prime Agent**：可编程 harness，递归语言模型（GPT-5.6 Sol）。
- **EWM**：单一编码智能体（GPT-5.5）。
- **Codex（无 harness 消融）**：与 Twin 相同的智能体和基础模型，但禁用 Twin harness。

#### 评估指标
- 每关效率因子：$e_\ell = \min\{1.15, (h_\ell / a_\ell)^2\}$（h 为人类动作数，a 为智能体动作数），未通关关卡为 0；按关卡长度加权并封顶后换算为百分制总分（0~100）。

#### 主要实验
1. **主实验**：所有 25 个游戏完整运行对比。
2. **消融实验**：禁用 Twin harness（保留相同智能体）。

### 6. 主要结论与发现

1. **Twin 在 ARC-AGI-3 上大幅领先**：得分 93.3/100，通关 23/25 个游戏（179/183 关），优于 OPINE-World（78.4）、Prime Agent（78.3）、EWM（63.8）、纯 Codex（61.1）和基础模型直接游玩（7.8）。
2. **世界模型比预期简单，目标推断才是真正瓶颈**：系统在 87.2% 的已完成关卡（156/179）中，在获得任何环境奖励前就提出了正确的目标假设；余下靠搜索发现。目标精度很低（0.214 精确率），说明目标推断是当前最大短板。
3. **重放验证是硬约束的关键价值**：系统将"模型必须复现整个交互历史"作为计分动作的前置条件，有效防止错误累积。消融实验表明，去掉此约束得分降低 32.2 个百分点。
4. **规划显著提高了动作效率**：Twin 在 13 个共同完全通关的游戏上使用 3,357 个动作，远低于 OPINE-World（5,367）、EWM（5,381）和人类（7,485）；平均动作数为人类基线的 0.61 倍。92.9% 的计分动作执行的是已在孪生模型中验证过的路径。
5. **世界模型具备泛化能力**：孪生模型对 70.1% 的先前未见状态-动作对能精确预测完整下一帧（79.0% 在线精度），显示其学到了可复用规则而非简单记忆。

### 7. 优点

1. **新颖且清晰的范式**：将"测试时编码世界模型"抽象为可验证、可修复的程序，使智能体从"黑盒反应"变为"白盒推理、规划与行动"，概念简洁有力。
2. **异步目标不对称处理**：明确区分动态（可验证、需全称拟合）与目标（只搜索、需存在路径），符合强化学习中的 optimism 原则，理念上有深度。
3. **硬性约束带来的工程有效性**：由 harness 强制执行的"无验证不得动作"原则，从机制上保证了学习闭环不会过早脱离现实。
4. **详尽的实验与多维度剖析**：不仅报告得分，还通过泛化测试、规划质量竞赛、目标声称日志、计算成本等多个角度解释系统的工作原理和瓶颈。
5. **零人工先验**：系统使用通用网格游戏归纳先验，不含任何游戏特定规则，泛化潜力大。
6. **可复现性与透明性**：提供了完整代码仓库和逐动作回放网站，并进行了完整性审计，保证了可复现性和结果的公信力。

### 8. 不足与局限

1. **确定性假设**：系统假设环境为确定性的、可程序压缩的状态转换；无法处理连续状态、概率性转换或需长时间隐藏状态（如内存）的任务。
2. **部分可观测性局限**：虽然 bp35 展示了处理"相机遮挡"的能力（通过逐地购买信息），但对于真正隐藏的状态变量（帧上从未展示的变量）不在处理范围内。
3. **目标推断能力较差**：目标谓词的精确率仅 0.214，false claim 遍布关卡任意位置；这导致大量无效动作和失败的可能。在 sp80、sc25、tn36 等目标复杂的关卡上，系统表现显著下降。
4. **计算成本高昂**：平均每动作需 224k tokens 的测试时计算，是消融版（48k）的约 4.7 倍；对实际部署构成一定障碍。
5. **搜索预算限制**：规划深度（8）与节点预算（20k）固定，无法找到超出此范围的目标；调高预算（如从起点开始）会迅速耗尽计算资源。
6. **通用性验证不足**：仅验证于网格类游戏（尽管 ARC-AGI-3 具有代表性），对于更广泛的控制任务或文本环境未进行实验。
7. **实验结果稳定性风险**：系统依赖 LLM 生成与修复代码；虽然通过验证与修复循环管理，但最终代码质量和推理链仍存在随机性，最优解不一定可达。
8. **跨方法比较公平性存疑**：各对比系统使用不同基础模型和计算预算，论文虽尽力控制但未完全消除这一变量。
