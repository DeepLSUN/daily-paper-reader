## 摘要
在策略蒸馏（OPD）使用学生语言模型从其当前策略采样的轨迹进行监督，但对具有不同监督价值的响应标记赋予相同的权重。选择性OPD通过根据估计的训练价值对响应标记进行非均匀分配监督来解决这一局限性。然而，现有的大多数准则主要关注优化需求，如不确定性或师生分歧，而任务相关性（即监督是否与当前输入的语义内容相关）作为补充维度仍未被直接刻画。为弥补这一空白，我们引入用于在策略蒸馏的反事实相关性（CROP），通过释义校准的反事实敏感性边际来操作化任务相关性。对于每个源提示，CROP构建一个经过验证的原始-释义-反事实三元组，保持学生策略生成结果固定，并通过每个响应位置对任务相关条件变化的敏感性（以对保持意义改写（即释义）的敏感性进行校准）来度量其重要性。匹配的选择控制实验表明，与随机或最低相关性选择相比，CROP能识别更有用的监督位置，而组件比较确认了反事实敏感性和释义校准两者的价值。在两种师生设置下，与最强的非CROP选择器相比，CROP将整体性能分别提升了1.92和2.96个百分点。这些结果支持任务相关性作为选择性OPD的补充准则，并确立CROP作为一种模型内部、对比特定方法来分配标记级监督。

## Abstract
On-policy distillation (OPD) supervises a student language model on trajectories sampled from its current policy, but assigns equal credit to response tokens with unequal supervision value. Selective OPD addresses this limitation by allocating supervision non-uniformly across response tokens according to their estimated training value. Most existing criteria, however, focus primarily on optimization need, such as uncertainty or teacher-student disagreement, while task relevance, namely whether the supervision is tied to the semantic content of the current input, remains less directly characterized as a complementary dimension. To address this gap, we introduce Counterfactual Relevance for On-Policy Distillation (CROP), which operationalizes task relevance through a paraphrase-calibrated counterfactual sensitivity margin. For each source prompt, CROP constructs a validated original-paraphrase-counterfactual triplet, holds the student rollout fixed, and measures each response position by its sensitivity to a task-relevant condition change calibrated by its sensitivity to a meaning-preserving rewrite. Matched selection controls show that CROP identifies more useful supervision positions than random or lowest-relevance selection, while component comparisons confirm the value of both counterfactual sensitivity and paraphrase calibration. Across two teacher-student settings, CROP improves aggregate performance by 1.92 and 2.96 points over the strongest non-CROP selector. These results support task relevance as a complementary criterion for selective OPD and establish CROP as a model-internal, contrast-specific method for allocating token-level supervision.

## 1. 核心问题与研究动机

- **背景**：在语言模型后训练中，通常结合监督微调（SFT）与强化学习（RL）。在策略蒸馏（OPD）将二者优势结合，通过教师模型在学生当前策略访问的前缀上提供稠密的 token 级分布监督，以缓解分布偏移问题。
- **现有缺陷**：标准 OPD 对所有响应 token 赋予均等监督权重，未区分不同 token 的训练价值。已有选择性 OPD 方法（如基于不确定性、师生分歧、可教性、轨迹位置等）虽实现了非均匀监督，但大多集中于估计 token 的**优化需求**（是否需要修正、是否容易改进），而对**任务相关性**——即该 token 的学习信号是否真正与当前输入的语义内容绑定——刻画不足。
- **核心问题**：一个 token 即使不确定、与教师分歧大或可修正，仍可能只是输入通⽤的响应模式。如何补充性地度量 token 与当前任务语义的关联，并将其纳入选择性 OPD 的监督分配？

## 2. 方法论：CROP（Counterfactual Relevance for On-Policy Distillation）

### 2.1 核心思想

CROP 通过构造并验证“原始提示–释义提示–反事实提示”三元组，将学生模型的 rollout 固定，在每个 token 位置上比较三种提示下学生模型下一 token 分布的变化。以**释义敏感性**（对意义保持改写的不变性的衡量）来校准**反事实敏感性**（对任务相关条件变化的响应强度），二者的差值即作为任务相关性的代理分数。

### 2.2 三元组构造与验证

- 离线阶段，对每个源提示，使用大模型生成候选的释义（保持数学含义与任务目标）和反事实（恰好改变一个明确的、实质性的数学条件，且不引入额外假设），再由独立批评模型校验语义保持、单条件干预、确定性和答案类型一致等标准。
- 构造统计：17,398 个源提示中有 16,594 个通过校验（95.38%），构成训练子集。

### 2.3 匹配的重打分与分数计算

- 固定学生应答 \(y\) 及其前缀 \(y_{\lt t}\)，在原始提示 \(x\)、释义 \(x_{\text{para}}\)、反事实 \(x_{\text{cf}}^t\) 三种条件下分别重打分，得到三个学生分布 \(P_t^o, P_t^p, P_t^c\)。
- 计算 top-K（K=64）带残差桶的 Jensen–Shannon 散度（JSD）：
  - 语义敏感性（counterfactual sensitivity）：\(d_t^{\text{sem}} = \text{JSD}_K(P_t^o, P_t^c)\)
  - 表面/释义敏感性（paraphrase sensitivity）：\(d_t^{\text{surf}} = \text{JSD}_K(P_t^o, P_t^p)\)
  - CROP 分数：\(s_t^{\text{CROP}} = d_t^{\text{sem}} - d_t^{\text{surf}}\)
- 该分数仅由学生模型内部计算，是一种模型内部、对比特定（contrast-specific）的排序启发式，不声称是因果效应或正确性的度量。

### 2.4 批量全局预算选择

- 在完成一批 rollout 后，对所有有效响应位置按 CROP 分数全局排序，保留前 \(\rho\)（默认 10%）作为最高优先级。
- 同时设置每个样本最少保留 1 个 token 的保障，得到最终的二进制 token 掩码。
- 掩码只影响哪些 token 进入既有 OPD 损失；教师目标、学生 rollout 分布、基础 OPD 更新均保持不变。
- 可选变体 CROP-ent：将学生熵（经 batch 内 5–95 分位归一化）与归一化 CROP 分数通过 Soft-OR 融合，用于检验不确定性度量与任务相关性是否互补。

## 6. 主要结论与发现

- 在两个师生设置中，CROP（或其变体 CROP-ent）均优于纯 OPD 和所有非 CROP 选择性基线：较最强非 CROP 选择器的平均分分别提升 **1.92 点**（Qwen3-4B→1.7B）和 **2.96 点**（Qwen3-8B→4B）。
- 最高 CROP 分数的 token 选择优于随机选择 2.00 点、优于最低分选择 3.34 点，说明 CROP 的排序确实有信息量。
- 反事实敏感性是主要信号来源；释义校准（区分语义变化与表面改写）是必要且有益的组成部分。
- CROP 在稀疏到中等监督预算（10%–20%）下最强，且并非通过单纯扩大覆盖范围获得；最佳预算因方法而异，说明不存在普遍最优的监督密度。
- CROP 并非熵的不确定性代理：它显著选择了低熵尾部 token，而熵类方法几乎将其完全排除。

## 7. 优点与亮点

- **概念清晰**：明确区分“优化需要”与“任务相关性”两个互补维度，为选择性 OPD 补充了语义层面的判据。
- **方法设计精细**：使用释义作为匹配对照，将表面改写效应与语义改变效应分离，提高了对比干预的有效性；固定 rollout 前提下做重打分，避免轨迹差异干扰。
- **干预验证严谨**：独立批评模型对三元组做语义保持、单条件变化、确定性与答案类型校验，并通过人工确认示例和统计表展示验证质量。
- **评价体系较完整**：包含主结果、预算敏感性、选择器排序质量检验、变体消融、定性分析和数据污染审计，证据链比较完整。
- **计算开销可控且兼容性好**：只改变 token 掩码，教师目标与 OPD 更新接口不变，可直接适配现有 OPD 训练流程。

## 8. 不足与局限

- **领域覆盖有限**：实验仅限于数学类提示（DAPO-Math）与 Qwen 模型家族，未在代码、开放域问答、通用指令等领域验证普适性。
- **三元组生成依赖自动管线**：虽然经过了批评模型校验，但生成与校验均依赖大模型，无法保证在全部属性（如问题难度、语义边界）上完全可控。
- **分数是启发式而非因果估计**：作者明确承认 CROP 分数是模型内部、对比特定的排序信号，不是因果效应或语义相关性的无偏度量，高分数也可能来自对残余提示差异的过度反应。

- **训练时长与复现成本信息不足**：未提供端到端训练时间、GPU-hours 或与前人的计算资源对比，复现难度较大，实际应用成本也难以估计。
