## 摘要
大语言模型（LLMs）越来越多地支持基于用户提供的异构结构知识进行响应生成。然而，现有基准测试对LLMs能否在这些知识背景下忠实地执行多跳推理链，并保持对输入顺序变化的鲁棒性，提供的评估有限。我们引入TKFQA，一个事实一致性基准，包含10,130个基于表格、文本和知识图谱（KGs）的问答（QA）对。每个示例由一条明确的反事实推理链构建，从而能够联合评估答案正确性、推理链准确性和对不同输入顺序的鲁棒性。对14个开源和闭源LLMs的广泛评估表明，最先进的模型在推理链准确性方面表现有限，并且对异构知识上下文输入顺序的变化仍然敏感。为解决这些局限性，我们提出ORLF，一种与LLM无关的训练框架，通过知识特定的潜在向量对跨上下文拓扑关系进行建模。ORLF整合了上下文位置编码、潜在桥梁注意力掩码和拓扑知识偏差，以保留知识特定偏差并编码拓扑语义。在四个LLM骨干网络上的实验表明，ORLF优于竞争性的免训练和基于LoRA的基线，平均精确匹配和推理链准确性分别提高了2.15%和4.29%，同时将顺序引起的性能标准差降低了0.04%至3.01%。

## Abstract
Large language models (LLMs) have increasingly supported response generation grounded in user-provided knowledge spanning heterogeneous structures. However, existing benchmarks provide limited assessment of whether LLMs can faithfully perform multi-hop reasoning chains across such knowledge contexts while remaining robust to variations in their input order. We introduce TKFQA, a factuality consistency benchmark comprising 10,130 question-answering (QA) pairs grounded in tables, texts, and knowledge graphs (KGs). Each example is constructed from an explicit counterfactual reasoning chain, enabling the joint evaluation of answer correctness, reasoning-chain accuracy, and robustness to different input-order. An extensive evaluation of 14 open- and closed-source LLMs reveals that state-of-the-art models exhibit limited reasoning-chain accuracy and remain sensitive to variations in the input order of heterogeneous knowledge contexts. To address these limitations, we propose ORLF, an LLM-agnostic training framework that models cross-context topological relations through knowledge-specific latent vectors. ORLF integrates context-wise position encoding, a latent-bridge attention mask, and topological knowledge bias to preserve knowledge-specific bias and encode topological semantics. Experiments across four LLM backbones show that ORLF outperforms competitive training-free and LoRA-based baselines, improving average Exact Match and Reasoning-Chain Accuracy by 2.15% and 4.29%, respectively, while reducing order-induced performance standard deviation by 0.04% to 3.01%.

## 一、核心问题与研究动机

- **研究背景**：大语言模型（LLMs）越来越多地被用于基于用户提供的异构知识上下文（表格、文本、知识图谱）进行接地响应生成。此类任务要求模型在多样化的知识结构上进行多跳推理，并严格遵守所提供的信息。
- **核心痛点**：
  - 现有基准（如 RAGTruth、FACTS、HaluEval、FActScore）大多只评估**单一知识结构**下的输出级事实性，未对**跨异构结构的推理链正确性**进行显式评估。
  - 已有工作忽略了**事实一致性**——即生成响应是否真正忠实于输入知识，而非依赖模型内部参数化知识。
  - LLMs 对输入知识上下文的**排列顺序敏感**，即同一内容的不同顺序会导致性能波动，现有基准未系统评估这一维度。
- **整体含义**：需要一个新的基准，能够联合评估答案正确性、推理链正确性以及输入顺序鲁棒性，同时需要一种训练方法，在异构知识上下文中增强模型的多跳接地推理能力、保持事实一致性并削弱顺序敏感性。

## 二、方法论

### 2.1 TKFQA 基准构建
- **数据来源**：Wikipedia 表格、与表格关联的文本段落，以及 Wikidata 知识图谱的子图。
- **对比事实（Counterfactual）上下文生成**：通过在表格、文本、KG 三个结构上进行**实体替换**，构造反事实推理链：
  1. **表格实体替换**：在目标行中，将同一语义类别（如国家、城市）的实体替换为另一实体（如“London”→“Paris”），得到反事实表格 $\tilde{T}$。
  2. **文本实体替换**：基于表格替换实体 $e_{ta}$，在网页正文中替换同类别实体（如“United Kingdom”→“USA”），得到反事实文本 $\tilde{P}$。
  3. **KG 实体替换**：从反事实文本中提取实体 $e_{te}$，在其一跳邻居中随机替换同类别实体，得到反事实 KG $\tilde{G}$。
  - 最终形成跨结构推理链：$\tilde{C} = \langle \tilde{T}, \tilde{P}, \tilde{G}\rangle(e_o, e_{ta}, e_{te}, e_{kg})$，其中替换实体连接三种知识结构。
- **问答对生成**：使用三个 LLM 独立生成候选问题，支持**双向推理方向**（Table→Text→KG 和 KG→Text→Table），以增强数据多样性。
- **自动验证与人工审查**：从链一致性、实体对齐、最终答案验证三个角度进行质量把关。
- **数据规模**：10,130 对 QA，由 5,065 条反事实推理链产生，划分为训练（8,106）、验证（1,012）、测试（1,012）。

### 2.2 ORLF 训练框架
- **核心思想**：通过**知识特定的可训练潜在向量**（latent vectors）对不同知识上下文中的拓扑关系进行建模，从而维持事实一致性并降低输入顺序敏感性。整体流程为：输入嵌入 → 潜在向量拼接 → 上下文位置编码 → LLM 层注意力增强 → 自回归解码。
- **三大关键组件**：
  1. **上下文位置编码（Context-wise Position Encoding, CPE）**：在每个知识上下文的内部独立重置并分配位置索引，避免因跨上下文顺序变化导致位置编码向量整体偏移。
     - 位置分配：$pos(x_{c\omega}) = [0, \dots, L_c-1]$，$pos(z_c) = [L_c, \dots, L_c+m-1]$，即每个上下文的 token 及其对应的 latent token 拥有独立的位置编码范围。
  2. **潜在桥接注意力掩码（Latent-Bridge Attention Mask, LBAM）**：让潜在向量能够**跨上下文**参加（attend）到不同知识片段，而原始上下文 token 仍只能关注本类型内的 token，从而在受控的方式下实现跨结构信息交换，避免不同知识上下文之间的直接干扰。
     - 掩码规则：$M_{ij} = 0$（$i,j \in X_c$）、$M_{ij} = 0$（$i \in Z_c, j \in X_c \cup Z$）、$M_{ij} = 0$（$i \in Q \cup Y, j \le i$），其余位置为 $-\infty$。
  3. **拓扑知识偏置（Topological Knowledge Bias, TKB）**：通过三种视角捕捉知识上下文之间的拓扑语义，并将其注入注意力分数中：
     - **跨知识路径距离（IKPD）**：基于跳数（Dhops）用可学习查找表编码知识间最短路径距离。
     - **跨知识方向（IKD）**：用指示函数编码知识间方向依赖关系（如 Table→Text→KG）。
     - **谱几何（SG）**：采用磁拉普拉斯核函数将知识拓扑的谱几何关系编码为置换不变表示。
  - 偏置公式：$b^{(l,h)}_{u,v} = b^{(l,h)}_{IKPD}(u,v) + b^{(l,h)}_{IKD}(u,v) + b^{(l,h)}_{SG}(u,v)$，最终注意力分数为 $A^{(l,h)}_{ij} = \frac{\text{RoPE}(Q_i, pos(i)) \cdot \text{RoPE}(K_j, pos(j))^\top}{\sqrt{d_h}} + M_{ij} + b^{(l,h)}_{ij}$。
- **训练目标**：最小化标准语言建模的累积对数似然损失（CE loss），使用 LoRA 微调骨干模型。

## 三、实验设计

- **评估基准**：TKFQA 测试集（1,012 对 QA），每对 QA 关联表格、文本、KG 三种异构知识上下文。
- **评估指标**：
  - **EM（Exact Match）**：答案正确率（报告 Avg/Best/Worst）。
  - **RCA（Reasoning-Chain Accuracy）**：推理链实体级一致性（报告 Avg/Best/Worst）。
  - **O. Std.（Order Standard Deviation）**：6 种上下文输入顺序（T-P-G、T-G-P、P-T-G、P-G-T、G-P-T、G-T-P）下 EM/RCA 的标准差，反映顺序鲁棒性。

  - **ORLF 微调实验（RQ2）**：4 个骨干模型（Qwen3-8B、GLM-4-9B-Chat、Llama-3.1-8B-Instruct、Mistral-7B-Instruct-v0.3）。

- **消融实验（RQ3）**：逐项移除 CPE、LBAM、TKB，观察整体性能与顺序鲁棒性的变化。

## 六、主要结论与发现

- **SOTA LLM 在 TKFQA 上表现有限**：
  - 最佳模型（DeepSeek-V4-Flash）Avg. EM 也仅 85.18%，Avg. RCA 仅 65.14%；GPT-5 的 Avg. EM/RCA 分别为 76.80%/52.52%。

- **ORLF 的有效性**：
  - 在四个 LLM 骨干上，ORLF 相比最强基线平均提升 **Avg. EM 2.15%**、**Avg. RCA 4.29%**。

  - 潜在向量长度 m=16 为性能与稳定性最佳设置。

## 七、论文的优点

- **基准设计创新**：
  - 反事实实体替换链的设计巧妙，能有效迫使模型依赖外部输入而非内部参数知识——“反事实”本身就是排除参数记忆的天然过滤器。
  - 同时提供答案、推理链、顺序鲁棒性三重标注/评估，形成对接地推理更全面的诊断维度。
- **框架设计合理**：
  - ORLF 与模型架构无关（LLM-agnostic），可迁移到任意基于注意力的 Decoder-only 模型。
  - 三组件设计动机清晰：CPE 解决位置编码偏移、LBAM 解决交叉注意力受限、TKB 解决拓扑关系建模，分工明确、互补性强。
  - 保留因果注意力以兼容现有自回归推理流程，同时通过潜在桥接token实现跨上下文信息交换，不破坏原有生成结构。
- **实验严谨**：
  - 6 种顺序全排列逐一报告，不是抽样报告；
  - 消融实验覆盖 4 个骨干，非单一模型；
  - 所有结果取 3 次随机种子平均，降低偶然性；
  - 对 SOTA LLM 的问题案例进行了细粒度分析（如 DeepSeek-V4-Flash 推理链错但答案对）。

## 八、不足与局限

- **基准覆盖面有限**：
  - 仅使用英文 Wikipedia 表格、文本与 Wikidata KG，语言、领域、知识源多样性不足，通用性待验证。
  - 不支持多模态知识上下文的评估。
- **框架可应用性受限**：
  - ORLF 需要访问模型的内部注意力机制和位置编码，**无法直接应用于仅提供 API 的闭源模型**（如 GPT-5、Gemini、Claude）。
  - 训练开销和计算资源需求未详细披露，不利于复现和成本评估。
- **评估方式局限**：
  - RCA 采用 prompt 触发式推理链提取，可能与模型内部真实推理不一致；且 RCA 的自动对比（严格实体级匹配）可能过于苛刻，忽略了语义等价但措辞不同的合法推理。
  - 闭源模型的结果受限于 API 的 token 生成策略，无法完全对齐开源模型的采样配置。
- **与基线比较的公平性**：
