## 摘要
长上下文训练对于大型语言模型日益重要，线性注意力与状态空间模型因提升长上下文效率而受到广泛采用。然而，针对循环模型和混合模型的高效长序列并行训练仍具挑战性。我们提出StateFlow，一种面向线性循环模型的序列流水线并行系统。StateFlow将每个序列划分为多个块，并在传播跨块边界状态与梯度的同时调度其执行，从而缩短激活生存期并提高训练吞吐量。StateFlow进一步利用基于剖析的非均匀分块来平衡混合模型中的循环计算与softmax注意力计算，并将并行度有限的边界状态转移与周围计算重叠。将StateFlow应用于参数量高达320亿、上下文长度达256K的模型时，相较于传统流水线并行，我们实现了高达2.22倍的吞吐量提升和2.45倍的内存缩减，从而支持了原本不可行的配置。

## Abstract
Long-context training is increasingly important for large language models, and linear attention and state space models have become popular for improving long-context efficiency. However, efficiently parallelizing long-sequence training for recurrent and hybrid models remains challenging.   We present StateFlow, a sequence pipeline parallelism system for models with linear recurrence. StateFlow partitions each sequence into chunks and schedules their execution while propagating boundary states and gradients across chunks, thereby reducing activation lifetimes and improving training throughput. StateFlow further uses profile-guided nonuniform chunking to balance recurrence and softmax attention computation in hybrid models, and overlaps state transitions that expose limited parallelism with surrounding computation. Applying StateFlow to models with up to 32B parameters and 256K context length, we achieve up to \(2.22\times\) throughput improvements and \(2.45\times\) memory reduction compared to conventional pipeline parallelism, enabling otherwise infeasible configurations.

## 2. 论文提出的方法论

### 2.1 核心思想

将每个完整序列（microbatch）进一步切分为多个序列块（chunk），以块为单位进行流水线调度。与常规 PP 以整序列为调度单元不同，StateFlow 在块级别传播前向边界状态和反向状态梯度，从而缩短激活的保留时间，降低峰值显存，并减少流水线气泡。

### 2.2 关键技术细节

- **状态感知的分块调度**（State-Aware Chunk Scheduling）
  - 将序列 `X = C0 ∥ C1 ∥ ... ∥ C_{N-1}` 切分为 N 个块。
  - 前向：`Fwd(C_i, S_in_i) -> (C_out_i, S_out_i)`，初始状态 `S_in_0 = S_init`，且 `S_out_i` 作为 `S_in_{i+1}` 的输入。
  - 反向：`Bwd(C_i, S_in_i, C_bar_out_i, S_bar_out_i) -> (C_bar_in_i, S_bar_in_i)`，状态梯度以逆序传播。
  - 定义了合法调度必须满足的偏序约束（公式 8），包括层间依赖、相邻块依赖和前反向依赖。调度器可在此基础上选择不同的发射策略（如 1F1B 风格）。
  - 块数 N 视为可调参数，从 {2, 4, 6, 8, 16, 32} 中根据显存约束选出最高吞吐的取值。

- **混合感知的非均匀分块**（Hybrid-Aware Nonuniform Chunking）
  - 在同时包含线性递归层和 softmax attention 层的混合模型中，后面的块 attention 计算量更大（因为 prefix 更长），等长分块会导致负载不均。
  - 建立了块计算代价模型：`Cost_i = (L_lin * C_lin + C_dense) * s_i + L_soft * C_soft * (c_i * s_i + s_i^2/2)`。
  - 基于 FLOP 平衡求解理论分块边界，并生成以 `α` 插值的分块候选：`c_i(α) = (1-α)*c_equal_i + α*c_hybrid_i`，α ∈ {0, 0.1, ..., 1.0, 1.25}，再结合实测 profile 挑选最快配置。

- **状态转换网格优化与计算重叠**（State Transition Optimization and Overlap）
  - 状态转换（ST）kernel 的并行度有限，SM 利用率低。StateFlow 通过调整值维度上的 tile 大小（B_V ∈ {8, 16, 32, 64}）来增大启动网格，改善 SM 覆盖。
  - 前向重叠：将块再拆分为两个片段，将第一片段的状态转换与第二片段的预处理重叠，第二片段的状态转换与第一片段的输出计算重叠，即 `Pre(1) → (ST(1) ∥ Pre(2)) → (ST(2) ∥ Out(1)) → Out(2)`。
  - 反向重叠：对 GDN 使用状态重放与输出梯度计算重叠；对 Mamba-3 将输出投影的激活梯度与权重梯度拆分，将权重梯度与反向状态计算重叠（`OutAG → (StateBwd ∥ OutWG)`）。

- **效率分析**
  - 显存近似：传统 1F1B 中每个设备保留 `min(M, P-r) * A_r`；StateFlow 降为 `min(MN, N+P-r-1) * (A_r/N + B_r)`，当 N 较大时显存约降为原来的 1/N 左右。
  - 吞吐近似：传统 1F1B 耗时约 `(M+P-1)*t`，StateFlow 约 `(M+(P-1)/N)*t`，气泡被 N 个块摊薄。

- **扩展到多维度混合并行**：块级状态传播可以天然与 DP、TP 交织，未来可在千卡级集群上设计全局调度器，同时优化跨节点通信量的最小化和气泡率的降低。

## 10. 总结

StateFlow 是专为线性递归与混合架构设计的高效序列流水线并行系统。它抓住线性递归仅依赖边界状态这一特性，以序列块为基本调度单元，配合非均匀分块、状态转换 kernel 重叠和显存敏感的参数选择，显著降低了长上下文训练的峰值显存和流水线气泡。实验在两种代表性架构、三种模型规模、多档上下文长度和两种训练框架上表现出一致而显著的收益，尤其使若干原本 OOM 的极端配置变为可训练。虽然其评估规模和自动化程度尚有提升空间，但整体方法论扎实、工程实现完整，为下一代长上下文线性递归模型的高效训练开辟了值得借鉴的系统方案。
