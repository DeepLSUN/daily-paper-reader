## 摘要
在线策略自蒸馏（OPSD）通过自蒸馏将特权上下文内化到模型参数中，从而提高大型语言模型的推理能力。近期的两条研究路线分别通过选择从哪些令牌（token）学习以及控制教师接收多少特权信息来改进原始OPSD。然而，我们表明每条路线在优化一个变量的同时固定另一个变量，这会导致次优解。我们认为这两个变量通过学生的学习能力耦合：特权信息决定了教师规定的每个令牌的散度，而令牌加权则选择学生必须吸收其中哪些。我们将这两条工作路线形式化为一个统一的优化框架，该框架在学生对总学习难度的预算约束下，最大化师生之间的总散度。在这种建模下，我们提出了统一在线策略自蒸馏（USD），一种用于求解拉格朗日函数的轻量级在线算法。USD揭示了单一对偶变量同时控制这两个决策：在一定的学习难度代价下，它同时设定令牌选择阈值和特权信息调整方向，使监督与不断发展的学生能力相匹配。通过大量实验，USD在各种推理基准和不同模型规模上持续展现出优于OPSD以及令牌侧和PI侧基线的性能。代码可在 https://github.com/lauvlalala/USD 获取。

## Abstract
On-policy self-distillation (OPSD) improves the reasoning abilities of LLMs by internalizing privileged context into model parameters through self-distillation.   Two recent research lines promote vanilla OPSD by choosing which tokens to learn from and by controlling how much privileged information the teacher receives, respectively.   However, we show that each line optimizes one variable while holding the other fixed, which leads to a suboptimal solution.   We argue that the two variables are coupled through the student's learning capacity: the privileged information sets the per-token divergence the teacher prescribes, while token weighting selects which of these the student must absorb.   We formalize the two lines of work into a unified optimization framework, which maximizes the aggregate teacher--student divergence, subject to a budget on the aggregate learning difficulty the student can absorb.   Under this modelling, we propose Unified On-Policy Self-Distillation (USD), a lightweight online algorithm to solve the Lagrangian.   USD reveals that a single dual variable governs both decisions: at one price for learning difficulty, it simultaneously sets the token-selection threshold and the direction of privileged-information adjustment, keeping supervision matched to the student's evolving capacity.   Through extensive experiments, USD consistently demonstrates superior performance over OPSD and token- and PI-side baselines across various model scales on various reasoning benchmarks. Code is available at https://github.com/lauvlalala/USD.

## 1. 核心问题与整体含义

- **研究背景**：On-policy self-distillation（OPSD）是一种无需外部强教师、无需人工构造推理轨迹、也无需交互式环境的 LLM 后训练范式。它在同一模型中同时扮演两个角色——学生从普通问题提示生成 rollout，特权教师（同一基础模型，但条件于特权信息 PI）逐 token 提供密集监督信号。
- **现有两条改进路线存在割裂**：
  - **Token 级选择**：如 TIP，根据熵、散度等信号对 token 重新加权或筛选，但默认教师使用完整 PI。
  - **PI 级控制**：如 PAINT，调整教师可见的特权信息量，但对所有 token 统一加权。
- **核心问题**：上述两条路线各自只优化一个变量、固定另一个变量，得到的是**条件最优解而非联合最优解**。论文的核心论点是：这两个变量通过**学生的学习能力（learning capacity）**耦合——PI 决定了每个 token 上教师规定的散度（潜在学习量），而 token 加权决定学生实际吸收哪些散度。

## 2. 方法论

### 2.1 统一优化框架

- **目标函数**：在给定学生 rollout $\hat{y}$ 和 PI 强度 $\beta \in [0,1]$ 下，定义带 per-token 权重 $w_t$ 的加权目标：
  $J(w, \beta) = \frac{1}{\sum_t w_t} \sum_{t=1}^{|\hat{y}|} w_t \cdot D_{KL}\left(p^T_\beta(\cdot|x,\hat{y}_{<t}) \| p_S(\cdot|x,\hat{y}_{<t})\right)$
- **两个核心量**：
  - **散度** $g_t(\beta)$：教师与学生分布间的 KL 散度，代表该 token 的潜在更新幅度。
  - **学习难度** $d_t(\beta) = \left[\log \frac{p^T_\beta(a^\star_t)}{p_S(a^\star_t)}\right]_+$：教师 top 预测高于学生当前信念的程度，代表吸收该修正所需付出的努力。

### 2.2 约束优化与 Lagrangian

- **形式化为约束优化问题**：在平均加权难度不超过容量预算 $\varepsilon$ 的约束下，最大化平均加权散度：
  $\max_{w, \beta} \frac{1}{N}\sum_t w_t g_t(\beta) \quad \text{s.t.} \quad \frac{1}{N}\sum_t w_t d_t(\beta) \leq \varepsilon$
- **Learnability Frontier**：随容量预算 $\varepsilon$ 变化的 Pareto 最优边界，描述每个能力水平下可获得的最大平均散度。
- **Lagrangian 分析**：
  - 每个 token 的净价值为 $v_t = g_t(\beta) - \lambda d_t(\beta)$，其中 $\lambda$ 是**单一对偶变量**，即学习难度的边际价格。
  - 最优权重理论上为硬阈值 $w^\star_t = \mathbb{1}[g_t(\beta) > \lambda d_t(\beta)]$。
  - PI 最优强度满足边际平衡条件：$\lambda = \frac{\sum_t \partial g_t/\partial \beta}{\sum_t \partial d_t/\partial \beta}$。
  - **关键洞察**：同一个 $\lambda$ 同时决定 token 选择阈值和 PI 调整方向，这是共享预算约束的结构性结果，而非人为设计。

### 2.3 USD 算法（Primal-Dual Online Algorithm）

- **可微软权重**：用 sigmoid 替代硬阈值，$w_t = \sigma((g_t - \lambda d_t)/\tau)$，熵正则化保证可微。
- **对偶上升（Dual Ascent）**：$\lambda \leftarrow \max(0, \lambda + \eta_\lambda (\text{load} - \varepsilon))$；当负载超预算时 $\lambda$ 上升、收紧 token 选择。
- **PI 残差更新（Primal Residual）**：$\beta \leftarrow \text{clip}(\beta + \eta_\beta (\varepsilon - \text{load}), \beta_{\min}, 1)$。
- **理论保障（Proposition 1）**：在 Assumption 1（负载和散度均随 $\beta$ 单调递增，已在真实训练 rollout 上验证）下，残差更新单调收敛到约束激活的最优 $\beta^\star$，且无需计算 $\beta$ 的梯度。
- **归一化训练损失**：$L_{\text{train}} = \frac{\sum_t w_t D_{KL}(p^T_\beta \| p_S)_t}{\sum_t w_t}$，避免 effective step size 漂移。
- **轻量级**：仅需单次 O(T) 的负载计算和两个标量更新，无需辅助网络或额外前向传播。

## 6. 主要结论与发现

- **USD 一致优于所有基线**：9 单元总体平均从 vanilla OPSD 的 56.4 提升至 58.7（+2.3 点），三个规模上各约提升 2 点；优于 TIP 和 PAINT 在每个规模上的表现。
- **两个轴具有互补性**：消融实验表明单独使用任一轴均有收益，但联合使用效果最好，且没有一个轴在所有规模上单独占优（1.7B 时 token 选择贡献更大，4B/8B 时 PI 适应贡献更大）。
- **单对偶变量的有效性**：训练动力学显示 $\lambda$ 和 $\beta$ 协同演化——负载低于预算时 $\beta$ 上升、$\lambda$ 保持零；负载触及预算后 $\lambda$ 激活并收紧选择、$\beta$ 相应回落，负载稳定在 $\varepsilon$ 附近。
- **容量预算 $\varepsilon$ 存在最优值**：在 $\varepsilon = 0.3$ 时性能最佳，过紧则欠拟合，过松则退化为近均匀加权。

## 7. 优点

- **统一的视角**：首次将 token 选择和 PI 控制纳入同一个优化框架，用单一容量预算解释两个看似独立的设计维度，理论优雅且具有解释力。
- **理论-实践结合紧密**：从 Lagrangian 推导出硬阈值规则，再通过熵正则化平滑为可微形式；残差更新有 Proposition 1 的收敛性保证，且单调性假设在真实数据上得到验证。
