## 摘要
大语言模型（LLM）智能体能够检索记忆、调用工具、提出澄清问题并变换响应风格，然而将这些执行决策适配到个体用户仍然困难。对专有系统而言，微调单独的LLM成本高昂或不可行，而提示与记忆主要将用户信息暴露给智能体，而非根据反馈调整其执行决策。我们将冻结智能体的个性化形式化为：仅根据所执行动作观测到的标量反馈，在线学习每个用户的执行策略。我们提出FABLE（用于执行的因子化自适应赌博机层），这是一个位于潜在黑盒宿主智能体外部的轻量级策略层。FABLE将记忆、信息获取和响应决策因子化，使反馈更新相关的选择；在探索前通过外部指定的可行集过滤动作；并基于固定的默认-成本评分，通过贝叶斯上下文汤普森采样学习用户特定的残差偏好。在线性残差奖励模型下，校准变体继承了针对最优可行动作的期望遗憾界。我们还刻画了在持续可行性约束下不可识别的偏好，并提供随时有效的虚假提升控制。在个性化推理、受控反馈和可执行工具使用评估中，FABLE相对于纯规则控制改善了几种偏好敏感行为，同时在端到端任务性能上保持竞争力。

## Abstract
Large language model (LLM) agents can retrieve memory, call tools, ask clarifying questions, and vary response style, yet adapting these execution decisions to an individual user remains difficult. Fine-tuning a separate LLM is costly or impossible for proprietary systems, while prompts and memory primarily expose user information to the agent rather than adapt its execution decisions from feedback. We formulate personalization of a frozen agent as online learning of a per-user execution policy from scalar feedback observed only for the executed action. We propose FABLE (Factorized Adaptive Bandit Layer for Execution), a lightweight policy layer outside a potentially black-box host agent. FABLE factorizes memory, information-acquisition, and response decisions so feedback updates related choices; filters actions through an externally specified feasible set before exploration; and learns user-specific residual preferences relative to a fixed default-and-cost score via Bayesian contextual Thompson sampling. Under a linear residual-reward model, a calibrated variant inherits an expected-regret bound against the best feasible action. We also characterize preferences unidentifiable under persistent feasibility constraints and provide anytime-valid false-promotion control. Across personalized-reasoning, controlled-feedback, and executable tool-use evaluations, FABLE improves several preference-sensitive behaviors relative to rule-only control while remaining competitive on end-to-end task performance.

  - **提示与记忆**：只能向智能体提供用户信息，不能从用户反馈中自适应调整执行策略，也无法覆盖用户反应与预设矛盾的情况；

- **核心问题**：如何在一个**冻结的、可能是黑盒的宿主智能体**外，根据仅对已执行动作观测到的标量反馈，在线学习**每个用户独立的执行策略**，同时满足外部硬约束（如权限、工具可用性、强制确认等）。
- **整体含义**：为黑盒 LLM 智能体的个性化提供了一种轻量、可解释、有理论保证的在线学习方案，在不修改宿主模型的前提下实现用户行为的持续适配。

### 2. 方法论：FABLE

#### 2.1 核心思想

FABLE（Factorized Adaptive Bandit Layer for Execution）是一个位于冻结宿主智能体外部的轻量级策略层，核心流程为：

> 上下文适配 → 可行性过滤 → 因子化贝叶斯汤普森采样 → 编译为宿主指令 → 观测反馈 → 更新残差偏好后验 → 循环。

核心设计原则：

- **因子化动作空间**：执行动作分解为 `a = (m, τ, s)`，其中 `m` 为记忆模式、`τ` 为信息获取模式、`s` 为响应行为。
- **残差偏好模型**：期望反馈分解为固定默认分 `b(c,a)` + 用户残差偏好 `ϕ(c,a)ᵀθ*` − 操作成本 `λ·cost(c,a)`；只学习用户相对默认行为的残差，避免从零学习整个执行效用。
- **可行性先于探索**：外部系统提供可行集 `At`，探索只在可行集内发生；禁止项不通过惩罚项实现，避免乐观后验采样选中被禁止动作。
- **可修订的 onboarding**：用户陈述偏好被编码为有限精度的伪观测，在线反馈可修订。
- **反馈共享**：因子化特征映射使一次所选联合动作的标量反馈可传递给共享相同组件的相关动作，解决稀疏联合反馈问题。

#### 2.2 关键技术细节

- **特征映射**：使用低阶块结构特征 `ϕ(c,a)`，包含主效应（memory/tool/style）、上下文-组件交互、组件-组件两两交互，避免高阶交互退化为扁平动作表。具体实例中动作空间 `|M|=5, |T|=6, |S|=6`，特征维度 d=254。
- **贡献**：上下文 `C_t = (k_t, r_t, g_t, p_t, q_t)`，分别表示任务类型、风险、歧义、记忆需求、工具需求。
- **Onboarding 编码**：将偏好文本编码为 J 个伪观测 `(v_j, u_j, κ_j)`，其中 `v_j` 为偏好方向、`u_j` 为有符号响应、`κ_j` 为精度；通过高斯共轭更新初始化后验 `(μ₀, Σ₀)`。
- **后验采样**：每轮采样 `θ̃_t ~ N(μ_t, ν²_t·Σ_t)`，选择使 `[b̄(C_t,a) + ϕ(C_t,a)ᵀθ̃_t]` 最大的可行动作。
- **后验更新**：残差反馈 `ẏ_t = y_t − b̄(C_t, a_t)`，以高斯工作似然更新精度矩阵和信息向量：
  - `Λ_{t+1} = Λ_t + σ⁻²·ϕ_t·ϕ_tᵀ`
  - `h_{t+1} = h_t + σ⁻²·ϕ_t·ẏ_t`
- **采样调度**：`ν_t = √(9d·log(t/δ))`，该校准尺度保障遗憾界。

#### 2.3 理论结果

- **Theorem 1**：在残差线性模型、有界特征、可预测非空可行集的假设下，FABLE 在对抗最优可行动作的遗憾界为 `Õ(d^{3/2}√n)`（高概率和期望遗憾）。
- **补充理论**：刻画了持续可行性约束下不可识别的偏好方向（Proposition 2/3）；提供随时有效的置信序列规则，控制偏好提升（写入可读状态）的错误概率（Appendix G）。

### 6. 主要结论与发现

- **tau2-bench**：FABLE (full) 在三个指标上均处于最高或并列最高：
  - 相对宿主：+0.077 个性化奖励（95% CI [0.027, 0.127]）、+0.281 对齐度（[0.210, 0.354]）；

  - 消融支持**因子化**（vs Flat LinTS，align +0.022，CI 正）、**在线更新**（vs frozen，align +0.024，CI 正）、**onboarding**（full vs no-onboarding：align +0.163、reward +0.071，CI 均正）、**promotion**（full vs no-promotion：align +0.031，CI 正）对偏好敏感指标的贡献；
  - **在线更新和因子化未带来可统计辨别的任务成功提升**。
- **PAHF**：FABLE (full) 在两个环境均优于 Rule-Only；Online Shopping 上最快学习；但 ablation 排序在不同环境不一致（如 onboarding 在 Embodied 反而略降 reward），说明奖励和成功指标并不总给出相同排序。
- **Math500**：FABLE (full) 准确率最高（0.972），但对齐度低于已知画像注入；在线更新相对冻结提升成本感知奖励（0.366 vs 0.235）；因子化在线性 TS 上相对扁平表示性能相当但维度/存储大幅降低。
- **受控实验**：在线策略正确选 18/20（冻结 14/20），两个方向的后验对比均按指定方向移动，但 20 轮单 seed 不够在统计上确立策略级差异。

### 7. 优点

1. **问题形式化清晰且务实**：将"冻结黑盒智能体个性化"严谨地建模为带可行集约束的上下文赌博机问题，直接回应了稀疏联合反馈和黑盒 API 的约束。
2. **方法设计轻量且通用**：无需宿主权重、梯度或隐藏状态，不修改工具实现，宿主可保持完全冻结；动作目录可替换（tau2、PAHF、Math500 用不同组件语义均可实例化）。
3. **残差化+因子化**：既能保留宿主的泛化行为（只学残差），又能在相关动作之间共享稀疏反馈信号；低阶交互保留了动作互补性，又避免扁平动作表的信息浪费。
4. **可行的工程细节**：可行性过滤先于探索，避免乐观采样选中被禁动作；onboarding 以有限精度先验进入同一坐标空间，可被在线反馈修正；偏好提升有随时有效置信序列控制。
5. **理论保障**：给出 `Õ(d^{3/2}√n)` 遗憾界；补充分析刻画了持续约束下不可辨识参数、非激活坐标不更新等问题；偏好提升具有随时有效的错误控制。
6. **实验设计较严谨**：预指定配对对比、簇自助置信区间、非劣效边界、多种消融，主动报告不显著结果和负面案例，降低了 p-hacking 风险。

### 8. 不足与局限

1. **算力信息缺失**：未报告 GPU 型号、数量、运行时间，无法评估部署成本与可扩展性。
2. **偏好覆盖有限**：tau2 仅两种合成 verbosity 画像；PAHF 和 Math500 均为合成用户，无真实人类用户；对真实用户偏好的复杂性和漂移缺乏验证。
3. **任务成功提升未证实**：tau2 中任务成功改善的 CI 含零，且非劣效性未通过；领域级成功呈异质（Airline 下降、Telecom/Banking 上升），不支持统一收益。
4. **多组对比统计不显著**：full vs no-cost、full vs no-promotion 的 reward 和/或 success 差异区间含零，因果归因受限；受控实验 20 轮单 seed 不显著。
5. **每用户独立后验**：未利用跨用户共享信息（Global LinTS 在部分指标上表现有限），在用户轮次很少时冷启动仍可能缓慢。
6. **固定语义假设**：方法要求动作语义、反馈尺度、特征映射、可行集规则在在线学习期间保持稳定，实际部署中若系统升级或反馈尺度变化，旧观测将失去可比性。
7. **"提升"（promotion）的含义限于可辨识对比**：复杂偏好或不可辨识方向无法写入持久的用户可读状态，实际可用性受限。
8. **实验规模有限**：PAHF 每用户仅 30 轮且无种子不确定性；Math500 仅 1 个合成用户；跨 benchmark 结果一致性较弱（如 onboarding 在不同环境的排名相反），无法得出统一因果结论。
