## 摘要
多令牌预测（MTP）已成为一种有效范式，它通过辅助头增强共享的大语言模型主干，并行训练模型预测多个未来令牌，以丰富监督信号并加速推理。然而，现有的训练框架采用刚性的固定长度预测范围，忽视了自然语言和代码的高度非均匀信息密度。强制辅助头跨越高熵语义边界进行预测，会注入噪声和冲突的训练信号；由于这些辅助头共享主干的潜在表示，由此产生的梯度反向传播并干扰模型的核心能力。我们提出AdaMTP，一种自适应训练范式，动态地将预测范围与序列的内在可预测性对齐。其核心是一种基于熵的分段算法，利用基础模型检测不确定性突增作为语义边界，将序列划分为可变长度的组。每个令牌被分配一个自适应预测深度，动态掩蔽的MTP目标抑制跨越这些边界的预测损失，从而衰减降低主干性能的噪声梯度。在三个主干（Llama-3.1-8B、Qwen-2.5-7B、Gemma-3-12B）上的数学推理、代码生成和通用基准测试中，AdaMTP在任务性能和推理加速方面均持续优于标准MTP。

## Abstract
Multi-Token Prediction (MTP) has emerged as an effective paradigm that augments a shared Large Language Model backbone with auxiliary heads, training the model to predict several future tokens in parallel to enrich its supervision signal and accelerate inference. However, existing training frameworks adopt a rigid, fixed-length prediction horizon, disregarding the highly non-uniform information density of natural language and code. Forcing the auxiliary heads to predict across high-entropy semantic boundaries injects noisy, conflicting training signals; because these heads share the backbone's latent representations, the resulting gradients backpropagate and interfere with the model's core capabilities. We propose AdaMTP, an adaptive training paradigm that dynamically aligns the prediction horizon with the intrinsic predictability of the sequence. At its core, an entropy-based segmentation algorithm leverages the base model to detect sudden surges in uncertainty as semantic boundaries, partitioning sequences into variable-length groups. Each token is assigned an adaptive prediction depth, and a dynamically masked MTP objective suppresses the loss for predictions that cross these boundaries, attenuating the noisy gradients that degrade the backbone. Across mathematical reasoning, code generation, and general benchmarks on three backbones (Llama-3.1-8B, Qwen-2.5-7B, Gemma-3-12B), AdaMTP consistently outperforms standard MTP in both task performance and inference speedup.

## 1. 核心问题与整体含义

- **背景**：大规模语言模型（LLM）多采用 Next-Token Prediction（NTP）训练，推理时逐 token 生成，造成高延迟和计算瓶颈。Multi-Token Prediction（MTP）通过共享骨干网配合多辅助头并行预测多个未来 token，以丰富训练监督信号并加速推理。
- **核心问题**：现有 MTP 训练框架采用**刚性、固定长度**的预测窗口（horizon），忽略自然语言和代码中**高度非均匀的信息密度**。强制辅助头跨高熵语义边界预测，会注入**噪声、冲突的训练信号**；由于辅助头与主头共享骨干网络的潜在表示，这些噪声梯度反向传播后**干扰模型的骨干能力**。
- **核心含义**：预测未来 token 的深度应与序列的内在可预测性对齐，而非机械地统一固定；AdaMTP 正是基于这一洞察，将 MTP 的训练信号“按需分配”。

## 2. 方法论

**核心思想**：利用熵信号检测语义边界，将序列划分为可变长度语义组；每个 token 分配自适应预测深度；仅在其深度范围内计算 MTP 损失，超出部分掩码掉，从而抑制跨边界的噪声梯度。

**关键技术细节与算法流程**：

1. **基于熵的数据分割**
   - 使用基础模型计算每个位置 t 的 next-token 分布熵：  
     **Eₜ = H(P(·|x<ₜ)) = −Σᵥ P(v|x<ₜ) log P(v|x<ₜ)**
   - 计算相邻位置熵差 **ΔEₜ = Eₜ₊₁ − Eₜ**。在连贯语义片段内，熵近似单调下降；在语义边界处，熵出现**突然跳升**（ΔEₜ > τ）。
   - 阈值 τ 通过数据集级搜索校准，使平均组大小与最大预测深度 n 匹配。
   - 对每个 token 分配自适应预测深度 dₜ（式 (5)）：
     - 组内 token：dₜ = 当前组末尾 − t − 1（预测剩余部分）；
     - 边界 token：dₜ = 下一组的长度（预测整个下一组）；
     - 训练时有效监督深度以 min(dₜ, n) 为上限。

2. **两阶段自适应训练**
   - **第一阶段：辅助头预热**。冻结骨干和主语言建模头，仅训练 n−1 个辅助头（MLP + 线性投影），使用基础模型自蒸馏生成的数据，损失为式 (6)。
   - **第二阶段：自适应联合训练**。使用 LoRA（r=32, α=16）对骨干和所有头联合微调；定义**动态掩码 MTP 损失**（式 (7)）：只有当 j+1 ≤ dₜ 时才计算第 j 个辅助头的交叉熵损失；超出深度 dₜ 的预测被掩码掉。
   - 总损失（式 (8)）：**L_total = L_LM + λ·L_MTP**，默认 λ = 0.1。

3. **双模式推理**
   - **固定窗口模式（默认）**：每次草案全部 n 个候选 token，组织为 token 树由基础模型一次验证，保证与 NTP 输出分布一致的无损加速。
   - **自适应窗口模式**：通过实时熵差决定草案生成多少 token，剪枝低置信度尾部候选，减少大 batch 服务场景的验证计算量。

## 6. 主要结论与发现

- 标准 MTP 在所有三个骨干上**平均分均低于 NTP 微调**，证实了固定预测深度导致的“表示干扰”真实存在且影响不可忽视。
- AdaMTP 在三个骨干上平均分**均优于 NTP 和标准 MTP**（Llama-3.1-8B: 36.85；Qwen-2.5-7B: 63.19；Gemma-3-12B: 46.12），尤其在数学推理上提升显著，代码任务上恢复了标准 MTP 的性能损失，通用能力保持最优。
- 推理加速方面，AdaMTP 相对 NTP 实现 1.43×~2.75× 加速，且在三个骨干全部基准上**都快于标准 MTP**（例如 Llama-3.1-8B 上 GSM8K 加速从 1.65× 提升到 2.12×）；由于推理流程相同，速度上的优势完全来自训练产生的更易被接受的草案质量。
- 随着辅助头数量增加，标准 MTP 性能持续下降而 AdaMTP 维持稳健，说明自适应掩码有效吸收了额外预测头引入的噪声。

## 7. 优点

- **问题诊断精准**：用熵增长识别语义边界、量化 MTP 的噪声来源，并通过实验验证了“固定窗口 + 跨边界预测”导致骨干表示干扰这一假设，机理清晰。
- **方法简洁高效**：熵分割 + 动态掩码在实现上非常简单，不引入复杂结构，可无缝集成到现有 MTP 微调流程中。
- **训练目标与推理目标高度一致**：AdaMTP 训练时避免跨边界预测，推理时草案质量更高、验证接受率更高，训练与推理协同增益。
- **推理无损**：默认推理模式与标准 MTP 一样通过自推测验证保证输出分布不变，加速收益无需牺牲质量。
- **泛化性强**：在三个不同模型家族（Meta、Qwen、Google）和不同规模（7B–12B）下结果一致，说明方法是架构无关的。
- **对“在低质量数据下微调”情形依然有增益**：Qwen-2.5-7B 上所有微调范式都低于 Base（因数据分布偏移），但 AdaMTP 仍优于 NTP 和标准 MTP。

## 8. 不足与局限

- **熵计算成本**：需要预先用基础模型对整个训练集做前向推理计算逐 token 熵，且阈值 τ 需要数据集级搜索，存在一个额外的前期计算开销，论文未量化。
- **依赖参考模型**：分割质量受基础模型概率估计质量影响，对于不确定度估计不准的模型可能不稳健。
- **训练数据规模较小**：联合微调仅使用 10,000 条子集，质量有限；Qwen-2.5-7B 上所有方法都低于 Base 的现象也说明数据分布偏移问题未解决，影响结论的普遍性。
- **自适应推理收益未实测**：自适应窗口模式仅在小规模实验上验证了每步验证 token 数减少，未在真实大 batch、高吞吐服务中测出端到端收益；单样本场景下收益微乎其微，适用范围有限。
- **对比范围有限**：未与 L-MTP、Medusa 等更先进的 MTP/自推测变体直接比较，无法判断 AdaMTP 与最优水平之间的差距。
- **预训练场景未验证**：实验仅覆盖“对预训练模型进行 SFT/LoRA 微调”这一种路径，AdaMTP 是否能用于从零预训练尚不明确。
