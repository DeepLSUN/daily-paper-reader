## 摘要
强化学习（RL）搜索智能体通常将检索建模为自由形式的自然语言查询生成，并使用最终答案奖励来优化多轮交互。当前研究主要通过更密集或更结构化的信用信号来改进训练，但很少检查检索在策略-环境接口处是否被正确表述。我们在Search-R1训练期间观察到明显的检索混叠现象：同一问题的轨迹持续生成不同的查询字符串，但其累积的证据集却越来越重叠。我们称这种现象为检索等价坍缩；在这种状态下，轨迹在检索决策方面趋向于效用等价，导致组内回报缺乏有效的检索对比。为解决此问题，我们提出Harness-G，一种图结构检索框架，重新设计了这一接口。它将自由形式的查询生成重新表述为有限动作选择：策略选择一个证据句子或实体，或选择作答，而环境则构建菜单、跟踪检索状态，并验证和执行每个选择。该接口减少了语言混叠，使同状态备选动作可直接比较。基于此接口，我们引入了结构化非近视信用（SNC），它使用冻结的答案评分器将所选动作与其备选动作进行比较，并将下游收益分配给使这些收益成为可能的早期动作。在六个问答基准上，Harness-G在两种评估模型规模下均取得最高平均F1分数，分别以10.74分（1.5B）和3.98分（3B）的优势超越了最强基线Graph-R1。

## Abstract
Reinforcement learning (RL) search agents commonly model retrieval as free-form natural-language query generation and optimize multi-turn interactions using final-answer rewards. Current studies mainly improve training with denser or more structured credit signals, but rarely examine whether retrieval is properly formulated at the policy-environment interface. We observe pronounced retrieval aliasing during Search-R1 training: rollouts for the same question continue to generate distinct query strings, yet their accumulated evidence sets increasingly overlap. We call this phenomenon retrieval-equivalence collapse; in this regime, trajectories approach utility equivalence with respect to retrieval decisions, leaving within-group returns with little effective retrieval contrast. To address this problem, we propose Harness-G, a graph-structured retrieval framework that redesigns this interface. It reformulates free-form query generation as finite action selection: the policy selects an evidence sentence or entity, or chooses to answer, while the environment constructs the menu, tracks retrieval state, and validates and executes each choice. This interface reduces linguistic aliasing and makes same-state alternatives directly comparable. Building on this interface, we introduce Structured Non-myopic Credit (SNC), which uses a frozen answer scorer to compare the selected action with its alternatives and assigns downstream gains to the earlier actions that enabled them. Across six QA benchmarks, Harness-G achieves the highest average F1 at both evaluated model scales, outperforming the strongest baseline, Graph-R1, by 10.74 points at 1.5B and 3.98 points at 3B.

## 1. 论文的核心问题与整体含义

- **研究背景**：现有RL搜索智能体（如Search-R1）将检索建模为**自由形式自然语言查询生成**，并依赖最终答案奖励进行训练。研究者们通常通过更密集的信用分配（如过程奖励、信息增益）来改善训练效果，但忽略了检索在**策略-环境接口**处的表述方式本身可能存在问题。
- **核心问题——检索等价坍缩**：论文观察到，训练中同一问题的不同rollout会生成越来越多样化的查询字符串，但累积证据集却高度重叠。即**查询形式多样性**远高于**检索结果多样性**，策略表面的探索是「虚假探索」。该现象被命名为 **检索等价坍缩（retrieval-equivalence collapse）**。
- **坍缩的直接影响**：(1) 轨迹间在检索决策层面趋于效用等价，组内优势（advantage）消失，GRPO的组相对优化失效；(2) 检索信用被混淆——相同证据产生不同答案时，回报差异主要反映下游推理而非检索质量，无法可靠识别更好的检索动作。
- **关键论点**：现有方法（过程奖励、信息增益等）只改善了信用信号的稠密度，但**未能改变自由查询到检索结果的多对一映射**，因此不能从根本上恢复检索层面的有效对比。**动作空间本身的设计**（而非只关注奖励设计）是制约检索智能体优化的关键维度。

## 2. 方法论

### 2.1 核心思想

Harness-G将检索从「自由形式查询生成」重述为「**图引导的有限动作选择**」：策略只负责在每个决策状态从环境构建的有限动作菜单中选择一个动作（选择证据句、查找实体、或结束作答），而**查询构造、检索执行、状态更新全部由环境确定性完成**。论文将此称为对检索接口的重新设计（interface redesign）。

### 2.2 段落-句子-实体三分图

- 离线阶段从语料库构建**无关系标注的三分图**：段落节点、句子节点、实体节点。
- 边类型：段落-句子（上下文归属）、句子-实体（提及关系，支持跨文档跳跃）、句子-句子（相邻句扩展）、实体-实体（表面形式归一化、同义词匹配、嵌入邻居）。
- 构建过程仅使用句子切分、NER（spaCy）、稠密编码，**不调用生成式LLM**，近线性时间完成，构建成本极低且可复用。

### 2.3 菜单环境

每个回合策略从三类动作中选择：

| 动作 | 语义 | 说明 |
|---|---|---|
| `Select(s)` | 选择可见句子 s 作为承诺证据 | 最终答案仅基于承诺证据集 Ct 生成 |
| `Lookup(e)` | 围绕实体 e 检索缺失信息 | 查询由环境确定性构造，按实体区分动作目标 |
| `Answer` | 终止检索并生成答案 | 另有 `Answer_With` 变体可一键提交并终止 |

菜单由环境生成，具有三个构造性属性：

- **有限性**：动作数量有明确上界（可见句子上限 Ks、Lookup候选上限 Ke）。
- **可验证性**：所有动作携带明确类型和目标，无效动作直接排除，而非事后惩罚。
- **可预览性**：任何候选动作都可以由环境以只读方式展开其预期效果（`Preview(zt, a)`），不改变真实状态——这是SNC信用分配的基础。

### 2.4 Structured Non-myopic Credit (SNC)

SNC由两个互补项组成，全部由环境计算，无需外部奖励模型或额外rollout：

**（1）前沿相对优势（Frontier-relative Advantage）**

- 冻结的答案评分器计算观测证据对标准答案的支持度：
  g(O) = P̄θ(y* | q, O)
- 每个信息获取动作 a 的边际增益：
  pₜ(a) = g(Oₜ ∪ Ũ(a)) − g(Oₜ)
- 策略选择的动作与同状态备选前沿 Fₜ 的平均增益之差即为前沿相对优势：
  rₜᶠʳ = pₜ(aₜ) − p̄ₜ
- 只有真正优于同状态可行备选的动作才获得正信用，表面选择（不改变证据的选项）获得约零信用。

**（2）结构化使能信用（Enablement Credit）**

- 当步骤 u 消费了步骤 t 产生的句子或实体时，记录**溯源边** (t, u)。
- 按逆拓扑序沿溯源图传播信用：
  Rᵤ = pᵤ(aᵤ) + γrᵤᵉⁿ
  rₜᵉⁿ = Σ_{(t,u)∈Dτ} Rᵤ / |Pred(u)|
- 下游收益沿使能链回传至早期桥接动作，学习「先找桥接实体，再查其缺失属性」的非近视模式。

## 6. 主要结论与发现

1. **Harness-G在六个QA基准上平均F1均为最高**：3B规模下平均F1 55.24，超过Graph-R1达3.98分；1.5B规模下以50.83超越Graph-R1达10.74分——限制为可执行的结构化动作对**较小模型尤其有效**。
2. **多跳数据集收益最大**：3B规模下2Wiki提升7.97 F1、HotpotQA提升9.12 F1、MuSiQue提升5.95 F1；单跳收益有限（NQ落后1.84）。
3. **动作菜单单独贡献显著**：界面从自由查询切换为菜单，在相同检索基底、相同奖励下，F1提升超过17个点（MuSiQue上超过35个点）——证明接口重设计本身即有重大价值。
4. **SNC贡献进一步增益**：完整SNC在三个多跳数据集上均优于任一组分缺失的变体；移除全部步骤信用使F1下降3.08/4.55/2.88。
5. **训练稳定性显著优于现有方法**：训练F1持续上升无晚期崩溃，梯度范数有界；与Search-R1的「零优势组崩溃」形成鲜明对比。
6. **跨数据集与跨领域泛化更强**：30对O.O.D.评估中赢21对，平均O.O.D. F1从44.10提升至47.38（+3.29）；零样本专业领域迁移超过Graph-R1 3.16 F1。
7. **交互效率高**：回合数更多但总响应token更短；SNC训练开销极小；构图无API成本。

## 7. 优点

- **问题诊断精准且有量化依据**：用「查询形式多样性 vs 检索结果多样性」双指标明确刻画了检索等价坍缩，并给出训练动态曲线，问题定义清晰可验证。
- **接口重设计视角新颖**：不局限于「更多奖励/更细信用」，而是从动作空间本身出发重述问题，为检索智能体优化提供了与奖励设计互补的**新轴心**。
- **方法工程性强**：图构建完全程序化、无LLM参与，菜单机制确定性可验证，SNC无需额外rollout——兼顾了效果与实用性。
- **SNC设计优雅**：前沿相对优势使同状态备选可比较、使能信用解决延迟回报问题，两者配合在数学上和直觉上都有说服力；预览机制使信用分配从「不可计算的开字符串空间」变为「有界的环境操作集」。
- **消融严谨**：转换匹配的界面比较隔离了「动作暴露方式」这一变量，在相同可达状态与转换下只改变策略输入的呈现形式；SNC leave-one-out消融清晰分离了两种信用项的贡献。
- **报告诚实透明**：明确标注方法属性（程序化vs LLM构建）、报告失败案例、公布成本细节和动作筛选过程，工业可复现性强。
- **鲁棒性考察全面**：跨骨干、跨RL算法、跨训练机制、跨数据集、跨领域的多重验证超出同类工作。

## 8. 不足与局限

- **实验覆盖偏差**：评估全部基于维基百科类文本语料，未涉及更复杂或噪音更大的真实网域检索；对单跳QA的优势有限（NQ上仍落后最强基线），方法的适用边界值得更明确地讨论。
- **主结果公平性局限**：主表（表1）中Harness-G与Graph-R1等基线虽在具体指标上进行对比，但二者在知识构建方式、接口设计上均不同，并非严格的「单变量对照」——论文通过附录G的匹配协议弥补了这一点，但主表内无法完全消除组间差异。
- **冻结评分器的偏差风险**：SNC依赖初始参考检查点作为冻结答案器，若该评分器对某些证据类型或答案形式存在系统性偏好，可能产生有偏的信用信号；论文未详细分析这种偏差的敏感性。
- **标量评分的简化**：SNC的信用基于条件概率增益，对「不同信息增益路径等价」的假设可能忽略证据间结构性依赖；使能信用的 `γ=1` 默认设定也缺少敏感性考察。
- **多学科验证不足**：没有进行其他任务类型（如代码搜索、工具调用、多模态检索）的验证；论文也承认当前是文本唯一的，多模态扩展留待未来。
- **留出集偏小**：每个数据集只有128个留出题，个别数据集的分数差异可能在统计上不够显著；论文承认依赖跨数据集的一致趋势而非单个边际差异。
- **搜索深度受限**：最多6个交互回合，对于更长链的多跳问题可能构成上限约束，论文未分析长度限制对性能的瓶颈效应。
