## 摘要
近年来，多模态大语言模型（MLLMs）如Qwen2.5-VL和InternVL3，为高分辨率输入生成大量视觉token，导致计算成本显著增加。现有的视觉token剪枝方法要么依赖于跨模态注意力，无法在预填充阶段之前进行剪枝，要么依赖于高计算开销的多样性估计。我们观察到，视觉和文本token的注意力分数在模态分隔符token处达到峰值，这表明这些分隔符桥接了两种模态。基于这一观察，我们提出了SepPrune，一种高效、无需训练、即插即用的剪枝方法，利用分隔符token作为统一查询来排序和选择信息丰富的视觉token。SepPrune重用LLM内置的投影参数，无需修改架构。在Qwen2.5-VL-7B上的实验表明，SepPrune达到了最先进的性能，在移除80.2%视觉token的同时保留了96.3%的原始准确率。

## Abstract
Recent multimodal large language models (MLLMs), such as Qwen2.5-VL and InternVL3, generate large numbers of vision tokens for high-resolution inputs, leading to substantial computational cost. Existing vision token pruning methods either depend on cross-modal attention and cannot prune before the prefill stage, or rely on diversity estimation with high computational overhead. We observe that attention scores from both vision and text tokens peak at modality separator tokens, suggesting that these separators bridge the two modalities. Based on this observation, we propose SepPrune, an efficient, training-free, plug-and-play pruning method that uses the separator token as a unified query to rank and select informative vision tokens. SepPrune reuses the LLM's built-in projection parameters and requires no architectural changes. Experiments on Qwen2.5-VL-7B show that SepPrune achieves state-of-the-art performance, retaining 96.3% of the original accuracy while removing 80.2% of vision tokens.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 核心思想
**利用模态分隔符（separator）作为统一查询（unified query）来评估所有视觉 token 的重要性**，将全量 N×N 自注意力计算简化为一组 1×N 的注意力打分，从而在 LLM 推理之前、以线性复杂度完成剪枝。

### 输入序列结构
```
X_input = [Tsys, S_left, V, S_right, Tusr]
```
其中 `Tsys` 为系统提示 token，`S_left` 和 `S_right` 为视觉 token 前后的分隔符，`V` 为视觉 token，`Tusr` 为用户文本 token。

### 关键技术细节
1. **分隔符作为统一查询（Separator as Unified Query）**：
   - 由于训练时使用因果注意力掩码，只有视觉 token **之后**的分隔符 `S_right` 才能访问完整的图像信息；
   - 将 `S_right` 的 query 向量 `Q_sep` 与所有视觉 token 的 key 矩阵 `K_visual` 做点积，得到 1×N 的注意力分数向量；
   - 这一步规避了完整的 N×N 注意力矩阵计算，将复杂度从 O(N²) 降至 O(N)。

2. **去除位置编码（Position-Free Encoding）**：
   - 在打分阶段**刻意省略 RoPE（旋转位置编码）**；
   - 原因：RoPE 会引入位置偏差，使查询向量倾向于关注相邻的视觉 token（尤其是图像底部区域），导致剪枝偏好位置而忽略语义内容；
   - 去除位置编码后可实现与位置无关、纯粹基于语义内容的评估。

### 核心公式
```
Score_prune = softmax(Q_sep · K_visual^T / √dk)
```
其中 `Score_prune` 是 1×N 的得分向量，`dk` 为 query/key 维度。

### 算法流程（文字描述）
1. 视觉编码器生成视觉 token 后，立即进入 SepPrune 模块；
2. 复用 LLM 第一层（Layer 0）的 q_proj 和 k_proj 投影参数；
3. 取视觉 token 之后的分隔符作为 query，所有视觉 token 作为 keys；
4. **不施加** RoPE 位置编码，直接计算注意力分数；
5. 按分数进行 Top-k 排序，保留最高分的 k 个视觉 token（保留原始位置索引）；
6. 将剪枝后的稀疏序列连同分隔符和文本 token 一起送入 LLM 处理。

### 重要特性
- **即插即用**：不改变 LLM 架构，不引入额外训练；
- **兼容 FlashAttention**：剪枝在 LLM 推理前完成，不中断注意力计算流；
- **无需管理 KV-cache**；
- **复杂度低**：O(N·D²)，显著低于基于多样性的 O(N²·D) 方法。

## 6. 主要结论与发现

- **机制层面**：首次揭示了模态分隔符在 MLLM 中扮演跨模态桥梁角色，浅层注意力在分隔符处出现峰值，且该峰值随着网络深度增加而衰减；
- **性能层面**：
  - 在 Qwen2.5-VL-7B 上，SepPrune 在 ↓60.5% 剪枝率下保留 **99.0%** 的原始性能；
  - 在 ↓80.2% 剪枝率下保留 **96.3%** 的原始性能，比 CDPruner 高出近 3 个百分点；
  - 在 ↓90.1% 的极端剪枝率下仍保留 **87.2%**，在信息密集任务（TextVQA、ChartQA）上显著优于基线；
  - 在 InternVL3-8B 上，↓80% 剪枝率下达到 **93.1%** 相对得分，优于所有基线；
  - 视频任务上在 0.6/0.8 剪枝率下均取得最佳表现；
- **效率层面**：在线性复杂度下取得了最低端到端延迟（591.4s vs 无剪枝基线 760.4s），比 DivPrune（598.7s）和 CDPruner（639.9s）更快；
- **消融验证**：使用视觉 token 之后的分隔符作为 query 优于使用末位 token 或视觉 token 之前的分隔符；去除 RoPE 后大幅提升剪枝效果（MME +82 分，TextVQA +7.2 分）。

## 7. 优点

- **机制洞察新颖**：通过注意力可视化揭示分隔符的跨模态桥梁功能，并基于严谨的消融实验验证假设，从“理解模型”出发设计方法；
- **方法简洁高效**：仅使用一次 1×N 注意力打分就能完成剪枝，时间复杂度 O(N)，理论上和实际上都比 O(N²) 的多样性方法快；
- **即插即用、免训练**：不需要任何训练/微调，可直接接入现有 MLLM，且不修改架构；
- **兼容主流优化**：在预填充阶段之前完成剪枝，不打断注意力计算流，可无缝配合 FlashAttention 等加速算子；
- **跨架构可迁移**：在 Qwen2.5-VL-7B 和 InternVL3-8B 两种最新架构上均验证有效；
- **保留位置信息**：剪枝后保留原始位置索引，避免因 token 压缩带来的位置错乱问题。

## 8. 不足与局限

- **依赖显式分隔符**：方法高度依赖 MLLM 中存在显式模态分隔符 token。并非所有 MLLM 架构都有这种设计，在无分隔符的架构上的应用方式未被讨论；
- **极端压缩下性能衰减明显**：在 ↓90.1% 时整体得分降至 87.2%，虽然领先基线，但与无剪枝相比性能损失仍较显著，在追求极限加速的场景下存在质量瓶颈；
- **未端到端报告实际吞吐**：效率分析仅报告单个数据集（MME）的延迟，未提供 Tokens/s、显存占用、批量推理等工程指标，实际加速效果仍需更系统的评测；
- **对比方法覆盖有限**：未与更多注意力类方法（如 FitPrune、SparseVLM、PyramidDrop）全面对比；
- **视频基准覆盖较少**：仅 2 个视频 benchmark，视频 token 的时序关联（相邻帧的视觉 token 高度相似）可能使基于分隔符的打分策略在复杂视频场景下表现受限，但文中没有深入讨论；
