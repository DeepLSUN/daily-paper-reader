## 摘要
提示压缩通过缩短LLM输入来降低推理成本，然而现有方法通过语言模型前向传播来评估令牌重要性。这种细致而昂贵的令牌选择是否必要，仍然值得怀疑。压缩需要识别信息性内容，而语言学研究长期以来通过可操作化为确定性规则的线索来解决这一问题。因此我们提出：仅语言规则能否在没有基于语言模型的评分的情况下，作为有效的提示压缩器？为解决此问题，我们针对词汇、句法、语义和篇章种子进行离线进化搜索，以找到有竞争力的规则组合。由此产生的语言压缩器在部署时无需语言模型前向传播，压缩仅使用CPU端处理。我们采用双路径协议对其进行评估，以平衡压缩质量和重建保真度。在短段落、多文档推理和对话记忆问答数据集上，进化压缩器取得了与近期先进提示压缩策略相似的表现。在轻度至中度压缩下性能最强，随着压缩更为激进性能下降，而直接路径与重建路径表现出不同模式。进化分析揭示，有效压缩融合了跨语言层面的信号，且随着压缩比增加，规则从令牌剪枝转向句子提取。

## Abstract
Prompt compression shortens LLM input to reduce inference cost, yet existing methods score token importance through LM forward passes. It remains questionable whether such nuanced, costly token selection is necessary. Compression requires identifying informative content, a problem that linguistic research has long addressed through cues that can be operationalized as deterministic rules. We therefore ask: can \textbf{linguistic rules alone} serve as effective prompt compressors, without LM-based scoring at compression time?   To address this, we conduct offline evolutionary search over lexical, syntactic, semantic, and discourse seeds to find competitive rule combinations. The resulting linguistic compressor requires no LM forward pass at deployment and uses only CPU-side processing for compression. We evaluate it with a dual-path protocol to balance compression quality and reconstruction fidelity.   Across short passages, multi-document reasoning, and dialogue-memory QA datasets, evolved compressors achieve performance similar to that of recent advanced prompt-compression strategies. Performance is strongest under light-to-moderate compression and degrades as compression becomes more aggressive, while the Direct and Reconstruction paths exhibit distinct patterns. Evolutionary analysis reveals that effective compression fuses signals across linguistic levels and, as the compression ratio increases, rules shift from token pruning to sentence extraction.

# 论文分析：基于语言规则的提示压缩——无需LM评分的低成本压缩途径

## 1. 核心问题与研究动机

- **背景痛点**：大语言模型在长上下文应用（RAG、多智能体通信、长期对话等）中面临推理成本高、延迟大、关键信息被稀释等问题。硬提示压缩（通过剪枝token保持自然语言可读性）是主流解决方案。
- **现状质疑**：现有提示压缩方法（LLMLingua、Selective Context等）无一例外地依赖**LM前向传播对token逐点评分**（perplexity、分类器概率、注意力信号等）来判断信息重要性，存在两大缺陷：
  - 计算成本高昂、依赖前向传播、本质不透明；
  - token级粒度的剪枝容易切断句法依赖和语义连贯性。
- **核心研究问题**：**语言学规则能否独立作为有效的提示压缩器**（无需LM评分）？语言学早已有成熟的可操作线索：词汇层的内容/功能词区分、句法层的论元结构、语义层的否定/量词辖域、话语层的主题句位置与实体连贯性，均可通过标准NLP工具低成本提取。
- **核心意义**：若成立，则可以大幅降低压缩环节的部署成本，压缩过程完全在CPU端完成，无需GPU推理。

## 2. 方法论

### 2.1 整体架构：离线进化搜索 + 确定性语言规则压缩器

- **种子构建**：设计42个语言学种子（seed），每个种子是一个独立的Python `compress(text)` 函数，含10个词汇层种子、12个句法层种子、6个语义层种子、9个话语层种子、5个复合管道种子。压缩时仅使用spaCy + NLTK/WordNet + 标准Python库，**无任何LM推理参与**。
- **进化搜索框架**（基于AlphaEvolve）：
  - **种群组织**：6个独立岛屿，均匀分配种子，每个岛屿管理一个48格（6×8）MAP-Elites存档，轴为“代码复杂度×压缩比”，每格仅保留最高适应度的压缩器。
  - **变异算子**：三层LLM集成（GPT-5.4-mini、DeepSeek-V4-Pro、GPT-5.5）通过SEARCH/REPLACE差分编辑压缩器代码，温度从1.0退火至0.0（前期探索、后期精炼）。
  - **三阶段级联评估**（降低计算成本）：
    - 阶段1：格式检查（2个样本），空输出/非字符串/超压缩比范围即淘汰；
    - 阶段2：粗筛QA过滤（样本池的1/6），阈值放宽（α<1）；
    - 阶段3：严格QA过滤（样本池的1/2），阈值收紧；通过者才在完整训练集上重新评分。
  - **岛屿迁移**：环形拓扑，每3代迁移15%的高适应度个体。
  - **搜索配置**：30代，4个目标压缩比（1.5×、2.5×、4×、6×）。
- **双路径评估协议**（公式）：
  - **Direct路径**：压缩文本 → 接收LLM → 问答评分，记为D；
  - **Reconstruction路径**：压缩文本 → 重建LLM → 恢复原文 → 接收LLM → 问答评分，记为R；
  - **适应度函数**：f = min(D, R)，取两路径中较弱者（保守目标，确保压缩器在两条路径上都保留足够信息）。

## 6. 主要结论与发现

1. **语言学规则可以作为有效的提示压缩器**：在许多长文档场景中，仅依赖CPU语言规则处理即可获得与先进LM评分压缩方法相似的表现。
2. **轻中度压缩最强，激进压缩衰减**：1.5×时在Qasper和Multi-doc QA上排名第一；2.5×时在LongMemEval排名第一；6×时排名第三到第五。原因在于语言学规则做“分类式”取舍，而LM评分可做“连续式”排序，在极限预算下差距拉大。
3. **有效压缩需要跨语言层级融合**：1.5×—4×范围内，最优压缩器同时采用词汇、句法、语义、话语规则；完全没有单一层级的压缩器成为最优。NER保留、否定强制保留、核心论元三元组、话语连接词保留是最稳定的规则。
4. **压缩粒度随压缩比加深从token转向句子**：1.5×为扁平token打分，2.5×为基于依存子树的分层填充，4×为句子选择+token剪枝的两阶段级联，6×为句子选择+子树删除+后处理。
5. **进化搜索不只是组合种子，还生成新机制**：如动态实体链评分（1.5×）、混合截断策略（2.5×）、句子-令牌复合管线（4×）、层次删除+实体折叠后处理（6×）。
6. **压缩比可控性极佳**：几乎零偏差地精确命中目标压缩比，而多个LM基线存在压缩比漂移（随目标压缩比增大而加剧）。

## 7. 方法优点

- **部署成本大幅降低**：压缩阶段完全CPU化，无需GPU推理。以1.5×为例，本方法在LongMemEval上每个输入约222ms，而PartPrompt需要约84,668ms；且内存占用仅1.4GB（对比LLMLingua的20GB+）。
- **透明可解释**：每一条压缩规则都是显式、可检查的语言学属性，而非模型生成的模糊分数，便于审计和调试。
- **压缩比控制精准**：显式词预算机制使实际压缩比与目标几乎零偏差，而LM基线（如LLMLingua-2目标6×实际7.5-7.9×）存在显著漂移。
- **跨模型稳定性好**：在RACE数据集上跨三个接收LLM的变异系数（CV）最低（9.66%），Multi-doc QA上仅次于最优。
- **方法学亮点**：将进化搜索（AlphaEvolve）适配到提示压缩问题，三阶段级联筛选显著降低了搜索成本；双路径适应度函数（min(D,R)）避免了单路径优化的偏见。

## 8. 不足与局限

- **统计证据不强**：0个显著胜出、9个显著损失、47个不确定是最严峻的问题。作者的“达到相似性能范围”仅是描述性的，未能在统计意义上证明等价或优越。
- **短文本与激进压缩是硬伤**：RACE显著弱于多款基线；6×时在Qasper等数据集上重建路径也出现显著损失（p<0.05）。
- **语言与文本类型受限**：仅支持英语标准散文；未验证源代码、JSON、数学符号、表格等非标准结构输入；解析器噪声可能改变最优规则组合。
- **搜索空间覆盖不足**：42个种子远未穷尽语言学压缩规则空间；训练池3/4来自长文档——进化可能偏向长文本模式，这是RACE失败的直接原因。
- **评估范围有限**：每数据集仅200测试样本（受LongMemEval可用案例限制）；开放生成任务的结论依赖judge模型与提示的设定（尽管做了人工验证）。
- **接收模型漂移风险**：使用7B-12B模型进行进化，规则核心未必能迁移到更大、不同架构的未来模型。
- **离线优化成本未完全消除**：部署虽便宜，但发现4个程序需26小时和50美元，且使用了测试基准族的训练样本进行调优（与通用训练的基线存在对比不对称）。
- **TokenShrink对比不完整**：尝试对比非LM压缩器TokenShrink，但因其无法达到1.5×以上的压缩比而未能纳入正式对比。
