## 摘要
仅解码器语言模型将长期记忆与推理纠缠在单一参数集中，使得独立扩展记忆容量变得困难。记忆解码器引入了一种参数化的长期记忆模块，但仅在相对较小的规模上进行了研究。在这项工作中，我们提出了大规模记忆解码器，将记忆模型扩展到6.9B参数，并在300B令牌上进行预训练。在此数据规模下，索引和搜索的联合成本使得标准的Faiss管道不可行。我们通过分布式Faiss索引和检索管道，以及稀疏的、批量加载的kNN分布来解决这一瓶颈。在不同模型规模下，我们发现将更多参数分配给记忆比单独扩展基础模型能带来更好的参数-性能权衡。在17个基准测试中，将6.9B通用记忆与Pythia-410M配对，将其平均得分从29.86提升至37.34，以少39%的总参数超越了Pythia-12B（37.24）。对于范围从0.6B到14B的Qwen3基础模型，1.7B领域记忆在每个规模上平均提升了三个领域超过9个百分点的得分。总体而言，我们的结果表明，独立扩展预训练记忆为提升语言模型性能提供了一条更具参数效率的路径。

## Abstract
Decoder-only language models entangle long-term memory and reasoning in a single parameter set, making it difficult to scale memory capacity independently. Memory Decoder introduces a parametric long-term memory module but only studies it at a relatively small scale. In this work, we present Memory Decoder at Scale, scaling memory models up to 6.9B parameters and pretraining them on 300B tokens. At this data scale, the combined cost of indexing and search makes a standard Faiss pipeline infeasible. We address this bottleneck with a distributed pipeline for Faiss indexing and retrieval, together with sparse, batch-wise loading of kNN distributions. Across model scales, we find that allocating more parameters to memory yields a better parameter-performance tradeoff than scaling the base model alone. On 17 benchmarks, pairing a 6.9B general memory with Pythia-410M raises its average score from 29.86 to 37.34, surpassing Pythia-12B (37.24) with 39% fewer total parameters. For Qwen3 Base models ranging from 0.6B to 14B, 1.7B domain memories improve the average score across the three domains by more than 9 points at every scale. Overall, our results demonstrate that independently scaling pretrained memory offers a more parameter efficient path to improving language model performance.

## 2. 论文提出的方法论

### 核心思想

Memory Decoder 是一种独立的参数化记忆模块，其训练目标为**模仿非参数 kNN 检索器的输出分布**（分布对齐），同时保留语言建模目标。推理时，冻结的基础模型与记忆模型并行处理同一上下文，两者的下一 token 分布通过线性插值融合。

### 关键技术细节

1. **kNN 分布构造**：
   - 用冻结的基础模型 \( M_\theta \) 对语料库每个位置的上下文 \( c_t \) 编码得到键 \( k_t = \phi_\theta(c_t) \)，与观测值 \( x_t \) 构成 datastore：\( R_{mem} = \{(k_t, x_t)\} \)。
   - 对每个查询 \( q_t \)，检索 \( K \) 个最近邻，按距离加权（温度 \( \tau \)）形成稀疏的 kNN 分布 \( p_{ret}(y|c_t) \)。

2. **记忆训练目标**：
   \[
   L_{mem} = \beta D_{KL}(p_{ret} \| p_\psi) + (1 - \beta)[-\log p_\psi(x_t|c_t)]
   \]
   - KL 项使记忆模型 \( M_\psi \) 模仿 kNN 分布（提供比单一目标 token 更丰富的监督）。
   - 语言建模项防止记忆过度偏离语料分布。
   - 推理时融合：\( p_{final} = (1 - \alpha)p_\theta + \alpha p_\psi \)。

3. **大规模工程创新——分布式 Faiss 管道**（针对 207B token 的 Pile 数据集）：
   - **嵌入压缩**：OPQ256 将 Pythia-6.9B 的 4096 维隐藏状态压缩为 256 维，降低存储和距离计算成本。
   - **索引分片**：使用 IndexHNSW 作为量化器，将 IVF 索引按连续质心范围划分为多个 IndexIVFPQ 分片，支持独立 GPU 搜索。
   - **并行检索**：HNSW 路由查询到对应分片，GPU 分片并行局部检索，writer 合并候选并输出稀疏 \( p_{ret} \)。

4. **稀疏存储与分布式流式加载**：
   - 稀疏 kNN 分布仅保留概率大于阈值 \( \epsilon \) 的 token，存为分片平铺数组 + 偏移量，复杂度为 \( O(N+M) \) 而非 \( O(N|V|) \)，约 250× 压缩比。
   - 每个训练样本附带对齐的分布行范围，分布式 workers 通过只读内存映射按需加载，以稀疏坐标三元组送入批处理接口。

5. **领域记忆流程**：每个领域语料先用同一骨干（Qwen3-4B）做一期继续预训练，再用其表示构造 datastore，训练独立的领域记忆。

  - 峰值学习率分别 3×10⁻⁴ / 2.5×10⁻⁴ / 2×10⁻⁴，AdamW，余弦衰减至 10%，2000 warmup steps。
  - 全局 batch size 2M tokens，序列长度 2048。
- **训练时长**：论文**未明确说明**具体训练时长/天数，仅给出训练 token 数（300B）和步数（148,000）。

## 5. 实验数量与充分性

### 实验数量概览

- **通用记忆**：3 种骨干规模 × 3 种记忆规模 + 12B 基线，共 18 种配置，覆盖 17 个 benchmark（51 个任务-规模组合）。
- **领域记忆**：5 个 Qwen3 骨干规模 × 3 个领域，加上 2 个 OLMo 骨干，覆盖 15–21 组完整评估。文中还报告了每任务级结果（21 个 BioInst 任务、20 个 LawBench 任务、25 个 FinEval 任务）。
- **消融与分析实验**：
  - 少样本鲁棒性（0/3/5-shot）
  - 记忆大小（0.6B vs 1.7B；1.4B vs 2.8B vs 6.9B）
  - 训练预算（20% vs 100%）
  - 训练目标控制（Memory vs CPT 模块）
  - 可提取记忆评估（两种探针）
  - 记忆对 kNN 监督的保真度（4 种指标）
  - 插值系数敏感性（21 个 α 值 × 6 任务 × 3 规模）
  - RAG 检索深度对比（top-3 vs top-5）

### 充分性与客观性评估

- **充分**：实验维度覆盖广泛，包括模型规模、记忆大小、训练预算、few-shot、跨词表迁移、逐任务分析、模型输出案例，比较全面。
- **公平性**：CPT/LoRA 与记忆使用相同训练数据和计算预算；控制实验（attached module control）确保记忆增益来自训练目标而非插值接口；RAG 的 top-3/top-5 对比显示结果对检索深度不敏感；插值系数 α 在验证集上调节，避免 cherry-pick。
- **潜在偏倚**：α 在验证集上调节可能略微高估测试性能；知识任务上 α 偏高（中位数 0.80），说明记忆贡献较大，但这也正是设计目标。

## 6. 论文的主要结论与发现

1. **记忆缩放比骨干缩放更参数高效**：
   - Pythia-410M + Mem-6.9B 在 17 项任务上达到 37.34，超过 Pythia-12B 的 37.24，且总参数少 39%。
   - 同参数和预算下，1.4B 骨干 + 1.4B 记忆（34.36）优于 2.8B 骨干（33.89）。
2. **通用记忆在所有规模和任务上广泛有效**：
   - 51 个任务-规模组合中，记忆提高 47 个、追平 1 个。
   - 最大增益集中在知识密集型任务（TriviaQA、2WikiMultiHopQA、HotpotQA）。
3. **领域记忆跨骨干规模一致有效**：
   - 1.7B 领域记忆在 Qwen3 0.6B–14B 上每规模平均提升超 9 分；最大增益在 14B 上 BioInst +17.96。
   - 领域记忆优于 CPT、LoRA、RAG 等基线（每规模至少超出最强基线 4.05 分）。
4. **跨词表迁移可行**：仅用 20% 预算即可将 Qwen3 记忆迁移到 OLMo 词汇表，OLMo-3-7B 上提升 7.77 分。
5. **记忆继续受益于更大容量和更长训练**，且记忆在 few-shot 下仍有效。
6. **记忆是可提取的**：可提取记忆评估显示记忆模型比 CPT 更忠实地保留训练数据内容（EM@8,16 从 42.4%→49.7%，域锚点完成任务从 22.6%→56.5%）。
7. **记忆忠实于检索监督**：top token 匹配 86.62%，Pearson r = 0.917，表明记忆不只是学习 argmax，而是学习整体分布结构。

## 7. 优点

### 方法上的亮点

- **模块化设计**：记忆独立于骨干训练，可实现领域切换（memory bank 概念）、跨骨干复用，推理时无需外部检索或额外上下文处理。
- **丰富的监督信号**：利用 kNN 分布而非单一 token 作为训练目标，能捕捉多种合理延续，使记忆学会不确定性和置信度，而非简单记忆 argmax。
- **大规模工程创新**：分布式 Faiss 管道（OPQ 压缩 + IVF 分片 + HNSW 路由 + GPU 并行检索）和稀疏分布存储 + 分布式流式加载，有效解决 207B token 规模下 kNN 构造的索引和搜索瓶颈。
- **全面的控制实验**：attached module control 用相同数据、FLOPs、容量和推理接口隔离了训练目标的影响；跨词表迁移实验验证了模块化架构的迁移优势。

### 实验设计上的亮点

- 覆盖模型家族多样（Pythia、Qwen3、OLMo），规模跨度大（0.6B–14B 骨干，0.6B–6.9B 记忆）。
- 每个记忆配置保持相同训练预算，确保公平对比。
- 逐任务结果（附录 J）全部公开，透明度高。
- 可提取记忆评估采用两种独立探针，交叉验证了记忆训练对数据保留的影响。
- 记忆保真度分析用 4 种互补指标 + 逐类目标分布分析，多角度确认学习有效性。

## 8. 不足与局限

### 实验覆盖层面的局限

- **通用记忆仅用 Pythia 骨干构造 datastore**：虽然记忆可跨骨干迁移，但探索范围有限——datastore 只用了一种骨干表示。不同骨干的表示空间差异可能影响记忆在其他架构上的上限。
- **领域记忆仅覆盖三个领域**（生物、法律、金融），且训练语料规模差异大（125M–4.4B tokens），缺乏更多领域（代码、医学、多语言等）的一般性验证。
- **跨词表迁移只测了 OLMo-2/3 两个模型**，且迁移后记忆大幅落后于 Qwen3 上的表现，说明词表迁移仍有性能损失，机制研究不够深入。
- **部分任务（如 TruthfulQA、HaluEval）上记忆增益有限，甚至略有下降**（如 TruthfulQA 在多个规模上下降），说明记忆对事实性和幻觉控制并非一致有益，论文未深入分析何时记忆会引入风险。

### 方法与实现上的局限

- **离线 kNN 构造开销大**：虽然推理无需检索，但记忆预训练前仍需对全部语料做索引和检索，这一预处理成本随语料规模增长，论文未报告具体的时间和资源消耗数字。
- **固定线性插值系数 α**：全局统一 α 无法自适应不同输入的需求，论文虽做了敏感度分析，但未解决自适应 α 的问题。
- **记忆与骨干缺乏协同训练**：记忆在骨干冻结下训练，两者分布可能不完全协调；联合训练可能更好，但会削弱模块化的独立性。
- **数据保留/隐私风险**：可提取记忆评估显示记忆比 CPT 更易提取训练数据，这在部署中存在隐私和合规风险，论文未讨论缓解方法。

### 客观性与风险偏差

- α 在验证集上调后用于测试，虽常见但存在轻微的过拟合验证集风险。
- 某些任务（如 BioInst 中部分 MCC 类任务）基线分数接近零甚至为负，记忆的绝对提升幅度虽大，但实际绝对分数仍偏低（如 20–30 分区间），实际应用价值需要谨慎解读。
- 论文部分基线（Qwen3-14B 的 CPT、LoRA 结果缺失）未报告，削弱了与最强基线的完整对比。

---

## 总评

本工作将参数化长期记忆从百万 token 的小规模验证推进到 300B tokens 的语言模型预训练规模，提出了有效的分布式检索工程方案，并以大量实验系统性证明"独立扩展记忆比扩展骨干更参数高效"的核心主张。方法模块化设计优雅，实验丰富且较为公平，是记忆增强语言模型方向的重要进展。主要不足在于离线预处理成本、固定插值系数、以及隐私风险和领域覆盖有限等问题未完全解决。
