## 摘要
AI编码代理越来越多地以开发者的个人账户提交拉取请求（PR），模糊了变更的实际作者身份。可靠的归属对于仓库治理、AI辅助软件开发的实证研究以及衡量AI编码代理的影响至关重要。现有工作集中于已知代理的封闭集识别，而开放世界中AI编码代理归属的实际边界在很大程度上尚未被探索。在本文中，我们提出了AgenTag，一个用于开放世界AI编码代理归属的多模态框架，并在AIDev上进行了评估，该数据集包含来自五个AI编码代理的33,580个PR和6,618个由人类编写的PR。我们使用基于文本、行为和代码的多模态表示每个PR，并比较了传统分类与监督对比学习在开放集识别和少样本注册未见代理方面的表现。AgenTag在识别编写代理时实现了0.96的加权F1分数（宏F1为0.84），在区分AI生成与人类编写的PR时实现了0.89的平衡F1分数，并在检测未见代理时实现了0.84的AUC。我们进一步表明，PR描述和提交消息几乎提供了所有的归属信号，而代码差异在各种表示下贡献甚微，这表明编码代理主要通过其沟通变更的方式而非生成的代码来区分。此外，这些行为指纹在移除明确的自我披露标记后仍然存在，表明归属主要依赖于潜在的风格特征。这些发现表明，对AI编码代理的可靠归属是可行的，并阐明了归属准确性与实现该目标所需信息之间的实际权衡。

## Abstract
AI coding agents increasingly author pull requests (PRs), often under developers' own accounts, obscuring who actually produced a change. Reliable attribution is important for repository governance, empirical studies of AI-assisted software development, and measuring the impact of AI coding agents. Existing work focuses on closed-set identification of known agents, leaving the practical limits of open-world AI coding agent attribution largely unexplored. In this paper, we present AgenTag, a multimodal framework for open-world AI coding agent attribution, evaluated on AIDev, comprising 33,580 PRs from five AI coding agents and 6,618 human-authored PRs. We represent each PR using textual, behavioral, and code-based modalities, and compare conventional classification with supervised contrastive learning for open-set recognition and few-shot enrollment of previously unseen agents. AgenTag identifies authoring agents with a weighted F1 of 0.96 (macro F1 of 0.84), distinguishes AI- from human-authored PRs with a balanced F1 of 0.89, and detects previously unseen agents with an AUC of 0.84. We further show that PR descriptions and commit messages provide nearly all of the attribution signal, whereas code diffs contribute little across multiple representations, indicating that coding agents are distinguished primarily by how they communicate changes rather than by the code they generate. Moreover, these behavioral fingerprints persist after removing explicit self-disclosed markers, demonstrating that attribution relies largely on latent stylistic characteristics. These findings show that reliable attribution of AI coding agents is feasible and clarify the practical trade-offs between attribution accuracy and the information required to achieve it.

### 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：AI 编码代理（如 OpenAI Codex、GitHub Copilot、Devin、Cursor、Claude Code）正在大量生成 Pull Request（PR）。这些代理常常在开发者自己的账号下提交 PR，导致"提交者身份"无法真实反映"代码作者身份"。

- **核心研究问题**：能否在开放世界（open-world）场景下，仅从 PR 公共工件出发，可靠地归属 AI 编码代理的身份？归属信号究竟来源于代码本身，还是来源于代理的沟通与行为风格？

### 2. 方法论：AgenTag

#### （1）核心思想

将 AI 编码代理归属问题重新定义为**多模态、可学习的开放世界问题**，而非传统的封闭集分类任务。AgenTag 学习一个监督对比度量空间，使同一代理的 PR 在嵌入空间中聚集，不同代理的 PR 互相分离，从而支持身份识别、未见代理检测以及少样本注册。

#### （2）四种信号模态

| 模态 | 内容 | 获取成本 |
|------|------|----------|
| PR 文本 | 标题 + 描述 | 随 PR 自带 |
| 提交消息 | 全部提交消息拼接 | 需获取 commit 历史 |
| 代码 diff | 新增代码行 | 需获取 patch |
| 行为特征 | 53 个特征（经相关性过滤后为 41 个），涵盖提交模式、PR 结构、代码变更形态、patch 特征、时间行为 | 需元数据 |

#### （3）表示与编码

- PR 文本与提交消息：用 Sentence-BERT（`all-MiniLM-L6-v2`）编码，标题与描述分别编码后拼接（768 维）。
- 代码 diff：用三类 encoder 对比评估——通用句编码器、CodeBERT 风格代码搜索编码器、GraphCodeBERT 结构感知编码器（取前 4000 字符，均值池化）。
- 行为特征：标准化处理，避免单一特征尺度主导。
- 多模态融合：各流向量拼接。

#### （4）度量空间学习

- 使用**监督对比学习**（Supervised Contrastive Learning）将表示映射到 128 维嵌入空间，使同类 PR 靠近、异类 PR 远离。
- 推理阶段：以余弦相似度将 PR 分配给最近训练质心（prototype）。
- 开放集识别：当 PR 与所有已知质心都相距过远时，标记为"未见代理"。
- 少样本注册：新代理通过少量（10 个）标注 PR 的质心加入模型，无需重训练。

#### （5）显式标记剥离

为区分"潜在行为指纹"与"自我披露水印"，设计了三级剥离策略：
- **Tier 1**：剥离结构化 trailer（如"Co-authored-by"、"Generated with"）；
- **Tier 2**：剥离工具 URL 与厂商模板（如 Devin 会话链接、Copilot 模板头）；
- **Tier 3**：剥离残留的工具名称提及。

剥离在特征提取之前进行，防止 trailer 被误计为行为特征。

  - OpenAI Codex：21,793（64.9%）

  - Claude Code：458（1.4%）

- 默认使用 **5 次重复 5 折分层交叉验证**（25 个训练-测试估计），报告 95% 置信区间。

- 统计检验使用 Nadeau-Bengio 校正配对 t 检验（校正重复 CV 的依赖性问题）。

### 6. 主要结论与发现

1. **识别精度**：加权 F1 达 **0.96**（宏 F1 0.84）；三个多数代理近乎完美（Codex 0.98、Copilot 0.98、Devin 0.90），两个少数代理偏低（Cursor 0.78、Claude Code 0.56）。
2. **信号来源逆转**：PR 描述与提交消息几乎贡献全部归属信号（0.890），代码 diff 是最弱模态（0.589），且四种代码表示一致表现不佳。这**反转了人类作者归属研究的结论**（人类领域代码风格是主导信号）。
3. **潜在行为指纹**：剥离 trailer、工具 URL、模板和名称后，加权 F1 仅下降 0.026（0.947 vs. 0.973）；仅靠代理名称的正则能达到 0.65，但模型不需要它——名称是"冗余"而非"无信息"。
4. **AI 与人类可区分**：平衡 F1 达 0.89（仅 PR 文本 0.85），在共享仓库 + 仓库不相交的严格条件下仍保持 0.81。
5. **数据集污染**：至少 **5.0%** 的 AIDev"人类"PR 含显式 AI 归属标记；无标记分类器将显式披露率从基线 5.0% 富集至高置信区间的 39.1%（7.7×），证实标签噪声真实存在。
6. **开放世界能力**：未见代理检测 AUC 达 0.837（非学习基线 0.756）；10-shot 注册后宏 F1 为 0.674（基线 0.595）。
7. **行为签名可解释**：Codex 在所有文本长度维度上极简（δ = −0.62 至 −0.75）；Copilot 97% 的 PR 以 "Initial plan" 提交开头；Claude Code 提交消息最结构化（δ = +0.81）。

### 7. 优点与亮点

- **问题定义完整**：将归属问题从封闭集分类推进到开放世界识别 + 少样本注册，贴合实际部署场景。
- **多模态系统设计**：四种模态覆盖沟通、行为、代码与元数据，且对各模态的获取成本做了显式分层，实用性导向明确。
- **对标签循环性的警惕**：识别出 Claude Code 标签与 trailer 完全重合的问题，并主动剥离标记，同时单独量化标记贡献，避免"模型复读标签"的方法论陷阱。
- **测量选择敏感性分析**：明确指出三个会颠倒结论的测量选择——剥离须在特征提取前完成、注册代理须与已知代理同场评分、剥离须覆盖 URL/模板/名称而非仅 trailer——并将此作为独立的可复用方法论贡献。
- **标签污染审计设计巧妙**：用"标记盲分类器在高置信区间的显式披露富集率"作为验证，将循环性估算（上限）与标记计数（下限）互相印证。
- **统计严谨**：使用校正重采样 t 检验、Cliff's delta 效应量、宏/加权/每类 F1 多重报告，并对不稳定估计显式标注可读性边界。

### 8. 不足与局限

- **外部效度受限**：仅覆盖 GitHub 平台、AIDev 快照、5 个编码代理；结论不一定推广到私有仓库、其他平台或未来新代理。
- **时间漂移风险**：七个月内宏 F1 已从 0.805 降至 0.749（Claude Code 降至 0.433），表明指纹是版本相关的而非内在属性；模型需周期性重新验证。
- **代码模态可能被低估**：编码时仅取前 4,000 字符、均值池化、未做 AST 解析或任务微调；虽然 4 种编码器表现一致偏低，但仍无法完全排除更强结构编码器提升代码信号的可能性。
- **对抗规避风险**：论文承认有动机的对手可通过系统提示或项目文件（如 `CLAUDE.md`）要求代理模拟人类风格来降级识别，且该规避成本低于修改工具本身。
- **少数类性能弱**：Cursor 和 Claude Code 的 F1 明显偏低，Claude Code 在剥离标记后仅为 0.446；少数类的开放集 AUC 与跨语言泛化估计不稳定。
- **AI 与人类检测的混淆控制不完美**：人类 PR 的 commit/diff 由作者自行采集，存在采集偏差风险（虽以 PR-text-only 结果缓解）；仓库匹配按 star 数而非全部特征。
- **算力信息缺失**：未披露训练资源与能耗，不利于复现成本评估。
