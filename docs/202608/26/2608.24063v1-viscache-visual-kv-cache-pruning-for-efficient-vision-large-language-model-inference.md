## 摘要
尽管视觉大语言模型（VLLMs）在多模态推理中取得了显著成功，但由于视觉键值（KV）缓存巨大的计算和内存开销，其长上下文推理仍然代价高昂。现有的KV压缩方法通常对视觉标记和层进行统一剪枝，导致大量信息丢失和性能下降。为了解决这一挑战，我们提出了VisCache，一种无需训练的即插即用框架，用于从粗到细的视觉KV缓存剪枝，它由两个协同阶段组成。首先，一个轻量级VLM通过选择性地转发具有语义信息的关键帧来过滤时间冗余。其次，我们引入了PruneKV，一种针对VLLM注意力动态量身定制的外科手术式KV压缩算法。与刚性剪枝策略不同，PruneKV采用抛物线式的逐层预算分配以及不对称更新机制，该机制选择性地剪枝键并融合值，从而保留关键上下文信息。大量实验表明，VisCache显著提高了推理效率，实现了高达2.35倍的加速和显著的内存减少，同时仅保留19%-28%的KV缓存即可保持有竞争力的性能。VisCache持续优于现有基线，为长上下文VLLM推理建立了效率与性能之间的新帕累托前沿。代码可在https://github.com/Wlklk/VisCache获取。

## Abstract
While Vision Large Language Models (VLLMs) have achieved remarkable success in multimodal reasoning, their long-context inference remains prohibitively expensive due to the massive computation and memory overhead of visual Key-Value (KV) caches. Existing KV compression methods often apply uniform pruning across visual tokens and layers, leading to substantial information loss and degraded performance.To address this challenge, we propose \textbf{VisCache}, a plug-and-play framework for coarse-to-fine \textbf{Vis}ual KV \textbf{Cache} pruning without training, which consists of two synergistic stages. First, a lightweight VLM filters temporal redundancy by selectively forwarding semantically informative keyframes. Second, we introduce {PruneKV}, a surgical KV compression algorithm tailored to the attention dynamics of VLLMs. Unlike rigid pruning strategies, PruneKV adopts a parabolic layer-wise budget allocation together with an asymmetric update mechanism that selectively prunes keys while fusing values, thereby preserving critical contextual information. Extensive experiments demonstrate that VisCache substantially improves inference efficiency, achieving up to {2.35$\times$ speedup} and significant memory reduction while maintaining competitive performance with only {19--28\%} KV cache retention. VisCache consistently outperforms existing baselines, establishing a new Pareto frontier between efficiency and performance for long-context VLLM inference. Code is available at https://github.com/Wlklk/VisCache

## 2. 方法论：核心思想、技术细节与流程

VisCache 框架由两个协同阶段构成：**推理前的粗粒度关键帧过滤** + **推理过程中的细粒度 KV 压缩**。

### 2.1 阶段一：基于 Prompt 感知的探针关键帧过滤（Scout-based Temporal Filtering）

**核心思想**：在视觉 token 进入 VLLM 之前，先从时间维度去除冗余帧。

- 使用轻量级视觉-语言模型（如 CLIP）作为 "scout" 探针模型；
- 将文本提示（prompt）和视频帧分别编码到共享语义空间；
- 通过 **最大边际相关性（MMR）** 准则迭代选择关键帧，兼顾两个目标：
  1. 与提示的语义相关性（relevance）；
  2. 帧间的多样性（diversity）。

**MMR 分数公式**：

```
MMR(f) = λ · sim(h_f, h_t) − (1 − λ) · max_{f′ ∈ Ω} sim(h_f, h_f′)
```

- λ 控制相关性与多样性之间的权衡；
- 迭代选择最高分帧，直至达到目标保留率 p。

### 2.2 阶段二：PruneKV——层级感知的视觉 KV 缓存压缩

PruneKV 围绕两个核心设计原则展开：

#### (1) 抛物线式逐层预算分配（Parabolic Budget Allocation）

- 观察发现：浅层保留更多细节视觉信息，深层多为抽象语义；
- 因此采用抛物线递减策略分配每层 KV 预算：

```
b_l = 1 − (l−1)² / [2(h−1)²]
```

满足 b₁ = 1，b_h = 0.5；即浅层和中层保留更多 token，深层更激进压缩；

- 引入截断层 h（默认 h = 3L/4），超过该层的视觉 KV 条目被完全丢弃（whole-layer eviction）；
- 目标保留比例由全局约束 Σb_l = h·m 控制。

#### (2) 共享全局排序（Shared Global Token Ranking）

- 视觉 token 重要性通过跨层聚合注意力分数获得：

```
s_v = (1/L) Σ_l Σ_i A^(l)_{i,v}
```

- 同一重要性排序用于所有层，各层根据自身预算截取 top-kᵢ 的 token；
- 实验证明共享全局排序优于逐层独立排序（3B 模型上平均准确率提升约 1.4 个百分点）。

#### (3) 非对称键值更新（Asymmetric Key-Value Update）

这是 PruneKV 最具特色的设计。核心洞察：**Key 负责相关性选择，Value 负责信息承载**。

- 对于被丢弃的 token（drop set C_d）：
  - **Key 彻底删除**：其注意力贡献本来就较低；
  - **Value 不清除，而是融合**：通过相似性加权聚合重分配给保留的 token。
- 具体实现：利用值之间的相似度构建重分配矩阵 Φ，再按权重融合：

```
Φ = Softmax(V_k V_d^T / τ)
V_new = μ · V_k + (1 − μ) · ΦV_d
```

- μ 为融合强度（默认 0.7），τ 为温度参数。

### 2.3 算法流程（PruneKV）

```
输入：视觉 KV cache {(K_l, V_l)}，注意力分数 {A_l}，截断层 h，保留率 m，融合强度 μ
Step 1: 所有层注意力分数取平均 → 聚合每个视觉 token 的重要性
Step 2: 按抛物线公式计算各层预算 {b_l}
Step 3: 对每个层 l ∈ [1,h]：
    - 划分 keep set C_k（top-b_l）和 drop set C_d
    - 保留 C_k 的键向量；删除 C_d 的键向量
    - 计算重分配矩阵 Φ，融合 C_d 的值到 C_k 中
输出：压缩后的视觉 KV cache
```

### 2.4 整体流程

```
输入视频帧 + 文本提示
→ Scout（轻量级 VLM + MMR）筛选关键帧
→ VLLM Prefill（仅对关键帧编码）、生成 KV cache
→ PruneKV（注意力打分 → 抛物线预算分配 → 非对称键值压缩）
→ VLLM Decode（使用压缩后的 KV cache 自回归生成）
```

## 6. 主要结论与发现

### 6.1 核心结论

1. **效率提升显著**：仅保留 19%–28% 的视觉 KV cache，VisCache 即可实现最高 2.35× 推理加速，FLOPs 降低至原始计算的 6%–10%。

2. **性能保持具备竞争力**：
   - 3B 模型在 28% RR 下平均准确率 45.64%，**超过全缓存**（44.16%）；
   - 32B 模型在 28% RR 下平均准确率 56.86%，最接近全缓存性能（57.46%），超越所有同 RR 基线；
   - 最激进的 19% RR 下仍保持约 44.85% 的平均准确率，优于多数基线在 40% RR 下的表现。

3. **抛物线预算优于算术/几何/均匀分配**：在相同 RR 下，抛物线分配的 VQA 平均准确率显著更高，尤其在极限压缩场景下优势更明显。

4. **非对称键值更新有效**：裁剪键的同时融合值，比直接剪除 KV 对具有更好的信息保持能力；在抛物线/算术/均匀预算下均带来正向收益。

5. **共享全局排序优于逐层独立排序**：跨层聚合注意力提供了更稳定的重要性估计。

6. **两阶段协同增益明显**：仅用 Scout 或仅用 PruneKV 都有性能损失，两者组合在所有 RR 下均达到最优性能。

7. **可迁移性好**：对 Qwen3-VL 和 LLaVA-OneVision 同样有效，说明方法不依赖于特定模型架构。

### 6.2 其他重要发现

- 与 KV 量化方法兼容：VisCache + 4-bit 量化（KIVI/FlatQuant）能在进一步降低内存的同时保持竞争性性能；
- Scout 模型的选择影响性能：CLIP 与 OpenCLIP 优于 BLIP，且 scout 与主模型的语义对齐程度是关键因素；
- Token 输出越长，VisCache 的时间节省越明显：

- 因为 KV cache 一经预填充即被压缩，后续每个生成步骤（decode 阶段）都受益于更小的 KV 读取与注意力计算，所以生成长度越长，累计节省的时间和显存带宽收益越显著；
- 在 DREAM1K（长生成任务）上，端到端加速比高于 ActCap，验证了“压缩发生在 prefill 后，解码阶段重复利用压缩结果”这一设计带来的复利效应。

## 7. 局限性与未来工作

### 7.1 局限性

1. **关键帧筛选引入额外开销**：Scout 模型需对全部输入帧进行一次额外编码（尽管使用了轻量级 CLIP），在帧数极大时仍会带来可测的延迟；论文未报告 scout 推理占端到端时间的比例。

2. **对时间维度高度敏感的任务存在风险**：MMR 的多样性项可能丢弃时间连续性强但语义变化微小的关键帧，这对细粒度动作识别或时序因果推理可能造成不可逆信息损失。

3. **注意力分数作为重要性代理并非无懈可击**：聚合注意力只能反映“历史查询对视觉 token 的关注”，无法捕捉未来生成过程中可能产生的新注意力需求；若后续查询需要先前被裁剪的信息，则无补偿机制。

4. **评估范围仍有局限**：未涉及多图交错输入、视频+音频等多模态联合场景，也尚未在更大规模（如 70B+）模型上验证。

### 7.2 未来方向

- 设计能随解码动态调整的“在线”KV 重分配策略，以便在生成过程中根据实时注意力变化微调压缩结果；
- 将 scout 关键帧选择与主模型联合蒸馏，训练专用的轻量级帧选择器，消除额外推理开销；
- 探索将非对称键值更新扩展到通用 KV cache 剪枝（包括文本 KV），而不仅限于视觉 token；
- 结合结构化稀疏或 MoE 路由，进一步压缩跨层共享冗余。

## 8. 总体评价

VisCache 的核心贡献在于提出了一种**同时利用时间冗余、层级异质性和键值功能不对称性**的粗到细视觉 KV cache 压缩框架，其价值体现在三个层面：

- **方法论层面**：通过“轻量级 scout 预筛选 + 抛物线预算分配 + 共享注意力排序 + 非对称键值更新”的组合，系统性地将视觉信息结构先验注入 KV 压缩过程，突破了以往粗粒度、无差别剪枝的局限。

- **工程层面**：免训练、即插即用、与量化和现有剪枝方法兼容的定位，使其可以在不修改模型权重的情况下直接部署到现有 VLLM 推理框架中，工程落地成本低。

- **实验层面**：在高压缩率下做到“不降反升”的性能（3B 模型 28% RR 下超越全缓存），且跨模型、跨数据集、跨基线均取得一致优势，结论可信度较高。

总体而言，VisCache 是长视频 VLLM 高效推理领域一项扎实且具有实用价值的工作。其“粗过滤定时间、细压缩控空间”的级联思想，以及“Key 删、Value 融”的非对称策略，为后续研究提供了清晰且可扩展的设计范式。
