## 摘要
智能体检索增强生成（RAG）要求语言模型决定何时继续搜索以及何时作答。现有的基于强化学习的方法依赖外部监督，忽视了智能体关于当前证据是否充分的内部信念。为解决这一问题，我们将搜索决策质量重新表述为信念-行动对齐，并提出了MetaRAG，一种面向智能体RAG的信念-行动对齐策略优化框架。MetaRAG采用先验证后行动生成（Verify-first Action Generation）在每个实际动作之前引出显式验证过程，并通过内部信念探测（Internal Belief Probing）从相同的问题-历史上下文中估计策略模型自身的可回答性信念。在此基础上，MetaRAG推导出一致性奖励，并进一步以答案正确性为门控，避免强化内部一致但错误的轨迹。信念探针仅在训练期间使用，不引入推理时开销。在七个公开问答基准上的实验表明，MetaRAG在准确性-效率权衡上持续优于基于强强化学习的智能体RAG基线，且其收益可迁移至深度研究场景、不同优化器以及多种模型主干。

## Abstract
Agentic retrieval-augmented generation (RAG) requires language models to decide when to continue searching and when to answer. Existing RL-based methods rely on external supervision and overlook the agent's internal belief about whether the current evidence is sufficient. To address this problem, we reformulate the search decision quality as belief-action alignment and propose MetaRAG, a belief-action aligned policy optimization framework for agentic RAG. MetaRAG uses Verify-first Action Generation to elicit an explicit verification process before each actual action, and Internal Belief Probing to estimate the policy model's own answerability belief from the same question-history context. Based on these, MetaRAG derives a consistency reward that is further gated by answer correctness, avoiding reinforcement of internally consistent but incorrect trajectories. The belief probe is used only during training and introduces no inference-time overhead. Experiments on seven public QA benchmarks show that MetaRAG consistently improves the accuracy-efficiency trade-off over strong RL-based agentic RAG baselines, with gains that transfer to deep research settings, different optimizers, and multiple model backbones.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**

- **问题定义**：智能体 RAG（Agentic Retrieval-Augmented Generation）要求语言模型在回答复杂知识密集型问题时扮演"搜索智能体"角色——自主决定是否继续检索、何时产出最终答案。每一次 Search/Answer 决策都涉及证据充分性与检索成本之间的权衡，因此 SEARCH/ANSWER 决策边界是智能体 RAG 的核心问题。
- **现有方法的缺陷**：
  - **基于结果的监督**（如 Search-R1）仅提供最终答案层面的稀疏奖励，对中间搜索决策缺乏有效指导。
  - **外部裁判过程监督**（如 HiPRAG）依赖昂贵的 LLM 裁判或因果干预来诊断 over-search（过度搜索）和 under-search（欠搜索），成本高且规模化受限。
  - **通用步骤级信用分配**（如 GiGPO）虽能抑制冗余检索，但不显式针对过早作答问题。
- **核心洞察**：现有方法都从外部监督搜索决策，却**忽略了智能体自身关于证据是否充分的内部信念**。智能体可能在已"相信"证据充分时仍继续检索（over-search），或在已"相信"证据不足时提前作答（under-search）——即决策行为与内部信念脱节。

**总体含义**：论文提出将搜索决策质量重新表述为"信念-行动对齐（Belief-Action Alignment）"，将 over-search 和 under-search 统一为同一枚硬币的两面——内部信念与实际行动之间的失配。

## 2. 论文提出的方法论

**核心思想**：在强化学习训练过程中，显式探测策略模型自身的可回答性信念（answerability belief），并将其与实际 Search/Answer 动作进行对比，从而生成轻量级的步骤级决策监督信号，引导策略校准搜索边界。该框架包含四个关键组件：

**（1）Verify-first Action Generation（先验证后行动生成）**
- 每个决策步骤首先提出一个候选动作类型（SEARCH 或 ANSWER），然后要求模型在执行实际动作前进行"验证优先推理"（Verify-before-Action Reasoning）。
- 候选动作被视为"决策假设"而非强制标签，模型可通过验证后接受或拒绝。
- 该机制在训练和推理阶段均使用，使证据充分性判断在每个决策前被显式化。

**（2）Internal Belief Probing（内部信念探测）**
- 对相同的"问题与历史"上下文，额外执行一次独立的 Yes/No 前向传递（同策略模型，非外部裁判）。
- 构念：取 "Yes" 和 "No" 两个词符的 next-token logits，经 softmax 归一化后计算信念分数：
  - **bt = P(Yes) − P(No) ∈ [−1, 1]**
- bt 越大表示模型认为当前上下文越可回答。信念探针**仅用于训练时的奖励计算，推理阶段无任何额外开销**。

**（3）Belief-Action Gap Diagnosis（信念-行动差距诊断）**
- 设 margin m，定义三个区域：bt > m（置信可回答）、bt < −m（置信不足）、|bt| ≤ m（边际区间，信号不确定）。
- 二值一致性指示器：
  - bt > m 且 αt = ANSWER → **OPTIMAL**（ot = 1）
  - bt < −m 且 αt = SEARCH → **OPTIMAL**（ot = 1）
  - bt > m 但 αt = SEARCH → **OVER-SEARCH**（ot = 0）
  - bt < −m 但 αt = ANSWER → **UNDER-SEARCH**（ot = 0）
  - 边际区间 → ot = 0

**（4）Consistency Reward Calculation（一致性奖励计算）**
- 步骤级一致性奖励：**Rconsist(τ) = (1/Tτ) Σ ot**
- 总奖励：**Rtotal(τ) = Routcome(τ) · (1 + λ·Rconsist(τ))**
  - Routcome 为最终答案的 EM（精确匹配）正确性指示器；
  - 乘以 Routcome 起到**正确性门控**作用：即使轨迹在内部信念与动作上高度一致，只要答案错误则总奖励为零，防止"自信地停止检索"等奖励作弊行为。
- 最终 Rtotal 作为标量奖励输入下游 RL 优化器（如 GRPO、DAPO、PPO）。

## 6. 论文的主要结论与发现

1. **一致性的准确率-效率优势**：MetaRAG 在 Qwen2.5-3B 上平均准确率 41.7%（超过最强基线 GiGPO 39.8% 达 1.9 个百分点），在 Qwen2.5-7B 上 45.4%（超过 GiGPO 43.9% 达 1.5 个百分点），且收益并非来自盲目增加检索次数。
2. **对比 HiPRAG**：MetaRAG 在更低搜索次数的同时实现更高准确率，显示内部信念信号可替代昂贵的外部 LLM 裁判过程监督。
3. **缓解欠搜索**：训练过程中 MetaRAG 的欠搜索率在约 100 步后持续低于 GiGPO；外部 LLM 裁判验证显示其欠搜索率从 35.6% 降至 30.1%（绝对降幅 5.5 个百分点）。
4. **增强知识边界感知**：标准 agentic RAG 训练（Search-R1、HiPRAG、GiGPO）会削弱模型区分可回答/不可回答问题的能力（AUROC/PRR 均低于基础模型），而 MetaRAG 将 AUROC 从 59.5 提升至 60.2、PRR 从 20.5 提升至 21.8。
5. **零样本迁移**：在 BrowseComp-Plus 深度研究场景中，MetaRAG 在 7B 级搜索智能体中取得最佳准确率（3.49%）和最高证据召回率（3.73%），逼近 Qwen3-32B 的准确率水平。
6. **框架通用性**：在 DAPO 优化器下依然优于 GiGPO，在 Llama3.2-3B 和 Qwen3-14B 等不同骨干上均表现一致，表明信念-行动对齐是稳健的奖励设计原则而非特定优化设置的产物。

## 7. 优点

- **方法创新性**：首次将智能体 RAG 的搜索决策质量形式化为"信念-行动对齐"，将 over-search 与 under-search 统一为同一决策边界失配问题的两个方向，为搜索-回答边界校准提供了新的理论视角。
- **无需外部监督**：诊断信号完全来自策略模型自身的内部信念，免除了 HiPRAG 式外部 LLM 裁判的高昂成本，具备良好的规模化潜力。
- **推理零开销**：信念探针仅在训练期间使用，推理阶段无额外前向传递，保留了部署效率。
- **正确性门控设计**：通过 Routcome × (1 + λRconsist) 的乘性门控有效防止了"内部一致但错误"的奖励作弊行为，消融实验表明包含错误轨迹会显著损害性能。
- **消融实验严谨**：从组件必要性、诊断信号选择、候选动作策略等多维度进行系统验证；并通过"GiGPO w/ VF-Inf"对照，证明了收益源于训练机制而非更强的推理提示。
- **鲁棒性验证充分**：覆盖多种优化器、模型家族、模型规模、更深度的研究场景以及替代信念探针实现，增强了结论的普适性。

## 8. 不足与局限

- **训练计算开销**：虽比 HiPRAG 轻量得多，但仍比 GiGPO 慢约 13%（单步 281s vs 249s），主要来自 verify-first 推理的生成长度增加和训练时信念探针的额外前向传递。
- **推理延迟略增**：verify-first 推理使每轮响应变长，推理时间高于 GiGPO（0.1453s vs 0.1179s/查询），尽管差距不大。
- **场景覆盖有限**：实验聚焦于 Search/Answer 决策的问答型智能体 RAG，未监督搜索查询的词汇质量、生成理由的忠实度、以及超出检索-回答之外的多工具使用、开放式浏览、长视界规划等更复杂智能体行为。
- **信念信号的内在局限**：使用内部信念本身作为监督信号存在潜在的循环性担忧（论文通过外部 LLM 裁判验证部分缓解了此问题）；信念探针的准确性受模型校准质量限制，且不同实现（如 Internal Confidence）的效果存在差异。
- **绝对准确率仍有限**：在深层研究基准上即使最优模型准确率也仅 3.49%（基础模型 Qwen3-32B 为 3.61%），说明 7B 级模型在复杂任务上的整体能力仍较弱，改进空间巨大。
- **外部裁判验证的范围**：附录中 LLM-as-judge 验证仅针对终局 ANSWER 步骤的欠搜索判断，未对搜索步骤的过度检索做外部验证。

## 8. 不足与局限（续）

- **实验结果报告的标注问题**：部分基线数据来源于其他文献（Xia et al., 2026），GiGPO 数据为复现所得，跨论文数据对比时可能存在轻微的设定差异（如检索器版本、段落截断长度、训练数据划分的细节不一致）。论文虽以 ‡ 标注复现结果，但未逐项说明与原文的差异来源，读者在横向对照时需谨慎。
- **信念阈值的静态性**：margin m 在实验中作为全局固定超参数（默认 0.0），但不同模型、不同数据分布下"置信—不确定—不足"的边界可能不同。静态阈值虽简化了实现，却可能限制信念信号在不同场景下的自适应性。
- **奖励信号的粒度**：一致性奖励以轨迹内所有决策步骤的平均一致性计算，对长轨迹中不同位置（早期探索 vs 后期收尾）的决策错误未做区分，可能将关键转折点的错误与次要冗余同等对待。

## 9. 对领域的影响与启示

- **方法论启示：从"外部裁判"转向"内部信念对齐"**。该工作的深层价值在于指出了一条区别于现有过程监督范式的路径——不是用更强大的外部模型去诊断智能体行为，而是让智能体的决策行为与其自身的认知状态保持一致。这一思路在概念上更接近"自我一致性"（self-consistency）与"诚实对齐"（honest alignment）的研究脉络，对后续智能体训练中如何利用模型内在状态（如隐层置信度、token 概率、内部指标）设计轻量级奖励信号具有启发意义。
- **对 Agentic RAG 训练范式的贡献**：将"是否继续检索"从启发式策略问题转化为可优化的对齐问题，使得搜索边界可以通过强化学习端到端地学习。这一框架天然兼容不同的 RL 优化器（GRPO/DAPO/PPO）和不同的模型主干，具有较强的即插即用属性，可能成为智能体 RAG 训练的重要设计范式之一。
- **对成本-性能权衡的示范**：论文展示了如何在不大幅增加训练成本、完全不增加推理成本的前提下获得稳定的性能增益，这对资源受限的研究团队和实际产业部署都有参考价值。
- **值得追踪的后续方向**：论文提到的"将信念-行动对齐推广到查询质量监督与理由忠实度验证"是自然延伸——例如模型是否"相信"当前查询能返回有用信息、是否"相信"已检索段落支持其生成的推理依据等。若该框架能覆盖更多智能体行为维度，其影响力将远超 Search/Answer 决策本身。

## 10. 总体评价

MetaRAG 是一篇方法思路清晰、实验设计扎实的智能体 RAG 训练工作。其核心贡献不在于提出更复杂的架构或更强的外部监督，而在于一个简洁而深刻的洞察：**智能体搜索决策的质量，可以由其内部信念与外部行动的一致性来度量**。通过一个近乎零成本的信念探针，论文将 over-search 与 under-search 统一为可优化的对齐目标，在多个基准上取得了优于外部裁判过程和通用信用分配方法的稳定结果，且不引入推理开销。

从学术严谨性看，论文的消融体系（组件、信号、候选策略、超参数、优化器、模型骨干、深度研究场景迁移、外部裁判交叉验证）覆盖面广，逻辑链条完整，显著增强了结论的说服力。从局限性看，其评估场景仍集中于问答型检索-回答智能体，信念信号本身的可靠性和静态阈值的适应性也存在提升空间。

总体而言，这是一篇在"轻量级过程监督"方向上具有代表性和可借鉴性的高质量工作。它提醒研究者：在追求更强大的外部监督信号之前，或许值得先审视智能体自己"知道什么、相信什么"——内部信念的校准本身，可能就是通往更高效、更可解释智能体训练的一把钥匙。
