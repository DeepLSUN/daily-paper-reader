## 摘要
多智能体系统（MAS）的自动化演进在减少设计和优化基于LLM的智能体架构所需的人工投入方面具有巨大潜力。然而，现有的基于搜索的范式面临一个基本权衡：扩大优化范围会加剧演进的不稳定性，而离散的分支丢弃式搜索则会将各条演进线中的见解相互隔离。为解决这些局限，我们提出了一种基于统一ReAct基础设施的连续数据驱动优化范式，该范式在广泛的优化范围与运行稳定性之间取得了调和。在此范式下，我们提出了OptiMAS，一种任务无关的智能体优化器，利用文本交互轨迹和任务反馈作为端到端MAS演进的损失信号。凭借新颖的双轨记忆机制，OptiMAS能够在更长的优化周期内持续保持性能提升。在四个异构智能体基准上，使用三种不同规模和可访问性的LLM骨干网络进行评估，结果表明，OptiMAS相对于领域特化的手工构建系统以及现有演化方法，均能持续取得具有竞争力或更优的准确性。我们的工作为稳健的自动化MAS演进树立了一个切实可行的里程碑。

## Abstract
Automated evolution of Multi-Agent Systems (MAS) holds significant potential for reducing the manual effort required to design and optimize LLM-based agent architectures. However, extant search-based paradigms face a fundamental trade-off, where an expanded optimization scope exacerbates evolutionary instability, while discrete branch-and-discard search isolates insights across lineages. To address these limitations, we propose a continuous, data-driven optimization paradigm built upon a unified ReAct-based infrastructure that reconciles a broad optimization scope with operational stability. Under this paradigm, we present OptiMAS, a task-agnostic agentic optimizer that leverages textual interaction trajectories and task feedback as loss signals for end-to-end MAS evolution. Equipped with a novel dual-track memory mechanism, OptiMAS sustains performance improvement over extended optimization horizons. Evaluation on four heterogeneous agentic benchmarks with three varying scale and accessibility LLM backbones, demonstrates that OptiMAS consistently achieves competitive or superior accuracy relative to both domain-specialized hand-crafted systems and existing evolutionary methods. Our work establishes a practical milestone toward robust, automated MAS evolution.

## 2. 方法论

### 2.1 核心思想

- 将 MAS 演化从“离散搜索”重新定义为“连续优化”：以 MAS 的执行轨迹和任务反馈作为损失信号，由智能体优化器生成“文本梯度”，端到端地更新 MAS 配置，从而实现单调、累积的性能提升。

### 2.2 统一 ReAct 基础设施

- **ReAct Agent 作为原子执行单元**：每个 agent 循环执行“思考 → 动作 → 观察”，轨迹记为 S = (P, τ₁, a₁, o₁, ..., τᵢ, aᵢ, oᵢ)，由策略 πM 生成。
- **主动分配-交付协议（Proactive Assign-Deliver）**：父 agent 将子任务作为工具调用委托给子 agent，子 agent 返回结构化结果，agent 按需激活而非固定流程，提高灵活性和可扩展性。
- **广谱优化范围**：MAS 配置包括 E = {A, G(A), (M_A, P_A, K_A, T_A)}，涵盖 agent 群体、编排图（DAG）、LLM 骨干、提示词、技能库和工具集。
- **稳定性保障**：工具从预定义宏库组合而非从零生成代码，编排图限定为有向无环图以保证可终止性。

### 2.3 连续优化流程（Algorithm 2）

1. **数据划分**：任务集分为 X_train、X_val、X_test，分别用于演化、泛化校准、最终评估。
2. **自适应采样（Algorithm 1）**：每个训练步从 X_train 中抽取 batch，优先重放上一步失败样本（比例 ϕ），其余用概率加权采样补充；权重按成功/失败进行 α/β 乘性更新，并有周期性重置。
3. **前向执行与评估**：当前 MAS E_{t-1} 在 batch 和 X_val 上执行，得到准确率 R_train、R_val 以及完整轨迹工作区 W_train。
4. **文本梯度反传**：OptiMAS 优化器检查工作区中的轨迹、中间产物等，进行根因分析，端到端地生成 MAS 修改指令并更新配置。
5. **循环演化**：重复至最大步数 T，返回最终演化后的 E*。测试集全程不可见。

### 2.4 双轨记忆机制

- **面向计划的短期记忆（Plan-oriented Short-term Memory）**：
  - 处理百万级 token 轨迹时，先制定结构化计划作为反传阶段的“骨架”，防止遗忘和幻觉漂移。
  - 计划状态包括 waiting、executing、completed、dropped；操作包括 add、modify、review、delete。
  - 禁止删除内容，不适用指令只能标记为 dropped 并附理由；步骤结束时执行程序化完整性检查，未完成指令必须继续处理。
- **假设驱动的长期记忆（Hypothesis-driven Long-term Memory）**：
  - 核心为闭环生命周期：PROPOSE → ENACT → VALIDATE / REFUTE / SUSPEND / DORMANT。
  - 每条假设包含分类、轨迹观察、文本梯度、修改动作和可证伪预期；所有 MAS 修改必须引用假设 ID，实现全程可追溯。
  - 该机制使演化变为有原则的自我修正优化，而非无方向试错。
