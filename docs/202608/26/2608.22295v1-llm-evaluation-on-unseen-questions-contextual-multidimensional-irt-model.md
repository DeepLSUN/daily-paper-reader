## 摘要
大语言模型（LLM）的评估日益需要在收集大量新标注之前，预测模型在新问题或新任务上的表现。这一问题具有挑战性，因为问题难度、情境和潜在能力需求可能差异显著。简单的回顾性平均值可能会混淆模型能力与题目特征。本文研究了一种基于模型的评估框架，该框架将多维项目反应理论模型与问题情境相结合，以预测LLM在未见问题上的表现。该框架通过潜在能力剖面表示LLM，同时利用问题内容为题目特征提供信息，使信息能够超越先前观察到的题目进行迁移。实验发现，在场景内评估中，引入问题嵌入相比无模型基线能改善预测，且多维潜在结构比单维替代方案能更丰富地描述能力差异。同时，我们的结果揭示了一个重要局限：在新场景迁移下，这种泛化能力不一定能转化为可靠的预测。这些发现表明，情境感知的心理测量建模是高效且可解释的LLM评估的一个有前景的方向，同时也凸显出跨场景泛化作为一个核心开放挑战。

## Abstract
Evaluation of large language models (LLMs) increasingly requires predicting how a model will perform on new questions or tasks before collecting large amounts of new annotations. This problem is challenging because question difficulty, scenario, and underlying capability demands can vary substantially. Simple retrospective averages may confound model ability with item characteristics. In this paper, we study a model-based evaluation framework that combines multidimensional item response theory model with question contexts to predict LLM performance on unseen questions. The framework represents LLMs through latent capability profiles while using question content to inform item characteristics, allowing information to transfer beyond previously observed items. Empirically, we find that for within-scenario evaluation, incorporating question embeddings improves prediction relative to model-free baselines, and that multidimensional latent structure provides a richer description of capability variation than unidimensional alternatives. At the same time, our results reveal an important limitation that the generalizability does not necessarily translate into reliable prediction under cross-scenario shift. These findings suggest that context-aware psychometric modeling is a promising direction for efficient and interpretable LLM evaluation, while also highlighting cross-scenario generalization as a central open challenge.

## 2. 论文提出的方法论

- **核心思想**：将 LLM 表示为**潜在能力剖面（latent capability profiles）**，同时利用**问题文本嵌入**为题目特征提供信息，通过双线性交互将模型侧能力与问题侧特征联系起来，从而实现对未见题目的预测。
- **模型形式（C-MIRT）**：
  - 设模型 \(i\) 在场景 \(s\) 中对问题 \(j\) 的作答正确概率为 \(\sigma(\theta_{ij}^{(s)})\)，其中：
    \[
    \theta_{ij}^{(s)} = \alpha_i^{(s)} + u_i^{(s)\top} \phi^{(s)}(e_j)
    \]
  - \(\alpha_i^{(s)}\)：模型 \(i\) 在场景 \(s\) 中的基线正确率（截距）；
  - \(u_i^{(s)} \in \mathbb{R}^r\)：模型 \(i\) 在场景 \(s\) 中的 \(r\) 维潜在能力向量；
  - \(\phi^{(s)}(e_j)\)：将问题嵌入 \(e_j\)（如 BERT 表示）映射到 \(r\) 维潜在题目特征空间的**特征映射**；
  - 双线性形式 \(u_i^{(s)\top} \phi^{(s)}(e_j)\) 捕捉模型能力与题目需求之间的多维交互。
- **与现有方法的区别**：
  - 相比 Truong et al. (2025) 的单维 Rasch 风格模型（仅用一个标量难度参数），C-MIRT 采用**多维双线性形式**，允许题目特征与模型能力在多个潜在上交互。
  - 相比 Lasso 逻辑回归（直接使用原始嵌入），C-MIRT 显式引入了**低秩潜在结构**，更具可解释性。
- **估计流程**（两阶段）：
  1. **第一阶段**：基于训练题目，拟合低秩 logistic 因子分解模型，估计 \((\alpha^{(s)}, U^{(s)}, V^{(s)})\)，并施加中心化约束与正则化项以保证可识别性；
  2. **第二阶段**：将第一阶段的估计题目因子 \(\hat{V}^{(s)}\) 作为回归目标，训练 MLP 参数化的映射 \(\phi^{(s)}\)（输入为题目嵌入 \(e_j\)）。
- **预测未见问题**：对目标场景 \(t\) 的新题目，使用 \(\hat{\theta}_{ij}^{(s\to t)} = \hat{\alpha}_i^{(s)} + \hat{u}_i^{(s)\top} \hat{\phi}^{(s)}(e_j)\) 计算预测概率。当 \(t=s\) 时为场景内预测，当 \(t \neq s\) 时为跨场景预测。

## 3. 实验设计

- **数据来源与 benchmark**：采用 Truong et al. (2025) 的 benchmark 设置，基于 5 个 HELM 仓库（Classic、Lite、AIR-Bench、Thai Exam、MMLU）的 22 个数据集，过滤掉描述不完整的问题后，保留 **11 个场景**（如 wikifact、math、gsm、imdb、boolq 等），每场景题目数从 436 到 29407 不等。
- **题目嵌入**：使用基于 BERT 的语言模型（MiniLM / Sentence-BERT）生成每个问题的上下文嵌入。
- **评估协议**：5 折交叉验证。每折以 80% 题目训练、20% 题目测试。
- **评估指标**：
  - **问题级 AUC（question-wise AUC）**：固定一个问题，看预测分数对 LLM 的排序质量；
  - **LLM 级 AUC（LLM-wise AUC）**：固定一个 LLM，看预测分数对问题的排序质量；
  - 每个分布报告其 **90 百分位数**作为汇总统计。
- **对比方法**：
  - **Rasch 风格模型**（Truong et al. 2025）：单维难度参数 + 问题嵌入；
  - **Lasso 惩罚逻辑回归**：\(\theta_{ij}^{(s)} = \gamma_{i0}^{(s)} + \gamma_i^{(s)\top} e_j\)，使用嵌入但无潜在结构；
  - **均值基线（Mean）**：用训练集平均正确率预测所有问题，仅用于问题级 AUC。
- **显著性检验**：5 折交叉验证产生 5 对配对差异，使用配对 t 检验（p < 0.05）判断差异显著性。
