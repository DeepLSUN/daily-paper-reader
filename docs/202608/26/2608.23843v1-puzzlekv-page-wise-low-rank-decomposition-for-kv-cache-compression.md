## 摘要
长上下文推理中，大型语言模型（LLM）日益受到键值（KV）缓存所需内存的限制。KV缓存压缩通过降低先前词元的存储成本来解决此问题。在现有方法中，低秩压缩尤其具有吸引力，因为它以降低的维度表示每个词元。之前的低秩方法通常从模型权重导出固定的投影空间，从校准激活构建固定空间，或在较大的缓存区域上构建共享基。此类表示可能无法捕获详细但重要的信息。我们将每个注意力头的KV缓存划分为固定长度的逻辑页，并观察到单个页面内存在显著的低秩结构。基于此观察，我们提出PuzzleKV，一种无需训练和校准的方法，将每个完整的页面视为独立的压缩单元。PuzzleKV对每个层和KV头内的页面进行分解，直接在密集和分解后的页面上计算注意力，并在自回归解码过程中增量压缩新的符合条件的页面。跨模型、上下文长度和基准的实验证明了PuzzleKV在匹配存储预算下的有效性。在原始KV缓存存储的大约60%下，PuzzleKV在两个评估模型和所有基准设置中实现了超过96%的完整KV性能，在RULER上相比全局SVD有显著提升，在LongBench上具有竞争力的性能。为实现更激进的压缩比，PuzzleKV可进一步与量化结合，仅使用原始存储的18.7%即可保持超过93%的完整KV性能。

## Abstract
Long-context inference in large language models (LLMs) is increasingly limited by the memory required for the key-value (KV) cache. KV cache compression addresses this problem by reducing the storage cost of previous tokens. Among existing approaches, low-rank compression is particularly attractive because it represents every token in reduced dimensions. Previous low-rank methods typically derive fixed projection spaces from model weights, construct fixed spaces from calibration activations, or construct a shared basis over a broad cache region. Such representations may not capture detailed but important information. We partition each per-head KV cache into fixed-length logical pages and observe substantial low-rank structure within individual pages. Based on this observation, we propose PuzzleKV, a training- and calibration-free method that treats each completed page as an independent compression unit. PuzzleKV decomposes pages within each layer and KV head, computes attention directly over dense and factorized pages, and incrementally compresses newly eligible pages during autoregressive decoding. Experiments across models, context lengths, and benchmarks demonstrate the effectiveness of PuzzleKV under matched storage budgets. At approximately 60% of the original KV cache storage, PuzzleKV achieves more than 96% of Full KV performance across both evaluated models and all benchmark settings, with substantial gains over Global SVD on RULER and competitive performance on LongBench. To achieve a more aggressive compression ratio, PuzzleKV can be further combined with quantization while retaining more than 93% of Full KV performance using only 18.7% of the original storage.

### 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

**核心思想**：**将每个KV页视为独立的局部低秩子空间**，对每一层、每一KV头内已完成填充的页，独立执行低秩分解（截断SVD），以页为单位进行压缩，避免全局共享基造成的信息丢失。

**关键技术细节与算法流程**：

1. **页划分与低秩缓存构造**：
   - 在预填充（prefill）阶段，计算标准密集KV缓存，将每个层和KV头的token按**固定页大小P**划分。
   - 保留两类密集区域：**注意力汇聚页（sink page，初始页）** 和**局部滑动窗口（最近的页）**，因这些token访问最频繁或对注意力贡献大。
   - 其余已完成页独立进行**截断SVD**分解，`X ≈ L(X)R(X)`，其中`L(X) = U_r`，`R(X) = Σ_r W_r^T`，分别存储左奇异向量与缩放的右奇异向量。
2. **高效批量分解**：
   - 由于页是短宽矩阵（P < d），直接对每个页做SVD计算量大。PuzzleKV利用**Gram矩阵技巧**：对`X_p X_p^T ∈ R^{P×P}`做特征分解，恢复左奇异向量，再通过`R = U^T X`得到右因子，映射为批量GPU操作，提升效率。
3. **混合注意力机制（Mixed Paged Attention）**：
   - 设计自定义注意力核，**同时处理密集页（sink + 局部窗口）和分解后的因子化页**，无需重建历史密集缓存。
   - 对于因子化页，先计算注意力和缩放因子，通过合理的括号化顺序（先小矩阵相乘），**避免物化重建的K、V矩阵**，再通过**在线Softmax（FlashAttention机制）**合并各页的局部结果，得到全局归一化注意力。
4. **增量更新（Incremental Cache Update）**：
   - 解码阶段，新生成的KV对先追加到当前密集页参与注意力；当该页填满并滑出局部窗口时，**被一次性分解转为因子化存储**，释放原密集槽位。
   - 每个解码步最多触发一次页分解，已分解页不再重访，确保**每个生成token都处于压缩状态**，实现整个解码过程的持续压缩。

**存储压缩率公式**（分配给因子化页的KV对存储比）：
`ρ_page = (r_K + r_V)(P + d) / (2Pd)`，其中`r_K`、`r_V`分别为键和值的秩。

### 7. 优点

- **方法设计新颖且无需训练**：引入**页级压缩粒度**概念，将PagedAttention的页抽象扩展为压缩单元，无需训练和校准，即插即用，实用性强。

- **实验分析深入**：除了常规精度比较，通过受控Global SVD基线有力论证了**压缩粒度是影响信息保留的关键**；消融实验较完整（秩、页大小、RoPE键），并提供了系统延迟与内存的量化分析。

### 8. 不足与局限

- **实验覆盖较窄**：仅评估**两种8B规模模型**（Qwen3-8B、Llama-3.1-8B-Instruct），未验证在更大模型（如70B+）或更小模型中页级低秩结构假设是否依然成立，也未涵盖不同架构（如Mamba等非Transformer）或跨语言更广的评测。RULER评估最大上下文为32K，未覆盖论文动机提到的128K等更长上下文场景。
- **对比方法的局限性**：作为SOTA在线低秩法的 **OjaKV复现结果不稳定（部分任务为0分）**，被移至附录，而非正面纳入对比，可能削弱与最先进方法对比的说服力；Palu仅为G-LRD变体且同样依赖校准，未与其他更近期的低秩压缩方法（如xKV）进行主实验对比（xKV因利用正交冗余被排除）。
- **实际部署的验证不足**：当前实现是**batch size为1的独立原型**，未在真实批量服务引擎（如vLLM）中集成验证。批量场景下的调度、页分解并发、混合注意力对吞吐的影响尚未评估。
- **未报告精度方差**：虽然作者指出使用贪婪解码、结果是确定性的（单次运行），但没有跨模型随机种子或输入变体的多次运行方差数据，无法评估方法对输入扰动（如种子、提示模板）的鲁棒性。
- **计算开销前置化**：prefill阶段的页分解带来一定时延（TTFT在32K下增加20.9%），虽解码阶段开销可忽略，但对首token时延敏感的应用，该开销需要进一步优化（如更快的交替方向法或低秩近似算法）。
