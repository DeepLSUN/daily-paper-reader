## 摘要
在策略（自我）蒸馏（OPSD）越来越多地被用于语言模型的后训练。它通过特权信息增强教师模型，但可能引发特权幻觉：学生模型学习到依赖特权的行为，而这些行为无法从其推理时的上下文中再现，却表现得好像训练时的特权信息仍然可用，最终损害性能。在本文中，我们指出特权教师模型与学生模型在推理时的信息不对称是OPSD中这一失败的根源。为解决这一不对称，我们提出了双锚点策略蒸馏（DAPD），一个具有两个层面锚点的统一框架。双路径锚点（DPA）引入一个自条件桥梁，并沿两条信息匹配路径对齐参考行为和 rollout 行为，防止依赖特权的行为迁移到推理时的学生模型。双源锚点（DSA）在参考到 rollout 和 rollout 到参考两个方向应用这些路径，减少对特权参考指导的依赖，同时保留正确性监督。大量实验表明，DAPD显著缓解了特权幻觉，在Qwen3-4B上跨任务平均比OPSD高出+2.00分。值得注意的是，其增益在不同规模上持续存在，在4B规模达到+2.69，在32B规模达到+2.78。

## Abstract
On-policy (self) distillation (OPSD) is increasingly adopted for language-model post-training. It strengthens the teacher with privileged information but can induce a privilege illusion: the student learns privilege-dependent behavior it cannot reproduce from its inference-time context, yet behaves as if the training-time privileged information remained available, ultimately degrading performance. In this paper, we identify information asymmetry between the privileged teacher and the student at inference as the root cause of this failure in OPSD. To resolve this asymmetry, we propose Dual-Anchored Policy Distillation (DAPD), a unified framework with two levels of anchoring. Dual-Path Anchoring (DPA) introduces a self-conditioned bridge and aligns reference and rollout behavior along two matched-information paths, preventing privilege-dependent behavior from being transferred to the inference-time student. Dual-Source Anchoring (DSA) applies these paths in both reference-to-rollout and rollout-to-reference directions, reducing reliance on privileged reference guidance while preserving correctness supervision. Extensive experiments show that DAPD significantly alleviates privilege illusion, outperforming OPSD on Qwen3-4B by +2.00 points on average across tasks. Notably, its gains persist across scales, reaching +2.69 at 4B and +2.78 at 32B.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：在后训练（post-training）阶段，语言模型通常借助监督微调（SFT）、强化学习（RL）和蒸馏（distillation）等手段转变为推理模型。在这之中，**在策略（自我）蒸馏（On-policy/Self Distillation，简称 OPSD）** 正越来越受到重视——它从当前策略采样的状态上训练，并逐 token 提供密集的教师监督，相比固定示范的 SFT 和稀疏奖励的 RL 更具优势。
- **问题的起点**：OPSD 实践中通常会用**特权信息**（如参考解答、工具输出）来增强教师模型，但这些信息在推理时是学生无法获得的。由此产生了一种被称为 **“特权幻觉”（privilege illusion）** 的现象：学生学会了依赖特权信息才能再现的行为（如无根据地断言答案、像是“看到”了参考解答一样继续推导），在推理时导致性能下降。
- **论文的根因分析**：论文认为，OPSD 中学生性能退化的根源是**信息不对称（information asymmetry）**——教师训练时拥有特权信息，而学生在推理时没有。这种不对称使得原 OPSD 目标同时混合了“可复现的有用指导”与“不可复现的特权依赖行为”，论文将这种混合更新称为**纠缠蒸馏（Entangled Distillation）**。
- **整体含义**：论文提出的 **DAPD（Dual-Anchored Policy Distillation，双锚点策略蒸馏）** 试图从信息源头上解决特权幻觉问题，而不是像此前工作那样仅仅对特权教师信号进行过滤、加权或路由。通过匹配教师与学生之间的信息可用性，DAPD 在保留 OPSD 有用监督的同时，有效抑制了特权依赖行为的迁移。

## 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想
- 在 OPSD 中引入 **Self 分布**（self-conditioned distribution，即条件于完整完成序列 y 或 y* 的分布）作为**可训练桥梁**。
- 通过**双路径锚定（Dual-Path Anchoring, DPA）** 在“信息匹配”条件下对齐参考与 rollout 行为，阻断特权依赖行为向推理时学生迁移。
- 通过**双源锚定（Dual-Source Anchoring, DSA）** 在“参考→rollout”和“rollout→参考”两个方向应用 DPA，平衡“可靠的参考指导”与“学生可达到的 rollout 指导”。

### 2.2 三种定向目标（Directed Objectives）
对于每个完成来源 s ∈ {y（rollout）, y*（参考）}，论文定义了三个核心目标：

- **纠缠蒸馏（Entangled Distillation）**：L_s_ent = E[D(sg[p_s_Cross] ∥ p_s_None)] —— 即原始的 OPSD 项（None 分布向 Cross 分布学习）。
- **推理锚点（Inference Anchor）**：L_s_infer = E[D(sg[p_s_None] ∥ p_s_Self)] —— 训练 Self 向 None 对齐，提供无特权信息条件下的行为对齐。
- **特权锚点（Privileged Anchor）**：L_s_priv = E[D(sg[p_s_Cross] ∥ p_s_Self)] —— 在双方都有特权信息时对齐 Self 与 Cross。

其中：
- **None 分布**：p_s_None = p_θ(· | x, s_<t)，不接收特权信息，与推理时学生信息状态一致。
- **Cross 分布**：p_s_Cross = p_θ(· | x, s_<t, s̄)，接收另一个完成作为特权信息。
- **Self 分布**：p_s_Self = p_θ(· | x, s_<t, s)，接收被预测的完成本身作为特权信息——是可训练的，且与 Cross 信息匹配。

### 2.3 双路径锚定（DPA）
对于有序方向 s → s̄：
- **无条件路径（Unconditioned Path）**：L_{s→s̄}_uncond = L_{s̄}_infer + L_s_ent —— 结合原始 OPSD 与推理锚点，在无特权信息条件下对齐两个 None 分布（通过 Self 作为代理桥梁）。
- **特权路径（Privileged Path）**：直接使用 L_s_priv —— 在双方均拥有完整完成时对齐 Self 与 Cross。
- 组合目标：L_{s→s̄}_DPA = L_{s→s̄}_uncond + L_s_priv。

### 2.4 双源锚定（DSA）
将 DPA 应用于两个方向：
- **Rollout→Reference（y → y*）**：参考导向——依赖参考提供正确性指导。
- **Reference→Rollout（y* → y）**：rollout 导向——利用学生可达到的 on-policy 指导。
- 最终目标：**L_DAPD = λ·L_{y→y*}_DPA + (1−λ)·L_{y*→y}_DPA**，其中 λ ∈ [0,1] 平衡两个引导来源。

### 2.5 算法流程（每 minibatch）
1. 从当前 LoRA-on 学生策略中为每个 (x, y*) 采样一个 on-policy rollout y。
2. 对每个完成来源 s ∈ {y, y*}，在 s 的 token 上构建 p_s_None、p_s_Cross、p_s_Self。
3. 在两个方向（y→y* 和 y*→y）上计算三个损失项，教师分布全部 stop-gradient，学生侧保留梯度。
4. 按系数组合 DAPD 目标并反向传播更新 LoRA 参数。
5. 周期性将当前 LoRA 参数复制到共享快照（用于两个 Entangled Distillation 教师）。

### 2.6 理论支撑（附录 B 简述）
- 论文提供了形式化的理论分析：在“桥接一致性”和“局部兼容性”假设下，无条件路径的联合优化可以显式地收紧 rollout 侧 None 与参考侧 None 分布之间的距离上界，解释为何 DPA 能实现隐式的 None-to-None 对齐。

## 6. 论文的主要结论与发现

1. **根因确认**：OPSD 中特权幻觉的根本原因是**信息不对称**——教师拥有特权信息而学生没有。实验证明，仅将学生从 None 替换为 Self 分布（即匹配信息条件）就能减少 45% 的晚期错误断言，Avg@12 提升 +6.22 分（图 2）。
2. **方法有效性**：DAPD 通过 DPA + DSA 的组合，显著缓解特权幻觉，在 Qwen3-4B 上比 OPSD 平均提升 +2.00 分。
3. **规模化稳健**：OPSD 的增益随模型规模增大而消失，但 DAPD 的增益在 1.7B~32B 范围内持续存在（32B 上 +2.78），说明信息匹配的监督结构在大规模上更能保留 rollout 质量提升的红利。
4. **源互补性**：参考（正确性导向）与 rollout（学生可达到）的引导来源互补，结合两者优于任一单一来源。
5. **参考无关的扩展**：DSA 即使在没有人工参考的情况下（双 rollout 或 verifier 验证），也能优于 OPSD，显示出减少对策划参考依赖的潜力。
6. **行为层面改善**：DAPD 显著降低了“无依据回忆答案”“推导失败后猜测”等特权幻觉行为（最后 50 步降低 73%）。

## 7. 优点

- **评估基准与任务类型有限**：所采用的基准集中于可自动验证的数学推理、代码生成和指令跟随，未能覆盖开放式问答、长文本生成、创意写作等更难自动评估的场景。特权幻觉很可能在这些任务中表现不同，因此 DAPD 在这些场景下的泛化性仍需验证。

## 9. 总结与总体评价

DAPD 通过对 OPSD 中“特权信息不对称”这一根因的精准诊断，提出了以 **Self 分布为桥梁、双路径锚定（DPA）为手段、双源锚定（DSA）为框架**的解决方案。该方法在保留 OPSD 的 on-policy 采样、密集 token 监督和无需额外教师模型等核心优势的同时，显式地切断了特权依赖行为向推理时学生的迁移路径，实现了信息匹配条件下的有效监督蒸馏。

从研究贡献角度看，这项工作具有以下几点方法论价值：

1. **将“信息不对称”这一宏观观察转化为可操作的训练目标**：论文没有停留在“特权信息导致幻觉”这一泛泛结论上，而是通过三种分布（None/Cross/Self）的构造，将信息匹配问题精确定义为分布对齐问题。
2. **提供了清晰的机制解释**：行为探针、梯度兼容性分析和理论证明三者结合，让读者不仅知道 DAPD 有效，还能理解它为什么有效。
3. **具有实用迁移潜力**：参考无关变体的实验表明，即使在没有高质量人工参考的环境中，DAPD 也能通过双 rollout 或 verifier 信号超越 OPSD，这对于实际训练场景具有现实意义。

当然，论文在计算资源报告、模型家族覆盖、超参数敏感性等方面仍有不足，但总体而言，这是一篇问题诊断扎实、方法设计巧妙、实验证据链完整的高质量工作，为后续关于蒸馏中特权信息处理的研究提供了一个坚实的起点。
