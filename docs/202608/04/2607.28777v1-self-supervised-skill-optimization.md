## 摘要
智能体技能为冻结的大型语言模型（LLM）智能体提供可复用的程序性指导，近期研究表明此类技能可以借助真实标签（GT）反馈进行优化。然而，许多应用缺乏GT标签、任务评分、奖励或可靠的任务特定评估器。因此，我们引入了自监督技能优化（SSO），这是一个仅从无标签任务实例中学习可复用技能的对比框架。在每一步中，SSO在无标签批次上运行当前技能，使用所得执行结果的一个子集生成完整的技能探针，并在同一批次上运行这些探针。一个LLM裁判会比较所得的答案、轨迹、工件或终端状态。一个独立的行为提取器在不查看裁判决策的情况下识别行为差异。SSO利用这些决策在各实例间聚合支持和反对所观察行为的证据，然后根据所得证据对行为进行排序，并从排名最高的行为中生成新的完整技能。仅当新技能在无标签验证集上优于当前技能时，更新才被接受。在封闭式和开放式任务上，SSO均优于现有的无GT提示优化器。在封闭式基准测试中，它接近甚至有时超过最强的基于GT的技能优化器，且不依赖任何GT反馈。

## Abstract
Agent skills provide frozen large language model (LLM) agents with reusable procedural guidance, and recent work shows that such skills can be optimized with ground-truth (GT) feedback. Many applications, however, lack GT labels, task scores, rewards, or reliable task-specific evaluators. We therefore introduce Self-Supervised Skill Optimization (SSO), a comparative framework that learns a reusable skill from unlabeled task instances alone. At each step, SSO runs the current skill on an unlabeled batch, uses a subset of the resulting executions to generate complete skill probes, and runs the probes on the same batch. An LLM judge compares the resulting answers, trajectories, artifacts, or terminal states. A separate behavior extractor identifies behavioral differences without seeing the judge's decisions. SSO uses these decisions to aggregate evidence for and against the observed behaviors across instances. It then ranks the behaviors by the resulting evidence and renders a new complete skill from the highest-ranked behaviors. The update is accepted only if the new skill outperforms the current one on an unlabeled validation set. SSO outperforms existing GT-free prompt optimizers on both closed-ended and open-ended tasks. On closed-ended benchmarks, it approaches and sometimes exceeds the strongest GT-based skill optimizer without using any GT feedback.

**研究动机与背景：**
- 大型语言模型（LLM）智能体常需要多步推理、工具调用与环境交互，而“技能”（Skill）可以以自然语言文档的形式为冻结的智能体提供可复用的程序性指导。
- 已有工作（如 SkillOpt）证明技能文档可以通过真实标签（Ground-Truth, GT）或任务分数等反馈进行优化，但实际应用中往往不存在 GT 标签、任务评分、奖励或可靠的任务专属评估器（如开放式对话、企业文档任务、工件生成任务）。
- 因此本文提出“无 GT 技能优化”（GT-free skill optimization）问题：能否仅依赖未标注的任务实例来优化可复用技能？

**核心含义：**
- 论文提出 **Self-Supervised Skill Optimization (SSO)**，一种完全不需要 GT 反馈的对比式技能优化框架。
- SSO 通过比较同一任务上不同技能（当前技能 vs. 探针技能）的执行结果，提取行为级差异，并跨实例聚合证据，从而指导技能更新，最终在未标注验证集上通过对比筛选接受或拒绝更新。

## 2. 方法论

**核心思想：**
- 以单个完整技能文档为可训练状态，执行函数 `f_exec(S, x)` 由冻结的目标模型决定。
- 利用 LLM 作为裁判，比较“当前技能”与“探针技能”在同一未标注任务上的执行效果，产生偏好信号；将偏好信号转化为对“行为”的鼓励或抑制，进而渲染新技能。

**关键流程（算法 1 概述）：**

1. **探针生成与锚定比较（Probe Generation and Anchored Comparison）**
   - 在训练批次 `X_t` 上执行当前技能 `S_t`，得到锚定执行 `r_o^i`。
   - 使用生成器 `f_gen` 基于当前技能和少量历史执行，生成 `K` 个完整技能探针 `{P_k}`。
   - 在同一批次上执行所有探针，得到 `r_k^i`。
   - 用 LLM 裁判 `f_judge` 比较每个探针执行与锚定执行，输出 `y_k^i ∈ {-1, 0, +1}`（+1 表示探针更优，-1 表示当前技能更优，0 表示平局），并通过随机化顺序缓解位置偏差。

2. **行为提取与聚类（Behavior Extraction and Clustering）**
   - 行为提取器 `f_beh` 在**不看到裁判决策**的情况下，从任务输入和所有执行中提取行为记录 `{β_ij, α_ij}`，其中 `α_ij(r) ∈ {1, 0, ⊥}` 表示行为在执行中是否存在或不明确。
   - 行为聚类器 `f_cluster` 将语义等价的行为描述聚类，且簇的代表保留原始描述，不生成新摘要。

3. **证据聚合与排序（Evidence Aggregation and Ranking）**
   - 对每个有明确行为差异的比较，计算激活差异 `d_kc = α_c(r_k) - α_c(r_o)`。
   - 给每个变化簇分配归一化证据：`e_kc = y_k * d_kc / |A_k|`，其中 `|A_k|` 是行为差异簇数，保证每次比较的总影响相同。
   - 对每个簇累积 `Q_c`（有符号分数）和 `E_c`（证据总质量）。
   - 根据 `sign(Q_c)` 确定行为意图（鼓励/抑制），按 `|Q_c|` 降序、再按 `E_c` 和贡献任务数排序，保留最多 `U` 个行为单元 `U_t`。

4. **整体技能渲染与无标注验证（Whole-Skill Rendering and Unlabeled Validation）**
   - 若 `U_t` 为空则保持技能不变；否则渲染器 `f_render` 基于当前技能和选定行为生成候选新技能 `\tilde{S}_{t+1}`。
   - 在验证集 `V_t` 上执行当前技能和候选技能，用同一裁判比较得到 `v_m`，统计胜场 `W_t` 和负场 `L_t`，仅当 `W_t > L_t` 时接受候选。

**关键公式：**
- 执行定义：`r = f_exec(S, x)`
- 证据分配：`e_kc = y_k * d_kc / |A_k|`
- 累计分数：`Q_c = Σ e_kc`，`E_c = Σ |e_kc|`
- 接受准则：`S_{t+1} = \tilde{S}_{t+1}` 如果 `W_t > L_t`，否则保持原技能。

## 6. 主要结论与发现

- **封闭式任务**：
  - SSO 在所有封闭式基准-模型组合上均优于现有 GT-free 优化器（SPO、PDO），且平均分大幅高于 No skill（GPT-5.5 上 +20.4，GPT-5.4-mini 上 +16.6，Qwen3.5-4B 上 +14.2）。
  - 在 GPT-5.5 上，SSO 恢复 SkillOpt 增益的 86.8%；在 GPT-5.4-mini 上超过 SkillOpt 1.2 个点；在 Codex harness 上仅落后 SkillOpt 1.9 个点。
- **开放式任务**：
  - SSO 对 No skill、SPO、PDO 的平均胜率分别为 62.4%、63.6%、62.5%，说明其行为级证据聚合也能扩展到多轮对话场景。
- **消融与动态分析**：
  - 移除行为聚类、证据归一化或验证门控，或替换为直接探针选择、随机行为选择，都会造成性能下降，说明每个模块都很关键。
  - 渲染后的候选技能一致优于“事后最优探针”，验证了跨探针行为聚合的价值。

## 7. 优点

- **问题新颖性**：正式定义了“GT-free 技能优化”，填补了现有技能优化完全依赖标签/分数反馈的空白。
- **自监督对比框架**：仅使用未标注任务实例和 LLM 裁判，无需任何任务特定评估器，适用范围广。
- **行为级证据聚合**：不像过去方法只做候选级选择，而是将行为作为最小单元，跨探针、跨任务累积证据，能够生成超越任何单个探针的新技能。
- **信息隔离设计**：行为提取不看裁判决策、聚类不看激活状态，减少了偏差传导，增强可信度。
- **验证门控**：在未标注验证集上通过成对比较决定接受与否，有效防止回归，且保持无 GT 特性。
- **归一化证据机制**：每条比较总影响力为 1，避免多行为差异的样本主导优化。
- **实验较全面**：多个模型、多个任务、多种基线，并包含消融、超参、动态过程分析。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 数量、训练时间或 API 调用成本，难以评估实际资源需求。
- **对 LLM 裁判的依赖**：裁判模型本身可能存在偏好和不稳定性（如顺序偏差虽缓解但未消除），且论文未系统研究裁判模型选择对结果的影响。
- **优化器侧模型偏见**：所有优化模块（生成/裁判/提取/聚类/渲染）均固定为 GPT-5.5，可能使方法对单一模型过拟合，缺少跨优化器泛化测试。
- **比较不全面**：开放式任务未与任何 GT-based 或更强无监督方法（如 UPA）对比；GT-based 基线多为引用数据，与 SSO 的实验条件是否完全一致未明确说明。
- **行为提取与聚类的可靠性**：依赖 LLM 自动提取行为和聚类，语义等价判断可能出现错误，影响证据归因。
- **丢弃信息**：对存在行为差异但无法归因到具体簇的比较，或没有清晰行为差异的决策，直接丢弃，可能会损失部分优化信号。
- **超参数敏感性**：尽管默认设置表现最佳，但 `K`、`U`、批大小等超参数的调优成本未讨论，不同领域可能需要重新调整。
- **验证门控有效性依赖裁判一致性**：在验证集上使用与训练集相同的裁判，存在“过拟合裁判”的风险，而非真正提高任务性能。

**整体来看**：SSO 提出了一种新颖且实用的无 GT 技能优化范式，实验证明其在多个任务和模型上有效，但在算力披露、裁判鲁棒性、多模型泛化与与更强基线对比方面仍有进一步探索空间。
