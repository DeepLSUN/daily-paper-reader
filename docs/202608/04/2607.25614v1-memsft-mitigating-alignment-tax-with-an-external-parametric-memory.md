## 摘要
将大型语言模型（LLMs）适配到专业领域通常会带来对齐税，因为针对领域特定任务的微调可能导致灾难性遗忘，并显著降低通用任务上的性能。我们提出了MemSFT，通过将领域专业化与骨干参数更新解耦，借助一种即插即用的参数化记忆来缓解对齐税。该记忆经过训练，以模仿在领域数据上运行的非参数化检索器的行为，从而记住原本需要通过检索才能获得的知识和模式。一旦在特定领域上训练完成，该记忆可复用于不同规模的LLMs。在生成过程中，一个学习到的路由器在每一步解码时动态融合记忆与骨干网络的输出分布，从而选择性地调用领域专业知识。在生物学、地球科学和法律领域的评估中，使用从Qwen3-8B到Qwen3-235B-A22B的模型，结果表明MemSFT在通用性能几乎不下降的情况下持续提升领域性能，而全量SFT则在通用任务上遭受严重遗忘。总体而言，我们的结果展示了一条在参数层面将通用模型能力与领域特定知识解耦的实用路径，从而在不损害通用能力的前提下为LLMs装备新的专业化能力。

## Abstract
Adapting Large Language Models (LLMs) to specialized domains often incurs an alignment tax, as fine-tuning on domain-specific tasks can cause catastrophic forgetting and substantially degrade performance on general tasks. We propose MemSFT, which mitigates the alignment tax by decoupling domain specialization from backbone parameter updates through a plug-and-play parametric memory. The memory is trained to imitate the behavior of a non-parametric retriever operating over domain data, thereby memorizing knowledge and patterns that would otherwise be accessed through retrieval. Once trained on a specific domain, the memory can be reused across LLMs of different sizes. During generation, a learned router dynamically fuses the output distributions of the memory and backbone at each decoding step, allowing domain expertise to be invoked selectively. Across biology, geoscience, and law, evaluations with models ranging from Qwen3-8B to Qwen3-235B-A22B show that MemSFT consistently improves domain performance with negligible degradation in general performance, whereas full SFT suffers severe forgetting on general tasks. Overall, our results demonstrate a practical path to decoupling general model capabilities from domain-specific knowledge at the parameter level, thereby equipping LLMs with new specialized capabilities without compromising their general capabilities.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：将大语言模型（LLM）适配到专业领域（如生物学、地球科学、法律）时，常规的领域微调（如全参数 SFT）会引发严重的**灾难性遗忘**，导致模型在领域任务上性能提升的同时，通用能力（数学推理、指令遵循、广泛知识问答等）显著下降。这种现象被称为“**对齐税**”（Alignment Tax）。
- **背景**：现代 LLM 经过预训练和后训练（如指令微调、对齐）后，已经具备强大的通用能力；但进一步的领域 SFT 会破坏这种后训练平衡，将模型行为拉回预训练分布，侵蚀指令遵循和推理能力。现有方法如 LoRA 等 PEFT 虽能缓解遗忘，但本质上仍是在“领域性能”与“通用能力保留”之间进行权衡，无法真正突破这一 trade-off。
- **论文含义**：MemSFT 提出一种**参数级解耦**方案：将领域知识外部化到独立的参数化记忆中，保持骨干模型完全冻结，从而在获得领域专业能力的同时几乎不损失通用能力，为 LLM 的领域适配提供了一种新范式。

## 2. 论文提出的方法论

### 2.1 核心思想
MemSFT 的核心是将“领域专业化”与“骨干参数更新”解耦。具体地：
- 训练一个**外部参数化记忆模型**（Memory LM），使其模仿非参数检索器（token-level KNN）在领域 SFT 数据上产生的教师分布，从而将领域知识内化到记忆参数中。
- 在推理时，一个**学习到的 token 级路由器**动态融合骨干模型与记忆模型的输出分布，使领域知识被选择性调用，而非在每个解码步骤均匀施加。

### 2.2 关键技术细节

1. **构建检索监督（Retrieval-Based Supervision）**：
   - 将领域 SFT 语料构建为 QA 形式的 token 级 datastore：对于每个答案位置 t，用固定教师编码器提取前缀上下文隐藏状态作为 key，对应答案 token 作为 value。
   - 查询时检索近邻，构造非参数教师分布：
     \[
     p_{\text{teacher}}(y|c_t) \propto \sum_{(k_j,v_j)\in N(k_t)} \mathbb{1}[y=v_j] \exp(-d(k_t,k_j)/\tau)
     \]
   - 实验中 key 为 4096 维（Qwen3-8B encoder），检索 top-2048 近邻并去掉自身，温度 τ=16.0，使用 FAISS L2 索引。

2. **记忆训练（Memory Training）**：
   - 目标函数为 KL 散度（对齐教师分布）与交叉熵（锚定 gold token）的加权和：
     \[
     \mathcal{L}_{\text{mem}} = \beta \cdot \text{KL}(p_{\text{teacher}} \| p_{\text{mem}}) + (1-\beta) \cdot \mathcal{L}_{\text{CE}}
     \]
   - β 在 0.1–0.3 之间选择（按领域微调）。

3. **路由器训练（Router Training）**：
   - 路由器为轻量级两层 MLP，输入为骨干和记忆的隐藏状态 + 置信度/熵等标量特征，输出每个 token 的插值权重 λ_t ∈ [0,1]。
   - 融合分布：
     \[
     p_{\text{fused}} = (1-\lambda_t) \cdot p_{\text{base}} + \lambda_t \cdot p_{\text{mem}}
     \]
   - 训练目标为交叉熵 + 符号线性正则项（领域样本推动 λ 上升，通用样本推动 λ 下降）：
     \[
     \mathcal{L}_{\text{router}} = \mathcal{L}_{\text{CE}} + \alpha_s \cdot s_t \lambda_t
     \]
   - 路由器参数量极小（约 1.08M–1.21M 参数）。

4. **推理机制**：
   - 骨干与记忆并行处理同一输入，路由器动态决定每个解码 token 的融合比例。
   - 记忆训练与骨干完全解耦，同一领域记忆可复用于共享 tokenizer 的不同骨干模型（如 Qwen3-8B 到 Qwen3-235B-A22B）。

## 6. 论文的主要结论与发现

- **MemSFT 显著提升领域性能，且通用能力几乎无损**：
  - BioIns 上，Qwen3-8B/14B/32B/235B 的领域分数分别提升 +37.77、+36.28、+36.57、+40.91，而通用平均变化为 +0.59、+0.40、-0.06、+0.03。
  - 相比之下，SFT 在 8B/14B/32B 上通用平均分别下降 -13.52、-31.39、-25.58；LoRA 下降 -17.08、-9.61、-3.74。
  - OpenSWI 上 MemSFT 取得最低 RMSE（8B/14B/32B 均为 0.47），同时通用能力保持稳定。
  - LawBench 上 MemSFT 达到与最强基线相当的法律分数（56.47），同时通用平均保持 83.79（+0.57）。
- **同一领域记忆可跨骨干复用**：8B 记忆直接用于 Qwen3-8B 到 235B-A22B，无需为每个骨干重新训练记忆。
- **学习路由优于固定插值**：固定 λ 存在明显的领域-通用权衡曲线，λ=0.7 时通用平均跌至 44.34；学习路由器达到 42.92 领域分同时保持 83.62 通用平均。
- **记忆规模与领域能力正相关**：1.7B/4B/8B 记忆在 Qwen3-14B 上分别达到 30.38/37.12/42.92 的 BioIns 分数，通用平均均在 83.2–83.6 之间。
- **路由器按 token 角色选择性调用记忆**：OpenSWI 案例分析显示，功能词 λ 均值 0.20、领域术语 0.43、数值剖面 token 高达 0.99；而 MATH 和 MMLU 案例中几乎完全骨干主导（λ 接近 0）。
- **普通 RAG 无法替代参数化记忆**：BM25 RAG top-50 仅将 BioIns 从 6.64 提升到 12.23，远低于 MemSFT 的 42.92。
- **适配算力显著降低**：适配四个 Qwen3 骨干，MemSFT 的总 FLOPs 仅为 SFT 的 0.22 倍。

## 7. 优点

- **思想新颖**：将“外部参数化记忆”从预训练语言模型场景推广到后训练 instruct 模型的领域专业化场景，系统性地解决了对齐税问题。
- **实现优雅**：记忆训练使用 KNN 教师分布提供软监督，路由器训练在双模型冻结下进行，组件解耦清晰。
- **模块化与可复用性**：同一领域记忆可在不同规模骨干间迁移，显著降低多模型适配成本。
- **实验严谨**：多领域、多骨干、多基线、多消融，自带算力 FLOPs 分析和实测资源报告。
- **分析深入**：路由器行为可视化（token 级 λ 分布）直观展示了选择性记忆调用的机制，增强了方法的可解释性。
- **突破 trade-off**：在领域-通用权衡图中逼近“理想区”，而 SFT/LoRA/Wise-FT/MixTraining 均无法做到。

## 8. 不足与局限

- **跨词表迁移受限**：记忆复用要求骨干共享 tokenizer 和输出词汇表；跨模型家族（如 Qwen 到 LLaMA）需额外的词汇表对齐或短时继续训练，论文仅以 LLaMA2 同族验证，未做真正的跨族迁移。
- **未探索强化学习**：记忆训练仅使用监督式目标，未结合 RL 进一步优化记忆的领域能力或与骨干的对齐。
- **大规模骨干对比不完整**：Qwen3-235B-A22B 上未运行 SFT/LoRA 基线，无法在大规模场景下做完整对比。
- **OpenSWI 仅评估浅层设置**：deep 设置因生成可靠性问题被排除，限制了地球科学场景的完整性。
- **法律领域验证规模有限**：仅在 Qwen3-14B 一个骨干上验证，未测试不同规模或跨骨干复用。
- **路由器训练依赖通用指令数据**：使用的 Nemotron-Post-Training-Dataset-v1 为单一来源，可能存在分布偏差。
- **常规 RAG 对比仅用 BM25**：未对比更强大的密集检索（如基于嵌入的 RAG）作为基线。
- **固定 LoRA 配置**：未对不同骨干做 LoRA 超参数搜索，虽然保证了一致性，但可能略微低估 LoRA 的性能上限。
