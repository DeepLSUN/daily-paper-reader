## 摘要
自主智能体越来越多地被要求对外部系统产生不可逆的影响——转移资金、写入持久存储、驱动硬件。现有的智能体框架（ReAct、Reflexion、MCP）在基准测试上优化任务成功率，却很少关注不可逆副效应的安全性。我们将这样一个场景——公共账本上的价值转移——形式化为由（钱包、链、地址、协议）索引的四维空间中的状态转换，并利用该形式化方法来陈述和证明我们称之为执行保真度的保证：在允许规划器错误映射、模糊结果、重试、至少一次投递以及委托的非人类调用者的故障模型下，会话在账本上的实际效果要么毫无效果，要么恰好是呈现给用户的那次转换，且恰好一次。该定理刻意不声称呈现的转换与用户意图一致——任何运行时层都无法决定这一点——但它将这一无界问题限制为对有限对象的单一谓词，这正是使预览成为充分控制而非形式化的原因。从保真度条件推导出的七个安全不变式（而非凭经验枚举）实现了这一保证。在实证中，在受控的N=60对抗性测试套件上，该技术栈在两个写激进的底层模型上将通过率比naive-ReAct基线提高了约74个百分点，但在一个写谨慎的模型上仅提高了约3个百分点——这表明对智能体安全技术栈的单模型评估几乎不可证伪。该系统已部署；8条链上的108次生产写操作为失败分类提供了支持。尽管评估场景是公共账本，但该形式化方法和不变式适用于任何作用于不可逆外部状态的概率性智能体。

## Abstract
Autonomous agents are increasingly asked to produce irreversible effects on external systems - transferring funds, writing to durable storage, actuating hardware. Existing agent frameworks (ReAct, Reflexion, MCP) optimize task success on benchmarks and give little attention to the safety of irreversible side-effects. We formalize one such setting, movement of value across public ledgers, as state transitions in a four-dimensional space indexed by (wallet, chain, address, protocol), and use that formalism to state and prove a guarantee we call execution fidelity: under a fault model admitting planner mis-mapping, ambiguous outcomes, retries, at-least-once delivery, and delegated non-human callers, a session's realized effect on the ledger is either nothing at all or exactly the transition that was rendered to the user, exactly once. The theorem deliberately does not claim that the rendered transition matches the user's intent - no runtime layer can decide that - but it confines that unbounded question to a single predicate over a finite object, which is what makes a preview a sufficient control rather than a formality. Seven safety invariants, derived from the fidelity condition rather than enumerated from experience, discharge the guarantee. Empirically, on a controlled N=60 adversarial suite the stack lifts pass rate by ~74 percentage points over a naive-ReAct baseline on two write-aggressive backing models, but by only ~3 points on a write-cautious one - evidence that single-model evaluations of agent safety stacks are close to unfalsifiable. The system is deployed; 108 production write operations across 8 chains back the failure taxonomy. Although the evaluation setting is public ledgers, the formalism and invariants apply to any probabilistic agent acting on irreversible external state.

## 2. 论文提出的方法论

**核心形式化框架：四维状态空间**

- 定义钱包状态 s 为映射：s : W × C × A × P → Z≥0，其中：
  - W：用户托管的助记词集合（钱包）
  - C：链集合
  - A：各链上的地址集合
  - P：各链上的协议集合（代币、合约、链外账户等）
- 四个维度中**没有一个是其余维度的函数**，各有操作原语专门移动该维度而固定其他维度（如 Transfer 只移动地址、Swap 只移动协议、Bridge 同时移动链/地址/协议等），因此缺一不可。
- 状态转换 τ 是偏函数，具有**守恒约束**（价值不能凭空创造/销毁，允许手续费和铸/焚差量）和**签名授权约束**（余额减少的坐标必须携带对应钱包派生的有效签名）。

**执行保真度（Execution Fidelity）定义：**

> 一个会话 σ 的实际效果 real(σ) ∈ {∅, {τp}}
> 即：要么什么都没发生，要么恰好发生一次呈现给用户的那次转换。

**故障模型（F1-F6）：**

- F1 意图错误映射（无界，不可由运行时层解决）
- F2 前态漂移（规划与广播之间链上状态变化）
- F3 结果模糊（广播后无法在有限窗口内观察是否生效）
- F4 重新发起（规划器可随意重复调用工具）
- F5 重复投递（通道至少一次投递语义）
- F6 非人类调用者（avatar 等自主调用方在委托授权下行动）

**七个安全不变式（从保真度条件推导而非经验枚举）：**

| # | 名称 | 执行层级 | 排除的故障 |
|---|------|---------|-----------|
| I1 | 确认门控（Confirm gate） | 执行器本地 | 未渲染的转换 |
| I2 | 前态充分性（Pre-state sufficiency） | 执行器本地 | 广播时已不适用 |
| I3 | 后态可观察性（Post-state observability） | 执行器本地 | 虚报失败 |
| I4 | 无幻影成功（No phantom success） | 执行器本地 | 虚报成功 |
| I5 | 作用域委托（Scoped delegation） | 跨层级 | 无权调用者 |
| I6 | 计划级重试安全（Plan-level retry safety） | 计划层 | 规划器重复发起 |
| I7 | 幂等意图接收器（Idempotent intent receiver） | HTTP 接收端 | 通道重投递 |

**核心证明：**

- **执行保真度定理**：在七个不变量全部生效、故障限于 F1-F6 且满足 §3.1 假设的条件下，会话必然满足执行保真度。证明按违反情形三分支（执行了非 τp / 重复执行 τp / 执行了从 τp 派生但不同的转换）逐一排除。
- **推论（剩余风险局部化）**：在七个不变量下，唯一能产生非预期不可逆效果的故障是 F1（意图映射）。这是论文最核心的工程价值声明。

**实现系统（cryptitalk-wallet）：**

- 三层架构：执行器（executor）+ 化身（avatar）+ 分析师（analyst），由 agent SDK 经 MCP 粘合。
- 执行器本地写路径严格按序执行：解析 tuple → 授权检查（I5）→ L1 余额检查（I2）→ 预览渲染（I1）→ 密钥派生 → 广播 → 轮询验证（I3/I4）。
- avatar 持有时效性的（user, avatar, Σ）作用域令牌，走与人类用户完全相同的 API 路径，无特权后门。

## 6. 论文的主要结论与发现

- **核心定理成立**：在七个不变量下，执行保真度得以保证：对账本的实际效果要么为空、要么恰好是呈现给用户的那次转换、恰好一次。
- **残余风险局部化**：唯一不可消除的故障源是意图映射（F1），从无界语义问题收敛为有限对象上的单一谓词判断。
- **实测安全增益**：
  - 在**写激进**模型（Claude、MiniMax-M2.7-highspeed）上：全栈比 naive-ReAct 基线提升约 **71.5-76.7 个百分点**（81.7% vs 10.2%、86.7% vs 10.0%），跨模型结论一致。
  - 在**写谨慎**模型（Gemini-2.5-flash-lite）上：仅提升约 **3 个百分点**（60.0% vs 56.7%），因为该模型本身有 46/60 个基线提示主动拒绝写工具。
- **方法论的发现**：**单模型评估智能体安全栈几乎不可证伪**——安全层的可测量价值高度依赖于底层模型的写激进程度，单模型报告可得出几乎任意结论。底层模型应作为一等实验变量对待。
- **消融实验的确证**：代码门类不变量（I1、I3、I5、I6、I7）从 20/20 全部通过降至关闭后的 0-8/20，证明确实承担了阻塞对应失败类别的作用。
- **生产验证**：系统已在真实链上运行，108 次写操作全部落地，9 个失败类别各有至少一次审计事件和对应修复。
- **形式化的应用边界**：该形式化适用于任何作用于不可逆外部状态的概率性智能体，公链只是最严苛的测试场。

## 7. 优点

- **诚实的保证边界**：论文明确不声称解决意图理解问题，而是通过严格的定理证明将残余风险收敛到唯一可控点。这种“话说到什么程度”的克制在安全论文中非常难得。
- **从保证推导不变量，而非从经验列举**：七个不变量不是“踩过的坑写成清单”，而是从保真度条件的三分支情形分析中逐一推导出来的。生产失败分类反过来验证推导的完备性（九类失败全部落入既有分支，无一类需要发明第八个不变量）。
- **四维形式化的可判定性价值**：引入 W 维度并非装饰——它让“错误钱包选择”这一常见失败（第二大观察类）有明确的坐标表达，而非表现为难以诊断的余额不足错误。
- **方法论自觉**：将“部署记录”与“受控实验”明确分离（并声明前者不是实验）；采用跨模型对比揭示单模型评估的不可证伪性；坦承配对检验、样本量、可复现性等统计缺陷。
- **层间职责划分清晰**：执行器本地不变式（I1-I4）与跨层不变式（I5-I7）分开，明确指出单用户单进程人类驱动场景只需前四个，避免了过度设计。
- **对实现层面的现实洞察**：确认门控的实际绕过点是 MCP 序列化中 bool 参数被转为字符串 "false" 后经 Python 真值判断提升为 True——类型边界比策略边界更常出问题，这一观察具有普遍借鉴意义。

- **意图映射问题未解决（且不可由运行时解决）**：无监督的 avatar 场景保证强度显著退化——作用域检查约束“谁能调用”而非“调用内容是否正确”，持有 transfer 作用域的 avatar 将“转 1 单位”解析为“转 10 单位”仍在作用域内执行。这是作者坦承的最重要扩展方向（作用域携带对转换元组的谓词）。
