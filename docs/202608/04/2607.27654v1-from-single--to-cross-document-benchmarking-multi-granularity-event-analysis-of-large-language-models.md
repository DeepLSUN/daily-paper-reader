## 摘要
事件分析是信息抽取中一个重要且基础的方向，涉及不同文档粒度上的各类事件中心任务。尽管大型语言模型（LLMs）已在其中部分任务的单独评测中初步展现出有前景的性能，但由于现有基准在文档粒度、任务设计及数据来源上的限制，它们的事件分析能力仍未得到全面理解。为弥补这些不足，我们引入MiGUE-Bench，一个系统化的基准，用于评估LLMs在多粒度事件分析中的表现。为支持大规模评测，我们首先开发了一个名为MiGUE-Pipeline的LLM驱动的自校正标注框架，能够以自动标签可扩展地获取高质量的事件源数据。随后，我们在基准中设计了四个核心任务，即事件检测、关系推理、结构归纳和未来预测，以从原子级事件细节到复杂跨文档叙事的多个层面探测模型能力。对最先进的LLMs及检索增强生成（RAG）方法的大量实验描绘了当前的能力边界，并识别出关键缺陷，为LLMs在具有挑战性的事件分析任务中的未来改进提供了洞见。

## Abstract
Event analysis is an essential and fundamental direction of information extraction, involving various event-centric tasks at different granularity of documents. While large language models (LLMs) have preliminarily achieved promising performance in part of these tasks individually, their capability in event analysis still lacks comprehensive understanding due to restricted document granularity, task designs, and data source of existing benchmarks. To address these limitations, we introduce MiGUE-Bench, a systematic benchmark for assessing the performance of LLMs in multi-granularity event analysis. To support large-scale evaluation, we first develop an LLM-driven self-correcting annotation framework called MiGUE-Pipeline, enabling scalable acquisition of high-quality source data of events with automatic labels. Then, we design four core tasks in our benchmark, i.e., event detection, relation reasoning, structure induction, and future prediction, to probe model competence at different levels, from atomic event details to complex cross-document narratives. Extensive experiments on state-of-the-art LLMs and retrieval-augmented generation (RAG) methods delineate the current capability boundary and identify critical deficiencies, providing insights into the future improvement of LLMs in challenging event analysis tasks.

## 2. 论文提出的方法论：核心思想、关键技术细节与流程

### 2.1 MiGUE-Pipeline：LLM驱动的自动标注框架

MiGUE-Pipeline是一个四阶段流水线，用于从原始语料自动构建高质量多粒度事件数据：

- **阶段一：文档过滤（Document Filtering）**
  - 使用LLM-as-a-Judge（GPT-4o）对候选文档从三个维度评估：事实信息度（优先客观报道而非主观评论）、文本质量（语法流畅性与结构连贯性）和事件密度（排除冗余或非信息性内容）。仅当三个维度全部满足时保留文档。

- **阶段二：事件标注（Event Annotation）**
  - 基于GPT-5.2先导研究识别出六类典型标注错误：未发生事件、否定声明、假设性表述、抽象/隐喻表达、命名实体误标和叙事性解释。
  - 采用两阶段协议：先用DeepSeek-V3.2生成候选事件触发词集合，再通过适配的检索增强反思方法（从各错误类型中检索语义相似样例），让LLM对照历史失败案例进行自校正。
  - 200条样本人工验证显示事件标注精度达0.87。

- **阶段三：关系标注（Relation Annotation）**
  - **单文档关系标注**：采用约束感知多步推理策略（CAMR）。LLMs在每次迭代选择最自信的关系标签，然后根据显式逻辑约束（如共指标签天然排斥因果或子事件关系）进行自我验证，在确认/修改/重做之间选择；确认后动态剪枝不兼容的关系类型。采用GPT-4o、DeepSeek-V3.2和Qwen3-Max三个LLM进行多数投票，不一致时升级至Claude-4.5-Opus裁决。100个样本上获得0.82的准确率。
  - **跨文档关系标注**：提出共指传播策略（PvC）。先用三个邻近性启发式约束搜索空间（时间邻近性——时间戳在一个月内；语义亲和——事件提及超过语义相似度阈值；实体重叠——事件分享共同参与者），再验证共指关系对。通过形式传递规则（如 e1 与 e2 共指、e1 因果→ e3，则可推出 e2 因果→ e3）恢复跨文档隐式依赖，规避了穷举配对的计算不可行性。

- **阶段四：簇生成（Cluster Generation）**
  - 以事件共指为信号构建文档亲和图，顶点为文档、边为存在共指事件对，使用Leiden社区检测算法划分出最大叙事连贯性的密集子图，为跨文档任务提供数据支撑。

### 2.2 MiGUE-Bench：四个核心任务

- **MiGUE-Detection（事件检测）**
  - 输入含候选触发词集（3-6个），模型需选出句子中的有效事件触发词。将六类标注失败模式注入为干扰选项，考察细粒度语义理解能力。数据来自事件标注阶段。

- **MiGUE-Reasoning（关系推理）**
  - 给定事件对 (e, e') 和关系维度（时间、因果、子事件、共指），从候选标签中选正确关系。分为Reasoning-Intra（单文档内）和Reasoning-Cross（跨文档）两个子任务。构造时排除显式语言线索（如“afterward”“because”），只保留需要上下文理解与多跳推理的关系对，并优先选择GPT-4o初始误判的对以增加难度。

- **MiGUE-Induction（结构归纳）**
  - **间隔基时间顺序排序**：将每个事件解耦为起止两个时间锚点，模型输出事件开始时间序列和结束时间序列两个排列。数据构造中移除绝对时间标记（如具体日期），迫使模型从叙事内容和隐式线索中归纳相对时间。
  - **因果图构建**：给定事件集、文档集及候选因果路径选项（4-6个），模型需识别DAG中所有最长有效因果链。正确答案为每条最大路径；干扰项为三种类型：无关链接、不完整路径、错误顺序。

- **MiGUE-Prediction（未来预测）**
  - 按时间顺序排列的文档序列（3-6篇），模型需选择最终文档中发生的正确事件。正确选项中去除具体细节以避免字面匹配捷径；干扰项通过四种对抗策略生成：反事实、过度概括、时间陷阱（历史事件）和无关干扰（捏造但上下文一致的事件）。

### 2.3 质量控制

多阶段验证：自动过滤保持类别平衡 → 检测并排除有害内容 → 对所有实例进行人工审查以验证答案正确性和选项无歧义。

## 6. 论文的主要结论与发现

- **闭源模型整体优于开源模型**，尤其是在跨文档事件分析任务上，GPT-5.2-Pro和Claude-4.5-Opus在几乎所有任务上表现最佳；开源中DeepSeek-V3.2和GLM-4.7最优。
- **RAG提升不稳定**：RAG对强模型（如Gemini-3-Pro）多数任务有增益，但对弱模型（如Qwen3-8B）噪声检索文档可能反而降低性能，需针对事件分析设计专门的RAG策略。
- **关系推理的粒度差异**：时间和子事件关系在跨文档设置下表现更好（多文档带来额外时间信号）；共指和因果在跨文档设置下表现下降（多视角叙事带来异质性与模糊性；时间连续不必然意味着因果）。
- **LLMs对事件时间跨度理解薄弱**：几乎所有模型在结束时间排序上准确率比开始时间排序低近一半，说明了事件持续时间的推理是当前LLMs的关键短板。
- **因果任务是最具挑战性的方向**：因果推理和因果图归纳的准确率普遍不理想，可能原因在于模型内部因果表征与人类因果理解的错位，以及事件分析中因果定义缺乏严格的数学形式化。
- **长上下文扩展的规模效应**：较大的模型（Qwen3-235B）在更长的输入指令上持续获益，而较小的模型（Qwen3-8B/30B）在中等长度附近达到峰值后下降。
- **检索数量对时间推理性能的影响**：呈现先升后降再稳定的模式——适度的检索文档提升表现，过多文档因噪声累积和上下文稀释反而降低准确率。
