## 摘要
智能文档处理（IDP）涵盖广泛的任务，包括光学字符识别（OCR）、文档问答（DocQA）和关键信息抽取（KIE）。尽管目标各异，这些任务都有一个共同需求，即感知文档内容、获取与任务相关的信息，并逐步优化中间结果。然而，它们通常被表述为单独的预测问题，并由特定任务的模型或处理流程来解决。我们引入DocClaw，一个统一的智能体系统，它将多种智能文档处理任务形式化为智能体与文档之间的共享交互过程。给定一个文档和一个特定任务的查询，DocClaw遵循适当的文档技能，迭代地识别所需信息，调用相关工具，并将得到的观察结果整合为所需的输出。在此过程中，结构化的文档状态组织了可复用的文档知识和特定任务的交互上下文，使智能体能够在交互过程中积累、重新审视并逐步优化信息。在这种表述下，特定任务的需求由智能体对查询目标和相应文档技能的解释来捕获，而底层交互循环、工具空间和文档状态则在任务之间共享。在多个智能文档处理基准上的大量实验表明，DocClaw在统一的智能体框架内有效处理多种任务，并且与通用视觉语言模型和特定任务方法相比，实现了有竞争力的性能。

## Abstract
Intelligent document processing (IDP) encompasses a broad range of tasks, including optical character recognition (OCR), document question answering (DocQA), and key information extraction (KIE). Despite their distinct objectives, these tasks share a common need to perceive document content, acquire task-relevant information, and progressively refine intermediate results. However, they are typically formulated as separate prediction problems and addressed by task-specific models or processing pipelines. We introduce DocClaw, a unified agentic system that formulates diverse intelligent document processing tasks as a shared process of interaction between an agent and a document. Given a document and a task-specific query, DocClaw follows an appropriate document skill to iteratively identify the information required, invoke relevant tools, and integrate the resulting observations into the desired output. Throughout this process, a structured document state organizes reusable document knowledge and task-specific interaction context, allowing the agent to accumulate, revisit, and progressively refine information as the interaction proceeds. Under this formulation, task-specific requirements are captured by the agent's interpretation of the query objective and the corresponding document skill, while the underlying interaction loop, tool space, and document state are shared across tasks. Extensive experiments across multiple intelligent document processing benchmarks demonstrate that DocClaw effectively handles diverse tasks within a single agentic framework and achieves competitive performance compared with both general-purpose VLMs and task-specific methods.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究痛点**：智能文档处理（IDP）涵盖 OCR、DocQA、KIE 等异构任务，尽管这些任务都共享“感知文档内容 → 获取任务相关信息 → 逐步精炼中间结果”的内在逻辑，但现有方法普遍存在两个关键缺陷：
  - **任务隔离**：单次预测模型依赖固定的任务特定映射；多步流水线受限于预定义的处理链，两者都无法灵活适配多种IDP任务。
  - **知识无法积累复用**：各任务独立处理，中间结果（如布局分析、OCR文本）无法在不同查询之间沉淀、复用和精炼，造成大量重复计算。
- **核心主张**：本文提出 DocClaw，将 IDP 重新定义为**智能体与文档的迭代交互过程**，使不同查询目标共享同一个交互循环、工具空间和文档状态，从而实现统一框架下的多任务处理。

## 2. 论文提出的方法论：核心思想、关键技术细节与流程

### 核心思想
- 将文档处理任务形式化为“Agent 基于当前状态，选择并调用工具，更新状态，再决定下一步动作”的闭环过程，直到信息充分后生成最终输出。

### 关键技术细节

1. **文档技能（Document Skills）**
   - 定义一个预定义技能集合 K（如 OCR 技能、DocQA 检查和列举技能、KIE 技能），根据查询目标 q 选择 k ∈ K。
   - 每种技能提供任务导向的交互策略与工具使用模式，例如：
     - **OCR 技能**：布局引导式解析，对低质量区域执行缩放、裁剪、旋转等增强操作后再识别。
     - **DocQA 检查技能**：粗到细的搜索与证据提取；**列举技能**：强调文档级广泛覆盖，用于计数、分组类问题。
     - **KIE 技能**：先进行视觉字段提取，再结合 OCR 文本二次提取，最终以原图参考解决冲突。

2. **结构化文档状态（Document State）**
   - 状态形式化为 `s_t = (m_t, e_t)`，其中：
     - **文档记忆（Document Memory）** `m_t`：持久保存可复用的文档知识，按“文档-页面-区域”三级层次组织；跨查询保留。
     - **任务记忆（Task Memory）** `e_t`：记录当前查询的上下文（已选技能、证据、已检查页面/区域、交互历史等）；查询结束后丢弃。
   - 规划器通过压缩表示 φ(s_t) 访问状态，避免将页面图像等大容量信息全部注入上下文。

3. **Agentic 交互循环**
   - 每一步规划器决定动作 `a_t = (τ_t, c_t) = π_θ(q, k, φ(s_t))`，其中 `τ_t` 为所选工具，`c_t` 为调用参数。
   - 工具执行结果 `r_t = F_{τ_t}(D, c_t; s_t)` 通过更新函数 `U` 分别写入文档记忆和任务记忆。
   - 循环持续至 Agent 选择输出动作 `a_out`，生成最终结果；文档记忆保留至下一查询，任务记忆重置为空。
   - 该过程本质上是 **ReAct 风格**的推理与行动协同循环。

- **统一框架的有效性**：DocClaw 以单一智能体框架在 OCR、DocQA、KIE 三个任务上均取得与通用 VLM 和任务专用方法相当的竞争性表现。

## 7. 优点

- **范式创新**：首次将 IDP 中的三大典型任务统一到单一 Agentic 交互框架，打破任务孤岛，提供了可扩展的通用范式。
- **设计巧妙**：文档状态区分“文档记忆”与“任务记忆”，既实现知识跨查询复用，又避免任务上下文污染，且通过压缩表示控制规划上下文开销。
- **技能机制灵活**：将任务差异性封装为可选择的“文档技能”，而非硬编码流程，使同一框架可适配不同查询目标。
- **实验覆盖均衡**：同时涵盖感知型任务（OCR）、理解型任务（DocQA）和抽取型任务（KIE），且对比对象丰富。
- **消融针对性强**：对状态、技能、精炼操作、验证操作分别做了细化分析，并提供了性能贡献与延迟的成本-效益视角。

## 8. 不足与局限
