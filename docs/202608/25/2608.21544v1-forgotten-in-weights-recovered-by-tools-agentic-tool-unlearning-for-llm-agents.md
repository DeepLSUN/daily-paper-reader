## 摘要
大型语言模型（LLM）越来越多地被部署为工具增强型智能体，其响应可能依赖于工具调用和外部观察，而不仅仅是模型参数。这造成了LLM遗忘的评估错位：先前的遗忘方法可能抑制直接的参数回忆，但智能体仍可通过网络搜索、检索或数据库查询等工具恢复相同的遗忘目标。我们将这种失败模式识别为工具介导的恢复，并研究代理工具遗忘，旨在减少参数回忆和工具介导的恢复，同时保留对已保留知识的正常工具使用。为了应对这一挑战，我们提出了代理工具遗忘（ATU），一个两阶段框架。第一阶段应用参数知识遗忘来抑制直接回忆，而第二阶段在模拟的工具增强环境中进行轨迹级强化学习，以惩罚目标寻求工具行为和最终答案泄露。在RWKU和MUSE上跨不同LLM架构的实验表明，ATU在目标遗忘和保留效用之间取得了更好的平衡，使遗忘在工具增强的智能体部署下更加鲁棒。

## Abstract
Large language models (LLMs) are increasingly deployed as tool-augmented agents, where responses can depend on tool calls and external observations rather than model parameters alone. This creates an evaluation mismatch for LLM unlearning: previous unlearning methods may suppress direct parametric recall, but an agent can still recover the same forget target through tools such as web search, retrieval, or database lookup. We identify this failure mode as tool-mediated recovery and study agentic tool unlearning, which aims to reduce both parametric recall and tool-mediated recovery while preserving normal tool use for retained knowledge. To address this challenge, we propose Agentic Tool Unlearning (ATU), a two-stage framework. The first stage applies parametric knowledge unlearning to suppress direct recall, while the second stage performs trajectory-level reinforcement learning in simulated tool-augmented environments to penalize target-seeking tool behavior and final-answer leakage. Experiments on RWKU and MUSE across different LLM architectures show that ATU achieves a better balance between target forgetting and retained utility, making unlearning more robust under tool-augmented agent deployment.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：大语言模型（LLM）日益被部署为工具增强型智能体（tool-augmented agent），其回复不仅依赖模型内部参数知识，还通过调用网络搜索、数据库查询、文档检索等外部工具获取信息。这导致现有机器遗忘（machine unlearning）评估出现**部署层面的错位**：标准参数级遗忘方法虽能抑制模型直接回忆被遗忘内容，但同一模型一旦被包装为工具增强型智能体，仍可通过外部工具轻易**重新恢复**被遗忘的目标知识，作者将这一现象命名为 **"工具介导恢复"（tool-mediated recovery）**。
- **研究意义**：在隐私、版权与安全合规场景下，模型提供方有义务确保被遗忘的知识（如受版权保护的书籍内容或特定人物信息）不再被模型（无论以何种方式）泄漏。若遗忘仅停留在参数层面而忽略工具通道，则实际部署中的遗忘承诺形同虚设。本文首次系统研究并尝试解决"工具增强场景下的智能体遗忘"问题。
- **现有工作的不足**：已有工具遗忘研究（如 ToolDelete）聚焦于将工具本身作为遗忘目标，或从模型参数和持久记忆中移除信息（如 Agentic Unlearning），但未充分探索"通过合法外部工具重新获取遗忘知识"这一通道；大多数标准遗忘评估也仅检查独立的模型输出，未考虑下游智能体部署。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式与算法流程

**整体框架**：作者提出 **ATU（Agentic Tool Unlearning）** 两阶段框架，依次压制"参数直接回忆"与"工具介导恢复"两条泄漏路径。

- **阶段一：参数知识遗忘（Parametric Knowledge Unlearning）**
  - 在遗忘集 F(c) 与保留集 R = Rsame(c) ∪ Rother 上优化通用知识遗忘目标：
    - θ₁ = argmin_θ L_KU(θ; F(c), R)
  - 可实例化为多种现有遗忘方法，如梯度上升（GA）、拒绝微调（RT）、直接偏好优化（DPO）、负偏好优化（NPO）等，并带有保留侧正则化：
    - L_KU = L_forget(θ; F(c)) + λ_ret · L_retain(θ; R)
  - 该阶段产出遗忘模型 π_θ₁，作为阶段二的初始化。

- **阶段二：代理工具遗忘（Agentic Tool Unlearning）**
  - 在模拟工具增强环境 E_train 中，将模型部署为智能体，通过在线 rollout 生成完整轨迹：
    - τ = (x, a₁, o₁, …, a_K, o_K, y)
  - **奖励设计**：对遗忘查询，使用冻结的 LLM judge 按轨迹级准则打分：安全拒绝 +1.0、模糊回应 +0.3、冒险工具调用但未泄漏 −0.5、轨迹中出现目标相关信息 −1.0、最终答案泄露目标 −2.0；对保留查询则奖励正确且帮助性的回答，惩罚无必要拒绝和严重幻觉。
  - **优化算法**：使用 **GRPO（Group Relative Policy Optimization）**，对每个提示采样 G 条轨迹，计算群组归一化优势值，并用裁剪目标与 KL 惩罚约束策略不偏离阶段一的模型。
    - A_i = (R_i − mean({R_j})) / (std({R_j}) + ε)
    - L_RL(θ) = −E[ min(ρ_i(θ)A_i, clip(ρ_i(θ), 1−ε_clip, 1+ε_clip)A_i) ] + β_KL · KL(π_θ ‖ π_θ₁)
  - 此外引入与遗忘目标无关的一般工具使用保留集 R_T，防止阶段二退化为全局禁用工具或一律拒绝回答。

**威胁模型**：防御者为模型提供方，只能控制发布前的微调；攻击者为下游部署方，可任意选择工具集与提示词，试图通过工具调用恢复遗忘目标。

## 6. 论文的主要结论与发现

- **结论一**：标准参数遗忘在智能体部署下显著失效。以 RWKU/Qwen-3-4B 为例，NPO 独立推理的 All 遗忘分从 57.7 降至 44.6，但部署为工具智能体后回升至 68.6；MUSE 上从 9.7 升至 29.8（Qwen-3-4B）、从 10.0 升至 32.9（Qwen-2.5-7B）。工具访问是恢复已遗忘知识的主要通道（工具贡献 Δ_tool 达 +22.8，而单纯框架效应仅 +1.2）。
- **结论二**：ATU 能有效降低工具介导恢复。在 RWKU/Qwen-3-4B 上，NPO + Stage 2 将 All 从 68.6 降至 47.5（降幅 21.1 点），且在 QA、FB、AA 各探针类型均有一致改善；在 MUSE 上，Qwen-3-4B 的 knowmem_f 从 29.8 降至 15.8，Qwen-2.5-7B 从 32.9 降至 22.4。
- **结论三**：ATU 的效果具有跨基准、跨模型的泛化性，但对工具替换和强制检索指令仍存在残余泄漏（如"精确复制工具输出"条件下 All 回升 +10.2），说明工具介导恢复的缺口无法完全闭合。
- **结论四**：ATU 在遗忘与效用之间取得更好的平衡：保留集上的邻居知识、事实性、流畅性以及一般工具使用能力均保持在与阶段一相当的水平，未出现整体效用崩塌或全局拒绝回答。
- **结论五**：行为层面，阶段一遗忘后智能体在遗忘查询上的工具调用率反而上升（以工具作为替代恢复路径），阶段二显著下调了目标导向的工具调用，但并非简单禁用所有工具。

## 7. 优点

- **问题发现的准确性**：首次明确指出"参数遗忘 + 工具增强部署"之间的评估错位，并通过定量实验（图 2、表 3）直观证明工具介导恢复是真实且普遍的问题。
- **方法设计的层次性**：两阶段框架将参数级遗忘与轨迹级工具行为训练解耦，既兼容已有的多种参数遗忘方法（GA/RT/DPO/NPO 均可作为阶段一），又通过轨迹级奖励灵活塑造工具使用行为，模块化程度较高。
- **奖励设计的精细性**：遗忘查询奖励并非简单二值（安全/不安全），而是五级连续评分，区分了"冒险工具调用"与"最终答案泄漏"，使模型能在不放弃工具的情况下学会回避目标导向的工具行为；保留查询奖励也明确惩罚过度拒绝。
- **实验验证的系统性**：从主基准到消融、工具替换、未见查询、强制检索对抗指令、奖励 judge 人工验证等，覆盖面广；并提供了完整案例（附录 F）展示阶段一与阶段二在相同查询上的行为差异。
- **威胁模型清晰**：明确区分模型提供方（defender）与下游部署方（adversary）的边界，并将工具集选择权赋予部署方，符合现实发布流程。

## 8. 不足与局限

- **无法完全闭合工具介导恢复缺口**：作者承认，ATU 虽能显著降低工具介导恢复，但当外部工具返回高度相关或明确的证据时，模型仍可能将证据纳入最终回答，遗忘分数未完全恢复到独立推理的水平；面对"精确复制工具输出"等更强的对抗指令时，残余泄漏更明显。
- **工具环境覆盖有限**：阶段二训练使用有限集合的模拟工具，真实下游智能体可能使用不同的工具 API、检索源、持久记忆或多智能体工作流；文中工具替换实验仅替换了同类型工具（如换一种搜索 API），未覆盖异构工具生态。
- **奖励依赖 LLM judge**：轨迹奖励由冻结的 LLM judge 打分，虽然进行了人工一致性验证（98.6%），但 judge 的评分偏差会直接影响训练效果；文中也展示了不同 judge 模型（4B/7B/8B）导致下游遗忘效果差异较大（All 从 47.5 到 60.0），说明对 judge 选择较敏感。
- **部分实验样本规模偏小**：RWKU 仅取前 100 个遗忘目标；未见查询泛化实验仅针对单个目标 47 条查询；一般工具保留集仅 80 个样本、未见工具仅 40 个样本，统计效力有限。
- **未涉及更复杂的恢复通道**：多步多工具链恢复、记忆系统持久化、多智能体协作、间接注入等方式可能带来论文未覆盖的恢复途径。
- **超参数与训练细节的调优空间**：阶段二的 GRPO 训练仅报告了 128 步的训练动态，长程训练的稳定性、KL 系数与轨迹采样量的调优边界未作系统探讨。
