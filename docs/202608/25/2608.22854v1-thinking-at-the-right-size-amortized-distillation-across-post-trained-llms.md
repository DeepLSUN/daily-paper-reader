## 摘要
大型语言模型（LLM）的实际部署需要一系列后训练变体——指令微调、推理微调和聊天风格模型——每种都有多个规模，以满足不同的延迟和内存预算。独立生成每个（变体，规模）对的成本高得令人望而却步，因此模型族通常每类后训练变体只覆盖少量粗粒度规模。Boomerang蒸馏（Kangaslahti等人，2026）在基础模型的规模轴上降低了这一成本。通过模型规模插值，它从单个教师-学生对构建中间规模的模型，无需额外训练。然而，它仍将每个后训练变体视为独立的优化对象。我们提出ADAPT——跨后训练LLM的摊销蒸馏——一个在模型族的两个轴上摊销蒸馏的框架：规模和后训练变体，通过单次蒸馏运行，为K个后训练变体的L个插值规模生成L×K个模型。ADAPT结合了两个组件。首先，两阶段蒸馏过程通过预训练对齐和监督微调蒸馏构建后训练学生模型，实现在生成和推理任务上规模和性能的平滑插值。其次，权重增量初始化通过将蒸馏引起的权重变化从基础模型转移到从不同后训练变体初始化的学生模型，近似跨后训练变体的构建。由此产生的插值模型连续体还支持推理时的自适应模型规模选择，改善长格式推理任务的计算-精度权衡。

## Abstract
Practical deployment of large language models (LLMs) requires families of post-trained variants---instruction-tuned, reasoning-tuned, and chat-style models---each at multiple sizes to meet diverse latency and memory budgets. Producing each (variant, size) pair independently is prohibitive, so model families typically span only a handful of coarse-grained sizes per post-trained variant. Boomerang distillation (Kangaslahti et al., 2026) reduces this cost along the size axis for base models. Through model size interpolation, it constructs models of intermediate sizes from a single teacher-student pair without additional training. However, it still treats each post-trained variant as a separate object of optimization. We introduce ADAPT---Amortized Distillation Across Post-Trained LLMs---a framework for amortizing distillation across both axes of a model family: size and post-training variant, producing $L \times K$ models for $L$ interpolated sizes across $K$ post-trained variants with a single distillation run. ADAPT combines two components. First, a two-phase distillation procedure constructs post-trained students through pre-training alignment and supervised fine-tuning distillation, enabling smooth size--performance interpolation on generation and reasoning tasks. Second, weight-delta initialization approximates this construction across post-trained variants by transferring the distillation-induced weight change from the base model to students initialized from different post-trained variants. The resulting continuum of interpolated models also enables adaptive model-size selection at inference time, improving the compute--accuracy trade-off for long-form reasoning tasks.

## 1. 论文的核心问题与整体含义

- **背景**：LLM 的实际部署往往需要“后训练模型家族”——同一基础模型上衍生出指令微调、推理微调、聊天等多种变体，且每个变体又需要覆盖从移动设备到多 GPU 服务器的多种规模，以满足不同的延迟与内存预算。逐一独立训练每个（变体，规模）组合在计算上不可行，导致现有的模型家族通常只在少数粗粒度规模上提供少量变体。
- **已有方法的局限**：
  - 任务向量（Task Vectors）等权重算术方法可以跨模型迁移微调能力，但仅限于同规模模型，无法覆盖规模轴。
  - Boomerang 蒸馏（BD）通过教师-学生蒸馏和层拼接，可以在基础模型上零训练地生成一系列连续规模的中等尺寸模型，但仅覆盖“规模”轴，且只针对预训练基础模型，不涉及后训练变体。
- **本文研究的问题**：能否把 Boomerang 蒸馏扩展到后训练模型？能否在零样本情况下，将规模插值同时应用到同一基础模型的多个后训练变体上，实现“一次蒸馏、多处复用”？
- **整体含义**：通过将蒸馏过程在两个轴（规模轴 × 后训练变体轴）上同时摊销，显著降低生产后训练模型家族的计算成本，并支持推理时按输入难度动态选择模型规模，提升计算-精度权衡。

## 2. 论文提出的方法论

### 2.1 核心思想
- 提出 **ADAPT（Amortized Distillation Across Post-Trained LLMs）** 框架，目标是用单次蒸馏运行生成 \( L \times K \) 个模型：L 个插值规模 × K 个后训练变体。
- 框架由两大核心组件构成：
  1. **两阶段蒸馏**（ADAPT-distilled）：解决“如何从后训练教师蒸馏出可平滑插值的学生”问题。
  2. **权重增量初始化**（ADAPT weight-delta）：解决“如何把一次基础模型蒸馏的结果复用到多个后训练变体”的问题，无需额外训练。

### 2.2 两阶段蒸馏（ADAPT distilled）
- **学生初始化**：沿用 Boomerang 蒸馏的学生初始化方法——将教师 N 层划分为 M 个连续块，每个块取第一层来初始化对应的学生层，嵌入层与 LM head 也由教师初始化。
- **阶段一：预训练对齐**：在预训练语料（如去重后的 Pile）上，使用综合损失进行蒸馏：
  \[
  \mathcal{L}(x_j) = \text{CE} + \lambda_{KL} \text{KL}\big(p_T \| p_S\big) + \lambda_{\cos} \sum_{i=1}^{M} \mathcal{L}^{(i)}_{\cos}
  \]
  其中 CE 为交叉熵、KL 为师生输出分布的 KL 散度、Cosine 为每层学生输出与对应教师块输出的余弦距离。
- **阶段二：监督微调（SFT）蒸馏**：在指令/推理数据（如 Llama Nemotron 数学子集）上使用相同蒸馏目标，但损失只计算在响应 token 上，以恢复指令跟随和推理能力。
- **关键细节**：
  - 两阶段各占一半训练预算，使用连续的学习率调度（单一 cosine schedule），避免两个独立调度器带来的性能下降。
  - 两阶段缺一不可：仅预训练蒸馏（BD pre-train）在中小规模上生成/推理能力崩溃；仅 SFT 蒸馏（BD SFT）虽然在小规模 ID（领域内）任务上尚可，但 OOD（领域外）泛化差。
- **学生 patching（层拼接）**：蒸馏后，通过将学生层替换为对应教师层来构造中间规模模型；实验中采用前向后向/后向前向两种简单顺序，并选择各模型上表现更好的顺序；另有 KLPatch 可作为正交改进。

### 2.3 权重增量初始化（ADAPT weight-delta）
- 设基础模型学生的初始化为 \(\theta^{base}_{S,\text{init}}\)，两阶段蒸馏后为 \(\theta^{base}_{S,\text{distill}}\)，定义蒸馏增量：
  \[
  \Delta^{base}_{S,\text{distill}} = \theta^{base}_{S,\text{distill}} - \theta^{base}_{S,\text{init}}
  \]
- 对任意后训练变体 T，以其对应的教师初始化学生 \(\theta^{PT}_{S,\text{init}}\)（同样的层选择规则），则构造：
  \[
  \theta^{PT}_{S,\Delta} = \theta^{PT}_{S,\text{init}} + \Delta^{base}_{S,\text{distill}}
  \]
- 得到的权重增量初始化学生无需训练即可近似“直接蒸馏的后训练学生”，从而把单次基础模型蒸馏“复制”到所有后训练变体上。

- **充分性评估**：
  - 覆盖模型族较多（Qwen、Olmo、Llama），规模覆盖 4B–14B；任务覆盖数学、指令跟随、通用知识、分类、代码。
  - 所有方法在相同训练预算、相同学生架构、相同评估协议下比较，基准设置公平。
  - 引入误差棒（一个标准差）以反映随机性。
  - 有一定不足：主要结果在 4B 规模上系统验证，更大规模（14B）上的实验较少且未给出详细消融；外部泛化（如多语言、更宽指令混合）未覆盖。

## 6. 主要结论与发现

1. **两阶段蒸馏是关键**：直接在 post-trained 教师上应用 BD（pre-train）会使中小规模模型的生成与推理性能崩溃；加入 SFT 阶段（ADAPT distilled）才能恢复指令跟随和推理能力，并稳定 OOD 性能。
2. **权重增量初始化有效**：从基础模型蒸馏中提取的权重 delta，可以不经训练地加到各后训练变体的初始化学生上，在 ID 任务上接近 ADAPT (distilled) 上界，OOD 任务上有轻微下降（主要是 thinking 风格模型的 `<think>` 标签解析伪影导致），但显著优于 cross-patch 基线。
3. **自适应模型选择带来 Pareto 最优**：在 MATH 数据集上，根据教师预测的难度将问题路由到最小且准确率达标的学生模型，其平均与最小准确率 - 计算量的权衡曲线优于任何单一固定模型。
4. **平滑权重插值在蒸馏后仍被保留**：基础模型与后训练模型之间、以及对应蒸馏学生之间，都存在低损失线性插值路径（size-agnostic smooth weight interpolation）。这解释了权重算术转移为何有效，且暗示与线性模式连接（linear mode connectivity）的联系。
5. **层剪枝方法在生成任务上远不如 ADAPT**：ShortGPT 与 LLM-Streamline 难以恢复中小规模的生成能力，ADAPT 在所有插值规模上明显优于它们。

## 7. 优点

- **创新性**：首次同时摊销“模型规模”和“后训练变体”两个轴上的蒸馏成本，提出 weight-delta 初始化这种零训练转移机制，具有很强的实用性。
- **实验设计扎实**：
  - 对比了多种强基线（直接 BD、SFT-only、cross-patch、层剪枝方法），且计算量匹配。
  - 含丰富的消融（阶段比例、损失项、delta 来源、继续训练等），系统验证各组件必要性。
  - 多模型族（Qwen、Olmo、Llama）、多任务（数学、指令、代码、分类）验证。
- **几何分析提供解释力**：通过损失景观、AUC 平面等分析展示权重空间的连通性，为 weight-delta 成功提供机制理解而非仅经验现象。
- **应用价值**：生成连续规模模型支持推理时动态路由，直接改善部署时的计算利用率。

## 8. 不足与局限

- **插值曲线局部塌陷**：某些中间规模出现性能骤降，论文认为可能是教师层与学生层局部不对齐造成，但未给出精确机制或预测方法。
- **weight-delta 转移并非普适**：在 Olmo、Llama 上转移效果不如 Qwen 稳定，依赖模型家族的权重兼容性和后训练细节；需要 base checkpoint 可用，限制了闭源或无法精确识别基础模型的场景。
- **模型与数据范围**：实验集中在 4B–14B 规模，未验证更大模型（如 70B+）上的摊销增益；SFT 数据主要限于数学和代码（Nemotron split），未验证多语言或更广指令混合。
- **自适应推理依赖难度信号**：实验使用教师模型预测难度，虽然便宜但属于任务特定设置；对难度难以定义或需要额外难度预测器成本的场景，泛化性未充分表征。
- **OOD 性能缺口**：weight-delta 方法在 thinking 模型上因 `<think>` 格式解析问题出现性能下降，虽说明非生成质量损失，但实际使用中需要额外后处理。
- **收益动机的验证局限**：对于一次性蒸馏到多个变体带来的实际成本节省，论文没有给出端到端的总体计算量对比（如训练 vs 节省），更多是概念性论证。
