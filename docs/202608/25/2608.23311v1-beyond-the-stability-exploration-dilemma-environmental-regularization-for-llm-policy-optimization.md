## 摘要
大语言模型的策略优化（PO）面临稳定性与探索之间的权衡，目前由动作侧的Policy-KL正则化器来调节。这使从业者陷入两难境地：保留Policy-KL会约束响应行为并消耗动作侧的探索预算，而丢弃它则使优化缺乏明确的漂移控制。我们提出一种替代方案，通过将正则化移至输入侧来打破这一困境。随着训练的进行，由当前策略引起的训练查询分布会不受控制地偏离其RL前的参考分布。具体而言，环境正则化策略优化（ERPO）引入了一个查询KL（QKL）项来限制这种查询分布偏移，同时使用一个数据集静态的、由参考派生的逐查询权重，使每次查询更新偏向参考下典型的查询。QKL梯度严格通过查询似然流动；策略梯度估计器使用的响应评分函数不出现在QKL项中，因此QKL对响应分布不产生直接的梯度压力——探索得以保留。ERPO可无缝集成到GRPO/PPO/REINFORCE风格的流程中，无需额外的前向传播。在六个数学推理基准上，ERPO取代了标准的Policy-KL正则化器，同时实现了对查询分布漂移的有效控制，在高温解码和长时程训练下提供了更强的准确性和显著更稳定的行为。我们的源代码可在 https://github.com/alibaba/ERPO 获取。

## Abstract
Policy optimization (PO) for Large Language Models faces a stability--exploration trade-off, currently mediated by an action-side Policy-KL regularizer. This puts practitioners in a double bind: keeping Policy-KL constrains response behavior and consumes the action-side exploration budget, while dropping it leaves the optimization without an explicit drift control. We argue for an alternative that breaks the dilemma by moving regularization to the input side. As training progresses, the distribution over training queries induced by the current policy drifts unchecked from its pre-RL reference distribution.   Concretely, Environment-Regularized Policy Optimization (ERPO) introduces a Query-KL (QKL) term that bounds this query distribution shift, together with a dataset-static reference-derived per-query weight that biases each per-query update toward queries typical under the reference. The QKL gradient flows strictly through the query likelihood; the response score function used by policy-gradient estimators does not appear in the QKL term, so QKL exerts no direct gradient pressure on the response distribution---exploration is preserved. ERPO plugs into GRPO/PPO/REINFORCE-style pipelines without additional forward passes. On six mathematical reasoning benchmarks, ERPO replaces the standard Policy-KL regularizer while achieving effective control over query distribution drift, delivering stronger accuracy and substantially more stable behavior under high-temperature decoding and long-horizon training.Our source code are available at https://github.com/alibaba/ERPO

## 1. 核心问题与整体含义（研究动机与背景）

- **稳定性-探索两难困境**：LLM 策略优化（Policy Optimization, PO）在训练中面临稳定性与探索之间的根本矛盾。现行主流做法是通过动作侧（action-side）的 Policy-KL 正则化（限制当前策略与 SFT 参考策略的 KL 散度）来控制更新幅度，但这构成了一个"双重束缚"：
  - 若保留 Policy-KL：它约束了响应行为，消耗了本应用于探索的预算，导致探索不足；
  - 若丢弃 Policy-KL：优化过程缺乏显式漂移控制，训练易发散或崩溃。
- **被忽略的输入侧非平稳性**：作者指出，一个关键且未被充分控制的失稳来源是"查询分布（query distribution）"意义上的环境非平稳性。即使训练语料固定，随着 θ 更新，模型对训练查询的自回归似然也会漂移，使有效训练环境发生变化，放大梯度方差，造成长期训练中的震荡和性能塌缩。
- **经验证据**：在固定 Policy-KL 预算下，GRPO 训练的 query 级 KL 持续上升，而 policy 级 KL 保持平稳——说明仅约束动作分布并不能稳定查询过程，即"环境"本身仍在漂移。
- **核心主张**：将正则化从输出/动作侧转移到输入/查询侧，直接约束策略引发的查询分布相对 RL 前参考分布的偏移，从而在不牺牲动作空间探索的前提下实现稳定训练。这一思路借鉴了非平稳/鲁棒 RL 中对初始状态分布或转移核的显式控制，以及模仿学习中针对协变量偏移的 DAgger/AggreVaTe 思想。

## 2. 方法论：核心思想、关键技术细节与公式

### 2.1 总体框架：环境正则化策略优化（ERPO）

- **核心思想**：将策略引起的查询分布 ρθ 视为"环境"，把 RL 前的参考查询分布 ρθ₀ 视为环境参考；在策略优化目标中显式惩罚 ρθ 相对 ρθ₀ 的漂移，同时保持响应侧 πθ(o|q) 的探索自由。
- **工作假设（A1）**：维持模型诱导的查询分布与 RL 前参考之间的一致性，比允许无约束漂移更能保留前期训练（预训练/SFT）继承的泛化能力——A1 通过实验进行验证。

### 2.2 查询似然与 Query-KL（QKL）

- 对查询 q（分词为 x₁...x_T），定义查询似然：

  ℓθ(q) = log Pθ(q) = Σₜ log Pθ(xₜ | x<ₜ)

  参考似然 ℓθ₀(q) 在训练前对全量数据集计算一次并缓存，训练中不变。

- **Query-KL 正则项**：

  R_query(θ) := KL(ρθ ∥ ρθ₀) = E_{q∼ρθ}[log ρθ(q) − log ρθ₀(q)]

- **命题 1（结构解耦）**：正则项的梯度可写为闭式解：

  ∇θ R_query(θ) = E_{q∼ρθ}[(ℓθ(q) − ℓθ₀(q)) · ∇θℓθ(q)]

  即梯度严格只经查询似然 ℓθ(q) 流动，响应策略的 score function ∇θlog πθ(o|q) 完全不出现——因此 QKL 对响应分布不产生任何直接的梯度压力，探索被完全保留。

### 2.3 查询重加权（Query Reweighting）

- ERPO 的目标实质上从"训练集经验分布 ρ_train 下的期望奖励"转向"参考对齐的查询先验 ρθ₀ 下的期望奖励"：

  J_ERPO(θ) = E_{q∼ρθ₀, o∼πθ(·|q)}[g(q,o)]

- 由于训练时查询来自 ρ_train，引入理想重要性权重：

  w⋆(q) = ρθ₀(q)/ρ_train(q)

  在近似均匀采样、数据集大小为 N 时，w⋆(q) = N·ρθ₀(q)，因此只需保持参考先验下查询的相对排序。
- **实用实现**：为避免数值不稳定和方差过大，使用裁剪后的、数据集静态的权重：

  w(q) = clip( s̄ / sᵢ, 0, 2 )

  其中 sᵢ = −log p_θ₀(qᵢ) 为参考负对数似然，s̄ 为数据集的均值（使权重无量纲且尺度居中）。

### 2.4 最终损失与 PG 兼容性

- ERPO 小批量损失为：

  L_PG(θ) = −(1/m)Σ_{q∈B} w_B(q) Σ_{o∈G(q)} uθ(q,o)·A⋆θ(q,o) + α·R̂_query(θ)

- ERPO 是完全**估计器无关**的：只需指定 (uθ, A⋆θ) 即可复现
  - **GRPO**（uθ≡1，A 为组内相对优势）、
  - **PPO**（clip 比率 + GAE 优势）、
  - **REINFORCE**（uθ≡1，A = g−b）。
- **零额外前向传播开销**：ℓθ₀ 预计算并缓存；ℓθ(q) 由基础 PG 估计器已有的 per-query 前向传播天然提供。Query 权重完全预计算、无梯度；QKL 估计也复用现有前向结果。

## 6. 主要结论与发现

1. **准确性全面提升**：ERPO 在 6 个数学推理基准上的平均性能显著超过 GRPO——Avg@32 平均提升 6.2%（最高 14.9%）、Pass@32 提升 3.64%、Pass@1 提升 5.69%，且 32B 模型上提升更明显（Avg@32 提升 2.98%，高温区间 1.2–1.5 提升高达 25.6% 个百分点）。
2. **有效控制查询分布漂移**：ERPO 将 query 级 KL 压制到极低水平（GRPO 的约 1/250），验证了输入侧正则化确实能约束环境非平稳性；policy 级 KL 虽未显式约束，也能维持在较合理范围。
3. **稳定性显著提升**：长时程训练（1K 步）中，GRPO 在约 400 步后出现高温采样性能崩溃，并随后蔓延至所有温度；ERPO 的退化幅度显著更小，高温区间甚至出现性能改善，证明了其对长期训练更稳健。
4. **有效缓解奖励攻击**：GRPO 的训练-评估精度平均差距为 6.47%（第 240 步时评估精度从约 75% 骤降至 58.4%），而 ERPO 将差距降低约 51%（至 3.14%），表明训练改进能更可靠地迁移到推理阶段。
5. **通用性**：ERPO 替换 Policy-KL 后可在 DAPO、RLOO 等不同 RLVR 算法上带来绝对提升（≤1.0 温度下分别 +10.24% 与 +2.28%），印证了其估计器无关的设计。
6. **采样数量影响**：将采样数从 8 增至 16，ERPO 的平均 Pass@1 提升至 74.6%，并显著改善了高温采样的稳定性（1.2–1.5 区间从 37.9% 升至 66.25%）。

## 7. 优点与亮点

- **概念创新性强**：将"查询分布漂移"显式概念化为 RL 中的环境非平稳性，跳出"动作侧 KL 正则化"的思维定式，提出了一个新的输入侧正则化视角，具有较好的理论与实际意义。
- **理论保证清晰**：命题 1 给出了 QKL 梯度只经查询似然流动的闭式证明，从结构上保证了"正则化"与"探索"的解耦，理论论证简洁有力。
- **工程上近乎零开销**：参考似然预计算并缓存、查询权重数据集静态化、QKL 复用 PG 前向传播——无需额外前向传递，无需修改基础估计器的内部逻辑，插件式接入 GRPO/PPO/REINFORCE，对现有 RLHF/RLVR 系统友好。
- **评估方法更严谨**：显式控制推断温度（0.1–1.5）并聚合报告，避免了很多工作因温度未说明而结果不可比的问题；同时将高温采样性能作为稳定性指标，为评估 RL 长程稳定性提供了新范式。
- **多维度验证**：不仅有精度提升，还从 query/policy KL 轨迹、长时训练稳定性曲线、训练-推理一致性差距、查询-响应似然相关性等角度提供解释性证据，使结论更有说服力。
- **算法无关性得到实证**：不仅验证了 GRPO，还在 DAPO/RLOO 上确认增益，说明方法具有广泛适用潜力。

## 8. 不足与局限

- **任务覆盖面有限**：仅在数学推理基准上验证，对指令跟随、对话、代码生成、多语言等场景的迁移性未知（作者在 Limitations 中明确承认）。
- **模型族局限**：只使用了 Qwen2.5-Math 系列，未验证在其他基础模型（如 Llama、Mistral）上的表现。
- **算力细节缺失**：未报告 GPU 型号、数量和训练时长，复现成本难以评估。
- **超参数调优不充分**：正则化强度 α 仅尝试了 3 个值且未做系统搜索；作者也承认留待未来工作。
- **理论假设依赖经验支持**：工作假设 A1（参考环境更有利于泛化）本质上是经验假设，缺乏理论保证；虽然实验支持，但在其他任务上的普适性还待检验。
- **查询似然估计的可靠性**：方法依赖对查询似然（或出现频率统计）的估计质量；不同数据筛选机制（课程学习、难度过滤、主动采样）下该估计的质量和成本可能差异较大。
- **探索保留的间接性**：虽然 QKL 不直接约束响应分布，但通过约束查询分布并影响更新方向，仍可能间接影响响应行为；这种间接效应的大小未被定量分离。
- **统计稳健性不足**：未报告多次运行的均值方差或显著性检验结果，对单次训练的随机性敏感度未知。

## 总结

ERPO 通过对输入侧查询分布施加 KL 正则化并经参考先验重加权，有效化解了 LLM 策略优化中长期存在的稳定性-探索两难困境。其在多个数学推理基准上全面超越使用 Policy-KL 的 GRPO，显著提升长时训练稳定性和高温采样鲁棒性，同时保持极低的工程开销和广泛的估计器兼容性。作为新的"环境正则化"范式，它为 RLVR/RLHF 训练提供了有价值的替代思路，但其任务/模型覆盖面、超参数敏感性及理论保障仍需进一步探索。
