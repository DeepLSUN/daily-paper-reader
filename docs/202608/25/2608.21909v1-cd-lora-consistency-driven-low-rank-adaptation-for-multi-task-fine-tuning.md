## 摘要
虽然多任务学习（MTL）对于将大型语言模型（LLM）适应到不同领域至关重要，但流行的基于LoRA的方法依赖于复杂的路由机制来划分任务特定知识。在这项工作中，我们揭示了这种基于路由的设计容易出现训练-推理差异，即分布偏移下的随机路由决策会损害推理稳定性。通过二阶泰勒分析揭示了路由方差引起的不稳定性，我们挑战了训练-推理差异，并提出了一致性驱动低秩适配（CD-LoRA）。通过完全消除路由器，CD-LoRA采用一致性驱动对齐机制，在共享低秩空间中强制跨任务表示一致性。这种范式在不增加显式划分开销的情况下促进了稳健、任务无关的特征。大量实验表明，CD-LoRA始终优于最先进的多适配器基线，为多任务PEFT提供了一种更简单、无路由器且更稳定的解决方案。代码可在匿名链接https://github.com/zhaqian21/CD-LoRA获取。

## Abstract
While Multi-Task Learning (MTL) is essential for adapting Large Language Models (LLMs) to diverse domains, prevailing LoRA-based methods rely on complex routing mechanisms that partition task-specific knowledge. In this work, we reveal that such routing-based designs are prone to a training-inference discrepancy, where stochastic routing decisions under distribution shifts compromise inference stability. Driven by a second-order Taylor analysis that exposes the instability induced by routing variance, we challenge the training-inference discrepancy and propose Consistency-Driven Low-Rank Adaptation (CD-LoRA). By eliminating routers entirely, CD-LoRA employs a consistency-driven alignment mechanism to enforce representation congruence across tasks in a shared low-rank space. This paradigm fosters robust, task-agnostic features without explicit partitioning overhead. Extensive experiments show that CD-LoRA consistently outperforms state-of-the-art multi-adapter baselines, offering a simpler, router-free, and more stable solution for multi-task PEFT. The code is available at the anonymous link https://github.com/zhaqian21/CD-LoRA.

- 大型语言模型（LLM）在各类 NLP 任务中表现优异，但将其适配到特定领域或任务分布时仍需参数高效微调（PEFT），其中 LoRA 是主流方法。
- 将 LoRA 扩展到多任务学习（MTL）时，现有方法普遍采用**多适配器**或**多分支 + 动态路由**的架构（如 HydraLoRA、R-LoRA、M-LoRA 等），假设“多任务适配必须依赖路由机制来解耦任务特定知识”。
- 论文指出这类路由型设计存在一个根本问题：**训练-推理不一致**（Training–Inference Discrepancy）。训练时使用随机 dropout 掩码和随机路由，推理时则用确定性掩码和固定聚合，由于 softmax 路由的非线性，期望训练输出与推理输出之间产生系统性偏差，损害推理稳定性。
- 论文的核心主张是：**多任务微调的成功并不依赖于显式的任务划分或复杂的路由机制，而在于维护共享低秩空间中的表示一致性**。由此提出 CD-LoRA：完全移除路由器，用一致性驱动对齐（Consistency-Driven Alignment）来稳定共享低秩投影，实现更简单、更稳定且性能更优的多任务 PEFT。

## 2. 论文提出的方法论：核心思想与关键技术细节

### 核心思想
- **De-routing（去路由化）**：移除 MoE 式 LoRA 中的路由网络，将所有 LoRA 分支视为均匀贡献，使训练和推理共享完全一致的前向计算图，消除路由非线性导致的训练-推理差异。
- **Consistency-Driven Alignment（一致性驱动对齐，CD-A）**：对共享的 LoRA-A 投影施加一致性正则化，强制同一输入在两次独立随机扰动下产生的潜在表示对齐，从而平滑低秩流形的曲率，间接约束 Hessian 范数，缩小训练-推理差距。

### 技术细节与公式
- 路由型 LoRA 训练输出：  
  `ΔW(x,z) = Σ_i ω_i(x,z) · B_i A(x ⊙ z)`
  其中 ω_i 是 softmax 路由权重，z 是随机 dropout 掩码。
- 去路由后的输出：  
  `f̂(x,z) = Wx + Σ_i B_i A(x ⊙ z)`，所有分支均匀参与，不再依赖输入选择。
- 训练-推理差异（TID）分解：  
  `TID(x) ≤ (1/N Σ||B_i||) · || E_z[A(x⊙z)] − A(x⊙z̄) ||`，表明 TID 主要源于共享投影 A 对随机扰动的敏感性。
- 二阶泰勒展开分析：  
  `E_z[g(z)] − g(z̄) ≈ ½ Tr(∇²g(z̄) · Var(z))`，即 TID 由 LoRA-A 投影流形的曲率（Hessian）决定。
- 一致性损失：对两个独立随机前向得到的表示 h⁽¹⁾、h⁽²⁾ 在假定各向同性高斯分布下，对称 KL 散度简化为：  
  `D_SKL(P∥Q) ∝ ||h⁽¹⁾ − h⁽²⁾||²`
  最小化该损失可隐式约束 Hessian 范数，实现曲率平滑。
- 最终目标：  
  `L_total = L_task + λ · L_cons`，其中 λ 为一致性正则权重（主实验设为 0.05）。

### 架构特点
- CD-LoRA 采用双前向设计：A 为主投影，A′ 提供辅助随机视图；一致性损失对齐两视图输出，平滑共享低秩流形。
- 无需路由器和额外推理开销，训练后 ΔW 可合并回主干权重。

## 6. 论文的主要结论与发现

- 路由型多分支 LoRA（R-LoRA 等）存在固有的训练-推理不一致，软max 非线性导致训练时随机路径与推理时确定性路径产生偏差，这一偏差是性能瓶颈。
- 去除路由（DR-LoRA）本身就比保留路由（R-LoRA）在 5 任务消融上平均提升 0.70%，且峰值内存降低 24.5%，说明路由并非必要甚至有害。
- 在去路由基础上加入一致性对齐（CD-LoRA）进一步提升性能：7B 上平均准确率 83.92%（超过 R-LoRA 0.80%、M-LoRA 0.49%），14B 上达 85.90%（超过 R-LoRA 1.18%）。
- 表示可视化（t-SNE）显示，CD-LoRA 在共享低秩空间中学习到更紧凑、任务可分的表示，优于路由方法中高度重叠的结构。
- 机制分析表明，CD-LoRA 显著提高了 LoRA-B 矩阵的跨任务子空间一致性（14B 平均余弦相似度 84.93% vs R-LoRA 的 77.64%），抑制了路由引起的表示碎片化。
- 一致性正则强度 λ 在 [0.01, 0.1] 区间内稳健，最优为 0.03；过大（0.5 以上）会过度约束而损害性能。
