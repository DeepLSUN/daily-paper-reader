## 摘要
由多模态大语言模型（MLLMs）驱动的图形用户界面（GUI）代理在跨多种数字环境自动化任务方面展现出强大的潜力，其中强化学习（RL）已成为主导的训练范式。然而，诸如群体相对策略优化（GRPO）等广泛使用的方法存在奖励梯度错配问题，导致优化效率低下且不稳定。近期工作通过将具有可验证奖励的强化学习（RLVR）重新表述为对比式或基于分类的目标来解决此问题，从而通过消除有问题的梯度行为来提高稳定性。尽管取得了这些进展，现有的对比式RLVR方法主要依赖于结果级别的监督，未能捕捉同一结果类别内轨迹质量的细粒度差异。在本文中，我们提出了面向GUI代理的长度感知对比学习（LACL-GUI），这是一种将轨迹级质量信号纳入策略优化的对比式RLVR框架。LACL-GUI在成功和失败的轨迹中都引入了结构化偏好，鼓励简洁的成功执行，并根据与成功轨迹的偏离程度区分失败质量，同时保持优化稳定性。在GUI代理基准上的实验表明，LACL-GUI提供了更有效的学习信号，并持续提升了代理相比于先前方法的性能，凸显了轨迹级监督在对比式RLVR中的价值。

## Abstract
Graphical User Interface (GUI) agents powered by Multimodal Large Language Models (MLLMs) have shown strong potential for automating tasks across diverse digital environments, where reinforcement learning (RL) has become a dominant training paradigm. However, widely used methods such as Group Relative Policy Optimization (GRPO) suffer from reward-gradient misalignment, leading to inefficient and unstable optimization. Recent work addresses this issue by reformulating RL with verifiable rewards (RLVR) as contrastive or classification-based objectives, which improve stability by eliminating problematic gradient behaviors. Despite this progress, existing contrastive RLVR methods rely primarily on outcome-level supervision and fail to capture fine-grained differences in trajectory quality within the same outcome category. In this paper, we propose Length-Aware Contrastive Learning for GUI Agents (LACL-GUI), a contrastive RLVR framework that incorporates trajectory-level quality signals into policy optimization. LACL-GUI introduces structured preferences within both successful and failed trajectories, encouraging concise successful executions and differentiating failure quality based on divergence from successful trajectories, while preserving optimization stability. Experiments on GUI agent benchmarks show that LACL-GUI provides more effective learning signals and consistently improves agent performance over prior methods, highlighting the value of trajectory-level supervision in contrastive RLVR.

- **核心问题**：GRPO 存在“奖励-梯度错配”问题——优化压力由策略似然而非轨迹质量主导，导致优化效率低且不稳定；近年提出的对比式/分类式 RLVR 方法（如 REAL）虽然解决了梯度病理问题，但仍只依赖二元的“成功/失败”结果级监督，无法区分同一结果类别内部轨迹质量的细粒度差异（如成功轨迹的冗余程度、失败轨迹离成功有多近）。
- **整体含义**：现有对比 RLVR 方法的学习信号粗糙，限制了 GUI 代理训练效果。论文主张在保持优化稳定性的前提下，将轨迹级质量信号注入对比 RLVR 框架，从而提升策略优化质量。

## 2. 论文提出的方法论

- **核心思想**：提出 LACL-GUI（Length-Aware Contrastive Learning for GUI Agents），在对比 RLVR 框架（以 REAL 为基础）之上，通过“结果保留、零均值 logit 扰动”的方式，在成功和失败轨迹组内部引入细粒度偏好：
  - **成功轨迹**：鼓励更简洁的执行路径（长度感知偏好）；
  - **失败轨迹**：根据失败轨迹与参考成功轨迹的分歧程度区分错误严重性（分歧感知偏好），对近成功失败施加较弱抑制，对早期偏离的失败施加更强抑制。
- **关键公式与算法流程**（用文字说明）：
  - 定义长度归一化相对对数概率得分 \( \bar{s}_j \) 作为 logit 值。
  - **正组扰动**：对成功轨迹，按 logit 的 softmax 权重计算加权平均长度 \( \mu_w \)，然后将 logit 修正为 \( \tilde{s} = \bar{s} + \epsilon(|\tau_j| - \mu_w) \)，使短轨迹获得相对更大的优化权重。
  - **负组扰动**：对失败轨迹，利用 SSIM 逐步骤计算与参考成功轨迹的首次分歧点，定义错误步数 \( E_j = |\tau_j| - d_j + 1 \)，按 logit 权重计算加权平均错误步数 \( \mu_e \)，修正为 \( \hat{s} = \bar{s} + \epsilon(E_j - \mu_e) \)，使错误步数多的失败受到更强抑制。
  - **总体损失**：\( L_{LACL-GUI} = \log(1 + \sum_{\tau \in T^+} e^{-\tilde{s}/\lambda}) + \log(1 + \sum_{\tau \in T^-} e^{\hat{s}/\lambda}) \)。
  - **理论保证**：通过 stop-gradient 保持组统计量为常数，论文证明了定理1（一阶不变性）——LACL-GUI 目标在一阶上与 REAL 等价，仅引入 \( O(\epsilon^2) \) 高阶调整，因此不会改变成功-失败的分类边界，同时重新分配组内梯度。
- **架构支持**：采用异步解耦训练架构（Rollout Service、Data Manager、Success Buffer、Trainer），其中 Success Buffer 存储成功轨迹作为参考并补充正样本，Data Manager 过滤掉无对比信息的同质轨迹组。
