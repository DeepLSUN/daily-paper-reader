## 摘要
深度搜索已成为大型语言模型（LLM）解决开放域复杂任务的基本能力。然而，现有方法通常依赖线性顺序推理来进行轨迹生成和推断，这使得在长距离多跳搜索中难以一致地保留中间状态和约束。因此，它们常常遭受上下文遗忘、搜索漂移和低效探索的问题。为了解决这些限制，我们提出了\textbf{G-ReAct}，一种深度搜索推理框架，将推理组织为\textbf{在固定拓扑查询图上的状态演化}。演化的图状态明确跟踪搜索进度并指导后续决策，将基于文本历史的探索性搜索转化为显式约束下的图引导推理。G-ReAct支持训练和推断：它为监督微调生成高质量的深度搜索轨迹，并在无需额外微调的情况下为推断时搜索提供结构化指导。实验表明，仅用1.9K条生成的轨迹进行微调，Qwen3-30B-A3B-Thinking-2507在BrowseComp-ZH上达到$52.6\%$的准确率，在XBench上达到$79.0\%$，优于在更大数据集上训练的同类开源方法，包括强化学习增强的方法。此外，在推断时应用时，G-ReAct持续提升现有强LLM在深度搜索任务上的性能。我们将公开发布所有代码和模型权重。

## Abstract
Deep search has become a fundamental capability of large language models (LLMs) for solving open-domain complex tasks. However, existing approaches typically rely on linear sequential reasoning for both trajectory generation and inference, making it difficult to consistently preserve intermediate states and constraints throughout long-horizon multi-hop search. Consequently, they often suffer from context forgetting, search drift, and inefficient exploration. To address these limitations, we propose $\textbf{G-ReAct}$, a reasoning framework for deep search that organizes reasoning as $\textbf{state evolution over a fixed-topology query graph}$. The evolving graph state explicitly tracks search progress and guides subsequent decisions, transforming exploratory search driven by textual history into graph-guided reasoning under explicit constraints. G-ReAct supports both training and inference: it generates high-quality deep-search trajectories for supervised fine-tuning and provides structured guidance for inference-time search without additional fine-tuning. Experiments demonstrate that with only 1.9K generated trajectories for fine-tuning, Qwen3-30B-A3B-Thinking-2507 achieves $52.6\%$ accuracy on BrowseComp-ZH and $79.0\%$ on XBench, outperforming comparable open-source methods trained on substantially larger datasets, including RL-enhanced methods. Furthermore, when applied at inference time, G-ReAct consistently improves the performance of existing strong LLMs on deep-search tasks. We will publicly release all code and model weights.

## 6. 主要结论与发现（续）

- **推理时即插即用**：将 G-ReAct 直接作为推理框架套用到 doubao-seed-2.0-pro、Claude-4.5-Sonnet、OpenAI-o3 时，三个模型在 BrowseComp-ZH 上的表现均优于各自原生的搜索推理管线；例如 Claude-4.5-Sonnet 提升约 12 个百分点。这表明即使在无微调条件下，查询图与结构状态机制也能以“通用框架”的方式增强完全不同的底层模型。
- **组件贡献**：消融显示，移除查询图或状态进化模块后性能显著下降，二者共同构成性能增益的主体；在状态更新粒度上，96K token 的更新窗口为最优区间，32K 过浅易丢约束、128K 过宽易引入噪声，说明**局部历史窗口存在非单调的“甜点区”**。
- **抗退化机制的实际效果**：状态转移函数引入的“只追加事实”“分层候选合并”“高置信度候选保护”三种机制，使状态演化轨迹满足单调非递减性质，直接抑制了 ReAct 式长程搜索中常见的重复检索与约束遗忘，是性能提升与稳定性改善的重要来源。
- **轨迹结构 vs 轨迹规模**：全部实验共同指向一个核心结论——**决定深度搜索上限的因素不只是“看到过多少问题—答案对”，更重要的是“推理轨迹如何在结构层面被组织和表示”**。图引导的结构化状态建模有望成为降低深度搜索规模化成本的新主轴；同源对比中，G-ReAct 以约 1/6 的轨迹规模实现了反超，说明每条轨迹所传递的监督质量远高于数量。

## 7. 局限性分析

- **数据规模与泛化边界**：仅 1.9K 条轨迹、单领域（以 Wikipedia 为核心的深度搜索为主）训练，缺少跨领域（如代码、数学、医疗、金融）的分布覆盖验证；当前收益能否泛化到长尾知识密集场景仍不明朗。
- **对基础模型的依赖**：G-ReAct 依赖 LLM 在查询图解析、状态更新等环节的稳定执行，若基础模型在指令跟随上较弱，其在复杂约束下生成的查询图或状态转移可能失真；论文未报告对弱基础模型（如 7B 级别）的鲁棒性测试。
- **评估协议的可比性**：多个基线结果直接引用官方报告或公开榜单，与自测环境在提示词模板、工具集、最大步数、评测版本上可能不一致；部分单元格用“—”标记，无法完成严格的同条件对比。
- **LLM-as-judge 的主观偏差**：仅以 GPT-4o-mini 打分作为主要依据，未报告人工评估相关性或打分器自身的偏好偏差（如对长答案、结构完整答案的倾向），可能影响 pass@1 的可靠性。
- **固定拓扑假设的局限**：查询图结构一旦初始化即固定，不支持中途对图本身进行增删重构；这意味着若初始解析遗漏关键逻辑分支（如问题本身存在歧义或多解），后续求解全部建立在一个不完整的骨架之上，存在结构性风险。
- **计算成本未充分透明**：训练算力、推理时平均工具调用轮数、交互 token 总量等关键成本指标没有系统报告，难以对“数据效率提升”与“总计算开销”进行全面的投入产出评估。

## 8. 总结与展望

G-ReAct 针对深度搜索中长程推理状态管理这一核心瓶颈，提出了一套“固定查询图 + 动态状态演化”的结构化建模框架，并以仅 1.9K 条图结构化轨迹和 16 张 A100 卡的训练预算，在四个基准上达到或超越大规模闭源模型与同尺寸开源深度搜索模型的水平。论文的核心贡献不仅在于一个具体方法，更在于一个可复用的认知视角：**推理过程的结构化组织本身就是一种强监督信号**，与单纯扩大数据或参数规模相比，可能提供一条更经济、更可持续的性能提升路径。

后续工作可从三个方向展开：① 将查询图扩展为支持动态结构调整的语义图，以应对歧义与多解问题；② 将 G-ReAct 从“训练数据生成器”延伸为“通用推理框架”与“RL 学习环境”，进一步释放其在测试时扩展与策略优化上的潜力；③ 引入跨领域数据与人工评估，验证该方法在不同任务分布和评测协议下的稳健性。
