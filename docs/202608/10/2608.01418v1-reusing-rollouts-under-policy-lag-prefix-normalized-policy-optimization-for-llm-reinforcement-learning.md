## 摘要
自回归轨迹生成是大语言模型强化学习中的主要计算成本。重复使用每个轨迹批次进行额外的学习器更新可以分摊这一成本，但随着学习器偏离行为策略，后续更新越来越偏离策略。在某个词元位置，精确的离策略校正必须同时考虑当前动作和到达其前缀的概率。累积重要性比率提供了这种校正，但其乘积形式可能产生难以处理的动态范围。我们研究了前缀归一化策略优化（PNPO），它用沿每个因果前缀的似然比率的几何平均值替代累积比率，在压缩对数权重规模的同时保留每个位置的因果前缀依赖性。在受控的长上下文数学推理实验中，我们通过每批次使用一轮或四轮策略更新来诱导两种离策略机制。PNPO在单轮更新时并未持续优于GSPO。在四轮更新时，它在每个基准上获得了最高的Avg@32观测值；三个独立选择的基准峰值的未加权平均值为50.24，比GSPO高出3.00个百分点。在匹配的2,400次更新预算下，四轮PNPO在150个轨迹批次后达到最终宏Avg@32为49.66，与单轮更新600个批次后达到的49.56相当。这些结果初步表明，随着训练进一步偏离策略，PNPO可能具有优势。

## Abstract
Autoregressive rollout generation is a major computational cost in reinforcement learning for large language models. Reusing each rollout batch for additional learner updates amortizes this cost, but later updates become increasingly off-policy as the learner departs from the behavior policy. At a token position, exact off-policy correction must account for both the current action and the probability of reaching its prefix. The cumulative importance ratio provides this correction, but its product form can produce an unwieldy dynamic range. We study Prefix-Normalized Policy Optimization (PNPO), which replaces the cumulative ratio with the geometric mean of likelihood ratios along each causal prefix, preserving causal-prefix dependence at each position while compressing the log-weight scale. In controlled long-context mathematical reasoning experiments, we induce two off-policy regimes by using one or four policy-update epochs per rollout batch. PNPO does not consistently outperform GSPO with one epoch. With four epochs, it attains the highest observed Avg@32 on each benchmark; the unweighted mean of the three independently selected benchmark peaks is 50.24, 3.00 percentage points above GSPO. Under a matched 2,400-update budget, four-epoch PNPO reaches a final macro Avg@32 of 49.66 after 150 rollout batches, comparable to the 49.56 reached after 600 batches with one epoch. These results provide preliminary evidence that PNPO can be advantageous as training moves further off-policy.

## 1. 核心问题与整体含义

- **研究背景**：在 LLM 的强化学习（RL）后训练中，自回归生成 rollout 是最大的计算开销之一。为摊薄这一成本，一种常见做法是复用同一批 rollout 进行多次 learner 更新（如 PPO 的多 epoch 小批次优化）。
- **核心问题**：当同一批轨迹被重复使用时，learner 不断更新而行为策略（behavior policy）保持不变，导致后续更新越来越偏离策略（off-policy）。在自回归生成中，精确的 off-policy 校正需要在每个 token 位置同时考虑当前动作的概率比和到达该前缀的状态概率比，即使用累积重要性比率（cumulative importance ratio）\( C_t = \prod_{k=1}^t \rho_k \)。
- **现有方法的张力**：
  - 局部 token 级比率（如 GRPO/PPO）仅校正当前动作分布，忽略了前缀状态分布偏移；
  - 精确累积比率虽包含完整的前缀校正，但其对数权重随序列长度和策略漂移累积，动态范围过大，训练不稳定；
  - GSPO 使用整句归一化的响应级权重，虽控制尺度，但让早期位置的权重依赖于未来 suffix，破坏了因果前缀依赖。
- **本文目标**：提出**前缀归一化策略优化（PNPO）**，用前缀几何平均替代累积比率，在保留因果前缀依赖性的同时压缩权重动态范围，并研究其在策略偏移加剧（更多更新轮次）时是否优于现有方法。

## 2. 方法论：PNPO 的核心思想与技术细节

### 2.1 核心思想

PNPO 的出发点是自回归生成中精确的状态-动作密度比（change-of-measure ratio）：

\[
C_t = \prod_{k=1}^t \rho_k,\quad \rho_k = \frac{\pi_\theta(a_k \mid s_k)}{\pi_\beta(a_k \mid s_k)}
\]

其中 \(\rho_k\) 是第 \(k\) 个 token 的局部似然比，\(C_t\) 是到达前缀 \(s_t\) 并选择动作 \(a_t\) 的精确联合密度比。

PNPO 的核心变换是将累积比率的 \(t\) 次方根作为位置 \(t\) 的权重：

\[
w^{\mathrm{PN}}_{i,t} = C_{i,t}^{1/t} = \exp\left(\frac{1}{t}\sum_{k=1}^t \log \rho_{i,k}\right)
\]

这一几何平均变换的性质：
- 在 \(t=1\) 时退化为局部 token 比率；
- 在 \(t=L_i\) 时等于整句响应的几何均值；
- 在中间位置仅依赖前缀，不包含未来 suffix 的 likelihood 变化；
- 压缩了对数累积权重的尺度，同时**保留每个位置的前缀因果依赖**，并在给定 t 时保持 log 符号和响应间排序不变。

### 2.2 完整目标函数

PNPO 的完整目标包含以下组件：

1. **位置相关接受门控**：使用尺度 \( h(t, L_i) = \sqrt{L_i / t} \)，只有当
   \[
   1 - \epsilon_- h(t,L_i) \le w^{\mathrm{PN}}_{i,t} \le 1 + \epsilon_+ h(t,L_i)
   \]
   时才保留该位置的 score 项。该门控在早期位置放宽接受区间，在末端位置收敛到基础区间，对越界权重执行**硬拒绝**而非截断。

2. **组相对优势**：沿用 GRPO 的 group-relative outcome advantage：
   \[
   \hat{A}_{i,t} = \frac{R_i - \mathrm{mean}(\{R_j\})}{\mathrm{std}(\{R_j\})}
   \]

3. **停止梯度的代理目标**：
   \[
   \mathcal{J}_{\mathrm{PNPO}}(\theta) = \mathbb{E}_{x\sim D, y_{1:G}\sim\pi_\beta(\cdot|x)}\left[\frac{1}{G}\sum_{i=1}^G \frac{1}{L_i}\sum_{t=1}^{L_i} \mathrm{sg}\left[M_{i,t} w^{\mathrm{PN}}_{i,t} \hat{A}_{i,t}\right] \log \pi_\theta(y_{i,t}\mid x, y_{i,<t})\right]
   \]
   其中 \(\mathrm{sg}\) 表示 stop-gradient，梯度只流过当前 token 的 log 概率。门控、权重和优势均视为数值系数。

4. **聚合方式**：先对每个响应的 token-level score 项求均值，再对响应间求均值（与 GSPO 的聚合方式一致），且经过门控后不做重新归一化。

### 2.3 与精确梯度的关系

论文严格区分了两种精确梯度表示：
- 保留行为优势 \(A^\beta_t\) 的表示需要**累积前缀 score** \(\sum_{k=1}^t z_k\)；
- 保留当前 token score \(z_t\) 的表示需要**学习策略优势** \(A^\theta_t\)。

二者期望相等，但其分量不可互换。PNPO 沿用 PPO/GRPO 的当前 token score 结构，同时将 \(A^\theta_t\) 近似为行为侧优势代理（rollout 导出的组相对优势），再将精确累积比率替换为前缀归一化权重。因此，**PNPO 整体是一个有意的有偏代理目标**，而非精确 off-policy 校正。

## 3. 实验设计

### 3.1 数据集与基准

- **训练数据**：DAPO-Math-17k 数学推理数据集
- **基础模型**：DeepSeek-R1-Distill-Qwen-1.5B
- **评估基准**：AMC 2023、AIME 2024、AIME 2025 三个数学推理基准
- **评估指标**：
  - Avg@32：每个问题采样 32 个回答的二进制正确率均值
  - macro Avg@32：三个基准得分的未加权平均

### 3.2 实验设置

- **训练配置**：
  - 每个 rollout 批次采样 256 个 prompt、每个 prompt 8 个响应，共 2,048 个响应
  - 最大 prompt 长度 1,024 token，最大响应长度 15,360 token
  - 学习率 \(10^{-6}\)，minibatch 为 64 个 prompt 组（512 个响应序列），每个 PPO epoch 内做 4 次优化器更新
  - 单轮更新运行 600 步、四轮更新运行 150 步，两种设置都完成 2,400 次优化器更新（保证预算匹配）

- **对比方法**：
  - **GRPO**：token 级局部比率 + token 均值聚合，clip 容差 (0.2, 0.28)，dual-clip 系数 10
  - **GSPO**：长度归一化响应级比率 + 响应均值聚合，clip 容差 (3×10⁻⁴, 4×10⁻⁴)
  - **PNPO（本文方法）**：前缀归一化权重 + 位置依赖门控，基础门控容差 (7×10⁻⁴, 9.5×10⁻⁴)

- **off-policy 机制控制**：通过每批次执行 **1 轮** 或 **4 轮** 策略更新，在相同预算下诱导不同强度的策略偏移。

### 3.3 硬件

- 所有训练运行使用 **32 块 NVIDIA H20 GPU**。
- 单步耗时估计：单轮设置约 283 秒/步，四轮设置约 510 秒/步（用于图 3 的时间估计）。
- 达到 rollout reward 0.25 的估计训练时长：
  - 单轮设置：37.7–38.0 小时
  - 四轮 GSPO：22.4 小时
  - 四轮 PNPO：16.0 小时（比四轮 GSPO 快 6.4 小时）

## 5. 主要结论

1. **PNPO 在策略偏移较大时优势显著**：在四轮更新（更强的 off-policy 条件）下，PNPO 在每个基准上均取得最高分，宏平均比 GSPO 高 3.00 个百分点，且这一优势在评估轨迹上持续可见（14/15 次评估领先），而非只是峰值。
2. **在低偏移条件下与现有方法相当**：单轮更新时，PNPO 与 GSPO 表现接近、交替领先，无法断言一致优势。
3. **rollout 复用效率显著提升**：在相同的 2,400 次更新预算下，四轮 PNPO 用 150 个批次达到了单轮 600 个批次的最终性能，即用 **1/4 的新生成响应数** 实现同等最终效果，对训练成本摊薄有直接价值。
4. **权重粒度解释**：GSPO 的四轮 reward 轨迹稳定但评估仍有差距，PNPO 保留位置相关的前缀统计，这一差异与实验结果模式一致，但实验设计不足以严格证明因果机制。

## 6. 优点

- **理论分析扎实**：从精确的状态-动作密度比出发，严格推导了两种精确梯度表示（行为优势+累积 score vs 学习优势+当前 token score）及其等价的边界条件，厘清了 PPO/GRPO 局部替代目标的近似本质。
- **方法设计精巧**：前缀几何均值在"精确但尺度爆炸"的累积比率和"尺度可控但破坏因果性"的响应级权重之间取了一个自然的中间点，既保留了前缀因果依赖，又控制了对数权重的动态范围。
- **实验控制严谨**：通过固定更新预算（2,400 次优化器更新）来比较不同 epoch 数，将"off-policy 强度"作为唯一的主要变化维度，实验设计较为干净。
- **问题意识明确**：针对 LLM RL 训练中 rollout 生成成本高、批次复用导致策略偏移这一实际痛点，提供了有据可依的解决方案。
- **诚实的实验报告**：论文明确指出单轮下 PNPO 不优于 GSPO，没有选择性地只报告有利结果，并披露了未做消融的局限。
- **计算效率指标**：额外报告了达到 reward 阈值的时间估计，从训练效率角度补充了评估价值。

## 7. 不足与局限

### 7.1 实验层面的局限

- **统计可靠性不足**：每组配置仅一次运行（seed 42），无法提供均值/方差/置信区间，3.00 个百分点的优势是否稳健值得存疑。
- **无消融实验**：门控、响应级聚合、前缀几何均值等组件未进行分离测试，无法证明前缀归一化本身是带来收益的关键因素。作者也明确承认"证据适用于完整配置，而非隔离前缀归一化的效果"。
- **模型与任务覆盖窄**：仅 1.5B 模型 + 数学推理，未验证在更大模型或非数学任务（对话、代码等）上的表现。
- **off-policy 场景单一**：只通过"增加同一批 rollout 上的更新轮数"诱导策略偏移，未覆盖异步收集（如 IMPALA 风格）、经验回放、离线数据和训练-推理不一致等更广泛的策略滞后场景。

### 7.2 方法本身的局限

- **明确有偏**：PNPO 权重 \(C_t^{1/t}\) 不是真正的密度比，不保留精确的 change-of-measure 恒等式，是一种有意的偏置换取尺度控制的折衷。在小规模策略偏移时，这一偏置可能不带来收益（单轮结果已证实）。
- **门控的启示性**：位置依赖门控 \(h(t,L_i)=\sqrt{L_i/t}\) 的选择是启发式的，缺少理论推导或敏感性分析。
- **未考虑采样误差**：几何平均压缩了权重尺度，但也可能压缩真实信号（如对优势较大的 token 的校正），可能限制策略更新的步幅上限。

### 7.3 应用限制

- 长期复用轨迹可能导致偏差积累，PNPO 虽然缓解了权重尺度问题，但实验时间跨度有限（最多 150 个批次），更长的复用周期（如 >10 epoch）的行为未被测试。
- 在异步真实系统中，策略滞后与探索-利用权衡的交互未被讨论或验证。
