## 摘要
多模态大语言模型（MLLMs）将图像编码为长视觉令牌序列，使得预填充和KV缓存存储成本高昂。现有的免训练剪枝方法通过重要性、多样性或空间覆盖来选择令牌，但将保留的令牌视为可互换，并未显式跟踪哪些与对象相关的区域已被覆盖。我们提出RoRA，一种免训练框架，将视觉令牌剪枝视为面向角色的区域证据分配。在给定固定预算下，RoRA将令牌划分为受保护语义核心、补充上下文和细粒度细节。它首先利用位置先验和提示校准的对象先验来校准文本条件注意力，然后从高置信度锚点构建注意力锚定区域（AARs），作为已覆盖对象支持的轻量级代理。上下文主要在校准区域之外探索，而小部分由AAR引导的预算用于恢复局部细节；成对相似性仅用于上下文阶段的冗余过滤。在匹配预算下，RoRA在LLaVA和Qwen-VL系列中持续优于强免训练基线，即使在激进剪枝比率下也能保留大部分未剪枝精度，例如在LLaVA-1.5上以88.9%剪枝率保持96.5%的完整性能，在Qwen3-VL上以75-90%剪枝率比D2Pruner提升约5%。在66.7%剪枝比率下，RoRA仅需0.7毫秒进行令牌选择，并将端到端推理时间减少24.6%，相当于在NVIDIA H800上相比未剪枝推理实现1.33倍加速。

## Abstract
Multimodal large language models (MLLMs) encode images as long visual token sequences, making prefilling and KV-cache storage expensive. Existing training-free pruning methods select tokens by importance, diversity, or spatial coverage, but treat retained tokens as interchangeable and do not explicitly track which object-related regions are already covered. We present RoRA, a training-free framework that casts visual token pruning as role-oriented regional evidence allocation. Given a fixed budget, RoRA partitions tokens into a protected semantic core, complementary context, and fine-grained detail. It first calibrates text-conditioned attention with a positional prior and a prompt-calibrated object prior, then builds Attention-Anchored Regions (AARs) from high-confidence anchors as lightweight proxies for covered object support. Context is explored mainly outside AARs, while a small AAR-guided budget restores local detail; pairwise similarity is used only for context-stage redundancy filtering. Under matched budgets, RoRA consistently outperforms strong training-free baselines across LLaVA and Qwen-VL families, retaining most of the unpruned accuracy even at aggressive pruning ratios, e.g., 96.5% of full performance at 88.9% pruning on LLaVA-1.5, and improving over D2Pruner by about 5% on Qwen3-VL at 75-90% pruning. At a 66.7% pruning ratio, RoRA requires only 0.7 ms for token selection and reduces end-to-end inference time by 24.6%, corresponding to a 1.33x speedup over unpruned inference on an NVIDIA H800.

## 1. 论文的核心问题与整体含义

- **背景与动机**：多模态大语言模型（MLLMs）将图像编码为冗长的视觉 token 序列，在高分辨率图像、多图输入和视频场景下，动辄产生数百到数千个 token，导致预填充（prefilling）阶段计算量大、KV-cache 占用高、推理延迟显著增加。
- **现有剪枝方法的局限**：已有的免训练（training-free）视觉 token 剪枝方法（如 FastV、DART、HoloV、D2Pruner 等）主要依据重要性、多样性或空间覆盖来选 token，但它们大多将保留的 token 视为可互换，并且没有显式追踪“哪些对象相关区域已被覆盖”，容易造成预算浪费在重复或任务无关的视觉证据上。
- **核心问题**：在固定保留预算下，如何按照视觉证据的不同语义角色来分配 token，既保住查询对象的核心证据，又兼顾场景上下文和细粒度细节，同时不引入昂贵的全局相似度建模开销。
- **整体含义**：RoRA 提出将视觉 token 剪枝重新定义为“面向角色的区域证据分配”（role-oriented regional evidence allocation），通过轻量级的注意力锚定区域（AAR）显式建模已覆盖的对象支持区域，从而在同等预算下更合理地保留多样且互补的视觉信息。

## 2. 方法论

- **总体框架**：在 LLM 的早期层（剪枝层 ℓp）处应用，视觉 token 已获得文本条件信息。总预算 K 被划分为三部分：受保护语义核心（Protected Core）P、互补上下文（Complementary Context）C、细粒度细节（Detail）D，三者不相交，且 Kp + Kc + Kd = K。
- **对象校准的注意力与核心保护**：
  - 针对原始注意力存在的位置偏置（attention sink），使用离线统计的位置先验 bi 进行去偏：ri = Norm( ai / (bi + ε) )；
  - 引入提示校准的对象先验 oi（用“List all visible objects in the image”等提示在 GQA 未标注图像上统计得到），得到 pi = Norm( ri + λobj · oi )，其中 λobj 取较小值以免过度牺牲样本特异性；
  - 取 pi 最高的 Kp 个 token 作为语义核心集合 P，这些 token 被“保护”，不参与后续候选池。
- **注意力锚定区域（AAR）**：
  - 从 pi 中选取 Ma 个高置信度 token 作为锚点（anchors），在二维 token 网格上扩展局部邻域得到 AAR：RAAR = ∪ Nra(a)；
  - AAR 是“对象相关支持区域”的轻量级空间代理，而非精确对象掩码。
- **互补上下文分配**：
  - 上下文分数 ci = Norm( pi + λctx · I[i∉RAAR] )，给 AAR 之外的 token 一个小的探索奖励，使预算流向次要对象、关系和场景背景；
  - 引入轻量级冗余过滤：若候选 token 与已保留 token 的余弦相似度超过阈值 τsem 则跳过；该相似度只在上下文阶段使用，不构建全图稠密相似度矩阵；
  - 形成集合 C = Select_{τsem, Kc}( { ci | i∉P } )。
- **AAR 引导的细节修复**：
  - 对每个 token 计算三个线索：注意力响应 bâi = Norm(ai)、特征幅值 bmi = Norm(||hi||2)、局部对比度 bℓi（基于 8-邻域特征余弦距离的平均）；
  - 细节分数 di = ωa·bâi + ωm·bmi + ωℓ·bℓi + λdet·ηi，其中 ηi = I[i∈RAAR]；
  - 从剩余 token 中取 Kd 个最高分者形成 D，最终保留集合 S = P ∪ C ∪ D。
- **复杂度优势**：RoRA 的复杂度约为 O(N + Nt²)（Nt 为去掉核心后的剩余候选数），远轻于 D2Pruner 的 O(N²) 全图相似度建模，与 HoloV 的 crop-wise O(N²/C) 相当。

## 5. 主要实验结果与对比

- **总体性能**：在 LLaVA-1.5-7B 上，当保留 192 个 token（剪枝 66.7%）时，RoRA 的平均归一化分数达到了与未剪枝模型接近的水平（约 97% 以上），同时优于 FastV、VisionZip、D2Pruner、HoloV 等代表性方法；当保留 64 个 token（剪枝 88.9%）时，RoRA 的性能下降幅度显著小于所有基线，说明其在极低预算下对关键视觉证据的保留能力更强。
- **跨模型泛化**：在 LLaVA-NeXT-7B 上使用 320 个 token（剪枝 88.9%）时，RoRA 在 GQA、TextVQA、VizWiz 等任务上均保持稳定，而 D2Pruner 和 HoloV 在部分任务上出现明显波动；在 Qwen2.5-VL-7B 和 Qwen3-VL-8B 上保留 25%/10% token 时，RoRA 同样在多数任务上领先，表明其不依赖特定视觉编码器或 token 序列结构。
- **任务类型分析**：RoRA 在需要细粒度定位和计数能力的任务（如 BLINK-counting、RefCOCO、ScienceQA-IMG）上收益最明显，这得益于 AAR 引导的细节修复机制；在纯全局理解任务（如 MME、MMBench）上，RoRA 与最优基线持平，但仍未出现明显退化。
- **效率-性能权衡**：在相同的端到端加速比下，RoRA 的平均得分明显高于所有免训练剪枝方法；尤其在高剪枝比例下，其性能优势随预算缩减而扩大，说明角色化区域分配策略能更有效地利用有限的 token 预算。
- **与训练方法的关系**：论文还对比了需要重新训练/蒸馏的剪枝方法（如 PruMerge），RoRA 在无需任何训练的前提下取得了相当甚至更好的效果，大幅降低了实际部署成本。

## 6. 消融研究与设计验证

- **关键组件的必要性**：在 LLaVA-1.5-7B 上逐步消融（去掉对象校准、AAR、上下文探索、细节修复）后，平均分数下降明显。其中去掉 AAR 的下降幅度最大（约 4–6 分），说明“显式标记已覆盖区域”是 RoRA 的核心贡献；去掉对象先验后的下降次之（约 2–3 分），去掉细节修复后的下降集中在细粒度任务上（TextVQA、ScienceQA）。
- **锚点数与邻域半径**：锚点数 Ma 和邻域半径 ra 的敏感性实验表明，Ma 在 60–100、ra 在 3–5 时性能最稳定；过小的 AAR 无法屏蔽重复区域，过大的 AAR 会错误排除有价值的背景信息。
- **上下文裁剪阈值 τsem**：论文测试了 τsem 在 0.5–0.9 之间的取值，发现 0.7 附近效果最佳；阈值过低会误删必要的上下文，过高则退化为不做冗余过滤。
- **保护预算的分配比例**：固定总预算 K = 192 时，Kp: Kc: Kd 约为 2:1:1（即 96:48:48）效果最好；核心预算不足时对象主要证据丢失，核心过多则细节和上下文不足。
- **先验校准的稳健性**：将对象先验 oi 换为 GQA 上不同子集统计或直接使用原始注意力时，性能下降幅度可控，说明 RoRA 不严重依赖特定校准数据，但显式加入对象先验始终优于纯位置去偏。
- **时间复杂度验证**：在不同分辨率（如 336×336 与 672×672 token 网格）下，RoRA 的 token 选择时间基本随 N 线性增长，而 D2Pruner 的稠密相似度计算时间随 N 平方增长，证实了 RoRA 的良好可扩展性。

## 7. 不足与未来方向

- **局限性**：RoRA 的对象先验需要离线统计，虽然在 GQA 1000 张图像上计算成本很低，但未标注领域（如医学影像、遥感）可能无法直接迁移；AAR 是基于空间邻域的粗糙代理，对非紧凑分布的对象（如分散的小物体）支持有限；此外，推理时注意力的偏差去偏依赖位置先验的准确度，不同模型可能存在分布偏移。
- **未来工作**：论文提出可将 RoRA 扩展为基于视觉-语言模型给出的伪标签来动态更新先验，或将角色分配嵌入到 KV-cache 管理与连续 token 合并的联合优化中，进一步减少预填充计算；同时也值得探索在视频多帧场景下的跨时间角色跟踪。
- **总结性评价**：RoRA 通过将视觉 token 剪枝分解为“核心保护、上下文补充、细节修复”三个角色，并引入 AAR 这一轻量级区域覆盖显式机制，在不牺牲精度的前提下显著降低计算量，是免训练剪枝方向的一个实用且直观的重要进展。
