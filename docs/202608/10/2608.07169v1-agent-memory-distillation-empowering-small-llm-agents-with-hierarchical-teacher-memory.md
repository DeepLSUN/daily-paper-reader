## 摘要
记忆系统在提升智能体性能方面展现出前景，但其潜力在小语言模型上仍未得到充分探索，这些模型难以自行生成足够的成功轨迹。我们提出了代理记忆蒸馏（AMD），一种无需训练的框架，通过层级记忆将结构化知识从大型教师智能体迁移到小型学生智能体。AMD从成功的教师轨迹中构建三种互补的记忆类型：工作流记忆编码任务级策略，子任务记忆提供中间粒度的具体行为示例，函数记忆捕获每个函数的调用约定和常见陷阱。工作流和子任务记忆在每个任务开始时主动注入，而函数记忆则在工具调用错误时被动检索。我们使用四个学生模型（4B-8B参数）以GPT-5-mini为教师，在三个工具使用基准上评估AMD，在AppWorld、BFCL V3和ToolSandbox上分别取得了27.2个百分点、11.2个百分点和3.4个百分点的平均准确率提升，同时持续优于现有的基于记忆的基线。进一步分析表明，子任务记忆贡献了最大的提升，教师有效性取决于教师能力和学生兼容性，而4B规模的学生从AMD中获益最多。

## Abstract
Memory systems have shown promise for improving agent performance, but their potential remains largely unexplored for small language models, which struggle to generate sufficient successful trajectories on their own. We propose Agent Memory Distillation (AMD), a training-free framework that transfers structured knowledge from a large teacher agent to a small student agent through hierarchical memory. AMD constructs three complementary memory types from successful teacher trajectories: Workflow memory encodes task-level strategies, Subtask memory provides concrete behavioral examples at an intermediate granularity, and Function memory captures per-function calling conventions and common pitfalls. Workflow and Subtask memories are injected proactively at the start of each task, while Function memory is retrieved reactively upon tool-calling errors. We evaluate AMD on three tool-use benchmarks using four student models (4B-8B parameters) with GPT-5-mini as the teacher, achieving average accuracy gains of 27.2%p, 11.2%p, and 3.4%p on AppWorld, BFCL V3, and ToolSandbox, while consistently outperforming existing memory-based baselines. Further analysis shows that Subtask memory contributes the largest gains, teacher effectiveness depends on both teacher capability and student compatibility, and 4B-sized students benefit most from AMD.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：小型语言模型（SLM，4B–8B参数）在作为智能体时表现不佳，其主要原因之一是**难以自主生成足够多的成功轨迹**，导致其自身的记忆系统中成功经验稀缺、失败样本占主导，记忆带来的收益极为有限。
- **关键洞察**：虽然可以借助更强的教师智能体（如GPT-5-mini）生成高质量经验并迁移给学生，但**简单的“记忆搬运”效果甚微**——教师与学生之间存在的“能力鸿沟”（capability gap），使得学生难以理解和应用高层次的教师记忆。例如，教师记忆建议“先登录再播放音乐”，但学生可能连登录流程都不会。
- **研究意义**：本文是**首个系统研究“教师→学生”记忆蒸馏问题的工作**，提出了一种无需训练（training-free）的层次化记忆迁移框架AMD，为增强小型LLM智能体提供了一条免训练、低成本的新路径。

## 2. 方法论（核心思想、技术细节与流程）

### 2.1 总体框架
AMD（Agent Memory Distillation）通过**层次化记忆构建 + 主动/被动双模式注入**，将教师智能体的经验结构化地传递给学生智能体，核心设计如下：

- **记忆来源**：仅使用教师智能体的**成功轨迹**（successful teacher trajectories）构建记忆，保证记忆质量。
- **记忆形式**：三类互补的记忆，覆盖从任务规划到工具调用的多个粒度层级。

### 2.2 三种记忆类型

| 记忆类型 | 粒度 | 内容 | 注入方式 |
|---|---|---|---|
| **Workflow Memory（工作流记忆）** | 任务级 | 高层任务完成策略：涉及的应用/工具、关键前置条件、决策规则、验证线索、常见失败模式；具体值用类型化占位符（如`<ID>`、`<EMAIL>`）代替 | **主动注入**：任务开始时检索top-1，预置到系统提示中 |
| **Subtask Memory（子任务记忆）** | 子任务级 | 中间粒度的具体行为示例：教师轨迹被切分为语义完整的子任务片段，每个片段包含标签、描述及具体执行代码与观察结果 | **主动注入**：学生先将任务分解为至多6个子任务标签，每个标签检索top-1，去重后注入系统提示 |
| **Function Memory（函数记忆）** | 函数级 | 单个工具的调用约定：函数名、具体调用示例、参数与响应schema、上下文与返回观察 | **被动检索**：工具调用报错时，按失败函数名检索top-1记录，附加到错误消息中 |

### 2.3 关键流程
1. **离线阶段**：教师智能体在任务集S上运行，收集成功轨迹集合D⁺，再由教师LLM分别生成三类记忆（Workflow通过提示词生成泛化性洞见；Subtask通过LLM+规则断点提示进行语义切分；Function直接从轨迹中提取函数调用记录）。
2. **在线推理阶段**（Algorithm 1）：
   - 任务开始前：检索Workflow记忆并注入系统提示 → 学生分解任务为子任务标签 → 逐标签检索Subtask记忆并去重注入；
   - 执行循环中：若某次工具调用返回错误，提取失败函数名，从Function记忆中检索匹配记录，以提示块形式追加到当前上下文；
   - 直到任务完成或达到最大步数（40步）。
3. **检索机制**：所有记忆条目用`text-embedding-3-small`预编码，采用余弦相似度检索，设定最低相似度阈值过滤，主实验统一取k=1。

## 3. 实验设计（数据集、基准与对比方法）

### 3.1 基准数据集
- **AppWorld**：多应用智能体基准，168个任务（test_normal子集），智能体通过Python API调用与模拟真实应用交互，以数据库状态单元测试评判。
- **BFCL V3**：函数调用基准，200个任务（multi-turn base子集），要求每轮函数调用及参数均正确。
- **ToolSandbox**：有状态、对话式工具使用基准，129个场景（base子集），由GPT-5-mini模拟用户，按里程碑与雷区评分。

### 3.2 模型配置
- **教师模型**：GPT-5-mini。
- **学生模型**：Qwen3-4B、Qwen3-8B、Gemma4-E4B、Llama3.1-8B四个模型；另在规模效应实验中补充Qwen3-1.7B和Qwen3-14B。

### 3.3 对比方法
- **Zero-shot**（无记忆基线）；
- **ReasoningBank**：扁平任务级记忆，每任务检索一条推理洞见；
- **MemP**：层次化程序记忆，但面向同模型自我进化而非跨模型迁移；
- **SASM**：子任务级检索粒度，但未区分规划/执行/纠错三类知识。
- 所有基线均使用相同的教师轨迹集生成记忆，并按其各自协议在学生推理时应用。

## 6. 主要结论与发现

- **AMD显著提升小模型智能体性能**：在AppWorld、BFCL V3、ToolSandbox上分别取得平均**27.2、11.2、3.4个百分点**的准确率提升，且在所有学生模型和基准上一致优于三种记忆基线。
- **现有记忆基线不稳定**：ReasoningBank、MemP、SASM在跨模型迁移场景下出现性能波动甚至负向退化，说明直接迁移不适当结构的教师记忆会引入噪声。
- **学生可达或超越教师水平**：Gemma4-E4B（54.17%）和Qwen3-8B（51.79%）在AppWorld上超越教师GPT-5-mini（50.00%）；BFCL V3上三个学生超过教师。
- **子任务记忆贡献最大**：在AppWorld上，添加ST记忆在WF基础上带来最高+25.0%p的提升；Function记忆提供额外但较小的增益。
- **教师有效性取决于能力与兼容性**：对强学生（Qwen3-8B），教师准确率是可靠预测因子；对弱学生（Qwen3-4B），GPT-5-mini反而比更强的DeepSeek V4 Pro产生更好的迁移效果。
- **4B规模学生受益最大**：学生规模从1.7B增到14B时绝对准确率持续上升，但**增益峰值在4B**（+34.52%p），且1.7B容量受限、14B提升空间收窄。
- **k=1为最优检索策略**：增加检索条数普遍导致性能下降（Subtask记忆从49.40%降至33.34%），说明小模型偏好“高精度、少注入”。
- **最优表示依粒度而异**：高层策略更适合自然语言，低层执行知识更适合具体代码示例。
- **三类记忆形成互补层级**：分别解决任务规划、执行策略与API交互三个层面的失败模式，整体效果大于部分之和。

## 7. 优点与亮点

- **问题选择精准**：填补了小模型智能体记忆中“教师→学生迁移”这一空白，切中现实应用中的关键瓶颈。
- **层次化记忆设计合理**：三类记忆按任务/子任务/函数粒度划分，与智能体执行过程的结构天然对齐，有效弥合了能力鸿沟。
- **免训练框架**：无需参数更新，部署成本低，可直接与任意开源小模型组合使用。
- **主动+被动双模式注入**：规划类记忆前置注入、纠错类知识按需触发，兼顾效果与上下文效率。
- **实验纵深充分**：从性能对比到消融、教师选择、规模效应、检索策略、表示形式、鲁棒性验证，分析层层递进。
- **定性案例丰富**：通过具体任务展示了三类记忆的级联效应，直观有力。
- **排除了数据泄漏风险**：跨分割与自排除检索实验证明增益来自记忆的真实泛化能力而非任务复用。

## 8. 不足与局限

- **应用范围有限**：仅在文本工具调用基准（Python API、结构化函数调用）上验证，未涉及多模态环境下基于视觉感知的智能体、也未覆盖开放式编码任务（非固定函数集合、需要从零生成代码）。
- **记忆离线冻结**：记忆从固定教师轨迹构建后推理时不再更新，无法纳入学生自身的在线经验，也无法适应教师演示与学生实际遇到任务之间的分布偏移。
- **教师选择存在开放问题**：更强的教师并不总是带来更好的迁移（如弱学生场景），如何自适应地为特定学生挑选最优教师仍待解决。
- **小模型的上下文容量与指令跟随能力限制**：额外记忆注入可能干扰部分弱模型（如LLaMA3.1-8B在增加FN记忆后出现性能回落），说明记忆注入量与模型容量的精细对齐仍需探索。
- **算力信息不透明**：论文未报告推理所需的GPU型号、数量或能耗，不利于复现成本评估。
- **基准性能天花板较低**：教师模型本身在三个基准上的准确率仅为28.68%~50.00%，整体水平不高，AMD在小模型上的增益上限可能受限于教师本身的能力。
