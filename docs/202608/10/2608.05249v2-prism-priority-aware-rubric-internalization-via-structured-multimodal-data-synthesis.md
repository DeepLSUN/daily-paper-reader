## 摘要
现实世界的多模态指令往往捆绑了多个重要性不等的需求，但大多数多模态训练数据仍然将指令跟随简化为回答一个自包含的问题。我们通过规则理解来研究这一差距，该任务不是将模型视为根据规则进行衡量的生成器，而是将其视为遵循规则执行者：给定一张图像和一个类型化、具有优先级的规则集，模型必须在生成整体判断之前验证每条规则。为了支持这一场景，我们提出了PRISM，一个四阶段数据合成框架，能够生成人物-任务对、前缀引导的规则集、质量过滤的规则以及结构化验证轨迹。我们进一步引入了PRISM-Eval，其Loose和Strict指标使用对固定标签的确定性匹配，因此不需要推理时的评判模型。仅使用10K合成样本，PRISM将Qwen3-VL-4B在PRISM-Eval上的Strict准确率从9.5%提升至30.1%，同时保持了通用基准测试的平均性能，并且这些提升能够迁移到另外四个开源多模态大语言模型（涵盖密集和MoE架构），表明结构化规则监督是迈向多规则、优先级感知的多模态指令跟随的一条可扩展路径。

## Abstract
Real-world multimodal instructions often bundle multiple requirements with unequal importance, yet most multimodal training data still reduce instruction following to answering one self-contained question. We study this gap through rubric comprehension, which casts the model not as a generator measured against rubrics but as an executor that follows them: given an image and a typed, prioritized rubric, the model must verify each rule before producing an overall judgment. To support this setting, we propose PRISM, a four-stage data synthesis framework that produces persona--task pairs, prefix-guided rule sets, quality-filtered rubrics, and structured verification traces. We further introduce PRISM-Eval, whose Loose and Strict metrics use deterministic matching against fixed labels and therefore require no inference-time judge model. With only 10K synthesized samples, PRISM lifts Qwen3-VL-4B from 9.5% to 30.1% Strict accuracy on PRISM-Eval while preserving average performance on general benchmarks, and the gains transfer to four additional open-source MLLMs across dense and MoE architectures, suggesting that structured rubric supervision is a scalable path toward multi-rule, priority-aware multimodal instruction following.

## 2. 方法论：PRISM 四阶段数据合成框架

PRISM（Priority-aware Rubric Internalization via Structured Multimodal Data Synthesis）是一个四阶段的数据合成流水线，包含以下核心技术步骤：

1. **阶段一：人物-任务对生成（Persona–Task Pair Generation）**
   - 生成多样化的虚拟人物角色（persona），每个角色对应特定的任务场景。
   - 将角色与其适配的任务需求进行配对，模拟真实世界中不同身份的用户会提出不同类型的捆绑式指令。

2. **阶段二：前缀引导的规则集生成（Prefix-Guided Rule Set Generation）**
   - 通过前缀引导（prefix guiding）方式生成带类型的规则集。
   - 每条规则被赋予明确的类型标签（如视觉属性、逻辑推理、情感判断等）。
   - 为每条规则设置优先级层级（priority level），明确规则之间的重要性排序。

3. **阶段三：质量过滤的rubric生成（Quality-Filtered Rubric Generation）**
   - 对生成的规则集进行质量过滤，过滤掉含糊、重复或不可验证的规则。
   - 确保最终的rubric（评分规则表）既清晰可执行，又与图像内容相关。

4. **阶段四：结构化验证轨迹生成（Structured Verification Trace Generation）**
   - 为每条规则生成结构化的验证轨迹（verification trace），即模型在做出最终判断前，逐步核对每个规则的过程记录。
   - 验证轨迹将规则"内化"为模型的推理步骤，是训练数据中的核心监督信号。

**训练范式**：模型作为"执行者"，在生成整体判断之前必须先对每条规则进行验证，输出结构化轨迹。

**PRISM-Eval 评估方法**：
- 定义了 Loose 和 Strict 两种指标。
- 使用与固定标签的确定性匹配（deterministic matching），因此不需要推理时的评判模型（inference-time judge model），评估可复现且成本低。
