## 摘要
长程LLM智能体需要记忆系统，从大型交互历史中恢复有用的证据，而无需向下游模型传递过多的上下文。现有的记忆流程通常依赖手工设计的启发式方法和重复的LLM调用，这可能引入冗余上下文和高推理成本。我们提出MemoryCPT，一个端到端可训练的智能体记忆流程，涵盖离线记忆构建和在线查询条件上下文生成。MemoryCPT包含两个阶段：查询无关蒸馏（QAD），使用显式推理轨迹将模块化记忆构建流程蒸馏为紧凑模型；以及查询感知检索与摘要（QAR），将倒数排名融合（RRF）与基于LoRA的摘要器结合，该摘要器通过成本感知奖励下的组相对策略优化（GRPO）进行训练。我们进一步引入单位成本质量（QPC）来量化单位推理成本的答案质量。在LoCoMo和LongMemEval上的实验表明，与评估的基线相比，MemoryCPT改善了成本-性能权衡，而消融和敏感性分析则表征了其组成部分的贡献以及关键设计选择的影响。

## Abstract
Long-horizon LLM agents require memory systems that recover useful evidence from large interaction histories without passing excessive context to downstream models. Existing memory pipelines often rely on hand-crafted heuristics and repeated LLM calls, which can introduce redundant context and high inference cost. We propose MemoryCPT, an end-to-end trainable agent memory pipeline that spans offline memory construction and online query-conditioned context generation. MemoryCPT consists of two stages: Query-agnostic Distillation (QAD), which distills a modular memory-construction pipeline into a compact model using explicit reasoning traces; and Query-aware Retrieval and Summarization (QAR), which combines reciprocal rank fusion (RRF) with a LoRA-based summarizer trained via Group Relative Policy Optimization (GRPO) under a cost-aware reward. We further introduce Quality per Cost (QPC) to quantify answer quality per unit inference cost. Experiments on LoCoMo and LongMemEval show that MemoryCPT improves the cost-performance trade-off over the evaluated baselines, while ablation and sensitivity analyses characterize the contributions of its components and the effects of key design choices.

### 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：长程LLM（大语言模型）智能体在与用户进行多会话、长时程交互时，需要依赖记忆系统从不断增长的交互历史中恢复有用证据。然而，现有记忆管线主要存在两大痛点：一是依赖**手工设计的启发式规则**（如固定阈值）和**重复的LLM调用**，导致上下文冗余与高昂的推理成本；二是随着上下文变长，模型在“大海捞针”场景下的性能会显著下降，无用信息会干扰答案质量。
- **研究动机**：作者指出，当前三种主流记忆范式——压缩、组织、检索——虽然各有进展，但大多是**无训练（training-free）**的流程，未能将记忆中间操作内化到模型参数中，且普遍缺乏对“成本-性能”的联合优化。
- **整体含义**：本文的核心主张是，智能体记忆系统的评估与设计不应仅关注最终答案质量（如F1），更应关注“**单位推理成本所获得的有效信息量**”。文章引入 **MemoryCPT**框架，旨在通过**端到端可训练**的模式，同时优化答案质量与推理成本，实现二者间的最优权衡。

### 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：MemoryCPT通过“**离线构建-在线提取**”的两阶段分离，将昂贵且复杂的记忆构建过程摊销到参数中，并在在线阶段通过强化学习动态压缩检索到的记忆，实现成本与质量的联合优化。

- **阶段一：查询无关蒸馏（Query-agnostic Distillation, QAD）**
  - **模块化蒸馏**：将Teacher模型（DeepSeek-V3）的复杂记忆构建流程拆解为四个角色：`BatchSegmenter`（批次切分）、`EpisodeGenerator`（情节生成）、`EpisodeMerger`（情节合并）、`SemanticExtractor`（语义提取）。
  - **推理轨迹训练**：使用Teacher模型生成的显式推理轨迹（`<think>...</think>` 内的CoT）和结构化JSON输出作为监督信号，通过LoRA适配器（LoRA-A）将知识蒸馏进Student模型（Qwen2.5-7B-Instruct或Llama-3.2-3B）。
  - **损失函数**：使用标准因果语言建模损失：$L_{QAD} = -E_{(x,r,y)\sim D_{QAD}} \sum_{t=1}^{|z|} \log p_\theta(z_t | z_{<t}, x)$，其中 $z = r \oplus y$。
  - **输出物**：训练后，LoRA-A被合并进基础模型得到`base A`，用于离线构建包含**情景记忆（Episodic）与语义记忆（Semantic）**的记忆库 $M$。

- **阶段二：查询感知检索与摘要（Query-aware Retrieval and Summarization, QAR）**
  - **粗略检索（RRF）**：对记忆库 $M$ 进行稠密检索（Embedding）与稀疏检索（BM25），并通过**倒数排名融合（RRF）** 合并候选集，限定输入范围，缩小行动空间。
  - **成本感知GRPO训练**：
    - **状态与动作**：状态 $s_q = (q, M^{RRF}_q)$（查询+RRF检索结果）；动作 $m_q$ 是由策略 $\pi_\phi(\cdot|s_q)$ 生成的摘要token序列。
    - **优化目标**：采用GRPO算法优化LoRA-B适配器：$\max_\phi E_q E_{m_q \sim \pi_\phi(\cdot|s_q)} [R(q, m_q)] - \beta D_{KL}(\pi_\phi \| \pi_{ref})$。
    - **奖励函数设计**：使用加权和替代直接优化QPC比值，保证训练稳定性：
      $R(q, m_q) = \alpha \cdot F1(\hat{y}, y^*) + (1-\alpha) \cdot (1 - \tilde{C}(q, m_q))$
      - 其中 $F1(\hat{y}, y^*)$ 是冻结QA模型输出与金标准答案的token级F1分数（质量项）；
      - $\tilde{C}(q, m_q)$ 是归一化的训练时成本代理（通过成本上限 $C_{ref}$ 裁剪，成本项），由摘要长度、QA输入输出长度及API单价决定。
  - **训练架构**：`base A` 冻结，LoRA-B为全新初始化并进行训练。分离了“记忆构建技能”（LoRA-A）与“在线成本感知摘要技能”（LoRA-B）。

- **端到端流程**：推理阶段仅包含三步：RF检索 -> LoRA-B生成摘要 -> 冻结的Qwen3-14B生成最终答案。整个系统只有 $f_{QAD}$ 和 $f_{QAR}$ 是可训练的，下游QA模型**完全冻结**。

### 6. 主要结论与发现

- **MemoryCPT显著提升成本-性能权衡**：在Qwen2.5-7B基础上，与BudgetMem相比，在LoCoMo上将F1从0.373提升至**0.479**，同时将成本从24.11降至**3.46**，QPC提升超过9倍，实现了“质量与效率兼得”，而非单纯的此消彼长。
- **QAD是质量放大器**：QAD的蒸馏过程虽引入少量成本，但大幅提升了记忆构建质量，使得下游QA输出显著改善。
- **QAR是成本控制器**：移除QAR会导致成本激增且质量下滑，验证了其作为“成本与质量调节器”的核心作用。
- **GRPO训练的Fine Summary (FS)** 是实现高质量-低成本的关键：FS极大降低了上下文长度（如QA输入平均仅~67 tokens），带来明显的成本节约，同时保持了语义正确性。
- **α=0.8是经验最优权衡点**：扫描实验表明，α=0.8在两个数据集上的QPC(QA)均达到峰值，实现了“在成本几乎不增加的前提下获取最高收益”。
- **检索深度存在“甜点区”**：top-20/50（情节/语义）是最优检索深度；过深（如32/80）反而引入噪声，轻微损害性能。

### 7. 优点

- **系统性的问题拆解与结合**：将记忆构建与在线压缩解耦为两个独立但连贯的训练阶段，设计逻辑清晰，且有效缩小了在线RL的动作空间。
- **新颖的成本感知训练机制**：引入GRPO进行在线摘要策略优化，并设计了带边界裁剪的成本奖励项，避免了直接优化QPC比值带来的不稳定问题，设计巧妙。
- **训练即推理的端到端范式**：将模块化记忆管线的中间决策（何时合并、何时抽取）通过推理轨迹显式蒸馏，避免了仅对最终摘要进行粗糙监督，学习目标更细腻。
- **全面且规范的评估体系**：提出QPC指标，并在成本核算中考虑了摊销成本，统一了价格和模型，使得跨系统比较更为客观。
- **充分的验证分析**：不仅报告了主结果，还系统性地进行了组件消融、α敏感性、检索深度分析和数据子集细粒度分析，增强了结论的可信度与可解释性。

### 8. 不足与局限

- **训练硬件与时长信息缺失**：未详述训练时长和能耗，不利于其他研究者评估整体复现成本。
- **实验覆盖范围有限**：仅覆盖两个公开的对话记忆基准（LoCoMo、LongMemEval）；测试的查询类型有限（如LongMemEval的SS-Pref类别表现不佳）。
- **奖励信号的简化**：训练时采用token级F1作为质量信号，虽然提供了密集反馈，但与下游最终评估（如LLM Judge）不完全对齐；未来可探索更复杂的可微奖励。
- **评估模型的规模偏差**：使用14B模型作为QA引擎，对于更小或更大的下游模型，MemoryCPT的收益是否保持一致尚待验证。
- **基线执行的不完全公平性**：对个别基线（如BudgetMem）因架构限制采用了不同的服务方式，这可能引入了超出算法本身的实现差异。
- **应用边界**：框架在动态成本预算下的**持续记忆更新**（continual update）方面尚未涉及，这在实际长程部署中至关重要。
