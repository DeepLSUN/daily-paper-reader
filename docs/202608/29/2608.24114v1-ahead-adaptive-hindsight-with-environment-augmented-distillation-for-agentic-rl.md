## 摘要
使用强化学习训练多轮LLM智能体通常依赖于轨迹级奖励，这种奖励为每一步分配统一的优势值，无法识别哪些决策导致了成功或失败。自蒸馏方法可以通过为强化学习增加特权信息来提供更细粒度的监督。然而，现有方法通常以难以区分的方式对每一步应用相同类型的特权信息，忽略了一个关键的不对称性：常规步骤几乎不需要额外指导，而关键错误步骤则需要环境反馈本身无法提供的纠正方向。我们提出了AHEAD，一个步骤感知框架，将不同的监督源匹配到不同的步骤类型。教师在所有步骤上接收环境反馈作为基于环境的密集信号，并在错误步骤上额外接收LLM生成的纠正提示，以提供环境反馈所缺乏的方向。该方法对标准GRPO算法引入了最小的改动。在ALFWorld、WebShop和基于搜索的QA上，以及三种模型规模下，AHEAD提高了任务成功率（在7B规模上，ALFWorld比GRPO提高13.3个百分点，WebShop提高11.0个百分点），用更少的训练步骤达到给定的成功率，并在比仅结果强化学习和先前的自蒸馏基线更紧凑的交互预算内解决问题。

## Abstract
Training multi-turn LLM agents with reinforcement learning typically relies on trajectory-level rewards, which assign a uniform advantage to every step and cannot identify which decisions led to success or failure. Self-distillation methods can provide finer-grained supervision by augmenting RL with privileged information. However, existing approaches usually apply the same type of privileged information to every step in an indistinguishable manner, ignoring a key asymmetry: routine steps need little additional guidance, while critical error steps require corrective direction that environment feedback alone cannot provide. We propose AHEAD, a step-aware framework that matches different supervision sources to different step types. The teacher receives environment feedback on all steps as a grounded dense signal, and additionally receives LLM-generated corrective hints on error steps to supply the direction that environment feedback lacks. The method introduces minimal changes to the standard GRPO algorithm. Across ALFWorld, WebShop, and Search-based QA, and across three model scales, AHEAD raises task success (+13.3 points on ALFWorld and +11.0 on WebShop at 7B over GRPO), reaches a given success rate in fewer training steps, and solves tasks within tighter interaction budgets than outcome-only RL and prior self-distillation baselines.

- **核心问题：轨迹级奖励无法进行细粒度信用分配。** 在多轮 LLM 智能体的强化学习训练中，GRPO 等方法依赖轨迹级环境奖励，将同一个优势值均匀广播给轨迹中的每一个 token。然而，并非所有步骤对结果贡献相同：大多数步骤是常规步骤，只需环境正常推进；少数错误步骤（如拿错物体、无效动作、错误搜索词）才是决定成败的关键。均匀分配梯度信号无法有效纠正真正需要修正的决策。
- **已有方法的不足：自蒸馏的特权信息使用过于单一。** 现有自蒸馏方法（如 SDAR、RLSD、Skill-SD）通过对比教师/学生分支的 token 级 log 概率差提供密集监督，但它们通常对所有步骤施加同一类型的任务级特权信息（如检索到的技能、参考答案），忽略了**关键不对称性**——常规步骤只需要确认信号，错误步骤则需要具体的纠正方向。
- **核心洞察：环境反馈是被忽视的天然步骤级特权信息源。** 环境在每个动作后返回的观察对学生生成该动作时不可见，因此是天然的 PI 来源。但对错误步骤而言，环境反馈（如 "Nothing happens"）只表明失败，不能揭示原因或纠正方向；LLM 生成的纠正提示（如 "Go to diningtable 1 to find the target object"）恰恰补齐了这一缺失信息。
- **论文整体含义**：提出 AHEAD（Adaptive Hindsight with Environment-Augmented Distillation）框架，将不同监督源与不同步骤类型匹配，实现在不改变推理成本的情况下，对标准 GRPO 算法做最小改动，显著提升多轮智能体 RL 的性能和训练效率。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想：步骤感知的特权信息（Step-Aware Privileged Information）

AHEAD 的核心是**按步骤类型差异化地构建教师上下文**：

- **常规步骤**（正常进展）：仅注入环境反馈（`Φ_env`），提供"动作结果确认"这一弱确认信号；
- **错误步骤**（关键错误）：同时注入环境反馈 + LLM 生成纠正提示（`Φ_llm`），提供"应该怎么做"的强纠正信号；
- 这种设计使教师对错误步骤自然产生更大的 log 概率偏差 `|δ|`，从而在无需显式门控或逐步骤系数的情况下实现**自适应监督强度**。

### 2.2 关键技术细节

**（1）错误步骤识别（Stage 1）**

- 仅对**失败轨迹**调用 LLM 分析器；
- 分析器读取完整轨迹记录（观察、动作、环境反馈、终局结果），识别关键错误步骤集合 `E_τ`，并为每个错误步骤生成纠正提示；
- 提示要求为祈使句、直接给出正确动作，**禁止描述失败原因**（因为环境反馈已覆盖"发生了什么"，提示需提供"应该发生什么"）。

**（2）步骤感知 PI 构建（Stage 2）**

- 教师上下文按如下公式构建：
  - 错误步骤（`t ∈ E_τ`）：`ĥ_t = H(h_t, Φ_env_t, Φ_llm_t)`——环境反馈 + 纠正提示；
  - 常规步骤（`t ∉ E_τ`）：`ĥ_t = H(h_t, Φ_env_t)`——仅环境反馈。

**（3）选择性轨迹过滤（Selective Trajectory Filtering）**

- **仅对失败轨迹**应用 PI 重加权（`A_ep < 0`），因为失败轨迹虽有统一负优势但缺乏步骤归因，正是蒸馏信号 `δ` 应填补的空白；
- **成功轨迹跳过 PI 管线**，保留 vanilla GRPO 优势，避免 PI 对已正确的梯度方向引入噪声。

**（4）优势重加权（Advantage Reweighting）**

- 计算 token 级蒸馏信号（教师与学生 log 概率差）：

  `δ_t,ℓ = log π_θ_old(y_t,ℓ | ĥ_t, y_t,<ℓ) − log π_θ_old(y_t,ℓ | h_t, y_t,<ℓ)`

- 转换为有界乘性权重：

  `w_t,ℓ = clip(exp(sgn(A_ep) · sg(δ_t,ℓ)), 1−ε, 1+ε)`，其中 `ε = 0.2`

- 重加权后的优势：

  `Ã_t,ℓ = A_ep · [(1−λ_k) + λ_k · w_t,ℓ]`

- 由于 `exp(·) > 0` 且裁剪保持正性，重加权优势始终与 `A_ep` 同号——**环境奖励始终控制更新方向**，蒸馏信号只调整更新强度；
- 混合系数 `λ_k` 从 0.5 线性衰减至 0（D=50 步）：训练早期依赖密集 PI 信用分配，后期回归 vanilla GRPO 避免对特权信息的过度依赖。

**（5）最终目标**

- 将 `Ã_t,ℓ` 替换 GRPO 裁剪替代目标中的 `A_ep`，其余完全不变。

### 2.3 训练与推理边界

- **训练时**：LLM 分析器、纠正提示、PI 增强评分全部用于构造优势；
- **推理时**：策略仅从原始历史 `h_t` 行动，**无需任何 PI、LLM 调用或环境反馈注入**——推理成本与 GRPO 完全相同。

## 7. 优点：方法与实验设计的亮点

- **步骤感知的自适应监督机制**：准确抓住"常规步骤需要确认、错误步骤需要纠正"的不对称性，利用环境反馈+LLM 提示两类异构 PI 源自然产生信号强度差异，无需显式门控或逐步骤系数；
- **对标准算法的极小改动**：在 GRPO 基础上仅增加三项训练期组件（LLM 分析、PI 增强前向、有界优势重加权），便于复现与集成；
- **稳定性好**：与 OPSD 等方法的梯度失控坍塌不同，AHEAD 的重加权只调强度不调方向，确保环境奖励始终掌控更新方向，避免了训练不稳定性；
- **推理零额外开销**：所有 PI 和 LLM 调用都限制在训练阶段，不增加部署成本；
- **分析实验完整**：从组件消融、分析器鲁棒性、训练效率、测试效率、泛化性能到信号集中性验证，多维度证据链相互支撑，结论可信度高。

## 8. 不足与局限

- **LLM 分析器带来的训练成本与依赖**：AHEAD 需要对失败轨迹调用外部 LLM 识别错误步骤与生成提示，这比 GRPO 多了训练期推理成本；四种分析器中三种为大型专有或前沿模型，**小型开放模型的可用性未测试**；
- **错误步骤可识别性的依赖**：方法的有效性依赖分析器准确定位关键错误步骤的能力；在错误更隐晦、累积性、或源于遗漏而非明显错误行为的场景（如软奖励、连续动作空间），分析器可能失灵；
- **评估场景范围有限**：三个基准均为相对短轨迹、二元成功/失败结果的环境；更长 horizon、部分可观测、连续动作空间或软奖励信号的环境可能带来额外挑战；
- **基线与复现的透明性问题**：主表基线数字与附录中自行复现的 GRPO 数字存在差异，论文未充分说明其来源分歧，可能影响读者对公平性的信心；
- **收益不等分布**：ALFWorld 上的增益主要集中在 Look、Pick2 等长序列类别，对 Clean、Cool 等 GRPO 已高分的类别无提升，说明方法的边际收益有其适用范围。
