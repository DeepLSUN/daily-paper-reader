## 摘要
半结构化$N$:$M$稀疏性已成为加速大型语言模型（LLM）的实用方向。然而，现有的可学习掩码方法会带来大量的参数和内存开销，限制了其在大规模模型和激进稀疏率下的可扩展性。在这项工作中，我们从调和效率与可扩展性的角度重新审视半结构化剪枝。我们提出了重要性水库（RoI），一种轻量级半结构化剪枝框架，通过可微分子集采样来学习稀疏掩码。与先前对所有可行$N$:$M$模式建模完整分类分布的方法不同，RoI引入了一种紧凑对数几率参数化用于稀疏掩码学习，并进行无放回采样以选择掩码，从而将可训练参数从组合复杂性降低到$\mathcal{O}({M})$。因此，RoI所需可学习参数减少1.5-8.75倍，且内存成本显著降低，同时与硬件友好的稀疏模式保持完全一致。在Qwen2.5 LLM系列（0.5-7B参数）多个规模上的广泛评估表明，RoI在强内存效率、稳定性和更激进$N$:$M$稀疏模式的可扩展性方面取得了具有竞争力的性能，为高效LLM部署提供了一条实用路径。

## Abstract
Semi-structured $N$:$M$ sparsity has emerged as a practical direction for accelerating large language models (LLMs). However, existing learnable-mask approaches incur substantial parameter and memory overhead, limiting their scalability to large models and aggressive sparsity regimes. In this work, we revisit semi-structured pruning from a perspective that reconciles efficiency with scalability. We propose Reservoir of Importance (RoI), a lightweight semi-structured pruning framework that learns sparsity masks through differentiable subset sampling. Unlike prior methods that model full categorical distributions over all feasible $N$:$M$ patterns, RoI introduces a compact-logit parameterization for sparsity mask learning and performs sampling without replacement to select masks, thereby reducing trainable parameters from combinatorial complexity to $\mathcal{O}({M})$. As a result, RoI requires 1.5-8.75$\times$ fewer learnable parameters and significantly lower memory cost, while remaining fully aligned with hardware-friendly sparsity patterns. Extensive evaluations across multiple scales of the Qwen2.5 LLM family (0.5-7B parameters) demonstrate that RoI achieves competitive performance with strong memory efficiency, stability, and scalability to more aggressive $N$:$M$ sparsity patterns, offering a practical path toward efficient LLM deployment.

## 1. 论文的核心问题与整体含义

### 研究动机与背景
- **半结构化稀疏剪枝（N:M sparsity）** 是加速大型语言模型（LLM）推理的重要技术方向。它要求每一组连续的 M 个参数中恰好保留 N 个非零值，既保留了一定的剪枝灵活性，又能与硬件（如 NVIDIA Ampere/Hopper 架构）的稀疏计算内核兼容。
- **现有可学习掩码方法的核心瓶颈**：以 MaskLLM 为代表的先前方法，需要将每个剪枝组上的掩码建模为**完整分类分布**，即对全部 $\binom{M}{N}$ 种可行 N:M 配置各维护一个 logit 参数。这一参数化方式的复杂度呈**组合爆炸**，导致：
  - 可训练参数数量庞大（如 7B 模型在 2:4 稀疏下就需要约 9.8B 额外参数）；
  - 显存/内存开销巨大；
  - 难以拓展到更大的模型和更激进的稀疏模式（如 2:8）。
- **本文提出的整体解决方案**：提出 **RoI（Reservoir of Importance，重要性水库）** 框架，以**可微分子集采样**替代全分类分布建模，将每个剪枝组的可学习参数从 $\mathcal{O}\!\left(\binom{M}{N}\right)$ 降至 $\mathcal{O}(M)$，在保持硬件友好和剪枝性能的同时大幅降低训练成本。

## 2. 论文提出的方法论

### 核心思想
- 不再枚举所有可能的 N:M 掩码，而是将掩码生成视为**从 M 个候选权重中无放回地采样 N 个权重**的过程。
- 通过引入**紧凑 logit 向量**（长度为 M），将完整分类分布替换为逐项的类别分布，从而把参数复杂度降低到 O(M)。
- 采样过程采用 **Gumbel-Top-K 技巧**进行连续松弛，保持端到端可微性，支持梯度训练。

### 关键技术细节
1. **随机变分优化框架**：
   - 将最优掩码搜索问题（NP-hard）转化为最小化变分上界的问题：
     $$
     \Phi^* = \arg\min_\Phi \mathbb{E}_{\Pr(\mathcal{M}|\Phi)}[\mathcal{L}_{CE}(\mathcal{D}; \mathcal{W}\odot\mathcal{M})]
     $$
   - 每个剪枝组的掩码分布由**加权水库采样（WRS）分布** 刻画。

2. **加权水库采样（WRS）**：
   - 给定权重 $w_1,\dots,w_L$，无放回地依次采样 K 个元素，第 t 个元素被选中的概率正比于其权重在剩余元素权重总和中的占比。
   - 其概率形式为链式乘积（论文公式 1），保证了子集采样的正确性。

3. **Gumbel-Top-K 与可微松弛**：
   - 对 logits 添加 Gumbel 噪声得到随机键 $\kappa_i = \phi_i + g_i$；
   - 逐步更新调整键 $\alpha^{(k)} = \alpha^{(k-1)} + \log(1 - \mu^{(k-1)})$；
   - 对调整键应用带温度 τ 的 softmax，得到松弛的一热向量（公式 10–12）；
   - 将 N 个松弛一热向量求和即可得到连续松弛的 N-hot 掩码。

4. **温度退火调度**：
   - 引入两个独立超参数：Gumbel-Softmax 温度 τ 和采样随机性温度 λ；
   - 两者采用**指数退火**策略，从高随机性逐步收敛到确定性解：
     $$
     \tau_t = \max\left(\tau_{end}, \tau_{init}\cdot \left(\frac{\tau_{end}}{\tau_{init}}\right)^{t/T_{anneal}}\right)
     $$
     λ 的退火方式同理。

5. **参数复杂度对比**：
   - MaskLLM 等分类参数化方法：$\mathcal{O}\!\left(\binom{M}{N}\right)$ 每个剪枝组；
   - RoI：$\mathcal{O}(M)$ 每个剪枝组；
   - 在常见模式下的实际压缩比：2:4 为 1.5×，4:8 为 8.75×，2:8 为 3.5×（见论文图 1）。

6. **定理保障**：论文给出定理 1，证明了从 WRS 分布采样有序子集再求和得到的掩码，其期望损失与直接从目标掩码分布采样得到的期望损失一致。

## 6. 论文的主要结论与发现

1. **RoI 显著优于传统显著性基线**：在 2:4 稀疏下，RoI 的 PPL 远优于 Magnitude、Wanda、SparseGPT——如 7B 模型上从 16.44（SparseGPT）降至 14.89，而 Magnitude 则完全崩溃（PPL > 5000）。

2. **RoI vs MaskLLM：性能持平但成本大幅降低**：
   - 7B 模型 2:4 稀疏下平均准确率 64.54% vs 64.44%、PPL 14.89 vs 14.91，几乎相同；
   - 但 RoI 的可训练参数仅为 MaskLLM 的 1/1.5（同为原始模型参数量），在 2:8 下仅为 1/3.5；
   - 训练时间也全面低于 MaskLLM（如 7B 模型：46.10 vs 55.39 GPU 小时）。

3. **RoI 在大规模/更激进的稀疏模式下依然稳健**：
   - 在 2:8 稀疏下，RoI 依然是 PPL 最低的方法（7B 模型 32.33），而 Wanda 等启发式方法完全失效（PPL > 10⁴）。
   - 说明 RoI 的参数化方式足以胜任极端稀疏场景。

4. **数据扩展性优于 ProxSparse**：正则化方法（ProxSparse）早期收敛快，但后续数据增多时性能增益停滞；RoI 则随训练 token 增加持续稳定下降 PPL，展现出更好的渐近性能。

5. **RoI 的掩码与 MaskLLM 高度相似**（重叠率最高），但用了大幅更低的训练成本，说明其有效的剪枝模式与更强的数据驱动方法一致。

## 7. 优点

- **参数效率显著**：从 $\mathcal{O}\!\left(\binom{M}{N}\right)$ 降到 $\mathcal{O}(M)$，是核心创新点，尤其在大 M 或 N≈M/2 时优势更加突出（1.5×–8.75×）。
- **理论保障清晰**：定理 1 严格证明了基于有序子集采样的期望损失与直接从目标掩码分布采样一致，保证了方法设计的正确性。
- **与硬件友好的稀疏模式天然对齐**：仍遵循 N:M 约束，不牺牲部署兼容性。
- **训练效率全面提升**：更少的可训练参数意味着更低的优化器状态、梯度流量和反向传播开销，在训练时间上也有实证支持。
- **实验设计兼顾广度与深度**：多模型规模、多基准、多稀疏率、多消融，并附带吞吐量验证和跨架构泛化（Gemma2-9B）。
- **代码开源**：提供了可复现的源代码。

- **硬件依赖明显**：真正的推理加速目前仅限支持 2:4 稀疏的特定平台（如部分 NVIDIA/AMD GPU）；对于其他 N:M 比例，缺少内核和工具链支持，实际加速收益有限。这一点论文在 Limitations 中坦承。
