## 摘要
高效地改进跨多样任务的自主代理，对于加速代理型AI中的递归自我改进（RSI）至关重要，而提示优化作为一种有前景的方法，能够提供与微调模型权重相当的性能提升，同时降低优化和推理过程中的计算成本。然而，近期的发展越来越倾向于使用不必要复杂的提示优化器。我们引入了朴素提示优化（NPO），一种轻量级的单线方法，通过教师模型和回滚反馈迭代地修订提示。NPO在更少的回滚次数下实现了与GEPA相当或更优的性能，且其优势随着教师模型能力的增强而扩大，表明更强的教师推理能力可以部分替代优化器端的搜索复杂性。在交互式游戏中，NPO总体上与GEPA保持竞争力，而GRPO在某些不适合提示优化的任务上表现更好。我们还表明，NPO优化后的提示在逐字应用于其他学生模型时，能带来类似的性能提升，尤其是在同一模型家族内。总体而言，我们的初步结果显示，简单、线性的提示优化可以媲美更复杂精细的搜索程序。

## Abstract
Efficiently improving autonomous agents across diverse tasks is central to accelerating recursive self-improvement (RSI) in agentic AI, with prompt optimization emerging as a promising approach capable of delivering performance gains comparable to those achieved by fine-tuning model weights, while reducing computational costs in both optimization and serving. However, recent developments increasingly favor unnecessarily complex prompt optimizers. We introduce Naive Prompt Optimization (NPO), a lightweight single-lineage method that iteratively revises prompts using a teacher model with rollout feedback. NPO achieves comparable or better performance than GEPA with fewer rollouts, and its advantage increases with stronger teacher models, suggesting that stronger teacher reasoning can partially substitute for optimizer-side search complexity. In interactive games, NPO remains broadly competitive with GEPA, while GRPO performs better on some tasks less amenable to prompt optimization. We also show that NPO-optimized prompts elicit similar performance improvements when applied verbatim to other student models, especially across models within the same family. Overall, our preliminary results show that simple, linear prompt optimization can rival substantially more sophisticated and complex search procedures.

## 2. 方法论
- **核心思想**：NPO 只维护一条提示谱系，不使用候选池或显式搜索；由“教师模型”基于完整 rollout 轨迹和奖励反馈，迭代生成下一版提示。
- **算法流程**（文字说明）：
  1. 初始化初始提示 \(P(0)\)；
  2. 在每次迭代 \(i\) 中，从环境中采样一个小批量任务；
  3. 用当前提示 \(P(i)\) 运行学生模型，收集 rollout 轨迹和奖励；
  4. 构造一个大小为 \(W\) 的滑动窗口，包含最近 \(W\) 次迭代的提示、轨迹和奖励；
  5. 将这些内容全部输入教师模型，由教师模型综合分析并输出下一版提示 \(P(i+1)\)。
- **关键区别**：
  - 与 OPRO 相比：NPO 不仅使用之前的提示和标量分数，还利用完整的 rollout 轨迹和逐样本奖励；
  - 与 GEPA 相比：GEPA 维护多候选池，通过反射和 Pareto 选择保留多个分支，而 NPO 只保留一条线性演化分支。
- **对比基线**：
  - **GEPA**：候选池 + 反射 + Pareto 选择；
  - **GRPO**：权重微调基线，使用 LoRA 适配器，通过组内相对优势更新策略。

## 6. 主要结论与发现
- **NPO 更高效**：在 IFBench 和 HotpotQA 上，NPO 用更少的 rollout 就达到或超过 GEPA 的性能。
- **强教师增强优势**：教师模型越强（如 GPT-5.5），NPO 相对 GEPA 的优势越明显，说明“更强的教师推理能力”可以部分替代“优化器端的搜索复杂度”。
- **提示可迁移**：优化后的提示在同一模型家族内迁移效果显著（例如小模型到大模型），跨家族迁移也有一定效果，但波动更大。
- **交互游戏中的竞争性**：在 22 个 TextArena 游戏中，NPO 与 GEPA 总体表现相当；GRPO 在部分不适合提示优化的任务上获得更好的性能。
- **无泄漏证据**：优化提示与训练集答案的重合度自然增长，但与验证集答案的重合度可忽略不计，说明性能提升并非来自评估集数据泄漏。

## 7. 优点
- **方法极简**：NPO 没有候选池、没有 Pareto 选择、没有显式搜索，仅靠“教师模型 + 完整 rollout 反馈”迭代，却能达到甚至超越复杂方法的性能。
- **实验设计细致**：
  - 使用共享伪随机数实现了配对评估，有效降低环境随机噪声；
  - 使用约束解码分离“决策能力”与“格式遵从”，提高了比较公平性；
  - 对验证集答案泄漏进行了系统性检查，增加了结果可信度。
- **实用性**：展示了优化提示可直接迁移到其他学生模型，突出了提示优化相比权重微调的可移植优势。
- **领域启示**：为提示优化研究提供了一个强基线，提醒社区重新审视“复杂搜索是否必要”的问题。

## 8. 不足与局限
- **任务覆盖有限**：实验仅包含两个传统基准和一批短时程游戏，缺乏复杂、长视界的代理任务。
- **学生模型范围窄**：未将 GPT-5.5 等前沿闭源模型作为学生，原因是 API 缺乏细粒度解码控制和 token 级 logits，且时间上存在性能不一致。
- **RL 稳定性问题**：GRPO 在某些游戏上训练不稳定，且对奖励函数设计敏感，导致不同任务可能只适用特定优化方法。
- **长时程扩展困难**：长时程环境需要更大的滑动窗口，可能超出教师模型的上下文限制，NPO 的优势在更长任务中尚不明确。
- **隐私风险**：NPO 需要将学生模型的 rollout 轨迹共享给教师模型；若使用第三方闭源 API 作为教师，敏感数据可能暴露，需要额外掩码和消毒处理。
