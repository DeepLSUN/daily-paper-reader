## 摘要
扩散大语言模型（dLLMs）通过迭代去噪并行解码多个令牌，为自回归生成提供了一种有前景的替代方案。然而，增加解码并行性通常会降低生成质量，因为早期错误可能污染后续上下文。可撤销解码通过重新评估已解码令牌并重新掩盖不可靠的令牌来缓解此问题，但现有方法忽略了不可靠的令牌也可能破坏验证上下文本身。我们识别出这种失败模式，并提出了依赖感知的可撤销解码（DARD），这是一种无需训练的框架，将令牌分为已掩盖、候选和未掩盖三种状态。DARD使用排除较不可靠令牌的选择性上下文来验证候选令牌，并自适应地调节它们对后续解码的影响。在3个开源dLLMs上的12个文本和多模态基准测试中的实验表明，与最近的可撤销解码方法相比，DARD持续改善了速度-质量帕累托前沿，在Flickr30K上比Saber实现了2.71倍加速和4.35个CIDEr分数提升。

## Abstract
Diffusion large language models (dLLMs) offer a promising alternative to autoregressive generation by decoding multiple tokens in parallel through iterative denoising. However, increasing decoding parallelism often degrades generation quality, as early errors can contaminate later contexts. Revocable decoding mitigates this issue by re-evaluating decoded tokens and remasking unreliable ones, but existing methods overlook that unreliable tokens may also corrupt the verification context itself. We identify this failure mode and propose Dependency-Aware Revocable Decoding (DARD), a training-free framework that separates tokens into masked, candidate, and unmasked states. DARD verifies candidate tokens using a selective context that excludes less reliable tokens and adaptively regulates their influence on subsequent decoding. Experiments across 12 textual and multimodal benchmarks on 3 open-source dLLMs show that DARD consistently improves the speed-quality Pareto frontier over recent revocable decoding methods, achieving a 2.71$\times$ speedup and a 4.35-point CIDEr score gain over Saber on Flickr30K.

# 论文详细中文总结

## 1. 论文的核心问题与整体含义

- **背景**：扩散大语言模型（dLLMs）通过迭代去噪并行解码多个 token，是自回归模型之外的高效生成方案。但并行解码会引入“组合错误”（如“Los Diego”），低置信度、被过早固定的 token 会污染后续上下文，导致生成质量下降。
- **已有缓解手段**：可撤销解码（Revocable Decoding）会在后续步骤重新评估已解码 token，并重新掩码不可靠 token；代表性方法包括 Saber 和 WINO。
- **被忽视的问题**：现有可撤销解码在验证某个 token 时，仍会将其他“不可靠 token”作为验证上下文使用。这些错误 token 可能本身扭曲验证信号，导致错误未被纠正，或造成不必要的重新掩码。
- **论文目标**：识别该失败模式，并提出 **DARD（Dependency-Aware Revocable Decoding）**，一种无需训练的推理框架，通过依赖感知的选择性上下文进行验证，改善 dLLMs 解码的“速度–质量”权衡。

## 2. 论文提出的方法论

- **核心思想**：将 token 分为三态：
  - **M（Masked）**：尚未解码的 token；
  - **C（Candidate）**：已解码但置信度不高的候选 token；
  - **U（Unmasked）**：已解码且置信度高的可靠 token。
- **影子序列（Shadow Sequence）**：在原有序列外引入一条长度相同的全掩码影子序列，原始序列和影子序列共享位置嵌入，由同一模型前向传播分别产生两组预测，从而并行完成“解码”和“验证”。
- **状态特定注意力掩码（State-Specific Attention Mask）**：
  - U 验证仅使用可靠上下文（U 与更高置信度 C）；
  - C 验证采用“置信度排序”的注意力掩码，只允许高置信度候选 token 作为低置信度候选的上下文，等价于按置信度降序进行近似多步解码，即
    \[
    p_\theta(s^{\pi_t(k)}_{t+1}|\tilde{x}_t; M) \approx p_\theta(s^{\pi_t(k)}_{t+1}|\hat{x}^{\pi_t(1:k-1)}_t,\hat{x}^{U_t}_t).
    \]
- **M 预测的自适应逻辑混合（Adaptive Logit Mixing）**：
  - 对每个掩码位置，模型分别从原始序列和影子序列获得两个预测：一个利用 C 上下文，一个不利用；
  - 根据上一轮验证结果（C 中被提升为 U 或降级为 M 的位置），用几何距离核计算局部“提升/降级”得分 \(P_t^i\)、\(D_t^i\)，得到权重
    \[
    w^i_t = \frac{P_t^i + p_0}{P_t^i + D_t^i + p_0};
    \]
  - 最终混合 logits：\(\text{logit}_{\text{mix}} = w^i_t \cdot \text{logit}(\text{原序列}) + (1-w^i_t)\cdot \text{logit}(\text{影子序列})\)。
- **状态转移**：每步依据置信度 \(c^i_t\) 和阈值 \(\tau_c,\tau_u\) 更新状态：
  - \(c \le \tau_c\) → 保持或回到 M；
  - \(\tau_c < c \le \tau_u\) → 进入 C；
  - \(c > \tau_u\) → 进入 U。
- **训练无关性**：DARD 不修改模型参数，只改变推理时的注意力掩码、状态管理和 logits 融合方式。

## 6. 论文的主要结论与发现

- 可撤销解码中，**不可靠 token 污染验证上下文**是真实存在的失败模式，会导致错误持续或产生不必要的重新掩码。
