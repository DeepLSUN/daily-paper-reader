## 摘要
同策略蒸馏（OPD）利用冻结教师模型提供的令牌级信号，在学生自身轨迹上对其进行监督，然而采样损失如何在令牌间分配更新仍鲜为人知。我们分析了关于学生逻辑的每令牌K2估计器（反向KL）的梯度。该梯度的ℓ1范数分解为教师-学生对数概率差的绝对值和一个学生端softmax因子，该因子随着采样令牌在学生模型下概率降低而增大。在我们的数学蒸馏实验中，这些每令牌范数高度非均匀：低学生概率令牌在范数总和中占不成比例的份额，并且在大教师-学生差距中富集。作为该分析启示的一种轻量级干预，我们研究了惊奇感知重新加权（SuRe），这是一种分离的、有界的加权规则，进一步放大了这种现有分配。在两种Qwen3学生规模下，SuRe在多项数学指标上优于普通OPD，并且在选定的域外基准上未显示明显退化。因此，我们的主要贡献是对使用K2估计器训练的反向KL OPD进行梯度级表征，而SuRe是其一种经验实例化。

## Abstract
On-policy distillation (OPD) supervises a student on its own trajectories with token-level signals from a frozen teacher, yet how a sampled loss allocates updates across tokens remains poorly understood. We analyze the gradient of the per-token K2 estimator of reverse KL with respect to the student logits. The $\ell_1$ norm of this gradient factorizes into the absolute teacher--student log-probability gap and a student-side softmax factor that grows as the sampled token becomes less likely under the student. In our math-distillation runs, these per-token norms are highly non-uniform: low-student-probability tokens account for a disproportionate share of their sum and are also enriched in large teacher--student gaps. As a lightweight intervention suggested by this analysis, we study Surprise-aware Reweighting (SuRe), a detached, bounded weighting rule that further amplifies this existing allocation. Across two Qwen3 student scales, SuRe improves several math metrics over vanilla OPD and shows no clear degradation on the selected out-of-domain benchmarks. Our primary contribution is therefore a gradient-level characterization of reverse-KL OPD trained with the K2 estimator, with SuRe as one empirical instantiation.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：现代语言模型（如 Qwen3、MiMo、DeepSeek-V4、Kimi K3、GLM-5）普遍采用“SFT → RL → 最终同策略蒸馏（OPD）”的多阶段后训练流程。OPD 直接在学生自身采样轨迹上提供稠密的 token 级教师信号，用于将大模型能力迁移到小模型或合并多策略能力。
- **核心问题**：在基于采样 token 的反向 KL 同策略蒸馏中，每个 token 位置的损失对参数更新（梯度）的贡献分配机制尚不清晰——哪些 token 获得大梯度、为什么获得大梯度，缺少理论层面的刻画。
- **研究目标**：从学生 logits 出发，对 per-token K2 估计器（反向 KL 的采样近似）的梯度进行精确分解，揭示梯度范数在 token 间的非均匀分布规律，并据此提出一种轻量级干预方法 SuRe，验证梯度分配视角能否有效指导优化。
- **整体含义**：本文的核心贡献不在于提出一种全新的蒸馏范式，而在于给出反向 KL OPD 的 **梯度级表征**，说明低学生概率 token 是不成比例更新的“惊奇”区域，并证明这种分配可以被简单、有界的加权规则进一步利用。

## 2. 提出的方法论

- **核心思想**：分析 per-token K2 估计器相对于学生 logits 的梯度，将其 ℓ1 范数分解为两个可解释因子的乘积；基于该分解设计一个“分离（stop-gradient）、有界、单调”的 token 级重加权规则 SuRe。
- **关键公式与推导**：
  - 定义每 token 教师-学生对数概率差：  
    \(\Delta \log p_t = \log \pi_T(y_t|c_t) - \log \pi_S(y_t|c_t)\)
  - K2 估计器：  
    \(L_t^{RKL} = \frac{1}{2}(\Delta \log p_t)^2\)
  - 梯度恒等式：  
    \(\nabla_z L_t^{RKL} = -\Delta \log p_t \left(e_{y_t} - \pi_S(\cdot|c_t)\right)\)
  - ℓ1 范数分解（Lemma 1）：  
    \(\|\nabla_z L_t^{RKL}\|_1 = 2|\Delta \log p_t| \cdot (1 - \pi_S(y_t|c_t))\)
  - 该分解表明：梯度系数随采样 token 的学生概率增大而减小；当 token 越“惊奇”（学生概率低），即使教师-学生差距相同，也会获得更大的梯度权重。
- **SuRe 加权规则**：
  - 定义分离后的学生概率 \(\bar{\pi}_{S,t} = \mathrm{sg}(\pi_S(y_t|c_t))\)
  - 权重 \(w_t = 1 + \alpha(1 - \bar{\pi}_{S,t})\)，\(\alpha \ge 0\)；\(\alpha=0\) 时退化为普通 OPD。
  - 目标函数：  
    \(L^{RKL\text{-}rw} = \frac{1}{|T|}\sum_{t\in T} w_t L_t^{RKL}\)，分母不重新归一化。
  - 效果：在保持原始梯度方向不变的同时，相对放大低学生概率 token 的梯度贡献，高学生概率 token 的权重趋近 1。
- **实现特点**：SuRe 无需额外参考模型、额外前向、学习选择器或硬阈值，仅需一个标量系数 α，属于极轻量级干预。

## 6. 主要结论与发现

- **梯度分解结论**：K2 估计器的 per-token 梯度 ℓ1 范数可精确分解为 \(2|\Delta\log p_t|(1-\pi_S)\)，并且低学生概率 token 在梯度范数总和中占据不成比例的份额，同时大教师-学生差距也富集于这些 token，形成联合经验模式。
- **诊断排序结论**：相比 JSD 和熵等非方向性诊断量，按 \(|\Delta\log p_t|\) 排序能覆盖更大比例的梯度范数总和（top 5%/10% token 覆盖 54.1%/74.6%，远高于 JSD 和熵）。
- **SuRe 效果**：
  - 在 Qwen3-1.7B 上，SuRe 相比 vanilla OPD 在 AIME24 pass@8 提升约 +6.7pp（16.67→23.33），AMC23 pass@8 提升约 +7.5pp（67.50→75.00），并改善多项 avg@k；在 4B 学生上 AMC23 pass@8 提升 5.0pp。
  - MATH-500 变化较小；4B 学生的 AIME25 指标下降。
  - OOD 基准上 SuRe 与 vanilla OPD 基本相当，无统一提升，也无明显退化。
- **训练动态**：SuRe 提高了早期梯度范数，但 actor 熵与 vanilla OPD 相近；这说明 SuRe 的效应是“重新分配”而非破坏学生探索行为。
- **总体判断**：本文的贡献不是声称 SuRe 是普遍最优方法，而是提供了反向 KL OPD 在 token 层面的梯度分配视角，并展示了一个基于该视角的简单干预实例。

## 7. 优点

- **理论清晰**：给出了梯度范数的精确闭式分解，使“哪些 token 被重点更新”有了可解释的数学依据，而非仅凭经验观察。
- **轻量实用**：SuRe 只需一个 α 系数、一个 detached 概率标量，不增加额外模型或计算开销，易于嵌入现有 OPD 流水线。
- **实验设计比较全面**：覆盖多基准、多学生规模、OOD 评估、超参数扫描、方向控制、匹配控制、第二 seed 等多个维度，结论较扎实。
- **诚实与克制**：作者没有夸大 SuRe 的普适性，明确报告了负面结果（如 4B AIME25 退化）并承认控制实验无法完全解开机制，保持了学术诚信。
- **诊断视角有普适潜力**：该 token 级梯度分配分析框架不仅适用于 SuRe，也可用于未来设计更精细的 OPD 重加权或 token 选择策略。

## 8. 不足与局限

- **范围限制**：仅分析采样 token 级反向 KL（K2 估计器），未覆盖全词表蒸馏、JSD 目标、前向 KL 等替代设定，结论不一定外推。
- **领域限制**：实验集中在数学推理，推理轨迹长度有限；在代码、长链推理或开放式生成上的泛化性未验证。
