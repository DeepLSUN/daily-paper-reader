## 摘要
代理技能通过任务特定指令、脚本和资源扩展编码代理，但也创建了一个可信指令通道，该通道可能被滥用以超越传统安全攻击。本文研究了通过技能注入实现的令牌放大：一种经济资源滥用威胁，其中恶意技能导致代理消耗比正常任务执行所需更多的令牌。我们提出了SkillBloat，一个两阶段框架，首先在多种放大机制中筛选多种攻击类型条件的库，然后通过LLM引导的全文技能重写来优化最强候选。在真实世界的技能基准上进行评估，SkillBloat在多种编码代理目标配置下实现了5.4184倍至10.1455倍的平均最佳放大。消融实验表明，第二阶段的重写循环持续提高了平均最佳放大效果，超过了仅进行第一阶段攻击类型筛选，这表明迭代优化在初始攻击类型选择之外提供了额外收益。这些结果表明，技能生态系统暴露了一个实用的资源放大攻击面，该攻击面与现有的面向安全的技能投毒正交。

## Abstract
Agent skills extend coding agents with task-specific instructions, scripts, and resources, but they also create a trusted   instruction channel that can be abused beyond conventional security attacks. This paper studies token amplification through   skill injection: an economic resource-abuse threat in which a malicious skill causes an agent to consume substantially more   tokens than needed for normal task execution. We present SkillBloat, a two-phase framework that first screens a library of   diverse attack-type conditions across multiple amplification mechanisms and then refines the strongest candidate through   LLM-guided full-document skill rewriting. Evaluated on a real-world skill benchmark, SkillBloat achieves 5.4184x-10.1455x   average best amplification across multiple coding-agent target configurations. An ablation shows that the second-stage   refinement loop consistently improves average best amplification over Phase 1 attack-type screening alone, demonstrating   that iterative optimization provides additional benefit beyond initial attack-type selection. These results show that skill   ecosystems expose a practical resource-amplification attack surface that is orthogonal to existing security-oriented skill   poisoning.

**攻击类型条件库（Z = {z₁, ..., z_K}，K = 15）**：每个条件指定一种放大器行为，并从共享清单中选择一个或多个辅助工具脚本。条件分为三大类：

## 6. 主要结论与发现

1. **SkillBloat 有效实现大规模令牌放大**：平均最佳放大从 5.4184×（Claude Code + glm-5）到 10.1455×（Codex + gpt-5.4-mini）；单任务峰值达 71.59× 和 75.86×。
2. **轻量级模型更易受攻击**：同一模型家族中较弱的后端更易被放大（GLM-4.7-Flash 9.3105× vs glm-5 5.4184×；gpt-5.4-mini 10.1455× vs gpt-5.5 6.0063×），更强的模型更能抵抗或压缩冗余程序性指令。
3. **放大并非失败执行的副产品**：攻击后任务完成率与基线相当或更高（GLM-4.7-Flash 从 76% 升至 80%，gpt-5.4-mini 从 86% 升至 92%），实现"保持任务完成的同时消耗更多资源"。
4. **Phase 2 迭代优化带来确定性增益**：从 Phase 1 的 5.7750× 提升至 Phase 2 的 7.7202×，绝对提升 1.9452×（约 33.7% 相对增益）。反馈引导优于无反馈重采样，确认迭代优化利用真实信号而非单纯多采样。
5. **攻击类型偏好有规律**：fake error retry 在所有 4 个模型中都进入 Top-5（共 26 次入选），multi-point injection 在 3 个模型中高频出现；Claude Code 后端偏爱 self-debate，Codex 后端偏爱 task decomposition。
6. **中毒技能跨任务转移性强**：10 个技能的平均保留率为 0.92，7 个技能保留至少 0.82 倍原始放大，4 个技能超过 1.0（在新任务上放大更多）。结构性攻击（增加验证、重试、报告脚手架）比行为性攻击更任务无关、更危险。
7. **一个案例的具体数字**：consciousness-principles 任务在 gpt-5.5 下从基线 38,410 tokens（$0.21）增至 Phase 2 后 1,013,561 tokens（$5.41），放大 26.39×；命令数从 3 增至 28，文件编辑数从 0 增至 10。

- **防御与检测讨论不足**：论文聚焦攻击构造，未系统讨论防御方的可行对策（如令牌消耗异常检测、技能指令沙箱化、上下文预算限制），也未分析 SkillBloat 生成的技能文档能否被现有安全过滤器识别。
- **模型命名与可复现性存疑**：文中涉及的模型版本（如 GLM-4.7-Flash、glm-5、gpt-5.4-mini、gpt-5.5）在本文写作时间点可能为虚构或预发布版本，且实验均通过 API 黑盒调用完成，研究者难以复现精确环境。
- **负责任披露缺失**：论文未说明是否已向相关模型提供商或技能平台披露漏洞，也未提供缓解建议的落地验证，安全研究的伦理规范性不足。

## 9. 综合评价与启示

- **总体定位**：SkillBloat 是首个系统化研究"令牌放大攻击"的工作，填补了智能体安全领域中对经济型资源滥用威胁的研究空白。其核心价值在于证明了一个反直觉的事实——攻击者无需破坏任务完成质量或窃取数据，仅通过"让智能体做更多正确的事"就能造成显著的经济损失，这使得该攻击天然绕过以保密性、完整性为核心的传统安全防线。
- **理论贡献**：提出的 15 类攻击类型条件库构成了一套可扩展的攻击分类学，覆盖输出层、工具层、上下文层三个资源消耗维度，为后续研究提供了统一的描述语言和评估基准。
- **方法贡献**：两阶段"筛选→优化"流水线（攻击类型条件库 + LLM 引导迭代优化）具有通用性，可迁移至其他注入场景（如 MCP 工具描述投毒、RAG 知识库污染）；完整的 SKILL.md 重写策略在隐蔽性与可操作性之间取得了良好平衡。
- **实践警示**：对编码智能体生态系统的设计者而言，本文结果意味着仅依赖模型安全对齐无法防御此类攻击，需要在系统层面引入硬性资源边界——例如技能执行令牌配额、工具调用次数限制、上下文长度预算、逐技能成本核算与异常告警。
- **未来方向**：(1) 针对令牌放大攻击的检测与防御机制研究；(2) 将攻击推广至多智能体协作、长时间运行任务等更复杂场景；(3) 研究模型规模、指令遵循能力与放大抵抗度之间的量化关系；(4) 开发考虑成本敏感度的基准测试，使资源消耗成为安全评估的标准维度。
- **最终评价**：这是一篇问题新颖、方法扎实、威胁论证具有说服力的高质量研究工作，虽在实验规模、统计严谨性和伦理披露方面仍有改进空间，但作为该新兴攻击面开启性的探索，其对智能体安全研究的推动价值显著，值得安全社区重点关注与后续深化。
