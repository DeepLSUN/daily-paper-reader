## 摘要
基于大型语言模型（LLM）的多智能体系统（MAS）正在迅速普及，但其异构的执行轨迹无法为跨方法的评估提供共同基础。仅基于结果的基准测试丢弃了协作信息，而LLM作为评判者的评估则需要额外的、依赖模型的推理，并且可能随LLM和评分标准的不同而变化。我们引入了一个可泛化的评估框架，将原生MAS轨迹映射到统一协作图的共享空间中，使不同方法能够在相同的表示、参考集和指标面板下进行评估。候选图与查询特定的参考森林进行比较。每个森林都是基准提供的已验证成功图的集合：它记录了代表性MAS方法完成任务的多种方式，而不是规定唯一的最优过程。将该框架实例化为ForestBench，我们从七个公开数据集中筛选出844个需要协作的查询，为每个查询预计算十个成功的、以目标为条件的参考图，并评估六个代表性的MAS框架。通过受控主干、参考构建和扰动研究来测试评估的稳定性和范围。一旦基准森林构建完成，ForestBench可在毫秒内对轨迹进行评分，无需进一步的LLM推理，为比较不同的MAS协作轨迹提供了可复用的结构基础。

## Abstract
Multi-agent systems (MAS) built on Large Language Models (LLMs) are proliferating rapidly, but their heterogeneous execution traces provide no common basis for evaluation across methods. Outcome-only benchmarks discard collaborations, whereas LLM-as-Judge evaluation requires additional, model-dependent inference and can vary with the LLM and rubric. We introduce a generalizable evaluation framework that maps native MAS traces into a shared space of unified collaboration graphs, enabling different methods to be evaluated under the same representation, reference set, and metric panel. Candidate graphs are compared with a query-specific reference forest. Each forest is a benchmark-provided collection of verified-success graphs: it records diverse ways in which representative MAS methods can complete the task, rather than prescribing a unique optimal process. Instantiating the framework as ForestBench, we filter $844$ collaboration-necessary queries from seven public datasets, precompute ten successful target-conditioned reference graphs per query, and evaluate six representative MAS frameworks. Controlled backbone, reference-construction, and perturbation studies test the stability and scope of evaluation. Once the benchmark forests are built, ForestBench scores a trace in milliseconds without further LLM inference, providing a reusable structural basis for comparing diverse MAS collaboration traces.

  - **结果型基准（Outcome-only benchmarks）**：如GSM8K、MMLU、HumanEval，仅看最终答案，完全丢弃了协作过程信息，无法区分不同协作模式的差异；
  - **LLM-as-Judge评估**：需要额外的、依赖模型的推理，且结果随LLM和评分标准（rubric）而波动，成本高、可复现性差；
- **论文的目标**：构建一个**可泛化、确定性、无需额外LLM推理**的统一评估框架，使不同MAS方法在同一表示空间、同一参考集、同一指标面板下进行公平、可复用的横向比较。

## 2. 论文提出的方法论

- **核心思想**：将任意MAS执行轨迹映射为**统一的有向无环协作图（Collaboration DAG）**，并将其与查询特定的“参考森林（Reference Forest）”进行结构比对。
  
- **关键步骤**：
  
  1. **图抽象（Graph Abstraction）**：将原始轨迹投影为 $G(\tau) = (V, E, \phi)$：
     - $V$：每个原子动作对应一个节点；
     - $E$：动作间的信息传递对应有向边（保证无环）；
     - $\phi$：为节点标注发出者、**规范化角色**（canonical role）、文本内容。
     - 该抽象是**有损但不变**的：丢弃框架特定的运行时状态和精确时间交错，但保留角色、动作与信息流依赖。
  
  2. **参考森林（Reference Forest）**：每个查询 $q$ 对应一个参考森林 $F(q) = \{(G_k, q_k)\}_{k=1}^{K}$，其中每个 $G_k$ 是**已验证正确**的参考图（来自不同协作范式的成功轨迹），而非唯一最优过程；$K=10$。
  
  3. **配对图相似度（Pairwise Graph Similarity）**：
     $$\text{sim}(G, G') = \alpha \, s_{node} + \beta \, s_{edge} + \gamma \, s_{topo}$$
     - 默认权重 $(\alpha, \beta, \gamma) = (0.4, 0.4, 0.2)$；
     - $s_{node}$ 基于规范化角色的多重集 Jaccard 相似度；
     - $s_{edge}$ 基于角色类型化边指纹的 Jaccard 相似度；
     - $s_{topo}$ 基于图大小（节点数、边数）的比例匹配，且不奖励冗长。
  
  4. **森林匹配（Forest Match）**：
     $$\text{FM}(G, F(q)) = \frac{\sum_{k=1}^{K} w_k \, \text{sim}(G, G_k)}{\sum_{k=1}^{K} w_k} \in [0,1]$$
     - $w_k$ 为归一化的参考图质量权重（结合正确性、结构简洁性和token成本）；
     - 另设 **Best Similarity**（与最近参考树的相似度）作为补充。
  
  5. **辅助指标面板**：Node Validity（下游消费比例）、Mean Uptake（内容语义承接）、Content Redundancy（内容冗余度）、Tokens（总token预算）、Efficiency（拓扑效率）。
  
  6. **评估优势**：所有指标是 $G(\tau)$ 的确定性函数，**无需LLM参与，毫秒级完成**。

## 3. 实验设计

- **数据集来源**：7个公开数据集，覆盖4大任务类别：
  - 推理：GPQA、MMLU、MATH-500、GSM8K
  - 代码生成：SWE-bench-Verified
  - 工具使用：Terminal-Bench
  - 多跳搜索：WideSearch
  
- **查询筛选（Trace-Suitability Pipeline, TSP）**：按深度 $d\ge5$、宽度 $w\ge0.5$、可分解性 $\delta\ge0.5$ 三维度筛选，最终保留 **844个协作必需查询**。
  
- **参考森林构建**：用6个代表性MAS框架（Multi-agent Debate、Swarm、AutoGen、MetaGPT、MAS-GPT、AFlow）加单智能体锚点，每个查询生成并验证**10个成功参考图**，共8,440个参考图。
  
- **对比方法**：上述6个MAS框架，默认骨干为DeepSeek-V4-Flash；在验证实验中额外使用Claude-Sonnet-4.6、GPT-5.5、Qwen3.6-Plus。
  
- **评估方式**：每个框架在每查询上运行3个随机种子，约2,532条轨迹/框架，总计约15,192条轨迹。

## 6. 论文的主要结论与发现

- **准确性无法有效区分MAS方法**：6个框架的准确率仅为0.531–0.569（跨度0.038），但结构信号差异显著：Forest Match范围为0.316（Debate）到0.421（MAS-GPT），结构指标提供了精度无法提供的区分度。
  
- **参考森林是稳定的评估基准**：跨骨干的Kendall τ和Spearman ρ均为1.00；留出生成器实验在6/7设置中保持Top-3；非金标条件化仍保留Top-3，Kendall τ=0.867。
  
- **指标面板各有分工**：Forest Match捕捉参考相对结构；Content Redundancy捕捉重复内容（AFlow冗余度为0.167，约为其他框架3倍）；Node Validity捕捉未被消费的动作（Swarm为0.968，唯一低于1的框架）。
  
- **编排增益依赖骨干能力**：相对单智能体CoT基线，平均编排增益在DeepSeek-V4上为−0.002，在GPT-5.5上为−0.039，在Claude-Sonnet-4.6上为−0.069——更强骨干下增加智能体反而可能有害。
  
- **框架施加结构先验**：跨骨干的框架间距离矩阵相关度为0.986–0.999，表明同一框架在不同骨干下产生结构相似的模式。
  
- **领域特化明显**：Debate在全局Forest Match最低（0.316），但在SWE-bench-V（代码补丁类任务）上排名最高（0.382），其审查-修订模式更匹配此类任务。

## 7. 优点

- **创新且统一的表示**：用DAG图统一异构MAS轨迹，剥离框架特定的日志格式，保留了协作的关键结构信息。
- **参考森林代替单一模板**：避免将评估绑定到单一协调范式，允许多种成功协作结构共存，评估更公平包容。
- **确定性评估，零推理成本**：所有指标是图结构的确定性函数，无需额外LLM调用，毫秒级评分，可大规模复用。
- **可复用的benchmark资产**：844个查询 + 8,440个验证成功参考图作为释放资产，用户无需重跑LLM judge即可评估新方法。
- **系统性验证框架自身**：通过骨干替换、生成器留出、权重扫描、TSP阈值网格（36种）、扰动注入等多种方式检验评估的稳健性，学术严谨性高。
- **指标面板多维度互补**：结构、内容流、冗余、成本等多个角度立体刻画协作质量。

## 8. 不足与局限

- **LLM辅助失败诊断的可靠性有限**：不同rubric变体下细分标签的Cohen's κ较低（0.129–0.621），提示细粒度诊断结果对提示措辞敏感，只能用于粗略方向。
- **参考森林构建成本较高**：一次性约20.5M tokens（平均24.3k tokens/查询），虽然可复用，但对小规模研究团队构成一定门槛。
- **评估覆盖范围有限**：仅覆盖6个MAS框架；数据集虽涵盖推理/代码/工具/搜索，但规模有偏（推理类占55.9%，工具使用仅4.6%）。
- **Forest Match对权重设置存在一定依赖**：拓扑仅权重下排序变化大（Kendall τ=0.20），说明只考虑拓扑、忽略角色和通信语义会显著改变评估结果。
- **金标条件化的参考构建方式**可能使参考森林偏向特定生成分布，非金标条件化时FM绝对值变化明显（±0.03~0.05），表明参考森林并非对构建过程完全不变。
- **TSP筛选是启发式方法**：论文明确承认它只是启发式机制，不能证明保留的每个查询都需要多智能体，也不能证明单智能体无法解决。
- **结构性指标本质上是参考相对比较**：高Forest Match支持“与已验证成功结构接近”，但不代表普适的协作质量；最终结果正确性仍需靠accuracy单独衡量。
- **未报告硬件具体配置**：GPU型号、数量、训练时长等信息缺失，影响算力需求评估的可复现性。
