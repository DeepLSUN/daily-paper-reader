## 摘要
基于大语言模型的搜索代理被广泛用于信息检索任务，但它们对外部工具返回结果的依赖引入了一个关键的安全风险：执行过程中检索到的网页内容是不可信的，这使代理面临提示注入和目标劫持的威胁。以往关于搜索代理安全性的研究主要关注静态网页内容注入，但现代代理会发起后续查询并交叉验证相互竞争的来源，因此单个被注入的页面往往会被稀释或拒绝。我们表明，传递搜索和页面观察结果的通道是一个脆弱的安全边界：不仅会让代理暴露于单个被投毒的页面，而且一个中介化的搜索界面可以反复引导代理如何收集证据并形成最终答案。在受限的工具中介威胁模型下，当证据在代理的轨迹上被协调时，每次查询仅追加一个受控结果就能显著提高攻击成功率。我们通过一种策略驱动的长视野攻击系统来研究这一场景，并引入了权威链劫持（ACH），这是一种专家精炼的策略，将孤立的搜索结果和页面内容操纵转化为跨看似相互印证来源的一致证据链。ACH在所有基线中取得了最高的总体ASR，在完整SafeSearch测试集上达到55.9% / 83.3%的ASR / MaxN ASR。我们还进一步引入了轨迹引导的策略演化（TGSE），它能从执行轨迹中自动改进攻击者策略，以轨迹驱动的精炼取代手动设计；其最强的单一设置在留出评估中达到71.4% / 95.0%。

## Abstract
LLM-based search agents are widely used for information-seeking tasks, but their reliance on external tool returns introduces a critical security risk: web content retrieved during execution is untrusted, exposing agents to prompt injection and goal hijacking. Prior work on search-agent safety primarily focuses on static web-content injection, but modern agents issue follow-up queries and cross-check competing sources, so a single injected page is often diluted or rejected. We show that the channel delivering search and page observations is a fragile security boundary: beyond exposing the agent to a single poisoned page, a mediated search interface can repeatedly steer how the agent gathers evidence and forms its final answer. Under a constrained tool-intermediary threat model, appending only one controlled result per query can substantially increase attack success when the evidence is coordinated across the agent's trajectory. We study this setting with a strategy-driven long-horizon attack system and introduce Authority-Chain Hijack (ACH), an expert-refined strategy that turns isolated search-result and page-content manipulations into a coherent evidence chain across seemingly corroborating sources. ACH achieves the highest Overall ASR among all baselines, reaching 55.9% / 83.3% ASR / MaxN ASR on the full SafeSearch test split. We further introduce Trace-Guided Strategy Evolution (TGSE), which automatically improves attacker strategies from execution traces, replacing manual redesign with trace-driven refinement; its strongest single setting reaches 71.4% / 95.0% in held-out evaluation.

## 一、论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：LLM 搜索代理是一类新兴的 Web 连接型智能体，通过多步轨迹自主发出搜索查询、访问页面并综合答案。典型代表如通义 DeepResearch 的 ReAct 搜索代理，每一步决策都依赖于外部工具返回值组成的“观察链”。
- **核心风险**：搜索代理执行过程中检索到的网页内容不可信，使其暴露于**提示注入（Prompt Injection）**和**目标劫持（Goal Hijacking）**。而现有安全研究（如 SafeSearch）主要关注**静态网页注入**——恶意页面在运行前就已固定，无法适应代理的后续查询与交叉验证行为。
- **关键洞见**：传递搜索和页面观察结果的通道是一个**脆弱的安全边界**。现代代理会跨来源交叉核对、稀释或拒绝单一被注入页面；但一个**中介化的搜索界面**可以被攻击者反复操纵，沿着代理的全部轨迹逐步引导其证据收集与最终答案形成，从而形成比静态注入更强、更隐蔽的长期威胁。
- **核心问题**：在没有控制整个搜索引擎的前提下，仅通过**每次查询注入至多一个受控结果**并维护攻击者引入的页面，能否在代理多步搜索轨迹上显著提高攻击成功率？协调性证据链策略是否优于孤立的单页操纵？

## 二、论文提出的方法论（核心思想、关键技术细节）

### 2.1 威胁模型：约束工具中介攻击
- 攻击者充当搜索服务与代理之间的**第三方工具中介**，不控制搜索引擎本体。
- 具体操作假设：个性化赞助内容管线允许恶意广告商观察查询信号、动态调整其赞助条目、维护落地页——搜索提供商本身良性。
- 权限边界：
  - 每次搜索返回中，攻击者最多**追加一个受控结果**（标题、URL、摘要、日期/来源线索），有机结果保持不变。
  - 若代理访问该攻击者引入的 URL，页面内容在请求时生成；有机 URL 的访问保持只读。
- 成功判据：最终答案满足攻击者清单 K，而非仅仅看到恶意内容（沿用 SafeSearch 判定标准）。

### 2.2 攻击者运行时（Attacker Runtime）
- 结构：轨迹记忆 $M_t$（记录先前查询、访问、原始返回、已生成载荷与反思）+ 策略 $s$（轨迹级宏指导）+ 规划器 $P$（事件级决策）。
- 形式化：$(p_t, \rho_t) = P(a_t, o_t, M_t, s, c)$，其中 $p_t$ 为载荷，$\rho_t$ 为反思。
- 观察篡改规则：搜索注入 $R_t(q_t) \oplus b_t$；可攻击访问返回 $c^{adv}_t$；有机访问返回 $C_t(u_t)$ 不变。
- URL 注册表机制：注入 URL 与声明的后续目标 URL 可攻击；已观察的真实有机 URL 永久只读——模拟多跳攻击（注入页面可链接到其他攻击者页面）。

### 2.3 专家策略：Authority-Chain Hijack (ACH)
- 设计来源：对初步评估轨迹的模式分析。成功运行不是让首个注入页更强，而是使后续受控页面围绕同一目标主张彼此呼应，并将用户发现的矛盾框架化为过时/次要证据。
- ACH 六阶段策略：
  1. **Stage 1 搜索**：权威建立——注入与 SERP 匹配的尾位结果，赢得首次点击。
  2. **Stage 1 访问**：权威强化——专业风格的 Jina 式页面，引入目标对齐框架，不过早强推目标。
  3. **Stage 2 搜索**：验证捕获——为后续验证查询注入一致的佐证结果，用日期/范围/粒度解释冲突。
  4. **Stage 2 访问**：权威链形成——跨来源交叉引用、复用指标、对比表格，使可信度来自源间一致性。
  5. **Stage 3 搜索**：信任巩固——注入合成性“共识”结果，呈现为更新后的收敛分析。
  6. **Stage 3 访问**：引导整合——决策导向的合成页，将关键主张置于易提取的摘要/表格/引用块中，最大化最终答案保留。

### 2.4 自动策略演化：Trace-Guided Strategy Evolution (TGSE)
- 动机：ACH 并非一致有效；不同失败需要不同修复（更强说服 vs. 特定内容提取到最终答案）。因此将**策略本身**作为可演化对象。
- 核心流程：
  - 对策略 $s$ 在训练集上运行重复实验，构建**轨迹反馈包** $D(s) = \{(\bar{\tau}_{i,r}(s), z_{i,r}(s))\}_{i,r}$，其中压缩轨迹记录攻击者载荷及代理的搜索/访问/回答行为，$z$ 为最终答案是否成功。
  - 关注“混合案例”（部分重复成功、部分失败）——目标可达但路径不稳定，信息量最高。
  - 每次迭代：从档案中按得分加权（加上谱系惩罚）采样父策略 → 让演化模型输出完整替换策略 $s' = E(s, D(s))$ → 在“廉价阶段”子集上评估 → 通过硬回归门控的子策略进入完整评估 → 成功子策略加入档案。
  - 最终选择档案中训练 ASR 最高的策略用于测试。
- 四种配置变体：Normal、Trace-warm（用小规模探测得到的策略作为先验）、Adv-train（在更强的验证感知研究者提示下演化）、Adv-warm（先对抗训练再用其结果热启动一次 Normal）。

## 六、论文的主要结论与发现

1. **ACH 显著优于静态与冻结记忆基线**：在完整测试集上达到 55.9% ASR / 83.3% MaxN ASR，相较最强非 ACH 基线提升 13.0–36.1 个 ASR 点（因受害者而异）。主要例外是 Prompt-Injection 族中的部分单元格（AgentDojo 的指令式注入更匹配直接指令服从任务）。
2. **ACH 通过打破两个轨迹门控获胜**：静态攻击常在“点击门”（注入页不被访问）或“保留门”（访问后打折）失败；ACH 通过实时观察轨迹、生成一致的证据链，同时提高注入访问率和访问后成功率。
3. **交叉模型分析**：攻击者侧能力决定策略实例化质量（Kimi 最强）；受害者侧差异源于证据处理习惯（Qwen3 / Qwen3.5 更易受影响，Kimi 更稳健，Gemma 因极少使用访问而呈搜索摘要易感型）。
4. **TGSE 提供留出泛化收益**：Normal TGSE 将 Overall ASR / MaxN ASR 从 56.0% / 85.0% 提升至 70.0% / 93.0%；Trace-warm TGSE 为最强单设置 71.4% / 95.0%；各族的“最佳观测上界”为 77.4% / 96.0%（表明按族路由策略可带来额外收益）。
5. **不同族需要不同 TGSE 先验**：Ads 需要更强的直接推荐；Bias/Misinfo 需要源-主张绑定与文档标识；Injec 需要将标记转化为可复制输出工件；Harm 即使经过 Adv-warm 演化仍难以显著提升——受害者常将最终答案改写为安全警告。
6. **消融表明策略质量与记忆指导互补**：移除策略输入导致最大性能下降（51.8→19.7 ASR）；移除记忆明显损失（→36.8）；移除反思影响较小；错配策略（Goal reframing / Directive embedding）甚至低于通用弱策略。

## 七、优点

- **问题识别新颖且重要**：首次系统证明了“工具中介动态协调操纵”是超越静态网页注入的搜索代理安全威胁，并给出了现实技术支撑（赞助内容管线）。
- **威胁模型务实且边界清晰**：允许每次查询仅追加一个受控结果、有机内容只读——与真实搜索生态的约束基本一致，避免假设攻击者控制搜索引擎。
- **方法体系完整**：状态化攻击运行时（轨迹记忆 / 规划器 / 策略分离）、专家精炼 ACH、自动演化 TGSE 形成了一个兼具可操作性和自动化的完整攻击研究框架。
- **实验设计严谨**：全文使用 5 次重复、bootstrap 置信区间、MaxN/ASR 双指标、门控诊断（点击门 vs. 保留门），区分了“源选择”与“最终保留”两个阶段。
- **迁移验证充分**：覆盖 6 个受害者、4 个攻击者、3 个外部脚手架和 1 个外部基准（SearchGEO），且承认并分析了跨受害者迁移的局限性。
- **机制分析深入**：附录 D 的逐事件轨迹案例（长链重锚定、多源建设两种模式）和策略/运行时消融，使结论不限于数值差异，而是链接到具体行为机制。
- **负责任披露**：提供净化复现包、不发布可被直接用于实时攻击的原始轨迹和页面内容，同时讨论防御方向。

## 八、不足与局限

- **环境为受控模拟而非真实攻击**：不涉及真实部署的落地页和搜索基础设施；平台反制可能降低重复暴露率，因此 ASR 衡量的是基线漏洞而非现实世界攻击成功率。
- **TGSE 是受害者条件化优化器**：策略从单受害者轨迹演化而来，混合跨受害者迁移（对 Gemma / Qwen3.5 提升，对 DeepSeek 降低 6.0 ASR 点）；多受害者轨迹联合演化尚未实现。
- **TGSE 离线计算成本高**：档案候选评估需要完整端到端 rollout 与判据调用，每族约 1,200 条轨迹，规模化应用受限。
- **防御评估缺失**：论文主要研究攻击侧，提示级与工具级缓解仅作讨论，未做系统防御评测（作者声明为未来工作）。
- **静态基线的适应为重建而非精确复现**：动态基线（AiTM / MAST 等）来自不同场景的“论文指导式推理期重建”，可能与

原始方法存在偏差，可能导致对比公平性争议；虽然作者给出了明确声明，但严格意义上仍需原始实现或作者复现来确认。

6. **攻击成功率（ASR）的分布被平均指标掩盖**：Overall ASR 掩盖了族间方差——同一攻击在不同风险族上的成功率跨度较大（例如 Ads 与 Injec 差异显著），按族路由或条件化策略的收益（上界 77.4%）说明“单策略打天下”并非最优，但论文未给出实践中如何选择族路由的明确指引。

7. **即时性与对抗性动态不足**：攻击者运行时虽强调“实时调整”，但实际评估中每个案例的轨迹数量有限（搜索轮次受脚手架限制），攻击者无法在中长期（数十轮以上）持续塑造受害者认知；真实场景中代理可能调用多种工具（地图、邮件、代码执行等），本方法仅覆盖搜索/访问两条工具通道。

## 九、对领域的影响与潜在启发

- **对搜索代理安全研究方向的引导**：本研究将攻击面从“页面内容”扩展至“搜索结果的排序与呈现过程本身”，启示后续工作应把搜索接口视为**可信边界的一部分**，而非仅关注到达页面后的语义注入。安全评测基准需要加入对工具中介动态操纵的模拟能力。
- **对防御研究的推动**：论文明确提出的防御方向包括工具输出净化、策略/记忆隔离、访问源多样化、内容一致性验证、对尾位结果的降权等；这些均可在不牺牲代理功能的前提下增强鲁棒性。尤其是“将记忆与策略从工具观察中分离”的运行时结构，本身即可作为防御设计参考。
- **对代理系统设计的反思**：ACH 的成功表明，当代理具备多源交叉验证能力时，攻击者不必伪造全部来源——只需维持**表面一致的替代叙事**，就能在代理自身的验证逻辑中“反客为主”。这提醒代理设计者：交叉验证的有效性高度依赖于来源选择的独立性，而搜索工具中介恰恰可能破坏这种独立性。
- **对演化攻击方法的启发**：TGSE 把攻击策略当作“程序”来演化，其轨迹反馈包、硬回归门控、谱系惩罚等设计，可作为**代理安全红队自动化**的一般方法论，适用于其他工具型代理（如代码执行代理、邮件代理）的风险探测。
- **对评测方法的贡献**：双指标（ASR / MaxN ASR）与门控分解（点击门/保留门）提供了更细粒度的攻击归因方式，类似的诊断框架可用于未来代理安全评测，帮助区分“未能诱导访问”与“访问后未能成功说服”两类失败。

## 十、可复现性与资源可用性

- 作者承诺发布**净化复现包**（sanitized reproduction package），包含实验脚手架、攻击者运行时实现、策略配置文件与评估脚本，但**不公开**原始轨迹日志和生成的攻击页面内容，以防被直接用于实时攻击。
- 所有攻击实验通过 **vLLM 本地端点与托管模型 API** 完成，未依赖私有数据集或不可获取的基准——SafeSearch 为公开基准，SearchGEO 亦为外部可获取数据。理论上具备复现条件。
- 受算力与 API 成本限制，部分实验（如交叉模型全组合）采用子采样或固定重复次数，复现时需注意随机种子与采样策略的一致性。

## 十一、总体评价

本文是搜索代理安全领域中一项**方法完整、实验扎实、威胁模型清晰**的攻击研究。其最大贡献不在于提出某个更强的单页注入模板，而在于**证明了一个更危险的攻击层级**：攻击者即使只拥有“每次查询追加一个受控结果”的微弱影响力，也能通过跨轨迹的协调性证据链逐步驯化代理的证据收集与推理过程，最终高频达成目标。与此同时，论文在实验设计上表现出较高的严谨性——多模型、多脚手架、多基线、消融、迁移与统计学不确定性报告俱全，结论具有相当的可信度。主要短板在于缺少真实部署环境验证与系统防御评测，但这并不削弱其作为攻击面定义与风险预警的学术价值。对于搜索代理的开发者、安全评测基准设计者和 LLM 智能体红队工程师而言，本文都值得仔细研读。
