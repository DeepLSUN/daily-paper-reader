## 摘要
我们介绍了Motif 3，一个仅解码器的混合专家语言模型，总参数为3140亿，每个token激活132亿参数。每个稀疏MoE层包含384个路由专家，每个token选择其中8个。这种细粒度的稀疏性在限制计算的同时提供了充足的专家容量。Motif 3基于分组差分潜在注意力（GDLA）构建，该机制将分组差分注意力与多头潜在注意力的压缩键值表示相结合。该架构进一步融入了改进的流形约束超连接、专家特定PolyNorm激活以及多token预测，以提升优化稳定性、专家专业化和推理效率。我们在约12.5万亿个token上预训练了Motif 3，覆盖网页文档、STEM、代码、数学、多语言内容以及领域专业化语料库。专家平衡和数值稳定技术支持了大规模稳定训练，而选择性MXFP8计算与通信、内存高效的融合内核以及窗口感知的上下文并行性，使得训练上下文长度可达256K token。我们的后训练流程结合了通用监督微调、六个通过强化学习训练的专业教师、一个通过监督微调训练的软件工程教师，以及多教师在线策略蒸馏。最终得到的统一模型整合了推理、编码、工具使用、专业工作、长上下文理解、校准性弃权以及指令遵循等方面的互补能力。在广泛的评估套件中，Motif 3展现了与领先开放权重模型相当的竞争力，包括在长时程智能体任务、数学推理、科学知识和幻觉敏感评估上的强劲表现。

## Abstract
We introduce Motif 3, a decoder-only Mixture-of-Experts language model with 314 billion total parameters and 13.2 billion activated per token. Each sparse MoE layer contains 384 routed experts, with eight selected per token. This fine-grained sparsity provides substantial expert capacity while limiting computation. Motif 3 is built around Grouped Differential Latent Attention (GDLA), which integrates grouped differential attention with the compressed key-value representation of Multi-head Latent Attention. The architecture further incorporates modified manifold-constrained hyper-connections, Expert Specific PolyNorm activations, and multi-token prediction to improve optimization stability, expert specialization, and inference efficiency. We pretrain Motif 3 on approximately 12.5 trillion tokens spanning web documents, STEM, code, mathematics, multilingual content, and domain-specialized corpora. Expert-balancing and numerical-stabilization techniques support stable training at scale, while selective MXFP8 computation and communication, memory-efficient fused kernels, and window-aware context parallelism enable training with context lengths up to 256K tokens. Our post-training pipeline combines general supervised fine-tuning, six specialist teachers trained with reinforcement learning, a software-engineering teacher trained with supervised fine-tuning, and Multi-teacher On-Policy Distillation. The resulting unified model consolidates complementary capabilities in reasoning, coding, tool use, professional work, long-context understanding, calibrated abstention, and instruction following. Across a broad evaluation suite, Motif 3 demonstrates competitive performance against leading open weight models, including strong results on long-horizon agentic tasks, mathematical reasoning, scientific knowledge, and hallucination-sensitive evaluation.

## 2. 方法论：核心思想与关键技术细节

### 核心架构

- **解码器专用 MoE 模型**：总参数约 314B，每个 token 激活约 13.2B 参数。模型包含 53 个 Transformer 层（前两层为稠密 FFN，其余 51 层为 MoE FFN）。
- **细粒度稀疏 MoE**：每层 384 个路由专家 + 1 个共享专家，每 token 仅选 top-8 个专家，中间维度 1,280。在不线性增加每 token 计算的前提下扩大专家池容量。
- **混合注意力模式**：每 4 层中 1 层为全因果注意力，3 层为滑动窗口注意力（窗口大小为 128 token）。

### GDLA（Grouped Differential Latent Attention）

- 将 **分组差分注意力（GDA）** 与 **多头潜在注意力（MLA）** 相结合，并用查询依赖的输出门控（类似 Qwen3-Next gated attention）控制信号。
- **潜在表示设计**：
  - 查询侧：低秩下投影 + RMSNorm + 上投影，并分解为内容分量和旋转位置（RoPE）分量。
  - KV 侧：联合下投影得到压缩 KV 潜在（cKV）和解耦旋转键（kR），对 cKV 做 RMSNorm 后用单一投影扩展为 16 个 KV 头，供信号路径和噪声路径共享。
- **分组差分机制**：设 query 头总数 nH，噪声路径头数 nN = nH/(g+1)，信号路径头数 nS = g·nN（g=4），采用非对称的"信号/噪声"头分配，通过共享重复的噪声头来降低计算开销。
- 每 token 预测一个 sigmoid 系数 λt∈(0,1)^nS 用于噪声路径缩放：Dt = HS,t − λt⊙Repeat_g(HN,t)，可抑制共享噪声而不反转/放大信号。
- 输出通过归一化查询潜在表示计算逐元素 sigmoid 门控，控制每个注意力输出通道。

### 修改的流形约束超连接（mHC）

- 用 4 条并行残差流替代单一残差流；Hpre（行向量加权）、Hpost（回写缩放，非负）；Hres 是 Birkhoff 多胞形上的双随机矩阵（Sinkhorn–Knopp 迭代得到），保持凸混合结构和恒等传播特性。
- 后映射缩放因子 st 从 2 退火到 1，避免深层激活异常值累积。

### Expert-Specific PolyNorm

- 以每专家独立学习的多项式归一化激活（三次项加权组合）替代固定 SiLU 门控。
- 系数经 sigmoid 约束在 (0,1)，偏置 clip 到 [−0.5, 0.5]，限制输出增长；归一化在 token 维度上计算，与专家分组无关。研究表明该设计保留更高的门控权重有效秩。

### 多 token 预测（MTP）

- 引入与 DeepSeek-V3 相同的辅助 MTP 层，用于自推测解码，不改变主解码架构。

### 训练系统优化

- 混合并行：EP=8（组内 NVLink），DP-shard=8，DP-replicate=其余；长上下文训练启用 CP=8。
- **MXFP8 低精度计算**：对 MoE 专家权重/激活采用 MXFP8；行/列式权重转换在本地融合核内完成；梯度同步用 BF16 传输、FP32 本地归约。
- **内存优化**：激活重计算 + 路由权重折叠（W(i)(p_i h_i)）+ 融合分片交叉熵（Liger）+ 不卸载专家权重（MXFP8 驻留副本）。
- **Muon 优化器**：对矩阵参数做 Newton–Schulz 正交化，嵌入/输出层用 AdamW；MoE 专家采用并行 Muon（按专家分片无通信正交化）；QK-Clip 防止注意 logit 异常增长（非对称 Q/K 缩放比例）。
- **长上下文策略**：滑动窗口层用窗口感知 Ring Attention（只需前序 rank 尾部 W token，单次 halo 交换），全注意层用 Ulysses（消除文档掩码引起的 rank 负载不均）；并引入注意力工作负载感知的跨 DP 重排。

### 预训练细节

- 约 12.5T token（按 Motif tokenizer 计），含 NVIDIA Nemotron 系列约 70%，其余为自采数据（网页、STEM、代码、数学、韩语/多语言、法律金融、合成 QA）。
- 动态数据配比调度：初始 19 个数据集逐步扩展到 57 个，按线性/余弦插值改变类别比例。
- 训练稳定化：FP32 路由器、sigmoid 路由 + 免辅助损失的专家选择偏置、序列级负载均衡损失、递减路由噪声（余弦退火）、FFN 幅度正则（软惩罚 ReLU(|y|−τ)²）、专家健康监控（分发 min/median、输出权重 min/median、路由/共享比率、输出余弦相似度等）。

### 后训练流水线

- **通用 SFT**：从预训练 checkpoint 重启训练，使用融合数据（含用预实验 SFT 模型识别失败模式后生成的针对性数据）；最大序列长度 256K；cosine 衰减学习率。
- **六位 RL 专家教师**（GRPO，基于 DAPO 变体）：
  - 智能体工具使用教师（terminal + 结果验证器）
  - 专业工作教师（偏好判别的 LLM 裁判）
  - 长上下文推理与校准弃权教师（四档奖励：正确/部分/未作答/错误）
  - 数学教师（math-verify + LLM 裁判）
  - 代码与科学教师（测试用例执行 + 科学库验证 + LLM 裁判）
  - 对话教师（韩语优先，规则条件奖励 + 长度分段整形）
- **软件工程教师**：用合法、独立生成的仓库级补丁做 SFT（不检索金 diff）。
- **多教师在线策略蒸馏（MOPD）**：学生按提示路由到对应教师 token 级 log 概率，用 ICE-POP 截断重要性权重，禁用环境奖励和参考 KL；学习率 5e-6 降至 3e-6。
- 训练中冻结 MTP 和路由参数，保留 SFT 阶段学到的路由配置。

## 6. 主要结论与发现

- 细粒度 MoE（384 专家、top-8）能在大参数规模下兼顾能力与激活效率。
- GDLA 在受控实验中显著优于 GDA 和 MLA，以更少 token 达到相同 loss（达到 loss=3.2 比 MLA 少约 9.2% token）。
- 多个并行稳定化机制（路由噪声、负载均衡偏置、FFN 幅度正则、mHC 退火、PolyNorm）联合解决了路由稀疏模型中常见的专家饥饿、过载、坍缩和激活异常问题。
- 异步 GRPO + 版本约束的重放缓冲 + 截断重要性采样，保证了训练与 rollout 的高效重叠和策略新鲜度。
- MOPD 将七位专门教师的能力整合进单个学生模型，使统一模型在多样化任务上保持强竞争力，尤其在 agentic 工具使用和终端问题求解上表现突出（τ3-Banking 35.3、Terminal-Bench 2.1 得 74.9，为对比前列；ITBench-AA 公开子集 51.5 为列表最高）。
- Motif 3 在不幻觉指标（AA-Omniscience Non-Hallucination 71.6）上表现良好，说明准确性和规避幻觉可以兼得。
- 局限：SciCode（40.6）和 CritPt（6.6）低于最强模型，科学代码与专门科学推理仍有提升空间。

## 7. 优点

- **架构创新系统性强**：GDLA 将差分注意力的降噪机制与 MLA 的 KV 压缩结合，并引入非对称头分配和 token 级系数控制，理论动机清晰、实现细致。
- **系统级优化全面深入**：从 MXFP8 量化、行/列转换、内存优化、Muon 并行到窗口感知 CP 与工作负载重排，覆盖了大规模长上下文训练的主要工程瓶颈，且多为闭环设计（如 QK-Clip 通过 FA4 内核直接输出 max logit）。
- **可解释的稳定性策略**：对路由噪声、mHC 退火、FFN 正则等设计了明确的时间调度与监控指标（如 min/median 比率、输出余弦相似度），故障模式与检测信号一一对应。
- **后训练蒸馏新颖**：将 RL 教师与 SFT 教师统一到 MOPD 框架，用 token 级 log 概率和 ICE-POP 截断保持策略一致性，避免了多模型部署的负担。
- **评估透明度较好**：主评估配置（temperature、top-p、最大长度等）和 benchmark 细节（如 τ2 的用户模拟器、SWE-bench 的智能体设置）有具体描述。

## 8. 不足与局限

- **算力细节缺失**：未披露 GPU 数量、训练时长、能耗等关键资源指标，难以评估其效率和可复现性。
- **部分对比不对齐**：ITBench-AA 仅评估公开子集，却与可能使用完整测试集的分数对比；对比模型分数来自各自 leaderboard，harness 和 prompt 差异可能引入偏差。
- **数据与训练细节不完整**：预训练语料的构成比例、去重/过滤质量指标、长上下文数据重建方式等没有详细说明；RL 数据过滤的"成功率"估计不透明。
- **实验规模与可复现性**：消融实验仅在约 10B 参数规模模型上验证，对 314B 规模的结论转移性存在不确定性；未报告多次运行的标准差。
- **模式局限**：Motif 3 为纯文本模型，无法处理视觉输入；长上下文超越 256K 的有效利用也尚未验证。
- **应用局限**：在科学编码（SciCode）和前沿科学推理（CritPt）上与最强模型仍有明显差距；现实世界中的任务多样性、语言覆盖、长期部署稳定性仍待探索。
- **蒸馏引入的潜在能力折扣**：MOPD 保证了 token 级对齐和领域覆盖，但在部分能力（如 CritPt 等专门推理）上可能不如单一专用教师，需更多场景验证其能力保持性。
