## 摘要
测试时扩展通过生成并聚合多个候选答案来提升大语言模型的推理能力，然而许多流程使用固定的查询预算，在简单和困难的提示上花费相同的计算量。这些固定预算也难以检查，因为它们没有解释为什么某个提示会获得特定数量的样本。我们提出了一种带有轻量级模糊控制器的自适应测试时扩展方法，该控制器将可解释信号（包括估计的提示复杂度和模型置信度）映射到每个查询的采样预算。控制器为较简单或置信度较高的提示分配较少的样本，而为较困难或确定性较低的提示分配更多的样本，从而使推理时的计算量可检查而非固定或不透明。我们在公平对齐协议下进行评估，使用匹配的解码设置和受控的答案选择，并在问答和数学推理任务上与最佳N选择、计算感知缩放和基于自置信度的基线进行比较。跨模型和数据集，自适应模糊控制在多个标准基线上有所改进，并且在与选择器匹配的全预算控制相比时仍保持接近，同时减少了平均样本数。这些发现表明，可解释的自适应采样是大语言模型中更高效的测试时推理的一个实用方向。

## Abstract
Test-time scaling improves LLM reasoning by generating and aggregating multiple candidate answers, yet many pipelines use fixed per-query budgets that spend the same compute on easy and difficult prompts. These fixed budgets are also difficult to inspect because they do not explain why a given prompt receives a particular number of samples. We propose adaptive} test-time scaling with a lightweight fuzzy controller that maps interpretable signals, including estimated prompt complexity and model confidence, to a per-query sampling budget. The controller assigns fewer samples to easier or more confident prompts and more samples to harder or less certain prompts, making inference-time compute inspectable rather than fixed or opaque. We evaluate under a fair-alignment protocol with matched decoding settings and controlled answer selection, and compare against best-of-$N$, compute-aware scaling, and self-certainty-based baselines on question-answering and mathematical reasoning tasks. Across models and datasets, adaptive fuzzy control improves over several standard baselines and remains close to a selector-matched full-budget control while reducing the average number of samples. These findings suggest that interpretable adaptive sampling is a practical direction for more efficient test-time reasoning in large language models.

## 2. 论文提出的方法论：核心思想、关键技术细节与流程

**核心思想：**

- 构建一个**两阶段分层模糊控制器**，将多个可解释信号映射到连续采样比例 `s ∈ [0,1]`，再转换为整数采样预算 `N(x)`。
- 控制器是**显式、规则可审计**的手工设计系统，非端到端黑盒策略。

**关键信号（共9个，均归一化到 [0,1]）：**

| 信号 | 含义 |
|---|---|
| `c` | 提示复杂度（表面复杂度 + NLP复杂度加权组合） |
| `γ` | 模型置信度（草稿答案 token 概率的几何平均） |
| `η` | 熵（生成时 token 分布的弥散程度） |
| `τ` | 提示类型（事实型 vs 开放型） |
| `λ` | 预期答案长度 |
| `π` | 历史缓存（相似提示的历史表现） |
| `a_sem`、`a_ling`、`a_rea` | 语义歧义、语言复杂度、推理深度 |

**控制器结构：**
- **第一阶段**：使用两个最强信号（复杂度 `c` + 置信度 `γ`），通过三角/梯形隶属度函数映射到"低/中/高"模糊区域，激活如"非常低/低/中/高/非常高"的计算标签，产生粗糙预算决策。
- **第二阶段**：用熵、预期答案长度、提示类型、历史表现、语义歧义等做精细化调整，以 Type-2 模糊区间表示；多个信号一致时输出区间窄，冲突时区间宽。
- **去模糊化**：按激活强度加权平均区间中心得到 `s`；不确定性 `u` 由活跃区间平均宽度计算。
- **最终预算映射**：`s' = clamp(s + αu)`，`N(x) = max(1, round(1 + s'(Nmax - 1)))`；若提示明显困难（`c > 0.6`），施加下限 `N(x) ≥ min(6, Nmax)`。

**答案选择：**
- 每个候选被赋予自置信度分数（基于 token 概率），按该分数排序，提取最终答案字符串后执行 Borda 聚合。

**公平对齐协议：**
- 主实验中所有方法使用相同的解码设置（温度 1.0, top-p = 0.95, 最大输出 256 tokens），禁用草稿步骤，控制器仅改变采样数——将预算策略与解码/选择效应分离。

## 6. 主要结论与发现

1. **自适应采样能有效降低平均样本数**：在 MATH 上对 Phi-3-mini 减少 10.8%、对 Qwen2.5-1.5B 减少 14.5% 的采样，准确率仅小幅下降（分别为 -0.007 和 -0.018）。
2. **在 GSM8K 上可保持准确率甚至略有提升**：Qwen2.5-1.5B 在 GSM8K 上以 3.9% 的采样减少实现了 +0.005 的准确率提升。
3. **控制器行为符合预期机制**：MATH 等更难任务中更多提示被分配低预算，GSM8K 中控制器更保守（接近全预算）。
4. **固定小预算不够**：固定 N=1/2/3/5 均明显劣于自适应方案，说明候选多样性对最终选择很关键。
5. **选择器是独立瓶颈**：Oracle 审计显示 Qwen2.5-1.5B 在候选池中已有正确解时选择器漏选率仍高达 24-25%，说明仅靠预算分配无法修复选择器缺陷。
6. **累计算力节省可观**：Phi-3-medium 在高预算上限（Nmax=32）下仍可节省约 27.9% 的样本。

## 7. 优点

- **可解释性设计**：模糊控制器的规则、信号值和输出均可按提示词检查，避免了"另一个黑盒"问题。
