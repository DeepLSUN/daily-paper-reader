## 摘要
差分隐私零阶优化(DP-ZO)仅使用前向评估即可实现大规模语言模型的内存高效私有微调。现有的基于聚合的DP-ZO方法以固定尺度重建模型更新，忽略了在整个训练过程中有用信号的强度会变化。因此，噪声主导的更新可能获得过大的权重并降低模型效用。为了解决这个问题，我们提出了SAGE，一种噪声感知收缩方法，根据估计的信号质量自适应地衰减私有化估计。SAGE从观测到的二阶矩中减去已知的高斯噪声方差来估计底层信号能量，通过时间跟踪稳定该估计，并将其当前的信号噪声比与预热参考进行比较，以导出有界收缩因子。作为纯后处理，SAGE既不需要额外的隐私预算，也不需要模型查询，并且仅引入恒定的额外状态。我们的理论分析表明，收缩比线性下降项更快地减少二次更新风险项，在限制噪声主导更新影响的同时保留了有用的下降。在RoBERTa-large、OPT-1.3B和OPT-6.7B上的实验表明，在相同的隐私预算下，SAGE在大多数设置中优于现有基线，同时保持了DP-ZO的前向内存效率。

## Abstract
Differentially private zeroth-order optimization (DP-ZO) enables memory-efficient private fine-tuning of large language models using only forward evaluations. Existing aggregation-based DP-ZO methods reconstruct model updates at a fixed scale, ignoring that the strength of useful signals varies throughout training. Consequently, noise-dominated updates may receive excessive weight and degrade model utility. To address this issue, we propose SAGE, a noise-aware shrinkage method that adaptively attenuates privatized estimates according to their estimated signal quality. SAGE subtracts the known Gaussian noise variance from the observed second moment to estimate the underlying signal energy, stabilizes this estimate through temporal tracking, and compares its current signal-to-noise level with a warm-up reference to derive a bounded shrinkage factor. As pure post-processing, SAGE requires neither additional privacy budget nor model queries and introduces only constant additional state. Our theoretical analysis shows that shrinkage reduces the quadratic update-risk term faster than the linear descent term, preserving useful descent while limiting the influence of noise-dominated updates. Experiments on RoBERTa-large, OPT-1.3B, and OPT-6.7B demonstrate that SAGE outperforms existing baselines in most settings under the same privacy budgets while preserving the forward-only memory efficiency of DP-ZO.

- **研究背景与动机**：微调大规模语言模型（LLM）在特定任务中已成为标准实践，但传统基于反向传播的一阶优化方法（如 Adam、AdamW）在内存开销上随着模型规模增长而急剧膨胀。MeZO 引入零阶优化（ZO），仅通过两次前向评估即可估计更新方向，将训练内存降低到接近推理水平。在此基础上，差分隐私零阶优化（DP-ZO）通过截断（clipping）和加噪实现隐私保护，兼顾内存效率与隐私安全。DP-AggZO 进一步通过聚合 K 个方向的梯度标量估计来降低截断误差，提升精度-隐私权衡。
- **核心问题**：现有基于聚合的 DP-ZO 方法（尤其是 DP-AggZO）以固定尺度重建模型更新，忽略了一个重要事实——训练过程中底层信号强度是**高度非平稳**的。初始阶段梯度信号较强，后期信号衰减，而高斯隐私噪声的方差由隐私机制固定（而非由当前信号强度决定），导致有效信噪比（SNR）在训练过程中剧烈变化。当信号变弱时，噪声在更新中占比增大，形成噪声主导的更新，从而增大更新风险（update risk），损害模型效用。论文以图 1 的 SNLI 微调实验为例，指出中位数噪声与信号能量比高达 7.8，且可靠性（reliability）从 warmup 结束时的 0.213 下降到后期的约 0.100。
- **整体含义**：固定尺度更新本质上没有考虑信号质量的时间变化，导致相同名义尺度在训练不同阶段对应的信噪比失配。论文提出 **SAGE（Noise-Aware Shrinkage）** 方法，通过纯后处理方式，根据估计的信号质量自适应地衰减（收缩）隐私化梯度标量估计向量——信号越不可靠，收缩越强；信号越可靠，收缩越弱，从而在保留有用下降方向的同时抑制噪声主导更新对优化过程的负面影响。该方法在隐私预算、查询次数和训练设置完全相同的条件下，一致地提升了 DP-ZO 微调的效用。

## 2. 方法论

### 2.1 核心思想

SAGE 的核心观察在于：高斯隐私噪声向发布的估计向量中引入了一个**可预测的噪声地板（noise floor）**。给定发布向量

\[
\tilde{s}_t = u_t + \xi_t, \quad \xi_t \sim \mathcal{N}(0, \tau_t^2 I_K)
\]

观测能量 \(\|\tilde{s}_t\|_2^2/K\) 的条件期望为：

\[
\mathbb{E}_\xi[r_t^2 | u_t] = \frac{\|u_t\|_2^2}{K} + \tau_t^2
\]

即观测能量 = 信号能量 + 已知噪声方差。SAGE 由此出发，构建一条从"观测能量"到"信号质量"再到"收缩因子"的推理链：

1. **噪声地板校正**：从观测能量中减去已知高斯噪声方差，得到信号能量的无偏（下界截断）估计。
2. **时间跟踪**：用指数移动平均（EMA）平滑单步估计的波动，捕捉信号能量的时间演化趋势。
3. **Warm-up 参考校准**：用训练前期的统计量作为参考，度量当前可靠性的相对变化，避免跨任务、跨隐私设置下绝对值的不可比性。
4. **有界收缩**：将当前可靠性相对参考的比值映射到 \([m_{\min}, 1]\) 区间内的收缩因子，对发布向量进行缩放。

### 2.2 关键技术细节

- **噪声地板校正（Noise-Floor Correction）**：计算去偏估计 \(\hat{q}_t = \max\{\|\tilde{s}_t\|_2^2/K - \tau_t^2, \rho\}\)，其中 \(\rho > 0\) 避免在噪声水平附近产生退化估计。相比直接使用观测能量，这一校正消除了隐私噪声带来的系统偏差，避免高估信号强度。
- **EMA 时间跟踪（EMA Tracking）**：\(v_t = (1 - \beta)v_{t-1} + \beta \hat{q}_t\)，采用 \(\beta = 0.03\)。由于单次发布的估计波动较大，EMA 能稳定可靠性估计。值得注意的是，该状态仅为标量，不引入参数量级的额外内存。
- **Warm-up 参考校准（Warm-up Anchored Reference）**：前 \(W = 50\) 步不应用收缩，仅收集 \(v_{\text{ref}}\) 和 \(\tau_{\text{ref}}^2\) 作为参考。这样避免了绝对信号阈值的依赖，使收缩因子适应不同任务和隐私设置。
- **可靠性分数**：\(\phi_t = v_t / (v_t + \lambda \tau_t^2)\)，即以信噪比整流形式（saturating form）度量当前信号可靠性，\(\lambda = 1\) 控制噪声水平的贡献。参考可靠性同理：\(\phi_{\text{ref}} = v_{\text{ref}} / (v_{\text{ref}} + \lambda \tau_{\text{ref}}^2)\)。
- **有界收缩因子**：\(m_t = \text{clip}(\phi_t / \phi_{\text{ref}}, m_{\min}, 1)\)，\(m_{\min} = 0.5\)。上界 1 确保 SAGE 从不放大估计，下界防止过度衰减。
- **纯后处理**：\(m_t\) 仅依赖已发布的噪声化输出和机制参数，因此 SAGE 是纯后处理，不增加隐私预算，不增加模型查询次数。

### 2.3 优化理论解释

论文给出了一步损失变化的上界分析。在标准平滑性假设下（忽略高阶有限差分误差），期望的单步损失变化满足：

\[
\mathbb{E}[\Delta L_t] \lesssim -\eta m_t S_t + \frac{L \eta^2 m_t^2}{2}(R_K S_t + N_K)
\]

其中第一项为**线性下降项**（随收缩因子 \(m_t\) 线性减小），第二项为**二次更新风险项**（随 \(m_t\) 平方减小）。由这一不对称性，收缩低可靠性估计时，噪声引起的更新风险被抑制的速度快于有用信号下降被衰减的速度，因此可以在不严重损失下降方向的前提下有效降低噪声的影响。忽略 \(m_t \le 1\) 约束的最小化给出 oracle 最优尺度 \(m_t^\star = S_t / [L\eta(R_K S_t + N_K)]\)，说明最优尺度应随估计可靠性单调递增——这正是 SAGE 遵循的原则。

### 2.4 算法整体流程（Alg. 1 文字说明）

1. 发布经拉普拉斯机制处理的数据集大小估计，计算采样率。
2. 每步对当前批次采样 K 个随机方向，构造 K 维梯度标量估计向量，联合截断并加高斯噪声，得到 \(\tilde{s}_t\)。
3. 计算 \(\tau_t^2 = (\sigma C / \tilde{m})^2\)。
4. 去偏信号能量 \(\hat{q}_t\)。
5. 若 \(t \le W\)（即 warmup 阶段）：收集 \(\hat{q}_t\) 和 \(\tau_t^2\) 到缓冲区，\(m_t = 1\)；到 \(t = W\) 时计算参考值 \(v_{\text{ref}}\)、\(\tau_{\text{ref}}^2\) 和 \(\phi_{\text{ref}}\)。
6. 若 \(t > W\)：更新 EMA \(v_t\)，计算 \(\phi_t\) 和收缩因子 \(m_t = \text{clip}(\phi_t / \phi_{\text{ref}}, m_{\min}, 1)\)。
7. 应用收缩 \(\bar{s}_t = m_t \tilde{s}_t\)，重建参数更新 \(\theta_{t+1} \leftarrow \theta_t - \frac{\eta}{K} \sum_{k=1}^{K} \bar{s}_{t,k} z_{t,k}\)。

## 8. 不足与局限性

- **依赖聚合式 ZO 框架**：SAGE 的核心操作是对 K 维梯度标量估计向量进行收缩，因此它仅适用于聚合方向（K>1）的 DP-ZO 方法（如 DP-AggZO）。对于单方向 DPZero，或基于一阶梯度的 DP-SGD/DP-AdamW，该方法无法直接应用，适用范围受限。
- **理论分析的简化假设**：论文的优化解释基于标准的 L-光滑性假设，并且忽略了有限差分（ZO）梯度估计本身带来的高阶误差。实际中，ZO 估计的方差和偏差与扰动尺度 μ 有关，而 SAGE 的收缩因子推导并未显式建模 μ 的影响，因此理论界与真实训练动态之间仍存在一定差距。
- **噪声方差时不变假设**：SAGE 假设每个发布步骤的噪声方差 τ_t² 是已知且固定的（由固定截断范数 C 和隐私噪声刻度 σ 决定）。如果未来方法允许截断范数随训练动态变化（例如自适应 clipping），则 τ_t² 将不再固定，SAGE 的噪声地板校正公式需要相应修正。
- **实验稳健性证据不足**：诊断图（图 3）和部分关键结果未报告多次重复运行的均值与方差，也未提供统计显著性检验（如 t 检验或置信区间）。在 DP 训练的随机性下，单次运行的性能可能存在波动，这削弱了结论的统计可信度。
- **任务与模型覆盖面有限**：实验涉及分类、NLI 和抽取式 QA，但未覆盖生成式任务（如对话、摘要、翻译）或更大的模型（如 30B/70B）。虽然 OPT-6.7B 具有一定代表性，但 SAGE 在更大规模、更复杂任务上的有效性仍属未知。
- **收缩因子的启发式设计**：m_t 的形式（比率裁剪）和超参数（m_min=0.5, λ=1）虽然经过了消融和敏感性分析，仍带有较强的手工设计痕迹。为何选择“比率”而非“差值”、为何 m_min=0.5 而非 0.3，论文未给出理论最优性推导，更多是经验选择。

## 9. 整体评价与未来方向

**总体评价**：SAGE 是一个简洁、巧妙且实用的改进。它敏锐地捕捉到 DP 聚合 ZO 优化中信号非平稳性与固定噪声地板之间的矛盾，并利用纯后处理的收缩机制加以缓解。论文的实验设计较为规范，匹配对比和消融研究验证了各组件的必要性。尽管存在适用范围和理论简化方面的局限，SAGE 仍然为 DP 微调的低内存、高隐私场景提供了极具吸引力的工程解决方案。

**未来研究方向**：
1. **自适应超参数**：研究如何基于在线信噪比估计动态调整 m_min 和 λ，而不是使用固定值。
2. **扩展到一阶方法**：将“噪声地板校正 + 收缩”思想迁移到 DP-SGD 或 DP-Adam 的梯度更新中，观察其对隐私-效用权衡的影响。
3. **更严格的理论分析**：在有限差分误差存在的情况下推导收缩因子的最优闭式解，并将批次随机性与隐私噪声同时纳入收敛性分析。
4. **更大规模验证**：在生成式 LLM（如 GPT 系列）和更大参数规模上测试 SAGE，并报告多次运行的统计分布。
5. **与差分隐私其他技术的结合**：例如与隐私放大、拜占庭鲁棒性等方法联合使用，扩展其应用边界。

**一句话总结**：SAGE 通过对隐私化聚合梯度标量估计进行“噪声意识收缩”，在几乎零额外开销的前提下显著改善了 DP-ZO 微调的精度-隐私权衡，是该领域一个值得关注的实用型进展。
