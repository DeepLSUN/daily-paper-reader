## 摘要
混合注意力大语言模型将全注意力与循环线性注意力相结合，以降低长上下文推理成本，但其自回归解码仍受内存带宽限制。树投机解码提供了一种有吸引力的加速路径，但现有的树投机系统是针对全注意力模型的键值缓存设计的。在混合模型上，它们逐分支遍历循环层，并为每个候选节点物化完整状态，导致验证延迟和瞬时内存随树大小和批大小扩展性差。我们提出了Bole，一种内核-运行时协同设计，实现了面向混合注意力大语言模型的高效树投机。Bole将线性注意力循环转化为树结构的闭式形式，并通过资源高效的GPU内核实现，并行验证所有候选节点，将线性注意力树验证加速3.4–7.7倍。它将投机状态更新无损编码为词元级因子，并仅重建采样后选中的状态，将瞬时状态内存减少82–99倍，释放GPU容量用于KV缓存。其集成到广泛部署的生产级LLM服务引擎SGLang中，将高效状态管理与针对完整混合前向计算的批级验证预算相结合。在四个模型、两个GPU平台和多种数据集上，Bole相比自回归解码实现了高达4.72倍离线解码吞吐量，相比最强的树投机基线实现了高达2.03倍。在在线智能体工作负载下，相比最强树投机基线，TTFT和TPOT分别降低高达67.6%和49.9%。

## Abstract
Hybrid-attention large language models combine full attention with recurrent linear attention to reduce long-context inference costs, yet their autoregressive decoding remains memory-bound. Tree speculative decoding offers an attractive acceleration path, but existing tree-speculation systems are designed around the key--value caches of full-attention models. On hybrid models, they traverse recurrent layers branch by branch and materialize a full state for every proposal node, causing verification latency and transient memory to scale poorly with tree and batch sizes. We present Bole, a kernel--runtime co-design that enables efficient tree speculation for hybrid-attention LLMs. Bole transforms the linear-attention recurrence into a tree-structured closed form and realizes it with a resource-efficient GPU kernel, verifying all proposal nodes in parallel and accelerating linear-attention tree verification by 3.4--7.7$\times$. It losslessly encodes speculative state updates as token-level factors and reconstructs only the state selected after sampling, reducing transient state memory by 82--99$\times$ and freeing GPU capacity for KV caches. Its integration into SGLang, a widely deployed production LLM serving engine, couples efficient state management with a batch-wide verification budget calibrated to the complete hybrid forward. Across four models, two GPU platforms, and diverse datasets, Bole delivers up to $4.72\times$ the offline decode throughput of autoregressive decoding and up to $2.03\times$ that of the strongest tree-speculative baseline. Under online agent workloads, it reduces TTFT and TPOT by up to $67.6%$ and $49.9%$, respectively, over the strongest tree-speculative baseline.

- **混合注意力大语言模型（Hybrid-Attention LLMs）**：以 Qwen3.5、Kimi Linear 为代表，将**全注意力（full attention）**层与**循环线性注意力（recurrent linear attention）**层交错组合，以固定大小状态压缩长上下文，降低长上下文推理成本。

- **树投机解码（Tree Speculative Decoding）**：通过轻量级 drafter（如 MTP、EAGLE）生成候选 token 树，目标模型一次前向验证整棵树，可显著加速解码。

  - **L1**：验证延迟随树规模快速增长（线性层时间占比从 4% 升至 27%）；
  - **L2**：瞬时状态内存爆炸（8 个 32 节点请求即消耗 36 GiB）；
  - **L3**：硬件相关的验证成本拐点使额外 token 并非“接近免费”。

### 论文含义

Bole 通过**内核-运行时协同设计（kernel–runtime co-design）**，实现面向混合注意力 LLM 的高效树投机解码，在算法、GPU 内核和服务运行时三个层面系统性地解决了上述瓶颈。

## 2. 方法论

### 核心思想

将线性注意力的**串行递归**转化为**树结构的闭式解（closed-form）**，实现所有候选节点的并行验证；同时将投机状态更新**无损编码为 token 级因子**，只重建采样后被选中的状态。

### 关键技术细节

#### （1）并行树验证的闭式解（Parallel Tree Solver）

- **定理 1**：顺序树执行门控 Delta 规则等价于闭式表达式  
  `O = D_P Q S_pre + C(I + G)^{-1} D_β (V - D_P K S_pre)`，该表达式**代数精确等价**，无需逐节点递归或逐节点状态物化。
- 三个关键引理：
  - **Lemma 1（路径因子化状态）**：每个节点的状态可分解为共享预树状态与祖先路径上的秩一修正之和；
  - **Lemma 2（祖先掩码线性系统）**：修正向量 U 满足 `(I + G)U = R`，G 是严格下三角矩阵（仅祖先节点之间有非零项）；
  - **Lemma 3（深度有界幂零性）**：`G^{d+1} = 0`，因此 `(I + G)^{-1} = Σ_{m=0}^{d} (-G)^m`，为有限多项式，可精确计算。

#### （2）值分块并行验证 GPU 内核（Value-Tiled Parallel Verification Kernel）

- 将值维度 `d_v` 划分为多个 tile，每个 tile 分配一个 CTA（CUDA 线程块）；
- 因子 `G`、`C`（与值通道无关）由单个 producer 构造一次，供所有 tile CTA 复用；
- CTA 内执行**片上有限 Neumann 展开**：`Z^{(m+1)} = -GZ^{(m)}`，`U += Z^{(m+1)}`，共 d 轮，全程不写回 HBM；
- 通过 `(b_k, b_v)` 二维资源 tiling 平衡片上工作集、CTA 并发度与因子复用效率。

#### （3）融合树验证流水线（Fused Tree Verification Pipeline）

- **Round 级拓扑预处理**：parent map、祖先掩码、最大深度仅依赖树结构，每轮一次、跨层复用；
- **Stage 1**：树并行卷积与门控准备（沿父指针回溯而非线性邻接）；
- **Stage 2**：因子构造（G、C 在 layer-local 临时空间）；
- **Stage 3**：值分块求解与读出（R、有限 Neumann 递归、O 构造）。

#### （4）因子化投机状态生命周期（Factorized State Lifecycle）

- 每个请求每层仅保留**一个不可变的规范状态（canonical state）**；
- 候选分支仅存储 token 级因子 `(P, K, U)`，空间复杂度  
  `Θ(H d_k d_v) [规范状态] + Θ(T H (d_k + d_v + 1)) [树因子]`；
- 采样后，仅被接受路径通过一次批量矩阵乘法重建状态：  
  `S_new = P_a S_pre + (D_a K_a)^T U_a`；
- 被拒绝分支**无需回滚、不占状态缓存槽**。

#### （5）硬件感知的批级验证预算（Hardware-Aware Batch-Shared Verification Budget）

- 离线校准：对每个执行配置（模型、GPU、批大小、KV 长度桶、树模板），扫描总验证 token 数 N，选取满足 `T_ver(N|c) ≤ (1+ε) T_dec(c)` 的最大 N 作为批级容量；
- 在线分配：以每条候选路径的**累积草稿概率**（`ρ(v) = Π draft-prob`）作为分数，在跨请求全局 top-k 选择中分配预算，因概率单调性自动保持每棵树的**前缀连通性**。

#### （6）生产引擎集成（SGLang 集成）

- 实现 CUDA Graph 原生的**扁平不规则森林（flat-ragged forest）**打包执行；
- 跨层统一状态提交（设备端批量提交）；
- 全过程 GPU 常驻（选择 → 物化 → 执行 → 采样 → 提交），消除主机同步气泡。

## 6. 主要结论与发现

1. **并行验证显著加速**：线性注意力树验证加速 **3.4–7.7×**（批大小 1→16 时加速比增大）；

3. **端到端吞吐提升**：
   - 相比 SGLang-AR：几何平均 **2.74×**，峰值达 **4.72×**（GB10）；
   - 相比最强树投机基线（AdaServe）：几何平均 **1.26×**，峰值 **2.03×**；
4. **在线延迟改善**：相比 AdaServe，TTFT 和 TPOT 分别最多降低 **67.6%** 和 **49.9%**；相比 SGLang-AR，分别最多降低 64.3% 和 67.6%；
5. **前缀缓存命中率**：Bole 在 A100/GB10 上达到 90.8%/92.6%，接近 SGLang-AR 的 89.8%/93.3%，显著高于 SGLang-Tree 的 69.7%/58.3% 和 AdaServe 的 69.3%/59.8%；
6. **硬件感知预算有效**：最优总 token 数在 A100 为 128、GB10 为 256，单一固定预算跨平台次优，验证了校准设计的必要性；
7. **消融验证三项设计均有效**：预算 +5.3%/10.7%（A100/GB10）、并行求解器累积达 1.21×/1.30×、因子化状态累积达 1.59×/2.23×。

## 7. 优点

- **算法创新性**：将门控 Delta 递归的树验证转化为精确闭式解，数学推导严密（三引理 + 定理），且**无损等价**于顺序执行；
- **系统工程完整性**：从算法、GPU 内核到 SGLang 运行时全栈一体设计，涵盖 CUDA Graphs、连续批处理、跨层统一提交等生产级关注点；
- **资源效率突出**：因子化状态将候选分支存储从 `Θ(H d_s²)` 降为 `Θ(2H d_s)`，对状态维度扩展友好；
- **实验严谨性**：消融实验清晰分离各设计贡献；预算敏感性验证了“硬件相关容量”的论点；内核级 profiling（nsys/ncu）提供了机制层面的证据；
- **可移植性**：内核用 Python + Triton 实现，论文声称可便捷移植到其他推理引擎；
- **在线工作负载价值明确**：在真实智能体轨迹上验证了 TTFT/TPOT 与缓存命中率的双重改善。
