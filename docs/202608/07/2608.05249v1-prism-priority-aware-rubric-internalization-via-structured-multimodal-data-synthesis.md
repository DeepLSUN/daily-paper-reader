## 摘要
现实世界的多模态指令通常包含多个重要性不等的要求，然而大多数多模态训练数据仍然将指令跟随简化为回答一个自包含的问题。我们通过**规则理解**来研究这一差距，该概念将模型不是作为根据规则衡量的生成器，而是作为遵循规则的**执行器**：给定一张图像和一个带类型化、优先级排序的规则集，模型必须在产生整体判断之前验证每条规则。为支持这一设定，我们提出了**PRISM**，一个四阶段数据合成框架，生成人物-任务配对、前缀引导的规则集、质量过滤的规则以及结构化验证轨迹。我们还引入了**PRISM-Eval**，其宽松和严格指标使用确定性匹配与固定标签，因此无需推理时的评判模型。仅用10K个合成样本，PRISM就将Qwen3-VL-4B在PRISM-Eval上的严格准确率从9.5%提升至30.1%，同时保持在一般基准上的平均性能，且提升可迁移到另外四个开源MLLM，涵盖密集和MoE架构，表明结构化规则监督是通往多规则、优先级感知多模态指令跟随的可扩展路径。

## Abstract
Real-world multimodal instructions often bundle multiple requirements with unequal importance, yet most multimodal training data still reduce instruction following to answering one self-contained question. We study this gap through \textbf{rubric comprehension}, which casts the model not as a generator measured against rubrics but as an \textbf{executor} that follows them: given an image and a typed, prioritized rubric, the model must verify each rule before producing an overall judgment. To support this setting, we propose \textbf{PRISM}, a four-stage data synthesis framework that produces persona--task pairs, prefix-guided rule sets, quality-filtered rubrics, and structured verification traces. We further introduce \textbf{PRISM-Eval}, whose Loose and Strict metrics use deterministic matching against fixed labels and therefore require no inference-time judge model. With only 10K synthesized samples, PRISM lifts Qwen3-VL-4B from 9.5\% to 30.1\% Strict accuracy on PRISM-Eval while preserving average performance on general benchmarks, and the gains transfer to four additional open-source MLLMs across dense and MoE architectures, suggesting that structured rubric supervision is a scalable path toward multi-rule, priority-aware multimodal instruction following.

- **现实与训练数据的严重脱节**：真实世界的多模态指令通常包含**多条重要性不等、类型不同的要求**（例如医疗场景中同时要求"描述病灶""确认检测时间""输出格式遵循特定模板"，且各要求优先级不同）。然而，绝大多数现有多模态训练数据将指令跟随简化为"回答一个自包含问题"，不包含**多规则优先级感知**的训练信号。
- **研究视角的转变**：论文提出"**规则理解（Rubric Comprehension）**"概念，将模型的角色从"根据规则被评判的生成器"重新定位为"遵循规则的执行器（Executor）"。在该设定下，给定一张图像和一组**类型化、带优先级排序的规则集**，模型必须**逐条验证每条规则**，最终才能产生整体判断。这远比传统的单轮问答更具挑战性，也更贴近真实部署场景。

### 2. 方法论：PRISM 四阶段数据合成框架

PRISM 是一个自动化的多模态数据合成流水线，通过四个阶段将原始图像和人物信息转化为结构化、带优先级标签的训练数据：

| 阶段 | 名称 | 核心功能 | 关键细节 |
|---|---|---|---|
| **第一阶段** | **人物-任务配对生成**（Persona–Task Pair Generation） | 生成符合图像内容的"参与者角色+任务描述" | 为每张图像合成多名虚拟用户角色（persona），并为其分配与图像内容相关的具体任务，确保指令的自然性和多样性 |
| **第二阶段** | **前缀引导的规则集生成**（Prefix-Guided Rule Set Generation） | 生成带优先级排序的规则集合 | 从第一阶段的输出中提取"前缀提示"（即上下文约束），引导 LLM/MLLM 生成**分层规则集（hierarchical rubric）**，每条规则包含类型标签（如格式型、内容型、安全型）和明确的优先级序号 |
| **第三阶段** | **质量过滤**（Quality Filtering） | 过滤低质量/信息量不足的规则 | 设计多种过滤标准（如规则与图像相关性、文本完整性、规则间的重要性区分度），只保留**区分度高、难度适中、优先级清晰**的规则集，防止退化样本 |
| **第四阶段** | **结构化验证轨迹生成**（Structured Verification Trace Generation） | 生成模型的"逐条规则验证过程" | 针对每条规则生成模型"是否通过验证、验证依据、最终判断"三步式轨迹；这一步是训练的核心监督信号，教导模型在推理时主动先验证各规则再下结论 |

- **训练监督信号**：上述四个阶段合成了 **三元组数据**：`(输入图像, 带优先级/类型的规则集, 结构化验证轨迹)`。模型通过**有监督微调（SFT）** 学习从"看到规则集"到"执行规则验证再输出整体判断"的推理链路。
- **推断时的评估方法——PRISM-Eval**：配套引入一个评估基准，使用**固定标签和确定性匹配**（而非 LLM-as-a-judge），输出两个指标：
  - **宽松准确率（Loose Accuracy）**：宽松匹配。
  - **严格准确率（Strict Accuracy）**：要求输出内容与所有固定标签严格匹配，更难获得高分。
  - 这种设计避免了推理时对评测模型的依赖，使评估完全**可复现、无偏、低成本**。
