## 摘要
监督微调（SFT）和强化学习（RL）在增强大语言模型（LLMs）的多任务推理方面表现出截然不同的行为。我们的初步实验揭示了一个现象：在多阶段训练下，SFT遭受严重的任务冲突，而RL能够在不同任务间实现稳定共存。在实证上，我们从参数层面追溯到这一现象，观察到RL跨任务产生稀疏且近似正交的更新。我们通过分析多任务梯度干扰，为这一机制提供了理论解释。我们的结果揭示了一个区别：SFT中的干扰受范数限制，随绝对梯度幅值缩放；而RL中的干扰受方差限制，由优势归一化和在策略优化引起的梯度方差界定。这一小方差界导致跨任务的优化方向近似正交。基于这一洞察，我们提出了Parallel-RL，一种解耦多任务训练的新范式，显著提高了效率和灵活性。

## Abstract
Supervised Fine-Tuning (SFT) and Reinforcement Learning (RL) exhibit fundamentally different behaviors in enhancing multi-task reasoning for large language models (LLMs). Our preliminary experiments revealed a phenomenon: SFT suffers from severe task conflicts under multi-stage training, whereas RL enables stable coexistence across diverse tasks. Empirically, we trace this to the parameter level, observing that RL induces sparse and approximately orthogonal updates across tasks. We provide a theoretical explanation for this mechanism by analyzing multi-task gradient interference. Our results reveal a distinction: interference in SFT is norm-limited, scaling with the absolute gradient magnitude, whereas interference in RL is variance-limited, bounded by the gradient variance induced by advantage normalization and on-policy optimization. This small variance bound yields near-orthogonal optimization directions across tasks. Leveraging this insight, we propose Parallel-RL, a paradigm that decouples multi-task training, significantly improving efficiency and flexibility.

- **背景**：当前大语言模型（LLM）的后训练主要依赖两条技术路线——监督微调（SFT）和强化学习（RL）。以往研究多在单任务场景下比较二者的差异，但多任务场景下的行为差异尚未被系统研究。
- **核心现象**：作者通过初步实验发现一个显著对比：
  - 在**多阶段训练**下，SFT出现严重的**任务冲突**，模型性能大幅下降（平均比基座模型低 23.1%）；
  - 而 RL 在同样的多阶段训练下，能够实现**稳定的任务共存**与累积性性能增长（平均提升 24.9%）。
- **核心问题**：为什么多阶段 SFT 会性能崩溃，而 RL 却能稳定地在多个任务上取得持续提升？
- **研究意义**：该问题直接关系到多任务训练范式（混合数据 vs. 多阶段训练）的选择，也为理解 SFT 与 RL 的本质差异、推动多任务 LLM 的发展提供了理论基础，并因此提出了一种更高效的多任务训练新范式。

## 2. 方法论：核心思想、技术细节与理论框架

### 2.1 核心思想
- SFT 与 RL 在多任务场景下的差异根源于其**梯度更新几何性质**的不同：
  - **SFT 更新**：幅度大、密度高、跨任务方向高度重叠，产生严重干扰；
  - **RL 更新**：幅度小、稀疏、跨任务方向近似正交，互不干扰。
- 基于此提出 **Parallel-RL**：利用 RL 更新的近似正交性，将多任务训练解耦为多个并行单任务训练，再合并更新，从而实现高效、灵活的多任务后训练。

### 2.2 关键技术细节

**（1）参数级经验分析**
- 计算每个任务的参数更新向量 ΔW_i，分析其 L2 范数与任务间余弦相似度；
- 发现 RL 的 ΔW 平均范数约为 3×10⁻²，比 SFT（约 7.4）小两个数量级以上；
- RL 更新中仅约 20% 的参数幅度超过 10⁻⁵，而 SFT 高达 93%；
- RL 跨任务余弦相似度约 10⁻⁵，SFT 则在 10⁻¹ 到 1.0 之间，甚至出现反向更新。

**（2）理论分析框架**

- 两种范式的期望梯度形式化为：
  - `g_SFT = E[∇θ log πθ(y|x)]`（off-policy，训练目标为外部专家分布 π_expert）
  - `g_RL = E[A(x,y)·∇θ log πθ(y|x)]`（on-policy，训练目标为策略自身采样 πθ）
- 两个关键机制：
  1. **优势函数（Advantage Function）**：GRPO 中优势满足零和性质（ΣÂ = 0），可代数消除均值梯度方向 S̄，仅保留组内残差 δS，降低干扰；
  2. **策略来源（Policy Source）**：RL 的 on-policy 特性使残差 δS 幅度极小且统计独立，在高维空间中近似正交；SFT 的 off-policy 则需密集大幅更新，跨任务高度重叠。

**（3）核心定理**

- **Theorem 4.5（梯度干扰上界）**：
  - SFT 干扰上界：`|I_SFT(i,j)| ≤ Mi·Mj`（**范数受限**，取决于梯度绝对幅值）
  - RL 干扰上界：`|I_RL(i,j)| ≤ Vi·Vj`（**方差受限**，取决于组内 rollout 方差）
- **补充分析（附录 C.4）**：SFT 余弦相似度存在正下界（共享主导方向无法消除），RL 余弦相似度仅受残差耦合因子控制，可趋于正交。

### 2.4 Parallel-RL 算法流程

- 将 N 个任务各自独立并行启动 RL 训练，得到任务专属更新 ΔW_i；
- 最终模型参数为：`W_final = W_base + M(ΔW_1, ..., ΔW_N)`；
- 合并函数 M 可选多种策略：简单求和（sum）、均值（mean）、TIES 稀疏化、SVD rank-1 合并、合并后轻量适应（Adapted，使用 5% 数据快速恢复）。

## 6. 主要结论与发现

1. **SFT 冲突，RL 共存**：SFT 训练单一任务会显著损害其他任务性能（平均下降 5.1%），而 RL 在提升目标任务的同时还能小幅提升其他任务性能（平均提升 2.3%）。
2. **参数更新几何性质差异**：RL 更新稀疏、幅度小（比 SFT 小两个数量级），且跨任务近似正交（余弦相似度 10⁻⁵ vs. SFT 的 10⁻¹）。
3. **理论机制**：SFT 的梯度干扰为范数受限，RL 的梯度干扰为方差受限；优势函数的零和性质与 on-policy 采样共同实现了“共模过滤”效应。
4. **Parallel-RL 有效**：简单求和合并即可保留单任务性能的约 95%，TIES 和 SVD 进一步提升至 97-98%，Adapted Parallel-RL 甚至能超过单任务模型表现（平均保留率 102-103%）。
5. **任务可解耦**：移除某任务更新向量只影响该任务性能（平均下降 7.1%），其他任务几乎不受影响，说明 RL 更新的模块化与可组合性。
6. **任务选择很重要**：并非所有任务都适合并行训练；通过 t-SNE 可视化 score function 分布可有效预判任务兼容性（如 Game 任务与 Math/Code 存在明显干扰）。

## 7. 优点

- **宏观范式对比**：首次系统性地从“多任务训练行为差异”视角切入，区别于以往单任务比较（如“SFT memorizes, RL generalizes”）；
