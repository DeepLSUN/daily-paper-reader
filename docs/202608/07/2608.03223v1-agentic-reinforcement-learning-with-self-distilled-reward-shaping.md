## 摘要
智能体强化学习使大语言模型智能体能够通过交互进行学习，但稀疏的轨迹级奖励只表明成功与否，却无法识别哪些中间决策应获得信用。仅在训练时使用的特权技能可以通过允许同一个冻结的策略快照在条件于任务匹配的程序性技能的同时，重新评分来自无技能轨迹的固定标记，从而提供更密集的监督。然而，现有方法并未在交互步骤间联合校准教师分数，未将教师置信度与实际回报相关联，也未能将由此产生的信号整合到原生奖励到优势的构建中。我们提出了一种名为ADRS（基于自蒸馏奖励塑形的智能体强化学习）的框架，用于为多轮语言智能体构建与回报相关的标记级信用。ADRS在每个步骤内对特权标记分数进行中心化和归一化，通过基于组内置信度-回报关联的回报相关教师价值优势（TVA）门控对其进行调制，并将门控后的标记信号纳入原生强化学习信用构建中。这些组件共同决定了教师偏好什么、何时这种偏好与回报相关，以及这种偏好如何进入原生强化学习信用路径，同时保持采样和推理无技能依赖。最后，在三个交互式基准上的实验表明，ADRS在长时程任务上持续提升了性能，且这些提升在强化学习骨干、数据减少场景、未见任务和延长训练中均能保持。为方便匿名评审，我们的代码可在以下链接获取：https://github.com/gitrxh/ADRS-arxiv

## Abstract
Agentic reinforcement learning enables LLM agents to learn through interaction, but sparse trajectory-level rewards reveal success without identifying which intermediate decisions deserve credit. Training-only privileged skills can provide denser supervision by allowing the same frozen policy snapshot to rescore fixed tokens from skill-free trajectories while conditioned on task-matched procedural skills. Existing methods, however, do not jointly calibrate teacher scores across interaction steps, relate teacher confidence to realized returns, and integrate the resulting signal into native reward-to-advantage construction. We introduce Agentic Reinforcement Learning with Self-Distilled Reward Shaping (ADRS), a framework for constructing return-associated token-level credit for multi-turn language agents. ADRS centers and normalizes privileged token scores within each step, modulates them with a return-associated Teacher Value Advantage (TVA) gate based on within-group confidence--return association, and incorporates the gated token signal into native RL credit construction. Together, these components determine what the teacher prefers, when that preference is return-relevant, and how it enters the native reinforcement-learning credit path, while keeping rollouts and inference skill-free. Finally, experiments across three interactive benchmarks show that ADRS consistently improves performance on long-horizon tasks, with gains persisting across RL backbones, reduced-data settings, unseen tasks, and extended training. ## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：多轮语言智能体在强化学习训练中，通常只能获得稀疏的轨迹级结果奖励（如成功/失败），而无法为轨迹中的中间决策（如某个步骤的查询、动作或生成的 token）提供细粒度的信用分配（temporal credit assignment）。这导致像 GRPO、GiGPO 这类基于组相对优势的无批评器算法也难以有效区分中间 token 的贡献。

- **已有尝试的不足**：近年来的方法利用训练时特权技能（privileged skills）为无技能轨迹提供更密集的监督，例如 OPSD、Skill-SD、RLSD、SDAR 等。然而，这些方法存在三个未解决的问题：
  1. **分数校准**：教师模型在交互步骤间给出的 token 对数概率存在偏移和尺度差异，不能跨步骤直接比较；
  2. **可靠性估计**：教师置信度高的 token 未必与更高的回报相关，可能仅反映语言上的惯性（canonical）而非决定任务成败的关键动作；
  3. **信用整合**：现有方法通常把蒸馏目标作为独立的辅助损失，绕过了主 RL 算法的 reward-to-advantage 路径，导致与原生优势计算不一致。

- **整体含义**：作者提出一种新的框架 ADRS（Agentic Reinforcement Learning with Self-Distilled Reward Shaping），将训练时特权技能转化为与回报关联的 token 级奖励信号，并注入原生 RL 优势构建过程，从而既不改变推理时的无技能交互方式，又能提供密集且可靠的信用分配。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **总体架构**：ADRS 在轨迹收集与策略优化之间增加一个“信用构建层”（credit-construction layer）。其工作流为：
  1. 行为策略（behavior policy）以无技能上下文采样多条轨迹，并获得环境回报和基础 token 奖励；
  2. 冻结同一策略快照，对已采样的固定 token 分别在普通上下文和特权技能上下文下重新评分；
  3. 通过三个模块将教师信号转换为最终优势，用于标准 GRPO/GiGPO 的裁剪式 actor 更新。

- **模块一：步内相对特权评分（Within-Step Relative Privileged Scoring）**
  - 对每个 token，计算普通上下文下的得分 \( \ell^b_{s,j} \) 和特权上下文下的得分 \( \ell^T_{s,j} \)：
    \[
    \ell^b_{s,j} = \text{sg}[\log \pi_{\theta_b}(y_{s,j} \mid h_s, y_{s,<j})]
    \]
    \[
    \ell^T_{s,j} = \text{sg}[\log \pi_{\theta_b}(y_{s,j} \mid \rho(x) \oplus h_s, y_{s,<j})]
    \]
  - 对每个交互步骤，计算步骤内均值 \( b_s \)，然后做中心化：
    \[
    q_{s,j} = \ell^T_{s,j} - b_s
    \]
  - 再按选定的归一化范围（全局批或序列）计算标准差 \( \sigma_q \) 并进行缩放：
    \[
    \hat{q}_{s,j} = \frac{q_{s,j}}{\sigma_q + \epsilon}
    \]
  - 该变换保证每个步骤内 \(\sum_j \hat{q}_{s,j} = 0\)（零和结构），从而消除步骤间的偏移和尺度差异。

- **模块二：回报关联的教师价值优势门控（Return-Associated TVA Reliability Gate）**
  - 用于估计教师置信度与真实回报之间的一致性。首先按单元（completion-level 或 step-level）计算教师平均置信度 \(\bar{\ell}^T_u\) 和软高置信度权重：
    \[
    \alpha_u = \sigma\left(\frac{\bar{\ell}^T_u - \bar{\ell}^T_{\text{batch}}}{T}\right)
    \]
  - 然后对比高置信度侧与低置信度侧的回报均值：
    \[
    \mu^+_g = \frac{\sum_{u \in g} \alpha_u R_u}{\sum_{u \in g} \alpha_u + \epsilon},\quad
    \mu^-_g = \frac{\sum_{u \in g} (1-\alpha_u) R_u}{\sum_{u \in g} (1-\alpha_u) + \epsilon}
    \]
    \[
    d_g = \mu^+_g - \mu^-_g
    \]
  - 门控值取 \( m_u = \text{sg}[\sigma(\tau \tilde{d}_g)] \)，其中 \(\tilde{d}_g\) 为归一化后的差值。该门控与回报正相关时大于 0.5，负相关时小于 0.5，不相关时为 0.5，关闭 TVA 时 \(m=1\)。
  - 命题 1 证明 \(d_g\) 与组内置信度-回报协方差成正比（不考虑数值 \(\epsilon\)）。

- **模块三：教师引导的逐 token 优势调制（Teacher-Guided Per-Token Advantage Modulation）**
  - 教师奖励定义为：
    \[
    r^T_{s,j} = \eta m_{s,j} \hat{q}_{s,j}
    \]
    \[
    \tilde{r}_{s,j} = r^{\text{base}}_{s,j} + r^T_{s,j}
    \]
  - 由于 \(\hat{q}\) 在步骤内零和，故 \( \sum_j r^T_{s,j} = 0 \)，轨迹总分不变，从而保持环境定义的轨迹顺序（命题 2 给出链式表示）。
  - 轨迹路径：将 \(\tilde{r}\) 输入 GRPO/GiGPO 的标准优势算子，得到 \(A^{\text{traj}}_{i,k}\)。
  - token 路径：将保存的教师奖励在 prompt 组内进行标准化（whitening）：
    \[
    Z^T_t = \frac{r^T_t - \mu^T_g}{\sqrt{(\sigma^T_g)^2 + \epsilon}}
    \]
  - 最终优势为：
    \[
    A^{\text{ADRS}}_{i,k,t} = A^{\text{traj}}_{i,k} + \eta Z^T_{i,k,t}
    \]
  - 第一项提供轨迹方向，第二项在该方向内重新分配 token 级更新强度。对 GiGPO 则把 \(\eta Z^T\) 加在 episode 级优势上，保留原生 step-level 分支。
  - actor 使用标准裁剪目标：
    \[
    \mathcal{L}_{\text{actor}}(\theta) = -\frac{1}{|\mathcal{V}|}\sum_{t \in \mathcal{V}} \min\left[\omega_t(\theta) A^{\text{ADRS}}_t, \bar{\omega}_t(\theta) A^{\text{ADRS}}_t\right]
    \]
  - 命题 3 说明该方法在行为策略点等价于一个带 token 辅助系数 \(a_t = \eta Z^T_t\) 的局部梯度更新，从而明确其优化含义。

- **算法流程**（Algorithm 1）：
  1. 用行为策略采样无技能轨迹，记录 valid-token mask、环境回报和基础奖励；
  2. 冻结教师，计算普通与特权得分；
  3. 按式 (2) 计算中心化归一化教师得分；
  4. 若 TVA 开启，按式 (4)-(5) 计算门控；否则 \(m=1\)；
  5. 形成教师奖励 \(r^T\) 和成形奖励 \(\tilde{r}\)；
  6. 轨迹路径计算原生优势；
  7. token 路径在 prompt 组内白化教师奖励；
  8. 合并为最终优势并 detach；
  9. 更新 actor；
  10. 将新策略作为下一轮行为策略。

## 6. 论文的主要结论与发现

- ADRS 在三个基准上均取得最好或接近最好的结果：
  - Qwen2.5-3B 上 ALFWorld 达到 94.5%（比最强基线 +10.1），Search 宏平均 45.0%（+0.4），WebShop 分数/成功率 87.5/76.6（+2.5/+8.6）；
  - Qwen2.5-7B 上 ALFWorld 达 96.1%（+7.8）；
  - Qwen3-1.7B 上 ALFWorld 达 62.5%（+8.6），Search 宏平均 42.9%，WebShop 成功率 65.6%（+7.0）。
- 延长训练至 300 步后，ADRS 的增益仍能保持（ALFWorld 上 ADRS-global+entropy/clip 最终达到 96.1%，比 GRPO 最终高 9.4 点；WebShop 上最高达到 84.4%）。
- ADRS 在 GiGPO 骨干上依然有效：在 ALFWorld 上从 GiGPO 的 82.8% 提升至 89.8%（+7.0），说明它能与步级优势骨干互补。
- 数据效率实验显示 ADRS 使用 60% 训练数据即超过全量 GRPO（78.1% vs 75.0%）。
- 未见任务泛化实验中，ADRS 相比 GRPO 平均提升 11.9 个点，除 Look 外五个类别全部提升。
- 在更长的最大交互步数下（25/35/50），ADRS 始终优于 SDAR，且增益随 horizon 增大而扩大。
- 机制诊断表明 ADRS 的 token 级调制能使动作/目标 token 与风格 token 的优势对比度大幅提高（动作-风格幅度比从初始化 1.6 升至 step 150 的 95.3），说明其信用分配集中于任务关键 token。

## 7. 优点

- **方法设计上的亮点**：
  - 将教师评分问题进行解耦，分别解决跨步可比性、置信度-回报关联和信用路径整合三个问题，结构清晰；
  - 零和教师奖励设计在轨迹层面保持环境回报顺序，不会破坏原生 RL 的轨迹方向；
  - 通过 TVA 门控自适应调节教师信号强度，避免高置信度但与回报负相关的误导；
  - 把特权监督注入到 reward-to-advantage 构建之前，而不是作为独立辅助目标，从而与 GRPO/GiGPO 等现有骨干无缝兼容；
  - 训练时使用冻结策略自蒸馏，无需额外的大模型、检索器或可学习的价值网络，推理完全无额外成本。

- **实验验证上的亮点**：
  - 覆盖多种模型规模（1.7B、3B、7B）和三个差异明显的任务领域；
  - 设计了 300 步长时程实验、数据效率实验、未见任务泛化实验和交互预算敏感性实验，验证充分；
  - Action–object 诊断提供了机制层面的解释，有助于理解为什么 token 级优势调制有效。

## 8. 不足与局限

- **理论层面**：
  - 命题 3 的等价性仅在行为策略点、未裁剪分支下成立，且限定于局部一阶梯度；在完整 PPO 更新、裁剪激活、或非当前策略点处，ADRS 与辅助 token 更新的关系并不保持；
  - 零和奖励的“策略不变性”仅在采样步骤上成立，并非固定马尔可夫势能，因此在环境动力学改变或部署到不同任务时可能不再有效；
  - TVA 门控基于批量内的经验协方差，当样本组很小或回报方差较大时，门控估计不稳定（论文只对 <2 的组回退到 0.5）。

- **实验层面**：
  - 未报告跨随机种子的均值和方差，无法判断增益的统计显著性；
  - 主要模型侧重 Qwen 系列，未验证在其他基础模型（如 Llama、Mistral）上的通用性；
  - Search 上 ADRS 相比 GRPO 只在宏平均上有 0.4 点的微小提升，个别数据集波动较大，说明短程信息获取任务中特权 token 信用收益有限；
  - 计算资源信息缺失，无法评估方法的训练成本；
  - 未见任务泛化实验仅覆盖 ALFWorld 的 hidden split，其他两个基准未见回归分析。

- **应用限制**：
  - 依赖于任务匹配的程序性技能库，需要事先设计或收集技能文本，对新型任务需要额外构建知识源；
  - 技能注入只在训练时使用，但对复杂交互来说，训练时强制使用技能可能使模型过度依赖“教师偏好”，在技能覆盖不足或质量较低时可能引入偏差；
  - 方法聚焦于语言智能体的 token 级信用分配，对连续动作或非文本环境不直接适用。
