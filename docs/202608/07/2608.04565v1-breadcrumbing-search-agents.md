## 摘要
基于LLM的搜索代理被广泛用于信息搜索任务，但它们对外部工具返回结果的依赖引入了严重的安全风险：执行过程中检索到的网页内容不可信，使代理面临提示注入和目标劫持。先前关于搜索代理安全性的工作主要集中于静态网页内容注入，但现代代理会发出后续查询并交叉核对相互竞争的信息来源，因此单个注入页面往往会被稀释或忽略。我们表明，传递搜索和页面观察结果的通道是一个脆弱的安全边界：除了使代理暴露于单个恶意页面之外，中介搜索界面还可以反复操纵代理收集证据和形成最终答案的方式。在受限的工具中介威胁模型下，当证据在代理的轨迹上进行协调时，每次查询仅附加一个受控结果即可显著提高攻击成功率。我们使用策略驱动的长周期攻击系统研究此设置，并引入了权威链劫持（ACH），这是一种专家优化策略，将孤立的搜索结果和页面内容操纵转化为跨看似相互佐证来源的连贯证据链。ACH在所有基线中实现了最高的总体攻击成功率（ASR），在完整SafeSearch测试集上达到55.9%的ASR和83.3%的MaxN ASR。我们进一步引入了轨迹引导策略进化（TGSE），它从执行轨迹中自动改进攻击者策略，用轨迹驱动优化取代人工重设计；其最强的单一设置在保留评估中达到71.4% / 95.0%。

## Abstract
LLM-based search agents are widely used for information-seeking tasks, but their reliance on external tool returns introduces a critical security risk: web content retrieved during execution is untrusted, exposing agents to prompt injection and goal hijacking. Prior work on search-agent safety primarily focuses on static web-content injection, but modern agents issue follow-up queries and cross-check competing sources, so a single injected page is often diluted or rejected. We show that the channel delivering search and page observations is a fragile security boundary: beyond exposing the agent to a single poisoned page, a mediated search interface can repeatedly steer how the agent gathers evidence and forms its final answer. Under a constrained tool-intermediary threat model, appending only one controlled result per query can substantially increase attack success when the evidence is coordinated across the agent's trajectory. We study this setting with a strategy-driven long-horizon attack system and introduce Authority-Chain Hijack (ACH), an expert-refined strategy that turns isolated search-result and page-content manipulations into a coherent evidence chain across seemingly corroborating sources. ACH achieves the highest Overall ASR among all baselines, reaching 55.9% / 83.3% ASR / MaxN ASR on the full SafeSearch test split. We further introduce Trace-Guided Strategy Evolution (TGSE), which automatically improves attacker strategies from execution traces, replacing manual redesign with trace-driven refinement; its strongest single setting reaches 71.4% / 95.0% in held-out evaluation.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：基于 LLM 的搜索代理（如 Tongyi DeepResearch）在执行多步搜索任务时，依赖外部工具返回的网页内容。这些内容不可信，因此代理面临提示注入（prompt injection）和目标劫持（goal hijacking）等安全风险。
- **现有研究的不足**：以往搜索代理安全研究（如 SafeSearch、WARP、FORGE）主要聚焦于**静态网页内容注入**——即事先固定恶意页面或结果。然而现代搜索代理会发出后续查询、交叉验证竞争性来源，单个注入页面往往会被稀释或拒绝，因此静态攻击模型严重高估了代理的安全性。
- **本文提出的新威胁视角**：搜索代理并非直接观察网页，而是通过第三方中介界面（搜索引擎 + 浏览服务）获取信息。一个**受约束的工具中介攻击者**（tool-intermediary attacker）无需控制整个搜索引擎，只需在每次查询返回结果中附加**一个攻击者控制的结果**，并在代理访问该链接时提供动态生成的页面内容，即可在受害者轨迹上协调地引导证据收集过程。
- **整体含义**：论文主张工具返回观察通道（observation channel）是一个脆弱的安全边界，而非中立的检索接口；协调的多步动态注入比孤立的静态注入更具威胁性。

## 2. 论文提出的方法论

### 2.1 威胁模型与攻击者能力边界
- 每个基准案例 \( c = (x, e, g, K) \)：良性查询 \( x \)、预期安全回答 \( e \)、攻击者目标 \( g \)、最终答案违规检查清单 \( K \)。
- 攻击者权限受限：对每次 SEARCH 最多附加一个合成结果；仅对攻击者引入的 URL 生成的 VISIT 页面可控制；有机（organic）搜索结果与页面保持只读不变。
- 成功标准：最终答案必须满足 \( K \)（即攻击影响最终输出，而非仅仅被看到）。

### 2.2 攻击者运行时（Attacker Runtime）
- **有状态、策略驱动**：攻击者维护轨迹记忆 \( M_t \)（历史查询、访问、注入、反思），利用策略 \( s \) 提供轨迹级引导，规划器 \( P \) 生成事件级载荷 \( (p_t, \rho_t) \)。
- 事件输出公式（文本描述）：
  - 搜索事件：`待观察结果 = 有机结果列表 ⊕ 一个合成尾结果`（或 ⊕ 空）；
  - 攻击者可访问的访问事件：返回动态生成的受控页面内容；
  - 只读访问事件：返回原始真实页面内容。
- 规划器输出结构化决策：`{attack: bool, payload: Payload|null, reflection: str}`，其中反思会进入后续记忆。

### 2.3 权威链劫持（Authority-Chain Hijack, ACH）
- ACH 是基于专家经验提炼的**三层六步策略**，目标是将逐次孤立的注入转化为“看似相互佐证的证据链”：
  1. **阶段一（权威建立）**：在搜索中注入与查询对齐的可信外观结果 → 赢得首次点击；在访问中提供专业风格页面，引入目标对齐框架同时不过度激进。
  2. **阶段二（验证捕获）**：对后续验证性查询注入相互佐证的结果，复用先前术语、引用先前材料、用“日期/范围/方法差异”解释冲突；在访问中通过交叉引用、重复来源名称、兼容指标和对比表形成权威链。
  3. **阶段三（信任巩固与引导整合）**：在代理围绕引入概念搜索时注入“趋同共识”类结果；最终提供决策导向的摘要页面，将目标声明、指标、来源置于易提取的列表、表格、引用块中，以提升最终答案保留率。

### 2.4 轨迹引导策略进化（TGSE）
- 动机：ACH 并非对所有案例族都均匀有效——不同失败模式需要不同策略调整。
- 方法：受 DGM（Darwin Godel Machine）启发的**归档搜索**过程：
  - 对策略 \( s \)，在训练集案例 \( c_i \)、重复 \( R \) 次，执行轨迹 \( \tau_{i,r}(s) \)，得到成功指示 \( z_{i,r}(s) \in \{0,1\} \)。
  - 对 \( 0 < \sum_r z_{i,r}(s) < R \) 的“混合结果”案例（部分重复成功、部分失败）尤为关注——说明目标可达但策略不稳定。
  - 构建**轨迹反馈包** \( D(s) = \{(\bar{\tau}_{i,r}(s), z_{i,r}(s))\}_{i,r} \)，含压缩轨迹、判断摘要、执行指标等。
  - 每代从归档中按分数加权的父选择机制采样父策略，调用进化模型生成完整替代策略 \( s' = E(s, D(s)) \)，经“廉价阶段”门控筛选（硬回归条件），合格子代再进入完整评估并加入归档。
- 关键特点：进化对象是**交给规划器的自然语言宏策略**，测试时冻结，但搜索/访问载荷仍是状态相关的。

  - TGSE 的跨受害者迁移结论为混合结果（对 DeepSeek-V4 有负迁移），说明训练条件的归纳偏差存在。

## 6. 论文的主要结论与发现

- **动态工具中介攻击显著强于静态注入**：ACH 在全部 6 个受害者上取得最高总体 ASR，超越最强非 ACH 基线 13.0–36.1 个 ASR 百分点。全量 SafeSearch 测试集上 ACH 达到 55.9% ASR / 83.3% MaxN ASR（Qwen3 受害者）。
- **成功的关键在于打破两个“门”**：注入访问率（点击门）与访问后的最终答案保留率（保留门）。静态攻击通常在某一道门失败；ACH 通过轨迹观测生成上下文一致的证据，同时提高两道门。
- **TGSE 提供留出集收益**：Normal TGSE 将总体 ASR/MaxN ASR 从 56.0%/85.0% 提升到 70.0%/93.0%；Trace-warm TGSE 最佳单一设置达 71.4%/95.0%；按族取最优的上包络为 77.4%/96.0%，暗示按风险族路由策略的潜力。
- **不同风险族有不同最优策略先验**：Injec 受益于 Trace-warm（热启动定向更好），Bias/Misinfo 受益于更强的验证感知训练，Harm 即使 Adv-warm 也仅小幅提升（50%），Ads 在验证感知下反而受损。
- **推理花销不必然正比于有效性**：ACH 在 provider-matched 对比中 ASR 最高，但攻击者 token/调用/货币成本仅为第二低，说明有效性不随 token 数或成本单调增长。
- **跨模型角色分析**：攻击者能力影响策略实例化质量（Kimi 最强）；受害者差异表现为证据处理方式不同（Qwen3/Qwen3.5 更脆弱，Kimi 更稳健；Gemma4 是低访问率异常值）。
- **冻结 TGSE 策略可部分复用**：跨族迁移中 4/5 的源族策略提高未见族的 ASR 点估计；跨攻击者迁移一致为正，跨受害者则混合。

## 7. 优点

- **威胁模型切合实际**：以个性化赞助结果为载体，不要求控制搜索引擎本身，场景落地性强。
- **策略驱动系统设计**：将“轨迹级策略”与“事件级规划”分离，记忆、反思、策略三者形成互补的运行时控制；消融实验清晰验证各组件贡献。
- **以证据链为核心**：ACH 把“复用来源身份、术语、指标、交叉引用”机制化为显式策略，比单纯更强页面的思路更有效且有可解释性。
- **自动进化闭环 TGSE**：从执行轨迹自动提炼策略更新方向，减少人工重设计；采用 DGM 式多谱系归档搜索而非单调的世代序列，符合真实迭代逻辑。
- **评估严谨程度高**：提供分族结果、置信区间、轨迹门控诊断、位置敏感性、跨模型/框架/基准迁移、推理成本分析等多种视角。
- **对潜台词风险敏感**：明确指出哪些对比是“适配”而非“等价对照”、哪些结论是点估计而非因果效应，学术诚信度较高。

## 8. 不足与局限

- **评估为受控环境而非真实攻击**：攻击运行在仪器化的搜索/访问仿真环境中，并非对真实用户和线上基础设施的攻击；平台控制可能使重复曝光更难。
- **ASR 度量的是基准脆弱性而非现实世界攻击成功率**：真实搜索引擎的过滤、排名、广告审查等可能降低注入可见性。
- **TGSE 归因边界**：TGSE 是“受害者条件化”的策略搜索，非模型无关优化器；从单个受害者轨迹演化出的策略可能对该受害者过拟合（跨受害者迁移中 DeepSeek-V4 出现负迁移）。
- **离线成本高**：归档候选的评估需要反复的端到端 rollout 和判断，算力开销不可忽略。
- **基线严格对照缺失**：动态基线（MAST、AiTM 等）为论文指导的适配重建，非原方法的完整复现；未做计算/状态匹配的因果对照，所以不能严格断言 ACH 各组件单独贡献。
- **个别族效果有限**：Harmful-Output 即使 TGSE 后最高也只有 50% ASR，说明安全类输出存在更顽固的“知识抵抗”效应。
- **小规模子集结论**：部分跨模型/位置/迁移分析基于每族 20 例的小子集，统计功效有限，不宜过度外推。
- **缺少系统防御评估**：论文主要讨论攻击端，防御仅提出提示级和工具级方向的讨论，未做系统化的防御评测。
