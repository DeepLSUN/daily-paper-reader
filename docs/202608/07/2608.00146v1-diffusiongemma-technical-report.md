## 摘要
我们介绍了 DiffusionGemma，一个实验性的开放权重语言模型，它使用离散扩散以极快的速度生成文本。DiffusionGemma 不是一次解码一个 token，而是并行迭代细化 256 个 token 的块，从而避免了传统自回归（AR）大语言模型的顺序解码瓶颈。我们并非从头训练，而是通过对混合专家模型 Gemma 4 进行微调获得 DiffusionGemma，该模型具有 38 亿激活参数和 252 亿总参数。我们计算高效的两阶段训练流程使用的训练 token 预算不到起始 AR 模型总预算的 10%。第一阶段使用监督微调来教授双向去噪，第二阶段将强化学习与采样器蒸馏相结合，以共同提高生成质量和推理效率。DiffusionGemma 为生成速度和模型能力之间的权衡开辟了新的帕累托前沿。在我们的整个评估套件中，它平均每次前向传播生成约 20 个 token，并在单个 NVIDIA H100 GPU 上实现每秒约 1500 个输出 token，即使采用最先进的推测解码，也远快于 AR 模型。DiffusionGemma 还保留了起始模型对思维模式、多模态输入和长上下文的支持。尽管经过扩散微调，它仍然能够以轻微的性能下降进行 AR 生成，这为混合扩散-AR 解码指明了道路。

## Abstract
We introduce DiffusionGemma, an experimental open-weight language model that uses discrete diffusion to generate text at exceptionally high speed. Rather than decoding one token at a time, DiffusionGemma iteratively refines blocks of 256 tokens in parallel, avoiding the sequential decoding bottleneck of conventional autoregressive (AR) large language models. Instead of training from scratch, we obtain DiffusionGemma by fine-tuning the mixture-of-experts Gemma 4 model with 3.8B activated and 25.2B total parameters. Our compute-efficient two-stage training pipeline uses fewer than 10% of the starting AR model's total training token budget. The first stage uses supervised fine-tuning to teach bidirectional denoising, while the second stage combines reinforcement learning with sampler distillation to jointly improve generation quality and inference efficiency. DiffusionGemma establishes a new Pareto frontier for the trade-off between generation speed and model capability. Averaged across our full evaluation suite, it generates around 20 tokens per forward pass and achieves roughly 1,500 output tokens per second on a single NVIDIA H100 GPU, which is substantially faster than AR models even with state-of-the-art speculative decoding. DiffusionGemma also retains the starting model's support for thinking mode, multimodal inputs, and long contexts. Despite diffusion fine-tuning, it remains capable of AR generation with only minor performance degradation, suggesting a path toward hybrid diffusion-AR decoding.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：传统自回归（AR）大语言模型（LLM）采用一次一个 token 的逐顺序解码，导致单请求或低并发场景下推理严重受限于内存带宽——权重和 KV cache 从显存搬运时间远超实际计算时间，GPU 计算单元利用率低下，用户级生成速度被"顺序解码瓶颈"锁定。
- **背景现状**：推测解码（speculative decoding）虽可在一定程度上缓解该问题（每前向约 3–6 个 token），但受制于 draft-then-verify 范式：AR draft 受顺序生成约束，并行 draft 在后续位置接受率衰减。文本扩散模型则可同时预测整块 token，将执行从内存受限转向计算受限，理论上显著加速；但现有扩散模型在"速度、智能、开放"三者间存在割裂：闭源模型（如 Gemini Diffusion、Mercury）性能优但不可访问，开源替代品要么推理能力/多模态理解不足，要么未真正兑现扩散的极致低延迟优势。
- **整体含义**：论文旨在填补这一空白——通过将已有开放权重 AR 模型（Gemma 4 26B A4B）高效微调为文本扩散模型，在不从零预训练的情况下，获得一个**同时具备高智能、极速推理和开放权重**的文本扩散模型，开辟生成速度与模型能力之间的新帕累托前沿。

## 2. 论文提出的方法论

### 2.1 总体设计思路

- **不从头预训练**：以已发布的 Gemma 4 26B A4B MoE 模型（3.8B 激活 / 25.2B 总参数）权重为初始化，通过两阶段微调将其"改造"为文本扩散模型，训练 token 预算不足 AR 模型总预训练预算的 10%。
- **采用离散扩散（discrete diffusion）**：基于连续时间马尔可夫链（CTMC）的离散流匹配框架，避免连续扩散中嵌入空间与离散 token 之间的投影不匹配、空间漂移等问题。

### 2.2 模型架构与生成流程

- **架构**：共享权重的编码器-解码器 transformer（encoder-decoder with shared weights）。编码器为因果注意力，用于编码上下文并维护 KV cache；解码器为双向注意力，用于对 256-token 画布（canvas）去噪。
- **块自回归生成（Block-AR Generation）**：
  - 先将输入上下文（系统指令、用户 prompt 等）通过因果编码器编码为 KV cache；
  - 初始化一个 256-token 的均匀随机噪声画布，通过解码器迭代去噪（约 12 步平均）；
  - 画布完全去噪后，通过因果编码器追加该画布的 KV 到缓存，继续生成下一个画布，直至产生结束 token。
- **去噪迭代**：训练目标是学习条件分布 \( p_\theta(x_0 | x_t, z_t, H) \)，其中 \( x_t \) 为噪声画布，\( z_t \) 为自条件信号，\( H \) 为 KV cache。采用**多项扩散**（multinomial diffusion），所有 token 之间可互相转移，允许模型在画布内不断自我纠错。

### 2.3 采样器设计（Algorithm 1）

- **熵界采样（Entropy-Bounded Sampler）**：按 token 预测熵从低到高排序，优先"锁定"低熵、高置信的 token；当累计熵预算达到阈值（\( b=0.1 \)）后，其余 token 重新均匀随机噪声化，迫使模型在下一轮继续探索。
- **温度退火**：温度从 0.8 线性退火到 0.4，早期保留多样性，后期促使模型果断提交高置信 token。
- **自适应停止（Adaptive Stopping）**：当整个画布的平均预测熵低于阈值（0.005）且连续两轮确定性预测（argmax）完全一致时，提前终止去噪。实际平均仅约 12 个去噪步（最大上限 48 步），带来 4× 延迟下降。

### 2.4 两阶段训练管线

- **第一阶段：监督微调（SFT）**
  - 使用离散多项扩散作为损坏过程，在 256-token 画布上训练模型去噪，损失为标准的交叉熵。
  - 使用块对角注意力掩码：画布内双向注意力，跨画布不允许相互注意。
  - 短 SFT 即可获得不错的非思维模式（non-thinking）性能；长 SFT 对学得"思考模式"（thinking behavior）至关重要。
- **第二阶段：采样器蒸馏与强化学习（SD·RL）**
  - 联合优化两个目标：(1) 通过奖励最大化提升生成质量与对齐；(2) 通过采样器蒸馏将模型高质量输出压缩到少步数（few-step）推理区域。
  - 在线教师为模型自身，使用高步数采样器生成高质量参考轨迹；训练过程中，自适应停止机制逐步提前触发——模型置信度提升→熵下降→停止更早→训练分布自动倾向更短的去噪轨迹，形成隐式课程学习效应。
  - SD·RL 后模型在 GPQA-Diamond + LiveCodeBench-v6 平均值上提升约 10 个点，TPF 从 5 提升至近 20。

- **训练效率**：两阶段管线以不足 10% 的 token 预算完成了从 AR 到扩散的转化，验证了"从已有 AR 模型 warm-start 训练扩散模型"的高效路径。

## 7. 优点

- **方法论创新**：将 SFT 与 SD·RL（采样器蒸馏 + 强化学习联合优化）融合为单一在线训练阶段，统一解决"质量提升"与"少步数压缩"两个目标；自适应停止机制自然地诱导隐式课程学习。
- **架构设计的实用主义**：共享权重的因果编码器 + 双向去噪解码器，使 KV cache 可增量追加，支持长序列高效生成；不严格绑定特定采样器，具备模块化可扩展性。
- **开放性**：Apache 2.0 许可发布开放权重，并提供 HuggingFace Transformers 与 vLLM 参考实现；附赠开源下游微调工具包（LoRA 配方），社区在发布数周内已涌现 ASR、医学影像报告等衍生应用。
- **低批量场景性能突出**：在低并发（≤~32）场景下，每用户 TPS 与总吞吐均优于含 MTP 的 AR 模型，对延迟敏感应用（单请求、agentic 工作流）尤为关键。
- **丰富定性分析**：通过去噪轨迹可视化与多组案例分析，直观展示了双向推理、自校正、结构化输出快速收敛等扩散模型独有的能力优势。

## 8. 不足与局限

- **相对 AR 基线的性能折损**：相比 Gemma 4 26B A4B，扩散模式在几乎所有基准上均有不同程度下降（如 GPQA 73.2 vs 82.3，Codeforces 1429 vs 1718）；原因包括绕过原生扩散预训练、SFT 预算有限、SD·RL 以低延迟为优化目标、继承 AR 架构可能不完全适配扩散等。
- **生成过于简洁**：SD·RL 训练产生的"简洁性"虽然放大速度收益，但也限制了超长推理链可能带来的质量增益。
- **偶发 token 退化**：在极少情况下输出会陷入局部重复循环（如 "the the the"），是超低延迟少步数运行时的剩余伪影。
- **多模态任务中的思考标签缺失**：处理多模态 prompt 时偶尔漏生成闭合思考标签，导致 MMMU-Pro 思维模式得分（54.3）反而低于非思维模式（66.0）；论文坦承该问题发现过晚未能修复。
- **高并发场景吞吐优势有限**：约 32 并发请求之后，AR 模型因每 token 计算成本更低而反超；论文未针对 batch > 1 做内核与采样优化，真实流量下的分析留待未来工作。
- **测评公平性局限**：不同模型在不同硬件/精度条件下测量（如 LLaDA 在 8×B200、Nemotron 为 bfloat16、Mercury 通过 API 估算），严格等价对比存在一定偏差风险；训练算力细节也未披露。
