## 摘要
长期任务的LLM智能体需要记忆系统，能够从大规模交互历史中恢复有用证据，而无需将过多上下文传递给下游模型。现有的记忆流水线通常依赖手工设计的启发式规则和重复的LLM调用，这可能引入冗余上下文和高推理成本。我们提出MemoryCPT，一种端到端可训练的智能体记忆流水线，涵盖离线记忆构建和在线查询条件化上下文生成。MemoryCPT包含两个阶段：查询无关蒸馏（QAD），利用显式推理轨迹将模块化记忆构建流水线蒸馏为紧凑模型；以及查询感知检索与摘要（QAR），结合倒数排名融合（RRF）与通过分组相对策略优化（GRPO）在成本感知奖励下训练的基于LoRA的摘要器。我们进一步引入单位成本质量（QPC）来量化单位推理成本下的答案质量。在LoCoMo和LongMemEval上的实验表明，MemoryCPT在成本-性能权衡上优于所评估的基线方法，而消融和敏感性分析则表征了其组件的贡献及关键设计选择的影响。

## Abstract
Long-horizon LLM agents require memory systems that recover useful evidence from large interaction histories without passing excessive context to downstream models. Existing memory pipelines often rely on hand-crafted heuristics and repeated LLM calls, which can introduce redundant context and high inference cost. We propose MemoryCPT, an end-to-end trainable agent memory pipeline that spans offline memory construction and online query-conditioned context generation. MemoryCPT consists of two stages: Query-agnostic Distillation (QAD), which distills a modular memory-construction pipeline into a compact model using explicit reasoning traces; and Query-aware Retrieval and Summarization (QAR), which combines reciprocal rank fusion (RRF) with a LoRA-based summarizer trained via Group Relative Policy Optimization (GRPO) under a cost-aware reward. We further introduce Quality per Cost (QPC) to quantify answer quality per unit inference cost. Experiments on LoCoMo and LongMemEval show that MemoryCPT improves the cost-performance trade-off over the evaluated baselines, while ablation and sensitivity analyses characterize the contributions of its components and the effects of key design choices.

- **压缩阶段**：如何让紧凑模型从原始历史中学习构建高质量长期记忆（包括分段、生成情景记录、合并事件、提取语义知识）？仅用最终摘要监督学习目标过于粗糙，中间决策过程被掩盖。

## 2. 方法论：MemoryCPT

### 2.1 总体框架

MemoryCPT 是一个两阶段端到端可训练流水线，将原始交互历史映射到查询条件化上下文：

```
H ->(fQAD)-> M,   (q, M) ->(fQAR)-> mq,   (q, mq) ->(fans)-> ŷ
```

- **离线阶段** QAD（Query-agnostic Distillation，查询无关蒸馏）：构建可复用的情景记忆与语义记忆库。
- **在线阶段** QAR（Query-aware Retrieval and Summarization，查询感知检索与摘要）：检索查询相关记忆并压缩为紧凑摘要。
- 下游QA模型（fans）保持**冻结**，只有记忆管线可训练。

### 2.2 QAD：查询无关蒸馏

- 将教师模型（DeepSeek-V3）的**模块化记忆构建流水线**蒸馏为紧凑学生模型（Qwen2.5-7B 或 Llama-3.2-3B + LoRA-A）。
- 四个教师角色构成“硬度脚手架”：
  - **BatchSegmenter**（批量分段器）：识别会话边界
  - **EpisodeGenerator**（情景生成器）：生成情景记录
  - **EpisodeMerger**（情景合并器）：合并相关情景
  - **SemanticExtractor**（语义提取器）：提取持久知识
- 关键：训练数据采用“**推理轨迹 + 结构化JSON输出**”格式（`<think>`标签内的显式推理 + 可执行JSON），教会学生模型“为什么要执行某个记忆操作”，而非仅学习最终输出。
- 相邻教师调用被折叠成单次学生预测以降低推理开销。训练目标为标准因果语言建模：

$$L_{QAD} = -\mathbb{E}_{(x,r,y)\sim D_{QAD}} \sum_{t=1}^{|z|} \log p_\theta(z_t | z_{<t}, x), \quad z = r \oplus y$$

- 学生输出作为离散操作由外部运行时执行，最终记忆库 $M = M_{ep} \cup M_{sem}$。

### 2.3 QAR：查询感知检索与摘要

**RRF检索**：结合稠密（embedding）与稀疏（BM25）双路检索信号，用倒数排名融合（Reciprocal Rank Fusion）统一不同分数尺度：

$$s_{RRF}(m; q) = \sum_{r \in \{dense, sparse\}} \frac{1}{k_{rrf} + rank_r(m|q)}$$

RRF分别作用于情景和语义索引，拼接top候选形成受限候选集 $M^{RRF}_q$。

**策略、动作与优化**：将QAR训练建模为**单步情境赌博机**（contextual bandit）问题：
- 状态：$s_q = (q, M^{RRF}_q)$
- 动作：摘要标记序列 $m_q \sim \pi_\phi(\cdot | s_q)$
- 优化：GRPO + KL正则，训练LoRA-B适配器

**成本建模**：训练用成本代理为可变在线边际成本：

$$C(q, m_q) = |m_q| \cdot (p^{out}_{7B} + p^{in}_{14B}) + |\hat{y}| \cdot p^{out}_{14B}$$

通过 $C_{ref}$ 归一化裁剪到 [0,1]：

$$\tilde{C}(q, m_q) = \min\left(1, \frac{C(q, m_q)}{C_{ref}}\right)$$

**奖励设计**：

$$R(q, m_q) = \alpha \cdot F1(\hat{y}, y^*) + (1-\alpha) \cdot (1 - \tilde{C}(q, m_q))$$

- 默认 $\alpha = 0.8$，F1 与成本项均限幅在 [0,1] 保证稳定性。
- 使用加权和代替直接优化 QPC = F1/Cost 比值，避免训练不稳定。

### 2.4 训练流程

1. 教师流水线产生角色级推理轨迹和结构化JSON → 转为单轮SFT数据 → 训练LoRA-A → 合并为基础模型 base_A。
2. base_A离线构建情景/语义记忆库 → RRF检索候选 → GRPO训练LoRA-B生成成本感知查询摘要。
3. 推理时仅三步：RRF检索 → LoRA-B生成摘要 → 冻结QA模型回答。

## 6. 主要结论与发现

1. **联合提升质量与效率**：用Qwen2.5-7B做记忆基础模型时，MemoryCPT在LoCoMo上比BudgetMem F1从0.373提升至0.479（+28%相对提升），Cost从24.11降至4.31（约7倍降低），QPC从0.015提升至0.138（超9倍）。在LongMemEval上同样在F1（0.358→0.485）与QPC（0.020→0.085）上全面领先。
2. **端到端记忆训练有效**：现有训练免流水线（LightMem、MemoryOS、BudgetMem）通过增加中间上下文成本来提升质量，而RL优化成本的方法（Memory-R1）又牺牲了质量；MemoryCPT在两个基础模型架构上均避免了这种“质量-成本二选一”的折中。
3. **QAD是质量放大器**：离线蒸馏引入少量额外成本但大幅提升下游记忆质量；移除QAD后F1从0.479降至0.370。
4. **QAR是成本控制器**：移除查询感知压缩后，Cost从4.31骤增至11.10，QPC从0.138崩溃到0.038。
5. **α = 0.8是最优奖励平衡**：α→1.0时摘要过长、成本升高；α过小时过度压缩、丢失关键证据；0.8位于Pareto前沿左上端。
6. **检索深度20/50最合适**：8/20已能恢复约96%的峰值F1，20/50达到质量峰值，超过后引入噪声并退化。
7. **记忆系统应以“单位成本的智能量”评估**，而非仅看原始准确率——这是全文的方法论主张。

## 7. 优点

- **端到端可训练范式**：将记忆构建与查询感知压缩全部内化为模型参数，替代手工启发式和重复LLM调用。
- **两阶段分离设计巧妙**：离线构建（QAD）与在线优化（QAR）分开，将RL动作空间从整个记忆库缩小到仅检索后候选集，显著降低学习难度；下游QA模型冻结，训练成本可控。
- **推理轨迹蒸馏**：显式的`<think>`推理轨迹+结构化JSON输出，提供比最终答案更稠密的监督信号，让学生学到“为什么合并/为什么提取”的决策逻辑。
- **成本感知奖励设计**：利用加权和代理（F1 + 成本项）
