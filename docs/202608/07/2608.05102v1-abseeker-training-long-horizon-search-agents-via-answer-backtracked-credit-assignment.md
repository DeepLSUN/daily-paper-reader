## 摘要
长视界搜索智能体必须执行多个顺序动作（步骤）来搜索、检索、验证和整合证据，以得出最终答案。然而，现有的训练这些智能体的方法通常在监督微调（SFT）和强化学习（RL）中将轨迹中的所有步骤一视同仁，未能区分有用动作与错误或冗余动作。在本文中，我们提出了一种细粒度的信用分配框架——答案回溯信用分配（ABC），用于训练长视界搜索智能体，通过将稀疏的轨迹级结果转化为密集的步骤级监督，奖励有用动作（即使在失败的轨迹中）同时抑制错误或冗余动作。具体而言，给定一个可能模糊的查询及其对应的真实答案，ABC首先执行答案回溯线索恢复，从答案回溯以恢复解决问题所需的中间线索。然后应用线索锚定步骤评分，根据这些线索评估每个搜索步骤，将稀疏的二元结果监督转化为密集的步骤级奖励。基于这些奖励，我们开发了ABC-SFT（重新加权每轮损失）和ABC-GRPO（在GRPO中使用步骤级分数作为奖励）。在此框架基础上，我们仅使用8.5k个示例基于Qwen3.5-4B训练了ABSeeker。ABSeeker在BrowseComp上达到37.3%，在BrowseComp-ZH上达到39.1%。通过上下文管理，得分进一步提升至55.3%和52.9%，显著优于同规模（4B）智能体，甚至匹配更大规模（约30B）智能体的性能。这些结果证明了答案回溯的步骤级信用分配在训练长视界搜索智能体中的有效性。

## Abstract
Long-horizon search agents must make multiple sequential actions (steps) to search, retrieve, verify, and integrate evidence to reach a final answer. However, existing methods for training these agents typically treat all steps within a trajectory uniformly during both supervised fine-tuning (SFT) and reinforcement learning (RL), failing to distinguish useful actions from erroneous or redundant ones. In this paper, we propose Answer-Backtracked Credit Assignment (ABC), a fine-grained credit assignment framework for training long-horizon search agents by converting sparse trajectory-level outcomes into dense step-level supervision that rewards useful actions (even in failed trajectories) while suppressing erroneous or redundant actions. Specifically, given a potentially obscure query and its corresponding ground-truth answer, ABC first performs Answer-Backtracked Clue Recovery, which traces back from the answer to recover intermediate clues required to solve the question. It then applies Clue-Anchored Step Scoring to evaluate each search step against these clues, converting sparse binary outcome supervision into dense step-level rewards. Based on these rewards, we develop ABC-SFT, which reweights the loss of each turn, and ABC-GRPO, which uses the step-level scores as rewards in GRPO. Building on this framework, we train ABSeeker based on Qwen3.5-4B with only 8.5k examples. ABSeeker achieves 37.3% on BrowseComp and 39.1% on BrowseComp-ZH. With context management, the scores further improve to 55.3% and 52.9%, respectively, significantly outperforming same-scale (4B) agents and even matching the performance of larger ones (approximately 30B). These results demonstrate the effectiveness of answer-backtracked step-level credit assignment for training long-horizon search agents.

## 1. 核心问题与整体含义

- **研究动机**：长视界搜索智能体需要通过多步搜索、检索、验证和整合证据来回答复杂问题。现有训练方法（SFT 与 RL）通常将一条轨迹中的所有步骤**一视同仁**：成功轨迹全部视为正例，失败轨迹全部视为负例。
- **根本问题**：这种稀疏的轨迹级监督无法区分“有用动作”与“错误/冗余动作”。成功的轨迹中可能包含错误结论或冗余探索；失败的轨迹中也可能包含发现关键证据的有用步骤。
- **核心含义**：本文提出 **答案回溯信用分配（Answer-Backtracked Credit Assignment, ABC）**，利用搜索任务“给定答案后可回溯”的特性，将稀疏的最终结果转化为**密集的步骤级奖励**，从而精细化地指导模型训练。

## 2. 方法论

### 2.1 核心思想

- 利用 ground-truth 答案，从答案出发**回溯恢复**解题所需的中间线索（实体、事实、属性、关系等）。
- 以这些线索为“锚点”，对轨迹中的每一步逐一评分，获得密集的步骤级奖励。
- 该奖励可同时用于 SFT 损失重加权和 GRPO 强化学习。

### 2.2 关键技术环节

1. **答案回溯线索恢复（Answer-Backtracked Clue Recovery）**
   - 输入：查询 `q` 和已验证答案 `a*`。
   - 输出：一组中间证据线索 `C = {c1, c2, ..., cK}`。
   - 恢复过程本身是主动 ReAct 循环：LLM 通过搜索和访问网页，从答案向查询方向回溯证据链，并锚定于真实网页内容，确保线索可靠。

2. **线索锚定步骤评分（Clue-Anchored Step Scoring）**
   - 输入：当前步骤（推理、工具调用、工具响应）、原始查询、完整线索集。
   - 输出：步骤奖励 `r_t` 及简短解释。
   - 评分规则：每步基础分为 `1.0`，在此基础上累加增减分，并截断至 `[0, 2.0]`：

   | 行为 | 增减分 |
   |---|---|
   | 发现或验证一个正确线索 | +0.8 |
   | 正确排除错误候选 | +0.4 |
   | 错误否定正确线索 | −0.8 |
   | 提交正确最终答案 | +1.0 |
   | 提交错误最终答案 | −1.0 |

   - 公式：`r_t = clip(1.0 + Σ_{j∈A_t} Δ_j, 0, 2.0)`，其中 `A_t` 是该步骤中命中的行为集合。

3. **训练阶段**
   - **ABC-SFT（奖励加权监督微调）**：对每个步骤的 token 损失按其奖励加权，权重为 `w(r_t) = σ(α(rt − β))`。高奖励步骤贡献更大梯度，低奖励步骤被抑制。
   - **ABC-GRPO（步骤级强化学习）**：在 GRPO 框架内，将步骤奖励作为即时奖励，组内归一化后计算折扣优势：
     `A_{i,t} = Σ_{k=t}^{T_i} γ^{k−t} R̂_{i,k}`，其中 `γ=0.25`。
   - 成功与失败轨迹都会被保留，用于提取有用步骤、惩罚错误步骤。

## 3. 实验设计

### 3.1 训练设置

- 基础模型：Qwen3.5-4B。
- 训练数据：来自 OpenSeeker 的 8.5K 条轨迹（5.5K 正确 + 3.0K 错误），最大步数 200。
- 线索恢复与步骤评分使用 DeepSeek-V4-Flash 作为 LLM。
- SFT 训练 3 个 epoch；RL 阶段从 1000 个问题中采样，每个问题 8 个 rollout。

### 3.2 评测基准

- **BrowseComp**：英文长视界浏览与多约束信息检索。
- **BrowseComp-ZH**：中文对应基准。
- **xbench-2505 / xbench-2510**：真实世界专业场景下的深度研究能力。
- **GAIA-text**：通用 AI 助理任务，涉及网页浏览、工具使用和多跳推理。

### 3.3 对比方法

- **前沿基础模型**：Gemini-3.1-Pro、Seed-2.0-Pro、GLM-5、DeepSeek-V4-Pro-Max、GPT-5 High。
- **约 30B 搜索智能体**：MiroThinker-1.7-mini、RedSearcher、DeepMiner、Tongyi-DeepResearch、OpenSeeker。

### 3.4 主要结果

- ABSeeker 在 4B 规模下全面最优：BrowseComp 37.3%（上下文管理后 55.3%）、BrowseComp-ZH 39.1%（后 52.9%）、xbench-2505 77.0%、xbench-2510 46.0%、GAIA-text 81.6%。
