## 摘要
经典的计算最优缩放定律假设无限的新鲜预训练数据供应，然而预训练正日益进入一个计算增长速度超过高质量数据可用性的阶段。我们提出了计算-数据（CD）缩放定律，这是一个统一框架，将计算最优缩放（数据随计算自由扩展）和数据最优缩放（语料库固定而计算可无限增长）联系起来。CD缩放通过引入标记有效性函数η扩展了经典缩放定律，该函数量化了派生标记（例如通过多轮重复或改述产生的标记）相对于新鲜标记的价值，范围从完美替代品到毫无价值。我们使用Dolma-3语料库，在14M到600M参数规模的模型上，针对两种数据扩展策略（多轮重复和改述）拟合了η。我们发现标记有效性远非常量：它共同依赖于模型大小、每参数标记数和派生数据量，并随着语料库扩展而饱和。η的函数形式意味着，当模型规模或数据可用性增加时，用计算替代数据会产生递减的回报。它还将训练划分为三种操作状态——计算受限、数据受限和模型受限——并表明经典的计算最优分配在大多数实际相关设置中并非最优。

## Abstract
Classical compute-optimal scaling laws assume an unbounded supply of fresh pretraining data, yet pretraining is increasingly entering a regime in which compute grows faster than the availability of high-quality data. We propose Compute-Data (CD) scaling laws, a unified framework that bridges compute-optimal scaling, where data scales freely with compute, and data-optimal scaling, where the corpus is fixed while compute can grow without bound. CD scaling extends classical scaling laws by introducing a token-effectiveness function, $η$, which quantifies the value of a derived token-produced, for example, through multi-epoch repetition or paraphrasing-relative to a fresh token, ranging from a perfect substitute to having no value. We fit $η$ for two data-expansion strategies, multi-epoch repetition and paraphrasing, across model sizes from 14M to 600M parameters using the Dolma-3 corpus. We find that token effectiveness is far from constant: it depends jointly on model size, the tokens-per-parameter ratio, and the amount of derived data, and it saturates as the corpus is expanded. The functional form of $η$ implies diminishing returns when substituting compute for data as either model size or data availability increases. It also partitions training into three operational regimes---compute-bound, data-bound, and model-bound---and shows that classical compute-optimal allocation is suboptimal across most practically relevant settings.

# 论文详细中文总结：弥合计算最优与数据最优的预训练（Bridging Compute- and Data-Optimal Pretraining）

## 1. 核心问题与整体含义

**研究背景与动机：**

- 经典缩放定律（如 Chinchilla，Hoffmann et al., 2022）隐含一个**数据无限**假设：新鲜预训练 token 取之不尽，语料规模 D 可随算力 C 同比例增长。
- 但现实中高质量文本数据**有限且昂贵**（Villalobos et al., 2024），算力增长（Sevilla et al., 2022）已远超可用数据增长速度，预训练正进入经典定律"不适用"的区间：D 有界，额外算力只能花在**派生 token**（由 D 经多轮重复、改写、蒸馏等产生）上。
- 核心科学问题可表述为：**对于固定模型 N 和固定语料 D，额外算力还能在多大程度上降低损失？** 经典缩放定律无法回答这一问题。

**论文的整体含义：**

- 该论文提出 **Compute-Data（CD）缩放定律**，将经典计算最优缩放（数据自由扩展）与数据最优缩放（固定语料、算力无限）统一到一个数学框架中，作为两种极端情况的桥梁。
- 核心创新是引入 **token 有效性函数 η**，量化派生 token 相对新鲜 token 的价值，从而解释"在数据受限时，反复训练（重复/改写）到底值多少"。

## 2. 方法论

**核心思想与公式：**

- **CD 缩放定律扩展了经典 Chinchilla 定律**，原始公式为：
  
  L<sub>Chin</sub>(N, D) = E + A/N<sup>α</sup> + B/D<sup>β</sup>

- 引入派生 token 数量 D′ 和有效性系数 η 后，扩展为：

  L<sub>CD</sub>(N, D, D′) = E + A/N<sup>α</sup> + B / (D + η<sub>strat</sub>(N, TPP, D′/D)·D′)<sup>β</sup>

- **η 的含义**：取值范围 [0,1]，η=1 表示派生 token 与新鲜 token 价值相等，η=0 表示完全无用。D<sub>eff</sub> = D + ηD′ 表示"等效新鲜 token 数"。
- 三个自然极限：
  - D′ = 0 时退化为经典 Chinchilla 定律（计算最优）；
  - D → ∞ 时趋近模型能力下限 L<sub>N</sub> = E + A/N<sup>α</sup>（模型受限）；
  - D′ → ∞ 时定义**数据最优缩放** L<sub>D</sub>，即固定语料下无限算力能达到的最低损失。

**η 的参数化与函数形式：**

- 论文通过系统实验实证发现 η 存在三个规律：随 r = D′/D 增大而衰减；随 TPP = D/N（每参数 token 数）增大而衰减；η·r（等效派生数据量）随 r 增大而**饱和**而非无限发散。
- 由此选择**指数形式**：

  η = (R*/r)·(1 − e<sup>−r/R*</sup>)，其中 R* 为饱和上限

  - R* 的物理含义：语料 D 通过数据扩展能够"变出"的新鲜等效 token 上限，表示为 D 的倍数（lim<sub>r→∞</sub> η·r = R*）。
  - R* 采用幂律形式建模：**R* = K · (D/N)<sup>ρ</sup> · N<sup>σ</sup>**，其中 ρ 和 σ 均为负值，表示 R* 随模型规模和数据丰裕度收缩。
- **五个 1-epoch Chinchilla 参数** (E, A, B, α, β) 与**三个策略特有参数** (K, ρ, σ) 被联合拟合，共享常量；数据最优点与数据受限重复数据定律（Muennighoff et al.）的差距也被明确说明。

**拟合方法：**

- 使用 Besiroglu et al. (2024) 的拟合流程：log 损失空间中的 Huber 损失，L-BFGS 优化器，并用残差迭代裁剪（iterative residual trimming）剔除离群点（k=15）。
- 通过 **200 次 bootstrap 重采样**计算 95% 置信区间，用于比较不同策略的统计显著性。

## 3. 实验设计

**数据集与模型：**

- 数据：Dolma-3 150B 语料库（OLMo3 数据混合）；验证集为 500 万条 held-out 文档。较少的 D 始终是较大 D 的严格子集，确保嵌套性。
- 模型：OLMo3 架构与训练基础设施；参数量 N ∈ {14M, 30M, 60M, 100M, 190M, 370M, 600M}，共 7 个量级。
- 序列长度固定 4096，batch size 512，AdamW 优化器，cosine LR 计划。
- 超参：sweep 学习率 ∈ {1e-4, 3e-4, 1e-3, 3e-3} 和权重衰减 ∈ {0.1, 0.2, 0.4, 0.8, 1.6}，在 30M 和 370M 上做全网格搜索，其余尺寸做局部网格。

**数据扩展策略（两种）：**

1. **多轮重复（Multi-epoch）**：将原始语料重复训练多个 epoch。
2. **改写（Paraphrasing）**：使用 SmolLM2-1.7B-Instruct 模型改写 D 中每个文档，每个文档最多取样 16 个改写版本，风格从 {question, math/wiki, FAQ, table} 四种中均匀随机选取；模型在新鲜 D 与改写后的 D′ 混合数据上训练 1 个 epoch。

**对比方法/基线：**

- 经典 Chinchilla 定律（Hoffmann et al., 2022）；
- 数据受限重复数据缩放定律（Muennighoff et al., 2025）；
- 其他 9 种备选 η 函数形式（消融对比）。

**下游验证基准：**

- 基于准确率的任务：LAMBADA、HellaSwag、OpenBookQA、RACE、SQuAD；
- 基于 LM 损失（BPB）的任务：GSM8K、TriviaQA、HumanEval、MBPP、NQ Open、WebQS、SQuAD、IFEval、C4、WikiText-103。

## 5. 实验数量与充分性

**规模与数量：**

- 总训练运行次数由联合拟合数据量（n=356 点）体现，涵盖了 7 种模型尺寸 × 多种 D × 多种 D′ × 两种策略；
- 超参扫描在 30M 与 370M 上完整执行 4×5=20 组 × 4 个 epoch 档位；
- 对 η 的 9 种函数形式做了 leave-one-out RMSE 对比消融；
- 对 R* 的幂律形式做了每项消融（去 ρ、去 σ、同时去除）；
- 做了跨尺度外推验证（仅用 14M/30M 拟合，预测 60M–600M）；
- 在 7 个下游基准上验证了验证损失与下游能力的单值对应关系。

**充分性与公平性评估：**

- **强项**：跨尺度外推验证是"诚实"的（模型尺寸最大差 20 倍），具有说服力；置信区间与统计显著性检验比多数同类工作严格。

## 6. 主要结论与发现

1. **派生 token 的有效性远非恒定**：η 随 TPP（D/N）和 N 的增大而系统性地衰减并饱和，即"更大模型 + 更充裕数据 → 额外算力收益越小"。
2. **经典计算最优分配并非最优**：在大部分实际相关区域，单 epoch 训练 + 固定计算预算会导致次优性能；增加少量额外画在 D′ 上的算力能显著降低损失（等损失线在 C 方向上远陡于 D 方向）。
3. **三种训练状态**：
   - **计算受限**（compute-bound）：L<sub>Chin</sub> 与 L<sub>D</sub> 之间，增加 D′ 有效；
   - **数据受限**（data-bound）：L<sub>D</sub> 与 L<sub>N</sub> 之间，再增加 D′ 已饱和，只有新鲜数据才能降损失；
   - **模型受限**（model-bound）：到达 L<sub>N</sub>，只有增大 N 才能进一步降损失。
   - 计算受限区间随 N 和 TPP 增大而**收紧**。
4. **策略选择的定量处方**：
   - 4-epoch 规则仅在约 3B 模型 + 近 1×Chinchilla 数据预算附近成立；随 N 和 TPP 增长，推荐 epoch 数显著下降（如 30M/TPP=3 时需 61 epochs 才能达到 Ep@90%，而 3B/TPP=160 时仅需约 1–2）。
   - 改写（paraphrasing）仅对 ≲600M 的小模型 + 低于 1×Chinchilla 的数据预算占优；
   - 对 N ≥ 7B 或数据预算 ≥ 4×Chinchilla 的情况，改写几乎无效（R*<1，即收益甚微）。
5. **验证损失是下游能力的充分统计量**：多 epoch 与改写运行在下游基准上完全落在同一条"验证损失-下游性能"曲线上，说明以验证损失为优化目标是合理的替代目标。

## 7. 优点与亮点

- **概念统一性强**：CD 缩放定律将经典 Chinchilla、Muennighoff 数据受限定律、Kim et al. 无限计算极限统一为同一框架的特殊情形，理论位置清晰。
- **公式优雅且可解释**：η 的指数形式（η = R*/r·(1−e<sup>−r/R*</sup>)）满足 η(0)=1、η·r 有界两个自然约束；R* 具有直观的"语料放大倍数"含义。
- **统计严谨**：用 bootstrap 置信区间做策略比较，而非仅做点估计；跨尺度外推验证做得到位。
- **实用性导向强**：给出了可以直接查阅的"推荐 epochs/推荐改写给数"图（R* heatmap），对实践者有明确指导意义。

## 8. 不足与局限

- **模型尺度有限**：最大训练规模仅 600M 参数，外推至 3B–7B 的可信度不足；论文也承认无法确证大规模行为的准确性。
- **η 吸收拟合残差**：η 的估计依赖 1-epoch Chinchilla 拟合的质量，任何对 1-epoch 拟合的误设定都会污染 η（例如 η 可能被推出 >1），拟合质量对基座定律敏感。
- **超参扫描不足**：固定了 batch size、序列长度、学习率计划等其他超参数，它们在更大的 D′ 下可能与 η 存在交互作用（例如 30M 模型在 64 epochs 时 weight decay 需要 1.6 之高，说明超参数敏感性极强）。
- **策略覆盖窄**：仅评估了重复与改写两种策略；蒸馏、结构化合成数据、多策略组合等均未覆盖，据称组合策略可能产生比单一策略更高的有效 η。
- **计算成本极高**：25 万 H100 小时对于大多数研究团队不可复现，放大了该类研究的准入壁垒。
- **改写成本未计入**：改写生成所耗的 FLOPs 不计入训练算力（被视为异步任务），但在整体资源考量中不可忽略，可能导致策略比较结果偏向改写。
