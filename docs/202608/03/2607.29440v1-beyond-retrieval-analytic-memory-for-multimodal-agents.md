## 摘要
长期多模态记忆不仅要支持检索相关信息，还要能够对跨交互累积的观察进行计算。现有系统主要强调\emph{检索记忆}，通过摘要和索引组织交互历史，以多粒度返回查询相关信息，从高层抽象到底层记录。在本文中，我们将\emph{分析记忆}定义为一种互补抽象，它将重复出现的多模态观察组织成可查询的结构，支持过滤、聚合、排序和时间比较。我们提出了AdaMM，一个联合支持检索和分析记忆的框架。AdaMM不依赖应用定义的模式，而是从对话、图像和上下文元数据中提取带有来源链接的属性-值观察，发现重复出现的字段结构，并将其物化以供分析访问。在推理时，一个具有记忆意识的规划器将查询分解为检索和分析操作，并将每个操作路由到适当的工具。在两个长期多模态记忆基准测试MemEye和MemGallery上的实验表明，AdaMM的性能分别提高了11.3%和7.3%。

## Abstract
Long-term multimodal memory must support not only retrieving relevant information but also computing over observations accumulated across interactions. Existing systems largely emphasize \emph{retrieval memory}, organizing interaction histories through summaries and indexes to return query-relevant information at multiple granularities, from high-level abstractions to underlying records. In this paper, we formulate \emph{analytic memory} as a complementary abstraction that organizes recurring multimodal observations into queryable structures supporting filtering, aggregation, ranking, and temporal comparison. We present AdaMM, a framework that jointly supports retrieval and analytic memory. Rather than relying on application-defined schemas, AdaMM extracts provenance-linked attribute-value observations from dialogue, images, and contextual metadata, discovers recurring field structures, and materializes them for analytical access. At inference time, a memory-aware planner decomposes queries into retrieval and analytic operations and routes each operation to the appropriate tools. Experiments on two long-term multimodal memory benchmarks, MemEye and MemGallery, show that AdaMM improves performance by up to 11.3\% and 7.3\%, respectively.

### 2. 论文提出的方法论

- **总体框架**：论文提出 **AdaMM**（Adaptive Multi-view Memory）框架，由两个互补的记忆子系统组成：
  - **分析记忆**（Analytic Memory）：通过数据驱动的结构归纳，将重复出现的多模态观测物化为可查询的表结构，支持过滤、聚合、排序、时间比较等操作。
  - **检索记忆**（Retrieval Memory）：采用 topic → episode → event 的三级层次结构组织开放事件、关系和视觉细节，支持灵活的语义检索。

- **分析记忆构建的三步流程**：
  1. **属性提取（Attribute Extraction）**：对每个交互回合，使用基于LLM的提取器联合分析对话和视觉内容，提取带来源的属性-值对应关系，形式化为 $O_t = \{(a_t^\ell, x_t^\ell, p_t^\ell)\}$，其中 $a_t^\ell$ 是属性，$x_t^\ell$ 是值，$p_t^\ell$ 指向支撑证据。
  2. **模式归纳（Schema Induction）**：分三个子过程：
     - **候选模式挖掘**：基于Apriori框架，使用支持度 $supp_t(C)$ 衡量属性集的共现频率，超过阈值 $\theta_s$ 的候选集被保留；
     - **模式发现**：使用 all-confidence 指标 $\text{all-conf}_t(C) = \frac{supp_t(C)}{\max_{a \in C} supp_t(\{a\})}$ 衡量模式内部共现一致性，超过阈值 $\theta_a$ 且是包含最大化的候选集被接纳为新模式；
     - **模式演化**：对于已有模式 $A$ 的扩展候选 $C \supset A$，使用扩展置信度 $\text{ext-conf}_t(C|A) = \frac{supp_t(C)}{supp_t(A)}$ 判断新增属性是否已成为稳定组成部分。
  3. **记忆物化（Memory Materialization）**：将每个模式 $A$ 物化为关系表 $T_A$，属性即列，匹配的交互即行，并附加 `order` 和 `time` 两个辅助列记录来源交互的位置和发生时间。

- **自适应查询处理**：
  - **记忆访问工具**：为分析记忆设计 LOOKUP、FILTER、COMPUTE、RANK 等工具，为检索记忆设计 SEMANTIC MATCH、EVENT LOCATE 等工具。每个工具以 $(d_i, \Theta_i, \Omega_i)$ 形式定义，包含功能描述、类型化参数和返回模式。
  - **规划上下文构建**：将分析表元数据（名称、描述、列、采样值）和检索片段描述作为候选，使用混合相似度评分 $h_\lambda(q, \mu) = \lambda \cos(E(q), E(\mu)) + (1-\lambda) \text{TokSim}(q, \mu)$ 检索相关记忆元数据，与工具描述一起构成规划上下文 $D_q$。
  - **渐进式工具执行规划**：先生成高层计划 $\bar{\pi}(q, D_q) = \{(g_\ell, \xi_\ell)\}_{\ell=1}^L$（信息目标 + 工具类型），再逐步实例化工具参数 $\Theta_\ell = \text{Planner}(q, g_\ell, \xi_\ell, D_q, Z_{<\ell})$，使后续工具调用可以利用前面步骤的中间结果。
