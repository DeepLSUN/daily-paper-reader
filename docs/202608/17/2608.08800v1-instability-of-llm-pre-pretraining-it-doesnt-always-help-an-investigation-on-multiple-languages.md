## 摘要
在人工语言上预训练大语言模型（“预预训练”）是一种据称能将标记效率提高33%的技术，即节省达到特定性能所需训练标记的33%。我们在更大范围的自然语言上验证了这一先前结果，涵盖四个语系，使用两种不同的分词器和不同模型规模。我们还将观察到的标记效率增益（或损失）与语言的量化语言属性相关联，如句子长度、形态丰富度以及依存句法树的特征（树深度、子节点数量、交叉依存数量）。我们的实证结果表明，所报告的增益在很大程度上取决于实验设置和随机种子的选择，尽管我们可以确认，对于大多数被检查的语言，使用Llama分词器对小型模型进行128-Dyck预训练的趋势是稳定增益的。总体而言，我们主张至少应对一部分实验进行多次训练运行，以避免社区采用不稳定的方法。

## Abstract
Pretraining LLMs on artificial languages ("pre-pretraining") is a technique that could reportedly increase token efficiency by 33%, i.e., save up to 33% of training tokens needed to reach a certain performance. We validate this prior result for English on a larger set of natural languages across four language families, using two different tokenizers and varying model sizes. We also relate the observed gains (or losses) in token efficiency to quantified linguistic properties of the languages, such as sentence length, morphological richness, and features of dependency syntactic trees (tree depth, number of children, number of crossing dependencies). Our empirical results indicate that the reported gains depend heavily on the experiment setup and the choice of random seed, although we can confirm the trend of stable gains with 128-Dyck pretraining of small models with the Llama tokenizer for most of the examined languages. On a general note, we argue that multiple training runs should be carried out at least for a subset of experiments to avoid the community adopting unstable approaches.

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：在自然语言训练之前，先用人工语言（formal languages）对模型进行额外预训练，以注入特定的句法结构偏置（如嵌套依赖或扁平的交叉依赖），再在目标自然语言上继续训练，比较其 token 效率增益。
- **人工语言设计**（关键技术细节）：
  - **k-Dyck**：包含 k 种类型嵌套依赖的括号语言，结构严格嵌套，例如 `( [ { } ] )`。
  - **k-Shuffle Dyck**：允许打破嵌套性，包含扁平依赖和交叉串行依赖，例如 `( [ ] { ) }`。
  - 括号符号用非负整数表示：若开符号为 n，对应闭符号为 n+k（0 ≤ n < k）。例如 k=128 时，配对为 ("81", "209")。
  - 设置 k=64 和 k=128 两种规模。
- **模型设置**：基于 Llama 3 架构，调整隐藏层数、注意力头数、隐藏维度等得到 3 种配置（154M、308M、481M 参数级别），每种配置配备 Llama 或 Gemma 分词器，共 6 种模型。
  - 分词器的关键差异：**Llama 分词器**将数字如 "81 209" 保留为独立词元 `['81', '˙G', '209']`；**Gemma 分词器**则将数字拆分为单个数字 `['8', '1', '_', '2', '0', '9']`。
- **训练流程**：
  1. 预预训练阶段：16,000 条 Dyck 序列（每条 2,048 token），即 500 训练步（batch size=32）。
  2. 自然语言训练阶段：320,000 条序列（各约 2,048 token），即 10,000 训练步（batch size=32）。
  3. 三种处理方式：无预训练（Base）、k-Dyck 预训练、k-Shuffle Dyck 预训练。
- **Token 效率增益计算**（Algorithm 1，文字描述）：
  - 以 Base 模型最终验证损失为目标损失。
  - 若预训练模型所有验证损失都未低于目标损失，则递归计算反向增益（即损失）。
  - 若预训练模型最终损失 ≤ 目标损失，则找到其验证损失首次持续低于目标损失的训练步 k（即从第 k 步起所有后续验证损失均不高于目标损失）。
  - 增益 = (1 − (预训练模型达到目标损失所用总 token 数) / (Base 模型总 token 数)) × 100%。
  - 总 token 数包括预预训练阶段与自然语言训练阶段所用 token；若增益为负，表示预训练反而有害，比 Base 更晚达到目标损失。

### 6. 论文的主要结论与发现

- **预预训练并非普遍有效**：所报告的收益高度依赖实验设置，包括人工语言类型、分词器选择、模型规模，甚至随机种子。同一种设置下，3 个不同种子的运行可能分别产生正增益、负增益或混合结果（图 3、图 12）。
- **英语上的结果部分复现先前研究**：在最小的 154M 模型上，除 64-Shuffle Dyck 外，英语在多种预训练设置下均获得一致增益，支持 Hu et al. (2025) 对英语的结论（但无法复现其具体的 33% 增益数字）。
- **唯一稳定增益的设置**：154M+LT（Llama 分词器的小模型）预训练于 128-Dyck，在全部 6 种语言上均产生一致的 token 效率增益（图 4、表 3）。
- **分词器影响显著**：Llama 分词器的模型平均增益高于 Gemma 分词器模型；且 Llama 分词器下 k-Dyck 通常优于 k-Shuffle Dyck，而 Gemma 分词器下规律不明确。
- **预训练步数的影响**：额外实验（154M+GT + 64-Dyck + 捷克语）表明，预训练 1,000 步可能优于 500 或 2,000 步，暗示存在最优预训练量，但该结论仅来自单一设置。
- **语言属性相关性微弱**：对 20 余种语言特征的分析显示，仅 154M+GT 模型表现出跨运行和跨预训练语言均稳定的统计显著相关性（与平均子节点数、平均困惑度、平均句长正相关；与形态丰富度、词汇量、最大子节点数负相关）。**与形式语言结构对齐假设不符的关键发现**：未检测到 k-Shuffle Dyck 预训练增益与自然语言交叉依赖百分比之间的显著正相关，否定了“Shuffle Dyck 预训练有助于含交叉依赖语言”的直观假设。
- **方法论建议**：研究强调多次重复实验的必要性，避免基于单次运行结果采纳不稳定的训练方法。

### 7. 优点

- **问题选择具有重要现实意义**：直接检验了社区广泛引用的结论（33% token 节省）的稳健性，具有较高的可复现性价值和方法论警示意义。
- **多维度系统验证**：同时改变自然语言、人工语言类型、人工语言深度（k 值）、分词器、模型规模和随机种子，覆盖面广。
- **严谨的随机种子控制**：所有设置均进行 3 次不同种子的重复，能够清晰展示方差问题，这种实践在 LLM 训练研究中值得推广。
- **跨语言视角新颖**：是少数将预预训练从英语扩展到多个语系自然语言的研究，讨论了不同语言类型（形态丰富度、依存结构等）对预训练效果的影响。
- **透明的不利结果报告**：诚实报告了负面和混合结果，并展示大量负增益数据（附录表 6），避免了选择性报告偏差。
- **细致的消融实验**：除主要实验矩阵外，专门对预训练步数进行了额外消融，探索了训练动态的非单调性。

### 8. 不足与局限

- **语言覆盖范围有限**：6 种语言均属欧洲语言（阿尔巴尼亚语、捷克语、丹麦语、荷兰语、芬兰语、英语），全部使用拉丁文字，未覆盖非拉丁文字（如阿拉伯文、天城文、汉字）、声调语言或语序差异更大的语言（如日语、土耳其语、中文等）。作者也承认此局限，无法将结论推广至所有语言。
- **模型规模偏小且训练不足**：模型规模仅达 481M-884M，token-to-parameter 比远低于 Chinchilla 最优值，属于“欠训练”模型。预预训练在大规模、训练充分模型上的表现尚不明确。
- **数据集多样性受限**：每种语言仅使用一种混合比例（8:1:1）的多领域语料，且评估仅基于 mC4 验证集的前 2,000 行，未测试不同语料构成或更大评估集的影响。
- **统计功效不足**：仅 3 个种子的重复次数对于检测小效应或进行稳健的统计推断仍然偏少；语言属性相关性分析仅在 6 个语言数据点上进行，统计检验力有限。
- **未充分探索超参数空间**：学习率、batch size、warmup 步数等超参数未进行系统搜索；这些超参数与预预训练之间的交互效应未知。
- **人工语言与实际语言的对应关系模糊**：论文未能建立人工语言结构属性（嵌套 vs. 交叉依赖）与自然语言句法属性之间的明确联系，核心假设（Shuffle Dyck 对交叉依赖语言更有用）未获支持，但缺乏对原因的深入分析。
- **缺乏结构分析**：虽然分析了 token 效率增益，但未深入分析预训练如何改变模型的内部表征（如探测实验、电路分析等），难以解释增益或不稳定的机制来源。
- **训练预算有限**：10,000 步训练虽在损失曲线上显示稳定，但更长训练（达到 Chinchilla 最优）下结论可能发生变化。
