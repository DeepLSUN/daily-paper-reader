## 摘要
基于大型语言模型（LLM）的多智能体系统（MAS）正在迅速 proliferate，但其异构执行轨迹为跨方法的评估提供了共同基础。仅基于结果的基准丢弃了协作信息，而LLM作为评审的评估需要额外的、依赖模型的推理，并可能随LLM和评分标准而变化。我们引入了一个可泛化的评估框架，将原生MAS轨迹映射到统一协作图的共享空间中，使得不同方法能够在相同的表示、参考集和指标面板下进行评估。候选图与查询特定的参考森林进行比较。每个森林都是基准提供的已验证成功图的集合：它记录了代表性MAS方法完成任务的多种方式，而不是规定唯一的最优过程。将该框架实例化为ForestBench，我们从七个公共数据集中筛选出844个需要协作的查询，为每个查询预计算十个成功的目标条件参考图，并评估六个代表性的MAS框架。受控的骨干、参考构建和扰动研究测试了评估的稳定性和范围。一旦基准森林构建完成，ForestBench可以在毫秒内对轨迹进行评分，无需进一步的LLM推理，为比较多样化的MAS协作轨迹提供了可重用的结构基础。

## Abstract
Multi-agent systems (MAS) built on Large Language Models (LLMs) are proliferating rapidly, but their heterogeneous execution traces provide no common basis for evaluation across methods. Outcome-only benchmarks discard collaborations, whereas LLM-as-Judge evaluation requires additional, model-dependent inference and can vary with the LLM and rubric. We introduce a generalizable evaluation framework that maps native MAS traces into a shared space of unified collaboration graphs, enabling different methods to be evaluated under the same representation, reference set, and metric panel. Candidate graphs are compared with a query-specific reference forest. Each forest is a benchmark-provided collection of verified-success graphs: it records diverse ways in which representative MAS methods can complete the task, rather than prescribing a unique optimal process. Instantiating the framework as ForestBench, we filter $844$ collaboration-necessary queries from seven public datasets, precompute ten successful target-conditioned reference graphs per query, and evaluate six representative MAS frameworks. Controlled backbone, reference-construction, and perturbation studies test the stability and scope of evaluation. Once the benchmark forests are built, ForestBench scores a trace in milliseconds without further LLM inference, providing a reusable structural basis for comparing diverse MAS collaboration traces.

# ForestBench 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：基于 LLM 的多智能体系统（MAS）在复杂推理、软件工程和科学工作流中快速普及，其核心价值在于通过多角色分工、信息交换和迭代校验实现超越单智能体的协作能力。大量新框架（固定流水线、动态角色分配、自组织群体）不断涌现。
- **核心问题**：MAS 框架的迭代速度远超评估能力：
  - **仅评估结果的基准**（如 GSM8K、MMLU、HumanEval）将完整执行过程压缩为一个最终答案，完全丢失了协作结构信息。
  - **过程感知评估受限**：不同框架的原生轨迹事件模式、角色词汇和通信协议异构，无法直接横向比较。
  - **LLM-as-Judge** 需要额外模型推断、成本高、可复现性差，且结果随模型和评分规则变化。
- **整体含义**：该领域缺少一个统一的、过程级别的、可复现的比较基础。作者主张用图结构作为自然表示，将异构执行轨迹映射到同一结构空间，从而在保持协作信息的同时实现确定性的横向比较。

## 2. 提出的方法论

### 核心思想
- 将 MAS 执行轨迹抽象为**有向无环协作图（DAG）**：节点为原子动作（agent_message、tool_call、decision），边表示信息流依赖，节点带角色标签。
- 提出**参考森林（reference forest）**：每个查询对应一个由多个“已验证成功”的参考图组成的集合，记录多种可成功完成任务的协作模式，而非规定唯一最优过程。
- 候选图与参考森林进行结构比较，得到确定性指标，评估过程无需额外 LLM 推理。

### 关键技术细节
1. **图抽象** \( G(\tau) = (V, E, \phi) \)：
   - 节点 = 原子动作；边 = 信息传递；\(\phi\) 标注智能体、规范角色、文本内容。
   - DAG 保证时间前向无环；丢弃运行状态与时钟交错，使不同框架轨迹可比较。
2. **参考森林构建**：
   - \( F(q) = \{(G_k, q_k)\} \)，每个 \(G_k\) 来自代表性 MAS 框架的验证成功轨迹。
   - 每个查询采样 10 个成功参考图，权重 \(q_k\) 综合正确性、结构简洁性和 token 成本。
3. **相似度公式**：
   \[
   \text{sim}(G, G') = \alpha s_{\text{node}} + \beta s_{\text{edge}} + \gamma s_{\text{topo}},\quad (\alpha,\beta,\gamma)=(0.4,0.4,0.2)
   \]
   - 节点相似度基于规范角色的多重集 Jaccard；边相似度基于角色类型化边指纹的 Jaccard；拓扑相似度基于节点/边数量比的加权平均。
4. **Forest Match 指标**：
   \[
   \text{FM}(G, F(q)) = \frac{\sum_k w_k \,\text{sim}(G, G_k)}{\sum_k w_k}
   \]
   - 另报告 **Best Similarity**（最近参考树相似度）。
5. **辅助指标**：
   - **Node Validity**：被下游消费的非终节点比例。
   - **Mean Uptake**：边两端文本语义相似度超过阈值的比例。
   - **Content Redundancy**：规范化后内容去重比例。
   - **Tokens** 与 **Efficiency**（并行度/智能体数）。

### 查询筛选流程（TSP）
- 对每个查询独立打分三个维度：
  - 深度 \(d \ge 5\)、宽度 \(w \ge 0.5\)（基于 8 项能力熵）、可分解性 \(\delta \ge 0.5\)。
- 只有三项同时满足才保留，最终得到 844 个“协作必要”查询。

### 评估的候选方法（6 个 MAS 框架）
- **Multi-agent Debate**、**Swarm**、**AutoGen**、**MetaGPT**、**MAS-GPT**、**AFlow**

### 主要对比实验类型
- **横向评估（RQ1）**：统一图表示下比较 6 个框架的准确性、Forest Match、Node Validity、Mean Uptake、Content Redundancy、Best Similarity、Tokens、Efficiency。

  - 使用不同骨干模型构建参考森林（DeepSeek、Claude、GPT），检验排序一致性。

## 6. 主要结论与发现

- **准确性无法区分方法，结构信号具有判别力**：
  - 六框架准确率仅差 0.038（0.531–0.569），而 Forest Match 从 0.316（Debate）到 0.421（MAS-GPT），方差更大。
  - Debate 准确率最高但 Forest Match 和 Best Similarity 最低，token 消耗最大；AFlow 内容冗余最高；Swarm 是唯一 Node Validity < 1 的框架。
- **参考森林具有稳定性**：
  - 跨骨干模型（DeepSeek/Claude/GPT）排序完全一致（Kendall τ = Spearman ρ = 1.00）。
  - 留一生成器和留一数据源实验中 Top-3 大多保持；无金条件化仅改变中间名次但 Top-3 不变。
- **指标行为符合预期**：
  - 结构扰动降低 Forest Match，节点删除影响最大（-0.058@p=0.5）；重复内容由 Content Redundancy 捕获而非结构指标。
  - 指标权重和 TSP 阈值在非退化范围内不影响排序（Kendall τ ≥ 0.73，阈值网格 τ = 1.00）。
- **失效模式可分结构/内容两类**：结构失效提示需要自适应角色/拓扑选择；内容失效提示需要更强验证/聚合机制。
- **编排收益取决于骨干能力**：更强骨干下 MAS 相对单智能体 CoT 的平均增益为负（GPT-5.5：-0.039，Claude-S4.6：-0.069）。
- **域特异性明显**：Debate 在 SWE-bench-V 上 Forest Match 最高（0.382），与其 review-and-revise 模式匹配；全局排序需配合按领域分析。
- **效率优势显著**：ForestBench 在线评估比 LLM-as-Judge 快约 2,900 倍，零推理 token。

## 7. 优点

- **统一表示创新**：用 DAG 图抽象解决了 MAS 轨迹异构问题，使不同框架可在同一结构空间比较。
- **森林而非单树作为参考**：保留多种成功协作模式，避免偏袒单一范式，兼顾多样性与可复现性。
- **确定性低成本评估**：参考森林预计算后可立即复用，评估无需额外 LLM 推理，毫秒级完成。
- **丰富而系统的消融**：覆盖骨干、参考生成器、金条件化、指标权重、阈值选择、扰动、源留一等多个角度验证稳健性。
- **可复用的基准资产**：发布 844 查询、8,440 参考图、适配器和指标面板，降低后续评估成本。
- **诊断价值**：将结构对齐与内容错误分离，提供可操作的修复方向（角色/拓扑调整 vs 验证/聚合增强）。
- **方法论适度谦逊**：明确区分参考相对对齐与“普遍质量”标签，避免过度声明。

## 8. 不足与局限

- **算力细节缺失**：未报告 GPU 型号、数量、训练/推理总时间等，硬件成本难以复现。
- **参考森林构建成本与固有偏差**：一次性 token 成本较高（20.5M）；参考图来自有限六个框架，不能覆盖所有有效协作模式，可能对未采样范式存在结构偏差。
- **评估范围相对窄**：
  - 查询依赖 TSP 启发式筛选，阈值设置无理论保证；
  - 数据集集中于英文文本任务，缺乏多模态、真实交互环境、长尾领域覆盖。
- **指标语义限制**：
  - Forest Match 依赖角色规范化质量，角色词汇差异可能导致失真；
  - Mean Uptake 的阈值固定，跨度较大场景可能不敏感；
  - 拓扑相似度忽略边的具体顺序和中间细节，粒度较粗。
- **失效诊断主观性**：LLM 标注的精细标签随评分规则变化（Cohen κ 低至 0.13–0.35），只有粗粒度方向稳定。
- **未讨论泄漏风险**：候选框架与参考生成器同源时虽用 LOO 处理，但不同版本同框架结构先验仍可能影响结果。
- **应用局限**：对需要实时反馈或需要解释性评分的场景，结构指标无法替代语义级评审；对完全新型协作模式（远超参考森林拓扑）的评估能力有限。
