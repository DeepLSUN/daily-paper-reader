## 摘要
文本技能为大型语言模型智能体提供了可复用的指导，但现有方法通常依赖于人工整理的技能库，或使用具有间接且延迟反馈的强化学习。我们提出SkillFM（Skill Flow Matching），一种生成式框架，可直接合成以任务为条件的文本技能，而无需在测试时进行技能检索。该框架将用于在连续潜在空间中编码和重建文本技能的编解码器，与使用改进MeanFlow训练的条件流模型相结合。在推理时，学习到的速度场支持单步潜在采样，基于LLM的解码器将采样得到的表示转换为文本指导，供冻结的下游智能体使用。我们在具身任务、问答和网络购物上评估了该框架。在ALFWorld和Search-QA上，我们的方法在比较的基于向量的技能方法中取得了最佳整体性能。我们的分析进一步表明，潜在技能生成是基于检索的技能增强的有效替代方案。我们的代码和训练技能库可在https://github.com/lulushang999/SkillFM获取。

## Abstract
Textual skills provide reusable guidance for large language model agents, but existing approaches often rely on manually curated skill banks or reinforcement learning with indirect and delayed feedback. We introduce SkillFM (Skill Flow Matching), a generative framework that synthesizes task-conditioned textual skills directly without test-time skill retrieval. Our framework combines a codec for encoding and reconstructing textual skills in a continuous latent space with a conditional flow model trained using improved MeanFlow. At inference time, the learned velocity field enables single-step latent sampling, and an LLM-based decoder converts the sampled representation into textual guidance for a frozen downstream agent. We evaluate the framework on embodied tasks, question answering, and web shopping. On ALFWorld and Search-QA, our method achieves the best overall performance among the compared vector-based skill approaches. Our analyses further demonstrate that latent skill generation is an effective alternative to retrieval-based skill augmentation. Our code and training skill libraries are available at https://github.com/lulushang999/SkillFM.

## 2. 论文提出的方法论

### 核心思想
- **SkillFM（Skill Flow Matching）**：一个任务条件化的文本技能生成框架。训练分两阶段：先训练技能编解码器（codec），再在其潜在空间中训练条件流模型（conditional flow）。推理时单步采样潜在码，经 LLM 解码器转为文本技能，指导冻结的下游执行器。

### 关键技术细节

**（1）技能库收集**
- 在训练任务上迭代执行与总结：执行器收集交互轨迹，总结器从成功尝试中提炼可复用流程；累积技能指导下一轮执行，直到成功率不再提升。
- 保留成功技能，用余弦相似度去除近似重复项，清洗摘要，形成固定的 (c, s) 训练对。ALFWorld 的技能对来自训练链，QA 与购物技能库还包含人工编写或修订的技能。

**（2）技能编解码器（Skill Codec）**
- 编码器 E_φ 只读取技能 s，输出单位球面上的潜在码 z ∈ R^d（d = 2560）。
- 投影器 P_ψ 将 z 映射为 K 个连续前缀嵌入（K = 16），供任务条件自回归解码器 D_ω 使用。
- 为让解码器接触邻近码，引入球面扰动增强分布 A(z)：`z̃ = cos(α)z + sin(α)v`，其中 v 是与 z 垂直的随机单位向量。
- 损失为教师强制重建：`L_codec = -E[Σ log p_ω(s_j | s_<j, P_ψ(z̃), c)]`，仅技能 token 与终止符计入损失，prompt/前缀/padding 位置被 mask。
- 训练投影器及编解码器 LoRA 适配器，冻结骨干权重。

**（3）条件流训练（Conditional Flow Training）**
- 冻结 codec 与独立的查询编码器；缩放码 `x = √d·E_φ(s)` 以匹配高斯噪声的 RMS 范数；q = E_query(c) 编码任务条件。
- 采样噪声 ε ~ N(0, I_d) 与时间 t ~ U(0,1)，构造插值 `x_t = (1-t)x + tε`（数据端点在 t=0，噪声端在 t=1），配对速度 `v_pair = ε - x`。
- 条件 Transformer `u_θ(x_t, r, t, q)` 预测区间 [r, t] 上的平均速度；采用改进 MeanFlow 目标：
  - 对角评估 `b_θ(x_t, t, q) = u_θ(x_t, t, t, q)` 提供瞬时速度估计；
  - 导数修正 `D_t u_θ = ∂_t u_θ + (J_{x_t} u_θ)b_θ`；
  - 复合预测 `V_θ = u_θ(x_t, r, t, q) + (t-r)·stopgrad(D_t u_θ)`；
  - 损失 `L_flow = E[w·||V_θ - v_pair||²₂]`，w 为自适应回归权重。
- 当 r = t 时修正项消失，退化为标准瞬时流匹配。

**（4）技能引导执行（推理）**
- 对新任务计算 q，单次流网络评估预测技能状态：`y_1 ~ N(0,I)`，`y_0 = y_1 - u_θ(y_1,0,1,q)`，`ẑ = y_0/||y_0||₂`。
- 冻结解码器由 P_ψ(ẑ) 与 c 贪心生成技能 ŝ；冻结执行器依据 `π_actor(· | c, ŝ, h_k)` 选择动作。
- 每个任务只生成一个技能，并在整个 rollout 中固定；**无测试时技能库查找**；NFE = 1（仅计流网络调用次数）。
