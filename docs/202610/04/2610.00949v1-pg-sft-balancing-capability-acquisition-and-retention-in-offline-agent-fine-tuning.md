## 摘要
对离线智能体轨迹进行监督微调（SFT）是训练专用工具使用智能体的标准方法，但迫使模型逐 token 模仿推理与动作可能损害基座模型的其他能力（例如通用推理、工具调用、代码生成）。本文聚焦于研究在智能体轨迹 SFT 过程中，如何更好地平衡获取新能力与保留已有能力之间的权衡。通过在我们的设置中比较若干基线，标准 SFT 提升了目标基准，却降低了若干非目标基准的分数；与此同时，仅通过 KL 惩罚约束分布漂移或限制更新幅度，并不能避免这种回退趋势。受近期 token 级自适应学习目标的启发，本文提出 Privilege-Guided SFT（PG-SFT），利用智能体轨迹的轮级信息增益作为指标来调整监督强度。PG-SFT 在评估基准上呈现出更有利的权衡：大幅减少分布漂移和广泛的能力退化，代价是目标任务性能略有下降。我们的发现表明，平衡获取—保持权衡不仅取决于模型是否锚定于其基座行为，还取决于监督应在何处以及以多强的程度偏离该行为。

## Abstract
Supervised fine-tuning (SFT) on offline agent trajectories is the standard approach for training specialized tool-using agents, but forcing models to imitate reasoning and actions token by token may harm other capabilities (e.g., general reasoning, tool calling, code generation) of the base model. In this work, we focus on studying \emph{how to better balance the trade-off between acquiring new capabilities and preserving existing ones during agent trace SFT}. By comparing several baselines in our setup, standard SFT improves the target benchmark while lowering several non-target benchmark scores; meanwhile, simply constraining distributional drift using KL penalty or limiting the update magnitude did not avoid this regression trend. Motivated by recent token-wise adaptive learning objectives, this work proposes \textbf{Privilege-Guided SFT (PG-SFT)} to leverage turn-level information gain of agent trajectories as an indicator to adjust supervision strength. PG-SFT yields a more favorable observed trade-off on the evaluated benchmarks, substantially reducing distributional drift and broad capability degradation at the cost of slight degradation in target-task performance. Our findings suggest that balancing the acquisition--retention trade-off depends not only on whether the model is anchored to its base behavior, but also on where and how strongly supervision should depart from that behavior.}

- **核心问题**：智能体轨迹 SFT 中，如何平衡“获取目标任务能力”与“保留基座模型已有能力”？标准 SFT 往往提升目标基准，却损害通用推理、工具调用、代码生成等非目标能力。
- **已有方法不足**：
  - 仅用 KL 惩罚约束分布漂移，或限制更新幅度，并不能可靠避免能力退化。
  - 现有自适应监督研究多集中在推理、数学等任务，智能体微调中的能力保持问题仍缺乏系统研究。
- **整体含义**：论文将后训练视为“学习—保持”联合问题，指出平衡关键不只是“是否锚定基座模型”，还包括“在何处、以多强程度偏离基座行为”。

## 2. 方法论：PG-SFT

### 2.1 核心思想

- **轮级监督分配**：智能体轨迹中，一个 assistant turn 同时包含推理与动作，是完整决策的最小单元。因此监督强度应按 turn 分配，而非按 token 统一分配。
- **特权信息作为训练时信号**：利用轨迹中“下一步动作”构造 hint，插入到当前 turn 之前，让同一个冻结基座模型分别在普通上下文和 hint 增强上下文下对相同目标 token 打分。
- **信息增益衡量“动作决定性”**：若知道下一步动作后，当前 turn 的目标 token 概率大幅提升，说明该 turn 的内容主要由动作决定，值得更强监督；若仍难以预测，则说明该 turn 高度特异，强制拟合可能损害基座分布。

### 2.2 关键技术细节

- 设冻结基座模型为 \(p_0\)，学生模型为 \(p_\theta\)。
- 对第 \(k\) 个 assistant turn 的监督 token 集合 \(T_k\)：
  - 普通上下文下目标 token 概率：\(b_t = q_{0,t}(y_t) = p_0(y_t \mid x_t)\)
  - hint 增强上下文下目标 token 概率：\(s_t = q_{+,t}(y_t) = p_0(y_t \mid x^+_t)\)
- 定义：
  - 正向增益：\(G_k = \sum_{t \in T_k} [s_t - b_t]_+\)
  - 可用概率空间：\(H_k = \sum_{t \in T_k} (1 - b_t)\)
  - turn 级学习系数：\(\alpha_k = G_k / H_k\)，若 \(H_k = 0\) 则 \(\alpha_k = 0\)
- \(\alpha_k \in [0,1]\)，同一 turn 内所有推理与动作 token 共享该系数。

### 2.3 训练目标

- 将目标分布构造为基座分布与 one-hot 示范 token 的插值：
  - \(r^{PG}_t(v) = (1 - \alpha_k) q_{0,t}(v) + \alpha_k \mathbb{1}[v = y_t]\)
- 使用全词表前向 KL 对学生模型进行训练：
  - \(\mathcal{L}_{PG-SFT}(\theta) = \frac{1}{N_B} \sum_i \sum_k \sum_{t \in T_k} D_{KL}(r^{PG}_t \| p_{\theta,t})\)
- 注意：目标分布**不蒸馏 hint 条件下的分布** \(q_{+,t}\)，hint 只用于测量“动作决定性”，不作为推理时可用信息。
- 与 Base-KL 的关系：
  - 若使用统一系数 \(\bar{\alpha} = \sum_k G_k / \sum_k H_k\)，则等价于 Base-KL 中 \(\lambda = (1-\bar{\alpha})/\bar{\alpha}\)。
  - PG-SFT 的关键在于 \(\alpha_k\) 随 turn 自适应，而非全局统一。

### 2.4 初步失败尝试

- 论文先尝试 token 级自适应方法 DFT：按 token 概率分配监督强度，概率越高监督越强。
- 结果：DFT 在 Qwen3.5 上仅解决 40 个 SWE-bench 问题，低于 Base 的 54 个。
- 原因分析：
  - 高概率 token 多为固定协议片段或可省略措辞，信息量低。
  - 低概率 token 混合了风格偏好与关键动作行为，按概率降权会抑制重要监督。
  - token 级信号与 turn 级决策不对齐。

## 6. 主要结论与发现

- **标准 SFT 的权衡**：
  - 提升目标 SWE-bench，但三个非目标基准全面回退。
  - Qwen3.5-4B：Macro Avg 55.87%，相对 Base 下降 4.74 pp。
  - Qwen3-4B-Thinking：Macro Avg 47.83%，下降 5.69 pp。
- **Base-KL 不能保证保持**：
  - 能显著降低分布漂移，例如 Qwen3.5 上 Base KL 从 0.0732 降到 0.0431。
  - 但非目标能力没有恢复，Macro Avg 仍下降。
- **PSFT 过于保守**：
  - 最接近基座分布，Base KL 最低。
  - 但目标任务学习不足，Qwen3 上甚至低于 Base。
- **PG-SFT 取得更优整体权衡**：
  - Qwen3.5-4B：SWE-bench 59/89，与 SFT 持平；非目标接近 Base；Macro Avg 62.10%，相对 Base +1.49 pp。
  - Qwen3-4B-Thinking：SWE-bench 27/89，低于 SFT 的 31/89；但非目标保持更强；Macro Avg 55.58%，相对 Base +2.07 pp。
  - PG-SFT 是唯一在两个 backbone 上 Macro Avg 均超过各自 Base 的微调目标。
- **离线学习信号**：
  - PG-SFT 的 NLL 优于 Base，但比 SFT 保守。
  - Base KL 显著低于 SFT 和 Base-KL。
- **轮级自适应不可被统一强度替代**：
  - 固定 \(\alpha=0.35\)
