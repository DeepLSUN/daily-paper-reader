## 摘要
使用一阶优化器微调大型语言模型（LLM）所需的内存是推理所需内存的数倍。内存高效的零阶优化（MeZO）仅通过前向传播估计梯度，从而规避了这一开销。然而，对于 BitNet 架构——一类具有三元 {-1,0,1} 权重和 8 位激活的 LLM——微调需要更新全精度潜权重，因此 MeZO 的内存占用不再与推理相匹配。一个有前景的解决方案是仅微调一部分潜权重，但现有稀疏零阶（ZO）方法要么忽略三元结构，要么需要一阶梯度信息来构建稀疏掩码，这与 ZO 微调的目的相矛盾。我们提出 TerMeZO，一种稀疏 MeZO 方案，它利用三元量化器本身的几何结构来识别在微调期间更可能改变值的潜权重，且不增加额外数据或内存开销。我们的收敛性分析表明，由于优化地降低了微调的有效维度，TerMeZO 可以比全参数 MeZO 收敛更快。我们在参数规模从 1B 到 3B 的 BitNet 模型上进行了大量实验，涵盖分类、指令遵循和数学推理任务。TerMeZO 在显著降低微调内存占用的同时，达到或超过全参数 MeZO 的性能。

## Abstract
Fine-tuning anguage models (LLMs) with first-order optimizers requires a memory several times larger than that required for inference. Memory-efficient zeroth-order optimization (MeZO) sidesteps this cost by estimating gradients from forward passes only. However, for BitNet architectures, a family of LLMs with ternary {-1,0,1\} weights and 8-bit activations, fine-tuning requires updating full-precision latent weights, and thus the memory footprint of MeZO no longer matches that of inference. A promising solution is to finetune only a subset of the latent weights, but existing sparse zeroth-order (ZO) methods either ignore the ternary structure or require first-order gradient information to build a sparse mask, which is at odds with the purpose of ZO fine-tuning. We propose TerMeZO, a sparse MeZO scheme that exploits the geometry of the ternary quantizer itself to identify the latent weights that are more likely to change values during fine-tuning, at no additional data or memory cost. Our convergence analysis shows that TerMeZO can converge faster than full-parameter MeZO, owing to its optimized reduction of the fine-tuning effective dimension. We run extensive experiments on BitNet models ranging from 1B to 3B parameters, spanning classification, instruction-following, and mathematical reasoning tasks. TerMeZO matches or exceeds the performance of full-parameter MeZO while substantially reducing the fine-tuning memory footprint.

# TerMeZO 论文中文总结

## 1. 核心问题与整体含义

- **背景**：在资源受限的边缘设备上部署 LLM 已成为实际需求，但现代 LLM 的内存、算力与能耗远超此类平台所能承受。极端量化（尤其是 BitNet 系列，采用三元 {-1,0,1} 权重与 8 位激活）是绕开该瓶颈的最有前景路径，其推理时可将大部分矩阵乘法替换为整数加法，显著缩小内存占用。
- **核心矛盾**：BitNet 模型微调时需维护**全精度潜权重（latent weights）**，在前向传播时即时量化。因此，即便使用内存高效的零阶优化器 MeZO（仅靠前向传播估计梯度，无需反向传播），仍需扰动并更新每一个潜权重，导致微调内存不再与推理内存持平。
- **现有方案的不足**：
  - **PEFT 方法**（如 LoRA）虽减少可训练参数，但仍依赖反向传播，保留了激活与梯度开销。
  - **FIM-S-MeZO** 需用一阶梯度信息构建稀疏掩码，本身需要 BP，部分抵消了 ZO 的内存优势。
  - **S-MeZO** 按权重幅值选择稀疏工作集，忽略了三元决策边界。
  - **QZO** 冻结整数权重、仅调量化尺度，在需要获取新知识的较难任务上过于受限。
- **论文含义**：提出 TerMeZO，一种**无需一阶梯度、无额外数据/内存开销**的稀疏 MeZO 方案，专为 BitNet 模型设计，使边缘端微调的内存占用接近推理水平。

## 2. 方法论

### 2.1 核心思想
- 利用**三元量化器本身的几何结构**识别更可能在微调中改变取值的潜权重：距离量化边界越近的权重对扰动越敏感，越可能翻转其三值；远离边界的权重在三元空间中实际上被冻结。
- 仅对边界附近的稀疏子集执行扰动与更新，同时更新 BitNet 中的全精度参数（嵌入、归一化层、LM head）。

### 2.2 关键技术细节
- **三元量化**：潜权重 $\tilde{w}_\ell = Q(w_\ell)$，其中 $Q(x) = 1$ 若 $x > \tau_\ell$；$Q(x) = -1$ 若 $x < -\tau_\ell$；否则为 0。阈值 $\tau_\ell = 0.5(\gamma_\ell + \delta)$，$\gamma_\ell$ 为平均绝对值，$\delta$ 为数值稳定小常数。
- **边界距离度量**：$d^\ell_{i,t}(w^\ell_t) = \min(|[w^\ell_t]_i - \tau^\ell_t|,\ |[w^\ell_t]_i + \tau^\ell_t|)$。
- **初始稀疏集**：给定目标比例 $\rho_0$，取所有潜权重距离的 $\rho_0$ 分位数 $\xi_0$，选择 $S^\ell_0 = \{i : d^\ell_{i,0}(w^\ell_0) \leq \xi_0\}$。该步骤可离线完成，复杂度与潜权重数成线性。
- **掩码收缩机制**：迭代中仅保留先前活跃且仍位于边界带内的索引，$S^\ell_t = \{i \in S^\ell_{t-1} : d^\ell_{i,t}(w^\ell_t) \leq \xi_0\}$，因此活跃权重比例非增且上界为 $\rho_0$；一旦权重漂移出带外即永久冻结。
- **ZO 更新**：对掩码后的潜权重 $w_t = m_t \odot w_t$ 与全精度参数 $\theta_t$ 施加 $K$ 个高斯扰动，采用双侧 SPSA 估计器，共享小批量 $B_t$，将有限差分对 $K$ 个扰动方向求平均后更新参数。
- **收敛分析**（定理 1）：在四个假设（损失有界、Lipschitz/光滑性、掩码对齐、小批量方差）下，得到时间平均梯度范数上界：
  - 主项 $\frac{2L_{\max}\Delta_0}{c^2 T}$，余项 $O(\epsilon^2 p^2 + \bar{N} + \sigma_B^2 + L_{\max}\bar{\sigma}_w^2)$。
  - 当无量化时退化为标准 MeZO 的 $O(p/T)$ 速率；当初始掩码规模 $k_0 \gg p$ 时，速率为 $O(\sqrt{k_0}/(\epsilon^2 T))$，由活跃潜权重数 $k_0$ 主导。
  - 取 $\epsilon^2 = 1/\sqrt{k_0}$ 可复现稀疏 MeZO 的 $O(k/T)$ 速率，且对应扰动尺度 $\epsilon \in [3\times10^{-3}, 10^{-2}]$，与实际常用量级一致。
- **内存分析**：$M_{\text{TerMeZO}} = M_{\text{MeZO}} - \lceil d(1-\rho_0)(B - B_Q)\rceil + \lceil\rho_0 d B_Q\rceil + M_{\text{mask}}$，其中 $B$ 为全精度字节数，$B_Q$ 为打包三元权重字节数，掩码可取稠密位掩码或活跃索引列表。

### 2.3 算法流程（文字说明）
1. 预训练模型上计算各层阈值与全部潜权重的边界距离，确定 $\xi_0$ 与初始稀疏集 $S^\ell_0$（可离线）。
2. 每次迭代：更新阈值 $\tau^\ell_t$，按式 (5) 收缩稀疏集，生成掩码 $m_t$。
3. 采样小批量，对 $K$ 个扰动分别做正向两次评估，计算投影梯度 $g^{(k)}$。
4. 用相同种子重绘扰动，按 $g^{(k)}$ 加权更新潜权重与全精度参数。
5. 返回最终的 $w_T, \theta_T$。

## 6. 主要结论与发现

- TerMeZO 在多数分类任务上与全参数 MeZO 持平，在部分任务（如 RTE、CoPA、MultiRC）上超过 MeZO。
- 在 GSM8K 与 MagiCoder 上，TerMeZO 显著优于基座模型并紧跟全参数 MeZO；QZO 在此类较难任务上明显落后，说明仅调量化尺度不足。
- S-MeZO（min/max 幅值）因忽略量化器几何而大幅落后。
- FIM-S-MeZO 性能与 TerMeZO 相当，但需额外一阶梯度步骤，内存开销接近 BP；TerMeZO 对学习率更鲁棒（FIM-S-MeZO 在 $\eta=5\times10^{-4}$ 时发散）。
- 内存方面：$\rho_0=0.05$ 时 TerMeZO 相比 MeZO 减少约 3×，$\rho_0=0.01$ 时减少约 4×，接近推理内存。
- RL 任务（Countdown）上 TerMeZO 超过全参数 MeZO 且收敛更快。
- 收敛分析证明 TerMeZO 可通过降低有效维度实现比全参数 MeZO 更快的收敛。

## 7. 优点

- **方法创新性**：首次利用三元量化器几何（边界距离）构建稀疏掩码，无需一阶梯度、无需额外数据或内存，契合 ZO 微调的初衷。
- **理论支撑**：提供了完整的收敛分析，证明其收敛速率可优于全参数 MeZO，并与稀疏 MeZO 的已有速率建立联系。
- **内存效率显著**：内存占用接近推理水平，使边缘设备微调更大模型成为可能（如 3B TerMeZO 超越 1B BP）。
- **工程可行性**：掩码选择仅需对潜权重线性扫描，可离线完成；掩码单调收缩保证活跃集有界。
- **实验扎实**：覆盖多任务、多模型、多基线，包含梯度幅值与掩码重叠率的实证验证（图 1），以及学习率鲁棒性和 QuZO 对比等补充实验。
- **可扩展性**：方法与方差缩减、曲率感知、激活引导等 ZO 改进正交，可组合使用；也自然扩展到 RL/ES 微调。

## 8. 不足与局限

- **硬件依赖**：高效实现 TerMeZO 需要自定义、硬件相关的内核才能真正实现内存节省，论文仅在 GPU 上验证，未在真实边缘硬件上测试。
- **模型规模受限**：由于开源大型 BitNet 模型有限，仅评估 1B–3B，未验证更大规模的可扩展性。
- **RL 验证有限**：RL 场景仅 Countdown 一个任务。
- **与 FIM-S-MeZO 的关系**：在部分任务上 FIM-S-MeZO 性能相当甚至略优，但代价是需一阶梯度；论文未探索两者选择准则的结合。
- **未涉及 KV 缓存**：未评估线性注意力/混合注意力模型，未联合处理 KV 缓存内存瓶颈。

- **超参数敏感性**：稀疏比例 $\rho_0$、扰动尺度 $\epsilon$ 等超参的影响未做系统性消融。
