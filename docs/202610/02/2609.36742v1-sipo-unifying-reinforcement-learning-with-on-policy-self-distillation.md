## 摘要
基于可验证奖励的强化学习（RLVR）已成为提升大语言模型（LLMs）在各种任务上表现的标准范式，但其稀疏的结果奖励缺乏对中间步骤的 token 级信用分配。为解决这一问题，同策略自蒸馏（OPSD）利用具有特权上下文的自教师来提供额外的稠密学习信号。然而，由于自教师往往过度自信，并对长推理轨迹施加过度惩罚，OPSD 在实践中经常难以奏效。为缓解这一问题，我们提出自指导策略优化（SIPO），采用对比式自教师来提供稠密信用。在每次迭代中，SIPO 从当前策略对每个提示采样多条 rollout，用环境奖励对其进行评分，并通过将参考答案与该组内所犯错误配对，为每条 rollout 构建两个教师上下文。然后，模型在两个上下文下重新评估自身回答，并将两个教师对数概率之差作为 token 级反馈，从而期望两个上下文共有的偏差能在很大程度上相互抵消。由此得到的目标为每条 rollout 产生 token 级优势：奖励仍决定每次更新的主要方向，而自教师则在 token 之间重新分配信用。即使在所有 rollout 都失败、组相对优势消失的组中，SIPO 仍能提供学习信号。通过保留对任务奖励的直接优化，同时提供稠密的 token 级反馈，该方法在强化学习与同策略自蒸馏之间架起桥梁。在多个推理与代码生成基准上的大量实验表明，SIPO 无需外部教师或额外生成，即优于 RLVR 和 OPSD 基线。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) has become a standard paradigm for improving large language models (LLMs) on various tasks, yet its sparse outcome rewards lack token-level credit assignment for intermediate steps. To address this, on-policy self-distillation (OPSD) leverages a self-teacher with privileged context to provide additional dense learning signals. However, because the self-teacher is often overconfident and imposes excessive penalties on long reasoning trajectories, OPSD frequently struggles in practice. To mitigate this, we propose self-instructing policy optimization (SIPO) with a contrastive self-teacher to provide dense credit. At each iteration, SIPO samples multiple rollouts per prompt from the current policy, scores them with environment rewards, and constructs two teacher contexts for each rollout by pairing the reference answer with mistakes made within the group. The model then re-evaluates its own responses under both contexts, using the difference between the two teacher log-probabilities as token-level feedback, so that biases shared by both contexts are expected to largely cancel. The resulting objective yields a token-level advantage for every rollout: the reward still sets the main direction of each update while the self-teacher redistributes credit across tokens. Even in groups where every rollout fails and group-relative advantages vanish, SIPO still provides a learning signal. By preserving direct optimization of the task reward while providing dense, token-level feedback, this approach bridges reinforcement learning and on-policy self-distillation. Extensive experiments across multiple reasoning and code-generation benchmarks demonstrate that SIPO outperforms both RLVR and OPSD baselines without an external teacher or additional generation.

# SIPO 论文深度总结

## 1. 核心问题与研究背景

- **RLVR 的范式地位与瓶颈**：基于可验证奖励的强化学习（RLVR）已成为提升 LLM 推理能力的标准范式（如 GRPO 通过组内 rollout 统计替代 critic）。但其根本缺陷是**结果奖励稀疏**——整条轨迹只得到一个标量奖励，无法做 token 级信用分配，模型难以识别哪些中间推理步骤促成了成功或失败。
- **稀疏性的极端表现**：在难题上，当一个提示组内所有 rollout 全部失败时，组相对优势归零，该提示完全不产生学习信号，采样算力被浪费。作者实测：Qwen3-8B 在 DAPO-Math-17k 上训练时，全失败组在训练早期占 20–30%，训练末期仍约 10%。
- **已有解法及其局限**：
  - **OPD（同策略蒸馏）**：用外部更强教师对学生自身 rollout 打分，提供稠密 token 级监督，但需要外部教师，且只最小化散度而非直接优化任务奖励，学生上限被教师能力封顶。
  - **OPSD（同策略自蒸馏）**：让模型自身以特权信息（如标准答案）为条件充当教师。但该自教师**过度自信**，对长推理轨迹施加过度惩罚，导致在数学等长推理任务上训练崩塌（奖励、熵、回答长度持续下降，梯度范数上升）。
- **论文含义**：SIPO 试图在**奖励驱动的策略梯度**与**同策略自蒸馏**之间架桥，用单一 token 级优势统一二者，兼顾任务奖励的直接优化与稠密信用分配，且**无需外部教师、无需额外生成**。

## 2. 方法论

### 核心思想
- 保留 GRPO 的策略梯度目标（奖励决定更新方向），但把其**均匀的序列级优势**替换为由**对比式自教师**产生的 token 级优势，实现细粒度信用重分配。
- 关键洞察：单个答案条件教师会偏好"直奔答案"的短续写，从而剪掉必要推理；若同时构造"正确答案上下文"与"错误答案上下文"，二者共享的偏差（如偏好短续写）**相互抵消**，剩余证据只反映"哪些 token 是正确/错误答案所特有"的。

### 关键技术细节
- **采样与评分**：沿用 GRPO 的组采样，对每个提示采样 G 条 rollout，用奖励函数给出二值奖励 $r_i \in \{0,1\}$，划分正确集 $S^+$ 与错误集 $S^-$。
- **构造两个教师上下文**（模板相同，仅特权信息不同）：
  - 正上下文 $x_i^+ = \text{augment}(x, a^\star)$，含参考答案 $a^\star$；
  - 负上下文 $x_i^- = \text{augment}(x, a_i^-)$，含错误答案 $a_i^-$。
  - 对**错误 rollout**，$a_i^-$ 是它自己的（经判定）错误答案；对**正确 rollout**，$a_i^-$ 取组内最常见的错误答案。因 $a_i^-$ 依赖该 rollout 自身结果，属**事后重标注（hindsight relabeling）**。
  - **无参考答案时**（如代码生成以单元测试判定）：正/负上下文改为组内**成功的兄弟 rollout** 与**失败的兄弟 rollout**（科学 QA 在两者都存在时也用此配对）。
  - 截断或无有效判定答案的错误 rollout **不给教师项**，以免与它并未犯的错误对比。
- **教师重评分**：教师参数 $\bar\theta$ 是策略的周期快照（每 K 步同步），仅在两个增广提示下**重新评估同一段回答 token**，不重新生成，因此只增加两次前向传播。
- **对比证据**：
  $$e_{i,t} = \text{sg}\big[\log \pi_T(y_{i,t}\mid x_i^+, y_{i,<t}) - \log \pi_T(y_{i,t}\mid x_i^-, y_{i,<t})\big]$$
  正值表示该 token 在"看到正确答案"时更可能，负值反之。
- **SIPO 目标**：损失形式与 GRPO/OPD 相同，只是优势变为
  $$A_{i,t} = \hat A_i + \kappa \cdot \text{clip}(e_{i,t}, -\delta, \delta)$$
  其中 $\hat A_i = r_i - \mu$（按 Dr. GRPO 去掉标准差），$\delta=0.2$，$\kappa \in \{0.1, 0.2, 0.5\}$；无对比对的 rollout 令 $e_{i,t}=0$。
- **方向保持**：二值奖励下最小非零 $|\hat A_i| = 1/G$；只要 $\kappa\delta < 1/G$，教师项无法翻转优势符号，奖励仍主导更新方向。作者另加**保号投影** $\Pi_{\hat A}$ 作为保险（在均匀失败组 $\hat A_i=0$ 时不改变符号，故其优势仍取证据符号）。
- **全失败组仍可学习**：$\hat A_i = 0$ 时 $A_{i,t} = \kappa\cdot\text{clip}(e_{i,t})$，这些被 GRPO 丢弃的 rollout 仍获得 token 级信号。且负上下文来自策略自身当前所犯错误，监督随训练迭代自适应演化。

## 6. 主要结论与发现

- **数学**：SIPO 平均 59.4，超过 GRPO 2.1%、RLSD 2.7%；在竞赛级难题上优势保持（AIME24 56.8 vs. GRPO 54.9；AIME25 41.4 vs. 40.3）。SDPO 仅提升基座 4.1%，是唯一在全部 6 个 benchmark 上都超过 GRPO 的自蒸馏方法。
- **科学 QA / 工具调用**：SIPO 平均 70.4，较 SDPO +1.3%、RLSD +7.0%、GRPO +7.7%；10 个设置中 6 个最优。Olmo3-7B 上同样领先（平均 66.5）。训练效率显著：1h SIPO 常可匹敌基线 5h（如 Chemistry 76.9@1h > GRPO 63.4@5h 与 RLSD 74.6@5h）。
- **代码生成（无参考答案）**：LCBv6 从 27.9 提升到 56.3，超过 RLSD（55.4）、SDPO、GRPO 与 self-teacher SFT；holdout 平均 42.7 接近基座 43.5，遗忘最少（SFT 反而降至 41.4）。此时全失败组无对比信号，增益来自混合组。
- **机制性发现**：
  - 单教师蒸馏在长推理上崩溃：SDPO 的奖励、熵、回答长度持续下降（回答短于 1000 token），梯度范数上升；解析 KL 变体在数学上仅得 42.6，比 GRPO 低 14.7%，但在短回答的科学 QA 上仍有竞争力（71.2）——说明该失败**特定于长推理**。
  - 单教师证据中位数近零但均值持续为负（−0.002 到 −0.004）并随训练增大，表明存在被重罚的 token 长尾；对比证据则围绕零波动（|均值| < 0.001），无一致符号。
  - RLSD 在教师权重衰减到零（第 50 步）前几乎停滞，之后退化为 GRPO；说明"重加权优势"会拖慢长轨迹学习。
  - **对比才是关键**：把 RLSD 的单教师证据换成对比证据（且教师权重可全程保持 0.5）平均从 56.7 升至 58.3；再加入全失败组信号升至 59.4。
  - 教师设计：仅用错误作特权上下文（SIPO-M）上限更低、熵停滞；actor 与教师共享权重（SIPO-OP）灾难性失败（奖励停在初值、熵崩塌为零），故**独立教师快照是必需的**。

## 7. 优点

- **方法简洁且即插即用**：仅修改优势项（$A_{i,t} = \hat A_i + \kappa\cdot\text{clip}(e)$），可作为 GRPO 的直接替代，无需外部教师、无需额外采样，只增加两次前向传播。
- **解决真实痛点**：显式针对"全失败组无学习信号"这一 RLVR 样本效率漏洞，使原本被丢弃的算力重新产生梯度。
- **对比设计有原理支撑**：利用正/负上下文共享偏差相消来缓解自教师过度自信，理论直觉清晰，并有证据统计（均值/中位数）与长短推理对比实验佐证。
- **保留奖励主导性**：通过 $\kappa\delta < 1/G$ 与保号投影，保证教师项不会反转奖励设定的更新方向，训练更稳定。
- **动态且自适应的监督**：负上下文来自策略当前所犯错误，监督信号随策略改进而演化。
- **实验较全面且公平意识强**：四域覆盖、双基座、含 off-policy GRPO 对照与多项消融，并复用了既有工作的数据与评测协议。
- **泛化友好**：holdout 上遗忘最少（仅 −0.8%），优于 SFT 与其他 RL 基线。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号/数量/总训练开销，"可比算力预算"缺乏可核验的量化支撑；墙钟时间受硬件与实现影响，横向可比性有限。
- **报告口径偏乐观**：多处以"最佳 checkpoint""1h/5h 最佳"汇报，缺少多次随机种子与方差/置信区间，存在选择性偏差风险。
- **超参敏感且未充分探索**：$\kappa \in \{0.1,0.2,0.5\}$ 需调参，$\delta$ 固定为 0.2；教师同步周期 K=10 等关键设计未做系统性敏感性分析。
- **场景覆盖有限**：
  - 无参考答案时（代码生成）全失败组无法获得对比信号，论文也承认增益仅来自混合组，参考解或执行反馈可能进一步提升——说明方法对"存在可对比的正/负样本"有结构性依赖。
  - 未涉及多轮 agent、多模态、长上下文等更复杂场景；工具调用等短回答任务上的优势（相对 SDPO）有限。
- **对教师快照的依赖**：SIPO-OP 的失败表明方法要求 actor 与教师结构性分离，这引入了额外的显存/计算开销（需维护快照权重），文中未量化该开销。
- **奖励假设受限**：核心的符号保持论证依赖**二值奖励**（最小非零 $|\hat A_i| = 1/G$）；对连续/稠密奖励的适用性未讨论。
- **潜在偏差风险**：负上下文使用"组内最常见错误答案"或"自身错误答案"，可能强化模型已有的高频错误模式；截断回答被直接跳过，可能使训练数据分布偏向较短/格式规范的输出。
- **与并行工作差异有限**：与 CEPO、RLCSD 等对比式自蒸馏工作思路相近，主要增量在于"全失败组也提供信号"与"奖励主导方向"两点，边际新颖性需更细致的对照实验支撑。
