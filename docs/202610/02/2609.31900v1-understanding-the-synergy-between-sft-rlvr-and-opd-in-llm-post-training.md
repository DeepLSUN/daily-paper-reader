## 摘要
现代 LLM 后训练将监督微调（SFT）、可验证奖励强化学习（RLVR）与同策略蒸馏（OPD）组合成多阶段流程，但这些阶段通常被孤立地设计和评估。我们表明，这种组合会产生重要影响：一个能提升当前模型性能的阶段，可能会降低下一阶段的有效性。通过对 Qwen3 模型在数学与科学推理上的受控实验，我们首先在九个参数比从 2 倍到 53 倍不等的学生-教师模型对上刻画了 OPD，并表明 OPD 的有效性取决于学生与教师之间的兼容性，而不仅仅是教师规模。OPD 的周边阶段会以三种方式重塑这种兼容性：（1）简短的 SFT 预热能改善后续 OPD，而经过 RLVR 强化的学生模型在从同一教师蒸馏时反而出现性能退化。（2）用 RLVR 适配教师模型会提升下游 OPD 准确率，提升幅度与其所增加的能力成正比。在上述两种干预之后，我们发现，仅结合教师适配与学生预热，就能在相同的蒸馏步数下将平均 OPD 准确率从 29.2% 提升到 43.8%（相对提升 50%），并伴随额外的预备训练。（3）在准确率相当的情况下，OPD 为下游 RLVR 留下的初始化比 SFT 更强，且这一差距会随着 RL 计算规模的扩大而增大。我们的结果表明，选择每个后训练阶段时，不仅应关注其带来的能力提升，还应关注它为下一阶段所创造的学习接口。

## Abstract
Modern LLM post-training composes supervised fine-tuning (SFT), reinforcement learning with verifiable rewards (RLVR), and on-policy distillation (OPD) into multi-stage pipelines, yet these stages are typically designed and evaluated in isolation. We show that this composition is consequential: a stage that improves the current model can make the next stage less effective. Through controlled experiments with Qwen3 models on math and science reasoning, we first characterize OPD across nine student-teacher pairs spanning 2x to 53x parameter ratios and show that OPD effectiveness depends on student-teacher compatibility rather than teacher scale alone. The surrounding stages of OPD reshape this compatibility in three ways: (1) A brief SFT warm-up improves subsequent OPD, while an RLVR-strengthened student regresses under distillation from the same teacher. (2) Adapting the teacher with RLVR raises downstream OPD accuracy in proportion to the capability it adds. Following these two interventions, we find that combining teacher adaptation and student warm-up alone raise average OPD accuracy from 29.2\% to 43.8\% (50\% relative improvement) after the same number of distillation steps, with additional preparatory training. (3) At comparable accuracy, OPD leaves a stronger initialization for downstream RLVR than SFT, with a gap that widens as RL compute scales. Our results suggest that each post-training stage should be chosen not only for the capability it adds, but for the learning interface it creates for the next stage.

## 1. 核心问题与研究动机

- **背景**：现代 LLM 后训练普遍将三类目标组合成多阶段流水线——监督微调（SFT，固定专家轨迹上的稠密监督）、可验证奖励强化学习（RLVR，学生自生成轨迹上的稀疏结果监督）、同策略蒸馏（OPD，学生自生成轨迹上的稠密教师监督）。
- **核心问题（composition problem）**：这些阶段通常被孤立地设计与评估，但阶段之间会相互重塑策略。作者指出，**一个能提升当前模型的阶段，可能同时降低下一阶段的有效性**，因此顺序、时长与交接点不能视为任意选择。
- **关键概念**：提出"**学习接口（learning interface）**"——一个阶段不仅贡献能力增益，还为下一阶段创造了特定的学习状态/数据分布，评价阶段时应同时考察这两者。
- **整体含义**：作者将后训练阶段视为对"学习状态"的变换而非独立能力来源，并用非交换性 `U_B(U_A(π)) ≠ U_A(U_B(π))` 概括这种顺序依赖。

## 2. 方法论

### 2.1 核心思想
采用**严格控制变量实验**：每次只改变学生状态、教师状态或阶段顺序中的一项，其余数据、优化配置、评估协议全部固定，从而隔离单个阶段对后续阶段的影响。

### 2.2 三个后训练目标（文字化公式）
- **SFT**：最小化固定轨迹上的 token 级交叉熵，off-policy、稠密监督。
- **RLVR**：用 GRPO，对每个 prompt 采样 G 条回答，按组内归一化优势 `Â = (r − μ_group)/σ_group`，奖励为二元可验证结果，on-policy、稀疏监督。
- **OPD**：在学生自采样轨迹上做 token 级 reverse-KL 匹配，默认用采样 token 的策略梯度估计器，教师优势 `A_t = sg[log π_T(y_t|h_t) − log π_Sold(y_t|h_t)]`，配合与 RLVR 相同的裁剪重要性比目标；`A_t>0` 表示强化教师更偏好的 token，`A_t<0` 仅抑制而不指定替代项。附录中还评估了 dense top-k forward-KL 目标（k∈{16,32,64}）作为稳健性检验。

### 2.3 三个迁移度量
- **蒸馏有效性 DE** = (A_S′ − A_S)/(A_T − A_S)，即恢复的师生准确率差距比例。
- **可强化比例 ρ⁺₀**：初始化时学生采样 token 中获得教师正信号的比例，刻画师生兼容性（单次打分即可得到，无需训练）。
- **归一化 reverse KL κ_s**：在训练过程中追踪学生采样状态上的师生距离。

### 2.4 组合配方
教师 RLVR 适配 → 学生简短 SFT 预热 → OPD 蒸馏 → 交给下游 RLVR；OPD 应在任务性能峰值处交接，而非等到教师匹配收敛。

## 6. 主要结论与发现

- **观察 3.1–3.3（OPD 独立特性）**：更大的教师并不稳定带来更好迁移；最优教师随学生规模、家族、目标、数据而变化；ρ⁺₀ 随教师规模下降，且能识别 scalar reverse KL 无法区分的有效师生配对；reverse KL 持续下降并不代表任务准确率提升。
- **观察 4.1–4.3（学生预热）**：SFT 与 RLVR 都能提升学生，但效果截然不同——简短 SFT 预热把 OPD 从 33.6% 提到 35.4% 并消除回退；RLVR 预热学生起点高达 38.5%（距教师仅 3.6 分）却在 OPD 后跌至 28.4%。**能力 ≠ 可蒸馏性**；SFT 收益在 K≈75–150 后饱和，首个验证损失平台可作实用停止信号。
- **观察 4.4–4.5（教师适配）**：RLVR 适配教师把学生准确率从 18.9% 提到 38.5–43.7%（对照 off-the-shelf 教师 33.6%）；STaR 式 SFT 教师几乎不提升教师本身，下游学生也相应不变——**只有真实能力增益才可迁移**；学生增益约稳定为教师增益的固定比例（DE≈60%），教师 RLVR 平台后学生增益同步停止。
- **观察 4.6–4.8（阶段排序）**：在起点准确率相当甚至 SFT 略优的情况下，260 步 RLVR 后所有 OPD 初始化运行（38.5–43.1%）均优于所有 SFT 初始化运行（33.4–36.8%），且差距随 RL 算力扩大；**聚合熵不能解释该优势**；OPD 峰值 checkpoint（step 50）也是最佳 RLVR 交接点，继续 OPD 会同时损害当前模型与后续 RL 潜力。
- **组合结果**：教师适配 + 学生预热把 200 步 OPD 平均准确率从 29.2% 提升到 43.8%（相对 +50%），但两者增益不可加（分别 +13.0 与 +6.1，合计 +14.6）。
- **递归案例**：固定使用最终教师无法持续提升（准确率 19.5%→16.6%），progressive 教师刷新是唯一跨轮改进的调度；但七项 benchmark 上最佳递归结果仍低于单阶段 OPD 0.9 分。

## 7. 优点

- **控制变量严谨**：在每个比较内部固定数据、优化器、评估协议与 prompt 顺序，能较干净地归因单阶段影响。
- **提出新诊断量 ρ⁺₀**：仅需一次打分、无需训练，能捕捉 scalar divergence（reverse KL）无法区分的师生兼容性，且在实际网格中选出最优教师（step 260 三种学生零后悔）。
- **跨维度稳健性**：覆盖 2×–53× 参数比、两个模型家族、base/instruct/post-trained 状态、两种蒸馏目标、两种训练数据、10 项 benchmark。
- **诚实报告负面结果**：附录 G.3 明确列出"最大化预热后能力""延长每阶段训练""递归复用最强教师"三种失败尝试，对实践者有直接警示价值。
- **实用指导明确**：给出可操作的配方（RLVR 适配教师 → 简短 SFT 预热 → 峰值处交接 OPD → RLVR），并以验证损失平台、任务准确率峰值作为停止信号。
- **可复现承诺**：声明将发布训练/评估代码、数据准备脚本、配置、日志与图表复现脚本。

## 8. 不足与局限

- **组合研究覆盖窄于 OPD 缩放研究**：核心组合结论主要基于 Qwen3-4B 学生 + Qwen3-14B 教师这一对配置，作者自述不主张该顺序对任意模型/领域最优。
- **控制实验分离的是流程而非机制**：RLVR 与 STaR 对照中教师准确率不同步，因此只能证明"RLVR 是更有效的教师准备方法"，无法证明"匹配教师准确率下 RLVR 诱导的能力更可迁移"。
- **诊断量是预测性而非解释性**：ρ⁺₀ 与熵能排除简单标量解释，但未揭示下游可学习性的完整机制。
- **统计强度有限**：除 4B 主网格 3 seeds 外，多数比较为单次运行；递归案例每调度仅 1 次运行，且未匹配总算力。
- **递归案例存在混淆**：递归运行触及 8,192 token 响应上限导致轨迹截断，单阶段 OPD 参照无此饱和，因此无法确立递归优于单阶段。
- **算力披露不完整**：未报告总 GPU 小时
