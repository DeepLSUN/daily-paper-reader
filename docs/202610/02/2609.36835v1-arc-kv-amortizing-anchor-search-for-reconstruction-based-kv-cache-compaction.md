## 摘要
长上下文大语言模型推理受制于随序列长度线性增长的 KV 缓存。对于长且可复用的上下文前缀，这一负担尤为严重，因为其缓存必须服务于许多下游查询。诸如 Attention Matching 等基于重建的方法能够以紧凑的 KV 缓存取得很强的下游任务性能。然而，迭代式锚点搜索主导了基于 OMP 的 Attention Matching 的压缩成本。这促使我们提出选择性摊销原则：学习跨上下文可复用的锚点选择策略，同时保留上下文特定的重建。在这项工作中，我们提出 ARC-KV，一种遵循该原则的新型基于重建的 KV 缓存压缩方法。为此，我们首先训练一个值感知索引器，以在单次评分过程中选择真实键锚点。然后，ARC-KV 应用凸包约束的键合并，并针对完整缓存拟合注意力质量偏置和紧凑值。在推理时，ARC-KV 使用冻结的索引器为每个上下文构建一次紧凑缓存，并将其复用于所有后续查询。大量实验表明，在 Llama-3.1-8B-Instruct 上的 QuALITY、RULER 和 LongBench 中，ARC-KV 在大多数设置下优于已报道的压缩方法。特别地，在 QuALITY 上保留 10% KV 时，ARC-KV 相较于 Attention Matching 将准确率从 0.6409 提升至 0.6474，同时将压缩时间缩短为原来的 1/25.73，从 959.8 秒降至 37.3 秒。

## Abstract
Long-context large language model inference is bottlenecked by KV caches that grow linearly with sequence length. This burden is especially severe for long, reusable context prefixes, whose cache must serve many downstream queries. Reconstruction-based methods such as Attention Matching achieve strong downstream task performance with compact KV caches. However, iterative anchor search dominates the compaction cost of OMP-based Attention Matching. This motivates our selective amortization principle of learning a reusable anchor-selection policy across contexts while retaining context-specific reconstruction. In this work, we propose ARC-KV, a novel reconstruction-based KV cache compaction method that follows this principle. To this end, we first train a value-aware indexer to select real-key anchors in a single scoring pass. ARC-KV then applies convex-hull-constrained key merging and fits an attention-mass bias and compact values against the full cache. At inference time, ARC-KV builds the compact cache once per context using the frozen indexer and reuses it for all subsequent queries. Extensive experiments demonstrate that ARC-KV outperforms reported compaction methods in most settings across QuALITY, RULER, and LongBench on Llama-3.1-8B-Instruct. In particular, at 10% KV retention on QuALITY, ARC-KV improves accuracy from 0.6409 to 0.6474 over Attention Matching while reducing compaction time by a factor of 25.73, from 959.8 s to 37.3 s.

## 一、核心问题与整体含义

- **背景瓶颈**：长上下文大语言模型（LLM）推理的核心瓶颈是 KV 缓存随序列长度线性增长。以 LLaMA-65B 为例，128K token 序列在 FP16 下仅 KV 缓存就需约 320GB 内存，严重拖累服务吞吐与延迟。
- **场景特殊性**：对于**长且可复用的上下文前缀**（如系统日志、代码库、长文档），同一份缓存需服务大量下游查询，压缩收益被反复放大，因此尤为重要。
- **现有方法谱系**：
  - 规则式 token 驱逐（StreamingLLM、H2O、SnapKV）——永久丢弃 token，造成不可逆信息损失；
  - 学习式驱逐（KVP、LKV）——训练轻量选择器，但仍为硬子集保留；
  - 缓存重建（Cartridges、Attention Matching、Still）——将缓存重建为紧凑形式，保真度更高。其中 **Attention Matching（AM）** 表现最强，但其 **OMP 迭代锚点搜索**成为压缩成本主导项（64K 上下文下 OMP-fast 单阶段需 15.36 小时，而其他阶段最多 1.17 分钟）。
- **核心洞察（选择性摊销原则）**：锚点发现与缓存重建具有不同的泛化需求——**选择策略可跨上下文学习可复用先验**，而**重建必须针对当前上下文直接拟合**。因此应摊销锚点搜索，保留上下文特定重建。

## 二、方法论

### 2.1 问题形式化

- 给定缓存 $K, V \in \mathbb{R}^{T \times d}$、预算 $t$、保留率 $\rho = t/T$，求锚点集 $S$ 及紧凑表示 $(C_k, \beta, C_v)$。
- 紧凑注意力算子：$\hat{O}(Q; C_k, \beta, C_v) = \text{softmax}(QC_k^\top + \mathbf{1}_n\beta^\top)C_v$。
- **关键约束**：不仅需匹配局部归一化输出，还需拟合未归一化注意力质量 $Z_K(q) \approx Z_C(q;\beta)$，以在与未压缩 KV 块共同参与注意力时保持竞争关系。

### 2.2 四阶段流水线

1. **参考查询池构建**：沿用 KVzip/AM 的 repeat-prefill——先预填充上下文，再令模型逐字复述，保留每个位置的投影前激活 $x_i$ 与 post-RoPE 查询 $q_i$，形成 $D_{ref}$。被压缩的 KV 均来自原始上下文预填充。
2. **值感知索引器（单次打分选锚）**：
   - 扩展 DeepSeek Sparse Attention 索引器，增加**一个辅助值注意力头**，使每个位置同时由 $k_j$ 和 $v_j$ 表示；
   - 对参考查询归一化后按 **RMS 池化**聚合（$\pi_{i,j}$ 归一化，$s_j = \sqrt{\frac{1}{n}\sum_i \pi_{i,j}^2}$），保留对部分查询重要但整体分数不高的位置；
   - $S = \text{TopK}_j(s_j, t)$，每上下文/层-KV头只选一次，供所有后续查询复用。
3. **凸包约束键合并**：
   - 以**归一化注意力响应剖面** $u_j$ 的相似度做硬分配，将每个非锚键归到最相似的锚点组 $G_r$；
   - 以查询平均未归一化注意力质量 $\phi_j$ 为权重求组质心 $\mu_r$；
   - 锚点向质心移动：$c_{k,r} = (1-\lambda_m)k_{s_r} + \lambda_m \mu_r$，因 $s_r \in G_r$，故 $c_{k,r}$ 始终落在该组真实键的凸包内，避免外推。
4. **闭式拟合**：固定 $C_k$ 后，用投影最小二乘求非负质量权重 $w^\star$ 并令 $\beta^\star = \log w^\star$；再用岭回归拟合 $C_v^\star$（沿用 AM 的闭式校准，不引入新参数）。

### 2.3 索引器训练（无 OMP 标签）

- **自监督信号**：以冻结基座模型的全注意力行为为监督，不使用 OMP 生成的锚点标签。
- **三路划分**：每个训练上下文采样互不相交的 $D_{score}$、$D_{fit}$、$D_{holdout}$，分别用于打分、拟合、评估留出输出，确保评估查询未参与前两步。
- **硬前向 + 软代理反向（STE）**：前向用真实 top-$t$ 锚点评估 $L_{out}^h$；反向因 top-$t$ 不可微，在候选集 $C=\text{TopK}(s, 2t)$ 上用 sigmoid 门控 $g_j$ 软化边界、加 $\log g$ 到注意力偏置，并做可微岭回归求 $C_v^s$；损失 $\mathcal{L}_{out}^{STE} = \text{sg}(L_{out}^h) + L_{out}^s - \text{sg}(L_{out}^s)$。
- **KL 预热 + 联合目标**：先以 $\mathcal{L}_{KL}$ 匹配逐查询键分布（10 epoch），再联合训练 $\mathcal{L} = \lambda_{out}\mathcal{L}_{out}^{STE} + \lambda_{KL}\mathcal{L}_{KL}$（$(\lambda_{out}, \lambda_{KL})=(2,1)$，5 epoch），温度从 1.0 退火至 0.1。基座模型全程冻结，仅更新索引器参数。
