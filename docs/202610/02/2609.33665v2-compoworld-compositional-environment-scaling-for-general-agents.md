## 摘要
自动生成的环境为训练通用智能体提供了可扩展的交互数据来源。然而，现有方法主要是在单一环境内生成任务，而现实世界的工作流要求智能体跨多个服务连接信息和动作。我们提出了组合式环境扩展（Compositional Environment Scaling，CompoWorld），它通过组合一个由可复用服务构成的有限库来扩展任务空间。编码智能体将工具规范转化为经过验证、具有带类型状态和共享接口的服务，而世界模型则处理无法可靠实现的工具。随机游走过程通过依赖图连接服务，从而能够生成并验证需要信息跨服务流动的任务。验证后的轨迹支持监督微调（SFT），而我们的聚焦完成度评分标准奖励（Completion-Focused Rubric Reward）通过强调每个 rollout 组内通过率较低的标准，引导强化学习（RL）朝向完整任务完成。我们构建了 448 个服务，暴露 10,130 个工具，并使用 3K 条 SFT 轨迹和 1K 个 RL 任务来训练 Qwen3.6-35B-A3B。实验结果表明，CompoWorld 在八个基准上平均比其主干模型提升 9.17 分。在 AutomationBench 上，它超越了 Claude Opus 4.6 等前沿模型，并在所有比较的智能体专用 35B-A3B 模型中领先。

## Abstract
Automatically generated environments provide a scalable source of interaction data for training general agents. However, existing approaches mainly generate tasks within a single environment, while real-world workflows require agents to connect information and actions across multiple services. We introduce Compositional Environment Scaling (\textbf{CompoWorld}), which expands the task space by composing a finite library of reusable services. Coding agents turn tool specifications into verified services with typed states and shared interfaces, while a world model handles tools that cannot be reliably implemented. A random-walk procedure connects services through dependency graphs, enabling the generation and verification of tasks that require information to flow across services. Verified trajectories support supervised fine-tuning (SFT), while our Completion-Focused Rubric Reward guides reinforcement learning (RL) toward full task completion by emphasizing criteria with lower pass rates within each rollout group. We construct 448 services exposing 10,130 tools and use 3K SFT trajectories and 1K RL tasks to train Qwen3.6-35B-A3B. Experimental results show that CompoWorld improves on its backbone by 9.17 points on average across eight benchmarks. On AutomationBench, it surpasses frontier models such as Claude Opus 4.6 and leads all compared agent-specialized 35B-A3B models.

# CompoWorld 论文总结

## 1. 核心问题与整体含义

- **研究动机**：自动生成的环境是训练通用智能体的可扩展交互数据来源，但现有方法（如 AgentScaler、ScaleEnv、Agent-World）主要在**单一环境内**生成任务，而真实工作流要求智能体跨多个服务连接信息与动作（如查询 Snowflake 数据库、查阅 PDF 手册、发邮件通知）。
- **核心问题**：环境扩展不应只扩大环境数量，更应扩展**环境之间的依赖关系**。如何构建可复用、可重组的服务库，并生成需要跨服务信息流动的可验证任务，是训练通用智能体的关键。
- **整体含义**：论文提出 **Compositional Environment Scaling（组合式环境扩展）**，把服务组合本身作为环境扩展的可控维度，将环境构建与组合泛化（compositional generalization）问题联系起来，目标是让智能体把对单个服务的知识迁移到全新工作流中。

## 2. 方法论

### 2.1 形式化建模
- 每个环境建模为**无任务特定奖励函数的 POMDP**：\(E_i = (S_i, A_i, T_i, \Omega_i, O_i)\)，成功由终端验证器判定，而非每步奖励。
- **组合环境**为乘积环境 \(E_C = \bigotimes_{E_i \in C} E_i\)，联合状态空间 \(S_C = \prod S_i\)，动作空间带命名空间 \(A_C = \bigcup \{(i,a)\}\)。
- 组合保留每个环境的局部动态与观察函数，动作 \((i,a)\) 只更新 \(E_i\)，信息通过智能体的观察与后续动作在服务间传递。

### 2.2 服务构建（Agent Environment Generation）
- **Typed Environment Modeling**：爬取并归一化 MCP 工具规格，编码智能体用 Pydantic 推断服务实体与状态模型，将每个工具实现为对当前状态的操作，返回统一 JSON 格式。
- **Agentic Synthesis and Verification**：在 pi harness 隔离沙箱中生成状态模型、工具实现与测试套件，迭代执行修复；随后由独立会话从工具规格派生**对抗性测试用例**，未通过者被隔离。
- **Selective World-Model Simulation**：对无法可靠确定性实现的工具（依赖外部系统或超出能力），用 LLM 世界模型预测输出对 \((s'_i, o)\)，并通过同一套 Pydantic 模型实例化，保证类型有效。
- **语料规模**：448 个服务、10,130 个工具，覆盖 13 个领域，最大领域（Dev & DevOps）占 22%，无单一领域超过四分之一。

### 2.3 跨环境任务生成与验证
- 任务表示为 \(x = (u, s_0, G, g, v)\)：指令、初始联合状态、服务级依赖图、可达参考目标、验证器。
- **组合与难度控制**：采样 K 个服务形成乘积环境；用**环境游走** \((E_{i_1}, \dots, E_{i_L})\) 构造依赖图，约束为覆盖全部选中服务、避免连续访问同一服务、至少重访一次且 \(L > K\)。主要难度控制为游走长度 L，辅以领域和 K。
- **四阶段智能体生成**：EXPLORE（探索工具与状态格式）→ DESIGN（构造场景、初始状态、指令与 rubric）→ PROBE（实际执行游走求解，得到参考目标 g，验证器必须接受参考解 \(s_0 \xrightarrow{\rho}_{E_C} s_H = g,\ v(s_H)=1\)）→ SUBMIT（定稿）。
- 验证器只检查任务相关条件，允许不同工具序列与无关状态字段差异。

### 2.4 训练与奖励
- **SFT**：使用验证成功的轨迹初始化策略。
- **Completion-Focused Rubric Reward**：对每个任务采样 N 条轨迹，设 \(b_{ij} \in \{0,1\}\) 表示轨迹 i 是否满足标准 j，组内通过率 \(p_j = \frac{1}{N}\sum_i b_{ij}\)，权重 \(w_j = \lambda + (1-p_j)\)，奖励 \(R_i = \frac{\sum_j w_j b_{ij}}{\sum_j w_j}\)。通过率越低的标准权重越大，\(\lambda > 0\) 保留正权重。
- **策略优化**：使用 GRPO，优势 \(\hat{A}_{i,t} = (R_i - \bar{R})/(\sigma_R + \delta)\)，同一轨迹所有智能体生成 token 共享优势；工具观察进入上下文但不计入损失。
- **梯度解释（附录 A）**：在更新原点，策略梯度可写为 \(\nabla_\theta \hat{J}_{\text{policy}} = \frac{1}{\sigma_R+\delta}\sum_j \alpha_j g_j\)，其中 \(\alpha_j \propto \lambda + (1-p_j)\)，因此 \(p_j < p_k \Rightarrow \alpha_j/\alpha_k > 1\)，即未可靠满足的要求获得更大梯度权重。
