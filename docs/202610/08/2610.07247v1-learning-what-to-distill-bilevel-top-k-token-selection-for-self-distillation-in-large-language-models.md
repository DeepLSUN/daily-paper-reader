## 摘要
大语言模型已展现出强大的推理能力，但其高昂的推理成本使得知识蒸馏成为在资源受限场景下将此类能力迁移到紧凑模型的重要方法。在线策略自蒸馏进一步减少了对大型外部教师模型的依赖，同时提升了紧凑语言模型的推理能力。然而，现有方法通常要么对所有词元位置均匀蒸馏，要么使用固定的启发式准则选择词元，并对所选位置赋予相同的蒸馏强度，而不是自适应地学习哪些词元最有利于蒸馏。为解决这些局限，我们提出BiToK-SD（用于自蒸馏的双层Top-K词元选择），一种基于双层优化的词元选择方法，能够在在线策略自蒸馏过程中学习应在何处施加蒸馏。具体而言，BiToK-SD被形式化为一个双层优化问题，其中下层问题将Top-K词元选择建模为可微的基于阈值的松弛，使所选位置能够随着学生策略的演化而自适应调整，而上层问题则在所选位置上执行知识蒸馏。数学推理基准上的实验表明，BiToK-SD在所有对比方法中取得了最佳平均性能，同时仅需轻量级的额外计算。

## Abstract
Large language models have shown strong reasoning capabilities, but their high inference costs make knowledge distillation an important approach for transferring such capabilities to compact models in resource-constrained scenarios. On-policy self-distillation further reduces the reliance on external large teacher models while improving the reasoning ability of compact language models. However, existing methods typically either distill all token positions uniformly or select tokens using fixed heuristic criteria, assigning the same distillation strength to the selected positions rather than adaptively learning which tokens are most beneficial for distillation. To address these limitations, we propose BiToK-SD (Bilevel Top-K Token Selection for Self-Distillation), a bilevel-optimization-based token selection method that learns where distillation should be applied during on-policy self-distillation. Specifically, BiToK-SD is formulated as a bilevel optimization problem, where the lower-level problem models Top-K token selection as a differentiable threshold-based relaxation, allowing the selected positions to adapt as the student policy evolves, while the upper-level problem performs knowledge distillation on the selected positions. Experiments on mathematical reasoning benchmarks show that BiToK-SD achieves the best average performance among all compared methods while requiring only lightweight additional computation.

# 论文总结：BiToK-SD——面向大语言模型自蒸馏的双层Top-K词元选择

## 1. 核心问题与整体含义

- **背景**：大语言模型（LLM）在复杂推理任务上表现优异，但模型规模大、推理成本高，难以部署到资源受限场景。知识蒸馏（KD）是将强模型能力迁移到紧凑模型的主流手段。
- **现有蒸馏范式的演进**：
  - 离线策略（off-policy）KD 依赖固定的教师输出或离线轨迹，存在分布不匹配问题；
  - 在线策略（on-policy）KD 从学生自身 rollout 构造监督信号，更贴合学生分布；
  - 自蒸馏（SD）进一步去除对外部大教师的依赖，代表性方法如 OPSD，由同一模型同时充当教师与学生。
- **核心痛点**：现有方法（含 OPSD、TIP 等）要么**对所有词元位置均匀蒸馏**，要么基于**固定启发式准则**（如词元熵、师生散度、Soft-OR 分数）选词元，且对选中位置赋予**相同蒸馏强度**（二元掩码）。这忽略了长思维链中词元的异质角色（探索、纠错、反思、答案推导等）。
- **关键研究问题**：不只是"是否需要选词元"，而是**如何学习自适应的词元级权重**，同时决定选中位置及其蒸馏强度。
- **挑战**：Top-K 选择本质是离散、不可微的，需要借助双层优化与可微松弛技术。

## 2. 方法论：BiToK-SD

### 2.1 核心思想
将 Top-K 词元选择建模为一个**双层优化问题**：
- **下层**：将 Top-K 选择松弛为可微的阈值优化，使选中位置随学生策略演化自适应调整；
- **上层**：仅在选中位置执行知识蒸馏，且权重连续可变（非二元掩码）。

### 2.2 关键技术细节

**（1）词元级自蒸馏信号**（沿用 OPSD 设定）
- 学生策略生成轨迹，得到 T_i = L_i − 1 个蒸馏位置；
- 每个位置的损失为反馈条件化自教师分布与学生分布之间的**全词表 KL 散度**（教师→学生）：
  - ℓ_pos(t;θ) = KL(p_T,t ‖ p_S,t)

**（2）词元效用分数**
- 默认使用 **Soft-OR 分数**：u = ĥ + d̂ − ĥ·d̂
  - h = 学生熵，d = 反向 KL 散度，帽号表示在 mini-batch 内做 min–max 归一化；
- 分数每步随学生策略演化重新计算，方法不绑定于此特定分数。

**（3）可微阈值松弛**
- 目标 Top-K 数量 K_B = max(1, ⌈k·M_B⌉)，其中 M_B 为 mini-batch 内有效非 padding 位置数；
- 硬 Top-K 选择器不可微且等权重，故松弛为：
  - ρ̂_B ≈ arg min_ρ Ψ_B(ρ;u)，其中
  - Ψ_B = K_B + εM_B/ρ + (τ₂/2)ρ² + τ₁ Σ log(1+exp((u−ρ)/τ₁))
  - τ₁ 控制 softplus 平滑度，τ₂ 稳定阈值优化，ε 避免边界歧义；
- 实际用**warm-started 动量梯度更新**近似 ρ̂_B，并在计算软掩码前 detach。

**（4）软选择掩码**
- z̃ = σ((u − ρ̂_B)/τ_m) · 1((i,t)∈Ω_B)，τ_m 控制掩码锐度；
- 与硬掩码不同，z̃ 连续，对不同词元赋予不同强度。

**（5）加权自蒸馏损失（双层形式）**
- min_θ L(θ;ρ̂_B) s.t. ρ̂_B ≈ arg min_ρ Ψ_B(ρ;u)
- L = Σ z̃·ℓ_pos / (Σ z̃ + δ)，等价于归一化权重 w̄ = z̃/(Σz̃+δ)；
- 词元权重作为**stop-gradient 系数**，但效用与阈值随策略演化动态更新，故强调位置与有效权重在整个训练中动态变化。

## 3. 实验设计

### 3.1 数据集与场景
- **训练数据**：OpenThoughts 的数学推理子集（约 30K 问题–解答对，含 CoT 轨迹）；
- **主评测基准**：AIME24、AIME25、HMMT25，thinking 模式下报告 **Avg@64**（每题 64 次采样平均准确率，降低方差）；
- **额外泛化实验（离线 KD）**：FineWeb 的 80M token 子集，Qwen3-8B → Qwen3-1.7B；评测 ARC-Easy、GSM8K、HellaSwag、PIQA、LAMBADA（Avg. Acc.）、IFEval、LAMBADA PPL。

### 3.2 对比方法
- **主实验**：SFT、GRPO（RL 基线）、OPSD（在线自蒸馏最强基线）、TIP（用相同 Soft-OR 分数 + 硬 Top-50% 掩码 + 反向 KL）；
- **离线 KD 实验**：Full-KD（全位置蒸馏）、SE-KD（基于学生熵选位置）、SE-KD 3X（沿类别与样本轴额外选择）。

### 3.3 模型与配置
- 三个规模：Qwen3-1.7B / 4B / 8B，同规模下所有方法从相同 checkpoint 初始化、同数据训练；
- 训练 200 步，仅在最终 checkpoint 评测（避免基于测试集的 checkpoint 选择）；
- LoRA（r=64, α=128）作用于所有 attention 与 MLP 投影；
- BiToK-SD 默认 k=50%，τ₁=0.1, τ₂=0.01, τ_m=0.1, ε=δ=1e-6，内层求解步长 η=0.1、动量 γ=0.9。

## 6. 主要结论与发现

- **性能**：BiToK-SD 在三个规模上均取得最佳平均性能（41.48 / 62.07 / 64.85），9 个 scale–benchmark 单元中 7 个最优；相较最强基线 OPSD 分别提升 0.63、0.58、0.21 平均分。
- **基线表现**：SFT 在所有规模与基准上均**低于基座模型**，说明固定轨迹模仿在在线推理场景下效果有限；GRPO 在 1.7B 略有提升但随规模增大优势消失，且因组采样训练成本更高；TIP 在全部 9 个单元中均低于 OPSD。
- **探索行为**：BiToK-SD 在整个训练中保持最高的学生熵与最大的师生熵差（全体词元与选中词元上均如此），表明其不是强化教师模仿，而是**保留了更强的策略探索**。
- **反思行为**：BiToK-SD 生成更多 epistemic markers（wait、hmm、maybe 等），且软掩码对反思相关位置的权重是其它位置的 **1.63 倍**；同时生成长度更短（比 OPSD 少 3.7%/1.6%/4.8%）、重复 4-gram 比例与截断率更低，说明反思增加是**推理过程的重新分配**而非冗长退化。
- **稀疏性约束**：掩码密度稳定收敛于目标 k=50% 附近，未退化为过稀或过密。
- **超参鲁棒性**：Top-K 比例呈倒 U 形，k=50% 最优但全区间表现接近；Soft-OR 与 forward KL 优于 uniform，熵类分数与反向 KL 无增益；掩码温度敏感性低。
- **阈值动态**：ρ 在 1.7B 上先升后回落（均值 0.073±0.012），在 4B/8B 上持续上漂（均值 0.077±0.028 / 0.126±0.040），说明阈值确实随训练自适应变化。
- **离线 KD 泛化**：在仅有截断 top-64 教师分布、改用学生熵分数的条件下，BiToK-SD 仍在 Avg. Acc.、IFEval、PPL 三个指标上全面优于 Full-KD、SE-KD 与 SE-KD 3X。

## 7. 优点

- **问题定位精准**：指出现有选择性蒸馏的两个叠加缺陷（固定准则 + 二元等权），并提出"学习在哪里、以多强蒸馏"的完整框架，而非仅做词元筛选。
- **方法设计优雅**：用可微阈值松弛替代不可微 Top-K，同时自然产生连续权重，一举解决"离散性"与"等权重"两个问题；阈值通过内层优化自适应调整，与在线策略演化同步。
- **与既有工作兼容**：框架不绑定特定效用分数，可替换熵、KL、Soft-OR 等；也可迁移到离线 KD 场景。
- **分析深入**：不仅报告最终精度，还通过熵、熵差、epistemic markers、掩码权重比、掩码密度、生成长度/重复率等多维指标解释性能来源，并给出"反思行为增加 ≠ 冗长退化"的实证。
- **实验纪律性好**：统一初始化、统一数据、统一步数，明确拒绝测试集 checkpoint 选择，同规模下公平对比。
- **计算开销轻**：仅需内层阈值求解的轻量额外计算，未引入额外大模型或奖励模型。

## 8. 不足与局限
