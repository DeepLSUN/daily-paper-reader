## 摘要
大语言模型（LLM）已经彻底改变了人工智能研究，并催生了令人兴奋的智能体系统。为了构建复杂的LLM智能体系统，多数现有研究依赖其他领域的洞见或启发式方法人工构建智能体系统。然而，这种方法往往需要大量手工工程，并且无法针对所关注的下游任务实现充分优化。受深度学习巨大成功的启发，我们提出以模块化方式构建LLM智能体系统，类似于构建深度神经网络。我们的核心洞见在于，将LLM的构建模块（如检索、记忆和提示策略）与成功的深度学习模块（如MLP、注意力机制和循环模块）进行类比。我们进一步为LLM设计前向推理和反馈机制，其中LLM中的提示被视为深度模型中的权重，而基于反馈的提示优化则类似于反向传播算法。我们还利用搜索算法来搜索LLM智能体系统的最佳配置，类似于深度学习研究中的神经架构搜索（NAS）。全面的实验结果表明，所提出的面向LLM智能体系统的深度学习方案非常有效，具体而言：（1）将LLM模块组织成深度学习风格的架构可带来明显的性能提升；（2）自动提示优化（等价于反向传播）能够高效地纳入来自所关注任务的反馈，并至少实现5%的性能提升；（3）NAS等价算法可进一步优化LLM智能体系统架构，与随机设计的架构相比取得11%的性能提升。总体而言，我们的研究展示了将深度学习的成功迁移到构建LLM智能体系统这一令人兴奋的机遇。

## Abstract
Large Language Models (LLMs) have revolutionized AI research and enabled exciting agent systems. To build a complex LLM agent system, most existing research relies on insights from other domains or heuristics to manually build the agent system. However, this approach often requires heavy hand-engineering and fails to fully optimize for the downstream task of interest. Inspired by the tremendous success of deep learning, we propose to construct LLM agent systems in a modular manner, similar to building a deep neural network. Our key insight is to make analogies between LLM building blocks, such as retrievals, memories, and prompting strategies, and the successful deep learning modules, such as MLPs, attention, and recurrent modules. We further design forward inference and feedback mechanisms for LLMs, where prompts in LLMs are considered as the weights in deep models, and the prompt optimization from feedback is analogous to the back-propagation algorithm. We additionally leverage a search algorithm to search for the best configuration of LLM agent systems, similar to the neural architecture search (NAS) in deep learning research. Comprehensive experimental results demonstrate that the proposed deep learning recipe for LLM agent systems is highly effective, in particular: (1) Organizing LLM modules into deep-learning-style architectures yields noticeable performance gain; (2) Automatic prompt optimization, equivalent to backpropagation, is efficient in incorporating feedback from the task of interest and achieves at least 5% performance improvement; (3) NAS equivalent algorithm works well for further optimizing the LLM agent system architecture with 11% performance gain compared with randomly designed architectures. Overall, our research demonstrates the exciting opportunity of transferring the success of deep learning to building LLM agent systems.

## 2. 方法论

### 2.1 核心思想：LLM 模块 ↔ DL 模块的类比映射

| LLM 智能体组件 | 深度学习对应模块 | 类比依据 |
|---|---|---|
| Vanilla LLM | 单层 MLP | 输入 query q → 输出 response r，基本计算单元 |
| Memory Processor | RNN | 都利用历史序列 {m0,…,mn,q} 维护隐状态 ht 以支撑后续输出 |
| Retrieval | Attention Network | 都基于 query 与语料 C 的嵌入相似度计算重要性分数 f 并加权；单查询检索≈单头注意力，多查询检索≈多头注意力 |
| Prompting Strategies（ToT/GoT） | GNN | 将 query 分解为相互关联的 thought 节点，节点与关系对应图的节点与边；树是图的特例 |

### 2.2 参数体系：提示即权重

- **训练参数（trainable）**：meta prompt，被视作深度网络中的权重，由反馈迭代更新。
- **超参数（predefined）**：每个 LLM 的 max tokens（≈MLP 宽度）、检索次数（≈注意力头数）、每次检索的召回数（≈mask）、ToT/GoT 的节点数或深度（≈GNN 层数）。

### 2.3 前向推理与反馈传播

- **前向推理（Forward Inference）**：输入 query 依次经过模块组合得到 response，全过程由 meta prompt（含输入 query、历史响应、自反思结果）引导。
- **反馈传播（Feedback Propagation）**：类比反向传播。设计 **self-reflection 模块**充当损失函数，包含两部分：
  - *Metric Calculation*：当响应质量有明确指标时使用；
  - *LLM Evaluation*：无明确指标时由 LLM 自行评判。
  - 产生的 reflection 与 response 被用于更新 meta prompt，指导下一轮推理。
- **算法流程（文字描述）**：初始化 meta prompt → 前向推理得 response → 自反思计算损失/评价 → 将响应与评价回写 meta prompt → 进入下一轮，循环若干步。

### 2.4 案例：用 LLM 模块搭建 Cross-Attention Transformer

- 原始 query 与语料 context 类比为两种不同的数据特征 Feature 1 / Feature 2。
- meta prompt 引导 LLM 生成多个查询 → **multi-query retrieval ≈ 多头交叉注意力网络**。
- 将原始 query 追加到生成的多查询中 → **残差连接**（缓解梯度消失/爆炸）。
- 最终 LLM 基于检索上下文与输入 query 输出响应 → **MLP 层**。

## 6. 主要结论与发现

- **架构适配任务**：将 LLM 模块按 DL 风格组织可获得明显性能提升。
  - 无外部知识场景：GNN-MLP 与 Tree-MLP 在 TSP/GSM8k 上最佳（GSM8k：MLP 53.3% → Tree-MLP 66.7%；TSP：79.2 → 73.2/73.9），因其逻辑推理与多路径探索能力更强。
  - 有外部知识场景：RNN 类架构最优（StrategyQA：Att-MLP F1 0.42 → RNN-Att-MLP 0.66），因其擅长处理并保留长序列信息——与 DL 中 RNN+Attention 组合有效的发现一致。
- **反馈传播有效**：类反向传播的自动提示优化无需人工干预即可持续提升性能，**至少带来 5% 增益**；GNN-MLP 与 Tree-MLP 迭代更快、结果更好（每步探索更多解）。
- **Transformer 变体表现因任务而异**：StrategyQA 上原版 Transformer 最佳（任务较简单，架构已足够复杂）；Related-multi 上 Tree-/GNN-Transformer 更优（写作任务需要更多发散性思考）。
- **架构搜索有效**：Optuna 搜索得到最优配置 pr = (m1=192, m2=192, m3=320, h=2, n=4)，测试集 F1 = 0.712，**比随机设计架构高 11%**；随 trial 数增加（0→7→43→78），F1 从 0.541 升至 0.712。
