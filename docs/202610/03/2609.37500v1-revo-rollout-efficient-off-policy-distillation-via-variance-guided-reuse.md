## 摘要
同策略蒸馏（OPD）利用对学生生成轨迹的密集 token 级教师监督来训练语言模型。然而，其依赖频繁刷新的学生 rollout，通常会带来可观的生成成本。我们提出 REVO，一种离策略蒸馏框架，通过将每个学生 rollout 复用于多步学习器更新，提高 rollout 效率。REVO 通过稳定化的前缀加权以及从当前学生进行一步重采样，解决了前缀级和当前 token 级的策略不匹配问题，从而能够在不重新生成完整轨迹的情况下进行重复更新。为了在复用的 rollout 中优先关注信息量大的 token 位置，REVO 使用学生-教师对数概率比的方差来量化剩余的 token 级学习信号，并指导重复优化。在多种学生-教师规模下，仅进行 50 次 rollout 迭代的 REVO 在同域和跨域推理基准上匹配或超过了训练 200 次迭代的 OPD 基线。

## Abstract
On-policy distillation (OPD) trains language models using dense token-level teacher supervision on student-generated trajectories. However, its reliance on frequently refreshed student rollouts often incurs substantial generation cost. We introduce REVO, an off-policy distillation framework that improves rollout efficiency by reusing each student rollout for multi-step learner updates. REVO addresses prefix-level and current-token policy mismatch through stabilized prefix weighting and one-step resampling from the current student, which enables repeated updates without regenerating full trajectories. To prioritize informative token positions within reused rollouts, REVO uses the variance of the student-teacher log-probability ratio to quantify the remaining token-level learning signal and guide repeated optimization. Across multiple student-teacher scales, REVO with only 50 rollout iterations matches or exceeds OPD baselines trained for 200 iterations on both in-domain and cross-domain reasoning benchmarks.

# REVO 论文深度总结

## 1. 核心问题与研究背景

- **核心痛点**：同策略蒸馏（On-Policy Distillation, OPD）通过在学生自生成轨迹上提供密集的 token 级教师监督来训练语言模型，但每次迭代都需要一批全新的学生 rollout，导致自回归生成成本极高，成为训练的 wall-clock 瓶颈（相关研究指出 rollout 生成可主导 OPD 训练成本）。
- **自然思路**：将每条轨迹复用于多步学习器更新（off-policy reuse），从而摊销生成成本。
- **复用带来的两大挑战**：
  - **分布偏移**：随着学生演化，存储前缀与采样 token 的分布会偏离当前策略，可细分为 **前缀不匹配（prefix mismatch）** 与 **当前 token 不匹配（current-token mismatch）**。精确重要性采样需沿前缀连乘似然比，长序列下方差极大、更新不稳定。
  - **学习信号衰减**：复用同一批前缀时，不同 token 位置的剩余蒸馏信号强弱不均，重复访问低信号位置会浪费计算并放大采样噪声。
- **整体含义**：论文提出 REVO，通过「离策略稳定化 + 方差引导的 token 优先级」实现 rollout 高效复用，目标是在显著减少 rollout 次数的前提下匹配甚至超越标准 OPD。

## 2. 方法论

### 2.1 核心思想
- 将每条学生 rollout 复用于 **N 次学习器更新**；同时区分并分别处理前缀不匹配与当前 token 不匹配，并通过 RKL 方差对复用位置做自适应优先级分配。

### 2.2 关键技术细节

- **一步重采样（One-Step Resampling）**
  - 在当前学生策略的存储前缀 $c_t$ 上重新采样 $K$ 个候选 token $a_t^{(1)},\dots,a_t^{(K)} \sim P_\theta(\cdot|c_t)$，利用蒸馏可对任意动作评分的特性，精确消除当前 token 的重要性比率 $r_t$，无需重新生成完整轨迹。
  - 用 $K$ 个样本的平均获得条件 reverse-KL 梯度的无偏估计，缓解有限样本噪声与采样分布偏移。

- **稳定前缀校正（Stabilized Prefix Correction）**
  - 由于前缀无法重采样，采用几何归一化并截断的代理权重：
    $$G_{<t}=\min\Big\{\exp\big(\tfrac{1}{t-1}\sum_{i<t}\log\tfrac{P_\theta(a_i|c_i)}{P_o(a_i|c_i)}\big),\; C\Big\},\quad G_{<1}=1$$
  - 低于上限时等于累积比率 $W_{<t}$ 的几何平均，避免随序列长度乘性增长；$C$ 为数值安全上限（默认 $C=4$）。

- **RKL 方差引导的 Token 优先级**
  - 定义局部相对熵方差 $E_t=\mathrm{Var}_{a\sim p_t}[\log\frac{p_t(a)}{q_t(a)}]$，称为 **RKL 方差**，刻画前缀处剩余的 token 级学习信号。
  - 用一步重采样的 $K$ 个样本计算无偏样本方差估计 $\hat E_t^K$；采用带阈值 $\delta$ 的**两级有界加权**：高于阈值权重为 $\tau$，其余为 $1-\tau$（默认 $\tau=0.75$），并归一化到均值为 1。
  - 权重与 RKL 信号在 stop-gradient 下作为常数参与梯度计算；每个学习器更新都刷新样本与优先级。

- **训练目标（式 8）**
  $$\hat L^{K,G,w}_t=\frac{1}{K}\sum_{k=1}^K \mathrm{sg}\big[G_{<t}\,w_t\,A^{(k)}_t\big]\log P_\theta(a^{(k)}_t|c_t)$$
  其中 $A^{(k)}_t=\log P_\theta(a^{(k)}_t|c_t)-\log P_T(a^{(k)}_t|c_t)$。

### 2.3 理论支撑
- **Proposition 4.1（SNR 引导的局部更新缩放）**：在 $\beta$-光滑假设下，最优确定性权重 $w^\star_t=\frac{1}{\beta\eta}\frac{\Gamma_t}{1+\Gamma_t}$ 随梯度 SNR $\Gamma_t$ 单调增并饱和。
- **Proposition 4.2（Fisher 几何解释）**：在局部可实现性条件下，$\langle g_t, n_t\rangle = g_t^\top F_t^\dagger g_t = E_t$，即 RKL 方差等于普通梯度与自然梯度的内积，表示沿自然梯度方向单位步长的**一阶下降量**。
- **经验关联**：1280 个前缀上，精确 $E_t$ 与 $K=16$ 重采样估计器的 logit 梯度 SNR 呈 Spearman $\rho=0.93$ 的强秩相关。

### 2.4 算法流程（Algorithm 1 概述）
1. 冻结行为策略 $P_o \leftarrow P_\theta$，生成并存储 rollout 批次及其行为 log 概率；
2. 重复 N 次学习器更新：对每个有效位置计算前缀校正 $G_{i,<t}$、采样 $K$ 个候选 token、计算 RKL 信号与方差估计、按两级规则赋权并归一化；
3. 构造重加权目标并更新 $\theta$。

## 6. 主要结论与发现

- REVO 仅用 **50 次 rollout 迭代**，即在同域与跨域推理基准上**匹配或超越训练 200 次的 OPD 基线**（如 1.7B 学生平均分 29.6 vs OPD 200 步的 27.3）。
- 增益并非单纯来自更多学习器更新：OPD(U10) 在同预算下未显著优于标准 OPD，而 REVO 明显更优，说明**离策略稳定化与优先级分配**是关键。
- RKL 方差高的位置提供持续有效的监督，低方差位置贡献有限；RKL 方差与梯度 SNR 强相关，可作为可靠性的实用代理。
- 更激进的复用（U50）可加速早期学习，但最终精度与 U10 相近，主要用学习器计算换取更少 rollout。
- 生成时间占比从标准 OPD 的约 70% 降至约 32%，实现「更少 rollout + 更低 wall-clock + 更高性能」。

## 7. 优点

- **问题分解清晰**：将复用偏差显式拆分为前缀不匹配与当前 token 不匹配，并分别用不同机制处理，逻辑严谨。
- **一步重采样设计巧妙**：利用蒸馏中「教师可对任意动作评分」的特性，在不重新生成轨迹的前提下消除当前 token 重要性比率，避免了 PPO 式裁剪 IS 的偏差。
- **理论—经验闭环**：给出 SNR 最优缩放（Prop 4.1）与 Fisher 几何解释（Prop 4.2），并用离线诊断验证 RKL 方差与梯度 SNR 的强相关性，方法设计有理论动机而非纯启发式。
- **零额外模型评估**：RKL 方差估计直接复用重采样已有的候选 token 与 RKL 信号，几乎不增加前向开销。
- **有界两级加权**：规避了 RKL 方差长尾、含零估计的数值不稳定问题，同时保留粗粒度优先级。
- **实验较全面**：多模型家族、多规模、跨域评测、系统 wall-clock 分析、混淆因素排除（OPD(U10)）。

## 8. 不足与局限

- **理论条件较强**：Prop 4.2 依赖「局部可实现性」条件，Prop 4.1 依赖 $\beta$-光滑上界，实际训练中难以严格满足；RKL 方差与 SNR 只是秩相关（$\rho=0.93$），并非校准映射，无法直接代入最优权重。
