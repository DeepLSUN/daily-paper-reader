## 摘要
MAS 规范表达智能体及其环境的动作所产生的影响，以及其他时间现象，例如智能体可以执行动作的时间区间。MAS 的规范还应当是可执行的，以便支持运行时监控。构建 MAS 规范需要形式语言专业知识，而机器学习技术依赖标注数据，而这类数据很少可得。为解决这些问题，我们提出 `genRTEC'，一种利用预训练大语言模型（LLMs）从自然语言描述生成可执行 MAS 规范的方法，所用语言为 `Run-Time Event Calculus'（RTEC）。genRTEC 仅基于对所涉及概念的简短自然语言描述，就能构建具有复杂层次和循环依赖关系的 MAS 规范。我们提出了对 genRTEC 的广泛实证评估，涵盖多种 MAS 规范，包括定性和定量评估。我们的结果表明，genRTEC 能够构建具有高预测准确率的可执行 MAS 规范，同时不损害推理效率。

## Abstract
MAS specifications express the effects of the actions of the agents and their environment, as well as other temporal phenomena, such as the intervals during which an agent may perform an action. The specification of a MAS should also be executable in order to allow for run-time monitoring. Constructing the specification of a MAS requires formal language expertise, while machine learning techniques depend on labelled data which are rarely available. To address these issues, we propose `genRTEC', a method that leverages pre-trained Large Language Models (LLMs) to generate executable MAS specifications, in the language of the `Run-Time Event Calculus' (RTEC), from natural language descriptions. genRTEC constructs MAS specifications with complex hierarchical and cyclic dependencies based only on short natural language descriptions of the concepts involved. We present an extensive empirical evaluation of genRTEC, spanning various MAS specifications, including both a qualitative and a quantitative assessment. Our results demonstrate that genRTEC constructs executable MAS specifications of high predictive accuracy without compromising reasoning efficiency.
