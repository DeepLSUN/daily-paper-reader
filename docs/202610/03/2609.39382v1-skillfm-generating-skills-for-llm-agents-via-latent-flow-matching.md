## 摘要
文本技能为大语言模型智能体提供了可复用的指导，但现有方法往往依赖人工整理的技能库，或依赖具有间接且延迟反馈的强化学习。我们提出了SkillFM（Skill Flow Matching），一种生成式框架，能够直接合成以任务为条件的文本技能，而无需在测试时进行技能检索。我们的框架结合了一个用于在连续潜在空间中编码和重构文本技能的编解码器，以及一个使用改进的MeanFlow训练的条件流模型。在推理时，学习到的速度场支持单步潜在采样，而基于LLM的解码器将采样得到的表示转换为用于冻结下游智能体的文本指导。我们在具身任务、问答和网络购物上评估了该框架。在ALFWorld和Search-QA上，我们的方法在比较的基于向量的技能方法中取得了最佳总体性能。我们的分析进一步表明，潜在技能生成是基于检索的技能增强的有效替代方案。我们的代码和训练技能库可在https://github.com/lulushang999/SkillFM获取。

## Abstract
Textual skills provide reusable guidance for large language model agents, but existing approaches often rely on manually curated skill banks or reinforcement learning with indirect and delayed feedback. We introduce SkillFM (Skill Flow Matching), a generative framework that synthesizes task-conditioned textual skills directly without test-time skill retrieval. Our framework combines a codec for encoding and reconstructing textual skills in a continuous latent space with a conditional flow model trained using improved MeanFlow. At inference time, the learned velocity field enables single-step latent sampling, and an LLM-based decoder converts the sampled representation into textual guidance for a frozen downstream agent. We evaluate the framework on embodied tasks, question answering, and web shopping. On ALFWorld and Search-QA, our method achieves the best overall performance among the compared vector-based skill approaches. Our analyses further demonstrate that latent skill generation is an effective alternative to retrieval-based skill augmentation. Our code and training skill libraries are available at https://github.com/lulushang999/SkillFM.

## 1. 核心问题与研究动机

- **背景**：文本技能（textual skills）为 LLM 智能体提供可复用的过程性指导。现有"技能驱动的自我进化"通常采用 **检索—执行—总结** 三件套：检索器挑选相关技能，执行器与环境交互，总结器把轨迹蒸馏为新技能。
- **问题一：检索式复用代价高且不可靠**。系统必须同时维护技能库与"选择规则"；技能更新的效用往往在后续任务中才显现（反馈延迟、间接），难以判断哪些技能应保留、修改或丢弃；技能库增长后，相似、冗余甚至误导性条目难以区分。
- **问题二：现有内化方案仍受限**。Skill0 通过课程式 RL 逐步撤除技能上下文，把过程知识压入执行策略；LatentSkill 把文本技能编译为模块化 LoRA 适配器——但仍需以合适的技能描述为输入，且表示与执行主干耦合，难以跨异构执行器迁移。
- **整体含义 / 本文主张**：把"任务→技能"的映射**直接学进一个生成器**，用可解码的连续隐空间表示技能本身，在推理时**用生成替代检索**；技能库退化为离线训练数据源，不再是测试时被查询的对象，下游 actor 保持冻结。

## 2. 方法论

### 2.1 核心思想
两阶段训练：**(I) 训练可重构的技能编解码器**（建立"文本技能 ↔ 隐向量"的双向接口）；**(II) 冻结编解码器，用改进 MeanFlow 学习条件速度场**，把技能库中的过程知识内化到生成器中。推理时单步采样隐码 + LLM 解码为文本指导，交给冻结的 actor 执行。

### 2.2 技能库构建
- 在训练任务上迭代"执行—总结"：执行器采集轨迹，总结器从成功轨迹蒸馏可复用过程；技能反过来指导下一轮执行；成功率不再提升即停止。
- 保留成功技能，用余弦相似度去近重复，清洗摘要，形成固定的 (c, s) 训练对。ALFWorld 技能来自训练链，QA 与购物技能还包含人工撰写/修订版本。

### 2.3 技能编解码器（Stage I）
- 编码器只读技能：`z = E_φ(s)`，`‖z‖₂ = 1`，维度 d = 2560。
- LayerNorm + 线性投影 `P_ψ` 把 z 映射为 **K = 16 个连续前缀嵌入**，供任务条件自回归解码器 `D_ω` 使用：`p_ω(s | z, c) = ∏_j p_ω(s_j | s_<j, P_ψ(z), c)`。
- **球面扰动增广**：`z̃ = cos(α)z + sin(α)v`（v 为与 z 垂直的随机单位向量），使解码器对邻近码鲁棒；α 角度标准差 0.16 rad、最大 0.35 rad、施加概率 0.75，强度在 8 个 epoch 内 ramp。
- 损失为教师强制重构 `L_codec = -E[Σ_j log p_ω(s_j | s_<j, P_ψ(z̃), c)]`，**仅技能 token 与终止符计入损失**，prompt/前缀/padding 位置被 mask。
- 只训练投影器与编码器/解码器 LoRA 适配器，主干权重冻结。

### 2.4 条件流匹配（Stage II）
- 冻结编解码器与独立的 query 编码器。缩放码 `x = √d · E_φ(s)` 使其与高斯噪声的 RMS 范数匹配；条件 `q = E_query(c)`。
- 插值路径 `x_t = (1-t)x + tε`，ε ~ N(0, I)，数据端 t = 0、噪声端 t = 1，配对速度 `v_pair = ε - x`。
- 条件 Transformer `u_θ(x_t, r, t, q)` 预测区间平均速度（0 ≤ r ≤ t ≤ 1）；每个 block 接收 query、时间与区间长度 t - r（adaLN-Zero 条件化）。
- **改进 MeanFlow 目标**：对角评估 `b_θ(x_t, t, q) = u_θ(x_t, t, t, q)` 给出瞬时速度估计；导数修正 `D_t u_θ = ∂_t u_θ + (J_{x_t} u_θ) b_θ`（JVP）；复合预测 `V_θ = u_θ(x_t, r, t, q) + (t - r)·stopgrad(D_t u_θ)`。
- 损失 `L_flow = E[w ‖V_θ - v_pair‖²]`，w 为自适应回归权重；r = t 时修正项消失，退化为标准瞬时流匹配。
- 附录 A 给出推导：区间平均速度恒等式、边界参数化与 target-form 目标的**代数等价性**（相同权重与梯度约定下梯度一致），以及 population-regression 分解（未加权总体损失 = 对边际速度的误差 + 不可约条件方差）；并说明用预测切线替代 v_pair 作为 JVP 状态方向可移除样本对变异性。

### 2.5 推理与执行
- 单次流网络评估：`y_1 ~ N(0,I)`，`y_0 = y_1 - u_θ(y_1, 0, 1, q)`，`ẑ = y_0/‖y_0‖₂` 归一化回单位球。
- 冻结解码器在 (P_ψ(ẑ), c) 条件下**贪心生成**技能 ŝ；冻结 actor 依据 (c, ŝ, 交互历史) 选动作。
- 每个任务只生成一个技能，整个 rollout 期间固定；**测试时不做任何技能库检索**。NFE = 1 只计流网络调用，query 编码、技能解码与执行不计入。
