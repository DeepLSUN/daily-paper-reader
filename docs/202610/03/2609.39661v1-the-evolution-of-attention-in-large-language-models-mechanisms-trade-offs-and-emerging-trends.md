## 摘要
自注意力使大语言模型（LLM）能够以细粒度、依赖查询的方式访问上下文，但稠密的 token 交互会带来二次方的预填充（prefill）开销，以及与上下文长度同步增长的键值（KV）缓存。因此，相关研究涵盖显式记忆压缩、稀疏访问、循环状态构建、结构化状态动力学以及异构机制组合等多个方向。本综述将这些进展统一视为模型内部的上下文记忆加以分析。我们提出一个五维分析视角——记忆表示、记忆更新、访问、读出与整合——分别刻画：被表示的内容是什么、其如何变化、哪些部分可被查询、如何被读取，以及读出结果如何形成输出。该视角可在不强加单一计算模型的前提下，对相互重叠的研究路线进行比较。我们借助来自 14 个主要模型谱系和 11 个高性能开源权重端点的 59 条发布级记录，重建了机制层面的发展脉络与架构采纳情况。第一，显式记忆方法与循环状态方法虽然保留了各自不同的接口，但在记忆功能上日益出现重叠与共管。第二，异构架构日益在网络的深度维度上进行协同：逐层组合将互补的记忆处理分配到不同的表示阶段，而跨层复用则将选定的记忆与路由产物向前传递。深度由此成为构建与管理上下文记忆的一个维度。第三，这些进展引出一个有状态的多维记忆路由假说：持久记忆在时间跨度、网络深度、载体类型与表示粒度等维度上被组织起来，而协同的稀疏写入（Sparse Write）与稀疏读取（Sparse Read）则决定哪些内容被保留、哪些内容对每次查询产生贡献。总体而言，高效的序列架构设计日益关注上下文记忆的组织方式、生命周期与选择性使用，而非孤立的注意力算子。

## Abstract
Self-attention gives LLMs fine-grained, query-dependent access to context, but dense token interactions incur quadratic prefill cost and a key--value cache growing with context length. Research thus spans explicit-memory compression, sparse access, recurrent state construction, structured state dynamics, and heterogeneous mechanism composition. This survey analyzes these developments as model-internal contextual memory. We introduce a five-dimensional lens---Memory Representation, Memory Update, Access, Readout, and Integration---describing what is represented, how it changes, what is query-eligible, how it is read, and how readouts form outputs. This lens compares overlapping research lines without imposing one computational model.   We reconstruct mechanism-level developments and architectural adoption using 59 release-level records from 14 major model lineages and 11 high-performing open-weight endpoints. First, explicit-memory and recurrent-state methods retain distinct interfaces but increasingly control overlapping memory functions. Second, heterogeneous architectures increasingly coordinate across network depth: layer-wise composition distributes complementary memory processing across representational stages, while cross-layer reuse carries selected memory and routing artifacts forward. Depth thus becomes a dimension along which contextual memory is constructed and managed. Third, these developments motivate a stateful multidimensional memory-routing hypothesis: persistent memory is organized across temporal scope, network depth, substrate type, and representation granularity, while coordinated Sparse Write and Sparse Read determine what is maintained and what contributes to each query. Overall, efficient sequence architecture design increasingly concerns the organization, lifecycle, and selective use of contextual memory rather than an isolated Attention operator.

## 1. 核心问题与整体含义（研究动机与背景）

- **根本矛盾**：自注意力（Self-Attention）为 LLM 提供了细粒度、依赖查询的上下文访问能力，支撑上下文学习、长程依赖建模与信息复用；但其稠密 token 交互带来两大可扩展性瓶颈：
  - **预填充（prefill）阶段**：query-key 比较次数随序列长度呈**二次方增长**。
  - **自回归解码阶段**：KV 缓存随累积上下文**线性增长**。
  - 更长的名义上下文窗口并不等于可靠使用远端证据，候选集膨胀会加剧检索干扰、削弱长程召回。
- **研究演化方向**：显式记忆压缩、稀疏访问、循环状态构建、结构化状态动力学、异构机制组合。
- **整体含义/定位**：本综述不把上述方向视为孤立的"降低复杂度"技巧，而是统一建模为**模型内部的上下文记忆（contextual memory）**。作者认为高效序列架构设计的核心问题，已从"优化孤立 Attention 算子"转向"上下文记忆的组织、生命周期与选择性使用"。
- **与既有综述的区别**：既有综述分别以架构族/复杂度（通用 Transformer）、上下文扩展/外推（长上下文）、稀疏与线性算法、SSM 谱系、KV 缓存管理、广义记忆等为组织原则；本文专门聚焦**注意力及相邻序列混合器**，以"上下文记忆"为共同分析单元。

## 2. 方法论：核心思想与关键技术细节

### 2.1 五维分析视角（核心贡献）

将任何序列机制拆解为五个功能维度，用统一符号刻画（ρ 为记忆 schema，Mt 为记忆，qt 为查询，xt 为输入）：

| 维度 | 核心问题 | 抽象表达 |
|---|---|---|
| **Memory Representation** | 过去哪些信息仍被表示、以何形式 | `Mt ∈ Mρ` |
| **Memory Update** | 新输入如何写入/修改/压缩/覆盖记忆 | `M+_t = Update_ρ(M−_t, xt)` |
| **Access** | 哪些表示对当前查询**有资格**参与 | `Ct = Access_ρ(qt, M̂t)` |
| **Readout** | 合格信息如何被加权/解码/聚合 | `rt = Readout_ρ(qt, Ct)` |
| **Integration** | 多个读出结果如何变换/协调为模块输出 | `ot = Integration_ρ(rt; xt)` |

- 关键区分：**Access 回答"可读什么"，Readout 回答"如何读"**；二者分离可解释"同一 Softmax Readout 配不同候选集"或"相似状态接口配不同解码"。
- 两个反复出现的属性：**history coverage（历史覆盖）** 与 **addressability（可寻址性）**——固定尺寸状态可覆盖全历史但不再保留逐 token 可寻址；显式 KV 缓存保留 token 级可寻址但随长度增长。

### 2.2 五条研究路线（四机制 + 一组合）

- **Softmax Attention**：显式记忆单元，主攻 Representation/Update。三条优化方向——表示效率（MQA/GQA 头共享、MLA 通道压缩、CLA 跨层共享）、序列表示压缩（固定容量循环记忆 RMT/TransformerFAM/Trellis/Lattice、动态分辨率记忆 KSA/HCA）、读出与整合调制（Talking-Heads、DCMHA、Differential Attention、FoX、MoH、Gated Attention）。
- **Sparse Attention**：主攻 Access。按证据来源分——结构约束（Longformer/BigBird、Sparse Transformer/LongNet/PowerAttention、StreamingLLM/LM-Infinite、MInference）、自路由（Reformer/Routing Transformer、Quest/XAttention、MoBA/NSA）、辅助代理路由（TokenButler、DSA Lightning Indexer、LSA、MSA、QSA、CSA）、时间与跨层复用（ReTopK、TidalDecode、Kascade、IndexCache、YOIO/CLSA、CSA2、HySparse）。
- **Linear Attention**：将历史折叠为循环关联状态。以 retain/decay、erase/correct、write/commit 三分量统一刻画更新规则，如 DeltaNet 的耦合纠正擦除 `St = (I − βt kt kᵀt)St−1 + βt kt vᵀt`，RWKV-7/GDN2/EDA 的解耦擦除-写入；容量扩展（SSE 分组、SDM 平坦行记忆）、时间扩展（Log-Linear 确定性多尺度、DLA 内容自适应、MHLA 固定块）、辅助协调（SLA 特征头、CLVR 跨深度）。
- **State Space Models**：结构化循环状态。从时不变动力学（HiPPO/S4/S4D/S5）到输入条件化（Mamba 的选择性扫描）再到 SSD（Mamba-2 的循环/矩阵双视角）；读-写接口（Mamba-3 MIMO、MIMOMamba）、状态组织（HADES 滤波组）、更新几何（MuonSSM）。
- **Hybrid Architecture**：按组合粒度分为层间（预定义分配、直接诊断、对齐选择、迭代蒸馏引导）、头间（固定、功能感知、输入自适应、深度自适应）、分支间（读出级融合、输出级融合）、token 间（时间边界、内容分数、学习操作分配）。

### 2.3 前瞻性假说：有状态多维记忆路由

- 用四坐标地址空间刻画持久记忆：`At = Tt × L × S × G`（时间跨度、网络深度、载体类型、表示粒度）。
- **Sparse Write**：`Wt ⊆ At`，仅选定地址接收更新；**Sparse Read**：`Ct = Access_ρ(qt, M̂t)`。
- 类似"多维 Memory-MoE"，但关键区别是**持久性**：路由不仅决定当前计算，还决定未来查询可用的信息。
- 四个可测试方向：工作负载感知的差异化记忆表示、非对称记忆构建与检索、增量式记忆生命周期与可复用产物、任务条件化的记忆与计算联合路由。

  - **局限**：作者自述清单是**有意策展（purposively curated）而非穷尽或市场份额加权**；样本以主流开源模型为主，可能低估闭源模型或非英语社区架构；跨层复用仅 5 条记录、3 种架构模式，统计效力弱。
  - **公平性**：作者反复强调分析是**描述性（descriptive）而非因果性**，明确拒绝用排行榜推断机制优劣——这一点在方法学上是诚实且克制的。

## 6. 主要结论与发现

- **机制层面（Synthesis 1）**：显式记忆路线与状态路线起点不同（可枚举单元 vs 循环压缩状态），但**控制范围日益重叠**——显式路线从表示/访问效率扩展到有界更新、读出调制与输出协调；状态路线从状态表示/更新扩展到多单元组织、选择性访问、更丰富读出与协调整合。收敛的是**设计控制范围**，而非记忆载体或计算机制。
- **架构层面（Synthesis 2）**：注意力设计**持续多样化而非收敛**。
  - 59 条记录中 58 条可分类：32 条单一族、26 条混合；Hybrid 记录从 2022–2023 的 0/6 增至 2024–2025 的 9/25、2026 的 17/27。
  - 主流组织方式仍是**预定义的逐层调度**；跨层复用（IndexCache/IndexShare、CSA2 的 Full/Reindex/Reuse、LSA 的 Cross-Layer Indexing）仅 5 条记录、3 种模式。
  - **网络深度成为构建与管理上下文记忆的新兴维度**：层间组合决定"各深度做什么记忆处理"，跨层复用决定"哪些记忆/路由产物跨深度存活"。
- **前沿横截面**：11 个高性能开源端点架构异质，但**每一个都保留了显式 token 检索路径**——循环状态与稀疏性目前是补充而非统一替代 token 可寻址注意力。
- **总判断**：高效序列架构设计日益关注上下文记忆的**联合组织、生命周期与选择性使用**，而非孤立 Attention 算子的优化。

## 7. 优点（方法或设计亮点）

- **统一分析词汇**：五维视角（Representation/Update/Access/Readout/Integration）可在不强加单一计算模型的前提下比较历史上重叠的研究路线，避免"把一切效率改进笼统称为改注意力"的模糊表述。
- **功能角色 vs 实现阶段**：明确五维是分析角色而非强制执行顺序，允许一个操作同时承担多个角色（如路由分数既选候选又分配概率质量）。
- **机制与架构双层证据互证**：机制层文献重建 + 纵向清单 + 冻结前沿快照，三个层次相互支撑。
- **诚实的方法学克制**：反复声明清单非穷尽、非市场份额加权、排行榜非因果归因；Undisclosed 不推断；多模态仅分类语言骨干。
- **前瞻性假说可落地**：多维记忆路由假说配有 4 个"可渐进实现、可测试"的研究方向，并给出已有系统的部分证据（QSA、HCA/CSA、Engram、CSA2、YOIO/CLSA、Elastic Attention、Mixture-of-Depths）。
- **对评估实践的批判性提醒**：强调数值稀疏 ≠ 实际节省，须报告 FLOPs、内存流量、核效率与端到端延迟；须区分路由计算节省与索引/KV 流量节省。

## 8. 不足与局限

- **综述性质决定无原创实验**：无训练、无消融、无受控对比，所有"结论"依赖对公开文档的整理与解释，无法验证机制与性能的因果关系。
- **清单偏差风险**：
  - 有意策展而非系统检索，可能遗漏非主流或非英语文档的架构。
  - 以开源权重与公开技术报告为主，闭源前沿模型（如未披露架构者）被排除或标为 Undisclosed，可能导致前沿图景不完整。
  - 记录按"发布级"计数，同一架构模式（如两个 GLM、两个 LongCat）会贡献多条记录，跨层复用的 5 条实际仅对应 3 种模式，统计独立性有限。
- **时间冻结限制**：清单与前沿比较均截至 2026-09-22，领域演进极快，结论可能迅速过时。
- **分类边界的主观性**：章节归属按"主要技术贡献"而非互斥划分，Sparse/Linear/SSM/Hybrid 之间存在重叠（如 NSA 同时含压缩与选择分支），作者自述为"编辑性归属"。
- **前瞻假说未验证**：多维记忆路由、Sparse Write/Sparse Read 的联合协调仅为设计假说，作者也承认其价值取决于能否在匹配的记忆/计算/路由预算下改善实际质量-效率前沿，且引入路由、优化、内存管理与硬件成本等风险。
- **应用限制**：结论主要面向自回归语言骨干；测试时学习、外部数据库检索、多模态特定记忆、纯实现优化被明确排除在核心分类之外。
