## 摘要
大型语言模型（LLMs）擅长自然语言处理，但难以与外部环境交互。工具学习为将 LLMs 扩展为可执行动作的智能体提供了一种有前景的途径，其中工具选择是成功使用工具的关键前提。现有工作通常假设工具集合较小或预先定义，导致大规模工具选择尚未得到充分探索。现实世界的工具库包含大量且多样化的工具，使得 LLMs 在上下文长度约束下难以有效搜索、区分和组合工具。我们将大规模工具选择视为智能体强化学习的一项新挑战，并强调现有的用于基于知识问答的强化学习方法不足以在考虑兼容性的同时选择工具。为应对这一挑战，我们提出 ToolSearcher，一种新颖的强化学习框架，用于大规模工具选择中的有效多轮搜索和细粒度优化。具体而言，我们引入类别约束的工具判别，以提高模型区分功能相似工具的能力；引入事件级搜索建模，以在多轮搜索中显式优化目标工具的发现；引入轨迹对齐的信用分配，为搜索-选择过程的不同阶段提供细粒度奖励信号。在大规模工具选择基准上的大量实验表明，在涉及迭代搜索和复杂工具组合的挑战性设置中，ToolSearcher 始终优于一系列强基线。

## Abstract
Large language models (LLMs) excel at natural language processing but struggle to interact with external environments. Tool learning provides a promising way to extend LLMs into actionable agents, where tool selection is a critical prerequisite for successful tool use. Existing work often assumes a small or predefined set of tools, leaving large-scale tool selection underexplored. Real-world repositories contain a vast and diverse array of tools, making it difficult for LLMs to effectively search, distinguish, and compose tools under context-length constraints. We identify large-scale tool selection as a new challenge for agentic reinforcement learning, highlighting that existing RL methods for knowledge-based question answering are inadequate for selecting tools while considering compatibility. To address this challenge, we propose ToolSearcher, a novel RL framework for effective multi-turn search and fine-grained optimization in large-scale tool selection. Specifically, we introduce category-constrained tool discrimination to improve the model's ability to distinguish functionally similar tools, event-level search modeling to explicitly optimize the discovery of target tools during multi-turn search, and trajectory-aligned credit allocation to provide fine-grained reward signals for different stages of the search-selection process. Extensive experiments on large-scale tool selection benchmarks demonstrate that ToolSearcher consistently outperforms a set of strong baselines in challenging settings involving iterative search and complex tool composition.

## 一、核心问题与整体含义（研究动机与背景）

- **背景**：LLM 在自然语言处理上表现优异，但难以主动感知和交互外部环境。工具学习（tool learning）是将 LLM 扩展为可执行智能体的关键路径，其典型流程包括**工具选择、工具调用、响应生成**三个阶段。
- **被忽视的环节**：现有研究大量聚焦于工具调用（如参数填充、执行），而**工具选择**——即如何依据任务需求从大规模、多样化的工具库中有效检索并选出合适候选工具——仍被严重忽视。
- **现实与假设的差距**：主流工作（如 BFCL、ToolLLM 等）常假设工具集**规模小或预先定义**，但真实生态（PyPI、npm、HuggingFace、RapidAPI）中工具数量与功能多样性极其庞大，受上下文长度限制不可能把所有工具文档塞入 prompt，**搜索成为必要步骤**。
- **新挑战的成因**：
  - 大规模工具库加剧了工具之间的**功能相似性与语义相似性**（语义相近但功能不同，或功能相近但接口设计不同）。
  - 工具选择本质是涉及**规划、搜索、决策**的复合过程，需要协调多种能力。
  - 现有面向知识密集问答的智能体强化学习（如 Search-R1）依赖迭代信息补充，**不适合需要推理工具可组合性（composability）的工具选择任务**。
- **论文识别出的两大挑战**：
  1. 如何在大规模工具库上进行有效的**多轮搜索**（检索相关工具、区分相似候选、推理接口兼容性）。
  2. 工具选择涉及多种能力，**联合学习与奖励设计困难**——轨迹级奖励导致监督稀疏，难以优化多轮过程中的细粒度行为。

## 二、方法论

### 核心思想
提出 **ToolSearcher**，一个面向大规模工具选择的强化学习框架，显式建模多轮搜索过程，并为工具选择中的多种能力提供细粒度优化信号。

### 关键技术细节

- **任务定义**：在大规模工具库 \( \mathcal{T} \) 中，给定用户需求 \( q \) 和搜索引擎 \( R \)，目标是找出满足需求的工具集合 \( T_s \)。每个工具文档 \( d_T = (f, I, O) \) 包含功能描述、输入约束、输出模式。优化目标是最大化 \( P_\theta(T_s | q, \mathcal{T}, R) \)。

- **1. 类别约束工具判别（Category-Constrained Tool Discrimination, CCTD）**
  - 将每个工具按功能归入类别 \( C \)，把工具检索从全局搜索转化为**功能相似子空间内的类别约束搜索**。
  - 搜索引擎配备子类搜索函数，搜索步骤形式化为 \( D = R(C^*, Q | \mathcal{T}^{C^*}) \)。
  - **两阶段训练**：第一阶段用 30% 数据在子类约束搜索设置下训练，聚焦区分功能相似工具；第二阶段切换到全局搜索，学习细粒度语义搜索。逐步引导模型学会区分相似工具并在大规模库中有效搜索。

- **2. 事件级搜索建模（Event-level Search Modeling, ESM）**
  - 将搜索轨迹显式建模为搜索事件序列 \( E = (e_1, e_2, \dots, e_k) \)，每个事件 \( e_k = (a_k, R(a_k)) \)，其中 \( a_k \) 是模型动作（搜索调用），\( R(a_k) \) 是返回的工具集。
  - 对检索到的 token 做 **loss masking**，策略梯度只作用于 LLM 生成的 token，避免模型记忆检索内容。
  - 只优化**首次发现未覆盖目标工具**的事件集合 \( E^* \)，避免优化重复搜索的事件。
  - 借鉴 GRPO，进行事件级优势优化：事件级搜索优势 \( \hat{A}_{i,e(t)} \) 定义为该事件首次检索到的目标工具集合 \( \mathcal{T}_{e(t)} \) 内目标工具优势的最大值，其他事件为 0。通过比较该搜索事件与其他轨迹的优势差距，度量每个搜索事件在轨迹中的重要性。

- **3. 轨迹对齐信用分配（Trajectory-Aligned Credit Allocation, TCA）**
  - 针对同一任务的不同轨迹进展差异大的问题（有的完成任务，有的只收集了信息却选不对工具，有的仍在早期搜索阶段），设计分阶段奖励。
  - **选择阶段**：工具选择优势 \( \hat{A}_{i,e_s^{(i)}} \) 仅在搜索过程 \( S_i \) 已包含全部目标工具 \( T_s \) 时计算（基于选择奖励 \( r_s \)），否则置零，避免模型基于训练结果或已搜工具进行不切实际的猜测。
  - **搜索阶段**：对组内已掌握（mastered）的目标工具对应的事件，其事件级优势置零，从而消除对已掌握能力的冗余奖励，只奖励在检索目标工具上优于其他轨迹的搜索事件。
  - 最终 RL 目标 \( J^{(i)}(\theta) = J^{(i)}_{search}(\theta) + J_{select}(\theta) \)，为不同进展阶段的多个搜索事件与选择事件分配对应奖励。

## 六、主要结论与发现

- **整体性能显著提升**：
  - Qwen2.5-7B：相比 Multi-turns，F1 从 **9.8% → 51.3%**，Match 从 **4.6% → 27.8%**；相比次优方法 GDPO 整体 F1 高 1.7%。
  - Qwen3-4B：F1 从 **40.8% → 53.1%**，Match 从 **16.9% → 31.6%**。
- **困难场景优势突出**：在 I3（集合内多工具）场景，ToolSearcher 分别超过 GDPO、MARAG-R1、GSPO、Search-R1 **6.6%/8.3%/9.8%/10.0%**；在所有三个场景的 F1-Inst. 均最高。
- **能力平衡**：能同时兼顾搜索阶段检索（SRecall）与最终选择（Recall），而其他方法常顾此失彼（如 Qwen-7B 基线 SRecall 高但最终选择弱）。
- **OOD 泛化强**：AppWorld 上工具选择的 F1/Recall/SRecall 均最优；TGC/SGC 平均最优（Qwen2.5-7B 超 GDPO 5.7%；Qwen3-4B 超 Search-R1 5.8%/2.9%），在 Difficulty-2（最多 8 个 API）下多数基线 SGC 近乎为零，而本方法仍保持优势。
- **消融结论**：三个组件均有效；ESM 对搜索影响最大（SRecall 在 StableToolBench 掉 22.4%、AppWorld 掉 39.4%，且交互轮数从 4 降到 2）；TCA 提供分阶段稳定信号；CCTD 构造的挑战环境显著提升模型区分相似工具的能力。

## 七、优点

- **问题识别新颖且贴合现实**：明确指出"大规模工具选择"是智能体 RL 的新挑战，并论证知识问答式 RL 不适用于工具可组合性推理。

- **训练策略务实**：CCTD 的两阶段渐进训练（先子类后全局）设计合理，能有效构造困难环境。
- **实验扎实**：域内 + 域外、双骨干、多场景、完整消融，且基线配置统一，公平性较好。
- **可复现性**：公开代码与数据集链接，附录提供详细数据集统计、实现细节、prompt 模板与梯度分析。
- **梯度分析有理论支撑**：附录 F 给出与 GRPO/GDPO/GSPO/MARAG-R1 的梯度系数对比，论证了细粒度优势分配的必要性。
