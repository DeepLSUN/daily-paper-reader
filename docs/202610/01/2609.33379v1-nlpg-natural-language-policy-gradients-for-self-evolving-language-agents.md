## 摘要
大型语言模型智能体日益依赖复合程序进行检索、工具使用、推理和验证，但其失败往往源于局部过程决策。现有的强化学习和提示优化方法通常依赖标量奖励或反复修改整个提示，因而难以在保持智能体冻结的同时捕捉和复用过程性改进。为解决这一问题，我们提出自然语言策略梯度（NLPG），这是一种外部策略记忆方法，可在不改变固定智能体模型参数或程序结构的情况下对其进行改进。NLPG 诊断执行轨迹，将下游反馈沿模块图反向传播，并将反复出现的失败转化为路由局部的自然语言修正，这些修正被聚合为用于后续执行的有界策略更新。在涵盖记忆、推理、指令遵循和证据验证的六个基准上，NLPG 在每个基准上均优于所列最强基线，平均高出 8.71 个百分点。这些结果提供了证据，表明经过评估的过程性经验可以转化为局部且可解释的策略更新，从而实现冻结智能体的持续改进。

## Abstract
Large language model agents increasingly rely on compound programs for retrieval, tool use, reasoning, and verification, yet their failures often arise from local procedural decisions. Existing reinforcement-learning and prompt-optimization approaches typically rely on scalar rewards or repeatedly modify entire prompts, making it difficult to capture and reuse procedural improvements while preserving a frozen agent. To address this problem, We propose Natural-Language Policy Gradients (NLPG), an external policy-memory method for improving a fixed agent without changing its model parameters or program structure. NLPG diagnoses execution traces, propagates downstream feedback backward through the module graph, and converts recurring failures into route-local natural-language corrections that are aggregated into bounded policy updates for subsequent executions. Across six benchmarks covering memory, reasoning, instruction following, and evidence verification, NLPG also outperforms the strongest listed baseline for each benchmark by 8.71 percentage points on average. These results provide evidence that evaluated procedural experience can be transformed into local and interpretable policy updates, enabling continual improvement of frozen agents.

- **核心问题**：如何在**不改变模型参数、程序结构与检索后端**（保持冻结智能体）的前提下，把可评估的过程性经验转化为**局部、可复用、可解释**的策略更新，实现持续改进。

## 2. 方法论：NLPG

### 2.1 核心思想

将"策略执行"与"策略改进"分离：执行时各模块使用其路由对应的策略；评估后把失败沿**已记录的模块依赖图反向传播**，由语言模型 critic 转化为**路由局部的自然语言修正**，跨执行聚合、过滤、排序后形成有界策略更新，仅在后续轮次生效。

### 2.2 关键记号与流程

- **策略记忆**：`M_t = {M^a_t}_{a∈A}`，按任务类别或程序模块索引，存短自然语言过程性指令（非任务答案）。另有共享块 `M^gen_t`（无共享路由时为空）。
- **执行轨迹**：`τ_i = (x_i, {o_{i,j}}^J_i, y_i)`，仅记录可观测输入/输出，不含隐藏推理。

**（A）路由策略记忆与注入**

1. 去重候选池：`C_{t,i,j} = Dedup(M^{a_{i,j}}_t ∪ M^gen_t)`
2. Top-K 选择：`P_{t,i,j} = TopK_{w_t}(C_{t,i,j}, K)`，按历史优先级分数排序
3. 上下文拼接：`c_{i,j}(M_t) = c^base_{i,j} ‖ Format(P_{t,i,j})`，即把有界策略附加到原模块上下文，原程序顺序不变。

**（B）自然语言策略梯度**

- **失败诊断**：`D_B(τ_i, z_i) = (α_i, S_i, e_i)`，α_i 为失败权重（正确=0、失败=1），S_i 为偏差类型集合，e_i 为执行标识（用于统计支持该修正的不同执行数）。
- **沿依赖图反向传播**：借鉴 TextGrad，反馈从终端模块出发，按**逆拓扑序**向直接前驱传播；每个模块由 critic 结合自身输入、输出、上下文与下游反馈，生成局部文本修正，并只向前驱转发相关反馈，无证据则终止传播。
- **输出级与路由级梯度**（语言级变换，非数值导数）：
  - `∂text L_i / ∂y_{i,j} ≜ ∇_LLM(o_{i,j}, F^down_{i,j})`
  - `g^text_{i,j} ≡ ∂text L_i / ∂r_{i,j} ≜ ∇_LLM(M^{a_{i,j}}_t, c_{i,j}, o_{i,j}, F^down_{i,j})`

**（C）跨执行聚合与策略更新**

- 按**路由 a、失败类型 s、归一化修正文本 u**分组；组内代表梯度按失败权重与 critic 置信度选取。
- 保留打分：
  `w_{a,s,u} = |E_{a,s,u}| / max(N_a, |E_a|, 1) · α_i · κ_{i,j}`
  三个因子分别代表**跨执行支持度、失败权重、critic 置信度**（论文明确说明该分数用于排序保留，不是因果效用估计）。
- 经**安全过滤**（去除空、重复、过窄、过长、标签泄漏、不安全指令，并限制每路由候选数）后与当前记忆合并，得到候选后继 `M̃_{t+1}`。
- 候选策略仅在**配对 held-out 验证**满足增益与回归约束时被提升，否则保留 `M_t`；提升后的记忆为下一轮提供 Top-K 策略。
- **生命周期**：单轮评估内策略冻结；构造、选择、最终测试三分区互斥；测试执行不参与任何策略构造或选择。

## 6. 主要结论与发现

- **总体**：6 个基准上 NLPG 均超过各自所列最强基线，**平均高出 8.71 个百分点**。
- **LoCoMo**：Overall **86.72**（+5.17），多跳 +4.14、时序 +10.70、开放域 +9.72、单跳 +2.85；过程复杂度越高的类别收益越大。
- **HaluMem**：Memory Accuracy **96.20**、QA Accuracy **85.37**（但 Memory Integrity 70.25 低于 ProMem 的 73.80）。
- **LongMemEval**：**71.80**，比 ProMem 高 2.23、比 LightMem 高 3.16。
- **GEPA 对齐三任务迁移**：
  - Qwen3-8B：NLPG **59.00** vs GEPA 51.09（+7.91）、GEPA+Merge 48.08；
  - GPT-4.1 Mini：NLPG **63.33** vs GEPA+Merge 59.43（+3.90）。
- **机制结论**：文本梯度（自然语言修正）与**模块级信用分配**是增益关键；策略更新与失败签名提供跨样本反馈累积；NLPG 未获得额外模型调用或更大推理预算。
- **案例结论**：在检索覆盖不变（recall=1.0）情况下，模块局部"specificity 策略"把过泛答案 "musician" 修正为金标 "guitarist"，说明改进来自查询/答案行为调整而非更多证据。

## 7. 优点

- **参数无关、架构无关**：不改模型权重、程序结构、检索索引，仅维护外部策略记忆，部署成本低、可与现有 agent 框架叠加。
- **细粒度信用分配**：把失败归因到具体路由（模块或任务族），而非整段提示，避免"误改无辜模块"。
- **可解释性**：每条策略都是短自然语言指令，携带支持样本标识、效用分数、失败签名与 critic 置信度，便于审计。
- **稳健的更新机制**：有界 Top-K 注入 + 去重 + 安全过滤 + 离线配对验证，候选未通过即回退旧版本，降低"越改越差"风险。
- **严格的数据隔离**：构造/选择/最终测试三分区，按更高层语义单元（对话-用户、历史-问题、claim）切分，并检查标识符重叠。
- **实验叙事完整**：不仅报告端到端精度，还拆解诊断质量、证据接地率、修复成功率与回归率，避免只呈现"涨点"。

checklist 对照提示虽在 basic 之上带来一定增益，但仍无法覆盖需要全局重写或跨句约束协调的失败类型，说明当前"局部文本梯度"在**词法级、结构级约束**上作用域有限；**执行层修复率（strict 8.79%）与诊断质量（路由家族 F1 82.14%）之间的落差**，表明"定位正确"离"改对"仍有相当距离。
- **聚合打分缺乏因果语义**：论文明确指出 `w_{a,s,u}` 只用于候选排序保留，而非效用估计，因此策略优先级与真实收益之间没有理论保证，高排名策略未必是最高增益策略。
- **对 critic 的依赖**：失败签名、偏差类型、修正文本均由 LLM critic 生成，其判断稳定性、跨模型一致性与潜在偏差（如偏好某类改写风格）虽有 F1 与置信度字段部分缓解，但未做 critic 模型替换或人工一致性校验。
- **超参数敏感性未系统评估**：Top-K 的 K、策略上下文长度上限（1000 字符）、置信度阈值、每路由候选数上限等关键超参缺少敏感性曲线或鲁棒性分析。
- **长期演化风险未验证**：策略记忆在多轮持续更新后是否出现冲突、冗余、局部最优或与任务分布漂移失配，仅靠单轮回退与安全过滤规避，缺少长轮次（数十轮以上）实验。
- **任务与场景覆盖有限**：实验集中在记忆问答、推理、指令遵循与证据验证，对代码生成、多模态、具身/工具长链任务未做验证；方法依赖"可自动评估的奖励信号"，对开放主观或无法自动判分的任务适用性未知。
- **路由粒度的先验依赖**：路由集合 `A` 由程序结构或任务类别给定，粒度过粗会削弱信用分配精度、过细则导致样本稀疏与支持度不足，论文未给出路由划分原则的系统性讨论或敏感性实验。

## 9. 与相关工作的定位关系

- **对参数化 RL（GRPO 等）**：NLPG 把"梯度"从数值空间搬到语言空间，用 critic 生成的局部修正替代标量优势估计，代价是放弃了对策略空间的连续可微优化，收益是无需训练、可解释、可局部回退。
- **对提示优化（MIPROv2、GEPA、TextGrad）**：核心差异在**信用分配的粒度**——这些方法多在整段提示或全局文本图层面做改进，NLPG 则先把失败沿模块依赖图反向路由到具体策略槽位，再聚合更新；GEPA 对齐实验正是为验证这一"局部化"带来的增量。
- **对反思/记忆类（Reflexion、ExpeL、Mem0 等）**：NLPG 存的不是交互内容或事实，而是**过程性指令**，且带有失败签名、支持样本数与置信度等元信息，使"经验"可被检索、排序、审计与版本回退，更接近"策略库"而非"记忆库"。

## 10. 结论与启示

NLPG 的核心贡献不在于刷新某个单点 SOTA，而在于提出了一条**"冻结智能体 + 语言级信用分配 + 有界策略记忆"**的持续改进路径：把失败诊断、反向传播、跨执行聚合与验证提升串成闭环，并让每一次更新都保持局部、可解释、可撤销。实验上，6 个基准平均 +8.71 点的提升、以及消融中"文本梯度 > 策略更新 > 路由信用分配"的递减贡献，共同支持了"细粒度归因是主要增益来源"这一机制性结论。

对后续研究的启示有三点：其一，**如何弥合"诊断正确"与"修复成功"的鸿沟**（尤其对全局词法/结构约束）是该方法最直接的改进方向，或需引入更强的局部重写算子或约束感知解码；其二，**critic 的可靠性与可替换性**值得单独研究，包括多 critic 投票、人工校验与偏差审计；其三，**路由划分与策略记忆容量**之间的权衡，以及长轮次下的策略冲突消解，是把该方法推向长期部署必须回答的问题。

## 11. 总体评价

这是一篇**问题定义清晰、机制设计自洽、实验叙事完整**的工作。它准确抓住了复合 LLM 智能体中"信用分配"这一被现有提示优化与记忆方法普遍绕开的痛点，并给出了一个工程上可行、理论上可解释的解法；消融层次分明、数据隔离严格、诊断质量与修复率分开报告，体现出较好的实验诚实度。主要短板在于**开销与算力披露不足**、**部分结论依赖小样本**（如 Open-Domain 13 例、单例干预）、以及**修复能力在全局约束任务上的明显天花板**。综合而言，方法层面的贡献扎实且可复用，但若要作为"通用自演化智能体范式"被采纳，仍需在成本可见性、critic 可靠性、长轮次稳定性与更广任务域上补足证据。
