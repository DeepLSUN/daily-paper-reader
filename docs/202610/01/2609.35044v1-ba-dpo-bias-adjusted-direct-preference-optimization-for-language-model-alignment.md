## 摘要
基于偏好的对齐方法，如直接偏好优化（DPO），使用由人类标注者标记的成对偏好来微调语言模型。然而，标注者对某些属性带有系统性偏差：例如暗示性别或族裔的姓名、人物设定、语言变体、格式惯例或长度。如果不加以妥善处理，这些系统性偏差会在对齐过程中被吸收并放大。现有方法处理长度偏差或标注者分歧，但无法消除对任意属性的偏差。为了解决这一局限，我们提出偏差调整 DPO（BA-DPO），它是 DPO 的推广，为每个标注者针对带有已声明属性的回复增加一个偏差参数。我们证明该目标关于偏差参数是凸的，并且投票能够识别每个标注者的偏差，直至相差一个共享常数。剩下的常数决定了对齐模型的属性率：默认是参考模型的属性率，或目标属性率，我们用它使有偏策略达到统计均等。在带有植入偏差的语料上，DPO 将属性从平衡起点驱动到概率 0.96，而 BA-DPO 消除了该偏移的 81% 到 95%；在具有真实标注者的 MultiPref 上，它消除了 DPO 长度增长的大约一半。这两者在 0.5B 全量微调和 8B LoRA 下都成立，且 KL 不高于 DPO，评判质量无损失。

## Abstract
Preference-based alignment methods such as Direct Preference Optimization (DPO) use pairwise preferences labeled by human annotators to fine-tune language models. However, annotators carry systematic biases toward some attributes: a name that signals a gender or an ethnicity, a persona, a language variety, a formatting convention, or length. If not properly addressed, these systematic biases can be absorbed and amplified during alignment. Existing methods address length bias or annotator disagreement, but fail to eliminate biases toward arbitrary attributes. To address this limitation, we propose Bias-Adjusted DPO (BA-DPO), a generalization of DPO that adds one bias parameter per annotator toward responses carrying a declared attribute. We prove that the objective is convex in the bias parameters and that the votes identify each annotator's bias up to a shared constant. The remaining constant is what fixes the aligned model's attribute rate: by default the rate of the reference model, or a target rate, which we use to bring a biased policy to statistical parity. On a corpus with planted biases, DPO drives the attribute from a balanced start to probability 0.96 and BA-DPO removes 81 to 95\% of that shift; on MultiPref with real annotators it removes about half of DPO's lengthening. Both hold at 0.5B with full fine-tuning and at 8B with LoRA, at no higher KL than DPO and no loss in judged quality.

# BA-DPO 论文详细总结

## 1. 核心问题与整体含义（研究动机与背景）

- **根本假设的失效**：RLHF 与 DPO 等偏好对齐方法都继承 Bradley-Terry 模型的核心假设——人类标注的成对比较是"有噪声但无偏"的质量测量。论文指出这一假设在现实中很少成立。
- **系统性偏差的来源**：标注者对与质量无关的属性存在系统性偏好，包括暗示性别或族裔的姓名、人物设定（persona）、语言变体、格式惯例（如 Markdown）、回答长度等。由于这些偏差在标注者之间**共享**，它们不会相互抵消，反而会在对齐过程中被策略吸收并放大。
- **具体表现**：若标注者一致偏好带有某一人群姓名签名的回答，DPO 目标会把该签名当作质量信号；实验显示，一个初始均衡签名的策略在 DPO 下会把概率推到 0.96 集中在被偏好的标记上。
- **现有方法的局限**：
  - 长度偏差方法（R-DPO、SamPO）把属性固定在目标中，只修正长度，可能把优化压力转移到另一属性（"偏差替代"现象）。
  - 标注者异质性方法（Group-DRO、EM-DPO）刻画标注者之间的**分歧**，而非他们**共同持有**的偏差。
  - ADPO 去除的是与标注者无关的响应级偏移；BiasDPO 处理的是相反问题（用干净偏好数据清洗有偏模型输出）。
- **论文定位**：提出 BA-DPO（Bias-Adjusted DPO），把标注者偏差直接建模为**已声明属性上的加性逐标注者标量**，从而将标注者共享的偏差与质量信号分离并**移除**，而非迁就。

## 2. 方法论

### 2.1 核心思想

- 以 BARP 模型（Ferrara et al., 2024）为基础：标注者 k 感知到的奖励为
  \(\tilde{r}_k(x,y) = r^\star(x,y) + \theta_k \delta_g(x,y)\)，其中 \(\delta_g \in \{0,1\}\) 表示响应是否带有待去除的属性，\(\theta_k\) 为标注者 k 的偏差参数。
- 偏好概率为 \(p_k(y_1 \succ y_2|x) = \sigma(r^\star(x,y_1)+\theta_k\delta_g(x,y_1) - r^\star(x,y_2)-\theta_k\delta_g(x,y_2))\)。

### 2.2 关键技术细节

- **兼容 DPO 重参数化（Proposition 2）**：将 DPO 隐式奖励代入上式，两个 \(\beta\log Z(x)\) 完全相消，偏差项因是加性且不含配分函数而原样通过。因此无需奖励模型、无需额外网络，保持单策略结构。
- **BA-DPO 损失**：
  \[
  \mathcal{L}_{\text{BA-DPO}} = -\mathbb{E}_{(k,x,y_w,y_l)}\left[\log \sigma(u + b_k)\right]
  \]
  其中 \(u = \beta\log\frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta\log\frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)}\)，\(b_k = \theta_k(\delta_g(x,y_w)-\delta_g(x,y_l)) = \theta_k \Delta\delta\)。
- **梯度分析**：策略梯度是 DPO 梯度，但重要性权重由 \(\sigma(-u)\) 变为 \(\sigma(-u-b_k)\)。偏差偏袒胜者时权重缩小（该比较"教得少"），胜者逆偏差取胜时权重增大，同组比较 \(b_k=0\) 则退化为 DPO。
- **三种参数化变体**：
  - **逐标注者**：每个标注者自由参数 \(\{\theta_k\}\)。
  - **池化（pooled）**：所有比较共享一个属性级标量 \(\theta\)（无标注者身份时可用）。
  - **共享均值**：\(\theta_k = \bar\theta + \varepsilon_k\)，均值在每个跨组比较上更新，偏差 \(\varepsilon_k\) 承载个体结构。
- **多属性推广**：\(b_k = \vec\theta_k^\top(\vec g_{y_w} - \vec g_{y_l})\)，每标注者每属性一个参数。

### 2.3 理论刻画（核心贡献）

- **Proposition 2**：偏差项不进入配分函数，故 BA-DPO 与 DPO 的单策略重参数化兼容。
- **Theorem 3（可识别性）**：损失关于奖励值与 \(\theta\) 联合凸；所有极小值点给出相同的判断概率；若标注者池连通，极小值恰为 \((\hat r + c\delta_g + h,\ \hat\theta - c\mathbf{1})\)。因此**任意两标注者偏差之差被投票唯一确定，但均值 \(\bar\theta\) 不可识别**。
- **Corollary 4（奖励-偏差退化）**：\(r \mapsto r+c\delta_g,\ \theta_k \mapsto \theta_k - c\) 不改变任何判断概率。偏差 \(\varepsilon_k\) 在所有极小值点取相同值。
- **Proposition 5（可分表性）**：共享分量 \(\bar\theta\delta_g\) 是 \((x,y)\) 的函数，可被策略隐式奖励表示；偏差分量 \(\varepsilon_k\delta_g\) 依赖标注者身份 \(k\)，策略不可见，除非所有 \(\varepsilon_k=0\)，否则任何策略都无法表示。
- **Proposition 6（学习速度）**：共享均值参数每步移动量是朴素逐标注者均值移动量的 \(m\) 倍（\(m\) 为标注者数）；Adam 下约为 \(\sqrt{m/b}\) 量级。
- **锚定选择**：退化方向上的自由常数 \(c\) 决定对齐策略的属性率。
  - **参考锚定**：保持参考模型的属性率（论文默认，所有实验从 \(\pi_{\text{ref}},\theta=0\) 出发）。
  - **目标锚定**：通过一维搜索设定 \(c\)，使输出达到指定率（如统计均等 0.5），可用于修正已有偏见的 DPO 策略。

### 3.4 评价指标

- **属性率**：Signed-UltraFeedback 从策略在签名位置的姓名概率精确读出；MultiPref 长度用平均 token 数，格式用重加权到参考长度分布的 markdown 率。
- **偏差消除比例**：\((rate_{DPO}-rate_{arm})/(rate_{DPO}-rate_{ref})\)，0% 为 DPO，100% 为参考。
- **留出差距（held-out gap）**：跨组与同组留出判断上隐式奖励准确率之差，接近零表示偏差已离开隐式奖励。
- **RM / RM⁻**：Skywork-Reward-V2-Qwen3-1.7B 评判分数，RM⁻ 为剥离属性后得分。
- **KL**：策略自身生成上对参考的逐 token KL。

## 6. 主要结论与发现

- **DPO 确实吸收偏差**：在 Signed-UltraFeedback 上，0.5B 和 8B 均从近均衡参考被推到 0.96–0.99；MultiPref 上 DPO 使回答变长 96 token（0.5B）/68 token（8B），格式属性上也打开 0.066–0.067 的 held-out gap。
- **BA-DPO 有效去偏**：
  - 植入语料：消除 DPO 偏移的 **81%–95%**（性别 89–95%，族裔 81–93%），KL 约为 DPO 的 2/3，评判质量无损失。
  - MultiPref 长度：消除约 **45%–51%** 的增长，gap 降至 0.00–0.05。
  - MultiPref 格式：gap 从 0.066 降至 0.000–0.004。
- **两个变体结果相近**：pooled（每属性一个标量）与 \(\bar\theta+\varepsilon_k\)（均值+60 个偏差）给出几乎相同的策略（差异约 0.01），符合 Proposition 5 的预测——只有共享均值能进入策略，偏差分量只用于刻画标注者。
- **偏差参数能恢复标注者个体偏差**：学习到的 \(\theta_k\) 与植入值相关 r=0.95（性别）/0.98（族裔），投票预测达到植入 \(\theta_k\) 的天花板；pooled 标量在反向类上仅相当于随机。
- **基线表现不佳**：Group-DRO 只消除 4–
