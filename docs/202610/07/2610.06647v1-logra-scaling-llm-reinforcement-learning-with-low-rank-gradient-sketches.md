## 摘要
强化学习（RL）极大地提升了大语言模型（LLM）的能力，但其内存需求仍是更广泛采用的障碍。我们提出 LoGRA，一种面向 RL 后训练的方法，通过将有用的学习信号保留在低秩梯度草图中来降低内存。这些紧凑表示同时支持模型更新和高效策略同步。为防止过大的更新破坏学习，我们在梯度压缩之外引入预测-KL 步长控制，它在应用每次更新前估计策略变化并相应调整更新幅度。在推理任务上，LoGRA 在不牺牲性能的情况下将平均训练内存降低多达 45.7%。它还使一个 27B 参数模型能够在单个八 GPU 节点上稳定训练超过 1,100 步，而稠密 Adam 在此会内存不足，从而使此前因内存不可行的 RL 训练变得实用。代码可在 \href{https://github.com/skzhang1/labs-molt/tree/logra/examples/scripts/logra}{Molt 库} 中获取。

## Abstract
Reinforcement learning (RL) has greatly advanced the capabilities of large language models (LLMs), but its memory demands remain a barrier to broader adoption. We introduce LoGRA, an approach to RL post-training that reduces memory by retaining useful learning signals in low-rank gradient sketches. These compact representations support both model updates and efficient policy synchronization. To prevent overly large updates from disrupting learning, we complement gradient compression with predicted-KL step control, which estimates policy changes before applying each update and adjusts its magnitude accordingly. Across reasoning tasks, LoGRA reduces average training memory by up to 45.7\% without sacrificing performance. It also enables stable training of a 27B-parameter model for over 1,100 steps on a single eight-GPU node, where dense Adam runs out of memory, making previously memory-infeasible RL training practical. Code is available in the \href{https://github.com/skzhang1/labs-molt/tree/logra/examples/scripts/logra}{Molt library}.

## 1. 核心问题与整体含义

- **研究动机**：强化学习（RL）已成为提升 LLM 推理与自我改进能力的关键后训练手段，但其显存开销远超模型本身。论文举例：7B 参数的 Qwen 模型 BF16 权重约 14 GB，而 Adam 的两个 FP32 动量缓冲就额外需要约 56 GB，尚未计入梯度与激活。
- **核心痛点**：能够"运行"模型的硬件，往往不足以"训练/改进"模型，RL 后训练的显存门槛限制了更广泛的研究与应用。
- **整体含义**：作者认为，在二值结果奖励下，每条生成响应只提供极少的正确性信号，因此完整梯度中大量信息可能是冗余的；用紧凑的低秩表示承载学习信号，有望在几乎不损失性能的前提下显著降低显存，并让更大模型的 RL 训练在有限硬件上变得可行。

## 2. 方法论

### 2.1 核心思想

- 用**低秩梯度草图（low-rank gradient sketch）**替代完整梯度：不物化选定权重矩阵的完整梯度，而是在反向传播中直接累积投影后的紧凑表示。
- 同一压缩表示既用于**权重更新**，也复用于**rollout 策略同步**，把压缩收益从训练显存扩展到通信开销。
- 引入**预测-KL 步长控制**，在应用更新前估计策略概率变化，避免过大更新破坏已学行为。

### 2.2 关键技术细节

- **草图构造**：对权重矩阵 \(W \in \mathbb{R}^{d\times k}\)，选秩 \(r \ll \min(d,k)\) 与随机投影 \(A \in \mathbb{R}^{r\times k}\)，定义草图 \(S = G A^\top \in \mathbb{R}^{d\times r}\)。存储量从 \(dk\) 降至 \(dr\)。
- **直接累积**：不先算完整梯度再压缩，而是在每个 microbatch 的反向过程中，将权重梯度计算所需的输入先投影，再与反向导数相乘，直接把贡献累加到 fp32 的 \(S\)。
- **低秩更新**：用 \(\hat{G} = S A\) 近似完整梯度，更新形式为 \(W \leftarrow W - \alpha\eta U A\)，其中 \(U\) 是经优化器调整后的草图（基础 SGD 中 \(U=S\)），\(\alpha\) 为预测-KL 控制器给出的缩放因子，\(\eta\) 为名义步长。
- **投影刷新**：每步重新采样 \(A\)，使连续更新落在不同子空间，其和不必受限于秩 \(r\)；\(A\) 独立于当前 batch 采样、不学习，默认取 Rademacher 随机符号 \( \pm 1/\sqrt{r}\)。
- **应用范围**：仅对 attention 与 MLP 投影矩阵施加草图更新，其余参数固定；更新直接合并进权重，**无持久 adapter 分支**。
- **内存与同步收益**：以 \(d=k=4096, r=64\) 为例，fp32 梯度累加器从 64 MiB 降至 1 MiB；同步时 rollout 引擎由种子再生 \(A\)，仅需传输 \(O(dr)\) 的因子与元数据，而非完整 \(d\times k\) 更新。

### 2.3 预测-KL 步长控制

- **动机**：参数空间的小更新仍可能显著改变策略输出概率，借鉴 TRPO 的信任域思想控制更新幅度。
- **二阶近似**：设提议更新为 \(D\)，应用 \(\theta \leftarrow \theta + \alpha D\)。在少量上下文 \(\mathcal{P}\) 上比较当前策略与提议策略的 next-token 分布，得到
  \[
  \frac{1}{|\mathcal{P}|}\sum_{s\in\mathcal{P}} D_{\mathrm{KL}}\big(\pi_\theta(\cdot|s)\,\|\,\pi_{\theta+\alpha D}(\cdot|s)\big) \approx \alpha^2 q(D).
  \]
- **曲率估计**：\(q(D) = \frac{1}{2|\mathcal{P}|T^2}\sum_{s\in\mathcal{P}}\mathrm{Var}_{v\sim p(s)}[\dot{z}_v(s)]\)，其中 \(\dot{z}_v(s)\) 是 token 分数沿 \(D\) 的初始变化率，方差按当前 token 概率加权。该估计只需考察被选中的上下文，无需存储稠密梯度或曲率矩阵。
- **预算缩放**：给定 KL 预算 \(\delta>0\)，取
  \[
  \alpha = \min\big\{\alpha_{\max},\ \sqrt{\delta/q(D)}\big\},
  \]
  即预测 KL 与步长平方成正比，超出预算则缩小、低于预算则放大但受 \(\alpha_{\max}\) 限制；预算可设为常数或逐步退火。

### 2.4 算法流程（Algorithm 1 概要）

- 初始化 rollout 权重；每步采样响应并构造损失。
- 对每个选定矩阵：从新种子采样 \(A\)，初始化 \(S=0\)，逐 microbatch 直接累加 \(S \leftarrow S + (\nabla_W \mathcal{L}_m) A^\top\)。
- 由 \(S\) 得到 \(U\)（或经草图优化器处理），由预测-KL 决定 \(\alpha\)。
- 训练端执行 \(W \leftarrow W - \alpha\eta U A\)；向 rollout 发送 \(\alpha\eta U\) 与种子；rollout 再生 \(A\) 并施加相同更新，等待同步完成。

### 2.5 配套优化器 RowAdam

- 行级自适应缩放：对每个矩阵仅维护 \(d\) 个二阶矩统计，不含一阶动量；\(\beta_2=0.95\)，\(\epsilon_t\) 取行均值的 \(10^{-8}\) 倍。
- 缩放后再将 \(\tilde{U}\) 重新归一化以匹配原草图 Frobenius 范数，保持整体幅度；行统计跨投影刷新持续存在。
