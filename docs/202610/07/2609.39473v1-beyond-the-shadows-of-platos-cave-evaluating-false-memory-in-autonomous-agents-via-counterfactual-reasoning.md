## 摘要
自主智能体日益依赖记忆来泛化到其训练环境之外。然而，智能体受限于其已见和已信的内容，在未见环境中利用此类记忆可能会将偏差引入其内部信念。我们将这一现象形式化为虚假记忆，它可能源于伪相关、环境偏移和知识冲突。尽管其重要性，虚假记忆难以评估，因为它源于智能体内部信念，并容易与普通的泛化失败相混淆。因此，我们提出FAME，一个免训练的框架，通过反事实推理下智能体信念的演化来评估虚假记忆。具体而言，反事实场景揭示了在假设干预下记忆的潜在概念发生偏移时信念如何变化；因此，测量由此产生的概念漂移为区分忠实记忆与虚假记忆提供了信号。此类概念可以在答案生成之前从智能体隐藏状态中估计，从而避免奖励设计或答案采样的需要。实证实验表明，仅监控答案往往无法检测虚假记忆，而FAME在虚假记忆设置下达到76.2% - 96.7%的AUROC，并在现实基准上以3.4% - 23.3%的优势优于最佳基线，涵盖数学推理（GSM-Symbolic）、代码生成（GitChameleon）和复杂推理（BigBench-Hard）。我们进一步发布了相应的反事实模板，并促进未来关于虚假记忆的研究。

## Abstract
Autonomous agents increasingly rely on memory to generalize beyond their training environments. However, agents are bounded by what they have seen and believed, and leveraging such memories in unseen environments can introduce biases into their internal beliefs. We formalize this phenomenon as \textit{false memory}, which can arise from spurious correlations, environment shifts, and knowledge conflicts. Despite its importance, false memory is difficult to evaluate because it stems from agent internal beliefs and is easily confounded with ordinary generalization failures. Therefore, we propose FAME, a training-free framework that evaluates false memory through the evolution of agent beliefs under counterfactual reasoning. Specifically, counterfactual scenarios reveal how beliefs change as the latent concept of memory shifts under hypothetical interventions; thus, measuring the resulting concept drift provides a signal for distinguishing faithful versus false memory. Such concepts can be estimated from agent hidden states before answer generation, avoiding the need for reward design or answer sampling. Empirical experiments reveal that simply monitoring answers often fails to detect false memory, while FAME achieves AUROCs of 76.2% - 96.7% across false-memory settings, and outperforms the best baseline by 3.4% - 23.3% across realistic benchmarks, spanning math reasoning (GSM-Symbolic), code generation (GitChameleon), and complex reasoning (BigBench-Hard). We further release corresponding counterfactual templates and facilitate future research on false memory.

## 2. 方法论：FAME 框架

### 2.1 核心思想

- **免训练、免答案生成、免奖励设计**：通过反事实推理下智能体信念的演化来评估虚假记忆。
- **关键洞察**：反事实场景揭示记忆的潜在概念在假设干预下如何漂移；测量概念漂移可区分忠实记忆与虚假记忆。
- **概念提取时机**：概念可在**答案生成之前**从智能体隐藏状态中估计，避免奖励校准和答案采样。

### 2.2 问题形式化

- 智能体存储经验于记忆空间 M，检索记忆集 M = {(qᵢ, aᵢ)}，诱导潜在概念 θ_M = f(M)。
- 虚假记忆定义为：将 θ_M 应用于目标查询 q̂ 时奖励显著低于记忆任务奖励：r̂(θ_M | q̂) ≪ E[r(θ | q,a)]。
- 评估目标：测量概念漂移与容许区域的对齐程度，F(M) = E_q'[⟨Δθ(q'), A(q')⟩]。

### 2.3 结构因果模型（SCM）与反事实推理

- **SCM 建模**：M = f_M(U_M)，Θ_M = f_ΘM(M, U_ΘM)，Q = f_Q(U_Q)，Θ' = f'(Q, Θ_M, U')。
- **三步反事实框架**：
  1. **溯因（Abduction）**：根据证据估计噪声，固定外生变量。
  2. **行动（Action）**：对查询进行干预 do(Q = q')，删除 U_Q → Q 但保留记忆概念。
  3. **预测（Prediction）**：推断反事实更新概念 Θ'_{Q=q'}。

### 2.4 关键理论结果

- **命题 1（反事实可识别性）**：马尔可夫 SCM 下，P(Θ'_{Q=q'} | M=m) = P(Θ' | do(Q=q'), M=m) = P(Θ' | Q=q', M=m)。
- **定理 1（概念漂移可识别性）**：通过孪生网络，概念漂移表征为处理组效应（ETT）：ETT = γ_h(P(Θ'|q',m)) − γ_h(P(Θ'|q₀,m))，可通过上下文学习构造并经验近似。
- **定理 2（隐藏状态概念近似）**：答案提交位置的残差流隐藏状态 h(M+q) 提供预测概念的近似表示，误差由演示代表性和隐藏状态充分性界定。
- **定理 3（免答案可识别性）**：Δℓ = ⟨Δθ, ḡ_O⟩，反事实对答案偏好的影响等于隐藏状态漂移在答案方向上的投影。
- **推论 1（边界解释）**：虚假记忆识别边界为容许概念空间 A 到读出空间 ḡ_O 的投影 B_O。

### 2.5 算法流程（Alg. 1）

1. 构造反事实查询 Q'。
2. 对每个 q'，计算概念漂移：Δθ = (1/N) Σ [h(M₋ᵢ+q') − h(M₋ᵢ+qᵢ)]，其中 M₋ᵢ 为留一法。
3. 根据期望类型确定读出方向：
   - **鲁棒性期望**（A = Θ_M）：ḡ_O = Cov(Δθ)，虚假记忆 ⟺ Δθ 越过边界。
   - **适应性期望**（A = Θ\Θ_M）：ḡ_O = w_{Y(q')} − w_{Y(M)}，虚假记忆 ⟺ Δθ 未越过边界。
4. 输出 F_M(q')。

### 2.6 虚假记忆分类与反事实查询构造

- **伪相关**：q' = T_sc(s(M), c(q))，s 识别伪特征，c 改变上下文；分为"伪相关保持"（需适应）和"伪相关移除"（需鲁棒）。
- **环境偏移**：q' = T_env(e(M))，e 提取环境并调整，期望概念鲁棒。
- **知识冲突**：q' = T_kc(κ(M))，T_kc 变换知识以增加对先验的吸引，期望概念稳定。

## 6. 主要结论与发现

- **FAME 有效性**：受控设置下 AUROC 达 76.2%–96.7%，真实基准上超越最佳基线 3.4%–23.3%。
- **仅监控答案无法检测虚假记忆**：Fig. 4 显示正确与虚假记忆的答案置信度分布严重重叠。
- **大幅概念漂移不一定意味着虚假记忆**：关键在于漂移是否越过相关边界（Fig. 6）；Cloud distance 和 Task vector 等依赖漂移幅度的方法持续欠佳。
- **免答案保证**：概念漂移与行为边际变化强相关（Pearson r = 0.48–0.98，p < 0.001），支持定理 3。
- **记忆规模效应**：演示越多，概念越集中，虚假记忆率越高（伪相关保持）；知识冲突中记忆保留率随规模增加。
- **跨模型泛化**：FAME 在 Llama-8B、Mistral-7B、Qwen2.5-3B 上均优于基线。

- **理论扎实**：提供完整的 SCM 建模、反事实可识别性证明、概念漂移 ETT 表征、隐藏状态近似定理和无答案可识别性定理。

- **超参数敏感性**：概念提取层、读出方向估计、留一法采样数、期望类型选择等均可能影响性能；论文虽进行了层扫描，但未系统分析所有超参数对 AUROC 的敏感度。

- **模型与任务覆盖有限**：实验主要针对指令微调模型（3B–8B），未验证基座模型、更大规模模型或多模态智能体；任务集中于文本推理与代码，未涉及具身决策、长程规划等场景。
- **评估指标单一**：仅以 AUROC 衡量区分能力，未报告精确率、召回率、F1、校准误差等，难以全面反映实际部署中的阈值选择与误判代价。
- **未讨论伦理与安全影响**：虚假记忆评估可被用于探测模型内部信念，也可能被滥用为操纵智能体的工具；论文未涉及隐私、安全或责任归属问题。

## 9. 总体评价与启示

- **理论贡献突出**：论文将因果推断中的反事实推理系统引入智能体记忆评估，形式化“虚假记忆”并给出可识别性证明，为后续研究提供了严谨的分析框架。
- **方法设计巧妙**：FAME 免训练、免答案生成、免奖励设计，直接从隐藏状态提取概念漂移，并通过鲁棒性/适应性期望统一处理三类虚假记忆，兼具理论优雅与工程可行性。
- **实验验证充分**：在受控设置与三个真实基准上，跨四种 LLM 架构，FAME 均优于多种代表性基线；消融、鲁棒性、层扫描、记忆规模分析等增强了结论可信度。
- **反直觉发现具有启发性**：仅监控答案置信度无法检测虚假记忆；概念漂移幅度大并不等于虚假记忆，关键在于是否越过相关边界。这些结论对智能体记忆监控与适应策略设计具有重要参考价值。
- **未来方向明确**：论文指出需探索自动反事实生成、虚假记忆缓解方法、更广泛任务与模型验证，以及将评估嵌入智能体在线决策闭环。所发布的反事实模板套件也为社区提供了可复用的基准资源。
