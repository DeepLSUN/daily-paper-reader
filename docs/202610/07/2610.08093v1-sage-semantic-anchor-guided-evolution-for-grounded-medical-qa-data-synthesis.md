## 摘要
开发用于临床任务（如医学问答（QA））的可靠模型，受到高质量、专家标注训练数据可用性有限的严重制约。严格隐私要求，以及在资源有限的临床环境中使用大型开源语料库或专有云 API 的不切实际性，进一步加剧了这一挑战。为应对这些障碍，我们提出 SAGE（Semantic Anchor-Guided Evolution），一种新颖的数据合成框架，使小型本地部署模型能够生成高质量的医学训练数据。SAGE 利用 MeSH 等轻量级公开分类体系作为语义锚点，施加结构化先验，以有效引导并为数据生成过程提供依据。其核心在于，SAGE 迭代地交替进行原子式（基于单个概念）和关联式（基于关系）合成，从极少量种子中自举训练数据。该方法无需大量医学文档集合，也不依赖外部 API，为本地数据创建提供了实用解决方案。在多个医学问答基准上的大量实验表明，使用 SAGE 合成数据微调的模型始终优于使用自衍生或传统基于文档范式训练的模型，凸显了其在医学 LLM 开发中数据效率和资源利用方面的切实提升。代码见 https://github.com/DIaacKr/SAGE。

## Abstract
Developing reliable models for clinical tasks, such as Medical Question Answering (QA), is severely constrained by the limited availability of high-quality, expert-annotated training data. This challenge is exacerbated by stringent privacy requirements and the impracticality of utilizing large open-source corpora or proprietary cloud APIs within resource-limited clinical settings. To address these obstacles, we introduce SAGE (\textit{Semantic Anchor-Guided Evolution}), a novel data synthesis framework that enables small, locally deployed models to generate high-quality medical training data. SAGE leverages lightweight, publicly available taxonomies such as MeSH as semantic anchors, imposing a structured prior to effectively guide and ground the data generation process. At its core, SAGE iteratively interleaves atomic (individual concept-based) and associative (relation-based) synthesis, bootstrapping training data from minimal seeds. This approach eliminates the need for large collections of medical documents or reliance on external APIs, providing a practical solution for on-premises data creation. Extensive experiments across multiple medical question-answering benchmarks demonstrate that models fine-tuned with SAGE-synthesized data consistently outperform those trained using self-derived or conventional document-based paradigms, highlighting tangible improvements in data efficiency and resource utilization for medical LLM development. Code is available at https://github.com/DIaacKr/SAGE.

## 2. 方法论：核心思想与关键技术细节

- **核心思想**：神经-符号演化。LLM 在文本空间生成医学问答，MeSH 分类体系提供离散概念空间，用于锚定、投影和更新生成轨迹。
- **问题设定**：
  - 固定分类体系记为 \(T=(V,E)\)，\(V\) 为医学概念节点，\(E\) 为层级关系。
  - 维护活跃锚配置集合 \(S^{(t)} \subseteq 2^V \setminus \{\emptyset\}\)，每个锚配置 \(A\) 包含一个或多个 MeSH 概念。
  - 映射函数 \(\phi_T\) 将医学问题映射为 MeSH 概念集合，作为语义锚配置。
  - 初始锚群体来自种子数据中非空映射：\(S^{(0)} = \{\phi_T(q_x) \mid x \in D_{\text{seed}}, \phi_T(q_x) \neq \emptyset\}\)。
- **双轨生成**：
  - **原子生成**：处理单概念锚 \(A=\{c\}\)。检索 MeSH 定义 \(\delta(c)\) 和允许限定词 \(Q(c)\)，采样临床限定词，生成定义中心、事实导向的 QA。
  - **关联生成**：处理多概念锚 \(|A|>1\)。从种子和已接受样本构成的 few-shot 池中采样示例，生成连接多个概念、需要多步推理的临床场景 QA。
- **符号选择与锚演化**：
  - **一致性检查**：用 Self-Consistency，生成 K 个辅助答案，若候选答案等于多数投票则接受。
  - **多样性控制**：维护概念和配置级出现计数，预算耗尽的锚不再采样。
  - **符号投影**：接受样本的问题重新映射回 MeSH，得到投影锚配置。
  - **语义突变**：生成过程中自然出现的新概念 \(\Delta(x)=\phi_T(q_x)\setminus A_{\text{in}}\) 被实例化为单例锚，进入下一轮原子生成。
  - **群体更新**：\(S^{(t+1)} = S^{(t)}_{\text{proj}} \cup S^{(t)}_{\text{mut}}\)，分类体系固定，活跃锚群体迭代演化。
- **流程概括**：少量种子 → 锚初始化 → 原子/关联并行生成 → 一致性筛选 → MeSH 投影与新概念发现 → 更新锚群体 → 下一轮迭代，逐步从原子事实扩展到复杂关联推理。
