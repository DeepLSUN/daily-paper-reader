## 摘要
激活稀疏化通过将不重要的激活置零，从而跳过相应计算，加速大语言模型（LLM）推理。然而，现有免训练方法做出了不同的权衡：基于阈值的方法（如 TEAL）使稀疏度水平适应每个 token，但无法严格控制实际实现的稀疏度；而基于 TopK 的方法（如 WINA）强制固定稀疏度水平，但对每个 token 使用相同的稀疏度预算。二者还在不同 transformer 块之间应用相同预算，尽管块敏感性差异很大。我们提出 TopK-Guided，一种免训练方法，通过将受限的 token 级稀疏度自适应与敏感性感知的块级预算分配相结合，解决了这两个局限。在 Llama-2 和 Llama-3 模型上，TopK-Guided 在保持与 WINA 基本相同的稀疏度相关投影计算量的同时，持续提升了困惑度和下游准确率，且在高稀疏度下增益最大。消融实验表明，这两个组件提供了互补的改进。

## Abstract
Activation sparsity speeds up large language model (LLM) inference by setting unimportant activations to zero so that the corresponding computations can be skipped. Existing training-free methods, however, make different trade-offs: threshold-based methods such as TEAL adapt the sparsity level to each token but do not tightly control the realised sparsity, while TopK-based methods such as WINA enforce a fixed sparsity level but use the same sparsity budget for every token. Both also apply the same budget across transformer blocks, despite large differences in block sensitivity. We introduce TopK-Guided, a training-free method that addresses both limitations by combining bounded token-level sparsity adaptation with sensitivity-aware block-level budget allocation. Across Llama-2 and Llama-3 models, TopK-Guided consistently improves perplexity and downstream accuracy over TEAL and WINA while preserving essentially the same sparsitydependent projection compute as WINA, with the largest gains at high sparsity. Ablations show that both components provide complementary improvements.

- **核心矛盾**：现有免训练激活稀疏方法各有取舍：
  - **TEAL**：基于阈值 \(\tau\)，能按 token 自适应决定稀疏模式，但实际稀疏率会偏离目标 \(s\)，导致加速不可预测。

  1. token 级稀疏自适应；

## 2. 方法论

### 2.1 总体框架

- 方法建立在 **WINA** 之上，保留其：
  - 残差流的张量旋转（来自 SliceGPT，计算不变）；
  - 块内按投影的贪心稀疏分配；
  - 仅在 decode 阶段应用稀疏化。
- TopK-Guided 只修改两个位置：
  1. **掩码规则**：从 WINA 的固定 TopK 改为带预算约束的 TopK-Guided masking；
  2. **块级预算**：从统一预算 \(s\) 改为敏感度感知的块预算 \(s_i\)。

### 2.2 TopK-Guided Masking

- 核心观察：TEAL 校准得到的阈值 \(\tau\) 已编码每个投影的典型激活分布，可低成本估计当前 token 的“自然稀疏度”。
- 对当前 decode token \(t\)，计算：
  \[
  \hat{s}(t)=\frac{1}{d}\sum_{j=1}^{d}\mathbb{1}[|h_j^{(t)}|<\tau]
  \]
  即该 token 中低于阈值 \(\tau\) 的激活比例。
- 将 \(\hat{s}(t)\) 裁剪到目标 \(s\) 附近的 \(\pm\delta\) 区间：
  \[
  s^*(t)=\min(s+\delta,\max(s-\delta,\hat{s}(t)))
  \]
- 最终保留数量：
  \[
  k(t)=\max(1,\lfloor d(1-s^*(t))\rfloor)
  \]
  并应用 TopK 选择。WINA 的精确 TopK 是 \(\delta=0\) 的特例。
- 实现上用 quickselect 找截断值，复杂度 \(O(d)\)，避免 WINA 实现中的 \(O(d\log k)\) 部分排序。
- 论文固定 \(\delta=0.01\)，使实际每 token 稀疏率最多偏离目标 1 个百分点，兼顾可预测加速与 token 自适应。

### 2.3 Sensitivity-Aware Block Sparsity

- **敏感度测量**：对块 \(i\)，在校准集 \(D\) 上以固定探针稀疏率 \(\bar{s}\) 稀疏化该块，计算输出相对变化：
  \[
  e_i=\frac{1}{|D|}\sum_{x\in D}\frac{\|f_i(x)-\hat{f}_i(x;\bar{s})\|_2}{\|f_i(x)\|_2+\epsilon}
  \]
  其中 \(f_i(x)\) 为稠密输出，\(\hat{f}_i\) 为稀疏输出。\(e_i\) 越大越敏感。
- **预算重分配**：设 \(\bar{e}\) 为所有块的平均敏感度，则块 \(i\) 的预算为：
  \[
  s_i=\min(0.95,\max(0.05,s+\lambda(\bar{e}-e_i)))
  \]
  敏感块 \(e_i>\bar{e}\) 获得低于 \(s\) 的预算，鲁棒块获得高于 \(s\) 的预算，平均仍接近全局目标 \(s\)。
- \(\lambda\ge 0\) 控制重分配强度；上下限 \([0.05,0.95]\) 防止块过密或过稀。
- 每个 \(s_i\) 再输入 WINA 原有的块内贪心投影分配，不新增其他机制。
- 新增超参：裁剪边距 \(\delta\)（固定 0.01）、探针稀疏率 \(\bar{s}\)、重分配强度 \(\lambda\)。
