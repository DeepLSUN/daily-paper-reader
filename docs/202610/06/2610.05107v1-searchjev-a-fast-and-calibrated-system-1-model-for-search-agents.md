## 摘要
搜索智能体会反复就相关性、证据充分性和搜索动作做出简短决策。使用生成式语言模型进行这些决策会带来延迟和不可靠的置信度。我们提出 SearchJev，一种快速且经过校准的系统1模型，将搜索决策与系统2推理和生成分离。给定搜索状态和决策模式，SearchJev 直接对合法选项进行评分，而无需自回归输出生成。我们提出用于校准决策的软标签学习（SLCD），以从不确定监督中学习决策概率并校准其置信度。在双系统搜索智能体中，SearchJev 处理简短决策，并将不确定判断委托给系统2，后者保留规划、查询生成和答案组织。我们还提出 SearchDecision-Bench，一个统一六类搜索决策以用于训练和评估的基准。在 SearchDecision-Bench 上，SEARCHJEV 相比同等规模的 Qwen3.5 自回归模型提升了决策质量，实现 5.2–5.3 倍的决策速度，并将平均期望校准误差降低 41–74%。在 BrowseComp-Plus 上，双系统智能体在主动搜索时间上实现 3.7–4.7 倍加速，同时将答案准确率从 45% 提升至最高 54%。

## Abstract
Search agents repeatedly make short decisions about relevance, evidence sufficiency, and search actions. Using generative language models for these decisions introduces latency and unreliable confidence. We present SearchJev, a fast and calibrated System-1 model that separates search decisions from System-2 reasoning and generation. Given a search state and a decision schema, SearchJev directly scores legal options without autoregressive output generation. We propose Soft-Label Learning for Calibrated Decisions (SLCD) to learn decision probabilities from uncertain supervision and calibrate their confidence. In a dual-system search agent, SearchJev handles short decisions and delegates uncertain judgments to System 2, which retains planning, query generation, and answer composition. We also introduce SearchDecision-Bench, a benchmark unifying six types of search decisions for training and evaluation. On SearchDecision-Bench, SEARCHJEV improves decision quality over same-size Qwen3.5 autoregressive models, achieves 5.2-5.3 times faster decisions, and reduces average expected calibration error by 41-74%. On BrowseComp-Plus, the dual-system agents achieve a 3.7-4.7 times speedup in active search time while improving answer accuracy from 45% to up to 54%.

# SearchJev 论文总结

## 1. 核心问题与研究动机

- **背景**：基于 LLM 的搜索智能体（search agents）在推理与检索之间交替，需要反复做出大量"短决策"——例如：这段段落是否相关？证据是否充分到可以作答？下一步该探索哪个链接？
- **核心痛点**：
  - 用生成式语言模型做这些决策时，必须逐 token 自回归解码，带来**高延迟**；
  - 其置信度（无论是语言化表达还是从 token 概率导出）往往**校准不良**，难以判断某个决策能否被直接接受，还是需要进一步推理。
- **现有方案的两难**：
  - 任务专用重排序器（如 monoT5）或查询复杂度分类器只支持单一功能，需为每种决策训练单独模型；
  - 提示通用 LLM 可覆盖多任务，但依赖自回归生成短判断，效率低且置信度不可靠。
- **论文定位**：受 Kahneman 双系统理论与 Jev（Almeida, 2026）"类型化概率输出"思想启发，提出 **SearchJev**——一个快速且校准良好的 System-1 模型，将短搜索决策与 System-2 的推理、规划、生成相分离。

## 2. 方法论

### 2.1 核心思想
将搜索判断建模为**模式条件化（schema-conditioned）的概率预测**，与 System-2 的推理和生成解耦。一个模型可处理多种决策类型，并输出可用于"是否升级到 System-2"的置信度。

### 2.2 三大组件

**（i）System-1 搜索决策模型（直接 Logit 读出）**
- 对每个决策任务 $f$，输入 $x_f$ 由搜索状态 $s$、任务问题与输出类型、合法选项 $V(f)$ 组成；
- 每个选项配对一个**单 token 标签**（如 A、B）；
- 直接取首个输出位置的词表 logits，仅对合法标签归一化：
  - 打分：$\ell_f(v) = [z_\theta(x_f)]_{\alpha_f(v)}$
  - 概率：$p_f(v) = \text{softmax}_{u \in V(f)} \ell_f(u)$
- 关键点：**不生成任何结构化文本、不做 JSON 解析**，仅复用 LM 原有的词表投影，无决策专用新增参数。

**（ii）软标签学习用于校准决策（SLCD）**
- 用软目标 $t_f$ 表达监督中的不确定性（对无分布标签使用 one-hot）；
- 损失函数为交叉熵与 Brier 损失的加权组合（两者均为严格恰当评分规则，唯一最优解为目标分布）：
  $$L_f = w_f\left[-\sum_v t_f(v)\log p_f(v) + \lambda_B \sum_v (p_f(v)-t_f(v))^2\right]$$
- 对 LLM 标注、演示、构造性改写样本赋予 $w_f=0.5$ 降权；
- 训练后按**输出类型**（Choice/Score/Noul）在留出验证集上拟合正温度 $T_{\kappa(f)}$，得到校准分布：
  $$\tilde p_f(v) = \text{softmax}_v\left(\ell_f(v)/T_{\kappa(f)}\right)$$
- 还通过中英文改写字段描述、打乱无序选项位置来降低位置偏差。

**（iii）双系统搜索智能体**
- System-2 负责：规划、查询生成、最终答案合成；
- SearchJev（System-1）负责：模式定义的六类短决策；
- **置信度门（confidence gate）**：当 $\max_v \tilde p_f(v) \ge \delta$ 时接受 System-1 判断，否则将同一决策问题委托给 System-2；
- 搜索控制器把解决后的判断映射为 search / open / rerank / stop 等动作，检索证据更新搜索状态。

### 2.3 SearchDecision-Bench
- 将异构监督源统一为"状态–模式"（state-schema）格式，覆盖 **6 类决策**：routing、rewriting、relevance、sufficiency、navigation、verification；
- **3 种输出类型**：Choice（类别选择）、Score（序数打分）、Noul（二元判断）；
- 标签来源包括原始标注、派生标签（如 MuSiQue 分解、VitaminC 反证对）、LLM 教师/投票；约 **33.7%** 训练行由 LLM 参与标注。
