## 摘要
扩展注意力参数可以提升语言模型质量，但在长上下文中保留完整的 token 历史会使额外注意力头代价高昂。此外，由于注意力会检索并组合上下文信息，参数扩展也应支持更长的上下文。因此，我们探究注意力参数扩展是否能够直接实现高效且有效的上下文扩展。我们提出 NAMOH，一种架构原生的稀疏注意力机制，每个 token 激活 H 个头中的 K 个头。每个头仅保留分配给它的 token，并在该子序列内执行因果注意力。因此，头选择无需扫描完整历史，即可共同决定激活参数与可用上下文。在均衡分配下，固定 K 而增加 H 会缩短各头的历史，并减少每个 token 的键值（KV）访问量，同时不增加总 KV 存储。我们进一步支持头相对旋转位置编码，以缩短路由后子序列内的位置跨度，旨在缓解位置引起的注意力噪声。实验表明，NAMOH 能超越总参数量相同的全激活模型，同时相比激活参数量匹配的更小稠密模型，可实现更高效的长上下文推理。它与 GQA 及现有稀疏注意力机制保持兼容。我们希望这项工作为扩展注意力提供一条新路径，使参数扩展能够直接促成上下文扩展。

## Abstract
Scaling attention parameters can improve language model quality, but retaining full token histories makes additional heads costly at long contexts. Furthermore, since attention retrieves and combines contextual information, parameter scaling should also support longer contexts. We therefore ask whether attention parameter scaling can directly enable efficient and effective context scaling. We introduce NAMOH, an architecture-native sparse attention mechanism that activates $K$ of $H$ heads per token. Each head retains only its assigned tokens and performs causal attention within this subsequence. Head selection thus jointly determines active parameters and available context without scanning the full history. Under balanced assignments, increasing $H$ at fixed $K$ shortens head histories and reduces per-token key-value (KV) access without increasing total KV storage. We further support head-relative rotary position embeddings to shorten positional spans within routed subsequences, aiming to mitigate position-induced attention noise. Experiments show that NAMOH can outperform fully activated models with the same total parameters, while enabling more efficient long-context inference than smaller dense models with matched active parameter counts. It remains compatible with GQA and existing sparse attention mechanisms. We hope this work offers a new path for scaling attention, with parameter scaling directly enabling context scaling.

- **现有方案不足**：
  - 线性时间循环架构将历史压缩为固定状态，可能丢失精确召回所需信息。
  - 选择型稀疏注意力保留显式 token 记忆，但引入 token/块选择开销；若索引器扫描全前缀，开销随上下文增长。
  - 稀疏化本身不解决位置问题：长 RoPE 跨度可能导致 query-key 虚假对齐、不同位置/ token 注意力分数难以区分、相关性排序反转等位置噪声。
- **核心问题**：**注意力参数扩展能否直接实现高效且有效的上下文扩展？**
- **整体含义**：提出 NAMOH，将注意力参数扩展与上下文扩展耦合，使参数增长直接带来更高效、更有效的长上下文能力，为注意力缩放提供新路径。

## 2. 方法论：NAMOH 核心思想与关键技术

### 2.1 核心思想

- 将每个注意力头视为一个“专家”，学习路由器为每个 token 激活 H 个总头中得分最高的 K 个。
- 路由同时决定两件事：**活跃的头参数** 与 **每个头处理的 token 子序列（可用上下文）**。
- 每个头仅在其路由子序列内执行因果注意力，层用路由权重组合投影后的头输出。
- 稀疏性直接来自路由结构本身，而非对稠密注意力结果施加掩码。

### 2.2 关键技术细节

- **Token-to-head 路由**：
  - 路由器计算亲和度：`a_t = softmax(x_t W_r)`，`W_r ∈ R^{d_model×H}`。
  - TopK 选择：`S_K(t) = TopK_i(a_{t,i})`，掩码 `m_{t,i} = 1{i ∈ S_K(t)}`，门控 `g_{t,i} = m_{t,i} a_{t,i}`。
- **稀疏投影与注意力**：
  - 对头 i，定义有序索引集 `I_i = {t : m_{t,i}=1}`，长度 `n_i = |I_i|`。
  - 仅活跃 token-head 对计算 QKV：`q_{t,i}=x_t W_Q^(i)`，`k_{t,i}=x_t W_K^(i)`，`v_{t,i}=x_t W_V^(i)`，`t∈I_i`。
  - 非活跃对不生成 QKV，不占 KV 缓存。
  - 头内因果注意力：`h_{t,i} = Attn(eq_{t,i}, [ek_{s,i}], [v_{s,i}])`，`s∈I_i, s≤t`。
  - 输出聚合：`o_t = Σ_{i∈S_K(t)} g_{t,i} h_{t,i} W_O^(i)`。
- **负载均衡**：
  - 定义分配比例 `f_i` 与平均亲和度 `p_i`，均匀目标 `f_i = p_i = 1/H`。
  - 三种策略：CV 重要性正则、Switch 式 (f p) 平衡、无辅助损失平衡（调节头特定路由偏置）。
  - 防止头坍塌，同时保证上下文稀疏性（避免路由集中在固定子集导致其历史变稠密）。
- **路由即上下文选择**：
  - 每个头维护自己的路由历史，选择头即选择 query 可用的上下文。
  - 路由器充当对历史的学习型索引器，无需重新评分历史 key/块。
  - 均衡路由下每头历史约 `TK/H` 条目，且可与 token/块级稀疏进一步兼容。
- **KV 成本**：
  - 总 KV 存储 `M_KV = TK`；解码时历史 KV 激活 `A_KV(T) ≈ TK²/H`。
  - 相对 H 头 MHA，存储降至 `K/H`，激活约 `(K/H)²`；相对 K 头 MHA（匹配活跃参数），存储不变，激活约 `K/H`。
  - 例：H=32、K=8 时，总 KV 存储为 32 头全注意力的 1/4，等于 8 头全注意力；均衡下每头约 L/4 条目，8 个活跃头每 token 访问约 2L 条目，KV 激活比率为 1/16 与 1/4。
- **头相对 RoPE**：
  - 用 token 在路由头子序列中的排名 `ρ_i(t) = Σ_{s=0}^t m_{s,i} - 1` 替代全局位置进行 RoPE。
  - 均衡路由下将编码跨度从 T 缩短至约 `TK/H`，保持 token 顺序但改变原始距离，旨在缓解位置引起的注意力噪声。
- **高效执行**：
  - 训练/预填充：将每个 (batch, head) 子序列打包为独立序列，用变长 FlashAttention；总打包长度固定为每序列 TK。
  - 使用长度感知调度，交错不同因果工作量的 query tile，减少 GPU 尾部空闲。
  - 解码：仅启动活跃头 query，仅读取/更新对应 KV 缓存。
