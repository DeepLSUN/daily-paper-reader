## 摘要
同策略蒸馏（OPD）利用学生模型自行生成的轨迹来训练学生模型，但在长推理轨迹上传输密集的教师分布会造成难以承受的通信与内存瓶颈。因此，实际系统依赖稀疏的教师接口，通常只传输采样词元的分数或一个小的 Top-k 分布。然而，这种稀疏设置面临一个根本性困境：采样词元估计量是无偏的，但存在严重的梯度方差；而直接优化 Top-k 目标则会引入系统性偏差。为改善这一权衡，我们提出 ResOPD（带尾部残差化的同策略蒸馏），其在同策略采样下提供无偏的全词表反向 KL 梯度估计，并在所评估设置中，于相同稀疏载荷下实现显著方差降低。ResOPD 将未观测词表聚合为一个可观测的粗粒度尾部事件，计算其精确的聚合梯度，并仅对尾部内部的细粒度残差进行采样，无需额外的教师查询或前向传播。大量实验表明，ResOPD 显著降低梯度方差、稳定在线训练动态，并在所评估设置中提升下游性能。这些结果确立了 ResOPD 作为一种高效、即插即用的稀疏同策略蒸馏方差降低原语。

## Abstract
On-policy distillation (OPD) trains a student model on self-generated trajectories, but transmitting dense teacher distributions across long reasoning traces creates prohibitive communication and memory bottlenecks. Practical systems therefore rely on sparse teacher interfaces, typically transmitting either the sampled-token score or a small Top-$k$ distribution. However, this sparse setting faces a fundamental dilemma: sampled-token estimators are unbiased but suffer from severe gradient variance, whereas directly optimizing Top-$k$ objectives introduces systematic bias. To improve this trade-off, we propose ResOPD (On-Policy Distillation with Tail Residualization), which provides unbiased full-vocabulary reverse KL gradient estimation under on-policy sampling, with substantial variance reduction under the same sparse payload in the evaluated settings. ResOPD aggregates the unobserved vocabulary into an observable coarse tail event, computes its exact aggregate gradient, and samples only the fine-grained within-tail residual, which requires no additional teacher queries or forward passes. Extensive experiments demonstrate that ResOPD substantially reduces gradient variance, stabilizes online training dynamics, and improves downstream performance across the evaluated settings. These results establish ResOPD as an efficient, plug-and-play variance reduction primitive for sparse on-policy distillation.

### 1.1 研究动机与背景

- **同策略蒸馏（On-Policy Distillation, OPD）** 通过学生模型自行生成的轨迹，利用教师模型的 token 级监督进行训练，相比离线蒸馏或监督微调能有效减少长序列上的暴露偏差，已成为前沿大模型后训练（如 Thinking Machines、GLM、DeepSeek）的标准步骤。
- **核心瓶颈**：标准 OPD 需要教师在每个生成 token 上提供完整分布，而现代 LLM 词表可达 250K，通信与显存开销随词表规模和 rollout 长度急剧增长，严重阻碍规模化。
- **实际妥协——稀疏 OPD**：训练系统通常只暴露稀疏教师接口，每步仅返回 Top-k token 概率及采样 token 分数，导致**尾部分布不可观测**。
- **根本困境（偏差-方差权衡）**：
  - 采样 token 估计量（如 Sampled-token OPD）无偏，但单样本蒙特卡洛导致**严重梯度方差**；
  - 直接在 Top-k 支撑上定义目标（截断、重归一化、ghost token 聚合）是全体词表反向 KL 目标的**有偏替代**；
  - 混合方案 HETS 精确评估头部，但将尾部修正完全视为未知，每次尾部命中需补偿整个被省略质量，注入巨大梯度尖峰——即便头部覆盖率达 98.4%，30K token 推理轨迹仍含 460–470 次此类尖峰，每个优化步累计数千次。

### 1.2 整体含义

- 论文在**梯度估计量层面**分析稀疏 OPD，揭示任何“精确头部 + 前缀相关控制向量加权学生尾部质量 + 尾部命中修正”的估计量都是无偏的，HETS 只是控制向量为零的特例。
- 通过**协方差迹分解**，将方差拆分为不变的尾部内采样项与正比于控制向量偏离真实尾部均值的“事件间项”，从而解释 HETS 梯度尖峰的根源。
- ResOPD 作为**即插即用的方差缩减原语**，在不增加教师载荷、不增加前向传播的前提下，实现无偏且低方差的稀疏 OPD 梯度估计。

## 二、方法论

### 2.1 核心思想

> 将未观测词表聚合为一个**可观测的粗粒度尾部事件（pseudo-token）**，精确计算其聚合梯度作为尾部均值的预测器，再仅对尾部内部的细粒度残差进行采样修正。

### 2.2 关键公式与算法流程

**（1）全体词表反向 KL 梯度与有偏替代**

- 定义 $r_i = \log(p_i/q_i)$，$s_i = \nabla_\theta \log p_i$，$G_i = r_i s_i$。
- 全体词表反向 KL 梯度：$g = \sum_i p_i G_i = \mathbb{E}_{A\sim p}[G_A]$，即采样 token 梯度是其无偏估计。
- 三种 Top-k 替代均有偏：
  - **重归一化**：仅学习头部条件分布，尾部 logit 梯度恒为零；
  - **截断**：引入边界项 $C_S$，当 $C_S>0$ 时梯度下降会增大所有被省略 logit，全局最优偏好约 $1-1/e$ 的学生质量落在教师头部之外；
  - **停止系数梯度**：虽避免边界项，但尾部期望未修正，$g_{\text{Top-}k} - g = -\tau_p \mu_{\text{tail}}$，仍固有偏差。

**（2）HETS 及其方差问题**

- 头部 $h = \sum_{i\in S} p_i G_i$ 精确已知；$\tau_p = 1-P$，$\mu_{\text{tail}} = \mathbb{E}[G_A | A\notin S]$ 不可得。
- HETS：$\hat{g}_{\text{HETS}} = h + J G_A$，其中 $J = \mathbb{I}\{A\notin S\}$，无偏但尾部命中时需补偿整个尾部均值。

**（3）ResOPD 估计量**

- 尾部桶（tail bucket）：$b = \log(\tau_p/\tau_q)$，$\bar{s}_{\text{tail}} = \nabla_\theta \log \tau_p$，$\mu_B = b\bar{s}_{\text{tail}}$。
- 粗粒度完整分布的精确梯度：$g_{\text{coarse}} = h + \tau_p \mu_B$。
- 通用单控制族：$\hat{g}(B) = h + \tau_p B + J(G_A - B)$，对任意前缀可测控制 $B$ 无偏。
- **ResOPD**：$\hat{g}_{\text{ResOPD}} = g_{\text{coarse}} + J(G_A - \mu_B)$，即可预测的粗粒度修正每步出现，仅细粒度尾部残差稀有出现。

**（4）方差分解与最优性**

- $\mathcal{V}(\hat{g}(B)) = \tau_p \mathcal{V}_{\text{tail}}(G_A) + P\tau_p \|\mu_{\text{tail}} - B\|_2^2$。
- 第一项与 $B$ 无关；第二项在 $B=\mu_{\text{tail}}$ 时最小。
- ResOPD 严格优于 HETS 的条件：$\|\mu_{\text{tail}} - \mu_B\|_2 < \|\mu_{\text{tail}}\|_2$，即尾部桶向量比零更好地预测真实尾部均值。

**（5）双控制统一族（扩展分析）**

- 引入条件零均值分数波动 $C_A = b(s_A - \bar{s}_{\text{tail}})$，定义 $\hat{g}(B,\gamma) = h + \tau_p B + J(G_A - B - \gamma C_A)$。
- 方差：$\mathcal{V}(\hat{g}(B,\gamma)) = \tau_p \mathcal{V}_{\text{tail}}(G_A - \gamma C_A) + P\tau_p \|\mu_{\text{tail}} - B\|_2^2$，两个控制坐标在迹协方差意义下正交。
- **统一族坐标**：HETS = (0, 0)；ResOPD = ($\mu_B$, 0)；SC-TA = ($\mu_B$, 1)；联合 oracle = ($\mu_{\text{tail}}$, $\gamma^\star$)。
- SC-TA 优于 ResOPD 当且仅当 $\gamma^\star > 1/2$；充分条件 $\mathcal{V}_{\text{tail}}(R_A) < \mathcal{V}_{\text{tail}}(C_A)/4$（条件尾部形状匹配时 $R_A=0$，$\gamma^\star=1$）。

**（6）采样假设边界**

- 无偏性假设 $A\sim p_\theta$ 在固定前缀成立；rollout 过滤器（temperature、top-p、top-k）改变采样律，但截断严格限于序列生成，所有学生量在训练时通过新鲜未截断前向重新计算。
- 在任意实际 rollout 分布 $\tilde{p}$ 下，方差分解仍精确成立，ResOPD 在 $\|\tilde{\mu}_{\text{tail}} - \mu_B\|_2 < \|\tilde{\mu}_{\text{tail}}\|_2$ 时仍优于 HETS。
